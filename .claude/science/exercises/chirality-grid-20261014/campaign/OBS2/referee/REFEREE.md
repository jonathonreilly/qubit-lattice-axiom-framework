## 3. Counterterm count, tuning, and set-C reallocation

### What is established

- A generic (3\times3) corner/axis velocity table has nine real diagonal-derivative entries.  Quotienting by the common speed and common tetragonal directions leaves seven.  Therefore seven $\kappa_{ca}$ components per affected chiral field, hence 14 on (Q) and (d^c), are a **sufficient generic component basis** for canceling the complete projected tensors (`scripts/sizes2.py:55-73`; `REPORT.md:52-57`).
- If set C contains only the nearest-neighbour speed operator, one additional cubic (A_1) tetragonal coefficient for each independently renormalized SM chiral multiplet is sufficient; the worker counts (Q,u^c,d^c,L,e^c), giving five (`REPORT.md:54-59`).  `ct_check.py` correctly establishes locality/cubic covariance of that particular momentum structure (`scripts/ct_check.py:1-10,20-35`).
- For the vector (d)-coefficient alone, the claimed fractional precision is arithmetically correct: over the low-scale and 0.45-rescaled Yukawa brackets, \(10^{-22}/|c_{TT}^d|\) ranges from (2.9\times10^{-15}) to (5.5\times10^{-14}) (`ref_tuning.out:1-2`; `scripts/sign_check.out:1-4`). If every vector and axial coefficient is quoted separately, the looser end extends to about (1.6\times10^{-13}) because (|d_{TT}^d|\simeq|c_{TT}^d|/3); the required *finest* tuning remains (2.9\times10^{-15}).

### What is not established

- **Minimality is not proved.**  Seven is the dimension of a completely generic residual tensor after two projections; it is not the minimum number needed merely to put the experimentally constrained combinations inside bounds, nor is it the number of independent spurion invariants at order (Y^2).  The packet gives no operator-classification theorem excluding a smaller Yukawa-spurion basis.  Therefore 14 is a safe upper bookkeeping count for the chosen component basis, not a certified minimal price.
- **The five tetragonal coefficients are also not a minimal observational price.**  Several branch-B circulant sectors average the corner-covariant tetragonal pattern to an isotropic term, and only coefficients needed for constrained physical combinations must be tuned for the fixed LV reading.  Conversely, if exact unbroken Spin(10) is imposed, five independent SM-multiplet coefficients are not available without explicit Spin(10)-breaking Higgs/flavon insertions.  The report calls the proposed terms (G_{\rm SM})-invariant and merely says cubic covariance can be restored with a spurion (`REPORT.md:52-57`); it does not write the Spin(10)-invariant completion demanded by `TESTS.md:313-314`.
- Consequently, `19` (or `14`) is not established as the minimal count of named, local, **X2-symmetric** counterterms.  A frozen $\kappa_{ca}$ array explicitly breaks the cubic action; formal covariance requires a specified dynamical spurion and its transformation law.  That missing completion is precisely what separates a sufficient component cancellation from the fixed `LV-PRICE(n)` claim.
- The strange-quark arithmetic, (1.5)-28 times (10^{-9}), is correct only after identifying the meson coefficient (c^K) with a valence-(s) coefficient (`REPORT.md:43-47`; `scripts/sign_check.out:1-4`). The worker properly labels the map "suggested"; it cannot support a model-independent minimal count.
- The statement that no reallocation of set C gives `LV-SAFE` is therefore **conditional**.  Algebraically, a common shift that cancels (d) moves (s) to roughly (+4\times10^{-8}), so it fails if the suggested kaon map is adopted (`REPORT.md:59-60`).  Without that map, the packet has not solved the full constrained multi-sector optimization using only direct SME rows, so the absolute "no reallocation" statement is too strong.
