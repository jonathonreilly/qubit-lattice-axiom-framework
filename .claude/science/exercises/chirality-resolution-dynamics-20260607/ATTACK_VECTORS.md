# Attack Vectors

## R1: Staggered Anticommutation Filter

Try to derive a current-surface reason that the physical kinetic operator must
obey `{D,gamma5}=0`.  Existing finite enumeration then forces `epsilon(x)` up to
global sign.

Stop condition: if vector-like/trivial sign assignments remain allowed, the
staggered chirality selector stays admitted.

## R2: Canonical Orientation Section

Try to derive a canonical section of the determinant/orientation line that can
act as a local source sign.

Stop condition: if both torsor sections remain equally coherent, hosting has not
become selection.

## R3: Eta / Spectral-Flow Filter

Try to turn eta or spectral flow into a native oriented boundary/index sector
that supplies an asymmetric filter without importing a source action.

Stop condition: if the boundary orientation or mass sign is supplied externally,
the route is still conditional.

## R4: Record-Compatible Instrument

Try to build a finite instrument where carrier chirality is realized upstream and
Record only tallies or conditions on it.

Stop condition: if Record is asked to create the carrier chirality, the route
violates the refresher boundary.

## R5: Koide / Generation Readout Separation

Separate signed spectral classifiers from anticommuting chirality and from
first-order holomorphic readout.  A readout can be a filter only if a native
theorem selects it.

Stop condition: if the readout is chosen because it gives the desired value, it
is an admitted selector.
