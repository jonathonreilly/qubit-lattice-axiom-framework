# Reframing

The original analogy was:

> An enzyme can flip molecular chirality or help separate one hand from a
> racemic production blend.  Could the chirality lane use the same idea?

The framework-native reframing is:

> A chirality lane needs a native asymmetric filter.  Blend and reversible flip
> are insufficient.  Dynamic resolution is only decisive after the filter is
> supplied.

This reframing avoids a new axiom.  It also avoids using Record as a hidden
dynamics axiom.  The useful next work is therefore not "add a chirality
resolution principle", but:

- derive chiral anticommutation from a future retained graded-locality or
  spin-statistics theorem;
- derive a canonical orientation section/source;
- derive an eta/spectral-flow boundary filter;
- or prove no-go results showing these cannot be native on the current surface.
