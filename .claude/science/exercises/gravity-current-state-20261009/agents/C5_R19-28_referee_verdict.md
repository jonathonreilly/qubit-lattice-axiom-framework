It returns \(1+3+9=13\) for \(W(B_4)\), \(1+2+4=7\) for \(O(4)\), and \(2+6+26=34\) for \(O_h\times T\); the respective degree-two Ward-exact dimensions are \(1,1,2\). 3. **§3.2 is sound only under its stated state-symmetry hypothesis.** If the state itself is exactly \(W(B_4)\)-invariant, rank-two invariance forces \(\langle T_{\mu\nu}\rangle=e\delta_{\mu\nu}\), hence \(\rho+p=0\) after a valid OS continuation. But “any vacuum of a \(W(B_4)\)-covariant law” is too strong: a covariant law may have symmetry-breaking vacua, and finite-temperature electroweak-crossover states select a Euclidean-time direction. For such states two independent components are allowed and symmetry does not set the enthalpy to zero. The report partly concedes this at `R19-28_report.md:146-156`; the crossover problem remains OPEN at `TESTS.md:8146-8154,8548-8557`. Moreover, on the literal box setting OS continuation is unavailable because RP has already failed. A homogeneous zero-temperature Higgs vacuum, by contrast, need not break spacetime \(W(B_4)\).
