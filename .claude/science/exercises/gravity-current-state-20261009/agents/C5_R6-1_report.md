## 0. In plain words

- **Is a continuous lattice shift possible?** For a qubit lattice in any dimension, a shift that is a continuous family of finite-range, translation-invariant rules cannot end at the one-site shift. Neither can any finite-range rule that is a square root (or n-th root) of the shift. This extends Lemma G from 1D to d ≥ 2 for every rule that commutes with the lattice translations, which any exact ℝ^d translation group does. For rules with tails, the same is argued but not proved.
- **But exact momentum is a different thing, and it exists.** I built an explicit interacting lattice law in d = 2, with one fermion mode per site, whose particles collide (nonzero 2→2 scattering). Its momentum, taken as a real vector in (−π, π]², adds up exactly in every collision, so umklapp never happens. The trick is that the interaction switches itself off smoothly, but completely, before either colliding particle reaches the zone edge. A switch-off that is exactly zero over a finite range of momenta cannot come from an analytic (exponentially local) rule. So the rule's couplings fall off faster than any power of distance but slower than exponentially. That is the price, and it is sharp in the class where it is proved.
- **What this does and does not open.** It removes "no exact additive momentum on a grid" as a wall in the stated class. It does not touch the boost wall (C3/I1/RN2), the need for the momentum to equal the energy current (RG G3: SLAC matter), or the one-cone problem. Grid sets are not shown to produce an exact graviton.
- **Against the fixed readings: REFUTED** (worker reading; codex referee required before recording). Scope: fermionic finite-per-site law (graded tensor product). The ⊗M₂(C) qubit version is only suggested, through exact 2D bosonization, and holds in the flux-free sector only.

## 3. Probe (a): the index in d ≥ 2

**Lemma A0 (wrapping) — proved, elementary.** Let β be an H-TI QCA of range R on Z^d, and L > 6R. Applying the same local rule on the cylinder Z × Z_L^{d−1} defines a QCA β^{(L)} of range R.
- *Why it is a QCA.* Images of two sites can overlap on the cylinder only if some lifts lie within 2R. Both supports then sit in a box of side 6R + 1 that embeds injectively, so the plane commutation relations carry over. The wrapped β⁻¹ inverts β^{(L)} by the same embedding argument.
- *Composition.* For L > 6(R_β + R_γ), (βγ)^{(L)} = β^{(L)}γ^{(L)}.
- *The shift.* T_1^{(L)} is the cylinder shift. Grouping each transverse slice into one supersite of dimension D = 2^{L^{d−1}}, it is a 1D shift of index D (GNVW convention; reciprocal in the other).

**Theorem A1 (paths) — proved, conditional on GNVW (published, RECALLED: index is a locally constant rational, multiplicative, and on-site QCAs have index 1).**
- *Claim.* No point-norm-continuous path s ∈ [0,1] ↦ α_s of H-TI QCAs with uniform range R has α_0 = id and α_1 = T_1, in any d ≥ 1.
- *Proof.* Under H-TI, continuity of the local rule at site 0 is uniform over sites. So the wrapped path is a continuous path of 1D QCAs with range R. Its index is constant, but 1 ≠ 2^{L^{d−1}}.

**Corollary A2 (roots; no continuity needed) — proved, conditional on GNVW.**
- *Claim.* No H-TI strict-range QCA β on qubits satisfies β^n = T_1 for any n ≥ 2.
- *Proof.* Take L ≡ 1 (mod n) with L large. On supersites of dimension 2^m the GNVW index lies in 2^Z. Then ind(β^{(L)})^n = 2^{L^{d−1}} has no solution, because n does not divide L^{d−1}.
- *Consequence.* There is no H-TI one-parameter group α_s with α_1 = T_1 in which even one α_{1/n} has strict range.

**Remark A3 — proved, trivially.** H-ℝ^d implies H-TI for every α^{(j)}_s, since α^{(1)}_s commutes with α^{(k)}_1 = T_k. So A1 and A2 cover every exact ℝ^d translation group whose elements have strict range. This removes the infinite-transverse obstacle flagged by the O2 and N1 referees *for translation groups*.

**(a)(ii), with Lieb–Robinson tails — suggested, with one named gap.**
- *Sketch.*
  - Wrap the generator, not the automorphism.
  - On the cylinder, α^{(L)}_1 is a 1D Hamiltonian evolution, so its RWW index is 1 (RECALLED).
  - By the Lieb–Robinson comparison, ‖α^{(L)}_1(a) − T_1^{(L)}(a)‖ ≤ C L^{d−1} e^{−μ′L} ‖a‖ for supersite operators a.
  - The contradiction needs index stability under ε-perturbation with ε₀ independent of the supersite dimension 2^{L^{d−1}}. Equivalently, it needs a Choi mutual-information index formula whose continuity loss is O(ε·log dim) relative to L^{d−1} log 2.
- *Where this leaves the open lemma.* That uniformity is the one missing step. It is narrower than the N1 gap: translation invariance removes the transverse partial-factor bookkeeping (`C4_N1_referee.md:28`).
- *Non-translation-invariant strict-range paths in infinite transverse volume.* OPEN. Freedman–Hastings dimensional reduction covers compact manifolds (RECALLED).

**Consistency check.** The witness of §4 has an exact continuous translation group e^{isQ} with e^{iQ_j} = T_j (checked algebraically). Its generator has 1/r tails, so it lies outside both (i) and (ii), as A1–A2 require.

## 4. Probe (c): asymptotic-only charge and the explicit witness

**Lemma U (only if) — proved; essentially RG G1, counted once.**
- Under H-asym with asymptotic completeness, Q is conserved if and only if every S-matrix element between configurations with Σq_in ≠ Σq_out vanishes (a.e.).
- If an amplitude is continuous on a connected shell component that crosses the lift's cut, it must vanish on the umklapp side and therefore at the crossing locus.
- If the amplitude is real-analytic, it vanishes on the whole component (G1).

**Witness W — law stated; exactness proved; scattering checked.** Spinless lattice fermions on Z^d, d = 2 (any d works; one complex fermion mode per site, local dimension 2).
- **The law.**
  - H = Σ_k (ε(k) − μ) n_k + (λ/N) Σ_K A_K† A_K, with A_K = ½ Σ_k g_K(k) a_{K−k} a_k.
  - g_K(k) = χ(k) χ(K−k) [f(k) − f(K−k)], where χ is a C^∞ plateau bump supported in the open box S = (−a, a)^d with a = 0.49π < π/2.
  - f(k) = sin k_x + 0.3 sin k_y (p-wave, antisymmetric).
  - ε is nearest-neighbour or NNN hopping (strictly local). μ is below the band and λ > 0, so the Fock vacuum is the gapped ground state.
- **Exactness (proved, two lines).**
  - If g_K(k) ≠ 0, then k and K−k lie in S, so q̂(k) + q̂(K−k) ∈ (−2a, 2a)^d ⊂ (−π, π)^d. That sum is the unique representative K̂ of K, independent of k.
  - Hence [Q, A_K] = −K̂ A_K, where Q = Σ_k q̂(k) n_k and q̂ is the sawtooth lift. So [Q, H] = 0 exactly, and e^{iQ_j} = T_j.
  - Q is an exact, additive, ℝ^d-valued momentum on every state, asymptotic states and bound states included.
- **Scattering data (checked, `r61_witness_tmatrix.out`).** On-shell T-matrix, L = 240, η = 0.05:
  - nonzero for in-box shells: max|T| = 14.6 at K = (0.3, −0.2), E = −5 (NN), with 12100 nonzero on-shell elements;
  - zero umklapp elements: max |Q_out − Q_in| = 6.7e-16 over all nonzero elements, on every shell tested;
  - on "mixed" shells, which carry both box pairs and pairs of another Q class (22 found for NN, 1547 for NNN), W has up to 9604 nonzero elements and still 0 umklapp.
- **The analytic comparator (χ ≡ 1)** has umklapp on the same shells: |T|² fractions 0.11–0.72 (e.g. 0.592 at K = (−2.62, −1.57), E = 3, NNN). This reproduces G1.
- **Many-body checks (checked, `r61_fock_and_decay.out`).**
  - N = 2, all 256 modes at L = 16: H is Hermitian to 7e-18, and max|ΔQ| = 1.3e-15 over 11864 nonzero off-diagonal elements.
  - N = 3 (49 box + 12 edge modes): ‖[H, Q_x]‖ = 2.8e-17.
  - Comparator, N = 3, L = 8: ‖[H, Q_x]‖ = 0.95 and ‖[H, Q_y]‖ = 1.64.
  - Time evolution from a high-Q_x configuration: ⟨Q_x⟩ drift is ≤ 1e-14 for W, against −0.026, −0.064, −0.124, −0.165 at t = 0.5, 1, 2, 4 for the comparator.
- **Locality (checked).**
  - The real-space kernel of χ falls as 0.31, 6.9e-4, 3.9e-7, 2.9e-13 at distances 1, 32, 128, 512. That is faster than any power and slower than exponential: a fitted stretched exponent β ≈ 0.3, rough; Gevrey-2 behaviour, exp(−c√r), is expected.
  - H is therefore a quasi-local interaction with super-polynomial tails. Lieb–Robinson bounds with sub-exponential F-functions apply (RECALLED: Nachtergaele–Sims–Young).

**Proposition N (the locality price is sharp, in the rank-one separable class) — proved, with Denjoy–Carleman/Beurling RECALLED.**
- *Setting.* A rank-one-per-K separable interaction with pair form factor G(k₁, k₂) on T^d × T^d, a dispersion whose shell map is a submersion near mixed shells, and mixed shells present (true for NN/NNN, checked).
- *Claim.* Exact Q with nonzero scattering forces G to vanish on a nonempty open set of pair space. Proof: T ∝ G*(out)G(in). The other-class partners of an open set of in-pairs with G ≠ 0 sweep an open set, and G must vanish there.
- *Consequences.*
  - G is not quasi-analytic. So its real-space kernel cannot decay like e^{−w(r)} with ∫w(r)/r² dr = ∞ (for regular w). Exponential and e^{−r/log r} tails are excluded.
  - Conversely, any non-quasi-analytic weight (e.g. e^{−r/log²r}, e^{−r^β} with β < 1) admits such bumps, so W can be built at that decay.
- *Agreement with prior art.* This matches RN L2's "exponentially quasi-local" boundary (`TESTS:858`) and RG's "finite range ⇒ analytic" (`RG_G1_report.md:183`).
- *Beyond the separable class.* Suggested only. The general non-perturbative finite-range case stays as RG left it.

**Generalization — proved by the same commutator, not run.**
- Put one rank-one channel per pair (K, m), where m is the Q-class, with form factors that vanish to infinite order whenever a leg reaches the cut (the zone boundary).
- Every A_{K,m} lowers Q by K̂ + 2πm, so Q is still conserved.
- Interactions then act at all momenta except a measure-zero cut. The "free zone-edge particles" in W are not essential, only the infinite-order vanishing at the cut.

**Qubit (⊗M₂) transfer — suggested.**
- Exact 2D bosonization (Chen–Kapustin–Radičević 2018; Verstraete–Cirac auxiliary fermions; RECALLED) maps parity-even quasi-local fermionic operators to quasi-local gauge-invariant qubit operators that commute with local flux constraints.
- In the flux-free sector, which is dynamically closed, contains the vacuum and contains all fermion scattering states, the qubit law reproduces W exactly.
- In sectors with static flux or constraint defects (creatable by local operators), fermions scatter off flat-band defects, and Q is **not** conserved there.
- Hard-core-boson qubit versions fail: the hard-core contact amplitude is momentum-independent, so it has umklapp. The fermion sign map is non-local in 2D (checked by hand, not run).

**Comparator, d = 1 (RECALLED).**
- Integrable chains (XXZ) are non-diffractive, so Σf(k_i) is conserved for every f.
- In 1D, even a generic nearest-neighbour 2→2 collision between equal-dispersion particles returns the same momentum set.
- d = 1 is therefore cheap and outside the fixed reading. Any no-go must use d ≥ 2 kinematics. The REFUTED direction was found through non-analyticity, not integrability.
