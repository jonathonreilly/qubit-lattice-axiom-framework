# Reduction to decisive objects

The immediate requirement is to establish which ground state is being studied.
Delete matter, gravity, empirical scale matching and continuum rhetoric from
this first block. Keep the exact local rates, three-state carrier, physical
mod-three constraint, integer-divergence sectors, and boundary data. The
smallest complete falsifier is an open cube; the next is two joined cubes.
It can refute a universal sector comparison but cannot establish a 3D phase.

There are two independent penalty dials. Sending the temporal mismatch penalty
to infinity removes all branch wraps. Sending the spatial charge penalty to
infinity removes charge-changing transitions, which need not remove every
branch wrap. Derive both projected generators before treating their low-energy
models as the same object. This is a concrete possible improvement over simply
repeating the prior hard-limit correspondence.
