# Private bindings and possible public projection

This private comparison authenticates the complete immutable independent PRE
and the released author packet. It does not publish or stage any file.
Scientific snapshots use relative aliases plus exact hashes so a relocated
public archive need not reproduce private absolute working paths.

The independent PRE includes three historical instruction snapshots under
sources/instructions/. They remain unchanged and bound privately. A public
projection may omit their bytes, as directed by the root, while recording
these omitted paths and hashes explicitly rather than claiming the public
bundle contains the entire private PRE inventory.

No third-party paper or extracted third-party text was copied into this clock
comparison. The released prior finite-supply comparison and seal include
bibliographic hash metadata for a private external paper. That metadata is
provenance, not an instruction to include the paper, and it does not make this
comparison's scientific controls depend on a private PDF path. Any public
projection should explicitly distinguish omitted external provenance from the
scientific files actually distributed.

The private FINAL_SEAL.json will bind all local evidence. A later public
projection needs its own manifest stating included scientific bytes, unchanged
private source identities and explicit provenance omissions. This task neither
creates that projection nor changes the frozen PRE or root source files.
