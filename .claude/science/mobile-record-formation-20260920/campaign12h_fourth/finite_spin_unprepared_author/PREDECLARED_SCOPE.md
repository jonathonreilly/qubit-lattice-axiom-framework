# Unprepared first-output probe

The prepared flat-sector candidate covers only half the actual first-mark
output. Test the full finite-spin no-event target in the joint scaling,
starting from the exact normalized first resolved/coherent edge-0 mark on
an initial zero-circulation field. This state requires no added projection.
Retain the full physical finite-spin Gauss sector. Compare the count curve
with the rotor-first prediction only as a countercontrol; their limits differ
in order and need not coincide.

Measure survival, the physical rotor flat-projector weight, and probability
remaining in a fixed low-circulation window. A possible issue is migration of
the dispersive component to circulation of order S, which would prevent
inferring a strong rotor-space state limit from finite-spin convergence of
some counts. This is a hypothesis, not an established obstruction. Preserve
the data even if it contradicts that picture. No extrapolation theorem,
semiclassical averaging law, or dark-state assertion is supplied by this probe.

On a principal-symbol heuristic only, with p=f/S one expects
H2_S(p,theta) approximately (1-p^2) H2_rotor(theta). The Hamiltonian is
then of order S^2 and its classical phase-space speed of order S. The
subprincipal charge terms, level crossings, boundaries and finite formation
rate must be checked before using any such semiclassical description.
