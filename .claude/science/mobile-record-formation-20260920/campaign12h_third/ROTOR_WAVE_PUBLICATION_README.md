# Generated rotor dynamics and prepared transverse waves

This draft extends [PR 8635](https://github.com/jonathonreilly/qubit-lattice-axiom-framework/pull/8635)
from a spin-half ring model to a compact rotor with both electric and magnetic
terms generated by the same permanent-record hopping. A subsequent, separately
controlled weak-field limit carries two transverse harmonic polarizations.
These are conditional mathematical constructions with independently reconstructed
proofs and selective numerical controls. They are not retained-grade conclusions
or a derivation of observed electromagnetism from the native axioms.

## Scientific chain and supplied premises

1. **Microscopic record motion to a rotor.** Start with the base PR's bosonic
   hard-core qutrit records, an A-occupied/B-empty prepared sector and selected
   Gauss background div E+1_A-q=0 on cubic tori with even periods at least six.
   Replace each link by integer spin S and U=S_+/sqrt(S(S+1)). Neither the
   link memory nor the quantum dynamics is derived from a native single qubit.

   With C=S(S+1), fixed K,J>0 and epsilon^2=J/(2KC), take
   Delta=2K^2 C^2/J, t=epsilon Delta, beta=beta0 epsilon^(2d).
   Virtual hopping generates K sum E^2-J sum(W+W^dagger).
   A fixed local dressing and a uniform per-link fourth electric moment give
   an O(epsilon) local-observable error on fixed times, uniformly in volume.
   Formation remains enabled at finite S; its rate vanishes in this limit.
   The nonunitary-link electric mechanism is established quantum-link
   machinery, credited to Zohar, Cirac and Reznik in the source.

2. **Rotor to prepared weak-field waves.** In three dimensions fix the finite
   box, spacing a and speed parameter c, and use
   K=c g^2/(2a), J=c/(2a g^2). Select zero global electric flux as well as
   Gauss; the harmonic directions are an extra sector choice.
   A compact-chart cutoff of a prescribed finite Hermite packet approximates
   its transverse oscillator evolution with O(g^2) vector error at fixed time.
   The lattice frequencies are
   omega(k)=(c/a)sqrt(4 sum_i sin^2(k_i/2)), with two polarizations.
   Taking a subsequent continuum limit on a fixed finite list of physical
   modes gives the massless free dispersion.

The order is S to infinity at fixed box and g, then g to zero at fixed box,
then a to zero for the specified finite modes in a fixed physical box.
No uniform simultaneous resource schedule is inferred. The initial dressing,
small-angle state, coherent Hamiltonian, scales, reservoir and c remain
supplied. No thermodynamic Coulomb phase, autonomous state selection, full
continuum QFT, finite limiting record production, native compiler or TOE
closure is established.

## Reproducibility and source mapping

Run python3 on verify_rotor_wave_publication.py in this directory for portable,
read-only byte and selected-seal binding verification. It does not execute the
science or confer a verdict. PUBLICATION_UNIT_ROTOR_WAVES.json maps all 83
unchanged source artifacts to repository-relative paths. The base PR contains
the prerequisite proofs and controls.

Historic source/result seals retain their original absolute paths. Raw seal
scripts are provenance tools for that original workspace; they should not be
mistaken for portable entry points. Scientific runners use Python with NumPy,
SciPy and SymPy. Rerunning many of them writes result files, so use a disposable
checkout to preserve frozen evidence.

The independent primary-literature HTML and substantial extract are excluded;
their URL, hash and read receipt remain. The new homogeneous charged-matter
model and other unreviewed campaign routes are outside this PR.
