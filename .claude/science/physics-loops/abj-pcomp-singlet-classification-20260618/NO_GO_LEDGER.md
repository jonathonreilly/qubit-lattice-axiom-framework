# No-Go Ledger

- Removing the neutral-singlet condition `n = 0` leaves a one-parameter
  family. Counterexample: `(x,y,z,n) = (0, 2a, -2a, -4a)` cancels the same
  anomaly traces but has no neutral singlet.
- Reducing the two color-triplet singlet slots to one leaves the `SU(3)^3`
  count uncanceled by this template.
- The theorem intentionally does not use the electric-charge sign convention;
  that convention only labels the `x <-> y` swap.
