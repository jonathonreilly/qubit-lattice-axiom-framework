# Assumptions And Imports

## Closed finite input

- Boolean corner cube `{0,1}^3`.
- Coordinate-permutation/bit-flip relabelings
  `x_i -> x_{pi(i)} xor f_i`, with `pi in S_3` and
  `f in (Z_2)^3`, giving order 48.

## Not imported

- Full affine group `AGL(3,2)`.
- Arbitrary Boolean maps.
- Physical matter-sector bridge.
- Tier-A registry edit.
- Charged-lepton value or readout context.
