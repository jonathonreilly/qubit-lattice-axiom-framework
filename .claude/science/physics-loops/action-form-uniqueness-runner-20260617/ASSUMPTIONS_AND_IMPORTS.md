- The verifier uses only the source note candidate set, canonical `N_c=3`,
  `g_bare=1`, and the retained Casimir value behind `exp(-2/3)`.
- The Manton matching check follows the note's own equation
  `beta_W/(4 N_c) = 1/(2t) = beta_M/2`, giving `beta_M = 1` for
  `beta_W = 6`, `N_c = 3`, `t = 1`.
- Wilson one-plaquette value is used as the note's own finite-beta comparator.
- The later heat-kernel diffusion theorem is used only to prevent overreading:
  it sharpens a conditional route but leaves the gauge-link diffusion premise
  open.
- No audit verdict, ledger row, or publication status is changed here.
