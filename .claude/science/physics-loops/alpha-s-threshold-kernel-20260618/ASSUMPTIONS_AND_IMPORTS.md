# Assumptions And Imports

- SU(3) group factors used on the existing QCD running surface:
  `C_A = 3`, `T_F = 1/2`.
- One-loop active-flavor running equation:
  `d(1/alpha_s)/d ln(mu) = b0(n_f)/(2 pi)`.
- Abstract positive threshold scales only.

Not imported:

- Physical heavy-quark threshold masses.
- Sommer scale setting.
- Higher-loop MSbar decoupling constants.
- Any numeric alpha_s(M_Z) target.
