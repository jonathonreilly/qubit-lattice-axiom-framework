# Assumptions And Imports

## Repo Inputs

- `docs/audit/data/audit_packet_script_deps.json` is generated by
  `scripts/audit_packet_script_deps.py`.
- The generated map helps audit packet assembly include transitive helper
  scripts so auditors do not hit class-C packet incompleteness.
- Ledger rows with `runner_path: null` should be counted as no-runner rows,
  not as missing file paths.

## Imports Avoided

- No audit verdicts or claim statuses are changed.
- No ledger rows are hand-edited.
- No claim truth is imported.

## Open Imports

- This PR refreshes the dependency map but does not run any audits using it.
