    85	directions `n`. Define the scaled-projector effects

    90	element of `S` is an effect; a nonzero element determines its parameters

    92	and, for rank 1, `n` are recovered from the operator). A **scaled-projector
    93	menu** is a finite family of nonzero elements of `S` summing to `1`.

    95	**T1 (exact menu characterization).** A finite family
    96	`{c_k P(n_k)}_k ∪ {d_j 1}_j` of nonzero scaled-projector effects is a menu
    97	iff
    98	
    99	> `Σ_k c_k n_k = 0` and `Σ_k c_k / 2 + Σ_j d_j = 1`.
   100	
   101	Proof: expand in the basis `{1, σ_x, σ_y, σ_z}`; the identity component
   102	gives the scalar condition, the Pauli components give the vector condition.
   103	The family therefore contains, among others: every projective menu
   104	`{P(n), P(−n)}`; every coin `{c 1, (1−c) 1}` and its refinements;
   105	same-direction splits `{λP(n), μP(n), (1−λ−μ)P(n), P(−n)}`; the
   106	axis-cancellation menus of T2; and three-element coplanar menus such as
   107	`{(2/3)P(n_1), (2/3)P(n_2), (2/3)P(n_3)}` with `n_1 + n_2 + n_3 = 0`. It
   108	does not contain any effect with two distinct nonzero eigenvalues (e.g.
   109	`diag(1/2, 1/4)`), so it is a proper subfamily of the parent block's
   110	effect-partition family.

   137	- **(a) Ray additivity.** Fix `n` and write `h(λ) = w(λP(n))`. For
   138	  `λ, μ ≥ 0` with `λ + μ ≤ 1`, T1 validates the same-direction splits

   143	  (`h(μ') = h(μ) + h(μ'−μ) ≥ h(μ)`), rational homogeneity by iteration, and
   144	  the rational squeeze `q_1 h(1) ≤ h(t) ≤ q_2 h(1)` for rationals
   145	  `q_1 < t < q_2`; hence `h(λ) = λ g(n)` for all real `λ ∈ [0,1]`, with
   146	  `g(n) := w(P(n))`.
   147	- **(b) Complement.** The projective menu `{P(n), P(−n)}` gives
   148	  `g(n) + g(−n) = 1`.
   149	- **(c) Axis cancellation.** For a unit `n` with components `n_a`
   150	  (`a ∈ {x,y,z}`), set `L = |n_x| + |n_y| + |n_z| ∈ [1, √3]` and

   154

   156	  part is `c_0 (1 + L)/2 = 1`. Normalization, (a), and (b) give
   157	
   158	  > `g(n) = (1 + L)/2 − Σ_a |n_a| g(−sign(n_a) e_a)

    93	
    94	Let `Λ ⊂ Z^3` be a finite region, `H_Λ = ⊗_{x∈Λ} C^2`, `d = 2^{|Λ|}`, and
    95	`E(H_Λ) = { E : 0 ≤ E ≤ 1 }` the effect algebra of the region algebra. The
    96	landed projective-horn hypotheses H1-H3 place `w ≥ 0` on projections with
    97	`w(0) = 0`, `w(identity) = 1`, menu-normalization on finite orthogonal
    98	resolutions of the identity, additivity, and embedding-independence. The
    99	effect-grade restatement assumed by the effect horn is:
   100	
   101	**(E1) grading exists at effect grade.** There is `w : E(H_Λ) → [0,1]` with
   102	`w(0) = 0` and `w(1) = 1`. As at projective grade, `w` is a function of the
   103	effect alone; the value does not depend on which eligible menu embeds it.
   104	
   105	**(E2) finite effect menus are eligible.** For every finite family
   106	`{E_i} ⊂ E(H_Λ)` with `Σ_i E_i = 1`, the family is an eligible menu and
   107	`Σ_i w(E_i) = 1`.

   110	menu-eligibility clause — in the landed note, universal eligibility is

   113	resolutions replaced by finite effect partitions. They are neither implied
   114	by nor implied-in the projective-grade hypotheses on the same region: the
   115	domain and the menu family are both enlarged, and the enlarged menu family
   116	is a strictly stronger normalization demand. Only finite menus
   117	are used anywhere below; no countable-additivity clause is assumed. Whether
   118	the physical registration supplies menus at projective grade, at effect

   122	## Results
   123	
   124	**T1 (effect horn: sitewise forcing at every finite dimension, no bridge
   125	input).** Assume E1-E2 on a finite region of dimension `d ≥ 2`. Then there is
   126	a unique density matrix `σ` with `w(E) = Tr(σE)` for every effect `E`. The
   127	proof is the five-step finite argument, dimension-generic:
   128	
   129	- **(A) Partial additivity.** For effects with `E_1 + E_2 ≤ 1`, apply E2 to
   130	  the menus `{E_1, E_2, 1 − E_1 − E_2}` and `{E_1 + E_2, 1 − E_1 − E_2}`:
   131	  subtracting, `w(E_1 + E_2) = w(E_1) + w(E_2)`. The two-outcome menu
   132	  `{E, 1 − E}` gives the complement law `w(E) + w(1 − E) = 1`.
   133	- **(B) Homogeneity.** Iterating (A) on the `(r+1)`-outcome menu
   134	  `{E/r, ..., E/r, 1 − E}` gives `w(E/r) = w(E)/r` and then `w(qE) = q w(E)`
   135	  for rational `q ∈ [0,1]`. Monotonicity follows from (A): if `E ≤ F` then
   136	  `F − E` is an effect and `w(F) = w(E) + w(F − E) ≥ w(E)`. For real
   137	  `t ∈ [0,1]` and rationals `q_1 < t < q_2`, the operator inequalities
   138	  `q_1 E ≤ tE ≤ q_2 E` then squeeze `w(tE)` between `q_1 w(E)` and
   139	  `q_2 w(E)`, so `w(tE) = t w(E)`.
   140	- **(C) Linear extension.** `Herm(M_d)` is a real vector space of dimension
   141	  `d^2` spanned by effects (the normalized identity-plus-generator elements
   142	  `(1 + B_k)/2` and `1` itself). Additivity plus homogeneity on the positive
   143	  cone extend `w` to a well-defined real-linear functional `F` on
   144	  `Herm(M_d)`: scale any positive `A` into the effect interval, set
   145	  `F(A) = s·w(A/s)` for `s` dominating the top eigenvalue (well-defined by
   146	  homogeneity), and define `F` on differences; the standard two-sided
   147	  cancellation argument shows representation-independence.
   148	- **(D) Trace representation.** The trace pairing `⟨X,Y⟩ = Tr(XY)` is a
   149	  nondegenerate real inner product on `Herm(M_d)`, so `F(H) = Tr(σH)` for a
   150	  unique Hermitian `σ`, reconstructed linearly from the `d^2` basis values of
   151	  `w`. At `d = 2` this is exactly the landed display
   152	  `σ = ½[ 𝟙 + Σ_{a∈{x,y,z}} (2 m(P_a^+) − 1) σ_a ]`.
   153	- **(E) State property.** `w(1) = 1` gives `Tr σ = 1`; for every unit vector
   154	  `ψ` the rank-1 projector is an effect, so `⟨ψ|σ|ψ⟩ = w(P_ψ) ≥ 0`, hence
   155	  `σ ≥ 0`.
   156	
   157	No step uses `d ≥ 3`, a composite, a projective frame-function analysis, or
   158	any literature theorem. The runner re-derives the load-bearing identities of
   159	every step exactly at `d = 2` and `d = 4`.
   160	
   161	**T2 (effect horn: the landed rogue extends to no effect-grade grading).**
   162	The landed R1 assignment `g` — the lexicographic hemisphere rule on one-site
   163	rank-1 projections, which satisfies the projective-grade hypotheses on
   164	one-site binary menus — extends to no `w` satisfying E1-E2 on a single site.
   165	By T1 any such `w` is a trace form; every `2 x 2` trace form is affine in the
   166	Bloch direction, and the landed exact three-direction contradiction
   167	(`g(e_x) = g(e_z) = 1` with `g(1) = 1` forces the value `1/2` at
   168	`(e_x − e_z)/√2`, where `g` assigns `0`) refutes every trace-form
   169	restriction. The landed note's sentence "Three directions plus normalization
   170	refute every `2x2` trace form at once" is reused unchanged; what is new is
   171	the direction of use: at effect grade the refutation kills the rogue rather
   172	than the forcing, at one site, with no composite and no bridge input.
   173	
   174	**T3 (projective horn boundary: product-projector menus do not force the
   175	Born form on the bonded pair).** Work on a bonded nearest-neighbor pair,
   176	`d = 4`, at projective grade, but with the eligible menus restricted to
   177	product-projector resolutions: finite families of nonzero projectors of the
   178	form `A ⊗ B` (`A`, `B` one-site projectors) summing to the pair identity.
   179	The weight domain remains all pair projections, as in the landed H1; with
   180	the menu family so restricted, values on non-product projections are
   181	constrained by no eligible menu, and the witness below is completed to the
   182	full domain by an explicit arbitrary extension. Then:
   183	
   184	- **(T3a) Classification.** Every product-projector menu is a tree menu: up
   185	  to swapping the two sites, it is `{1}`, or `{P(a)⊗1, P(−a)⊗1}`, or
   186	  `{P(a)⊗1, P(−a)⊗P(d), P(−a)⊗P(−d)}`, or
   187	  `{P(a)⊗P(b), P(a)⊗P(−b), P(−a)⊗P(b'), P(−a)⊗P(−b')}` — a first-site split
   188	  refined branchwise on the second site, or the site-swapped form. The proof
   189	  is a finite case analysis from two exact facts: one-site rank-1 projectors
   190	  are orthogonal exactly when their Bloch directions are antipodal, and
   191	  `(P(a)⊗P(b)) ⊥ (P(c)⊗P(d))` exactly when `a·c = −1` or `b·d = −1`. Three
   192	  pairwise-orthogonal rank-1 products cannot share one first-site direction
   193	  (three mutually antipodal second-site directions are impossible), a rank-3
   194	  complement is never a product projector (product-projector ranks on the
   195	  pair are 1, 2, 4), and a rank-1 product below `P(−a)⊗1` must carry first
   196	  slot `−a` (a rank-1 projector lies below a projector exactly when their
   197	  overlap trace is 1, and `Tr(P(−a)P(c)) = (1 − a·c)/2 = 1` forces
   198	  `c = −a`). The runner gates each fact and each case branch exactly.
   199	- **(T3b) Constructive rogue.** Define `W` on product projectors by the
   200	  product rule `W(A ⊗ B) = g_1(A) · g_2(B)`, with `g_1`, `g_2` lexicographic
   201	  hemisphere rules and `g_i(1) = 1`, `g_i(0) = 0`, and extend `W` to the
   202	  remaining (non-product) pair projections by the constant value `1/2` — an
   203	  arbitrary choice that no product-projector menu constrains, so the
   204	  extended `W` is defined on the full projection domain of the landed H1
   205	  while every menu-normalization obligation of the restricted family falls
   206	  on the product values alone. Using `g_i(n) + g_i(−n) = 1` (which the
   207	  hemisphere rule satisfies exactly, including on its tie set), `W` sums to
   208	  1 on every tree menu of either rooting, hence on every product-projector
   209	  menu by T3a. Its one-site restriction `W(A ⊗ 1) = g_1(A)` is the landed
   210	  rogue, which by the three-direction contradiction is no trace form; since
   211	  `E ↦ Tr(ρ(E ⊗ 1))` is trace-affine for every pair state `ρ`, no density
   212	  matrix on the pair represents `W`.
   213	- **(T3c) Consequence.** At `2 x 2`, projective-grade hypotheses whose menu
   214	  family contains only product-projector resolutions do not force the Born
   215	  form. The landed composite route's H4 clause — menu-eligibility for
   216	  resolutions "that contain entangled projections", with the landed
   217	  refutation-seat finding "Without this full projection-measure strength a
   218	  partial menu assignment is not a frame function and Gleason does not
   219	  apply" — therefore cannot be weakened all the way to product-projector
   220	  menus at `2 x 2`; whether full H4, or some intermediate projective-menu
   221	  family, is minimal is untested here. This agrees with the comparator
   222	  statement (Wallach 2002) that
   223	  unentangled frame functions determine density operators only when every
   224	  factor has dimension at least 3; the `2 x 2` case claimed here is proved
   225	  natively by T3a-T3b. Entangled projections are not products (the runner
   226	  gates a Bell-projector Schmidt-rank witness), and `W` assigns them no
   227	  value, so T3 is consistent with, and does not touch, the landed R2/R3
   228	  forcing under full H4 strength.
   229	
   230	**T4 (the menu grade is the dial, and the attribution moves).** T1-T3
   231	together relocate the landed dimension-2 loophole: it is not a fact about the
   232	site, it is a fact about the projective grade. On the effect horn the form is
   233	fixed sitewise and the nearest-neighbor lattice pays for nothing in the
   234	form-fixing step — composites matter there only for values (joint states and
   235	their conditioning), which remain underived. On the projective horn the
   236	lattice composite plus full entangled-menu strength plus the Gleason bridge
   237	input remain exactly what the landed note says they are, and T3 shows the
   238	entangled-menu clause cannot be weakened to product menus at `2 x 2`. The
   239	landed attribution sentence "adjacency alone pays for nothing here without
   240	H4's strength" is thereby sharpened in both directions: with effect menus,
   241	adjacency is not needed for the form; with product-projective menus,
   242	adjacency plus the bridge input still do not suffice. Which menu family the
   243	physical registration supplies — the two grades treated here are the poles,
   244	and intermediate families remain untested — is an open item of the declared
   245	specification burden; this note records two bounded horns and selects no
   246	grade.
   247	
   248	**T5 (zero-information limit at a finite-group premise, effect horn).**
   249	Under the additional named premise that `w` is invariant under conjugation by
   250	the three one-site Pauli unitaries — a finite group, strictly weaker than the

   122	## Results
   123	
   124	**T1 (effect horn: sitewise forcing at every finite dimension, no bridge
   125	input).** Assume E1-E2 on a finite region of dimension `d ≥ 2`. Then there is
   126	a unique density matrix `σ` with `w(E) = Tr(σE)` for every effect `E`. The
   127	proof is the five-step finite argument, dimension-generic:
   128	
   129	- **(A) Partial additivity.** For effects with `E_1 + E_2 ≤ 1`, apply E2 to
   130	  the menus `{E_1, E_2, 1 − E_1 − E_2}` and `{E_1 + E_2, 1 − E_1 − E_2}`:
   131	  subtracting, `w(E_1 + E_2) = w(E_1) + w(E_2)`. The two-outcome menu
   132	  `{E, 1 − E}` gives the complement law `w(E) + w(1 − E) = 1`.
   133	- **(B) Homogeneity.** Iterating (A) on the `(r+1)`-outcome menu
   134	  `{E/r, ..., E/r, 1 − E}` gives `w(E/r) = w(E)/r` and then `w(qE) = q w(E)`
   135	  for rational `q ∈ [0,1]`. Monotonicity follows from (A): if `E ≤ F` then
   136	  `F − E` is an effect and `w(F) = w(E) + w(F − E) ≥ w(E)`. For real
   137	  `t ∈ [0,1]` and rationals `q_1 < t < q_2`, the operator inequalities
   138	  `q_1 E ≤ tE ≤ q_2 E` then squeeze `w(tE)` between `q_1 w(E)` and
   139	  `q_2 w(E)`, so `w(tE) = t w(E)`.
   140	- **(C) Linear extension.** `Herm(M_d)` is a real vector space of dimension
   141	  `d^2` spanned by effects (the normalized identity-plus-generator elements
   142	  `(1 + B_k)/2` and `1` itself). Additivity plus homogeneity on the positive
   143	  cone extend `w` to a well-defined real-linear functional `F` on
   144	  `Herm(M_d)`: scale any positive `A` into the effect interval, set
   145	  `F(A) = s·w(A/s)` for `s` dominating the top eigenvalue (well-defined by
   146	  homogeneity), and define `F` on differences; the standard two-sided
   147	  cancellation argument shows representation-independence.
   148	- **(D) Trace representation.** The trace pairing `⟨X,Y⟩ = Tr(XY)` is a
   149	  nondegenerate real inner product on `Herm(M_d)`, so `F(H) = Tr(σH)` for a
   150	  unique Hermitian `σ`, reconstructed linearly from the `d^2` basis values of
   151	  `w`. At `d = 2` this is exactly the landed display
   152	  `σ = ½[ 𝟙 + Σ_{a∈{x,y,z}} (2 m(P_a^+) − 1) σ_a ]`.
   153	- **(E) State property.** `w(1) = 1` gives `Tr σ = 1`; for every unit vector
   154	  `ψ` the rank-1 projector is an effect, so `⟨ψ|σ|ψ⟩ = w(P_ψ) ≥ 0`, hence
   155	  `σ ≥ 0`.
   156	
   157	No step uses `d ≥ 3`, a composite, a projective frame-function analysis, or
   158	any literature theorem. The runner re-derives the load-bearing identities of
   159	every step exactly at `d = 2` and `d = 4`.
