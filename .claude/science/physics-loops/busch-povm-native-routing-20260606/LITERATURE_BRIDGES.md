# Literature Bridges

Busch 2003 and CFMR 2004 are retained as parallel literature comparators for the
effect-Gleason theorem. The branch does not rely on them as the only derivation
path for the finite qubit-lattice cases used by the parent note.

The source-local route is:

- native `M_2(C)` effect bridge for the single-site qubit;
- projection-lattice companion plus spectral decomposition for multi-site
  finite regions.
