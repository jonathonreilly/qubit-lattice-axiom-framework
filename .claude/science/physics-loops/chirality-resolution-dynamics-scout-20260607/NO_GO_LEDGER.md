# No-Go Ledger / Frontier Guardrails

This physics-loop pack keeps the required no-go memory file, but the entries
below are finite toy guardrails for this scout.  They are not audit-grade
`claim_type = no_go` theorem proposals.

## N1: Blend Does Not Select

A racemic or two-sector blend has zero signed excess unless a selection rule is
added.

## N2: Symmetric Flip Does Not Select

A reversible symmetric transfer has an unbiased fixed point.  It can erase
excess, but it does not choose a hand.

## N3: Symmetric Sink Does Not Select In The Finite Toy

A sink applied equally to both hands changes retained mass but not handedness.

## N4: Host Does Not Choose Section

An orientation line can host sign data, but hosting both sections is not a
canonical source-section theorem.

## N5: Record Does Not Produce Carrier Chirality

Record can store realized labels after the carrier exists.  It cannot be used as
hidden dynamics or as a hidden chirality axiom.

## N6: Signed Readout Is Not Automatically Chirality

A signed spectral classifier can commute with the symmetry labels.  That is not
the same as an anticommuting chirality operator.
