# Route Portfolio

1. **Staggered anticommutation filter**
   Derive `{D,gamma5}=0` from a future retained graded-locality or
   spin-statistics theorem.  If successful, existing finite enumeration forces
   `epsilon(x)` up to global sign.

2. **Canonical orientation/source section**
   Derive a native section of the determinant/orientation line that can act as a
   local source sign.  This is the signed-gravity analog of the asymmetric
   filter.

3. **Eta / spectral-flow boundary filter**
   Search for an index/spectral-flow theorem that supplies the orientation or
   boundary asymmetry natively.

4. **Record-compatible instrument**
   Build finite instruments where carrier chirality is realized upstream and
   Record only consumes the realized label.  This guards against hidden Record
   dynamics.

5. **Koide / generation readout selector**
   Separate signed spectral classifiers from anticommuting chirality and from
   first-order holomorphic readout.  A selected readout is a filter and must be
   derived.

6. **No-go completion**
   If the routes above cannot be made native, package exact no-gos that prevent
   repeated false starts.
