# Route portfolio

| Route | Dramatic-step score | Result |
|---|---:|---|
| Residual-`Z_2` paired mass normal forms | 3 | Exact fixed-spectrum orbit spans every overlap; symmetry does not select the law |
| Shared oriented `C_3` source operators | 2 | Common Fourier eigenbasis gives zero/one overlap; oriented coefficient changes spectra, not eigenvectors |
| Jacobi/NNI inverse spectral construction | 3 | Constructs admissible mass pairs but leaves spectral weights, coefficients, and relative phases free |
| Separable spectral source action with fixed `f` | 2 | Depends on overlap but has `R`-decoupled stationarity; cannot select the mass-dependent law |
| Linear mixed trace action | 2 | Stationary points commute and select endpoint/permutation alignment |
| Composite positive-volume determinant balance | 3 | Selected: exact target-equivalent representation forces the desired scalar law after explicit carrier, rank, block-weight, and action dictionaries are supplied |
| Direct squared alignment residual | 1 | Rejected as tautological because it inserts the complete target equation |

The determinant-balance route is selected because it supplies a typed exact
representation and falsifiable physical selectors. It has no predictive
selection until those dictionaries are independently derived. The symmetry
and NNI routes establish that they are not already latent in the current
carrier.
