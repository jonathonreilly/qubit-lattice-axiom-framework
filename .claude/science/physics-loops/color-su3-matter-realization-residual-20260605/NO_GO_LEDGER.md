# No-Go Ledger

- Post-record histories and counts cannot choose the quark carrier.
- Endpoint invariance counts cannot choose base `SU(3)` over fiber `SU(2)`.
- A primitive one-qubit endpoint cannot be treated as already carrying the
  `SU(3)` color fundamental.
- A stable dial location cannot substitute for a matter/link realization
  theorem.

Each no-go is narrow and route-specific. None says physical color is
impossible.
