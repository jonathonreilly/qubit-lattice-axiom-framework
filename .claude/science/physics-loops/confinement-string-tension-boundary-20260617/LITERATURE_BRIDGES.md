# Literature Bridges

The branch keeps textbook/lattice physics as cited support, not as untracked
framework-native proof material.

- Wilson pure-gauge lattice action and beta normalization.

The correct repo discipline is to prove the framework-local beta=6 statement
inside the framework, then cite the standard literature in parallel as bounded
