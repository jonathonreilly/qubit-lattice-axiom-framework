# Assumptions And Imports

This block does not add imports. It exposes the existing runner for the algebra already written in the note.

The runner checks the explicit finite Clifford/chirality packet from the note:

- Clifford relations for the spatial `Gamma_i`;
- `gamma_5` anticommutation and chiral projectors;
- weak `su(2)` bivector closure;
- weak-vector covariance of `Gamma_i` and `Y_i = P_R Gamma_i P_L`;
- spin-1 Casimir and trace orthogonality;
- rescaling invariance showing covariance does not fix normalization.
