# No-Go Ledger

## Stability implies selection

No. Every `pi_s` has the same reset-stability construction, so stability alone
does not choose the dial position.

## Record supplies equal-letter prior

No. Record supplies the realized atom type and finite additivity only. The
post-record atom-symmetric dynamics is an additional named support surface.

## Koide forced

No. This block only certifies that the `s=0` / `r=1/2` / `Q=2/3` point is a
stable location under a named dynamics.
