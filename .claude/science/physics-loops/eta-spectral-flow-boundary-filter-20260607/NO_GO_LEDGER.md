# No-Go Ledger

## Eta/Spectral Flow As Selector

Status: pruned by this block.

Reason: spectral flow is an oriented invariant.  The same unoriented crossing
supports both signs, and paired bulk eta vanishes.  A supplied selector can
choose a sign, but that selector is the missing structure.
