# No-Go Ledger

- A one-token unit-square loop in `UD_2` is not automatically null-homotopic
  just because its base projection is a geometric plaquette.

- In the finite connected square-plus-tail model, the fixed-token square loop
  is not a `GF(2)` cellular boundary. Since null-homotopy implies null-homology,
  it is not null-homotopic in that model.

- This does not prove the full eta braid-invariant no-go, because the actual
  compared detour swaps have not been identified as one braid class.
