# Goal

Repair the EW Higgs gauge-mass diagonalization row so its exact symbolic
algebra is preserved while its source status is bounded to declared EW-Higgs
inputs.

The target is not to derive the electroweak gauge group, Higgs carrier,
hypercharge, vacuum, or covariant derivative from the minimal framework in
this block. The target is to make the current theorem surface honest and
cleanly reviewable.
