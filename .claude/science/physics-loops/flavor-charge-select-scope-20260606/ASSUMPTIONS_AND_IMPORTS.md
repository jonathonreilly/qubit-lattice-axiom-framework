# Assumptions And Imports

## Used Directly

- Finite `C3` circulant matrix algebra.
- Conditional scalar generation action `iI`.
- Order-three rephasing arithmetic.
- Embedded empirical mass tables as comparators only.

## Deliberately Not Used As Load-Bearing

- Physical proof that Standard Model gauge `U(1)` acts scalar on generation.
- Framework derivation of charged-sector ordering.
- Physical det_C/det_R selector.

## Axiom Count

No new axiom is introduced.
