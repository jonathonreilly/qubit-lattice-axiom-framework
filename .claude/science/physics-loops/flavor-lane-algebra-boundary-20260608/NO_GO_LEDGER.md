# No-Go Ledger

- The retained Frobenius isotype split no-go leaves the singlet:doublet ratio free.
- The retained action-normalization no-go declines to rank block-count `(1,1)` against real-dimension count `(1,2)`.
- The scalar swap `r -> 1-r` changes `Tr(H^2)` away from `r=1/2`, so it is not a C3-covariant forcing mechanism.
- This PR does not try to reverse those no-go results.
