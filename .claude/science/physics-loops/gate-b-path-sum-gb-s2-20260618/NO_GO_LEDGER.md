# No-Go Ledger

| Route | Reason |
|---|---|
| Claim path-sum algebra is physical readout closure | Finite path expansion does not select the detector window, mass gain, `TOWARD`, or `F~M` semantics. |
| Use Record to derive detector semantics | Record supplies durable realized-outcome readout with finite scalar additivity, not Gate B measurement dynamics. |
| Derive the edge kernel from this theorem | The theorem expands the supplied kernel; it does not select it. |
