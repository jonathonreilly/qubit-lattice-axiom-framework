# Handoff

This branch adds an exact route-pruning theorem for the audited conditional
gauge-algebra row.

The new runner proves that:

- the supplied factorwise `su(3)+su(2)+u(1)` algebra is closed, dim 12, and
  irreducible on `C^3 x C^2`;
- a non-factor-local unitary conjugate has the same invariant profile but is a
  distinct embedding;
- full `u(6)` has the same scalar-commutant irreducibility profile;
- therefore carrier-level invariant data, scalar commutant, and
  irreducibility cannot select the factorwise dim-12 gauging.

This does not derive `MR_color`, the factorwise carrier/gauging principle, or
chiral `su(2)_L`. The parent remains conditional. The useful audit-unblock is
that one possible repair route is now exactly closed off, leaving the real
positive bridge named.
