# No-go and failed-route ledger

| Route | Exact prior boundary | Re-open condition | Current disposition |
|---|---|---|---|
| Generic positive witness | verifies packaging only, not Wilson data | never without an independent physical construction | closed as target route |
| Single-link Wilson coefficients | actual computed local coefficients, but not the multi-link environment | only as a control or local factor | excluded from closure |
| Naive Haar product estimator | nontrivial 81-plaquette character products were noise-dominated at 5000 samples | a variance-reduced estimator | not re-run |
| Naive dense exact contraction | tested original factor-primal widths exceed 4 GiB by many orders; not a global treewidth no-go | rank-aware/stabilizer/recoupling method | method-specific boundary |
| Orbit quotient | tying orbit variables changes the independent-link integral | exact representation blocks on original state space | diagnostic only |
| Finite word/rim ladders | compute surrogate 1D/product geometries | exact map to the physical 3D rim | support only |
| Formal Peter-Weyl packaging | maps supplied diagonal data to a central sequence | derive the sequence and operator from the same Wilson integral | insufficient alone |
| Static-density equals stripped two-slice residual by literal deletion | drops one spatial half-weight set, 77 mixed-link factors, and compression ordering | construct and strip the full compressed two-slice operator | falsified as a proof route; equality itself remains open |

The static coefficient route is new because it is a variance-reduced identity
under the positive full Wilson measure, not the prior Haar product estimator.
The doubled-slice route prevents that valid support result from being
overextended into an operator theorem.
