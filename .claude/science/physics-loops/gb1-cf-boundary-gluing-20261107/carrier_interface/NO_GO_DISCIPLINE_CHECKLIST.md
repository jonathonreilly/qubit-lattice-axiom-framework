operational effect addition. The scalar-code construction realizes those

## N7 — Strongest counterargument

The construction chooses a finite classical code and an injective decoder.
A physically relevant quantum sector could permit fewer distinguishable
preparations or a narrower set of tests; then the scalar copying program
would not describe its available operations. This is a real route, not a
logical defect in the constructed model. The decisive task is to derive
those preparation/readout restrictions and their effect geometry from a
specified native law, with source and apparatus access fully accounted for.
The current result cannot dismiss that route or establish all lattice
models classical. The source notes' supplied quantum-control routes remain
conditional alternatives, not failed theories.
