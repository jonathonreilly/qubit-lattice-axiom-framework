## Exact diagnostic and deliberate failures

The standalone standard-library Fraction replay imports no old runner or
scientific data file. Its only repository integrity read is its own source
hash. Its probability law is the declared program, while an independently
derived cylinder formula checks the physical path replay. Agreement tests
the construction; it does not derive the stored probabilities from axioms.

The five declared r examples have S=0,2,3,4,4 and respectively 16,16,16,8,8
positive cylinders. The executable checks all reachable prefixes, 12,216
occupied-site support instances and 72 selected transformed configurations
(three snapshots times 24 proper rotations, with a nonzero translation).
It also enumerates 16 deterministic local responses and checks the exact
4x4 quantum square/saturation calculation. These are not 12,216 independent
scientific confirmations, an all-matrix enumeration or an infinite simulation.
The arbitrary-r and universal norm inequalities are hand proofs.

Five fault controls actually failed:

- Removing one initial program buddy loses old-record support.
- Choosing the last program without the first setting changes a cylinder.
- Ignoring the recovered transformed axes breaks next-site covariance.
- Giving a local-response expression a remote-setting dependence breaks its
  purported local-vertex bound.
- Reversing the commutator-product sign fails the Bell square identity.

The first two use explicit diagnostic fault switches. The other three use
scratch copies; outputs/mutation_receipt.json records exact literal edits and
source hashes so each executed source is reconstructible. All five exits are
nonzero failures, not relabelled successful computations. Full stdout/stderr
and execution receipts are preserved. No unchanged large production runner
was rerun merely to add PASS lines.

The first numerical preflight refused host load 8.2; no numerical job launched.
Later preflights passed at reported loads 5.6 and 3.5. Executions were serialized
under two numeric leases, nice10, five single-thread environment variables,
CPU55/60 limits, internal wall50/RSS250MiB guards and outer timeout60. Both
numeric leases were released. The exact run took about 0.84 seconds externally
with reported maximum RSS 22,560,768 host bytes. Timing is diagnostic only.
