# No-Go Ledger

- Conditional Wilson/Ward algebra at fixed normalization does not derive the
  normalization scalar.
- L3 invariance/robustness does not prove L3 uniqueness or select
  `N_F = 1/2`.
- Killing-form rigidity on simple `su(3)` leaves one positive scalar free.
- Per-site `SU(2)` spin normalization is not automatically the gauge `su(3)`
  trace normalization.
- Dynamic fixed point, maximum entropy, mean-field iteration, and the lattice
  beta-function selector do not select `g = 1` on the current parent note.
