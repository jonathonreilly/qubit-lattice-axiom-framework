# Assumptions And Imports

No new axiom is introduced.

The branch does not derive:

- physical mass-source/readout;
- `G_N`, SI normalization, or a Planck lattice pin;
- Penrose-Diosi `gamma = E_G / hbar`;
- BMV/NV geometry and cutoffs;
- `L^{-1}=G_0` from minimal framework primitives.

Those inputs are external packet data for the companion arithmetic only, not retained premises for a physical theorem.
