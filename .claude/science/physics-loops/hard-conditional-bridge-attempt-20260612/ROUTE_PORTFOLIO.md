# Route Portfolio

1. **Direct closure when possible.**
   Reuse retained suppliers or existing runners to close a named missing
   bridge. This succeeded only for sub-blocks already narrowed in source, such
   as single-clock B-RANGE retirement and alpha_s B3 algebra/operator halves.

2. **Negative route pruning.**
   When the obvious route is blocked, wire the no-go into the parent source row
   and make the remaining bridge exact. Used for single-clock B-AXIS,
   signed-gravity source origin, and DM-neutrino phi-space transport.

3. **Open-gate hard residual.**
   When the row is intentionally comparator/open-gate only, add a status
   firewall and a runner guard so downstream cannot mistake support-only
   numerics for retained physics. Used for teleportation and quark Koide.
