# Assumptions and Imports

The binding proof uses only finite-dimensional trace algebra on `Herm(3)`,
unitary conjugation, and positivity of the Frobenius norm on nonzero Hermitian
matrices. It uses no observed masses, fitted values, literature inputs,
physical source law, selector, or framework normalization.

`beta = 0` is not a premise of the no-go. It appears only in the explicitly
out-of-scope conditional corollary. Counterfactually changing the relative
scalar/traceless weight moves the AM-GM output according to
`kappa(lambda) = 2/(1+3 lambda)`, which is the obstruction being recorded.
