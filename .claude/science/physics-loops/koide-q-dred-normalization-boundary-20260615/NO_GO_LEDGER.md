## Reduced Algebra Does Not Select `D_red = I_2`

For every `c > 0`,

```text
log det(cI + K) - log det(cI)
  = log(1 + k_+/c) + log(1 + k_perp/c).
```

After `u_i = k_i/c`, this is the same normalized law as `c = 1`.
The derivative scale at zero is `1/c`, so the physical source unit remains
external.
