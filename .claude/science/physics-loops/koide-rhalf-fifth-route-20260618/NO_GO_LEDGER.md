# No-Go Ledger

## Existing routes preserved

- `C3` invariance: leaves `r` free because `Q = (1 + 2r)/3` is non-constant.
- `S3` axis-permutation enhancement: forces eigenvalue multiplicities `{1, 2}`.
- Intermediate `C3 < G < S3` subgroup: none exists.
- Unitary singlet/doublet swap: impossible because the real isotype dimensions
  are `1` and `2`.

## New route in this block

- `C3`-compatible coefficient rephasing / doublet-basis calibration: preserves
  `|b|^2/a^2`; therefore it cannot select `r = 1/2`.

## Routes intentionally left open

- Dynamical derivation of the hopping/on-site ratio.
- Variational selection principle outside the checked symmetry/calibration
  routes.
- Nonunitary maps.
- Enlarged operator algebra or extra-structure mechanisms.
