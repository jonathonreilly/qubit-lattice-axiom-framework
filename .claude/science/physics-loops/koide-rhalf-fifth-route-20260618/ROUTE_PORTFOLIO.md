# Route Portfolio

## Selected route

**C3-compatible coefficient rephasing / doublet-basis calibration.**

The real doublet coordinates `(Re b, Im b)` rotate as
`(x, y) -> (c x - s y, s x + c y)` with `c^2 + s^2 = 1`. The runner checks
that this preserves `x^2 + y^2 = |b|^2`, hence preserves
`r = |b|^2/a^2`. A phase or basis convention cannot tune arbitrary `r` to
`1/2`.

## Rejected alternatives for this block

- Rescope to four-route bounded support: valid fallback, but lower value
  because it narrows the row instead of answering the audit's preferred N1
  route request.
- Claim a dynamical derivation of `|b|/a = 1/sqrt(2)`: not available from this
  finite-algebra route.
- Broaden to all variational/nonunitary/extra-structure mechanisms: not
  supported and intentionally left open.
