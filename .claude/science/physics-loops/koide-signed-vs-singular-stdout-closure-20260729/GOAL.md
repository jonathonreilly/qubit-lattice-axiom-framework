# Goal

## Exact target contract

**Target statement:** the same Koide signed-eigenvalue versus singular-value
source theorem must be independently re-auditable with a complete authenticated
execution record covering all 30 primary checks and the note's narrow derived
negative boundary.

**Domain:** the existing `C_3`-circulant Hermitian family and the existing
`r=1/2` specialization; no scientific rescope.

**Allowed premises:** the source proof, standard exact algebra, SymPy, the
existing runner assertions, and repository audit-packet transport rules.

**Forbidden weakenings:** dropping checks, changing tolerances, replacing live
execution with a summary-only cache, removing the boundary, or changing the
claim type.

**Required edge cases:** `theta=pi/12`, immediately inside/outside the equality
window, and the arbitrary-`r` counterexample already in Part 8.

**Completion witness:** live stdout below both 6,000 and 20,000 characters,
exactly 30 `PASS (A)` lines, zero failures, fresh SHA-pinned cache, complete
N1/N5/N7 execution locators, and review disposition `pass`.

**Non-closures:** an audit-status edit, a longer packet cap alone, or a cache
whose source SHA is stale.
