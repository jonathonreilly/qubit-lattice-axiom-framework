# Assumptions And Imports

## Minimal Premise Set

- Use the existing finite ordered 3D dense-lattice harness from `scripts/lattice_3d_dense_10prop.py`.
- Preserve its graph, slit, detector, spent-delay action, propagation, and sign classifiers.
- Evaluate only the finite source positions z=2,3,4,5,6.

## Imports Retired Or Avoided

- No literature theorem is load-bearing.
- No observed physical target value is used.
- No fitted selector is introduced.
- No external comparator is used.
- No new axiom is introduced.

## Remaining Limits

The result is finite endpoint support only. It does not prove continuum attraction, all-distance attraction, physical Newtonian gravity, or an asymptotic distance law.
