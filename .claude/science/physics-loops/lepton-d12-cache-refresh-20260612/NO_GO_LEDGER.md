# No-Go Ledger

## Do Not Claim A Lepton Yukawa Prediction

The formal hypercharge equation gives `y_tau = g_1/sqrt(2)` only if a
unit lepton scalar operator is supplied. This branch does not supply
that operator.

## Do Not Treat Channel Fraction As Scalar Normalization

The current Yukawa color-projection note is a representation
channel-fraction theorem. It is not a physical Yukawa or scalar
wave-function normalization.
