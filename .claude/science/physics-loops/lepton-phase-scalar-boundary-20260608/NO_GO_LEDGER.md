# No-Go Ledger

- No universal real `C3` scalar-action no-go: false, because `Im z^3` is a legal
  invariant and can carry a supplied phase target.
- No blanket even/spectral scalar no-go: false, because `W_X=0` can encode a
  supplied extremum at `delta=2/9`.
- Preserved no-go: nondegenerate even/spectral scalar branch with `W_X != 0`
  cannot stationarize `delta=2/9`.
