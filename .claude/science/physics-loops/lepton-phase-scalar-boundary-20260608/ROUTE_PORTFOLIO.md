# Route Portfolio

1. Universal scalar no-go: rejected. General real `C3` scalars can target a
   supplied phase through `(Re z^3, Im z^3)`.
2. Even/spectral scalar no-go: partially rejected. The `W_X=0` branch can
   target a supplied phase.
3. Nondegenerate even/spectral branch: preserved. If `W_X != 0`, stationarity
   forces `sin(3 delta)=0`, so `delta=2/9` is excluded.
4. Register-not-read partition route: preserved as modulus-only support. It
   delivers `r`, not the phase.
5. Phase/covariant route: left open for future science.
