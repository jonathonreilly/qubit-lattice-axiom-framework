# Goal

## Exact target contract

**Target statement.** Preserve the existing theorem: for positive integer
`n_color` and a nonzero real pair `(a,b)` satisfying
`2 n_color a + 2 b = 0`, derive `a != 0`, `b != 0`,
`b = -n_color a`, `[a:b] = [1:-n_color]`, and
`a/b = -1/n_color`.

**Allowed premises.** Exactly the displayed count, real-domain, trace-equation,
and nonzero-pair hypotheses; elementary real linear and projective algebra.

**Forbidden weakenings.** No removal of the nonzero-pair hypothesis; no
restriction to finitely many counts or scales; no normalization or physical
charge convention inserted into the clean theorem.

**Required edge cases.** The excluded zero pair, `n_color = 0`, negative and
noninteger parameter extensions, and nonzero scales of both signs.

**Completion witness.** A current no-argument runner execution whose complete
stdout contains the NORMAL load-bearing checks and `TOTAL: PASS=51 FAIL=0`, is
within the live transport limit, and is bound to both runner and note content.

**Not closure.** A clipped summary, a stale cache, a cache bound only to runner
source, or an author-side claim about the audit outcome.
