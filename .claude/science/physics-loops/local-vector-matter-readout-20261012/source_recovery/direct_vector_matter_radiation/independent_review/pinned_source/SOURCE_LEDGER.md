# Primary source boundary

Read October 12, 2026:

- Weisberg and Huang, 2016, [arXiv1606.02744](https://arxiv.org/html/1606.02744v1),
  DOI10.3847/0004-637X/829/1/55. Sections II–IV identify arrival-time
  preparation, the relativistic timing model, fitted orbital parameters and
  the Galactic correction. Its abstract gives a corrected observed/GR decay
  ratio0.9983±0.0016. This is contextual motivation; it is not a raw,
  model-independent calibration or validation input for the vector theory.
- [Peters and Mathews1963](https://journals.aps.org/pr/abstract/10.1103/PhysRev.131.435),
  Gravitational Radiation from Point Masses in a Keplerian Orbit. The leading
  GR circular quadrupole formula is an explicitly supplied theory comparator.
- Author data landing page [Zenodo54764](https://zenodo.org/records/54764)
  was found in search; a direct web open returned an internal error. No data
  file or timing likelihood has been downloaded or run in this block.

No new observation has been used as an independent holdout here. All control
parameters are synthetic. Physical speed identification and matching a GR
formula would be new calibration assumptions, not empirical validation.
