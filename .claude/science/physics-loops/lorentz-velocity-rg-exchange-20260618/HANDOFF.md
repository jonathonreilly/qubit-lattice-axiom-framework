# Handoff

This branch is a source-side audit unlock PR only.

It adds an exact theorem for the algebraic one-loop velocity-RG exchange matrix:
with positive mutual-drag coefficients `a,b`, the common-speed line is fixed,
`b v_F + a v_B` is invariant, and the speed-difference mode has eigenvalue
`-(a+b)`.

It intentionally does not claim physical coefficient closure. The next science
target is the framework-native one-loop calculation that produces positive
`a,b` from the actual interacting vertices.
