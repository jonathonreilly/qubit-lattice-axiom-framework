# Assumptions And Imports

Open measurement-side premises:

- `p(E | sigma) = Tr(sigma E)` as a probability interpretation.
- Sequential record conditioning has the standard U1-U4 consistency shape.
- A physical measurement/record instrument semantics exists for the finite
  operator algebra.

Retained/repaired source-side algebra:

- The finite PEP bridge proves `0 <= PEP <= P`, trace cyclicity, and nested
  compression identities in finite matrix algebra.

This PR does not add an axiom and does not admit the open measurement-side
premises as framework-native.
