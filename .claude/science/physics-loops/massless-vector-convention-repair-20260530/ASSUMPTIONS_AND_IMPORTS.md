# Assumptions And Imports

## Load-Bearing

- Four-component contravariant polarization vector `epsilon^mu`.
- Mostly-minus Lorenz row `k_mu`.
- Residual gauge shift along `k^mu`.
- Null-shell identity `k_mu k^mu = 0`.

## Context Only

- Lorentzian `R^{3,1}` setup.
- Free-field plane-wave decomposition.
- Continuous abelian gauge orbit.
- Physical use in any `g_*` parent row.
