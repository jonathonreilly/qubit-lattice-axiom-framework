# Assumptions And Imports

## Consumed

- `V = C^4` as an abstract complex vector space.
- A fixed nondegenerate symmetric bilinear form with matrix
  `diag(1, -1, -1, -1)`.
- A nonzero null vector `k`.

These are theorem hypotheses, not physical imports.

## Not Consumed

- physical Lorentzian spacetime;
- Fourier/plane-wave decomposition;
- gauge invariance;
- Lorenz gauge;
- Maxwell/Yang-Mills dynamics;
- Standard Model particle inventory;
- observed values, fitted constants, literature numerical comparators;
- audit ledger status.
