# Delivery state

The common metric/clock milestone is approved for opening by the local content
value assessment below, contingent on final source confirmation and mechanical
validation. It is independent of the earlier vector PR stack. No PR exists for
this unit yet. Network or validation failures will be recorded here or in the
campaign runtime with exact recovery actions; they do not stop science.

Conformal/nonconformal alternatives remain campaign commits for later synthesis.
Charge and finite-body results are not yet another milestone PR; they require
focused checks and a coherent source/material synthesis before a delivery
choice. This avoids treating every useful intermediate calculation as a PR.
