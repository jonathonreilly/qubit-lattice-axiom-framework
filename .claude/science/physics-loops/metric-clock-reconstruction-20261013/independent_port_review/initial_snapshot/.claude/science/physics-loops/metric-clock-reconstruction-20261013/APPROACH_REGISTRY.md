# Approach and value assessment

The construction moves from specified observations to a common candidate
action, then derives a linked force/bending/radiation/clock response. Its
value is the shared source and normalization bridge, not a novel claim for
the familiar tensor/scalar theory or a larger number of tests.

Earlier campaign vector response and matter/readout PRs used a preferred
vector and mechanical source. They do not supply the metric gauge identity,
light-bending map, scalar quantum normalization or balanced-clock source.
This packet uses a different action and adds an explicit source/observable
map with independently checked exact finite-time geometry. The earlier
conformal/nonconformal alternatives remain on the campaign branch; making a
separate PR for each would add review burden without completing this common
construction. This packet groups its two completed dependent arguments.

Before opening, the local cluster/value evaluation will inspect the final
note and cache. Distinct empirical likelihood, material-source sensitivities,
full nonlinear state and cosmology are open; no volume or status count is
scientific evidence. No frontier theorem is promoted to framework authority.
