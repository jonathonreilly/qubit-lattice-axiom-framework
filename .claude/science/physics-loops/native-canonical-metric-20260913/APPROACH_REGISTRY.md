# Approaches

- Configuration bundle: explicit connection, curvature and Darboux momenta.
- Local functional variation: metric/spinor mixed bracket and ansatz coefficients.
- Spacetime reconstruction: direct ADM Christoffels and symmetric Weyl action.
- Finite native sources: protected paths, node moments and smooth Taylor errors.
- Unreduced triad canonical derivation: comparator read; not separately completed.

These are positive and partial approaches, not a list of failed no-go routes.
The native quantum metric realization remains an open physical continuation.
