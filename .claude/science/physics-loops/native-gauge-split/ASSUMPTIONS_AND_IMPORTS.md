- anomaly cancellation;
- electroweak matching;
- matter labels or flavor labels;
- Wilson gauge dynamics and plaquette values.

## Import Judgment

The proposed nonabelian source boundary uses only exact finite-dimensional
matrix algebra and retained graph-first nonabelian dependencies. The abelian
eigenvalue surface is moved to a separate bounded note so it cannot be a
hidden load-bearing input to the positive-theorem candidate.
