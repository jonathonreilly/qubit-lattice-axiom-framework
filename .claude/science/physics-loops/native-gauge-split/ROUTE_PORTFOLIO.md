# Route Portfolio

## Chosen Route: Source Split

Move the old high-downstream native gauge source file to a narrow
nonabelian claim boundary and preserve the abelian eigenvalue surface in a
separate bounded note.

Why this route:

- keeps the 1126-descendant `native_gauge_closure_note` claim ID as the
  review target;
- removes the abelian surface from the positive-theorem candidate;
- avoids new axioms and new conventions;
- lets the audit queue expose the source edit as a ready critical audit item.

## Rejected Route: Leaf-Only Positive Note

A standalone new nonabelian note would be scientifically clean but would
not unlock the long descendant chain because downstream rows cite the old
`native_gauge_closure_note` row.

## Rejected Route: Ledger Retag

Not allowed. The audit lane owns `claim_type`, `audit_status`, and
`effective_status` after independent review.
