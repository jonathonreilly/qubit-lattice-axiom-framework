# Preserved non-discriminating spinor challenge

The original primary passed even when the native left-wave sigma3 was
removed in the direct two-particle amplitude calculation. All three original
spinor pairs had |u^dagger v|=|u^dagger sigma3 v|, so they were blind to this
error. The mathematical vertex formula was unchanged; the test set was
inadequate for that defect. A fourth coherent pair was added, without
changing the expected cosine formula, normalization or tolerance. The full
original source, harness, output and ineffective mutated source/output are
preserved here. The ineffective mutation is not counted as validation.
