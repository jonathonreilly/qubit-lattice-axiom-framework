# Exact finite-grid regeneration

Run from the repository root. The checked Python environment has NumPy, SciPy and Numba. These commands are ordered: the space-group run reads the first run's basis arrays and ground vector; the response run reads its low eigenvectors. Allow several GB of scratch storage and RAM. Existing scratch arrays with these task-specific names are regenerated by these scripts.

```sh
cd .claude/science/physics-loops/neutral-composite-24h-20261018/native
export VECLIB_MAXIMUM_THREADS=1
export OPENBLAS_NUM_THREADS=1
export NUMBA_NUM_THREADS=2
/usr/local/bin/python3 neutral_rect_ground.py
/usr/local/bin/python3 neutral_rect_spacegroup.py
/usr/local/bin/python3 neutral_rect_spacegroup_response.py
```

The literal scripts preserve the original absolute scratch destinations. Their inputs are the supplied native Hamiltonian, fixed geometry and stated symmetry sector; they do not read fitted spectra.

| Regenerated scratch JSON | Frozen packet filename |
|---|---|
| `/private/tmp/neutral_rect_data/ground.json` | `neutral_rect_data_ground.json` |
| `/private/tmp/neutral_rect_spacegroup_data/low.json` | `neutral_rect_spacegroup_data_low.json` |
| `/private/tmp/neutral_rect_spacegroup_data/response.json` | `neutral_rect_spacegroup_data_response.json` |

Numerical timings, eigensolver basis choices and last floating-point digits can vary. Compare direct residuals, energies and summed degenerate response weights, rather than requiring new JSON byte equality. IDENTITIES.json binds the original frozen files and sources; the short runner checks those identities and independently replays the smaller controls.

For the preserved larger translation-only diagnostic, run `neutral_rect_response.py` after the first command above; its `observables.json` and `response.json` correspond to `neutral_rect_data_observables.json` and `neutral_rect_data_response_rejected_nodes.json`. `neutral_rect_original_source.py` regenerates `original_source.json`, frozen as `neutral_rect_data_original_source_rejected_nodes.json`. Their poorly converged quadrature nodes are preserved as failed diagnostics, not accepted eigenmodes. The intentionally wrong Q JSON is never regenerated by the corrected recipe and must not be used as science output.
