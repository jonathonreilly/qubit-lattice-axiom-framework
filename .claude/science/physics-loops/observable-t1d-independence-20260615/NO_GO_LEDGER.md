# No-Go Ledger

## Record Alone Does Not Derive T1-d

Countermodel:

```text
(Z, q) sqcup (Z', q') = (ZZ', q+q')
I_lambda(Z, q) = log Z + lambda q
```

For every `lambda`, `I_lambda` is finitely additive. For `lambda != 0`, two
records can have the same determinant datum and different readouts. Therefore
the determinant-only quotient is an extra bridge, not a Record consequence.

Effect: this prunes the route "Record axiom restatement closes observable
principle T1-d."
