# Preserved cosmological inverse evidence

`EVIDENCE_v1.tar.gz` contains original working derivations and calculations, the first failed parameter recovery, precision diagnosis, all canonical source versions, deliberate variants and their execution receipts, and the independently frozen proof, ODE and source-admission work. `EVIDENCE_INDEX_v1.json` lists every member with its SHA-256 and size. Members are relative to this action_selection directory; extraction into a separate empty directory recreates that evidence tree.

Selected reports, identity records, the original failure output and current outputs remain plain files for review. Their archived copies have the same bytes. The archive is preservation, not an additional independent computation or audit verdict. Check `REVIEW_RECORD_v1.md` for the final source and scope, and `CANONICAL_EQUIVALENCE_v5.json` for the narrow equality between independently checked v3 values and final v5 values.

External paper PDFs, HTML, extracted texts and rendered pages are retained locally but excluded from this archive. The index lists each excluded path and hash; exact version URLs and read scope are in the source acquisition and admission reports. Generated Python bytecode is also excluded. No failure or superseded scientific source was removed to produce a passing result. The archive and index do not include themselves recursively.
