The fair target gives each path mass 2^-N and the allowed event A contains exactly the paths never exiting [-B,B]. Any admissible law has Q(A)=1, so TV>=1-P(A). For the reflecting rule, an allowed path has k boundary departures of probability one and N-k interior departures of probability 1/2. Thus Q(path)=2^(-N+k)>=P(path). Summing min(P,Q) over all paths gives P(A); hence TV=1-P(A). This one causal rule works for every N because its prefix laws are consistent; it is not the survival-conditioned coin process.
