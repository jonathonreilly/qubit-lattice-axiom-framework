# Independent reconstruction before author code/output

Detector class: within the herald-conditioned ensemble, conditional detector independence gives E[AB]=E[f(J)g(J)]. Using an independent identically distributed Jprime, expand E[(f(J)-f(Jprime))(g(J)-g(Jprime))] to twice the covariance. Both increments have the same sign since both functions are nondecreasing, so covariance is nonnegative. Positive denominator expectations give the ideal ratio >=1. A separate Bernoulli retention coin thinning only the numerator multiplies it by eta, giving >=eta. This is not valid for arbitrary electronics, or if herald conditioning destroys conditional independence, or if hidden detector states introduce anticorrelation. It is a ratio of ensemble probabilities, not a deterministic lower bound on every finite count estimate.

Full-branch map: inverses are h0(w)=p*w and h1(w)=p+(1-p)*w, half-open images partitioning [0,1). Uniform mass on each inverse branch is branch length times uniform w mass. Therefore every finite cylinder has the product branch lengths, and the remaining state is uniform conditional on the entire cylinder. Adaptive controls depending only on past outputs do not break this induction: along each fixed past cylinder the next p is fixed. Dependence on unobserved u would break it. Prescribed controls and adaptive controls need separate entropy interpretations later.

Local pair: q=1-p and u1=1-u0. If u0<p, detector0 clicks and u1>q does not; its nonclick update (u1-q)/p equals 1-u0/p. If u0>=p, detector1 clicks and u1/q equals 1-(u0-p)/q. At equality u0=p, u1=q, only detector1 clicks and new states are (0,1); at u0=0 they map to (0,1). Domains are [0,1) and (0,1], respectively. This is a supplied correlated initial condition, paired incident fractions and fixed shared cadence, not a derived autonomous detector law.

Perron operator: inverse-branch change of variables gives Lrho(w)=p*rho(pw)+q*rho(p+qw). Integrals and positivity are preserved. The derivative-free Lipschitz bound is p^2*K+q^2*K=c*K. A Lipschitz function f has |f(x)-integral f|<=Lip(f) by integrating |f(x)-f(y)| over y. Thus supnorm convergence is <=c^n*K, and density TV <=c^n*K/2. Pushforward through any fixed future record map contracts TV. No conditioning on rare burn-in histories is allowed without another argument.

L1: positivity and normalization imply ||Lf||1<=||f||1. For any rho and Lipschitz approximant f, ||L^n rho-integral rho||1<=2||rho-f||1+c^n*Lip(f). Hence all L1 initial densities converge, with no universal rate independent of approximation regularity. Any invariant normalized L1 density must be 1. This does not exclude Dirac at 0 (fixed for all p) or periodic-orbit measures. No actual seed is chosen by an ensemble theorem.

For rho0=2u, L(2u-1)=c*(2u-1). Thus rho_n=1+c^n*(2u-1). Integrating absolute difference over [0,1] and dividing by two gives c^n/4; integrating density to p gives p-p*(1-p)*c^n.

Baker embedding: each branch stretches horizontally by 1/p or 1/q and contracts vertically by p or q, determinant +1. Images are horizontal strips with vprime in [0,p) or [p,1). Inverse is (p*uprime,vprime/p) in first strip, and (p+q*uprime,(vprime-p)/q) in second. These exactly partition the half-open square, so invertibility holds including branch ties. The u marginal and record stream are unchanged. For p=1/2 and half-open interval conventions, use terminating binary expansions at dyadics. u=0 has all zero symbols; 1/7 has binary repetend 001 and gives a period-three stream.

Information budget: for discrete random inputs, conditional deterministic data processing gives H(Y|X)<=H(S0,E|X). With no incoming E and at most M possible initial states this is at most log2 M. For fixed externally supplied controls and a nondegenerate iid Bernoulli target, H(Y)=n*h2(p), while full support requires M>=2^n regardless of bias. The support claim refers to one fixed n-trial protocol, not mixing over external random controls. Continuous real seeds are not subject to a finite discrete entropy bound without a discretization premise.

For an m-cell uniform cyclic register and n>=m, each initial word produces a distinct n-output string because its first m bits reconstruct the word. Thus support size is 2^m with probability 2^-m per string. Relative to the uniform n-bit distribution, TV=1-2^m*2^-n. For n<=m the initial segment is exactly iid fair. Repeated append-only blank storage does not add random support; unknown incoming states do, and belong in E.
