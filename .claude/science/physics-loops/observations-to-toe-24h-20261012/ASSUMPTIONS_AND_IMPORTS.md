# Assumptions and empirical inputs

Status: conditional-support

Separate observation provenance, experimental extraction assumptions, mathematical hypotheses, model assumptions, calibration parameters and test data. Each concrete candidate must replace the initial rows below with its exact dependency map. No calibration fit is an unconditional derivation.

| Item | Role | Present standing | Test or retirement path |
|---|---|---|---|
| Existing four-axiom lattice framework | Optional rival/candidate baseline | Adopted repository foundation at launch revision, not imposed on new candidates | Compare its forward predictions on the same observations |
| Scale reference, kinetic isotropy, realized state primitives | Existing-framework conditions only | Registry and source notes read at launch | Use only within each declared grant; do not infer dynamics or measured dimensionless values |
| New laws, geometry, composition or readout hypotheses | Candidate physical assumptions | Explicitly authorized for exploration; conditional scientific conclusions | Construct observable forward map, falsifier and cross-domain test |
| Experimental observations | Inference constraints or comparison data | Pin primary source, version, units, uncertainties and model dependence | Independent observational check with fit/test separation |
| Mathematical tools and provisional lemmas | Proof/constructive support | State hypotheses and unresolved obligations | Different derivation or focused independent check before extensive reuse |

For every candidate ask: what if this assumption is wrong; which alternative becomes live; what observation could tell them apart? Count free parameters and observationally indistinguishable mechanisms. No accepted-primitives registry change is part of this campaign.
