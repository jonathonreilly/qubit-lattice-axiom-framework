## Architecture decision

The checked vector theorem is a constructive mathematical escape from the
restricted two-scalar failure. The minimal scalar matter coupling then
reveals a physical tidal-response gap. Preserve both results: a successful
causal construction does not validate its identification with observed
gravity, and a restricted readout failure does not prohibit other couplings.

A useful next theory block must specify which observation it addresses and
which source/readout assumptions it adds. Possible routes are a reciprocal
metric coupling that produces the required tidal structure, a nonlinear
background completion whose coefficients emerge from one local action, or
a quantum-state extension that links the same source response to noise.
None is treated as an established primitive. Do not assemble individually
checked pieces into a claimed unified theory without checking their common
action, parameter identities, conservation laws and measurement maps.

The empirical next action remains a source-specific HI pressure/readout
test. If a usable cube/tabulation is unavailable, record the precise data
gap and move to the next constructive route without repeating failed fits.
This map does not change the original deadline or the final packaging time.
