# Nonconformal metric and source-radiation linkage

Status: conditional-support. Direct parent research, October13 UTC.
Frozen before the new numerical comparisons. Observational motivation is
the exposed solar radio bending context and the existing circular radiation
comparator, not a new blind data set or a fitted binary-pulsar likelihood.

The conformal completion supplies clocks/photons but no light bending.
Test the explicit one-parameter replacement in preferred coordinates

    ds^2 = -exp(2psi)c^2 dt^2 + exp(-2 lambda psi) dx.dx,
    psi=phi/c^2,  phi=e.u.

Keep the homogeneous vector field action. Restrict this block to isotropy
N=D>0 so the sourced u=e phi sector obeys one scalar wave equation with
speed c_s. Other free vector components can be set to zero for this sector.
Let G_N=G N. The point-particle action is the proper-time action in this
new metric; vacuum Maxwell uses the same metric. Derive its Hamiltonian and
exact source rather than keeping the earlier conserved-mass source.

First derive asymptotic static optics for psi=-G_N M_g/(c^2 r), where M_g
is the exterior active mass, not an inferred binary mass. Recover the leading
bending dependence on lambda, the weak-field PPN coefficients, and a second
order bending coefficient. Treat lambda=1 as an illustrative calibration to
the exposed near-unit bending coefficient, not a newly predicted success.
No strong-field existence or point-source regularity claim is permitted.

Then expand the exact particle source to consistent weak-field/slow-motion
radiative order for a Kepler pair with fixed weakly self-gravitating masses.
Use the formal separated-particle/constant-self-term approximation explicitly;
do not claim it covers neutron stars or complete material interiors.
Compute both quadrupole and source/trace monopole terms. Derive eccentric
orbit averages directly before comparing with a supplied GR quadrupole
expression for the same trajectory, masses and G_N. Freeze e=0,.2,.6,.8
and c_s/c=.6,1,1.4, with lambda=-1,0,1, for synthetic arithmetic checks.
The observed-pulsar eccentricity, masses and measured decay are not needed.

Check two questions algebraically: can the circular GR power be matched by
one positive speed choice, and can the eccentric dependence then agree at
lambda=1? Any mismatch is a conditional same-orbit comparator obstruction,
not an empirical exclusion. Find the lambda that would instead cancel the
leading monopole and report whether it agrees with that bending calibration.

Independent numerical routes: null-ray orbit quadrature versus bending
series; direct Kepler quadrupole third derivatives and source time variation
versus closed orbit averages; symbolic source/Legendre/PN identities. Preserve
all failures and initial formulas. No parameter-grid selection after results.
