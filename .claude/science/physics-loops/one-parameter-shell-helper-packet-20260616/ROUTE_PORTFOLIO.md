# Route Portfolio

1. **Static import plus helper source/cache packet.**
   Directly addresses the blocker asking for full source/cache coverage for the
   five helper imports. Selected.

2. **Retained helper authority notes.**
   Stronger long-term route, but it would require separate audits for each
   helper theorem and is not necessary to repair the packet artifact.

3. **Inline all helper logic into the primary runner.**
   More self-contained but high churn and worse maintainability than static
   imports plus SHA-fresh caches.
