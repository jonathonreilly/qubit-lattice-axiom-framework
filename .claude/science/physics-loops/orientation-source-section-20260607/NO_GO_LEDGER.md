# No-Go Ledger

## N1: Free Torsor Has No Equivariant Section

The sign-flip automorphism has no fixed point on `{+1,-1}`.

## N2: Sewing Does Not Rank Sections

Multiplicative sewing is coherent for both section choices.

## N3: Flat Transport Does Not Rank Sections

Both global flat sections exist and are related by gauge transformation.

## N4: Desired Source Branch Is A Section Choice

The orientation-odd source appears only after choosing a section; the host
without a section supplies no active source.
