# Literature Bridges

This branch uses literature only as explicit context/support for standard
mathematical machinery. It does not import a missing all-degree theorem as a
repo-native result.

- Bars 1980: Bessel-determinant representation of SU(N) Wilson character
  integrals.
- Stanley 1980 / Lipshitz 1988: D-finite closure context.
- Brower-Nauenberg 1981: SU(N) Wilson holonomic-operator context.
- Mallinger 1996 / Bostan 2010 / Salvy-Zimmermann 1994: finite-window
  sufficiency context for D-finite identities.

Open literature bridge: a source that cleanly proves the full SU(3) V=1
all-degree `R=3,D=2` minimal-annihilator bound in the exact form required by
the repo has not been supplied here.
