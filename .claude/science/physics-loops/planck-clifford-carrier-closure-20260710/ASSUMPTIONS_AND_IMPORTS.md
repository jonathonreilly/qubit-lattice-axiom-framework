# Assumptions And Imports

## Minimal allowed premise set

The first-principles reset uses only the current framework node
`minimal_axioms` plus dependencies whose present audit state is stated below.
For the decisive finite-dimensional test, the strongest substrate packet is
granted as a hypothesis: `H_cell = Lambda^* W`, `W = span(t,x,y,z)`, the
standard spatial rotation action on `W = 1 + 3`, and `P_A = P_1`. Granting
`P_A` makes a failure stronger: the test then asks whether the supplied exterior action
on that already-selected space is the action induced by an irreducible
`Cl_4(C)` module.

## Forbidden imports

- no observed target value, fitted selector, or coefficient match;
- no rank-four-equals-spinor identification;
- no hand-picked unitary identification between inequivalent substrate and
  Clifford representations;
- no link-local action source, reflection-positive vacuum sector, or
  first-order coframe law unless separately classified as an added premise;
- no use of `P_A` selection as evidence for the induced gamma action;
- no use of the existing explicit `C^4` gamma matrices as evidence that those
  matrices descend from `H_cell`.
