# No-Go Ledger

## Ambient-adjoint CAR from metric compatibility alone

Metric compatibility is not enough to infer ambient-Hilbert-adjoint CAR. A nonunitary similarity of a Pauli-gamma model preserves `Gamma_a Gamma_b + Gamma_b Gamma_a = 2 delta_ab I` while the ambient adjoint no longer matches the formal Clifford conjugate. The runner now includes this check, so future repairs should not restore `c_j^dagger` language without an explicit star-compatible premise or a separate retained-grade bridge.
