# No-Go Ledger

- Direct Padé[3/3] gives `3/5`, not the MC comparator `0.5934`.
- Padé[4/4] at the same supplied point gives `157/395`, worsening the gap.
- Ordinary Borel-Padé[3/3] has a positive-contour pole, so that resummation
  route does not reproduce the direct Padé[3/3] continuation.
- None of these is a universal no-go for all resummation schemes.
