# No-Go Ledger

## Not A Full Plaquette Derivation

The repair does not derive `<P>(beta=6)` or the beta=6 Wilson/Haar plaquette
surface. It only removes the Wilson coefficient relation from the list of
runner-local imports.

## Strong-Coupling Coefficients Are Not NSPT Coefficients

Existing retained-bounded strong-coupling coefficient rows cannot be used as
authority for the weak-coupling NSPT packet `w_1..w_16`. They are different
expansions.

## Alpha Boundary

`alpha_bare = 1/(4 pi)` is used only as standard notation after the diagnostic
specialization gives `g_bare^2 = 1`. This branch does not promote a reusable
alpha authority.
