# Handoff

This branch is ready for reviewer extraction. The scientific payload is a
bounded negative boundary for the P-LH NCG route:

- the same local `Cl(3)` chirality block admits SM-like and Pati-Salam-like
  finite actions;
- `M_3(C)` is not present in the one-site qubit algebra;
- two inequivalent antiunitary `J` choices exist on the same block;
- order-one depends on extra finite Dirac/opposite-action data.

The branch intentionally does not touch audit ledger/status surfaces, does not
land anything to main, and does not need to be kept fresh against main before
reviewer processing.
