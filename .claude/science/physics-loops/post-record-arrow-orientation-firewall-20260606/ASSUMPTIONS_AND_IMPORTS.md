# Assumptions And Imports

## Minimal premise set

- A finite record alphabet `O`.
- A finite post-record word `w in O*`.
- The count map `count: O* -> N^O`.
- Finite probability laws on words only when explicitly supplied.

These are enough to prove the reversal/count no-go.

## Used source surfaces

- `RECORD_CLASSICALIZATION_DYNAMICS_FIREWALL_2026-06-05.md`: pre-record
  probabilities and post-record realized information are different typed
  surfaces.
- `RECORD_FINITE_ALPHABET_POST_RECORD_DYNAMICS_2026-06-05.md`: post-record
  append/count dynamics is exact once atoms are realized, but does not supply
  production probabilities, rates, or dial selection.
- `POST_RECORD_STABILITY_DYNAMICS_SELECTOR_SUBDIVISION_2026-06-06.md`: the
  `arrow_or_dynamics_bridge` bucket needs physical-arrow and dynamics bridges.

## Open imports

- An oriented law or boundary condition is still required for a physical arrow.
- A clock/rate or production kernel is still required for dynamics calibration.
- A Hamiltonian, transfer operator, instrument, or measurement bridge is still
  required for physical formation.
- Independent audit remains required before repo-wide status changes.

## Forbidden imports

- No observed target value is used as a proof input.
- No fitted selector is used as a proof input.
- No generation or Koide value is selected.
- No stable setting is converted into a selected dial.
- No physical arrow is derived from Record.
- No production kernel is selected from counts.
- No audit verdict is applied or predicted.
