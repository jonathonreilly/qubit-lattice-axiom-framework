# Assumptions And Imports

No new axiom, admitted observation, fitted value, or retained-status assertion is
introduced.

The branch imports only the current audit ledger as read-only row metadata. The
primary runner no longer imports
`scripts/frontier_post_record_measure_weight_normalization_subdivision_2026_06_06.py`
to prove the `9`-row inventory. Instead it explicitly names the nine claim IDs
and note paths, verifies each in the ledger, verifies the source files exist, and
checks the ledger hash is unchanged.

derive a Record path rule, channel rule, character packet, Born law, physical
measure, production kernel, generation selector, or Koide dial.
