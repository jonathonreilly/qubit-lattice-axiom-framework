# Assumptions And Imports

## Supplied inputs

- Current audit-ledger snapshot.
- Upstream measure/weight normalization subdivision.
- Supplied finite path carrier and local path weights.
- Supplied finite channel row weights.
- Supplied finite character coefficients or Wilson-surface weights.

## Not derived here

- Directional path parameter, path rule, channel rule, or character packet.
- Physical measure, Born law, prior, source law, or selector.
- Generation/Koide dial value.
- Production dynamics, kernel, clock, rate, or physical arrow.
- Audit verdicts or effective retained status.
