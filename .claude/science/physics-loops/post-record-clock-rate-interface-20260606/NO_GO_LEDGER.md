# No-Go Ledger

## Counts-Alone Clock

Finite event index and prefix order are not a physical time metric. Many
strictly increasing clocks preserve the same record history.

## Counts-Alone Rate

Rates require a denominator. Event count alone does not determine elapsed time.

## Counts-Alone Hamiltonian

Append/count algebra does not select a carrier Hamiltonian, transfer operator,
coupling, or lattice time step.

## Counts-Alone Dial Selection

Event order and rates, even when clocked, do not select a generation/Koide dial
without separate dynamics or prior assumptions.
