# No-Go Ledger

- Directed certificate data do not select a production kernel.
- Same finite law can be induced by distinct kernels when rows are unvisited.
- Same scalar directed certificate can admit distinct full-support candidate
  kernels.
- A supplied kernel id can scope a certificate, but the certificate does not
  create that id.
- Post-record realized information does not derive a clock, rate, Born law, or
  physical arrow.
- Stable settings are not selected generation/Koide dials.
