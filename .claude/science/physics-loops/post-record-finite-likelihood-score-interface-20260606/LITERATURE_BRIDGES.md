# Literature Bridges

No external literature is required for this finite certificate. Likelihoods,
ratios, and supplied-prior Bayes weights are verified by direct rational
calculation on finite word spaces.

Potential later bridges:

- likelihood-ratio test calibration for supplied model classes;
- information criteria when a complexity penalty is supplied;
- Bayesian model comparison under explicitly supplied prior families;
- large-horizon approximations when exact enumeration is too large.

Those later bridges would be additional supplied-method interfaces, not
derivations from Record alone.
