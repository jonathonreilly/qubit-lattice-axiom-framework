# No-Go Ledger

## Record Alone Derives The Audit Null

Rejected. The post-record layer supplies realized finite histories and counts.
It does not supply probabilities over possible histories.

## P-Value Applies Audit Verdict

Rejected. A p-value under a supplied null can support an audit argument, but it
does not edit audit ledgers, compute effective status, or ratify retained
claims.

## Same Word Has One Canonical Audit Outcome

Rejected. The same realized word can be ordinary under one supplied null and
rare under another. Model choice is a separate input.

## Audit Interface Selects The Dial

Rejected. The finite-null interface does not select a generation/Koide dial
location. It can only test a supplied null that may encode a candidate dial.
