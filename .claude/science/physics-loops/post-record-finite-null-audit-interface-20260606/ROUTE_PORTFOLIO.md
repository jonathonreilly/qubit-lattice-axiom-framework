# Route Portfolio

## Route A: General Finite Null

Use a supplied normalized law on `O^n` and a supplied ordered statistic to
define the exact one-sided tail p-value by finite summation.

Status: pursued and verified.

## Route B: Supplied Transition-Kernel Null

Specialize the finite null to a law generated by a supplied initial law and
row-stochastic transition kernel. This connects the audit grammar to
post-record dynamics candidates without deriving the kernel.

Status: pursued as runner example and verified.

## Route C: Derive The Null From Record Alone

Try to infer the audit null law directly from post-record append/count
structure.

Status: rejected. Append/count gives realized finite data and algebraic
updates, not probabilities over possible words.

## Route D: Apply Audit Verdicts

Use the p-value interface to edit audit status or promote rows.

Status: rejected. The independent audit lane owns verdicts; this branch only
adds a reviewable source artifact.
