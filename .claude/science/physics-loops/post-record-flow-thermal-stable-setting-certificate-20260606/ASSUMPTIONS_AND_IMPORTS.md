# Assumptions And Imports

## Imported surfaces

- Current audit ledger snapshot under `docs/audit/data/audit_ledger.json`.
- Stability/dynamics selector subdivision from the stacked parent block.
- Conditional evidence ladder rule that stable dial settings need supplied
  score/rule plus map/flow stability certificate.

## Open imports

- Supplied dial domain.
- Supplied flow, score, or thermal rule.
- Supplied stability predicate.
- Exact finite or algebraic check.
- Separate selector rule before any selected-dial reading.
- Independent audit for any eventual verdict.

## Non-imports

- No selected dial is admitted.
- No generation/Koide value is forced.
- No flow, score, thermal rule, production dynamics, clock, rate, kernel, or
  physical arrow is derived from Record.
