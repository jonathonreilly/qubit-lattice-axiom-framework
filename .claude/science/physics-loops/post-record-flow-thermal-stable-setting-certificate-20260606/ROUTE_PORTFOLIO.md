# Route Portfolio

Status: selected.

Define exact certificate semantics for finite score minima, flow fixed
points/separatrices, and thermal roots under supplied rules.

## Route B: Stable setting selects dial

Status: rejected by firewall.

Stable features can locate dial settings but do not select the physical dial
value without an additional selector rule.

Status: rejected by user constraint and certificate firewall.

not forced values.
