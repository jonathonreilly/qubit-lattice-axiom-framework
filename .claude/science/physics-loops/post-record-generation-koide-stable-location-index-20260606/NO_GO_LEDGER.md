# No-Go Ledger

## Stable location is not selected dial

A stable location under a supplied rule can be indexed and audited. It is not a
selected physical dial value without a selector/invariance/target rule.

## Koide/generation remains unfixed

The index does not force `r=1/2`, `Q=2/3`, a phase, a generation count, or a
sector choice. It only records candidate row classes and stable-feature rows.

## Record does not derive the missing rule

The Record axiom types pre-record laws and post-record information. It does not
derive the stable rule, selector, measure, source law, kernel, clock, or arrow.
