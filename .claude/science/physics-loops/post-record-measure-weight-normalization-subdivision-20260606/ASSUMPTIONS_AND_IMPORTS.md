# Assumptions And Imports

## Imported surfaces

- Current audit ledger snapshot under `docs/audit/data/audit_ledger.json`.
- Selector/dial bucket subdivision from the stacked parent block.
- Conditional evidence ladder rule that selected dials need selector authority.

## Open imports

- Supplied carrier and nonnegative weights.
- Supplied trace/reference state or invariance principle.
- Supplied source functional or Radon-Nikodym density bridge.
- Supplied character/path/channel weight rule.
- Supplied readout/tangent bridge.
- Separate selector rule before any selected-dial reading.
- Independent audit for any eventual verdict.

## Non-imports

- No selected dial is admitted.
- No measure, prior, trace state, source unit, or Born law is derived from
  Record.
- No generation/Koide value is forced.
