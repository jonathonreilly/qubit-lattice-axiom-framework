# Literature Bridges

No external literature is required. The no-go uses finite counterexamples over
explicit finite word spaces.

Potential later bridges:

- decision theory for supplied loss functions;
- Bayesian model comparison under specified prior families;
- likelihood-ratio test calibration under supplied nulls;
- model-class admissibility criteria for physical candidate laws.

Each would be an added premise or interface, not a derivation from Record
alone.
