# Goal

Build a branch-local exact-support gate map for what the post-record dynamics
stack unlocks toward retained and unbounded claims.

The target is not retained. The target is a clean gate discipline:

- finite post-record certificates remain bounded;
- post-record records carry realized information, counts, and markers;
- pre-record laws carry probabilities;
- unbounded interpretation requires a separate family-lift principle;
- independent audit remains required before authority surfaces can mark any
  effective retained status.
