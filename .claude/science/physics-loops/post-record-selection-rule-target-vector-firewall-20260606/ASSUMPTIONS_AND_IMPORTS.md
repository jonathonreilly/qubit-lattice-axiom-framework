# Assumptions And Imports

## Allowed premises

- supplied finite candidate family;
- supplied source and candidate laws;
- supplied target vectors and loss weights for scoring witnesses;
- exact rational finite scoring.

## Open imports

- Record does not derive target vectors.
- Record does not derive loss weights.
- Record does not select a kernel without a supplied rule.
- Record does not derive the physical arrow or Born law.
- Stable settings are not selected dials.
- Independent audit owns any future verdict.
