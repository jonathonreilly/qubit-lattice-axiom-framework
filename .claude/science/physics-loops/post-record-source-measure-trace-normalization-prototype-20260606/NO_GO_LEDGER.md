# No-Go Ledger

## Normalization is not physical selection

Finite normalization proves that supplied weights define a probability measure.
It does not prove that the measure is physically selected.

## RN density is not Born law

An exact RN density relates two supplied finite measures. It does not derive
Born law, prior, source law, or physical reference state from Record.

## Trace uniqueness is not pre-record identification

The tracial note keeps physical identification of the trace state as an open
admission. This block preserves that boundary.
