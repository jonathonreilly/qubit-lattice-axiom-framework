# Route Portfolio

## Route A: Derive Born/source measure from Record

Rejected. Record types post-record information; it does not derive the physical
pre-record law, Born law, source measure, or selector.

## Route B: Finite source-measure trace/RN prototype

Selected. Supply finite carrier, reference measure, source weights, and RN
density, then verify exact expectation and composition identities.

## Route C: Character/path/channel weights

Deferred. The `character_path_channel_weight` rows need their own supplied
carrier and path/channel rule.

## Route D: Selector/tangent readout weights

Deferred. Those rows need a readout/tangent selector bridge and should not be
folded into this finite trace/RN block.
