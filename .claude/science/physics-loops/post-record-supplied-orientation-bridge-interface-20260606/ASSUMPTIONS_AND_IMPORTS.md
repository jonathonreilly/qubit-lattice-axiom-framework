# Assumptions And Imports

## Used

- A supplied finite law on post-record words.
- A supplied orientation bridge naming the physical forward convention.
- A supplied clock/order id.
- A supplied kernel, Hamiltonian, transfer, or instrument id when the row uses
  dynamics language.
- Exact enumeration on finite words.

## Open Imports

- The orientation bridge is supplied, not derived.
- The law is supplied, not derived.
- The clock/rate/kernel/Hamiltonian/transfer/instrument bridge is supplied, not
  derived.
- Independent audit remains required before repo-wide status changes.

## Forbidden Imports

- No observed target value is used as a proof input.
- No fitted selector is used as a proof input.
- No generation or Koide value is selected.
- No stable setting is converted into a selected dial.
- No physical arrow is derived from Record.
- No production kernel is selected from counts.
- No audit verdict is applied or predicted.
