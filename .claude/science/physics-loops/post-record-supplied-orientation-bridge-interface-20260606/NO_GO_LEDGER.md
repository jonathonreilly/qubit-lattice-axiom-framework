# No-Go Ledger

## Orientation bridge is supplied, not derived

The interface works only after a row supplies physical forward order or an
equivalent boundary/clock convention.

## Directed certificates are law-scoped

Directed endpoint probabilities can change under reversed orientation. They
must be rechecked under the named law and bridge.

## Counts do not select kernels

Forward and reversed empirical kernels can both be row-stochastic while the
count state is identical. The count state selects neither.

## Stable setting is not selected dial

This interface does not change the dial firewall. Stable settings remain
stable settings unless a selector is supplied.
