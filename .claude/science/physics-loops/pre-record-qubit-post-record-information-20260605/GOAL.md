# Goal

Explore the user hypothesis:

> the qubit is the pre-record state; post record the site has information and
> not probability.

Deliver an exact-support framework artifact for the Record-typing theorem, plus
bounded dynamics corollaries that answer what this buys and whether it needs a
new axiom. The intended result is a typed firewall: pre-record qubit dynamics,
record-event instrument, and post-record information/count dynamics.
