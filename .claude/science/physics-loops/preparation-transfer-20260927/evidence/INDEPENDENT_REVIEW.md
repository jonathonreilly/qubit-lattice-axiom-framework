Reviewed the complete calibration/evaluation scripts, protocol, source eligibility and hash closure; independently reconstructed both raw acquisitions and all three saved-rate predictions without importing either author script or rerunning an optimizer. No arithmetic blocker found for the conditional, fixed-preparation transfer result. This is not an audit verdict or precision validation.

`independent_check.py`, `independent_results.json`, `independent_arrays.npz` and `independent_check.log` preserve reproducible evidence and exact input hashes. The checker groups samples independently by exact gate, uses a 2x2 difference-coordinate least-squares readout for calibration (primary uses augmented 3x3), and augmented affine QR for target readout (primary uses 2x2). It propagates populations with a 3x3 matrix exponential in seconds and rates/second, rather than the primary closed form.

## Separation and scope

Every calibration-input and prediction-freeze hash, all ten source member hashes, evaluation script identity in the release, and release-to-freeze identity matched. The calibration code reads target x0/x1 only, never target signal, processed populations or fitted QOI; its objective contains only calibration populations. It stores all three returns, selects by calibration cost, and writes complete predictions before the freeze. The evaluator verifies the literal freeze hash and every entry before reading target I/Q; no offsets, rescaling, target fits or target-based choice. These code paths and supplied release record support the declared order; hashes cannot independently prove the absence of all historical human access. Calibration-input scope is retrospective source research, with this particular target amplitude access prospectively gated.

The model assumes pure |2> calibration preparation, equal |1>/|2> target preparation, shared stationary nonnegative downward rates, and an affine three-centroid readout. A final unitary confined to the 1–2 subspace preserves Pexc at any angle, so the sum does not require an exact final pi/2 rotation; initial preparation, leakage and relaxation during pulses remain limitations. Acquisitions are 10 h 42 min 02 s apart; recorded fields agree but frequencies, pulse amplitudes and initialization duration changed (SOURCE_ELIGIBILITY.md). Exact gate matching is verified, not an assertion of stationary charge offset. No per-gate rate alternative was fitted here. Equal-weight three-population residuals are correlated because populations sum to one; the objective is a descriptive metric, not an independent-coordinate likelihood. No experimental noise/covariance model, confidence interval, native microscopic derivation, or circuit/03 comparison is supplied by this check.
