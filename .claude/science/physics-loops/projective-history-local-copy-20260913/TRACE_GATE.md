# Trace gate

The construction addresses a concrete compatibility question: can complete
finite projector-valued histories coexist with an actual nearest-neighbor
content law, permanent support, current-Record state and fixed terminal
registers? The positive answer uses a supplied nonlocal occurrence kernel
and outcome-dependent first data sites. It supports a route comparison; it
does not close the common-first-target local-marginal or native calibration
obligations in the selected sector benchmark.
