# Route Portfolio

## Route A: Exact fitted-ratio boundary

Compute `|xi_s| / |c13_s(base)|` for the shipped parent fit. This gives an exact
lower cap required to include the current solution.

Disposition: executed.

## Route B: Bounded capped-carrier parent-slice scan

Constrain `xi_s = rho_s c13_s(base) exp(i phi_s)` with a common cap `R`, then
optimize against the parent CKM/J target while allowing the parent mass ratios
to move within `1%`.

Disposition: executed as bounded support only.

## Route C: Analytic global no-go for all small alternatives

A full analytic supremum over capped Hermitian NNI carrier families would be
stronger, but it would require a new spectral perturbation theorem not
available in this block.

Disposition: not claimed.
