# No-Go Ledger

- Exact reset channel cannot be finite-time bounded-generator dynamics.
- Asymptotic damping with `0 < p < 1` leaves positive residual at finite step
  count.
- Step-count thresholds do not determine physical time or rate.
- Multi-bit reset thresholds scale with the number of bits.
- This block does not fix any generation/Koide dial setting.
