# No-Go Ledger

- Closed clean reset without blank boundary or sink is many-to-one.
- Reset-with-sink exports old memory rather than erasing it.
- Sink discard/reblanking is a many-to-one step.
- Closed finite blank-sink preparation from arbitrary prior sink state is
  another many-to-one reset.
- A fixed finite sink capacity cannot support arbitrary many clean reset cycles
  for arbitrary old fragment words.
