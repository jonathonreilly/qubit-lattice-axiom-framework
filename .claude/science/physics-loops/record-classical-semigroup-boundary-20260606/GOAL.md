# Goal

Establish an exact branch-local boundary for dynamics on finite post-record
algebras:

- reversible algebra dynamics is only discrete permutation of atoms;
- infinitesimal derivations vanish;
- append/count dynamics is irreversible information accumulation;
- Markov/rate/dial-attractor dynamics requires a supplied generator.

The block should build on the current `origin/main` record stack and avoid
forcing any Koide/generation dial location.
