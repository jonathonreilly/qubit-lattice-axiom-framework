# No-Go Ledger

## Pruned Routes

- Record-only dial selection: the Record axiom supplies durable realized
  outcomes, not a production generator, stationary distribution, or physical
  dial selector.
- Stable dial implies physical rate: scaling a generator preserves the stable
  dial but changes rates; a physical rate claim still needs a clock/rate unit.
- Transition matrix fixes rate and time separately: the two-state check shows
  only the dimensionless product is fixed in the example.

## Routes Left Open

- Derive or admit a physical production generator, then test its stable dial.
- Derive a probability-origin bridge for pre-record probabilities.
- Supply a physical clock/rate unit if rates are claimed.
- Connect a sector-specific dynamics generator to a generation/Koide dial
  location without using observed target values as proof inputs.
