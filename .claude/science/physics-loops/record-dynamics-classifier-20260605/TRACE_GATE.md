# Trace Gate

## Claim boundary

The new source note proves stability classifications for supplied dynamics
classes on the exact generation dial. It does not derive the physical
charged-lepton arrow.

## Dependency trace

```text
Record axiom
  -> finite additive readout over supplied record sectors
  -> record-function finite-sector algebra (new)
  -> two-sector generation readout (imported)
  -> exact generation dial r(s)=2^(s-1) (imported)
  -> local stability grammar on the positive dial (new)
  -> dynamics classifier on s (new)
```

## Non-derivations

- No source/action.
- No time metric.
- No Born probability.
- No occupancy rule.
- No unique physical selection of `s=0`.

## Audit gate

The source can be audited as a bounded theorem. Any retained-grade use must
preserve the distinction between:

- classifier theorem: "this dynamics class stabilizes this dial setting";
- physical theorem: "this sector follows this dynamics class."
