# Route Portfolio

## Route 1: finite suffix action

Prove that finite suffixes act on histories by append and on counts by
translation. This route is exact support and is selected for block 1.

## Route 2: coarse-graining grammar

Prove that alphabet maps extend to word/count maps and commute with append.
Include the scalar-readout compatibility boundary. This is bundled with Route
1 because the same runner certifies the commuting square.

## Route 3: physical formation dynamics

Use PR #2701 / #2711 style finite-model formation and preservation dynamics.
Not selected for this block because those PRs already cover a bounded model
class and this block should first supply the post-record information layer.

## Route 4: dial stability

Use the finite-alphabet grammar to discuss stable dial locations. Not selected
because the user explicitly does not want to force or fix the dial; the next
use should be audit unlocks or dynamics grammar, not another selector claim.
