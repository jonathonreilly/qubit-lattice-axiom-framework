# No-Go Ledger

- Closed clean reset without blank boundary or sink is many-to-one.
- Blank-sink preparation from arbitrary prior state regresses to the same reset
  problem.
- Open-system reset channel exports old memory to an environment.
- Exact reset superoperator is singular and cannot be a finite-time exponential
  of a finite bounded generator.
- This no-go does not block asymptotic, discrete, singular-limit,
  non-Markovian, or open-boundary reset routes.
