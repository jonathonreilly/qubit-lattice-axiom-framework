# Route Portfolio

| route | status | reason |
|---|---|---|
| finite-time bounded-generator exact reset | active no-go | exponential maps are invertible; reset is singular |
| amplitude damping finite parameter | active boundary | exact reset only at endpoint |
| asymptotic relaxation | open | compatible with no-go |
| discrete reset channel | open | parent interface supplies channel, not rate |
| non-Markovian/open-boundary implementation | open | not ruled out here |

The active route is a rate-boundary no-go, not a physical implementation.
