# No-Go Ledger

- QND-alone route is closed: `H_int = 0`, a system-only pointer phase, and a
  nonzero commuting `sigma_z(S) sigma_z(E_1)` interaction with `E_1` in a
  `sigma_z` eigenstate all conserve `Pi_S` but write no fragment record.
- Same-fragment coherent re-use is not a persistence proof: a second identical
  kick can erase the record. Persistence is only the fresh/idle/decoupled
  completed-fragment statement.
