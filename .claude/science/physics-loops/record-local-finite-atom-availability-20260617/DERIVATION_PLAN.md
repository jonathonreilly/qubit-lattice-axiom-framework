2. Use each one-site `M_2(C)` to declare a diagonal two-atom readout algebra.
3. Verify the projectors are nonzero, orthogonal, idempotent, sum to identity,
   and are fixed by entrywise `K`.
4. Tag one atom per site and verify support-disjointness.
5. Add the finite Boolean unit-count functional and prove finite additivity.
6. Update the parent schema to cite this theorem while preserving the
   production residual.
