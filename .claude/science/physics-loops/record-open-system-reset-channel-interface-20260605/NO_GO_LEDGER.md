# No-Go Ledger

- Closed clean reset without blank boundary or sink is many-to-one.
- Sink reset exports old memory; it does not erase for free.
- Blank-sink preparation from arbitrary prior state has the same reset regress.
- A finite-rate damping semigroup does not derive the exact reset endpoint at
  finite time without a supplied endpoint parameter.
- The reset channel interface does not fix a clock, rate, cost, boundary, or
  generation/Koide dial setting.
