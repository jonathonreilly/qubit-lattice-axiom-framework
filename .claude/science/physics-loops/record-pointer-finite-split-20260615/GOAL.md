# Goal

Repair the post-review record-pointer lane by splitting the clean finite
controlled-coupling example away from the over-broad equivalence claim in the
parent record-formation note.

The target is not an effective-status change. The target is an audit-ready
source packet with explicit finite hypotheses:

- one system qubit and finitely many environment qubits;
- pointer observable `Pi_S = sigma_z(S)`;
- controlled coupling `H_rec(g) = g sigma_z(S) sum_k sigma_x(E_k)`;
- recording time `t_rec = pi/(4g)`;
- singleton fragments obtain full pointer information;
- a finished fragment persists under later local controlled recording.

The parent equivalence, necessity theorem, transfer-class consequence, physical
pointer derivation, coupling selection, action/dynamics derivation, and
`beta = 6` claims remain out of scope.
