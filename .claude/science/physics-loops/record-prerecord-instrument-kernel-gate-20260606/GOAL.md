# Goal

Add a conditional instrument gate for the pre-record side of record dynamics.

The target claim is:

```text
with a supplied projective instrument and Born trace rule, a one-qubit state
produces probabilities over possible future record atoms; the realized
post-record atom is a separate information object.
```

This is not a derivation of the instrument, Born rule, IID frequencies, a
physical generator, a clock/rate unit, or a dial value.
