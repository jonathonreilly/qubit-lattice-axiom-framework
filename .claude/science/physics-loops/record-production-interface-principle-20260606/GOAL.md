# Goal

Package the pre-record/formation/post-record distinction as a reusable
dynamics-interface principle.

The target is exact support for the type split:

- pre-record quantum states can carry predictive weights and coherence;
- record production is a separate bridge or instrument;
- post-record histories/counts/readouts are information dynamics after the
  realized atom exists.

The target is not a derivation of record-production dynamics, Born
probabilities, or a generation dial.
