```yaml

target_claim_id: null
target_blocker_text: "Can post-record append/count dynamics determine the production kernel, probability law, rate, or dial attractor?"
source_of_blocker_text: user_goal
```

The artifact prunes the route that tries to get production dynamics from the
post-record information layer. It supports a typed dynamics interface:

```text
producer kernel / instrument -> realized atom stream -> append/count layer
```
