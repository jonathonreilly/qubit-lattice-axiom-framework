# Goal

Quantify the finite information bookkeeping of the reset-with-sink construction.

The target is a bounded-support ledger: the reversible sink map preserves the
full finite label support while moving old fragment memory into explicit sink
bits. Discarding or reblanking that sink is a separate many-to-one step.

This block must not derive thermodynamic cost, physical reset dynamics, rates,
sink blankness, or any dial setting.
