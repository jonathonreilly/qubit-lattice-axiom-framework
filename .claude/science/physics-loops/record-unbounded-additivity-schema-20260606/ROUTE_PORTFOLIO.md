# Route Portfolio

| Route | Result | Reason |
| --- | --- | --- |
| Fixed finite prefix | exact-support | Once `N` is fixed, finite additivity gives exact readout and a finite bound by the prefix length. |
| Arbitrary finite-prefix schema | conditional-support | With supplied nonzero pairwise-disjoint records, `I(R_n)=n I0` has no global finite cap over finite `n`. |
| Infinite completed history | open / not needed | The block uses arbitrary finite `n`, not an actually completed infinite collection. |
| Probability/frequency route | open | Counts and frequencies are post-record readouts; a future law needs a kernel/IID bridge. |
| Production dynamics route | open | Record consumes realized atoms; it does not produce them. |
| Dial-selection route | no-go for this block | No generator or selector is supplied by finite additivity. |
