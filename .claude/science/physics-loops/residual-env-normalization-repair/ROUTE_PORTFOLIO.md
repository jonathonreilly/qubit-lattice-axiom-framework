# Route Portfolio

## Chosen Route

Separate the arbitrary scale of the unnormalized class function from the actual trivial Peter-Weyl coefficient:

```text
z_(p,q)^env = lambda_env * kappa_(p,q) / a_(p,q)^4
z_(0,0)^env = lambda_env * kappa_(0,0)
```

Then `(1/lambda_env) C_(Z_beta^env)` equals `R_beta^env` at every weight.

## Rejected Route

Do not assert or cite `kappa_(0,0)=1`. That would be a stronger normalization theorem and remains a future target.
