# No-Go Ledger

- `S_0=+beta Re` with `exp(-S_0)` gives negative coefficients already for
  `Z_2`; do not use that convention for the positive Wilson plane kernel.
- A finite angular grid is not exact Haar integration for `exp(beta cos theta)`
  because the exponential has infinitely many Fourier modes.
- Numeric `SU(2)` Monte Carlo is support only, not an exact nonabelian proof.
