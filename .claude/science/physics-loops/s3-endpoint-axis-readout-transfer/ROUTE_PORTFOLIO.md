## Stuck Fan-Out Synthesis

Three independent frames agree on the same wall:

- counting frame: four labels can only become three axes by pairing exactly one
  pair of labels;
- measure frame: a total quotient is uniform only if the pair has weight
  `1/3` and both singleton labels each have weight `1/3`;
- typing frame: the current endpoint readout is channelwise and does not
  identify same-source signed axis variables.

The resulting theorem target is therefore not "find any selector." It is a
specific physical endpoint transfer theorem selecting one classified quotient,
one classified source law, and one same-source signed readout.
