# Assumptions And Imports

## Used

- Exact finite source model: `X_CR=+1` with probability `2/3` and `X_CR=-1`
  with probability `1/3`.
- Standard source-coupled exponential family:
  `Z_CR[J]=(2/3) exp(J)+(1/3) exp(-J)`.
- Connected cumulant identity:
  `D^2 log Z = D^2 Z - (D Z)^2` at `Z[0]=1`.

## Not Used

- No endpoint value is used as an input.
- No endpoint triple is used as an input.
- No fitted scalar calibration is used.
- No observed comparator is used.
- No audit verdict is applied.
