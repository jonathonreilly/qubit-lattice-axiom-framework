# Goal

Create an exact atlas for the remaining S3/Route-2 readout endpoint primitive
and use it to prevent the campaign from treating equivalent faces as separate
closures.

The block verifies that `rho_E=21/4`, `q_E=15/8`, `c_TE=-8/9`,
`lambda=q_E/q_T=9/4`, the diagonal metric ratio `b/a=1449/704`, and the
O_h inverse-square form are exact equivalent discharge faces once the granted
T-side values are assumed. It also verifies that no current named surface
derives the missing center primitive.
