# Goal

Block56 attacks the finite-size version of the S3/Route-2 readout endpoint
triple problem.

The target implication is:

```text
finite-size E-center calibration evidence
  -> exact q_E = 15/8
  -> exact beta_E / alpha_E = 21/4.
```

The result is negative for the current evidence.  The landed fixed-radius and
box-proportional schedules miss `15/8`, and a same-evaluator radius-window
probe at `N=17` and `N=19` does not find an untuned rescue.  Future positive
work must supply a predeclared schedule theorem, a selector theorem, or an
independent nonblind source/readout primitive.
