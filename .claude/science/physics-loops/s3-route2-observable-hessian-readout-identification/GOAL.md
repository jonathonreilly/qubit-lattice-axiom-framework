# Goal

Block77 tests whether the existing scalar observable-Hessian route supplies
the physical Route-2 source/readout primitive exposed by Block76.

## Result

It does not.  The scalar `log|det|` Hessian is scalar-only and does not provide
a color/channel-resolved Route-2 `E/T` connected readout or a pure-disconnected
singlet identification.

The remaining primitive is a color/tensor-resolved source functional whose
connected Hessian is the Route-2 physical readout for the same source.
