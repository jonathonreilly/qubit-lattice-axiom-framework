# No-Go Ledger

## Prior Boundaries

- Equivariance alone leaves the `E:T1` readout ratio free.
- Quadratic `O_h` invariants leave the `E:T1` ratio free.
- Positive one-pole channel-volume cones cannot reach `q_E/q_T=9/4`.
- Theta-to-slice transport preserves source-side ratios.

## Block45 Boundary

The current class-A polynomial carrier `K_R` contains no channel-weight
coordinate. Its E/T endpoint columns are identical up to relabeling:

```text
E-shell=(1,0), T-shell=(1,0)
E-center=(1,1/6), T-center=(1,1/6).
```

Thus a channel-blind polynomial response cannot generate the E/T density
factor `3/2` or inverse-square ratio `9/4`.

## Not Claimed

This is not a global no-go over all source/readout primitives. It only prunes
the current polynomial carrier as the source of channel-density normalization.
