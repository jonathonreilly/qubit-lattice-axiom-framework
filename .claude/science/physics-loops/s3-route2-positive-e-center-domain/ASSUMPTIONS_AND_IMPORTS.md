# Assumptions And Imports

## Minimal Premise Set

- Exact reduced readout family `q_E = 1 + rho_E/6`.
- E-shell normalization from the Route-2 carrier.
- Conditional T-side values `q_T=5/6` and `s_TE=-2` when analyzing the sign dependency.
- Optional oriented Rconn ansatz as conditional support, not as current-surface closure.

## Forbidden Inputs

- The desired target `rho_E=21/4` as a positivity proof.
- A fitted readout-map endpoint.
- A hidden positivity axiom for the E-center column.
- An audit verdict.

## Open Import

An exact readout-domain theorem excluding `rho_E <= -6`, or a stronger
endpoint theorem deriving the target `rho_E=21/4`.
