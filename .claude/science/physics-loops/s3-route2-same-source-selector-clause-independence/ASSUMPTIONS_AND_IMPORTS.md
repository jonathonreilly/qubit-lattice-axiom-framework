# Assumptions And Imports

Allowed support:

- Block147 selector-equivalence atlas.
- P-cal connected subtraction when typed to a same source.
- Block121 minimal `1 + adjoint` source-extension consistency support.
- Block127 source-readout isometry sufficient theorem as a target contract.
- Existing endpoint orientation sign support, consumed only after `kappa=0`.

Forbidden imports:

- Endpoint value or endpoint triple.
- `rho_E`, `q_E`, or observed quark values.
- Fit-derived source weights or target comparators.
- Reading `c_TE=-8/9` backward into the source.
- Treating formal `J_CR`, `O_CR`, or finite `P_R` rows as physical without a
  typed source/readout theorem.
