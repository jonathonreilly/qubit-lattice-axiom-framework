# Assumptions And Imports

Allowed support:

- P-cal connected subtraction.
- Same-source raw moment contract `E[XY]=1` when explicitly assumed.
- Binary same-record subcase when explicitly assumed.
- Formal binary source-jet algebra when explicitly marked formal.
- Existing Block143-146 source-measure/source-typing boundaries.

Forbidden imports:

- Endpoint value or endpoint triple.
- `rho_E`, `q_E`, or observed quark values.
- Fitted scalar calibration.
- Assertion that the physical Route-2 source already has `q=2/3`.
- Assertion that formal `J_CR`, `O_CR`, or `P_R` rows are physical without a
  typed source/readout theorem.
