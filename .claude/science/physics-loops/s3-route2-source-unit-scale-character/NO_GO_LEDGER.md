# No-Go Ledger

- Log-action cocycle semantics alone does not select derivative order.
- Affine-gauge Hessian readout leaves `g(w) Phi''(w)` prefactors open.
- Positivity and channel-uniform functional form do not force constant `g`.
- Homogeneous prefactors `g=w^m` miss the endpoint for `m != 0`.
- Endpoint equality `g_E/g_T=1` does not imply global no-scale coefficient.
- Regular scale-character covariance reduces to `g(w)=C w^m` but does not
  force `m=0`.
- Endpoint equality inside the character family diagnoses `m=0` only by using
  the target endpoint.
