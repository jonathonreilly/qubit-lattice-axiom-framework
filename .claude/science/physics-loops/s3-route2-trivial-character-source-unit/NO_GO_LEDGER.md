# No-Go Ledger

- Log-action cocycle semantics alone does not select derivative order.
- Affine-gauge Hessian readout leaves `g(w) Phi''(w)` prefactors open.
- Positivity and channel-uniform functional form do not force constant `g`.
- Regular scale-character covariance reduces to `g(w)=C w^m` but does not
  force `m=0`.
- One-point source-unit normalization leaves all `m` open.
- Primitive RN/Fisher source-coordinate normalization does not fix Hessian
  coefficient weight.
- Planck/action source-coordinate normalization does not fix Hessian
  coefficient weight.
- Endpoint equality diagnoses `m=0` but cannot be used as source-unit proof.
