# Route Portfolio

## R1: One-Point Source Unit

Premise: fix `g(1)=C`.

Result: no-go. Every `C w^m` satisfies it.

## R2: Primitive RN/Fisher Unit

Premise: accept primitive source coordinate `lambda=1`.

Result: no-go for the coefficient by itself. The source coordinate is fixed,
but the Hessian coefficient can still carry character weight.

## R3: Planck/Action Unit

Premise: accept action exponent coordinate as source unit.

Result: no-go for the coefficient by itself. Action-source normalization does
not prove the Hessian prefactor is a scalar.

## R4: Source-Unit Scalarity

Premise: prove `g(a w)=g(w)`.

Result: exact support. This directly closes the Block112 coefficient subgate.

## R5: Distinct-Weight Calibration

Premise: prove `g(u)=g(v)` for one independent pair `u != v`.

Result: exact support inside the Block113 character family. It forces `m=0`.
