# Goal

Continue the S3/Route-2 endpoint campaign by testing a concrete positive
origin for the inverse-square covariance primitive:

```text
D_X = A_X / w_X,
q_X proportional to D_X^2.
```

This block asks whether the two-pole law needed for
`rho_E=21/4` can be represented as a channel-density covariance primitive.

Actual status: conditional support. The primitive gives the endpoint exactly,
but the current surface does not derive it.
