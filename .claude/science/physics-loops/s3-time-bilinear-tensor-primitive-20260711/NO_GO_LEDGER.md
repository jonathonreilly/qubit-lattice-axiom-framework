# No-Go Ledger

## Exact route pruned

**Route:** select `lambda=1` from homogeneous carrier properties inside the
explicit family `O_lambda=lambda K_R`.

**Reason:** all enumerated properties are homogeneous, while the exact star
point `q_*=e0+E_x` makes `K_R(q_*)` nonzero for arbitrary finite `delta`.
Therefore `K_R` and `2K_R` both satisfy those properties and differ.

**Scope:** only homogeneous overall normalization.  Physical ray
identification, relative E/T normalization, and any nonhomogeneous response
condition are not pruned.

- Endpoint-fixed contraction: available as bounded support only.
- Full five-component covariant carrier: algebraically viable; physical
  semantics remain open.
