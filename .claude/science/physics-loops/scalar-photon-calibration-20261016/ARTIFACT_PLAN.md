# Review surface

The source note contains the complete theorem, observation contract, original
equations, explicit coefficient formulas, extraction, compatibility tests and
limits. The primary `scripts/scalar_photon_calibration.py` imports all four
load-bearing helpers; its declared closure binds the note and helpers. Output
is `outputs/scalar_photon_calibration/result.json`, with the standard cache in
`logs/runner-cache/scalar_photon_calibration.txt`.

Historical frozen development and independent evidence are preserved in an
archive with a per-file digest manifest. It is provenance only; canonical
computation does not read it or require a prior worktree. Review bindings name
the exact bytes checked. Source mutation, portable replay, vocabulary, graph
and file-set checks are recorded alongside the final result.
