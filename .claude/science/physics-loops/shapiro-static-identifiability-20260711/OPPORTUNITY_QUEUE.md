# Opportunity Queue

This is a single named-target run. Ranked follow-on opportunities are recorded
for completeness but are not separate science blocks in this PR.

1. **Exact input-interface/history-label no-go:** high closure probability, zero physics imports, existing runner and cache, small review radius.
2. **History-sensitive two-time observable:** potentially restores a real causal discriminator, but needs a temporal state and source protocol.
3. **Discrete retarded-field construction:** potentially supplies a causal phase comparator, but needs a supplied or derived wave equation and boundary data.
4. **Single-static-field hypothesis test:** narrows the static hypothesis class without claiming causal uniqueness.
5. **Cross-family temporal replay:** only meaningful after a temporal construction exists.
