# Route Portfolio

## Route A: Keep Generic Lambda

Rejected. The floor formula shows non-half-integer cutoffs can fail the
uniform interval label theorem.

## Route B: Exact Fractional-Cutoff Condition

Partially recorded. For one fixed positive twist, the condition is
`a <= frac(Lambda) < 1-a`.

## Route C: Uniform Half-Integer Cutoff

Chosen. The theorem needs a uniform statement over `a in (0,1/2)` and
`a in (-1/2,0)`, so `frac(Lambda)=1/2` is the exact clean cutoff family.
