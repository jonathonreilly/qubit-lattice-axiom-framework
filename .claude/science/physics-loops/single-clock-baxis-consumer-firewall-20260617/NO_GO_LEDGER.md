# No-Go Ledger

- Record durability does not select the axis: Record supplies no time metric,
  no dynamics, and no axis label.
- KMS/APBC does not select the axis before a time circle is supplied; APBC is
  covariant with the supplied circle.
- Anomaly/chirality constrains the count `d_t`, not the axis label.
- RP uniqueness alone is false as an axis selector because the staggered
  surface has the exact `tau <-> x1` exchange certificate.
