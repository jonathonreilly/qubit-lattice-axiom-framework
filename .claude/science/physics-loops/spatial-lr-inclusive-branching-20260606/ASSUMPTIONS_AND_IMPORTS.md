# Assumptions And Imports

## Minimal Premises Used

- Finite connected spatial lattice `Lambda`.
- Finite set of bounded self-adjoint local Hamiltonian terms `h_Z`.
- Finite interaction supports with bounded diameter `R_0`.
- Operator norm submultiplicativity, triangle inequality, Duhamel expansion, and locality of commutators.

## Repaired Premise

The LR proof now uses the inclusive interaction-graph degree

```text
D_I^+ := max_Z |{Z' : Z' intersects Z}|
```

so repeated choices `Z_{i+1}=Z_i` are counted. The previous exclusive degree is not used in the LR constants.
