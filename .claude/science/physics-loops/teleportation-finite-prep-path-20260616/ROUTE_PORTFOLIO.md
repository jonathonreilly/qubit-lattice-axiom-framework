2. Analytic finite interval gap certificate

   Attempt a rigorous lower bound for every `G in [0,1000]` rather than a
   sampled certificate. This is higher value but needs stronger perturbation or
   monotonicity control than this block proved.

3. Native apparatus/readout theorem

   Use the 2026-06-15 microscopic closure and apparatus dynamics candidates to
   build one deterministic protocol theorem. This is the main remaining closure
   target, but it is larger than this bounded support block.

4. No-go demotion

   If the finite path failed, record that endpoint diagonalization cannot be
   used as a preparation route. It did not fail on sampled finite surfaces.
