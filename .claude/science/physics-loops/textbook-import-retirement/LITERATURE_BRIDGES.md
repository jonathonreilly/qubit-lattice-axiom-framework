# Literature Bridges

This block keeps literature in parallel rather than load-bearing wherever the
repo already has a framework-local calculation:

- Maradudin / Spitzer / Lawler remain context for the `Z^3` Green theorem.
- Kolb-Turner / Gondolo-Gelmini / Sommerfeld references remain context for DM
  thermal conventions, with finite normalization algebra proved locally.
- Lawson-Michelsohn remains context for Clifford classification, with
  `Cl^+(3)` computed directly in the runner.
- Bernoulli terminology remains context for exact rational forms; no
  Bernoulli-polynomial theorem is imported.
