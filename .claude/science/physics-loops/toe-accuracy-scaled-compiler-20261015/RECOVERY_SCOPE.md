# Exact recovery and evidence scope

BODY_MAP selects the three literal current bodies once in the canonical note. The sole external canonical parent is pinned as a complete file, with exact intervals for the protected finite-grid proof and exposed comparison. Source aliases sharing those hashes recover from those intervals. No separate Gibbs, clock, bank or mediator theorem edge is inferred from the Git stack or packaging precedent.

SOURCE_MANIFEST names each selected identity and its recovery path; ARCHIVE_INDEX stores remaining selected bytes once per SHA256; RECOVERY_SELECTION distinguishes every verified frozen member from the narrower set promised as portable recovery. Omitted older snapshots are explicitly marked, not represented as recursively recoverable. Nested freeze files are included by exact path when selected and are not silently excluded by basename.

Current candidate/readout/check metadata, actual qualified root source decision, real source-at-launch captures and streams are selected. Parent publication/review metadata provide provenance only. Initial null bindings are immutable historical evidence; later source/parent bindings are separate. Existing read-only access failures remain recoverable. No root fixture from the packaging precedent is imported or rerun.

Source hashes, AST comparisons, function counts, freeze-member counts and subprocess exit codes demonstrate identity and actual metadata execution only. They are not scientific evidence or PASS quotas. The direct seal describes its in-process operation honestly; no extra subprocess receipt is invented.
