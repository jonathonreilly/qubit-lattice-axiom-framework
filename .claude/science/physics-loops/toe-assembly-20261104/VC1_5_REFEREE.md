### R1. P implies F

**Proposition R1.** Let `ω` be a state of `A` with `ω∘Ad V = ω` for every local gauge unitary `V` (Def 3). If `ω|A^G` is pure, then `π_ω(A)''` is a factor. This holds on `L5-O[R]`, on `L5-U[m]` and on `L_cube`.

*Proof.* Let `(H, π, Ω)` be the GNS triple of `ω`. Let `Z` be a projection in the centre `π(A)'' ∩ π(A)'`. Put `φ(A) = ⟨Ω, Zπ(A)Ω⟩`.
1. *`0 ≤ φ ≤ ω`.* `Z` commutes with `π(A)`, so `φ(A^*A) = ⟨π(A)Ω, Zπ(A)Ω⟩ ≥ 0` and `ω(A^*A) − φ(A^*A) = ⟨π(A)Ω, (1 − Z)π(A)Ω⟩ ≥ 0`.
2. *`φ` is gauge invariant.* Fix a local gauge unitary `V ∈ A`. Define `W` on `π(A)Ω` by `Wπ(A)Ω = π(AV^*)Ω`. Gauge invariance gives `‖π(AV^*)Ω‖^2 = ω(VA^*AV^*) = ω(A^*A) = ‖π(A)Ω‖^2`, so `W` is well defined and isometric. Its range contains every `π(B)Ω` (take `A = BV`), so `W` extends to a unitary. For every `B`, `Wπ(B)π(A)Ω = π(BAV^*)Ω = π(B)Wπ(A)Ω`, so `W ∈ π(A)'`. Now `π(A)π(V^*)Ω = Wπ(A)Ω` and `π(V^*)Ω = WΩ`. Since `Z` commutes with `π(V)` and with `W`,
   `φ(VAV^*) = ⟨π(V^*)Ω, Zπ(A)π(V^*)Ω⟩ = ⟨WΩ, ZWπ(A)Ω⟩ = ⟨WΩ, WZπ(A)Ω⟩ = φ(A)`.
3. *`φ` is a multiple of `ω`.* The proof of Theorem 2.1 gives `φ = φ∘E` for every bounded gauge-invariant functional. `φ|A^G ≤ ω|A^G`, and `ω|A^G` is pure, so `φ|A^G = cω|A^G` with `c = φ(1)`. Hence `φ = φ∘E = cω∘E = cω`.
4. *`Z` is a scalar.* For all `A, B`, `⟨π(B)Ω, (Z − c)π(A)Ω⟩ = ⟨Ω, (Z − c)π(B^*A)Ω⟩ = φ(B^*A) − cω(B^*A) = 0`. So `(Z − c)π(A)Ω = 0` for every `A`, and `Z = c1`. A projection that is a scalar is `0` or `1`.

The centre of a von Neumann algebra is generated by its projections. So the centre is trivial, and `π_ω(A)''` is a factor. ∎

*Consequence.* The P-witnesses `ω_0`, `ω_F` (Theorem 4.2), the even-`m` witnesses of Theorem 5.5 and the singlets of Theorem 7.1 are factor states in the sense of Def 5. The proof uses only that each gauge automorphism is `Ad` of a unitary of `A` and that gauge-invariant functionals satisfy `φ = φ∘E`.

### Lemma C (central form of Theorem 3.1(d))

**Lemma C.** Let `ω` be a state of `A`. Let `P_i ∈ A` be local projections such that each local `A` commutes with `P_i` for all large `i`, `ω((P_i − P_0)^2) = 0` for all `i`, and `0 < ω(P_0) < 1`. Then `π_ω(A)''` is not a factor.

*Proof.* In the GNS triple, `‖π(P_i − P_0)Ω‖^2 = 0`, so `ξ := π(P_i)Ω` does not depend on `i`. For local `A` and large `i`, `π(A)ξ = π(AP_i)Ω = π(P_i)π(A)Ω`. So `Zπ(A)Ω := π(A)ξ` is well defined on `π(A_loc)Ω`, has norm at most one, and equals `lim_i π(P_i)` there. The `π(P_i)` are uniformly bounded, so `Z = s-lim_i π(P_i)` on all of `H`. Hence `Z` is self-adjoint and `Z ∈ π(A)''`. For local `B`, `Zπ(B)π(A)Ω = π(BA)ξ = π(B)Zπ(A)Ω`, so `Z ∈ π(A)'` by density and continuity. On `π(A_loc)Ω`, `Z(π(A)ξ) = Z(π(AP_j)Ω) = π(AP_j)ξ = π(A)ξ`, so `Z^2 = Z`. Thus `Z` is a central projection with `⟨Ω, ZΩ⟩ = ω(P_0) ∉ {0, 1}`, so `Z ≠ 0, 1`. ∎

### R2. E does not imply F (on `L5-U[m]`)

**Proposition R2.** Fix `m ∈ {1, …, 9}`, the base tick and any `ε, μ, τ_E`. Choose an admissible end number `a`, `max(0, m − 5) ≤ a ≤ min(5, m)`, with `a ≠ m − a`; one exists for every `m`. ### R4. The odd-`m` ice limits are stationary and symmetric

Each site then has, along each axis, one link pointing in and one pointing out: three high ends and three low ends. (b) Each hop term has a matter annihilator on its right, so each cube gate fixes `|c⟩`. On `|c⟩`, `(p_{ℓ,src} − m/2)^2 = 1/4` on every link, so `W_E` acts as the scalar `e^{−3iτ_EL^3/4}`.
(c) The map `x ↦ Q(x − c_0) + c_0 + 2t` is well defined mod `L`, since `c_0 − Qc_0 ∈ Z^3`. It preserves the tilings, since `L` is even. The relabelling fixes the matter vacuum.
