# Artifact Plan

Block 1 will produce an artifact only if it honestly records whether the
mathematics closes natively or only at named-theorem granularity:

1. a self-contained theorem/counterexample resolving the at-most-three
   scaled-projector threshold, or a bounded theorem that exposes its exact
   named mathematical import and preserves the native residual;
2. an exact symbolic runner or finite certificate when it checks genuinely
   load-bearing identities;
3. the complete loop pack and claim-status/trace certificates;
4. a hypothetical candidate-axiom consequence section, without modifying the
   canonical axioms;
5. one dedicated branch commit, push, and prepared/open PR after full
   conformance self-review.

A partial derivation remains in the loop pack unless it establishes a useful,
nonduplicative exact lemma with direct trace to the named blocker.
