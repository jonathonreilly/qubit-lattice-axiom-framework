# No-Go Ledger

No broad negative is preregistered.  Failure to derive the typed intertwiner,
raw normalization, or exact gluing rejects only the displayed determinant
functional on the six registered carriers.

Live alternatives include another direct action functional, covariant
POVM/null semantics, action-derived support/filling, degree-mixing Nambu or
Bogoliubov symbols, OS/GNS reduction, a different event algebra, and the
independent open-boundary route.  A failure does not prove that an axiom is
required.  Any shipped negative broader than the executed family must pass a
fresh N1--N8 gate and name every untested route.
