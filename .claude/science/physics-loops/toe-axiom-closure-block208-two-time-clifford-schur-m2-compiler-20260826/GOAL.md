# Goal

This campaign tests the highest-ranked successor to the exact H1
edge-comparison/cell-corner factorization: whether a reproduced local
two-time Clifford cell fixes a positive one-site `M2(C)` Record instrument
that supplies the temporal factors missing from the same-time construction.
The target is complete H1 local ownership, not another presentation of the
Qubit axiom's already supplied `Cl(3,0) ~= M2(C)` equivalence.

transpose right-Schur state, fixed H1 second TT column, literal forward and

## Preregistered instrument families

The candidate families are fixed before target evaluation.

1. **Spectral measure-and-prepare.** Use only the generator spectral
   projectors `P(i,s)=(I+s sigma_i)/2`.  For a fixed complete menu,
   `J(i,s)(rho)=Tr(P(i,s) rho) P(i,s)`.  Joint normalization, Choi positivity,
   endpoint reversal and cubic transport are mandatory.
2. **Two-endpoint product instrument.** Apply the fixed projective menus to
   both endpoint carriers.  Oriented differences and endpoint averages must
   be reconstructed as fixed signed statistics of the joint Record outcomes;
   the signed statistic itself is not an outcome probability.
3. **Ordered sequential instrument.** Test both orders of the same fixed
   projective operations.  Any Jordan/radial or commutator/handed selection
   must arise from order and the reproduced cell, not from a post-result sign.
4. **Local cell-block instrument.** Test whether the reproduced four-corner
   `CP` matrix supplies a positive normalized effect or Choi operator after
   typed realification, using only local blocks.  No positive-part projection,
   eigenvalue clipping, or fitted normalization is allowed.
5. **Strict local relay.** If the direct families miss only temporal support,
   test one preregistered nearest-neighbor microstep carrying an explicit
   Record pointer between the two time layers.  A host label or hidden state
   is disallowed.

For any family, the same fixed construction must handle forward and actual
reverse, every proper-cubic frame, and the same-`q`, different-`p` collision.

## Decision classes

- **complete H1 local ownership:** every completion witness passes and the
  instrument composes with the Block-206 positive port-free law;
- **typed compiler support:** realification and a positive normalized local
  instrument are exact, but one or more named H1 ownership leaves remain;
- **scoped candidate boundary:** the complete preregistered family fails a
  named exact gate, with untested process/action/relay families kept live.

Only complete H1 local ownership opens H2.  Two physically complete laws on
the same inputs with distinct distributions and no remaining discriminator
would meet the existing axiom-update decision threshold.  Anything weaker
moves no TOE percentage and retires no formal obligation.
