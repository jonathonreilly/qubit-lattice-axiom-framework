# Block 220 covariance-certificate repair preregistration

Date frozen: 2026-08-28

## Why this repair is required

The repaired v2 classical Markov process has no observed hidden-state or
schedule counterexample, but the first frozen physical certificate does not
literally satisfy repair-preregistration item 4. Runtime directions are stored
as tangent-port ordinals `0..3`, whereas the controller intertwiner has six
signed-axis columns. The frozen bytes do not bind the two encodings. They also
treat diagnostic symbol `X` like a scalar ray even though no such invariant
one-dimensional carrier was embedded.

This is an evidence defect, not permission to change the accepted classical
transition semantics after seeing held-out outcomes. The repair may only
conjugate the base-frame port encoding into physical directions and make the
declared CP realization literal. Any change to a winner, write, priority,
weight, success/failure terminal, or tested scan count fails the repair.

## Frozen physical direction convention

1. A directed controller state stores an actual signed coordinate axis
   `d in D6={-x,+x,-y,+y,-z,+z}`, not a bare ordinal.
2. The scheduler supplies an oriented front normal `n in D6` and only tangent
   directions with `n dot d=0` are active.
3. In the already-tested base context `n=+x`, ordinals `0,1,2,3` mean
   `(+y,+z,-y,-z)`, hence D6 columns `[3,5,2,4]` in the existing ordering.
4. Physical inverse is `d -> -d`. Physical successor is
   `successor(n,d)=n cross d`. For every normal, the four-port table must be
   generated by repeated successor applications. Proper-cubic rotations act
   on both `n` and `d`; a context-dependent cyclic relabelling of ordinals is
   allowed, but inverse and successor must commute with transport.

## Frozen on-site signature sectors

For each supplied normal context, the active named rays are

- `U_b` from the Block 219 transient pair;
- `R_(b,d), P_(b,d), H_(b,d)` for the four tangent directions;
- `L_b, S_b, LOCK_b, BG_b`.

These are 34 mutually orthonormal rays. `X_n` is not a scalar ray. It is the
orthogonal projector onto their 94-dimensional complement in the rank-128
on-site block. A malformed-target transition that leaves `X_n` unchanged is
a covariant block partial isometry with factor `X_n`, not a rank-one `X` row.
The family must obey `U_g X_n U_g^dagger=X_(gn)` and complement invariance.

## Required executable certificate

The primary and a structurally independent consumer must construct, not just
describe, the following finite certificate from the frozen semantic table.

1. Rebuild the controller intertwiners and all named physical rays. Verify
   their orthogonality, noncode support, proper-cubic transport and complement
   transport before compiling any transition.
2. Compile genesis for both bits and all six normal contexts. It has four
   separately indexed rows of squared weight `1/4` on each scheduled `U_b`
   input.
3. For every six-normal context, every one of four scheduled directed pairs,
   and every ordered pair of the 35 named-or-projector signature sectors,
   compile exactly one priority winner or the default identity. This is
   `6*4*35^2=29,400` pair branches.
4. For every six-normal context, every center signature sector, and every one
   of the 16 reserved/nonreserved neighbour-projector masks, compile exactly
   one guarded star winner or default. This is `6*35*16=3,360` star branches.
5. Construct each branch as a tensor product of named-ray partial isometries
   and, where present, `X_n` or reserved/nonreserved projectors. Check
   `K^dagger K` equals its declared input-sector projector.
6. Verify completeness: genesis sums to the scheduled `U_b` projector; the
   pair input sectors sum to `I tensor I` for each context and selected port;
   the star input sectors sum to `I^tensor5` for each context. No coherent sum
   of distinct branch rows is allowed.
7. Under all 24 proper-cubic rotations and complement, transport the context,
   selected port, complete input signature, priority winner/default, weight,
   output signature, and operator factors. Each compiled branch must land on
   the transported branch up to the phase calculated from its actual input
   and output rays. `R` and `S` carry the existing `A2` sign; projectors erase
   that sign in `K^dagger K` and in the CP branch.
8. The frozen JSON must serialize the six-normal port map, signed-axis
   inverse/successor operations, role representation types, signature-sector
   projectors, branch compiler and completeness domain. Its digest must bind
   the exact bytes consumed by both implementations.

## Required regressions and falsifiers

- All prior baseline classical outcomes, terminal words, scan counts, cleanup
  state counts and held-out counts must remain unchanged.
- Mutations of the base port map, inverse, successor handedness, root or eroder
  `A2` type, complement transport, winner/default coverage, priority, genesis
  normalization, residual-projector treatment, or semantic-table digest must
  be rejected.
- The independent consumer may not import the primary implementation.
- Numerical Hom witnesses may certify reproducible coordinates, but the note
  must distinguish them from the exact character-containment proof. A claim
  of exact floating coordinates is forbidden without an exact or interval
  rank certificate.

## Decision rule

`CLEAN` requires every item above plus an independent exact-byte audit. If the
direction conjugation changes classical behavior, a branch lacks a covariant
transport partner, the signature sectors fail completeness, or the malformed
projector cannot be realized, Block 220 remains evidence-blocked and no
retained-grade theorem or TOE promotion may be proposed.
