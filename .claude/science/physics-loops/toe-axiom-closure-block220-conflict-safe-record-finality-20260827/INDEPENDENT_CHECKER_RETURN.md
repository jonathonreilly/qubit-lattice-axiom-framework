# Independent Checker Return

## First audit: not clean

The closure auditor found a reachable load-bearing hidden-state collision in
the first H/P/L/S/F simulator. Identical complete physical states had different
next actions because host `root` and `first_port` values remained live. It
also found that the sidecar froze prose transition names rather than
executable semantics, so the old held-out stack did not consume the same
rule. Those findings invalidated the proposed compiler, CP, history and
held-out claims. The 30-ray representation containment and abstract rollback
potential survived.

## Repair challenge

Before implementation, the same auditor checked the proposed R/P/H/L/S
repair. It independently verified the twisted-root representation arithmetic,
L4 inverse-dart logic and punctured-torus connectivity, then ran an ephemeral
L4/L6 model with zero identical-state/action collisions. It required R to be
physical and erodible, commit to be an atomic H/R exact-dart transition, and
both runners to consume one executable table.

The repaired table was frozen at commit `3bb6cce284` before the held-out
consumer was written or executed.

## Exact-byte audit of the first repair

The fresh auditor sealed the classical Markov surface `CLEAN` but returned
`NOT CLEAN` for the CP-instrument theorem. It independently:

- cross-compiled all 5,040 actual R/H actor-target/dart L6 cases with zero
  primary/independent resolver mismatches;
- explored every reachable mixed-failure table schedule on L4 and L6,
  finding only cleanup actions and exact original-word terminals;
- reproduced all primary and held-out counts and the 40-ray representation
  containment; and
- found no post-genesis root, first-port, history, target-write or
  cleanup/commit leakage.

The blocking defect was narrower. Raw runtime ordinals `0..3` were never
joined to the six physical carrier directions, the executable projective
phase check only inspected metadata, and `X` had been declared as a scalar
without an embedded invariant ray. The audit also required flood liveness to
name the supplied fair/nonstuttering scheduler.
