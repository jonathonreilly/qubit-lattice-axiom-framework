# Mechanical preparation limits

Same selected model family, separate author/reviewer contexts, selected model/effort preserved. Candidate formulas and reported outcomes were visible; this was not blinded or cross-family checking. Root is a coauthor, not the independent reviewer. Preparation adds no new scientific review.

Preparation uses the current workflow/delivery/conformance source bytes,
unchanged from the preceding inspected revision, and the already reviewed
source evidence. Root's latest source/evidence completion and clean base report
are inputs; preparation itself performs no Git/ref read or mutation. The future
script checks exact HEAD and clean state before any writes. It never executes
science or changes existing source evidence. Unknown input or target mappings
fail closed instead of becoming invented results.

Own/repository evidence is preserved completely for the ten named bundles,
selected root records and explicitly consulted instructions/dependencies.
Transient bytecode and desktop metadata are explicitly excluded. Raw third-
party source/extraction/media bytes are inventoried and left untouched. Counts
derive from original results and mean only their recorded units. No mathematical
repair, silent finite-gate improvement or new science occurs during publication.

SOURCE_IDENTITIES.json initially covers the prepared payload except itself.
Root must regenerate or supplement the final manifest after verification or
metadata changes. PUBLICATION_EDITS.json remains the authority for exact note
and primary reconstruction; any later canonical change needs its own explicit
source map and hash. This snapshot is not a second live campaign checkpoint.
