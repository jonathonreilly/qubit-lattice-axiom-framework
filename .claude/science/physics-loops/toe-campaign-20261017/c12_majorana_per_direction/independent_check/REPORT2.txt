each B_v that anticommutes with P contributes a factor (-i B_v).

1. Per element, the claim is CORRECT. On a clean string creator, lambda(U_R) = -1 and
   lambda(U_R W) = +1 for all 3 axis C2 and all 6 edge C2.
   - Reason: W S W^dag = (-i B_x)(-i B_Rx) S = -B_x B_Rx S.

2. The group law FAILS when every element is dressed. The note's step is wrong. It states
   (U_R W)(U_S W) = U_R U_S W^2 with W^2 = const (-1)^F. But the realization of RS is U_RS W, not U_RS W^2.
   The leftover factor is W itself. W is not proportional to 1 or to (-1)^F on the excitation space: it
   acts as i^{N_f}, which is -1 on two-fermion states relative to the vacuum.
   Numerical test: check whether V_g V_h = V_gh, up to (-1)^F, as automorphisms on test operators
   (A_e, B_v, single gamma; also even operators only):
     n = 0           (U_g)                      : fails for   0 / 576 (g,h)
     n = 1 for all g (incl. identity)           : fails for 576 / 576
     n = 1 for g != e (the note's U_R W)        : fails for 506 / 576  (also fails on even operators alone)
     n = [sgn g = -1] (W only on C4 and edge C2) : fails for   0 / 576
   So V_g = U_g W^{n(g)} is an action up to fermion parity iff n mod 2 is a homomorphism O -> Z2. Since
   W^2 is proportional to (-1)^F, only the parity of n matters.

3. The only nontrivial consistent twist is n = [sgn = -1], because H^1(O; Z2) = Z2. Under it:
   - eta_f(axis C2) = +1, unchanged (the axis C2 is even: the square of a C4);
   - eta_f(edge C2) = -1 (computed: axis [+1], edge [-1]).
   The resulting class is sgn^2 (pattern +,-), the same pattern as the Majorana-level extension A4 x| Z4.
   It is NOT w2 (-,-).
   - No W-twist can reach w2. eta(axis C2) cannot be flipped, because n(axis C2) = 2 n(C4) = 0 for any
     homomorphism n.
   - Twists by other internal symmetries are not excluded by this argument.
   Required correction to item 5:
   - "U_R W for every R" is not an O action.
   - The per-C2 statement holds only within each Z2 subgroup.
   - The consistent W-twisted O action carries sgn^2, not w2.

4. The same issue affects C8 item 6 ("P_R W gives the trivial class"). In BKSF, prod_v B_v = I exactly, so
   W^2 is a constant there. The consistency condition is again that n must be a homomorphism from the
   stabilizer to Z2.
   - D3 codes: n(C2) = 1, n(C3) = 0 is a homomorphism. All three C2 flip, so trivial on D3. OK.
   - Single-C2 codes: OK.
   - Order-4 codes (one axis C2, two edge C2): any homomorphism has n(axis) = n(e1) + n(e2). So at most
     two of the three can flip. Starting from w2 = (-,-,-), the reachable patterns are (+,+,-), (+,-,+)
     and (-,+,+), never trivial.
     -> C8 item 6 is false for the 12 order-4 codes, and it needs n restricted to a homomorphism
        everywhere ("P_R W" for every R, including C3, is not an action).
