matter U(u)) composed with the site permutation, applied by conjugating Majorana monomials.
The non-Clifford matter part is expanded exactly as a linear map on chi_6..chi_9. Pair
eigenvalue lambda = <A^dag (V A V^dag)> / <A^dag A> on the code space. Each monomial is reduced
exactly: it either anticommutes with a generator (giving 0), or lies in the signed stabilizer
group (giving +-1). A logical term would abort the run, and none occurred. Each state is also
checked to be an eigenstate, |lambda| = 1; failures were 0.

       The doublet's w2 is literally the class of the local operator c^dag (the matter qubits

(6) INTERPRETATION / PRIOR ART.

    GL(2,3)-type cover. Calling the result "the spin-1/2 class on O" needs the sector
    restriction of (4c).
  - "Spin-statistics" and "electron-like": these do not hold in the full model. Spinless
    fermions exist (the bare charge at 2K and the flux loop at 8J), and so do local bosons
    with 2pi = -1 (c^dag b at 2mu+8J). 2pi rotation equals matter parity, not exchange
    statistics.
  - Vacuum: a symmetric vacuum exists. With all Wilson loops +1 (or all -1), the stabilizer
    state is invariant under all 24 rotations (L=4, L=6). It is NOT unique on the torus
    (8-fold topological degeneracy). "Unique" holds only in the infinite or sphere sense.
