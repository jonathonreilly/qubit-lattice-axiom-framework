# Reviewable milestone plan

The planned deliverable is one draft PR containing the four proofs and
their personal evidence. The carrier/reflection proof is the central
independent-review target. Shared-boundary counts, trace powers, compact
windings, physical sector and limit order are mandatory review points.

All changed science stays in this branch-local pack. No canonical docs,
runner registry, citation-graph node, auditor-owned output, editable prompt
or governance file is changed. Registering canonical claims and fresh audit
caches is later review/integration work; raw outputs here are preserved
author evidence, not canonical caches. The later audit may disagree with
the author or identify a counterexample.

After the draft is pushed and its exact remote head is verified, preserve
an external recovery receipt, release the lock and remove this worktree.
The next campaign starts from fetched current main and refers to these
proofs only as provisional. Archives and git garbage collection are untouched.
