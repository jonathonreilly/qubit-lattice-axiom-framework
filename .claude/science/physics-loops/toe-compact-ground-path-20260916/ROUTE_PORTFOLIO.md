# Artifact roles

Four linked proof notes constitute the scientific argument. Three primary
programs challenge geometry, independent representations and constants.
The formula-fault program checks selected sensitivities; it does not add
physics. Source-reading receipts identify exactly what literature was used.
The personal review and conformance record separate author checks from
independent review, registration and later audit work.

The proofs, not a count of numerical checks or artifacts, support the
proposed theorems. No compute-driven phase inference is made.
