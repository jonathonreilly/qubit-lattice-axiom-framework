# Identity-runner and formal scope

The two primary runners share one source-integrity implementation with different
claim attribution. Each declares 152 input paths, including ten canonical parent
files and the archive/map/publication records. Each has AUDIT_TIMEOUT_SEC = 60.
They reconstruct the accepted 125-member source schema, its three authorized
wording changes, four complete bodies, byte/line pieces and complete diffs; then
they reconstruct the publication wrappers and unchanged bodies and compare
all pinned parent and review records. They are not mathematical tests.

All success output explicitly states zero mathematical predicates, zero
scientific mutations and no independent review or no-go conclusion supplied by
the tool. Per-element, site, mode, block and lattice-wide lines state source
integrity only. No Lean proof or formal analytic execution is claimed.

The preparation worker parsed sources and performed off-repository bookkeeping.
Neither the canonical identity runners nor the prepare/verify driver was run
by that worker. Root's later driver requires successful baselines before four
byte-corruption rejection controls and preserves exact expected/actual errors.
These controls are archive/publication/metadata/parent integrity controls, not
alternative scientific calculations. Previous PR9508 runtimes do not validate
the adapted programs, counts, source schema or branch.

Root-owned canonical calls must preserve raw INNER/OUTER cache API returns,
complete available merged child logs, argv, actual exit codes and timeouts.
The API combines original child stderr with stdout; returned empty stderr must
not be represented as a separately captured child stream. Selected-ledger
compatibility may report checked[] empty and then checks no scientific claim.
