# Artifact plan

First deliverable is a fully specified next-order target with an exact symbolic
residual system and independent reconstruction of a critical seed. Then produce
a scoped theorem/construction or an explicit incomplete research checkpoint.
A decisive calculation should bind its source, actual inputs and full output.

Use existing loop files for state. Science source and paired runners/caches
belong in declared docs/scripts/logs paths on isolated milestone branches.
Open review PRs only for coherent new evidence after current conformance gates.
Incomplete work and conditional hypothesis tests are not forced into a claim.
Final plain-language report must price any proposed axiom change by the exact
failed premise, surviving escape, and test that would resolve it.
