# Supplement derivation correction before freeze

The first unfrozen endpoint-table draft omitted the negative-order moving-hole commutator when its shared B was initially empty. That omission would not have been acceptable for the claimed FULL-W1 support table: (-1,0)->(0,0) and (0,0)->(+1,0) are real T_+ transitions with negative coefficients. They have been restored explicitly, and all resulting length-two chains are included in the proof.

The corrected table still has no length-three path. The new length-two chain beginning (-1,0)->(0,0) is unavailable on an initially aligned star because its original hole is adjacent to the initially empty shared B. Thus the conclusions T_+^3=0 and T_+^2 A=0 survive the correction for stated reasons; the omitted rows are not declared irrelevant. The same local sign-reversed correction is understood for T_-.

No scientific control was run and no earlier table was delivered as a frozen proof. The core21:48 packet is unchanged. This note preserves the actual author-side failure and repair rather than implying the first support enumeration was complete.
