# Preserved finite witnesses and deduction limits

These are witnesses and exact calculation boundaries within a positive conditional source theorem, not an exhaustive no-go or route count.

| Preserved object | Deduction it tests | Retained scope |
|---|---|---|
| Bare positive edge parent | Unique unary ground without occupancy selection | Vacuum is also a ground; the proved vacancy bias selects one normal mode |
| Vacuum-favoring mu sum n | Correct sign of onsite occupation selection | The actual construction uses mu sum(I-n) |
| Explicit11 block and CAR occupation basis | One-particle calculation substituted for all sectors | The complete2^M basis supplies the actual full-space proof |
| Imaginary exchange matrix element | Dropping a hopping phase or conjugation | Both same-edge quadratures retain the supplied psi |
| Closing spin edge | Open-path string cancellation reused on a cycle | Suppression/isolation or an additional calibrated term is required |
| Uniform amplitudes | Normalized and unnormalized edges assigned one price | B_j=(2/M)h_j already changes the scale |
| M=12,k=1 and larger multiples of4L_0 | Nonzero packet components for every multiple of four | Design-stage power-of-two subclass, or an actual support check |
| Two-component purification | Marginal2d error reused as complete correlated error | Exact joint error is g(d); the unconditioned reference marginal stays |
| Normalized good block | Erasing retained failure-weight reference records | The comparator uses exact rho_R |
| Arbitrary full-source perturbation | Sector norm or perturbed free-mode factorization assumed | Full norm and either continuity or actual-gap certificate |
| Separately positive Pauli channels | Uncollected coefficient sum reused as channel norm sum | Actual C_gamma identity reserve and larger load |
| Source/runtime generator mismatch | Ignoring K_C or noncommuting program drift during cooling/release | Paid compensation/isolation and actual chronological handoff |

The mixed Gibbs state at finite beta is not exact purity. A thermal source Hamiltonian does not by itself construct cooling, a bath, an autonomous waveform or reusable memory. The witnesses do not exclude other state suppliers or handoff constructions.
