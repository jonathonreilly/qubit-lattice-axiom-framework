## 1. A fixed full-domain kernel

Treat each neighbor condition as either absent or a matrix A_i. Absence is an
isolated input type; regularity is on each fixed presence pattern. Put
m(eta)=sum of the present matrices, with m(empty)=0. Define the smooth function

 h(t)=exp(-1/t) for t>0, and h(t)=0 for t<=0,
 psi(u)=h(1-u)/(h(1-u)+h(u-1/4)).

For u>=0, psi is1 on u<=1/4,0 on u>=1, and lies in[0,1]. Its denominator
is positive. Use the similarity-invariant, nonnegative tags

 r(A)=psi(|tr A-5|^2),
 s(B)=psi(|tr B-1|^2+|det B|^2).

For ordered distinct present neighbors define

 w_ij=r(A_i)s(A_j),
 x_ij=Re tr[(A_i-2I)A_j],
 S=sum_(i!=j) w_ij,
 b(S)=(S-1)^2,
 Z(S)=b(S)+S=S^2-S+1>=3/4.

For any continuous f:R->[0,1] set

 K_f(eta) = [ b(S) delta_m
       +sum_(i!=j) w_ij { f(x_ij) delta_(A_j)
                   +(1-f(x_ij)) delta_(I-A_j) } ] / Z(S).       (1)

This is a probability measure on the full M2(C) space for every input tuple;
its domain has not been restricted to density matrices or effects. The tags
are encoding conventions and part of this supplied law, not newly selected
physical constants. The fixed scalar values2,5,1 serve only to distinguish
carrier and program Records through their traces.

All weights are nonnegative and their sum is Z. Trace, determinant and real
part are invariant under simultaneous complex similarity. The output atoms
transform by that similarity; summing ordered pairs makes the law invariant
under all neighbor permutations. It is consequently covariant under lattice
translations and proper cubic rotations. It is also equivariant under entrywise
complex conjugation, since the tags and coefficients are real. No matrix
adjoint, eigenvector ordering or preferred matrix basis appears in(1).

For any bounded continuous test function, its integral under(1) is a finite
sum of continuous terms divided by Z>=3/4. Hence K_f is weakly continuous.
When f is smooth, the same statement with smooth compactly supported test
functions proves weak smoothness of every order. Each output lies in the
unital algebra generated by the neighbor matrices. This directly agrees with
the earlier regular-kernel support result without relying on it as a premise.

## 2. Exact binary projective benchmark

For the Born benchmark take f_B(x)=min(1,max(0,x)). At a target with exactly
one preparation Record A=2I+rho and one program Record B=P, where rho is a
trace-one positive density and P a rank-one orthogonal projector, the tags are

 r(A)=1, s(P)=1, r(P)=0, s(A)=0.

Thus S=1, b(S)=0, and tr(rho P) is already in[0,1]. Equation(1) reduces to

 K_B(2I+rho,P)=tr(rho P) delta_P

The same conclusion holds on every simultaneous similarity image of such a
pair; the trace probabilities and algebraic projectors are unchanged under
the corresponding identification. The usual Hilbert-space density/projector
interpretation is the supplied benchmark domain, not an imposed restriction
on the full kernel outside that domain.

Record content is the actual output matrix P or I-P. Its intrinsic readout
may be the matrix itself. The experimental branch label is recovered by

## 3. The same kernel copies and retags a realized projector

A site with just one recorded neighbor R has S=0, so(1) is delta_R: it copies
that matrix exactly. This is copying classical Record content, not a quantum
channel that clones an unknown state.

At a site whose two recorded neighbors are a rank-one projector R and the
scalar marker2I, both r(R) and r(2I) vanish. In particular |tr(2I)-5|^2=1,
where psi is exactly0. Hence S=0 and the output is deterministically

 R+2I.                                                    (3)

This uses the sum fallback, not an average. Equations(2)-(3) are different
operating contexts of one fixed kernel; no site-specific rule is switched in.

## 4. Explicit nearest-neighbor corridor and arbitrary horizons

Choose an initial preparation carrier at a_0=(-1,0,0) with content2I+rho_0.
For each j>=0 place a supplied program P_j at p_j=(3j,-1,0), and a supplied
marker2I at k_j=(3j+2,1,0). All sites used below are initially blank. In order,
form

 e_j=(3j,0,0), c_j=(3j+1,0,0), a_(j+1)=(3j+2,0,0).       (4)

At e_j the recorded nearest neighbors are precisely a_j and p_j, so(2)
produces R_j=P_j or I-P_j with the benchmark weights. At c_j only e_j is a
recorded nearest neighbor, so it copies R_j. At a_(j+1) the recorded nearest
neighbors are precisely c_j and k_j, so(3) writes2I+R_j. Other supplied
programs, markers and previous corridor sites are at graph distance at least2
from each target except for these named inputs. Later events leave every old
Record unchanged. Each site is used once.

For rank-one idempotent R, R rho R=tr(rho R) R. Therefore, on every supported
outcome, the normalized projective update is exactly the next carrier R_j.
Induction on the corridor proves, for any finite supplied program sequence,

 Pr(R_0,...,R_(L-1))
  = tr(R_0 rho_0) product_(j=1)^(L-1) tr(R_j R_(j-1))
  = tr[R_(L-1)...R_0 rho_0 R_0...R_(L-1)].               (5)

Zero-weight branches remain zero and are never conditional states. Summing a
terminal binary outcome gives the preceding cylinder by P_j+(I-P_j)=I;
thus the finite laws are prefix-consistent. With a supplied countable program
and marker array and this deterministic event order, the countable finite-
alphabet extension gives the corresponding infinite outcome-history law.
Each finite prefix uses only finitely many sites and has the displayed local
realization. No physical time or autonomous infinite formation schedule is
inferred from the index j.

## 5. Explicit alternative weights and a regularity distinction

The same construction also accepts the smooth function

 f_S(x)=h(x)/(h(x)+h(1-x)).                              (6)

Its denominator is positive on all real x. It is smooth, takes values in[0,1],
is0 for x<=0 and1 for x>=1, and satisfies f_S(1-x)=1-f_S(x). Thus K_S is a
full-domain weakly smooth probability kernel with the same matrix covariance,
locality, endpoint repeatability, copying and retagging properties. Yet on the
same encoded context with tr(rho P)=1/4 its probability is

 f_S(1/4)=1/(1+exp(8/3)),                                (7)

have not selected the Born trace dependence.

real t near0. This is a straight line in the full matrix input domain, though
