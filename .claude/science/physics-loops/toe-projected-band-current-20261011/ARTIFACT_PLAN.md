# Milestone artifacts

Two complete theorem notes form one current-response milestone. Each primary
embeds its complete frozen finite controls in separate namespaces, with a
declared timeout and note dependencies. Historical proofs, reviews, identity
receipts and actual failed source-copy controls are preserved in evidence/.
EVIDENCE_MAP.json maps original paths to exact repository bytes, including
lossless gzip containers. Historical absolute paths are provenance, not new
runtime dependencies. Only the deterministic citation topology manifest is
an audit-data change. Toolchains and primary-paper images remain external.
