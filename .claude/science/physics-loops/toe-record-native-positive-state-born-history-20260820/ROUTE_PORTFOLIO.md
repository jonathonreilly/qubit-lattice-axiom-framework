should descend from one independently specified finite action and resource
debit. If the first block can only insert the write table, it records that
supplier honestly and pivots to the action-to-write derivation rather than
calling the route closed.

## Panel Decision Rule

The selected route must have a concrete first return within one deep block:
an exact lemma, construction, counterexample, or dependency reduction. If its
terminal residual is equivalent to selecting the complete law by fiat, mark
it blocked-equivalent and pivot. Two consecutive non-terminal returns force a
new panel and a route change unless a new mechanism has appeared.
