## 1. Theorem K — the algebraic K-theory step

**Formula check.** The full Bass–Heller–Swan / Quillen fundamental theorem gives
`K_n(A[t,t^-1]) ≅ K_n(A) ⊕ K_{n-1}(A) ⊕ NK_n(A) ⊕ NK_n(A)`. For A regular Noetherian,
`NK_n(A) = 0` for all n and `K_{-1}(A) = 0` (negative K-theory of a regular ring vanishes) (recalled; Weibel,
K-book III.3–4, V.6). Regularity passes to A[t,t^-1]. Induction from A = C:
- K_0: `K_0(C[Z^d]) = K_0(C[Z^{d-1}]) ⊕ K_{-1}(C[Z^{d-1}]) = Z` for every d.
- K_1: `K_1(C[Z]) = C^* ⊕ Z`, `K_1(C[Z^2]) = C^* ⊕ Z ⊕ Z`, `K_1(C[Z^3]) = C^* ⊕ Z^2 ⊕ K_0(C[Z^2]) = C^* ⊕ Z^3`.
- The K_0 summand enters through `[P] ↦ [tP + 1 − P]`. The generator [A] goes to [t], so K_1 is generated by
  classes of units. det restricted to unit classes is the identity of R^×, so `det: K_1(R) → R^×` is an
  isomorphism, i.e. `SK_1(R) = 0`. The note's formula, including the iterated NK, K_0 and K_{-1}
  bookkeeping, is right. (Recalled cross-check: Suslin 1977 proves the stronger unstable statement
  `SL_n(k[x_1..x_m, y_1^±..y_l^±]) = E_n` for n ≥ 3 over a field.)

**Passage K_1 → factorisation.** `K_1(R) = GL(R)/E(R)` (Whitehead lemma: E(R) = [GL(R),GL(R)]). So
`[M ⊕ 1] = [diag(det M,1,..)]` means `(M ⊕ 1_{N−n})·diag(det M,1,..)^{-1} ∈ E_N(R)` for some finite N. That is
step 3 (E(R) is normal, so the order of factors does not matter). Correct.

**W3 on GL_N(C) and stabilisation.** ω = tr(g^{-1}dg)^3 is closed and bi-invariant on GL_N(C). For a smooth
homotopy H: T^3×I → GL_N, Stokes gives equal integrals. Continuous maps are handled by smoothing (GL_N is
open). Under `M ↦ M ⊕ 1`, θ ↦ θ ⊕ 0 and the trace is unchanged. So W3 is stable, and it descends to a
homomorphism on GL(R)/E(R) once it is additive (Polyakov–Wiegmann: the cross term is exact). The
elementary matrix `1 + t p e_ij` has det 1 for all t, so the homotopy stays in GL (not in U, which is
irrelevant). `diag(c z^m,1,..)` has θ = diag(i m·dk,0,..) and a scalar 1-form cubed is 0. All five steps
check. Numerical confirmation in `r3_K_structure.log`: random diag(c z^m,1,1)·E1E2E3 over C[Z^3] give
W3 = 0 on exact grids; W3[V_2 ⊕ 1_2] = W3[(V_2 ⊕ 1_2)·E] = −1; W3[V_2 V_2] = −2.

**Verdict K: correct.** The load-bearing input is a classical theorem, applied correctly.

### Independent second proof (slice / Toeplitz index bundle + Pic = 0)

This route does not use BHS or SK_1. It uses only (i) the Toeplitz families index theorem and
(ii) `Pic(C[z1^±,z2^±]) = 0`, which is elementary because the ring is a localisation of C[z1,z2] and hence a UFD.

Let M ∈ GL_n(R) and set R2 = C[z1^±,z2^±]. Multiply by z3^L so that P = z3^L M has only non-negative powers
of z3 (W3[P] = W3[M] by the scalar-phase lemma). Then det P = u·z3^d with u ∈ R2^× and d independent of
(z1,z2).
1. *Toeplitz family.* For each (k1,k2) ∈ T^2, T_P on H^2(S^1)⊗C^n is injective, because P is invertible a.e.
   on the circle. Its cokernel H^2/PH^2 equals C[z3]^n/P C[z3]^n. The map is injective because q = P h with
   h ∈ H^2 forces h = adj(P)q/(u z3^d) to be a polynomial. Both sides have dimension d, from the Smith form,
   since det P(a,·) = u(a) z3^d. So ind = −[E], where E is the cokernel bundle over T^2.
2. *E is algebraic.* The module `Q = R2[z3]^n / P R2[z3]^n` is killed by z3^d, so it is finitely generated
   over R2. By right-exactness its fibre at every point a ∈ (C^*)^2 is C[z3]^n/P(a)C[z3]^n, of constant
   dimension d. A finitely generated module of constant fibre rank over a reduced Noetherian ring is
   projective, so Q is a rank-d projective R2-module and E is its topological bundle restricted to T^2.
3. *c_1(E) = 0.* det Q = Λ^d Q is an invertible R2-module, and it is free because Pic(UFD) = 0. A free
   generator is a nowhere-vanishing continuous section of the topological line bundle det E, so
   c_1(E) = c_1(det E) = 0.
4. *Families index.* The degree-2 part of ch(ind T_P) is the fibre integral over z3 of the degree-3 part of
   the odd Chern character of P. This gives `c_1(ind) = ±W3[P]` (recalled standard result; Bott periodicity
   via Toeplitz operators). I checked the normalisation numerically on U = 1 − Q + z3 Q with Q the QWZ band
   projector. Its cokernel bundle is range Q, and |W3| = |Chern(Q)| for m = ±1, 3 (`r3_K_structure.log`).

*Finishing reviewer's tightening of step 4 (removes the "recalled" normalisation).* Both
`W3` and `c_1∘ind` (ind: K^1(T^2×S^1) → K^0(T^2) the Toeplitz/Atiyah families index, additive; c_1 additive
on virtual bundles) are homotopy-invariant homomorphisms `K^1(T^3) → Z`, and `K^1(T^3) ≅ Z^4` is torsion-free,
spanned by the three coordinate loops z_1, z_2, z_3 and one top class. Both functionals vanish on z_1, z_2
(constant in z_3: index 0) and on z_3 (cokernel = trivial line bundle, c_1 = 0). On U = 1 − Q + z_3 Q
(QWZ, m = 1) the cokernel bundle is range Q, so c_1∘ind = −Chern(Q) = +1, while W3 = −1 (`r3_K_structure.log`).
Hence `c_1∘ind = −W3` on all of K^1(T^3) in this orientation, with no appeal to a recalled index formula;
the only external inputs of the second route are then Pic(UFD) = 0, the constant-fibre-rank ⇒ projective
lemma, and additivity/homotopy invariance of the families index. I also re-checked steps 1–3 line by line:
det P = c z_1^{m_1} z_2^{m_2} z_3^d with d ≥ 0 because units of R are monomials and P is polynomial in z_3;
`adj(P)P = det P` gives z_3^d Q = 0, so Q is generated over R2 by {z_3^j e_i, j < d}; injectivity of
C[z_3]^n/P → H^2/PH^2 and equal dimension d give the isomorphism. I agree with this second proof.

Hence W3[M] = 0. This also confirms the note's §11(b) sketch, which in fact needs only Pic = 0 and not the
full Quillen–Suslin–Swan theorem. It shows, too, that a finite-range counterexample to K would be
equivalent to a strictly local (Laurent-polynomial) band projector on T^2 with nonzero Chern number. The
same algebra rules that out (the K_0 sibling the note mentions).

## 5. Scope remark (medium)

K controls W3 of the whole step. The physical gloss "a net-chirality (single Weyl node) tick needs a
unitary step of infinite range" holds for a one-qubit (two-band) walk, by Corollary N. For a multiband walk
it holds only for the total HNU invariant W3. A web search this session surfaced Sun–Xiao–Bzdušek–Zhang–Fan,
PRL 121, 196401 (2018) (arXiv:1806.09296). From the search snippet only, not the full text: the net
chirality in an *adiabatic two-band subspace* equals twice the winding of the projected ("adiabatic")
Floquet operator. Projected-subspace chirality is not W3 of the full U, so K does not obviously forbid it.
Recommended fix: say "W3 ≠ 0 (total net chirality) requires infinite range". A low-energy sector of a
larger finite-range walk with unbalanced chirality is not excluded by this note.
