# Authority Gate

## Foundation boundary

The current minimal axioms state explicitly that Admissibility is not a
dynamics axiom and does not choose a Hamiltonian or transfer operator, supply
transition probabilities or weights, define time, or provide a Record-
production process. Any directed action/transfer-to-append bridge must
therefore be separately derived and retained, explicitly approved, or remain
conditional/open.

## Reversibility firewall

Let the state graph be append-only: `R -> R^(x,f)` is allowed while the reverse
edge is absent because Records cannot be erased. For a full-support stationary
law `pi`, ordinary detailed balance on that same graph gives

```text
pi(R) q(R,R^(x,f)) = pi(R^(x,f)) q(R^(x,f),R)=0,
```

so `q(R,R^(x,f))=0`. This proves only that a nontrivial append-only generator
cannot be the literal full-support reversible dynamics on the same state
graph. It does not rule out oriented histories, absorbing dynamics, a larger
reversible state including an archive/environment, or a nonreversible
transfer. Those alternatives remain live and must be steelmanned.

## Decision protocol

1. Resolve the exact source and status of each candidate.
2. Extract a typed map only from literal equations and declared semantics.
3. Reject any hidden operation listed in `GOAL.md`.
4. If one bridge exists, freeze it before constructing a runner or cache.
5. If none exists, return `INTERFACE-UNSUPPLIED`; do not construct an empty
   numerical cone and do not call it an action no-go.
6. Pivot immediately to the microscopic selector sidecar.

## Axiom implication

Failure to find an existing bridge does not itself justify editing the
minimal axioms. It identifies a missing downstream law/interface. A future
axiom decision would need to show that the extensional law cannot be derived
or physically selected from the available quantum, locality, symmetry,
environment, and Record structure, and that adding it is both necessary and
minimal. Block20 does not make that showing.
