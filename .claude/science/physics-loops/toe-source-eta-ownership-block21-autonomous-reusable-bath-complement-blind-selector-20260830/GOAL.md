# Block21 goal: autonomous reusable-bath selector

Date: 2026-08-30

## Objective

Determine whether an explicit autonomous reusable environment can derive,
rather than insert, the control-complement-blind coupling that selects the
remaining Block19 occurrence parameter.

The imported conditional writer family is

```text
q_f(r)=c beta^n(r) 2^m_f(r),
```

where `c>0` is one state-independent rate scale and `beta>0` changes relative
Record-formation odds. The first exact target is one physical beta ray,
ideally `beta=1`, **conditional on** Block19's supplied factor-two mark
kernel. A stronger, separately labelled target would derive that factor two
as well. Neither target is complete without a nontrivial permanent-Record
append instrument whose reuse and process semantics are explicit.

This is a `6--8` hour algebraic/commutant and two-use pre-gate. Continue the
bath route only if the pre-gate produces a physically licensed mechanism that
can satisfy every positive threshold below. Otherwise pivot immediately to a
distributed orthogonal pointer plus strictly causal-past action-state
attachment.

## Frozen pointer and control alphabet

Use the same auxiliary orthogonal pointer as Block19:

```text
S={0,+x,-x,+y,-y,+z,-z},
```

with `0` blank and the six signed axes permanent Record marks. For a fixed
candidate mark `f`, the stabilizer of `f` in the proper cubic group has four
control orbits:

```text
{0}, {f}, {-f}, {g : g perpendicular to f}.
```

A diagonal one-control response is therefore recorded as

```text
F_f=u P_0 + a P_f + o P_{-f} + p sum_(g perpendicular f) P_g.
```

Block19's pair-factor grammar is the smaller slice `u=1`, `o=p=b`, with
`(a/b)^2=2` and `beta=b^2`. The desired control-complement-blind point is

```text
u=o=p=1, a=sqrt(2), beta=1.
```

The equality `u=o=p` is a target, not a premise. When `o!=p`, the response is
outside the Block19 beta family; it is not a second beta ray. Projection to
beta is legal only after `o=p`, positivity, common-phase handling, and `u>0`
are established. Setting `u=1` is only a common nonzero amplitude quotient.

## Frozen grammar classes

- `G_cov`: the joint proper-cubic-covariant six-mark microscopic response
  superfamily. Its source coordinates permit independent positive-real
  `u,o,p` directions before any physical constraint is applied. All six
  marks, all neighbor profiles, and one shared bath interaction are required.
- `G_CB-assumed`: the subclass in which `u=o=p`, dependence only on
  `I-P_f`, or an equivalent tied parameter appears in the Hamiltonian, bath
  state, spectrum, boundary data, basis choice, or parameter declaration.
  This is a useful control but cannot earn `DERIVED-CB`.
- `G_fin,k`: one fixed finite memory and fixed unitary realize the declared
  visible instrument for exactly the first `k` uses.
- `G_fin,infinity`: one fixed finite memory and fixed unitary realize the same
  declared channel/instrument for every use and every allowed adaptive
  visible history, without reset or replacement.
- `G_extensive`: a growing or infinite reservoir with explicit ownership,
  transport, boundary state, outgoing archive, and local process semantics.

The algebraic pre-gate may classify these classes without claiming that it
has exhausted every bath Hamiltonian.

## `DERIVED-CB` provenance gate

Control-complement blindness is derived only if all of the following hold:

1. `G_cov` is frozen with independent `u,o,p` source directions;
2. a physical constraint is stated without `u=o=p`, `I-P_f`, a shared tied
   coefficient, or a reparameterized equivalent;
3. every nonzero admissible survivor of that constraint satisfies `u=o=p`;
4. a provenance ledger identifies the source of every equality and rejects
   ties placed in the interaction, state, spectrum, boundary condition,
   normalization, or basis; and
5. reparameterized mutants such as `o/u=1`, `p/u=1`, or equal spectral
   functions are classified `ASSUMED-SELECTOR` or `RELOCATED`.

Merely verifying that a finished model lies in `span{I,P_f}` is not evidence
for why it lies there.

## Eligible bath semantics

An eligible finite-bath candidate must state:

1. a finite-dimensional bath space `K`, initial state `rho_B`, and one local
   time-independent unitary or Hamiltonian;
2. the proper-cubic action on pointer, controls, and bath, with an invariant
   bath state;
3. one joint Hermitian interaction and one shared bath that simultaneously
   produce all six mark channels for every frozen neighbor profile; a table
   of profile-dependent unitaries or six externally selected binary queries
   is ineligible;
4. no active reset, disposal, fresh-ancilla replacement, outcome-conditioned
   host instruction, or undeclared scheduler;
5. CP/TP, cross-mark compatibility, proper-cubic covariance, and the declared
   instrument including subnormalized conditional bath states;
6. QND treatment of neighbors plus exact target lock and no erasure or
   overwrite on every bath state reachable after every allowed prior history;
7. a two-use calculation with the same bath comparing conditional CP maps,
   not only averaged probabilities, and handling zero-probability branches;
8. an all-use theorem or explicit process-tensor/instrument factorization
   before any `reusable`, Markov, finite-history, or Harris claim; and
9. the physical origin of every dimensionless ratio and any cadence.

An extensive translating reservoir or incoming-field construction is a
separate eligible family only if its whole reservoir, translation, boundary
state, outgoing information, and local process are explicit. A stock of
independent prepared factors may be physically useful, but it must be called
an extensive reservoir rather than exact reuse of one finite bath.

## Positive thresholds

### Selector conditional on the supplied mark kernel

A conditional beta-selector result requires one construction to:

1. derive `u=o=p` from a stated physical mechanism rather than placing that
   equality in the interaction definition;
2. establish `o=p` before beta projection and use Block19's supplied
   same/nonmatch factor two without claiming to predict it;
3. leave exactly one beta ray modulo one common rate;
4. implement a nonzero blank-to-mark append channel;
5. fix every occupied Record sector and forbid erasure/overwrite;
6. pass the two-use test without reset, hidden fresh factors, or
   outcome-dependent retuning;
7. for a fixed finite bath, prove arbitrary-use repeatability; or, for an
   extensive reservoir, account explicitly for transport, resource growth,
   boundary state, and outgoing information;
8. supply a normalized finite-history law and a declared local-infinite
   process class; and
9. keep beta out of temperature, energy gap, spectral density, bath
   preparation, cadence, and boundary data.

This is meaningful conditional science but does not by itself derive the
factor-two extensional Admissibility law.

### Full physical mark-law result

The stronger result must meet every condition above and independently derive
`a^2/u^2=2` from the same eligible microscopic mechanism. Only this stronger
grade can be considered for full occurrence-law obligation retirement, and
only after dependency and audit accounting.

A coefficient census, one-use dilation, assumed binary query, or selected
thermal point does not meet this threshold.

## Exact discriminators

For the Block19 equal-`Z` profile pairs with `Z=9,10,12`, adjacent profiles
whose recorded-neighbor counts differ by one have local two-site odds

```text

```

Thus `beta=1` and `beta=2` give `1/2` and `2/3`. These are output
discriminators, never fitted inputs.
