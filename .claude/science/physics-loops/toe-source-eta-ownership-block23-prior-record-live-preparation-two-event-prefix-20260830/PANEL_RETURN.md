# Five-physicist panel and preregistration return

The Block22 post-execution panel ranked strictly prior Record-to-live
preparation and exact two-event composition first by a `5-0` vote, ahead of
mixed-front arbitration.  Two independent Block23 preregistration attacks
then required the target to use the complete Locked label `(f,b)`, generate
the second Ready word, expose the fresh-substrate cost, and state the exact
commuting-algebra QND scope.

The initially sketched selected-successor construction would have preloaded
the old front direction into the target Ready packet.  The corrected fixed
star instead begins with six identical covariant Blank blocks.  `f` selects
one block and its Ready word, and `b` selects its live state.  This is the
smallest direct Record-to-Admissibility type bridge that does not use the
disturbed first live poststate.

The consumable SWAP relay remains a control route, not the primary target.  It
would propagate live quantum information but would generally leave future
probabilities dependent on the hidden first live poststate, so the old Record
would not itself be a sufficient statistic.

A complete pass would be meaningful program progress: it would join one
permanent Record to a second normalized Record event on an explicit local
substrate.  It would still leave substrate generation, overlapping fronts,
arbitrary history, clock/rate, action/source continuity, gravity, and
retention open.

The same all-six-Blank eligibility cannot simply be applied again at the
second anchor because its backward candidate is the already-Locked first
anchor.  The panel therefore treats the reversible seven-ray kernel as a
finite transition-law characterization, not yet a stationary realized Record
process.  A predecessor-aware or conflict-arbitrating extension is the next
high-leverage seam.
