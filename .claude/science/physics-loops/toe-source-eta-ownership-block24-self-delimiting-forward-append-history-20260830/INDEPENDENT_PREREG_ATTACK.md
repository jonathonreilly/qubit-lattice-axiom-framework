# Block24 independent preregistration attack

## Primary false-green risks

1. A target-site helper accepts `f` as an oracle rather than decoding the
   physical Locked word.
2. `T(c|b)` is assigned to a branch instead of contracted from preparation,
   an explicit positive root, and pointer maps.
3. Successful branches normalize only on the Blank domain, with no global
   STOP complement.
4. The source pointer is copied in metadata but overwritten or dephased by the
   actual channel while being called QND.
5. Rotation tests permute labels but do not rotate all live/pointer factors and
   physical support centers.
6. A finite reference dimension is sampled instead of proving an `I_R`
   identity.
7. The old source appears disabled only because it is removed from an active
   list, rather than because the new Locked target is orthogonal to Blank.
8. The new tip is declared eligible without returning an exact complete Locked
   word or without a new Blank input.
9. Three-event normalization is used rhetorically as an arbitrary-history
   proof.
10. A supplied finite Blank rail is renamed as generated, replenished, free, or
    infinite physical substrate.
11. Sequential unique-tip action is renamed as a simultaneous global update;
    shared-target collisions are omitted.
12. The range-nine compound action is called a nearest-neighbor compiler.

## Required hostile controls

- arbitrary backward and lateral block contents do not change the append;
- an exact nonblank forward block produces only STOP;
- `R=8`, `-f`, host-selected, and outcome-selected target locations fail;
- rotating labels without physical supports fails covariance;
- preparing with future outcome `c` changes the intended causal factorization;
- sign reversal in `Q_b` changes the kernel;
- dropping any outcome or perturbing one effect/root coefficient breaks
  completeness or branch equality;
- coherent summation of Record-indexed branches fails the separate-map
  covariance/QND contract;
- old-source reapplication STOPs, while translated new-tip application on a
  new Blank succeeds;
- reusing the same consumed block fails because Locked is orthogonal to Blank;
- one-step prefix and a multi-step prefix mutation each fail; and
- two sources aimed at one target defeat any unarbitrated global-process
  promotion while leaving the anchored theorem intact.

## Completion criterion

A passing total is insufficient unless every target statement in `GOAL.md`
has a direct model-derived predicate and every negative/scope statement is
separated from executed altered models. Static source review must reject
count-only, label-only, and expected-table surrogates before first execution.
