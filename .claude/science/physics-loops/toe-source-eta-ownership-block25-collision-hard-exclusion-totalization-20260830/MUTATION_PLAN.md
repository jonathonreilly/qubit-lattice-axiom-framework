# Block25 mutation plan

## Executed altered models

The Stage-A source must execute and reject exactly these altered models:

1. omit one constrained current-pointer factor;
2. omit one selected-Blank pointer factor;
3. replace physical-factor derivation with a label-only overlap flag;
4. treat every nonzero product overlap as commuting;
5. scan only the exact shared-target family;
6. move one constrained factor to a fake physical coordinate; and
7. remove one proper-cubic frame from the actual frame list.

Each mutation must alter the constructor or predicate used by its designated
load-bearing check. A mutation counts as rejected only when that named check
fails; an unrelated failure is insufficient.

## Unexecuted Stage-B scope guards

Because a Stage-A noncommuting witness stops A0, the following are coverage and
claim-scope guards rather than altered physical models:

- no conflicting tip is activated;
- no coordinate/lexicographic winner is selected;
- no overlapping double writer is constructed;
- no old Record is overwritten;
- no Blank debit, STOP completion, or arbitrary-reference channel theorem is
  claimed for unconstructed Stage B;
- no runtime oracle, padding theorem, collision liveness, Blank production,
  rate, gravity, axiom, audit, obligation, or TOE result is claimed; and
- the one A0 witness is not widened to a general arbitration no-go.

Stored-answer, count-only, and mutation-name boolean toggles do not qualify as
executed model mutations.
