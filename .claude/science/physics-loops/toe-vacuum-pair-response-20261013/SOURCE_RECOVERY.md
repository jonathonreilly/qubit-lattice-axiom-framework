`EVIDENCE_MAP.json` is the complete content-addressed archive index. Each gzip object has compressed and raw byte hashes, byte counts and original aliases. Decompressing the object and writing its raw bytes at a chosen safe recovery destination recovers that named historical file; absolute aliases are identifiers, never instructions to open or overwrite their former paths. All 77 accepted assembly files are included: 72 sealed members plus five explicit self-reference exclusions. The archive retains all 24 original evidence members, the original freeze container, 32 accepted immediate archives, source corrections, read limits, and earlier actual logs. Five new exact root records and one trusted-dispatch correction capture add six aliases. Shared identical bytes are deduplicated; alias count and object count differ.

`PUBLICATION_EDITS.json` describes the new note as three exact pieces: publication prefix, unchanged entire accepted792 core, and publication suffix. Byte ranges are zero-based half-open; line ranges are one-based inclusive LF lines, with all original bytes unchanged. Hashes apply to raw UTF-8/LF bytes without normalization. `PARENT_BINDINGS.json` binds all three scientific cores to actual canonical parents and their exact byte/line positions.

All newly produced diffs use Python `difflib.unified_diff`, UTF-8 source bytes split with keepends=True, deterministic explicit fromfile/tofile labels, and exactly n=3 context lines. Every hunk is retained, including empty diffs when sources are identical. Gzip uses mtime=0. The note, both wrappers, six support records, preparation driver, identity template and combined driver have complete new diffs. Archived historical full-context diffs retain their original n=max(old line count,new line count) convention; the old context-3 correction artifact retains its original convention. Neither is rewritten or relabelled.

It performs zero mathematical predicates.
