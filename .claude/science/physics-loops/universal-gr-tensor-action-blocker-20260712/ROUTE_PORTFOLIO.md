# Route Portfolio

## First-principles reset

The working premise set for this cycle consists only of the displayed finite determinant
generator, elementary differentiation, real finite-dimensional linear maps,
and the explicitly displayed linearized Einstein symbol. Forbidden imports:
observed values, fitted selectors, a supplied `Pi_curv`, an assumed
metric-to-source map, a supplied Regge action, literature-only theorems, and
audit verdicts.

## Synthesis

All attack frames agree that the pointwise polarization-frame wording is not
the load-bearing residual. The selected route combines the source-map theorem
with the congruence/inertia theorem. This gives a self-contained exact
negative boundary while preserving every construction that adds an
independent curvature operator. It prunes the source-only and real-pullback
routes; it does not close the full localization target.
