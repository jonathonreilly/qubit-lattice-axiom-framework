## Defects, ranked by what they block

1. **The literal nonlinear LIFT-1 is false, so it cannot supply REST or W1-M.** Exact lines: ES:47-51,65. Here is a hand counterexample with no frozen data and j=0, for which Phi_0=A (ES:17). Let X=i sigma_1, Y=i sigma_2. Give the vertices of one oriented square the Lie-algebra values 0, tX, t(X+Y), tY, respectively, extend these values to a finitely supported site function omega, and put h_xy=omega_y-omega_x on every bond. Then d h=0 on **every** plaquette. Set W=1. The square's group holonomy in W e^h is

       exp(tX) exp(tY) exp(-tX) exp(-tY).

   Direct multiplication using X^2=Y^2=-1 and XY=-YX gives half its real trace as 1-2 sin^4(t). Its Wilson action is therefore 2 sin^4(t)>0 for 0<t<pi/2. All bond increments can be made arbitrarily small, and all plaquette fluxes lie below T by taking t small. But N_S(1)=0 and d_1 h=d h=0, so ES:49 asserts A(e^h)<=A(1)=0. This also pinpoints the problem with ES:65's energy expansion: a linear covariant curl does not include the nonlinear curvature of the increment. This is a written exact calculation, not a run or a recalled theorem. **Repair (unproved):** formulate an estimate for a finite gauge-corrected chart displacement, retaining its nonlinear curvature terms, or restrict to an explicitly gauge-fixed admissible class and prove the required nonlinear bounds. Replacing h by h+D_W omega as in ES:65 is only an infinitesimal gauge operation, not an exact equality of the exponentiated fields.

2. **Locked action reappears in the asserted lift-energy domination, although it does not reappear in the definition of Xi.** Exact line: ES:65, the final claim that fine energy in c is bounded by an exponentially weighted sum of |theta(W)|^2. Use PE's separated frozen abelian pairs, whose identity parents and positive fixed action are proved at PE:42-88,92-131. At a level j>=1 take W=1, keep those fine data, and use the explicit minimizing field: Phi_j(1)=M e(a)>0. A cell containing a pair has positive fine energy while the asserted weighted coarse-curvature sum is identically zero. This refutes that unqualified estimate. Clearance in ES:25-27 protects the **replacement cubes**, not this estimate for the entire lift; an exponentially small weight on a positive frozen contribution is not exact cancellation. Likewise ES:102's claim that all final cell energies outside the cubes are <=kappa T^2 is false for fine energy under frozen coarse cells: PE:169-205 makes that energy arbitrarily large. If ES:102 means level-j curvature instead, frozen cells need a separate QD bound and a stated conversion from fine to coarse energy. The slab example does **not** refute AE-R: it has no active R, and the common frozen action cancels (AC:92-107,149-178; ES:130). **Repair (unproved):** prove a localized *variation/excess* estimate with lower data held exactly fixed and a quantified tail; never bound the whole constrained lift's energy solely by the top curvature.

For the sparse steps alone, put B=sum_s E(s), q=C_*^-1+eta_0, m=m_0, and let N count their selected cells with repetition. Then kappa T^2 N<=B<=C K T^2 N by ES:71-77. Also T=a_*/L^2 (RD:145).    | Cost | Bound | In T,a_*,L and the sparse-step/affected-parent count |
   |---|---|---|
   | Frozen correction: linear term | C N_S norm(d H_F) <= C sqrt(m) q B | <= C sqrt(m) q K N T^2 = C sqrt(m) q K N a_*^2/L^4 |
   | Frozen correction: displayed quadratic term | C norm(d H_F)^2 <= C m q B | <= C m q K N T^2 = C m q K N a_*^2/L^4 |

Against the available B>=kappa N T^2, its linear cost requires C(K/kappa)(r_*/L)^(3/2)<<1. No count N_p<=C N is supplied here for a single arbitrarily large dense-cluster step (ES:88,98).
