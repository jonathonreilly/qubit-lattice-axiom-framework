**1. L175 (Section 4, before (20)): the metric is not stated.** "A double block and its one-bond margin lie within distance 2L+2 of the relevant pivot base." This holds in the l-infinity metric: the true reach is L+1. In the l1 metric the double block reaches about 3(L-1)/2+L+1 (about 5L/2) from the pivot base, so "2L+2" is false there for large L. The conclusion survives in both metrics. In l1, each lower step adds at most about (5L/2)L^{-j}, the sum is still below 3, and r_p=4L+8 still covers the total (about 5L/2+4). Repair: write "l-infinity distance" (this is HMA's cube and hull convention), or replace 2L+2 by 3L. Editorial.

**2. L218-259 and Result L297: the primitive averaging inputs are not among HMA's named imports.** The admission check (3) uses ST1 r4's AV/CURV (st1-r4 L127). This means the raw row bound with constant C_Q on a weighted value ball of radius r_av, and the real curvature recursion. piv names that recursion's domain constants v_rec and C_rec; ST1 L127 states the recursion without a domain. HMA imports AV only through descent L64 ("local branch existence and uniform finite-stencil bounds on the admitted domains"), which does not state the C_Q row bound or CURV. So PIV is proved **conditional on ST1 AV/CURV**, with these four constants fixed early. The Result says so ("retaining the primitive averaging inputs stated in Section 6"). Repair: in hma L51 and the L555 import list, name the supplier as "piv.md, from ST1 AV/CURV (C_Q, r_av, v_rec, C_rec, all IN1 rows 2-3)". This is an import list change, not a missing argument.

**3.
