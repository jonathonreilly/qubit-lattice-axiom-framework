### Step 13. First-principles pass on Decision 1 (mine; each item marked). Question: what can an interpolation read, what does every bound on it need, and is there a move left?

Setting. An interpolation is (X, R, D): a slice space X (one slice, or two replica slices) with product Haar measure; a measurable Haar-preserving family R_s, 0 <= s <= s_1, R_0 = id; R_(s_1) = D almost everywhere, where D is an involution that the seed's data read. Its readout is H(s_1)/H(0), with H(s) the trace of the thermal operator against the pullback by R_s.

(13.1) The endpoints are exhausted. ON FILE, check 1580: P_K = Pi a_(2u)/a_u^2, with Pi = Z^0(2u)/Z^0(u)^2 and a_t = Z_+(t)/Z^0(t) = (1/8) sum_z Z^z(t)/Z^0(t). The sixteen masses enter the seed only through the fourteen twist ratios Z^z(t)/Z^0(t) and the one number Pi. A centre flip as endpoint reads twist ratios. The swap as endpoint reads Pi (or P_K after projection). So the data are exhausted by these fifteen numbers (PROVED given the identity; it is a count). That no other discrete operation on slice data reads them in a different combination is ARGUED, not proved; Row A item (ii) tests it. The exchange of axes (Lemma Z3, row 1332) reads the same sixteen masses in the crossed channel; it is a size carry at fixed coupling and is ON FILE (row 1553 step 13 (b)).

(13.2) Lemma CONST (PROVED, one line; trivial). If every R_s preserves the weight as well as Haar measure, H is constant. So every family that reads a ratio different from 1 moves the weight at intermediate s. An exact symmetry cannot be the interpolation. In the 2D engine the twist is a symmetry of the interior weight and changes only boundary data; a global continuous group lets the change be spread at a cost that is a stiffness.
