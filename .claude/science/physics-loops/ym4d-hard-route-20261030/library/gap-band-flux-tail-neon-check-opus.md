## Decisive outcome: the "PROVED incompatible along beta_K" claim

What is proved (Theorem 4(1)): if (L-tail) holds along a subsequence of calibrated cutoffs (n_K, beta_K), then r_1(d_K) = Z_od/Z_ev -> 0 (Prop 1.1(1)), and by (2.14) every uniformly bounded C_1-odd untwisted two-point function at a fixed time fraction tends to 0. Both steps hold.

Hypotheses: (L-tail) along beta_K itself, which is neither proved nor refuted. The tools used ((1.3), (2.14)) hold for every positive semidefinite transfer operator with a strictly positive kernel and a commuting involution C. No property of 4D SU(2) Wilson fields enters.

So it is a conditional statement about a model class. It is true for 4D SU(2) Wilson only because it is true for the whole class. It does not decide whether (L-tail) is true or false along beta_K for 4D SU(2). The "nontrivial continuum electric-flux sector" it is incompatible with is defined in the text as the conclusion being negated (a bounded C_1-odd correlator that stays positive). The added clause "or equivalently finite continuum electric-flux energy" is not proved, because nothing on file gives a continuum limit or convergence of the twisted ratios. The reading that (L-tail) is "the wrong statement" on beta_K is a sound argued warning: a finite flux free energy on a fixed physical torus would give r_1 -> a positive constant. It is not a theorem. Theorem 4(2) refutes nothing even under its own hypothesis, since per-arc o(1) gives E N_amb = o(sqrt n), not o(log n).

The only unconditional 4D SU(2) results in the file are these: Theorem 4(3), in the regime beta(n) >> n^2/log n, far from [2,3] and from beta_K; Prop 4.1(2)-(3), plaquette positivity and the cost of one map; and Theorem 6, which holds only on atypical backgrounds.

1. The RESULT line's "PROVED incompatible with any nontrivial continuum electric-flux sector along beta_K" overstates. It is a conditional contrapositive of a model-general identity, with an unproved "finite energy" equivalence. It says nothing unconditional about 4D SU(2).
2. Theorem 2's "no rough-cut wall" is not an escape. Its premise implies r_1(2 l_j) <= C n^{-2 eps}, a flux bound at a shorter period. Row 1587's example shows the even-weight factor can be n^p.

4. Prop 4.1(4) is labelled PROVED but is order-of-magnitude.
5. Minor: the period dependence of alpha_n in Prop 1.2(3), and the v-sum bookkeeping in Theorem 5(2). Neither changes a conclusion.
