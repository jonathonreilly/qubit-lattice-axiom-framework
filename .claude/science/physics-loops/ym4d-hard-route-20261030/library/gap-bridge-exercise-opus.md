#### 2.1 The wall, plain version (skill step 1)

We want to prove that a certain model of the strong nuclear force on a grid has a "gap": distant measurements are almost independent, with a dependence that dies exponentially. This is one half of a famous open problem. The model has a strength knob. We can prove the gap only in corners of a larger family of models in which the knob is set differently in different directions: one pair of directions is stiff, the other pair barely coupled. There the model falls apart into thin flat layers, and for flat layers the gap is known. The wanted point is the even-handed model, all directions alike, with the knob in a middle range. The wall: every road from the corner to that point found so far either needs the answer at the end point, or would also "prove" a gap for a related model (electromagnetism on the grid) that has none. Getting past means a statement that carries the gap along the road, uses what is special to the corner, and fails where it must. Analogy (only an analogy): a rope bridge must be anchored on both banks; tying it to the far bank is the crossing itself.

W(beta_L, beta_M, beta_T): SU(2) lattice gauge theory on Z^2 x Z^2, points (u, x), Wilson weight exp(sum_p beta_type(p) (1/2) tr U_p), type L for (0,1) planes, T for (2,3) planes, M for mixed planes (row 1066 L41-42, from row 1053 3.2). **Remark RP-ANI (PROVED, given I12).** For every (beta_L, beta_M, beta_T) in [0, infinity)^3 the anisotropic Wilson model is reflection positive for site and link reflections orthogonal to each of the four axes. Proof. Osterwalder and Seiler's proof writes the action as A + theta(A) + sum_i c_i B_i theta(B_i)-type terms with c_i >= 0 for one fixed plaquette coupling; it is local in plaquettes and uses only that each plaquette's coefficient is non-negative and that theta maps the plaquettes of the action onto the plaquettes of the action with the same coefficient. A reflection orthogonal to axis mu maps a plaquette in plane (mu, nu) to a plaquette in plane (mu, nu), and a plaquette in a plane not containing mu to one in the same plane. So it preserves the type L, M, T. QED (given I12 as recalled). Consequence: l_par and l_perp are inverse spectral gaps of positive transfer matrices at every point of every path. Group-blind and dimension-blind.

**Lemma MON-T (PROVED on finite boxes).** Work on the face, on a finite free box Lambda_long x Lambda_perp. Let p be a transverse plaquette with adjacent boundary links 1 and 2, let (a, b) be a longitudinal nearest-neighbour bond, and let F = (1/2) tr(Phi_1(a) Phi_1(b)^(-1)), H = (1/2) tr(Phi_2(a) Phi_2(b)^(-1)). These are the two mixed plaquettes over the bond (a, b) on links 1 and 2; they are gauge-invariant local observables of W. Then Cov_t(F, H) = 0 at t = beta_T = 0, and Cov_t(F, H) = c_2 t^2 + O(t^3) with

  c_2 = (1/8) sum_{u,u'} G(u,u')^2 kappa(u,u')^2 >= 0,   kappa(u,u') = Cov_0( e_ab , e_uu' ),   e_vw = (1/2) tr(Phi(v) Phi(w)^(-1)) on one sheet,

and c_2 > 0 for every beta_M > 0 outside a discrete subset of (0, infinity).
Proof. Claim S2 (I9) gives c_2 = (1/16) sum G^2 tr(A B), A = <F ; Phi_1(u')^(-1) Phi_1(u)>_0, B = <H ; Phi_2(u) Phi_2(u')^(-1)>_0. Each sheet law is invariant under Phi to g Phi h for constant g, h in SU(2). F is invariant under Phi_1 to Phi_1 h, and Phi_1(u')^(-1) Phi_1(u) goes to h^(-1) (...) h. So A = h^(-1) A h for all h. A lies in the real span of SU(2), the quaternions; a quaternion that commutes with every unit quaternion is real. So A = kappa_1 I with kappa_1 = (1/2) tr A = Cov_0(F, e_uu') on sheet 1. In the same way (left invariance) B = kappa_2 I, kappa_2 = Cov_0(H, e_uu') on sheet 2. The two sheets have the same law, so kappa_1 = kappa_2 = kappa, and tr(A B) = 2 kappa^2. This gives the formula; every term is >= 0. The term (u, u') = (a, b) has kappa(a, b) = Var_0(e_ab) > 0, since e_ab is not almost surely constant under a law with a positive density with respect to Haar measure. G(a, b) = E_0[e_ab] (Claim S2's normalization; as in Corollary ANCH-W the matrix expectation is G times the identity) is a real-analytic function of beta_M on a finite box, equal to beta_M/4 + O(beta_M^2) near 0 (one-bond expansion of the density: E_0[e_ab] = beta_M E_Haar[e_ab^2] + O(beta_M^2) = beta_M/4 + O(beta_M^2), since E_Haar[((1/2) tr U)^2] = 1/4). So it vanishes at most on a discrete set. Off that set c_2 >= (1/8) G(a,b)^2 kappa(a,b)^2 > 0. QED

#### 3.2 The least a solution must contain

**Lemma CONT (PROVED; elementary topology).** Let P: [0, 1] to coupling space be a path, and Q(t) a statement about W(P(t)). If S = { t : Q(t) } contains 0 and is open and closed in [0, 1], then S = [0, 1]. (Connectedness of [0, 1].)

Every path argument has this form, or a discrete form with finitely many steps. Two choices of Q:
- Q_fix(t): "every limit state at P(t) clusters with rate >= m_0 and prefactor <= C_0 C_F C_H". Closedness holds when the state at the limit point is unique: a weak limit of limit states at P(t_n) is a Gibbs state at P(t), covariance bounds of local observables pass to weak limits (ARGUED; standard). Openness is the content: it says a gap with fixed constants cannot be lost by a small move, with no loss of constants. That is an a priori improvement estimate.
- Q_some(t): "clustering with some constants". Openness can come from a strict finite-box criterion (I13, as recalled: a finite-box condition at one size L is a continuous function of the couplings, so its strict form is open). Closedness is the content: constants must stay bounded along the path.

So **any carry needs an a priori estimate that prevents the gap from closing along the path** (C5 below). By I4-I6 and I11, for compact U(1) on any path from the strong-coupling region to large isotropic beta such an estimate is false. By I18 (BELIEF) the same holds in five dimensions. So the a priori estimate must read the group and the dimension.
