## 1. Exact Setup and the Canonical Real-Wilson Spin-Current Observable $\mathcal{W}_R(U)$

### 1.1 Lattices, twisted Wilson measures, and conventions

Fix dimension $d \in \{4, 5\}$ and a finite periodic rectangular torus
$$\Lambda := (\mathbb{Z}/n\mathbb{Z})^{d-1} \times (\mathbb{Z}/v\mathbb{Z}), \qquad V := |\Lambda| = n^{d-1} v,$$
with sides $n, v \ge 32$. For the calibrated trajectory in $d = 4$ (Check 1453; `library/gap-k2-tool-design-fable.md` §3.1), fix the release witnesses (odd block factor $b$, calibration level $g_0$) and a physical side $\ell \in 1024\mathbb{N}_{>0}$; at cutoff $K$, put $n = \ell b^K$, $u = n/512$, and $v \in \{u, 2u\}$ (note $n$ and $v$ are even and divisible by $2$), with calibrated bare inverse coupling $\beta_K$ satisfying
$$c_{\rm tr} \log n \le \beta_K \le B_0 \log n \qquad (K \ge K_0)$$
for positive trajectory constants $c_{\rm tr}, B_0$ independent of $K$. (In $d = 5$ we use the same $n, v, \beta_K$ for direct side-by-side comparison.)

Let $E(\Lambda)$ be the set of positively oriented edges $e = (x, x + e_\mu)$ ($x \in \Lambda$, $\mu \in \{1, \dots, d\}$, where coordinate $d$ is the time direction of period $v$) and $P(\Lambda)$ the set of positively oriented geometric plaquettes $p = (x, \{\mu, \nu\})$ with $1 \le \mu < \nu \le d$, so $|E(\Lambda)| = d V$ and $|P(\Lambda)| = \binom{d}{2} V$.

**Group conventions (unified for $G = SU(2)$, $SU(N)$, $U(1)$, $U(1)^m$):**
- For **$G = SU(2)$**: identify $g \in SU(2)$ with $w I + i \mathbf{u} \cdot \vec{\sigma}$ ($w = \chi(g) = \frac{1}{2}\operatorname{tr}(g) \in [-1, 1]$, $\mathbf{u} = \operatorname{Im}(g) \in \mathbb{R}^3$, $w^2 + |\mathbf{u}|^2 = 1$). Identify the real Lie algebra $\mathfrak{su}(2)$ of skew-Hermitian traceless $2\times 2$ matrices $X = i\mathbf{x}\cdot\vec{\sigma}$ with $\mathbb{R}^3$ via the normalized inner product
  $$\langle X, Y \rangle_{\mathfrak{g}} := \frac{1}{2}\operatorname{tr}(X^\dagger Y) = \mathbf{x} \cdot \mathbf{y}.$$
  Then the matrix commutator is $[X, Y] = XY - YX = -2i(\mathbf{x} \times \mathbf{y})\cdot\vec{\sigma}$, so $\|[X, Y]\|_{\mathfrak{g}}^2 = 4|\mathbf{x} \times \mathbf{y}|^2$. The adjoint action $\operatorname{Ad}(g) X = g X g^{-1}$ acts on $\mathbf{v} \in \mathbb{R}^3$ by the orthogonal matrix $\operatorname{Ad}(w + \mathbf{u}) \in SO(3)$:
  $$\operatorname{Ad}(w + \mathbf{u})\mathbf{v} = (w^2 - |\mathbf{u}|^2)\mathbf{v} + 2(\mathbf{u}\cdot\mathbf{v})\mathbf{u} - 2w(\mathbf{u}\times\mathbf{v}), \qquad \|I - \operatorname{Ad}(g)\|_{\rm op} = 2|\mathbf{u}| = 2\sqrt{1 - w^2}. \tag{1.1}$$
  Near $+I$, exponential coordinates $g = \exp(i\mathbf{a}\cdot\vec{\sigma}) = \cos|\mathbf{a}| + i\frac{\sin|\mathbf{a}|}{|\mathbf{a}|}\mathbf{a}\cdot\vec{\sigma}$ ($|\mathbf{a}| < \pi$) give geodesic distance $d_{S^3}(g, +I) = |\mathbf{a}| = \arccos(\chi(g))$, $1 - \chi(g) = 1 - \cos|\mathbf{a}| = \frac{1}{2}|\mathbf{a}|^2 + O(|\mathbf{a}|^4)$, $\operatorname{Im}(g) = \mathbf{a} + O(|\mathbf{a}|^3)$, and normalized Haar measure $dg = \frac{1}{2\pi^2}(\frac{\sin|\mathbf{a}|}{|\mathbf{a}|})^2 d^3\mathbf{a}$.
- For **$G = SU(N)$** ($N \ge 2$): use $\chi(g) = \frac{1}{N}\operatorname{Re}\operatorname{tr}(g)$, $\langle X, Y \rangle_{\mathfrak{g}} := \frac{1}{N}\operatorname{tr}(X^\dagger Y)$ on $\mathfrak{su}(N)$, and Lie-algebra projection $\pi_{\mathfrak{g}}(g) := \frac{1}{2}(g - g^\dagger) - \frac{1}{2N}\operatorname{tr}(g - g^\dagger)I \in \mathfrak{su}(N)$ (which equals $i\operatorname{Im}(g)\cdot\vec{\sigma}$ for $N=2$). For an orthonormal basis $\{T_a\}_{a=1}^{N^2-1}$ with $\langle T_a, T_b \rangle_{\mathfrak{g}} = \delta_{ab}$ and $[T_a, T_b] = \sum_c f^{abc} T_c$, the quadratic Casimir constant is
  $$C_G := \sum_{a, b, c} (f^{abc})^2 = 2 N^2 (N^2 - 1) \qquad (C_{SU(2)} = 24,\quad C_{SU(3)} = 96). \tag{1.2}$$
- For **$G = U(1)$** (or **$U(1)^m$**): $\mathfrak{g} = i\mathbb{R}$ (or $(i\mathbb{R})^m$), $\operatorname{Ad}(g) \equiv \operatorname{Id}_{\mathfrak{g}}$, $[X, Y] \equiv 0$, so $C_{U(1)^m} = 0$.

**Twisted Wilson probability measure:** For a temporal center twist $z \in \mathbb{Z}_2^{d-1}$ (represented in periodic link variables $U \in G^{E(\Lambda)}$ by seam signs $\sigma_p \in \{+1, -1\}$, where for each spatial direction $j \in \{1, \dots, d-1\}$ with $z_j = 1$ we set $\sigma_p = -1$ on the $n^{d-2}$ plaquettes of orientation $(j, d)$ at $x_j = 0, x_d = 0$, and $\sigma_p = +1$ on all other plaquettes), define the normalized Wilson action and probability measure
$$A(U) := \sum_{p \in P(\Lambda)} \big(1 - \sigma_p \chi(U_p)\big), \qquad d\mu_{\beta}^{z, v}(U) := \frac{1}{Z^z(v; \beta)} e^{-\beta A(U)} \prod_{e \in E(\Lambda)} dU_e, \tag{1.3}$$
where $U_{x, \mu\nu} := U_{x, \mu} U_{x + e_\mu, \nu} U_{x + e_\nu, \mu}^{-1} U_{x, \nu}^{-1}$ for $\mu \ne \nu$ (so $U_{x, \nu\mu} = U_{x, \mu\nu}^{-1}$). We write $\mu_\beta^0$ and $\mathbb{E}_\beta^0$ for the untwisted torus ($z = 0$, all $\sigma_p \equiv +1$).

**Adjoint-Higgs comparison model (in $d = 4$, $G = SU(2)$):** Couple the Wilson link field $U \in SU(2)^{E(\Lambda)}$ to a unit-length adjoint Higgs field $\phi = (\phi_x)_{x \in \Lambda} \in (S^2)^\Lambda$ with normalized Haar/area measure $\prod_x d\phi_x$ and action
$$S_{\rm AH}(U, \phi; \beta, \kappa) := \beta \sum_{p \in P(\Lambda)} \big(1 - \chi(U_p)\big) + \frac{\kappa}{2} \sum_{e=(x,y) \in E(\Lambda)} \big|\phi_x - \operatorname{Ad}(U_e)\phi_y\big|^2, \qquad d\mu_{\beta, \kappa}^0(U, \phi) \propto e^{-S_{\rm AH}} dU\, d\phi. \tag{1.4}$$

### 1.2 Definition of the canonical real-Wilson spin-current observable $\mathcal{W}_R(U)$

Given any link configuration $U \in G^{E(\Lambda)}$ and seam signs $\sigma_p \in \{\pm 1\}$:

1. **Adjoint covariant Laplacian $H_U = D_U^* D_U$** on $\ell^2(\Lambda; \mathfrak{g})$:
   $$(H_U s)(x) := \sum_{\mu=1}^d \Big(2 s(x) - \operatorname{Ad}(U_{x, \mu}) s(x + e_\mu) - \operatorname{Ad}(U_{x - e_\mu, \mu})^{-1} s(x - e_\mu)\Big), \qquad x \in \Lambda. \tag{1.5}$$
   Clearly $H_U \succeq 0$ is self-adjoint with quadratic form $\langle s, H_U s \rangle = \sum_{e=(x,y)} \|s(x) - \operatorname{Ad}(U_e) s(y)\|_{\mathfrak{g}}^2$ and $0 \preceq H_U \preceq 4d I$.

2. **Gauge-covariant lattice field strength and covariant divergence:** For each $x \in \Lambda$ and $\mu \ne \nu$, set
   $$\mathbf{F}_{\mu\nu}(x) := \pi_{\mathfrak{g}}\big(\sigma_{x, \mu\nu} U_{x, \mu\nu}\big) \in \mathfrak{g} \qquad (\mathbf{F}_{\nu\mu}(x) = -\mathbf{F}_{\mu\nu}(x)), \tag{1.6}$$
   $$(D_U^* \mathbf{F})_\mu(x) := \sum_{\nu \ne \mu} \Big(\mathbf{F}_{\mu\nu}(x) - \operatorname{Ad}(U_{x - e_\nu, \nu})^{-1} \mathbf{F}_{\mu\nu}(x - e_\nu)\Big) \in \mathfrak{g}. \tag{1.7}$$
   Notice that for $SU(2)$, $\|\mathbf{F}_{\mu\nu}(x)\|_{\mathfrak{g}} = |\operatorname{Im}(U_{x, \mu\nu})| \le 1$, so $\|(D_U^* \mathbf{F})_\mu(x)\|_{\mathfrak{g}} \le 2(d - 1)$ deterministically at every site.

3. **Scale-$R$ covariant gluon potential, paramagnetic spin current, and dimensionless amplitude $\mathcal{W}_R(U)$:** For every real scale $R \ge 1$, define on $\ell^2(\Lambda; \mathfrak{g})$:
   $$\mathcal{A}_\mu^{(R)} := e^{-R^2 H_U} (H_U + R^{-2})^{-1} (D_U^* \mathbf{F})_\mu \in \ell^2(\Lambda; \mathfrak{g}), \tag{1.8}$$
   $$\mathcal{J}_{12}^{(R)}(x) := \beta \, \big[\mathcal{A}_1^{(R)}(x),\, \mathcal{A}_2^{(R)}(x)\big]_{\mathfrak{g}} \in \mathfrak{g}, \tag{1.9}$$
   $$\Phi^{(R)} := (H_U + R^{-2})^{-1} \mathcal{J}_{12}^{(R)} \in \ell^2(\Lambda; \mathfrak{g}), \tag{1.10}$$
   $$\mathcal{W}_R(U) := \frac{1}{V} \big\|\Phi^{(R)}\big\|_{\ell^2(\Lambda; \mathfrak{g})}^2 = \frac{1}{V} \sum_{x \in \Lambda} \big\|\Phi^{(R)}(x)\big\|_{\mathfrak{g}}^2 \ge 0, \qquad \mathcal{W}_R^{\rm bd}(U) := \frac{1}{V} \sum_{x \in \Lambda} \min\!\Big(1,\, \big\|\Phi^{(R)}(x)\big\|_{\mathfrak{g}}^2\Big). \tag{1.11}$$

**Lemma 1.1 (Exact Symmetry, Center Neutrality, and Translation Invariance on All Twisted Tori — `PROVED`).**
*(1) For every compact matrix group $G$, $\mathcal{W}_R(U)$ and $\mathcal{W}_R^{\rm bd}(U)$ are strictly invariant under all site gauge transformations $U_{x, \mu} \mapsto g_x U_{x, \mu} g_{x+e_\mu}^{-1}$.*
*(2) For $G = SU(2)$ (and $SU(N)$), $\mathcal{W}_R(U)$ and $\mathcal{W}_R^{\rm bd}(U)$ are center-neutral (invariant under every $\mathbb{Z}_2^{d-1}$ center translation $C_z$).*
*(3) Under $\mu_\beta^{z, v}$ on **every** twisted torus ($z \in \mathbb{Z}_2^{d-1}$), the joint distribution of the pair $\big(\{\operatorname{Ad}(U_e)\}_{e \in E(\Lambda)},\, \{\sigma_p U_p\}_{p \in P(\Lambda)}\big)$ is exactly invariant under all lattice translations of $\Lambda$. Consequently, $\mathbb{E}_\beta^{z, v}[\|\Phi^{(R)}(x)\|_{\mathfrak{g}}^2]$ and $\mathbb{E}_\beta^{z, v}[\min(1, \|\Phi^{(R)}(x)\|_{\mathfrak{g}}^2)]$ are independent of $x \in \Lambda$, and equal $\mathbb{E}_\beta^{z, v}[\mathcal{W}_R(U)]$ and $\mathbb{E}_\beta^{z, v}[\mathcal{W}_R^{\rm bd}(U)]$ respectively.*

*Proof.*
**(1)** Under $U_{x, \mu} \mapsto g_x U_{x, \mu} g_{x+e_\mu}^{-1}$, we have $U_{x, \mu\nu} \mapsto g_x U_{x, \mu\nu} g_x^{-1}$, so $\mathbf{F}_{\mu\nu}(x) \mapsto \operatorname{Ad}(g_x)\mathbf{F}_{\mu\nu}(x)$. In (1.7), $\operatorname{Ad}(U_{x-e_\nu, \nu})^{-1}\mathbf{F}_{\mu\nu}(x - e_\nu)$ transforms by $\operatorname{Ad}(g_x)\operatorname{Ad}(U_{x-e_\nu, \nu})^{-1}\operatorname{Ad}(g_{x-e_\nu})^{-1}\operatorname{Ad}(g_{x-e_\nu}) = \operatorname{Ad}(g_x)\operatorname{Ad}(U_{x-e_\nu, \nu})^{-1}$, so $(D_U^* \mathbf{F})_\mu(x) \mapsto \operatorname{Ad}(g_x)(D_U^* \mathbf{F})_\mu(x)$. Likewise $H_{U^g} = \mathcal{G} H_U \mathcal{G}^{-1}$ where $(\mathcal{G}s)(x) = \operatorname{Ad}(g_x) s(x)$ is unitary on $\ell^2(\Lambda; \mathfrak{g})$. By functional calculus, $\mathcal{A}_\mu^{(R)}(x) \mapsto \operatorname{Ad}(g_x)\mathcal{A}_\mu^{(R)}(x)$. Since $\operatorname{Ad}(g_x)$ is a Lie-algebra automorphism and isometry, $\mathcal{J}_{12}^{(R)}(x) \mapsto \operatorname{Ad}(g_x)\mathcal{J}_{12}^{(R)}(x)$ and $\Phi^{(R)}(x) \mapsto \operatorname{Ad}(g_x)\Phi^{(R)}(x)$, preserving $\|\Phi^{(R)}(x)\|_{\mathfrak{g}}^2$ at every $x$.
**(2)** A center flip multiplies links on a coordinate slab by $-I \in Z(SU(2))$. This leaves $\operatorname{Ad}(U_e)$ unchanged and preserves every untwisted plaquette $U_p$, hence preserves $\mathcal{W}_R$ and $\mathcal{W}_R^{\rm bd}$.
**(3)** Shifting $\Lambda$ by $e_\alpha$ shifts the seam signs $\sigma_p$ by $e_\alpha$. To restore the seam of a $(j, d)$-twist from $x_j = 0$ to $x_j = 1$ (holding $x_d = 0$ fixed), multiply every link $U_{(x), d}$ with $x_j = 0, x_d = 0$ (all other coordinates arbitrary) by $-I$: this flips the sign of $U_p$ on the $(j, d)$-plaquettes at $x_j = 0, x_d = 0$ and $x_j = n-1, x_d = 0$, while every $(k, d)$-plaquette ($k \ne j$) contains either zero or two flipped $d$-links and is unchanged. Similarly, multiplying all spatial links $U_{(x), j}$ at $x_j = 0, x_d = 0$ by $-I$ shifts the seam by one step in the $x_d$-direction. Each such link-flip bijection preserves product Haar measure, preserves $\operatorname{Ad}(U_e)$ identically (since $\operatorname{Ad}(-I) = I$), and preserves every signed plaquette $\sigma_p U_p$ (hence the Wilson weight $e^{-\beta A(U)}$). Thus the translated law of $(\{\operatorname{Ad}(U_e)\}, \{\sigma_p U_p\})$ equals the original law. Since $\Phi^{(R)}$ depends on $U$ solely through $(\{\operatorname{Ad}(U_e)\}, \{\sigma_p U_p\})$ and is translation-covariant, every site has the same expectation. $\blacksquare$

To make the entire proof 100% self-contained (requiring zero unchecked external claims), we establish five compact lemmas: (2.1) pointwise Kato domination and localization of $e^{-R^2 H_U}$ and $(H_U + R^{-2})^{-1}$; (2.2) exact free-energy bounds and the chessboard single-plaquette/single-link exponential tail; (2.3) the open-box relative-entropy comparison for pure $SU(2)$ and Adjoint-Higgs $SU(2)$; (2.4) the three-line Hilbert-space projection coupling between open-box and periodic Gaussian curls (both massless and massive Proca); and (2.5) exact periodic-Gaussian spectral bounds in $d = 4$, $d = 5$, and 4D Adjoint-Higgs.

### 2.1 Pointwise Kato domination and deterministic localization

**Lemma 2.1 (`PROVED`).** *Let $H_0 = H_I$ be the scalar periodic Laplacian on $\Lambda$, and let $H_U$ be the adjoint covariant Laplacian (1.5) for any $U \in SU(2)^{E(\Lambda)}$ (or $SU(N)^{E(\Lambda)}$). Then:*
1. *(Pointwise Kato domination).* For all $t \ge 0$, $s > 0$, and $x, y \in \Lambda$,
   $$\big\|(e^{-t H_U})(x, y)\big\|_{\rm op} \le e^{-t H_0}(x, y), \qquad \big\|(H_U + s)^{-1}(x, y)\big\|_{\rm op} \le (H_0 + s)^{-1}(x, y). \tag{2.1}$$
   In particular, $\|e^{-t H_U}\|_{\ell^\infty \to \ell^\infty} \le 1$, $\|(H_U + R^{-2})^{-1}\|_{\ell^\infty \to \ell^\infty} \le R^2$, and for $SU(2)$ deterministically at every site $x \in \Lambda$ and every $R \ge 1$:
   $$\|\mathcal{A}_\mu^{(R)}(x)\|_{\mathfrak{g}} \le 2(d - 1) R^2, \qquad \|\mathcal{J}_{12}^{(R)}(x)\|_{\mathfrak{g}} \le 8(d - 1)^2 \beta R^4, \qquad \|\Phi^{(R)}(x)\|_{\mathfrak{g}} \le 8(d - 1)^2 \beta R^6. \tag{2.2}$$
2. *(Exponential spatial localization).* For every $R \ge 1$, $s \in [0, R^2]$, and $x, y \in \Lambda$ with periodic distance $r = |x - y|_\infty$, setting $\alpha := (4\sqrt{d}\, R)^{-1}$:
   $$(H_0 + R^{-2})^{-1}(x, y) \le 4 R^2 e^{-\alpha r}, \qquad e^{-s H_0}(x, y) \le 3 e^{-\alpha r}, \qquad \big(e^{-s H_0}(H_0 + R^{-2})^{-1}\big)(x, y) \le e\,(H_0 + R^{-2})^{-1}(x, y). \tag{2.3}$$
   Consequently, for $C_1 := 240\sqrt{d}$ and $L := \lceil C_1 R \log\beta \rceil$ ($\beta \ge 2$, $R \le \beta^{1/10}$), whenever $B_\alpha \subset \Lambda$ is a coordinate cube of side $h \ge 4L + 4$ and $x \in B_\alpha^{\rm in} := \{z \in B_\alpha : \operatorname{dist}_\infty(z, \Lambda \setminus B_\alpha) \ge 2L\}$, letting $H_{U, B_\alpha}$ denote the Dirichlet restriction of $H_U$ to $B_\alpha$ (zero outside $B_\alpha$) and $\Phi_{B_\alpha}^{(R)}$ the corresponding quantity defined with $H_{U, B_\alpha}$, $D_{U, B_\alpha}^*$, and $\mathbf{F}|_{B_\alpha}$, we have deterministically for every $U$:
   $$\big\|\Phi^{(R)}(x) - \Phi_{B_\alpha}^{(R)}(x)\big\|_{\mathfrak{g}} \le C_d \, \beta R^8 \, \beta^{-25}. \tag{2.4}$$

*Proof.*
**(1)** Write $H_U = 2d I - \mathcal{A}_U$, where $(\mathcal{A}_U s)(x) = \sum_{\mu=1}^d [\operatorname{Ad}(U_{x,\mu}) s(x+e_\mu) + \operatorname{Ad}(U_{x-e_\mu,\mu})^{-1} s(x-e_\mu)]$. Expanding $e^{-t H_U} = e^{-2dt}\sum_{m=0}^\infty \frac{t^m}{m!}\mathcal{A}_U^m$ as a sum over $m$-step nearest-neighbor walks $\gamma : y \to x$, each walk carries an orthogonal parallel-transport operator of norm $1$, so by the triangle inequality $\|(e^{-t H_U})(x, y)\|_{\rm op} \le e^{-2dt}\sum_{m=0}^\infty \frac{t^m}{m!} \#\{\text{walks } y \to x \text{ of length } m\} = e^{-t H_0}(x, y)$. Integrating over $t \in [0, \infty)$ against $e^{-st} dt$ gives the resolvent bound. Since $\sum_y e^{-t H_0}(x, y) = 1$ and $\sum_y (H_0 + R^{-2})^{-1}(x, y) = R^2$, Schur's test gives the $\ell^\infty$ operator norms, and combining with $\|(D_U^* \mathbf{F})_\mu\|_{\ell^\infty} \le 2(d-1)$ and $\|[X, Y]\|_{\mathfrak{g}} \le 2\|X\|_{\mathfrak{g}}\|Y\|_{\mathfrak{g}}$ (for $SU(2)$, $\|[X, Y]\|_{\mathfrak{g}} = 2|\mathbf{x}\times\mathbf{y}| \le 2|\mathbf{x}||\mathbf{y}|$) yields (2.2).
**(2)** Let $\alpha := (4\sqrt{d} R)^{-1} \le 1/4$ and fix one coordinate $\mu$ attaining $r = |x_\mu - y_\mu|_{\mathbb{Z}/n_\mu}$. For the continuous-time simple random walk $X_t$ with generator $-H_0$ starting at $0$, each jump changes $X_{t, \mu}$ by $\pm 1$ at rate $2$, so $\mathbb{E}[e^{\alpha X_{t, \mu}}] = \exp(2t(\cosh\alpha - 1)) \le \exp(2t \alpha^2)$ (using $\cosh\alpha - 1 \le \alpha^2$ for $|\alpha| \le 1$). By symmetry and Markov's inequality, $e^{-t H_0}(x, y) \le \Pr(|X_{t,\mu}| \ge r) \le 2 e^{-\alpha r + 2 t \alpha^2}$. Integrating against $e^{-R^{-2} t} dt$ over $t \ge 0$ (noting $2\alpha^2 = \frac{1}{8 d R^2} \le \frac{1}{2} R^{-2}$) gives $(H_0 + R^{-2})^{-1}(x, y) \le 2 e^{-\alpha r} \int_0^\infty e^{-\frac{1}{2} R^{-2} t} dt = 4 R^2 e^{-\alpha r}$. Evaluating directly at $t = s \in [0, R^2]$ gives $e^{-s H_0}(x, y) \le 2 e^{-\alpha r + \frac{1}{8d}} \le 3 e^{-\alpha r}$. Finally, the change of variables $u = t + s$ in $(e^{-s H_0}(H_0 + R^{-2})^{-1})(x, y) = \int_0^\infty e^{-R^{-2} t} e^{-(t + s) H_0}(x, y)\, dt = e^{s R^{-2}}\int_s^\infty e^{-R^{-2} u} e^{-u H_0}(x, y)\, du \le e\,(H_0 + R^{-2})^{-1}(x, y)$ proves the third inequality of (2.3). At $L = \lceil 240\sqrt{d} R \log\beta \rceil$ we have $\alpha L \ge 60 \log\beta$, so $\sum_{|y - x|_\infty \ge L} (H_0 + R^{-2})^{-1}(x, y) \le C_d R^2 L^d \beta^{-60} \le C'_d R^2 \beta^{-50} \le C'_d R^2 \beta^{-25}$ (for $R \le \beta^{1/10}$).

For (2.4), write $H_U = H_{U, B_\alpha} \oplus H_{U, B_\alpha^c} + \Delta_\partial$, where $\Delta_\partial$ acts only on boundary edges joining $B_\alpha$ to $B_\alpha^c$ ($\|\Delta_\partial\|_{\ell^\infty \to \ell^\infty} \le 4d$). For every $y \in B_\alpha$ with $\operatorname{dist}_\infty(y, B_\alpha^c) \ge L$, the exact resolvent identity
$$(H_U + R^{-2})^{-1} - (H_{U, B_\alpha} + R^{-2})^{-1} = -(H_{U, B_\alpha} + R^{-2})^{-1} \Delta_\partial (H_U + R^{-2})^{-1}$$
and Duhamel's identity $e^{-R^2 H_U} - e^{-R^2 H_{U, B_\alpha}} = -\int_0^{R^2} e^{-(R^2 - s) H_{U, B_\alpha}} \Delta_\partial e^{-s H_U} ds$ (noting $H_{U, B_\alpha}$ satisfies the same Kato domination by $H_{0, B_\alpha} \le H_0$ on $B_\alpha$) show that every intermediate site $z$ hit by $\Delta_\partial$ lies at distance $\ge L$ from $y$. Applying (2.3) and (2.2) gives $\|\mathcal{A}_\mu^{(R)}(y) - \mathcal{A}_{\mu, B_\alpha}^{(R)}(y)\|_{\mathfrak{g}} \le C_d R^4 \beta^{-25}$ for all $y$ at distance $\ge L$ from $B_\alpha^c$. For $x \in B_\alpha^{\rm in}$ (distance $\ge 2L$ from $B_\alpha^c$), every $y$ with $|y - x|_\infty \le L$ has distance $\ge L$ from $B_\alpha^c$; splitting the sum for $\Phi^{(R)}(x) - \Phi_{B_\alpha}^{(R)}(x)$ into $|y - x|_\infty \le L$ and $|y - x|_\infty > L$ and applying the resolvent identity once more gives (2.4). $\blacksquare$

### 2.2 Free-energy comparison, total-action bound, and chessboard exponential tail

**Lemma 2.2 (`PROVED`).** *Let $d \in \{4, 5\}$, $\Lambda = (\mathbb{Z}/n)^{d-1} \times (\mathbb{Z}/v)$ with $n, v \ge 4$, and $\beta \ge 2$ with $\frac{\log\beta}{v} \le 1$ and $\frac{\beta}{n v} \le 1$ (which hold for all late $K$ on the calibrated trajectory).*
1. *(Pure $SU(2)$, all $2^{d-1}$ twisted tori).* There exists $C_0 = C_0(d) > 0$ such that for every temporal center twist $z \in \mathbb{Z}_2^{d-1}$,
   $$\frac{Z^z(v; \beta/2)}{Z^z(v; \beta)} \le e^{C_0 V}, \qquad \mathbb{E}_\beta^{z, v}\!\left[\frac{\beta A(U)}{V}\right] \le 2 C_0. \tag{2.5}$$
   If in addition $n$ and $v$ are even and $z = 0$ (the untwisted torus), then for every plaquette $p \in P(\Lambda)$ and every $\eta > 0$,
   $$\Pr_\beta^0\!\big(1 - \chi(U_p) > \eta^2\big) \le \exp\!\Big(C_0 - \frac{1}{2}\beta \eta^2\Big). \tag{2.6}$$
2. *(4D $SU(2)$ + Adjoint Higgs, untwisted even torus, $\kappa = \kappa_0 \beta$ with $\kappa_0 > 0$ fixed).* There exists $C_{\rm AH} = C_{\rm AH}(\kappa_0) > 0$ such that
   $$\frac{Z_{\rm AH}^0(v; \beta/2, \kappa_0\beta/2)}{Z_{\rm AH}^0(v; \beta, \kappa_0\beta)} \le e^{C_{\rm AH} V}, \tag{2.7}$$
   and for every plaquette $p \in P(\Lambda)$, every link $e = (x, y) \in E(\Lambda)$, and every $\eta > 0$,
   $$\Pr_{\beta, \kappa_0\beta}^0\!\big(1 - \chi(U_p) > \eta^2\big) \le \exp\!\Big(C_{\rm AH} - \frac{1}{2}\beta \eta^2\Big), \qquad \Pr_{\beta, \kappa_0\beta}^0\!\left(\frac{1}{4}|\phi_x - \operatorname{Ad}(U_e)\phi_y|^2 > \eta^2\right) \le \exp\!\Big(C_{\rm AH} - \kappa_0 \beta \eta^2\Big). \tag{2.8}$$

*Proof.*
**(1)** This follows Chatterjee's spanning-tree comparison (also used in Row 1143 and Row 1530 (7)), included here in full for self-containment. Fix a spanning tree of $\Lambda$ and gauge-fix all $V - 1$ tree links to $I$ (exact Haar-preserving change of variables), leaving $M = (d - 1)V + 1$ chord links. Restrict each chord link to the geodesic ball $|\mathbf{a}_e| \le \beta^{-1/2}$; its Haar mass is $\frac{2}{\pi}\int_0^{\beta^{-1/2}} \sin^2 r\, dr \ge c_1 \beta^{-3/2}$ ($\beta \ge 2$). By the triangle inequality on $S^3$, every plaquette off the twist seam has $|\mathbf{a}_p| \le 4\beta^{-1/2}$, hence $1 - \chi(U_p) \le 8/\beta$, while each of the at most $(d - 1)n^{d-2}$ seam plaquettes contributes at most $2$. Thus
$$Z^z(v; \beta) \ge \exp\!\Big(-8\binom{d}{2} V - 2\beta (d-1) n^{d-2}\Big) \big(c_1 \beta^{-3/2}\big)^{(d-1)V + 1}.$$
For the upper bound on $Z^z(v; \beta/2)$, drop all spatial plaquettes and all wrapping temporal plaquettes between $x_d = v - 1$ and $x_d = 0$ (since $1 - \sigma_p \chi(U_p) \ge 0$, this only increases the integral). Fix all temporal links and integrate out the spatial links sequentially in layers $x_d = v - 1, v - 2, \dots, 1$: each spatial link in layer $x_d$ appears in exactly one remaining temporal plaquette, contributing $I(\beta/2) := \int_{SU(2)} e^{-\frac{\beta}{2}(1 - \sigma\chi(g))} dg = \int_{SU(2)} e^{-\frac{\beta}{2}(1 - \chi(g))} dg \le C_1 \beta^{-3/2}$ by Haar invariance (the sign $\sigma = \pm 1$ is absorbed by $g \mapsto \sigma g$). The $(d - 1)n^{d-1}$ spatial links at $x_d = 0$ and the $V$ temporal links integrate to $1$. Hence $Z^z(v; \beta/2) \le (C_1 \beta^{-3/2})^{(d-1)(V - n^{d-1})}$. Dividing and using $\frac{\log\beta}{v} \le 1$, $\frac{\beta}{nv} \le 1$ yields $Z^z(v; \beta/2)/Z^z(v; \beta) \le e^{C_0 V}$. Since $\mathbb{E}_\beta^{z,v}[e^{\frac{\beta}{2}A}] = Z^z(v; \beta/2)/Z^z(v; \beta)$, Jensen's inequality gives $\mathbb{E}_\beta^{z,v}[\beta A / V] \le 2 C_0$.

For (2.6) on the untwisted even torus $Z^0(v; \beta)$, fix a $(1, 2)$-plaquette $p_0 = (0, \{1, 2\})$. The Wilson measure is reflection-positive under link-bisecting reflections (hyperplanes $x_\mu = k + \frac{1}{2}$) in directions $\mu \in \{3, \dots, d\}$ and under site-plane reflections (hyperplanes $x_\mu = k$) in directions $\mu \in \{1, 2\}$ (Osterwalder–Seiler 1978; FILS). Disseminating the indicator $\mathbf{1}_{\{1 - \chi(U_{p_0}) > \eta^2\}}$ by link-bisecting reflections in directions $3, \dots, d$ and site-plane reflections in directions $1, 2$ fills all $V$ plaquettes of orientation $(1, 2)$ (noting $\chi(U_p^{-1}) = \chi(U_p)$ under reflection). By the chessboard inequality,
$$\Pr_\beta^0\big(1 - \chi(U_{p_0}) > \eta^2\big) \le \left(\Pr_\beta^0\Big(\forall x \in \Lambda,\; 1 - \chi(U_{x, 12}) > \eta^2\Big)\right)^{1/V} \le \left(e^{-\frac{1}{2}\beta \eta^2 V} \mathbb{E}_\beta^0\Big[e^{\frac{\beta}{2} A(U)}\Big]\right)^{1/V} \le e^{C_0 - \frac{1}{2}\beta \eta^2}.$$
The same holds for every plaquette orientation by axis permutation.

**(2)** For 4D $SU(2)$ + Adjoint Higgs ($d = 4$, $\kappa = \kappa_0\beta$), pass to unitary gauge $\phi_x \equiv e_3$ by rotating each site spin $\phi_x$ to $e_3$ via a Haar-preserving $SU(2)$ gauge transformation. Factor every link in Cartan–Coset coordinates $U_e = C_e A_e$ with $A_e = e^{i\theta_e \sigma_3} \in U(1)$ and $C_e = \begin{pmatrix} \sqrt{1 - |w_e|^2} & w_e \\ -\bar w_e & \sqrt{1 - |w_e|^2} \end{pmatrix}$ ($w_e \in \mathbb{D} = \{|w| < 1\}$), whose normalized Haar measure is the exact flat product $\frac{d\theta_e}{2\pi}\frac{d^2 w_e}{\pi}$ (Row 1528 Theorem 1; directly verified by the Hopf parametrization $U_e = (\sqrt{1 - |w|^2} e^{i\theta}, w e^{-i\theta})$ on $S^3 \subset \mathbb{C}^2$, where $|w|^2 = \sin^2\alpha$ has $d(\sin^2\alpha) = 2\sin\alpha\cos\alpha\,d\alpha$, matching $S^3$ Haar measure $\frac{1}{2\pi^2}\sin\alpha\cos\alpha\,d\alpha\,d\theta\,d\varphi$). In these coordinates, $\operatorname{Ad}(U_e) e_3$ has third component $1 - 2|w_e|^2$, so $\frac{1}{2}|e_3 - \operatorname{Ad}(U_e) e_3|^2 = 2|w_e|^2$ identically. Fixing a spanning tree of the residual diagonal $U(1)$ phases $\theta_e = 0$ leaves $3V + 1$ chord phases $\theta_e$ and $4V$ disk variables $w_e$.
- *Lower bound on $Z_{\rm AH}^0(v; \beta, \kappa_0\beta)$:* Restrict every $w_e$ to $|w_e| \le (\beta(1 + \kappa_0))^{-1/2}$ (area $\frac{1}{\beta(1+\kappa_0)}$) and every chord $\theta_e$ to $|\theta_e| \le \beta^{-1/2}$ (mass $\frac{1}{\pi\sqrt{\beta}}$). Then $d_{S^3}(U_e, +I) \le 2\beta^{-1/2}$, every plaquette has $1 - \chi(U_p) \le 32/\beta$, and every Higgs link has $2\kappa_0\beta |w_e|^2 \le 2$. Total phase-space factor is $\ge c_{\kappa_0}^V \beta^{-4V - \frac{1}{2}(3V + 1)} = c_{\kappa_0}^V \beta^{-\frac{11}{2}V - \frac{1}{2}}$.
- *Upper bound on $Z_{\rm AH}^0(v; \beta/2, \kappa_0\beta/2)$:* Drop all spatial plaquettes and wrapping temporal plaquettes, keeping all $4V$ link factors $e^{-\kappa_0 \beta |w_e|^2}$ and all $3(V - n^3)$ non-wrapping temporal plaquettes. Conditioning on the temporal links and integrating out spatial links from $x_4 = v - 1$ down to $x_4 = 1$ gives at most $(C_1 \beta^{-3/2})^{3(V - n^3)}$ (dropping the spatial Higgs terms only increases the integral); then integrating each temporal $w_e \in \mathbb{D}$ against $e^{-\kappa_0 \beta |w_e|^2} \frac{d^2 w_e}{\pi}$ gives at most $\frac{1}{\kappa_0 \beta}$ per temporal link, i.e. $(\kappa_0 \beta)^{-V}$. Multiplying yields $Z_{\rm AH}^0(v; \beta/2, \kappa_0\beta/2) \le C_{\kappa_0}^V \beta^{-\frac{11}{2}V + \frac{9}{2}n^3}$. Dividing establishes (2.7).
- *Chessboard for (2.8):* The gauged adjoint-Higgs weight $\exp(\kappa \phi_x \cdot \operatorname{Ad}(U_e)\phi_y)$ has strictly positive spherical-harmonic expansion coefficients (via $e^{\kappa \cos\theta} = \sum_{\ell \ge 0} (2\ell+1)\sqrt{\frac{\pi}{2\kappa}} I_{\ell + 1/2}(\kappa) P_\ell(\cos\theta)$ with $I_{\ell+1/2}(\kappa) > 0$), so $\mu_{\beta, \kappa}^0$ is reflection-positive under both link-bisecting and site-plane reflections on even tori (Osterwalder–Seiler 1978). The first bound of (2.8) follows identically to (2.6). For the second bound, note $\frac{1}{4}|\phi_x - \operatorname{Ad}(U_e)\phi_y|^2 = |w_e|^2$ sits on a single edge $e = (0, e_1)$, which lies strictly on one side of every site-plane reflection; disseminating $\mathbf{1}_{\{|w_e|^2 > \eta^2\}}$ by site-plane reflections in all four directions fills all $V$ edges of direction $1$, and using $e^{\kappa_0\beta \sum_{e \parallel e_1} |w_e|^2} \le e^{\frac{1}{2} S_{\rm AH}(U, \phi; \beta, \kappa_0\beta)}$ with (2.7) gives the second inequality of (2.8). $\blacksquare$

### 2.3 Open-box relative entropy comparison (pure $SU(2)$ and Adjoint-Higgs $SU(2)$)

Fix an integer cube side $h \ge 4$ with $h \le v/4$. Partition $\Lambda$ into disjoint coordinate cubes $B_\alpha$ of side $h$ (leaving a remainder strip of thickness $< h$ in each direction not divisible by $h$), and let $\mathcal{C}$ be the set of those $B_\alpha$ that contain no twist-seam plaquette ($N_{\rm clean} := |\mathcal{C}|$). Since there are at most $(d - 1)n^{d-2}$ seam plaquettes, the fraction of sites of $\Lambda$ outside $\bigcup_{\alpha \in \mathcal{C}} B_\alpha$ is at most $\frac{dh}{v} + \frac{d h^d}{n v}$. Let $P_{\rm clean} := \bigcup_{\alpha \in \mathcal{C}} P(B_\alpha)$ be the internal plaquettes of clean cubes.

- **Pure $SU(2)$ ($d \in \{4, 5\}$):** On each clean cube $B_\alpha$, fix its comb spanning tree $T_\alpha$ rooted at the lower corner $x_\alpha$. Since the cubes $B_\alpha$ are vertex-disjoint, $\bigcup_{\alpha \in \mathcal{C}} T_\alpha$ is a forest, so a single exact Haar-preserving gauge transformation sets $U_e = I$ on every $e \in \bigcup_\alpha T_\alpha$ simultaneously, leaving $M_h := d h^{d-1}(h - 1) - (h^d - 1) = (d - 1)h^d - d h^{d-1} + 1$ chord links inside each $B_\alpha$. Define the good event
  $$\Omega_\alpha := \Big\{\max_{p \in P(B_\alpha)} \big(1 - \chi(U_p)\big) \le \eta_h^2\Big\}, \tag{2.9}$$
  where we take:
  - *Untwisted even torus ($z = 0$):* $h := \lfloor \beta^{1/16} \rfloor$, $\eta_h := \sqrt{\frac{100\log\beta}{\beta}}$;
  - *Twisted even tori ($z \in \mathbb{Z}_2^{d-1}$):* $h := \lfloor \beta^{1/30} \rfloor$, $\eta_h := \sqrt{\frac{h^{d+1}}{\beta}}$.
  On $\Omega_\alpha$, every internal plaquette has geodesic distance $d_{S^3}(U_p, +I) = \arccos(\chi(U_p)) \le \pi \eta_h$. In comb tree gauge, every chord link $e \in E(B_\alpha) \setminus T_\alpha$ is the holonomy of a loop formed by sliding $e$ across at most $(d - 1) h$ internal plaquettes, so by the bi-invariant triangle inequality on $S^3$:
  $$d_{S^3}(U_e, +I) = |\mathbf{a}_e| \le (d - 1)\pi h \eta_h =: r_h \qquad (\forall e \in E(B_\alpha)). \tag{2.10}$$
  For all sufficiently large $\beta$, $r_h < \pi/4$, so every link in $B_\alpha$ lies uniquely in the $+I$ exponential chart $U_e = \exp(i\mathbf{a}_e\cdot\vec{\sigma})$ with $|\mathbf{a}_e| \le r_h$. Let $\tilde{\mathbf{a}}_\alpha := (\sqrt{\beta}\,\mathbf{a}_e)_{e \in E(B_\alpha) \setminus T_\alpha} \in \mathbb{R}^{3 M_h}$, and let $\gamma_\alpha$ be the open-box free Gaussian law on $\mathbb{R}^{3 M_h}$ with density $Z_{G, h}^{-1}\exp(-\frac{1}{2}\sum_{p \in P(B_\alpha)} |(d\tilde{\mathbf{a}})_p|^2)$ (which is nondegenerate because $d_{B_\alpha}$ is injective on chord 1-forms).

- **4D $SU(2)$ + Adjoint Higgs ($d = 4$, untwisted even torus, $\kappa = \kappa_0\beta$):** Pass to unitary gauge $\phi_x \equiv e_3$, then fix the comb tree $T_\alpha$ of the diagonal $U(1)$ phase $\theta_e = 0$ on every $B_\alpha$ simultaneously (exact Haar-preserving change of variables). Put $h := \lfloor \beta^{1/16} \rfloor$, $\eta_h := \sqrt{\frac{100\log\beta}{\beta}}$, $\eta_h^{\rm H} := \sqrt{\frac{50\log\beta}{\kappa_0\beta}}$, and
  $$\Omega_\alpha^{\rm AH} := \Big\{\max_{p \in P(B_\alpha)} \big(1 - \chi(U_p)\big) \le \eta_h^2 \;\text{ and }\; \max_{e \in E(B_\alpha)} |w_e| \le \eta_h^{\rm H}\Big\}. \tag{2.11}$$
  On $\Omega_\alpha^{\rm AH}$, every tree link $e \in T_\alpha$ has $\theta_e = 0$ — which in exponential coordinates $U_e = \exp(i\mathbf{a}_e\cdot\vec{\sigma})$ is **identically** $a_e^3 = 0$, with $|w_e| = \sin|\mathbf{a}_e|$ and exact 2D area element $\frac{d^2 w_e}{\pi} = \frac{1}{\pi}\frac{\sin|\mathbf{a}_e|\cos|\mathbf{a}_e|}{|\mathbf{a}_e|} d^2\mathbf{a}_e$ — so $d_{S^3}(U_e, +I) = \arcsin|w_e| \le \frac{\pi}{2}\eta_h^{\rm H}$. Every chord link's root-loop holonomy has distance $\le 3\pi h \eta_h$ from $+I$; since each tree path has length $\le 4h$, the triangle inequality gives
  $$d_{S^3}(U_e, +I) = |\mathbf{a}_e| \le 3\pi h \eta_h + 4\pi h \eta_h^{\rm H} =: r_h^{\rm AH} \qquad (\forall e \in E(B_\alpha)). \tag{2.12}$$
  Let $\tilde{\mathbf{a}}_\alpha = (\tilde{a}_\alpha^1, \tilde{a}_\alpha^2, \tilde{a}_\alpha^3)$ denote the rescaled exponential coordinates $\sqrt{\beta}\,\mathbf{a}_e$ (with $\tilde{a}_e^3 = 0$ on $T_\alpha$, and $\tilde{a}_e^1, \tilde{a}_e^2$ unconstrained on all $E(B_\alpha)$), and let $\gamma_\alpha^{\rm AH}$ be the open-box Gaussian law with quadratic action $\frac{1}{2}\sum_{p \in P(B_\alpha)} |(d\tilde{\mathbf{a}})_p|^2 + \frac{m_W^2}{2}\sum_{e \in E(B_\alpha)} ((\tilde{a}_e^1)^2 + (\tilde{a}_e^2)^2)$ where $m_W^2 := 4\kappa_0$.

In either model, define the **diluted / replaced field** $\tilde{\mathbf{A}} = (\tilde{\mathbf{A}}_\alpha)_{\alpha \in \mathcal{C}}$ by sampling $U \sim \mu$ and an independent draw $G = (G_\alpha)_{\alpha \in \mathcal{C}} \sim \gamma^{\otimes \mathcal{C}}$, and setting $\tilde{\mathbf{A}}_\alpha := \tilde{\mathbf{a}}_\alpha$ if $B_\alpha \in \Omega_\alpha$ and $\tilde{\mathbf{A}}_\alpha := G_\alpha$ if $B_\alpha \notin \Omega_\alpha$.

**Lemma 2.3 (Open-Box Relative Entropy Bound — `PROVED`).** *Let $\Lambda = (\mathbb{Z}/n)^{d-1} \times (\mathbb{Z}/v)$ have even sides $n, v$, and let $\beta$ be sufficiently large with $\frac{h \log\beta}{\varepsilon v} \le \varepsilon$ and $\frac{\beta}{n v} \le \varepsilon$ (where $\varepsilon := \beta^{-1/32}$ in (1),(3) and $\varepsilon := \beta^{-1/60}$ in (2); these hold with exponential room for all late $K$ on the calibrated trajectory).*
1. *(Pure $SU(2)$, $d \in \{4, 5\}$, untwisted even torus, $h = \lfloor \beta^{1/16} \rfloor$):*
   $$p_{\rm bad} := \Pr_\beta^0(B_\alpha \notin \Omega_\alpha) \le C_d \beta^{-49}, \qquad D_{\rm KL}\big(\mathrm{Law}(\tilde{\mathbf{A}}) \,\big\|\, \gamma^{\otimes \mathcal{C}}\big) \le C_d V \Delta_h, \quad \Delta_h := \beta^{-1/32}. \tag{2.13}$$
2. *(Pure $SU(2)$, $d \in \{4, 5\}$, all $2^{d-1}$ twisted even tori, $h = \lfloor \beta^{1/30} \rfloor$):*

### 2.4 Three-line Hilbert-space projection coupling (open-box to periodic Gaussian)

**Lemma 2.4 (`PROVED`, building on Row 1231 (1) and extending to massive Proca fields).**
*Let $\Pi_{\rm clean}$ be the coordinate projection onto $P_{\rm clean} \subset P(\Lambda)$ (setting plaquettes outside $\bigcup_{\alpha \in \mathcal{C}} P(B_\alpha)$ to $0$). Let $Z \sim \mathcal{N}(0, I)$ be standard i.i.d. normals.*
1. *(Massless Yang–Mills curl, $d \in \{4, 5\}$).* Let $P_{\rm per}$ be the orthogonal projection onto $\operatorname{im}(d_\Lambda) \subset \ell^2(P(\Lambda); \mathbb{R}^3)$, and $P_{\rm open}$ the orthogonal projection onto $\bigoplus_{\alpha \in \mathcal{C}} \operatorname{im}(d_{B_\alpha}) \subset \ell^2(P_{\rm clean}; \mathbb{R}^3) \subset \ell^2(P(\Lambda); \mathbb{R}^3)$.    $$\mathbb{E}\Big[\big\|F_{\rm per} - F_{\rm open}\big\|_{\ell^2(P(\Lambda))}^2\Big] = \big\|P_{\rm per} - P_{\rm open}\big\|_{\rm HS}^2 \le C_d \, V \left(\frac{1}{h} + \frac{h}{v}\right). \tag{2.19}$$

   $$\mathbb{E}\Big[\big\|P_{\rm per}^{\rm Pr} Z - P_{\rm open}^{\rm Pr} Z\big\|_{\mathcal{H}}^2\Big] = \big\|P_{\rm per}^{\rm Pr} - P_{\rm open}^{\rm Pr}\big\|_{\rm HS}^2 \le C_4 \, V \left(\frac{1}{h} + \frac{h}{v}\right). \tag{2.20}$$

*Proof.*
**(1)** By definition $\operatorname{im}(P_{\rm open}) \subset \operatorname{im}(\Pi_{\rm clean})$, so $P_{\rm open} \Pi_{\rm clean} = P_{\rm open}$. $$\|P_{\rm per} - P_{\rm open}\|_{\rm HS}^2 = \operatorname{Tr}(P_{\rm open}) - \operatorname{Tr}(P_{\rm per}) + 2\operatorname{Tr}\big((I - \Pi_{\rm clean}) P_{\rm per}\big).$$

**(2)** Set $\widetilde{\Pi} := \Pi_{\rm clean} \oplus I_{E(\Lambda)}$. ### 2.5 Exact periodic-Gaussian spectral evaluation in $d = 4$, $d = 5$, and 4D Adjoint-Higgs

Let $\mathcal{W}_R^{\rm free}(F_{\rm per})$ denote the observable (1.11) evaluated with the free Laplacian $H_0$, free divergence $d^*$, and periodic Gaussian curl field $F_{\rm per} = d\tilde{\mathbf{a}}$ (rescaled by $\sqrt{\beta}$ so $\beta$ cancels identically from $\mathcal{J}_{12}^{(R)}$). Let $\Lambda^* := (\frac{2\pi}{n}\mathbb{Z}/2\pi\mathbb{Z})^{d-1} \times (\frac{2\pi}{v}\mathbb{Z}/2\pi\mathbb{Z})$ be the dual torus with representatives in $[-\pi, \pi)^d$, $\tilde{k}_\mu := e^{i k_\mu} - 1$, $\hat{k}_\mu^2 := |\tilde{k}_\mu|^2 = 4\sin^2(k_\mu/2)$, and $\hat{k}^2 := \sum_{\mu=1}^d \hat{k}_\mu^2$.

**Lemma 2.5 (Exact Dimensional & Higgs Dichotomy for Periodic Gaussian Fields — `PROVED`).** *Let $R \ge 4$ and $n \ge v \ge 32 R$. Let $c(k) := \frac{e^{-2R^2 \hat{k}^2}\hat{k}^2}{(\hat{k}^2 + R^{-2})^2}$ ($c(0) = 0$) and for $k \ne 0$ let $P^\perp_k := I_d - \frac{\tilde{k}\tilde{k}^*}{\hat{k}^2}$ and $M(k) := ((P^\perp_k)_{\mu\nu})_{1 \le \mu, \nu \le 2}$ (a $2 \times 2$ Hermitian PSD matrix).*
1. *(Exact Wick identity for pure $SU(N)$, $N \ge 2$).* With $C_G = 2N^2(N^2 - 1)$ ($C_{SU(2)} = 24$, $C_{SU(3)} = 96$, $C_{U(1)^m} = 0$),
   $$\mathbb{E}_{G, \rm per}^{(d)}\big[\mathcal{W}_R^{\rm free}\big] = \frac{C_G}{V^2} \sum_{p, k \in \Lambda^*} \frac{c(k)\, c(p - k)}{(\hat{p}^2 + R^{-2})^2} \cdot \frac{1}{2}\operatorname{Tr}\!\Big(M(k)\,\operatorname{adj} M(p - k)\Big), \tag{2.21}$$
   where every summand is nonnegative ($\frac{1}{2}\operatorname{Tr}(M(k)\operatorname{adj} M(p-k)) \in [0, 1]$).
2. *(4D lower & upper bounds, $d = 4$, $G = SU(N)$).* There exist absolute positive constants $c_*, C_* > 0$ (independent of $R, n, v, N$) such that

   (Explicitly, $c_* \ge \frac{e^{-40}}{3 \cdot 10^5 (8\pi)^6 (4\pi)^2} > 0$, proved in 5 lines below.)
3. *(5D quadratic decay, $d = 5$, $G = SU(N)$).* There exists an absolute constant $C_5^* > 0$ such that
   $$\mathbb{E}_{G, \rm per}^{(5)}\big[\mathcal{W}_R^{\rm free}\big] \le \frac{C_5^* C_G}{R^2}. \tag{2.23}$$
4. *(4D $SU(2)$ + Adjoint Higgs quadratic decay, $d = 4$, $m_W^2 = 4\kappa_0 > 0$).* For the periodic Gaussian Adjoint-Higgs law (massless photon $a^3$, massive Proca $W$-bosons $a^1, a^2$ of mass $m_W$), there exists an absolute constant $C_{\rm H}^* > 0$ such that
   $$\mathbb{E}_{G, \rm per}^{\rm AH}\big[\mathcal{W}_R^{\rm free}\big] \le C_{\rm H}^* \left(\frac{1}{\kappa_0 R^2} + \frac{1}{\kappa_0^2 R^4}\right). \tag{2.24}$$

*Proof.*
**(1)** For a plane wave $e^{i k\cdot x}$, $(d^* d \tilde{\mathbf{a}})_\mu(k) = -\sum_{\nu \ne \mu} \overline{\tilde{k}_\nu}(\tilde{k}_\mu \widehat{\tilde{\mathbf{a}}}_\nu(k) - \tilde{k}_\nu \widehat{\tilde{\mathbf{a}}}_\mu(k)) = \hat{k}^2 (P^\perp_k \widehat{\tilde{\mathbf{a}}}(k))_\mu$. Thus $\widehat{\mathcal{A}}_\mu^{(R)}(k) = e^{-R^2 \hat{k}^2}\frac{\hat{k}^2}{\hat{k}^2 + R^{-2}}(P^\perp_k \widehat{\tilde{\mathbf{a}}}(k))_\mu$, with exact covariance
$$\mathbb{E}_{G, \rm per}\Big[\widehat{\mathcal{A}}_\mu^{(R), a}(k)\, \widehat{\mathcal{A}}_\nu^{(R), b}(-k')\Big] = \delta^{ab} \delta_{k, k'} V \, c(k)\, (P^\perp_k)_{\mu\nu}.$$
Write $\widehat{\mathcal{J}}_{12}^{(R)}(p) = \frac{1}{V}\sum_k [\widehat{\mathcal{A}}_1^{(R)}(k), \widehat{\mathcal{A}}_2^{(R)}(p - k)]_{\mathfrak{g}}$. By Parseval, $\mathcal{W}_R^{\rm free} = \frac{1}{V^2}\sum_p (\hat{p}^2 + R^{-2})^{-2}\|\widehat{\mathcal{J}}_{12}^{(R)}(p)\|_{\mathfrak{g}}^2$. In $\mathbb{E}[\|\widehat{\mathcal{J}}_{12}^{(R)}(p)\|_{\mathfrak{g}}^2]$, the disconnected pairing vanishes identically because $[T_a, T_a] = 0$. The direct pairing ($k' = k$) contributes $C_G c(k)c(p-k)(P^\perp_k)_{11}(P^\perp_{p-k})_{22}$. The cross pairing ($k' = p - k$) carries a minus sign from antisymmetry of the Lie bracket and uses $(P^\perp_{-k})_{12} = \overline{(P^\perp_k)_{12}} = (P^\perp_k)_{21}$ and $(P^\perp_{-(p-k)})_{21} = (P^\perp_{p-k})_{12}$, contributing $-C_G c(k)c(p-k)(P^\perp_k)_{21}(P^\perp_{p-k})_{12}$. Symmetrizing $k \leftrightarrow p - k$ yields $\frac{1}{2}(A_{11}B_{22} + A_{22}B_{11} - A_{21}B_{12} - A_{12}B_{21}) = \frac{1}{2}\operatorname{Tr}(A\,\operatorname{adj} B)$ with $A = M(k)$, $B = M(p-k)$. Since $0 \preceq A, B \preceq I_2$ are $2 \times 2$ Hermitian PSD matrices, $0 \preceq \operatorname{adj}(B) \preceq I_2$ as well, hence $0 \le \frac{1}{2}\operatorname{Tr}(A\,\operatorname{adj} B) \le \frac{1}{2}\operatorname{Tr}(I_2) = 1$, proving (2.21).

**(2) Lower bound in $d = 4$:** Restrict the nonnegative sum (2.21) to the discrete box
$$p \in \Lambda^* \cap \Big[-\frac{1}{4R}, \frac{1}{4R}\Big]^4, \qquad k \in \Lambda^* \cap \left(\Big[-\frac{1}{4R}, \frac{1}{4R}\Big]^2 \times \Big[\frac{1}{R}, \frac{2}{R}\Big]^2\right).$$

Using $\frac{4}{\pi^2}\theta^2 \le 4\sin^2(\theta/2) \le \theta^2$ on $[-\pi, \pi]$:
- $\hat{p}^2 \le \frac{1}{4R^2} \implies (\hat{p}^2 + R^{-2})^{-2} \ge \frac{16}{25} R^4$;
- $\hat{k}_1^2 + \hat{k}_2^2 \le \frac{1}{8R^2}$ and $\frac{4}{5R^2} < \frac{8}{\pi^2 R^2} \le \hat{k}_3^2 + \hat{k}_4^2 \le \frac{8}{R^2}$, so $\frac{4}{5R^2} \le \hat{k}^2 \le \frac{9}{R^2}$, giving $c(k) \ge \frac{e^{-18}}{125} R^2$ and $M(k) = I_2 - \frac{\tilde{k}_{12}\tilde{k}_{12}^*}{\hat{k}^2} \succeq (1 - \frac{5}{32})I_2 = \frac{27}{32}I_2$;

**(2) Upper bound in $d = 4$ and (3) Decay in $d = 5$:** For all $x \ge 0$ and $a = R^{-2}$, $\frac{x}{(x + a)^2} \le \frac{1}{4a} = \frac{R^2}{4}$, so $c(k) \le \frac{R^2}{4} e^{-2R^2 \hat{k}^2}$. $$g_2(F) := \frac{1}{|S_{\rm in}|}\sum_{x \in S_{\rm in}} \min\!\big(M^2, \|\Phi^{(M_1)}(F)(x)\|_{\mathfrak{g}}^2\big), \qquad g_{\rm bd}(F) := \frac{1}{|S_{\rm in}|}\sum_{x \in S_{\rm in}} \min\!\big(1, \|\Phi^{(M_1)}(F)(x)\|_{\mathfrak{g}}^2\big),$$

## 4. Main Selective Theorem for 4D $SU(2)$ Wilson Lattice Gauge Theory (Theorem 1)

Before stating Theorem 1, we record the self-contained non-abelian spectral gap bound for $H_U$ on **all sixteen** twisted 4D tori, valid simultaneously for every fixed $\beta \in [2, 3]$ uniformly in $n$ and along the calibrated trajectory $\beta_K \asymp \log n$. **Proposition 4.1 (Self-Contained Non-Abelian Spectral Gap on All 16 Twisted Tori — `PROVED`).**

$$\lambda_{\min}(H_U) \ge \gamma(n, \beta) := \frac{c_k}{(1 + \beta)^2 + \sqrt{\log(2 + n)}}. \tag{4.1}$$

*Proof.*
1. *(Exact non-abelian 3D commutator lower bound).* Let $g_1 = w_1 + i\mathbf{u}_1\cdot\vec{\sigma}$ and $g_2 = w_2 + i\mathbf{u}_2\cdot\vec{\sigma}$ be any two elements of $SU(2)$.    $$|(I - \operatorname{Ad}(g_1))\mathbf{v}|^2 + |(I - \operatorname{Ad}(g_2))\mathbf{v}|^2 = 4\big(|\mathbf{u}_1 \times \mathbf{v}|^2 + |\mathbf{u}_2 \times \mathbf{v}|^2\big) \ge 2 |\mathbf{u}_1 \times \mathbf{u}_2|^2 \, |\mathbf{v}|^2. \tag{4.2}$$

Conditioned on all links outside $\mathcal{E}_{\rm ind}$, all links in $\mathcal{E}_{\rm ind}$ are mutually independent!
