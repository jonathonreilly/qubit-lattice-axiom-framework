## S2. The literal centre-even pin path is invalid (Step 4.2 line 130, Step 8.2 line 382, Step 8.3 line 391; reused from row 902) — HOLDS

- Let `G_z` (`z` in `Z_2^3`) multiply the spatial links in direction `i` that cross one fixed plane `x_i = const` by `z_i`. The pure-gauge centre-even projection is `P_ev = (1/8) sum_z G_z`. Inserting `G_z` in the trace gives the temporal twists of C8-beta, so this is the object of rows 895/898.
- `G_z` commutes with `R(g)` (the centre is central), hence with `Q_h`. It commutes with `C_beta`: `x(z U V^{-1} z^{-1}) = x(U V^{-1})`. It commutes with the spatial-plaquette factor of `M_h`: each spatial plaquette contains an even number of crossing links (a plaquette in the `(i,j)` plane crosses the plane `x_i = const` on 0 or 2 links). The centre-even subspace is not invariant. `Tr(P_ev T_h^t)` is not a sum `sum_j e^{-t E_j}` over an invariant sector. (R) and the energy reading of THERM-DI do not apply to it. Keeping `V = 1` removes a supremum; it does not restore the symmetry. This matches row 902 (`gap-next3-check-astra.md:249-253`).
- Checker remark (beyond the note; PROVED at fixed box, all-time domain only). The projected trace is still a positive mixture, `Tr(P_ev T_h^t) = sum_k w_k lambda_k^t`, `w_k = <phi_k, P_ev phi_k>` in `[0,1]`. Its vacuum weight is `w_0(h) = (1/8) sum_z <Omega_h, G_z Omega_h>`. At `h = 0`, `G_z` commutes with `T_0`, and the strictly positive simple top vector gives `G_z Omega_0 = Omega_0`, so `w_0(0) = 1`. Normalised by the full `lambda_0(h)`, `X_ev(h,t) -> log w_0(h)` as `t -> infinity`, while `-t d_t X_ev -> 0`. If `w_0(h_0) < 1` (ARGUED for large `h_0`: the pinned vacuum concentrates near `U = 1` and `G_z Omega` near the flipped configuration), then `int d_s log w_0 = -log w_0(h_0) > 0` along `s = h_0 - h`. So the literal path is not only unjustified; its all-time form is false whenever `w_0(h_0) < 1`. The restricted domain `t <= b/24` is not decided by this remark.

Its strong-pin regime freezes only temporal links and leaves the spatial links coupled at order `beta`, so no seed is supplied there. This is not a live repair from the supplied sources.
