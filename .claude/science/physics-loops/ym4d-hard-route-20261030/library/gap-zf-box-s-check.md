**(FD') (rebuild).** Let A be trace class and r > 0. Let nu_1, ..., nu_J be the eigenvalues of A with |nu| > r (finitely many by (FD4)), n_j their algebraic multiplicities. Then
  G(w) = sum_j n_j nu_j w/(1 - nu_j w) + G_r(w), with G_r analytic in |w| < 1/r.
So G continues to a meromorphic function on the plane; its poles are the points 1/nu (nu a nonzero eigenvalue), all simple, with residue -n_nu/nu at 1/nu, that is -w_0 n_nu at w_0 = 1/nu.
Proof. Let P be the Riesz projection of A for {nu_1, ..., nu_J}. P has finite rank sum_j n_j, commutes with A, and P(1 - P) = 0, so A^m = (AP)^m + (A(1 - P))^m. (AP)^m has range in V = ran P and equals A^m on V; on V, A has the eigenvalues nu_j with algebraic multiplicities n_j (Jordan form), so Tr (AP)^m = sum_j n_j nu_j^m. The spectrum of A(1 - P) is {0} together with the spectrum of A on ran(1 - P), which is spec(A) minus {nu_j}, inside |z| <= r. By the spectral radius formula, ||(A(1 - P))^{m-1}|| <= C_eps (r + eps)^{m-1}, so |Tr (A(1 - P))^m| <= ||A(1 - P)||_1 C_eps (r + eps)^{m-1}, and G_r(w) = sum_m w^m Tr (A(1 - P))^m is analytic in |w| < 1/(r + eps) for every eps > 0. Summing the geometric series gives the first term. Near w_0 = 1/nu_j, n_j nu_j w/(1 - nu_j w) = -n_j w/(w - w_0), with residue -n_j w_0. QED. (Credit: this is the classical Riesz-Schauder argument; it gives (FD3) with the meromorphic continuation, which is all of (FD1)-(FD3) that Lemma G reads.)

**(FD5) (rebuild).** Let T be compact, k_0 >= 1, nu != 0, Lambda_nu = {lambda in spec T: lambda^{k_0} = nu} (finite, by (FD4)), Q the Riesz projection of T for Lambda_nu. Q commutes with T, so with A = T^{k_0}. On ran Q (finite-dimensional), T has only the eigenvalues in Lambda_nu, so (A - nu)^N = 0 there for N = dim ran Q. On ran(1 - Q), spec(T) misses Lambda_nu, so by the polynomial spectral mapping theorem spec(A|ran(1 - Q)) = {lambda^{k_0}: lambda in spec(T|ran(1 - Q))} misses nu, and A - nu is invertible there. Hence ker (A - nu)^N = ran Q for N large, and mult_A(nu) = dim ran Q = sum_{lambda in Lambda_nu} mult_T(lambda). QED.
