Here is an explicit threshold, also used for the later tests.
For $`K,a>0`$ and $`p\ge0`$, define

```math
T(K,p;a)=\max\{1,16p^2,4\log^+(K/a)\},\qquad
\Gamma(K,p;a)=\exp[-T(K,p;a)/2],
\qquad \log^+z=\max\{0,\log z\}.
```

If $`0<g\le\Gamma(K,p;a)`$, then $`Kg(\log g^{-2})^p\le a`$.
Indeed, for $`t\ge1`$, $`\log t\le\sqrt t`$.
The minimum of $`\sqrt t-\log t`$ is $`2-\log4>0`$.
For $`t\ge16p^2`$ this gives $`p\log t\le t/4`$.
Hence $`Ke^{-t/2}t^p\le Ke^{-t/4}\le a`$ at the displayed threshold.
This is a hand inequality, not a numerical certificate.

Consequently the running R12 test holds on every level when

```math
g_m\le\Gamma(K_{12},q_0+s;a_\flat^Y).
```

$`\Gamma(12\mathfrak M C_0,q_0;a_\flat^Y)`$.
