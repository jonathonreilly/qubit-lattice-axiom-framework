## 2. A fixed inner reference and the required margin

Here is an explicit **proposed definition**, not an identification with the actual operation. Put $s=k_\flat+n_{\rm c}$. Choose a box $W$ containing $Z^\natural$ and its fixed localisation collar, inside the level-$s$ shell. Cap the prepared sequence at $s$: keep its members through $s$ and set later members empty. Localise this sequence to $W$, with the same fixed collar-tower rule as (SEP-L). On each retained core row use the stored datum $\zeta(c)$. On each retained shell row use $\exp(ig_kB(c))$. On every added boundary or tower row use $\mathbf1$. Inherited core rows take precedence over shell rows; added rows are disjoint from inherited rows.

Call this datum $\bar{\mathbf V}(\xi)$ and its real critical background $\bar P(\xi)$. Its definition requires admissibility, including every mixed core/collar test. This is a separate premise. All collar lifts are vacuum lifts, since $\mathcal M(\mathbf1)=\mathbf1$. Thus the definition has no exterior-pair argument. It retains the stored core rather than replacing that core by a regular field. Define the candidate inner Wilson read to be $A(w\psi,\bar P(\xi))$.

An interior margin must apply to the **full** inner domain. Fix a chart for an inner read $y$. Choose seminorms $\|\cdot\|_a$ on its coordinate increments and positive margins $m_{y,a}$. They must control potential, first derivative, current, every tower condition, and the assigned layer radii. The precise premise is
\[
 \bar p_y+\{h:\|h\|_{*,y}<1\}\subset D_y,\qquad
 \|h\|_{*,y}:=\sup_a\frac{\|h\|_a}{m_{y,a}},
 \quad \bar p_y=\bar p_y(\xi).
 \tag{M}
\]
The addition denotes genuine pair coordinates, not raw matrix addition. Tower fields are functions of these coordinates, not independent coordinates. The inclusion in (M) requires every nonlinear tower clause throughout the ball; a bound on its differential alone does not suffice. For an actual substituted read write $p_y=\bar p_y+h_y$ in this chart.

**Elementary consequence.** If $\|h_y\|_{*,y}\le a<1$ and a holomorphic remainder satisfies $|f_y|\le bN_y$ on the ball in (M), then
\[
 |f_y(p_y)-f_y(\bar p_y)|\le bN_y\,\frac{a}{1-a}.
 \tag{1}
\]
Indeed $z\mapsto f_y(\bar p_y+zh_y)$ is bounded by $bN_y$ for $|z|<1/a$. Cauchy's formula bounds its $n$th coefficient by $bN_ya^n$. Sum from $n=1$. For $a\le1/4$, summing (1) costs at most $b\sum_yN_y/3$.

This proves the analytic implication. It does not prove (M), the actual displacement bound, or a bound for the unexpanded Wilson action. Proposition I' compares $p$ with its own real splitting. It does not compare $P_{p_{\rm r}}$ with this fixed $\bar P(\xi)$.

## 3. The full gauge substitution

Write $S^\circ=(S^{\rm L})^u$, with $V^u(c)=u(c_-)V(c)u(c_+)^{-1}$. The exact pullback is
\[
 u_-^{-1}\big(e^{igB^\circ(c)}u_-W(c)u_+^{-1}\big)u_+
   =e^{igB^{\rm L}(c)}W(c),\qquad
 B^{\rm L}(c)=\operatorname{Ad}(u_-^{-1})B^\circ(c),
 \quad \zeta^{\rm L}=\zeta^{u^{-1}}.
 \tag{2}
\]
Thus the shell fluctuations and the stored core must both move. At real pairs, each adjoint matrix is orthogonal with determinant one. The determinant is positive by continuity from the identity in $\mathrm{SU}(2)$. Consequently (2) preserves Lebesgue measure, bond norms and the zero fluctuation-tree constraints. Left and right Haar invariance preserve the core measure. These statements concern a gauge fixed independently of the integration coordinates.

**The remaining matching is substantive.** SA 17598 tests a background made from $(\mathbf1,\zeta)$, with the vacuum on the shell side. Pulling back this complete datum gives
\[
 ((\mathbf1)^{u^{-1}},\,\zeta^{u^{-1}}),\qquad
 (\mathbf1)^{u^{-1}}(c)=u_-^{-1}u_+.
 \tag{3}
\]
It does not give $(\mathbf1,\zeta^{u^{-1}})$. For an explicit algebraic failure, start with all bonds equal to one. Take a plaquette crossing the interface. At one interface vertex set $u=e^{itT}$, $T=\operatorname{diag}(1,-1)$; set the other three gauges to one. One incident edge belongs to each side. Transforming both sides leaves its holonomy one. Transforming the core side while resetting the other side to vacuum leaves holonomy $e^{\pm itT}$. Hence the reset datum is not gauge equivalent to the original datum, for $0<|t|<\pi$.

This closes the algebraic check of (2), but refutes automatic covariance of the vacuum-joined datum. It is not an admitted-pair counterexample to (Inn). One must transport the last-shell test, the stored constraints and their reference fields as well. That transported test then contains $u(p)$. Neither (2) nor its unit Jacobian proves a fixed integration support. At complex pairs the transformed real contour is also not automatically the original contour.

There is a second issue even after this matching. Relative to each $p_{\rm r}$, (2) gives the Landau shell increment its factor $\xi_j$. At $\beta=0$, however, $u=\mathbf1$ and its base is still $S_{p_{\rm r}}$. Changing the real exterior changes this base. Therefore this relative substitution cannot by itself identify the actual read with Section 2's fixed reference.

## 4. A real seam calculation; the missing history

The following calculation isolates a possible obstruction. It does **not** certify the operation's support.

Take odd $L$, $T=\operatorname{diag}(1,-1)$, and, in level-$k$ units, the commuting field
\[
 S_t(x,x+\eta e_1)=e^{-it\eta x_2T},\qquad S_t(x,x+\eta e_\mu)=1\quad(\mu\ne1).
 \tag{4}
\]
Work in a box with the usual axial order $1,2,3,4$, rooted at $x_2=0$. Its $12$ plaquettes have constant angle of magnitude $t\eta^2$. Other plaquettes are one. Opposite staples cancel in the current, so the field is critical. Off-diagonal Lie variations have zero trace against $T$. Prescribing its exterior averages therefore gives this reference orbit, conditionally on P81 and Theorem 2.4.

In the commuting subgroup the centered average is linear in the angles on the small branch. Internal contour contributions cancel between translated segments; the remaining offsets have centered mean zero. Thus at spacing $h=L^{j-k}$ its un-gauged averages are $e^{-ithx_2T}$ in direction 1 and one otherwise.

On the plane $x_2=1$, every ancestor block center has second coordinate 1. The successive comb transports therefore telescope. At a level-$j$ site with level-$k$ ancestor $y$, the gauge to the representative outside the nodes is
\[
 u_j(x)=e^{-it(x_1-y_1)T}.
\]
For a direction-1 bond crossing the face $x_1=1/2$, its two ancestors have first coordinates 0 and 1. Consequently
\[
 u_j(c_-)\,e^{-ithT}\,u_j(c_+)^{-1}=e^{-itT}.
 \tag{5}
\]
This equality holds at every $j$. The gauge is independent of $x_3$, so direction-3 bonds on this plane remain one. This is an explicit reference-row calculation, not an inference from an upper curvature bound.

Now put a core face normal to direction 3 across this row, with both parallel direction-1 rows crossing $x_1=1/2$. Give the core-side row datum one, and give the shell-side row (5). Set the two connecting rows to one. Such a placement does not require the core face to coincide with a level-$k$ face. The resulting $13$ determining plaquette is exactly $e^{-itT}$. All four rows are at level $j=k_\flat$.

For these supplied determining data, every compatible real fine field has a quantitative cost. Suppose $w\psi\ge0$, the ancestor plaquettes of this loop lie in $\{\psi=1\}$, and $w\ge x_k/2$ there. Equation (6.5) of *sa-2.13-2.md* gives, for sufficiently small $|t|$,
\[
 A(w\psi,P_t)\ \ge\ \frac{x_k}{2}\,\frac{\|e^{-itT}-1\|^2}{8}
 \ \ge\ \frac{x_kt^2}{64}.
 \tag{6}
\]
The last inequality uses $2|\sin(t/2)|\ge |t|/2$ for $|t|\le1$. The first uses the small-$t$ branch of the minimum in (6.5). With all remaining data flat, $P_0=1$. For any scalar read $W^\circ(\xi)$ independent of this exterior pair, the triangle inequality yields
\[
 \max_{\nu\in\{0,t\}}|A(w\psi,P_\nu)-W^\circ(\xi)|
 \ge x_kt^2/128.
 \tag{7}
\]
Thus chart admission alone cannot imply the required inner comparison. For example, $t=cg_k\ell^a$ makes this cost proportional to $\ell^{2a}$. A formal single-box record with $k_\flat=1$ has at most $C(1+\ell)^{4r+1}$ stored sites by the shell counts, including its level-zero core. If $2a>4r+1$, (7) exceeds every fixed constant per site.

**First unproved step:** making these data a point of one nonempty, passing history, with its old creation, all surviving stage tests and all stored deltas. An all-flat core does not supply that history. Inserting a distant old defect requires a new action comparison and a check of those tests; continuity alone gives no uniform margin. The same history must work at both real exterior reads. Moreover, a failure of the displayed Wilson subcomparison must be matched to the complete (Inn) exponent before claiming that no cancellation is possible. I have established neither assertion. Equations (6)–(7) are a conditional obstruction, not the requested real-pair counterexample.
