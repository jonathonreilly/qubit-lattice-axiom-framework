## 2. A fixed inner reference and the required margin

Here is an explicit **proposed definition**, not an identification with the actual operation. Put $s=k_\flat+n_{\rm c}$. Choose a box $W$ containing $Z^\natural$ and its fixed localisation collar, inside the level-$s$ shell. Cap the prepared sequence at $s$: keep its members through $s$ and set later members empty. Localise this sequence to $W$, with the same fixed collar-tower rule as (SEP-L). On each retained core row use the stored datum $\zeta(c)$. On each retained shell row use $\exp(ig_kB(c))$. On every added boundary or tower row use $\mathbf1$. Inherited core rows take precedence over shell rows; added rows are disjoint from inherited rows.

Call this datum $\bar{\mathbf V}(\xi)$ and its real critical background $\bar P(\xi)$. Its definition requires admissibility, including every mixed core/collar test. This is a separate premise. All collar lifts are vacuum lifts, since $\mathcal M(\mathbf1)=\mathbf1$. Thus the definition has no exterior-pair argument. It retains the stored core rather than replacing that core by a regular field. Define the candidate inner Wilson read to be $A(w\psi,\bar P(\xi))$.

An interior margin must apply to the **full** inner domain. Fix a chart for an inner read $y$. Choose seminorms $\|\cdot\|_a$ on its coordinate increments and positive margins $m_{y,a}$. They must control potential, first derivative, current, every tower condition, and the assigned layer radii. The precise premise is
\[
 \bar p_y+\{h:\|h\|_{*,y}<1\}\subset D_y,\qquad
 \|h\|_{*,y}:=\sup_a\frac{\|h\|_a}{m_{y,a}},
 \quad \bar p_y=\bar p_y(\xi).
 \tag{M}
\]
The addition denotes genuine pair coordinates, not raw matrix addition. Tower fields are functions of these coordinates, not independent coordinates. The inclusion in (M) requires every nonlinear tower clause throughout the ball; a bound on its differential alone does not suffice. For an actual substituted read write $p_y=\bar p_y+h_y$ in this chart.

**Elementary consequence.** If $\|h_y\|_{*,y}\le a<1$ and a holomorphic remainder satisfies $|f_y|\le bN_y$ on the ball in (M), then
\[
 |f_y(p_y)-f_y(\bar p_y)|\le bN_y\,\frac{a}{1-a}.
 \tag{1}
\]
Indeed $z\mapsto f_y(\bar p_y+zh_y)$ is bounded by $bN_y$ for $|z|<1/a$. Cauchy's formula bounds its $n$th coefficient by $bN_ya^n$. Sum from $n=1$. For $a\le1/4$, summing (1) costs at most $b\sum_yN_y/3$.

This proves the analytic implication. It does not prove (M), the actual displacement bound, or a bound for the unexpanded Wilson action. Proposition I' compares $p$ with its own real splitting. It does not compare $P_{p_{\rm r}}$ with this fixed $\bar P(\xi)$.

## 3. The full gauge substitution

Write $S^\circ=(S^{\rm L})^u$, with $V^u(c)=u(c_-)V(c)u(c_+)^{-1}$. The exact pullback is
\[
 u_-^{-1}\big(e^{igB^\circ(c)}u_-W(c)u_+^{-1}\big)u_+
   =e^{igB^{\rm L}(c)}W(c),\qquad
 B^{\rm L}(c)=\operatorname{Ad}(u_-^{-1})B^\circ(c),
 \quad \zeta^{\rm L}=\zeta^{u^{-1}}.
 \tag{2}
\]
Thus the shell fluctuations and the stored core must both move. At real pairs, each adjoint matrix is orthogonal with determinant one. The determinant is positive by continuity from the identity in $\mathrm{SU}(2)$. Consequently (2) preserves Lebesgue measure, bond norms and the zero fluctuation-tree constraints. Left and right Haar invariance preserve the core measure. These statements concern a gauge fixed independently of the integration coordinates.

**The remaining matching is substantive.** SA 17598 tests a background made from $(\mathbf1,\zeta)$, with the vacuum on the shell side. Pulling back this complete datum gives
\[
 ((\mathbf1)^{u^{-1}},\,\zeta^{u^{-1}}),\qquad
 (\mathbf1)^{u^{-1}}(c)=u_-^{-1}u_+.
 \tag{3}
\]
It does not give $(\mathbf1,\zeta^{u^{-1}})$. For an explicit algebraic failure, start with all bonds equal to one. Take a plaquette crossing the interface. At one interface vertex set $u=e^{itT}$, $T=\operatorname{diag}(1,-1)$; set the other three gauges to one. One incident edge belongs to each side. Transforming both sides leaves its holonomy one. Transforming the core side while resetting the other side to vacuum leaves holonomy $e^{\pm itT}$. Hence the reset datum is not gauge equivalent to the original datum, for $0<|t|<\pi$.

This closes the algebraic check of (2), but refutes automatic covariance of the vacuum-joined datum. It is not an admitted-pair counterexample to (Inn). One must transport the last-shell test, the stored constraints and their reference fields as well. That transported test then contains $u(p)$. Neither (2) nor its unit Jacobian proves a fixed integration support. At complex pairs the transformed real contour is also not automatically the original contour.

There is a second issue even after this matching. Relative to each $p_{\rm r}$, (2) gives the Landau shell increment its factor $\xi_j$. At $\beta=0$, however, $u=\mathbf1$ and its base is still $S_{p_{\rm r}}$. Changing the real exterior changes this base. Therefore this relative substitution cannot by itself identify the actual read with Section 2's fixed reference.

 \tag{4}
\]

\[
 u_j(c_-)\,e^{-ithT}\,u_j(c_+)^{-1}=e^{-itT}.
 \tag{5}
\]
This equality holds at every $j$. The gauge is independent of $x_3$, so direction-3 bonds on this plane remain one. This is an explicit reference-row calculation, not an inference from an upper curvature bound.

Thus chart admission alone cannot imply the required inner comparison. For example, $t=cg_k\ell^a$ makes this cost proportional to $\ell^{2a}$. ### 6d. Theorem F

Choose \(e\) by (i), and let \(S\) be the set of level-\(k_\flat\) plaquettes in the \((e,e_4)\) plane that straddle both \(F_e\) and one of the two core faces normal to \(e_4\), on the side of the edge belonging to \(e\) and in the chosen column. Each has a core row parallel to \(e\) (datum \(\mathbf1\) by (H2)), a shell row parallel to \(e\) (datum \(\exp(i\theta^\circ T)\)), and two rows parallel to \(e_4\) (datum \(\mathbf 1\) by (iii) or (H2)). Its holonomy angle \(\phi\) is therefore \(\mp\theta^\circ\), so
\[
 \tfrac12|z|\le|\phi|\le(A_{\max}+\tfrac12)|z|,\qquad \#S\ge8(M\check R_{k_\flat})^2 .
 \tag{6.3}
\]
Here \(A_{\max}\) bounds \(|A|\) on the box, \(A_{\max}\le(C_\Lambda M)^2\). The count uses (H1): two cells of side \(M\check R_{k_\flat}\) on the edge's side in each of the two transverse directions, and two faces.

Put \(f(z):=A(w\psi,P(\xi_*;\mathbf p_z))\). Let \(T_\natural\) be the number of tops in \(Z^\natural\), and \(K_1:=\max(A_{\max}+\frac12,D_X)\).

**Theorem F (implication; proved by Claude, not yet checked by the other model).** Assume premise U°, P81's complex chart (radius \(r_{\rm B}\), complex local curvature \(\le C_{\rm R}r_{\rm B}\); I2 of `sa-2.8-terms.md`), `sa-2.13-2.md` (6.5), and \(w\in[x/2,2x]\) on \(Z^\natural\). Put \(\rho:=r_{\rm B}/(2K_1)\), \(\kappa_1:=x\#S/(16\pi^2)\), \(t_0:=(8e_*/\#S)^{1/2}/(A_{\max}+\frac12)\) and \(\tau_1:=\min\{\rho/2,\ \#S\rho^3/(384\pi^2C_{\rm R}^2r_{\rm B}^2T_\natural)\}\). Then:

(a) \(f\) is holomorphic on \(|z|<\rho\), real on \(\mathbb R\), with \(f(0)=0\) and \(f(t)\ge\kappa_1t^2\) for real \(|t|\le t_0\).

(b) \(-\operatorname{Re}f(i\tau)\ge\kappa_1\tau^2/2\) for \(0<\tau\le\tau_1\).

(c) For every pair-independent inner read in \(\Phi^\circ\), the inner remainder \(V^{\rm Inn}_X(\xi_*;\cdot)\) satisfies
\[
 \max_{\mathbf p\in\{\mathbf p_0,\mathbf p_t,\mathbf p_{i\tau}\}}|V^{\rm Inn}_X(\xi_*;\mathbf p)|\ \ge\ \tfrac14\max(\kappa_1t^2,\ \kappa_1\tau^2),
\]
with \(t=\min(t_0,\varepsilon_k)\) and \(\tau=\min(\tau_1,\alpha_0/2,\alpha_*/D_X)\). The same strict inequalities, with \(\frac18\) in place of \(\frac14\), hold on a neighbourhood of \(\xi_*\) in \(\mathcal U_*\).

*Proof.* (a) The prepared datum at \(\mathbf p_z\) differs from the flat datum by angles at most \(|z|(A_{\max}+\frac12)\) on shell rows (Lemma J and the same computation off the faces) and \(|z|D_X\) on exterior rows of gauge (O). For \(|z|<\rho\) this is below \(r_{\rm B}/2\), so P81's chart gives a holomorphic background. At real \(t\) it is real, so \(f(t)\ge0=f(0)\). The four rows of each plaquette of \(S\) are determining rows, so the background's level-\(k_\flat\) averages there are the data. (6.5) applies to every real compatible field on the ancestor plaquettes, which lie in \(\{\psi=1\}\) because the level-\(k_\flat\) shell has width \(\ge M\xi_{k_\flat}\) (GEO3). With \(\|e^{i\phi T}-\mathbf1\|^2=4\sin^2(\phi/2)\ge(4/\pi^2)\phi^2\ge t^2/\pi^2\), and with \((1/8)\sum_S\|\cdot\|^2\le e_*\) for \(|t|\le t_0\):
\[
 f(t)\ge\tfrac x2\cdot\tfrac18\sum_{p'\in S}\|\partial(\mathcal M^{k_\flat}P_t)(p')-\mathbf1\|^2\ge\kappa_1t^2 .
\]
(b) Write \(f=\sum_{n\ge2}c_nz^n\). The \(c_n\) are real, \(c_1=0\) because \(0\) is a real minimum, and \(c_2\ge\kappa_1\) by (a). For a top \(y\) and a plaquette \(p\) it carries, \(|1-\frac12\operatorname{tr}P_p|=\frac12|\det(P_p-\mathbf1)|\le\frac12\|P_p-\mathbf 1\|^2\le\frac12(C_{\rm R}r_{\rm B})^2(\eta/\xi_y)^4\). A top carries at most \(6(\xi_y/\eta)^4\) plaquettes. So \(F:=\sup_{|z|<\rho}|f|\le6x(C_{\rm R}r_{\rm B})^2T_\natural\), and Cauchy gives \(|c_n|\le F\rho^{-n}\). Then
\[
 \operatorname{Re}f(i\tau)=-c_2\tau^2+\sum_{n\ge3}c_n\operatorname{Re}(i^n)\tau^n\le-\kappa_1\tau^2+2F\tau^3/\rho^3\le-\kappa_1\tau^2/2
\]
for \(\tau\le\tau_1\). (c) The inner read in \(\Phi^\circ\) does not depend on the pair, and (H4) gives no other inner term. So \(V^{\rm Inn}(\mathbf p)-V^{\rm Inn}(\mathbf p_0)=f(0)-f(z)\) for \(\mathbf p=\mathbf p_z\), and the triangle inequality gives the bound. The three pairs are admitted by (6.1). The background is continuous in the datum on P81's chart, so the strict inequalities persist near \(\xi_*\). \(\square\)

**Size.** By (6.3) and \(D_X\le C_XM\check R_k\le C_XM\check R_{k_\flat}\) (\(\check R\) does not increase with the level), \(\kappa_1\tau^2\ge x\alpha_*^2/(2\pi^2C_X^2)\) at the coupling ceiling, where \(\tau=\alpha_*/D_X\). The outline's pair radius is \(\alpha_{1,k}=C_1\theta_k^{-1/2}(\log\theta_k)^q\) (SA 6033). If (ADM) admits imaginary potentials of that size, \(x\alpha_*^2\ge c\,\ell^{2q}\). If (ADM) is taken with a smaller \(\alpha_A\), the complex failure still exceeds \(CN_0\) as long as \(\alpha_A\ge g_k(1+\ell)^{2r+1}\). On the other side, \(N_0(\omega_*)\le C(M,L)(1+\ell)^{4r+1}\). Since \(q>\mathfrak p_0+2r\) with \(\mathfrak p_0\ge\frac12\), we have \(2q>4r+1\), so the complex failure exceeds \(CN_0\) for every fixed \(C\). The real failure is \(\kappa_1\varepsilon_k^2\ge(M\check R_{k_\flat})^2p_0^2/(2\pi^2)\). It exceeds \(CN_0\) when \(\mathfrak p_0>r+\frac12\).

## 7. Repair: a core-rooted representative, and (Inn) under it

**Claim.** The outline does not fix the representative of \(U_0\) in \(V_0\). If it is rooted at the core near the core and kept as \(U^\circ\) near the box boundary, the near-core shell data are the vacuum up to a factor \(L^{-\mathsf N/2}\). ### 7a. Definition R (supplied)

Fix \(\omega\), its frame \(r\), and a level-\(k_\flat\) site \(z_c\) of the core nearest its centre. Put
\[
 n_{\rm m}:=\lfloor\mathsf N/4\rfloor,\qquad s':=k_\flat+n_{\rm c}+n_{\rm m}\le k-\mathsf N/4 .
\]
Let \(W\) be the union of the core, the shells of levels \(k_\flat,\dots,s'-1\), and the inner half of the level-\(s'\) shell. Let \(N_{\rm c}\) be the nest box bounding the shells of levels \(\le s'+1\) (GEO3). For a site \(x\) of \(\Lambda^{\rm pr}\), put \(h(x):=T_{U^\circ}(z_c\to x)\), the \(U^\circ\)-transport along the comb from \(z_c\) to \(x\) in frame \(r\)'s order, if \(x\in N_{\rm c}\), and \(h(x):=\mathbf 1\) otherwise. **Form every average of the reference that the operation reads (the shell datum \(V_0\) and the reference rows of \(T(B)\)) from \(S^R:=(U^\circ)^h\).** Nothing else changes: the tests, trees, deltas, reference law and stored variables are those of the outline.

Properties.
- (R1) \(h\) is a holomorphic function of the pair, and unitary at real pairs.
- (R2) \(S^R=U^\circ\) on bonds with both ends outside \(N_{\rm c}\). Every shell of level \(\ge s'+2\), and every row near \(\partial\Lambda^{\rm pr}\), is unchanged.
- (R3) The centred average is covariant (SA: \(W^h(z,x)=h(z)W(z,x)h(x)^{-1}\)). Hence \(\mathcal M^j(S^R)(c)=h(c_-)\mathcal M^j(U^\circ)(c)h(c_+)^{-1}\). For \(c\) with both ends in \(N_{\rm c}\) this equals \(\mathcal M^j(U^c)(c)\), where \(U^c\) is the comb gauge rooted at \(z_c\).
- (R4) Each shell row is a gauge transform of its \(U^\circ\) value by one gauge function \(h\). So all gauge-invariant functions of shell data alone are unchanged. Only the interfaces with untransformed data (the core, and the exterior) see \(h\). There \(h\) is the jump-removing transport near the core and \(\mathbf1\) near \(\partial\Lambda^{\rm pr}\).

### 7b. Proposition D (near-core data; proved by Claude, not yet checked)

Assume the box curvature bound \(\|\partial S(\mathbf p)_p-\mathbf 1\|\le C'(M)(\varepsilon_k+\beta_A)\eta^2\) on bare plaquettes of \(\Lambda^{\rm pr}\) (`ref-chart.md` 9f with the curl correction of `gates/ref-chart-regate.md` Section 10, checked by Codex) and Lemma R (`ref-chart.md` Corollary P item 1). Then at every admitted pair, every shell row \(c\) of level \(j\) with both ends in \(N_{\rm c}\) satisfies
\[
 |\log V_0^R(\mathbf p)(c)|\le C_D(\varepsilon_k+\beta_A)\,\xi_j\big(|c_--z_c|_1+8\xi_j\big),\qquad C_D:=72C_{\rm R}C'(M)/r_* .
 \tag{7.1}
\]
In particular, on every retained row of \(W\),
\[
 |\log V_0^R(c)|\le\delta_D:=C_D(\varepsilon_k+\beta_A)\,\xi_{s'}\big(D_W+8\xi_{s'}\big)\le C(M)(\varepsilon_k+\beta_A)(\check R+L^2)L^{-\mathsf N/2},
\]
with \(D_W:=\sup_{x\in W}|x-z_c|_1\le4C_nM(\check RL^{k_\flat-s'}+L^2)\xi_{s'}\) (GEO3 for the nest box of levels \(\le s'\), which contains \(W\) and \(z_c\)).

*Proof.* By (R3) it suffices to bound \(\mathcal M^j(U^c)(c)\). Let \(b\) be a bare bond of \(N_{\rm c}\). In the comb gauge rooted at \(z_c\), \(U^c(b)\) is the holonomy of \(L_b=\mathrm{comb}(z_c\to b_-)\cdot b\cdot\mathrm{comb}(z_c\to b_+)^{-1}\). The two combs agree up to the leg in \(b\)'s direction, and after it they run parallel at distance \(\eta\). So \(L_b\) bounds a ladder of at most \(|b_--z_c|_1/\eta+1\) plaquettes. Non-abelian Stokes writes the holonomy as an ordered product of \(T_i\,\partial S_{p_i}T_i^{-1}\). The transports \(T_i\) run along comb paths of length \(\le C_nM\) in \(S(\mathbf p)=(e^{i\eta a}S(p_{\rm r}))^{u_B}\), with \(|a|\le C_aC'_v\beta_A\) and \(|u_B^{\pm1}|\le1+C_w\|B\|_\infty\) (`ref-chart.md` 9b). So \(|T_i^{\pm1}|\le3\) at the coupling ceiling. Then \(\|\prod(1+Y_i)-1\|\le e^{\sum\|Y_i\|}-1\) gives
\[
 \|U^c(b)-\mathbf1\|\le18C'(M)(\varepsilon_k+\beta_A)\,\eta\,(|b_--z_c|_1+\eta).
\]
Write \(U^c=e^{i\eta a^c}\) with \(|a^c(b)|\le36C'(M)(\varepsilon_k+\beta_A)(|b_--z_c|_1+\eta)\). The row map \(a\mapsto\frac1i\log\mathcal M^j(e^{i\eta a})(c)\) is holomorphic, bounded by \(C_{\rm R}\) for \(\xi_j\sup|a|<r_*\), and vanishes at \(a=0\). Schwarz's lemma (with \(|\log X|\le2|X-\mathbf1|\)) gives (7.1); the double block of \(c\) lies within \(\ell^1\)-distance \(8\xi_j\) of \(c_-\). The second bound uses \(\xi_{s'}=L^{-(\mathsf N-n_{\rm c}-n_{\rm m})}\le L^{-\mathsf N/4}\) and GEO3. \(\square\)

So under Definition R the actual near-core shell data are \(e^{igB}\) up to \(e^{i\delta_D}\), at real and complex pairs. Codex's "second issue" of Section 3 disappears: changing the real exterior moves this base only by \(\delta_D\). Theorem F has no analogue. In (6.3) the interface angle becomes \(|\phi|\le\delta_D\), not \(\ge|z|/2\).
