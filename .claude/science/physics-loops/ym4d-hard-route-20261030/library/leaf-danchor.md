## 1. Kill test first

**Outcome: no counterexample. A native Gaussian spectator is inert; the complete anchor test remains unresolved.**
This is not a pass for D-OLD-ANCHOR.

The pass criterion is equality of the complete old row read throughout that range, with positive original datum room.
A changed node defeats the proposed anchor identification.

For the native kept Gaussian, the stored field occurs in
\[
 -\frac12\sum_{b,b'}a_b^{\mathsf T}D_\omega(P)_{bb'}a_{b'}.
 \tag{K1}
\]

This is Sussman–Alpoge's construction, SA 17550–17564 and Y 68832–68838.
