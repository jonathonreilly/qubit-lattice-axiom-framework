## 2. The exact finite certificate

Fix one original call $`e`$ and its complete finite link-read graph $`G_e`$.
Include the outward blocks, old pillars and node-completion paths.
Keep distinct occurrences when their field versions differ.
Do not identify their edges merely because their spatial coordinates agree.
Work on a common original branch where both precursor fields and every defining map exist.

In each connected component choose a spanning tree, rooted in its original frame.
This choice lists paths. It applies no gauge transformation.
Write $`p_x`$ for its root-to-$`x`$ path.
For a field $`A`$, define

```math
T_A(x)=A(p_x),\qquad
C_A(b)=T_A(x)A(b)T_A(y)^{-1},\qquad b=(x,y).
\tag{1}
```

For each nontree edge, $`C_A(b)`$ is its fundamental based loop matrix.
For a tree edge, it is the identity.
Thus the requested lemma has the following exact form.

**D-HOLONOMY.** For every admitted history, real fibre and surviving parameter value,
the complete first old read satisfies

```math
T_W(x)=T_V(x)\quad(x\in G_e),\qquad
C_W(b)=C_V(b)\quad(b\notin\text{the spanning forest}).
\tag{DH}
```

All paths are evaluated in the original frames.
Stored prescribed transports must be compared with their original prescriptions.
An added tree path does not acquire a transport-restoration identity by being chosen here.

The finite reconstruction is exact:

```math
A(b)=T_A(x)^{-1}C_A(b)T_A(y).
\tag{2}
```

Consequently (DH) is equivalent to $`W=V`$ on this complete graph.
For a tree edge use $`C_A(b)=1`$ in (2); for every other edge use (1).
The converse follows by multiplying equal links along each path.
Disconnected components are treated separately.
This elementary certificate establishes an equivalence, not (DH).
It supplies no original-domain admission.
Sussman–Alpoge's related parallel-frame argument, Y 43159–43215, concerns flat connections and retains their based holonomies.
It does not assert equality of the present curved precursors.

Here is the full first-order version of the kill test.
At a comparison point $`W(0)=V(0)=U`$, put

```math
X_b=(\dot W_b-\dot V_b)U_b^{-1}.
\tag{3}
```

The dots include all retained response, current, mean, alignment and node derivatives.
They are exactly the full derivatives specified in leaf-dretained (2)–(4), (11)–(12).
For $`\gamma=(b_1,\ldots,b_m)`$, the product rule gives

```math
\left.\frac{d}{dt}(\operatorname{Hol}_W(\gamma)
                  -\operatorname{Hol}_V(\gamma))\right|_0
             \operatorname{Hol}_U(\gamma)^{-1}
 =\sum_{j=1}^m\operatorname{Ad}_{U_{b_1}\cdots U_{b_{j-1}}}X_{b_j}.
\tag{4}
```

Each differentiated factor is multiplied on the right by its original inverse.
This proves (4) without commutativity.
For a reversed edge use $`X_{\bar b}=-\operatorname{Ad}_{U_b^{-1}}X_b`$.
No response term or later factor has been deleted.

Put $`a_x=(\dot T_W(x)-\dot T_V(x))T_U(x)^{-1}`$.
Differentiating (1) gives the fundamental-cycle test

```math
(\dot C_W(b)-\dot C_V(b))C_U(b)^{-1}
 =a_x+\operatorname{Ad}_{T_U(x)}X_b
       -\operatorname{Ad}_{C_U(b)}a_y.
\tag{5}
```

The last term follows from differentiating the inverse transport.
Equation (5) checks the endpoint contributions rather than suppressing them.
With all cycle derivatives zero, it says
$`X_b=k_x-\operatorname{Ad}_{U_b}k_y`$, where $`k_x=-\operatorname{Ad}_{T_U(x)^{-1}}a_x`$.
This conclusion also holds on tree edges by their path definition.
It is only an infinitesimal gauge difference.
The tree condition $`a_x=0`$ is still needed to conclude $`X_b=0`$.

At the identity anchor (4) is an ordinary cycle sum.
A traced loop can miss it: $`\operatorname{tr}e^{it\operatorname{diag}(1,-1)}=2\cos t`$ has zero first derivative at zero.
This is why the test uses matrix holonomies.
Neither a flat admitted history nor a nonzero value of (4) for such a history is assumed here.
