## 4. Route 2: obtain the fixed list from compatibility

The second route uses the definition of the evaluation fibre.
It tests whether the compatibility equations themselves provide the missing prescribed arguments.
This differs from the previous leaf's genealogy and determining-mask calculations.

Y 74072–74122 and SA 18139–18176 distinguish the stored record from an evaluation.
An evaluation contains a real field $`U`$ compatible with that record.
It also supplies exterior test reads, admissible inner reads and the specified one-sided bounds.
Compatibility on determining bonds has the form

```math
\mathcal M^\ell U(b)=V_\ell(\xi)(b).
\tag{3}
```

The proposed route treats the left side as a fixed target while varying the old chart coordinates.
That would produce a readily identifiable residual list of old determining values.
The order of quantifiers prevents this inference.

Fix the inner stored variables $`\eta`$ and retain all already prescribed exterior arguments.
The required outer expression has the form

```math
\int^* 1_{S_\omega}(x,\eta)
 \sup_{\mathfrak e\in\mathcal K^\sharp(\omega,x,\eta)}
 G_\omega(x,\eta;\mathfrak e)\,d\mu^\circ(x).
\tag{4}
```

This is the quantifier order in Y 74129–74169 and 76970–77013.
At each $`x`$, the supremum ranges over evaluations compatible with that $`x`$.
Equation (3) is a relation between the chosen evaluation and the current stored record.
There is no single field $`U_0`$ fixed across the integration in (4).
Imposing

```math
V_\ell(x,\eta)(b)=\mathcal M^\ell U_0(b)
\tag{5}
```

would select a different section of that relation.
It is not the definition of (4).
Likewise, a recorded test restricts the compatible set; its value is not a new prescribed continuous field coordinate.
An empty compatible set contributes zero, as the source stipulates.

This observation excludes a false source of new fixed values.
It does not prove that the support in (4) is a product.
The compatible set may be empty at some stored records, and the original tests remain in force.
Nor may a reference map depend on the varying evaluation: Y 76970–76975 forbids that dependence.

The true exterior of a lower inverse is a different matter.
It is held fixed during that inverse evaluation, even when generated inside a larger operation.
Y 76010–76014 includes the actual retained arguments in that exterior.
Y 76177–76189 separately treats a generated spectator prescribed as a raw target.
Neither role can be decided merely from (3).

**Failed step of Route 2:** identify those fixed lower-call parameters with one compatible evaluation of the whole history.
The evaluation varies in (4); the lower call's parameter signature does not follow from it.
Thus compatibility neither supplies the missing $`Q_R`$ nor proves that it is empty.

## 5. Route 3: differentiate the original inverse, then compare whole fibres

The third route tests a proposed fixed component against the actual row equations.
It retains every reconstructed dependence, instead of testing one bare link in isolation.

On a regular branch of a supplied chart, let $`t`$ be its selected input coordinates.
Let $`u`$ be its original unselected coordinates and $`e`$ its permitted exterior.
Write its complete solved equations as

```math
\mathcal A(t,u;e)=y,\qquad
J=D_t\mathcal A,\qquad J\text{ invertible}.
\tag{6}
```

For a component $`q(t,u;e)`$ of the proposed $`Q_R`$, all derivatives below are total derivatives.
They include earlier graph substitutions, collar reconstruction and the ordinary strip inverse.
Holding $`e`$ fixed, differentiation of (6) gives

```math
dt=J^{-1}(dy-D_u\mathcal A\,du).
\tag{7}
```

The exact tests for a target sublist $`I`$ are therefore

```math
\begin{aligned}
D_u(q\circ\Phi_T)
 &=D_uq-D_tq\,J^{-1}D_u\mathcal A,\\
D_{y_{I^c}}(q\circ\Phi_T)
 &=D_tq\,J^{-1}\iota_{I^c}.
\end{aligned}
\tag{8}
```

Here $`\iota_{I^c}`$ inserts the unfixed target directions into the full target vector.
These identities follow by substituting (7) into $`dq`$.
They are written calculus, not a numerical test or a new inverse theorem.

For a proposed residual generated by a raw row, use its literal expression

```math
q=\mathcal M(V_{\ell-1}^{\mathrm{recorded}})(b),\qquad
Dq=D\mathcal M\,D V_{\ell-1}^{\mathrm{recorded}}.
\tag{9}
```

The field in (9) is reconstructed by (2), with its original version.
For an ordinary or collar inverse, (7) must also be used inside that reconstruction.
Keeping just the derivative of the last average would omit these dependencies.

The available chart results prove invertibility of $`J`$ and bound its inverse density.
They do not make either expression in (8) zero for an additional prescribed argument.
The private-pivot separation applies to the supplied simultaneous stock, Y 75564–75582 and 76185–76189.
It is not a relation between an unspecified extra reader and that stock.
The protected two-level port supplies a particular enlarged stock, with its stated free alternate.
It cannot be invoked before identifying the extra prescribed rows and checking their complete carriers.

There is also a separate whole-fibre requirement.
For every two admissible points, possibly in different inverse branches, require

```math
y_I=y'_I,\quad e=e'
\quad\Longrightarrow\quad
Q_R(\Phi_{T,\beta}(y,u;e))=Q_R(\Phi_{T,\beta'}(y',u';e)).
\tag{10}
```

Here $`\beta,\beta'`$ label the original inverse branches, when there is more than one.
Vanishing in (8) would imply constancy on each connected open regular fibre piece.
It would not compare different pieces or different branches.
Sharp tests may remove connecting regions.

A pointwise graph identity $`q=F(y_I,e)`$ would establish all these comparisons at once.
