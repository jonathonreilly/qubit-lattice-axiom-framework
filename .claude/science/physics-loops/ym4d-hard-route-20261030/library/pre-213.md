### 1c. Clarifications (none is a defect)

(i) *sa-2.13, (5.5).* \(O(u)\subset C(u)\) needs each node to have one successor. This holds: the parent image of a connected cell set is connected, healing removes whole components, and SA's chain rule (SA 18575) has no split start. The note uses this tacitly.

(ii) *sa-2.13, (6.2).* \(\#_t\) counts level-\(t\) sites, as in SA's \(N_0=\sum_j\#_j\) (SA 18086). Then \(C_L=8(L+1)^4\) works: a level-\((j+1)\) site covers at most \((L+1)^4\) level-\(j\) sites, and a site carries at most eight bonds. With \(\#\) read as a cell count, (6.2) would lose a factor \((MR_{j+1})^4\). (6.3) uses the site reading, so the note is consistent.

(iii) *sa-2.13, (8.4).* The cell price \(c_t=K\ell_t(MR_t)^4\) must satisfy \(c_t\le r_t=C_3c_1M^4R_t^5\) (SA 18608). This holds with \(c_1:=2K/C_3\), since \(\ell_t\le 2R_t\) at the ceiling: FLOW gives \(R_t\ge(\ell_t-1)^r\) with \(r\ge2\). The ceiling of (5.4) then depends on \(K\). This is allowed, because \(K\) is fixed first.

(iv) *sa-2.13-2, Lemma 3.2.* The lemma needs \(\epsilon\le B\). If \(\epsilon>B\), then \(B\) itself bounds \(\lvert f\rvert\). Section 3 below always uses \(\min(B,\sqrt{B\epsilon})\).
