**discharged — proof of the implication.** For two sources write

    Delta_k(Y) = int_0^1 [D_{f_1}epsilon_k(Y;s f_1+f_2)

    eta/a_k <= d_1 + d_2 + diam_k(Y) <= 2 max(d_1,d_2) + D_M |Y|.                (M2)

    b = min(c_s/2, (q-h)/(2 D_M)) > 0,
    beta_1 = (q-h)/2 > 0.

Combining (M1),(M2) bounds a term by

    2 A_s exp(-b eta/a_k) exp[-(q-b D_M)|Y|].

For completeness, the animal count used here has a direct proof. Fix an ordering of the finite cube graph. To each connected m-vertex set containing a given vertex assign its deterministic rooted spanning tree and its depth-first traversal. That walk has length `2(m-1)` and visits exactly that set. Distinct sets give distinct visited sets, hence distinct walks; there are at most `D_*^{2(m-1)}` walks. Thus the number of such sets is at most `exp(h m)`.     sum_Y |Delta_k(Y)| <= C_0 A_s (P/a_k)^4 exp(-b eta/a_k),                      (M3)

    sum_{k<K} x_k^4 exp(-b x_k) <= 24/[(1-ell^-4)b^4].                          (M4)
