Disposition: `block` on the initial combined rewrite.

Findings:

1. A first-variation moment identity did not control finite nonlinear endpoint
   differences.
2. Reusing the old critical claim ID for a new exact scope would have laundered
   the meaning consumed by existing descendants.
3. The auxiliary chain counterfamily did not justify a full-framework
   nonselection theorem.
4. Point-mass falsifiers lay outside the initially stated density domain.
5. The load-bearing premise boundary lacked machine-visible markdown links.
6. The first N1-N8 packet was incomplete.
7. The runner did not assert all displayed stationarity, moment, and Hessian
   values and did not fingerprint approved primitive scopes.

Fixes:

- restored the old claim ID as a bounded target-conditioned numerical scan;
- created a distinct `no_go` source note for only the generic chain-local,
  fixed-endpoint, strict-convexity selector route;
- reformulated the moment lemma for finite positive Borel measures and added
  the midpoint-Jensen affinity proof;
- added the exact nonlinear path-derivative identity and explicitly left the
  profile-uniform kernel bound open;
- renamed the discrete witness moments `A_disc,c_disc`;
- linked the minimal axioms and all relevant approved primitive source notes;
- narrowed the trace class to `negative_route_pruning`;
- completed N1-N8 in the source note and claim certificate; and
- strengthened the runner to assert exact minimizers, Euler stationarity,
  moment values, Hessian minors, primitive scopes, external output paths, and
  paired hashes.
