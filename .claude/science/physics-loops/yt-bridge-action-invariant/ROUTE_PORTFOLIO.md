## Sequential stuck fan-out synthesis

1. **Minimal algebraic frame.** For a positive response measure `q dx`, an
   affine kernel gives the exact identity
   `R = A (a c + b)`. A curved kernel adds a rigorously bounded variance
   remainder. This is the strongest target-independent positive theorem.
2. **Variational frame.** A local positive action can select a profile only
   after its coefficients and source term are supplied. Locality and stability
   alone admit a coefficient family with different minimizers, `I_2`, and
   centroids.
3. **Operator/Schur frame.** Schur/Feshbach marginalization is an exact map
   from a supplied microscopic operator to a coarse operator. It cannot select
   the supplied microscopic operator or identify its entries with the YT
   response.
4. **Symmetry/model-theory frame.** `A_min` contains no scale coordinate,
   coupling trajectory, endpoint functional, or source/action symbol. The same
   `A_min` model admits downstream expansions with different bridge actions and
   centroids, so neither value is entailed.
5. **Falsifier frame.** Equal-`I_2` profiles at different centroids have
   different response for any nonconstant affine kernel; equal-`I_2` and
   equal-centroid profiles can differ for a curved kernel. These witnesses
   falsify action-only and two-moment exactness outside their stated kernel
   classes.

## Selected route

Execute the narrow generic-selector counterfamily. The response-moment algebra
is retained only as a lemma explaining what additional common-kernel theorem a
future physical construction must provide. The result prunes the shortcut from
generic chain locality, fixed endpoints, and strict convexity; it does not
claim that the full framework cannot derive a microscopic operator.
