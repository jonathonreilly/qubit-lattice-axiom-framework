# Assumptions And Imports

## Explicit Inputs

- Source-action support packet: normalized RN source/action identity.
- Primitive record intervention law: normalized RN/Fisher source family.
- C3 tangent basis `B_a`, `B_x`, `B_y`.

## What If Wrong

- If identity source terms were physical, `B_a` would survive and the C3
  source direction would remain three-dimensional.
- Since normalized RN cancels identity terms, this block removes only `B_a`.
- It does not remove `B_y`; reflection evenness remains a separate premise.

## Forbidden Imports

No `H_unit`, Ward route, `y_t_bare`, observed masses, PDG, `alpha_LM`,
plaquette/u0, Planck, alpha_s, or fitted selector is used.
