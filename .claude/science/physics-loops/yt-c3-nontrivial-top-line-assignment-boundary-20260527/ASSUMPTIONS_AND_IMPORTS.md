# Assumptions And Imports

## Explicit Assumptions

- The connected/reflection-even C3 source candidate supplies `B_x`.
- C3 spectral projectors `P_0`, `P_omega`, and `P_omega2` are available as
  finite algebra.
- LSP supplies sharp-projective instruments for supplied projectors.

## What If Wrong

- If top is `P_0`, the response magnitude is `2/sqrt(6)`.
- If top is one of `P_omega`, `P_omega2`, the response magnitude is
  `1/sqrt(6)`.
- If no same-surface dynamics selects the top line, the coefficient remains
  unclosed.

## Forbidden Imports

No `H_unit`, `yt_ward_identity`, `y_t_bare`, observed masses, PDG values,
`alpha_LM`, plaquette/u0, Planck, alpha_s, or fitted selector is used.
