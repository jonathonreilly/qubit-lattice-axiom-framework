# No-Go Ledger

## NG-1: Fierz Dimensions Do Not Select The Physical Readout

Fierz fixes `F_adj = 8/9` and `F_singlet = 1/9`, but not whether the
physical Yukawa scalar normalization reads `F_adj`, `F_adj + F_singlet`, or
`F_adj + kappa_Y F_singlet`.

## NG-2: Color-Blind Scaling Does Not Select kappa_Y

A shared color-blind factor multiplies both channels and cancels in the
normalized readout. It cannot distinguish `kappa_Y = 0` from `kappa_Y = 1`.

## NG-3: Vertex Projection Points Away From The Historical Package Factor

The retained projection lemma gives `rho_singlet(I_color) = 1` and
`rho_singlet(t^A) = 0`. A color-blind Yukawa vertex tied to this projection
would select `K_Y = 1`, not `K_Y = 8/9`.
