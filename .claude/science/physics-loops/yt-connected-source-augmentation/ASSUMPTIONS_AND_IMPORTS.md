# Assumptions And Imports

## Used

- Finite-dimensional color algebra `End(C^N)`.
- Trace-one color records/states for normalized source response.
- Normalized Radon-Nikodym source tangent: score equals observable minus its
  zero-source expectation.
- Existing Y_T color family `K_Y(kappa_Y) = (N^2-1)/N^2 + kappa_Y/N^2`.

## Not Used

- `H_unit`.
- `yt_ward_identity`.
- `y_t_bare`.
- observed top/Yukawa values.
- `alpha_LM`, plaquette/u0, Planck, alpha_s, or fitted selectors.

## Open Imports

- The theorem does not derive that the physical Y_T neutral EW/Higgs source is
  this normalized connected color source tangent.
- Canonical `O_H` and scalar LSZ normalization remain open.
