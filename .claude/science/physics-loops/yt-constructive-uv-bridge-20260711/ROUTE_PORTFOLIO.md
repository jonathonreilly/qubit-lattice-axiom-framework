## Stuck fan-out frames

1. **Smallest algebraic surface.** Search for any term in `A_min` that can
   define a dimensionless Yukawa readout or evolution law. Falsifier: two
   expansions of the same axiom model with different endpoint assignments.
2. **Symmetry/naturality.** Ask whether translation and proper-cubic
   covariance force a bridge location. Falsifier: endpoint-preserving switching
   functions localized near the IR, spread diffusely, or localized near the
   UV, all carried as spectator expansions of the same axiom reduct.
3. **Variational/source-domain route.** Ask whether Record additivity yields a
   scalar action whose stationary point is the bridge. Falsifier: additivity
   acts only on disjoint record readout and supplies no action or source map.
4. **Atlas reuse.** Inspect the exact coarse-graining, rearrangement, Hessian,
   and transport notes. Falsifier: each imports the accepted bridge/window,
   fitted kernel, or target-conditioned class rather than deriving it.
5. **Strongest obstruction.** Prove a conservative-extension theorem: because
   endpoint and bridge symbols do not occur in the physical premise language,
   arbitrary assignments preserve every axiom. Add exact endpoint-preserving
   profile witnesses and an infinite-dimensional perturbation family.

## Synthesis

Frames 1--4 agree on the same wall: the current physical language does not
contain the dynamics or semantic map that a positive derivation would need.
Frame 5 directly reaches the auditor's blocker without importing the target.
It is therefore the selected dramatic-step route.
