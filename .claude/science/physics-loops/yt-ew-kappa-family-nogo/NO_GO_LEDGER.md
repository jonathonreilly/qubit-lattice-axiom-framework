# No-Go Ledger

- `K_EW(kappa_EW)` is exact rational algebra for fixed `kappa_EW`.
- Weak-angle preservation holds for any fixed `kappa_EW`, so it cannot select
  `kappa_EW = 0`.
- CMT-style common scaling cannot select `kappa_EW`.
- Historical agreement at `kappa_EW = 0` is diagnostic, not derivational.
