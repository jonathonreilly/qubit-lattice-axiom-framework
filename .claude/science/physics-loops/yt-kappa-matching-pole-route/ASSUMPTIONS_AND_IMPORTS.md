# Assumptions And Imports

## Minimal Premise Set

- A strict single-pole model class for rows `C_ss`, `C_sH`, and `C_HH`.
- Positive pole amplitudes `A_s`, `A_H` and common mass `m`.
- Algebraic field/source rescalings `s -> mu s`, `H -> lambda H`.
- Existing repaired Y_T color family `K_Y(kappa_Y) = 8/9 + kappa_Y/9`.

## Forbidden Imports

- `H_unit` or H-unit-to-top matrix elements.
- `yt_ward_identity` or `y_t_bare`.
- Observed top mass, observed top Yukawa, or PDG comparators.
- `alpha_LM`, plaquette/u0, Planck, alpha_s, package-v, or fitted selectors.
- Treating common-pole evidence as canonical LSZ normalization by wording.

## Imports Exposed

Pole-row evidence still requires these independent positive gates before it
can support full Y_T closure:

- accepted same-surface source/action authority;
- canonical `O_H`;
- canonical scalar LSZ normalization;
- strict source-Higgs rows or a W/Z response after the normalization theorem.
