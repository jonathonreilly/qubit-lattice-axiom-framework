# Goal

Test whether PR230's strict source-Higgs pole rows can close the missing
Y_T normalization bridge by themselves.

Outcome target: best honest status. Positive closure is allowed only if the
pole-row algebra fixes absolute scalar/source normalization and selects
`kappa_Y = 0` without importing `H_unit`, Ward identities, observed targets,
or fitted selectors.

Actual outcome: narrow no-go. Pole rows and Gram purity certify common-pole
support, but preserve a source/Higgs rescaling freedom. They cannot select
absolute normalization or `kappa_Y = 0` without an independent canonical
`O_H`/LSZ theorem.
