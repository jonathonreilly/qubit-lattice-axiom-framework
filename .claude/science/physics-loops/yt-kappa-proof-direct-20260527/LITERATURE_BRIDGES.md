# Literature Bridges

Literature was used for route discipline, not as proof input.

- SM/flavor literature treats Yukawa magnitudes as the flavor puzzle, so pure
  gauge structure should not be expected to fix them.
- Feynman-Hellmann lattice/QFT literature supports the same-source response
  route once a source generator is supplied.
- Information geometry literature supports Fisher source units after a
  statistical model/source statistic is accepted.
- Representation theory supports the scalar-multiple boundary: symmetry fixes
  rays/Hom spaces, not physical scalar normalization by itself.
