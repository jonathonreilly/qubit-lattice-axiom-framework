# No-Go Ledger

| No-go | Applies here? | Scope |
|---|---|---|
| Source-Higgs pole-row normalization no-go | Yes | Pole rows and Gram purity alone cannot fix absolute scalar/source normalization. |
| Color projection correction no-go | Yes | The SU(3) channel-count packet does not derive `kappa_Y = 0`. |
| Top-response coefficient underdetermination | Yes | Carrier alignment plus W/Z denominator response leaves the top numerator coefficient free. |
| Finite per-site bosonic CCR obstruction | Yes | A literal per-site bosonic canonical commutator cannot hold on finite qubit blocks. |
| BRST/ST lambda non-selection | Boundary | Gauge identity does not select every allowed scalar invariant coefficient. |

None of these is a global no-go against strict top response, direct correlator
measurement, or a future same-surface canonical `O_H`/LSZ theorem.  The new
top-response underdetermination no-go only blocks the shortcut from W/Z
denominator support to the missing top numerator.
