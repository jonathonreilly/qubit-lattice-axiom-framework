# Assumptions And Imports

## Used As Support

- `LSP_PROJECTIVE_DERIVATION_FROM_NAIMARK_FRAME_NARROW_THEOREM_NOTE_2026-05-22.md`
  supplies `K_P=P` only for a supplied sharp projector in the canonical frame.
- `YT_LSP_SIGNED_RECORD_SOURCE_READOUT_SUPPORT_NOTE_2026-05-24.md` supplies
  the signed Pauli readout carrier for the source record.
- `YT_C3_SPECTRAL_TOP_PROJECTOR_ROUTE_SUPPORT_NOTE_2026-05-27.md` keeps C3
  spectral projectors live if dynamics supplies a nondegenerate operator.
- `YT_C3_SOURCE_DIRECTION_SELECTION_NO_GO_NOTE_2026-05-27.md` establishes that
  unit Fisher normalization does not select the C3 tangent direction.

## Not Imported

No `H_unit`, Ward identity, `y_t_bare`, observed masses, PDG targets,
`alpha_LM`, plaquette/u0, Planck, alpha_s, or fitted selector is used.

## What If Wrong

If LSP did select a source direction, the theorem would need a rule mapping a
supplied projector/instrument to a unique source-generator tangent. The cited
LSP theorem does not contain such a rule; it explicitly starts after the
projector is supplied.
