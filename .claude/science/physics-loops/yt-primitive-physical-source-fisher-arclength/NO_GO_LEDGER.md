# No-Go Ledger

## Raw Primitive Unit Source/Action No-Go

The current support stack does not select a raw physical source coordinate
`h`.  The family

```text
S_h^(lambda) = S_0 - h lambda O_top
```

preserves projective readout and normalized carrier rays while changing the
raw coordinate coefficient.

This block does not refute that no-go.  It proves that the coefficient per
unit Fisher arclength is invariant under this raw coordinate rescaling.

## LSP Source-Scale Blindness

Ideal projective readout supplies signed outcomes and probabilities, but it
does not select an action-source scale.  This remains true.

## Old Ward/H_unit Route

The old route defined the Yukawa readout by the `H_unit` matrix element.  This
block does not use that route or any `y_t_bare` definition.
