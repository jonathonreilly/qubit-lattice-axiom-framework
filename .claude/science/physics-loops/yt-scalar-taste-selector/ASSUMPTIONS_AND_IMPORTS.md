# Assumptions And Imports

## Explicit Assumptions Tested

- The target bridge is specifically the standard one-Higgs / scalar-taste
  condensate top-Yukawa route.
- The Higgs/scalar is color singlet.
- A local quark bilinear color insertion can be represented by a matrix
  `M_color`.
- `kappa_Y = 0` corresponds to excluding the singlet/disconnected color
  channel in the repaired family `K_Y(kappa_Y)=8/9+kappa_Y/9`.

## Implicit Assumptions Surfaced

- "Connected scalar fluctuation" is not the same statement as "traceless
  color insertion."
- VEV subtraction removes a c-number expectation value, not the identity
  color matrix in the source derivative.
- A nonzero color-singlet insertion invariant under SU(N) is proportional to
  identity.

## Import Discipline

No observed values, fitted selectors, PDG comparators, or Ward/H_unit
definitions are used. The proof is finite-dimensional color algebra plus the
route's own one-Higgs color-singlet premise.

## What If We Are Wrong

- If a future theorem proves the physical scalar is a nonzero color-adjoint
  object, this no-go does not apply; but that would no longer be the ordinary
  one-Higgs color-singlet top Yukawa.
- If a future theorem defines `kappa_Y` by something other than the
  color-insertion singlet weight, the present diagnostic does not decide that
  new selector.
- If connected fluctuation is shown to change the color insertion itself from
  identity to traceless, the VEV-subtraction guardrail must be revisited.
