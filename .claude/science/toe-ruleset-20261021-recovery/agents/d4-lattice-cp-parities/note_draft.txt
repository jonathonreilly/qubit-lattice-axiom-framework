## 1. Exactness [T]
- C = g0 g2 satisfies C g^T C^-1 = -g and C g5^T C^-1 = g5. The fixed-point symbol satisfies C D*(p)^T C^-1 = D*(-p) (2e-15).
- Slab (Ls = 8, mf = 0.1). C alone needs the reflection s -> Ls+1-s, and so does P (d4-zoom-chirality 2c). Their composite CP_g needs none:
  M D5(p)^T M^-1 = X^-1 D5(-g p) X with M = C S_g^-T, for all 576 improper g (3e-15). The J version is off by >= 0.51.
  The wall-fermion operator obeys M D_eff(p)^T M^-1 = D_eff(-g p).
  So CP maps the near wall to itself: it is a new symmetry, not the failed face swap. (This is the standard domain-wall fact that P and C each reflect s and CP does not.)
- Far wall. psi -> W psi^+ with W_int = 1 (occupation-basis conjugation) is Spin(10)-covariant: -t^T = s_a s_b t, an outer automorphism with R = diag(+,-,...,+,-), as 16 -> 16bar requires.
  It maps B_a -> sum_b U_ab B_b^+ with U unitary for any unitary Weyl block, so the Spin(12) Casimir is CP-invariant.
- Cayley 4-form. It is invariant under the Fock particle-hole with W4 = C S^-T, and det W4 = 1 for all 576 lifts (4e-14).
- Links. The improper g permute the 24 D4 roots, so the plaquette action is invariant. eps F F is P-odd and C-even, so CP forbids theta_gauge except 0 or pi.
- Informational. The Luscher split (P_hat on psi, P on psibar) is not CP-symmetric: the image projector differs from P_+ by 0.85, cf. Fujikawa-Ishibashi-Suzuki. The D4 route uses the slab, which is exact.

## 2. Channel parities [T]
- With the family index Y (symmetric for 10 and 126, antisymmetric for 120), the CP image of channel k is channel k with Y -> Y^*. It carries one common factor (phase x wedge^k R) that is the same for k = 1, 3, 5.
- The pattern is (+,+,+), and it is unchanged when W_int is multiplied by a random Spin(10) element.
- The (-1)^(k(k-1)/2) of the menu's (+,-,+) is cancelled by the antisymmetry of Y120.
- So "mass-feeding channels enter with intrinsic CP parity (+,-,+)" is FALSE on the register: all Yukawas are real in the CP basis.

## 4. Loop quality [E]
- Hermiticity is unprotected after spontaneous breaking. The one-loop estimate is theta_bar ~ (1/16 pi^2) lambda_mix y^2 sin phi ~ 6e-3 lambda_mix (supplied scale from parity/Hermitian-mass literature: Babu-Mohapatra, Barr-Chang-Senjanovic, Hall-Harigaya).
- So theta_bar < 1e-10 needs lambda_mix < ~1e-8, or a protection. This is order of magnitude only.

## Verdict (pre-set criteria, corrected definition): FAIL
- Lattice CP IS exact and wall-preserving. This is new on D4 and worth keeping. It gives theta_gauge in {0, pi}, and with CP-even vacua it gives J = 0 (the record-arrow death, as in #10068).
- The channel parities are uniform (+,+,+), so P1's law does not hold as stated.
- What survives is a conditional: if CP breaks only in the 120 vacuum, then the masses are Hermitian, J is nonzero, and theta_tree is 0 or pi with one unfixed bit, plus a loop-quality problem.
- No CL text is proposed. A candidate for later is a vacuum-alignment rule that keeps the CP-odd vacuum in antisymmetric channels; it is unforced and UNTESTED.
