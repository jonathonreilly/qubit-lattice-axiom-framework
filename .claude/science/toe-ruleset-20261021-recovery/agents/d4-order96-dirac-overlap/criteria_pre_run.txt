Question. Keep the Qubit axiom (one complex fermion mode per D4 event). The parent probe (d4-chiral-rotations-only, C7) found
that order-96 protected rotations-only subgroups G of W(F4), realised nonsymmorphically (x -> A x + tau_A, no fixed event class)
with U(1) phases putting the 16-event module in the spinor class, can contain S+ alpha and S- alpha together: a Dirac block at
P = 0 is rep-allowed. Is it buildable, chiral via the overlap, and protected at loop level?

   representation with U(z) = -1. Locate S+ alpha and S- alpha (isotypic projectors from characters). Need: each with
   multiplicity exactly 1, S+ and S- irreducible and inequivalent on Ghat.
