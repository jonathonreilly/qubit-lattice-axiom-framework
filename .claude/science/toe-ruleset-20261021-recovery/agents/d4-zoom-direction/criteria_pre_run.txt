d4-zoom-direction: pre-registered criteria (written 2026-10-26 BEFORE any computation in this folder)

Question. The PR #10110 table (agents/d4-predictions-recompute) labels rows by a rung count n and reads rung n as an
NN start kernel on a lattice 2^n finer than the events, blocked n times. The events are the smallest object.
Which kernel sits on the events under the finite-rung decision, and what physical dim-8 matter LIV follows?

Readings.
 (A) NN start ON the events; rungs = coarser descriptions (zoom up).
 (B') The event weight IS the n-rung kernel G_n = R^n(G_NN), R = the factor-2 zoom map acting on functions on the
      event Brillouin zone (the "n-step truncation of the fixed-point series"); no finer lattice is assumed.
 (B) Exact fixed point on the events (rejected by the finite-rung decision; quoted only as the n -> inf limit).

Pre-registered checks (bars fixed now):
 Z1 [T+F] Reading A: physical dispersion is rung-invariant. For a fixed physical momentum K (event units), the n-times
    blocked description's light pole satisfies E_n(2^n K)/2^n = E_0(K) to rel 1e-9 (n = 1, 2, 3, body ray); hence the
    physical beta is beta_0 for every n (rung n in cell units = beta_0/16^n is a units change only).
 Z2 [T] G_n is a function on the EVENT Brillouin zone: G_n(q + b) = G_n(q) for b in 2 pi D4* (generators 2 pi e_1 and
    pi(1,1,1,1)), rel 1e-12, n = 0..3, random q. (So R^n(NN) is an event kernel; the finer lattice is a summation
    device, not a degree of freedom.)
 Z3 [F] D_n = G_n^-1 is exponentially local on the events: on an antiperiodic D4 event torus (Z^4 side 8, even sites),
    D_0 vanishes beyond the roots to 1e-12, and for n = 1..3 the shell maxima of |D_n(X)| fall monotonically out to
    the torus half-width with a fitted decay rate > 1 per unit length (D4 coordinates).
 Z4 [F] Event-scale dim-8 coefficient read from the event kernel's own slice correlator (event slices along a root):
    beta_n(event units) * 16^n / beta_0 = 1 within 1e-2 for n = 1, 2, 3; beta_0 (body) = -0.1185 within 1e-3 rel.
    Limit n -> inf: |beta_n| -> 0 geometrically (ratio 1/16 per rung), never 0 at finite n (T1 of zoom-fixed-point-tick).
 Z5 [E] Thresholds for both readings (photon unzoomed, b_gamma = -7.41e-3 body): reading A gives the n = 0 row for every
    n (gamma -> e+e- 1.9e20 eV, wall 9.7e20 A eV); reading B' reproduces the #10110 rows to 1e-2.
 Z6 [T] decision-text test: the finite-rung decision's stated cost ("ghost weight < 1e-14 at rung 2") is a property of
    the EVENT weight only under B' (under A the event-scale NN pair keeps its rung-0 position and weight).

Verdict rule.
 - If Z1-Z4 pass and the decision text implies B': TABLE STANDS (numbers), with the sub-event reading of #10110
   corrected; n stays a supplied integer.
 - If the decision text implies A: TABLE CORRECTED (only the n = 0 row is physical).
 - If neither reading delivers the LIV benefit without sub-event structure: DECISION NEEDS REVISION.
Deviations will be reported, not hidden.
