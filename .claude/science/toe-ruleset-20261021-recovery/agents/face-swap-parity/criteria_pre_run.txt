Question: is an exact face swap P_slab (walls exchanged, chirality flipped) a rule symmetry, and does it give
theta_bar = 0 at tree level with J != 0 (Barr-Chang-Senjanovic shape) after spontaneous breaking only?

Predictions / pass criteria (each is a runner line; a mismatch is a RESULT, recorded, not tuned away):
P1  On the working Wilson domain-wall slab (m = 0.6, Ls = 16), P_slab = (layer reversal) x (3D inversion k -> -k)
    x (spinor matrix S) is an exact symmetry for S = beta (commutes with beta, anticommutes alpha_1..4).
    Residual ||P H(-k) P^-1 - H(k)|| < 1e-12 at random k. It maps near-wall Weyl to far-wall Weyl, flipping Gamma.
P2  With a constant link background A, P_slab is a symmetry only if A_i -> -A_i: on gauge fields P_slab acts as

    projector (gamma5_hat -> -gamma5_hat). Expect: the history-level chiral selection breaks P_slab explicitly.
P4  The far-wall-only gapping term breaks P_slab explicitly (nonzero commutator). Expected.
P5  Toy with ONE gauge field (adopted Links clause): P-symmetric mass matrices M(h,h') = sigma M(h',h)^dag sigma with
