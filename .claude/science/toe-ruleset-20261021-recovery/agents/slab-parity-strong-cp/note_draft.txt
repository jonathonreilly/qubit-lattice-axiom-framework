# Slab-reflection parity restates the face swap: its internal twists leave the mirror-vertex phase unforced, and the antiunitary swap allows theta

Claim type: bounded_theorem. Labels: [T] exact, [F] finite diagnostic, [E] estimate with supplied numbers, [S] reading.

Repo first. origin/main has no Barr-Chang / Babu-Mohapatra / mirror-parity note. Open PR #10079 (face-swap-parity) is

## The proposal as stated (w2, approach 2)

- Rule: S_w2 = (slab reflection z -> L - z) o (D-parity in Spin(10)) is exact, broken only by the far wall's gapping.
- Claim: theta is P-odd so bare theta = 0; S_w2 relates near-wall Yukawa phases to far-wall coupling phases, so
  theta_bar = theta - arg det(Y_u Y_d) - kappa arg lambda_4 cancels pairwise and the CKM phase sits freely in Y.
- Kappa check: compute kappa; does S force arg lambda_4 = -(1/kappa) arg det(Y_u Y_d), exactly or mod pi/2?

## Is it a restatement of #10079?

The only element #10079 lacked is the internal twist X = D. The runner tests X = D and the two other twists the brief
named (C, and the antiunitary K the FREEZE slab would need), plus the Floquet 0 <-> pi exchange.

1 [T] kappa. One 16 holds 16 Weyls; its colour content is 4 triplets/antitriplets (one per SU(4) quartet), so
  sum 2T = 4. A common mirror phase alpha shifts theta by 4 N_f alpha and the charge-4 vertex by 4 alpha, so
  |kappa| = N_f = 3. The Z4 generator (alpha = pi/2) shifts theta by 2 pi N_f: anomaly-free, so theta_bar is continuous
  in arg lambda_4 (no pi/2 quantisation). Same as #10079 D1-D2. (w2's literal formula "anomaly of the Z4 / 4" gives
  0 mod 2 pi; the continuous mirror U(1) is the right object.)

2 [T] Any wall swap, any twist. For X in {1, D-like on-site u(4), C, K} the image of H_far = e^{i phi} Omega_far + h.c.
  commutes with every far mode (near-local), has zero overlap with every bilinear (degree 4 is kept), and differs from
  H_far (S explicitly broken). Its coefficient is the near-wall vertex with phase phi (X = 1), -phi (C, K) or
  phi -/+ arg det u (D). This is the general reason: a wall swap keeps locality and fermion degree, so it can never map
  the quartic lambda_4 onto a bilinear Yukawa. w2's "P relates near-wall Yukawa phases to far-wall coupling phases"
  is false for every twist. (w2's kill condition is met in substance: nothing cancels the vertex phase.)

3 [F] Making S exact (adding the image) gaps the light wall: ground degeneracy 16 -> 1. So exactness and a light 16
  are incompatible; the vertex must be an explicit breaker, as in #10079 A7/D3.

5 [E] With one gauge field, Y' = Y^dag does cancel the Yukawa phases (arg det Y det Y' = 1e-16), so
  theta_bar = -N_f arg lambda_4 exactly, and arg lambda_4 is unconstrained. Fraction of phases with
  |theta_bar| < 1e-10: 1e-10/pi. FAILS by ten orders without a tuning.

4 [T] Theta-density signs (8^3 spectral grid; su(3) algebra for C and D):
  - P_slab: odd. P_slab o D: odd (tr E.B is invariant under any automorphism). P_slab o C: odd (C: B -> -B^T).
  - P_slab o K: EVEN. K (A even, E odd in the A basis) is T-like, so the composite is PT-like and allows theta.
    The FREEZE slab (light in copy q = 2, mirror in q = 1) can only have the antiunitary swap (#10079 A, [S]), so on
    that slab the swap does not even remove the bare theta. If K alone were exact, K o (P_slab o K) = P_slab would be
    exact too, which the copy mismatch forbids; so nothing protects theta there.
  - Floquet 0 <-> pi exchange: even. floquet-pi-slab C3 puts the light q 2 at 0 AND pi on the SAME near wall with the
    SAME hand; the exchange preserves wall, hand and the link register, so it is no parity at all.

6 [T] D vs the register. D maps the 16's charge set to itself, but D(T3L) = T3R and D(Y) lie outside span{T3L, Y}
  (residual 0.80). With an SM-only register S_w2 does not exist; with Spin(10) gauged D is inner and S_w2 is
  gauge-equivalent to P_slab; with a left-right register it is new, but item 2 still applies (locality, not group).

Conclusion: DUPLICATE. S_w2 is #10079's P_slab up to an internal twist, and no twist changes what decides the question
(locality and fermion degree of the mirror vertex). Within the adopted rules (one gauge field, SMG mirror): FAILS.

## Leading radiative theta_bar where the tree-level zero does hold (#10079's BCS shape, X1)

This re-qualifies #10079's route, not w2's: wall-local electroweak registers, shared colour, mirror heavy through its own
Higgs (no lambda_4, so kappa does not enter).
- 7a [T] Every word of length <= 5 in H_u = Y_u Y_u^dag, H_d = Y_d Y_d^dag has a real trace; length 6 is the first
  CP-odd invariant.
- 7b [T] Covariance forces delta Y_u = P(H_u, H_d) Y_u, so delta theta = Im tr P: no 1/y enhancement from renormalisable
  spurions (checked: arg det((1 + eps W) Y) = eps Im tr W + O(eps^2)). Mirror spurions are complex conjugates, so mirror
  words carry the opposite sign; they cancel up to the scale dependence of the coefficients.
- 7c [E] Supplied inputs (running masses at mu = m_t, PDG Wolfenstein; J = 3.12e-5): Im tr(H_u H_d H_u^2 H_d^2) =
  1.53e-24, det[H_u, H_d] = 3.1e-24. With any loop factor <= 1, theta_bar_rad <= 3e-24, below 1e-10 by 14 orders.
  The binding leak in that shape is therefore #10079 E1-E2 (P-even cutoff operators, v' < ~1e11 GeV), not loops.

## Verdict

DUPLICATE of #10079 section D, and FAILS within the adopted rules for every twist tested (D, C, K, Floquet 0/pi).
- |kappa| = 3, not quantised; arg lambda_4 is unforced, theta_bar = -3 arg lambda_4 generically O(1).
- The antiunitary variant is worse: it does not forbid the bare theta.
- The only working shape stays #10079's X1 (wall-local electroweak registers), whose radiative leak is 3e-24.
No CL text is proposed: no new rule works.

[S] One door seen, not tested: if lambda_4 were the expectation value of a charge-4 condensate of a mirror U(1) that is
otherwise exact, its phase would be a QCD-anomalous Goldstone, i.e. an axion with f ~ the mirror gap, and theta_bar
would relax dynamically. That is a Peccei-Quinn route, not parity. It needs (i) the light-mirror bilinears of #10079 B
to be absent (they break the separate mirror U(1)), (ii) the condensate to coexist with SMG's no-bilinear gap, and
(iii) an axion-quality bound. It is a candidate next probe.
