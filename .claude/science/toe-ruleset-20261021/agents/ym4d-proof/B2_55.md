### 2.3 Lemma LS (lattice sums; PROVEN-HERE, elementary; exact check b2_55_1)
Let 0 < h ≤ 1 with T/h ∈ ℤ, a ∈ ℝ⁴, G := (hℤ⁴ + a) mod T ⊂ (ℝ/Tℤ)⁴, p ∈ (ℝ/Tℤ)⁴, d_T := the ℓ¹ torus distance. Then for μ > 0:
  **Σ_{z∈G} e^{−μd_T(z,p)} ≤ [2/(1 − e^{−μh})]⁴ ≤ 16(1 + 1/(μh))⁴ ≤ 16·h^{−4}(1 + 1/μ)⁴.**
*Proof.* d_T(z, p) = Σ_ν min_{n∈ℤ}|z_ν − p_ν + nT|; choosing the minimising image coordinatewise maps G injectively into the
infinite grid hℤ⁴ + a′ with |z̃ − p|_1 = d_T(z, p), so the torus sum is ≤ the grid sum, which factorises over the four coordinates.
In one coordinate the grid points t_0 + ih (i ∈ ℤ, t_0 ∈ [0, h)) have distance t_0 + ih ≥ ih to the right (i ≥ 0) and
(i + 1)h − t_0 > ih to the left (i ≥ 0), so the 1D sum is ≤ 2Σ_{i≥0}e^{−μih} = 2/(1 − e^{−μh}). Finally e^x ≥ 1 + x gives
1/(1 − e^{−x}) ≤ 1 + 1/x, and 1 + 1/(μh) = h^{−1}(h + 1/μ) ≤ h^{−1}(1 + 1/μ) for h ≤ 1. ∎
**Applied to link positions.** For a fixed orientation ν, the coarse positions of the level-j ν-links form such a G with
h = h_j = L^{−(k−j)} — under Convention C (block-centre roots), under Convention K (lower corners), and for link midpoints alike
