### 1.3 The source class — SAME class; the source NORM does NOT match as stated (finding), and the mismatch is repairable
**Class.** Both are Setting LIN^cc (BFT_B §27.1: plain currents need not be level-wise co-closed; only Ξ^TS = 0, i.e.

**N(S) is not bounded by C·N^{(σ)}(S) uniformly in k.** Exact example (derivation, no numerics): k ≥ 2, one plain current at
level 1, j_1 := (Q^{(1→k)})^T(c e_μ) (a constant level-k current pushed down), all other slots zero. d*j_1 = 0 (d*Q^T = ev^Td*

"‖x_E‖ ≤ C·N(S)" does **not** give a k-uniform "‖x_E‖ ≤ G·N^{(σ)}(S)". GF-E **as stated does not deliver (GV^{(σ)})_Γ.**
(The response to this source is O(|c|), not O(L^{θ(k−1)}|c|): its top residual is c/κ_{k−1} exactly — the one-level case of
