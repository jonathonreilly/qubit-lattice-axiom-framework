## Independent mathematical assessment

**Gaussian rank and normalization.** The exact primary passage, Kirk v4 Lemma 3.26, PDF p.20, allows arbitrary finite-dimensional core spaces, uses a weighted block operator row, and declares constants uniform in core sizes. The group is fixed: enlarging the core space is not a large-rank gauge-group limit. For the two-core family with off-diagonal block `t I_d`, every hypothesis of the unmarked example is met, while direct rational elimination gives determinant `(1-t^2)^d`. The normalized density ratio consequently contains `(1-t^2)^(d/2)`. Direct Gaussian integration confirms its normalization. Omitting it changes the integral; a once-only normalization ledger cannot turn its mode count into a dimension-free estimate.

The trace expansion itself exposes the problem: `Tr K^2=2 d t^2`. Rooting a cyclic word changes combinatorial multiplicities, but cannot remove the dimension in a matrix trace. Corollary 4.2, pp.23–24, retains `sum Tr(C B_i)` in its numerator; an operator-norm denominator does not eliminate that numerator. The note correctly treats these as one mode-count issue.

The scalar caveat remains essential. A norm controlling the value at the origin yields the stated contradiction directly. If a different intended norm quotients field-independent scalars, the supported conclusion is failure of the printed determinant inference and a missing exact normalization treatment. This review does not silently impose a norm definition or identify the example with the actual Karcher optical matrix. The marked example is now admissible, but its derivatives are derivatives of the Gaussian density normalizer, not established physical source cumulants. A normalized Gaussian partition function can still have cancellations with the rest of its score.
