The required correction is a statement, not a new proof. Choose a concrete B_j and its global/domain completion, or explicitly quantify over a defined admissible class of maps with the required covariance, locality, symmetry and observable matching.     Xi^H_(j,h)(z) = Z^H_return(j,h,z) / Z^H_reference(j,h,z) != 0,
    log Xi^H_(j,h)(z) = sum_X E^H_(j,h)(X,z),
    ||E^H_(j,h)||_(specified source/polymer norm) <= epsilon_j,

with a specified epsilon_j compatible with the existing induction/flow budget, specified constants and radii independent of j, total depth, volume and admissible history, and an explicit rule that the complete output belongs to the next step's input class. This is a schematic checklist for the revision, **not a claimed theorem or a choice of the correct norm**. The author must tie each quantity to the actual HIST/return/source consumer, not assume the terminal target as an unnamed hypothesis. For H2, state how the collar width covers the required halos and how crossing activities enter the same bound.
