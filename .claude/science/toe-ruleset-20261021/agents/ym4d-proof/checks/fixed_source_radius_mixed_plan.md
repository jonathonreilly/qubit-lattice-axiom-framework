# Supplemental numerical registration for the mixed-decoration proof

Registered after the first 46 checks and the written mixed proof, before this
new implementation. It does not change any earlier threshold. These are
source-exposed exact algebra controls for the newly completed interface.
Use the same resource gate, niceness, thread, memory and runtime limits.

1. For an object with three scalar coordinates, incoming leg at coordinate 0,
   enumerate all child distributions through six children. The labelled-tree
   child factorial, endpoint-distribution multinomial and coordinatewise
   moment factorials must leave exactly l_0+1 for every distribution. Deleting
   the incoming-leg factor must disagree at distribution (1,0,0). The sum
   must match the generating function
   (1-x_0)^(-2)(1-x_1)^(-1)(1-x_2)^(-1) through total degree six.
2. In the three-coordinate even product measure, use bounded decoration
   U=lambda x_1^2 x_2^2/p^4 and Gaussian pair e x_2 x_3. Extract [lambda e^2]
   log Z independently from the direct finite exponential/log series and
   the one-object forest with its exact scalar moments. Both must equal
   -m_2^2(m_4-m_2^2)/(2p^4) as a symbolic identity. Treating the decorated
   object and the 2--3 pair as compatible despite their shared coordinate
   must fail this identity. Deleting the attached component must also fail.
3. Specialize to the actual normalized truncated Gaussian at p=2. Its
   coefficient must be nonzero, negative, and agree between the formula
   and direct integrated finite series to absolute error <1e-45.
