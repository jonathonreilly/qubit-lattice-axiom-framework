# LFPRICE numerical criteria

No numerical experiment is planned. Claims are proved analytically or
labelled OPEN/ARGUED. Hash, path, link and source-stability checks are
mechanical bookkeeping and do not validate the mathematics.

If a numerical experiment becomes necessary, add its exact statements,
domains and thresholds here before creating its script. Execute only
with a numerical lock, working nice priority, all BLAS/OMP threads set
to one, memory below 1 GB, load below 8 and at least 30% memory free.
No process pools. A blocked guard is reported, never bypassed. The
initial sandbox priority probe was blocked; no numeric execution follows.
