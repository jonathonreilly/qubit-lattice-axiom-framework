# LGF verification scope

Written before any LGF numerical script. Numerical checks are optional and
are not selected for this execution. There are no numerical acceptance
thresholds, numerical proof inputs, or numerical scripts.

Required written-proof checks: exact graph-Laplacian normalization; all
constants explicit; legitimate Fourier integration by parts; zero-frequency
alias accounting; uniform bounds for every integer T with nonempty stated
domain; explicit orbit grouping and quadratic coefficient; origin-crossing
stencils; a full order-zero counterexample; exact curvature-kernel signs and
consumer conventions. Independent review must identify its source hash and
end with VERDICT: LAND or VERDICT: HOLD.

Any later numerical experiment would require a new criteria revision before
its script and all resource guards in the author brief. Floating-point evidence
would remain diagnostic. The present work does not rely on it.
