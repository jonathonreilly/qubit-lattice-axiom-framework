# MGX numerical criteria

No numerical experiment is proposed or executed in this probe. The resource
preflight rejected `nice` with `Operation not permitted`; the guard is not
weakened. Consequently there are no numerical thresholds, numerical PASS
counts, simulations, fitted parameters, or runner claims. Exact constants
in MGX are derived in the written argument and checked analytically by the
independent reviewer. Hashes and link/scope checks are bookkeeping only.

Any later numerical experiment requires new predeclared statements and
thresholds here before its script is written, and a successful resource/lock
preflight with nice, single BLAS threads, memory below 1 GB, load below 8 and
at least 30% free memory. This file does not authorize bypassing those rules.
