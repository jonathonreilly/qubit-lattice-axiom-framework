## Mathematical falsifiers

1. CJ3–CJ8 fail if independent matrix-product Taylor algebra changes a sign,
   factor, normalization, polar/determinant contribution through degree four,
   or a hidden source term on the actual centered paired S4 paths.
2. CJ11 fails as stated if TU-3 lacks a uniform periodic holomorphic domain,
   if the actual defect is not holomorphic and closed there, if a harmonic
   component survives at momentum zero, or if one admissible lift does not
   have both weighted absolute row and column bounds with its stated density.
   The one-form family lemma will be checked analytically, not by samples.
3. CJ12/CJ17 fail if coefficientwise anchoring, weighted summation, composition,
   or scale/density counting requires a stronger unprovided input. A finite
   lattice test cannot establish depth-uniformity.
4. CJ13–CJ16 fail if the log-coordinate current is confused with a right
   current, if the endpoint half-factor/sign is wrong, if an intermediate
   polar/BCH source is absent, or if ordinary co-closedness is substituted for
   the actual covariant identity. Check unequal kappas and n>=2 if feasible.
5. The conditional CJ18 implication fails if a further unproved inverse,
   harmonic lift, uniform strip, or stronger kernel norm is necessary. CJ18
   itself remains OPEN. A finite-u one-step covariance is not an all-depth
   hidden inverse, and the tree phase is not the full finite-u density.

## Prospective independent controls

Build periodic four-dimensional paths from their geometric definition, with
integer offsets and labelled positive links; do not import author helpers.
Use noncommuting SU(2) data, explicit counting adjoints and a gauge-completed
linear stationary solve. Compute group-product Taylor coefficients by direct
polynomial multiplication or equivalent independent quaternion algebra, and
compare local jet/current identities with direct matrix/group evaluations.
Preserve all failures and implementation revisions. Constant noncommuting
fields are a cancellation/normalization control, never the sole endpoint
detector. Small rectangular quotients test labelled wrapping, not T>=3
uniform estimates. Numerical comparisons are floating-point diagnostics,
not interval proofs.

Initial tolerances: linear/adjoint/gauge and current identities use relative
`1e-8` plus absolute `1e-9`; polynomial coefficient identities use `1e-9`
relative plus `1e-10` absolute. Direct group finite-epsilon comparisons use
observable Taylor scaling or extrapolated error at most `2e-5` relative plus
`2e-6` absolute. A mutation must produce a discrepancy exceeding 100 times
the relevant measured numerical residual and the relevant absolute floor.
Test wrong exchange sign/factor/omission, bracket deletion, path divisor,
endpoint omission, counting-adjoint normalization, source/funnel omission,
and log/right-current half-factor when their fixture has a nonzero witness.
An ineffective mutation is recorded as such and is not counted as evidence.

All finite checks are ancillary to the source-level proof reconstruction.
No audit, retained-status, whole-PR, or negative-route verdict is authorized.
