# Independent uniform soft minimizer review: falsification contract

Recorded after reading the complete US1–US17 source, its input/author receipt,
the consumed linear symbol/strip/intermediate-curvature proofs and repairs, and
FC18–FC20; before creating or executing independent diagnostic code. Author
runner implementations have not been read. Numerical summary values in the
note and author receipt were visible; no outcome is treated as independent.

The target is the actual normalized d=4 rooted S4-prime finite-soft chain with
counting inner products, fixed odd L>=3, kappa in a positive compact interval,
arbitrary depth and periodic top side T>=3. The exact claimed output is FC19
with theta=L^-2 and hence the neutral FC20 implication. Existence, the physical
continuum mass gap, charged exchange, nonlinear neighborhoods and conditional
fluctuation inverse localization are outside this review unit.

Proof falsifiers:

1. A root/straight replacement outside the co-closed residual domain; a missing
   counting factor; a wrong Euler sign; an uncanceled normalized-kernel quadratic
   spread term; a gauge/harmonic inverse on a kernel; or kappa/noise accumulation
   depending on depth invalidates the stated bridge.
2. A missing uniform bound for beta, near-zero Psi, away-from-zero Sigma, a
   nonzero alias pole, omitted fine-curvature denominator condition, failure of
   meromorphic periodic gluing, or nonsummable curvature aliases leaves the
   uniform theorem open. Finite samples and previously reviewed labels do not
   discharge these points.
3. A contour spread that is not the boundary of a uniformly local bounded
   plaquette chain invalidates US14. All winding and endpoint terms must be
   retained. A constant or gradient must annihilate the spread.
4. Both weighted ABSOLUTE norms are required. Replacing the output mesh count
   r^4 by one, discarding torus images, using only an l2 estimate, or using the
   uncurled amplitude L^-s invalidates the FC19-to-FC20 estimate.
5. The hard/soft inverse comparison is checked only on CoCl_0. Extending its
   projected covariance bound to the unprojected root map is not authorized.
6. A full-colour or physical-gap conclusion from the neutral linear theorem is
   a scope failure even if every finite diagnostic passes.

Independent diagnostic plan (no author or predecessor helpers):

- Enumerate actual centered S4-prime paths as signed link chains. Construct
  plaquette fillings by sweeping each axial path edge through the mu-direction
  straight leg. This differs from an adjacent-step-swap filling. Check exact
  integer boundaries for every L=3 ordering, block point and link direction;
  mean subtraction is checked with an integer common denominator. Delete one
  plaquette and omit mean subtraction as mandatory failing mutations.
- Build fine incidence, root-contour and straight matrices directly from links
  with coarse Bloch boundary phases. Check Q_root d=d_c ev, the exact funnel
  difference, constant link transfer, counting sums and co-closed projection.
  The mutation Q/L must fail the integrated-link convention.
- Solve the one-step actual normalized minimization with an explicit root-zero
  gauge KKT constraint, rather than an alias-formula or author LSMR helper.
  Compare its curvature and residual against an independently assembled Schur
  calculation. Keep p=0 harmonic modes separate through the exact zero-energy
  lift. At generic nonzero p, reject an unprojected inverse/comparison.
- Obtain finite T=3 periodic data kernels from these direct KKT Bloch solves,
  including all four source orientations. Compute weighted absolute row and
  column sums separately at m=0.003. The missing-density mutation is the false
  assertion max_column<=max_row for the actual coarse-scaled fine-curvature
  kernel; it must be rejected by the computed witness, not by defining a toy
  kernel. The valid density bound is r^4 times a common pointwise majorant,
  not a universal equality between maxima.
- Check complex strip formulas using analytic transpose continuation (negative
  momentum, not conjugation at complex momentum), including near-zero and
  boundary-face samples, both residual formulas and the fine-curvature zero-

- Check depth-two residual transport and curvature scaling on actual path
  matrices if the direct sparse calculation is practical. Any resource failure
  is preserved and not interpreted as scientific falsification.

Numerical tolerances are 2e-8 for independent stationary/Schur comparisons and
1e-10 for finite matrix identities, with exact integer equality for chains.

or strip analyticity. Any unexpected failure, change to these criteria, or
implementation defect is retained with its original evidence. Read author
