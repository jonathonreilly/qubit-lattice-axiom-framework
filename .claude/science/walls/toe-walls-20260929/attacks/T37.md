Provenance: Claude Sonnet 5.5, same vendor family as the supervisor (Opus 5.5); same-family checks, not independent referees.

## Verdict in plain words
The wall is real: three species families sit at three Koide balances (leptons 0.500, down 0.621, up 0.831), and no mass-convention choice hides it (the b mass alone would need a 55% cut). No route passes it. Running, flavour-blind dressings and charge laws are dead (checked). A Georgi-Jarlskog-type integer link gets the down value from lepton masses (0.618) but was fitted to those masses in 1979 and does nothing for up quarks. The spread is priced: one supplied dial per family.

## The wall (checked)
- Plain: Charged-lepton masses obey Koide's relation; the same measure gives 0.62 for down and 0.83 for up quarks. A rule treating all species alike gives one number, so something must tell species apart; the axioms contain nothing that does.
- Precise: Derive from the axioms plus approved primitives the sector-indexed dial r_s = |b|^2/a^2 of the C3 circulant on hw=1 (Q = (1+2r)/3): r_e = 1/2, r_d = 0.621 +- 0.008, r_u = 0.831 +- 0.002 (common-scale MSbar, mu >= m_t), with a named scheme. Passing: sector dependence without inserted values; per-sector assignments with as many parameters as sectors do not count.
- Real? Yes. Reproduced 0.6211/0.8310; no open PR, doc or archive note closes it. L08-W7 does not belong: a 1.8e-3 shift in r, live only after r is derived (T38/T39). Siblings: T36, T38, T32.

## Test run
- Pre-registered (`T37_scratch/PREREGISTRATION.md`, before any script): S1 real if a +-15% per-entry envelope keeps r_d >= 0.55, r_u >= 0.75. S2 pass if running brings the spread <= 0.10, fail if it stays > 0.20. S4 live if r within 0.02, trial fraction <= 5%. S5 dead if a charge law misses the neutrino band.
- Scripts: `T37_scratch/s1_scheme.py` to `s6_hierarchy.py`; outputs `s*_out.txt`.
- Result:
  - S1 real. Envelope r_d [0.578, 0.662], r_u [0.807, 0.852]; +-30% keeps r_d >= 0.529. Reaching 1/2 needs m_b x0.45 or m_s x2.7 (down), m_t x0.06 (up). Lepton MSbar r 0.5018.
  - S2 fail. SM one-loop, 162.5 GeV to 1.22e19 GeV: spread 0.329 to 0.338, never lower.
  - S3 fail. Tilt exponents -0.172 (d) vs -0.450 (u); shifts 0.032 vs 3.9 GeV.
  - S4 wounded. r_d 0.6181 vs 0.6211 +- 0.0075; phase 0.1051 vs 0.1006 +- 0.0045. 24 of 343 alphabet triples (7.0%) hit r_d, 12 (3.5%) also the phase; none reaches r_u (max 0.778).
  - S5 dead. Linear (T3,Y) law fitted to e,d,u predicts r_nu = 0.71; Q-linear 0.68; neutrino band max 0.379. Order by |Q| (d, u, e) is not monotone in the data.
  - S6 not supported: two-generation truncation errs 0.060 for down (limit 0.03); r is only a recoordinatization of (m3/m2, m2/m1).
- Reading: gauge running is flavour-universal and cancels in r; only route B moves anything, and only the down half. Deviation: the pre-registered outcome rule also listed S6 supported for PRICED; it failed, and I judge the price to rest on S1-S5 alone.
