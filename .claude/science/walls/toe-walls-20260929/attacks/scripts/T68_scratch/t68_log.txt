== rate-linear ledger (b60: one density, K_m = K_s) inside the G-family ==
kappa_m = kappa_s  =>  b = [-2*a]
family member with K_m=K_s divided by the B4 (hypercubic) member = -2*a (pure number => same form)
TT speed^2 = 1 ; b60 beta = 1 ; kappa_m/alpha = 2
In this normalisation kappa_m = 2*alpha in every G-invariant member, so a member with K_m=K_s=K and alpha != K/2 is not G-invariant (it is the c_g-deformed algebra of b112, structure function K/(4 alpha)).
