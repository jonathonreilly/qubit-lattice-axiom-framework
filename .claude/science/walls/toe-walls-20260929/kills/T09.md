## Errors found
1. **"One qubit" means one particle.** Read literally (one M_2(C) per site, many-body), Cycle 40 already has exactly covariant radius-1 one-qubit Clifford QCAs (18 neighbour-coupled skeletons; propagating class L_s H). Re-verified: Q=[[0,1],[1,s]] is symplectic over F_2 and a Pauli string's support grows one step per tick (`kill_qca_one_qubit.py`). The audit warns a two-component coin "is not the primitive onsite M_2(C)". The attack lists Cycle 40 as read but never cites it; it supports "the cone is free" and contradicts the headline.
2. **"Three qubits per site" contradicts the attack's lemma.** Three spin-1/2 copies fall to the spin-1/2 x any-taste lemma, as do one-dimensional (trivial onsite) reps. The only working six-dimensional carrier is the direction rep A1+E+T1.
3. **"With a Hamiltonian the qubit works" is massless only.** The target includes massive modes. Schur: an irreducible carrier makes H(0) scalar, so bands are degenerate at Gamma and (pi,pi,pi) (spread <= 1e-14; `kill_gamma_schur.py`). A mass gap needs a reducible carrier, s >= 4.
4. **"Non-negative odds cannot" is wider than the landed note.** It calls the linear rule "an extra linear-model assumption", puts nonlinear rules and other state variables outside, and denies showing an amplitude layer is "the only possible mechanism". The attack's own table marks nonlinear rules untested, yet the outcome is unscoped. "A non-negative unitary is a permutation" is the wrong lemma for stochastic rules (T2's Perron-Frobenius equality applies). A point-mass signed rule on M_2(C) values has non-negative odds and waves; the gap is that AX:116-123 fixes no form.
5. **Novelty overstated.** D'Ariano-Erba-Perinotti (arXiv 1708.00826, cited in the audit) classifies s=2 in d=3; the attack cites only the 2014 paper. Cubic coin-6 is in the audit.
6. **Census coverage.** `census.py` silently prunes irreps repeated more than twice (11 integer reps, s<=6). I ran four with its solver (3A1+E, 3A2+E, 4A1+E, 3A1+A2+E): no solution; seven not finished. Only the trivial covariance character was tested (my sign-twisted runs at s<=4 found none). Negatives are random-start fits, yet "smallest carrier is six" is stated as fact.
