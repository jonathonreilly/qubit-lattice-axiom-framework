## Errors found
1. **Plain verdict false for 2D.** "Extra qubits plus constraints" holds only for Fock-space encodings; Wen's plaquette rule needs constraints only.
2. **Missed prior art:** `docs/FINITE_BKSF_SIGN_AND_SUPERLATTICE_MARKER_CENSUS_…2026-09-02` (sections E, F; withdrawal paragraph), the same-date π-flux note, `archive/chains/july-car-compiler-era.md` (C235, C237, C240 measurement-prepared vacuum, C244).
3. **Lemma S rate is not derived.** The pre-registered bound treats all (L-4)^2 far modes as pairwise anticommuting on the reference region; nearby far modes also overlap at their own ends. A separated set gives (k4) r=1 impossible for L>=12, r=2 for L>=24, r=3 for L>=36, so r ≳ sqrt(L/2.8), not 0.29(L-4.8). Data to W=10 fit linear growth; rate open.
4. **Lemma S is under-labelled.** Growth is provable for any operator class (checker's sketch). Two disjoint paths put pi(E_ru) in A(B_ref)⊗A(B_u). Then pi(E_vu) = -[pi(E_ru), pi(E_vr)] would have a scalar reference part; a trace forces it to zero, contradicting injectivity.
5. **Test B criterion rewritten.** Pre-registration: PASS = gamma 1 bit. Report: PASS = locally indistinguishable states. The toric-code control itself gives -3 bits (k5), so KP is uncalibrated; the degeneracy count (4 in 2D, 8 in 3D) carries the result. BHV is unitary-only; measurement plus feedforward (C240) is an alternative to "vacuum supplied".

## Corrected plain-language verdict
With one qubit per fermion mode and no constraints, no bounded-range rule works in 2D or 3D; the needed range grows with lattice size (provable; rate open). Bounded-range fermions then need a constrained, ordered vacuum. On Z^2 one qubit per site suffices (Wen plaquette); in Z^3 the repo has an edge-site code (3/8 of sites, fermion density 1/8) and no known one-qubit-per-cell mobile-fermion model. The price is the code, its role pattern and its vacuum sector.
