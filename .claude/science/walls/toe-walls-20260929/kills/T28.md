## Errors found

True spectra (`killD_true_spectrum.py`): j = 2 gives {-1/3 x3, 0 x2}, not -1/5; j = 3 gives min -1.0. The lazy-repair threshold is p_min = 0.5, not 0.1907. The tau_j values are meaningless. Also, the 6 rotations generate a finite subgroup, and j = 4 has eigenvalue exactly 1, so the walk is not ergodic on SU(2). The FAIL verdict survives and is stronger than stated. Symmetric +-lifts give 0 on half-integer spin.
2. **Mislabel.** "Exact transfer operator" is only the temporal-plaquette (electric) factor. The full transfer matrix has a magnetic factor too. The July-1 note calls its object a "gloss".
3. **Not the repo's "next route".** July-1 and the bridge note name a framework-native derivation of the tick law. Reading unit points off a supplied Wilson kernel is not that.
4. **Overstated novelty.** "Nobody has printed g_E^2 at beta = 6" is true only for the R-resolved table. For R = 3 it repeats the known Block 02 gap: eps_3 = 0.8615 vs 2/3. July-1 K4 already says "leading"; 09-02 W1 already says "not the large-beta asymptotic".
5. **Sensitivity.** The factor 7-40 on v_cand holds at fixed plaquette only, which is inconsistent when beta moves. It is 1-1.6 orders of magnitude, not "orders of magnitude".
6. **Test B is a strawman.** No note claims g' = 1 corresponds to beta = 6.
7. **Prior-art search.** It missed Blocks 01/02, the HK uniqueness note and the retained semigroup boundary.
