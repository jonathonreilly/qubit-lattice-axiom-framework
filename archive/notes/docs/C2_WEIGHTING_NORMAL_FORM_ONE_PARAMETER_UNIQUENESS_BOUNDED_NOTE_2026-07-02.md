## Purpose

Block02 separated a supplied readout context into C1 frame data and C2 scalar
weighting data. It also gave the two-cell witness

```text
I_w(x_A, x_B) = x_A + w x_B.
```

This note proves that, on a precisely named finite rational two-cell record
class, that form is not merely an existence witness. It is the unique additive
content-determined normal form, up to the expected degenerate boundary cases.

## Supplied Surface

The two cells `{A, B}` are taken as the algebra-canonical C1 partition supplied
by Block02. This note does not derive C1.

The Record additivity sentence used here is exactly:

```text
Only records are readable. A readout value is determined by record content
alone. For any finite collection of pairwise-disjoint records, scalar readout
`I` is additive, with `I(empty)=0`.
```

That axiom licenses scalar additivity and content-determined record readout.
It does not by itself identify all relevant record content with the two-cell
pair `(x_A,x_B)`; that compression is the named `C2_Q_content` class
assumption below.

Define the finite rational record lattice `L` as follows. Records are content
pairs `(x_A, x_B)` whose cell contents are drawn from the finite rational span
generated by

```text
G = {(1, 0), (0, 1)}
```

under formal disjoint union, where contents add, and formal rational
refinement, where a record may be split into `k` equal disjoint sub-records for
any positive integer `k`.

Thus the supplied combinatorial surface is exactly

```text
L = Q_{>=0}^2.
```

Reachability is finite and exact. Given `(p/q, r/s)` with nonnegative integers
`p,r` and positive integers `q,s`, refine `(1,0)` into `q` equal pieces and
union `p` such pieces to obtain `(p/q,0)`. Refine `(0,1)` into `s` equal pieces
and union `r` such pieces to obtain `(0,r/s)`. Union the two results to obtain
`(p/q,r/s)`. Conversely, starting from `G`, finite unions and integer
refinements preserve nonnegative rational coordinates, so no other contents are
created.

## Named Function Class

`C2_Q_content` is the class of scalar readouts

```text
I: L -> Q
```

with all of the following properties:

1. `I(empty) = I(0,0) = 0`.
2. `I` is finitely additive over disjoint union:

   ```text
   I(R + S) = I(R) + I(S).
   ```

3. `I` is content-determined: if two records have the same content pair
   `(x_A,x_B)`, they have the same scalar readout.

Refinement consistency is not an independent axiom in this class. If a record
with content `x` is split into `k` equal disjoint sub-records, those sub-records
all have content `x/k`. Content-determination makes their readouts equal, and
additivity gives

```text
I(x) = k I(x/k),
```

so each equal sub-record carries exactly `I(x)/k`. Without the two-cell
content-determined assumption, equality of the pair `(x_A,x_B)` would not force
equality of readout values; the compression to that pair is part of the class
definition, not imported as a hidden consequence of Record additivity alone.

## T1 - Normal Form and Uniqueness on `C2_Q_content`

**Claim.** Every `I` in `C2_Q_content` has the exact form

```text
I(x_A, x_B) = u x_A + v x_B,
```

where

```text
u = I(1,0),      v = I(0,1),
```

and `u,v` are rational.

**Proof.** Additivity gives integer scaling. For every nonnegative integer `n`,

```text
I(n,0) = n I(1,0) = n u,
I(0,n) = n I(0,1) = n v.
```

Refinement gives rational scaling. Splitting `(1,0)` into `q` equal pieces
gives

```text
u = q I(1/q,0),
```

so `I(1/q,0) = u/q`; unioning `p` such pieces gives

```text
I(p/q,0) = (p/q) u.
```

The same argument gives

```text
I(0,r/s) = (r/s) v.
```

Finally,

```text
(x_A,x_B) = (x_A,0) + (0,x_B),
```

as a disjoint union on the two cells, so additivity gives

```text
I(x_A,x_B) = I(x_A,0) + I(0,x_B) = u x_A + v x_B.
```

This is a finite Cauchy argument over `Q_{>=0}` only. It uses no continuity, no
real-linearity, and no extension beyond the rational record lattice.

Uniqueness is immediate: the coefficients are forced by the two generators,
`u = I(1,0)` and `v = I(0,1)`.

If `u != 0`, normalizing the overall scale by `u` gives

```text
I proportional to x_A + w x_B,      w = v/u in Q.
```

The boundary cases are:

- `u = 0, v != 0`: the readout ignores `A` and is proportional to `x_B`.
- `u != 0, v = 0`: the readout ignores `B` and is proportional to `x_A`; this
  is the `w = 0` endpoint in the `u != 0` chart.
- `u = 0, v = 0`: the zero readout, with no nonzero overall scale.

## T2 - C2 Freedom Is Exactly One Parameter

On `C2_Q_content`, the nonzero readout space modulo overall nonzero rational
scale is exactly the one-parameter family

```text
{ x_A + w x_B : w in Q }
```

in the chart where `u != 0`, together with the degenerate projective boundary
where `u = 0, v != 0`, represented by `x_B`. The zero readout is a separate
non-projective degenerate case.

Block02's T2 exhibited both `w = 1` and `w = 2` as admissible for the same C1
frame. This note upgrades that supplier specification from "some weighting
freedom exists" to: on the named finite rational content-determined class, the
freedom is exactly the single parameter `w`, plus the degenerate boundary.

Thus a C2 supplier must supply exactly one scalar number, or a rule fixing that
number, on this class. Nothing else in the scalar two-cell normal form is
missing.

## T3 - What This Does Not Cover

This theorem does not cover readouts that are not determined by the content
pair. A record identity or history dependent assignment can give different
readout values to two records with the same `(x_A,x_B)`, and then the
content-normal-form theorem does not apply.

This theorem also does not cover non-rational contents. Extending from
`Q_{>=0}^2` to real nonnegative contents would require an additional regularity
import. Monotonicity or boundedness would suffice for the usual Cauchy
extension, but neither is supplied here.

Finally, this theorem says nothing about within-cell fine structure. C1 handles
partition/frame data. This note takes the two-cell partition `{A,B}` as given
and proves only the scalar C2 normal form on that partition.

The `kappa_EW` wall's missing-rule line quoted in Block02 is:

```text
weighting/readout-bridge rule
```

Conditional correspondence only: if the `kappa_EW` wall is restricted to this
two-cell rational content-determined C2 class, then the missing
"weighting/readout-bridge rule" is exactly the missing choice of the single
parameter `w` or a rule that fixes it. This note does not close the wall and
does not claim the value of `w`.
