## T1 -- SU(3) is not a Hurwitz unit set

**T1 (exact; the classification is external, the dimension and associator
facts are runner-verified):** `SU(3)` is not isomorphic to the unit set of
any normed division algebra.

The standard Hurwitz classification is cited as an external theorem, not
re-proven here: finite-dimensional real normed division algebras are exactly
`R`, `C`, `H`, and `O`, whose norm-one unit sets have real dimensions `0`,
`1`, `3`, and `7`.  The real Lie dimension of `SU(3)` is `8`; the runner
constructs an explicit traceless Hermitian `3 x 3` basis, verifies zero trace
and Hermiticity, and counts real rank `8`.  Since `8` is not in
`{0, 1, 3, 7}`, no Hurwitz norm-one unit set has the same manifold dimension
as `SU(3)`.

The octonion case also fails as an operating group.  The runner derives the
octonion multiplication from the Cayley-Dickson doubling construction (exact
integer structure constants -- no multiplication-table convention is trusted
from memory), verifies that every basis product is a signed basis element
with `e_i^2 = -1` and anticommuting imaginary units, runs a redundant seeded
numerical norm control, and verifies the nonzero associator
`(e1 * e2) * e4 - e1 * (e2 * e4)`.  Thus the historical sentence "SU(3) is the
unit group of no normed division algebra" is an exact obstruction to using
Hurwitz units as the physical `SU(3)` gauge group.

## T2 -- C^3 is not a Hurwitz carrier

**T2 (exact, runner-verified):** the Standard Model color fundamental carrier
`C^3` has real dimension `6`, and `6` is not a Hurwitz dimension
`{1, 2, 4, 8}`; hence no normed division algebra structure exists on the color
carrier itself.

The Hurwitz carrier dimensions are the real vector-space dimensions of `R`,
`C`, `H`, and `O`.  The color fundamental carrier is complex three-dimensional,
so as a real vector space it has dimension `2 * 3 = 6`; because `6` is not a
Hurwitz dimension, the color carrier itself cannot be the proposed normed
division algebra.  This proves only the target mismatch for sub-admission (i).
