## T1 — the Dirac operator defines the grading character (new)

Conjugating the integer adjacency D2 by each of the 1536 elements h of H yields, in exact integer arithmetic, EXACTLY +D2 or −D2 (`G02a`: `np.array_equal(h @ D2 @ h.T, ±D2)`, violations = 0/1536). This defines a per-element sign s(h) ∈ {+1, −1}. Its +1 level set is exactly the ambient group: s(h) = +1 iff h ∈ G_amb, with 768 elements at +1 and 768 at −1 (`G02b`). Multiplicativity is checked directly: over gens_H × H (5 × 1536 = 7680 integer products, all landing back in H by closure) s(g·h) = s(g)·s(h) with 0 failures (`G03a`), so s is a homomorphism H → {±1} whose kernel is exactly G_amb (|ker| = 768, ker = G_amb), i.e. s = χ_sgn (`G03b`). The single-generator seed S_eps·D2·S_eps = −D2 and the group H = ⟨G_amb, S_eps⟩ itself, with its two-coset decomposition, are already landed in the chiral-parity common-sign-orbit note `KCPT_CHIRAL_PARITY_COMMON_SIGN_ORBIT_BOUNDED_THEOREM_NOTE_2026-07-19.md`, which also records that G_amb lies inside the D2-commutant; granting those landed facts, the coset-wise sign pattern is a corollary, and the content T1 adds is the direct exact-integer census over all 1536 elements, the gated multiplicativity, and the identification of the sign with the quotient character — the Dirac operator itself defines the grading character. The claim is discriminating: for h = S_eps the sign is s = −1 and S_eps·D2·S_eps ≠ +D2, the wrongest single entry differing by 2 = 2·max|D2| (`G02c`), and D2 ≠ 0 (max|D2| = 1) so the sign is meaningful and not vacuous (`G02d`).

## T5 — deriving the Unit-20 commutator pins (new)

The Unit-20 commutator [D2, P₁₂₊] factors exactly through the fused-block objects of T4: with K := D2·P⁺ − P⁺·D2, ‖K + Gam·D₂₄‖ = 3.788e-15 (`G07a`), i.e. [D2, P₁₂₊] = −Gam·D₂₄. Because Gam is Hermitian with Gam² = Q₂₄ and D₂₄† = −D₂₄ with Q₂₄·D₂₄ = D₂₄, the positive operator K†K collapses:

  K†K = D₂₄†·Gam²·D₂₄ = D₂₄†·Q₂₄·D₂₄ = −D₂₄² = 4Q₂₄,

a scalar 4 times a rank-24 projector. Every one of the 24 nonzero singular values of K therefore equals √4 = 2 and the remaining 40 vanish — measured directly as 24 singular values within 1e-9 of 2 and 40 at ≤ 1e-9 (`G07b`; sv₁ = 2.000000000000001, sv₂₄ = 1.999999999999998, sv₂₅ = 1.052e-15). The companion max-entry value is a measured lattice-frame quantity, re-pinned but not derived here: ‖[D2, P₁₂₊]‖_max = 0.35355339059327884 against 1/(2√2) = 0.35355339059327373, difference 5.107e-15 (`G07d`). The whole mechanism is sharply contrasted against an unfused constituent — an ind12 (central) projector commutes with the Dirac operator, ‖[D2, P_ind12]‖ = 4.279e-15 (`G07e`) — so the nonzero commutator is a property of the fused pair alone.
