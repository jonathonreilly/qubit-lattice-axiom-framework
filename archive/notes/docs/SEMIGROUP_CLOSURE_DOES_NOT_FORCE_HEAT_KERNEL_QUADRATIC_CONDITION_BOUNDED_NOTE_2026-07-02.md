positive finite-subgroup convolution semigroup closure alone does not force the
heat-kernel `n^2` law.

## T1 -- direct positive semigroup witness on Z_5

Fix

```text
theta_0 = 2*pi/5,
psi(n) = 1 - cos(n theta_0),
c_n(t) = exp(-t psi(n)).
```

Semigroup closure is immediate:

```text
c_n(t1)c_n(t2)
= exp(-t1 psi(n)) exp(-t2 psi(n))
= exp(-(t1+t2) psi(n))
= c_n(t1+t2).
```

The paired runner checks this as an exact symbolic identity.

The underlying positive weights are constructed directly on the finite cyclic
subgroup generated by `theta_0`. Identify that subgroup with `Z_5`, and let `M`
be the symmetric nearest-step stochastic matrix

```text
(Mf)(j) = (1/2) f(j+1) + (1/2) f(j-1).
```

Equivalently, on column probability vectors, `M` sends a point mass to the
symmetric mixture of its two neighboring point masses. Set

```text
A = M - I,
w_t = exp(tA) delta_0 = exp(-t) exp(tM) delta_0.
```

Since `M` is entrywise nonnegative, every term in the finite-dimensional series

```text
exp(tM) = sum_{k>=0} t^k M^k / k!
```

is entrywise nonnegative for `t >= 0`; multiplying by `exp(-t)>0` preserves
nonnegativity. This is the finite `Z_5` positivity argument. It uses only the
matrix exponential of a generator with nonnegative off-diagonal entries, and no
external theorem.

The runner also verifies rational-time samples

```text
t in {0, 1/5, 1/3, 1, 2}
```

by a rational truncated series with a certified scalar remainder bound. At
positive sample times, all five entries are strictly positive. At `t=0`, the
weight is the nonnegative point mass `delta_0`.

Finally, the `Z_5` Fourier modes diagonalize `M`. For the mode
`v_n(j)=exp(2*pi*i*n*j/5)`,

```text
M v_n = ((exp(2*pi*i*n/5)+exp(-2*pi*i*n/5))/2) v_n
      = cos(2*pi*n/5) v_n.
```

Therefore `A=M-I` has mode eigenvalue `cos(2*pi*n/5)-1`, and

```text
widehat{w_t}(n)
= exp(t(cos(2*pi*n/5)-1))
= exp(-t(1-cos(2*pi*n/5)))
= c_n(t).
```

## T2 -- exact violation of the n^2 law

For arbitrary `theta`,

```text
4(1 - cos theta) - (1 - cos 2theta)
= 2(cos theta - 1)^2.
```

At `theta_0=2*pi/5`,

```text
cos(2*pi/5) = (sqrt(5)-1)/4,
```

so

```text
4 psi(1) - psi(2)
= 2(cos(2*pi/5)-1)^2
> 0.
```

Consequently, for every `t>0`,

```text
log(c_2(t) / c_1(t)^4)
= t(4 psi(1) - psi(2))
> 0,
```

and hence

```text
c_2(t) != c_1(t)^4.
```

The witness is therefore a genuine positive convolution semigroup that violates
the first nontrivial heat-kernel `n^2` discriminator.

## T3 -- corrected consequence for Block04 T5

The corrected premise chain is conditional:

```text
record-composition additivity + a future kernel/regularity bridge
    ⇒ a convolution-semigroup class;
Q-gen ⇒ heat-kernel within the class;
block04's discriminator remains the correct first-level test for Q-gen.
```

Here `Q-gen` names the quadratic generator condition:

```text
psi(n) = s n^2 for all integer modes n
```

for some fixed scale `s >= 0`. Its first-level check is exactly

```text
psi(2) = 4 psi(1),
```

equivalently Block04's character test `c_2=c_1^4` inside a semigroup class.

Thus if a future Record-side bridge supplies the needed kernel assumptions and
regularity, it may select a broad class of the form

```text

```

It does not, by itself, select the heat-kernel subfamily. Within Block04's three
candidate families, the Block04 conclusion stands: Wilson and principal-angle
Manton are not semigroups at finite beta by Block04 T4, so among those three
candidates the heat-kernel remains the qualifying semigroup family. This note's
additional content is only the finite `Z_5` existence witness showing that a
positive finite-subgroup convolution semigroup can still fail the quadratic
generator condition.

## T4 -- what Q-gen means and does not mean

`Q-gen` is an exact mode-growth condition on the generator: the exponent
`psi(n)` grows quadratically in the mode number. The `Z_5` jump witness has
bounded generator values,

```text
0 <= psi(n) = 1 - cos(2*pi*n/5) <= 2,
```

so it is semigroup-positive but not quadratic.

This note does not import continuum or limiting language as authority. The
distinction is exactly the difference between a bounded jump generator on the
finite subgroup and a quadratic mode generator.

Named next-attack only: whether any Record-side structure, such as a
nearest-neighbor admissibility shape of single-step records, supplies `Q-gen`.
No such bridge is claimed here.
