## The Complete Candidate Law

### 1. Relational program

A program cell is an ordered triple

```text
g = (t,d,e),
```

where `t` is a trigger site, `d` and `e` are perpendicular unit lattice
directions, and `u=d cross e` completes a proper oriented frame.

Place six permanent typed records at

```text
t+e,
t+2e,
t+3e,
t+u,
t+2u,
t+d+e+u
```

with contents

```text
H1, H0, H1, H1, H0, H1.
```

In the exact test representation, `H1` is the rank-one `Y+` projector and
`H0` is the rank-one `Y-` projector. Dynamic center records use `X+/-`, and
dynamic endpoint records use `Z0/1`. These are six distinct rank-one
projectors in the same `M2`, not a six-level onsite carrier.

The law scans the same pattern at every site and every oriented frame. An
isolated header decodes exactly one `(t,d,e)`. Its data sites are

```text
a=t+d,      b=t+2d,      c=t+3d.
```

The coherent edges `(a,b)` and `(b,c)` are nearest-neighbor edges. Header sites
do not overlap them. Repeating the header at `t+3d` makes `c` the next trigger.

The `Y`/header type is a relational program context, not a globally privileged
possibility asserted by Qubit. The candidate assumes a common frame/connection
that makes the six headers comparable and makes their program meaning
available to the local law. Deriving that cross-site reference is a separate
target.

### 2. Static collision graph

Decode every program from the permanent `H` records. Two different programs
conflict if their three-site data sets intersect or if either data set
intersects the other's header. Every program touching a conflict is frozen; it
never fires. Programs outside that set are enabled. A stray header record on a
data site also keeps that cell unready because the carrier is not open.

This is conservative but complete:

- exact reverse nominations of one triple freeze;
- partial overlaps freeze;
- disjoint branches from one trigger may proceed;
- malformed headers do nothing; and
- compatible nonoverlapping cells remain active.

The collision graph is static because the dynamic law writes only `X` and `Z`
records, never `H` records. A late record cannot create a new program and
invalidate an earlier collision decision. Under a translation or rotation,
the headers, triples, intersections, and frozen set transform together.

Freeze is a candidate law value, not a theorem of symmetry. A merge, braid,
or winner rule remains an alternative.

### 3. Center event

For an enabled program, the center event `E_g` is ready exactly when:

- trigger `t` carries a dynamic endpoint `Z` record; and
- `a,b,c` carry no records.

On the open triple apply

```text
U_g = CZ_(a,b) CZ_(b,c).
```

The two gates commute. Then perform the onsite projective `X` instrument at
`b`. Outcome `m=+1` or `m=-1` appends the corresponding `X` record at `b`.
The trigger and every prior record are untouched.

This is an event instrument, not a unitary formation derivation. For an input
density operator `rho`, its conditional branch is

```text
rho -> P_m^X(b) U_g rho U_g^* P_m^X(b),
```

with normalization/weight supplied by the chosen instrument semantics.

### 4. Endpoint reads

Once `b` carries its `X` record:

- if `a` is open, its onsite `Z` instrument is ready;
- if `c` is open, its onsite `Z` instrument is ready.

The two reads commute. Each appends `Z0` or `Z1` and changes no earlier record.
The read at `c` makes `c` a trigger for the cell beginning there. It may enable
that next center event even if the independent `a` read is delayed.

## Growing Record Algebra

One completed cell has four consistent outcome triples. Let

```text
Omega_n = set of complete outcome histories for n cells,
|Omega_n| = 4^n,
A_n = C^(Omega_n).
```

`A_n` is the commutative algebra of functions of the first `n` event records.
Appending the next event defines the cylinder inclusion

```text
iota_n : A_n -> A_(n+1),

(iota_n f)(omega_1,...,omega_n,omega_(n+1))
    = f(omega_1,...,omega_n).
```

It is unital, injective, and multiplicative. Every old event projector is
literally the same cylinder event after extension. The inductive limit

```text
A_R = direct-limit A_n
```

is the growing record algebra of the infinite programmed wire.

This algebra formalizes permanence without pretending stochastic branching is
a deterministic endomorphism. A probability law is a compatible family of
states on the `A_n`. One actual history is a point of the corresponding path
space. The algebra and its inclusions do not choose that point.

## Infinite Fresh-Capacity Theorem

Every center event consumes exactly three previously unrecorded fundamental
sites:

```text
left endpoint + center certificate + forward endpoint.
```

The next cell shares only the already-recorded trigger; its three data sites
are new. Therefore `N` completed events require exactly `3N` fresh data sites.
If a programmed region contains `M` usable fresh data sites, it supports at
most

```text
floor(M/3)
```

completed events. No scheduling trick changes this count because records are
never erased or reused.

The explicit header chosen here adds six permanent program records per cell;
the repeated intended headers are disjoint. An indefinite wire therefore uses
an infinite fresh ray and an infinite prepared program, or it needs a new law

This is the infinite fresh-capacity theorem for this candidate, not a theorem
that the universe has finite total storage. An infinite lattice can host an
infinite wire. A finite causal region still has a finite event budget unless
