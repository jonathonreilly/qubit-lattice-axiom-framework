## Result In Plain Language

There is a clean way for a perfectly homogeneous rule to make local programs
without hiding one special origin. Give every site the same chance to become a
candidate, give candidates independent continuous marks, and keep a candidate
only when its mark is strictly smallest in a fixed local ball. Every accepted
site then carries one of the 24 cubic frames and one of 16 binary program words.
Nearby candidates cannot both win. The output is translation stationary,
proper-cubic covariant, locally finite, and has no hidden absolute origin,
frame, permanent priority record, or nonce. The ephemeral random marks doing
the arbitration are an explicit import, not hidden state.

At the densest tested activity, one event occurs per 15225 sites on average.
It initially writes ten binary program records and ultimately uses fourteen
records per completed Bell packet. That is a low density—about `0.0657%`
initially and `0.0920%` after completion—but it is not a finite-record
universe. On full `Z^3` it produces infinitely many events and records almost
surely: an infinite sublattice has disjoint dependence balls, so its
positive-probability winner events are independent and the usual
Borel-Cantelli argument applies.

This construction closes the *origin-selection* problem for one bounded route.
It does not close the bare-metal problem. The candidate probability, continuous
marks, frame and data distributions, relational one-qubit reference,
cross-site reference transport, one-shot initiation layer, actual random
sample, Bell gates, Bell weights, and Bell visibility are supplied. The
current axioms do not provide them. A second law with the same architecture
but a different activity or visibility gives different physical statistics.

That distinction is the main constitutional result:

> Homogeneity can be preserved without a first spatial seed, but not without
> an occurrence law and an actual history. A local formation sentence can
> define what an allowed append event is. It cannot, by syntax alone, select
> the spatial event density, any temporal rate in an ongoing version, branch
> weights, initial boundary, or actual sample.

This also sharpens the proposed “forms, then is read, which locks it” picture.
Under the current Record axiom, a record already is the permanent lock, and a
state contains records only. A pre-lock “formed thing” would therefore be a new
ontic state type. If no new state type is wanted and reading is supposed to do
the locking, that locking read must coincide with the record write. Ordinary
later readout can still occur, but it does not create or lock the record.
Likewise, making “the clock” the final locker either imports a clock record as
a trigger or uses record order as the clock; the latter can measure formation
order but cannot cause the first formation without a circular definition.

## Exercise Zero: The Exact Wall

The target is not “put one program somewhere.” That requirement is too strong
and has no nonempty translation-invariant infinite-volume probability law. The
minimum target is:

1. start from a translation- and proper-cubic-invariant low-record condition;
2. generate at least one finite observer-accessible causal patch without an
   absolute origin or frame;
3. keep collisions and concurrent updates local and covariant;
4. reconstruct all later predictions from permanent records and the fixed law;
5. admit an exact Bell-capable continuation; and
6. state honestly what supplies actuality, probability, and the cosmological
   boundary.

Progress means an explicit projectively consistent law on finite windows with
a record-cost calculation and a paired law ablation. Decisive microscopic
closure would additionally derive or constitutionally supply the law's event
and branch values. Unconditional cosmological closure would also need an actual
boundary/typicality account.

## Elon-Style First-Principles Reduction

### Make the requirement less wrong

Delete “exactly one first record somewhere.” A TOE needs finite accessible
causal patches, not a unique coordinate seed. Positive-density nucleation is
the smallest homogeneous relaxation that has a nonempty local limit.

### Delete unnecessary machinery

The earlier `CFSI-QH11` construction used role tokens, nonces, priority values,
and distinct rank-one one-site elements. Those are not needed. Geometry can
carry the header; four ordinary binary records carry phase, two settings, and
the relational link; local mark minima supply collision exclusion before any
packet is written.

### Split the problem into independent dials

There are four different questions:

1. **eligibility:** which local configurations may append a record;
2. **occurrence:** which eligible event actually happens and at what density;
3. **content:** which admissible possibility is locked; and
4. **actuality/boundary:** which complete history is the realized one.

The two-witness or read-lock language primarily addresses eligibility and
public stability. It does not automatically fix occurrence, content weights,
or the boundary. Calling all four “formation” hides rather than removes the
remaining physics.

### Smallest falsifying tests

- a two-site or transitive finite-torus symmetry test attacks deterministic
  finite-seed initiation;
- a finite codeword PVM attacks hidden nonorthogonal classical tokens;
- the exact local-minimum density attacks normalization drift;
- a two-packet union attacks hybrid decoding and concurrency;
- two activities with identical geometry attack derived-event-density
  rhetoric; and
- two Bell visibilities with identical geometry attack derived-probability
  rhetoric.

## CFSI-QB16 Orthogonal Binary Carrier Repair

The `CFSI-QH11` note encoded roles, a nonce, a priority, and values as distinct
rank-one elements of one `M_2(C)` site. It correctly disclosed that those
elements need not be orthogonal, but its symbolic decoder then treated their
labels as perfectly distinguishable classical data. A physical nondemolition
decoder cannot perfectly distinguish two nonorthogonal pure states: preserving
both states while writing different orthogonal labels would preserve their
inner product on one side and set it to zero on the other. That carrier is not
acceptable as a physical classical program register.

The repaired construction, called `CFSI-QB16` inside this exploratory packet,
uses sixteen distinct sites. Ten are initial program records, four are work or
outcome sites, and two are stage certificates. Pick the rank-one effect `E`
carried by the first header record as the packet's relational binary reference.
Every other public program value is either `E` or its orthogonal complement
`I-E`. The runner writes these as `P1/P0`, but that is only one matrix
coordinate choice.

The six-site header is defined by the relation pattern

```text
equal, complement, equal, equal, complement, complement
```

relative to its first site. Four data sites carry phase, Alice setting, Bob
setting, and relational link by equality versus complement to the same
reference. A global possibility-label exchange `E <-> I-E` therefore leaves
the logical packet unchanged. So does simultaneous one-site algebra
conjugation of every packet record,

```text
E -> U E U*,        I-E -> U(I-E)U*.
```

The runner checks the label exchange, several exact nontrivial conjugations,
all sixteen logical words, the conjugated code PVM, and a committed
stage/outcome transcript under both transformations. The algebraic argument
holds for every unitary because conjugation preserves equality,
complementarity, products, and sums. No role label, nonce, coordinate,
permanent priority, or fixed `P0/P1` possibility is read as hidden side data.

The four data sites have sixteen mutually orthogonal codewords. Their rank-one
effects sum to the identity on `M_2(C)^{tensor 4}` and are nondemolition on the
codewords. This physical interpretation is conditional on generated finite
composition: the four disjoint local algebras must generate their finite
composition as a C-star algebra. The current generated finite-composition
theorem then gives the tensor product.

There is still a real Qubit-boundary condition. Comparing `E` at one site with
`E` at another requires a physical relational identification or transport
between their local algebra frames. Simultaneous-conjugation covariance proves
that the decoder does not privilege one global matrix basis; it does not derive
that cross-site transport. The first header record is a physically recorded
reference, but the exact law must still say how its relation is carried to the
other nine program sites. This packet therefore does not claim full closure of
Qubit's no-privilege clause and does not edit Qubit.

There is also no finite-storage theorem here. The logical word is binary, but
a generic covariant rank-one reference lies on a continuous unitary orbit.
That continuum is compatible with the already supplied full local algebra; it
does not show that a simulator or physical substrate stores `E` in finitely
many bits. A finite operational quotient or relational code remains open.

The motif has full support radius eight, full diameter ten, and program-record
diameter six. The runner checks unique decoding for every one of the sixteen
data words, exact translation covariance, covariance under all 24 proper cubic
rotations, and the absence of hybrid packets in tested separated unions with
opposite binary labels and differently conjugated relational references.
The ten initial program records are currently one finite-radius atomic write.
They have not been nearest-neighbor compiled. Treating their geometry as an
instant decoder is an explicit construction boundary, not a consequence of
Admissibility.

## Positive-Density Stochastic Nucleation

At each `x` in `Z^3`, independently:

1. make `x` a candidate with probability `q`;
2. if it is a candidate, attach a continuous IID mark, one uniform cubic
   frame, four fair data bits, and a unitarily invariant rank-one reference
   effect `E`; and
3. accept it only if its mark is strictly lower than every other candidate
   mark in the Manhattan ball of radius `R=22` around `x`.

The radius-22 ball contains

```text
M = (4 R^3 + 6 R^2 + 8 R + 3)/3 = 15225
```

sites. For candidate density `q`, the exact winner density is

```text
rho(q) = [1-(1-q)^M]/M.
```

This follows by conditioning on the number of other candidates in the ball:
among `k+1` continuous IID marks, each is the unique minimum with probability
`1/(k+1)`. The runner also checks the finite binomial identity independently
for several neighborhood sizes and activities.

For `q=1`, `rho=1/15225`. Conditional on the relational reference, each
winner's discrete frame/program branch has probability
`1/(24*16)=1/384`. A Haar/uniform choice on the rank-one orbit is an additional
supplied measure; it is not counted as one of those 384 discrete branches.
The factor is local, so every finite output window depends on only a finite
input enlargement. Starting from the infinite IID product law therefore gives
projective finite-window consistency. The runner checks
normalization and marginalization for separated and hard-core-adjacent
cylinders; this is a diagnostic, while the product-measure construction is the
mathematical consistency argument.

Winners are more than 22 steps apart. Since each packet lies within radius
eight of its anchor, their full sixteen-site footprints are disjoint. Since
each valid program's record diameter is six, records from two accepted packets
cannot combine into a valid hybrid program: any cross-packet record pair is at
least seven steps apart. Exact ties reject all tied local candidates; they
have probability zero for continuous marks.

The construction is stationary and covariant as a probability law. An actual
sample breaks the symmetry, as any nontrivial record history must. Covariance
of the law is not selection of that sample.

## Record Cost, Concurrency, and Bell Continuation

At `q=1`, the expected densities are

```text
initial program records:  10/15225 = 0.0006568...
completed records:        14/15225 = 0.0009195...
reserved packet sites:    16/15225 = 0.001051...
```

One exclusion-volume patch therefore contains one winner and ten initial
records on average. Full `Z^3` has divergent expected total record count and,
by the disjoint-ball argument above, infinitely many records almost surely.
The construction replaces the impossible finite uniform seed with a sparse
extensive field; it does not get an infinite universe for finite total storage.

After packet creation, the permanent binary records reconstruct the blank,
prepared, propagated, and committed stages. Two separated packets can be
advanced in either order and end with identical records. Randomizer identities
that produce the same records have no later predictive effect in the declared
continuation. The relational finite-causal-patch view conditions on a winner
and calls that event the local origin; it does not insert an absolute lattice
origin. At `q=1`, conditioning on a winner at the origin has density
`1_{origin winner}/rho`; the Radon factor on that event is therefore exactly
`M=15225`.

The packet supports the exact CFSI-Q7 Bell continuation, including no
signalling and `CHSH=2 sqrt(2)`. This is compatibility, not derivation. Changing
only visibility from `1` to `1/2` changes CHSH from `2 sqrt(2)` to `sqrt(2)`
while preserving the same binary architecture.

## Paired Exact-Law-Value Ablations

Two candidate activities,

```text
q_low  = 1/M,
q_high = 2/M,
```

use the same lattice, exclusion radius, packet decoder, covariance, and record
semantics, but give distinct positive winner densities. One candidate
randomizer coordinate lies above `q_low` and below `q_high`, so the pathwise
transcripts can differ.

Likewise, ideal and half-visibility Bell kernels use the same binary program
and stage architecture but give different exact CHSH values. These controls
show that neither the current axioms nor the carrier geometry selects the exact
law value. The one-shot event density and probability kernel remain
substantive physical content. A continuing process would introduce the
additional question of temporal rate.

## What This Says About Axiom Language

This probe supports a narrow formation clause, not a cosmology clause. The
bare-metal ontology can say that a lawful local event *writes* a permanent
record. It should not say that “reading later locks an already formed record”
unless the framework is willing to add a provisional, non-record state type.

It also should not say that a clock causes locking. If “clock” means an
independent existing record, it is a supplied trigger/witness. If it means the
order or frequency of record appends, it is a derived description of the
event history. It can be a clock after records occur, but it cannot explain the
first occurrence.

For the microscopic law, the minimum still-open content is an event relation
with five separately auditable parts:

1. its record-defined local domain or eligibility condition;
2. a covariant occurrence rule for concurrent eligible events;
3. a content/branch rule for the possibility written;
4. append-only public-state semantics; and
5. exact law values for spatial density, any temporal rate, and branch weights.

For unconditional cosmology, add a sixth question outside that local clause:
the initial/boundary condition and the selector or measure that makes one
complete history actual. The realized-state primitive evaluates the supplied
history; it does not select it.

Therefore a two-witness sentence can still be a useful *eligibility and
stability* proposal. This probe says it is not yet a complete formation law.
The theorem dossier must separately test whether the witness condition forces
occurrence, branch content, and event density/rate, or merely identifies when
an append is allowed.

### N6 — Partial-closure path

No new axiom is forced by the narrow obstruction. A supplied preparation,
positive-density stationary law, relational conditioning, or global boundary

### N7 — Strongest steelman

A hostile reviewer should object that the “deterministic” map need not output a
classical record configuration in one step. It could first evolve a symmetric
coherent state, develop unstable long-range correlations, and only later form
records whose individual history breaks symmetry; or a deterministic global
consistency rule could select one nonlocal history while covariance acts on the
set of histories. That objection is strong and is not closed here. It does not
break the stated stabilizer theorem because both proposals leave its domain:
one introduces non-record coherent state and sampling, the other is not the
tested local classical map. It does prevent any broader deterministic-cosmology
no-go.

### N8 — Cross-cycle echo

can accept or generate different actual records depending on a seed,
randomizer, or boundary. Some apparent “needs a new axiom” walls were retired

used here: the deterministic all-open obstruction is not inflated into a new
