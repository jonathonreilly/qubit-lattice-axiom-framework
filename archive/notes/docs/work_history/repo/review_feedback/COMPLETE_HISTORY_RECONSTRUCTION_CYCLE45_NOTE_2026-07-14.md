### Complete corpus

“Complete corpus” is not merely “many records.” For the first theorem it
means that an injective decoder exposes, for every event record,

```text
(event_id, parent_id, pre_state, protocol, outcome, post_state),
```

with one genesis, one successor along the declared history, no missing parent,
and consistent adjacent states. For an indefinitely growing corpus, every
finite prefix has those properties and the prefixes are nested. No final
infinite-time state is required; the coherent prefix family defines `H`.

For law reconstruction, completeness additionally means coverage of every
row or every separating protocol in the declared counterfactual domain.
Temporal length alone does not imply that coverage.

## 2. Corpus-Chain Reconstruction Theorem

### Statement

Let `C` be a finite set of permanent records decoded into the six fields above.
Suppose:

1. event identifiers are unique;
2. exactly one event has no parent;
3. every other parent identifier occurs in `C`;
4. every nonterminal event has at most one child in this declared history;
5. following child pointers visits every event exactly once; and
6. each event's post-state equals its child's pre-state.

Then there is exactly one ordered complete finite history compatible with
`C`: begin at the unique genesis and follow the unique child relation.

For nested finite corpora `C_0 subset C_1 subset ...`, where each ordering
extends the previous one, the unique finite histories form coherent prefixes
and therefore define one infinite `H`.

### Proof

The genesis is forced by condition 2. At each stage the next event is forced
by conditions 3–5. Condition 5 prevents a disconnected component or cycle,
and condition 6 makes the decoded states composable. Induction fixes every
finite position. Coherent finite positions define the infinite sequence.

### Executable witness

The runner scrambles four event records in storage order. Parent headers
recover the unique chronology and preserve every protocol/outcome label. It
then deletes one parent, adds a fork, and corrupts one adjacent state; all
three malformed corpora are rejected. Finally it shows that the bare outcome
multiset `{0,1}` admits both orders `(0,1)` and `(1,0)`. Permanence preserves
information, but a causal decoder is what turns that information into `H`.

This theorem closes `C -> H` without new axiom text. It does not prove that
Nature's records carry the displayed headers; that is an exact candidate-law
and decoder question.

## 3. Deterministic Universal-Context Theorem

### Statement

Let `X` be a declared finite physical context domain, `Y` a finite output
domain, and

```text
mathcal L_det = {f : X -> Y}.
```

Suppose a certified corpus contains one deterministic response pair
`(x,f_*(x))` for every `x in X`. Then the corpus uniquely determines `f_*`.
If a separately proved extension operator `G_f` maps each local table to one
complete global record law, the corpus uniquely determines `G_(f_*)` on every
unperformed global input as well.

### Proof

Any compatible rival `g` must agree with the corpus on every `x in X`, hence
`g=f_*` extensionally. Applying the single-valued extension operator gives
`G_g=G_(f_*)`.

This is the strongest exact route because it closes the off-path seam with

## 4. Adaptive Separating-Signature Theorem

### Statement

Let `mathcal L` be any law class, `Pi` a family of finite adaptive record
protocols, and `Sigma_L(Pi)` the exact transcript signature. Let `sim` be the
declared physical record-protocol equivalence. If

```text
Sigma_L(Pi) = Sigma_M(Pi)  iff  L sim M,
```

then any exact corpus signature identifies one unique equivalence class
`[L]`.

This is the **Adaptive separating-signature theorem**. Its proof is simply
injectivity of the signature map on `mathcal L/sim`, but that injectivity is a
substantive physical theorem about the allowed protocols.

### Genuine adaptive witness

The runner defines three two-step deterministic response laws. Under the
fixed action word `(0,0)`, `L0` and `L1` have the same transcript. Under one
adaptive protocol, the second action is `1` after first outcome `0` and `0`
after first outcome `1`. The resulting three action/outcome signatures are
pairwise distinct. The signature generated by `L1` therefore identifies only
`L1` in that finite class.

This is an exact finite self-test, not a claim that the current physical
protocol category is already separating. The adaptive full-abstraction work

## 5. Finite-Order Process-Tomography Theorem

### Statement

Fix a finite alphabet, a finite intervention set, and known memory order `k`.
A controlled Markov/process law is the finite table

```text
K(y | c,u),
```

where `c` is a length-`k` record context and `u` a legal intervention. If the
corpus supplies every row exactly, normalization reconstructs `K`. The chain
rule then determines the exact probability of every finite adaptive
transcript, conditional on the supplied initial `k`-record boundary.

This is the **Finite-order process-tomography theorem**. It identifies the
full law inside the declared memory-order class, not only the protocols that
happened to be run.

### Exact rational witness

The runner uses binary order two and two interventions, giving eight
context-action rows. Each response probability is a rational multiple of
`1/8`. All rows reconstruct exactly, and the reconstructed process gives the
same rational distribution for every depth-three adaptive transcript. The
distribution normalizes exactly to one. Removing one row admits a distinct
kernel and is rejected as incomplete tomography.

The integer row counts in the runner represent **certified exact limiting
ratios**, not inference from one finite sample. For a physical stochastic
corpus, Cycle 21's component-mean theorem, an every-history deterministic
cycle, or another pointwise limit theorem must connect permanent records to
those exact rows. Without that bridge, tomography estimates rather than
exactly reconstructs `K`.

## 6. Law-Owned One-Outcome Recursion Theorem

### Statement

Let `F` be a supplied single-valued law on a supplied domain, let `Q` be a
single-valued legal protocol scheduler, and let `z_0` be supplied initial or
boundary data. Define recursively

```text
(z_(n+1), r_n) = F(z_n,Q(z_n,n)).
```

Then every finite prefix and hence one complete history `H` is unique. If each
step appends `r_n` without altering earlier records, `H` is a permanent
record history. No stochastic sampler or second actuality rule is needed.

This **Law-owned one-outcome recursion theorem** closes `(L,z_0) -> H`. It
does not identify `L` or choose `z_0`; those are different type problems.

### Universal dovetail witness

The runner supplies a scheduler whose phase cycles through all eight
radius-one binary contexts. Rule 110 supplies one output. Every step appends
one record with a unique predecessor, phase, query, outcome, and next phase.
For a supplied initial phase:

- the law generates the same unique corpus on every execution;
- predecessor headers reconstruct its order;
- one eight-event cycle covers the whole local domain and reconstructs Rule
  110; and
- the recursion extends to every requested finite prefix.

Changing the supplied initial phase changes the particular ordered `H` but
not the reconstructed rule after one complete cycle. Thus boundary data can
matter for actuality while a universal corpus still identifies the law.

This is the cleanest two-way positive model:

```text
(L,z_0) -> H -> L
```

inside one explicitly declared finite local class. It is not circular: the
first arrow is tested by single-valued recursion, while the second uses only
the recorded universal response table. What remains externally typed is the
exhaustiveness of the class, legality of the context preparations, decoder,
scheduler, and boundary.
