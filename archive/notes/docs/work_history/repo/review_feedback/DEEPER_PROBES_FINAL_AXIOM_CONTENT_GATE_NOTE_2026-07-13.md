## Verdict

The generic probe phase is now deep enough to decide the language scope, but
the framework is **not yet physically complete** and the two proposed
Admissibility/Record sentences are **not the complete possible update**.

The tests establish four things.

1. **Continuation support and exact permanence can be theorems of an explicit
   append-only local rule.** They are not consequences of the present
   structural statement that one rule exists.
2. **Multi-site quantum composition remains a distinct constitutional seam.**
   A record-graph rule cannot exclude an invisible global sector. The minimum
   clean direct condition is generated finite-site composition.
3. **Operational nouns do not need to be axioms.** Preparations, effects,
   density representatives, transformations, channels, and instruments can be
   defined or represented from complete future-record statistics.
4. **The data needed for those definitions are still physics.** Record-state
   sufficiency, a separating experimental repertoire, normalized probabilities,
   composition/marginality, mixing, ancilla stability, actualization, and a
   frequency law have not been derived.

The named generic finite controls will not choose the final law. This is not a
universal claim that no other counterexample matters. The remaining
high-leverage work is constructive: a candidate predictive specification, or
a proposed physical-equivalence class, should be written and tested against
the interfaces below.

## The Four Possible Constitutional Seams

These are candidate locations for the one coordinated update. They are not a
recommendation to add four sentences regardless of derivability.

| location | candidate content under test | retirement condition |
|---|---|---|
| **Qubit** | every finite joint possibility domain is generated by mutually commuting copies of its one-site domains; no silent extra global sector | derive generated composition from the physical rule or a record-tomographic separation theorem |
| **Admissibility** | the rule returns a set of lawful physical continuations and supports a record-forming continuation for every locally available possibility when formation is enabled | print an exact rule for which these are theorems |
| **Record** | one candidate semantics is that every lawful continuation preserves each existing record at the same site and with the same content | derive fixed-site identity or compare it with migrating/re-encoded permanence before any wording decision |
| **Qualification** | a record configuration is a complete physical state for future continuation, including all phase- and preparation-relevant information; answer/set semantics are unambiguous | prove persistent global records plus the rule separate every operationally distinct preparation; otherwise widen the state definition |

The operational probe removes a previously suspected fifth location: there is
no present case for inserting preparations, effects, density matrices,
channels, instruments, FRAME-EXT, or PREP-FRAME into Record.

## The Predictive Specification Is Larger Than These Sentences

The current Admissibility text says that one fixed nearest-neighbor rule
exists and that availability varies with neighbor conditions. On the smallest
binary six-neighbor shadow, proper-cubic covariance, neighbor variation, and
exact no-privilege symmetry still leave

```text
282,429,536,480
```

different rule tables. The candidate sentences are a contract on a law; they
do not state the law.

An explicit append-only majority/tie witness closes menu support, transitive
continuation, same-site/content preservation, and nonreconnection on every one
of `3^8 = 6561` finite test configurations. That proves the contract is
coherent. It does not make that toy rule the universe's rule, recover coherent
quantum propagation, or choose a realized continuation.

A second maximum-support schema works on an arbitrary possibility set without
selecting a named value: a blank site admits the values represented by its
recorded neighbors, or the whole domain if none are recorded, and one step
appends any admitted value. Exhaustive finite checks confirm full cubic
covariance and equivariance under every relabeling of a three-value domain.
This strengthens the derivability witness but remains far too permissive to be
the physical TOE rule.

The current **five-output project checklist** for a serious candidate is:

```text
1. physical finite-region domain and generated composition
2. complete state and a separating operational record repertoire
3. exact local covariant update and lawful intervention class
4. invariant record-formation/preservation theorem
5. actual-history and Born-frequency theorem
```

A single law may provide all five. Calling several premises "one rule" does
not make one output a theorem of the others; each output must be proved from
the rule's exact definition.

## What The Bare-Metal Tests Say About Formation

The current research-priority conceptual architecture remains the nonreconnecting-sector
route: unresolved alternatives propagate coherently; a record forms when the
physical continuation structure enters a refinement that later lawful
operations cannot reconnect.

The tests rule out three tempting shortcuts as fundamental explanations:

- **reading is not automatically locking:** a reversible CNOT writes a copy,
  and the same local operation erases it;
- **a deterministic channel is not an event:** one dephasing channel has both
  projective and random-unitary unravelings with different event meanings and
  weights; and
- **a clock is not automatically the lock:** an event count or phase labels an
  order only after the update law supplies the irreversible invariant. Clock
  motion cannot create permanence by definition.

Reading can create another record and a clock can index commits. Neither is
the bare-metal reason a record is final. Finality belongs to the allowed
continuations/operations.

The compute/storage interpretation remains viable but not yet physics. Exact
append-only writing consumes fresh capacity or exports old information. To turn
"the universe avoids overspending" into a TOE result, the rule must derive a
capacity variable, its conservation or renewal law, and its coupling to rate,
matter, and geometry. Archive size by itself is not entropy, energy, stress, or
gravity.

## Operational Reconstruction Result

Once normalized future-record statistics exist, the following are legitimate
definitions:

- preparation = equality under all later readable statistics;
- effect = equality across all preparations;
- transformation/instrument = equality under all later sequential record
  statistics; and
- density matrix/channel = the finite-dimensional representative of those
  operational equivalence classes when the quantum representation hypotheses
  hold.

This can dissolve `PREP-FRAME`: if the prepared state *means* the complete
operational equivalence class, its unique density representative is not a
second object needing identification. It does not dissolve an identification
claim involving some independently named ontic matrix.

The strongest current qubit route is the composite-projective Gleason theorem.
Ordinary tensor composition and consistency of probabilities under
`P -> P tensor I` allow a qubit density/Born representation using projective
measurements. That can shrink the older all-effects FRAME-EXT route. It still
requires normalized context-consistent probabilities, a physical projective
repertoire, ordinary composition, and composite extension of preparations.

The weakest remaining operational ledger is:

| key | missing physical content |
|---|---|
| `H` | normalized history/test probabilities plus trials and conditioning |
| `R` | a separating repertoire of preparations and readable contexts, with shared events glued consistently |
| `M` | physical randomization/forgetting if convex mixing is used |
| `C` | generated composition, local spectator embedding, and marginal consistency |
| `S` | stability under later tests and untouched ancillas, yielding CP rather than mere positivity |

Born state/effect representation and state update remain separate. Two
instruments can have the same immediate effect and different later records;
one deterministic channel can have inequivalent event decompositions.

## Decisive Constructive Tests Still Required

The remaining tests are not more generic no-gos. They require an actual
candidate rule.

1. **Five-output law-card test.** Print the domain, state, update, allowed
   operations, and boundary conditions; prove the five outputs above.
2. **Generated-composite test.** For every finite block, prove that the
   physical joint algebra is generated by faithful commuting one-site copies.
3. **Record-state phase test.** Construct `|+>`/`|->` and an entangled phase
   pair as different persistent record configurations and recover their
   different later record fingerprints. Failure forces a state-definition
   change.
4. **One-spectator marginality test.** Build a qubit plus spectator from the
   rule; derive normalized projective frames and
   `f(P)=F(P tensor I)` for every preparation.
5. **Instrument/ancilla test.** Reconstruct sequential update maps and prove
   stability beside an untouched ancilla.
6. **Frequency test.** Prove that the rule selects its history statistics.
   Determinism alone is insufficient: the identity update admits every
   Bernoulli invariant measure, while a specially structured finite cycle can
   uniquely fix uniform visit frequencies.
7. **Bell/intervention test.** State explicitly how settings enter the local
   rule. Deterministic Bell-local joint assignments obey `CHSH <= 2`; a
   successful deterministic TOE must expose its actual escape route rather
   than hiding it in "global consistency" or "initial conditions."
8. **Resource-to-gravity test.** Derive a conserved/renewed capacity and show
   how it controls clocks, active stress, and geometry.

## Constitutional Recommendation Before Polishing

Do not add probability, clocks, witnesses, reading, storage scarcity, or
operational quantum nouns to Record.

For the next scientific pass, track these candidate seams without treating the
list as final language:

1. **Qubit:** generated finite-site composition;
2. **Admissibility:** determined lawful-continuation set plus menu-complete
   formation support;
3. **Record:** physical record-identity semantics—fixed-site preservation or a
   derived migration/re-encoding alternative; and
4. **Qualification:** complete record-state and answer semantics, but only if
   the phase-sufficiency construction fails or needs explicit clarification.

Treat each as staged target language. The larger unresolved obligation is an
exact predictive specification—or a proved physical-equivalence class—for the
already-postulated fixed rule. If that content proves any candidate, delete
the corresponding sentence from the final constitutional package rather than
keeping a redundant axiom.

not used as time; capacity is not used as gravity.

### N5 -- resolution audit

The countermodels are finite exact witnesses. They prove non-entailment at the
tested interface, not impossibility for all local rules. The rule-table census
is exhaustive only for the stated binary shadow.

### N6 -- partial closure

Operational nouns and potentially PREP-FRAME retire into definitions;
continuation and permanence retire under an append-only/invariant rule;
composition retires under a generated-global-algebra theorem; statistics can
retire under a unique-ergodic/frequency theorem.

### N7 -- steelman

The strongest route is one algebra-valued local covariant rule on a generated
quasi-local domain whose complete record configuration retains all operational
phase information, whose dynamics creates an increasing invariant record
algebra, and whose histories carry a unique normal frequency measure. Such a
rule could make all four candidate seams theorems. It has not yet been built.

### N8 -- cross-cycle echo

physical selection. This gate preserves the reset: an existence sentence is
not a rule table, a tensor construction is not physical composition, a density
representation is not a probability law, and a stable archive is not gravity.
