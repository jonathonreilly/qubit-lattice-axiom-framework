small number of genuinely load-bearing physical atoms from their downstream
representations and consequences.

1. the four live axioms;

## AND/OR Dependency Map

The dependencies are route-sensitive rather than one linear chain.

```text
C + S + L
    |-- L supplies physical continuation and formation eligibility/support
    |-- L + V + record uniqueness -> nonreconnecting conflicting records
    |-- single-valued L on complete S -> X
    |        or: branching L + selector/history law -> X
    |-- unique-ergodic L + trials -> W
    |        or: branching L + normalized history measure -> W
    |-- S + W + separating record repertoire
    |        + [all-effects additivity OR (C + spectator marginality)]
    |        -> state/effect probability representation
    |-- probability representation + physical mixing M
    |        -> convex operational structure
    |-- convex operational structure + sequential/ancilla stability
    |        -> channel/instrument representations -> O
    |-- L + event ordering + frequency comparison -> T
    |-- C + L + stable excitation/quotient theorems -> I
    |-- L + conserved capacity/source + T + B -> G
```

The realized-state primitive can evaluate a result on the realized history. It
does not supply either branch of the `X` or `W` alternatives.

## Exact Independence Witnesses

The runner gives finite witnesses for the following narrow separations:

1. `C`: the same local `M_2(C)` copies fit both `M_4(C)` and
   `M_4(C) direct-sum M_4(C)`; the latter contains a silent central sector.
2. `S`: the same terminal record label can be paired with `|+>` or `|->`,
   which have different future `X` statistics. A state-based law must retain a
   distinguishing record/reference or widen its state.
3. `L`: one availability menu admits both menu-complete and singleton
   successor support.
4. `V`: append-only and site-migrating rules can preserve the same record
   content multiset while differing on same-site permanence.
5. `X`: one branching continuation graph accepts different realized-member
   selectors.
6. `W`: one support graph and one realized-member slot accept distinct
   normalized measures.
7. `O`: equal immediate effects can have different conditional future states.
8. `T`: one event order accepts inequivalent durations.
9. `I`: identical one-site qubit/occupation data admit commuting hard-core and
   anticommuting CAR cross-site readings.
10. `G`: one append history accepts different capacity, source, and response
    maps.
11. `B`: one law accepts different initial record configurations.

These are non-entailment witnesses at the named interface, not universal
claims that one deeper law cannot close several atoms together.
