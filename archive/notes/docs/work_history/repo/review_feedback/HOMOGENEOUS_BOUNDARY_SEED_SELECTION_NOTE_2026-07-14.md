# Homogeneous Boundary-Seed Selection Probe

**Date:** 2026-07-14

**Type:** meta

**Scope:** exact finite-volume and countable-additivity controls for selecting
a finite nontrivial anchor or program under translation covariance

**Authority:** none. This is a boundary-selection probe, not the physical
cosmology, an axiom proposal, an audit verdict, or a retained theorem. It
changes no live foundation surface.

## Result In Plain Language

The homogeneous causal-front construction can use a finite program packet,
but spatial homogeneity cannot itself choose one finite packet at one place in
infinite `Z^3`.

On every finite cubic torus, “put exactly one anchor somewhere uniformly” is
a normalized translation-invariant distribution. Its probability of placing
the anchor in any fixed local window is the window volume divided by the
whole volume. That probability goes to zero as the torus grows. The local
infinite-volume limit is the empty configuration, not a universe containing
one uniformly located seed.

The exact infinite statement is elementary. In a translation-invariant
probability law on exactly one marked site, every site must have the same
probability `q` of being marked. If `q=0`, countable additivity says the
probability that any site is marked is zero. If `q>0`, the probabilities of
finitely many disjoint site events eventually sum above one. Neither can give
an exactly-one-seed probability law.

The same obstruction holds for any fixed finite nonzero number of uniformly
located seeds. It does not hold for a positive-density stationary seed field,
an infinite boundary, a distinguished physical boundary record, a global
constraint, or a dynamical nucleation process. Those are the live routes.

The constitutional consequence is a classification, not another axiom:

> The exact local law must specify the allowed boundary/program type and how
> records decode it. The actual cosmological boundary instance is contingent
> state/history data unless a deeper global law uniquely selects it.

Thus an exact local-law reference can finish the **microscopic constitution**
while predictions remain conditional on a boundary/preparation. An
unconditional TOE of this particular universe needs a boundary-selection or
typicality theorem as well. It should not hide a finite origin, ray, frame, or
program in Lattice, Admissibility, or Record.

## Finite-Torus Control

For the cubic torus `T_L=(Z/LZ)^3`, define the one-anchor distribution

```text
mu_L({x}) = 1/L^3.
```

Every translation permutes the `L^3` singleton configurations, so `mu_L` is
exactly invariant. For a fixed window `W` whose sites remain distinct modulo
`L`,

```text
mu_L(anchor in W) = |W|/L^3 -> 0.
```

The runner checks a 27-site window for `L=5,7,9,13,21`. It also checks exact
hypergeometric hit probabilities for uniformly chosen `k=1,2,5` anchors; all
go to zero at fixed window size.

This is not a failure of the finite distributions. It is a failure of
tightness around any unprivileged finite observation window. The single
anchor escapes to infinity in the local weak limit.

The information cost says the same thing. A location in volume `L^3` needs at
least `ceil(log2 L^3)` bits, which grows without bound. Choosing one of the 24
cubic frames costs a fixed five bits, but a frame label does not choose an
origin.

## Positive Homogeneous Alternative

An IID Bernoulli seed field with density `p>0` has a volume-independent local
law:

```text
P(W contains a seed) = 1-(1-p)^|W|.
```

For `p=1/8` and `|W|=27`, the runner verifies the same exact value at every
tested volume. Its expected total seed count is extensive and its infinite
interpretation has infinitely many seeds. This is a genuine homogeneous
boundary class, but it is not the low-record finite seed used by the current
outward-front examples.

Other positive routes are physically different:

- an all-sites homogeneous initiation event;
- a positive-density random or quasiperiodic program field;
- a past boundary hypersurface or boundary at infinity;
- a global/two-boundary consistency condition;
- spontaneous nucleation governed by an exact spacetime event law; or
- a finite causal patch defined relationally by other records rather than an
  absolute spatial origin.

Each can preserve covariance at the law level while individual histories
break it. Each still needs its exact boundary or event semantics.

## Law Versus Boundary Instance

One fixed local rule can accept distinct physical program records. A toy copy
rule conditioned on program `0` writes `0000`; conditioned on program `1` it
writes `1111`. The rule is unchanged and the conditional transcripts differ.
Similarly, two normalized measures over the same allowed program class—fair
and `2:1` biased—give different unconditional transcript laws.

This separates four jobs:

1. the microscopic rule;
2. the allowed boundary/program **class** on which the rule is defined;
3. the actual boundary/program **instance** of one experiment or universe;
4. any measure or selector used for unconditional claims across instances.

The exact-law referent must fill jobs 1 and 2. Records and supplied
preparations can fill job 3 conditionally. Job 4 is needed only when the
theory claims a distribution or unique prediction for the actual cosmological
boundary.

## Relation To `CFSI-QH11`

The homogeneous local decoder removes the hand-coded rule-location problem:
one finite motif rule is applied at every anchor and in every proper cubic
frame. It uses strict local priority and causal certificates to resolve
overlap, and its outcomes are covariant when the entire physical packet is
translated or rotated.

This note tests a different question: why does a valid packet exist at a
particular place at all? The local decoder does not need to answer that for a
laboratory protocol, where preparation records are supplied. A cosmological
TOE does need either a boundary account or a law whose homogeneous state
generates its own physical packets.

The distinction prevents two opposite mistakes:

- calling a boundary-relative construction noncovariant because one actual
  boundary breaks symmetry; and
- claiming that covariance of the rule selects the boundary that breaks it.

## Constitutional Consequence

This result does not add a boundary sentence to the four local axioms.
Cosmological state is not a universal local ontology premise. It does add one
acceptance condition to the exact-law dossier:

> Every referenced law must distinguish its covariant domain/boundary class
> from the actual preparation or cosmological instance, and every
> unconditional prediction must name the selection or measure over instances.

The one-clause Admissibility reference remains the universal constitutional
minimum if a complete exact law is eventually identified. A separate
boundary axiom becomes necessary only if the owner chooses **unconditional
cosmological prediction** as part of the constitution rather than as state or
meta-law content. Present science does not force such a placement.
