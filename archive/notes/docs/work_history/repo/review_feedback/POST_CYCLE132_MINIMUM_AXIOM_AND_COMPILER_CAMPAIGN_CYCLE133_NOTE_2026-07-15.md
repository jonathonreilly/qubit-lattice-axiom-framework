## Why no axiom edit is licensed

### Admissibility already contains the right generic slot

Every successful new row says which content is available from a complete
nearest-neighbour signature.  Proper-cubic covariance supplies all rotated
images.  The exact signatures and output labels belong to the still-candidate
law `L*`; moving them into generic axiom prose would confuse a value of the
rule with the existence and covariance of the rule.

### Record already states what a present record does

The current constitution says that a record locks exactly one admissible local
possibility. The campaign model treats an append as the appearance of that
already-locking record. Cycle 118 shows the source record is present and fixed
before any downstream read carrier. The compiler repairs never use a later
read or clock to complete an old lock. Read-lock and clock-lock wording would
contradict the tested campaign chronology rather than explain it.

### Incompatible locked contents are already separated at record level

Once two histories contain incompatible locked contents at the same site,
permanence and one-record-per-site prevent them from later agreeing at that
site. Histories that differ only by compatible append order or temporary
absence may still reconverge; the campaign's confluence graphs rely on that.
Cycles 129 and 132 enlarge the tested histories with exact local provenance,
without needing an extra generic continuation-sector sentence. This does not
establish a continuum superselection theorem; it removes only the alleged
constitutional prerequisite from this finite compiler lane.

### Resource economy remains an interpretation

Append-only local construction can be read as computational or storage
economy, but no conserved capacity, global budget, erasure price, or gravity
response was derived here.  “The universe is storage limited” remains a useful
bare-metal intuition, not an axiom-grade physical statement.
