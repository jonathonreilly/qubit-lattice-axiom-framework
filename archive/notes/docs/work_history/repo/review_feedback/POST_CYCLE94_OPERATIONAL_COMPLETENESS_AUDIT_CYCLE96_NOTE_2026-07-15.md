## Classification rule

Each row below has one primary disposition.

`THEOREM_TARGET`
: The object may be hard, and its failure can reject a candidate, but the
  statement is expected to follow from the candidate's exact contents.

`EXACT_LAW_FIELD`
: Different values change legal record predictions. The complete artifact
  must specify the value exactly unless another theorem derives it.

`REFERENCE_PRIMITIVE`
: The existing allowlist already supplies the narrow reference. Scale grants
  unit conversion only; kinetic isotropy grants only structural `c_t=c_s`;
  realized state grants only pointwise reference to a supplied admissible
  state.

`EMPIRICAL_INPUT`
: The value is a fact about this preparation, history, boundary, or data set.
  The law must type and condition on it but need not turn it into universal
  constitution content.

`GENUINE_CONSTITUTIONAL_ATOM`
: Extensional content that must be supplied by the final constitution because
  it is scientifically selected, record-distinguishing, indispensable, and
  not uniquely derivable. Only the conditional complete-law identity currently
  survives this test.

`PARTIAL` means an exact predecessor closes a strict subdomain. It never means
that the general interface is nearly proved.
