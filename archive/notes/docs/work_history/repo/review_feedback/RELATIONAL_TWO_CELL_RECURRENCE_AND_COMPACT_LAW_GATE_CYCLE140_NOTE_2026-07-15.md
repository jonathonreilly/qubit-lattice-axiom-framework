## 1. Exact Architecture

The construction uses one period-four `A/B/C/D` rail. Each slice is a
role-labelled finite cross-section. The `A/B/C` slices have a two-record tail;
the `D` slice omits the guard record and thereby leaves one concave notch.

At that notch:

```text
B root + B guard                         -> JOINT
A root + A guard + JOINT                -> H1
earlier D-root R_B01 + H1               -> OZ.
```

The `D` root is itself generated by the preceding rail history. Four slices
later the same geometry and local signatures recur by translation. The next
socket is therefore not installed by a host loop; its parents are ordinary
records output by the same physical grammar.

The table uses phase-labelled roles, but it has no external phase input. The
distinction is the same as a finite-state machine whose state is stored in its
physical tape: `A/B/C/D` are onsite contents read by local rows, not simulator
time, coordinate parity, or a separate clock.

Every rule input is a subset of the six axial neighbours. Every canonical row
is closed under all 24 proper cubic rotations. The raw union is single-valued
and all input/output roles lie in the already declared 153-role campaign
alphabet.

## 8. Bare-Metal And Wolfram Comparison

The result supports a simple bare-metal picture. A permanent local fact can
change which facts are available next; a finite role pattern can reproduce
the relational conditions needed to continue that process; and arbitrary
legal local orderings can commute to one record corpus. No later read creates
or finally locks an old record. No clock approves formation. No storage
manager checks a global budget.

This resembles a small causal-invariance construction in Wolfram-style local
rewriting, but the substrate is materially different: fixed `Z^3`, append-only
site records, and a selected finite rule table rather than dynamic hypergraph
rewriting or the ruliad. The analogy supplies no GR, quantum measure, observer
quotient, exact-law selection, or actuality theorem.

The compute/storage-limited-universe intuition remains an interpretation, not
a derived `G`-lane law. It earns physical status only when record cost becomes
an invariant resource/current with measurable response, renewal, thermal, and
gravitational consequences.
