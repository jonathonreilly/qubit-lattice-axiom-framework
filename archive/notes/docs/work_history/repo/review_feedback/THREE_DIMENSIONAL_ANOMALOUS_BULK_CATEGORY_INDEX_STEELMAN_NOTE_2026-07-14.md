## Result In Plain Language

The genuinely three-dimensional route is stronger than the preceding
wire-flow surrogate, but it does not produce the hoped-for unique bare-metal
law.

There is now a positive, explicit qubit result in the primary literature. The
April 2026 revision of Sun, Yang, Wang, Tantivasadakarn, and Chen constructs the
three-fermion `Z_2` Clifford QCA on arbitrary cellulations, proves that its
cubic representative squares exactly to the identity, and identifies its
boundary algebra with the corresponding invertible-subalgebra construction.
This is a real anomalous three-dimensional bulk, not six independent rays.

It does not yet live on one primitive qubit per cubic site. Its displayed
cubic realization places two qubits on every face. There are three face
orientations per cubic unit cell, hence six qubits per cell. The older
three-fermion Walker-Wang construction uses two qubits per link, also six per
cubic cell. The chiral-semion construction uses one qubit per edge, three per
cubic cell. Odd-prime Witt examples use two odd-prime qudits per site. These
are positive compiled carriers, not a proof of impossibility for a block code
built from primitive `M_2(C)` sites.

The decisive mathematical boundary is what an index is designed to forget.
The Clifford boundary form determines a QCA only up to local Clifford circuits,
translations, and stabilization; the newer categorical classification is also
a classification of stabilized QCAs modulo circuits and separated
automorphisms. Therefore an invariant can select a bulk *class* while remaining
blind to the microscopic representative inside that class.

That kernel is not merely formal. On the primitive one-qubit lattice, apply
the same controlled-phase gate to every nearest-neighbor edge. The product is
translation invariant, invariant under every proper cubic rotation, local,
unitary, and finite depth: the cubic edges can be colored in six disjoint
layers. Angles `pi/2` and `pi` produce different exact entanglement on
`|++>`, yet composing either circuit with the same bulk QCA leaves every
invariant defined modulo general finite-depth circuits unchanged. The `pi`
member is itself a Clifford circuit; identity versus this member already gives
a nontrivial kernel inside the Clifford quotient. A category class therefore
cannot, by itself, name the microscopic interaction phase or representative.

A record can generate a boundary normal after it exists. The exact record
gradient from the parent cycle remains translation and proper-cubic covariant.
But with no record the gradient is zero, so the anomaly route does not
nucleate the first record. It is a conditional boundary theorem, not a
first-record theorem.

The anomaly can constrain boundary content. If a *non-self-inverse* bulk Witt
class is supplied, then its class versus its inverse can distinguish opposite
chiral boundary categories relative to a supplied outward normal. That is a
genuine possible closure of the hand lane. It does not occur for the displayed
qubit three-fermion class: the explicit QCA squares to the identity, so its
inverse is the same class. The odd-prime `Z_4` examples can distinguish inverse
classes but do not use the primitive qubit carrier. The qubit chiral-semion
route has a potentially non-self-inverse `Z_8` class, but its 2022 categorical
identification and order statement are presented as conjectural and its
carrier is compiled on edges.

Even after granting an outward anomalous boundary, exact same-class pairs
remain:

- two nonempty occurrence-domain truth tables;
- half transfer and full transfer, both conserving the source quantum;
- different finite-depth interaction angles;
- an invariant append sector versus an actual outcome instrument;
- coherent GHZ premeasurement versus the corresponding dephased outcome
  channel;
- different proper-cubic tensor trace weights; and
- common versus charge-dependent species phases, both commuting with the same
  conserved charge.

The finite-dimensional append-sector lemma is especially important. If a
finite unitary leaves a record subspace invariant, that subspace is reducing;
no orthogonal blank state can enter it. An infinite no-return exterior can
evade the lemma by carrying inverse information away, but that supplies a
sector/boundary condition, not an outcome instrument. A QCA remains a reversible
automorphism. Restricting or tracing it can yield a channel, but selecting one
actual outcome is additional semantics not classified by the bulk category.

## 2. Exact Finite-Depth Kernel On Primitive Qubits

Let `n_x=(1-Z_x)/2` be the occupation projector at primitive site `x`. For
every undirected nearest-neighbor edge `<x,y>`, define

```text
C_phi(x,y) = exp(i phi n_x n_y).
```

All these diagonal gates commute. Their full product

```text
C_phi = product_<x,y> C_phi(x,y)
```

has four exact properties.

1. Every gate has range one.
2. The set of undirected nearest-neighbor edges is invariant under translations
   and all 24 proper cubic rotations.
3. The edges split into six disjoint layers: one layer for each axis and each
   parity of the lower endpoint. Thus the product is a depth-six local circuit.
4. In a record basis the circuit is diagonal, so it does not change any locked
   basis value. It may change the coherent open sector before locking.

On a single edge,

```text
C_phi |++> = (|00>+|01>+|10>+exp(i phi)|11>)/2.
```

Its squared concurrence is

```text
sin(phi/2)^2.
```

Therefore `phi=pi/2` and `phi=pi` give respectively `1/2` and `1`. The
representatives are physically distinct before records lock.

For any bulk QCA `alpha`, both

```text
alpha_(pi/2) = C_(pi/2) o alpha,
alpha_pi     = C_pi o alpha
```

remain local, unitary, translation covariant, and proper-cubic covariant when
`alpha` has those properties. Any category invariant whose equivalence
relation quotients by general finite-depth circuits assigns them the same
class. In the Clifford-only quotient, `C_pi` is a Clifford circuit, so
`alpha` and `C_pi o alpha` are already an exact distinct same-class pair.

This does not prove the angle is observable in every finished record theory.
A stronger rule could declare every finite-depth representative physically
equivalent. But that would be a new physical-equivalence theorem with a readout
test, not information contained in the category index itself.

## 4. Record-Generated Boundary And The Hand Lane

For binary record indicator `r(x)`, define at an empty site

```text
g_i(x) = r(x-e_i) - r(x+e_i).
```

For one record at `c`, the six neighboring sites obey

```text
g(c+d)=d,   d in {+/-e_x,+/-e_y,+/-e_z}.
```

Translations move this fixture and every proper cubic rotation rotates its six
normals. If there is no record, `g=0` everywhere. The boundary is therefore
relational and covariant, but only after a record exists.

Now grant a bulk-boundary theorem linking an anomalous class `w` to a boundary
category. There are three cases.

- If `w != -w`, supplying `w` rather than `-w` can distinguish the two chiral

  The order-two label does not distinguish outward from inverse transport.

The boundary theorem also cannot create its own input. At the all-unrecorded
state there is no record normal. The global axiom statement that records form

## 6. Append Sectors Are Not Outcome Instruments

Let `R` be a finite-dimensional record subspace and `U` a unitary with

```text
U R subset R.
```

Because `U` preserves dimension, `U R=R`. Unitarity then gives

```text
U R_perp = R_perp.
```

No blank vector in `R_perp` can enter `R`. This is the exact finite append
sector lemma. An exhaustive four-state permutation fixture in the companion
runner shows the same fact combinatorially.

The infinite-lattice escape is real: a local record can remain stable while
inverse information propagates into an infinite no-return exterior. A
three-dimensional anomaly may constrain the exterior algebra. But the escape
requires a selected asymptotic sector or boundary condition, and the inverse
automorphism contains the returning precursor. It does not make the global QCA
irreversible.

A unitary two-witness premeasurement gives

```text
(|000>+|111>)/sqrt(2).
```

The record marginals are diagonal and perfectly correlated. The global state
still contains the off-diagonal term

```text
|000><111| + |111><000|.
```

The outcome instrument deletes that coherence and labels one outcome. The
coherent automorphism and the instrument agree on the local record marginals
but are different maps. A bulk QCA category classifies the former type of
object, not the latter.

Thus three separate ideas must not be collapsed:

```text
stability of record correlations,
an append/no-return sector,
selection of one actual record member.
```
