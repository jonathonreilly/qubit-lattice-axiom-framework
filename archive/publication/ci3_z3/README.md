## Status Rule

- `retained`, `retained_bounded`, and `retained_no_go` are retained-grade.
- `retained_pending_chain`, `audited_*`, `audit_in_progress`, `open_gate`,
  `meta`, and `unaudited` are not publication authority.
- Author headings and raw table labels do not set status.
- Negative claims require a current authenticated N1-N8 packet.
- Historical sole-, single-, or three-axiom arguments do not automatically
  apply to the current Lattice, Qubit, Admissibility, and Record baseline.

## Author And Reproduction Sources

The raw manuscript, prediction lists, science maps, claim tables, and
derivation tables remain in this directory as authoring and provenance inputs.
They are not public authority when read without generated badges. The
[historical manuscript](./ARXIV_DRAFT.md) is explicitly quarantined inside a
collapsed archive.

Use [REPRODUCE.md](./REPRODUCE.md) to locate commands, then verify the claim's
badge and source-note boundary before interpreting runner PASS output. A PASS
line validates only the checks the runner actually executes; it is not an audit
verdict.

## Current Boundary

The current four named axioms are Lattice, Qubit, Admissibility, and Record.
The three registered framework primitives are the only supplied non-axiom
premise type. Every other named conditional or open obligation has zero premise
weight. None of these surfaces silently adds selectors, probability or occurrence
rules, state selection, dynamics, readout bridges, source/action maps,
normalizations, scales, or empirical matches beyond their declared scope.
