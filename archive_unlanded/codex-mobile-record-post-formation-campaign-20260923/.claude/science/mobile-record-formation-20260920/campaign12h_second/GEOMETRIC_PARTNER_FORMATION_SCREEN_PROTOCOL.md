# Formation-selected geometric matchings: declared first screen

2026-09-21, before production runs. Root diagnostic protocol; no phase fit or
thermodynamic conclusion is authorized by these finite samples. The new
geometric-partner construction has a finite-volume filling proof. This screen
tests times, site reuse, the full-state winding sector and low-mode spectra.

Use its exact geometric projection. Every vacant edge forms one dimer at
rate beta, and every ordered occupied-pivot/vacant-neighbor edge slides the
pivot's partner through it at rate kappa=1. The record contents are not
simulated as sampled Bloch vectors: integer identities track the two members
of each almost-surely unique antipodal class. This is valid for geometric
statistics because every marked edge density integrates to the same beta,
and conservative geometric rates do not depend on the marks. It does not
test a quantum implementation or sampling of the full marked law.

The first screen sets nu=0 throughout formation. This is one of the fixed
rates allowed by the theorem; it leaves every full matching absorbing.
It does not select uniform matchings through post-formation mixing. A later
conservative sampling comparison, if attempted, must be declared separately.

Implement exact continuous-time Gillespie sampling over active vacant-vacant
birth edges and occupied-vacant oriented slide edges. At an event, update
only the adjacency entries affected by occupancy changes. Validate the full
catalog and reverse slide channels against a separate Python representation,
including periodic boundaries, before production. Verify identities, pair
reciprocity, full-state Gauss, birth budget, and active-catalog consistency.

Pilot: N=4,6,8; beta=1; seeds 21092301,21092302; empty initial state. Stop at
the first full matching or at 10^7 accepted events. Store every rate-family
count and elapsed-time receipt, final integer matching/identity state,
birth counts per site, and source/executable hashes. An event cap is a
right-censored outcome, not a proof of jamming.

If catalog and pilot checks pass, first declared screen: N=4,8,12,16,24,32;
beta=0.1,1,10; eight seeds 21092401 through 21092408 at each condition;
144 independent empty-start runs, with the same 10^7-event cap. Keep each
configuration and all birth/slide totals, first full-packing time, and complete
run receipts. Different rates with the same seed are not a pathwise coupling.

Report filling times and accepted moves descriptively, retaining cap failures.
For full states measure integer winding fluxes through coordinate planes;
verify agreement of all parallel plane fluxes. Store the normalized staggered
field spectrum on the first two axis shells and on the (1,1,0), (1,1,1)
proper-rotation shells. Retain exact discrete longitudinal residuals and
the zero mode separately. Eight formation realizations do not establish
Coulomb scaling, Gaussianity, an equilibrium measure, or a mixing time.

Decision: if rates materially change winding or spectra, formation selection
is a live supplied input and cannot be replaced by a uniform dimer ensemble.
If samples appear similar, that is finite evidence only. No large-volume
phase claim or continuum-wave conclusion follows from full packing alone.
