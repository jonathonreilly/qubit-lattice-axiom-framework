## 1. Claim


```text
    S(p) = ( m 1 - i gamma.p ) / ( p^2 + m^2 ),    p^2 = sum_mu p_mu^2  (4D Euclidean).
```

> **Theorem (smeared 2-point convergence).** Fix `m > 0`. Given rung A's

## 2. The exact envelope: `||S_a(p)||_F = 2/sqrt(Delta_a)` and the Jordan bound

The free covariance is exactly solvable. Using
`{gamma_mu, gamma_nu} = 2 delta_{mu nu}` and `gamma_mu^dag = gamma_mu`,

```text
    S_a S_a^dag = ( m 1 - i sum_mu gamma_mu s_mu )( m 1 + i sum_nu gamma_nu s_nu ) / Delta_a^2
                = ( m^2 1 + sum_{mu,nu} gamma_mu gamma_nu s_mu s_nu ) / Delta_a^2
                = ( m^2 + sum_mu s_mu^2 ) 1 / Delta_a^2
                = (1 / Delta_a) 1_4,
```

(the cross terms `m s_mu (gamma_mu - gamma_mu) = 0`, and
`sum_{mu,nu} gamma_mu gamma_nu s_mu s_nu = sum_mu s_mu^2 1` by the Clifford
relation since the antisymmetric part drops against the symmetric `s_mu s_nu`).
Hence the **exact Frobenius norm**

```text
    ||S_a(p)||_F^2 = tr( S_a S_a^dag ) = 4 / Delta_a(p),
    ||S_a(p)||_F   = 2 / sqrt( Delta_a(p) ).
```

(Runner C1 verifies `S_a S_a^dag = (1/Delta_a) 1_4` and the norm identity to
machine precision; it also confirms, as a sanity check on the named target, that
the **matrix** `S_a(p) -> S(p)` pointwise -- rung A's input.)

**Jordan bound on the Brillouin-zone half.** Jordan's inequality
`|sin x| >= (2/pi)|x|` on `0 <= x <= pi/2` gives, on the BZ half
`|p_mu a| <= pi/2` (each axis),

```text
    s_mu(p)^2 = sin^2(p_mu a)/a^2 >= (2/pi)^2 p_mu^2,
    Delta_a(p) = m^2 + sum_mu s_mu(p)^2 >= m^2 + (2/pi)^2 |p|^2,
```

so

```text
    ||S_a(p)||_F <= 2 / sqrt( m^2 + (2/pi)^2 |p|^2 )  =:  Phi(p),
```

an **`a`-independent** envelope on the BZ half. (Runner C2: over a large
randomized sample on the BZ half, `0` violations of both
`Delta_a >= m^2 + (2/pi)^2 |p|^2` and `||S_a||_F <= Phi(p)`.) Everywhere on the
full BZ, the crude floor `Delta_a >= m^2 > 0` gives the uniform cap
`||S_a(p)||_F <= 2/m` (runner C2, `0` violations).

## 3. The dominated-convergence step (and the integrand-vs-`Phi` `L^1` subtlety)

We must interchange `lim_{a->0}` with the momentum integral in
`<f, S_a g> = integral d^4p fbar(p) S_a(p) g(p)`. Dominated convergence requires
(i) pointwise convergence of the integrand and (ii) a single `a`-independent
**`L^1`** dominating function.

- **(i)** Rung A gives `S_a(p) -> S(p)` pointwise; hence the scalar integrand
  `fbar(p) S_a(p) g(p) -> fbar(p) S(p) g(p)` pointwise for fixed `f, g`.
- **(ii)** By Cauchy-Schwarz / submultiplicativity and Section 2,

```text
    | fbar(p) S_a(p) g(p) |  <=  |f(p)| · ||S_a(p)||_F · |g(p)|
                             <=  |f(p)| · Phi(p) · |g(p)|  =:  h(p)      (BZ half),
```

with `|f(p)| = (f(p)^dag f(p))^{1/2}` the spinor magnitude. The dominator `h`
is **`a`-independent**.

**The subtlety (stated precisely, because it is the crux the gate flagged).** The
envelope `Phi(p) = 2/sqrt(m^2 + (2/pi)^2 |p|^2)` decays only like `1/|p|`, so

```text
    Phi  is NOT in  L^1(R^4):
    integral_{|p|<R} Phi d^4p  =  2 pi^2 integral_0^R r^3 Phi(r) dr  ~  R^3  ->  infinity.
```

`Phi` **alone** is not integrable in 4D. What is integrable is the **dominating
function of the integrand**,

```text
    h(p) = |f(p)| Phi(p) |g(p)|  in  L^1(R^4),
```

because Schwartz `f, g` supply Gaussian / rapid decay that beats the `1/|p|`
factor in 4D (any inverse-polynomial envelope times a Schwartz function is `L^1`).
So the dominating function is `h = |f| Phi |g|`, **not** `Phi` itself.

Even more robustly, the crude cap `||S_a||_F <= 2/m` (valid on the **full** BZ,
from `Delta_a >= m^2 > 0`) gives the `a`-independent dominator

```text
    | fbar(p) S_a(p) g(p) |  <=  (2/m) |f(p)| |g(p)|  in  L^1(R^4)
```

with no Brillouin-zone bookkeeping at all -- a product of `2/m` and a Schwartz
function. Either dominator suffices.

**Conclusion.** Dominated convergence applies and interchanges the limit and the
integral:

```text
    <f, S_a g> = integral fbar S_a g d^4p  ->  integral fbar S g d^4p = <f, S g>,
```

for all Schwartz `f, g`. This is the smeared / tempered convergence of Section 1.
The runner exhibits **both** sides of the subtlety **non-vacuously** (runner C3):
`integral Phi d^4p` diverges (`2.0e4 -> 1.6e5 -> 1.3e6 -> 1.1e7` as the cutoff
doubles, increments **growing** -- an unambiguous divergence witness), while
`integral |f| Phi |g| d^4p` **converges** (stable at `9.0788` to six digits under
resolution and cutoff refinement); the crude-cap integrand `integral |f|(2/m)|g|`
converges likewise.
