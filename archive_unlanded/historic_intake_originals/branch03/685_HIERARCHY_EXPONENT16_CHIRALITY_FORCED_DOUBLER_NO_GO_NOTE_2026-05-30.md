## 1. Claim

> **Theorem (no-go).** On one discrete Euclidean-time axis, write the
> most general hermitian translation-invariant nearest-neighbour kernel
>
> ```text
> D(k4) = a * gamma4 * sin(k4)  +  b * 1 * (1 - cos(k4)),     a, b ∈ ℝ.
> ```
>
> The `sin(k4)` term is the kinetic / doubler term (it vanishes at both
> `k4 = 0` and `k4 = pi`, giving a naive doubler at `k4 = pi`); the
> `b * (1 - cos(k4))` term is the Wilson doubler-killer (`g(pi) = 2 != 0`
> lifts the `pi`-doubler). For `2^4 = 16` to be **forced by chirality**,
> the framework's chirality operator must ban the `b`-term. The
> framework's **realized** chirality is the vector-like sublattice parity
> `epsilon`, acting in momentum space as `k4 -> k4 + pi`. It does **not**
> anticommute with the Wilson term:
>
> ```text
> 1 - cos(k4 + pi) = 1 + cos(k4)   ≠   -(1 - cos(k4)),
> residual:  [1 - cos(k4 + pi)] + [1 - cos(k4)]  =  2  ≠ 0   (constant in k4).
> ```
>
> Therefore `epsilon` does not force `b = 0`; the Wilson term survives,
> the time axis admits a doubler-free kernel, and the count `2^4 = 16` is
> **not forced** by anomaly-exact chirality on the derived time axis.

## 2. The load-bearing algebra

The entire result is a single contrast in how a candidate chirality
operator treats the **identity** (Wilson) structure on the time axis.

**Idealized anticommuting `gamma5` (does NOT exist in the framework).**
With `{gamma5, gamma4} = 0` and `[gamma5, 1] = 0`:

```text
{D, gamma5} = a*sin(k4)*{gamma4, gamma5} + b*(1 - cos(k4))*{1, gamma5}
            = 0                          + b*(1 - cos(k4))*(2*gamma5).
```

`gamma5` anticommutes with `gamma4` (the `sin` term is `gamma5`-compatible)
but **commutes with the identity**, so `{1, gamma5} = 2*gamma5 != 0`. The
anticommutator vanishes for all `k4` **iff** `b = 0` (`a` free). An
idealized `gamma5` would therefore **ban** the Wilson term -> only
`sin(k4)` survives -> doubler at `k4 = pi`. But there is no such per-site
`gamma5` in the framework (`omega = gamma1 gamma2 gamma3 = i*I_2` is
central), so this branch is **unavailable**.

**Framework's realized chirality `epsilon` (vector-like sublattice
parity).** `epsilon` is single-component and vector-like; in momentum
space it is the shift `k4 -> k4 + pi`, realizing the staggered/CPT
identity `epsilon D epsilon = -D`, i.e. `D(k4 + pi) = -D(k4)`. Applying
the shift term by term:

```text
kinetic:  sin(k4 + pi)      = -sin(k4)        ->  satisfies D(k4+pi) = -D(k4)  (epsilon-ODD).
Wilson :  1 - cos(k4 + pi)  =  1 + cos(k4)    ->  does NOT equal -(1 - cos(k4)).
```

The Wilson residual under `epsilon`-anticommutation is

```text
[1 - cos(k4 + pi)] + [1 - cos(k4)]  =  (1 + cos k4) + (1 - cos k4)  =  2,
```

a **nonzero constant**, independent of `k4`. The condition `b * 2 = 0`
forces `b = 0` only if one demands anticommutation — but `epsilon` simply
does **not** anticommute with the Wilson term: it **commutes** with the
even `(1 - cos)` structure. Position-space cross-check (single-component
chain, `epsilon = diag((-1)^n)`): the constant `1` piece is
`epsilon`-even (`epsilon * 1 * epsilon = +1`), and that even piece — which
is precisely the `k4 = pi` doubler-lifting part of the Wilson term — is
what breaks anticommutation. Hence `b` **survives**.

**The whole story in one line:**

```text
idealized gamma5 :  {1, gamma5}        = 2*gamma5 != 0   ->  b = 0   (Wilson BANNED).
framework epsilon:  epsilon * 1 * epsilon = +1           ->  b free  (Wilson ALLOWED).
```

This is exactly the `NO_PER_SITE_CHIRALITY` content: the only chirality
the framework has is the vector-like `epsilon`, which is the
Wilson-compatible chirality of a Kähler-Dirac / staggered system.

   `2^4 = 16` is not forced by anomaly-exact chirality on the time axis.
7. **Distinction** — `{1, gamma5} = 2*gamma5` (bans `b`) vs
   `epsilon * 1 * epsilon = +1` (allows `b`): the whole result.
8. **P3 independence** — det-power `u_0^16` vs coupling-power
