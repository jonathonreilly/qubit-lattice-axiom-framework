## 2. The eta-holonomy of a UD_2 cycle, and the decisive invariant P(t)

A base-graph `Z_2` link connection is `eta : E(Gamma) -> {0,1}` (additive;
holonomy `= (-1)^{sum}`). The staggered hopping sign is **exactly** an object of
this form: a sign attached to each lattice link. It **lifts** to a `1`-cochain
`A_eta` on `UD_2(Gamma)` in the only natural way: a `1`-cell `{w, e}` is "token
parked at `w`, the other token moving along edge `e`", so the moving token picks
up the link phase and

```text
A_eta({w, e}) = eta(e)        (only the MOVING token's edge counts).
```

**Lemma (well-definedness).** `A_eta` is a cocycle on `UD_2` for every base `eta`:
on a `2`-cell `{e, f}` (both tokens move, on vertex-disjoint edges `e=(a,b)`,
`f=(c,d)`), with boundary `{b,f}-{a,f}-{d,e}+{c,e}`,

```text
A_eta(d{e,f}) = eta(f) - eta(f) - eta(e) + eta(e) = 0   (mod 2).
```

So `Hol_eta` descends to a homomorphism `H_1(UD_2; Z) -> Z_2`. (Runner verifies
`d1.d2 = 0` and the cocycle property on every test graph.)

**Define the base-edge projection** `P : C_1(UD_2; Z) -> C_1(Gamma; Z_2)`,
`P({w, e}) = e`. Then for any `1`-chain `z`, `Hol_eta(z) = (-1)^{<eta, P(z)>}`,
the `GF(2)` pairing of `eta` with the per-base-edge multiplicity of the moving
token. **The exchange holonomy is therefore controlled entirely by `P(t)` for the
exchange generator `t`.**

**Main computation (the no-go).** The integral `Z_2` exchange generator `t` -- the
order-2 torsion class of `H_1(UD_2; Z)`, isolated by integer Smith normal form
(`t` is a `1`-cycle, `t` is **not** integrally in `im(d2)`, but `2t` **is**) --
satisfies

```text
P(t) = 0   in   C_1(Gamma; Z_2):
every base edge is traversed a NET-EVEN number of times by the moving token
around the swap.
```

Hence **for every base-graph `Z_2` link connection `eta`** (the staggered hopping
sign / `sign(beta)` included),

```text
Hol_eta(t) = (-1)^{<eta, P(t)>} = (-1)^0 = +1.
```

The graph-braid exchange `Z_2` is **decoupled** from every link connection; no
staggered hopping sign can put a sign on the swap.

**Why `P(t) = 0` (structural reason).** In the ordered space `D_2(Gamma)` the
exchange is a path from `(x,y)` to its swap `(y,x)`: token 1 travels a base path
`x->y`, token 2 travels a base path `y->x`. Their **total** base displacement is
the concatenation `x->y->x`, a closed base walk that is null mod 2 (forward and
return cancel on the unordered projection). This is the **exact, holonomy-level**
statement of the "centrality" obstruction named qualitatively in the unaudited
`koide_matter_attachment_gate_extra_assumptions_review_note_2026-06-02` (§C): a
**symmetric** (base) connection cannot resolve the swap, because the swap's total
base displacement is even. The present note converts that prose into a computed
homological invariant on the **actual lattice**.

## 3. The fermion swap sign exists -- but not as a hopping connection (the residual)

The decoupling is **not** a statement that the fermionic sign is unreachable in

**That cocycle is genuine -- the fermionic swap sign is realizable

lift of any base-edge connection**: it is not constant on the base-edge fibers
`{ {w, e} : w }` of a fixed edge `e`. It is **non-fibered** configuration-space

**This is the residual, framed as the next path.** The fermionic exchange sign
lives in `H^1(UD_2; Z_2)` but **off** the image of the link-connection
(`H^1(Gamma; Z_2)`) pullback. So the next path is **not** another hopping-sign
choice (every such choice gives `+1` on the swap); it is whatever supplies the

centrality obstruction holds at the lattice level, made exact (runner Part B).
