## Minimal Countermodel

Let a finite source block carry two central-sector coordinates:

```text
(Z, q) in R_{>0} x R
```

with disjoint union defined by

```text
(Z_1, q_1) sqcup (Z_2, q_2) = (Z_1 Z_2, q_1 + q_2).
```

Interpret `Z` as the Berezin determinant datum `det(D+J)`. Interpret `q` as a
supplied central-sector coordinate that the current axioms do not forbid or
select away. The Record axiom permits a supplied readout context with finite
central-sector decomposition and then requires finite scalar additivity over
pairwise-disjoint records. It does not supply the readout context, the
sector-generation rule, or a determinant-only quotient.

For any real `lambda`, define

```text
I_lambda(Z, q) = log Z + lambda q.
```

Then

```text
I_lambda((Z_1, q_1) sqcup (Z_2, q_2))
  = log(Z_1 Z_2) + lambda(q_1 + q_2)
  = I_lambda(Z_1, q_1) + I_lambda(Z_2, q_2).
```

Thus every `I_lambda` is a valid finitely additive scalar readout on this
supplied context. For `lambda != 0`, it is not a function of `Z` alone:

```text
(2, 0) and (2, 1)
```

have the same determinant datum but different readout values. No scalar
function `f: R_{>0} -> R` can satisfy

```text
f(2) = I_lambda(2, 0) = log 2
f(2) = I_lambda(2, 1) = log 2 + lambda
```

when `lambda != 0`.

## Relation To The Three Axioms

- **Lattice** can be satisfied by placing the finite block in any finite
  region of `Z^3`; it does not select a readout context.
- **Quantum** can be satisfied by using the local `M_2(C)` carrier; it does
  not select a determinant-only scalar readout.
- **Record** supplies durable realized-outcome registration and finite scalar
  additivity for an already supplied readout context. It explicitly does not
  supply the readout context, decomposition, weighting, normalization,
  source/action coupling, or physical-observable identification.

The countermodel uses the Record additive law exactly. Its extra `q` coordinate
is not generated by Record; it is a supplied central-sector coordinate. That is
the point: Record lacks a rule that kills such supplied coordinates or quotients
the scalar readout down to the determinant datum alone.
