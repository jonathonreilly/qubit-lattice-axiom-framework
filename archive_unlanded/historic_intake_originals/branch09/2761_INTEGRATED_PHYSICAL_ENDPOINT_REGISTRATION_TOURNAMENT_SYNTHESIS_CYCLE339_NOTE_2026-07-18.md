## Destructive and semantic controls

The direct route suppresses commit under false close, endpoint/content
mismatch, two-candidate ambiguity, wrong identity, and occupied target slot.
Content-only retarget suppresses commit; endpoint-plus-content retarget changes
the registered data covariantly. Every equality, commit, insert, phase, and
export deletion changes the lawful result and has its own exact inverse.

The protected route detects and corrects the declared single-bit shell, but a
triple logical flip preserves every repetition check while changing content.
A two-bit fault is exactly ambiguous with one fault about the opposite logical
word. One phase Z changes a coherent code relation while leaving diagonal
labels unchanged. Copying and redundancy therefore do not create a Record or
full quantum memory.

The process route rejects missing packet fields, false close, ambiguity,
deleted transition, endpoint-only or content-only retarget, candidate retarget,
spliced post-boundary, and phase overflow. Joint endpoint/content retarget is
lawful and changes registered data, as required by pointwise state
contingency. Recurrence relocates a blank rather than creating capacity.

Exact inverse evolution exists in every route. The result is therefore not
permanence. If a future formation rule lawfully types a carrier as a Record,
the Record axiom supplies permanence; Cycle 339 does not derive that typing or
formation rule.
