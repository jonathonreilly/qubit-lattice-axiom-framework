## No-Go: Treating Empty `ok` Cache As Sufficient Evidence

An `ok` cache with empty stdout is not a useful audit-unblock artifact for this target because
reviewers cannot inspect the runner's checks, stated status boundaries, or final pass/fail
summary. The block replaces that record with the full generated transcript.
