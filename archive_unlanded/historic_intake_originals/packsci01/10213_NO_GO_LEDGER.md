# No-Go Ledger

## Existing PR Refresh Loop

Status: rejected by user instruction.

Reason: fast-moving `main` makes repeated rebases low-value. The review lane
will update or cherry-pick useful science/tooling from open PRs.

## Retained Note-Hash Drift

Status: out of scope for this block.

Reason: strict lint reports retained-grade note-hash drift, and its own
message says edited retained notes must be independently re-audited. This
campaign does not run audits or apply verdicts.

## Sidecar-as-Evidence Shortcut

Status: forbidden.

Reason: dispatcher manifests are target-selection surfaces only. The refreshed
dispatch queue must not be handed to auditors as evidence for a claim.
