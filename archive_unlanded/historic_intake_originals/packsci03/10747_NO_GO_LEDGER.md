# No-Go Ledger

## Finite Grid To Arbitrary Degree

The scanned Koutschan-style system excludes order `<= 2` only through
coefficient degree `30`. That does not imply lower-order exclusion at arbitrary
degree. The previous note wording incorrectly treated the finite-grid result
as if it supplied the all-degree bridge.

## Conditional Threshold Without Bound

Bostan-Salvy-Schost threshold arithmetic is useful only after a bound
`R=3,D=2` is supplied. The depth-196 residual check greatly exceeds the
threshold that would apply under that premise, but the runner does not certify
the premise.

## Wrong-Observable Boundary

Even a fully closed V=1 single-plaquette Picard-Fuchs theorem would not by
itself solve the thermodynamic-limit plaquette lane. The branch therefore
does not claim downstream closure.
