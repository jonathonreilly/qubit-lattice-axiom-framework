### Continuous and merely Borel natural kernels have different maximal supports

Personal conditional theorem, 2026-09-15. Fix a recorded-slot subset and
identify its inputs and output with one M2(C), acted on by simultaneous
inner automorphisms. A kernel below is an ordinary probability kernel on
matrix labels. Continuity means weak continuity in the input matrix entries,
including degenerate profiles in that fixed slot subset. None of these
interpretation or regularity choices is adopted for the framework.

Let A(eta) be the unital complex algebra generated by the recorded inputs.
The polynomial-word Gaussian kernel in the companion note is weakly
continuous and has support exactly A(eta). The following proves that this
support is maximal among all weakly continuous equivariant kernels.

#### 1. Continuous natural kernels stay in the generated algebra

If all inputs are central, the full-inner invariant-probability theorem
forces central output. If the inputs commute and one is noncentral A,
all lie in C[A]. The entire centralizer of A then fixes the profile, so
the one-input stabilizer argument forces the output into C[A]=A(eta).

For a noncommuting profile whose algebra is proper, the algebra is conjugate
to the upper-triangular algebra. Here is an elementary two-by-two proof.
If one input has two distinct eigenvalues, diagonalize it. Its two spectral
projectors belong to the generated algebra. Projecting any other input
between them extracts its upper and lower off-diagonal entries. If both
orientations occur, even in different inputs, both matrix units belong
to the algebra and the algebra is full. Otherwise all inputs are triangular
in one common orientation, and a nonzero off-diagonal entry together with
the diagonal input spans that three-dimensional triangular algebra.

If no input has distinct eigenvalues, subtract scalar parts. Every remaining
matrix is nilpotent. Conjugate one nonzero nilpotent to E12. Another
nilpotent [[a,b],[c,-a]] obeys a^2+bc=0. If c=0, then a=0 and it commutes
with E12. If c is nonzero, E12 and this matrix generate the full algebra:
their commutator has two distinct eigenvalues. They cannot share an
invariant line, since E12 has the unique invariant line C e1 and the
other matrix sends e1 outside that line when c is nonzero. Thus the
preceding projector argument supplies both off-diagonal orientations. Thus the proper
noncommutative case is exactly the common triangular case already identified.

In that coordinate let g_t=diag(t,1), t>0. The profiles
eta_t=g_t eta g_t^(-1) converge, as t decreases to zero, to their diagonal
parts. Weak continuity implies that K(eta_t,.) is a tight family along any
sequence t_n decreasing to zero. Equivariance says that its output is the
pushforward of B~K(eta,.) under g_t B g_t^(-1). The21 entry is B21/t.
If K(eta,|B21|>=epsilon)>0 for any epsilon>0, these outputs would fail
tightness. Hence B21=0 almost surely. The output is upper triangular,
exactly the generated algebra in this case. We have proved

    supp K(eta,.) subset A(eta)                        (1)

for every weakly continuous equivariant kernel and every profile.
Probability support is closed, so the almost-sure subspace statement gives
the displayed support inclusion. The word Gaussian attains equality at
every profile; this is a sharp maximal-support result in the stated class.

#### 2. A merely Borel kernel can escape at a triangular profile

Take A with distinct eigenvalues lambda,mu and spectral idempotents
P_lambda,P_mu. For another input B set T=P_lambda B P_mu. If T is nonzero,
it is an invertible linear map between the two one-dimensional ranges.
There is a UNIQUE matrix C with

    C=P_mu C P_lambda, TC=P_lambda, CT=P_mu.            (2)

It is the inverse between those ranges, extended by zero on the other
range. In coordinates P_lambda=E11,P_mu=E22,T=tE12, it is C=t^(-1)E21.
Equation (2) defines it from the algebraic inputs without a star or norm.
Uniqueness proves covariance under simultaneous algebra automorphisms.
It is a Borel function on the nonzero-corner domain: locally it solves
a uniquely determined finite linear system with a nonzero pivot. Define
the feature to be zero when the eigenvalues coincide or the corner is zero.

Enhance the word Gaussian by adding independent circular complex Gaussian
coefficients times EVERY such inverse corner, for every ordered pair of
distinct recorded slots and both ordered eigenvalue pairs. There are at
most60 additional features. Eigenvalues may be measurably enumerated to
construct the kernel; the law does not depend on their enumeration because
all features receive iid coefficients. Complex conjugation or a slot
permutation permutes these features, so the law is covariant under all
simultaneous real algebra automorphisms and all slot permutations.

For commuting profiles all off-diagonal corners vanish. For any
noncommuting profile, either the word algebra is already full, or it is
triangular and one inverse corner supplies the missing matrix unit.
Consequently this explicit Borel kernel K_plus has support

    center,               all inputs central;
    C[A],                 inputs commute and some A is noncentral;
    full M2(C),           some inputs do not commute.                (3)

The first two restrictions hold for ANY equivariant probability kernel
by the stabilizer proof. Thus (3) is the maximal support for the merely
Borel class, also achieved simultaneously by one kernel. It does not
contradict (1), because K_plus is not weakly continuous everywhere.

For the actual triangular profile A=diag(1,-1),B=tE12, t nonzero, the
new inverse feature is t^(-1)E21. Its independent Gaussian coefficient
makes E|output21|^2=|t|^(-2); original word features have no21 entry.
For each fixed radius R, the probability |output21|<=R tends to zero
as t tends to zero. This is an explicit failure of tightness, not merely
a divergent second moment. At t=0 the kernel is instead supported on
the diagonal algebra. Weak continuity is therefore genuinely lost.

#### 3. Record support and scope of the escape

Every old word and inverse-corner feature remains present when a new
neighbor record is appended. Supports are nested. K_plus therefore has
the same finite-ancestor global formation construction and ongoing-support
proof as the word kernel. Evaluation on a finite ancestor graph remains
finite even though small nonzero corners can produce large coefficients.
No uniform moment or tightness-in-profile claim is made.

The compatible four-record seed from the companion note still works.
Neither kernel creates noncentral records from an empty or all-central
start. Independent-fiber naturality still forces central output everywhere;
both constructions consume a common algebra identification. The strict
continuous/Borel distinction is not a selected regularity principle, an
axiom amendment, or verification of the approved kinetic primitive.

### Full algebraic naturality and the support of a probability law

Personal conditional derivation, 2026-09-15. The chosen naturality group is
an explicit hypothesis, not a new interpretation adopted for the axioms.
These statements concern ordinary Borel probability measures on the algebra
M2(C), not density matrices, quantum instruments, or a selected physical law.

#### 1. A finite invariant measure cannot follow an escaping polynomial orbit

Let T be a unipotent linear map on a finite-dimensional real vector space.
For every v outside Fix(T), T^n v is a vector-valued polynomial in n with
a nonzero positive-degree leading coefficient, so ||T^n v|| tends to infinity.
If a probability measure mu is invariant under T, then for every ball B_R,

    mu(B_R)=integral 1B_R (`T^n v`) mu(dv).

Dominated convergence gives mu(B_R)=mu(B_R intersect Fix(T)). Increasing
R to infinity proves mu(Fix(T))=1. No moment, density or bounded-support
hypothesis was used. The norm is a temporary proof coordinate, not structure
added to the invariant measure or physical law.

Apply this to conjugation by U=I+E12 on M2(C), viewed as a real vector
space. For B=[[a,b],[c,d]],

    U^n B U^(-n)=[[a+nc, b+n(d-a)-n^2 c], [c,d-nc]].

The fixed subspace is c=0 and d=a. Conjugation by I+E21 similarly fixes
only b=0 and d=a. Therefore any probability measure invariant under both
of these conjugations, and hence any measure invariant under all inner
automorphisms of M2(C), is supported on the center C I. Conversely every
probability on that center is invariant under inner automorphisms.
For invariance under all real algebra automorphisms its scalar law must
also be invariant under complex conjugation.

In particular no such invariant probability has full topological support
on M2(C), or assigns positive probability to noncentral matrices. This
does not say there is no probability law on the full algebraic DOMAIN:
the intrinsic 0/I law and every conjugation-symmetric scalar law are
examples. Domain and support remain different notions.

The unipotent fixed-measure mechanism is established mathematics; the
related primary article *Generic subgroups of Lie groups*, section3, was
located by search. This proof specializes the mechanism directly to two
explicit matrices and imports no general homogeneous-space theorem.

#### 2. A one-input equivariant kernel stays in the input-generated algebra

Suppose K(A,dB) obeys simultaneous inner-conjugation covariance. Fix A.
Then K(A,.) is invariant under every invertible matrix commuting with A.

If A has two distinct eigenvalues, use a conjugate coordinate in which it
is diagonal. Its stabilizer contains diag(2,1/2), whose action multiplies
B12 by4 and B21 by1/4. A finite probability invariant under multiplication
by4 on C is concentrated at zero: equal measures of the disjoint annuli
4^k<=|z|<4^(k+1) must all be zero. Applying this also to the inverse
scaling forces both off-diagonal entries to vanish. The remaining matrices
are exactly C[A].

If A is a nontrivial Jordan block, its stabilizer contains I+E12 after
conjugation and rescaling its nilpotent part. The preceding unipotent
argument forces B=[[b0,b1],[0,b0]], again exactly C[A]. If A is scalar,
its stabilizer is the full group, and section1 forces scalar B=C[A].
Thus, in every case,

    K(A, C[A])=1.                                     (1)

This is a support theorem for one input; it is not a classification of
all kernels or a claim about two noncommuting inputs. Similarity/Jordan
coordinates only prove a coordinate-independent conclusion.

#### 3. Independent fibers and shared fibers are different hypotheses

If a forming site's algebra can be relabeled independently of ALL its
neighbour algebras, its relabeling fixes the input profile. An equivariant
kernel must then have an invariant output probability at every profile.
Section1 forces central support even when neighbour records are noncentral.
This is the independent-fiber naturality hypothesis.

If all site algebras have instead been identified with one common algebra
and only simultaneous relabeling is required, neighbour contents transform
with the output. Two noncommuting records can supply enough algebraic
structure for a noncentral law. The companion note gives a full-domain
kernel and a reachable example. Products of elements in different abstract
fibers are undefined until such a comparison/identification is supplied.
The existing lattice covariance clause alone does not choose between these
two internal action contracts.

Under the simultaneous action, an all-central input profile is still fixed
by every inner automorphism. Its output law is therefore central. Any
empty-start sequential construction with finite ancestor sets remains
central at every formed site, by induction through each finite ancestor
graph. This conclusion does not assume that every possible initial state
is empty or central; the companion compatible-seed example escapes it.

#### 4. Concrete controls on overbroad readings

Replacing all inner automorphisms by unitary conjugations changes the
answer: independent circular complex Gaussian matrix entries define a
full-support probability invariant under unitary conjugation. Its density
uses a supplied Hermitian norm. Conjugating by diag(2,1/2) multiplies
the variance of its12 entry by16, so it fails the full-inner hypothesis.
Compact symmetry does not establish full algebraic naturality.

A law can be covariant while a selected initial state is not invariant.
The realized-state primitive does not supply a probability measure invariant
under every automorphism. It is therefore invalid to infer central physical
records merely from that primitive. Conversely calling a kernel covariant
does not authorize multiplying neighboring algebra elements without a
specified comparison of their fibers.

The approved kinetic-isotropy primitive is unchanged and is not verified
by these support statements. They neither give a complete model of the
foundation nor force an axiom update. See BLOCK5_SCOPE_AND_NO_GO_REVIEW.md
for the attempted routes and surviving constructive escapes.

#### 1. Define the measure without a selected matrix basis or star

    B_eta=sum_(length(w)<=3) 2^(-length(w)) Z_w w(eta),

#### 2. Its support is exactly the algebra generated by the inputs

    supp K(eta,.)=Alg_C(I, recorded contents).          (2)

This may be the center, a two-dimensional commutative algebra, a proper

A formed output belongs to its formation-time input algebra. Later input

site, and permanent content. This is a classical kernel on recorded matrix

    (0,0,0)=A, (1,0,0)=A,
