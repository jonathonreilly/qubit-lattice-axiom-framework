## Proof

### 1. Action Dirac operator and regulator

The local staggered action couples the fermion to link variables. On smooth
links, the link expansion

```text
U_mu(x)^Y chi(x+mu)
  = [1 + a Y A_mu(x) + O(a^2)]
    [chi(x) + a partial_mu chi(x) + O(a^2)]
```

turns the symmetric nearest-neighbor action into the reconstructed local
Dirac operator

```text

```

on each physical left-handed mode, up to irrelevant higher-order lattice
corrections. The Fujikawa regulator is not an imported theorem here; it is the
finite-action heat-kernel regulator built from the same `D_A^dag D_A` operator
that already appears in the framework's finite-lattice trace notes.

### 2. 3+1 heat-kernel coefficient

With Wick-rotated Euclidean gamma matrices for the local 3+1 tangent
calculation,

```text
D_A^2 = nabla^2 + (1/2) sigma^{mu nu} Y F_{mu nu},
sigma^{mu nu} = (1/2)[gamma^mu, gamma^nu].
```

Only the second-order spin-curvature term contributes to
`tr_spin(gamma_5 ...)`. The paired runner verifies:

```text
tr_spin(gamma_5 sigma^{mu nu} sigma^{rho sigma})
  = nonzero multiple of epsilon^{mu nu rho sigma},
```

and

```text
int d^4k/(2 pi)^4 exp(-k^2) = 1/(16 pi^2).
```

Therefore the local Jacobian density is nonzero and proportional to
`Y^2 F wedge F` for an axial rotation, and to `Y^3 F wedge F` for the
left-handed U(1) gauge transformation, because the transformation inserts
one more factor of the generator `Y`.

### 3. Framework cubic trace

The retained graph-first left-handed surface has six `Y=+1/3` states and two
`Y=-1` states. The exact rational cubic trace is:

```text
6*(1/3)^3 + 2*(-1)^3 = 2/9 - 2 = -16/9.
```

This is not a fitted value, observational input, or Standard Model naming
convention.
It is the same finite-dimensional trace arithmetic used by the framework's
gauge-closure and anomaly notes.

### 4. No 3+1 abelian local counterterm cancels it

On the abelian local polynomial action surface in 3+1 dimensions, the
ghost-number-zero four-form counterterm candidates made from the connection
one-form `A` and curvature two-form `F=dA` are:

```text

A wedge A wedge F,
A wedge A wedge A wedge A.
```

For a single abelian one-form, `A wedge A = 0`, so the last two vanish. The
remaining `F wedge F` is gauge invariant:

```text

```

The anomaly cocycle is

```text

```

with ghost number one. It is nonzero when `F wedge F != 0` and cannot be the
BRST variation of any allowed 3+1 local counterterm in the action's
counterterm class. The paired runner enumerates this counterterm
space and checks the nonzero representative on a concrete two-plane field
strength background.

### 5. Ward obstruction

Gauge invariance of the quantum effective action requires the gauge variation
of the fermion measure plus local counterterms to vanish. Steps 1-4 give a
nonzero uncancellable local variation proportional to `Tr_LH[Y^3]`. Thus the
left-handed framework action alone has a U(1)^3 Ward-identity obstruction.

Adding opposite-chirality matter can cancel it. Without that cancellation, the
longitudinal gauge degree does not decouple from the quantum theory, so the
uncompleted chiral gauge action is inconsistent as a unitary gauge theory.
