## Proof

The left-handed traces are

```text
Tr[Y]        = 6*(1/3) + 2*(-1) = 0,
Tr[Y^3]      = 6*(1/3)^3 + 2*(-1)^3 = -16/9,
Tr[SU(3)^2Y] = 2*(1/2)*(1/3) = 1/3,
Tr[SU(2)^2Y] = 3*(1/2)*(1/3) + (1/2)*(-1) = 0,
SU(3)^3      = +2.
```

For the no-`nu_R` minimal right-handed completion, anomaly cancellation gives

```text
y_u + y_d = 2/3,
3*(y_u + y_d) + y_e = 0,
3*(y_u^3 + y_d^3) + y_e^3 = -16/9.
```

Therefore `y_e = -2`. The cubic equation gives

```text
y_u^3 + y_d^3 = 56/27.
```

Using

```text
(y_u + y_d)^3 = y_u^3 + y_d^3 + 3*y_u*y_d*(y_u + y_d),
```

we get

```text
y_u*y_d = -8/9.
```

So `y_u,y_d` are the roots of

```text
t^2 - (2/3)t - 8/9 = 0,
```

namely `4/3` and `-2/3`. The positive-charge convention chooses
`y_u=4/3`, `y_d=-2/3`.

Substituting these values into the all-left anomaly bookkeeping gives exact
zero for the full one-generation anomaly conditions.

## Boundary Lemmas

### B1. `nu_R` neutrality is not load-bearing in the no-`nu_R` proof

The minimal proof does not consume a `nu_R` value. A neutral singlet can be
added to the witness without changing any anomaly trace:

```text
nu_R : (1,1)_0.
```

If instead `nu_R` is included with free hypercharge `t`, then the family

```text
y_u  =  4/3 + t,
y_d  = -2/3 - t,
y_e  = -2   - t,
y_nu =  t
```

cancels `Tr[SU(3)^2Y]`, `Tr[Y]`, and `Tr[Y^3]` for every `t`. Thus
`y_nu=0` is a branch/convention only when the `nu_R` species is present.

### B2. The matter content is not anomaly-unique

Adding a vectorlike pair with charges `+a` and `-a` preserves `Tr[Y]` and
`Tr[Y^3]`. Therefore anomaly cancellation by itself does not prove minimal
matter content and does not exclude mirror/vectorlike matter. P-COMP-min is an
admitted minimal-completion premise, not a theorem of this note.

### B3. The absolute hypercharge scale is a convention

If all `Y` charges are scaled by a common nonzero factor `lambda`, all anomaly
zero equations remain zero. The ratio `+1:(-3)` on the left-handed surface and
the forced right-handed ratios are the invariant content; the absolute doubled
`Y` scale is a normalization convention unless separately bridged.
