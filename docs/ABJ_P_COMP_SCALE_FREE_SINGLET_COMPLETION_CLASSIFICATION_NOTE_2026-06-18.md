## Claim

This note isolates the exact finite algebra inside the ABJ bridge's
`P-COMP` premise.

Let `a != 0` be the scale of the native left-handed abelian surface:

```text
Q_L : (2,3)_a       six left-handed Weyl states,
L_L : (2,1)_(-3a)  two left-handed Weyl states.
```

Suppose the completion surface is the narrow `P-COMP` singlet template:

```text
u_R : (1,3)_x,
d_R : (1,3)_y,
e_R : (1,1)_z,
n_R : (1,1)_0,
```

with opposite chirality and with anomaly cancellation required for `Tr[Y]`,
`Tr[Y^3]`, `Tr[SU(3)^2 Y]`, `Tr[SU(2)^2 Y]`, and `Tr[SU(3)^3]`. Then the
completion charges are forced, up to swapping the two color-triplet singlet
labels:

```text
{x, y, z, n} = {4a, -2a, -6a, 0}.
```

At the existing `a = 1/3` normalization this is the usual one-generation
SM witness:

```text
(4/3, -2/3, -2, 0).
```

This is a scale-free classification of the completion arithmetic. It
does not derive the physical `P-COMP` premise itself.

## Proof

The left-handed anomaly traces on the scale-free surface are:

```text
Tr[Y]_LH            = 6a + 2(-3a) = 0,
Tr[Y^3]_LH          = 6a^3 + 2(-3a)^3 = -48a^3,
Tr[SU(3)^2 Y]_LH    = 2 * T(F) * a = a,
Tr[SU(2)^2 Y]_LH    = 3*T(F)*a + 1*T(F)*(-3a) = 0,
Tr[SU(3)^3]_LH      = 2.
```

Here `T(F) = 1/2`. In the chirality-signed convention used by the ABJ
bridge, opposite-chirality right-handed Weyl fields subtract from the
left-handed anomaly traces.

The two color-triplet singlet slots cancel `Tr[SU(3)^3]` by slot count:

```text
2 - 1 - 1 = 0.
```

The mixed color anomaly then gives:

```text
a - (1/2)(x + y) = 0,     hence     x + y = 2a.        (1)
```

The linear anomaly with the neutral singlet `n = 0` gives:

```text
0 - (3x + 3y + z + 0) = 0,
z = -3(x + y) = -6a.                                      (2)
```

The cubic anomaly gives:

```text
-48a^3 - (3x^3 + 3y^3 + z^3 + 0) = 0.
```

Substitute (1) and (2):

```text
3(x^3 + y^3) - 216a^3 = -48a^3,
x^3 + y^3 = 56a^3.
```

Using `x^3 + y^3 = (x+y)^3 - 3xy(x+y)` and `x+y = 2a`,

```text
8a^3 - 6a xy = 56a^3,
xy = -8a^2.
```

Thus `x` and `y` are the two roots of

```text
t^2 - 2a t - 8a^2 = 0 = (t - 4a)(t + 2a).
```

So `{x,y} = {4a,-2a}` and `z = -6a`, as claimed.

## Counterfactuals

This theorem deliberately records the open parts of `P-COMP`.

1. If the neutral singlet condition `n = 0` is removed, uniqueness fails.
   The equations leave a one-parameter family. In symmetric-product
   form, with `p = xy` and `q = zn`,

```text
x + y = 2a,
z + n = -6a,
q - p = 8a^2.
```

For example `(x,y,z,n) = (0, 2a, -2a, -4a)` cancels the same anomaly
traces but has no neutral singlet.

2. If the two color-triplet singlet slots are not supplied, the
`SU(3)^3` anomaly count is not canceled by this template. The color-slot
shape is part of the completion premise, not a theorem of this note.
