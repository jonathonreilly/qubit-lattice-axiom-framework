## Theorem

Let `a, x, y, z, n in R`, with `a != 0`. Supply the following three equations
and the additional hypothesis `n = 0`:

```text
E_mix = a - (x + y)/2 = 0,                              (1)
E_lin = -(3x + 3y + z + n) = 0,                        (2)
E_cub = -48a^3 - (3x^3 + 3y^3 + z^3 + n^3) = 0.       (3)
n = 0.                                                  (4)
```

The signs and multiplicities in (1)--(3) are data of the supplied algebraic
surface. Under these hypotheses,

```text
z = -6a,
xy = -8a^2,
{x, y} = {4a, -2a}
```

up to exchange of the labels `x` and `y`. Conversely, the two exchanged
branches

```text
(x, y, z, n) = (4a, -2a, -6a, 0),
(x, y, z, n) = (-2a, 4a, -6a, 0)
```

satisfy (1)--(4) exactly. Thus the displayed result is an exact implication
and classification of the supplied finite algebraic system.

## Derivation

Equation (1) gives

```text
x + y = 2a.                                             (5)
```

Using `n = 0`, equation (2) gives

```text
z = -3(x + y) = -6a.                                   (6)
```

Equation (3), after substituting (6), is

```text
-48a^3 - (3x^3 + 3y^3 - 216a^3) = 0,
x^3 + y^3 = 56a^3.                                     (7)
```

The symmetric-polynomial identity
`x^3 + y^3 = (x + y)^3 - 3xy(x + y)`, together with (5),
turns (7) into

```text
8a^3 - 6a xy = 56a^3.
```

Because `a != 0`, division by `-6a` is valid and yields

```text
xy = -8a^2.                                             (8)
```

Equations (5) and (8) make `x` and `y` the roots of

```text
t^2 - 2a t - 8a^2 = (t - 4a)(t + 2a),
```

which proves the two exchanged branches. Direct substitution gives zero for
each of (1)--(4), proving the converse.
