## Theorem

Let `H = C^V tensor C^2` be a finite nearest-neighbor bipartite lattice
factor `C^V` carrying the site-parity operator

```text
E |x> = epsilon(x) |x>,     epsilon(x) = (-1)^(x_1+x_2+x_3),
```

and the one-site spatial Clifford generators

```text
Gamma_i = I_V tensor sigma_i,      i = 1,2,3.
```

Then:

1. `E tensor I_2` anticommutes with any nearest-neighbor odd hopping
   operator on the site factor.
2. `E tensor I_2` commutes with every one-site spatial `Gamma_i`.
3. More generally, no factored current-surface candidate
   `Gamma_chi = E tensor B`, with `B in M_2(C)`, can anticommute with
   all three spatial `Gamma_i` unless `B = 0`. Therefore no such
   candidate can satisfy `Gamma_chi^2 = I`.

Consequently, the current staggered `epsilon` anticommutation statement is
not a spacetime Clifford-chirality bridge. It is a kinetic-operator grading,
not a proof that the staggered carrier supplies the ABJ `gamma_5` premise.

## Proof

Nearest-neighbor hopping changes the parity of exactly one coordinate, so
for any odd nearest-neighbor kinetic matrix `D`,

```text
(E D + D E)_{xy} = (epsilon(x) + epsilon(y)) D_{xy} = 0.
```

This proves the staggered chiral symmetry statement `{E,D}=0`.

But the one-site spatial Clifford generators act on the separate
`M_2(C)` factor:

```text
Gamma_i = I_V tensor sigma_i.
```

Therefore

```text
[E tensor I_2, Gamma_i] = 0,
{E tensor I_2, Gamma_i} = 2 E tensor sigma_i != 0.
```

Thus the scalar site-parity grading itself is not a Clifford `gamma_5`
for the spatial generators.

For any factored candidate `Gamma_chi = E tensor B`,

```text
{Gamma_chi, Gamma_i}
  = E tensor (B sigma_i + sigma_i B).
```

So anticommutation with all three `Gamma_i` would require a nonzero
`B in M_2(C)` satisfying `{B,sigma_i}=0` for `i=1,2,3`. Writing

```text
B = a I + b_1 sigma_1 + b_2 sigma_2 + b_3 sigma_3
```

gives

```text
{B,sigma_j} = 2 a sigma_j + 2 b_j I.
```

Requiring this to vanish for every `j` forces
`a=b_1=b_2=b_3=0`, hence `B=0`. A zero `B` cannot satisfy
`Gamma_chi^2=I`.

This proves the no-go for the epsilon-shortcut route.
