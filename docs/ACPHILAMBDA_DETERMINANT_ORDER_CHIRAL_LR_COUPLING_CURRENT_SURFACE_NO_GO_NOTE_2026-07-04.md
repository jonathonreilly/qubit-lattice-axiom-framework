## No-Go Statement

The current surface does not supply the determinant-order theorem required to
retire AC(i).

The count-once branch is structurally meaningful. The finite C3 regular
representation has one copy of each character, so a multiplicity/index readout
has `(singlet,doublet)=(1,1)`, while a dimension/trace readout has `(1,2)`.
That is why the supertrace/holomorphic route remains a real candidate.

But current source packets stop before the physical bridge:

| candidate ingredient | current status | missing bridge |
|---|---|---|
| non-SUSY index availability | available as route-boundary/meta support | does not select the physical readout |
| supertrace/holomorphic map | exact conditional algebra | does not prove the generation determinant is holomorphic/chiral |
| native `R^3`/`C3` mass | exact no-go for anticommuting selector in the native circulant family | cannot supply the first-order selector |
| separate chiral factor | algebraic L-R coupling shape exists | no physical `AC_phi_lambda -> M(b) tensor sigma_+` action/readout bridge |
| explicit Kahler-Dirac realization | concrete current realization | gives modulus-square/count-twice surface |

Therefore determinant-order closure still needs a new theorem:

```text
derive a physical chiral L-R coupling plus readout rule that makes the
generation determinant holomorphic/Pfaffian before the mass-energy readout.
```

Without that theorem, first-order/index availability remains support for an
open route, not AC(i) retirement.

## Exact Algebraic Boundary

The runner rechecks four finite facts.

First, the weight map is still

```text
r = w_d / (2 w_s),
```

so `(1,2) -> r = 1` and `(1,1) -> r = 1/2`.

Second, with

```text
Gamma_chi = (2/3)(I + C + C^2) - I,
H = a I + p C + q C^2,
```

the only C3-circulant `H` that anticommutes with `Gamma_chi` is zero. The
native circulant mass cannot be the first-order anticommuting selector.

Third, on the separate factor `R^3 tensor C^2`, a nonzero algebraic operator
can commute with `C tensor I` and anticommute with `I tensor sigma_z`. That is
the escape shape, not the physical bridge.

Fourth, the finite Dirac block

```text
D = [[0, M], [M^dag, 0]]
```

has determinant sign times `det(M) det(M^dag)` and `D^2` has `M M^dag` /
`M^dag M` blocks. This is the modulus-square/singular-value surface unless a
separate theorem supplies a chiral/Pfaffian/holomorphic quotient.
