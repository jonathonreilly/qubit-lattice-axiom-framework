## Exact Algebraic Boundary

For weights `(w_s, w_d)` assigned to the singlet and doublet energy channels,
the finite map used by the runner is

```text
r = w_d / (2 w_s).
```

Thus:

```text
(1, 2)       -> r = 1
(1, 1)       -> r = 1/2
(1/2, 1)     -> r = 1
```

The last line is the uniform-complex-rescaling objection: halving both the
singlet and doublet count does not produce the desired asymmetric branch.

For a finite Dirac block

```text
D = [[0, M], [M^dag, 0]],
```

the determinant is, up to the block sign, `det(M) det(M^dag)`. On the
positive mass/readout side this is the modulus-square surface, and `D^2`
contains `M M^dag` and `M^dag M`. This is the count-twice/singular-value
branch unless an additional theorem supplies a chiral, Pfaffian, or
holomorphic quotient before the readout.

For the transfer fork, the currently checked correspondence fixes kernel
normalization inside a selected mode set. It does not choose the mode set:

```text
Z_sector = 2 pi / g  -> rho = 1/2 -> r = 1
Z_orbit  = pi / g    -> rho = 1   -> r = 1/2
```
