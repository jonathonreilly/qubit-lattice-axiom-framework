## Route Analysis

### Frame 1: first-order determinant is a real result, but it relocates the fork

The first-order theorem computes that the one-component staggered measure
delivers a holomorphic determinant to first power. It also computes the exact
fork:

```text
holomorphic reading, c independent -> count-once / orbit horn
K-real reading, c = conj(b)         -> count-twice / sector horn
```

The theorem's own conclusion says the fork is relocated, not resolved. Which
horn is physical remains undecided.

### Frame 2: the theorem uses a declared probe coupling

The first-order theorem works with the rotation-channel probe
`A = aI + bU_R + cU_R^T`. It explicitly does not derive the generation Yukawa
coupling form or enumerate all C3-equivariant physical matter couplings. That
is acceptable for its bounded theorem, but it is not enough to retire the
measure-side realization binary.

### Frame 3: realized-state registration does not choose the measure horn

The realized-state primitive lets a row evaluate an already-defined state
functional at the supplied realized state. It supplies no measure, weighting,
occupancy pattern, or state-selection rule. Therefore it can house the
per-lane `r` value, but it cannot decide whether the matter action implements
the sector or orbit grain.

### Frame 4: K-real physicalization remains separate

If the physical monitor were derived to be the K-real family, the result would
not be `r = 1/2`; it would select the count-twice side of the fork. If the
physical readout were derived to be the holomorphic K-orbit quotient, that
could move the charged-lepton horn. Neither physicalization theorem is present
on the current surface.
