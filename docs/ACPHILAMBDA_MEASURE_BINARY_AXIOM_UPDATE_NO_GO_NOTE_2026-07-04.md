## Exact Carrier-Measure Check

Let `J_N` be the all-ones matrix and `B_N = J_N - I_N`. In the Hilbert-Schmidt
form,

```text
||I_N||^2 = N,
||B_N||^2 = N(N-1),
<I_N, B_N> = 0.
```

If a separate theorem selects equal Hilbert-Schmidt energy across those two
generator channels, then

```text
N a^2 = N(N-1)b^2,
r = b^2/a^2 = 1/(N-1).
```

For `N = 3`, this yields `r = 1/2` and
`Q = 1/3 + (2/3)r = 2/3`. That is exact support conditional on a supplied
generator-channel Hilbert-Schmidt scoring rule, not a derivation of the rule.

The same carrier also admits the retained boundary note's competing readings:

| reading | condition | result |
|---|---|---|
| generator-channel Hilbert-Schmidt | `3a^2 = 6b^2` | `r = 1/2` |
| dimension/per-mode | `a^2 = b^2` | `r = 1` |
| idempotent/eigenvalue | `(a + 2b)^2 = 2(a - b)^2` | `r = 17/2 - 6 sqrt(2)` |

Record additivity is compatible with all supplied finite coordinates. For a
normalized two-sector coordinate `p = d/(u+d)`, choosing
`d = p u/(1-p)` realizes any `p in (0,1)`. Thus both the generator-channel
endpoint and the dimension/per-mode endpoint are permitted once their
coordinates are supplied. Additivity does not rank them.
