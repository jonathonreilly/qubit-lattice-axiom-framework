## Hostile-guard

**(a) "This is just renaming the admission."** No — it is re-slotting with
three substantive consequences, none of which a rename has:

1. *Demand-shape change.* The Tier-A framing demands a future retained
   derivation of the selection. An **unconditional** law-level occupancy rule
   outputting a unique `r` would contradict the multi-lane dial (lanes
   registering other settings would falsify it), so the rule-shaped retirement
   demand was pointed at content the ontology assigns to the state, not the
   laws. Lane-conditional derivations (lane property → reading type) remain
   open routes and are unaffected.
2. *Audit-class change.* A Tier-A derivation-target dependency bounds
   dependents at `retained_bounded` until retired; realized-state data makes
   dependents *conditional on supplied registered data* — the masses' class,
   per the primitive's audit-pipeline treatment. These are different classes
   with different cascade behavior; the move is the same one Record and the
   scale reference already made (the `reclassified_primitives` block).
3. *Frontier relocation.* The open work moves from a rule-shaped slot the
   value chain no longer needs to two genuine derivation targets: the dynamical realization
   (first-order `det D` vs second-order `det D†D` — the staggered-corner
   question) and the exactness/stability account (below). Neither demands
   forcing a unique `r`.

**(b) "The counterfactual test fails — a different `r` in the charged-lepton
lane would change downstream physics, so something selects it."** The same
objection applies verbatim to the electron mass, and is answered the same
way: yes, something selects it — **the realized state**, which is exactly
the primitive's content (*the laws do not pick the state; the world does,
among the states the laws permit*). Counterfactual sensitivity is the
primitive's *test for* registered data, not evidence against it. The
parallel to the masses is exact at the functional level because `r` **is** a
function of the registered masses (S4.3). Where the parallel is honestly
imperfect: the mass values look generic, while the charged-lepton `r` sits
on a *derived distinguished cell* to `~3×10⁻⁶`. This note does not explain
that exactness and does not wave it off ("no coincidences" holds): the
derived geometry makes the registered location a stationary/attractor point
(S6; `flavor_r_half_stable_under_thermalizing_arrow`, retained_bounded;
`flavor_r_half_is_the_records_flow_separatrix`, retained_bounded) — i.e. a
point where a registered pattern *persists* — but "why exactly there" is
relocated, not resolved. It is named as the **exactness residual** inside
the `(i-realization)` frontier, the next path this opens.

**(c) "The primitive's register item 4 already says this — the note is
vacuous."** Item 4 records the G3 discipline as an *example* of
state-contingent data; the Tier-A registry simultaneously carries
sub-admission (i) as a *derivation-target admission*. On the value face the
two registries are in tension: the same content cannot be both supplied
registered data and a rule awaiting derivation. This note proves the
decomposition that resolves the tension (`(i-value)` vs `(i-realization)`)
and maps exactly what survives — content neither registry states.

**(d) "You are smuggling the orbit-occupancy premise."** No grain is adopted.
The charged-lepton lane's registered pattern *sitting on* the orbit cell is
comparator-labeled data (S4.4); a lane registering the sector cell would be
equally well-formed registration (S8.1 keeps both models alive). The
orbit-occupancy premise candidate remains a proposal in owner-decision
territory, unmodified; the reduction shows a third resolution path
(registration) exists that requires adopting **neither** horn for the value
chain.
