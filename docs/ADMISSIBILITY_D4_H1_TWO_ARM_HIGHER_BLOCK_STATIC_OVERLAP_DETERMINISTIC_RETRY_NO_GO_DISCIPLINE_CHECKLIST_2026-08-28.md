## N7 -- Steelman

A strong deterministic repair does not erase both probes.  When marked arms
meet, it can coalesce the conflict component into one physically connected
certificate, propagate a single root guard, and return one release signal to
all participating seams.  Because the parent darts orient the forest and the
collision seams are explicit, such a certificate need not carry a root ID.
Alternatively, a collision-relative port/projective phase may choose one
retry while remaining covariant.  Either mechanism destroys the identical
two-probe restart state that makes W_R possible.

This steelman still owes a bounded alphabet, visible overlap consistency,
deadlock-free hostile schedules, full cubic/complement covariance, and a
literal CP instrument.  It has not been attempted here, so the broad negative
is premature.
