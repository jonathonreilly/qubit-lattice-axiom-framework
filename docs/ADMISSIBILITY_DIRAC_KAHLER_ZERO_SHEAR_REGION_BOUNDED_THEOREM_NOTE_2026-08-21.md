## N2 — the criterion

**The hollow-corner lemma.** For a symmetric matrix a zero diagonal entry forces
its whole row to vanish, so

```
[[B, C],[C^T, 0]] >= 0   <=>   C = 0  and  B >= 0 .
```

The two halves are then solved separately, in closed form.

### The `C = 0` half

As a form in the eight local shears, `C` has **rank 8 on 256 cells** and **rank
7 on 128** — and the rank-7 cells are **exactly** the classes
`(e_x, p_x) in {(-1,0), (-1,2)}`, all 16 edges, with kernel the single direction
`(1,1,1,1,-1,-1,-1,-1)`: a **uniform shear profile odd under the site
reflection**. On the x-trivial class the pure-mass entries of `C` are the eight
local shears **one by one** at `+-m/8` (64 of 64), so there

```
C = 0   <=>   all eight local shears vanish,
```

for **every** `m != 0` and **every** `s_x`, with no genericity assumption.

### The `B >= 0` half

Write the diagonal of the quotient Hodge in closed form — an identity on all 16
quotient sites:

```
D(t,x)  =  ( nu_{t,x} + a_{t-1,x} + a_{t,x-1} + mu_{t-1,x-1} ) / 4 .
```

Then the mass part of `B` is exactly `m ( D(c,x) + D(c,pi(x)) ) / 2` at
`(x, pi(x))`, with `pi(x) = e_x (x - p_x)` — an identity in 384 of 384 cells,
not a census. All four summands of `D` are strictly positive on the cone
`nu > 0, |sigma| < 1`, so `D > 0` there.

> **THE 2-CYCLE THEOREM.** On every 2-cycle `{x, pi(x)}` of `pi`, the principal
> `2x2` minor of `B` is **traceless** — 1024 of 1024 slots — with off-diagonal
> exactly `m (D_x + D_y) / 2`, also 1024 of 1024. A **traceless** symmetric
> `2x2` is PSD only if it is **zero**, which forces `m (D_x + D_y) = 0`, i.e.
> `m = 0` on the cone.

Every non-x-trivial class has at least one 2-cycle, so `B >= 0` with `m != 0`
holds **exactly** when `pi = id`, i.e. `(e_x, p_x) = (+1, 0)`; and there
`B = m diag(D(c,.))`, so `B >= 0` exactly when `m >= 0`.
