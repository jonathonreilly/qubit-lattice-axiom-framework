## Theorem 1 — The Gaussian Law Supplies A Density-Operator Candidate

The centered noise satisfies

`E[Z Z^dagger]_(ik)=sum_j E[Z_(ij) conjugate(Z_(kj))]=2 delta_(ik)`.

The cross terms vanish. Because `C` is Hermitian,

`M_C := integral A A^dagger d mu_C(A)=C C^dagger+2I=C^2+2I`.

Therefore

`rho_C := M_C/Tr(M_C)=(C^2+2I)/(Tr(C^2)+4)`

is positive definite and has trace one. It varies when `C^2` has a non-scalar
part. Under simultaneous unitary conjugation,

`C -> V C V^dagger`, `rho_C -> V rho_C V^dagger`.

Translation and proper-cubic covariance follow from the already checked
neighbor-average rule. This is a mathematical density-operator extractor on
the displayed Gaussian family. The current axioms do not say that this
extractor is the physical state map.

## Theorem 2 — Effect Grade, Endpoints, And Descent

For every qubit effect `0<=E<=I`, define

`w_C(E)=Tr(rho_C E)`.

Then `0<=w_C(E)<=1`, `w_C(0)=0`, and `w_C(I)=1`. If a supplied finite ordered
menu `M=(E_1,...,E_r)` obeys `E_i>=0` and `sum_i E_i=I`, linearity gives

`sum_i w_C(E_i)=1`.

At fixed `C`, the value depends on the effect alone. If two supplied menus at
that condition associate labels with the same exact effect, they receive the
same value automatically. Thus the normalized grade, endpoints, and
fixed-condition same-effect descent are consequences of the constructed
density-operator extractor rather than separate probability primitives. If
apparatus programs change the complete neighbor condition, the resulting
`rho_C` may change; descent across those conditions is not proved here.

This formula is not imported as a physical Born rule. It is used below as the
explicit target mass of a partition constructed from the already existing
measure `mu_C`.

## Theorem 3 — Explicit Quantile Content Decoder

Define the centered real-trace statistic

`t_C(A)=Re Tr(A-C)`.

It is standard normal under `mu_C`: the two real diagonal noises contribute
variance `1/2` each. Let `Phi` be the standard-normal CDF and set

`u_C(A)=Phi(t_C(A))`.

For `0<y<1`, the probability-integral transform is immediate:

`mu_C({A:u_C(A)<=y})=P(t_C<=Phi^(-1)(y))=y`.

Hence `u_C` pushes `mu_C` to uniform Lebesgue measure on `(0,1)`.

For the supplied ordered menu, write

`p_i=w_C(E_i)`, `c_0=0`, `c_i=sum_(j<=i) p_j`.

Define

`d_(C,M)(A)=i` when `c_(i-1)<=u_C(A)<c_i`,

with the final endpoint assigned to label `r`. Each fiber is Borel, the fibers
partition `M_2(C)`, and

`mu_C(d_(C,M)^(-1)({i}))=c_i-c_(i-1)=p_i=w_C(E_i)`.

Because `rho_C` is positive definite, every nonzero positive menu effect has
strictly positive weight. The construction therefore covers every supplied
binary or ternary nonzero resolution in the full scaled-projector domain, and
in fact every supplied finite nonzero effect resolution.

The map `d_(C,M)` is a program-relative mathematical event label. It is not a
Record readout: the same `A` can receive a different label when `M` changes.
The current Record axiom contains no named scalar `I`, finite-additivity rule,
or value for absence. This construction imports none. A physical
identification would have to encode the program distinction in record content,

### Atomic deterministic-decoder boundary

`rho_nu=(integral A A^dagger d nu_C+I)/(integral Tr(A A^dagger)d nu_C+2)`.
