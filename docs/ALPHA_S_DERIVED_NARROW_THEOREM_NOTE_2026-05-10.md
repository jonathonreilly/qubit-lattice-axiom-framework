## Proof

Pure algebraic substitution.

`(P1)`. From `(D1)` and `(D2)`:

```text
alpha_LM^2  =  (alpha_bare / u_0)^2
            =  alpha_bare^2 / u_0^2
            =  alpha_bare * (alpha_bare / u_0^2)
            =  alpha_bare * alpha_s(v).
```

`(P2)`. From `(D1)` and `(D2)`:

```text
alpha_s(v) / alpha_LM  =  (alpha_bare / u_0^2) / (alpha_bare / u_0)
                       =  (alpha_bare / u_0^2) * (u_0 / alpha_bare)
                       =  u_0 / u_0^2
                       =  1 / u_0.
```

∎

All follow algebraically from `(D1)` and `(D2)`.
