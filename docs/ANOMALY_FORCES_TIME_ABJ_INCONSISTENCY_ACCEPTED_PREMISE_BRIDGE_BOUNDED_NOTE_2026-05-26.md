## Artifact checks

The runner verifies the anomaly and parity arithmetic directly, using
exact rational arithmetic where applicable and finite matrix checks as
diagnostics for the retained Clifford theorem:

- **(B1)** Anomaly traces for the LH SM content are computed by
  summing fermion contributions weighted by multiplicities:
    - `Q_L = (2, 3)_{+1/3}`: 2 (weak) × 3 (color) = 6 copies with `Y = 1/3`.
    - `L_L = (2, 1)_{-1}`: 2 (weak) × 1 (color) = 2 copies with `Y = -1`.
  - `Tr[Y] = 6 · (1/3) + 2 · (-1) = 2 - 2 = 0` (vanishes accidentally
    on LH alone; this is *not* one of the three nonzero traces but
    is recorded for completeness).
  - `Tr[Y^3] = 6 · (1/3)^3 + 2 · (-1)^3 = 6/27 - 2 = 2/9 - 18/9 = -16/9`
    (nonzero).
  - `Tr[SU(3)^2 Y] = 2_weak · T(F) · Y_Q = 2 · (1/2) · (1/3) = 1/3`
    (nonzero; with normalization `T(F) = 1/2` for the SU(3)
    fundamental).
  - `Tr[SU(2)^2 Y] = 3 · T(F) · Y_Q + 1 · T(F) · Y_L
                  = 3 · (1/2) · (1/3) + 1 · (1/2) · (-1) = 1/2 - 1/2 = 0`
    (vanishes; recorded for completeness).
  - `Tr[SU(3)^3] = +2 · A(F) · n_doublet = +2 · 1 · 1 = +2`
    (nonzero; with anomaly coefficient `A(F) = +1` for the SU(3)
    fundamental, summed over 1 quark doublet with chirality +1).

  All five trace evaluations are exact rationals in `Q`. Three of
  the five are nonzero: `Tr[Y^3]`, `Tr[SU(3)^2 Y]`, and
  `Tr[SU(3)^3]`.

- **(B2)** (P1) registers the ABJ implication: nonzero anomaly trace
  ⇒ non-unitary quantum gauge theory. The runner records (P1) as
  the accepted-premise packet entry and verifies that the parent
  theorem text contains the admission text matching (P1).

- **(B3)** With the right-handed SM singlet completion
  `(y_1, y_2, y_3, y_4) = (4/3, -2/3, -2, 0)`, the full (LH plus RH)
  anomaly traces are recomputed. RH Weyls contribute with opposite
  chirality sign (i.e. as `LH - RH` in the canonical anomaly trace
  convention; equivalently, CPT-conjugated to LH antiparticles).
  The runner computes each trace as an exact rational in `Q` and
  verifies cancellation:
  - `Tr[Y]_full = 0`;
  - `Tr[Y^3]_full = Tr[Y^3]_LH - Tr[Y^3]_RH = (-16/9) - (-16/9) = 0`;
  - `Tr[SU(3)^2 Y]_full = (1/3) - (1/3) = 0`;
  - `Tr[SU(2)^2 Y]_full = 0` (RH SU(2)-singlets carry zero `T(F)`);
  - `Tr[SU(3)^3]_full = (+2) - (+2) = 0` (1 LH color-fund quark
    doublet contributes `2` color-fund Weyls; `u_R + d_R` contribute
    `2` RH color-fund Weyls; the difference is zero);
  - Witten SU(2): 4 LH doublets total (3 color + 1 lepton), even
    count → zero global anomaly.

  All cancellations are exact rationals in `Q`.

- **(B4)** Chirality-operator existence. The runner checks the
  explicit even-dimensional chirality construction used by the
  retained Clifford theorem:
  - `gamma_5^2 = +I` (involution).
  - `{gamma_5, gamma_mu} = 0` for all generators `gamma_mu` of
    `Cl(d_s, d_t)`.

- **(B5)** Even-dimension forcing. The runner constructs the volume
  element `omega = gamma_1 gamma_2 ... gamma_d` for `d = 1, 2, ..., 6`
  and verifies, by direct matrix evaluation:
  - For `d` even: `omega` anticommutes with each `gamma_mu`, so a
    rescaled `gamma_5 = phase · omega` satisfies the chirality
    relations.
  - For `d` odd: `omega` commutes with each `gamma_mu` (i.e.,
    `omega` is central). The full no-chirality conclusion is supplied
    by the retained even-dimension narrow theorem; the runner only
    replays the finite volume-element parity behavior.

- **(B6)** With `d_s = 3` and `d = d_s + d_t` even, `d_t` is odd. The
  runner verifies the parity arithmetic for `d_t = 1, 2, 3, 4, 5`
  and confirms `d_t in {1, 3, 5, ...}`.

No PDG-observed value, no lattice action plaquette evaluation, no
