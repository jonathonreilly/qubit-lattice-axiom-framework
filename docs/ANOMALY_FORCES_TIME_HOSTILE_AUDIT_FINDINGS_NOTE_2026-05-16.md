### 1.4 Elon first-principles — what is the parent theorem, really?

Strip the framework conventions: the parent theorem's claim is

> "Cl(3) on Z³ produces gauge content `su(2)+su(3)+u(1)` with chiral
> fermion content `(2,3)_{+1/3} + (2,1)_{-1}`; ABJ anomaly cancellation
> + chirality grading + single-clock evolution force spacetime
> signature (3,1)."

The Cl(3) algebra is the SPATIAL Clifford algebra on a 3D lattice. It has 3
generators γ_1, γ_2, γ_3, and its volume element is γ_1 γ_2 γ_3 which is
CENTRAL (commutes with all generators) — by Lawson-Michelsohn, an odd-dim
Clifford algebra has no internal chirality grading that anti-commutes with
all generators.

So a γ_5 chirality (the kind ABJ needs) cannot live in Cl(3) per-site. It
must be supplied by some OTHER structure: an additional generator (extending
to Cl(3,1)), a staggered taste structure (the BZ-corner / Kogut-Susskind
correspondence), or a Z_2-graded doubling.

The parent theorem claims the chirality is supplied by "staggered ε(x) =
γ_5 carried by CPT_EXACT_NOTE.md". Finding F-C verifies whether this
identification is actually carried by the cited file.

## 2. Finding F-A: Admission (i) is structurally non-internalizable

PR #402 (`AXIOM_FIRST_LATTICE_WESS_ZUMINO_FUJIKAWA_Z4_THEOREM_NOTE_2026-05-02`)

The PR's load-bearing W4 step (no local counterterm cancels a nonzero
index on a closed periodic torus) relied on Lüscher/Adams admissions cited
but not re-proven within the note.

### 2.2 Structural obstruction

Three obstructions stack against the retained-primitives-only route:

1. **Nielsen-Ninomiya:** no local, Hermitian, translation-invariant,
   chirally-symmetric lattice Dirac operator without species doubling.
2. **No Ginsparg-Wilson on the staggered Dirac:** the framework's `D`
   does not satisfy `{γ_5, D} = a D γ_5 D`. Without GW, there is no
   t-independent index defined off-shell of zero modes and no rigorous
   map to the continuum anomaly trace `(1/16π²)∫ε F̃F`.
3. **W4 (no local counterterm) requires gauge cohomology:** standard
   lattice cohomology of admissible gauge fields (Lüscher 1999) provides
   this; staggered formulation does not.

The `STAGGERED_DIRAC_REALIZATION_GATE_NOTE_2026-05-03` explicitly flags
this as an open gate, not retained.

### 2.3 Recommended reframing

Either (a) admit Lüscher 1999 (or Hasenfratz-Niedermayer-Neuberger
overlap) as a named external lattice-QFT import on equal footing with
admissions (ii) and (iii), OR (b) lock the parent at `bounded_theorem`
permanently with the load-bearing class B annotation made structural
rather than provisional.

The current text's framing of "future promotion to positive_theorem
conditional on a successor companion for admission (i)" should be
retired in favor of one of the above.

## 3. Finding F-B: "Anomaly forces time" is mis-framed; d_t = 1 is baked in

**Claim:** the parent theorem's logic chain forces only `d_s + d_t = even`
(parity). The "exactly d_t = 1" comes from admission (iv)'s lattice block
ansatz `Λ = Z_τ × Z³`, which presupposes a one-dimensional time axis.

### 3.1 Inference chain analysis

Parsing the parent's §Proof Steps 1-5:

| Step | Claim | Class |
|---|---|---|
| S1 | Cl(3) on Z³ → gauge `su(2)+su(3)+u(1)` with LH content | cited (NATIVE_GAUGE_CLOSURE) |
| S2 | LH anomaly traces Tr[Y³]=−16/9, Tr[SU(3)²Y]=1/3, SU(3)³=2 nonzero | algebra |
| S3 | Nonzero ABJ trace ⟹ inconsistent | bare admission (i) |
| S4 | Solving anomaly cancellation gives SM hypercharges | algebra |
| S5 | Chirality grading needs γ₅: {γ₅, γᵤ}=0 | definition |
| S6 | Cl(p,q) volume element anti-commutes with all generators iff p+q even | Lawson-Michelsohn |
| S7 | d_s + d_t even; with d_s = 3, d_t ∈ {1, 3, 5, ...} | parity arithmetic |
| S8 | Single-clock codim-1 evolution: one U(t) = exp(−itH) | cited (admission iv) |
| S9 | Single U(t) ⟹ d_t ≤ 1 | semantic; circular (see §3.2) |
| S10 | d_t odd, d_t ≤ 1 ⟹ d_t = 1 ⟹ signature (3,1) | arithmetic |

### 3.2 The circular step

Admission (iv)'s source note
(`AXIOM_FIRST_SINGLE_CLOCK_CODIMENSION1_EVOLUTION_THEOREM_NOTE_2026-05-03`)
defines its lattice block as `Λ = (Z/L_τ Z) × (Z/L_s Z)^3` at line ~111,
with the staggered-Dirac action specifying `η_t(θx) = −η_t(x)` at line ~116
(a temporal axis labeled τ by convention).

This means the single-clock theorem **starts from** a manifold already
factorized into one temporal × three spatial coordinates. It does not
derive d_t = 1; it derives "given Λ = Z_τ × Z³, there is exactly one U(t)".

### 3.3 Honest restatement

The honest theorem statement is:

> Given (a) Cl(3) on Z³, (b) ABJ anomaly cancellation, (c) a chosen
> staggered-Dirac action on `Λ = Z_τ × Z³` with one designated temporal
> axis, (d) Wilson plaquette positivity: the lattice block has temporal
> dimension d_τ = 1 and spatial dimension d_s = 3. Under Osterwalder-
> Schrader Wick rotation (conditional on the audited_conditional
> emergent-Lorentz program), the reconstructed Lorentzian QFT has
> signature (3,1).

The "anomaly forces time" framing collapses the inheritance of d_t from
A3 into the anomaly cancellation step, hiding that ABJ contributes only
the d_s + d_t = even parity.

### 3.4 Recommended source-note repair

Retitle parent from "Anomaly Cancellation Forces 3+1 Spacetime" to
"Anomaly Cancellation is Consistent with (3,1) Given the Staggered
Single-Clock Structure" (or similar). Update §Theorem to make explicit
that d_t = 1 is INHERITED from admission (iv)'s lattice ansatz, not
derived from ABJ.

## 4. Finding F-C: Admission (iii) routing is broken

**Claim:** the parent theorem's admission (iii) routing to
`CPT_EXACT_NOTE.md` is unsupported by the cited file. The
ε(x) = staggered γ_5 identification is not made there.

### 4.1 What CPT_EXACT_NOTE actually contains

Programmatic check (see runner Part 1):

```text
grep -c "gamma_5\|gamma5\|γ_5\|γ5" docs/CPT_EXACT_NOTE.md  →  0
```

CPT_EXACT_NOTE has ZERO occurrences of the γ_5 token. The note identifies
ε(x) = (-1)^(x_1+x_2+x_3) as the **C operator** (charge conjugation),
satisfying `C·H·C = -H`. This is the spectral-flip property of charge
conjugation, not a chirality identification.

### 4.2 The framework's internal NO-GO on per-site γ_5

`NO_PER_SITE_CHIRALITY_THEOREM_NOTE_2026-05-02` proves that no element
γ_5 ∈ M_2(C) satisfies {γ_5, σ_i} = 0 for all three Pauli generators.
The Cl(3) volume element σ_1 σ_2 σ_3 = i·I_2 is CENTRAL, commuting with
all generators — exactly the OPPOSITE of γ_5's required anti-commutation.

So the framework has both:
- (a) a proven internal NO-GO against per-site γ_5 in Cl(3)
- (b) a parent theorem citing a chirality identification that the cited
  file does not contain

These are inconsistent.

### 4.3 The sister theorem's explicit disclaimer

`CLIFFORD_VOLUME_CHIRALITY_EVEN_DIMENSION_NARROW_THEOREM_NOTE_2026-05-10`
(audited_clean) explicitly states (line ~219):

> "does not identify the volume-element chirality with any physical
> staggered-sublattice realization (e.g. ε(x) of CPT_EXACT_NOTE.md);
> that identification is a separate downstream realization step."

So the sister theorem explicitly DISCLAIMS the identification that the
parent theorem claims is internalized.

### 4.4 Where does γ_5 actually come from?

The actual chirality (if any) in the framework's staggered formulation
must come from the BZ-corner / taste-cube structure of the staggered
Dirac (`STAGGERED_DIRAC_REALIZATION_GATE_NOTE_2026-05-03`). That gate
is currently OPEN: "Open. ... not been packaged as a single end-to-end
canonical proof".

### 4.5 Recommended source-note repair

The parent's admission (iii) should be reclassified as either:
- (a) a BARE external admission to Kogut-Susskind 1975 / Karsten-Smit
  1981 staggered-to-Dirac correspondence (alongside admission (i)), OR
- (b) ROUTED to the staggered-Dirac realization gate
  (`STAGGERED_DIRAC_REALIZATION_GATE_NOTE_2026-05-03`) with explicit
  acknowledgment that the gate is currently open.

The current text claiming the routing goes to CPT_EXACT_NOTE
overstates internalization. The parent has TWO bare external
admissions, not one.
