## Statement (narrowed)

Let `H = Σ_X h_X` be a Hermitian Hamiltonian on the finite block
`Λ ⊂ Z^3` with each `h_X` supported on a region of diameter `≤ R_int`
and with operator norm `‖h_X‖ ≤ J`. Define the per-site interaction norm
and finite interaction adjacency degree by

```text
    J_*    :=  max_{z ∈ Λ}  Σ_{X ∋ z} ‖h_X‖
    D_int  :=  max_{z ∈ Λ} |{w ∈ Λ : w ≠ z and some X contains z, w with h_X ≠ 0}|.
```

For nearest-neighbour cubic interactions `D_int = Z_lat = 6`; for general
finite-range interactions on a finite cubic block `D_int` is finite. Let

```text
    v_LR  =  2 · e · J_* · R_int · D_int                               (1)
```

be the Lieb–Robinson velocity.

**(L1) Lieb–Robinson commutator bound.** For any local Cl(3) operators
`A` at site `x` and `B` at site `y`,

```text
    ‖ [ A(t), B ] ‖  ≤  2 · ‖A‖ · ‖B‖ · exp( −(d(x, y) − v_LR |t|) / ξ )   (2)
```

with `ξ` an `O(R_int)` length scale fixed by the lattice geometry.

**(L3) Lattice light cone.** The information-theoretic lattice "light
cone" is the region `d(x, y) ≤ v_LR |t|`. Outside it, two local
observables commute up to exponentially small terms: the lattice
analogue of microcausality.

**(L4) Cl(3)-specific finite constant (repaired bound).** Each local
term `h ∈ Cl(3)` evaluated on the minimal complex spinor module has
finite operator norm, bounded by the **triangle (ℓ¹) coefficient-norm**

```text
    ‖h‖  =  ‖ Σ_α c_α γ^α ‖  ≤  Σ_α |c_α| · ‖γ^α‖  =  Σ_α |c_α|          (3')
```

where `{γ^α}` are the eight Hermitian Cl(3) generators on the minimal
complex spinor module, each with `‖γ^α‖ = 1`. Hence the single-term
bound `J` is finite at canonical normalization, and since a finite-range
local rule touches each site with at most `N_touch < ∞` nonzero terms,

```text
    J_*  ≤  N_touch · J  <  ∞,                                          (3'')
```

so the velocity `v_LR` in (1) is finite.

**Out of scope of this note (named open bridge — not a no-go).** The
parent note's **L2 / equation (3)**, the spatial cluster-decomposition
bound

```text
    | ⟨A_x B_y⟩_ρ − ⟨A_x⟩_ρ ⟨B_y⟩_ρ |  ≤  C · ‖A_x‖ · ‖B_y‖ · exp(−d(x, y) / ξ_β),
```

is **not** a load-bearing claim of this narrowed note. Lieb–Robinson
finite-speed control (L1) does not by itself prove static spatial

## Proof

### (L1) Lieb–Robinson commutator bound

The proof is the standard finite-lattice Lieb–Robinson argument, used as
the *technique* (not a numerical import). For a local operator `A`
initially supported on `X`, `A(t) = e^{iHt} A e^{−iHt}`, and Duhamel's
formula gives the integral inequality

```text
    ‖ [ A(t), B ] ‖  ≤  ‖ [A, B] ‖  +  2 ‖B‖ Σ_Z Λ(t) ‖[h_Z, A]‖.       (4)
```

The per-iteration operator-norm estimate uses the per-site sum, not just
the single largest local term:

```text
    Σ_{Z : Z ∩ supp(A_s) ≠ ∅} ‖[h_Z, A_s]‖
        ≤  2 ‖A_s‖ Σ_{Z : Z ∩ supp(A_s) ≠ ∅} ‖h_Z‖
        ≤  2 ‖A_s‖ |supp(A_s)| J_*.                                     (4a)
```

Iterating yields a series in powers of `J_* · t`; the `n`-th term has
support extending at most `n · R_int` sites from `supp(A)`. The number
of interaction paths of length `n` between `x` and `y` is bounded by
`D_int^n`, and vanishes for `n < d(x, y) / R_int`:

```text
    N_paths(x, y, n) ≤ D_int^n  for d(x, y) ≤ n R_int;
    N_paths(x, y, n) = 0        for n < d(x, y) / R_int.                (5)
```

Combining (4), (4a), and (5) gives a geometric/factorial series whose
resummation, via the elementary inequality `(a/n)^n ≤ e^{−n} e^{n log(a/n)}`
expanded around `n = d(x, y) / R_int`, produces

```text
    ‖ [ A(t), B ] ‖  ≤  2 ‖A‖ ‖B‖ · exp( −(d(x, y) − v_LR |t|) / ξ )    (6)
```

with `v_LR = 2 e J_* R_int D_int` and `ξ = R_int`. This is (L1) and (2).
The runner exhibits the exponential envelope on a free-fermion lattice
representative (CHK3) and checks that the LR-1972 bound is never violated
in the nontrivial regime `d > v_LR |t|`.

### (L3) Lattice light cone

(L3) is the contrapositive of (L1): for `d(x, y) > v_LR |t|` and any
tolerance `ε > 0`, choosing `d(x, y)` large enough makes the right-hand
side of (6) fall below `ε`, so `[A_x(t), B_y]` is below `ε` in operator
norm. This is the lattice analogue of microcausality. The runner
exhibits, at each tested time, a finite distance threshold past which the
commutator proxy is below tolerance (CHK4).

### (L4) Cl(3)-specific finite constant (repaired)

The parent Step 6 used the Euclidean coefficient-norm bound
`‖h‖ ≤ (Σ_α |c_α|² ‖γ^α‖²)^{1/2}`. This is **false** for general
Hermitian elements: the audit witness `h = I + σ_z` has operator norm
`2`, while the Euclidean expression gives `√2`. The valid
finite-dimensional bound is the **triangle inequality** applied to the
operator norm:

```text
    ‖ Σ_α c_α γ^α ‖  ≤  Σ_α ‖ c_α γ^α ‖  =  Σ_α |c_α| · ‖γ^α‖.
```

On the minimal complex spinor module each Hermitian Cl(3) generator is a
Pauli word times a phase, so `‖γ^α‖ = 1`, giving (3'):
`‖h‖ ≤ Σ_α |c_α|`. On the witness `I + σ_z` this returns
`1 + 1 = 2 = ‖h‖`, exactly tight. Therefore the single-term norm `J` is
finite at canonical normalization, and a finite-range local rule with at
most `N_touch < ∞` terms per site gives `J_* ≤ N_touch · J < ∞` (3''),
and hence `v_LR` is finite. (An equivalent valid route is the Frobenius
operator bound `‖h‖_2 ≤ ‖h‖_F`; the runner verifies both the triangle
bound and the failure of the Euclidean bound by random sampling and on
the explicit witness, CHK1/CHK2.) ∎
