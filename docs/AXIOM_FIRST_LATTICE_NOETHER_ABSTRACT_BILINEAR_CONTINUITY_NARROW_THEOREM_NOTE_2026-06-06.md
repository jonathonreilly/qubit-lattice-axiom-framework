## Claim

Let `I` be a finite index set. Let `{E_pq : p,q in I}` be the matrix-unit
Lie algebra with

```text
[E_ij, E_pq] = delta_jp E_iq - delta_qi E_pj.                         (B)
```

For an arbitrary number-conserving bilinear

```text
H = sum_{i,j in I} c_ij E_ij
```

with symbolic coefficients `c_ij`, define the local number density

```text
rho_p := E_pp
```

and the oriented inflow current from `q` to `p`

```text
J_{p<-q} := i ( c_qp E_qp - c_pq E_pq ),       q != p.                 (J)
```

Then:

1. **Local continuity.**

   ```text
   d rho_p / dt := i[H, rho_p] = sum_{q != p} J_{p<-q}.                (C1)
   ```

   Equivalently, with `(div J)_p := - sum_{q != p} J_{p<-q}`,

   ```text
   d rho_p / dt + (div J)_p = 0.                                      (C2)
   ```

2. **Global conservation.**

   ```text
   Q := sum_p rho_p,        i[H,Q] = 0.                               (C3)
   ```

3. **Exact support envelope.** The current on the unordered pair `{p,q}`
   depends only on `c_pq` and `c_qp`, and vanishes when both coefficients
   vanish. Therefore a finite-range Hamiltonian has finite-range currents,
   a nearest-neighbour Hamiltonian has nearest-neighbour currents, and an
   all-to-all Hamiltonian has all-to-all current support. Noether continuity
   preserves the Hamiltonian coefficient support envelope; it does not upgrade
   an arbitrary bilinear to nearest-neighbour locality.

4. **Orientation antisymmetry.**

   ```text
   J_{p<-q} = - J_{q<-p}.                                             (C4)
   ```

These statements are exact identities in the finite matrix-unit algebra and do
not depend on a staggered realization.

## Proof

The only algebraic input is `(B)`. For fixed `p`,

```text
[E_ij, E_pp] = delta_jp E_ip - delta_pi E_pj.
```

Hence

```text
i[H, rho_p]
  = i sum_{i,j} c_ij (delta_jp E_ip - delta_pi E_pj)
  = i sum_i c_ip E_ip - i sum_j c_pj E_pj
  = sum_{q != p} i(c_qp E_qp - c_pq E_pq),
```

where the `q=p` term cancels. This is `(C1)`, and `(C2)` is just the definition
of outflow divergence. Summing `(C1)` over `p`, every oriented pair appears with
opposite signs, so `i[H,Q]=0`. The support-envelope and orientation statements
are immediate from `(J)`.
