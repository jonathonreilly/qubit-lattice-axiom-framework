## 2. Setup and definitions

- **Carrier.** The staggered-only surface, as in the RP and
  spectrum-condition rows: `L` sites on an open chain (finite
  representative of the Lattice-axiom `Z³` substrate), one qubit per
  site (Quantum-axiom surface under Jordan-Wigner), `dim H_phys = 2^L`.
  The dynamics is the free
  staggered fermion many-body Hamiltonian
  `H = Σ_xy h_xy (c_x† c_y − ½δ_xy)` with `h_xx = m(−1)^x`,
  `h_{x,x+1} = i/2` (Hermitian; `m = 0.3`), built by Jordan-Wigner —
  the same construction family as
  `scripts/axiom_first_spectrum_condition_check.py`. After the
  spectrum-condition normalization the reconstructed Hamiltonian is
  `H − E_0 ≥ 0` with the vacuum `|Ω⟩` the ground state.
- **Local algebra.** For a left-anchored region `O = {0,…,R−1}`,
  `A(O) := B(H_O) ⊗ 1`, `d_O = 2^R`, `d_Oc = 2^(L−R)`. For
  left-anchored `O` this tensor factor coincides exactly with the
  fermionic CAR algebra generated by `{c_x, c_x† : x ∈ O}` (the
  Jordan-Wigner strings of these modes stay inside `O`); interior
  fermionic regions carry a parity subtlety and are out of scope
  (boundary B-4).
- **Schmidt data.** `v = Σ_k s_k e_k ⊗ f_k` with `s_1 ≥ … ≥ s_r > 0`;
  `ρ_O = Tr_Oc |v⟩⟨v| = Σ_k s_k² |e_k⟩⟨e_k|`; `r = rank ρ_O =
  rank ρ_Oc`.
- **Cyclic / separating.** `v` is cyclic for an algebra `M` if
  `Mv` is dense (here: spans `H_phys`); separating if `Bv = 0`,
  `B ∈ M` implies `B = 0`.
- **Time-translated algebra.** `α_t(A) = e^{itH} A e^{−itH}`;
  `A_T(O) :=` the *-algebra generated by `{α_t(A) : A ∈ A(O),
  t ∈ R}`.

## 3. Statements

### 3.1 Theorem RS-1 (finite-lattice cyclicity/separating dichotomy; exact)

For any unit vector `v ∈ H_O ⊗ H_Oc` with Schmidt rank `r`:

- **(R1′)** `A(O)v = H_O ⊗ supp ρ_Oc`, so `dim A(O)v = d_O · r`.
- **(R2′)** `v` is **cyclic** for `A(O)` ⟺ `r = d_Oc`
  (possible only when `d_O ≥ d_Oc`).
- **(R3′)** `v` is **separating** for `A(O)` ⟺ the map
  `A ↦ Av` is injective ⟺ `r = d_O` ⟺ `ρ_O` has full rank ⟺ `v`
  is cyclic for `A(O)' = 1 ⊗ B(H_Oc)`.
- **(R4′)** `v` is cyclic **and** separating for `A(O)` ⟺
  `r = d_O = d_Oc` (balanced cut, full Schmidt rank).

This is unconditional, with proof in §4.1 from the Schmidt
decomposition plus the standard commutant identity — pure linear
algebra on the Quantum tensor structure. It replaces the continuum
statement: for a small region (`d_O < d_Oc`) the honest
finite-lattice Reeh-Schlieder property is the **separating** clause
(R3′) — "no nonzero local operator annihilates the vacuum" — and
equal-time cyclicity is **impossible**.

### 3.2 Certificate RS-2 (the staggered vacuum is separating; per-carrier)

On the `L = 6` and `L = 8` open staggered carriers (`m = 0.3`), the
vacuum's reduced state `ρ_O` has full rank for every tested region
`R = 1, 2, 3` (runner checks 4, 10; min eigenvalues `1.9e-1` down to
`4.1e-8`). By RS-1 (R3′), `|Ω⟩` is separating for each such `A(O)`
and cyclic for each commutant `A(O)'`. This is verified **exactly**
per carrier and per region — it is not derived for all sizes, and
cannot be derived from the gap plus the spectrum condition alone
(Proposition RS-X below exhibits a gapped counterexample).

### 3.3 Corollary RS-3 (time-translated cyclicity; genericity exposed)

On the `L = 6` carrier, `A_T(O)' = C·1` (computed exactly: the
largest `ad_H`-invariant subspace of `A(O)'` collapses
`256 → 64 → 16 → 4 → 1`), hence `A_T(O) = B(H_phys)` by the
finite-dimensional double-commutant theorem, hence `A_T(O)v` is dense
for **every nonzero** `v ∈ H_phys`. Two consequences are stated on
the claim's face:

- **Not vacuum-specific.** The cyclicity conclusion holds for every
  nonzero vector; the runner exhibits the same word set cyclic for
  excited eigenstates (check 12). RS-3 is a property of the pair
  `(A(O), H)`, not of `|Ω⟩`.
- **Not local.** `α_t(A)` has global support for `t ≠ 0` (exact
  strict locality fails on the lattice), so `A_T(O)` is not a local
  algebra and RS-3 is **not** the continuum Reeh-Schlieder theorem.

### 3.4 Proposition RS-X (the boundaries are load-bearing; certificate grade)

- **(X1)** The mass-only carrier (`hop = 0`) has `H ≥ 0`, gap
  `= 0.3 > 0`, but a product vacuum (Schmidt rank 1) annihilated by
  the local projector `n_0 ∈ A(O)`: the separating property is
  state-sensitive and does not follow from gap + positivity
  (check 8).
- **(X2)** The `L = 6` **periodic** staggered carrier pins a
  half-chain correlation eigenvalue at exactly 1: Schmidt rank
  `4 < 8`, and an explicit unit-norm annihilator in the half-chain
  algebra kills the vacuum (check 7). Full Schmidt rank is not even
  generic *within the framework's free carriers* — it must be
  certified per carrier and per region.
- **(X3)** A large region (`d_O > d_Oc`) is cyclic but **not**
  separating (check 9): equal-time cyclicity is a large-region
  triviality, not Reeh-Schlieder content.

## 4. Proofs

### 4.1 Proof of RS-1

Write `v = Σ_{k=1}^{r} s_k e_k ⊗ f_k`, `s_k > 0`, `{e_k}, {f_k}`
orthonormal. For `A ∈ B(H_O)`: `(A ⊗ 1)v = Σ_k s_k (A e_k) ⊗ f_k`.

**(R1′).** As `A` ranges over `B(H_O)`, the tuples `(A e_1, …, A e_r)`
range over all of `H_O^r` (the `e_k` are linearly independent), so
`A(O)v = span{u ⊗ f_k : u ∈ H_O, k ≤ r} = H_O ⊗ supp ρ_Oc`,
of dimension `d_O · r`.

**(R2′).** `A(O)v = H_phys` ⟺ `supp ρ_Oc = H_Oc` ⟺ `r = d_Oc`.
Since `r ≤ min(d_O, d_Oc)`, this needs `d_O ≥ d_Oc`.

**(R3′).** `(A ⊗ 1)v = 0` ⟺ `A e_k = 0` for all `k ≤ r` ⟺
`A` vanishes on `supp ρ_O`. So a nonzero annihilator exists iff
`supp ρ_O ≠ H_O` iff `r < d_O`. The commutant identity
`(B(H_O) ⊗ 1)' = 1 ⊗ B(H_Oc)` is the standard von Neumann
double-commutant fact (admitted-context linear algebra; the inclusion
direction is machine-checked exactly in runner check 1); applying
(R1′)-(R2′) with the factors swapped gives: `v` cyclic for
`1 ⊗ B(H_Oc)` ⟺ `r = d_O`. Hence separating-for-`A(O)` ⟺
cyclic-for-`A(O)'`, the standard equivalence, here with both sides
characterized by the same rank condition.

**(R4′).** Conjunction of (R2′) and (R3′). ∎

### 4.2 Proof of RS-3 (lemma + double commutant)

**Lemma.** `A_T(O)' = W`, where `W` is the largest
`ad_H`-invariant subspace of `A(O)'`.
*Proof.* `X ∈ A_T(O)'` ⟺ for all `t, A`: `[X, α_t(A)] = 0` ⟺ for
all `t`: `α_{−t}(X) ∈ A(O)'`. In finite dimension `t ↦ α_t(X)` is
entire, so the orbit stays in the (closed) subspace `A(O)'` for all
`t` iff all derivatives at `t = 0` lie in it, i.e. iff
`ad_H^n(X) ∈ A(O)'` for all `n ≥ 0` — which is exactly membership in
the largest `ad_H`-invariant subspace `W` of `A(O)'`. ∎

The runner computes `W` exactly by iterated nullspaces starting from
`A(O)' = 1 ⊗ B(H_Oc)` (check 11); on the `L = 6` carrier
`W = C·1`. Since `A_T(O)` is a finite-dimensional *-algebra
containing 1, `A_T(O) = A_T(O)'' = (C·1)' = B(H_phys)`. Every
nonzero vector is trivially cyclic for `B(H_phys)`. ∎

*Why words of length 3 appear in check 12:* `H` conserves fermion
number and `|Ω⟩` lies in the `N = 3` sector; words of length ≤ 2 in
parity-odd generators reach only `ΔN ∈ {0, ±1, ±2}` and miss the
one-dimensional `N = 0, 6` sectors (rank 62 of 64). This is a
truncation artifact of the word set, not of the algebra.

### 4.3 RS-X certificates

X1: with `hop = 0` the ground state is the odd-sublattice Fock
product state; `n_0 = c_0† c_0 ∈ A(O)` annihilates it exactly while
`‖n_0‖ = 1` (check 8). X2: the periodic `L = 6` correlation matrix
restricted to a half chain has eigenvalues
`{0.1121, 0.1121, 1.0000}`; the pinned eigenvalue forces Schmidt rank
`2² = 4 < 8`, and `A = |u_1⟩⟨u_ker|` built from the kernel of `ρ_O`
satisfies `‖A‖ = 1`, `‖(A ⊗ 1)Ω‖ < 1e-16` (check 7). X3: at
`O = {0,1,2,3}` on `L = 6`, `r = 4 = d_Oc` so `A(O)Ω` spans all 64
dimensions, while `r < d_O = 16` yields an exact annihilator
(check 9).

## 5.5 No-Go Discipline Gate for the Negative Boundary

This row ships a bounded positive theorem plus a narrow negative
boundary: finite tensor-factor **equal-time** cyclicity for a small
region is impossible. The gate below is scoped only to that negative
boundary; it does not claim that the continuum Reeh-Schlieder theorem
cannot emerge after a separate continuum/type-III/locality limit.

- **N1 alternative routes.** Five routes were checked. Equal-time
  local cyclicity fails by RS-1: `dim A(O)v = d_O r ≤ d_O² < d_O d_Oc`
  for small `O`. Continuum analytic continuation fails because the
  lattice input is a spatial region, not a spacetime-open region, and
  exact strict locality of `α_t(A)` fails for `t ≠ 0`. The
  time-translated algebra route succeeds only as RS-3, where
  `A_T(O)=B(H_phys)` is non-local and vector-generic, not a local
  vacuum theorem. The gap-plus-positivity route fails by the mass-only
  product-vacuum counterexample. A carrier-uniform route fails by the
  `L=6` periodic half-chain counterexample with Schmidt rank `4/8`.
- **N2 wall independence.** The dimension wall, strict-locality wall,
  full-rank-vacuum wall, and finite-carrier/continuum wall are
  independent: closing strict locality would not change the finite
  equal-time dimension bound; proving a full-rank vacuum would not make
  small-region equal-time cyclicity possible; taking a continuum limit
  is a separate theorem surface and does not follow from the finite
  carrier certificates.
- **N3 hidden-wall scan.** "Framework carrier" is tied to the Quantum
  and Lattice axioms plus the RP/spectrum-condition staggered
  construction cited in §6. "Standard" inputs are only Schmidt
  decomposition/SVD and finite-dimensional double-commutant linear
  algebra. Cluster decomposition and microcausality are explicitly
  non-load-bearing context.
- **N4 residual matching.** The residuals match exactly: old equal-time
  density is attacked by RS-1/check 6; old continuum time-translation
  import is attacked by the strict-locality boundary and RS-3; old
  vacuum-uniqueness import is replaced by per-carrier gap checks 3/10;
  old hidden genericity is attacked by check 12.
- **N5 rhetoric audit.** "False" is used only for finite tensor-factor
  equal-time cyclicity in small regions. "Not local" is used only for
  `A_T(O)` with time translates. "Cannot follow from gap + spectrum
  condition alone" is limited to the separating property and is witnessed
  by the product-vacuum counterexample.
- **N6 partial-closure scan.** Legitimate future closure paths remain:
  a uniform full-rank theorem for the staggered vacuum; an interior
  fermionic-region parity-local algebra theorem; or a continuum/type-III
  local-algebra theorem with true spacetime-open localization. None is
  supplied here, so this row stays bounded.
- **N7 steelman.** A hostile reviewer can argue that the continuum
  Reeh-Schlieder theorem may reappear after the thermodynamic/continuum
  limit, where finite tensor-factor dimension counting no longer
  applies and local algebras become type III. This note accepts that
  steelman by making no continuum claim and by fencing RS-3 as non-local
  finite-dimensional genericity.
- **N8 cross-cycle echo.** Similar overclaims in the repo came from
  importing continuum or physical-matching structure into finite lattice
  rows. This repair follows the established bounded-theorem pattern:
  prove the finite carrier certificate, state residual walls, and leave
  continuum/physical matching to a separate retained authority.

Gate result: **PASS** for the narrow negative boundary above; the claim
is bounded, not a retained no-go.
