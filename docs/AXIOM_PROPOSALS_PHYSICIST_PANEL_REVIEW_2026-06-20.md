## Per-proposal findings

### Addition U — `MEAS-REC-READOUT` (unified operational measurement axiom)

**Tally:** 0 accept / 0 conditional / 10 reject. Reasonability LOW (10/10).
**Tier:** reject as a unit; unbundle each atom to its honest existing home.

**Smuggling findings (flagged by >= 2 reviewers, with counts):**

- **Arrow EXISTENCE / past hypothesis** smuggled via the oriented `t>=0`
  monotone einselecting semigroup. The "no arrow SIGN" disclaimer is
  self-refuting: monotone record formation **is** the low-record boundary.
  (**10/10**)
- **Pointer basis identified with the central-sector / K-CPT decomposition** —
  exactly the readout context / decomposition the `Record` axiom is explicitly
  written to withhold. (**10/10**)
- **SBS / spectrum-broadcast objectivity** installed as **the** determinant
  record-readout identification: a measurement / readout bridge asserted not
  derived. Objectivity fixes basis, not weight. (**9/10**)
- **Single-clock / registration-axis selector** ("which lattice axis carries
  event order" = the undischarged B-AXIS / registration-direction datum the
  axis-selection no-go proved underivable). (**8/10**)
- **Einselecting CPTP generator `e^{tL}` = record-production / decoherence
  dynamics + a metric time parameter** — content all three axioms explicitly
  supply none of. (**8/10**)
- **Measurement-problem resolution by fiat** (einselection + pointer basis +
  objectivity asserted to jointly solve preferred-basis / objectification).
  (**7/10**)
- **Bundling of 4-5 deliberately-separated, independently load-bearing gates**
  into one "existence / slot only" premise, violating one-narrow-datum
  minimality discipline (`AXIOM_MINIMALITY_POLICY` section 1). (**6/10**)

**Strongest objections:**
1. The "EXISTENCE / SLOT ONLY" framing is false by the framework's own evidence:
   an oriented, monotone, einselecting CPTP semigroup on `t>=0` is **not** a
   contentless slot — it is the thermodynamic arrow's existence by construction.
   The framework's own time-symmetric-microdynamics result locates monotone
   record accumulation **entirely** in a low-record boundary (= the past
   hypothesis); generic high-entropy states form no redundant record. So
   "a durable record forms / coherence is monotonically suppressed" with a
   "no past hypothesis" disclaimer is a direct self-contradiction.
2. U is not one premise but a bundle of 4-5 logically independent heavyweight
   inputs, each already pinned by the repo as a separate open gate, named
   residual, or computed no-go (arrow existence = past-hypothesis residual;
   axis = registration-direction derivation target; objectivity = open
   local-observability bridge; pointer basis = K/CPT readout context the
   `Record` axiom disclaims). Folding them into one "slot" is the disallowed
   "accept X so lane Y closes" move (policy section 1 / section 4).
3. It launders content the existing axioms are explicitly written to withhold:
   `Record` supplies no readout context / decomposition / K-CPT structure;
   `Lattice` supplies no causal cone / dynamics / axis; all axioms supply no
   measurement / decoherence / record-production dynamics.
4. Categorical mismatch with the approved primitives, each of which is exactly
   one narrow, dimensionless, dynamics-free datum (scale = units only;
   kinetic-isotropy = one structural form ratio; realized-state = a pure slot).
   U is the maximal opposite: a packaged measurement-plus-emergent-dynamics
   theory carrying directional dynamical content.
5. Circularity against the framework's marquee anomaly result: it derives
   signature (3,1) only by importing the `d_t <= 1` cap conditional on the
   registration axis; U would supply that axis by fiat, degenerating
   "anomaly + chirality force time, single-clock caps it" into "the measurement
   primitive declared the time axis."

**Governance recommendation (panel):** do not adopt U as one admission.
Unbundle into atoms and route each to its honest existing home — arrow ->
past-hypothesis residual; axis -> declared registration-direction derivation
target; einselection / SBS / pointer-basis -> bounded derivation targets. The
only contentless salvage (an unoriented existence-of-record-structure slot) is
already covered by `Record` + `realized_state_primitive` and adds nothing.

## Overall verdict

**A blind expert panel would accept none of the four additions as an axiom or a
primitive.** Across 40 reviewers: 0 accept, 1 conditional, 39 reject; 0 votes
for axiom grade and 0 for primitive grade on any proposal. The four additions
fail at the framework's own admissibility boundary, each in a characteristic way:

- **What smuggles, and what it smuggles.** All four covertly import content the
  current surface is explicitly written to withhold.
  - **U** smuggles the **thermodynamic arrow's existence / past hypothesis**
    (oriented monotone einselecting semigroup), the **readout context / pointer
    basis** (K/CPT decomposition `Record` withholds), **record-production /
    decoherence dynamics + a metric time parameter**, a **registration-axis
    selector**, and an entire **measurement-problem resolution** — then mislabels
    the bundle "existence / slot only."

    reverse-engineered to produce, dressed as a content-free

  - **S** smuggles a **time metric / clock-unit normalization** (dimensionless
    dynamical content) and the **empirical isotropic answer** (`=1`), and
    double-counts both `scale_reference` (absolute scale) and `kinetic_isotropy`

  - **C3** smuggles **gauging, chirality against the K/CPT mirror, and SM

- **Axiom vs primitive vs derivation target.**
  - **None is an axiom.** Each carries dynamical / selector / measurement
