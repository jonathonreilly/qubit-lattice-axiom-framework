## Statement

Let `C` be the standard `3 x 3` cyclic permutation matrix with
`C^3 = I`, and let `(a, b) in R x C` be abstract symbols. Define the
circulant Hermitian
```text
H  =  a I  +  b C  +  b̄ C^2.                                              (H)
```
Define the `3 x 3` swap-on-(1,2) matrix
```text
U_swap  =  [[1, 0, 0],
            [0, 0, 1],
            [0, 1, 0]],                                                    (Uswap)
```
and the anti-unitary involution `J : C^3 -> C^3` acting on vectors as
```text
J(v)  :=  U_swap * conj(v),    equivalently    J(z_0, z_1, z_2)
       =  (conj(z_0), conj(z_2), conj(z_1)),                               (J)
```
where `conj(v)` denotes entry-wise complex conjugation.

**Conclusion (T1) (`J^2 = +I`).** `J^2(v) = U_swap * conj(U_swap * conj(v))
= U_swap^2 * v = v` for every `v in C^3`, since `U_swap` is real and
`U_swap^2 = I`. So `J^2 = +I` on `C^3`, placing `J` in the KO-dim 0 mod 8
family (which also contains KO-dim 1, 6, 7).

**Conclusion (T2) (orbit-orientation reversal).** Acting by conjugation
in the matrix algebra on `End(C^3)`,
```text
J C J^{-1}  =  U_swap * conj(C) * U_swap  =  U_swap C U_swap  =  C^2
            =  C^{-1}.                                                     (JC)
```
Equivalently, `J` swaps the two non-trivial `C_3` characters
`(omega, omega_bar)`.

**Conclusion (T3) (commutation with every circulant Hermitian D).** For
every `(a, b) in R x C` and the corresponding `D = H` from (H),
```text
J D J^{-1}  =  U_swap * conj(D) * U_swap  =  D                             (JDJ)
```
as an exact polynomial identity over `(a, b_re, b_im)`. Equivalently,
the operator equation `D U_swap = U_swap conj(D)` holds for every
circulant Hermitian `D`. Hence `[D, J] = 0`.

**Conclusion (T4) (`H_R` 3-real-dim with explicit basis; `D_R` real
symmetric; eigenvalues unchanged).** The `+1` eigenspace
`H_R := {v in C^3 : J(v) = v}` is parametrized as
```text
H_R  =  { (x_0, u + i v, u - i v)  :  (x_0, u, v) in R^3 }.                (HR)
```
The vectors
```text
e_1 := (1, 0, 0),    e_2 := (0, 1, 1) / sqrt(2),    e_3 := (0, i, -i) / sqrt(2)
```
are an orthonormal `J`-fixed basis of `H_R` in the `C^3` inner product.
The operator `D` from (H) preserves `H_R` (it has real matrix elements
in the `(e_1, e_2, e_3)` basis), and its restriction
`D_R := D|_{H_R}` is real symmetric with eigenvalues
```text
lambda_0  =  a + 2 b_re,
lambda_om =  a - b_re - sqrt(3) b_im,                                     (EIG)
lambda_omb = a - b_re + sqrt(3) b_im,
```
exactly the eigenvalues of `D` on full `C^3`. In particular,
`Tr(D_R) = 3 a` and `Tr(D_R^2) = 3 a^2 + 6 |b|^2`, identical to the
block-total Frobenius `E_+ + E_perp` from
[`KOIDE_KAPPA_BLOCK_TOTAL_FROBENIUS_ALGEBRAIC_NARROW_THEOREM_NOTE_2026-05-10.md`](KOIDE_KAPPA_BLOCK_TOTAL_FROBENIUS_ALGEBRAIC_NARROW_THEOREM_NOTE_2026-05-10.md)
Conclusion T2.

**Conclusion (T5) (negative core — NCG / KO-dim route does NOT select
F1).** The spectral-action functional `S[D] := Tr_{H_R} f(D / Lambda)`
on `H_R` is a sum over the three eigenvalues from (EIG) and therefore
equals the unrestricted spectral-action functional
`Tr_{C^3} f(D / Lambda) = sum_k f(lambda_k / Lambda)` for every even
function `f`. As a symmetric function of `(lambda_0, lambda_om, lambda_omb)`,
the spectral-action functional weights the doublet pair
`(lambda_om, lambda_omb)` as two distinct eigenvalues, which is F3-style
real-dim weighting `(mu, nu) = (1, 2)` at the eigenvalue level — not F1
multiplicity `(1, 1)`. The F1 weighting would require collapsing the
doublet pair `(lambda_om, lambda_omb)` into a single eigenvalue bin in
the functional, which is structurally not supplied by `J`-projection
(the doublet eigenvalues remain distinct after `J`-projection because
`H_R` has full real-dim 3, not real-dim 2).

**Conclusion (T6) (counterfactual: `K` alone is more restrictive).** The
pointwise-conjugation involution `J' := K`, with `K(v) = conj(v)`
(no swap), does not commute with circulant Hermitian `D` when `b` is
complex:
```text
K H K^{-1} - H  =  -2 i b_im (C - C^2)  !=  0  for b_im != 0.              (KH)
```
The `K`-fixed slice of `Herm_circ(3)` is the 1-real-dim subspace
`b_im = 0` (the real-`b` slice of the doublet). In contrast, the
`J`-fixed slice (per T3) is the full 2-real-dim doublet plus the
1-real-dim trivial isotype, i.e., the entire space `Herm_circ(3)`.
The `U_swap`-twist in (J) is the precise modification that allows the
real structure to commute with the full complex-`b` doublet.

## Proof

Items (T1)-(T6) are immediate consequences of the explicit construction
plus matrix algebra on `M_3(C)`. The runner verifies each step at
exact sympy precision.

(T1) `J^2(v) = U_swap * conj(U_swap * conj(v)) = U_swap * U_swap * v = v`
since `U_swap` is a real matrix and `U_swap^2 = I` by direct
multiplication.

(T2) `U_swap * C * U_swap` is the matrix swap-conjugation of `C`.
Direct multiplication yields `U_swap C U_swap = C^2`, and analogously
`U_swap C^2 U_swap = C`.

(T3) `J D J^{-1} = U_swap * conj(D) * U_swap`. For `D = a I + b C + b̄ C^2`:
```text
conj(D) = a I + b̄ C + b C^2,
U_swap * conj(D) * U_swap = a (U_swap I U_swap) + b̄ (U_swap C U_swap) + b (U_swap C^2 U_swap)
                          = a I + b̄ C^2 + b C
                          = a I + b C + b̄ C^2
                          = D.
```
The third equality uses `U_swap C U_swap = C^2` and `U_swap C^2 U_swap = C`
from (T2). The fourth equality uses commutativity of addition. The
identity `J D J^{-1} = D` for every circulant Hermitian `D` is equivalent
to the operator equation `D U_swap = U_swap conj(D)`, which is the
`[D, J] = 0` statement for the anti-unitary involution `J = U_swap * K`.

(T4) The parametrization `H_R = {(x_0, u + iv, u - iv) : x_0, u, v in R}`
follows from solving `J(v) = v`, i.e., `U_swap conj(v) = v`. Writing
`v = (z_0, z_1, z_2)`, the equation is `(conj(z_0), conj(z_2), conj(z_1)) = (z_0, z_1, z_2)`,
i.e., `conj(z_0) = z_0` (so `z_0` is real), `conj(z_2) = z_1`,
`conj(z_1) = z_2` (so `z_1, z_2` are complex conjugates). Setting
`z_0 = x_0`, `z_1 = u + i v`, `z_2 = u - i v` with `x_0, u, v in R`
gives the parametrization.

The basis vectors `e_1, e_2, e_3` are obtained by setting one of
`(x_0, u, v) = 1` and the other two `= 0`, then normalizing in the
`C^3` inner product. Orthonormality and `J`-invariance are direct
matrix-element checks.

`D` preserves `H_R` because `[D, J] = 0` and `H_R` is the +1 eigenspace
of `J`. Computing the matrix elements `D_R[i, j] = <e_i, D e_j>`
yields a real symmetric matrix; explicit computation gives
```text
D_R  =  [[ a,            sqrt(2) b_re,  -sqrt(2) b_im ],
         [ sqrt(2) b_re,  a + b_re,      b_im         ],
         [-sqrt(2) b_im,  b_im,          a - b_re     ]].                  (DR)
```
The characteristic polynomial of `D_R` factors as
`(x - lambda_0)(x - lambda_om)(x - lambda_omb)` with eigenvalues from
(EIG). Both `Tr(D_R) = 3 a` and `Tr(D_R^2) = 3 a^2 + 6 |b|^2` are direct
arithmetic.

(T5) The spectral action `Tr_{H_R} f(D_R / Lambda) = sum_k f(lambda_k / Lambda)`
because `D_R` is diagonalizable with eigenvalues from (EIG). The same
sum equals `Tr_{C^3} f(D / Lambda)` because `D` and `D_R` share the same
eigenvalue spectrum. Hence the spectral action is a symmetric function
of `(lambda_0, lambda_om, lambda_omb)`. The F1-weighted log-functional
`F1(H) = log E_+(H) + log E_perp(H) = log(3 a^2) + log(6 |b|^2)`
cannot be reconstructed as a sum `sum_k f(lambda_k / Lambda)` because
such a sum counts each eigenvalue exactly once — the doublet pair
`(lambda_om, lambda_omb)` contributes two terms, equivalent to
`(mu, nu) = (1, 2)` real-dim weighting at the eigenvalue level. The
F1 collapse `(lambda_om, lambda_omb) -> single bin` is not supplied
by `J`-projection.

(T6) For `K(v) = conj(v)`, the matrix-algebra action is
`K H K^{-1} = conj(H) = a I + b̄ C + b C^2` (since `C` is real, so
`conj(C) = C`). Hence
```text
K H K^{-1} - H  =  (b̄ - b) C + (b - b̄) C^2  =  -2 i b_im (C - C^2),
```
which vanishes iff `b_im = 0`. So `K` is the trivial real structure on
`Herm_circ(3)`'s `(B_1, B_2) = (C + C^2, i(C - C^2))` doublet basis,
acting as `(+, -)` and pinning to the 1-real-dim `b_im = 0` slice. In
contrast, the `U_swap`-twist makes `J = U_swap K` act as `(+, +)` on
`(B_1, B_2)` (since `U_swap` flips the sign of `(C - C^2)` and `K`
conjugates `i` to `-i`, giving an overall `+1` on `B_2 = i(C - C^2)`).
This means `J` fixes the entire 2-real-dim doublet, while `K` fixes
only its 1-real-dim sub-slice. ∎
