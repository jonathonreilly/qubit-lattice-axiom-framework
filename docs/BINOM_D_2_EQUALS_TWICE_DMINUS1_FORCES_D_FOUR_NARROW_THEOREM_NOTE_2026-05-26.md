## 1. Claim scope

For each integer `d ≥ 2`, define

```text
L(d)  :=  binom(d, 2)  =  d (d - 1) / 2,                             (L)
R(d)  :=  2 · (d - 1).                                                (R)
```

The following identities hold by direct integer arithmetic:

- **(D1) Solving `L(d) = R(d)` over the integers.** The equation
  `L(d) = R(d)`, i.e., `d(d-1)/2 = 2(d-1)`, simplifies (multiplying
  both sides by 2 and using `d - 1 ≠ 0` for `d ≥ 2`) to
  `d - 1 ≠ 0 ⇒ d = 4`. Equivalently:

  ```text
  d (d - 1)  =  4 (d - 1)
    ⇒  (d - 1) (d - 4)  =  0
    ⇒  d ∈ {1, 4}.
  ```

  Restricting to `d ≥ 2`, the unique integer solution is `d = 4`.

- **(D2) Numerical evaluation.** For `d = 2, 3, 4, 5, 6, 7, 8`:

  ```text
  d = 2:  L = binom(2, 2) = 1,   R = 2 · 1 = 2.   L < R.
  d = 3:  L = binom(3, 2) = 3,   R = 2 · 2 = 4.   L < R.
  d = 4:  L = binom(4, 2) = 6,   R = 2 · 3 = 6.   L = R.  ✓
  d = 5:  L = binom(5, 2) = 10,  R = 2 · 4 = 8.   L > R.
  d = 6:  L = binom(6, 2) = 15,  R = 2 · 5 = 10.  L > R.
  d = 7:  L = binom(7, 2) = 21,  R = 2 · 6 = 12.  L > R.
  d = 8:  L = binom(8, 2) = 28,  R = 2 · 7 = 14.  L > R.
  ```

  Only `d = 4` matches both sides.

- **(D3) Monotonicity for `d ≥ 5`.** For every `d ≥ 5`,
  `L(d) - R(d) = d(d-1)/2 - 2(d-1) = (d-1)(d-4)/2 ≥ (5-1)(5-4)/2 = 2
  > 0`, so `L(d) > R(d)`. The gap grows quadratically in `d` thereafter.

- **(D4) `d ≤ 3` violates the equation.** For `d = 2`, `L = 1 < 2 =
  R`. For `d = 3`, `L = 3 < 4 = R`. Hence `L(d) < R(d)` strictly for
  `d ∈ {2, 3}`.

- **(D5) Uniqueness statement.** Combining (D1)-(D4): among integers
  `d ≥ 2`, the equation `L(d) = R(d)` holds **uniquely** at `d = 4`.

- **(D6) Geometric reading (informational, not load-bearing).** The
  left-hand side `L(d) = d(d-1)/2` is the dimension of:
  - the space of antisymmetric `d × d` real matrices,
  - the real Lie algebra `so(d)` of skew-symmetric infinitesimal
    rotations,
  - the space of 2-forms `Λ^2(R^d)`.
  The right-hand side `R(d) = 2 (d - 1)` is twice the dimension of:
  - the standard `(d - 1)`-sphere `S^{d-1}` (or any orientable
    `(d-1)`-dim hyperplane),
  - the natural representation `R^d` minus one dimension (e.g., the
    traceless part of `R^d`),
  - the adjoint of `su(2)` (since `dim su(2) = 3 = d - 1` at the
    matching dimension `d = 4`).
  The matching at `d = 4` is the dimensional precondition for the
  self-dual / anti-self-dual decomposition of 2-forms (each half of
  dimension 3 = d - 1) and for the matching `so(4) ≅ su(2) ⊕ su(2)`
  with each summand of dimension 3 = d - 1. The present narrow
  records the matching purely at the integer-arithmetic level; the

Facts (D1)-(D6) are abstract elementary integer-arithmetic

## 5. Proof

Pure integer arithmetic.

### 5.1 (D1) Solving `binom(d, 2) = 2(d - 1)` over the integers

The equation is

```text
d (d - 1) / 2  =  2 (d - 1).
```

Multiply both sides by 2:

```text
d (d - 1)  =  4 (d - 1).
```

Rewrite:

```text
d (d - 1)  -  4 (d - 1)  =  0,
(d - 1) (d - 4)  =  0.
```

The integer solutions are `d - 1 = 0` (i.e., `d = 1`) and `d - 4 = 0`
(i.e., `d = 4`). Restricting to `d ≥ 2` (the natural lower bound for
`Λ^2(R^d)` to be non-trivial), the unique solution is `d = 4`. ∎

### 5.2 (D2) Numerical evaluation

Direct evaluation of `L(d) = binom(d, 2) = d(d - 1) / 2` and
`R(d) = 2(d - 1)` for `d ∈ {2, 3, 4, 5, 6, 7, 8}`:

```text
d = 2:  L = 1,   R = 2,   L - R = -1
d = 3:  L = 3,   R = 4,   L - R = -1
d = 4:  L = 6,   R = 6,   L - R =  0   ✓
d = 5:  L = 10,  R = 8,   L - R = +2
d = 6:  L = 15,  R = 10,  L - R = +5
d = 7:  L = 21,  R = 12,  L - R = +9
d = 8:  L = 28,  R = 14,  L - R = +14
```

Only `d = 4` yields `L - R = 0`. ∎

### 5.3 (D3) Monotonicity for `d ≥ 5`

For `d ≥ 5`:

```text
L(d) - R(d)
  =  d (d - 1) / 2  -  2 (d - 1)
  =  (d - 1) (d - 4) / 2.
```

For `d ≥ 5`, `(d - 1) ≥ 4` and `(d - 4) ≥ 1`, so the product
`(d - 1)(d - 4) ≥ 4`, and `L - R ≥ 2`. The gap grows quadratically:
at `d = 8`, `L - R = 7 · 4 / 2 = 14`. ∎

### 5.4 (D4) `d ∈ {2, 3}` violation

For `d = 2`: `L = 1, R = 2`, so `L < R`. For `d = 3`: `L = 3, R = 4`,
so `L < R`. Hence the equation fails strictly for `d ∈ {2, 3}`. ∎

### 5.5 (D5) Uniqueness

Combining (D1)-(D4): among integers `d ≥ 2`, the equation
`L(d) = R(d)` holds uniquely at `d = 4`. ∎
