## 0. The claim under test

A scale-axis agent asserted that b-tau Yukawa unification (y_b → y_tau at a GUT
scale) is a **"genuine structural relation tying m_b and m_tau"** within the
Cl(3)/Z³ framework, thereby **reducing the free-scale count** (2 scales → 1).

b-tau unification is a classic minimal-SU(5) prediction: down-type and charged-
lepton Yukawas descend from the **same** SU(5) operator (the `10·5̄·5̄_H`
coupling), so `Y_d = Y_e` as matrices at M_GUT, giving `y_b = y_tau` for the
third generation. The question is whether the framework **derives** this
boundary or merely **imports** the GUT relation.

## 1. Quantitative check — SM-only b-tau running (the most charitable test)

**Setup.** Impose `y_b(M_GUT) = y_tau(M_GUT)` and run both down to the EW scale
with the **standard SM 1-loop RGEs** (Machacek–Vaughn / textbook; *imported*
running, not framework content). The splitting is driven by the color coupling:

```text
16π² dy_b/dt   = y_b ( … − ( ¼ g₁² + 9/4 g₂² + 8 g₃² ) )      ← has −8 g₃²
16π² dy_tau/dt = y_τ ( … − ( 9/4 g₁² + 9/4 g₂²        ) )      ← NO g₃² (color-singlet)
```

The `−8 g₃²` term enhances `y_b` below M_GUT; leptons are color-singlets and
feel no strong coupling, so `m_b/m_tau > 1` is generated by running alone.

**Result** (RK4 in `t = ln μ`, GUT-normalized `g₁² = (5/3) g_Y²`, gauge +
3rd-gen Yukawas seeded from PDG values at M_Z, `M_GUT = 2·10¹⁶` GeV):

| quantity | value |
|---|---|
| `(y_b/y_τ)(M_Z)` | **2.61** (robust 2.59–2.66 over M_GUT ∈ [10¹⁶, 10¹⁷]) |
| predicted `m_b(m_b)/m_τ` (MSbar) | **≈ 3.83** |
| PDG `m_b(m_b)/m_τ` (4.18 / 1.777) | **≈ 2.35** |
| pred / PDG | **≈ 1.63 (≈ 63% high)** |

**Honest agreement.** SM-only b-tau unification gives the **right order and the
correct sign** (`m_b/m_tau` is O(1) and > 1, color-driven), but it
**OVERSHOOTS** the observed ratio by ~60%. This is the well-known SUSY-vs-SM
b-tau issue: exact `y_b = y_tau` works far better with **SUSY sparticle
thresholds** (finite tan β corrections to `m_b`, and the MSSM's different gauge
running so the three couplings actually meet), or with a **lower effective
α_s / tuned GUT scale**. Pure SM running with PDG α_s(M_Z)=0.1181 does not
reproduce `m_b/m_tau`; it requires a ~60% downward correction that the SM does
not supply.

For context the SM gauge couplings here meet only pairwise: `g₂ = g₃` at
~10¹⁷ GeV but `g₁` sits ~13% apart there — i.e. **the SM does not exhibit
exact three-coupling unification at all**, which is itself why SM-only b-tau is
not the right benchmark.

## 3. Verdict

```text
VERDICT:  IMPORTED-GUT-ASSUMPTION
```

- The framework **derives SU(5) embedding consistency + hypercharge
  normalization (rep theory)** — NOT coupling unification, NOT the GUT scale,
  NOT any Yukawa relation.
- `y_b = y_tau` at M_GUT is the **minimal-SU(5) Yukawa-unification assumption**,
  imported on top of the embedding. It is **not** a consequence of A1+A2+the
  retained surface; the Yukawa sector is, on the contrary, a documented wall of
  bounded obstructions and no-go's.
- Quantitatively, even granting the import, **SM-only running OVERSHOOTS
  `m_b/m_tau` by ~60%**; exact b-tau wants SUSY thresholds (or a tuned α_s/
  GUT scale), which the framework neither contains nor derives.

**Scale-count consequence.** b-tau does **NOT** genuinely tie `{m_b, m_tau}`
within the framework, so it does not reduce the free-scale count. On the
retained surface `m_b` and `m_tau` remain **two independent observational
pins** (consistent with the 3-pin down-type / 3-pin lepton
requirement already on record). The scale-axis agent's "reduces the free-scale
count" claim is **not honest**: it imports a GUT relation and re-labels it a
framework relation. The honest free-scale count is **higher** than claimed —
the b-tau relation buys nothing the framework derives.

(If anything is *positively* available, it is only the weaker statement: the
framework's matter content is SU(5)-embeddable, so b-tau unification is
*compatible* with the gauge structure — "gauge-generic." But the **boundary
`y_b = y_tau` is assumed**, the unification scale is assumed, and the SM running
overshoots. That is `GAUGE-GENERIC-BUT-BOUNDARY-ASSUMED` at best, and since the
agent's specific claim was a *derived mass relation reducing the scale count*,
the operative verdict for that claim is `IMPORTED-GUT-ASSUMPTION`.)
