## Result Up Front

Work in one-site `M_2(C)`. Let `ω` be a primitive cube root of unity:
`ω^3 = 1`, `ω ≠ 1`, `ω^2 + ω + 1 = 0`. Let `R = diag(1, ω)` and
`Ad_R(X) = R X R^{-1}` with `R^{-1} = diag(1, ω^2)`. This is an
order-3 automorphism of `M_2(C)`.

Start from the equatorial projector
`P0 = |+⟩⟨+| = ((1/2, 1/2), (1/2, 1/2))`. Set `P1 = Ad_R(P0)` and
`P2 = Ad_R(P1)`. Then `{P0, P1, P2}` is a 3-orbit of distinct
rank-1 projections, `Ad_R(P2) = P0`, and

```text
P0 + P1 + P2 = (3/2) I_2.
```

They are not a resolution of the identity. The unital `*`-algebra they
generate is all of `M_2(C)` (`dim = 4 ≠ 9`). There is still no unital
`*`-hom `M_3(C) → M_2(C)` because `3 ∤ 2`.

This 3-set is not `{|0⟩⟨0|, |1⟩⟨1|, |+⟩⟨+|}`: `P1 ≠ E_11` and
`P1 ≠ P0`. A `C_3`-covariant 3-menu is a different type from a unital
`M_3` factor. Record, when present, locks exactly one of the three
rays. Leftover not adopted as QCD.

## Theorem 1 — a 3-orbit of rank-1 projections

Each `P_k` satisfies `P^2 = P`, `P^* = P`, `tr(P) = 1`. They are
pairwise distinct. `Ad_R(P2) = P0`.

## Theorem 2 — not the `{P0, P1, P+}` menu

`P1 ≠ diag(0, 1)` and `P1 ≠ P0`. The `{|0⟩, |1⟩, |+⟩}` 3-set is a
different menu.

## Theorem 3 — not a PVM

`P0 + P1 + P2 = (3/2) I_2 ≠ I_2`. Off-diagonal parts cancel because
`1 + ω + ω^2 = 0`. This is a 3-atom menu of rays, not a 3-outcome PVM.

## Theorem 4 — generated algebra is `M_2`, not `M_3`

The unital `*`-algebra generated by `{P0, P1, P2}` is all of `M_2(C)`.
The `Q(ω)`-span of the generators and their products has rank 4.
`dim_C M_3(C) = 9` and `4 ≠ 9`.

## Theorem 5 — still no unital `M_3 → M_2`

A unital `C`-linear `*`-hom `M_k → M_m` exists iff `k | m`. Here
`3 ∤ 2`. A `C_3`-covariant 3-menu is not a unital `M_3` factor.

## Theorem 6 — Record locks one; leftover not QCD

Record, when present, locks exactly one of `{P0, P1, P2}`.
Admissibility allows a 3-atom support *as a type*. This particular
orbit is displayed; nearest-neighbour covariance of the menu as a
lattice law is not claimed. No `SU(3)`, no QCD, no Qubit rewrite, no
adopted weights, no `r = 1/2` axiom.
