## Setup (A1+A2-native, no new imports)

Each site is one qubit `C²` (A1); sites sit on a `Z` temporal/`Z³` spatial chain
(A2). On each site the **creation** operator is `a† = σ_-` (maps vacuum `e₁` to
occupied `e₂`); `a = σ_+`; `n = a†a`. The carrier bit is **purely** the cross-site
sign:

```
hard-core boson:  b_x = bare on-site ladder, [b_x, b_y] = 0     (commute across sites)
fermion (JW):     c_x = (∏_{y<x} σ₃^(y)) · ladder_x, {c_x, c_y} = 0  (anticommute)
```

On any single site `b_x = c_x` as a `2×2` matrix; `b_x² = c_x² = 0`. The two differ
only in cross-site exchange. (Matches the parent `statistics_agnostic` framing
exactly.)

RP for fermions would use is available to — and identical for — the HCB.)

**Emergent-time generator (3).** From a Hermitian on-site-symmetric Hamiltonian, the
two-site transfer operators are Hermitian-positive in both frames and the Stone

**DHR challenge done correctly (5) — the load-bearing semantic check.** A naive DHR
reading ("the JW string is just a unitary gauge, so the sign is erasable") is **FALSE
at the generator level**, and is recorded here as a *refuted sub-claim* (this is the
over-claim the brief warned about; I built it, tested it, and it failed):

> There is **no** inner `*`-automorphism (no unitary `W`) of `M₄(C)` sending the
> commuting pair `(b₁, b₂)` to the anticommuting pair `(c₁, c₂)`. The operator
> intertwiner `{W : W b_i = c_i W, W b_i† = c_i† W}` has **null dimension 0** (both
> the ordered and the swapped assignment). Reason: `[b₁,b₂]=0` vs `{c₁,c₂}=0` (with
> `[c₁,c₂]≠0`) is an **isomorphism-invariant** relation, and a `*`-automorphism
> preserves all (anti)commutators.

So the cross-site sign is a **genuine generator-level distinction**, not erasable by
an inner unitary on a fixed Hilbert space. Neutrality therefore **cannot** be argued
as "the sign is trivially gauge." It must — and does — come from **positivity being
blind to the sign**, which the transfer-matrix test establishes directly.

**Frame-invariant physics agrees (6).** The manifestly gauge-invariant, parity-even
density correlator `<n_x n_y>` is identical across frames. The bare one-particle
bilinear `<a_x† a_y>` is **ordering/string-dependent** (different operator orderings
give different signs because the JW string hits different matrix elements) — a
hallmark that it is **not** a frame-invariant and **not** a positivity witness.

**Negative control (7).** The single-step naive (no-η) reflected form is indefinite
(min eig `-1`), and the defect is **identical** in both frames — it lives in the

**Decisive transfer-matrix test on an L = 4 chain (8) — the centerpiece.**

cross-site sign is now the JW string running along the chain):

- **(8a)** the two Hamiltonians have **identical spectra**. In fact, for the
  Hermitian number-conserving hopping on an **open** chain, `H_HCB = H_fermion` as

- **(8b–8c)** therefore `T = exp(-τH)` is the **same positive operator** (min eig

- **(8f)** the sign lives in the **JW string**: the fermion's string-completed

## Is any positivity difference physical or convention? (DHR resolution)

**There is no positivity difference to begin with.** The certified object (the
positive transfer operator / its spectrum) is frame-identical on the local structure
(§8a–c). The *only* frame-dependent quantities are:

1. **Bare, non-gauge-invariant correlators** (`<a_x† a_y>` for non-adjacent `x,y`): the
   sign is a **JW-string-convention** bookkeeping choice (§8d, 8f) — **convention**, as
   DHR warns.
2. **Closed-loop / boundary spectra** (§9): a **physical** difference, but one that
   distinguishes **two theories** rather than ranking them by positivity — both remain
   T-positive.

So: the sign is **convention** where it is local (and there positivity is blind), and
**physical** only where it is a global loop/boundary datum (and there positivity
certifies both theories without selecting). Either way, **positivity does not force the
statistics.** This is consistent with the generator-level fact (§5) that the sign is a
*real* distinction — it just is not a *positivity* distinction.
