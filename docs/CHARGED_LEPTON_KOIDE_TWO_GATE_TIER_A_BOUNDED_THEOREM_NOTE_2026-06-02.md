## 2. Claim scope

This note makes five narrow load-bearing claims.

### S1 — Algebraic surface (pure polynomial algebra)

On the Brannen-style cyclic parameterization with scalar amplitude
`a > 0` and nonnegative doublet radius `r >= 0`, define

```text
c := 2 r / a,                                                       (1)
Q := 1/3 + c² / 6.                                                  (2)
```

Then the target value `Q = 2/3` is equivalent to

```text
c² = 2,        r² / a² = 1/2.                                       (3)
```

(Pure algebra; identity (3) follows from (1)-(2) by direct computation,
verified in the runner.)

### S2 — Gate 1 admission (Koide surface selection)

Consuming the `AC_φλ` Tier-A admission as sharpened by the
chain-of-custody (line 27-43): the `r = 1/2` selection over the
endpoint lanes (`r = 0` and `r = 1`) and over the alternative interior
ratio `r = 1` is accepted as the Tier-A `AC_φλ` admission for the
charged-lepton sector. This note does not derive `r = 1/2` and does
not modify the Tier-A registry.

The associated retained no_go portfolio (why `r = 1/2` is genuinely
admitted, not derivable on the current substrate):

`effective_status` proposes to compute to **retained_bounded** per the

`retained_bounded` source row that:

  `Q = 2/3 ⇔ r² /a² = 1/2`)

  `AC_φλ` admission per the registry rather than treating them as
  open derivation targets
- anchors to the chain-of-custody note (S5) for the full structural
  derivation chain L1-L10

This is a strictly more honest framing of the same algebraic content
than the prior open-gate row carries. It does not promote the Tier-A
admission to retained. It does not weaken any retained no_go.

If the audit lane disagrees with the Tier-A framing — for example, if
the `AC_φλ` registry classification is determined to apply only to
specific sub-pieces and not to the umbrella two-gate row — the effective
status would compute to `audited_conditional` and the note would need
either a narrower Tier-A scope or to revert to an open-gate framing.
In that case no retained content is touched and the lane's status is
unchanged.
