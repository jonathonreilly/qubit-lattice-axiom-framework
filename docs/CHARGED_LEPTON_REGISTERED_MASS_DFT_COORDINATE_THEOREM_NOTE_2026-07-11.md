## Theorem

Let `(m0,m1,m2)` be any positive real triple and set `zj=sqrt(mj)`. With
`omega=exp(2*pi*i/3)`, define the normalized `C3` Fourier coordinates

```text
a = (z0+z1+z2)/3,
c = (z0+omega^2 z1+omega z2)/3,
r = |c|^2/a^2.
```

Then `a>0`, `r>=0`, and

```text
zj = a + c omega^j + conjugate(c) omega^(-j)
   = a + 2|c| cos(phi+2*pi*j/3),
```

where `phi=arg(c)` when `c` is nonzero. The parameter `r` has the symmetric
form

```text
r = [sum_j (zj-a)^2]/(6a^2),
```

so it is invariant under every permutation of the mass triple and under a
common positive rescaling of all three masses.

The Koide quotient

```text
Q = (m0+m1+m2)/(sqrt(m0)+sqrt(m1)+sqrt(m2))^2
```

satisfies the exact identity

```text
Q = 1/3 + 2r/3.
```

Consequently

```text
r=1/2  <=>  Q=2/3.
```

This equivalence is an identity at every supplied coordinate value; `r`
remains a free dial.

## Folded phase

For `c` nonzero, define

```text
delta_fold(phi)
  = min over integers k of |phi-2*pi*k/3|,
```

so `delta_fold` lies in `[0,pi/3]`. This minimum definition is unambiguous at
the boundary class represented by both `-pi/3` and `pi/3`.

Cyclic permutation multiplies `c` by a cube root of unity, and reflection of
the three positions sends it to a cube-root multiple of `conjugate(c)`.
Therefore `delta_fold` is invariant under the full permutation group of the
unordered triple. Phase sign and generation origin form its permutation
degeneracy. When `c=0`, `r=0`, the phase coordinate is absent, and every phase
representative gives the same reconstruction.

Thus a positive unordered mass triple with `c` nonzero determines
`(a,r,delta_fold)` with the stated phase degeneracy. At `c=0` it determines
`(a,0)` and has no phase coordinate. In the nonzero case, substituting
`phi=delta_fold` in the inverse cosine formula reconstructs the same unordered
square-root triple, though generally in a different ordering.

## Proof

The inverse `C3` Fourier transform gives the reconstruction formula. Parseval's
identity in this normalization gives

```text
sum_j zj^2 = 3(a^2+2|c|^2),
sum_j zj   = 3a.
```

Division yields

```text
Q = 3(a^2+2|c|^2)/(9a^2)
  = 1/3+2|c|^2/(3a^2)
  = 1/3+2r/3.
```

Also

```text
sum_j (zj-a)^2 = 6|c|^2,
```

which proves the symmetric formula for `r`. The permutation statements follow
because `S3` is generated by a cyclic shift and a reflection.
