## 1. Claim scope

matrix-valued `2k`-form

```text
F^∧k  :=  F ∧ F ∧ ⋯ ∧ F   (k factors)                              (W)
```

Define the **`k`-th Chern-character formal polynomial term** by
(C) above. Then:

- **(K1) Degree of `ch_k(F)`.** For any integer `k ≥ 1` and any

## 5. Proof

The argument is direct graded-algebra degree counting on the
Chern-character formal polynomial.

### 5.1 (K1) Degree of `ch_k(F)`

The wedge product `Λ^p × Λ^q → Λ^{p+q}` is bilinear with
`(α ∧ β) ∈ Λ^{p+q}` whenever `α ∈ Λ^p, β ∈ Λ^q`. Extended to
matrix-valued forms via matrix multiplication on the matrix factor,
this gives `(α_{form} ⊗ A) ∧ (β_{form} ⊗ B) = (α_{form} ∧ β_{form})
⊗ (A · B)`, preserving the additive form-degree rule.

For a 2-form `F ∈ Λ^2(R^d) ⊗ M_N(C)`, applying this `k - 1` times
gives

```text
F^∧k  ∈  Λ^{2k}(R^d) ⊗ M_N(C).
```

Taking the matrix trace `tr : Λ^{2k}(R^d) ⊗ M_N(C) → Λ^{2k}(R^d)` is
linear and preserves form degree, so `tr(F^∧k) ∈ Λ^{2k}(R^d)`.
Multiplying by the scalar `(i / (2π))^k / k! ∈ C` (a complex number,
not a form) does not change the form degree. Hence
`ch_k(F) ∈ Λ^{2k}(R^d)`.

By convention, `Λ^{2k}(R^d) = 0` when `2k > d` (no `2k`-form basis
elements exist on an `R^d` with `d < 2k`). So `ch_k(F) = 0` for
`2k > d`.

### 5.2 (K2) Top-form criterion

The top-degree form space is `Λ^d(R^d)`, of dimension
`binomial(d, d) = 1`, spanned by the volume form
`e^1 ∧ e^2 ∧ ⋯ ∧ e^d`. A homogeneous form
`α ∈ Λ^p(R^d)` (`α ≠ 0`) is a top-degree form iff `p = d`.

### 5.3 (K3) `ch_k(F)` is top-form iff `2k = d`

Combining (K1) and (K2): `ch_k(F) ∈ Λ^{2k}(R^d)` is a top-degree
form iff `2k = d`. At `2k < d`, `ch_k(F)` lies in a proper subspace
of `Λ^*(R^d)` of degree `2k < d`. At `2k > d`, `ch_k(F)` vanishes
identically (the form algebra truncates). Only at `2k = d` is
`ch_k(F)` a top-form candidate.

### 5.4 (K4) Specialization `k = 2`

Setting `k = 2` in (K3) gives `4 = d`, i.e., `d = 4`. Substituting
`k = 2` into the formal definition (C) gives

```text
ch_2(F)  =  ( i / (2 π) )^2  ·  tr( F ∧ F ) / 2!
          =  ( -1 / (4 π^2) )  ·  tr( F ∧ F ) / 2
          =  - tr( F ∧ F ) / ( 8 π^2 ).
```

This reproduces the canonical chiral-anomaly density normalization
`(1 / (8 π^2)) · tr(F ∧ F)` (up to the `-1` sign carried by the
`(i)^2` factor, consistent with the standard chiral-anomaly sign
convention).

### 5.5 (K5) Existence of nonzero `ch_2(F)` at `d = 4`

At `d = 4`, take `F := i · (e^1 ∧ e^2 + e^3 ∧ e^4) ⊗ I_N` with
`I_N` the `N × N` identity matrix. Then in the form factor,

```text
F_{form} ∧ F_{form}  =  ( e^1 ∧ e^2 + e^3 ∧ e^4 ) ∧ ( e^1 ∧ e^2 + e^3 ∧ e^4 )
                      =  ( e^1 ∧ e^2 ) ∧ ( e^3 ∧ e^4 )
                       + ( e^3 ∧ e^4 ) ∧ ( e^1 ∧ e^2 )
                      =  2 · e^1 ∧ e^2 ∧ e^3 ∧ e^4,
```

since both `(e^1 ∧ e^2) ∧ (e^1 ∧ e^2) = 0` and `(e^3 ∧ e^4) ∧
(e^3 ∧ e^4) = 0` (repeated-factor cancellation). Including the
`i^2 = -1` from `F = i · ( ... )`, we get

```text
F ∧ F  =  i^2 · 2 · e^1 ∧ e^2 ∧ e^3 ∧ e^4 ⊗ I_N
        =  - 2 · e^1 ∧ e^2 ∧ e^3 ∧ e^4 ⊗ I_N.
```

Taking the trace: `tr(I_N) = N`, so

```text
tr( F ∧ F )  =  - 2 N · e^1 ∧ e^2 ∧ e^3 ∧ e^4,
```

a nonzero multiple of the volume form on `R^4`. Then

```text
ch_2(F)  =  ( i / (2 π) )^2 · tr( F ∧ F ) / 2!
          =  ( - 1 / (4 π^2) ) · ( - 2 N · e^1 ∧ ⋯ ∧ e^4 ) / 2
          =  ( N / (4 π^2) ) · e^1 ∧ e^2 ∧ e^3 ∧ e^4,
```

a nonzero top-form on `R^4`.

### 5.6 (K6) Counterfactual at `d ∈ {0, 1, 2, 3}`

For `d ≤ 3`, `Λ^4(R^d) = 0` (since `4 > d`). Hence `F^∧2 = F ∧ F ∈
Λ^4(R^d) ⊗ M_N(C) = 0 ⊗ M_N(C) = 0`, so `ch_2(F) = 0` identically.
At `d = 0, 1, 2, 3`, the `k = 2` Chern-character term is the zero
form, not a (nonzero) top-form.

(Aside: the matching `k`-values at low `d`:
- `d = 0`: matching `k = 0`, with `ch_0(F) = tr(I_N) = N` a degree-0
  scalar.
- `d = 2`: matching `k = 1`, with `ch_1(F) = (i / (2π)) tr(F)` a
  degree-2 top-form. Note `k = 1`, not `k = 2`.

So the only Chern-character term at the top form at `d = 2` is
`ch_1`, not `ch_2`. The chiral-anomaly identification (k = 2)
cannot land at `d = 2`.)

### 5.7 (K7) Counterfactual at `d ∈ {5, 6, 7, ...}`

For `d ≥ 5`, the wedge-square `F ∧ F` is a nonzero element of
`Λ^4(R^d)` (since `binomial(d, 4) ≥ binomial(5, 4) = 5 > 0`). But
`Λ^4(R^d) ≠ Λ^d(R^d)` since `4 < d`. The 2nd Chern-character term
`ch_2(F) ∈ Λ^4(R^d)` is a 4-form, not a top-form on `R^d`.

For `d = 6`, the matching `k = 3` term is the top form:
`ch_3(F) = (i / (2π))^3 · tr(F^∧3) / 3! ∈ Λ^6(R^6)`. The `k = 2`
term `ch_2 ∈ Λ^4` is strictly sub-top.

For `d = 8`, the matching is `k = 4`: `ch_4 ∈ Λ^8(R^8)` is top-form,
while `ch_2 ∈ Λ^4(R^8)` is half-top.

For odd `d ∈ {5, 7, 9, ...}`, no `k ≥ 1` Chern-character term lands
at the top form (since `2k` is always even). The chiral-anomaly
identification fails at odd `d` for purely degree-parity reasons.

### 5.8 (K8) Uniqueness over `d ∈ {0, 1, ..., 8}` with `k = 2`

The integer equation `2k = d` with `k = 2` has unique solution
`d = 4`. Verifying: `d = 4` matches `k = 2` via `2 · 2 = 4`. All
other `d ∈ {0, 1, 2, 3, 5, 6, 7, 8}` give `2 · 2 = 4 ≠ d`. The
chiral-anomaly identification with the second Chern character
(`k = 2`) selects `d = 4` as the unique dimension where this term
is a top-form.

### 5.9 Combining

From (K1)-(K8): the `k`-th Chern-character term `ch_k(F)` is a
top-degree form on `R^d` iff `2k = d`. Specializing to `k = 2` (the
ABJ chiral-anomaly identification), the unique dimension is `d = 4`.
The factorial denominator `1 / k! = 1 / 2!` then produces the
canonical chiral-anomaly normalization `(i / (2π))^2 / 2! =
-1 / (8 π^2)`. QED.
