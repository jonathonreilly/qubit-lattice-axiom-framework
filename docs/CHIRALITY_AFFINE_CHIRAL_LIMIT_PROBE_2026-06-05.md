## 1. The fresh framing

The circulant eigenvalue Koide readout gives `Q = 2/3` at

```text
   r  :=  |b|^2 / a^2  =  1/2 ,        H = a I + b C + conj(b) C^2     (1.1)
```

where `C` is the cyclic shift (`C^3 = I`). The eigenvalues in the `Z_3`
Fourier basis are `L_k = a + b ω^k + conj(b) ω^{2k}` (`ω = e^{2πi/3}`),
with **mean** `(L_0 + L_1 + L_2)/3 = a` and **variance** `2|b|^2`. Hence

```text
   var / mean^2  =  2 |b|^2 / a^2  =  2 r                              (1.2)
```

so `r` is the **index of dispersion** (variance/mean²) of the spectrum —
a degree-0 *affine invariant* that explicitly references the origin
`a = 0`. The point `a = 0` is the **chiral limit**: the overall mass
scale (the trace direction `I`) vanishes and chiral symmetry is restored.
The chiral grading `Gamma_chi` is the generator of that restored symmetry.

**The move.** The established no-go
(`KOIDE_Z3_EQUIVARIANT_ANTICOMMUTING_NO_GO_NOTE_2026-05-16`) shows no
`C_3`-equivariant (circulant) Hermitian operator anticommutes with the
circulant grading `Gamma_chi = (2/3) J − I`. This probe drops the
`C_3`-equivariance of the *grading*: seek an affine-canonical
`Gamma_chi` (referencing the `a = 0` point / trace direction `I`) that
natively anticommutes with the circulant `H`, supplying the
singlet↔doublet off-block mixing the no-go requires via the
trace/origin relation rather than via a `C_3`-equivariant operator.

## 2. The affine anticommutation condition (exact)

In the Fourier basis `H = diag(L_0, L_1, L_2)`. For **any** matrix
`Gamma`, the anticommutator has entries

```text
   {Gamma, H}_{jk}  =  (L_j + L_k) Gamma_{jk}                          (2.1)
```

(verified symbolically for all 9 entries; runner Part 3 and Part 5a).
Therefore a nonzero grading element between Fourier modes `j, k` REQUIRES

```text
   L_j + L_k  =  0       (origin reflection of the two eigenvalues)    (2.2)
```

and a nonzero diagonal element at mode `m` requires `2 L_m = 0`, i.e.
`L_m = 0`. This is the precise affine statement: anticommutation pins the
supported modes to be reflections through the chiral origin. The
**general Hermitian** grading (Part 5a, no candidate restriction) is
forced to `Gamma = 0` at generic eigenvalues — a nonzero anticommuting
Hermitian grading exists only on the origin-reflection locus.

## 3. What the probe finds

Let `H = a I + b C + conj(b) C^2` with `a ≠ 0` (finite mass scale).

**(A) `C_3`-equivariant grading → `H = 0`.** If `Gamma` is required
circulant, it lies in `⟨I, C, C^2⟩`, commutes with the circulant `H`, so
`{Gamma, H} = 2 H Gamma`; anticommutation forces `H Gamma = 0`, hence
`H = 0`. This is exactly **WALL 1** = the established
`comm(C) ∩ anticomm(Gamma_chi) = {0}` identity.

**(B) Off-block affine grading → only at `a = 0`.** Forcing the grading
to be genuinely off-block (mixing the `Z_3` singlet, mode 0, with a
doublet mode) gives a Hermitian involution that anticommutes with `H`
**only on the constraint surface** `L_0 = −L_j` and `L_m = 0`. Solving
these for `(a, b)` yields, for every pairing,

```text
   a  =  0 .                                                           (3.1)
```

Since the mean of the eigenvalues **is** `a` (§1), an off-block
anticommuting involution exists **exactly at the chiral limit** `a = 0`
— precisely the locus where the affine ratio `r = |b|^2 / a^2`
**diverges**. The grading the framing seeks lives only where its own
invariant is undefined; it never reaches the finite `r = 1/2` Koide point.

On that surface the spectrum is `{+λ, −λ, 0}` (the anticommuting
spectrum). The **eigenvalue / affine-`r`** Koide readout is then

```text
   (Σ L^2)/(Σ L)^2  =  2λ^2 / 0  =  ∞      (NOT 2/3) ,                 (3.2)
```

because `Σ L = 0`. The value `Q = 2/3` returns **only** through the
**eigenvector** readout — which is the already-established
`KOIDE_ANTICOMMUTING_OPERATOR_DERIVATION_THEOREM` route: the explicit
`L4` class `H = (1/3)(1⊗h + h⊗1)` with `Σh = 0`, whose nonzero-eigenvalue
eigenvectors give `Q = 2/3` (runner Part 6 reproduces `Q = {2/3, 2/3}`).
That class is **not** `C_3`-native: it breaks `C_3`-equivariance by an
external choice of pairing (`[Gamma_aff, C] ≠ 0`; runner Part 6).

## 4. Verdict and the wall

**VERDICT: REDUCES-TO-ESTABLISHED-NO-GO.**

The affine framing **does** evade the literal
`comm(C) ∩ anticomm(Gamma_chi) = {0}` statement in the sense that the
off-block `Gamma` need not commute with `C`. But it then lands on the
origin-reflection `{+λ, −λ, 0}` spectrum, where:

1. the **affine ratio / eigenvalue** readout — the very `r` the framing
   is built on — gives `Q = ∞`, not `2/3`; and
2. the `a = 0` chiral-limit locus on which the grading exists is exactly
   where `r` is undefined, so the finite `r = 1/2` point is never reached;
   and
3. recovering `Q = 2/3` requires switching to the **eigenvector** readout
   of the pre-existing, **non-`C_3`-native** anticommuting (`L4`) class.

No **new** `C_3`-native Hermitian off-block orbit-splitting grading
delivering the affine `r = 1/2` value `Q = 2/3` is produced. The wall is
the same origin-reflection `{+λ, −λ, 0}` spectral obstruction, now
surfaced as a **readout-class fork**: a Hermitian grading anticommuting
with a finite-mass-scale circulant forces the spectrum to be
origin-symmetric (`mean = a = 0`), which is incompatible with the affine
ratio that the framing's `Q = 2/3` depends on. The eigenvector route that
escapes this still imports the same external `C_3`-orbit-splitting choice
the established gate already names.
