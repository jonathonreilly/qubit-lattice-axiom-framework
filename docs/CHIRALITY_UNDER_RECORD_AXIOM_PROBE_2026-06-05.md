## 2. The wall, stated entrywise (the object every candidate must clear)

In the `Z_3` Fourier basis `H = diag(L_0, L_1, L_2)`,
`L_k = a + b ω^k + conj(b) ω^{2k}` (`ω = e^{2πi/3}`), with **mean** `a`. For any
matrix `Gamma`,

```text
   {Gamma, H}_{jk}  =  (L_j + L_k) Gamma_{jk}.                           (2.1)
```

So a nonzero off-diagonal grading entry between modes `j, k` REQUIRES
`L_j + L_k = 0`, and a nonzero diagonal entry at mode `m` requires `L_m = 0`.
Anticommutation pins the supported modes to origin-reflection pairs through the
chiral origin. (Verified symbolically, runner Part 0.)
