## 5. Proof

The argument is direct Clifford-algebra structure.

### 5.1 (C1) Universal-property dimension formula

The real Clifford algebra `Cl(p, q)` on `n = p + q` generators
`e_1, ..., e_n` satisfying `{e_i, e_j} = 2 η_{ij} · 1` admits as a
real-linear basis the `2^n` ordered products

```text
e_{i_1} e_{i_2} ... e_{i_k},   i_1 < i_2 < ... < i_k,  k = 0, 1, ..., n,
```

with the empty product `1` included at `k = 0`. The cardinality count
follows directly: `∑_{k=0}^n binom(n, k) = 2^n`. Hence
`dim_R Cl(p, q) = 2^n = 2^{p+q}`. This is the universal-property
dimension formula on the free graded-anticommutative algebra modulo
the diagonal relations `e_i^2 = η_{ii}`.

### 5.2 (C2) Cartan-Bott classification cell `(3, 1)`

The Cartan-Bott periodic table for real Clifford algebras
`Cl(p, q)` for `n = p + q ≤ 8` is the standard classification
(Lawson-Michelsohn, *Spin Geometry*, Theorem I.4.3; see also
Atiyah-Bott-Shapiro, *Topology* 3 (1964), Suppl. 1):

```text
n = 0:   Cl(0, 0) ≅ R
n = 1:   Cl(1, 0) ≅ R ⊕ R          Cl(0, 1) ≅ C
n = 2:   Cl(2, 0) ≅ M_2(R)          Cl(1, 1) ≅ M_2(R)          Cl(0, 2) ≅ H
n = 3:   Cl(3, 0) ≅ M_2(C)          Cl(2, 1) ≅ M_2(R) ⊕ M_2(R)  Cl(1, 2) ≅ M_2(C)   Cl(0, 3) ≅ H ⊕ H
n = 4:   Cl(4, 0) ≅ M_2(H)          Cl(3, 1) ≅ M_4(R)           Cl(2, 2) ≅ M_4(R)   Cl(1, 3) ≅ M_2(H)   Cl(0, 4) ≅ M_2(H)
n = 5:   Cl(5, 0) ≅ M_4(C)          Cl(4, 1) ≅ M_4(R) ⊕ M_4(R)  Cl(3, 2) ≅ M_4(C)   ...
n = 6:   Cl(6, 0) ≅ M_8(R)          ...
n = 7:   ...
n = 8:   Cl(8, 0) ≅ M_{16}(R)        ...
```

Bott periodicity gives `Cl(p + 8, q) ≅ Cl(p, q) ⊗_R M_{16}(R)` for
the eightfold periodicity. The cell `(p, q) = (3, 1)` of the `n = 4`
row reads

```text
Cl(3, 1)  ≅  M_4(R).                                          (★)
```

This is the textbook fact cited above; the present narrow theorem
does not re-derive the full periodic table but uses (★) as an
admitted-context classification cell. The companion runner verifies
(★) directly by exhibiting four explicit `4 × 4` real matrices
satisfying the signature-`(3, 1)` Clifford relations and generating
a 16-dimensional real subalgebra equal to all of `M_4(R)`.

### 5.3 (C3) Dimension readout

By (C1), `dim_R Cl(3, 1) = 2^{3+1} = 2^4 = 16`. By (★),
`dim_R Cl(3, 1) = dim_R M_4(R) = 4 · 4 = 16`. Both sides agree on the
integer `16`. ∎

### 5.4 (C4) Uniqueness statement (signature-conditional)

Consult the Cartan-Bott table in §5.2:

- At `n ∈ {0, 1}`: dimensions `1, 2`; no `M_k(R)` cell with `k = 4`.
- At `n = 2`: dimensions `4`; `Cl(2, 0) ≅ Cl(1, 1) ≅ M_2(R)`, so
  `k = 2 ≠ 4`.
- At `n = 3`: dimensions `8`; no `M_k(R)` cell at all (the real
  matrix-algebra entries are `M_2(R) ⊕ M_2(R)`, a direct sum, not a
  single `M_k(R)`).
- At `n = 4`: dimensions `16`; the cells `Cl(3, 1) ≅ M_4(R)` and
  `Cl(2, 2) ≅ M_4(R)` are both single `M_4(R)` (not direct sums).
- At `n ≥ 5`: dimensions `≥ 32`; if a single `M_k(R)` cell occurs at
  all, `k ≥ 8` and the dimension is `≥ 64`.

Hence `n = 4` is the **unique smallest** total dimension at which a
real Clifford algebra `Cl(p, q)` is isomorphic to a single (not a
direct sum) real `M_k(R)` algebra with `k = 4`. The signature
`(p, q) = (3, 1)`, matching the framework's `Z³` spatial substrate
combined with one timelike direction (per the standard Minkowski-
signature convention `(+, +, +, -)` used in Lawson-Michelsohn), is one
of the two `n = 4` cells realizing this property (the other being
`(2, 2)`). QED.
