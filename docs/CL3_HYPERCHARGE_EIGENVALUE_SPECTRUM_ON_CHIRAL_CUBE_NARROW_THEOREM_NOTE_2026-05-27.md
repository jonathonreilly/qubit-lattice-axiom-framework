## 1. Claim scope

Let `(C^2)^{⊗3}` be the 8-dimensional chiral cube with computational
basis `|b_1 b_2 b_3⟩` for `(b_1, b_2, b_3) ∈ {0, 1}^3`, indexed by
`n = 4 b_1 + 2 b_2 + b_3 ∈ {0, 1, ..., 7}`. Let `P_swap` be the unitary
permutation that swaps the first two tensor factors,

```text
P_swap |b_1, b_2, b_3⟩ = |b_2, b_1, b_3⟩,
```

and let

```text
P_symm     := (I_8 + P_swap) / 2,
P_antisymm := (I_8 − P_swap) / 2.
```

Define the operator

```text
Y := (+1/3) · P_symm + (-1) · P_antisymm.
```

The narrow theorem records the following purely algebraic identities
on this `(C^2)^{⊗3}` and on this `Y`:

- **(S1) Projector identities.** `P_symm` and `P_antisymm` are
  orthogonal projectors with `P_symm + P_antisymm = I_8`,
  `P_symm · P_antisymm = 0`, `P_symm^2 = P_symm`,
  `P_antisymm^2 = P_antisymm`, all Hermitian.

- **(S2) Rank counts.** `rank(P_symm) = 6` and
  `rank(P_antisymm) = 2`, consistent with the
  `(3-dim symmetric base) ⊗ (2-dim b_3 fiber) = 6` and
  `(1-dim antisymmetric base) ⊗ (2-dim b_3 fiber) = 2` block
  decomposition.

- **(S3) Tracelessness.** `Tr(Y) = (1/3) · 6 + (-1) · 2 = 0`.

- **(S4) Eigenvalue spectrum.** The operator `Y` on
  `(C^2)^{⊗3}` has eigenvalues exactly
  `{+1/3 with multiplicity 6, -1 with multiplicity 2}`. No
  other eigenvalues occur.

- **(S5) Burnside-decomposition placement of `|111⟩`.** Under the
  Burnside Hamming-weight decomposition
  `(C^2)^{⊗3} = ℂ_{hw=0} ⊕ ℂ^3_{hw=1} ⊕ ℂ^3_{hw=2} ⊕ ℂ_{hw=3}`
  with dimensions `1 + 3 + 3 + 1 = 8`, the dark `hw=3` Burnside
  singlet `|111⟩` lies entirely in the symmetric base subspace
  (`⟨111|P_symm|111⟩ = 1` and `⟨111|P_antisymm|111⟩ = 0`) and
  therefore carries `Y |111⟩ = (+1/3) |111⟩`.

- **(S6) Antisymmetric block spans the `Y = -1` eigenspace.** The
  2-dim subspace
  `span{ (|010⟩ − |100⟩)/√2,  (|011⟩ − |101⟩)/√2 }`
  is the image of `P_antisymm` and is exactly the
  `Y = -1` eigenspace.

(S1)-(S6) are statements of standard finite-dimensional linear algebra
on the explicit `8 × 8` matrices. No lattice-action, staggered-Dirac,
graph-first axis-selection, `g_bare`, or numerical-prediction content
is in scope.

## 6. Proof

### 6.1 (S1) Projector identities

`P_swap` is a real unitary with `P_swap^2 = I_8` (swapping the first
two tensor factors twice is identity) and `P_swap^† = P_swap`
(real symmetric). Hence

```text
P_symm^2     = (I_8 + P_swap)^2 / 4 = (2 I_8 + 2 P_swap) / 4 = P_symm,
P_antisymm^2 = (I_8 − P_swap)^2 / 4 = (2 I_8 − 2 P_swap) / 4 = P_antisymm,
P_symm · P_antisymm = (I_8 + P_swap)(I_8 − P_swap) / 4
                     = (I_8 − P_swap^2) / 4 = (I_8 − I_8) / 4 = 0,
P_symm + P_antisymm = I_8.
```

Hermiticity follows from `P_swap^† = P_swap`. ∎

### 6.2 (S2) Rank counts

Enumerate the standard basis `|b_1 b_2 b_3⟩` and apply `P_swap`. The
fixed-point states (eigenvalue `+1` of `P_swap`) are those with
`b_1 = b_2`:

```text
|000⟩, |001⟩, |110⟩, |111⟩       (b_1 = b_2 = 0 or = 1; b_3 ∈ {0,1})
```

— four states — together with the symmetric combinations of the
remaining `b_1 ≠ b_2` pairs:

```text
(|010⟩ + |100⟩) / √2,   (|011⟩ + |101⟩) / √2.
```

This gives a 6-dim eigenspace for eigenvalue `+1` of `P_swap`. The
remaining 2-dim eigenspace for eigenvalue `-1` of `P_swap` is

```text
(|010⟩ − |100⟩) / √2,   (|011⟩ − |101⟩) / √2.
```

Therefore `rank(P_symm) = 6` and `rank(P_antisymm) = 2`. The block
factorisation `6 = 3 × 2` and `2 = 1 × 2` matches the cited
`(base) × (fiber) = (3-dim sym + 1-dim antisym) × (2-dim b_3
fiber)` decomposition of
[`CL3_COLOR_AUTOMORPHISM_THEOREM.md`](CL3_COLOR_AUTOMORPHISM_THEOREM.md)
Section B. ∎

### 6.3 (S3) Tracelessness

By (S2) and `Tr(P) = rank(P)` for orthogonal projectors,

```text
Tr(Y) = (1/3) Tr(P_symm) + (-1) Tr(P_antisymm)
      = (1/3) · 6 + (-1) · 2
      = 2 − 2
      = 0.
```

∎

### 6.4 (S4) Eigenvalue spectrum

Since `P_symm` and `P_antisymm` are orthogonal projectors with
`P_symm + P_antisymm = I_8` and `P_symm · P_antisymm = 0`,

```text
Y · v_s = (+1/3) v_s   for all v_s ∈ Im(P_symm),
Y · v_a = (-1) v_a     for all v_a ∈ Im(P_antisymm).
```

Together with `Im(P_symm) ⊕ Im(P_antisymm) = C^8`, this shows `Y` is
diagonalisable with eigenvalues `+1/3` on a 6-dim subspace and `-1`
on a 2-dim subspace; no other eigenvalues occur. The full spectrum is

```text
spec(Y) = { +1/3 (multiplicity 6),   -1 (multiplicity 2) }.
```

∎

### 6.5 (S5) Burnside placement of `|111⟩`

The Burnside Hamming-weight decomposition of the chiral cube is

```text
C^8 = ℂ |000⟩  ⊕  span{|001⟩, |010⟩, |100⟩}
                  ⊕  span{|011⟩, |101⟩, |110⟩}
                  ⊕  ℂ |111⟩,
```

with block dimensions `1 + 3 + 3 + 1 = 8` (cited from
[`CL3_TASTE_GENERATION_THEOREM.md`](CL3_TASTE_GENERATION_THEOREM.md)
Section A; verified at the script
[`scripts/verify_cl3_sm_embedding.py`](../scripts/verify_cl3_sm_embedding.py)
Section G, Burnside `1+3+3+1`).

The state `|111⟩` satisfies `P_swap |111⟩ = |111⟩` (since `b_1 = b_2`
already), so

```text
P_symm     |111⟩ = (I_8 + P_swap) |111⟩ / 2 = |111⟩,
P_antisymm |111⟩ = (I_8 − P_swap) |111⟩ / 2 = 0,
```

and

```text
Y |111⟩ = (+1/3) P_symm |111⟩ + (-1) P_antisymm |111⟩ = (+1/3) |111⟩.
```

Therefore the dark `hw=3` Burnside singlet `|111⟩` carries
`Y = +1/3`. ∎

### 6.6 (S6) Antisymmetric block spans the `Y = -1` eigenspace

By (S2), `Im(P_antisymm)` is spanned by

```text
v_{ant, 0} := (|010⟩ − |100⟩) / √2,
v_{ant, 1} := (|011⟩ − |101⟩) / √2,
```

(indexed by the `b_3` fiber). Both satisfy `P_swap v = -v`, hence

```text
P_symm     v_{ant, k} = 0,
P_antisymm v_{ant, k} = v_{ant, k},
Y          v_{ant, k} = (-1) v_{ant, k},          k ∈ {0, 1}.
```

By (S4), the `Y = -1` eigenspace has dimension 2; by the explicit
construction above it contains the 2-dim subspace
`Im(P_antisymm)`, hence equals it. ∎

This completes the proof of (S1)-(S6).
