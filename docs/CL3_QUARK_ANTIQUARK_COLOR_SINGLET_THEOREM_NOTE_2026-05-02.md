## Statement

Let `V = C^3` be the symmetric-base fundamental carrier supplied by
`CL3_COLOR_AUTOMORPHISM_THEOREM.md`, with algebraic SU(3) action generated by
the embedded Gell-Mann matrices. Let `V*` be its conjugate carrier. Then:

**(S1) Carrier decomposition.** Under the canonical identification
`V ⊗ V* ≅ End(V)`,

```text
    End(V) = C . I_3  ⊕  sl_3(C)
```

where `C . I_3` has dimension 1 and `sl_3(C)` has dimension 8.

**(S2) Singlet multiplicity = 1.** The scalar trace line is the unique
algebraic SU(3)-invariant line in `V ⊗ V*`.

**(S3) Normalized singlet projector.** In the induced tensor basis, the
rank-one projector onto the scalar trace line is

```text
    P_trace = |trace⟩⟨trace| = (1/3) Σ_{i,j} |i ī⟩⟨j j̄| .
```

**(S4) Eight-dimensional complement.** The traceless complement has dimension
8 and is invariant under the conjugation action generated by the cited
algebraic SU(3) carrier.

These statements constitute an algebraic symmetric-base SU(3)
fundamental/conjugate decomposition theorem. They do not identify the carrier
with physical SM quark color.

## Proof

### Step 1 — Use the supplied carrier directly

`CL3_COLOR_AUTOMORPHISM_THEOREM.md` supplies a 3-dimensional symmetric-base
carrier `V` with algebraic SU(3) generators. Therefore
`dim_C End(V) = 3 * 3 = 9`.

### Step 2 — Split trace and traceless parts

Every `X ∈ End(V)` decomposes uniquely as

```text
    X = (Tr X / 3) I_3 + (X - (Tr X / 3) I_3).
```

The first term is scalar, and the second term is traceless. Thus
`End(V) = C . I_3 ⊕ sl_3(C)`. The scalar line has dimension 1, and the
traceless condition removes one complex degree of freedom from the 9-dimensional
matrix space, so `dim_C sl_3(C) = 8`.

### Step 3 — Invariance and uniqueness

The algebraic SU(3) action on `End(V)` is conjugation:

```text
    X -> g X g^{-1}.
```

It fixes the scalar line because `g I_3 g^{-1} = I_3`. It preserves the
traceless complement because `Tr(g X g^{-1}) = Tr(X)`.

The only matrices commuting with all eight embedded Gell-Mann generators are
scalars; the paired runner solves this commutant system directly. Therefore
the invariant line has multiplicity one.

### Step 4 — Projector

Vectorizing the scalar matrix `I_3 / sqrt(3)` gives the normalized trace vector

```text
    |trace⟩ = (1/sqrt(3)) Σ_i |i ī⟩.
```

The projector `P_trace = |trace⟩⟨trace|` has rank 1, trace 1, and satisfies
`P_trace^2 = P_trace`; the paired runner verifies these identities directly.
∎
