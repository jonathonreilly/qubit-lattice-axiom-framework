## Proof

### Step 1 — Apply standard SU(N) tensor product rule with N = 3

The standard Clebsch-Gordan decomposition for SU(N) gives:

```text
    N ⊗ N̄  =  1 ⊕ adj(N)                                                       (3)
```

with `dim(adj) = N² - 1`. `CL3_COLOR_AUTOMORPHISM_THEOREM.md` supplies the
algebraic carrier dimension `N = 3` on the symmetric base. Substituting N = 3:

```text
    3 ⊗ 3̄  =  1 ⊕ 8                                                           (4)
```

establishing (S1). Total dim check: 3 · 3 = 9 = 1 + 8 ✓. ∎

### Step 2 — Trace-singlet construction (S2)

The trace-singlet state of `V ⊗ Vbar` is the SU(3)-invariant combination.
By Schur's lemma, the trace singlet is unique up to normalization. The invariant
tensor `δ_{ij}` (Kronecker delta) gives:

```text
    |trace⟩  =  (1/√N)  Σ_i  δ_{ij}  |i⟩ ⊗ |jbar⟩  =  (1/√3)  Σ_i  |i ibar⟩   (5)
```

The factor `(1/sqrt(3))` ensures `<trace|trace> = 1`. Hence (S2).

### Step 3 — Octet from orthogonal complement (S3)

The 8-dimensional adjoint representation is the orthogonal complement of the
trace singlet inside the 9-dimensional `3 ⊗ 3bar` tensor product. Explicit
basis: the 8 traceless `3 x 3` matrices `M_{ij}` parameterized by Gell-Mann
generators. Dimension count: `9 - 1 = 8`.

### Step 4 — Trace projector matches Fierz (proves S4)

Compute `|trace><trace|`:

```text
    P_trace  =  (1/N)  Σ_{i,j} |i ibar⟩⟨j jbar|                                (6)
```

This is the rank-one projector onto the invariant trace channel. It uses
the same `δ` tensor selected by the cited Fierz completeness relation; the
runner verifies normalization, idempotence, and rank directly rather than
importing an additional coefficient convention. ∎
