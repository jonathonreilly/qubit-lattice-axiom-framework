## §1. Setting (axis-permuted)

Fix a spatial axis `μ ∈ {1, 2, 3}` (one of the three Z³ generators).
Let `Λ ⊂ Z³` be a finite connected spatial sublattice with edge set
`E(Λ)`. Partition `Λ` into slabs orthogonal to `μ`, with slab edge
sets `E_⊥(s)` for slab `s`.

**Hilbert space.** The single-slab Hilbert space along `μ` is

```
H_Λ^{(μ)} := L²(SU(3)^{|E_⊥|}, dU_Haar)
```

(with `dU_Haar` the per-bond Haar measure). Structurally this is the
same `L²(SU(3)^E, dU_Haar)` as the temporal-axis parent's `H_Λ`, with
`E` instances of independent SU(3) Haar measure and the same product
structure.

**Spatial transfer operator.** The pure-Wilson spatial-axis transfer
operator is the integral operator with kernel

```
T_W^{(μ)}(U, V) = exp(-β · ΔS_W^{(μ)}[U, V]) · Π_{ℓ ∈ E_⊥} K_τ(U_ℓ V_ℓ^†)
```

where `K_τ` is the SU(3) heat kernel at lattice-spacing parameter `τ`
(identical to the parent's §1 definition) and `ΔS_W^{(μ)}` is the
spatial-Wilson action increment along axis `μ` (real-valued, by
`tr(plaquette) ∈ R` after the standard `Re tr` in the Wilson action).

**Conditional fermion extension.** As in the parent's §6, the full
spatial-axis transfer operator factors as
`T_x^{(μ)} = T_W^{(μ)} · T_F` where `T_F[U] = det(D[U] + m I)` acts as
