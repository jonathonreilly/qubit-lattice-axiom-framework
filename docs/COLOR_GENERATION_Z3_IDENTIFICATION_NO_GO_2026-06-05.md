## 3. The derivation (no-go)

### 3.1 The two `Z₃` characters

Write each `Z₃` action by its generator and read off the character
`χ = (χ(e), χ(g), χ(g²))` as traces of `(I, gen, gen²)`.

- **Color.** The center generator is `Z = ω·I₃`. Then
  `χ_color = (tr I₃, tr(ωI₃), tr(ω²I₃)) = (3, 3ω, 3ω²)`.
- **Generation.** The axis cycle `P` is fixed-point-free (`tr P = tr P² = 0`).
  Then `χ_gen = (3, 0, 0)`.

Both generators are genuine order-3 elements (`Z³ = I₃`, `P³ = I₃`,
`det P = det Z = 1`).

### 3.2 Inequivalence by trace comparison at each group element

The character (trace) is a **similarity invariant**, and two finite-group
representations over `ℂ` are isomorphic **iff** their characters agree at **every**
group element. Comparing element-by-element:

| element | `χ_color` | `χ_gen` | equal? |
|---|---|---|---|
| `e` | `3` | `3` | yes (same dimension) |
| `g` | `3ω` | `0` | **no** |
| `g²` | `3ω²` | `0` | **no** |

At the generator `g` the values differ: `|χ_color(g)| = 3` (a scalar) while
`|χ_gen(g)| = 0` (fixed-point-free permutation). A single disagreement suffices:
the two representations are **inequivalent**. The only non-trivial automorphism of
`Z₃` (relabel `g ↔ g²`) sends `χ_color` to `(3, 3ω², 3ω)`, still `≠ (3, 0, 0)`, so
no relabeling of the group generator rescues the match.

### 3.3 `χ_ω` multiplicities (3 in color, 1 in generation)

Decomposing each character into irreducibles via `m(χ_k) = ⟨χ, χ_k⟩ =
(1/3)·Σ_h χ(h)·conj(χ_k(h))`:

```text
χ_color = (3, 3ω, 3ω²)  =  3·χ_ω           (m(χ₀) = 0,  m(χ_ω) = 3,  m(χ_{ω²}) = 0)
χ_gen   = (3, 0, 0)      =  χ₀ + χ_ω + χ_{ω²}  (m(χ₀) = 1,  m(χ_ω) = 1,  m(χ_{ω²}) = 1)
```

The color rep is the scalar (isotypic) rep `3·χ_ω`; the generation rep is the
regular rep. The multiplicity of any single irrep is itself a complete
isomorphism invariant for `Z₃` reps. Here `m(χ_ω) = 3` for color but `m(χ_ω) = 1`
for generation — **3 ≠ 1** — which alone forbids isomorphism.

### 3.4 Schur obstruction: every intertwiner has rank ≤ 1

Let `Hom_{Z₃}(generation, color) = { T : Z·T = T·P }`. By Schur's lemma its
dimension is
`Σ_k m_gen(χ_k)·m_color(χ_k) = m_gen(χ_ω)·m_color(χ_ω) = 1·3 = 3`
(the only shared irrep is `χ_ω`). The runner solves the linear system
`Z·T·P^{-1} − T = 0` and confirms `dim Hom = 3`.

But **every** such intertwiner factors through the *single* `χ_ω` line of the
regular rep (its source-side `χ_ω` isotypic component is 1-dimensional), so its
image lands in a 1-dim space: **rank ≤ 1**. The runner verifies that the maximum
rank over the whole 3-dim `Hom` space is exactly `1`. An isomorphism would require
rank `3`; since `rank ≤ 1 < 3`, **no `Z₃`-equivariant isomorphism exists**. The
reverse direction is identical: `dim Hom(color, generation) = 3·1 = 3`, again all
of rank `≤ 1`. Equal determinant (`det P = 1 = ω³ = det Z`) is necessary but not
sufficient and does not rescue a bridge.

This is the no-go: the carriers are inequivalent `Z₃` representations, so they
cannot be identified by any change of basis, twist, or carrier map (all of which
preserve the character).

## 4. The named import that *would* bridge it

The exact missing ingredient is:

> **`scalar-generation-action`** — replace the generation `Z₃` action on the
> `hw=1` orbit (the derived cubic axis-cycle permutation `P`) by the scalar action

Under that replacement the generation character becomes `(3, 3ω, 3ω²)` and matches
the color center trivially. But this **discards** the cubic-symmetry provenance of
the generation `Z₃` — the only native order-3 structure on the orbit — in favor of
a stipulated scalar action. The runner exhibits that `ω·I₃ ≠ P` (a different
operator), so the replacement is a **non-native stipulation**, i.e. an **import**,
not a consequence of `A1 + A2 + A3` plus the retained carriers. Per the repo's
