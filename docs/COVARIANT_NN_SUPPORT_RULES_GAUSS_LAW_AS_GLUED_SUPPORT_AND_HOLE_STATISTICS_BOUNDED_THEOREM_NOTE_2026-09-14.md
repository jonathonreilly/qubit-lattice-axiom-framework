**Windows.** CUBE = the 2x2x2 window (8 sites, 12 edges, all degree 3); BOX =

**Support rule, code, glued group.** A covariant nearest-neighbour support rule
is a rotation-invariant subset Z of the local configurations (own value,
six neighbour values); its zero set on a window is the set of record patterns
whose every in-window local configuration lies in Z. When Z is a subgroup of
Z_q^7 the zero set is a linear code over GF(q). A glued group is a minimal
codeword (a nonzero codeword whose support contains no strictly smaller nonzero
codeword support), a code-theoretic use of the word glued in this note. The current hierarchy
parent does not identify minimal codewords with physical moving groups. The
reported flux dimension means the rank of a specified cycle-sum readout of a
specified field map, both defined below; it is not an intrinsic code invariant.

**Exterior conventions (supplied here).**
Exterior-empty: sites outside the window carry the empty value 0, so every
site sees a full 6-star and the divergence-type rule becomes A_W (adjacency)
plus a multiple of I. Exterior-unrecorded: exterior edges carry no field, so
the in-window star appears and the divergence rule becomes D_W + A_W (degree
plus adjacency). Plain sum rules a r_v + b (sum of neighbours) give aI + bA_W
under both conventions; only the divergence-type rule sees the degree.

**Roles (supplied).** On the box, a site's role is fixed by the parity of its
coordinates in {0,1,2}: V (all even, 8 sites), L (one odd, 12), P
(two odd, 6), C (three odd, 1). Each L site has exactly two V neighbours and
each V site exactly three L neighbours; the V and L sites with their adjacency
form the superlattice cube Q_3 (8 vertices, 12 links). The roles are an input
of this note, not a derived quantity; the current role-pattern note separates its nearest-neighbour parity skeleton
from the additional corner-pin field that needs a larger window. The latter
field is absent here; neither field is derived from Qubit.

**Model P and Model R (names for supplied codes).** Model P denotes the five
binary cube codes and four box kernels enumerated here, not all invariant
support subspaces. Model R is the binary Gauss code on the supplied parity
roles, with no constraints at L/P/C. The static relation at V uses nearest
neighbours and is covariant when roles are transformed with the configuration.
A fixed chosen parity pattern is a supplied background sector.

**Completed-check fair-coin attempt process.** Fix an order of the sites.
For a site last in a check, demand the parity of the other check members.
With no demand use an independent fair bit; with one demand take that bit;
with two different demands declare the history failed. At a link, the other
members of a neighbouring V check include L sites two fine-lattice steps
away. This radius2 attempt process is distinct from the static NN relation.
The simulation propagates an arbitrary first demand after failure and discards
that entire history. It therefore computes no partial-hole pattern law.
An empty allowed set is an abort event here, not a normalized distribution
conditional on formation. d(order) counts links last in both checks.

**All-order proof and matching control.** Write n for the number of sites
(including any inert sites) and m for the number of V checks: m=4 on the
plane and m=8 on the cube. The check rows are independent because each has
its own unique V coordinate. Group rows by their latest site in the chosen
order. There are m-d distinct latest sites: only a link can close two rows,
and double closers cannot share a V. Choose one row from each group; solving
these rows in order fixes each of their m-d pivot sites from earlier values.
All remaining n-m+d sites receive independent fair bits. Every Gauss word
uniquely specifies those free bits, and conversely success imposes all m
rows. There are2^(n-m) successful outputs out of2^(n-m+d) free assignments,
so success has probability2^-d and its conditional output law is uniform.
In the runner's full n-bit coin enumeration, unused pivot coins give every
successful output exactly2^(m-d) preimages; successful coin vectors number
2^(n-d). Nothing in this proof fixes a failed partial-record distribution.

For the matching control, assign independent uniform arrival times in[0,1]
to all V/L sites. A selected matching of k double closers bounds its2k endpoint
vertex times and every incident unselected link time by the appropriate
selected link time (the minimum if two selected links bound it). Partition
the k selected times by their k! possible orders. On each ordered simplex,
the integrand is a monomial with exponents a_j; its integral is the product
of1/(a_0+...+a_j+j+1). Sum these probabilities over size-k matchings to get
E[binom(d,k)]. Binomial inversion gives P(d=j). The independent graph uses
binary vertex labels, not the parity-window or subset-DP builder. The current
runner compares all cube and plane probabilities, matching counts and means.
