`V_int = C^2` is the dim-2 internal Cl(3) factor (carrying a faithful

on `V_int` per [`CL3_PAULI_IRREP_UNIQUENESS_NARROW_THEOREM_NOTE_2026-05-10.md`](CL3_PAULI_IRREP_UNIQUENESS_NARROW_THEOREM_NOTE_2026-05-10.md):
`γ_i = σ_i` (Pauli matrices).

Define `C` and `P` on `V` as the framework operators of the parent
`cpt_exact_note` row, factored explicitly as

```text
C  =  C_lat ⊗ G_C,         P  =  P_lat ⊗ G_P,
```

with

- `C_lat ∈ End(V_lat)`: real diagonal `[C_lat]_{x,y} = (-1)^{x_1+x_2+x_3} δ_{x,y}`,
  the sublattice parity (`(C_lat)^2 = I_lat`);
- `P_lat ∈ End(V_lat)`: real involutory permutation `[P_lat]_{x,y} = δ_{-x mod L,\, y}`,

  the positive-chirality irrep `γ_i = σ_i`, satisfying
  `G_C σ_1 G_C^{-1} = -σ_1`, `G_C σ_2 G_C^{-1} = -σ_2`,
  `G_C σ_3 G_C^{-1} = +σ_3`. This is the spatial-inversion-compatible
  parity automorphism on the dim-2 spinor; it is real and involutory
  (`G_C^2 = I_int`).
- `G_P ∈ End(V_int)`: the partner Cl(3) grading automorphism — `G_P = σ_3`
  (same as `G_C` for the canonical choice; the runner verifies the
  whole construction is symmetric in `G_C ↔ G_P` so the alternative

  Real, involutory.

**(S1) Scalar square on the internal factor.** On `V_int`:

```text
(G_C G_P)^2  =  +I_int.                                           (S1)
```

**(S2) Scalar square on the orbital factor.** On `V_lat`, for even `L`,

```text
(C_lat P_lat)^2  =  +I_lat,                                        (S2_mod)
```

i.e. `ε_lat^{mir} = -1` for every even `L` (since `3(L-1)` is odd for

```text
ε_lat  =  +1   under modular inversion (parent CPT-note item 7 convention),
ε_lat  =  -1   under mirror inversion (parent runner Part 10 convention).
```

The sign is locked by the specific lattice convention; it does not

**(S3) Combined scalar square on V.** Tensoring (S1) and (S2):

```text
(C P)^2  =  (C_lat ⊗ G_C)(P_lat ⊗ G_P)(C_lat ⊗ G_C)(P_lat ⊗ G_P)
```

This is the explicit scalar-square identity that the C3 step of

## Proof

The proof is direct matrix algebra on the explicit C, P factorisations,
using only:

- The selected Pauli-irrep relations `σ_i σ_j = δ_{ij} I + i ε_{ijk} σ_k`
  on `V_int = C^2` per
  [`CL3_PAULI_IRREP_UNIQUENESS_NARROW_THEOREM_NOTE_2026-05-10.md`](CL3_PAULI_IRREP_UNIQUENESS_NARROW_THEOREM_NOTE_2026-05-10.md).
- The retained dim-2 conclusion per
  [`CL3_COMPLEXIFICATION_SPLIT_NARROW_THEOREM_NOTE_2026-05-10.md`](CL3_COMPLEXIFICATION_SPLIT_NARROW_THEOREM_NOTE_2026-05-10.md) §(K4)
  and the complexification split per
  [`CL3_COMPLEXIFICATION_SPLIT_NARROW_THEOREM_NOTE_2026-05-10.md`](CL3_COMPLEXIFICATION_SPLIT_NARROW_THEOREM_NOTE_2026-05-10.md).
- Direct combinatorial computation on `V_lat`.

### (S1) Internal factor

With `G_C = G_P = σ_3`:

```text
(G_C G_P)^2  =  (σ_3 σ_3)^2  =  (I_2)^2  =  I_int.
```

For the alternative choice `G_P = -σ_3`:

```text
(G_C G_P)^2  =  (σ_3 (-σ_3))^2  =  (-I_2)^2  =  +I_int.
```

In both choices, `(G_C G_P)^2 = +I_int`. The dim-2 reduction follows
from the Pauli-irrep classification: any Cl(3)-grading-compatible
involution on `V_int` is `±σ_3` up to similarity in the chirality
summand, and both square to `+I` in the product. ∎

### (S2) Orbital factor

Compute `(C_lat P_lat)^2` site-by-site. For a basis vector `|x⟩` with
`x = (x_1, x_2, x_3) ∈ (Z mod L)^3` and `Σx := x_1 + x_2 + x_3`,
let `y := P_lat(x)` denote the lattice-inversion image of `x`. Then

```text
(C_lat P_lat) |x⟩  =  (-1)^{Σy} |y⟩,
(C_lat P_lat)^2 |x⟩  =  (-1)^{Σy} · (-1)^{Σ(P_lat(y))} |P_lat(y)⟩
                    =  (-1)^{Σy + Σx} |x⟩,
```

using `P_lat^2 = I_lat` so `P_lat(y) = P_lat(P_lat(x)) = x`. The
scalar factor is `(-1)^{Σy + Σx}`, which depends on the lattice-inversion
convention.

**Modular convention** `P_lat(x) = (-x) mod L`. For each component:
`y_i = 0` if `x_i = 0`, else `y_i = L - x_i`. So
`y_i + x_i = L · [x_i ≠ 0]` (Iverson bracket). Summing over the three
spatial components:

```text
Σy + Σx  =  L · #{i : x_i ≠ 0}.
```

For even `L`, every multiple of `L` is even, so
`(-1)^{Σy + Σx} = +1` for every `x ∈ (Z mod L)^3`. Hence

```text
(C_lat P_lat)^2  =  +I_lat                        (modular, even L).
```

**Mirror convention** `P_lat(x) = (L-1) - x` (component-wise; here we
interpret `(L-1) - x_i` as a fixed integer in `{0, ..., L-1}`). Then
`y_i + x_i = L - 1`, and `Σy + Σx = 3(L-1)`. For even `L`, `L-1` is odd
so `3(L-1)` is odd, hence `(-1)^{Σy + Σx} = -1`. Therefore

```text
(C_lat P_lat)^2  =  -I_lat                        (mirror, even L).
```

In both conventions, the product is an exact scalar multiple of the
identity. ∎

### (S3) Combined factor

The tensor structure `(A ⊗ B)(A' ⊗ B') = (A A') ⊗ (B B')` gives

```text
(C P)^2  =  (C_lat ⊗ G_C)(P_lat ⊗ G_P)(C_lat ⊗ G_C)(P_lat ⊗ G_P)
        =  (C_lat P_lat C_lat P_lat) ⊗ (G_C G_P G_C G_P)
        =  (C_lat P_lat)^2 ⊗ (G_C G_P)^2
        =  ε_lat I_lat ⊗ I_int
        =  ε_lat · I_V.
```

In the modular convention with even `L`: `ε = +1`, so `(CP)^2 = +I_V`.

∎
