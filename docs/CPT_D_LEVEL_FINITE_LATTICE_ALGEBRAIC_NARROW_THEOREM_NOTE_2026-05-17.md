## Statement

Let `V = C^N` and let `H ∈ End(V)` be a Hermitian operator
(`H^\dagger = H`) with **real entries** (`H_{ij} ∈ R` for all `i, j` in
the chosen basis; equivalently `H^* = H` under componentwise complex
conjugation). Let `C, P, T` be three operators on `V` satisfying the
abstract type axioms

```text
C real, diagonal, involutory       (C real, C = C^T = C^\dagger, C^2 = I)
P real, permutation, involutory    (P real, P = P^T = P^{-1}, P^2 = I)
T = K complex conjugation          (T linear-conjugate, T^2 = I)
```

and the three action identities

```text
C H C = -H,        (1)   sign-flip through C
P H P = -H,        (2)   sign-flip through P
T H T^{-1} = H.    (3)   H real, complex conjugation acts trivially
```

Then:

**(P1) Composite invariance under the literal three-operator product
`CPT`.**

```text
CPT · H · (CPT)^{-1}  =  C P H P C  =  C (-H) C  =  -(-H)  =  H.
```

Equivalently, the antilinear composite `CPT` commutes with `H` in the
operator sense `CPT · H = H · CPT`.

The substitution chain is the load-bearing step in the parent
`cpt_exact_note` item 4 verbatim.

## Proof

Pure algebraic substitution, step by step.

Start from the composite-action expression

```text
CPT · H · (CPT)^{-1}.
```

Use `(CPT)^{-1} = T^{-1} P^{-1} C^{-1}`. Since `T^2 = I` (so
`T^{-1} = T`) and `P, C` are involutory (so `P^{-1} = P`, `C^{-1} = C`),
this becomes

```text
CPT · H · (CPT)^{-1}  =  C P T · H · T P C.
```

Apply `T H T = T H T^{-1}` (using `T^2 = I`) and premise (3) on the inner
`T H T = H`:

```text
=  C P (T H T) P C
=  C P H P C                            (by premise (3): T H T = H).
```

Apply premise (2) on the middle `P H P`:

```text
=  C (P H P) C
=  C (-H) C                             (by premise (2): P H P = -H)
=  -(C H C).
```

Apply premise (1) on the inner `C H C`:

```text
-(C H C)  =  -(-H)                      (by premise (1): C H C = -H)
        =  H.
```

Therefore `CPT · H · (CPT)^{-1} = H`. The chain matches the parent's
item 4 verbatim:

```text
CPT * H * (CPT)^{-1} = C * P * H * P * C = C * (-H) * C = -(-H) = H.
```

∎
