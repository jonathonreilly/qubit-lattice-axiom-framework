## Result Up Front

Work in one-site `M_2(C)`. Lattice supplies proper cubic rotations of
the physical lattice `Z^3`. Qubit supplies the abstract one-site algebra
`M_2(C)`. Neither sentence names an action of those rotations on the
algebra. The map that sends the body-diagonal 3-fold to a Pauli-axis
automorphism is a supplied extra (the unresolved trivial-versus-Pauli-adjoint
fork). The algebra below is conditional on that supplied action.

Conditional on that action, one such rotation is the order-3 turn by
`120°` about a cube space diagonal, which cycles the three coordinate
axes `x → y → z → x`. The corresponding automorphism `φ` of `M_2(C)` is
the unique unital `*`-linear map on the Pauli basis with

```text
φ(σx) = σy,    φ(σy) = σz,    φ(σz) = σx.
```

This is exhibited two ways: as that cycle map extended `C`-linearly and
`*`-linearly, and as `Ad_U` for the displayed spin-`1/2` lift

```text
U = (I - i(σx + σy + σz))/2,
```

which is unitary and obeys `U^3 = -I`.

The associated rank-1 projectors are

```text
Px = (I+σx)/2 = ((1/2, 1/2), (1/2, 1/2))
Py = (I+σy)/2 = ((1/2, -i/2), (i/2, 1/2))
Pz = (I+σz)/2 = ((1, 0), (0, 0)).
```

They are pairwise distinct, `φ` cycles them, and `φ^3 = id` with `φ ≠ id`.
The unweighted sum is not a resolution of the identity:

```text
Px + Py + Pz = (3/2) I + (σx + σy + σz)/2  ≠  I.
```

The three Bloch vectors `(1,0,0)`, `(0,1,0)`, `(0,0,1)` do not cancel, so
the sum is also not `(3/2)I`. Uniform scaling by `2/3` therefore does not
produce a POVM. The unital `*`-algebra generated by `{Px, Py, Pz}` is all
of `M_2(C)` (complex dimension `4`, not `9`). There is no unital `*`-hom
`M_3(C) → M_2(C)`, because `3` does not divide `2`.

This triad is not Lattice-named. It is the Pauli-axis cycle of a
*supplied* cube-3-fold action, not the displayed z-equator of the
companion `R = diag(1, ω)` construction. The trivial action (rotations
move sites, identity on `M_2`) and the Pauli-adjoint action disagree:
the former sends `σx` to `σx`, the latter sends `σx` to `σy`. Here
“menu” means only the displayed finite candidate support; it does not
assert that the framework's fixed Admissibility rule selects that
support. Conditional on the support at a site being supplied as exactly
`{Px, Py, Pz}`, Record locks one member of that supplied support when a
record forms. The leftover is not adopted as QCD. The note derives no
menu-selection rule, probability weights, measurement implementation,
`SU(3)`, color identification, or Qubit rewrite.

```text
Py = ((1/2, -i/2), (i/2, 1/2))

```

Any matrix is written uniquely as `a I + b σx + c σy + d σz`. The
automorphism is

```text
φ(a I + b σx + c σy + d σz) = a I + b σy + c σz + d σx.
```

## Theorem 1 — three distinct rank-1 projections

Direct multiplication in `Q(i)` gives `Px^2 = Px`, `Py^2 = Py`,
`Pz^2 = Pz`, each is self-adjoint, and each has trace one. Hence each is
a rank-1 projection. The three matrices are unequal: `Pz` is the
computational projector `|0⟩⟨0|`, while `Px` and `Py` have off-diagonal
entries `1/2` and `-i/2` respectively.

## Theorem 2 — `φ` is the cube 3-fold and cycles the triad

The assignment `σx ↦ σy ↦ σz ↦ σx` extends uniquely to a unital
`C`-linear map on `M_2(C)`. It preserves the Pauli product table

```text
σx σy = i σz,    σy σz = i σx,    σz σx = i σy
```

and therefore is a unital algebra homomorphism. It commutes with the
adjoint on the Hermitian Pauli basis, hence is a `*`-automorphism.
Applying it three times returns every Pauli generator, so `φ^3 = id`.
It is not the identity because `φ(σx) = σy ≠ σx`. Consequently
`φ(Px) = Py`, `φ(Py) = Pz`, `φ(Pz) = Px`.

The same map is inner. The displayed unitary

```text
U = (I - i(σx + σy + σz))/2
```

satisfies `U U* = I` and `U^3 = -I`. Conjugation implements the cycle:
`U σx U* = σy`, `U σy U* = σz`, `U σz U* = σx`. Thus `φ = Ad_U`.

## Theorem 3 — not a PVM

```text
Px + Py + Pz = (3 I + σx + σy + σz)/2
             = (3/2) I + (σx + σy + σz)/2
             ≠ I.
```

The extra body-diagonal term is nonzero. The unweighted projectors
therefore are not a PVM. They are also not mutually orthogonal:
`Px Py ≠ 0`.

Unlike a coplanar equatorial 3-orbit, the Bloch vectors of `Px, Py, Pz`
sum to `(1,1,1)`, not to zero. In particular

```text
Px + Py + Pz  ≠  (3/2) I.
```

Uniform scaling cannot cancel that remainder:

```text
(2/3)(Px + Py + Pz) = I + (σx + σy + σz)/3  ≠  I.
```

So the scaled family is not a POVM. There is no partial closure of the
kind available to a centered trine.

## Theorem 4 — generated algebra is `M_2`, not `M_3`

The identities `σx = 2 Px - I`, `σy = 2 Py - I`, `σz = 2 Pz - I` place
the full Pauli basis in the unital `*`-algebra generated by
`{Px, Py, Pz}`. Exact elimination over `Q(i)` shows that
`{I, σx, σy, σz}` already has rank four, which is the ambient dimension
of `M_2(C)`. Hence

```text
C*(Px, Py, Pz) = M_2(C),    dim_C = 4 ≠ 9.
```

## Theorem 5 — still no unital `M_3 → M_2`

Suppose `ψ : M_3(C) → M_2(C)` were a unital `*`-hom. Its kernel is an
ideal of the simple algebra `M_3(C)`. Unitality makes `ψ` nonzero, so
the kernel must be zero and `ψ` must be injective. No injective
complex-linear map can send a nine-dimensional vector space into a
four-dimensional one. Therefore no such `ψ` exists. This is the
`3 ∤ 2` instance of the usual finite-dimensional representation
divisibility criterion.
