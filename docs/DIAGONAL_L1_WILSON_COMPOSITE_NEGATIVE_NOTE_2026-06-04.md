## §1. Setup and conventions

Work on a single unit cube of `Z^3` with `SU(2)` NN link variables (the
`su(2)` summand of the qubit-link `u(2)` of
[`QUBIT_LINK_U2_CONNECTION_ALGEBRA_BOUNDED_THEOREM_NOTE_2026-06-04`](QUBIT_LINK_U2_CONNECTION_ALGEBRA_BOUNDED_THEOREM_NOTE_2026-06-04.md);
the central `u(1)` factor and the larger non-Abelian cases only make the
argument easier, never harder — see §5).

Standard lattice-gauge conventions (Montvay–Münster Ch. 3):

- `U_μ(n) ∈ SU(2)` is the link from site `n` to `n + μ̂`.
- Parallel transport along an oriented path is the path-ordered product with
  link factors appended in traversal order:
  a path `n₀ → n₁ → n₂` has holonomy `U(n₀→n₁) · U(n₁→n₂)`. In a pure-gauge
  field `U_μ(n) = g(n) g(n+μ)†` this telescopes to `g(n₀) g(n₂)†`. A backward
  hop `n+μ → n` contributes `U_μ(n)†`.
- The oriented `(μ,ν)` plaquette holonomy based at `n` is the standard
  staple-closed Wilson loop `n → n+μ → n+μ+ν → n+ν → n`:

  ```text
  U_p(μ,ν; n) = U_μ(n) · U_ν(n+μ) · U_μ(n+ν)† · U_ν(n)† .
  ```

  This is the lattice field strength `F_{μν}` at `n` (group element; we do not
  take a trace until §4-C5/C6).

## §2. Face-diagonal as a composite (the core computation)

The face-diagonal `O = (0,0,0) → XY = (1,1,0)` has exactly two NN paths inside
the face:

- **Path P1** (via `X = (1,0,0)`): `W₁ = U_x(O) · U_y(X)`.
- **Path P2** (via `Y = (0,1,0)`): `W₂ = U_y(O) · U_x(Y)`.

Each is a well-defined `SU(2)` holonomy (runner A1). Their ratio is **exactly**
the `xy` plaquette holonomy based at `O`:

```text
W₁ · W₂†
  = U_x(O) U_y(X) · U_x(Y)† U_y(O)†
  = U_p(x,y; O)        (the lattice field strength F_xy).
```

Equivalently `W₁ = U_p · W₂`: the two path holonomies differ by, and only by,
the NN plaquette field strength. The runner verifies

```text
A2: max |W₁ W₂† − U_p| = 2.5e-16  over 40 random SU(2) configs
A4: explicit worked example W₁ W₂† = U_p   (residual 1.2e-16)
A5: explicit W₁ = U_p · W₂                  (residual 1.8e-16)
```

with the printed `SU(2)` matrices of `U_x(O)`, `U_y(X)`, `W₁`, `W₂`, `U_p`, and
`W₁ W₂†` showing `W₁ W₂†` and `U_p` are the same matrix. The path-choice ambiguity
is generically non-trivial (A3) — it is precisely `F_xy ≠ I` — and it vanishes
exactly when the face is flat (`F_xy = I`).

**Conclusion (face-diagonal).** Under L1 the face-diagonal "connection" =
(NN link data) + (path choice), and the path-choice term is the already-present
NN plaquette. Zero new degree of freedom.

## §3. Body-diagonal as a composite

The body-diagonal `O → (1,1,1)` has `3! = 6` monotone NN staircases, one per
ordering of the three hops `x, y, z` (runner B0). All six holonomies are `SU(2)`
(B-su2). Two facts pin them to NN data:

- **B1 (adjacent transposition = transported plaquette).** Any two orderings
  differing by a single adjacent swap at staircase position `k` have holonomies
  related by a **face plaquette transported by the common prefix**:

  ```text
  W(order) · W(swapped)† = P · U_p(μ,ν; base) · P† ,
  ```

  where `P` is the prefix holonomy `O → … → base` and `(μ,ν)` are the swapped
  hops. Runner: `max |ratio − transported U_p| = 5.6e-16`.

- **B2 (flat collapse).** On a pure-gauge (flat) NN field all six holonomies
  coincide (`max spread = 7.3e-16`); on a curved field they generically differ
  (B3: 40/40 samples). The full six-path data is therefore generated by the
  three face plaquettes `(xy, yz, zx)` transported around (B4) — all of which
  are NN observables.

Since every adjacent transposition contributes a transported face plaquette,
and the symmetric group `S₃` on the three hops is generated by adjacent
transpositions, **every** pairwise body-diagonal holonomy ratio is a word in
transported face plaquettes. The body-diagonal under L1 = (NN links) + (path),
with the path-dependence carried entirely by the NN field strength. Zero new
degree of freedom.

## §4. Zero-DOF accounting

The runner makes the "no new DOF" statement precise (Part C):

- **C1.** For a *fixed* path, the diagonal holonomy is a deterministic function
  of the NN links (identical fields → identical holonomy, residual 0).
- **C2.** Changing one NN link changes the diagonal holonomy: there is no
  independent diagonal variable that could be set while NN links are held fixed.
- **C3.** Dimension count: the face-diagonal holonomy lives in `SU(2)`
  (`dim = 3`); the NN source it depends on (two links along a path) has
  `dim = 6`. The map (NN links) → (diagonal holonomy) is onto but introduces no
  coordinate beyond the NN links: `3 ≤ 6`, zero new DOF.
- **C4.** The path-choice ambiguity is a **discrete** 2-element orbit
  `{W₂, U_p · W₂}`, not a continuous parameter; the only freedom is the (NN)
  plaquette.
- **C5 / C6.** The out-and-back face-diagonal loop (out via P1, back via P2)
  *is* the NN plaquette Wilson loop, with real trace in `[−2, 2]`. The diagonal
  "curvature" is literally the NN field strength.

## §5. Gauge covariance — the defect is field strength, not gauge artifact

To rule out the reading "the path difference is merely a gauge choice," Part D
checks covariance under lattice gauge transformations
`U_μ(n) → g(n) U_μ(n) g(n+μ)†`:

- **D1.** The path defect `U_p` transforms covariantly,
  `U_p → g(O) U_p g(O)†` — it is field strength, a physical (gauge-covariant)
  object, not pure gauge.
- **D2.** On a pure-gauge NN field `U_p = I`: no field strength ⇒ no path defect.
- **D3.** Each diagonal path holonomy transforms as an honest parallel
  transporter `W → g(start) W g(end)†` — confirming `W₁, W₂` are genuine
  connection holonomies with no extra internal DOF.

The argument is `SU(2)`-explicit but convention-independent: it uses only
associativity of the ordered product and the staple identity, so it holds
verbatim for the full qubit-link `u(2)` (central `u(1)` factors out of both
paths identically) and for any `SU(N)`/`U(N)` link group. Enlarging the fiber
cannot create a diagonal DOF that the NN composite lacks.
