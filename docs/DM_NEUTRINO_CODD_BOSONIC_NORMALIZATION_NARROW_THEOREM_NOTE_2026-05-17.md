## Statement

Let `S_cls`, `T_gamma`, `Z_odd` be the three explicit matrices defined
above. `S_cls` is real diagonal Hermitian on `C^4`; `T_gamma` is
complex Hermitian on `C^3`; `Z_odd` is real diagonal Hermitian on
`C^2`. All three have the same nonzero spectrum `{+1, -1}` and differ
only by null multiplicity (two zero eigenvalues for `S_cls`, one for
`T_gamma`, none for `Z_odd`).

The three spectrum identities (S1)-(S3), the three cubic involution

`m != 0`, and `j` real with `|j| < m` (so that the absolute-value

## Proof

Pure finite-dimensional matrix algebra on `C^4`, `C^3`, and `C^2`,
closed at exact symbolic precision.

**Step 1 — Spectrum of `S_cls`.** `S_cls = diag(0, 0, 1, -1)` is real
diagonal, so its eigenvalues are exactly the diagonal entries
`{0, 0, 1, -1}`. The nonzero spectrum is `{+1, -1}`, with two zero
eigenvalues from the upper `2 x 2` block. This is (S1). (Verified at
exact sympy precision by `Matrix.eigenvals` and by characteristic
polynomial `det(S_cls - λ I_4) = λ^4 - λ^2 = λ^2 (λ - 1) (λ + 1)`.)

**Step 2 — Spectrum of `T_gamma`.** The characteristic polynomial of
`T_gamma` on `C^3` is

```text
det(T_gamma - λ I_3)  =  -λ^3  +  λ                                     (C2)
                      =  -λ (λ - 1) (λ + 1),
```

(direct sympy computation, where the off-diagonal pair `[1,3]` and
`[3,1]` carries the `-i`/`+i` entries that combine via
`(-i)(i) = 1`). Hence `spec(T_gamma) = {0, +1, -1}`. This is (S2).
(Verified at exact sympy precision by `Matrix.eigenvals` and by
characteristic polynomial expansion.)

**Step 3 — Spectrum of `Z_odd`.** Trivially, `spec(Z_odd) = {+1, -1}`.
This is (S3).

**Step 4 — Cubic involutions.** For each generator, `M^3 = M` is a
consequence of the eigenvalue set `{0, ±1, ...}` and the minimal
polynomial dividing `λ (λ - 1) (λ + 1) = λ^3 - λ`. Concretely:

- `S_cls^3 = diag(0, 0, 1, -1)^3 = diag(0, 0, 1, -1) = S_cls` (real
  diagonal). This is (E1).
- For `T_gamma` on `C^3`, direct sympy computation gives
  `T_gamma^2 = diag(1, 0, 1)` and then
  `T_gamma^3 = T_gamma^2 · T_gamma = T_gamma`. This is (E2).
- `Z_odd^3 = diag(1, -1)^3 = diag(1, -1) = Z_odd`. This is (E3).

(All three verified at exact sympy precision by entry-by-entry matrix
equality.)

**Step 5 — Determinant of `m I_4 + j S_cls`.** Since `S_cls` is
diagonal with eigenvalues `{0, 0, +1, -1}`, the eigenvalues of
`m I_4 + j S_cls` are `{m, m, m + j, m - j}`, so

```text
det(m I_4 + j S_cls)  =  m · m · (m + j) · (m - j)
                     =  m^2 (m^2 - j^2)                                 (DG4)
                     =  m^4 (1 - j^2 / m^2).
```

Hence

```text
log|det(m I_4 + j S_cls)|  -  log|m^4|
   =  log|1 - j^2 / m^2|.                                               (W.S)
```

**Step 6 — Determinant of `m I_3 + j T_gamma`.** Since `T_gamma` is
Hermitian with eigenvalues `{0, +1, -1}`, the eigenvalues of
`m I_3 + j T_gamma` are `{m, m + j, m - j}`, so

```text
det(m I_3 + j T_gamma)  =  m · (m + j) · (m - j)
                       =  m (m^2 - j^2)                                 (DG3)
                       =  m^3 (1 - j^2 / m^2).
```

Hence

```text
log|det(m I_3 + j T_gamma)|  -  log|m^3|
   =  log|1 - j^2 / m^2|.                                               (W.T)
```

**Step 7 — Determinant of `m I_2 + j Z_odd`.** Same calculation: the
eigenvalues of `Z_odd` are `{+1, -1}`, so the eigenvalues of
`m I_2 + j Z_odd` are `{m + j, m - j}`,

```text
det(m I_2 + j Z_odd)  =  (m + j) · (m - j)
                     =  m^2 - j^2                                       (DG2)
                     =  m^2 (1 - j^2 / m^2).
```

Hence

```text
log|det(m I_2 + j Z_odd)|  -  log|m^2|
   =  log|1 - j^2 / m^2|.                                               (W.Z)
```

**Step 8 — Closing.** Identities (S1)-(S3) follow from Steps 1-3;
identities (E1)-(E3) follow from Step 4; identity (W) follows by
combining (W.S), (W.T), (W.Z). All eight identities are pure
finite-dimensional matrix algebra, verified at exact sympy precision
in the runner on the explicit `4 x 4`, `3 x 3`, and `2 x 2`
matrices. ∎

## Derivable corollaries

**(R1) Equal small-source bosonic curvature.** Expanding
`log|1 - j^2 / m^2|` in powers of `j/m` near `j = 0` gives

```text
log|1 - j^2 / m^2|  =  -j^2/m^2  +  O(j^4 / m^4),                       (R1)
```

so the leading bosonic curvature `∂^2 W / ∂j^2 |_{j=0} = -2/m^2` is
identical for all three generators. This corollary is a pure
determinantal-spectral identity; the admissibility-class selection
step that elevates this to the canonical odd normalization
`|c_odd| = 1` is a separate premise of the parent row.

**(R2) Equal nonzero spectrum after null-multiplicity subtraction.**
The three generators `S_cls`, `T_gamma`, `Z_odd` have nonzero spectra

```text
spec(S_cls) \ {0}    =  { +1, -1 },
spec(T_gamma) \ {0}  =  { +1, -1 },                                     (R2)
spec(Z_odd) \ {0}    =  { +1, -1 },
```

with null multiplicities `(2, 1, 0)` respectively. After subtracting
the zero-source baseline (which contributes only to the null
multiplicity), the three sources have identical odd nonzero spectra.

Both corollaries follow algebraically from the proof.
