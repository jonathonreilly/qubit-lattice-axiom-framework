```text
F00    =  J3 / 3,
F_row  =  J2 / 2.                                                       (Frow)
```

## Proof

Pure finite-dimensional real matrix algebra on `C^3` and `C^2`, closed
at exact symbolic precision.

**Step 1 — `F00` is a rank-one projector with `Tr F00 = 1`.** Direct
computation:

```text
F00 · F00  =  (J3/3) · (J3/3)  =  J3^2 / 9  =  (3 J3) / 9  =  J3 / 3
            =  F00,                                                     (E1)
```

using `J3^2 = 3 J3` (the all-ones-matrix square identity on `C^3`,
which follows from `(J3)_{ij} = 1` so `(J3^2)_{ij} = sum_k 1 = 3`).
Hence `F00` is idempotent. Its trace is `Tr F00 = Tr(J3)/3 = 3/3 = 1`,
and its rank is `rank(J3) = 1`, so its eigenvalues are
`{1, 0, 0}` (idempotency forces eigenvalues in `{0, 1}`; trace fixes
the count of `1`s; rank fixes the count of nonzero eigenvalues). This
is (S1).

**Step 2 — `F_row` is a rank-one projector with `Tr F_row = 1`.**
Same argument with `J2^2 = 2 J2` (since `(J2)_{ij} = 1` gives
`(J2^2)_{ij} = sum_k 1 = 2`):

```text
F_row · F_row  =  J2^2 / 4  =  2 J2 / 4  =  J2 / 2  =  F_row.           (E2)
```

`Tr F_row = Tr(J2)/2 = 2/2 = 1`. Rank is `1`. Eigenvalues are
`{1, 0}`, which is (S2).

**Step 3 — Determinant of `m I_3 + j F00`.** Because `F00` is a
rank-one projector with one eigenvalue `1` and two eigenvalues `0`,
the eigenvalues of `m I_3 + j F00` are `{ m + j, m, m }`, so

```text
det(m I_3 + j F00)  =  (m + j) · m · m  =  m^2 (m + j)
                   =  m^3 (1 + j/m).                                    (DG3)
```

Hence

```text
log|det(m I_3 + j F00)|  -  log|m^3|
   =  log|1 + j/m|.                                                     (W.L)
```

**Step 4 — Determinant of `m I_2 + j F_row`.** Same argument: the
eigenvalues of `F_row` are `{1, 0}`, so the eigenvalues of
`m I_2 + j F_row` are `{ m + j, m }`,

```text
det(m I_2 + j F_row)  =  (m + j) · m  =  m^2 (1 + j/m).                 (DG2)
```

Hence

```text
log|det(m I_2 + j F_row)|  -  log|m^2|
   =  log|1 + j/m|.                                                     (W.R)
```

Combining (W.L) and (W.R) gives (W).

**Step 5 — Closing.** Identities (S1), (S2), (E1), (E2), and (W) are
established. All five identities are verified at exact sympy precision
by the companion runner on the explicit `3 x 3` and `2 x 2`
matrices. ∎

exactly in the runner). So the trace pairing against `F00` is
insensitive to `(δ, ρ, γ)`, which matches the parent's "diagonal slot
is independent of the breaking triplet" statement.

Both corollaries follow algebraically from the proof.
