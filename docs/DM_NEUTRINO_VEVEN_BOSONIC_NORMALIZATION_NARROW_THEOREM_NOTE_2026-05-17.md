## Proof

Pure finite-dimensional real matrix algebra on `C^3` and `C^2`, closed
at exact symbolic precision.

**Step 1 — Frobenius-orthogonality of the active basis.** Compute
`Tr(M_a^T M_b)` for `M_a, M_b ∈ {A_op, b_op, c_op, d_op, T_delta, T_rho}`.
Direct entry-by-entry calculation gives

```text
Tr(A^T A)       = 1,    Tr(b^T b)       = 4,
Tr(c^T c)       = 2,    Tr(d^T d)       = 2,
Tr(T_delta^T T_delta) = 2,
Tr(T_rho^T   T_rho)   = 4,
all other Tr(M_a^T M_b) = 0   for a != b.                              (G)
```

Hence the six-matrix active basis is exactly Frobenius-orthogonal (with
unequal magnitudes). (Verified at exact sympy precision in the runner.)

**Step 2 — `F1` as Frobenius dual of `E1 = delta + rho`.** For any
linear combination `H = α A_op + β b_op + γ c_op + δ d_op + ε T_delta
+ ζ T_rho` with `(α, β, γ, δ, ε, ζ)` real coefficients, define
`E1(H) := ε + ζ` and `E2(H) := α + β - γ - δ`. Then

```text
Tr(H · F1)  =  Tr(H · ((1/2) T_delta + (1/4) T_rho))
            =  (1/2) Tr(H · T_delta)  +  (1/4) Tr(H · T_rho)
            =  (1/2) · ε · 2          +  (1/4) · ζ · 4
            =  ε + ζ  =  E1(H),                                         (D1)
```

using (G) and `Tr(T_delta^T T_delta) = 2`, `Tr(T_rho^T T_rho) = 4`, and
the orthogonal annihilation of all other terms. Similarly,

```text
Tr(H · F2)  =  Tr(H · (A_op + (1/4) b_op - (1/2) c_op - (1/2) d_op))
            =  α + (1/4) β · 4 - (1/2) γ · 2 - (1/2) δ · 2
            =  α + β - γ - δ  =  E2(H).                                 (D2)
```

So `F1` and `F2` are the exact Frobenius-dual generators of `E1` and
`E2` on the active basis.

**Step 3 — Spectra of `F1` and `F2`.** The characteristic polynomial of
`F1` on `C^3` is

```text
det(F1 - λ I)  =  -λ^3  +  (3/8) λ                                      (C1)
```

(direct sympy computation), giving eigenvalues
`{-sqrt(3/8), 0, +sqrt(3/8)}`. This is (S1). Likewise the characteristic
polynomial of `F2` is

```text
det(F2 - λ I)  =  -λ^3  +  (9/8) λ                                      (C2)
```

giving eigenvalues `{-3/sqrt(8), 0, +3/sqrt(8)}`, which is (S2).
(Verified at exact sympy precision via `Matrix.eigenvals` and direct
characteristic-polynomial expansion.)

**Step 4 — Spectra of scaled `Z_row`.** Trivially,
`spec(sqrt(3/8) Z_row) = { -sqrt(3/8), +sqrt(3/8) }` and
`spec((3/sqrt(8)) Z_row) = { -3/sqrt(8), +3/sqrt(8) }`. This is (S3),
(S4).

**Step 5 — Determinant of `m I_3 + j F1`.** Using `F1^3 = (3/8) F1`
(consequence of (C1) and Cayley-Hamilton on `C^3`), the eigenvalues of
`m I + j F1` are `{ m + j λ : λ ∈ spec(F1) }`, so

```text
det(m I_3 + j F1)  =  m · (m + j sqrt(3/8)) · (m - j sqrt(3/8))
                  =  m · (m^2 - (3/8) j^2)                              (DG1)
                  =  m^3 · (1 - (3/8) j^2 / m^2).
```

Hence

```text
log|det(m I_3 + j F1)|  -  log|m^3|
   =  log|1 - (3/8) j^2 / m^2|.                                         (W1.L)
```

**Step 6 — Determinant of `m I_2 + j sqrt(3/8) Z_row`.** Since
`Z_row = diag(1, -1)`, the eigenvalues of
`m I + j sqrt(3/8) Z_row` are `{ m + j sqrt(3/8), m - j sqrt(3/8) }`,
so

```text
det(m I_2 + j sqrt(3/8) Z_row)
   =  (m + j sqrt(3/8)) · (m - j sqrt(3/8))                             (DS1)
   =  m^2 - (3/8) j^2
   =  m^2 · (1 - (3/8) j^2 / m^2).
```

Hence

```text
log|det(m I_2 + j sqrt(3/8) Z_row)|  -  log|m^2|
   =  log|1 - (3/8) j^2 / m^2|.                                         (W1.R)
```

Comparison of (W1.L) and (W1.R) gives (W1).

**Step 7 — Same calculation for (W2).** Replacing `sqrt(3/8)` by
`3/sqrt(8) = 3/(2 sqrt(2))` in Steps 5-6:

```text
det(m I_3 + j F2)             =  m^3 · (1 - (9/8) j^2 / m^2),
det(m I_2 + j (3/sqrt(8)) Z)  =  m^2 · (1 - (9/8) j^2 / m^2),
```

so both sides of (W2) reduce to `log|1 - (9/8) j^2 / m^2|`.

**Step 8 — Closing.** Identities (S1)-(S4) follow from Steps 3-4, and
(W1)-(W2) follow from Steps 5-7. All steps are pure finite-dimensional
real matrix algebra, verified at exact sympy precision in the runner
on the explicit `3 x 3` and `2 x 2` matrices. ∎
