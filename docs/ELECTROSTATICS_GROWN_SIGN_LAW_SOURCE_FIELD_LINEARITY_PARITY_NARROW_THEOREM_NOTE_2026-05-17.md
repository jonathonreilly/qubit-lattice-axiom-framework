## Statement

Let `Q = (q_1, q_2, ...)` be abstract real source-charge symbols at
positions `Z = (z_1, z_2, ...)` (positions admitted from the upstream
geometry). Suppose the parent note's pointwise source-field-construction
rule `(I1)`-`(I2)` is supplied as a cited input from
`electrostatics_grown_sign_law_note` (current `audited_conditional`,
per `docs/audit/data/audit_ledger.json` at the date of this note); the
geometry `(pos, adj, layers, det)` and the kernel `g(z, i)` (strictly
positive at every node) are admitted as black-box inputs from the
parent runner.

Define the source-field-construction map

```text
F({(z_k, q_k)}_k)[i]  :=  sum_k q_k * g(z_k, i).                       (D1)
```

`(D1)` is the verbatim parent-runner `_field_from_sources` rule. Then
the three identities

```text
F({(z_0, +n)})           =  n * F({(z_0, +1)}),                        (P1)
F({(z_0, -1)})           =  - F({(z_0, +1)}),                          (P2)
F({(z_0, +1), (z_0, -1)}) = 0  (pointwise),                            (P3)
```

hold exactly as identities in the free real-vector ring over the
geometry node set, parametrically in `g(z_0, ·)`.

## Proof

Pure algebraic substitution in `(D1)`.

`(P1)`. From `(D1)` with a single source `(z_0, +n)`:

```text
F({(z_0, +n)})[i]  =  (+n) * g(z_0, i)
                   =  n * (+1) * g(z_0, i)
                   =  n * F({(z_0, +1)})[i],   for every i.
```

`(P2)`. From `(D1)` with a single source `(z_0, -1)`:

```text
F({(z_0, -1)})[i]  =  (-1) * g(z_0, i)
                   =  - (+1) * g(z_0, i)
                   =  - F({(z_0, +1)})[i],     for every i.
```

`(P3)`. From `(D1)` with two same-point sources `(z_0, +1)` and
`(z_0, -1)`:

```text
F({(z_0, +1), (z_0, -1)})[i]
  =  (+1) * g(z_0, i) + (-1) * g(z_0, i)
  =  g(z_0, i) - g(z_0, i)
  =  0,                                        for every i.
```

The pointwise zero-field consequence `(P3)` together with the parent
runner's definition `Phi(0, q_test) = centroid_z(free)` (verbatim from
`scripts/ELECTROSTATICS_GROWN_SIGN_LAW.py` lines computing the
`free_centroid` baseline) yields, as a direct algebraic corollary,

```text
delta_z(same-point +1/-1, q_test)
  := Phi(F({(z_0, +1), (z_0, -1)}), q_test) - centroid_z(free)
  =  Phi(0, q_test) - centroid_z(free)
  =  0.                                                                (C1)
```

∎

## Derivable corollaries

```text
F({(z_0, q), (z_0, -q)})  =  0  for any abstract charge q              (C2)
F({(z_0, q_a), (z_0, q_b)}) =  (q_a + q_b) * g(z_0, ·)                 (C3)
                            (same-point sum collapses to net charge)
F({(z_a, q), (z_b, q)})    =  q * (g(z_a, ·) + g(z_b, ·))              (C4)
                            (like-pair separates as q-scaled sum)
F({(z_0, c * q)})          =  c * F({(z_0, q)})  for any scalar c      (C5)
                            (general charge scaling, `(P1)` with n -> c)
```

All follow algebraically from `(D1)`.
