## Why this note exists

The retained finite-range Lieb-Robinson lane is adequate for Hamiltonians whose interaction supports have a fixed diameter. It is not adequate for exact logarithms of strictly local transfer operators after noncommuting factors are multiplied: BCH commutators generate longer supports with exponentially small coefficients.

The tempting repair is to put a pure exponential weight `G_mu(r) = exp(-mu r)` into the finite-range proof. That fails on `Z^d`. If `x = 0`, `y = R e_1`, and `z = k e_1` runs along the geodesic from `x` to `y`, then

```text
    G_mu(d(x,z)) G_mu(d(z,y)) / G_mu(d(x,y))
      = exp[-mu(k + R-k - R)]
      = 1
```

for each `k = 0,...,R`. Thus

```text
    sum_z G_mu(d(x,z)) G_mu(d(z,y)) / G_mu(d(x,y))  >=  R + 1,
```

so no volume-independent convolution constant exists for the pure exponential weight. This note uses the standard reproducing weight with a polynomial denominator and displays the finite constant.

## Setting

Let `Lambda` be a finite subset of `Z^d` with graph metric `d(x,y) = ||x-y||_1`. The site Hilbert space is finite dimensional. A Hamiltonian is written as

```text
    H = sum_{Z subset Lambda} h_Z,
```

where each `h_Z = h_Z^*` acts trivially outside `Z`, and the sum is finite. For `mu > 0` and `alpha > d`, define

```text
    F_{mu,alpha}(r) = exp(-mu r) / (1+r)^alpha.
```

This note uses the pair weighted interaction norm

```text
    ||H||_{mu,alpha}
      := sup_{u,v in Lambda}
            F_{mu,alpha}(d(u,v))^{-1}
            sum_{Z contains u,v} ||h_Z||.                         (1)
```

This is the clean interaction norm for the proof below. The more local diameter version

```text
    sup_u sum_{Z contains u} ||h_Z|| / F_{mu,alpha}(diam Z)
```

implies finiteness of (1), because `d(u,v) <= diam Z` for every `u,v in Z` and `F_{mu,alpha}` is decreasing.

Set

```text
    S_alpha^{(d)} := sum_{z in Z^d} (1+||z||_1)^(-alpha)  < infinity,
    C_alpha^{(d)} := 2^alpha S_alpha^{(d)}.                       (2)
```

The runner computes finite-box approximations to this constant in `d=1` and `d=2` and checks the reproducing inequality numerically.

## Statements

**(L1) Pure-exponential obstruction.** For `G_mu(r)=exp(-mu r)`, the convolution ratio

```text
    R_G(x,y) := sum_z G_mu(d(x,z)) G_mu(d(z,y)) / G_mu(d(x,y))
```

is unbounded on `Z^d`. Already in `d=1`, `R_G(0,R) >= R+1`.

**(L2) Reproducing weight.** For `F = F_{mu,alpha}` with `alpha > d`,

```text
    sum_{z in Z^d} F(d(x,z)) F(d(z,y))
      <= C_alpha^{(d)} F(d(x,y))                                  (3)
```

with the explicit finite constant (2).

**(L3) Quasilocal Lieb-Robinson bound.** Let `J_F := ||H||_{mu,alpha}` from (1). For single-site observables `A_x` and `B_y`,

```text
    ||[ exp(i t H) A_x exp(-i t H), B_y ]||
      <= (2 ||A_x|| ||B_y|| / C_alpha^{(d)})
         ( exp(2 C_alpha^{(d)} J_F |t|) - 1 )
         F_{mu,alpha}(d(x,y)).                                    (4)
```

Every constant in (4) is finite on finite `Lambda` whenever `J_F < infinity`.

**(L4) Finite velocity after a rate split.** For any `0 < mu' < mu`,

```text
    F_{mu,alpha}(r) <= exp(-mu' r),
```

and therefore (4) gives the cone form

```text
    ||[A_x(t),B_y]||
      <= (2 ||A_x|| ||B_y|| / C_alpha^{(d)})
         exp(2 C_alpha^{(d)} J_F |t| - mu' d(x,y)).
```

The associated finite velocity is

```text
    v(mu') = 2 C_alpha^{(d)} J_F / mu'.                            (5)
```

**(L5) Finite-range consistency.** If the interaction is finite range, then `J_F` is finite for every `mu > 0` and `alpha > d`, so (4) specializes to a valid finite-range Lieb-Robinson envelope. Its spatial factor is no slower than the pure exponential `exp(-mu r)`, because `(1+r)^(-alpha) <= 1`.

**(L6) Conditional consumer corollary for log-transfer dynamics.** If a downstream log-transfer source supplies finite `J_F = ||H_log||_{mu,alpha}` for some `mu > 0` and `alpha > 3`, then (4) applies on the framework's finite `Z^3` blocks. This is not stated as an axiom-level derivation for every transfer operator: the companion runner constructs one concrete strictly local positive transfer

```text
    T = exp(-A/2) exp(-B) exp(-A/2)
```

with noncommuting nearest-neighbor qubit terms, computes `H_log = -log T`, decomposes it in the Pauli basis, verifies finite `J_F`, and checks the bound without fitted constants.

## Proof

### Step 1: the reproducing inequality

Write

```text
    r = d(x,y),    a = d(x,z),    b = d(z,y).
```

The triangle inequality gives `r <= a+b`, hence

```text
    exp[-mu(a+b-r)] <= 1.                                          (6)
```

Now compute the pointwise ratio:

```text
    F(a)F(b)/F(r)
      = exp[-mu(a+b-r)] (1+r)^alpha / ((1+a)^alpha (1+b)^alpha).   (7)
```

Since `1+r <= 1+a+b <= (1+a)+(1+b)` and, for positive `U,V`,

```text
    (U+V)^alpha <= 2^(alpha-1)(U^alpha + V^alpha),
```

we have

```text
    (1+r)^alpha
      <= 2^(alpha-1)((1+a)^alpha + (1+b)^alpha).                   (8)
```

Combining (6), (7), and (8),

```text
    F(a)F(b)/F(r)
      <= 2^(alpha-1)
         ( (1+a)^(-alpha) + (1+b)^(-alpha) ).                      (9)
```

Summing over `z in Z^d` gives

```text
    sum_z F(d(x,z)) F(d(z,y)) / F(d(x,y))
      <= 2^(alpha-1) sum_z (1+d(x,z))^(-alpha)
       + 2^(alpha-1) sum_z (1+d(z,y))^(-alpha)
      = 2^alpha sum_z (1+||z||_1)^(-alpha)
      = C_alpha^{(d)}.                                             (10)
```

Because `alpha > d`, the lattice sum in (10) converges. This proves (L2).

### Step 2: interaction kernel bound

Define

```text
    K(u,v) := sum_{Z contains u,v} ||h_Z||.                         (11)
```

By (1),

```text
    K(u,v) <= J_F F(d(u,v)).                                        (12)
```

For `k >= 1`, define the weighted path sums

```text
    P_1(x,y) := K(x,y),
    P_k(x,y) := sum_{z_1,...,z_{k-1}}
                K(x,z_1) K(z_1,z_2) ... K(z_{k-1},y).              (13)
```

For `k=1`, (12) gives

```text
    P_1(x,y) <= J_F F(d(x,y)).                                      (14)
```

For `k=2`, using (12) and then (3),

```text
    P_2(x,y)
      <= J_F^2 sum_z F(d(x,z)) F(d(z,y))
      <= J_F^2 C_alpha^{(d)} F(d(x,y)).                            (15)
```

Inductively, if

```text
    P_k(x,z) <= J_F^k (C_alpha^{(d)})^(k-1) F(d(x,z)),
```

then

```text
    P_{k+1}(x,y)
      = sum_z P_k(x,z) K(z,y)
      <= J_F^(k+1) (C_alpha^{(d)})^(k-1)
         sum_z F(d(x,z)) F(d(z,y))
      <= J_F^(k+1) (C_alpha^{(d)})^k F(d(x,y)).                    (16)
```

Thus, for every `k >= 1`,

```text
    P_k(x,y) <= J_F^k (C_alpha^{(d)})^(k-1) F(d(x,y)).              (17)
```

The reproducing inequality is used once at each induction step.

### Step 3: Duhamel and the commutator series

Let

```text
    A_x(t) = exp(i t H) A_x exp(-i t H).
```

The finite-dimensional Duhamel expansion of the Heisenberg equation is

```text
    A_x(t)
      = A_x
        + sum_{k>=1} (i t)^k / k! ad_H^k(A_x),
    ad_H(O) := [H,O].                                               (18)
```

Since `x != y` implies `[A_x,B_y]=0`, the first nonzero contribution to
`[A_x(t),B_y]` is controlled by interaction chains that connect `x` to `y`. Each commutator with a local term contributes the elementary bound

```text
    ||[h_Z,O]|| <= 2 ||h_Z|| ||O||.                                 (19)
```

Applying (19) along a length-`k` interaction chain and summing over all intermediate sites gives the term-by-term estimate

```text
    T_k
      := || k-th Duhamel contribution to [A_x(t),B_y] ||
      <= 2 ||A_x|| ||B_y|| (2 |t|)^k P_k(x,y) / k!.                 (20)
```

Insert (17) into (20):

```text
    T_k
      <= 2 ||A_x|| ||B_y||
         (2 |t|)^k J_F^k (C_alpha^{(d)})^(k-1) F(d(x,y)) / k!
      = (2 ||A_x|| ||B_y|| / C_alpha^{(d)})
        (2 C_alpha^{(d)} J_F |t|)^k F(d(x,y)) / k!.                 (21)
```

Summing (21) for `k >= 1` yields

```text
    ||[A_x(t),B_y]||
      <= (2 ||A_x|| ||B_y|| / C_alpha^{(d)})
         sum_{k>=1} (2 C_alpha^{(d)} J_F |t|)^k / k!
         F(d(x,y))
      = (2 ||A_x|| ||B_y|| / C_alpha^{(d)})
        (exp(2 C_alpha^{(d)} J_F |t|) - 1)
        F(d(x,y)).                                                  (22)
```

This proves (L3).

### Step 4: finite velocity

For any `0 < mu' < mu`,

```text
    F_{mu,alpha}(r)
      = exp(-mu' r) exp(-(mu-mu')r) (1+r)^(-alpha)
      <= exp(-mu' r).                                               (23)
```

Substituting (23) into (22) gives

```text
    ||[A_x(t),B_y]||
      <= (2 ||A_x|| ||B_y|| / C_alpha^{(d)})
         exp(2 C_alpha^{(d)} J_F |t| - mu' d(x,y)).                 (24)
```

The exponent is nonpositive outside

```text
    d(x,y) >= (2 C_alpha^{(d)} J_F / mu') |t|,
```

which proves the finite velocity (5).
