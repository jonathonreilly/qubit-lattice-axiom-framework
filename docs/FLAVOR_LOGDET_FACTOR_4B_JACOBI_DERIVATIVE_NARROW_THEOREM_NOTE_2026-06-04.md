## Claim

Let `n` be a positive integer. Let `D` be a fixed `n × n` complex matrix.
Let `j = (j_1, ..., j_n) ∈ R^n` and set `J(j) := diag(j_1, ..., j_n)`. Let

```text
M(j) := D + J(j),
```

and assume `M(j)` is invertible on an open neighborhood `U ⊂ R^n` of a
point `j*`. Define on `U`:

```text
W(j) := log |det M(j)|.
```

Let `P_x` (for `x ∈ {1, ..., n}`) be the diagonal `n × n` matrix with a
`1` in entry `(x, x)` and zeros elsewhere — the canonical "site-`x`
projector" on the site label set.

**Theorem (finite-block Jacobi derivative identity).** On `U`,

```text
∂W/∂j_x  =  Re Tr[ M(j)^(-1) · P_x ]  =  Re [ M(j)^(-1) ]_{xx}.        (T1)
```

This is the source-derivative identity stated in factor 4 of
`FLAVOR_LOGDET_GENERATOR_THREE_FACTOR_PROVENANCE_2026-06-04.md`,
proved here as a pure finite-matrix calculus statement.

## Inline proof

We prove `(T1)` for general invertible complex `n × n` matrices with smooth
parametric dependence; the case `M(j) = D + diag(j)` then follows by
specializing the matrix-derivative `∂M/∂j_x`.

### Step 1 — Standard Jacobi formula for `det`

Let `M(t)` be a smooth one-parameter family of invertible `n × n` complex
matrices on an open `t`-interval. The textbook Jacobi formula reads

```text
d/dt det M(t)  =  det M(t) · Tr[ M(t)^(-1) · dM/dt ].                     (J)
```

This is finite-matrix calculus and is independent of the Record axiom. A
direct cofactor-expansion proof:

```text
det M(t)
  =  Σ_σ sign(σ) Π_i M(t)_{i, σ(i)}
d/dt det M(t)
  =  Σ_σ sign(σ) Σ_k (dM/dt)_{k, σ(k)} · Π_{i ≠ k} M(t)_{i, σ(i)}
  =  Σ_k Σ_σ sign(σ) (dM/dt)_{k, σ(k)} · Π_{i ≠ k} M(t)_{i, σ(i)}.
```

Group the inner `Σ_σ` by the value of `σ(k) = ℓ`:

```text
  =  Σ_k Σ_ℓ (dM/dt)_{k, ℓ} · Σ_{σ : σ(k)=ℓ} sign(σ) Π_{i ≠ k} M(t)_{i, σ(i)}
  =  Σ_k Σ_ℓ (dM/dt)_{k, ℓ} · C_{k, ℓ},                                  (J')
```

where `C_{k, ℓ}` is the `(k, ℓ)` cofactor of `M(t)`. The classical adjugate
identity reads `M(t)^(-1) = (1 / det M(t)) · adj(M(t))^T`, i.e.
`[ M(t)^(-1) ]_{ℓ, k} = C_{k, ℓ} / det M(t)`. Substituting,

```text
d/dt det M(t)
  =  det M(t) · Σ_k Σ_ℓ (dM/dt)_{k, ℓ} · [ M(t)^(-1) ]_{ℓ, k}
  =  det M(t) · Tr[ M(t)^(-1) · dM/dt ],                                 (J)
```

which is `(J)`.

### Step 2 — From `det` to `log |det|`

On the open set `U` where `M(j)` is invertible, `det M(j) ≠ 0`, so
`|det M(j)| > 0` and `log |det M(j)|` is smooth in `j`. For any smooth
complex-valued nowhere-zero function `f(j)`,

```text
d log |f(j)|  =  d ((1/2) log |f|^2)  =  (1/2) d log (f f̄)
              =  (1/2) ( df/f  +  df̄/f̄ )
              =  Re ( df / f ).                                          (LOG)
```

Apply `(LOG)` to `f = det M(j)` and substitute `(J)` along the partial
derivative `t → j_x` (with all other `j_y`, `y ≠ x`, held fixed):

```text
∂_x log |det M(j)|
  =  Re ( (∂_x det M(j)) / det M(j) )
  =  Re ( Tr[ M(j)^(-1) · ∂M/∂j_x ] ).                                  (T0)
```

This holds for any smooth parametric family `M(j)` of invertible complex
matrices.

### Step 3 — Specialize the source coupling `M(j) = D + diag(j)`

For `M(j) = D + J(j)` with `J(j) = diag(j_1, ..., j_n)`, the partial
derivative `∂M/∂j_x` is the diagonal matrix with a `1` in entry `(x, x)`
and zeros elsewhere:

```text
∂M/∂j_x  =  P_x.                                                       (P)
```

Substituting `(P)` into `(T0)`:

```text
∂W/∂j_x  =  Re Tr[ M(j)^(-1) · P_x ].                                  (T1a)
```

Since `P_x` is the rank-one diagonal projector at site `x`,
`Tr[ A · P_x ] = A_{x, x}` for any `A`. Therefore

```text
∂W/∂j_x  =  Re [ M(j)^(-1) ]_{x, x},                                   (T1b)
```

establishing both forms of `(T1)`. ∎

## Independence from the Record axiom

The proof above uses:

1. Cofactor expansion of `det` over `S_n` (finite combinatorics);
2. The classical adjugate identity `M^(-1) = adj(M)^T / det M`;
3. The complex log-derivative identity `d log |f| = Re(df/f)` for
   smooth nowhere-zero `f`;
4. Chain rule for partial derivatives.

None of these requires the Record axiom. The Record axiom contributes
nothing to the Jacobi identity; it only governs the upstream form-selection
question of whether `W = log |det|` (factors 1-3 of the provenance
decomposition).
