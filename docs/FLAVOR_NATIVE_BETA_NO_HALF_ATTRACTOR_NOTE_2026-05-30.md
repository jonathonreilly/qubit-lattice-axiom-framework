## Statement

For the supplied one-parameter path

```text
r(t) = tanh^4(t),        t >= 0,
```

the derivative is

```text
beta_r(t) = dr/dt = 4 tanh^3(t) sech^2(t).
```

Hence `beta_r(t)>0` for every finite `t>0`, with endpoint limits
`r(0)=0` and `lim_{t->infty} r(t)=1`. The value `r=1/2` occurs at the finite
transit time

```text

```


Therefore `r=1/2` is not a fixed point of this supplied `tanh^4` path. It is a
transit value of this path.

## Proof

Differentiate directly:

```text
dr/dt = 4 tanh^3(t) * d(tanh t)/dt
      = 4 tanh^3(t) sech^2(t).
```

For finite `t>0`, `tanh(t)>0` and `sech^2(t)>0`, so `dr/dt>0`. The endpoint
values follow from `tanh(0)=0` and `lim_{t->infty} tanh(t)=1`.

Solving `tanh^4(t)=1/2` gives `tanh(t)=2^(-1/4)` and
`t=t_* = atanh(2^(-1/4))`. Substitution gives
`beta_r(t_*) = 4 * 2^(-3/4) * (1 - 2^(-1/2))`, which is strictly positive.
Thus `r=1/2` is a transit value, not a fixed point, for this supplied path. ∎
