## 1. Claim

For the continuum free Dirac kernel

```text
    S(p) = (m - i gamma.p) / (p^2 + m^2),
```

the finite mode algebra has the following bounded support facts:

1. `S(p)` is the inverse of the Euclidean quadratic form
   `M(p) = m + i gamma.p`.
2. The scalar denominator has Euclidean poles `p4 = +/- i E`, which continue to
   the Minkowski mass shell `p0 = +/- E`, with
   `E(p) = sqrt(|p|^2 + m^2)`.
3. The Minkowski Dirac Hamiltonian
   `H_D = Gamma^0 (Gamma^k p_k + m)` has spectrum
   `{+E, +E, -E, -E}`.
4. The positive-energy `u` spinors and negative-energy `v` spinors obey the
   standard completeness relations

```text
    sum_s u_s(p) ubar_s(p) = pslash + m,
    sum_s v_s(p) vbar_s(p) = pslash - m,
```

   with the load-bearing relative sign

```text
    sign(ubar u) = - sign(vbar v)
```

   and positive Hilbert norms `u^dag u = v^dag v = 2E`.
5. Given CAR quantization, the negative-energy branch can be relabeled as a
   positive-energy antiparticle branch,

```text
    H_CAR = sum_{p,s} E(p) (a^dag_{p,s} a_{p,s} + b^dag_{p,s} b_{p,s}),
```

   so the finite-mode Fock spectrum is bounded below by `0`.

This is a bounded support theorem about the free Dirac mode algebra. It does
not claim that the framework has derived the full free-sector spin-statistics
theorem.
