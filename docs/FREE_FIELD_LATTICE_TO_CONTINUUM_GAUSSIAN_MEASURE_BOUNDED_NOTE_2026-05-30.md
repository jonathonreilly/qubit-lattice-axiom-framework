## 2. Gaussian rigidity: the measure is fixed by the 2-point (Pfaffian map)

For the free (quadratic-action) fermion, the Euclidean expectation is the Berezin
integral against `exp(-chibar M chi)`, and every Schwinger function is the
**Pfaffian of the antisymmetric 2-point matrix** built from the covariance
`S = M^{-1}`:

```text
    < chi_{i_1} ... chi_{i_{2n}} >  =  Pf( S_{[i_a, i_b]} ),
    Pf(A)^2 = det(A),
```

with the equal partner statement for the bosonic Gaussian (the symmetric Isserlis
sum). This is `R`'s sub-piece 3 (ESTABLISHED there) and is re-exhibited here as a
**deterministic map** `2-point |-> all n-point`: the whole hierarchy is a fixed
continuous function of the 2-point matrix. The runner verifies the Pfaffian
hierarchy and `Pf^2 = det` at the 4- and 6-point level (G1), and the Laplace
recursion `Pf(A) = sum_j (-1)^{j} A[0,j] Pf(minor)` (G1). The map is
**statistics-blind in the covariance** (the same `S` feeds both the Pfaffian and
the Isserlis recursion); selecting which recursion the free sector obeys is the
spin-statistics question, which this note does **not** perform (it is `R`'s
deferred G3, untouched here).

**Consequence (the rigidity input).** If `S_a -> S` in a topology in which the
Pfaffian map is continuous (it is a polynomial in the matrix entries, hence
continuous in any norm), then **every** n-point function converges:
`Pf(S_a-block) -> Pf(S-block)`. Equivalently, the Gaussian **characteristic
functional**


is determined by the covariance `C`, and `C |-> chi_C(.)` is injective on a
spanning test set: convergence of the smeared covariance `<J, S_a J> -> <J, S J>`

convergence of the **measure / state**. The runner verifies the injectivity and
