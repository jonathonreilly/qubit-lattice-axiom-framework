## 4. Minkowski mode expansion with the antiparticle sector (load-bearing)

Wick-rotating the Euclidean pole structure gives the Minkowski mass shell. The
scalar denominator `p4^2 + E^2` has poles at `p4 = +-iE`; continuing
`p4 -> i p0` places the mass shell at `p0 = +-E`, the two-sheet `{+E, -E}`
structure that becomes the particle/antiparticle split.

In Minkowski signature (mostly-minus `eta = diag(+,-,-,-)`,
`{Gamma_mu, Gamma_nu} = 2 eta_{mu nu}`) the Dirac Hamiltonian
`H_D = Gamma^0 (Gamma^k p_k + m)` has eigenvalues exactly

```text
    { +E, +E, -E, -E },   E(p) = sqrt(p^2 + m^2),
```

-- two positive-energy solutions (particle, u-spinors) and two negative-energy
solutions (antiparticle, v-spinors). The spinors satisfy

```text
    (p_slash - m) u = 0,   (p_slash + m) v = 0,
```

with the **completeness relations**

```text
    Sum_s u_s(p) ubar_s(p) = p_slash + m,   Sum_s v_s(p) vbar_s(p) = p_slash - m,
```

normalizations `udag u = vdag v = 2E` (positive-definite Fock inner product) and
the **load-bearing relative sign**, stated convention-independently:

```text
    sign(ubar u) = - sign(vbar v)
    (in every Dirac basis; here ubar u = +2m, vbar v = -2m).
```

The antiparticle v-spinors are the canonical charge-conjugates `v = C ubar^T`,
`C = i Gamma^2 Gamma^0`. This `{+E, +E, -E, -E}` mode structure, with the
particle/antiparticle sectors and the negative relative sign, is **the
load-bearing reconstructed object**.

## 6. Microcausality (Pauli-Jordan)

The field (anti)commutator is governed by the Pauli-Jordan function `Delta(x)`,
which is Lorentz invariant and **odd** under `x -> -x`, and **vanishes for
spacelike `x`** (`x^2 < 0`). The Dirac anticommutator inherits this:

```text
    { psi(x), psibar(y) } = (i Gamma.partial + m) Delta(x - y)  ->  0
    for (x - y) spacelike.
```

On a momentum grid symmetric under `p <-> -p`, the equal-time (`x0 = 0`)
Pauli-Jordan integrand is exactly odd in `p`, so the spacelike kernel vanishes
identically (microcausality), while the timelike kernel does not (causal
support).

The **CAR-vs-Bose discriminator** is the canonical projector identity: the
antiparticle sector enters the equal-time anticommutator with the sign that,
together with `sign(ubar u) = - sign(vbar v)`, yields

```text
    (p_slash + m) + Gamma^0 (p_slash - m) Gamma^0 = 2E Gamma^0
    (CAR: canonical {psi, psidag} = delta^3),
```

whereas the commuting (Bose) combination

```text
    (p_slash + m) - Gamma^0 (p_slash - m) Gamma^0 = 2(gamma.p + m) != 2E Gamma^0
    (Bose: non-canonical),
```

leaving a nonzero spacelike commutator. CAR is microcausal; the commuting
spin-1/2 field is not.
