## Statement

On the free `U = 1` staggered surface, with real `m > 0`, d spatial axes, even
spatial periods, and the same two-step RP blocking in time, the
action-derived two-step transfer is diagonal after the standard reduced
momentum/two-site-cell transform.  For every full Brillouin-zone momentum
`p in T^d`, the forward decaying one-particle eigenvalue is

```text
    lambda_-(p) = exp(-2 E_d(p)),
    E_d(p) = arcsinh(sqrt(m^2 + sum_{mu=1}^d sin^2 p_mu)).
```

Equivalently, the reconstructed free log-transfer Hamiltonian has symbol
`E_d(p)` up to the already declared blocked-time normalization convention.
The formula is taste-degenerate across the `2^d` two-site-cell corners because
`sin^2(k_mu + pi r_mu) = sin^2 k_mu`.

For the position-space kernel

```text
    h(z) = (2 pi)^(-d) int_{T^d} E_d(p) exp(i p.z) d^d p,
```

the two-step symbol is `pi`-periodic in each momentum component, so
`h(z) = 0` whenever any coordinate `z_mu` is odd.  Along coordinate axes the
decay-rate scale is the one-axis value `arcsinh(m)`.  For arbitrary directions
the general contour bound proved below gives, for every
`0 < eta < arcsinh(m)`,

```text
    |h(z)| <= C_d(eta, m) exp(-eta ||z||_inf),
    C_d(eta, m) = sqrt(m^2 + (d-1) + cosh^2 eta).
```

Consequently, in the `l1` metric one may use any rate below
`arcsinh(m)/d`; a concrete uniform choice is
`r_d(m) = arcsinh(m)/(2d) > 0`.  The sharp anisotropic rate away from axes is
left open.

## Cell Convention and Phase Bookkeeping

Use time coordinate `t` and spatial coordinate `x in Z^d`.  The canonical
staggered phases are

```text
    eta_0(t,x) = 1,
    eta_mu(t,x) = (-1)^(t + x_1 + ... + x_{mu-1}),      mu = 1,...,d.
```

Write

```text
    xi_mu(x) = (-1)^(x_1 + ... + x_{mu-1}),
    H_hop = (1/2) sum_mu xi_mu(x) (tau_{+mu} - tau_{-mu}).
```

The spatial term on time slice `t` is `(-1)^t H_hop`, so the free mode
equation has the same alternating form as the one-axis construction:

```text
    psi_{t+1} = -2 (m I + (-1)^t H_hop) psi_t + psi_{t-1}.
```

Thus

```text
    T_even = [[-2(m I + H_hop), I], [I, 0]],
    T_odd  = [[-2(m I - H_hop), I], [I, 0]],
    T_2    = T_odd T_even.
```

Now fold the spatial lattice by translations through two sites in every
spatial direction.  A reduced momentum sector is labelled by
`k in (-pi/2, pi/2]^d` and a cell/taste corner
`r in {0,1}^d`, representing the full momentum
`p_r = k + pi r`.  Multiplication by `xi_mu(x)` shifts the corner by
`s_mu = (1,...,1,0,...,0)` with ones in slots `< mu`, and the finite
difference contributes
`i sin(p_{r,mu}) = i (-1)^{r_mu} sin(k_mu)`.  Therefore

```text
    H_hop(k) = i sum_mu sin(k_mu) Gamma_mu,
    Gamma_mu |r> = (-1)^{r_mu} |r xor s_mu>.
```

A direct sign check gives

```text
    Gamma_mu^2 = I,
    Gamma_mu Gamma_nu + Gamma_nu Gamma_mu = 0,     mu != nu.
```

Therefore

```text
    H_hop(k)^2 = - (sum_mu sin^2 k_mu) I.
```

This is the only dimension-dependent algebraic step.

## Two-Step Eigenvalue Algebra

Let `i lambda` be an eigenvalue of `H_hop(k)`, so
`lambda^2 = sum_mu sin^2 k_mu`.  On that eigenline the time recurrence is
identical to the one-spatial-axis recurrence with `sin p` replaced by
`lambda`:

```text
    a = m + i lambda,
    T_even(lambda) = [[-2a, 1], [1, 0]],
    T_odd(lambda)  = [[-2conj(a), 1], [1, 0]].
```

The two-step matrix is

```text
    T_2(lambda) = T_odd(lambda) T_even(lambda)
                = [[4|a|^2 + 1, -2conj(a)], [-2a, 1]].
```

It has determinant `1` and trace `2 + 4(m^2 + lambda^2)`.  With
`R = m^2 + lambda^2` and `sinh E = sqrt(R)`,

```text
    spec T_2(lambda)
      = { 1 + 2R + 2 sqrt(R(1+R)),
          1 + 2R - 2 sqrt(R(1+R)) }
      = { exp(+2E), exp(-2E) },
    E = arcsinh(sqrt(R)).
```

Substituting `lambda^2 = sum_mu sin^2 k_mu` and unfolding
`p = k + pi r` gives the displayed d-dimensional dispersion

```text
    E_d(p) = arcsinh(sqrt(m^2 + sum_mu sin^2 p_mu)).
```

The decaying forward channel is `exp(-2 E_d(p))`; the reciprocal growing
channel is the backward-time solution, as in the one-axis construction.

## Rate Bound and Axis Scale

For `z != 0`, choose an axis `mu*` with `|z_mu*| = ||z||_inf` and shift only
`p_mu*` to `p_mu* + i eta sign(z_mu*)`, with `0 < eta < arcsinh(m)`, while
the transverse momenta remain real.  This is the sign compatible with the
Fourier convention `exp(i p.z)`: the shifted exponential contributes
`exp(-eta |z_mu*|)` on the selected axis.  On the shifted strip,

```text
    Re(m^2 + sum_mu sin^2 p_mu) >= m^2 - sinh^2 eta > 0,
    |m^2 + sum_mu sin^2 p_mu| <= m^2 + (d-1) + cosh^2 eta.
```

The principal square root and `arcsinh` branches are analytic there, and the
same integral bound as the one-axis note gives

```text
    |E_d(p)| <= sqrt(m^2 + (d-1) + cosh^2 eta) = C_d(eta,m).
```

The contour shift then yields

```text
    |h(z)| <= C_d(eta,m) exp(-eta ||z||_inf).
```

Since `||z||_inf >= ||z||_1/d`, this also gives

```text
    |h(z)| <= C_d(eta,m) exp(-(eta/d) ||z||_1).
```

Choosing `eta = arcsinh(m)/2` gives the explicit positive all-direction
`l1` rate `arcsinh(m)/(2d)`.  Along an axis, the first branch point is still
at the transverse minimum `p_perp = 0`, `p_axis = i arcsinh(m)`; the local
branch expansion is the same one-axis obstruction with transverse Laplace
prefactors.  The runner verifies the axis rate against `arcsinh(m)` on
resolved `d = 2` and `d = 3` blocks.  The sharp anisotropic rate for general
directions is not asserted here.
