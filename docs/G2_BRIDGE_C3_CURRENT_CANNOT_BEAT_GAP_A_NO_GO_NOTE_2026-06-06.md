per [`FLAVOR_EINSELECTION_2SECTOR_MODULO_KREALITY_2026-06-02.md`](FLAVOR_EINSELECTION_2SECTOR_MODULO_KREALITY_2026-06-02.md),

A tempting bridge would close Gap A by using the **K-odd `C_3` current**

single missing ingredient.

This note does **not** claim `δ=0` / K-reality is underivable in general; it
is scoped to the `A = i(C - C^2)` route and to emergent time as the source.

## 1. Positive half (derived, weight-clean): partition given K-reality

Let `C` be the `C_3` cyclic shift (`C^3 = I`), `S = C + C^2`,
`A = i(C - C^2)`. A `C_3`-invariant Hermitian monitored observable that is
**K-real** (`conj(M) = M`) lies in `span_R{I, S}`. With

```text
eig(S) = {+2, -1, -1}     (singlet rank 1, doublet rank 2 degenerate)
```

a sharp `S` record registers the **2-block partition** `{P_singlet, P_doublet}`
(`P_singlet + P_doublet = I`, ranks 1 and 2). Resolving the doublet — i.e.
the 3-mode (`r=0`) partition — strictly requires the K-odd `A`, with
`eig(A) = {0, ±√3}`.

**Weight-clean (guardrail G3).** For *every* `C_3`-invariant
`H = a I + b C + b̄ C^2`, the registration map
`D(H) = P_singlet H P_singlet + P_doublet H P_doublet` is a **no-op**
(`‖P_singlet H P_doublet‖ = 0` for all `r = |b|^2/a^2`; verified at
`r ∈ {0, 0.13, 1, 5, 12.2}`). So the partition is delivered while the
weight `r` is left a **free registered pattern** — no weight leak, no
realist slip.

## 2. The no-go: `A = i(C - C^2)` cannot source the `δ=0` selector

`A` is the obvious candidate: it is genuinely the Hermitian generator of
`C_3` cyclic rotation (it shares `C`'s Fourier eigenbasis, and
`exp(i t* A) = C^2` at `t* = 2π/(3√3)`), and it is K-odd
(`conj(A) = -A`). Nonetheless it cannot beat Gap A, for four independently
verified reasons:

1. **Wrong kind of generator.** `A` has **indefinite** spectrum
   `{0, ±√3}` and `exp(i t A)` is **periodic** (`exp(i (2π/√3) A) = I`) —
   a compact U(1) that returns to identity. The framework emergent-time
   generator `H_gen = -(1/τ) log T` has **non-negative** spectrum and a
   **monotone** record-accumulation arrow
   ([`SINGLE_CLOCK_STONE_FINITE_DIM_UNIQUENESS_NARROW_THEOREM_NOTE_2026-05-10.md`](SINGLE_CLOCK_STONE_FINITE_DIM_UNIQUENESS_NARROW_THEOREM_NOTE_2026-05-10.md),
   retained). A flow that returns to the identity is not an arrow, and lives
   on the spacetime/transfer factor, not the generation factor.

2. **The flow freezes the commutant.** `[S, A] = 0`, so `exp(i t A)` leaves
   both `S` and `A` invariant (`‖S(t) - S‖, ‖A(t) - A‖ ~ 10^{-15}`). There
   is no standing-vs-winding distinction to exploit.

3. **The `δ` direction *is* the `A` direction — and it is partition-blind.**
   The K-odd deformation is exactly
   `H(a,b) - H(a,b̄) = 2·Im(b)·A`, i.e. moving `δ` moves along `A`. Since
   `A` commutes with `S`, this deformation is **block-diagonal**
   (`‖P_singlet (H-H̄) P_doublet‖ ~ 10^{-16}`): it lives inside the
   `S`-commutant and the 2-block partition registration is **blind** to it.

4. **The unique `C_3`-invariant T-odd operator is `A`.** The space of
   `C_3`-invariant K-odd Hermitian operators is **1-dimensional**,
   `= span{A}`, every member commuting with `S`. Therefore a `δ=0` selector
   — which must be **T-odd AND non-commuting with `S`** to reach the `δ`
   direction without being parity-blind — **necessarily breaks
   `C_3`-invariance**. That is exactly the chirality import
   ([`KOIDE_Z3_EQUIVARIANT_ANTICOMMUTING_NO_GO_NOTE_2026-05-16.md`](KOIDE_Z3_EQUIVARIANT_ANTICOMMUTING_NO_GO_NOTE_2026-05-16.md),
   retained_bounded). Emergent time, being `C_3`-invariant and
   conjugation-even, cannot supply it.

The reflection-positivity / CPT variant of the bridge is independently dead:
RP is provably blind to CP-odd imaginary content
([`STRONG_CP_RP_HALF_CANNOT_FORBID_CP_ODD_IMAGINARY_NO_GO_NOTE_2026-05-16.md`](STRONG_CP_RP_HALF_CANNOT_FORBID_CP_ODD_IMAGINARY_NO_GO_NOTE_2026-05-16.md),
