## Statement

Let `H` be `scripts/gate_b_farfield_harness.py` at the SHA-256 pinned
in the cached runner output at
`logs/runner-cache/gate_b_farfield_harness.txt`
(`runner_sha256: 366ba73255b74b1775847ea5eaba9ac004fc4c3bf2a60a710102330f4900947a`).
Let the **admitted-context ingredient list** `Ξ` be:

- **growth rule** `G`: template previous layer at spacing `h = 0.5`,
  Gaussian per-coordinate drift of standard deviation `drift · h` from
  the templated grid position, restoring force toward the grid label
  of strength `restore`, and nearest-neighbor connectivity from grid
  labels at radius `MAX_D_PHYS / h = round(3 / 0.5) = 6` cells;
- **source law** `S`: `1 / r` field perturbation of magnitude
  `STRENGTH / (r + 0.1)` placed at the per-seed grid label
  `(layer = 2 NL / 3, iy = 0, iz = round(z_mass / h))` for each
  declared `z_mass ∈ {3, 4, 5}`;
- **propagation kernel** `K`: ordered-by-`x` two-slit-style amplitude
  update with weight `exp(-β θ^2) · h^2 / L^2`, `θ` the polar angle
  between the edge and the `x`-axis, `β = 0.8`, and complex phase
  `exp(i k L (1 - f̄))` with `k = 5.0` and `f̄ = (f_i + f_j) / 2`;
- **valley-linear action** `A`: `S(edge) = L (1 - f̄)` on each edge,
  used inside the kernel phase exactly as in `K`;
- **readout criterion** `R`: per-seed z-centroid of the
  detector-row probability `|amp[d]|^2` summed over the last layer's
  nodes, the binary TOWARD test
  `z_centroid(with source) > z_centroid(without source)` accumulated
  across `seeds × z_masses`, and the slope of `log Δz_centroid` vs
  `log STRENGTH` on the three-point probe
  `STRENGTH ∈ {1e-6, 1e-5, 5e-5}` at the `z_mass = 3` source position
  per seed, with the slope rounded to two decimals.

Let the **declared rows** `Λ` be the four `(drift, restore)` rows
hard-coded in `DRIFT_RESTORE_ROWS`:
`(0.3, 0.5)`, `(0.2, 0.7)`, `(0.1, 0.9)`, `(0.0, 1.0)`.

Let the **declared seeds** be `seeds = list(range(12))`.

Let the **cached readout** `Ω` be the contents of the frozen runner
cache `logs/runner-cache/gate_b_farfield_harness.txt`:

```
drift=0.3,rest=0.5       : 36/36 TOWARD (100%), F~M=1.00
drift=0.2,rest=0.7       : 36/36 TOWARD (100%), F~M=1.00
drift=0.1,rest=0.9       : 36/36 TOWARD (100%), F~M=1.00
exact grid               : 36/36 TOWARD (100%), F~M=1.00
```

**Conclusion (T1) (determinism of the harness under `Ξ`).**
The harness `H` is purely deterministic conditional on `Ξ` and the
declared seed list: the only stochastic element used by `H` is
`random.Random(seed).gauss(...)` in `G`, which is seed-deterministic;
all of `S`, `K`, `A`, `R` are deterministic functions of the geometry
produced by `G`. Therefore, for any fixed `(Ξ, Λ, seeds)`, repeated
execution of `H` returns byte-identical numerical readout up to
floating-point reproducibility on the same execution stack.

**Conclusion (T2) (the cached readout `Ω` is the readout under
`(Ξ, Λ, seeds)`).** The frozen cache
`logs/runner-cache/gate_b_farfield_harness.txt` was produced by
`H` at the pinned SHA-256, with exit code `0`, elapsed `1043.14 s`,
status `ok`. Its `stdout` table is exactly `Ω`. Therefore `Ω` is
the harness-defined readout of `H` under `(Ξ, Λ, seeds)`.

**Conclusion (T3) (the bounded conditional implication).** As an
implication between the admitted ingredient list `Ξ` and the cached
readout `Ω`:
```text
Ξ  AND  (Λ, seeds as declared)    ⊨    H reproduces Ω.                  (BC)
```
This is the bounded-conditional separator statement.

**Conclusion (T4) (separator: no physical-gravity content).** `(BC)`
does **not** make any claim about whether `Ξ` is the correct framework
identification of a Gate B far-field gravity observable. In
particular, `(BC)` is consistent with every choice of upstream
primitive-to-observable bridge: a bridge that fails to derive `Ξ`
from accepted primitives only refutes the parent
`GATE_B_FARFIELD_NOTE.md` physical-gravity reading; it does **not**
refute `(BC)`. The bounded conditional separator deliberately encodes
no physical reading and therefore is unfalsifiable in any direction
other than: (a) the runner-cache contents do not actually match `Ω`
under the pinned SHA-256, or (b) `H` is not deterministic under
`(Ξ, seeds)` as claimed.
