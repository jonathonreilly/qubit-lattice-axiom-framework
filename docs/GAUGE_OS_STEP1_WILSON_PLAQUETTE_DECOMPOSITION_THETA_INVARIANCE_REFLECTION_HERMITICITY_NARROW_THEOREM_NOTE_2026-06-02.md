## §1. Setting

### §1.1 Lattice, links, plaquettes

Let `Λ = (Z/L)^4` be a finite hypercubic lattice with sites
`x = (t, x⃗)`, `t ∈ Z/L`, `x⃗ ∈ (Z/L)^3`. Directed links carry a
group element

```text
    U_μ(x) ∈ G,     μ ∈ {0, 1, 2, 3},   x ∈ Λ.                          (1)
```

where `μ = 0` is the temporal direction and `G = SU(N_c)` (the
substep proofs work for any compact `G`; explicit SU(3) is used in
the runner for concreteness). The reverse link is `U_{-μ}(x + μ̂) :=
U_μ(x)^†` by gauge action convention.

A plaquette `p = (x, μ, ν)` with `μ < ν` carries holonomy

```text
    U_p  =  U_μ(x) · U_ν(x + μ̂) · U_μ(x + ν̂)^† · U_ν(x)^†.            (2)
```

Plaquettes split by orientation type:

- **spatial plaquettes** `p = (x, μ, ν)` with `μ, ν ∈ {1, 2, 3}` — three
  per site `(x, 1, 2), (x, 1, 3), (x, 2, 3)`;
- **temporal plaquettes** `p = (x, 0, i)` with `i ∈ {1, 2, 3}` — three
  per site `(x, 0, 1), (x, 0, 2), (x, 0, 3)`.

Total plaquette count on `Λ`: `6 · L^4`.

### §1.2 Wilson plaquette action

```text
    S_W[U]  =  -(β/N_c) Σ_{p} Re Tr U_p.                                 (3)
```

The sum runs over all distinct undirected plaquettes (each plaquette
counted once). `β > 0` is the bare lattice coupling. The action is
**real-valued** because for any group element `g ∈ G`,
`Tr g^{-1} = (Tr g)^*` and `Re Tr g = Re Tr g^{-1}`, so the reversed
plaquette gives the same `Re Tr` contribution.

### §1.3 Reflection through `t = -1/2`

The reflection `Θ` acts on lattice sites by

```text
    Θ(t, x⃗)  =  (-1 - t, x⃗).                                          (4)
```

Fixed-point set: `t = -1/2` (a half-integer time plane between
`t = -1` and `t = 0`). Action on slices: `Θ` exchanges
`t = 0 ↔ t = -1`, `t = 1 ↔ t = -2`, etc. On periodic lattice
`t ∈ Z/L`, equivalently `t ∈ {-L/2, ..., L/2 - 1}` and `Θ` acts as
`t ↦ -1 - t (mod L)`.

The induced action on directed links is:

- **temporal link** `U_0(t, x⃗)` (from `(t, x⃗)` to `(t + 1, x⃗)`) is
  reflected to the directed link from `(-1 - t, x⃗)` to `(-2 - t, x⃗)`,
  i.e. the reverse of the temporal link `U_0(-2 - t, x⃗)`:

  ```text
      (ΘU)_0(t, x⃗)  :=  U_0(-2 - t, x⃗)^†.                              (5)
  ```

- **spatial link** `U_i(t, x⃗)` is reflected to the spatial link at
  reflected time `(-1 - t, x⃗)`:

  ```text
      (ΘU)_i(t, x⃗)  :=  U_i(-1 - t, x⃗),   i ∈ {1, 2, 3}.              (6)
  ```

This is the standard OS reflection convention (Osterwalder-Seiler 1978
§4 eq (4.6); Montvay-Münster 1994 Ch. 7.1, eq (7.1.7)). Composition
twice: `Θ^2 U_μ(x) = U_μ(x)` (involution).

### §1.4 Temporal gauge fixing

By the standard temporal-gauge orbit-representative choice, set every
temporal link to identity:

```text
    U_0(t, x⃗)  =  I       for all  t, x⃗.                                (7)
```

In temporal gauge:

- the reflection acts trivially on temporal links:
  `(ΘU)_0(t, x⃗) = I^† = I = U_0(t, x⃗)`;
- the reflection acts on spatial links by `(ΘU)_i(t, x⃗) = U_i(-1 - t, x⃗)`,
  i.e. it reflects the spatial-link time-coordinate through `t = -1/2`.

In temporal gauge, every plaquette holonomy reduces to a product of
spatial links only (no temporal-link factor remains). This is the
setting on which the OS Step 1 decomposition is performed.

## §2. Substep (D1): Plaquette set partition and `S_W = S_+ + Θ(S_+) + S_mixed`

### §2.1 Plaquette set partition by time-coordinate type

In temporal gauge, every plaquette `p` has a well-defined
**time-coordinate signature** determined by the time-coordinates of its
four link endpoints. The temporal extent of plaquette `p`:

- **purely spatial** `p = (x, i, j)`, `i, j ∈ {1, 2, 3}`: all four
  links share a single time-slice `t = t(p)`. Define
  `t(p) := t` ∈ `Z/L`.
- **mixed temporal/spatial** `p = (x, 0, i)`, `i ∈ {1, 2, 3}`: links
  span two adjacent slices `t(x), t(x) + 1`. Define
  `t_(low)(p) := t(x)`, `t_(high)(p) := t(x) + 1`.

In temporal gauge with `U_0(x) = I`, the mixed plaquette holonomy
reduces to

```text
    U_(p = (x, 0, i))  =  I · U_i(x + 0̂) · I^† · U_i(x)^†
                       =  U_i(x + 0̂) U_i(x)^†                             (8)
```

per the retained
[`GAUGE_TEMPORAL_GAUGE_MIXED_KERNEL_SPATIAL_LINK_FACTORIZATION_NARROW_THEOREM_NOTE_2026-05-10`](GAUGE_TEMPORAL_GAUGE_MIXED_KERNEL_SPATIAL_LINK_FACTORIZATION_NARROW_THEOREM_NOTE_2026-05-10.md)
eq (11). Each mixed plaquette depends on exactly the **same spatial
link** `(x⃗, i)` at two adjacent times. So `S_mixed` is already
factorized into spatial-link convolution kernels by the retained
theorem; no new derivation is needed for this piece.

### §2.2 Three-set decomposition

Partition the plaquette set `P(Λ)` into three disjoint subsets keyed
by their relation to the half-integer plane `t = -1/2`:

```text
    P_+  :=  { p :  every link endpoint has t ≥ 0 }
    P_-  :=  { p :  every link endpoint has t ≤ -1 }
    P_(mixed)  :=  { p :  some endpoint has t ≥ 0 AND some endpoint has t ≤ -1 }
```

This partition is **exhaustive and disjoint**: every plaquette `p`
either lies entirely in `t ≥ 0` half-space, entirely in `t ≤ -1`
half-space, or straddles the `t = -1/2` plane. (No plaquette can lie
on the half-plane itself because plaquettes have integer-time link
endpoints.) The runner enumerates all plaquettes on a `2×2×2×2`
lattice and verifies the partition is disjoint + exhaustive.

For each subset:

- **`P_+`**: purely spatial plaquettes with `t(p) ∈ {0, 1, ..., L/2 - 1}`,
  plus mixed temporal/spatial plaquettes with both slices in
  `{0, 1, ..., L/2 - 1}`, i.e. `t_(low)(p) ≥ 0` and `t_(high)(p) ≤ L/2 - 1`.

- **`P_-`**: the reflection image `P_- = Θ(P_+)`: purely spatial
  plaquettes with `t(p) ∈ {-L/2, ..., -1}`, plus mixed plaquettes with
  both slices in `{-L/2, ..., -1}`.

- **`P_(mixed)`**: mixed temporal/spatial plaquettes with one slice at
  `t = -1` and the other at `t = 0` — the **cross-slice** plaquettes
  spanning the `t = -1/2` reflection plane — together with, on finite
  periodic `Λ = (Z/L)^4`, the temporal wraparound plaquettes with one
  slice at `t = L/2 - 1` and the other at `t = -L/2`. Spatial
  plaquettes never appear in `P_(mixed)` (they live in one slice, so
  either `t ≥ 0` or `t ≤ -1`). Thus, for finite periodic even `L`,
  `P_(mixed)` has two boundary families: (i) the reflection-plane
  family `t_(low) = -1`, `t_(high) = 0`, and (ii) the
  periodic-wraparound family `t_(low) = L/2 - 1`,
  `t_(high) = -L/2`. In a nonperiodic or infinite-time half-space
  setup only the first family is present.

### §2.3 Action decomposition

Define the half-actions

```text
    S_+(U)  :=  -(β/N_c) Σ_(p ∈ P_+) Re Tr U_p,                          (9)
    S_-(U)  :=  -(β/N_c) Σ_(p ∈ P_-) Re Tr U_p,                          (10)
    S_(mixed)(U)  :=  -(β/N_c) Σ_(p ∈ P_(mixed)) Re Tr U_p.              (11)
```

By the disjoint partition (`P_+ ⊔ P_- ⊔ P_(mixed) = P(Λ)`):

```text
    S_W[U]  =  S_+(U) + S_-(U) + S_(mixed)(U).                           (12)
```

Now we identify `S_-(U) = Θ(S_+)(U)`. Recall `(ΘU)_i(t, x⃗) = U_i(-1 - t, x⃗)`
(eq (6)). For a purely spatial plaquette `p = (x⃗, t; i, j)` (one
spatial slice at time `t`), the reflected plaquette acts on the
reflected slice at time `-1 - t`. Explicitly, the plaquette holonomy
on the reflected configuration is

```text
    (ΘU)_p  =  (ΘU)_i(x⃗, t) · (ΘU)_j(x⃗ + î, t)
              · (ΘU)_i(x⃗ + ĵ, t)^† · (ΘU)_j(x⃗, t)^†
           =  U_i(x⃗, -1 - t) · U_j(x⃗ + î, -1 - t)
              · U_i(x⃗ + ĵ, -1 - t)^† · U_j(x⃗, -1 - t)^†
           =  U_(p′),                                                     (13)
```

where `p′ = (x⃗, -1 - t; i, j)` is the spatial plaquette at the
reflected slice. As `t` runs over `{0, 1, ..., L/2 - 1}` (the spatial
plaquettes in `P_+`), `-1 - t` runs over `{-1, -2, ..., -L/2}` (the
spatial plaquettes in `P_-`). The map is a bijection.

Similarly for mixed temporal/spatial plaquettes in `P_+` (both slices
in `{0, ..., L/2 - 1}`): the reflected plaquette has both slices in
`{-L/2, ..., -1}`, again a bijection onto the mixed plaquettes in `P_-`.

Therefore:

```text
    -(β/N_c) Σ_(p ∈ P_+) Re Tr (ΘU)_p
        =  -(β/N_c) Σ_(p′ ∈ P_-) Re Tr U_(p′)
        =  S_-(U).                                                       (14)
```

I.e. `Θ(S_+)(U) := S_+(ΘU) = S_-(U)`. Substituting in eq (12):

```text
    S_W[U]  =  S_+(U) + Θ(S_+)(U) + S_(mixed)(U).                        (15)
```

This is the OS Step 1 decomposition (D1). The runner verifies eq (15)
on a `2×2×2×2` SU(3) lattice configuration to machine precision.

## §3. Substep (D2): `S_+(U)` is real and Θ-invariant on time-symmetric configurations

### §3.1 Reality of `S_+(U)`

`S_+(U)` is a sum of `Re Tr U_p` factors (eq (9)), each of which is a
real number for every `U ∈ G`. Therefore `S_+(U) ∈ R` for every
configuration `U`. This is immediate from the definition; no
hypothesis on `U` is needed.

### §3.2 Θ-invariance on time-symmetric configurations

Define the **time-symmetric configuration class**:

```text
    C_(sym)  :=  { U :  (ΘU)_i(t, x⃗) = U_i(t, x⃗) for all i, t, x⃗ }
              =  { U :  U_i(-1 - t, x⃗) = U_i(t, x⃗) for all i, t, x⃗ }.   (16)
```

This is the class of spatial-link configurations symmetric under
reflection through `t = -1/2`. Examples: any `t`-independent spatial
configuration (`U_i(t, x⃗) ≡ U_i(x⃗)`) is in `C_(sym)`; in particular
`U = I` (the free configuration on the parent's free `U = 1` surface)
is in `C_(sym)`.

For `U ∈ C_(sym)`, eq (13) gives `(ΘU)_p = U_(p′)` where `p′` is the
reflected purely-spatial plaquette. But by the symmetry condition,
`U_i(-1 - t, x⃗) = U_i(t, x⃗)` for every link, so

```text
    U_(p′)  =  U_i(x⃗, -1 - t) U_j(x⃗ + î, -1 - t) ...
            =  U_i(x⃗, t) U_j(x⃗ + î, t) ...
            =  U_p.                                                       (17)
```

That is, on `C_(sym)` the plaquette holonomy is reflection-symmetric:
`U_(Θp) = U_p`. Summing:

```text
    Θ(S_+)(U)  =  S_+(ΘU)  =  -(β/N_c) Σ_(p ∈ P_+) Re Tr (ΘU)_p
                           =  -(β/N_c) Σ_(p ∈ P_+) Re Tr U_p
                           =  S_+(U)        for U ∈ C_(sym).              (18)
```

This proves (D2): `S_+(U)` is real and Θ-invariant when restricted to
the time-symmetric configuration class `C_(sym)`. The runner constructs
an explicit time-symmetric SU(3) configuration on a `2×2×2×2` lattice
and verifies `S_+(ΘU) = S_+(U)` to machine precision.

### §3.3 Boundary of the time-symmetric check

The retained_bounded gauge-half Cauchy-Schwarz norm-square identity
`REFLECTION_POSITIVITY_GAUGE_HALF_CAUCHY_SCHWARZ_NARROW_THEOREM_NOTE_2026-05-10`
(G1) has an explicit hypothesis `S_+(Θx) = S_+(x)`:

```text
    ⟨Θ(F)·F⟩  =  ∫ dμ(x) exp(-S_+(x)) exp(-S_+(Θx)) F(Θx) F(x)
              =  ‖ψ² F‖²  ≥  0.
```

Substep (D2) does **not** prove that hypothesis on the full Wilson

`C_(sym)`. The full `U`-integrated reflection-positivity statement
therefore remains downstream of the retained mixed-kernel theorem plus
the retained Cauchy-Schwarz lemma, and is not derived in this packet.

## §4. Substep (D3): Reflection-Hermiticity of OS-Hermitian observables

### §4.1 Wilson-loop observables localized in `t ≥ 0`

Let `γ` be a closed contractible loop on the lattice with all vertices
at sites with `t ≥ 0`. Order vertices `x_0, x_1, ..., x_n = x_0` along
`γ`. Define the Wilson loop observable

```text
    f(U)  :=  Tr [ U_(γ_1) · U_(γ_2) · ... · U_(γ_n) ],                  (19)
```

where `U_(γ_k)` is the directed link variable from `x_(k-1)` to `x_k`
(equal to `U_μ(x_(k-1))` if the link is forward in direction `μ`, or
`U_μ(x_k)^†` if reversed).

In temporal gauge, the only links that contribute non-trivially are
spatial; temporal links are identity. So `f(U)` is a polynomial in the
spatial-link matrix entries `U_i(t, x⃗)` and their conjugate transposes,
restricted to vertices with `t ≥ 0`. The observable is **localized in
the `t ≥ 0` half-space** in this strict sense.

### §4.2 The OS-Hermitian observable class

Reflection-Hermiticity `F(ΘU) = conj(F(U))` is not an automatic
property of an arbitrary Wilson loop `f(U)` in `t ≥ 0`; rather, it
**characterizes the class of test observables** for which the OS
Step 1 Cauchy-Schwarz step (the retained_bounded
`REFLECTION_POSITIVITY_GAUGE_HALF_CAUCHY_SCHWARZ_NARROW_THEOREM_NOTE_2026-05-10`)
can consume when its separate half-action hypotheses are met. The
substep (D3) statement is therefore a **construction**
of the OS-Hermitian observable class, not a claim that arbitrary loops
satisfy it.

The standard OS construction. For any complex Wilson-loop observable
`f(U)` localized in `t ≥ 0` (eq (19)), the **symmetrized observable**

```text
    F(U)  :=  f(U) + conj( f(ΘU) )                                       (20)
```

satisfies the reflection-Hermiticity identity

```text
    F(ΘU)  =  conj( F(U) )                                               (21)
```

by construction. This is the OS-Hermitian observable built from `f`.

### §4.3 Proof of (21)

Apply `Θ` to `F`:

```text
    F(ΘU)  =  f(ΘU) + conj( f(Θ²U) )
           =  f(ΘU) + conj( f(U) )       [using Θ² = id, eq (22) below]. (22)
```

Take complex conjugate of `F(U)` (eq (20)):

```text
    conj( F(U) )  =  conj( f(U) + conj( f(ΘU) ) )
                  =  conj( f(U) ) + f(ΘU).                               (23)
```

Equations (22) and (23) are the same expression. Therefore
`F(ΘU) = conj(F(U))`, proving (21). The proof uses **only**:

- the involution property `Θ² = id` (eq (4));
- the elementary complex-number identities `conj(z + w) = conj(z) + conj(w)`,
  `conj(conj(z)) = z`.

No further structural hypothesis on the loop `γ` is needed.

### §4.4 Real-valued symmetrization

A real-valued counterpart is

```text
    G(U)  :=  Re f(U) + Re f(ΘU),                                        (24)
```

which is manifestly real, so `conj(G(U)) = G(U)`, and (by analogous
calculation) `G(ΘU) = Re f(ΘU) + Re f(U) = G(U)`. Therefore the
identity `G(ΘU) = conj(G(U))` holds in the trivial form
`G(ΘU) = G(U)`.

### §4.5 Special case: time-symmetric configurations

For configurations `U ∈ C_(sym)` (substep (D2), eq (16)), we have
`ΘU = U` on spatial links, so `f(ΘU) = f(U)` for any spatial-link
observable `f`. Then the symmetrized observable (20) simplifies to

```text
    F(U)  =  f(U) + conj( f(U) )  =  2 Re f(U),
```

which is automatically real. This is the direct consequence
"on time-symmetric configurations, any reflection-localized observable
is real after symmetrization" used downstream in OS-style RP arguments
on the `Θ`-fixed configuration class.

### §4.6 Linear-algebra basis: trace orientation reversal

The linear-algebra fact that grounds (D3) for non-symmetric observables
is the orientation-reversal property of the trace under Hermitian
conjugation. For any closed loop `γ` traced as
`x_0 → x_1 → ... → x_n = x_0`, the reverse-oriented loop has Wilson
holonomy

```text
    Tr [ U_(γ^(-1)) ]  =  Tr [ U_(γ)^† ]  =  conj( Tr [ U_(γ) ] ).        (25)
```

The first equality uses the directed-link convention (reversed link =
Hermitian conjugate); the second uses `Tr A^† = conj(Tr A)`. This
identity is verified in the runner on an explicit SU(3) matrix product.
Together with the symmetrization (20), it characterizes the standard
OS-Hermitian observable algebra used in the gauge-extension RP
argument.

### §4.7 Combining (D3) with (D2) and (D1)

The OS-Hermitian symmetrized observable `F(U)` (eq (20)) is exactly
the test-function class that the retained_bounded gauge-half
Cauchy-Schwarz lemma (G1)-(G3) consumes. The substep (D3) provides
the **explicit construction** of this class for the Wilson plaquette
action — supplying the parent's plain-text "Osterwalder-Seiler picture"
