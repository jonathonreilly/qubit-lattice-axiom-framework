## Theorem

Let `H_src` be the marked plaquette class-function sector with character basis
`chi_(p,q)`. Let

```text
M_beta = exp[(beta / 2) J],
D_beta^loc chi_(p,q) = a_(p,q)(beta)^4 chi_(p,q).
```

Define the environment interface sequence on the same normalization surface by

```text
rho_(p,q)(beta) = z_(p,q)^env(beta) / lambda_env(beta)
```

for the unnormalized all-weight structural row, or by
`rho_(p,q) = z_(p,q)^env / z_(0,0)^env` on finite normalized readout packets.
The convention must be fixed before comparing two environments. With that
convention fixed,

```text
R_beta^env chi_(p,q) = rho_(p,q)(beta) chi_(p,q)
```

and the factorized source kernel consumed by this lane is

```text
T_src[rho](beta)
  = M_beta D_beta^loc R_beta^env M_beta
  = M_beta D_beta^loc diag(rho_(p,q)(beta)) M_beta.
```

Therefore every source-sector readout that is a function of the factorized
marked kernel `T_src[rho](beta)` and marked source operator `J` depends on the
environment through `rho` alone. If two environments have the same interface
coefficients `rho_(p,q)` on the same normalization convention, then they give
the same `R_beta^env`, the same `T_src[rho]`, and the same marked source-sector
readout. Equivalently, on this lane the full beyond-packet residual is the
coefficient mismatch

```text
rho_physical - rho_packet
```

on the stated interface. No additional non-central or off-interface
environment datum is an input to the marked class-function source readout.

## Proof

First, the temporal-gauge row gives a linkwise product over spatial links.
When the source-sector observable depends on the marked subset `M`, every
non-marked spatial link contributes `c_0(beta)` before normalization and `1`
after normalization. Thus widening a marked-sector chain by adding links that
remain non-marked under the source projection supplies no extra character
coefficient to the marked class-function readout after the stated
normalization.

Second, the source-factorization row reduces the marked readout lane to
`T_src(beta) = M_beta D_beta M_beta`, with `D_beta` diagonal in the character
basis. The marked local mixed-kernel contribution is already the diagonal
operator `D_beta^loc` with eigenvalues `a_(p,q)^4`, so the remaining stripped
operator is `R_beta^env = (D_beta^loc)^(-1) D_beta` on the same basis.

Third, the residual-environment row identifies that stripped operator, at
each weight, with the central convolution action by `Z_beta^env` up to its
stated scale. Central convolution on the character basis is diagonal, and a
diagonal operator is determined on this sector by its diagonal coefficients.
Consequently the environment contribution to `T_src` is the diagonal sequence
`rho_(p,q)` and nothing else on this lane.

This proves equality of the factorized source kernel, and hence equality of
all readouts that consume that kernel, for any two environments with the same
`rho` interface.

## Corollary: Strip vs Rail

A marked-sector rail is a link-chain enlargement still read through the marked
class-function source projection. The temporal-gauge compression authority
licenses the non-marked links in that rail to the trivial channel after
normalization. Thus the finite rail calculation recorded in
docs/GAUGE_VACUUM_PLAQUETTE_WIDTH_REDUCTION_MAP_DERIVED_COUPLED_LIFT_BOUNDED_NOTE_2026-06-12.md
is context-consistent with the theorem: when the effective interface collapses to the trivial sequence
`rho = delta_(0,0)`, the source readout is the trivial-channel readout
`P_triv`.

A tensor-transfer strip is different. The strip is the unmarked spatial
environment that generates the interface coefficients. Its internal unmarked
spatial plaquette factors are expanded in exact `SU(3)` character content on
the tensor-transfer surface, and its shared slice links are integrated at
interfaces. Changing that strip changes the boundary sequence
`z_(p,q)^env`, and therefore can change normalized `rho_(p,q)`. On this
theorem's lane, that is the practical improvement direction: improve the
environment generator for `rho`, then re-read the same marked source-sector
kernel through `T_src[rho]`.

The corollary does not evaluate the full physical strip. The tensor-transfer
row leaves the full untruncated operator, boundary-character law, and
framework-point Perron/boundary readout as named open targets.
