## Statement

Fix the finite weight box `B = {(p, q) : 0 <= p, q <= NMAX}` with
`NMAX = 3`. Index it by `(p, q)`. Let `H_B = span{chi_(p,q) : (p,q) in B}`
be the orthonormal class-function sector on `B`.

Let `J|_B` denote the restriction to `H_B` of the explicit local plaquette
source operator `J = (chi_(1,0) + chi_(0,1)) / 6`, represented in the
character basis by the six-neighbor recurrence

```text
[J|_B]_{(a,b),(p,q)} = sum_{(a,b) in N(p,q) cap B} 1/6,                   (1)
```

where `N(p,q)` is the standard SU(3) Pieri neighbor set
`{(p+1,q), (p-1,q+1), (p,q-1), (p,q+1), (p+1,q-1), (p-1,q)}` restricted to
nonnegative integer pairs.

Let `D_beta^loc|_B` denote the diagonal operator on `H_B` with eigenvalues
`a_(p,q)(beta)^4`, where `a_(p,q)(beta) = c_(p,q)(beta) / (d_(p,q) c_(0,0)(beta))`,
`c_(p,q)(beta) = integral_{SU(3)} chi_(p,q)(U) exp((beta/3) Re tr U) dU`.

Let `K_beta^src|_B` denote the one-step Wilson source-sector kernel
restricted to `H_B`, taken in factored form from the source-sector
decomposition

```text
K_beta^src|_B = exp[(beta/2) J|_B] D_beta^loc|_B R_beta^env|_B exp[(beta/2) J|_B].   (D|_B)
```

**Conclusion (U1) (half-slice multiplier invertibility).** `J|_B` is a real
symmetric matrix on the finite-dimensional space `H_B`. Therefore
`exp[(beta/2) J|_B]` is symmetric and has strictly positive eigenvalues
(the exponential of a real symmetric matrix's eigenvalues), hence strictly
positive definite, hence invertible.

**Conclusion (U2) (local-factor invertibility).** For `beta > 0`, the
canonical single-link Wilson normalization satisfies `a_(0,0)(beta) = 1`
and `a_(p,q)(beta) > 0` for all `(p,q)`. The strict coefficient statement is
supplied by the constructive representation-ring/exponential-series argument
for the Wilson character coefficients: a positive `n=p+q` term reaches every
dominant weight, while all series contributions are nonnegative.
Therefore `D_beta^loc|_B` has strictly positive diagonal entries, hence
strictly positive determinant, hence invertible.

**Conclusion (U3) (stripping uniqueness).** Conjoining (U1) and (U2),
`(D|_B)` algebraically inverts to

```text
R_beta^env|_B = (D_beta^loc|_B)^{-1} exp[-(beta/2) J|_B] K_beta^src|_B exp[-(beta/2) J|_B].   (S)
```

Equation `(S)` is a function from `(K_beta^src|_B, D_beta^loc|_B, J|_B,
beta)` to a unique operator on `H_B`. No second operator solution exists on
`H_B`: any operator `R'` on `H_B`
satisfying `(D|_B)` with the same `K_beta^src|_B, D_beta^loc|_B, J|_B,
beta` must equal `R_beta^env|_B` by left-multiplying both sides of `(D|_B)`
by `(D_beta^loc|_B)^{-1} exp[-(beta/2) J|_B]` and right-multiplying both
sides by `exp[-(beta/2) J|_B]`.

**Conclusion (U5) (finite-box agreement with the bounded companion).**
Build `K_beta^src|_B` at `beta = 6` from the factored form `(D|_B)` using
the bounded companion's runner-computed `rho_(p,q)(6) = c_(p,q)(6) /
(d_(p,q) c_(0,0)(6))` coefficients on `B` for the residual factor. Compute
`R_6^env|_B` from `(S)` by direct inversion. The result agrees with the
input `rho_(p,q)(6)` diagonal sequence on the finite box `B` to machine
precision. This is only a consistency cross-check because the diagonal packet
was used to construct `K_6^src|_B`; it does not derive the physical stripped
Wilson operator or its character diagonality.

## Proof

**(U1).** `J = (chi_(1,0) + chi_(0,1)) / 6` is a real central class
function. On `H_B`, it acts by the six-neighbor recurrence (1) (Pieri
rule restricted to `B`). The matrix is symmetric because the Pieri rule
is symmetric in the pair of weights (the coefficient
`<chi_(a,b) * chi_(1,0), chi_(p,q)>` equals `<chi_(p,q) * chi_(0,1),
chi_(a,b)>` by conjugation of the fundamental representations
`(1,0) <-> (0,1)`, and `J` averages over both fundamentals). A real
symmetric matrix is unitarily diagonalizable with real eigenvalues. The
exponential of such a matrix has strictly positive eigenvalues
`exp((beta/2) lambda_i)`, so `exp[(beta/2) J|_B]` is positive definite,
hence invertible.

**(U2).** For `beta > 0`, the single-link Wilson character integral
`c_(p,q)(beta) = integral_{SU(3)} chi_(p,q)(U) exp((beta/3) Re tr U) dU`
is strictly positive: the integrand is a continuous central function on a
compact group, the exponential weight is strictly positive, and the
character `chi_(p,q)` integrates against `exp((beta/3) Re tr U) chi_(0,0)
= exp((beta/3) Re tr U)` to a positive trace (positive expansion
coefficient in the Peter-Weyl character series of the heat-kernel-like
positive-type function `exp((beta/3) Re tr U)`). The normalization
`c_(0,0)(beta) > 0` is the integral of `exp((beta/3) Re tr U)` itself.
The standard SU(3) irrep dimension `d_(p,q) = (p+1)(q+1)(p+q+2)/2 > 0`.
Therefore `a_(p,q)(beta) = c_(p,q)(beta) / (d_(p,q) c_(0,0)(beta)) > 0`
on `B`, and `D_beta^loc|_B` has strictly positive diagonal entries, hence
positive determinant, hence invertibility.

**(U3).** Apply (U1) and (U2). `(D|_B)` is an equation of the form
`K = M D R M` with `M, D` invertible on `H_B`. Multiply both sides by
`M^{-1}` on the left and right, then by `D^{-1}` on the left:

```text
D^{-1} M^{-1} K M^{-1} = R,
```

which is exactly `(S)`. Any second solution `R'` must satisfy the same
equation, hence `R' = R`.

**(U5).** Construct `K_6^src|_B` at `beta = 6` from the factored form
`(D|_B)` with `R_beta^env|_B = R[rho(6)]` from the bounded companion's
coefficients. Invert via `(S)` to recover `R_beta^env|_B`. The recovery
must equal the input `R[rho(6)]` to machine precision, since `(S)` is the
algebraic inverse of `(D|_B)`. This is the cross-check that the unique
stripped finite-box residual factor numerically agrees with the canonical
Wilson single-link boundary character coefficients on `B`. ∎

### Numerical conditioning note

The local Wilson factor `D_beta^loc|_B` has diagonal entries spanning ~14
orders of magnitude even on the modest finite box `NMAX = 3` at `beta = 6`
(largest entry `a_(0,0)(6)^4 = 1`, smallest `a_(3,3)(6)^4 ~ 2 x 10^-13`).
Naive float64 inversion of `D` therefore loses precision and the round-trip
error `||R - strip(reconstruct(R))||` blows up to `~10^-5`. The runner
therefore uses mpmath (`dps = 60` decimal digits) for the algebraic
stripping checks `(U1)`-`(U3)` and the `(U5)` round-trip. Float64 numbers
(Wilson character integrals from `scipy.special.iv`, eigendecomposition
seeds) are promoted to mpmath, with `J|_B` reconstructed as an exact
rational `1/6` matrix and the local Wilson coefficient sequence enforced to
be exactly swap-symmetric at float64 precision before promotion, so the
algebraic stripping is not contaminated by float64 noise on the *input*
matrices.

This is a numerical-implementation detail, not a load-bearing
mathematical assumption: the uniqueness theorem `(U3)` is a purely
algebraic statement about invertibility of `M D` on the finite box; the
mpmath arithmetic is used to *verify* the algebraic identity numerically
without losing precision through the `~10^13` condition number of `D`.
