## Statement

Fix the finite weight box `B = {(p, q) : 0 <= p, q <= NMAX}` with
`NMAX = 4`. Index it by `(p, q)`. For each `(p, q)`, define the standard
`SU(3)` irrep dimension

```text
d_(p,q) = (p + 1) (q + 1) (p + q + 2) / 2.                                (1)
```

Let `H_B = span{chi_(p,q) : (p, q) in B}` be the finite-dimensional
character-basis truncation of the marked-plaquette class-function sector,
with orthonormal characters `{chi_(p,q)}` under the SU(3) Haar inner
product on class functions.

Let `R_beta^env|_B : H_B -> H_B` be the finite-box stripped residual factor
defined by the source-sector decomposition `(D)`; by block 17's narrow
finite-box stripping-uniqueness theorem, `R_beta^env|_B` is the unique
positive self-adjoint diagonal operator on `H_B` in the orthonormal character
basis. Denote its eigenvalues

```text
R_beta^env|_B chi_(p,q) = rho_(p,q) chi_(p,q),       (p, q) in B,         (2)
```

with `rho_(p,q) > 0` and `rho_(p,q) = rho_(q,p)` (positivity and conjugation
symmetry from block 17 transport `(U4)`).

Fix any `z_(0,0)^env(beta) > 0` (e.g. the trivial-character coefficient of
the boundary class function inherited from the parent, or, on the bounded
witness, the canonical normalization `c_(0,0)(beta) > 0` from the Wilson
single-link character integral).

**Definition of finite-box truncated boundary class function:**

```text
Z_beta^env|_B(W) := z_(0,0)^env(beta) sum_{(p, q) in B} d_(p,q) rho_(p,q)
                     chi_(p,q)(W),     W in SU(3).                       (3)
```

Note `Z_beta^env|_B` is a finite linear combination of characters and is
therefore a well-defined real-valued central class function on `SU(3)`.
Because `rho_(p,q) >= 0`, `d_(p,q) > 0`, and `chi_(p,q)(W) >= chi_(p,q)(1)
- d_(p,q)`, the truncation is real, central, and (by the positive-type
character expansion truncated to nonnegative coefficients) of positive type
on `SU(3)`.

**Conclusion (M1) (finite-box existence).** `Z_beta^env|_B` defined in `(3)`
is a real central class function on `SU(3)` whose character expansion,
restricted to `B`, has coefficients `z_(0,0)^env(beta) d_(p,q) rho_(p,q)`.
Its support in the Peter-Weyl decomposition is contained in `B`.

**Conclusion (M2) (forward convolution-realization on the finite box).** The
normalized convolution operator
`C_(Z_beta^env|_B) := (1 / z_(0,0)^env(beta)) (Z_beta^env|_B) * (·)` acts on
`H_B` by

```text
C_(Z_beta^env|_B) chi_(p,q) = rho_(p,q) chi_(p,q),     (p, q) in B,       (4)
```

and therefore equals `R_beta^env|_B` as a finite-dimensional self-adjoint
operator on `H_B`:

```text
R_beta^env|_B = C_(Z_beta^env|_B)|_B.                                    (E')
```

**Conclusion (M3) (inverse Peter-Weyl finite-box uniqueness).** Let `Z'` be
*any* real central class function on `SU(3)` whose character expansion
truncated to `B` reads

```text
Z'|_B(W) = z_0' sum_{(p, q) in B} d_(p,q) rho'_(p,q) chi_(p,q)(W),       (5)
```

with `z_0' > 0` and `rho'_(p,q) >= 0`, and suppose the normalized convolution
operator `C_(Z'|_B) := (1 / z_0') (Z'|_B) * (·)` on `H_B` equals
`R_beta^env|_B`. Then

```text
rho'_(p,q) = rho_(p,q)         for all (p, q) in B,                       (6)
```

and consequently

```text
Z'|_B / z_0' = Z_beta^env|_B / z_(0,0)^env(beta),                         (7)
```

i.e. the **normalized finite-box truncated boundary class function realizing
`R_beta^env|_B` as a convolution operator on `H_B` is unique up to overall
normalization, and the normalized truncation is unique exactly**.

**Conclusion (M4) (joint uniqueness of both sides of `(E)` at finite-box
scope).** Combining `(M2)` + `(M3)` with block 17's stripping-uniqueness of
`R_beta^env|_B`: both objects in the parent's identification

```text
R_beta^env|_B = C_(Z_beta^env|_B)|_B                                     (E')
```

are uniquely determined at finite-box scope — the left side by `(D)` via
the block 17 algebraic stripping, the right side by `(M3)` via inverse
Peter-Weyl uniqueness. The named identification therefore identifies
*unique* finite-box-truncated objects, not renamings.

**Conclusion (M5) (witness-source consistency).** Instantiating
`rho_(p,q) := rho_(p,q)(6)` from the bounded coefficient companion's
runner-computed normalized single-link `SU(3)` Wilson character integrals
(iter b7 / bounded companion `(N3)`),

```text
rho_(p,q)(6) = c_(p,q)(6) / (d_(p,q) c_(0,0)(6)),                        (8)
c_(p,q)(6)   = integral_{SU(3)} chi_(p,q)(U) exp((6 / 3) Re tr U) dU,    (9)
```

the constructed `Z_(6)^env|_B` from `(3)` is precisely the canonical
normalized single-link `SU(3)` Wilson boundary class function truncated to
`B` (with `z_(0,0)^env(6) := c_(0,0)(6)`). The runner verifies:

- `(M2)`: numerical equality `C_(Z_6^env|_B) chi_(p,q) = rho_(p,q)(6)
  chi_(p,q)` with eigen-action error `0` (exact, since the action is
  diagonal in the character basis);
- `(M3)`: coefficient-sequence uniqueness on a representative
  finite subspace by perturbing the eigenvalue sequence and re-deriving
  the resulting class function via Peter-Weyl inversion;
- `(E')` numerical: `R_(6)^env|_B = C_(Z_(6)^env|_B)|_B` to machine
  precision.

## Proof

### Proof of `(M1)`

`(3)` writes `Z_beta^env|_B(W)` as a finite linear combination of
characters with real coefficients (`rho_(p,q) >= 0`, `d_(p,q) > 0`,
`z_(0,0)^env > 0`). Each `chi_(p,q)` is a central class function on
`SU(3)` (representation character of an irrep), so any real linear
combination is real central. The character expansion of `(3)` truncated
to `B` has coefficients `z_(0,0)^env(beta) d_(p,q) rho_(p,q)` by direct
reading. Outside `B`, the coefficients vanish: only finitely many
characters appear in `(3)`. So the Peter-Weyl support is in `B`.
Real-valuedness follows from the SU(3) reality identity
`bar(chi_(p,q)) = chi_(q,p)` plus conjugation symmetry `rho_(p,q) =
rho_(q,p)` and `d_(p,q) = d_(q,p)`. ∎

### Proof of `(M2)`

By the bounded companion's `(N2)` theorem (Peter-Weyl convolution-on-
characters identity at finite-box scope), normalized convolution by any
positive central class function `Z = c_0 sum d_b rho_b chi_b` acts on
`H_B` diagonally:

```text
C_Z chi_(p,q) = rho_(p,q) chi_(p,q),     (p, q) in B.
```

Applying this with `Z := Z_beta^env|_B` from `(3)` and `c_0 :=
z_(0,0)^env(beta)`, with `rho_b := rho_(p,q)`, gives `(4)` immediately.
The resulting `C_(Z_beta^env|_B)` is then a finite-dimensional self-
adjoint diagonal operator on the orthonormal character basis on `B` with
eigenvalues `rho_(p,q)`. By `(2)`, the same eigenvalues uniquely
characterize `R_beta^env|_B` (block 17 stripping-uniqueness; both are
diagonal in the same orthonormal basis with the same eigenvalues).
Therefore `R_beta^env|_B = C_(Z_beta^env|_B)|_B`, which is `(E')`. ∎

### Proof of `(M3)`

Suppose `Z'` satisfies `(5)` with `C_(Z'|_B) = R_beta^env|_B`.

By the bounded companion's `(N2)` applied to `Z'|_B / z_0'`,

```text
C_(Z'|_B) chi_(p,q) = rho'_(p,q) chi_(p,q),     (p, q) in B.            (5b)
```

By assumption `C_(Z'|_B) = R_beta^env|_B`, so combining with `(2)`,

```text
rho'_(p,q) chi_(p,q) = rho_(p,q) chi_(p,q),     (p, q) in B.            (5c)
```

The character set `{chi_(p,q) : (p, q) in B}` is orthonormal in
`L^2(SU(3))^conj` under Haar measure (Peter-Weyl orthonormality), so each
`chi_(p,q)` is nonzero in the inner product. `(5c)` forces

```text
rho'_(p,q) = rho_(p,q),     (p, q) in B,                                  (6)
```

which is the eigenvalue-uniqueness statement of `(M3)`.

Then substituting `(6)` into `(5)`,

```text
Z'|_B(W) = z_0' sum_{(p, q) in B} d_(p,q) rho_(p,q) chi_(p,q)(W),
         = (z_0' / z_(0,0)^env(beta)) Z_beta^env|_B(W)                   (5d)
```

by `(3)`. Dividing both sides by `z_0'`,

```text
Z'|_B(W) / z_0' = (1 / z_(0,0)^env(beta)) Z_beta^env|_B(W) =
   Z_beta^env|_B(W) / z_(0,0)^env(beta),                                 (7)
```

which is the normalized-truncation uniqueness statement of `(M3)`. ∎

### Proof of `(M4)`

`(E')` is `(M2)`. The left side is uniquely determined as a finite-box
operator by block 17's stripping-uniqueness (`R_beta^env|_B = (D_beta^loc
|_B)^{-1} exp[-(beta/2) J|_B] K_beta^src|_B exp[-(beta/2) J|_B]`, no
admissibility freedom). The right side is uniquely determined as a
normalized finite-box truncation of a positive central class function by
`(M3)`. Therefore both objects in `(E')` are unique. ∎

### Proof of `(M5)`

For the witness-source consistency check, instantiate `rho_(p,q) :=
rho_(p,q)(6)` from `(8)`-`(9)`, with `z_(0,0)^env(6) := c_(0,0)(6) > 0`.
Then `(3)` reduces to

```text
Z_(6)^env|_B(W) = sum_{(p, q) in B}
                  (c_(p,q)(6) / c_(0,0)(6)) (1 / d_(p,q)) d_(p,q)
                  chi_(p,q)(W) * c_(0,0)(6)
                = sum_{(p, q) in B} c_(p,q)(6) chi_(p,q)(W),            (3b)
```

which is the canonical normalized single-link `SU(3)` Wilson boundary
class function truncated to `B`, up to an overall normalization by
`c_(0,0)(6)`. The bounded companion's `(N3)` instantiation supplies the
numerical values of `rho_(p,q)(6)` to machine precision. Combined with
`(M2)` and `(M3)`, this gives an *explicit* finite-box realization of the
parent's `(E)` with both sides constructed from canonical single-link
Wilson data and uniquely determined at finite-box scope. ∎
