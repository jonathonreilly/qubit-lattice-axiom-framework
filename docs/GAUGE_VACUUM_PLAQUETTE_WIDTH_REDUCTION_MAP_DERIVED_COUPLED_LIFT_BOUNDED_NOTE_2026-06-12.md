## Reduction Derivation

The temporal-gauge factorization theorem gives the mixed kernel as an
independent product over spatial links. The deciding phrases are:

```text
same spatial link
```

and, for non-marked links after normalization,

```text
prod_(x,mu) NOT in M 1
```

Thus "remove a transverse rail" is not the old operation "pin it to the
trivial slice." In the factorized geometry a removed rail is an unmarked
link sector and must be contracted as a rail environment and then divided by
the scalar that the same contraction gives in the independent-rail limit.

Let `D_lambda = c_lambda(6) / (d_lambda c_0(6))` be the finite normalized
one-link Wilson coefficient on the `B_4` box, `d_lambda` the `SU(3)` irrep
dimension, and `t(lambda,mu)` the existing entrywise-power packet from the
word-count lane. For a rail-removal vector `v`, define

```text
s_v = v^T t v,
C_v e_a = sum_b v_b e_(a,b).
```

The reduction of the factorized width-two link-step is

```text
t_red = C_v^T (t tensor t) C_v / s_v = t.
```

That identity is G1: independent rails reduce to the width-one packet for
any nonzero candidate `v` whose scalar `s_v` is finite and positive.

Two candidate `v` rows were tested.

**R-a, Perron contraction.** Use the finite tensor-word Perron/vacuum row

```text

```

This is the depth-axis philosophy imported as a width-axis control. It passes
G1, but the temporal-gauge compression map does not specify a stationary
finite tensor-word distribution for a non-marked link; it specifies the
non-marked link as the normalized trivial scalar in the linkwise product.
Therefore R-a is reported as a control, not the primary licensed reduction.

**R-b, Haar/Wilson channel-sum contraction.** The Wilson class function has

## Effective Width-One Packet

For a coupled pair link-step, indexed by `A=(a,b)` and `B=(c,d)`, the
625-box entrywise kernel is

```text
t_2^q(A,B) = sqrt(q(A) q(B)) t(a,c) t(b,d).
```

Reducing rail 2 with `C_v` gives the effective width-one kernel

```text

  = v_a v_c sqrt(q_a q_c) t(a,c)^2 / s_v,
```

where `q_a = 1` for the character control and `q_a = 1 / d_a` for the
matrix-element branch. This is positive and conjugation-symmetric on the
finite box. It is also a fixed link-step kernel, so the entrywise-power
chain remains


With `G_eff = G^2`, the corresponding normalized effective Wilson row is

```text

```

For the licensed Haar/Wilson plus matrix-element branch this simplifies to

```text

```

That fourth-power row is the measured width-reduction effect at packet level.
