## Reduced Entrywise-Power Packet

Let `M = N_f + N_fbar` on the finite dominant-weight box
`B_4 = {(p,q): 0 <= p,q <= 4}`. Let `D_mu` be the normalized Wilson
coefficient and `d_mu` the representation dimension. The reduced word-count
matrix is

```text
S_k(mu,nu)
  = sqrt(D_mu^k / d_mu^(k-1)) G(mu,nu)^k
    sqrt(D_nu^k / d_nu^(k-1)),

G(mu,nu) = sum_w D_w^2 M(w,mu) M(w,nu).
```

Equivalently,

```text
S_k(mu,nu) = sqrt(d_mu d_nu) t(mu,nu)^k
```

with

```text
t(mu,nu) = sqrt(D_mu D_nu) G(mu,nu) / sqrt(d_mu d_nu).
```

The runner verifies that the largest `t` entry is the trivial diagonal:

```text
t((0,0),(0,0)) = 0.357066142023283.
```

The measured eigenvalue ratio `lambda_{k+1}/lambda_k` therefore approaches
this top entry. This is an eigenvalue statement for the entrywise-power
packet, not a Birkhoff iterate statement.

## Eigenvector Asymptotics

Normalize the top eigenvector of `S_k` by `y_0 = 1`, and write `R` for the
24 nontrivial channels. With

```text
r_k(mu) = S_k(mu,0) / S_k(0,0),
B_k(mu,nu) = S_k(mu,nu) / S_k(0,0)       (mu,nu in R),
lambda_bar = lambda_k / S_k(0,0),
```

the finite channel equation is exact:

```text
y_R = (lambda_bar I - B_k)^(-1) r_k.
```

The two-term Neumann surface used in the runner is

```text
y_R = r_k + B_k r_k + remainder.
```

This keeps the full 24 by 24 correction matrix rather than a single
subchannel. The runner verifies that the correction improves the relative
eigenvector approximation:

```text
k= 8: first_rel=1.098363539170e-02; second_rel=1.206402320088e-04
k=10: first_rel=2.408293978514e-03; second_rel=5.799879869647e-06
```

For the fundamental coefficient this gives

```text
c_f = d_f [sqrt(D_f/d_f) t(f,0)/t(0,0)]^k
      [1 + 3 alpha^k + 3 gamma^k + smaller finite-channel terms],
```

where

```text
alpha = t(f,f) / t(0,0)  = 0.482546354923910
gamma = t(f,fb) / t(0,0) = 0.404832799613057.
```

The eta-weighted readout denominator is forced through the `f/fb` channels:

```text
raw_0 = 2 c_f L_eta(f)^(k-1) [1 + lower-scale corrections],
```

while the marked fundamental numerator has the leading term

```text
raw_f = D_f L_eta(0)^(k-1) [1 + lower-scale corrections].
```

Therefore

```text
rho10_k = theta^(1-k) [1 - 3 alpha^k - 3 gamma^k + smaller terms].
```

## Source Composition Boundary

Let `chi_pair` be the source vector supported on `f` and `fb`. Let
`sigma_slice` be the finite slice vector with components

```text
sigma_0  = 1,
sigma_11 = 0.162259799479938,
sigma_20 = sigma_02 = 0.067980863681696,
```

and zero on the pair component after the large scale is split off. The source
transfer has the form

```text
T_src(R) = R A_pair + B_slice
```

with

```text
A_pair  = exp(3J) D_loc diag(chi_pair) exp(3J),
B_slice = exp(3J) D_loc diag(sigma_slice) exp(3J).
```

The top eigenvalue of `A_pair` is simple on the finite source box. The runner
computes the standard symmetric-matrix perturbation in `epsilon = 1/R`:

```text
P(epsilon) = P_inf + p1 epsilon + p2 epsilon^2 + O(epsilon^3),
P_inf      = 0.615191992185898,
p1         = -0.410170474927582,
p2         = -3.715455712621910.
```

Thus

```text
C_source = -p1 = 0.410170474927582.
```

Composing with `R_k = theta^(1-k)` gives the displayed finite-packet
composition surface:

```text
P_inf - P_k
  = C_source theta^(k-1)
    + 3 C_source theta^(k-1) alpha^k
    + remainder on smaller finite-packet scales.
```

This display is a measured-envelope diagnostic on the stated finite packet,
not a proof-grade all-`k` asymptotic theorem. The omitted Neumann, source
perturbation, gamma-channel, and higher-scale terms are controlled by the
runner on the measured window below; a uniform all-`k` finite-packet
tail/remainder theorem remains open.

## Measured Envelope

The runner verifies the measured `k = 2..20` finite-packet errors against the
same `P_inf` and computes, without an added safety factor,

```text
c_hat = max_{2 <= k <= 20} |P_inf - P_k| / theta^k
      = 3.927112357448185,
```

attained at `k = 3` in the displayed finite table. Therefore the measured
finite rungs obey


for the dropped Neumann and source perturbation terms remains a named target.
