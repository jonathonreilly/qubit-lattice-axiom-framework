## Finite Theorem

Let the three oriented lattice edge directions be labelled by bits

```text
e_x = (1,0,0),   e_y = (0,1,0),   e_z = (0,0,1).
```

The `C3[111]` rotation acts by cycling coordinates:

```text
(x,y,z) -> (y,z,x).
```

The Hamming levels of the corner cube `{0,1}^3` are:

```text
hw=0: 1 point   scalar/empty reference
hw=1: 3 points  one-edge alternatives
hw=2: 3 points  two-edge/face alternatives
hw=3: 1 point   full/complement reference
```

The nontrivial three-point `C3` orbits are exactly `hw=1` and `hw=2`.

Complementation

```text
C(b) = (1,1,1) - b
```

exchanges `hw=1` and `hw=2` and commutes with `C3[111]`. Thus the two triplets
are isomorphic as finite `C3` sets.

But they are not equally minimal as edge-generated contexts:

- `hw=1` contains exactly one primitive edge bit;
- `hw=2` contains exactly two primitive edge bits and is the face/complement
  orbit;
- the only nontrivial `C3` orbit with minimal positive edge count is `hw=1`.

Therefore an oriented record context whose primitive alternatives are direct
nearest-neighbor edge alternatives selects `hw=1` as the canonical minimal
triplet.
