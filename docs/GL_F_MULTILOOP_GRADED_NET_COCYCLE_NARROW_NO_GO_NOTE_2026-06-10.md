## 2. Formalization (the multi-loop graded-net cocycle condition)

`(ψ_x)_{x∈Λ}` of operators on `H_Λ` with

```text

 (R2)  {F, ψ_x} = 0                         (F-odd w.r.t. the retained grading)
 (R3)  ψ_x ψ_y = ε(x,y) ψ_y ψ_x,  ψ_x ψ_y† = ε(x,y) ψ_y† ψ_x   (x ≠ y)
 (R4)  ψ_x† ψ_x = n_x                       (bare on-site number operator)
```

## 3. Result (the no-go, with the exact classification as witness)

exchange-sign assignment `ε` satisfies (MC1)–(MC4) **iff `ε` is symmetric**

**Corollary (the no-go).** The commuting assignment `ε ≡ +1` (hard-core

The conditions are not vacuous (falsification legs): asymmetric assignments

## 4. Proof

**Lemma 1 (2-loop reduction: realizable ⇒ symmetric; general, frame-free).**
Let `(ψ_x)` realize `ε` per (R1)–(R4). For `x ≠ y`, (R3) and its adjoint give
`n_x ψ_y = ψ_x† ψ_x ψ_y = ε(x,y)² ψ_y ψ_x† ψ_x = ψ_y n_x` (only `ε² = 1` is
used, no symmetry). Hence
`‖ψ_x ψ_y v‖² = ⟨v, ψ_y† n_x ψ_y v⟩ = ⟨v, n_x n_y v⟩ = 1` for any state `v`
occupied at both `x` and `y` (such `v` exists because (R4) pins `n_x` to the
bare on-site number operator). So `ψ_x ψ_y ≠ 0`; applying (R3) twice,
`ψ_x ψ_y = ε(x,y) ε(y,x) ψ_x ψ_y`, forces `ε(x,y) ε(y,x) = +1`. The shortest
loop (swap twice) is therefore the ONLY loop condition with teeth. Runner
[A5] verifies `‖ψ_x ψ_y‖ = 1` across all Klein two-site frames; [A2]/[A3]
verify exhaustively (all `2⁶` string families at `N = 3` dense, all `2¹²` at
`N = 4` in the mask calculus, certified against dense) that every Klein-string
family yields a symmetric `ε` and that the image is ALL symmetric assignments
— including `ε ≡ +1` and `ε ≡ −1`. ∎

**Lemma 2 (symmetric ⇒ every exchange-groupoid loop is consistent).** For
symmetric `ε` define `sgn_ε(π) = ∏_{(u,v) ∈ Inv(π)} ε(u,v)` over the
inversion set of a permutation `π` of the particle labels. Multiplying a word
by one adjacent transposition swapping values `u, v` changes the inversion set
by exactly the unordered pair `{u,v}` and multiplies the accumulated
reordering sign by `ε(u,v)`; by induction the sign of ANY transposition word
equals `sgn_ε` of the permutation it implements. The sign therefore descends
to a well-defined function on `S_n`, so every closed loop (identity word) has
holonomy `+1`. Runner [B1] certifies this as a full edge-consistency
certificate on the `S₄` Cayley graph for ALL 64 symmetric `ε` (tree
assignment + every edge checked = every fundamental cycle), and the dense
operator-level reordering signs match the inversion-count prediction in both
frames. Conversely an asymmetric `ε` already fails the 2-loop. So
(MC1) ∧ (MC2) ⇔ symmetry — nothing more. ∎

**Lemma 3 (lattice loops reduce to plaquettes; transport is frame-blind).**
Plaquette boundaries span the full GF(2) cycle space of the `Z³` block
(rank certificates `2 = 2` on `3×2×1`, `5 = 5` on `2×2×2`, `28 = 28` on
`3×3×3`; runner [B2] — the same generation fact behind the flux
classification), so every lattice-loop consistency condition reduces to
plaquette conditions. At the operator level (exact signed-state calculus,
certified against the dense representation at `N = 6`, runner [B3a]):
single-particle transport around a contractible 8-ring is identical across
frames, with and without an enclosed spectator; transport around a loop that
**threads** a second loop (16-site configuration, linking number 1) is
frame-blind and independent of the threaded loop's occupation (empty / one
particle / fully occupied — no mutual anyonic phase in 3D; runner [C3]); the
doubled exchange loop has holonomy `+1` in BOTH frames. The unique frame-odd
loop datum is the single exchange-loop holonomy (`+1` HCB vs `−1` CAR, runner
[B3]), whose only consistency constraint is its square. ∎

**Lemma 4 (framing coherence is never a new constraint).** Two different
JW-string orderings realizing the same `ε ≡ −1` are conjugate by an explicit
diagonal, `F`-even Klein unitary `D` (`D c²_x D⁻¹ = c¹_x` exactly, runner
[C4]); string framings are mutually consistent data, not an additional
condition that could exclude a frame. Both frames are moreover Hermitian,
parity-conserving, and T-positive overall and in each parity sector on the
