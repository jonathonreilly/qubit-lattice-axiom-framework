# The Record-Influence Criterion And The Graded-Constraint Program

**Date:** 2026-07-04
**Type:** program / criterion memo (owner-reviewed thinking bank)
**Claim type:** none. This memo proves nothing, sets no audit verdict, changes
no axiom, and registers no primitive. It fixes shared vocabulary and targets so
that every worker builds against one picture. Where it states results, it cites
the note that owns them; where it states targets, it says so.
**Status authority:** none. Independent audit lane and owner channels are
untouched.

## 1. The criterion

**Pre-record structure is real exactly to the extent it influences which
records form and with what frequencies.**

Record statistics is the only reality-meter the framework owns: "Only records
are readable. A readout value is determined by record content alone."
(`docs/MINIMAL_AXIOMS_2026-06-29.md`). Structure that influences no record
statistics in any realizable context is not part of the physics; structure
whose entire effect is on record statistics is real precisely as that effect,
and is knowable precisely through frequencies — which are records.

This criterion is not new; it is how the framework has already ruled:

- The conjugate-pair phase at doublet grade influences no constructible
  readout, so the pair contributes one statistical slot (the recorded-branch
  filing; the registrability no-go of 2026-07-03).
- A conjugation-odd phase becomes measurable only when dynamics supplies a
  context in which it influences records; it is real exactly then and there
  (the theta cross-check).
- Global phase influences nothing anywhere: gauge, permanently.
- Relative phase across reconverging paths influences frequencies: real,
  exactly to that extent.

Worker guidance: proposals that introduce pre-record structure with no record
influence are out of scope by this criterion. Proposals should say, in one
sentence, which record statistics their structure influences.

## 2. The supply-indexing correction

The no-privilege sentences ("No site is privileged... supplied lattice
structure alone", "No possibility is privileged... supplied algebraic structure
alone") are indexed to the current supply. They are not standing prohibitions
on supplying more. Registration enlarges the supplied structure, and the
sentences remain true relative to the enlarged supply. Reading them as absolute
bars was an error, corrected 2026-07-04. The channels are unchanged:
derivation, bridge, explicit admission, or approved primitive registration

## 3. Formation: what the 2026-07-04 append settles

The Record axiom now opens with "Records form." (owner-approved 2026-07-04;
provenance and rulings in `docs/audit/AXIOM_MINIMALITY_POLICY.md`, entry
"2026-07-04 -- Formation sentence"). What every worker should carry:

- **Occurrence strength, deliberately.** A law-form formation sentence — any
  wording that fires at every state of a domain — supplies a maximal formation
  rate. Rate is supplier content; law-form formation is over-supply. Occurrence
  strength is the unique non-over-supplying form. Do not re-attempt stronger
  formation axioms.
- **Eternal succession is closed, permanently.** Configurations are not
  restricted to finite support; a saturated configuration (a permanent record
  at every `Z^3` site) is a state with no valid formation-successor. "No state
  is final" is false in the landed state space, not merely unsupplied. The
  certification note holds the exhibit.
- **What is free once succession exists:** wherever a formation-successor is
  realized, it strictly extends its predecessor (permanence + one record per
  site) — succession is monotone; direction is growth; there is no recurrence.
- **What is NOT supplied:** the formation rule (which admissible possibility,
  which site, what weight, what rate) and comparability of realized
  configurations (below).

## 5. The graded-constraint program

**The observed fact that forces the program:** identical menus with stably
unequal frequencies. A 70/30 beamsplitter presents the same admissible outcome
set every run; the frequencies are reproducibly 70/30. Binary availability plus
symmetry can only pay uniform weights on symmetric menus (the harvested
uniform-on-orbits results, e.g. r = 1/2). Binary constraint structure cannot
express the beamsplitter fact at all.

**The program's one candidate primitive:** record influence on possibility
menus comes in degrees. Prior records do not only allow or forbid possibilities
at a site through the neighbor structure — they bias them. The grading is
constraint structure, exactly as Admissibility is: not a readout, not hidden
state. It is real by the Section 1 criterion because record frequencies read it
in aggregate, and only that way. "Only records are readable" is untouched — it
is how the grading is known at all.

**What is then forced rather than supplied** (division of labor):

- **The form of the weights is a theorem target, not a postulate.** If grading
  exists, is additive over exclusive alternatives, and does not depend on which
  compatible menu embeds an alternative, then Gleason-type uniqueness forces
  the quadratic (Born) form. The known dimension-2 exception is exactly one
  `M_2` site alone; neighbor composites are `M_4` and above, where the theorem
  holds — the lattice, which the axioms supply for free, is what eliminates the
  loophole. Owned by the composite-Gleason bridge note (in preparation,
  2026-07-04); the honest load-bearing hypothesis there is menu eligibility of
  composite (including entangled) projections.
- **The values of the weights come from records.** Preparation is records:
  apparatus settings, filter events, calibration outcomes. The bias at a new
  site is prior record content propagated through the constraint structure.
  The realized measure comes only from the record.
- **Interference is grade composition.** Quadratic readout means biases compose
  before squaring; influences along reconverging paths add with signs. The
  composition/propagation rule of the grades is precisely what the carrier
  registration supplies (the Dirac-square shape: frequencies quadratic in the
  propagated bias). Relative bias phase is real where reconvergence makes it
  influence frequencies; absolute phase never is.
- **Orientation is not a separate insertion.** With a growth direction (arrow)
  and a one-sided spectrum (stability clause on the carrier), the rotation
  sense is fixed relative to record succession. Nobody chooses `i` over `-i`;
  the pair is oriented by succession plus stability. Consistent with the
  registrability no-go: absent those, the orientation is gauge.
