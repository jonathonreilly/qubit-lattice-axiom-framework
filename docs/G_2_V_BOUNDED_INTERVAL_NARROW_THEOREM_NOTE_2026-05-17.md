## Proof

Pure substitution plus a one-line monotonicity check.

**Step 1 (lattice-scale bare 1/α and tadpole improvement).** Combine
`(X4a)` and `(X4b)`:

```text
g_2² |_lattice  =  1/4
α_2^bare |_lattice  =  g_2² / (4 π)  =  1 / (16 π)
1 / α_2^bare |_lattice  =  16 π.                                          (S1)
```

Apply `(X5)`: `1 / α_2^tadpole |_lattice = (1 / α_2^bare) · u_0²`:

```text
1 / α_2^tadpole |_lattice  =  16 π u_0².                                  (S2)
```

The Wilson normalization `(X4c)` `β = 2 N_c / g_bare² = 16` is the
direct algebraic substitution of `(N_c, g_bare²) = (2, 1/4)` and is not
independently load-bearing on the running calculation; it appears here
only to record the lattice action coefficient in canonical form.

**Step 2 (1-loop Peskin–Schroeder running from M_Pl to v).** The
standard 1-loop SU(2) running equation at b_2 > 0 (asymptotic-freedom
convention as in `SU2_WEAK_BETA_COEFFICIENT_NARROW_THEOREM_NOTE_2026-05-10`
Eq. (P1)–(P3)):

```text
1 / α_2(v)  =  1 / α_2(M_Pl)  -  (b_2 / (2 π)) · ln(M_Pl / v).            (S3)
```

Substituting `(S2)` for `1 / α_2(M_Pl) ≡ 1 / α_2^tadpole |_lattice` and
`(X6)` for `ln(M_Pl/v) = L`:

```text
1 / α_2(v)  =  16 π u_0²  -  (b_2 / (2 π)) · L.                            (S4)
```

This is `(R1)`.

**Step 3 (closed-form g_2(v)).** From `(S4)`:

```text
α_2(v)  =  1 / (16 π u_0² - (b_2 / (2 π)) · L),                            (S5)
g_2(v)  =  sqrt( 4 π · α_2(v) )
        =  sqrt( 4 π / (16 π u_0² - (b_2 / (2 π)) · L) ).                  (S6)
```

This is `(R3)`.

**Step 4 (monotonicity, endpoint reversal).** Differentiate `(R1)`:

```text
d/du_0 [1 / α_2(v)]  =  32 π u_0  >  0  for u_0 > 0.                       (S7)
```

Hence `1 / α_2(v)` is strictly increasing in `u_0`, `α_2(v)` is
strictly decreasing in `u_0`, and `g_2(v) = sqrt(4 π α_2(v))` is
strictly decreasing in `u_0`. Therefore the `u_0` interval
`[u_lo, u_hi]` maps to the `g_2(v)` interval `[g_lo, g_hi]` with the
reversal

```text
g_hi  =  g_2(v) |_{u_0 = u_lo},                                            (S8)
g_lo  =  g_2(v) |_{u_0 = u_hi}.                                            (S9)
```

These are `(G2)`–`(G3)`.

**Step 5 (framework instance evaluation).** Substitute
`(u_lo, u_hi, b_2, L) = (96/100, 98/100, 19/6, 3844/100)` into `(G2)`
and `(G3)`. Exact-symbolic evaluation in sympy
([`scripts/audit_companion_g2_v_bounded_interval_narrow_exact_2026_05_17.py`](./../scripts/audit_companion_g2_v_bounded_interval_narrow_exact_2026_05_17.py))
yields

```text
1 / α_2(v) |_{u_lo = 96/100}  =  (115248 π² - 456475) / (7500 π)
                              ≈  26.937,                                   (S10)
1 / α_2(v) |_{u_hi = 98/100}  =  (115248 π² - 456475) / (7500 π) + (388/625) π
                              ≈  28.887,                                   (S11)
g_hi  =  sqrt( 4 π / 26.937 )  ≈  0.68283 43045 53706 87,                   (S12)
g_lo  =  sqrt( 4 π / 28.887 )  ≈  0.65939 28361 86702 25.                   (S13)
```

The exact rational-times-π forms in `(S10)`, `(S11)` are evaluated to 30
decimal digits in the runner; the digits in `(S12)`, `(S13)` round to
the displayed 14-digit values `(G4)`, `(G5)`. ∎
