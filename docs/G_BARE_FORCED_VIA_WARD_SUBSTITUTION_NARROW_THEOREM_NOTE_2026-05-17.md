## 1. Theorem

Let `g_bare > 0` denote the bare gauge scale on the retained
`Cl(3) x Z^3` Wilson-plaquette + staggered-Dirac action on the
`Q_L = (2, 3)` block. Let `F_Htt^(0)(g_bare)` denote the tree-level
scalar-singlet form factor `<0 | H_unit | tbar t>_tree` on this block.

**Hypotheses.**

(W1) The retained Ward Rep-B-independence form-factor identity:

```text
F_Htt^(0)(g_bare)  =  1 / sqrt(6)    for all g_bare > 0.            (1)
```

(W2) The candidate same-1PI coefficient identity:

```text
F_Htt^(0)(g_bare)^2  =  g_bare^2 / (2 N_c)    for all g_bare > 0.   (2)
```

(NC) The retained color-rank identification:

```text
N_c  =  3.                                                          (3)
```

**Conclusion (T1) (substitution closure).** Substituting `(1)` into `(2)`
and using `(3)`,

```text
g_bare^2  =  1.                                                     (4)
```

**Conclusion (T2) (positive bare-coupling branch).** On the positive
bare-coupling branch `g_bare > 0`, the unique solution is

```text
g_bare  =  1.                                                       (5)
```

**Conclusion (T3) (counterfactual color rank).** Substituting `(1)` into
`(2)` at a different color rank `N_c = 2` (i.e., the SU(2) counterfactual)
gives instead `g_bare^2 = 2/3`, and at `N_c = 4` gives `g_bare^2 = 4/3`.
The specific conclusion `g_bare^2 = 1` is therefore a consequence of the
retained framework rank `N_c = 3`, not an algebraic identity true for any
`N_c`.

## 2. Proof

**`(T1)`.** Square both sides of `(1)`:

```text
F_Htt^(0)(g_bare)^2  =  1 / 6.                                      (6)
```

Equate `(2)` and `(6)`, which both express `F_Htt^(0)(g_bare)^2`:

```text
g_bare^2 / (2 N_c)  =  1 / 6.                                       (7)
```

Equivalently, applying the retained abstract narrow forcing identity
`(AN)` (which states that `F^2 = c0` together with
`F^2 = g^2 / (2 N)` forces `g^2 = 2 N c0`) at the framework instance
`(F, g, N, c0) = (F_Htt^(0), g_bare, N_c, 1/6)`:

```text
g_bare^2  =  2 N_c * (1/6)  =  N_c / 3.                             (8)
```

Substitute `(3)` (the retained `N_c = 3` identification):

```text
g_bare^2  =  3 / 3  =  1.                                           (4)
```

**`(T2)`.** From `(4)`, `g_bare^2 = 1` has two real solutions `g_bare = ±1`.
Restricting to the positive bare-coupling branch `g_bare > 0` selects the
unique positive root `g_bare = 1`.

**`(T3)`.** Substituting `N_c = 2` into `(8)` gives `g_bare^2 = 2/3`, and
substituting `N_c = 4` gives `g_bare^2 = 4/3`. Neither matches `g_bare = 1`
on the positive branch, demonstrating that the conclusion is a parametric
function of the retained color rank, not an algebraic identity over `N_c`.
∎
