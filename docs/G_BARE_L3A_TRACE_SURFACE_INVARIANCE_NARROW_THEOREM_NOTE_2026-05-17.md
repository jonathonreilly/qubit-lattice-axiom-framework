## 1. Theorem

Let `V_3 = C^3` be the irreducible color carrier with canonical
Gell-Mann generators `T_a^{(3)}` satisfying `Tr_{V_3}(T_a T_b) =
(1/2) δ_{ab}`. Let `V = C^8 = V_color ⊕ V_lepton` be the full framework
Hilbert space with `V_color = V_3 ⊗ V_fiber` (`dim V_fiber = 2`) and
`dim V_lepton = 2`. Define the V-embedded gauge generators
`T_a^{(V)} ∈ End(V)` by:

```text
T_a^{(V)} |v ⊗ w⟩  =  (T_a^{(3)} |v⟩) ⊗ |w⟩    for |v⟩ ∈ V_3, |w⟩ ∈ V_fiber, (1a)
T_a^{(V)} |x⟩      =  0                          for |x⟩ ∈ V_lepton,         (1b)
```

so that `T_a^{(V)} = T_a^{(3)} ⊗ I_2 ⊕ 0_lepton` and the L3a binary
admission reads:

```text
N_F^{(3)} := Tr_{V_3}(T_a T_b) / δ_{ab} = 1/2,                              (2a)
N_F^{(V)} := Tr_V(T_a^{(V)} T_b^{(V)}) / δ_{ab} = 1.                        (2b)
```

Their ratio is **structurally fixed by Cl(3) + Z^3 primitives**:

```text

```

per [`N_F_BOUNDED_Z2_REDUCTION_THEOREM_NOTE_2026-05-07_w2.md`](N_F_BOUNDED_Z2_REDUCTION_THEOREM_NOTE_2026-05-07_w2.md).

Let `A_op = Σ_a A^a T_a^{(W)}` be the operator-valued connection on
trace surface `W ∈ {V_3, V}`. Let `U_p^{(W)} = expm(ia A_μ) expm(ia A_ν)
expm(-ia A_μ) expm(-ia A_ν)` denote the elementary plaquette on `W`.

**Hypotheses.**

(L1) The lattice Wilson action on trace surface `W` takes the
universal form

```text
S_W^{(W)}  =  β^{(W)} · Σ_p F^{(W)}(U_p^{(W)}),                              (4)
```

with `F^{(W)}(U) := (dim(W) - Re Tr_W(U)) / dim(W)`. This is the


makes no reference to any trace surface.

(L3) `F` lives in `End(V_3) ⊗ I_2 + 0_lepton ⊂ End(V)`, so
`Tr_V(F^2) = 2 · Tr_{V_3}(F^2)`.

**Conclusion (T1) (trace-surface inflation).** Under (L3),

```text
Tr_W(F^2)  =  c_W · Tr_{V_3}(F^2),                                          (6)
```



## 2. Proof

**`(T1)`.** Direct calculation. `F` lives in `End(V_3) ⊗ I_2 + 0_lepton`,
so `F^2 = (F^{(3)})^2 ⊗ I_2 + 0_lepton`. Then

```text
Tr_V(F^2)  =  Tr_{V_3}((F^{(3)})^2) · Tr_{I_2}(I_2) + Tr_lepton(0)
           =  2 · Tr_{V_3}((F^{(3)})^2)
           =  c_V · Tr_{V_3}(F^2),
```

with `c_V = 2`. For `W = V_3`, the identity is `c_{V_3} = 1`. ∎

**`(T2)`.** The standard Baker-Campbell-Hausdorff plaquette expansion
(verified numerically by the cached `frontier_g_bare_derivation.py`
runner in its Section C):

```text
Re Tr_W(U_p^{(W)})  =  dim(W) - (a^4 / 2) Tr_W(F^2) + O(a^6),
```

with the constant-A limit `F = i[A_μ, A_ν]`. Dividing by `dim(W)`:

```text
F^{(W)}(U_p^{(W)})  =  (a^4 / (2 · dim(W))) · Tr_W(F^2) + O(a^6).
```

For the ratio (7b), substitute (6) at `c_V = 2`:

```text
[F^{(V)}(U_p^{(V)})] / [F^{(V_3)}(U_p^{(V_3)})]
   =  [c_V · Tr_{V_3}(F^2) / dim(V)] / [c_{V_3} · Tr_{V_3}(F^2) / dim(V_3)]
   =  (c_V · dim(V_3)) / (c_{V_3} · dim(V))
   =  (2 · 3) / (1 · 8)  =  3/4. ∎
```

**`(T3)`.** The trace form `Tr_W(T_a^{(W)} T_b^{(W)}) = N_F^{(W)}
δ_{ab}` gives `Tr_W(F^2) = N_F^{(W)} · Σ_a (F^a)^2` by orthogonality of
the canonical basis. Substituting into (8):

```text
(1/(2 g²)) · (1 / N_F^{(W)}) · Tr_W(F^2)
   =  (1/(2 g²)) · (1 / N_F^{(W)}) · N_F^{(W)} · Σ_a (F^a)^2
   =  (1/(2 g²)) · Σ_a (F^a)^2  =  (1/(4 g²)) · Σ_a F^a_{μν} F^{a,μν}
```

(using `F^2 = (1/2) F_{μν} F^{μν}` for antisymmetric `F` with `μ ≠ ν`).
This is the convention-independent (5). ∎

**`(T4)`.** Equating (7a) per-plaquette to the continuum's `a^4`
coefficient (8):

```text
β^{(W)} · (a^4 / (2 · dim(W))) · Tr_W(F^2)
   =  (a^4 / (2 g_bare²)) · (1 / N_F^{(W)}) · Tr_W(F^2),
```

so dividing both sides by `(a^4 / 2) · Tr_W(F^2)`:

```text
β^{(W)} / dim(W)  =  1 / (g_bare² · N_F^{(W)}),
```

equivalently `β^{(W)} = dim(W) / (N_F^{(W)} · g_bare²)`, giving (9b).
At `g_bare = 1`:

```text
β^{(V_3)}  =  3 / (1/2 · 1)  =  6,    β^{(V)}  =  8 / (1 · 1)  =  8. ∎
```

**`(T5)`.** By (T4), `g_bare² = dim(W) / (N_F^{(W)} · β^{(W)})`. Under
the binary L3a swap `(W, N_F^{(W)}) → (W', N_F^{(W')})`, the lattice
matching coefficient `β^{(W)}` simultaneously transforms to `β^{(W')} =
dim(W') / (N_F^{(W')} · g_bare²)` at the same `g_bare`. The substitution
is consistent: both binary admissions give the SAME `g_bare` at the
canonical matching surface, with only the conventional `β` value
differing. ∎
