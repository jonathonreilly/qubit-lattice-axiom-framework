## 0. Review-Loop Boundary

The prior source presented this row as a positive theorem removing the
continuum `A -> A/g` rescaling freedom. Review-loop narrows that surface
because the argument load-bears the Wilson matching/action-surface premise

```text
beta = 2 N_c / g_bare^2,
```

which this row does not derive as a one-hop retained authority. The repaired
source therefore takes the conservative route: it is no longer a theorem that
removes all continuum rescaling freedom from retained first principles. It is
only the bounded algebraic split

```text
CN + WM + rescaling by c  =>  Gram -> c^2 Gram,
fixed-g WM                =>  beta_new = beta_old,
counter-rescaled-coupling action surface
                           =>  beta_new = c^2 beta_old.
```

Here:

- **CN** is the canonical trace normalization
  `Tr(T_a T_b) = delta_ab / 2`, supplied by the retained CL3 color algebra
  authority [`CL3_COLOR_AUTOMORPHISM_THEOREM.md`](CL3_COLOR_AUTOMORPHISM_THEOREM.md).
- **WM** is the scoped Wilson matching relation
  `beta = 2 N_c / g_bare^2`.
- The counter-rescaled-coupling action surface is the explicit scoped
  convention `g_bare,new^2 = g_bare,old^2 / c^2`. Under that convention,
  Wilson matching gives `beta_new = c^2 beta_old`.
- Wilson matching and the counter-rescaled-coupling action surface are scoped
  inputs to this lemma, not retained conclusions proved here.

## 1. The Narrowed Claim

> **Lemma (bounded rescaling algebra on two action surfaces).**
> Assume:
>
> 1. `Tr(T_a T_b) = delta_ab / 2` on the canonical SU(3) triplet carrier.
> 2. The Wilson matching relation `beta = 2 N_c / g_bare^2`.
> 3. A scalar rescaling of the carrier/connection normalization by `c`,
>    with `c^2 != 1`.
>
> Then exact algebra gives
>
> ```text
> Tr((c T_a)(c T_b)) = c^2 delta_ab / 2,
> fixed g_bare^2 in WM: beta_new = beta_old,
> counter-rescaled coupling g_bare,new^2 = g_bare,old^2 / c^2:
>     beta_new = c^2 beta_old.
> ```
>
> Therefore a nontrivial scalar rescaling does not preserve the same
> canonical-normalization surface. It changes the trace normalization. The
> `beta -> c^2 beta` statement is valid only on the explicitly scoped
> counter-rescaled-coupling action surface; it is not a consequence of WM at
> fixed `g_bare^2`.

This is a class-A algebraic implication over the listed inputs.
