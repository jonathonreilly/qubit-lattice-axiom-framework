## 2. Proof

Each step is class (A) algebraic substitution into a cited retained
identity.

### Step 1 — Gram scaling `(T1)`

Substitute `(D)` into `Tr(T_a^{(lambda)} T_b^{(lambda)})`:

```text
    Tr(T_a^{(lambda)} T_b^{(lambda)})
        =  Tr((lambda T_a)(lambda T_b))
        =  lambda^2 * Tr(T_a T_b)
        =  lambda^2 * (1/2) * delta_{ab}                                  [by (G)]
        =  (lambda^2 / 2) * delta_{ab}.                                   ∎(T1)
```

### Step 2 — Casimir scaling `(T2)`

Substitute `(D)` into `sum_a T_a^{(lambda)} T_a^{(lambda)}`:

```text
    sum_a T_a^{(lambda)} T_a^{(lambda)}
        =  sum_a (lambda T_a)(lambda T_a)
        =  lambda^2 * sum_a T_a T_a
        =  lambda^2 * (4/3) * I_3                                         [by (C)]
        =  (4 lambda^2 / 3) * I_3.                                        ∎(T2)
```

### Step 3 — Joint preservation locus `(T3)`

By `(T1)`, the Gram preservation condition
`Tr(T_a^{(lambda)} T_b^{(lambda)}) = (1/2) delta_{ab}` is equivalent to
`(lambda^2 / 2) = 1 / 2`, i.e., `lambda^2 = 1`. On the positive ray
`lambda > 0`, this gives `lambda = 1`.

By `(T2)`, the Casimir preservation condition
`sum_a T_a^{(lambda)} T_a^{(lambda)} = (4/3) I_3` is equivalent to
`(4 lambda^2 / 3) = 4/3`, i.e., `lambda^2 = 1`. On the positive ray
`lambda > 0`, this gives `lambda = 1`.

Both preservation conditions force `lambda = 1`, so each is individually
sufficient to identify the preservation locus. Their conjunction is
trivially the same singleton:

```text
    Lambda_*  =  {lambda > 0 : lambda^2 = 1 AND lambda^2 = 1}
              =  {lambda > 0 : lambda = 1}
              =  {1}.                                                     ∎(T3)
```

In particular: each cited invariant individually witnesses the
rigidity. The conjunction is over-determined; either cited invariant
alone (Gram or Casimir) suffices on the positive ray.

### Step 4 — Parent load-bearing step `(T4)`

The parent's load-bearing step is the contrapositive of `(T3)`:
`lambda != 1 => lambda not in Lambda_*`. By `(T3)`, `Lambda_* = {1}`, so
the contrapositive is immediate. The two cited invariants `(G)` and
`(C)` each change under `lambda != 1` (by `(T1)` and `(T2)`
respectively), confirming the parent's stated reason ("because it
changes the fixed trace form and fixed Casimir").  ∎(T4)
