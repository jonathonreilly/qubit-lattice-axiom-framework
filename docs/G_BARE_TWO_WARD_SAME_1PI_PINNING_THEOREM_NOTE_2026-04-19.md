same-1PI coefficient identity:

```
1/6 = g_bare^2 / (2 N_c).
```

With `N_c = 3`,

```
1/6 = g_bare^2 / 6.
```

Therefore

```
g_bare^2 = 1.
```

On the positive bare-coupling branch,

```
g_bare = 1.
```

At `g_bare = 1`, the admitted same-1PI coefficient evaluates to

```

```

matching the retained Rep-B-independence coefficient. For any positive
sample with `g_bare != 1`, equation (A) would require a coefficient
different from `1/6`, so it cannot be combined with the retained
Rep-B value.
