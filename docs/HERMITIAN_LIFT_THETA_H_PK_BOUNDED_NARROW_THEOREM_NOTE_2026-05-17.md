## Statement

Let `Λ = (Z mod L)^3` with even `L`. Let `V_lat := C^{|Λ|} = C^{L^3}`
with the lattice-basis vectors `|x⟩` indexed by `x = (x_1, x_2, x_3) ∈ Λ`.

Define the **staggered hopping operator** `D ∈ End(V_lat)` by

```text
    D |x⟩  =  Σ_{μ=1}^{3}  (1/2) · η_μ(x) · (|x + e_μ⟩ − |x − e_μ⟩)    (D)
```

with `e_μ` the unit lattice vector in direction `μ` (with addition mod
`L`), and the staggered phase

```text
    η_1(x) = 1,    η_2(x) = (−1)^{x_1},    η_3(x) = (−1)^{x_1 + x_2}.   (η)
```

All `η_μ(x) ∈ {+1, −1}`, hence `D` has only **real** entries (in fact
in `{0, ± 1/2}` on each row). By direct computation, `D^T = −D`, hence
`D^† = −D` (componentwise complex conjugation is the identity on real
matrices). So `D` is **real anti-Hermitian** on `V_lat`.

Define the **physical Hermitian Hamiltonian**

```text
    H  :=  i D                                                           (H)
```

so `H^† = (−i) D^† = (−i)(−D) = i D = H`; `H` is Hermitian.

Define on `V_lat` the framework operators of the parent `cpt_exact_note`
row:

- `C ∈ End(V_lat)`: real diagonal, `[C]_{x,y} := (−1)^{x_1 + x_2 + x_3} δ_{x,y}`
  (sublattice parity). `C` is real and involutory: `C^T = C`, `C^2 = I_lat`.
- `P ∈ End(V_lat)`: real involutory permutation, `[P]_{x,y} := δ_{(−x) mod L, y}`
  (spatial inversion). `P^2 = I_lat`, `P^T = P`.

The framework C, P-on-D identities (parent `cpt_exact_note`):

```text
    C D C^{-1}  =  −D,           (D1)
    P D P^{-1}  =  −D,           (D2)
    K D K^{-1}  =  D     (D real),  with K linear-conjugate.           (D3)
```

Identities (D1), (D2) are framework parent content (derived in
`frontier_cpt_exact.py` Parts 1–5 at exact precision on `L ∈ {4, 6, 8}`),
and (D3) is immediate from `D` real.

Let `K` denote componentwise complex conjugation on `V_lat` in the
lattice basis (the **antilinear** involution `K |x⟩ = |x⟩`, `K (c |v⟩) = c^* K |v⟩`
for `c ∈ C`; `K^2 = I_lat`).

Define the **antiunitary Hermitian-lift CPT representative**

```text
    Θ_H  :=  P K  ∈ Antiunitary(V_lat).                                  (Θ)
```

Then:

**(L1) Antiunitary involution.** `Θ_H` is an antiunitary involution on
`V_lat`: `Θ_H^{-1} = Θ_H` (using `P^{-1} = P`, `K^{-1} = K`,
`K P K^{-1} = P` because `P` is real, and `P K P K = P P K K = I_lat`),
so `Θ_H^2 = I_lat` and `Θ_H` is its own inverse.

**(L2) Hermitian-lift symmetry.** `Θ_H` commutes with `H`:

```text
    Θ_H  H  Θ_H^{-1}  =  H,                                              (L2)
```

equivalently `[Θ_H, H] = 0` interpreted as the matrix-level identity
`Θ_H H = H Θ_H` (each side viewed as a composition of
linear/antilinear maps on `V_lat`).

**(L3) Odd-sector Hamiltonian matrix vanishes.** Define the
`Θ_H`-odd Hamiltonian-sector matrix

```text
    H_odd  :=  (H − Θ_H H Θ_H^{-1}) / 2  ∈  End_C(V_lat).                (L3-def)
```

Under (L2), `H_odd = (H − H) / 2 = 0`, so every entry of `H_odd`
equals `0` as a complex `L^3 × L^3` matrix. The Frobenius norm of
`H_odd` is zero: `||H_odd||_F = 0`.

**(L4) Direction-resolved hopping sectors vanish.** Write the
direction-decomposition `H = Σ_{μ=1}^{3} H_μ` with

```text
    H_μ |x⟩  :=  (i/2) · η_μ(x) · (|x + e_μ⟩ − |x − e_μ⟩).               (Hμ)
```

Each `H_μ` is Hermitian (each summand is `i` times a real
anti-Hermitian piece). Define `H_{μ,odd} := (H_μ − Θ_H H_μ Θ_H^{-1}) / 2`.
Then for every `μ ∈ {1, 2, 3}`:

```text
    H_{μ,odd}  =  0.                                                     (L4)
```

(L1)–(L4) are the load-bearing content of this narrow theorem. They
are pure class-A algebraic substitutions in the parent identities
(D1)–(D3) plus the abstract operator-type axioms `(P real involutory,
K antilinear with K^2 = I, K(i) = −i)`. They are sympy-verified exact
at audit-companion precision on the constructed framework instance.

## Proof

Pure algebraic substitution at the matrix level. All four items follow
from (D1)–(D3) and the antilinear action `K i K^{-1} = −i`.

### (L1) Antiunitary involution

Compute `Θ_H^2 = (P K)(P K) = P (K P K^{-1}) K^2 = P P I_lat = I_lat`.
The middle equality uses that `P` is real (`K P K^{-1} = P^* = P`).
The factor `K^2 = I_lat`. Hence `Θ_H^2 = I_lat`, i.e. `Θ_H^{-1} = Θ_H`. ∎

### (L2) Hermitian-lift symmetry

Apply `Θ_H` and `Θ_H^{-1}` to `H = i D`:

```text
    Θ_H H Θ_H^{-1}
      =  (P K)(i D)(P K)^{-1}
      =  P (K i K^{-1}) (K D K^{-1}) (K P^{-1} K^{-1})   [K antilinear; expand]
      =  P (−i) (K D K^{-1}) (K P K^{-1})                [K(i)=−i; K P K = P]
      =  −i · P (K D K^{-1}) P                            [reorder real factors]
      =  −i · P D P                                       [by (D3): K D K^{-1} = D]
      =  −i · (−D)                                        [by (D2): P D P = −D]
      =  i D
      =  H.
```

Each `=` is a sympy-`simplify` step on explicit `L^3 × L^3` matrices in
the runner. Hence `Θ_H H Θ_H^{-1} = H`, i.e. `Θ_H H = H Θ_H`. ∎

### (L3) Odd-sector matrix vanishes

By (L2), `Θ_H H Θ_H^{-1} = H`, so

```text
    H_odd  =  (H − Θ_H H Θ_H^{-1}) / 2  =  (H − H) / 2  =  0_{V_lat}.
```

Therefore every entry of `H_odd` equals `0` in `C`, and
`||H_odd||_F^2 = Σ_{x, y} |[H_odd]_{x,y}|^2 = 0`. ∎

### (L4) Direction-resolved sectors vanish

Each `H_μ` is independently Hermitian: `H_μ = i D_μ` where `D_μ` is
the direction-`μ` piece of `D` (real, anti-Hermitian by the same
combinatorial argument restricted to direction-`μ` links: the hop
`|x⟩ → ±(1/2) η_μ(x) |x ± e_μ⟩` is real, and the matrix transpose
exchanges `+e_μ` and `−e_μ` rows). The same identity `P D_μ P = −D_μ`
holds direction-by-direction in (D2) because the parity action is
direction-blind on `D` and acts on hops `|x⟩ → |x ± e_μ⟩` by
sending each to `|−x ∓ e_μ⟩`; the sign-flip is independent of the
direction-`μ` label.

Concretely, for each `μ` and each pair `x, y = x ± e_μ`:

```text
    P D_μ P |x⟩
      =  P D_μ |(−x) mod L⟩
      =  P [(1/2) η_μ(−x) (|(−x) + e_μ⟩ − |(−x) − e_μ⟩)]
      =  (1/2) η_μ(−x) (|x − e_μ⟩ − |x + e_μ⟩)
      =  −(1/2) η_μ(−x) (|x + e_μ⟩ − |x − e_μ⟩).
```

Since `η_μ(−x) = η_μ(x)` for `μ = 1` (constant `+1`) and for `μ = 2`,
`μ = 3` the staggered phase `η_μ(x) = (−1)^{x_1 + ... + x_{μ-1}}`
takes `(−1)^{(−x_1) + ... + (−x_{μ-1})} = (−1)^{x_1 + ... + x_{μ-1}}`
(since each `−x_i` has the same parity as `x_i` modulo 2, equivalently
`(−1)^{−n} = (−1)^n`), we get `η_μ(−x) = η_μ(x)`. Therefore
`P D_μ P = −D_μ`, and so by the same calculation as (L2),

```text
    Θ_H H_μ Θ_H^{-1}  =  Θ_H i D_μ Θ_H^{-1}
                     =  −i · P (K D_μ K^{-1}) P
                     =  −i · P D_μ P
                     =  −i · (−D_μ)
                     =  i D_μ
                     =  H_μ.
```

Hence `H_{μ,odd} = (H_μ − H_μ)/2 = 0` for every `μ ∈ {1, 2, 3}`. ∎
