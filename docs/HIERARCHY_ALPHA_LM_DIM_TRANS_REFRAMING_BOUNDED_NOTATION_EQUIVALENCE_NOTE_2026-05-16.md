## T1. Exact Identity

Let `alpha > 0` and let `N` be a positive integer. Define

```text
c_eff(alpha, N) := N alpha ln(1/alpha).
```

Then

```text
alpha^N = exp(-c_eff(alpha, N) / alpha).
```

**Proof.** Since `alpha > 0`, the real logarithm is defined and
`ln(1/alpha) = -ln(alpha)`. Therefore

```text
-c_eff(alpha, N) / alpha
  = -N alpha ln(1/alpha) / alpha
  = -N ln(1/alpha)
  = N ln(alpha).
```

Exponentiating both sides gives

```text
exp(-c_eff(alpha, N) / alpha) = exp(N ln(alpha)) = alpha^N.
```

This is a tautology of real exponentiation and logarithms.
