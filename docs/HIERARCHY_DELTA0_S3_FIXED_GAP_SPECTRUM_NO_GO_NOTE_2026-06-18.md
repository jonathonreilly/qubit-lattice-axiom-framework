## 0. Question

The DELTA0 route-inventory synthesis leaves a surviving S3 route:
a direct non-link transport rule in which the hierarchy rung ratio
`mu_{k+1}/mu_k = alpha_LM` would come from a gap-equation mass spectrum
at successive taste decouplings. The same inventory already notes that
the leading-order lattice-gauge-only NJL row is in the symmetric phase,
so this note asks the narrower, dedicated S3 question:

> On the current lattice-gauge-only NJL surface, can the active-taste
> gap equation supply a nontrivial threshold mass spectrum whose
> successive ratios are `alpha_LM`?

Answer: no, at the stated scope.

At the leading-order Kawamoto-Smit value `G_LO = 1/6`, every active
taste count `1 <= n <= 16` lies below its NJL threshold, so no
nontrivial gap masses exist. If one instead grants a hypothetical
common broken-phase coupling `G` to make several roots exist, the fixed
`G` spectrum has adjacent ratio

```text
R_n(G) = sigma_{n-1}/sigma_n
       = sqrt(((n - 1) G - 4 u_0^2)/(n G - 4 u_0^2)).
```

For a prescribed constant ratio `alpha_LM`, each adjacent step forces
a different coupling

```text
G_*(n) = 4 u_0^2 (1 - alpha_LM^2)/(n - 1 - alpha_LM^2 n),
```

so no single fixed `G` can realize the same `alpha_LM` ratio at two
different adjacent thresholds, much less across the full taste
staircase. A successful S3 closure must therefore supply additional
structure: a derived threshold-dependent `G_n`, an EW-sector gap driver,
or a non-NJL non-link transport rule.

## 1. Computed theorem

For active taste count `n`, use the same finite-spectrum form as the
NJL-style row, with the coefficient generalized from `8 = 16/2` to
`n/2`:

```text
V_n(sigma; G) = sigma^2/(2 G) - (n/2) log(sigma^2 + 4 u_0^2).
```

Then

```text
dV_n/dsigma = sigma [1/G - n/(sigma^2 + 4 u_0^2)].
```

The nontrivial root exists exactly when

```text
sigma_n^2 = n G - 4 u_0^2 > 0,
G > G_crit(n) = 4 u_0^2/n.
```

Using the B1-licensed plaquette value `<P> = 0.5934`, so
`u_0 = <P>^(1/4) = 0.877681381`, and the leading-order
Kawamoto-Smit value `G_LO = 1/(2 N_c) = 1/6`, the largest active count
has

```text
sigma_16^2 = 16/6 - 4 u_0^2 = -0.414602 < 0.
```

Since `sigma_n^2` decreases with `n` for smaller active taste counts,
all `n = 1, ..., 16` are symmetric-phase at this leading order. There
is no gap-equation mass spectrum on this surface, hence no S3 rung
ratio to read.

The fixed-broken-phase extension is also obstructed. Suppose a single
fixed coupling `G` is granted and both adjacent roots `sigma_n` and
`sigma_{n-1}` exist. The ratio condition
`R_n(G) = alpha_LM` rearranges to the unique forced value `G_*(n)`
above. Because `alpha_LM^2 != 1`, `G_*(n) = G_*(m)` implies `n = m`;
therefore a common fixed `G` cannot make the same `alpha_LM` ratio for
two distinct adjacent steps. The runner verifies this over the full
`n = 2, ..., 16` range.
