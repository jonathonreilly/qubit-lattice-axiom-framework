## 1. Claim scope

> **Theorem (integer evaluation plus a conditional dimensional-exponent
> statement).** Let
>
> ```text
> eta(s)  =  sum_{n >= 1} (-1)^(n-1) / n^s,
> zeta(s) =  sum_{n >= 1} 1 / n^s,
> ```
>
> with both displayed series absolutely convergent for real `s > 1`.
> On the integer domain `s >= 2`, define the positive real quantity
>
> ```text
> g(s) = (eta(s) / zeta(s))^(1/s).
> ```
>
> Then:
>
> **(A) Closed form.** For every integer `s >= 2`,
>
> ```text
> g(s) = (1 - 2^(1-s))^(1/s).
> ```
>
> **(B) Strict monotonicity and limit.** `g` is strictly increasing on
> integer `s >= 2`, and `lim_{s -> infinity} g(s) = 1`.
>
> **(C) Integer uniqueness at `s = 4`.** Among integers `s >= 2`,
>
> ```text
> g(s) = (7/8)^(1/4)
> ```
>
> holds if and only if `s = 4`, with the positive real value
>
> ```text
> g(4) = (eta(4) / zeta(4))^(1/4)
>      = (7/8)^(1/4)
>      ~= 0.9671682101.
> ```
>
> **(D) Dimensional exponent for a supplied monomial magnitude map.**
> Let `d` be a positive integer. Suppose a real quantity `f` has physical
> dimension `mass^d`, and suppose a nonnegative mass magnitude is defined
> on `f != 0` by the nontrivial monomial map
>
> ```text
> M(f) = kappa |f|^p,
> ```
>
> where `p` is real and `kappa > 0` is a supplied dimensionless coefficient. Covariance
> under a positive change of mass unit,
>
> ```text
> f -> lambda^d f,       M -> lambda M       (lambda > 0),
> ```
>
> fixes `d p = 1`, hence `p = 1/d`. The resulting proportionality class
> is exactly
>
> ```text
> M(f) = kappa |f|^(1/d).
> ```
>
> After the exponent has been fixed by the nontrivial positive-coefficient
> family, the zero function may be represented by setting `kappa = 0` in
> that family. The identical zero function is covariant for every exponent,
> however, so its `p = 1/d` label carries no uniqueness information. If strict
> positivity for `f != 0` is assumed, then `kappa > 0`. For finite
> `kappa`, the continuous extension at `f = 0` is `M(0) = 0`.
>
> Dimensional analysis fixes only the exponent. It does not select
> `kappa`, the magnitude/sign convention, the value or physical carrier
> of `f`, dynamics, or an empirical scale. The special convention
> `kappa = 1` is permitted only when supplied explicitly. At `d = 4`,
> the exponent is `1/4`; this is the same outer exponent appearing in
> part (C) when the two independent statements are evaluated at the
> common integer `s = d = 4`.

The theorem therefore combines two exact but logically independent facts:
the integer-`s` number-theoretic result in parts (A)-(C), and the exponent
theorem for a supplied monomial magnitude map in part (D). Setting the two
indices equal at `s = d = 4` is a joint specialization. It does not select a
physical spacetime dimension or a physical hierarchy map.

## 2. Proof

### 2.1 Part (A): Riemann-Dirichlet identity

For real `s > 1`, absolute convergence permits the odd/even split

```text
zeta(s) = sum_{n odd >= 1} 1/n^s + 2^(-s) zeta(s).
```

Thus the odd sum is `(1 - 2^(-s)) zeta(s)`. Subtracting the even sum
from it gives

```text
eta(s) = (1 - 2^(-s)) zeta(s) - 2^(-s) zeta(s)
       = (1 - 2^(1-s)) zeta(s).
```

Because `zeta(s) > 0` on this real domain,

```text
eta(s) / zeta(s) = 1 - 2^(1-s).
```

For integer `s >= 2`, the right side lies strictly between zero and one,
so its positive real `1/s` power is unambiguous. This proves (A). The
same alternating-series identity is DLMF equation 25.2.3.

### 2.2 Part (B): strict monotonicity and limit

Set `u = 2^(-s)`. For every integer `s >= 2`,

```text
g(s+1) > g(s)
```

is equivalent, after taking logarithms and multiplying by the positive
number `s(s+1)`, to

```text
s [-log(1-u)] < (s+1) [-log(1-2u)].
```

Using `-log(1-x) = sum_{k >= 1} x^k/k`, the coefficient difference at
each `k >= 1` is positive because

```text
(s+1) 2^k - s
  = (s+1)(2^k - 2) + (s+2)
  > 0.
```

Both logarithmic series converge absolutely, so termwise comparison proves
strict monotonicity on the stated integer domain.

For the limit, take logarithms:

```text
log g(s) = log(1 - 2^(1-s)) / s -> 0.
```

Therefore `g(s) -> exp(0) = 1`. No indeterminate `1^0` step is used.

An independent route, used by the runner rather than by the proof above,
sets `h(s) = log g(s)` for real `s > 1`. With `x = 2^(1-s)`,

```text
h'(s) = [s log(2) x/(1-x) - log(1-x)] / s^2 > 0,
```

because both terms in the numerator are positive. This independently
confirms the monotonicity needed on the integer subset.

### 2.3 Part (C): exact value and integer uniqueness

At `s = 4`,

```text
g(4) = (1 - 2^(-3))^(1/4) = (7/8)^(1/4).
```

Part (B) makes `g` injective on integers `s >= 2`. The displayed value
therefore occurs at exactly one integer in that domain, namely `s = 4`.

### 2.4 Part (D): dimensional covariance and the coefficient boundary

For `f != 0`, apply the monomial magnitude map after the positive rescaling
`f -> lambda^d f`:

```text
M(lambda^d f)
  = kappa |lambda^d f|^p
  = lambda^(d p) kappa |f|^p.
```

Mass-dimension-one covariance requires this to equal `lambda M(f)` for
every `lambda > 0`. Because the map is nontrivial (`kappa > 0` and
`f != 0`), division by `M(f)` is allowed, giving

```text
lambda^(d p) = lambda  for every lambda > 0,
```

and hence `d p = 1`. Since `d > 0`, `p = 1/d > 0`, so the finite-`kappa`
extension at `f = 0` is zero.

This derivation leaves every dimensionless `kappa > 0` allowed. The zero
map is an important boundary: if `kappa = 0` is assumed from the start,
covariance holds for every exponent and cannot prove exponent uniqueness.
That is why the exponent theorem is stated for a nontrivial map. Writing the
zero function afterward as the `kappa = 0` member of the derived family is
only a representation convention; the zero function itself does not retain
or identify an exponent.

The dimensionless-coefficient hypothesis is also load-bearing. If `kappa`
instead has mass dimension `q`, covariance gives

```text
q + d p = 1,       so       p = (1-q)/d.
```

Thus a dimensionful coefficient can compensate an exponent different from
`1/d`, but it lies outside the theorem's stated map class.

The absolute value is a supplied magnitude convention, not a consequence
of dimensions. If `f < 0` and `d` is even, the naive expression
`f^(1/d)` is not generally a real positive scale. If `d` is odd, the real
root of negative `f` is negative and still is not a nonnegative magnitude.
The sign/magnitude rule must therefore be stated separately from the
exponent theorem.

A massless thermal free-energy density is one possible example of a
mass-dimension-`d` quantity, with `f(T) = c_d T^d` in natural units. The
dimensionless coefficient `c_d` can carry sign, statistics, and field-content
information. Dimensions alone neither compute `c_d` nor convert it into a
unit coefficient. The original proportionality statement therefore supports
only the proportionality class `M proportional to |f|^(1/d)`.

## 3. Exact domains and boundaries

- Parts (A)-(C) use the displayed Dirichlet series only for real `s > 1`
  and state uniqueness only for integers `s >= 2`.
- At `s = 1`, the displayed zeta series diverges. That endpoint is not in
  the theorem's domain.
- No real-noninteger or complex uniqueness statement is made. In particular,
  the fractional power would require a branch choice in the complex domain.
- Part (D) assumes positive integer `d`. The cases `d = 0` and `d < 0`
  are outside the mass-density/root statement; at `d = 0`, `d p = 1`
  has no solution, while negative `d` would give a negative exponent and
  destroy the finite value at `f = 0`.
- Part (C)'s base `7/8` is positive, so its positive real fourth root is
  unambiguous. This fact does not resolve the sign of a separate, possibly
  signed physical quantity `f` in part (D).
