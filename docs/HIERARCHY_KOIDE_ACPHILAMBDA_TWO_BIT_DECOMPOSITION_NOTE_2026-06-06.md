## 1. The two readings (Bit B arithmetic)

With `E_singlet = 3 a^2`, `E_doublet = 6 |b|^2`, weights `(w_s, w_d)`,
singlet energy fraction `x = w_s / (w_s + w_d)`, and `r = (1 - x)/(2 x)`:

```text
count once   (w_s, w_d) = (1, 1)  ->  r = 1/2   (Q = 2/3)
count twice  (w_s, w_d) = (1, 2)  ->  r = 1
```

A uniform complex-mode rescale `(1, 2) -> (1/2, 1)` is proportional to
`(1, 2)` and still gives `r = 1`; it is not a selector. The gap between the
two readings is the exact integer `2` (the real dimension of the complex
doublet, equivalently the taste/weak fiber multiplicity), **not** a
continuous parameter. The continuous overall (Killing) scalar that an
algebraic rescaling argument would invoke is already removed by
[`G_BARE_RIGIDITY_THEOREM_NOTE.md`](G_BARE_RIGIDITY_THEOREM_NOTE.md)
(`retained_bounded`): on the fixed Hilbert-Schmidt trace form a continuous
dilation `T_a -> lambda T_a` is not an allowed ambiguity. Only the discrete
count bit remains.

## 2. Bit B native ingredient is available but non-selecting

`J_cs = (C - C^2)/sqrt(3)`, with `C` the `C_3` cyclic shift on `C^3`, has
eigenvalues `{0, i, -i}`: a complex structure on the doublet (`J_cs^2 = -I`
there) and zero on the democratic singlet axis. Hence:

```text
det(J_cs) = 0                         (singular; measure-neutral)
det(exp(theta J_cs)) = 1  for all theta  (SO(2) orbit preserves det_R and det_C)
```

So `J_cs` supplies the structure that *defines* a count-once (signed /
holomorphic) reading but does not *prefer* it over the count-twice reading.

[`KOIDE_SIGNED_EIGENVALUE_VS_SINGULAR_VALUE_READOUT_NARROW_THEOREM_NOTE_2026-05-29.md`](KOIDE_SIGNED_EIGENVALUE_VS_SINGULAR_VALUE_READOUT_NARROW_THEOREM_NOTE_2026-05-29.md)

therefore precisely: a native source establishing that the framework's

real-antisymmetric (symplectic) bilinear that **selects** the count-once
reading as the physically realized stable setting (e.g. under reflection
