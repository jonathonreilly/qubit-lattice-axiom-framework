## 2. Why this bridge is useful

A devil's-advocate audit of the hierarchy formula observed that:

- `v_pred` without prefactor (`= M_Pl · α_LM^16`) ≈ 254.64 GeV
  (overshoot `+3.42%` vs `v_obs = 246.22 GeV`)
- `(7/8)^(1/4) ≈ 0.9672` absorbs this overshoot to within `0.03%`:
  `1 / 1.0342 ≈ 0.9669` vs prefactor `0.9672`

Two readings of this absorption:

- **Structural-support reading (what this bridge proves):** if a
  dimension-one hierarchy readout is converted using the d=4
  fermion-to-boson Stefan-Boltzmann ratio, the required conversion
  factor is exactly `(7/8)^(1/4)`.
- **Fit-band reading (devil's advocate):** ~113 alternative rationals
  `(a/b)^(1/k)` land within `±0.5%`; the framework is fitting.

This bridge does not prove that every fit-band alternative is impossible.
It narrows the objection: `7/8` has multiple named framework and
textbook-support witnesses at d=4, while the named fit-band alternatives
checked here do not satisfy the same W2/W3/W5 support pattern.

(W1) APBC Matsubara fermion determinant ratio
`|det D(L_t=4)| / |det D(L_t=2)|^2 = (7/8)^16`.

(W2) Per-mode lattice rational `(c+1/2)/(c+1) = 7/8` at
`c=3 = d-1`.

(W3) Riemann-Dirichlet `η(4)/ζ(4) = 1 - 2^(1-4) = 7/8`.

(W4) Integer alignment `2^(d-2) = d` at d=4.

(W5) Fermi-Dirac vs Bose-Einstein per-degree-of-freedom
radiation-energy ratio at 3+1 spacetime = `7/8`.

The useful review-clean claim is the exact conversion bridge and this
support pattern, not a universal no-alternative theorem.
