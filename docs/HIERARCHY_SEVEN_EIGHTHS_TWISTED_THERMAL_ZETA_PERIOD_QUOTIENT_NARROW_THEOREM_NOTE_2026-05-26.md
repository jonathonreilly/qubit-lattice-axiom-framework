## 2. Proof

The proof is three small classical-analysis steps composed by direct
algebra.

### 2.1 Partial-sum split of the integer lattice

For real `s > 1`, both `ζ(s) = Σ_{n ≥ 1} 1/n^s` and
`λ(s) = Σ_{n ≥ 0} 1/(2n+1)^s` are absolutely convergent. Split the
positive integers `n ≥ 1` into odd and even:

```text
ζ(s)  =  Σ_{n odd ≥ 1} 1/n^s   +   Σ_{m ≥ 1} 1/(2m)^s
      =  λ(s)   +   2^(-s) ζ(s),                                       (A)
```

since the `n` odd sum is `λ(s)` and the `n` even sum reparametrizes
as `m`-sum with `n = 2m`. Hence

```text
λ(s)  =  (1 − 2^(-s)) ζ(s)                                             (B)
```

is the **DLMF §25.2 odd-tail identity** (a standard analytic-number-
theory identity, no framework input).

### 2.2 Twisted zeta sum (Hurwitz form)

The Hurwitz zeta function is defined for `Re(s) > 1`, `a > 0` by

```text
ζ(s, a)  :=  Σ_{n ≥ 0} 1 / (n + a)^s                                   (C)
```

(DLMF §25.11.1). With `a = 1/2`, the half-integer-shifted Hurwitz sum
is

```text
ζ(s, 1/2)  =  Σ_{n ≥ 0} 1 / (n + 1/2)^s
           =  Σ_{n ≥ 0} 2^s / (2n + 1)^s
           =  2^s · λ(s).                                              (D)
```

So the **half-period-twisted Hurwitz sum** equals `2^s · λ(s)` exactly.
Equivalently, the **dimensionless APBC Matsubara fermion sum**
`ζ_F(s)` of (2) — formed by multiplying `ω_n^(F) = (2n+1)π/β` modes
by the rescaling factor `(π/β)^s`, i.e. measuring each mode in units
of the fermionic fundamental spacing `π/β` — is exactly `λ(s)`, the
Hurwitz zeta at twist `a = 1/2` divided by `2^s`:
`ζ_F(s) = ζ(s, 1/2) / 2^s = λ(s)`. The reciprocal rescaling factor
`(π/β)^s` cancels the dimensionful `(β/π)^(-s) = (π/β)^s` carried by
`ω_n^(F)`, leaving a `β`-independent pure number.

### 2.3 Combining the splits

From (B), `2 λ(s) = 2(1 − 2^(-s)) ζ(s) = (2 − 2^(1−s)) ζ(s)`. So

```text
2 λ(s) − ζ(s)  =  (2 − 2^(1−s) − 1) ζ(s)
              =  (1 − 2^(1−s)) ζ(s)
              =  η(s),                                                 (E)
```

where the last step uses the standard Dirichlet-eta identity
`η(s) = (1 − 2^(1−s)) ζ(s)` (DLMF §25.2.3).

Therefore

```text
Q(s)  =  (2 λ(s) − ζ(s)) / ζ(s)  =  (1 − 2^(1−s))  =  η(s) / ζ(s).     (F)
```

This is the **APBC/PBC twisted thermal-zeta period quotient** in
closed form. At `s = 4` integer dimension, `Q(4) = 1 − 2^(-3) = 7/8`.
At any other integer `s ≥ 2`, `Q(s) ≠ 7/8` by the same arithmetic
that drives W3.
