## 1. Bridge (1) — d=4 naive taste count N_taste = 2^d = 16 (Class A)

### 1.1 Statement

> **Lemma (taste/doubler count).** Let the free massless naive lattice Dirac
> operator have momentum-space symbol `D(p) = i · Σ_{μ=1}^{d} γ_μ sin(p_μ)` on the
> first Brillouin zone `p_μ ∈ (−π, π]`. The symbol is singular (its determinant
> vanishes; equivalently every `sin(p_μ) = 0`) exactly at the points where
> `p_μ ∈ {0, π}` for every μ. The number of such Brillouin-zone corners is `2^d`.
> At `d = 4` this is `2^4 = 16`.

### 1.2 Proof

For the massless naive operator, `Σ_μ γ_μ² sin²(p_μ) = (Σ_μ sin²(p_μ)) · I` (using
the Euclidean Clifford relation `{γ_μ, γ_ν} = 2 δ_{μν} I`, so cross terms cancel
and `γ_μ² = I`). Hence `D(p)† D(p) = (Σ_μ sin²(p_μ)) · I`, which is the zero
matrix iff `sin(p_μ) = 0` for **every** μ. On `(−π, π]` the equation
`sin(p_μ) = 0` has exactly the two solutions `p_μ ∈ {0, π}`. The simultaneous
zero set is therefore the Cartesian product `{0, π}^d`, whose cardinality is
`2^d`. Each such corner is a distinct low-energy (pole/zero) mode of the naive
propagator — a *doubler* / taste. Therefore the naive taste count is
`N_taste = 2^d`, and `N_taste = 2^4 = 16` at `d = 4`. ∎

The cross-check at lower dimension is `2^1 = 2`, `2^2 = 4`, `2^3 = 8`, the
standard naive-doubler progression; the runner enumerates all four.

### 1.3 Why this is the count the ratio note needs

The ratio note's structural block sets `N_sites = 2^4 = 16 = N_taste` as the
"minimal APBC block" taste multiplicity entering `R_lattice = 4/(u_0^2 N_taste)`.
The repair item names this number verbatim as `N_taste = 16 = 2^4`. Bridge (1)
derives `2^d` from the naive symbol's corner-zero set and evaluates it at `d = 4`,
giving `16`; the even-spacetime dimension `d = 4` is supplied by the retained
Clifford/dimension row, not assumed here. So the count is reproven from the
operator symbol and a retained dimension input rather than declared.

### 1.4 Finite-lattice cross-check (APBC vs PBC)

On a finite periodic (PBC) momentum grid `p_k = 2π k / L`, `k = 0,…,L−1`, the
per-axis solutions of `sin(p_k) = 0` are `p = 0` and (once `L` is even) `p = π`,
i.e. exactly two per axis, so the corner count is `2^d = 16` at `d = 4` for any
even `L`. On a strictly anti-periodic (APBC) grid `p_k = π (2k+1)/L`, even `L`
has no exact `sin(p)=0` momentum. Odd `L` representatives can hit the boundary
point `p = π`, but then there is only one exact zero per axis, not the full
two-corner set `{0,π}` per axis. Thus finite APBC exact-zero counting is a
regulator artifact and is not the structural `2^d` taste count. The structural
species count used here is the continuum Brillouin-zone corner count `2^d`.
The runner verifies the continuum-BZ corner enumeration, the even-`L`
periodic-grid count, even-`L` APBC no-zero behavior, and odd-`L` APBC boundary
behavior.

## 2. Bridge (2) — mean-field generating functional W(J) = log det(D + J) (Class A)

### 2.1 The Berezin determinant form

The scalar source generator is the finite Grassmann (Berezin) fermion partition
function. For a finite set of sites and a complex matrix `M`, the quadratic
Grassmann integral evaluates exactly to a determinant,

```text
Z_F[M] = ∫ ∏_x dχ̄_x dχ_x exp(−Σ_{x,y} χ̄_x M_{xy} χ_y) = det(M),
```

(`Z_F[M] = det(M)`). With the operator-plus-source matrix `M = D + J` (source
`J · I`), the **log** of the partition function is the additive source generator

```text
W(J) = log Z_F[D + J] = log det(D + J).
```

This is the standard generating-functional form; the runner reproves

### 2.2 The tadpole mean-field spectrum, determinant, and curvature

The runner verifies the matrix fact that real antisymmetric blocks have purely
imaginary conjugate-pair eigenvalues `± i a`. It also verifies the Clifford
taste-square identity `D_taste² = d·I`, giving `sqrt(d)=2` at `d=4`. The
tadpole mean-field block is then the explicit finite matrix

```text
D_mf = i u_0 D_taste = i u_0 Σ_μ γ_μ.
```

Because `D_taste² = 4I`, the runner computes

```text
char(D_mf)(λ) = (λ² + 4u_0²)²,
det(D_mf + JI_4) = (J² + 4u_0²)².
```

So the uniform paired spectrum `± 2i u_0` is derived inside the tadpole
mean-field block. The bounded input remains only the mean-field truncation
itself (`U_ab -> u_0 δ_ab`), not a separate spectral assertion.

For each conjugate pair shifted by the real source
contributes

```text
det over the pair = (J + 2i u_0)(J − 2i u_0) = J^2 + 4 u_0^2,
```

so summing the log over all `N_tot` modes (`N_tot/2` pairs) gives the mean-field
generating functional

```text
W(J) = (N_tot / 2) · log(J^2 + 4 u_0^2).
```

The eigenvalue-ratio **curvature** is the second source-derivative at zero
source,

```text
W''(0) = d²/dJ² [ (N_tot/2) log(J^2 + 4 u_0^2) ] |_{J=0}
       = (N_tot/2) · [ 2/(J^2 + 4u_0^2) − (2J)^2/(J^2+4u_0^2)^2 ] |_{J=0}
       = (N_tot/2) · (1 / (2 u_0^2))
       = N_tot / (4 u_0^2),
```

which is exactly the mean-field form the ratio note consumes (its
`d²W/dJ²|_{J=0} = N_tot/(4 u_0²)`). The runner reproves the per-pair
determinant, the closed-form `W''(0)`, **and** the general operator identity
`d²/dJ² log det(D + J) = − Tr[(D + J)^{−2}]` numerically on random
anti-Hermitian matrices (analytic vs finite-difference agree to `< 1e-5`), so the
"curvature = second source-derivative of W" statement is checked beyond the
single closed form.

### 2.3 Why this is the form the ratio note needs

The ratio note writes `W(J) = (N_tot/2)·log(J² + 4 u_0²)` and uses
