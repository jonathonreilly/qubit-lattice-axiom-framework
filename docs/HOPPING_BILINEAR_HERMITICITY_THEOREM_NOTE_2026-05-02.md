## Statement

On the finite periodic block `Lambda` and tensor-product Fock space

```text
    H_{xy} := a_x^dag a_y + a_y^dag a_x.                  (1)
```

Then:

**(B1) Hermiticity.** `H_{xy}^dag = H_{xy}`.

**(B2) Translation covariance.** For every finite-block translation

```text
    T_a H_{xy} T_a^dag = H_{x+a,y+a}.                     (2)
```

**(B3) Number conservation.** `[H_{xy}, Q_total] = 0`.

**(B4) Translation-invariant sums.** If `L` is a translation-invariant

```text
    H_total := sum_{(x,y) in L} H_{xy},                    (3)
```

`|11>`, preserving total occupation.

## Proof

### Step 1 - Hermiticity

Taking adjoints gives

```text
    (a_x^dag a_y)^dag = a_y^dag a_x.
```

Therefore

```text
    H_{xy}^dag = a_y^dag a_x + a_x^dag a_y = H_{xy}.
```

This proves (B1).

### Step 2 - Translation covariance

By the cited bridge,

```text
    T_a a_x T_a^dag = a_{x+a},
    T_a a_x^dag T_a^dag = a_{x+a}^dag.
```

Thus

```text
    T_a H_{xy} T_a^dag
      = a_{x+a}^dag a_{y+a} + a_{y+a}^dag a_{x+a}
      = H_{x+a,y+a}.
```

This proves (B2).

### Step 3 - Number conservation

The local ladder identities give

```text
    [Q_total, a_x]     = -a_x,
    [Q_total, a_x^dag] =  a_x^dag.
```

Therefore

```text
    [Q_total, a_x^dag a_y]
      = [Q_total,a_x^dag] a_y + a_x^dag [Q_total,a_y]
      = a_x^dag a_y - a_x^dag a_y
      = 0,
```

and the conjugate term is identical. Hence `[H_{xy},Q_total]=0`,
which proves (B3).

### Step 4 - Translation-invariant sums

Using (B2),

```text
    T_a H_total T_a^dag
      = sum_{(x,y) in L} H_{x+a,y+a}
      = sum_{(x',y') in L} H_{x',y'}
      = H_total,
```

where the second equality is relabeling inside the translation-invariant
link family. The number-commutator vanishes by linearity from (B3). This
proves (B4).

### Step 5 - Real spectrum

`H_total` is a sum of Hermitian operators, so it is Hermitian. The finite
spectral theorem gives a real spectrum. This proves (B5).

### Step 6 - Occupation-swap action

On the two tensor factors `C^2_x tensor C^2_y`, `a_x^dag a_y` maps
`|01>` to `|10>` and annihilates the other basis states where that move is
not allowed. Its adjoint term maps `|10>` to `|01>`. Thus `H_{xy}` is the
swap on the one-particle two-site subspace and preserves total occupation.
This proves (B6).
