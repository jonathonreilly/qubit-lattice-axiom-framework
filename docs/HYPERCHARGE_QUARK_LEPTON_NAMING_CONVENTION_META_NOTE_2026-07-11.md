blocks `(2,3)` and `(2,1)`, Standard-Model language conventionally calls the
SU(3)-fundamental block the color-charged quark doublet `Q_L` and the trivial

selector, or derivation from the commutant. Any field or copy with the same
representation class has the same algebraic carrier before a physical-species
