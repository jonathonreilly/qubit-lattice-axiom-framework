## Setup

By [`MINIMAL_AXIOMS_2026-05-20.md`](MINIMAL_AXIOMS_2026-05-20.md), for
each finite region `Lambda subset Z^3`:

- `H_Lambda = tensor_{x in Lambda} C^2`, with dimension
  `d = 2^|Lambda|`;
- `A_Lambda = tensor_{x in Lambda} M_2(C) ~= M_d(C)`;
- a finite-region state is represented by a density matrix
  `rho in M_d(C)`, `rho >= 0`, `Tr rho = 1`;
- inner unitary automorphisms act by `rho -> U rho U^dagger`.

The conditional premise PRR says that the finite-region pre-record
reference state is fixed by that full inner-unitary action.

## Theorem

For a finite-dimensional matrix algebra `M_d(C)`, the only density
matrix fixed by `rho -> U rho U^dagger` for every unitary `U in U(d)`
is

```text
rho = I_d / d.
```

Equivalently, the corresponding state is the normalized trace
`tau_d(X) = Tr(X) / d`.

## Proof

Let `rho in M_d(C)` be fixed by conjugation with every unitary.
Then `U rho = rho U` for every `U in U(d)`.

There are two elementary ways to see the conclusion:

1. By Schur's lemma, the commutant of the defining irreducible
   representation of `U(d)` on `C^d` is `C I_d`; hence
   `rho = c I_d`.
2. Concretely, invariance under diagonal sign/phase unitaries kills
   every off-diagonal entry of `rho`, and invariance under permutation
   unitaries forces all diagonal entries to be equal.

The trace condition fixes `c = 1/d`, and positivity is automatic for
`I_d / d`. Therefore the fixed state is unique and tracial.

## Application to the Qubit Lattice

For each finite `Lambda`, the qubit-lattice finite-region algebra is
`M_{2^|Lambda|}(C)`. Applying the theorem with `d = 2^|Lambda|` gives:

```text
PRR on Lambda
  ==> rho_ref|_Lambda = I_{2^|Lambda|} / 2^|Lambda|.
```

The finite-region family is compatible under restriction: tracing out
`Lambda_2 \ Lambda_1` from
`I_{2^|Lambda_2|} / 2^|Lambda_2|` gives
`I_{2^|Lambda_1|} / 2^|Lambda_1|`.
