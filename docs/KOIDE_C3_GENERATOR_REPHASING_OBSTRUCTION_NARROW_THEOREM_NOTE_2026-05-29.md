# Koide C3 Generator-Rephasing Obstruction Narrow Theorem

**Date:** 2026-05-29
**Type:** positive_theorem
**Claim scope:** the exact finite-dimensional algebraic fact that the
order-three cyclic generator `C` on the `C_3` generation carrier cannot be
continuously scalar-rephased while preserving the relation `C^3 = I`.
Equivalently, a putative generator rephasing

```text
C  ->  exp(i alpha) C
```

is compatible with `C^3 = I` only for
`alpha in {0, 2pi/3, 4pi/3}`. Continuous state-space centralizers of the
real two-dimensional nontrivial `C_3` carrier are not denied here: they
commute with `C`, leave the circulant coefficient `b` in
`H = aI + bC + bbar C^2` unchanged, and therefore do not supply the
missing `b`-phase / generator-rephasing route.
**Status authority:** independent audit lane only. This source note does
not set or predict an audit outcome; later status is generated by the
audit pipeline after independent review.
**Primary runner:** [`scripts/frontier_koide_c3_generator_rephasing_obstruction.py`](../scripts/frontier_koide_c3_generator_rephasing_obstruction.py)

## Statement

Let `C` be the `3 x 3` cyclic shift with `C^3 = I`, and let

```text
B1 = C + C^2,      B2 = i(C - C^2).
```

Then:

1. Rotating the coefficient pair in the `(B1, B2)` plane by an angle
   `alpha` is algebraically the same as replacing `C` by
   `exp(i alpha) C` and `C^2` by `exp(-i alpha) C^2`.
2. The replacement `C -> exp(i alpha) C` preserves the order-three
   relation only when `exp(3 i alpha) = 1`, i.e. only at the three
   discrete cube-root phases.
3. A continuous unitary centralizer of the real `C_3` doublet can exist,
   but it commutes with `C` and leaves every `C_3`-circulant Hermitian
   `H = aI + bC + bbar C^2` unchanged. It is a state-space redundancy,
   not a physical or algebraic rotation of `b`.
4. Gauge scalar phases are generation-blind and likewise leave `b`
   unchanged. Diagonal corner phases either move `C` out of the
   `C_3`-circulant class or reduce to the same discrete cube-root
   character.

So the salvageable conclusion is narrow: the **generator-rephasing route**
to a continuous `b`-phase symmetry is obstructed by `C^3 = I`. This note
does **not** claim that every continuous action on the generation doublet
is impossible.

## Proof

For (1), expanding a rotated `(B1, B2)` pair gives

```text
cos(alpha) B1 + sin(alpha) B2
  = exp(i alpha) C + exp(-i alpha) C^2,

-sin(alpha) B1 + cos(alpha) B2
  = i(exp(i alpha) C - exp(-i alpha) C^2).
```

Thus coefficient-plane rotation is scalar rephasing of the cyclic
generator in the group-algebra presentation.

For (2),

```text
(exp(i alpha) C)^3 = exp(3 i alpha) C^3 = exp(3 i alpha) I.
```

This is equal to `I` exactly for the three cube-root phases.

For (3), diagonalize the regular carrier by the `C_3` Fourier transform.
On the two nontrivial complex-character lines, a continuous centralizer has
the form

```text
diag(1, exp(i phi), exp(-i phi))
```

in Fourier coordinates. Conjugating back to the original generation basis
gives a continuous real action on the nontrivial doublet, but it commutes
with `C`. Therefore `U C U^dag = C`, `U C^2 U^dag = C^2`, and
`U H U^dag = H`; it does not rotate the coefficient `b`.

For (4), generation-blind gauge phases are scalar multiples of the
identity on the triplet. A diagonal phase profile `P` satisfies
`P C P^dag proportional C` only when the phase differences are constant
around the three-cycle and sum to a cube-root-compatible phase; otherwise
the transformed matrix is not in the same `C_3`-circulant class.

All four statements are exact finite-dimensional matrix algebra and are
checked by the runner.

## What this claims

- Exact equivalence between `(B1, B2)` coefficient rotation and scalar
  rephasing of the cyclic generator.
- Exact cube-root quantization of generator rephasings compatible with
  `C^3 = I`.
- Exact distinction between a continuous centralizer that commutes with
  `C` and a generator rephasing that changes the coefficient `b`.
- Exact generation-blindness of gauge scalar phases and the discrete/exit
  dichotomy for diagonal corner phases.

## What this does NOT claim

- Does **not** prove that every continuous action on the real `C_3`
  doublet is absent. The centralizer action exists and is explicitly
  accounted for.
- Does **not** prove `Q = 1` or derive the Koide value.
- Does **not** force or reject any measure by itself. The result only
  forecloses the specific generator-rephasing route as a source of the
  missing `b`-phase symmetry.
- Does **not** address a separate tensor-factor chirality route that does
  not rephase `C`.
- Does **not** introduce an axiom, admission, fitted selector, or
  observational input.

## No-go discipline scope

This note has a negative boundary, but only for one proposed route: scalar
rephasing of the cyclic generator. It is not a global Koide no-go.

- **N1 (alternative route enumeration).**
  1. Scalar generator rephasing `C -> exp(i alpha) C`: **ruled out here** except
     at cube roots by `(exp(i alpha) C)^3 = exp(3 i alpha) I`.
  2. Continuous state-space centralizer on the real doublet: **accounted for
     here**; it exists, commutes with `C`, and does not rotate `b`.
  3. Generation-blind gauge scalar phases: **accounted for here**; they multiply
     all generations equally and do not rotate `b`.
  4. Diagonal corner-phase profiles: **accounted for here**; they either leave
     the `C_3`-circulant class or reduce to the discrete cube-root case.
  5. Separate tensor-factor chirality / non-circulant routes: **left open**;
     this note does not test them.
- **N2 (wall-independence audit).** The only walls are the order-three relation
  `C^3 = I` and the `C_3`-circulant presentation of the tested route. They are
  stated explicitly and are not inflated into independent route closures.
- **N3 (hidden-wall scan).** "Physical or algebraic rotation of `b`" means
  generator rephasing inside the same `C_3`-circulant class. Continuous
  centralizer actions and tensor-factor routes are not silently folded into
  that phrase.
- **N4 (residual matching).** The residual matched here is exactly the missing
  `b`-phase route through generator rephasing. It is not the residual "derive
  Koide" and not the residual "classify all continuous doublet actions."
- **N5 (rhetoric audit).** The negative statement is per-generator and
  per-circulant-class. It is not a per-doublet, per-state-space, or
  lattice-wide absence claim.
- **N6 (partial-closure path scan).** This is a partial route closure: it
  removes one proposed mechanism and leaves the broader Koide lane open.
- **N7 (steelman).** A hostile reviewer would point to the continuous real
  centralizer `diag(1, exp(i phi), exp(-i phi))` in Fourier coordinates and say
  the doublet has a continuous action after all. The response is exactly the
  theorem's scope: that action commutes with `C`; it changes basis/state
  coordinates but not the generator coefficient `b`, so it does not supply the
  missing generator-rephasing route.
- **N8 (cross-cycle echo).** Prior overbroad Koide U(1)-style route claims failed
  when a continuous action was conflated with a rotation of the load-bearing
  coefficient. This note is written to avoid that echo: only the scalar
  generator-rephasing route is closed.
