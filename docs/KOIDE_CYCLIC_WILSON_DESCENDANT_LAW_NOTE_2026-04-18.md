## Bottom line

On the Hermitian part of the unital adjacent-chain matrix algebra, cyclic
conjugation has a three-real-dimensional fixed subspace. A supplied real-linear
functional is compressed to that subspace by three responses, and those
responses have a unique Riesz representative. The abstract cone
`a^2 = 2(x^2 + y^2)` is exactly the response equation
`2 r0^2 = r1^2 + r2^2`.

## Typed inputs

Let `Eij` denote the standard `3 x 3` matrix units, and let `A_adj` be the
unital complex star-algebra generated by

```text
E12, E23, E21 = E12^dagger, E32 = E23^dagger.
```

Its Hermitian real subspace is

```text
V = A_adj intersect Herm(3),
<X,Y>_R = Re Tr(XY).
```

Supply an arbitrary real-linear functional

```text
ell : V -> R.
```

Fix the displayed cycle and its square:

```text
C   = [[0,0,1], [1,0,0], [0,1,0]]
    = E21 + E32 + E13,
C^2 = [[0,1,0], [0,0,1], [1,0,0]]
    = E12 + E23 + E31.
```

Then `C^3 = I` and `C^2 = C^dagger = C^{-1}`.

## Theorem

Define

```text
B0 = I,
B1 = C + C^2,
B2 = i(C - C^2),
V_cyc = {H in V : HC = CH}.
```

The following statements hold.

1. `B0`, `B1`, and `B2` belong to `A_adj` and are Hermitian.
2. The conjugation average
   ```text
   P_cyc(H) = (1/3) sum_{k=0}^2 C^k H C^{-k}
   ```
   is the orthogonal projector from `V` onto `V_cyc` for the real pairing
   `<.,.>_R`.
3. `V_cyc = span_R{B0,B1,B2}` and `dim_R(V_cyc) = 3`.
4. In the ordered basis `(B0,B1,B2)`, the Gram matrix is
   ```text
   G_ij = <Bi,Bj>_R = diag(3,6,6).
   ```
5. If `rj = ell(Bj)`, the restriction `ell|V_cyc` has the unique Riesz
   representative
   ```text
   H_ell = (r0/3) B0 + (r1/6) B1 + (r2/6) B2.
   ```
   Thus `ell(K) = <H_ell,K>_R` for every `K in V_cyc`.
6. Conversely, every `H in V_cyc` is recovered from its trace responses
   `rj = Re Tr(Bj H)` by the same formula.
7. Under `a = r0/3`, `x = r1/6`, and `y = r2/6`, the abstract cone
   `a^2 = 2(x^2+y^2)` is equivalent to
   `2 r0^2 = r1^2+r2^2`.

## Proof

### Adjacent-chain containment

The generating words give

```text
E13 = E12 E23,             E31 = E32 E21,
E11 = E12 E21,             E22 = E21 E12,
E33 = E32 E23.
```

Together with the four supplied adjacent units, these are all nine matrix
units, so `A_adj = M3(C)`. In particular, the displayed `C`, `C^2`, and the
three Hermitian combinations `B0`, `B1`, and `B2` belong to `A_adj`. With
`Yij = i(Eji-Eij)` for `i<j`, the fixed orientation also gives

```text
B2 = Y12 + Y23 - Y13.
```

### Orthogonal cyclic projection

Let `Ad_C(H) = CHC^{-1}`. Since `Ad_C^3` is the identity,
`P_cyc = (I + Ad_C + Ad_C^2)/3` is idempotent and its image is the fixed
space of `Ad_C`, which is exactly the Hermitian commutant of `C`. Conjugation
by `C` is orthogonal for `<.,.>_R` by cyclicity of trace, and its inverse is
`Ad_C^2`. Hence the group average is self-adjoint. An idempotent self-adjoint
map is the orthogonal projector onto its image.

### Full Hermitian commutant

Write a general Hermitian matrix as

```text
H = [[d0,        x12-i y12, x13-i y13],
     [x12+i y12, d1,        x23-i y23],
     [x13+i y13, x23+i y23, d2       ]],
```

with nine real coordinates. Solving every real and imaginary entry of
`HC-CH = 0` gives

```text
d0 = d1 = d2 = a,
x12 = x13 = x23 = x,
y12 = y23 = y,
y13 = -y.
```

Therefore

```text
H = a B0 + x B1 + y B2,
```

with `a,x,y` free and real. This explicitly solves the full nine-real-variable
Hermitian commutant, proving both the stated span and dimension.

### Gram matrix and Riesz reconstruction

Direct multiplication using `C^3=I` and `Tr(C)=Tr(C^2)=0` yields

```text
<B0,B0>_R = 3,
<B1,B1>_R = 6,
<B2,B2>_R = 6,
<Bi,Bj>_R = 0  for i != j.
```

For `K = u0 B0 + u1 B1 + u2 B2`, real-linearity gives

```text
ell(K) = u0 r0 + u1 r1 + u2 r2
       = <(r0/3)B0 + (r1/6)B1 + (r2/6)B2, K>_R.
```

The Gram matrix is nonsingular, so this representative is unique. Conversely,
if `H = aB0+xB1+yB2`, then its trace responses are exactly
`(r0,r1,r2) = (3a,6x,6y)`, and the displayed reconstruction returns `H`.

Finally,

```text
a^2 - 2(x^2+y^2)
  = r0^2/9 - 2(r1^2+r2^2)/36
  = (2r0^2-r1^2-r2^2)/18.
```

The two cone equations are therefore equivalent, including the sign and the
factor of two.
