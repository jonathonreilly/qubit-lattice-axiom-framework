## Question

For a supplied Hermitian matrix `H in Herm(3)`, what finite-dimensional
information determines its average under the cyclic permutation generated by
`C`?

## Claim scope

This note proves an abstract finite-linear-algebra lemma:

1. the adjacent-chain path algebra contains the cyclic Hermitian basis
   `B0 = I`, `B1 = C + C^2`, and `B2 = i(C - C^2)`;
2. cyclic averaging is the exact projector from `Herm(3)` onto their real
   span;
3. the three Riesz/trace coordinates of a supplied Hermitian matrix uniquely
   reconstruct that projection; and
4. on a supplied cyclic Hermitian matrix, the stated Koide cone equation is
   algebraically equivalent to one equation among those coordinates.

The theorem begins with `H` already supplied. It does not derive `H`, the
functional that might produce it, or a physical interpretation of it.

## The adjacent-chain basis

Let `Eij` be the standard `3 x 3` matrix units. The adjacent generators
`E12`, `E23`, and their adjoints contain the long corners because

```text
E13 = E12 E23,
E31 = E32 E21.
```

With the fixed convention

```text
C   = E21 + E32 + E13,
C^2 = E12 + E23 + E31,
```

one has `C^3 = I` and `C^2 = C^dagger`. Therefore the same path algebra
contains

```text
B0 = I,
B1 = C + C^2,
B2 = i(C - C^2).
```

For `Yij = i(Eji - Eij)` with `i < j`, this convention gives the sign check

```text
B2 = Y12 + Y23 - Y13.
```

No carrier interpretation is needed for this containment statement.

## Exact cyclic projection

Define

```text
P_cyc(H) = (1/3) sum_{k=0}^2 C^k H C^{-k}.
```

Because this is the average over the order-three conjugation action,
`P_cyc^2 = P_cyc`. Its Hermitian image is the commutant of `C` inside
`Herm(3)`, namely

```text
span_R{B0, B1, B2}.
```

The real trace Gram matrix in this ordered basis is exactly

```text
G_ij = Re Tr(Bi Bj) = diag(3, 6, 6).
```

Consequently, for the supplied `H`, define its three real trace coordinates

```text
r0 = Re Tr(B0 H),
r1 = Re Tr(B1 H),
r2 = Re Tr(B2 H).
```

Orthogonality and the nonzero Gram entries give the unique reconstruction

```text
P_cyc(H) = (r0/3) B0 + (r1/6) B1 + (r2/6) B2.
```

These are Riesz/trace coordinates of the supplied matrix `H`. They are not an
identification of an arbitrary action derivative or microscopic functional
with `H`.

## Coordinate form of the Koide cone

For a supplied cyclic Hermitian amplitude matrix, write

```text
H_cyc = a B0 + x B1 + y B2.
```

The reconstruction formula gives

```text
a = r0/3,
x = r1/6,
y = r2/6.
```

Therefore

```text
a^2 = 2(x^2 + y^2)
```

is algebraically equivalent to

```text
2 r0^2 = r1^2 + r2^2.
```

This is an equivalence of coordinate equations. It is not a derivation of why
a supplied matrix should obey the cone equation, and it is not a selector.
