## Frozen finite input and import boundary

The theorem is conditional on one explicit finite support model. Its Hilbert
space and operators are

```text
H = C^4 tensor C^(3^3), with periodic boundary conditions,
gamma_j = sigma_y tensor sigma_j,
D = sum_j gamma_j tensor (T_j - T_j^dagger)/(2 i)
    + r I_4 tensor sum_j (2 I - T_j - T_j^dagger)/2,
r = 1,
U = [I_2 tensor exp(-i pi n.sigma/3)] tensor P,
n = (1,1,1)/sqrt(3),
P |x,y,z> = |z,x,y>.
```

The site permutation `P` has order three. Its spin lift satisfies `U^3 = -I`,
so `zeta = exp(i pi/3)` below is a spin-lift eigenvalue over the geometric
three-cycle, not an ordinary eigenvalue of an order-three matrix.

The Wilson form, spin lift, finite size, periodic boundary condition, and
`r = 1` are supplied definitions for this theorem. They are not derived from
the framework axioms. No charged-lepton masses, fitted Koide value, Koide
Frobenius-equipartition condition, physical selected-line identification, APS
eta value, or endpoint readout is used.

## Attempted bridge

The attempted algebraic bridge was

```text
D,U-generated joint spectral algebra A_DU
  -> rank-one projector on the zeta zero-mode sector.
```

That implication fails. The relevant common zero-mode eigenspace is

```text
M_zeta = {v : D v = 0 and U v = zeta v},
zeta = exp(i pi/3),
```

and the runner computes

```text
dim(M_zeta) = 2,
D restricted to M_zeta = 0,
U restricted to M_zeta = zeta I_2.
```

Because restriction is a star-algebra homomorphism, every element of
`A_DU = C*(D,U)` restricts to a scalar multiple of `I_2` on `M_zeta`.
Consequently `A_DU` contains no projector whose restriction to `M_zeta` has
rank one.

## Exact finite multiplicity check

The full zero-mode count does not rely only on floating-point diagonalization.
For periodic `L = 3`, every momentum component lies in
`{0, +2 pi/3, -2 pi/3}`. If `m` components are nonzero, then at `r = 1` the
Wilson scalar and squared kinetic magnitude are

```text
W_m = 3m/2,
|s_m|^2 = 3m/4.
```

The exact Clifford relations give momentum-block eigenvalues
`W_m +/- sqrt(|s_m|^2)`, each twice. For `m = 1,2,3`,

```text
W_m^2 - |s_m|^2 = 3m(3m - 1)/4 > 0,
```

so every nonconstant momentum block is invertible. The kernel is therefore
exactly the four-dimensional constant-site (`k = 0`) block. At `k = 0`, both
the kinetic and Wilson terms vanish, and the spin lift reduces to

```text
U_spin = I_2 tensor [I_2 - i(sigma_x + sigma_y + sigma_z)] / 2.
```

For `zeta = (1 + i sqrt(3))/2`, its exact spectral projector is

```text
P_zeta = (U_spin - conjugate(zeta) I_4)
         / (zeta - conjugate(zeta)).
```

The runner verifies symbolically that

```text
P_zeta^2 = P_zeta,
rank(P_zeta) = 2,
U_spin P_zeta = zeta P_zeta.
```

Thus `dim(M_zeta) = 2` exactly. The dense `108 x 108` diagonalization is a
separate numerical cross-check, not the proof of the multiplicity.

## Joint-algebra obstruction

Let `(psi_0, psi_1)` be any orthonormal basis of `M_zeta`.  For every
normalized pair `(a,b)`,

```text
psi(a,b) = a psi_0 + b psi_1
```

obeys the same equations

```text
D psi(a,b) = 0,
U psi(a,b) = zeta psi(a,b).
```

The runner samples a real one-parameter slice of this `CP^1` family. It also
extends a nontrivial `U(2)` rotation on `M_zeta` by the identity on its
orthogonal complement. The resulting unitary commutes with both `D` and `U`
while moving rank-one projectors inside `M_zeta`.

Here `canonical from the pair (D,U)` means equivariant under the full unitary
stabilizer of that pair, or, more narrowly, constructed as an element of
`A_DU`. Either definition excludes a rank-one selector: the stabilizer
contains the displayed `U(2)` action, and `A_DU|M_zeta = C I_2`.

The residual proved here is only

```text
RESIDUAL_EIGENLINE = rank_two_zeta_zero_mode_sector_not_split_by_D_U_generated_algebra
```

## Scope firewall

This is only a no-go inside `A_DU`. It is not a claim that the full finite
Wilson construction lacks a selector, and it makes no statement that a
Wilson route to a physical delta phase fails.

Indeed, the Clifford matrices used to build `D` provide the central volume
element (the chirality operator on this doubled representation)

```text
Gamma = -i gamma_1 gamma_2 gamma_3.
```

The runner verifies that `Gamma` commutes with `D` and `U` and has eigenvalues
`-1,+1` on `M_zeta`, so its spectral projectors split the doublet. Thus the
full Wilson/Clifford data evade the `A_DU`-only no-go. `Gamma` is outside
`A_DU` because its restriction is non-scalar. Whether either line has a
physical carrier or charged-lepton interpretation is a separate, unproved
claim.

The former ambient eta-proxy assertion is withdrawn from this note and from
the runner closeout.  That proxy applied `sign` to floating-point zero modes,
was sensitive to the Wilson parameter and numerical zero-mode signs, and is
not a derived mismatch with the APS value.  No `RESIDUAL_AMBIENT` is retained.

The former endpoint-lift discussion is also outside this repaired claim.  No
`RESIDUAL_ENDPOINT` or `RESIDUAL_TRIVIALIZATION` is used to establish the
rank-two non-selection result.

## Falsifiers

This joint-algebra no-go would fail if either of the following were exhibited:

- an element of `C*(D,U)` whose restriction to `M_zeta` is a rank-one
  projector;
- a demonstration that the `zeta` common eigenspace is actually
  one-dimensional for the stated finite periodic `L = 3`, `r = 1` matrices.

The displayed Clifford-volume split does not falsify the scoped statement: it
falsifies the broader statement that the full Wilson/Clifford construction has
no selector, which is why that broader statement is not made here.
