## Defined Toy Algebra

All statements below are definitions of the finite toy object being
studied.

- **(D1)** Defined two-channel source-response toy. Work in
  `V = C^2` with central label `Z = diag(1, -1)` and source coordinates
  `J_0 = (s + z, s - z)` for rational `s, z`. The local probe
  coefficient is `Y = (1, 1)`. For denominators nonzero, define
  ```text
  Q(s, z)  :=  (1/3) * ( 1  +  y_perp / y_plus ),
  y_plus   :=  1 / (1 + s + z),
  y_perp   :=  1 / (1 + s - z).
  ```
- **(D2)** Defined central `Z` expectation. For source-state channel
  weight `w ∈ [0, 1]`, define `<Z>(w) = 2w - 1`.
- **(D3)** Defined selected-line endpoint algebra. Work in a basis
  adapted to a selected line `L_chi ⊂ V`, with selected-line projector
  `P_chi = diag(1, 0)`. The selected-line endpoint algebra
  `End(L_chi)` is one-dimensional; the ambient endpoint algebra
  `End(V)` is four-dimensional.
- **(D4)** Defined based-endpoint section. The endpoint torsor shift is
  `c = 0`.
- **(D5)** Defined toy scalar and endpoint formula. Set
  `eta_toy = 2/9` and define
  ```text
  delta(s_chi, c)  :=  eta_toy * (1 - s_chi)  +  c,
  ```
  where `s_chi ∈ Q` is a spectator/ambient endpoint weight and `c ∈ Q`
  is the endpoint torsor shift.

None of `(D1)-(D5)` is a framework axiom or retained physical bridge
claim. They define the finite algebraic object for this bounded theorem.

## Algebraic Identities

Inside `(D1)-(D5)`, the following identities hold exactly in `Q`.

**(T1) Q zero-background identity.**
```text
Q(0, 0)  =  2 / 3.
```

**(T2) Q common-source invariance.** For any `s ∈ Q` with denominators
nonzero,
```text
Q(s, 0)  =  2 / 3.
```
That is, the common source background drops out of `Q`.

**(T3) Q traceless-background departure.** For any
`z ∈ Q \ {0}` with denominators nonzero,
```text
Q(0, z)  ≠  2 / 3.
```
Two specific exact counterdomains:
```text
Q(0,  1/4)   =  8 / 9,
Q(0, -1/4)   =  8 / 15.
```

**(T4) Z survives in the toy algebra.**
```text
Z^2          =  I,
<Z>(w)       =  2 w - 1,
<Z>(w) = 0   <=>   w = 1 / 2.
```
In particular, the central `Z` label is nonzero on every non-midpoint
source state and therefore distinguishes such states inside the toy.

**(T5) Selected-line endpoint dimensionality and projector identities.**
```text
dim End(L_chi)  =  1,
dim End(V)      =  4,
P_chi^2         =  P_chi,
P_chi * P_chi   =  P_chi  (selected channel weight 1, spectator weight 0).
```

**(T6) delta selected-line toy value.** With the selected-line and based
choices `(s_chi, c) = (0, 0)`,
```text
delta(0, 0)  =  eta_toy  =  2 / 9.
```

**(T7) delta ambient toy countermodels.** Varying the toy arguments gives
```text
delta(0, 0)     =  2 / 9      (closing endpoint),
delta(1, 0)     =  0          (spectator endpoint),
delta(1/2, 0)   =  1 / 9      (mixed endpoint),
delta(0, 1/9)   =  1 / 3      (shifted endpoint, c = 1/9).
```
In particular, the closing value `delta = 2/9` is not the only value of
`delta` reachable from the endpoint formula; selecting
`(s_chi, c) = (0, 0)` is load-bearing inside the toy.

**(T8) Q toy selection boundary.** Tracking `<Z>` on source states does
not force `Q = 2/3`: `Q(0, z) ≠ 2/3` for `z ≠ 0` while non-midpoint
states still have nonzero `<Z>`. Therefore, inside the toy, `Q = 2/3`
requires the additional selection `z = 0` or equivalently the
`Z`-erasure subdomain.

**(T9) delta toy selection boundary.** The value `delta = 2/9` requires
the joint endpoint selection `(s_chi, c) = (0, 0)`. The ambient
countermodels in `(T7)` show this is not the only value reachable from
the endpoint formula.

## Proof

Pure rational arithmetic in `Q`.

**Proof of (T1).** Substituting `s = z = 0`:
`y_plus = y_perp = 1 / 1 = 1`, so
`Q = (1/3) * (1 + 1) = 2/3`. ∎

**Proof of (T2).** For `z = 0`: `y_plus = y_perp = 1 / (1 + s)`, so
`y_perp / y_plus = 1`, hence `Q = 2/3`. ∎

**Proof of (T3).** For `s = 0`,
`y_plus = 1 / (1 + z), y_perp = 1 / (1 - z)`, so
`y_perp / y_plus = (1 + z) / (1 - z)` and
`Q = (1/3) * (1 + (1 + z) / (1 - z)) = (1/3) * (2 / (1 - z))
   = 2 / (3 (1 - z))`. For `z ≠ 0` this is not `2/3` because equality
would require `1 - z = 1`. The two concrete substitutions are direct:
`Q(0, 1/4) = 2 / (3 * 3/4) = 8/9`, and
`Q(0, -1/4) = 2 / (3 * 5/4) = 8/15`. ∎

**Proof of (T4).** Direct computation:
`Z * Z = diag(1, -1) * diag(1, -1) = diag(1, 1) = I`;
`<Z>(w) = w * 1 + (1 - w) * (-1) = 2 w - 1`;
`2 w - 1 = 0 <=> w = 1/2`. ∎

**Proof of (T5).** `End(L_chi)` is one-dimensional because `L_chi` is a
line in `V`; `End(V) = End(C^2)` is four-dimensional; idempotency of
`P_chi = diag(1, 0)` is direct: `diag(1, 0) * diag(1, 0) = diag(1, 0)`.
Selected channel weight `e_1^T P_chi e_1 = 1` and spectator weight
`e_2^T P_chi e_2 = 0`. ∎

**Proof of (T6).** `(s_chi, c) = (0, 0)` gives
`delta(0, 0) = eta_toy * (1 - 0) + 0 = eta_toy = 2/9`. ∎

**Proof of (T7).** Direct substitution:
`delta(0, 0) = 2/9 * 1 + 0 = 2/9`;
`delta(1, 0) = 2/9 * 0 + 0 = 0`;
`delta(1/2, 0) = 2/9 * 1/2 + 0 = 1/9`;
`delta(0, 1/9) = 2/9 * 1 + 1/9 = 2/9 + 1/9 = 3/9 = 1/3`. ∎

**Proof of (T8).** From `(T3)`, `Q(0, z) ≠ 2/3` for any
`z ∈ Q \ {0}` with denominators nonzero. From `(T4)`, every
non-midpoint source state has `<Z> ≠ 0`. Hence tracking `<Z>` does not
entail `z = 0`; an extra selection of `z = 0` is required for the
`Q = 2/3` identity. ∎

**Proof of (T9).** From `(T7)`, the four listed countermodels give four
distinct values `{2/9, 0, 1/9, 1/3}`. Hence the endpoint formula alone
does not entail `delta = 2/9`; the joint selection
`(s_chi, c) = (0, 0)` is required. ∎
