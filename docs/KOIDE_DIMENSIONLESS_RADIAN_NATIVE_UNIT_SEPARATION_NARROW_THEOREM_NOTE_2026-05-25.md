## 1. Claim scope

Let `U_1, ..., U_6` denote the six native angular constructions
enumerated on the qubit-on-`Z^3` substrate (equivalently `Cl(3)/Z^3`) as
candidate replacements for the radian unit (full list in §3). Each `U_i`
is, on that substrate, a fixed real number `alpha_i` of the form
`alpha_i = q_i * pi` with `q_i in Q` and `q_i != 0`.

Let

```text
r  :=  2 / 9    (the pure rational, in Q).
```

The following identities hold:

- **(S1) Native-unit form.** Each `alpha_i` is exactly `q_i * pi` for a
  fixed nonzero rational `q_i`. The six values are:

  ```text
  alpha_1  =  2  * pi          (cycle, one full revolution),
  alpha_2  =  (2/3) * pi       (Z_3-step, lattice-translation per-step),
  alpha_3  =  (2/9) * pi       (Plancherel-step, per Plancherel slot),
  alpha_4  =  pi               (Bargmann closed-orbit, three-step equator),
  alpha_5  =  (2/3) * pi       (character-step, per chi_omega increment),
  alpha_6  =  (1/3) * pi       (selected-line CP^1 Berry-per-step).
  ```

- **(S2) No-rational-solution lemma.** For every `i in {1,...,6}`, there
  is no nonzero rational `c_i in Q` such that

  ```text
  c_i * alpha_i  =  r    (in R).                                       (1)
  ```

  Equivalently, the equation `c_i * q_i * pi = 2/9` has no rational
  solution `c_i`. In particular, `r != alpha_i` and `r != q * alpha_i`
  for every rational `q != 0`.

- **(S3) Separation theorem.** Therefore, for every `i in {1,...,6}`:

  ```text
  r  notin  Q . alpha_i                                                (2)
  ```

  where `Q . alpha_i := {q * alpha_i : q in Q}`. The radian-valued
  number `r = 2/9 rad` is not expressible as any nonzero rational
  multiple of any of the six native-unit values `alpha_i`.

- **(S4) What S1-S3 do not do.** The separation (S3) does **not** close
  the radian-bridge postulate `P`. It pins, positively and precisely,
  what `P` would have to supply: an identification of the pure rational
  `2/9` with a radian phase that is structurally irreducible from the
  six native-unit constructions enumerated. The status of `P` is
  unchanged by this narrow theorem; the retained no-go
  `KOIDE_A1_RADIAN_BRIDGE_IRREDUCIBILITY_AUDIT_NOTE_2026-04-24.md`
  remains the authority on `P` itself.

Facts (S1)-(S4) are exact algebraic identities about the six listed
radian values and the pure rational `2/9`. The proof is direct
arithmetic plus transcendence of `pi` (admitted-context standard
real-analysis fact; see §4).

## 5. Proof

### 5.1 (S1) Native-unit values

The six native angular constructions on `Cl(3)/Z^3` produce the
following six radian values (by definition of each construction):

1. **Cycle** = one full revolution = `2 pi` rad. So `alpha_1 = 2 * pi`,
   `q_1 = 2`.
2. **Z_3-step** = lattice-translation per-step on the three-element
   cyclic group = `2 pi / 3` rad. So `alpha_2 = (2/3) * pi`,
   `q_2 = 2/3`.
3. **Plancherel-step** = per Plancherel slot on the `d^2 = 9` real-
   dimensional `Herm_3` Plancherel-pairing surface = `2 pi / 9` rad.
   So `alpha_3 = (2/9) * pi`, `q_3 = 2/9`.
4. **Bargmann closed-orbit** = three-step equatorial Bargmann phase on
   `CP^1` = `pi` rad. So `alpha_4 = pi`, `q_4 = 1`.
5. **Character-step** = per `chi_omega` increment on the `d = 3`
   character group = `2 pi / d = 2 pi / 3` rad. So `alpha_5 = (2/3) * pi`,
   `q_5 = 2/3`.
6. **Selected-line CP^1 Berry-per-step** = per step on the selected
   line under the retained Berry connection `A = d theta`, with the
   one-third-of-`pi` step from the closed-orbit / Z_3 decomposition
   = `pi / 3` rad. So `alpha_6 = (1/3) * pi`, `q_6 = 1/3`.

Each `q_i` is a fixed nonzero rational; each `alpha_i` is a fixed
nonzero element of `Q * pi`. ∎

### 5.2 (S2) No-rational-solution lemma

Fix `i in {1,...,6}` and assume, for contradiction, there exists a
nonzero rational `c_i in Q \ {0}` such that
`c_i * alpha_i = 2/9`. Then

```text
c_i * q_i * pi  =  2 / 9.                                              (3)
```

Since `c_i in Q \ {0}` and `q_i in Q \ {0}`, the product `c_i * q_i`
is a nonzero rational, call it `t_i := c_i * q_i in Q \ {0}`. Then
(3) reads `t_i * pi = 2/9`, i.e.

```text
pi  =  (2 / 9) / t_i  =  2 / (9 t_i)  in  Q.                          (4)
```

But (4) contradicts the transcendence of `pi`: `pi` is not a rational
number. Hence no such `c_i` exists. ∎

### 5.3 (S3) Separation theorem

By (S2), for every `i in {1,...,6}`, the equation `c_i * alpha_i = r`
with `c_i in Q` has no nonzero rational solution. Setting `c_i = 0`
gives `c_i * alpha_i = 0 != 2/9 = r`. Hence `r notin Q . alpha_i`
where `Q . alpha_i = {q * alpha_i : q in Q}`. ∎

### 5.4 (S4) Scope of the separation

The separation (S3) establishes that, on the six native-unit list of
§3, the pure rational `2/9` is not reachable by any `Q`-linear
combination of any single native unit. It does **not** establish:

- that `2/9 = phi` (radian) holds physically — the radian-bridge
  postulate `P` (already named in the existing retained no-go) is
  precisely the additional structure required to make that
  identification;
- that no further-enumerated native unit could fail this separation —
  the claim is restricted to the six explicit `alpha_i` listed in §3;
- any PDG-comparator outcome — no PDG value is consumed.

This narrow theorem is a positive statement about the structural
algebraic relationship between `Q` and the six specific points
`{alpha_1,...,alpha_6}` in `Q . pi`. It pins precisely what the
radian-bridge postulate `P` must contribute. ∎

Primary runner: [`scripts/audit_companion_koide_dimensionless_radian_native_unit_separation_2026_05_25.py`](../scripts/audit_companion_koide_dimensionless_radian_native_unit_separation_2026_05_25.py)
verifies via sympy exact symbolic arithmetic that:

1. **(S1) Six native-unit values defined exactly in `Q * pi`.** For
   each `i in {1,...,6}`, construct `alpha_i = q_i * pi` as a sympy
   `Mul(Rational, pi)`. Verify that `q_i` is a nonzero rational and
   that `alpha_i` simplifies to `q_i * pi` symbolically.

2. **(S2) No-rational-solution lemma for each native unit.** For
   each `i in {1,...,6}`, solve `c_i * alpha_i = 2/9` symbolically and
   inspect the formal solution. Verify that the only formal solution is
   `c_i = 2/(9 q_i pi)` which is NOT a rational-domain solution (it
   contains `pi` in the denominator). Verify
   symbolically that `simplify(c_i * alpha_i - 2/9) != 0` for every
   nonzero rational test value `c_i`.

3. **(S3) Separation theorem: 2/9 not in Q . alpha_i for any i.** For
   each `i in {1,...,6}` and for a list of nonzero rational test
   coefficients `c in Q \ {0}`, verify `c * alpha_i != 2/9`
   symbolically by computing `simplify(c * alpha_i - 2/9)` and
   checking it does NOT reduce to zero. The expression
   `c * q_i * pi - 2/9` simplifies to a nonzero element of `Q * pi + Q`
   (a non-trivial linear combination of `pi` and `1`), which sympy
   does not collapse to zero.

4. **Numerical disagreement at high precision.** For each `i in
   {1,...,6}`, compute `float(alpha_i)` and `float(2/9)` to high
   precision (50 decimal digits via `sp.N(..., 50)`) and verify that
   `alpha_i != 2/9` numerically by a margin many orders of magnitude
   larger than floating-point precision.

5. **Symbolic transcendence-style witness.** For each `i`, verify that
   sympy reports `simplify(alpha_i - 2/9)` as a sympy expression of
   the form `q_i * pi - 2/9` (not zero). Verify that
   `is_rational` on `alpha_i` returns `False` (since `pi` is not
   rational in sympy).

6. **Counter-example positive control.** Verify that the trivial case
   `c_i = 0` gives `c_i * alpha_i = 0 != 2/9`. Verify that the
   "literal-rational-as-radian" identification (i.e., interpreting
   `2/9` directly as a radian value without a native unit) is
   precisely the missing primitive `P`, not one of the six native
   units.

7. **Sanity: each native unit is enumerated.** Verify that the six
   `alpha_i` produce five distinct values in `R` (since
   `alpha_2 = alpha_5 = (2/3) pi`). The narrow theorem holds whether
   the six unit-constructions are distinct as rational multiples of
   `pi` or coincide; the separation is per-unit.

8. **Boundary: q_i = 0 excluded.** Verify that none of the six
   `q_i` equals zero (which would collapse `alpha_i = 0` and make
   the separation trivial / vacuous). The rationals `2, 2/3, 2/9,
   1, 2/3, 1/3` are all nonzero.
