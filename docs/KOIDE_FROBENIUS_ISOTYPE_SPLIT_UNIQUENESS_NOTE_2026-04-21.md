## No-Go Statement

On `Herm(3)`, the Ad-invariant symmetric bilinear forms generated by the trace
and scalar trace are

```text
B_{alpha,beta}(A,B) = alpha Tr(AB) + beta tr(A) tr(B).
```

On the scalar/traceless decomposition

```text
A = A_s + A_t,
A_s = tr(A) I / 3,
tr(A_t) = 0,
```

the quadratic form is diagonal:

```text
B_{alpha,beta}(A,A)
  = (alpha + 3 beta) Tr(A_s^2) + alpha Tr(A_t^2).
```

Thus it is positive definite exactly when

```text
alpha > 0,
alpha + 3 beta > 0.
```

The Frobenius normalization is the point `beta = 0`, where the scalar and
traceless weights are equal. But the positive-definite region contains many
points with `beta != 0`. For example, `alpha = beta = 1` has scalar weight
`4`, traceless weight `1`, is positive definite, is Ad-invariant, and differs
from Frobenius on trace-bearing matrices.

Therefore PD + Ad-invariance + scalar/traceless orthogonality cannot derive
the Frobenius isotype-weight ratio `w_scalar / w_traceless = 1`.
