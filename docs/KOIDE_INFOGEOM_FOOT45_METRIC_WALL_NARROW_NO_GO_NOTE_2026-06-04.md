## 0. Setup

cited Koide notes. The operator class is

```text
H = a I + b C + \bar b C^2,        C^3 = I,        C^2 = C^dagger,
```

```text
v_g = a + 2 beta cos(phi + 2 pi g / 3),        g = 0,1,2.               (0.1)
```

```text
Q := (sum_g v_g^2)/(sum_g v_g)^2
```

## 1. Result

### 1.1 Eigenstate quantum geometric tensor

For every circulant `H` in the class above, the Fourier character basis
diagonalizes `H` independently of `a` and `b`. Therefore the spectral projectors
are `b`-constant. For a band eigenstate `|n(b)>`,

```text
Q_ij^(n) = <partial_i n | (1 - |n><n|) | partial_j n>
```

vanishes exactly on the non-degenerate stratum:

```text
Re Q_ij^(n) = 0        (Fubini-Study metric),
-2 Im Q_ij^(n) = 0     (Berry curvature).
```

The runner verifies the fixed-DFT diagonalization and a finite-difference QGT
bound of `max |QGT component| = 1.89e-20`. At the measure-zero doublet
degeneracy, the in-doublet basis is ambiguous, but the doublet projector remains
constant, so the non-abelian projector-level QGT is still zero.

This closes only the native circulant eigenstate-bundle metric route. It does
not rule out an operator deformation off the circulant class, a non-metric
state-selection principle, or a chiral/matter-action route.
