## T1 -- the kappa flow class

**Statement.** Agreement-conditioned independent double registration on the
normalized two-cell bookkeeping

```text
(p_s, p_d) = (a^2, kappa|b|^2) / (a^2 + kappa|b|^2),   kappa > 0,
```

induces `x -> x^2` on the odds coordinate `x = p_d/p_s = kappa r`
(`r = |b|^2/a^2`), hence the induced flow on `r` is `f(r) = kappa r^2`. The
complete fixed set on `[0, oo]` is `{0, 1/kappa, oo}`; the interior fixed point
is unique at `r* = 1/kappa`; and the multiplier is `|f'(r*)| = 2` for every
`kappa` (kappa-independent).

**Proof (inline; the G2 algebra reproven, not cited).**

*Odds coordinate.* With the stated normalization, `p_s = a^2/(a^2 + kappa|b|^2)`
and `p_d = kappa|b|^2/(a^2 + kappa|b|^2)`, so

```text
x = p_d/p_s = kappa|b|^2 / a^2 = kappa r.                        [check 1]
```

*Induced odds map.* Premise A composes the bookkeeping by
`p_i' = p_i^2/(p_s^2 + p_d^2)`. The normalizing sum cancels in the ratio:

```text
x' = p_d'/p_s' = (p_d^2)/(p_s^2) = (p_d/p_s)^2 = x^2.            [check 2]
```

This holds for any `(p_s, p_d)`, hence for any `kappa`: the odds map is `x -> x^2`
independent of the bookkeeping weight.

*Induced r-flow.* Converting back through `x = kappa r`,

```text
r' = x'/kappa = x^2/kappa = (kappa r)^2/kappa = kappa r^2,       [check 3]
```

so `f(r) = kappa r^2`.

*Fixed set.* Solving `kappa r^2 = r` on the real line gives the finite fixed
points `{0, 1/kappa}` [check 4]. Under the projective chart `s = 1/r`, the flow
conjugates to `s -> s^2/kappa`, whose fixed point `s = 0` is the endpoint
`r = oo` [check 5]. The complete fixed set on `[0, oo]` is therefore
`{0, 1/kappa, oo}`, and the unique interior (`0 < r < oo`) fixed point is
`r* = 1/kappa` [check 6].

*Multiplier is kappa-independent.* Differentiating, `f'(r) = 2 kappa r`, so
`f'(1/kappa) = 2` for every `kappa` [check 7]. The structural reason is
conjugacy: with the linear change of coordinate `h(r) = kappa r`,

```text
(h o f o h^{-1})(x) = kappa * f(x/kappa) = kappa * kappa (x/kappa)^2 = x^2,
```

so `f` is linearly conjugate to the square map `sq(x) = x^2` [check 8]. A
conjugacy preserves the multiplier at a fixed point, and `sq'(1) = 2`; hence
`|f'(r*)| = 2` for the whole class. **This feeds the durability chain's
knife-edge (a repelling interior fixed point with multiplier 2) unchanged for
every kappa** -- the sharpness of the fixed point is a property of the flow
class, not of any particular bookkeeping weight. QED.
