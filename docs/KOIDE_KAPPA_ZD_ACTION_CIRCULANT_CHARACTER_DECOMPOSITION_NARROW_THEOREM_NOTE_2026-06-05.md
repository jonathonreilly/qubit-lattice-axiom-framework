## Background: why the action must be fixed (and the shift trap)

A circulant matrix `M = sum_{k=0}^{d-1} a_k C^k` commutes with the cyclic shift
`C`. Therefore conjugation by the shift,

```text
M  -->  C M C^{-1}  =  M,                                                  (S)
```

is the **identity map** on `Herm_circ(d)` and carries **no** character
structure. The real-isotype labels (trivial / doublet / sign) used to count
`(T4)` of the target row are therefore **not** the orbits of shift-conjugation.
They are the isotypes of a different, genuinely nontrivial `Z_d` action, fixed
below. This note makes that action explicit so the character-`k` labelling is a
theorem rather than an unstated convention.

## Statement

Let `d >= 2`. Let `C` be the standard `d x d` cyclic permutation matrix with
`C[i, (i+1) mod d] = 1`, so `C^d = I` and `C` is unitary
(`C^{-1} = C^H = C^{d-1}`). Let `omega = e^{2 pi i / d}` and let

```text
Omega  =  diag(1, omega, omega^2, ..., omega^{d-1}).                       (1)
```

`Omega` is unitary with `Omega^d = I`. Define the `Z_d` action on the complex
matrix algebra `M_d(C)` (and by restriction on `Herm_circ(d)`) by

```text
rho(M)  :=  Omega^{-1} M Omega.                                            (2)
```

A general circulant Hermitian matrix is

```text
H  =  sum_{k=0}^{d-1} a_k C^k,    a_0 in R,    a_{d-k} = conj(a_k).         (3)
```

(The constraint `a_{d-k} = conj(a_k)` is exactly Hermiticity: `C^H = C^{d-1}`,
so `(a_k C^k)^H = conj(a_k) C^{d-k}`, and `H^H = H` pairs the `C^k` and
`C^{d-k}` coefficients.)

**Conclusion (C1) (the action is a faithful `Z_d` representation).** `rho` as
defined in `(2)` satisfies `rho(I) = I`, `rho(M N) = rho(M) rho(N)`, and
`rho^d = id`. It preserves Hermiticity (since `Omega` is unitary) and preserves
the circulant subspace (since `Omega^{-1} C^k Omega` is a multiple of `C^k`,
by `(C2)`). Hence `rho` restricts to a representation of `Z_d` on the real
vector space `Herm_circ(d)`. The generator `rho` is **not** the identity for
`d >= 2` (it has eigenvalue `omega != 1` on the line `C . C^1`), in contrast to
shift-conjugation `(S)`.

**Conclusion (C2) (the `C^k` line carries character `k`).** For each
`k in {0, 1, ..., d-1}`,

```text
rho(C^k)  =  Omega^{-1} C^k Omega  =  omega^k C^k.                         (4)
```

Hence the complex line `C . C^k subset M_d(C)` is the eigenspace of `rho` with
eigenvalue `omega^k`, i.e. it carries the **character-`k`** irrep of `Z_d`.

**Conclusion (C3) (Hermitian conjugate pairs are real doublets).** Fix `k` with
`1 <= k <= d-1` and `k != d-k mod d`. Define the two Hermitian circulants

```text
B_1^{(k)}  :=  C^k + C^{d-k},    B_2^{(k)}  :=  i (C^k - C^{d-k}).         (5)
```

Both lie in `Herm_circ(d)`, and the real 2-plane `V_k := span_R{B_1^{(k)},
B_2^{(k)}}` is `rho`-invariant. In the ordered real basis `(B_1^{(k)},
B_2^{(k)})`, `rho` acts as the planar rotation

```text
rho |_{V_k}  =  [[ cos(2 pi k / d),  -sin(2 pi k / d) ],
                 [ sin(2 pi k / d),   cos(2 pi k / d) ]].                  (6)
```

This is the real 2-dimensional irrep of `Z_d` realizing the conjugate pair
character-`k` (+) character-`(d-k)` = character-`k` (+) conj(character-`k`). The
Hermitian coefficient constraint `a_{d-k} = conj(a_k)` is exactly the statement
that `(a_k C^k + a_{d-k} C^{d-k})` lies in `V_k`: writing
`a_k = p + i q` with `p = Re(a_k)`, `q = Im(a_k)` in `R`, one has
`a_k C^k + conj(a_k) C^{d-k} = p B_1^{(k)} + q B_2^{(k)}` (verified exactly in
the runner).

**Conclusion (C4) (even `d`: the `k = d/2` sign irrep; `k = 0` trivial).** If
`d` is even, then `omega^{d/2} = -1` and the single Hermitian basis matrix
`C^{d/2}` (real symmetric) spans a 1-dimensional `rho`-invariant line on which

```text
rho(C^{d/2})  =  - C^{d/2},                                                (7)
```

the **sign irrep** of `Z_d`. The line `R . I = R . C^0` is fixed,
`rho(I) = I`, the **trivial irrep**.

**Conclusion (C5) (real-irrep multiplicity and dimension count).** As a real
`Z_d`-representation,

```text
Herm_circ(d)  =  (R . I)  (+)  ( (+)_{k=1}^{floor((d-1)/2)} V_k )
                 (+)  (R . C^{d/2} if d even),                             (8)
```

with real-irrep multiplicities

```text
(trivial, doublets, sign)  =  (1, floor((d-1)/2), [d even]),              (9)
```

so the real dimension is

```text
1  +  2 . floor((d-1)/2)  +  [d even]  =  d  =  dim_R Herm_circ(d).       (10)
```

The pattern `(trivial, doublets, sign) = (1, (1,), 0)` (one trivial, one
doublet, no sign) holds iff `floor((d-1)/2) = 1` and `d` is odd, i.e. **iff
`d = 3`** among `d in {2, 3, 4, 5, 6}`.

## Proof

**(C1).** `rho(I) = Omega^{-1} I Omega = I`. For products,
`rho(M N) = Omega^{-1} M N Omega = (Omega^{-1} M Omega)(Omega^{-1} N Omega) =
rho(M) rho(N)`. Iterating `(2)`, `rho^n(M) = Omega^{-n} M Omega^{n}`, and since
`Omega^d = diag(omega^{0 . d}, ..., omega^{(d-1) d}) = I`, we get
`rho^d = id`. Unitarity of `Omega` gives `rho(M)^H = Omega^{-1} M^H Omega =
rho(M^H)`, so `rho` maps Hermitian to Hermitian. Circulant-preservation and the
non-triviality of the generator follow from `(C2)`.

**(C2).** `Omega` is diagonal: `Omega_{jj} = omega^{j}`. The shift `C` has
entries `C_{i, i+1} = 1` (indices mod `d`), and `C^k` has entries
`(C^k)_{i, i+k} = 1` (mod `d`), all other entries zero. Then

```text
(Omega^{-1} C^k Omega)_{i, i+k}
   =  (Omega^{-1})_{ii} (C^k)_{i, i+k} (Omega)_{i+k, i+k}
   =  omega^{-i} . 1 . omega^{i+k}
   =  omega^{k},
```

independent of `i`, and all other entries vanish (since `C^k` is supported only
on the `(i, i+k)` diagonal and `Omega^{-1}, Omega` are diagonal). Hence
`Omega^{-1} C^k Omega = omega^k C^k`, which is `(4)`. In particular the line
`C . C^k` is `rho`-invariant with eigenvalue `omega^k`, i.e. character `k`.

**(C3).** Both `B_1^{(k)}` and `B_2^{(k)}` are Hermitian: `(C^k)^H = C^{d-k}`,
so `(C^k + C^{d-k})^H = C^{d-k} + C^k = B_1^{(k)}`, and
`(i(C^k - C^{d-k}))^H = -i(C^{d-k} - C^k) = i(C^k - C^{d-k}) = B_2^{(k)}`. They
are circulant by construction. Using `(C2)` with characters `omega^k` on `C^k`
and `omega^{d-k} = omega^{-k} = conj(omega^k)` on `C^{d-k}`, set
`t = 2 pi k / d`, so `omega^k = cos t + i sin t`:

```text
rho(B_1^{(k)})  =  omega^k C^k + omega^{-k} C^{d-k}
   =  cos t (C^k + C^{d-k}) + i sin t (C^k - C^{d-k})
   =  cos t . B_1^{(k)} + sin t . B_2^{(k)},
rho(B_2^{(k)})  =  i ( omega^k C^k - omega^{-k} C^{d-k} )
   =  i [ cos t (C^k - C^{d-k}) + i sin t (C^k + C^{d-k}) ]
   =  - sin t . B_1^{(k)} + cos t . B_2^{(k)}.
```

These are exactly the columns of the rotation matrix `(6)`. The 2-plane `V_k`
is thus `rho`-invariant, and `rho|_{V_k}` is rotation by `t = 2 pi k / d`, the
standard real 2-dimensional irrep of `Z_d` (irreducible over `R` whenever
`omega^k` is not real, i.e. `k != 0, d/2`). Finally, with `a_k = p + i q`
(`p, q in R`), `a_k C^k + conj(a_k) C^{d-k} = (p + i q) C^k + (p - i q) C^{d-k}
= p (C^k + C^{d-k}) + q . i(C^k - C^{d-k}) = p B_1^{(k)} + q B_2^{(k)} in V_k`,
so the Hermiticity constraint `a_{d-k} = conj(a_k)` is precisely membership in
`V_k`.

**(C4).** If `d` is even, `omega^{d/2} = e^{i pi} = -1`. `C^{d/2}` is its own
Hermitian conjugate (`(C^{d/2})^H = C^{d - d/2} = C^{d/2}`) and is real (its
entries are `0/1`), so it spans a real line. By `(C2)`,
`rho(C^{d/2}) = omega^{d/2} C^{d/2} = - C^{d/2}`, the sign irrep. The `k = 0`
case is `rho(I) = omega^0 I = I`, the trivial irrep.

**(C5).** A Hermitian circulant is parametrized by `a_0 in R` (one real
coordinate, trivial irrep), one complex `a_k` for each conjugate pair
`{k, d-k}` with `1 <= k < d/2` (two real coordinates each, doublet `V_k`), and
(if `d` even) one real `a_{d/2}` (one real coordinate, sign irrep). The number
of conjugate pairs is `floor((d-1)/2)`. Summing real dimensions:
`1 + 2 floor((d-1)/2) + [d even]`. For `d` even, `2 . (d-2)/2 + 1 + 1 = d`; for
`d` odd, `2 . (d-1)/2 + 1 = d`. Either way the total is `d = dim_R
Herm_circ(d)`, and the decomposition `(8)` is the isotypic decomposition under
`rho`. The pattern `(1, (1,), 0)` requires `floor((d-1)/2) = 1` (so `d in
{3, 4}`) and `d` odd, leaving `d = 3` uniquely among `{2, 3, 4, 5, 6}`. The
full table is

```text
d = 2:  (1, (),     1),    dim = 1 + 0 + 1 = 2,
d = 3:  (1, (1,),   0),    dim = 1 + 2 + 0 = 3,
d = 4:  (1, (1,),   1),    dim = 1 + 2 + 1 = 4,
d = 5:  (1, (1,1),  0),    dim = 1 + 4 + 0 = 5,
d = 6:  (1, (1,1),  1),    dim = 1 + 4 + 1 = 6.
```

QED.
