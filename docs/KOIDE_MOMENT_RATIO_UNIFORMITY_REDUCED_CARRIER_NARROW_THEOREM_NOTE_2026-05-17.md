## Statement

Let `rho_+, rho_perp` be positive real symbols (the admitted SO(2)
frame-quotient carrier on the charged-lepton scalar lane, per parent
§2.2 admission). Let `a in R, b in C` be the circulant coordinates of
`H = a I + b C + bbar C^2 in Herm_circ(3)`, with `C` the standard
3 x 3 cyclic shift. Let `E_+, E_perp` be the canonical block-total
Frobenius coordinates defined by the retained narrow theorem
`koide_kappa_block_total_frobenius_algebraic_narrow_theorem_note_2026-05-10`
(T2):
```text
(I2)   E_+(H)     :=  || pi_+(H) ||_F^2     =  3 a^2,
       E_perp(H)  :=  || pi_perp(H) ||_F^2  =  6 |b|^2.
```
Impose the definitional relation between the admitted carrier and the
retained Frobenius coordinates:
```text
(I3)   rho_+^2     =  E_+,
       rho_perp^2  =  E_perp.
```
Impose the positive total-power constraint
```text
(I4)   rho_+^2 + rho_perp^2  =  E_tot,   E_tot > 0.
```
Define the reduced-carrier log-volume functional
```text
(D1)   S_rho (rho_+, rho_perp)  :=  log rho_+ + log rho_perp.
```
Then the constrained extremum of `S_rho` under `(I4)` has unique
interior positive critical point
```text
(P1)   rho_+^*  =  rho_perp^*  =  sqrt(E_tot / 2),
```
the critical point is the unique strict maximum of `S_rho` on the
positive-orthant slice `{rho_+, rho_perp > 0 : rho_+^2 + rho_perp^2 = E_tot}`,
and at the critical point
```text
(P2)   E_+  =  E_perp  =  E_tot / 2,
```
equivalently via `(I2)`,
```text
(P3)   3 a^2  =  6 |b|^2,   i.e.   a^2  =  2 |b|^2,
       kappa  :=  a^2 / |b|^2  =  2.
```
Moreover, the reduced-carrier extremum problem `(S_rho, (I4))` is
monotone-reparametrization equivalent to the retained Frobenius-carrier
extremum problem `(S_E, (I5))` defined by
```text
(D2)   S_E (E_+, E_perp)  :=  log E_+ + log E_perp,
(I5)   E_+ + E_perp  =  E_tot,
```
already certified by `koide_kappa_block_total_frobenius_algebraic_narrow_theorem_note_2026-05-10`
(T3). The two problems share a one-to-one positive-monotone
substitution `(rho_+, rho_perp) <-> (E_+, E_perp) = (rho_+^2, rho_perp^2)`,
related functionals `S_rho = (1/2) S_E`, identical constraint set, and
identical critical point in the shared positive orthant.

## Proof

`(P1)`. The constrained extremum of `S_rho = log rho_+ + log rho_perp`
on `{rho_+^2 + rho_perp^2 = E_tot, rho_+ > 0, rho_perp > 0}` has
Lagrangian
```text
L  =  log rho_+ + log rho_perp - lambda (rho_+^2 + rho_perp^2 - E_tot).
```
Stationary equations:
```text
partial_L / partial rho_+    =  1 / rho_+    - 2 lambda rho_+    = 0,
partial_L / partial rho_perp =  1 / rho_perp - 2 lambda rho_perp = 0.
```
Multiplying through by `rho_+` (resp. `rho_perp`):
```text
1  =  2 lambda rho_+^2,
1  =  2 lambda rho_perp^2.
```
Hence `rho_+^2 = rho_perp^2 = 1 / (2 lambda)`. Substituting into the
constraint:
```text
1 / lambda  =  E_tot,   lambda  =  1 / E_tot,
```
so `rho_+^2 = rho_perp^2 = E_tot / 2`, and since both are required
positive, `rho_+ = rho_perp = sqrt(E_tot / 2)`. Uniqueness in the
positive orthant follows from strict concavity of `S_rho`: the Hessian
of `S_rho` on the unconstrained `(rho_+, rho_perp) > 0` orthant is
```text
Hess(S_rho)  =  diag(-1/rho_+^2, -1/rho_perp^2),
```
both diagonal entries strictly negative, so `S_rho` is strictly concave;
the constraint slice is convex; hence the critical point is the unique
strict maximum on the slice.

`(P2)`. By `(I3)`, `E_+ = rho_+^{*2} = E_tot/2` and
`E_perp = rho_perp^{*2} = E_tot/2`, hence `E_+ = E_perp = E_tot/2`.

`(P3)`. By `(I2)`, `E_+ = 3 a^2 = E_tot/2` and `E_perp = 6 |b|^2 = E_tot/2`,
so `3 a^2 = 6 |b|^2`, i.e. `a^2 = 2 |b|^2`, i.e.
`kappa := a^2 / |b|^2 = 2`.

`(Reparametrization equivalence).` Under the positive-monotone
substitution `E_i = rho_i^2` (with `rho_i > 0`, `E_i > 0`),
```text
S_rho (rho_+, rho_perp)  =  log rho_+ + log rho_perp
                         =  (1/2)(log rho_+^2 + log rho_perp^2)
                         =  (1/2)(log E_+ + log E_perp)
                         =  (1/2) S_E (E_+, E_perp),
```
and the constraint `rho_+^2 + rho_perp^2 = E_tot` becomes
`E_+ + E_perp = E_tot`. Multiplying the functional by `1/2` does not
change the set of constrained critical points; the constraint set is
unchanged; the substitution `(rho_+, rho_perp) <-> (E_+, E_perp)` is a
diffeomorphism of the positive orthant `(R_{>0})^2`. Hence the two
constrained extremum problems share the same critical points in the
shared coordinates. The retained narrow theorem
`koide_kappa_block_total_frobenius_algebraic_narrow_theorem_note_2026-05-10`
(T3) gives the critical point in `(E_+, E_perp)` coordinates as
`E_+ = E_perp = E_tot/2`; substituting back via `E_i = rho_i^2` gives
`rho_+ = rho_perp = sqrt(E_tot/2)`, matching `(P1)`. ∎

## Derivable corollaries

```text
(C1)   At the critical point, S_rho = log(E_tot/2),
       S_E  = log((E_tot/2)^2)  =  2 log(E_tot/2)  =  2 S_rho.
(C2)   The Hessian of S_rho at the critical point is
       Hess(S_rho)|*  =  diag(-2/E_tot, -2/E_tot)
       (substituting rho_+^{*2} = rho_perp^{*2} = E_tot/2).
(C3)   The critical point is invariant under the (rho_+, rho_perp) ->
       (rho_perp, rho_+) swap, since the constraint and the functional
       are both symmetric in (rho_+, rho_perp).
(C4)   In (a, b) coordinates via (I2), the critical condition reads
       a^2 = 2 |b|^2, equivalent to E_+ = E_perp (T2 substitution).
(C5)   The set of constrained critical points of S_rho on the positive
       slice is a single isolated point {(sqrt(E_tot/2), sqrt(E_tot/2))},
       not a positive-dimensional submanifold (uniqueness from strict
       concavity in (P1)).
```

All follow algebraically from `(P1)`-`(P3)` and the cited inputs `(I2)`-`(I4)`.
