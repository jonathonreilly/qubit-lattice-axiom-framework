## Theorem (independent verification + route reframing)

For the isolated `Z_p` fixed point of `C_3[111]` on `S^3` with transverse
weights `(a_1,a_2)`, the equivariant η-defect is
`η = (1/p) Σ_{k=1}^{p-1} Π_j 1/(ζ^{k a_j} − 1)`, `ζ = e^{2πi/p}`.

**(1) Forced weights.** `C_3[111]` has eigenvalues `(1, ω, ω²)`; the transverse
eigenvalues `(ω, ω²)` force weights `(1,2) mod 3`. Core identity
`(ω−1)(ω²−1) = 3`.

**(2) Value.** `η(1,2;3) = (1/3)[1/((ω−1)(ω²−1)) + 1/((ω²−1)(ω−1))] =
(1/3)(1/3 + 1/3) = 2/9`, real (imag `~10⁻¹⁶`). Alternative weights give
`η(1,1;3) = η(2,2;3) = 1/9 ≠ 2/9`; only the `C_3`-consistent `(1,2)~(2,1)` give
`2/9`. (Independently reproduces the unaudited `koide_aps_block_by_block_forcing`
value.)

**(3) Rationality ⇒ radian no-go inapplicable.** `η = 2/9 ∈ ℚ` is a spectral
asymmetry defined mod integers, not an angle defined mod `2π`. So the
"period-`1`-rad vs period-`2π`-rad" obstruction that blocks the Berry route does
not arise on this route.

**(4) Parity basepoint.** A transposition sends `δ → −δ` (the circulant-phase
parity, `NEW_PARITY...`). The transposition-fixed parity-symmetric loci are
`δ = 0` and `δ = π` modulo `2π`; the APS value `2/9` lies on the local
small-positive branch through `δ=0`. This is the canonical local basepoint the
radian-bridge no-go said was missing; the branch choice is `k=0`, not
`2/9 + 2πk`. ∎
