## Question

Can the `Q = 1` offsite `-2/9` residue be typed as the APS eta value and the
Brannen `2/9` magnitude, rather than merely noted as another numerical
coincidence?

## Answer

Yes at the exact coefficient/magnitude layer:

```text
coeff_nonid(S_Q1) = - eta_APS(1,2;3)
|coeff_nonid(S_Q1)| = eta_APS(1,2;3) = n_eff/d^2 = 2/9.
```

This builds the requested bridge as an exact `C3` group-algebra identity.
It still does not close the physical Brannen phase, because `S_Q1` is
transposition-even and supplies no parity-odd sign or selected-line readout
law by itself.

## Theorem

Let `C = g` be the regular 3-cycle and

```text
P_plus = (e + g + g^2)/3
P_perp = e - P_plus
Z      = P_plus - P_perp.
```

Then

```text
Z = -1/3 e + 2/3 g + 2/3 g^2.
```

The `Q = 1` source is

```text
S_Q1 = e - Z/3
     = 10/9 e - 2/9 g - 2/9 g^2.
```

So every nonidentity group-algebra coefficient, and every offsite matrix entry
in the site basis, equals `-2/9`.

For the `C3[111]` APS fixed-point route with transverse weights `(1,2)`, the
two nonidentity fixed-point denominator terms are

```text
1 / ((omega - 1)(omega^2 - 1))     = 1/3
1 / ((omega^2 - 1)(omega - 1))     = 1/3.
```

Therefore

```text
eta_APS(1,2;3) = (1/3) * (1/3 + 1/3) = 2/9.
```

The unaveraged APS class sum `1/3 + 1/3 = 2/3` is exactly the nonidentity
coefficient of `Z`; multiplying by the `Q = 1` source factor `-1/3` gives
the nonidentity coefficient of `S_Q1`:

```text
coeff_g(S_Q1) = coeff_g2(S_Q1) = -2/9 = -eta_APS.
```

This proves the exact coefficient bridge.

## Brannen Composition

The Brannen conjugate-pair support layer gives

```text

```

Thus the exact-support composition is

```text

```

This is not the `Q/d` route for `Q = 1`; that would give

```text

```

The bridge uses the offsite coefficient of the `Q = 1` projected source, not
the physical `Q` readout itself.

## Remaining Gap

This note does not prove the physical phase theorem:

```text
delta = eta_APS.
```

The reason is structural.  A transposition swaps `g` and `g^2`.  Since

```text
coeff_g(S_Q1) = coeff_g2(S_Q1),
```

the `Q = 1` source is transposition-even.  The existing parity theorem says
the circulant phase `delta` is transposition-odd.  Therefore `Q = 1` supplies
the exact magnitude/coefficient bridge, but not the signed parity-order
parameter by itself.

The next theorem target is now:

```text
signed_selected_line_readout_delta_equals_minus_q1_offsite_coeff_or_no_go
```

That theorem must either:

- derive a signed selected-line readout/orientation law sending
  `delta` to `-coeff_nonid(S_Q1)`, or
- prove that the `Q = 1` coefficient bridge remains only an excluded
  source-domain shadow.
