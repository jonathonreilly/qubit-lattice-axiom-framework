## Question

The `Q` source-domain lane admits both the Koide value `Q = 2/3` and the
counterdomain value `Q = 1` depending on which source domain is allowed.  The
`Q = 1` point is exact, positive, and `C3`-central, and its projected source
matrix contains the offsite coefficient `-2/9`.

Is that the same `2/9` that keeps appearing in the Koide/Brannen/APS/anomaly
phase hunt, and does it give enough ingredients to build the missing
`delta = eta_APS` bridge?

## Answer

It gives a live, reviewable bridge target, but not a retained bridge yet.

The positive content is sharp:

```text
z = -1/3  ->  Q(z) = 1
S_Q1 = I - Z/3
     = [[10/9, -2/9, -2/9],
        [-2/9, 10/9, -2/9],
        [-2/9, -2/9, 10/9]]
```

The offsite coefficient is not accidental.  In the formal `d` version,
`S_d = I - Z/d` has offsite coefficient `-2/d^2`, so at the forced `C3`
surface it has magnitude `2/9`.  This is the same arithmetic footprint as the
Brannen `n_eff/d^2` and Callan-Harvey `2/d^2` functions.  The APS eta route is
still typed differently, `(d^2 - 1)/(12d)`, but at the framework's forced
`d = 3` it also equals `2/9`.

The negative content is equally important:

- `Q = 1` interpreted on the charged-lepton carrier is not a neutral dark
  sector.
- A direct current-stack map from the charge-zero Koide `Q = 1` source to a
  charge-minus-two Majorana/RHN activation is ruled out for the scoped bridge
  class.
- Under strict onsite descent, the `Q = 1` reduced `Z` information is erased:
  every one-site detector sees only the common scalar `10I/9`, and normalized
  onsite readout returns the source-free representative, hence effective
  `Q = 2/3`.
- The offsite `-2/9` is a matrix coefficient, not automatically a Brannen
  radian phase, anomaly, or APS eta invariant.

So `Q = 1` is best treated as an exact counterdomain/source-shadow probe for
the `Q = 2/3` hunt.  It may be the missing shadow that explains why the
forbidden offsite source has the same `2/d^2` arithmetic as the phase lane, but
the physical readout theorem is still missing.

## Ingredients now available

### 1. Forced `d = 3` makes APS eta admissible

The prior discriminator remains correct:

```text
APS eta(d)       = (d^2 - 1)/(12d)
anomaly/offsite  = 2/d^2
```

They are different functions of `d`, coinciding only at `d = 3`.  If `d = 3`
is independently forced by the framework's `C3` surface, the APS value is an
exact geometric witness, not a fitted dimensional choice:

```text
eta_APS(1,2;3) = (9 - 1)/(36) = 2/9.
```

What remains open is not the value of APS eta.  The open theorem is the
physical identification of the charged-lepton Brannen phase with that APS
eta-defect.

### 2. `Q = 1` exposes an offsite `2/d^2` source residue

Let

```text
P_plus = (I + C + C^2)/3
P_perp = I - P_plus
Z      = P_plus - P_perp.
```

Then the `Q = 1` point is `z = -1/3`, with source

```text
S_Q1 = I - Z/3.
```

Its diagonal entries are `10/9`; its offsite entries are `-2/9`.  Formally, in
dimension `d`,

```text
offdiag(I - Z/d) = -2/d^2.
```

This is exactly the arithmetic footprint that the phase hunt keeps seeing.

### 3. Strict onsite descent erases `Q = 1`

The same source is invisible as a reduced onsite background.  Diagonal/local
compression maps

```text
Z    -> -I/3
S_Q1 -> 10I/9.
```

Every one-site detector sees the same value.  After quotient/normalization the
local representative is `I`, so the effective reduced coordinate is `z = 0`
and the readout is `Q = 2/3`.

This makes `Q = 1` a precise source-domain witness:

```text
projected/offsite readout: sees -2/9
strict onsite readout: erases reduced Z and returns Q=2/3
```

### 4. The dark-matter interpretation does not close

The shared `C3` singlet/doublet projector skeleton is real, and the neutral
`nu_R` Majorana slot is the natural place one would try to use a neutralized
`Q = 1` object.  But the current stack blocks the direct bridge:

- charged-lepton `Q = 1` inherits visible electric charge if read on the
  charged-lepton carrier;
- `nu_R` is neutral, but no retained map sends Koide `Z`/`Q = 1` to the
  `nu_R` Majorana source;
- the current Majorana stack has `mu_current = 0`;
- a `U(1)`-equivariant number-preserving map cannot send the charge-zero
  Koide source to a charge-minus-two pairing activation;
- abundance, stability, and the live dark-matter selector law remain on the
  separate two-real `Z3` doublet-block gate.

Thus this PR should not be cited as `Q = 1` dark matter.

The next theorem target is now narrower than "derive `2/9`":

```text
derive_whether_projected_offsite_2_over_d2_is_physical_APS_Brannen_readout
```


readout selects `Q = 2/3`.

Either outcome helps the `Q = 2/3` hunt.
