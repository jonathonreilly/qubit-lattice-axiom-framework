## Question

After the gamma-sheet probe, the right question is not "is the sign wrong?".
It is:

```text
In an oriented C3 / selected-line frame, does the Q1 coefficient support the
current positive sign delta = +2/9?
```

## Answer

Yes, conditionally.  In an oriented C3 frame with generator `g`,

```text
S_Q1 = 10/9 e - 2/9 g - 2/9 g^2.
```

The oriented positive readout is

```text
delta_oriented := -coeff_g(S_Q1) = +2/9.
```

This matches

```text
eta_APS = 2/9
```

and the existing selected-line first-branch target

```text
delta = +2/9.
```

So the sign is not contradicted.  In the admitted oriented frame, it is the
right sign.

## What Is Still Missing

The physical orientation is still load-bearing.  Q1 alone is fixed under the
transposition that swaps `g` and `g^2`:

```text
tau S_Q1 tau = S_Q1.
```

The signed selected-line direction is odd:

```text
J = i(g - g^2),
tau J tau = -J.
```

Thus Q1 has zero odd projection.  It supplies the magnitude `2/9`; an
orientation/basepoint supplies

```text
epsilon in {+1,-1},
delta = epsilon * eta_APS.
```

The current selected-line frame is the `epsilon=+1` branch.  The missing theorem
is still the physical derivation of that frame, not a numerical sign repair.
