## Answer

Partially.

The oriented generator half is much better than a convention. The same matrix
used in the Q1 coefficient bridge,

```text
g = [[0,0,1],
     [1,0,0],
     [0,1,0]],
```

is exactly the proper spatial `C_3[111]` rotation by `+2*pi/3` about the
`Z^3` body diagonal. The full taste-cube descent carries this same generator
onto the `T1` charged-sector triplet:

```text
U8|T1 = g.
```

The explicit full-cube orbit sources also descend with orientation:

```text
P1 Qf P1 = g,
P1 Qb P1 = g^2,
P1 i(Qf - Qb) P1 = i(g - g^2).
```

So the oriented `g` carrier is not floating. It is the spatial/taste
orientation seen by the Q1 bridge.

## Q1 Sign Consequence

In that spatial/taste `g` frame,

```text
S_Q1 = 10/9 e - 2/9 g - 2/9 g^2.
```

Therefore the oriented readout used by the Q1 sign closeout gives

```text

```

This is the positive sign we need. Q1 itself still does not create the odd
line: the odd projection onto `i(g-g^2)` is exactly zero. The orientation is
coming from the spatial/taste carrier, not from hidden Q1 data.
