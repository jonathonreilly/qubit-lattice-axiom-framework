## Question

The previous no-go showed:

```text
C3 + S = C + C^2
```

forces a two-atom sharp record with ranks `(1,2)`, but does not select the
atom measure, forward channel, or endpoint. This note attacks the measure side:

```text
Can existing source-measure / record-intervention machinery make the
charged-lepton readout count record atoms equally rather than by Hilbert rank?
```

## Answer

It gives the exact fork, not the physical selection.

The embedded sharp record algebra is generated by

```text
P0 = (I + C + C^2)/3
P1 = I - P0
S  = 2 P0 - P1.
```

The full Hilbert trace pushes forward to the atom weights

```text
tau_H(P0) = 1/3
tau_H(P1) = 2/3.
```

Interpreted as singlet/doublet block weights, this gives

```text
r = 1
Q = 1.
```

That is the rank/Born/default branch.

The abstract quotient record algebra, after forgetting the ranks of the
embedded projectors, is just two record atoms:

```text
C^2 = functions({singlet_atom, doublet_atom}).
```

The counting/max-entropy reference on that quotient record set is

```text
tau_count(e0) = 1/2
tau_count(e1) = 1/2,
```

which gives

```text
r = 1/2
Q = 2/3.
```

So the exact bridge is:

```text
full Hilbert trace / Born rank      -> Q = 1
rank-erased quotient record count   -> Q = 2/3
```

## Why This Is Not Closed

The two traces are different. Under the embedding

```text
iota(e0)=P0,
iota(e1)=P1,
```

the pullback of the full Hilbert trace is

```text
(tau_H o iota)(x0,x1) = (x0 + 2 x1)/3,
```

while the quotient counting trace is

```text
tau_count(x0,x1) = (x0 + x1)/2.
```

Because `rank(P0)=1` and `rank(P1)=2`, no trace-preserving map that keeps the
same embedded projectors can turn the full Hilbert trace into equal atom count.
Equal atom count is therefore a genuine rank-erasing quotient/source principle,
not a consequence of the existing full-trace state.

## Source-Measure Interpretation

The source-measure record-intervention theorem is useful here: it says a
record-facing source is operationally a probability law on the finite
sharp-record algebra. That legitimizes talking about the quotient record
probability law.

But it does not choose the reference law. It keeps a full-support reference
`P0` as an input.

The sharp-record tangent theorem exposes the same dependence. For the uniform
two-atom reference `(1/2,1/2)`, the primitive signed score is

```text
epsilon = (+1,-1),
```

with Fisher norm one. For the rank/Born reference `(1/3,2/3)`, the same
`epsilon` has nonzero mean and is not a valid score tangent. The unit score in
that reference is instead

```text
(sqrt(2), -1/sqrt(2)).
```

Thus Fisher geometry does not hide the measure choice. It tells us which
reference law we selected.

## What This Means

This is the cleanest form of the missing physical statement:

```text
the charged-lepton mass-ratio readout is a rank-erased sharp-record quotient
readout, not the full Hilbert trace/Born-rank readout.
```

If that rank-erasing recordization principle is derived, the measure side gives
`Q=2/3`. If not, the current native full-trace reading remains `Q=1`.

This also explains why the closed historical flavor campaign and the current
Q1 lane converge: the `Q=1` branch is the full trace/rank branch; `Q=2/3` is
the quotient record atom-count branch. The unsolved problem is the physical
selection of the latter.
