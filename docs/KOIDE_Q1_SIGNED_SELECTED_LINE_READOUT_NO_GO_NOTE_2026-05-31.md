# Koide Q=1 Signed Selected-Line Readout No-Go

## Question

The coefficient bridge proves

```text
coeff_nonid(S_Q1) = -eta_APS.
```

Can this be promoted to the signed selected-line readout

```text
delta = -coeff_nonid(S_Q1) = eta_APS
```

from `Q = 1` data alone?

## Answer

No.  `Q = 1` supplies the exact magnitude, but not the parity-odd sign.

The obstruction is representation-theoretic.  A transposition swaps the two
nonidentity `C3` coefficients:

```text
(c_g, c_g2) -> (c_g2, c_g).
```

For `Q = 1`,

```text
(c_g, c_g2) = (-2/9, -2/9),
```

so the source is fixed by transposition.  But the selected-line circulant phase
is transposition-odd:

```text
delta -> -delta.
```

Any transposition-equivariant readout from a transposition-fixed input to an
odd target line must vanish:

```text
F(d) = F(tau d) = tau F(d) = -F(d)  ->  F(d) = 0.
```

Since `eta_APS = 2/9` is nonzero, `Q = 1` alone cannot produce the signed
selected-line phase.

## Linear Form Check

For a linear readout

```text
f(c_g, c_g2) = a c_g + b c_g2,
```

transposition-equivariance to the odd line requires

```text
f(c_g2, c_g) = -f(c_g, c_g2).
```

Therefore `a = -b` and

```text
f(c_g, c_g2) = a(c_g - c_g2).
```

On the `Q = 1` source, `c_g = c_g2`, so every such odd readout gives zero.

The even magnitude readout

```text
-(c_g + c_g2)/2 = 2/9
```

is valid, but it is not a signed parity-odd selected-line phase.

## Minimal Conditional Escape

If an extra signed selected-line orientation primitive is supplied,

```text
epsilon in {+1, -1},     tau epsilon = -epsilon,
```

then the conditional readout

```text
delta = epsilon * eta_APS
```

is equivariant and gives the two mirror phases:

```text
epsilon = +1 -> delta =  2/9
epsilon = -1 -> delta = -2/9.
```

But `epsilon` is not contained in `S_Q1`.  It is the same kind of based
endpoint/source orientation data already isolated by the selected-line and
generation-selector no-go notes.

## What This Claims

- `Q = 1` alone cannot supply a nonzero signed selected-line phase.
- Any transposition-equivariant odd readout from the `Q = 1` coefficient data
  vanishes.
- The exact coefficient bridge remains useful as magnitude support:
  `|coeff_nonid(S_Q1)| = eta_APS`.
- A new signed orientation/basepoint primitive would be sufficient to turn the
  magnitude into a signed phase, but that primitive is additional data.

## What This Does Not Claim

- Does not kill all possible future `delta = eta_APS` routes.
- Does not negate the exact coefficient bridge.
- Does not prove `delta = eta_APS`.
- Does not prove `Q = 1` is physical source data.
- Does not prove `Q = 1` is dark matter.

## Consequence

The next live target is no longer an unqualified signed readout from `Q = 1`.
That route is blocked.  The remaining positive target must derive the missing
odd orientation/basepoint primitive:

```text
derive_signed_selected_line_orientation_from_retained_source_domain
```

or accept the no-go boundary:

```text
Q1 gives magnitude support only; signed physical phase closure remains open.
```
