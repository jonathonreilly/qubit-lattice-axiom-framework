## Question

If the `Q = 1` packet lands, what does it unlock for the `Q = 2/3` charged
lepton hunt and the APS/Brannen phase hunt?

## Answer

It unlocks two separate conditional tracks:

```text
physical strict onsite source-domain law
  -> reduced Z erased
  -> charged-lepton Q = 2/3
```

and

```text
Q = 1 projected/offsite source shadow
  -> coeff_nonid(S_Q1) = -eta_APS
  -> |delta| = eta_APS = 2/9 magnitude support
```

It does not by itself unlock the signed physical phase:

```text
delta = +2/9
```

because `Q = 1` is transposition-even, while `delta` is transposition-odd.

## Exact Unlocks

### 1. Charged leptons

The `Q = 1` counterdomain sharpens the source-domain problem.  If the physical
undeformed charged-lepton source domain is strict onsite/local, then reduced
`Z` is erased and the normalized readout returns

```text
Q = 2/3.
```

So the charged-lepton `Q` closure target is no longer a new numerical Koide
calculation.  It is the physical source-domain theorem:

```text
derive physical source domain = strict onsite descent
```

or equivalently:

```text
exclude projected Z as undeformed charged-lepton source data.
```

### 2. APS/Brannen magnitude

The excluded/projected `Q = 1` source gives the exact coefficient bridge:

```text
S_Q1 = 10/9 e - 2/9 g - 2/9 g^2
eta_APS(1,2;3) = 2/9
coeff_nonid(S_Q1) = -eta_APS.
```

Therefore the `Q = 1` shadow explains the repeated `2/9` arithmetic footprint:

```text
|coeff_nonid(S_Q1)| = eta_APS = n_eff/d^2 = 2/9.
```

This is magnitude support for the APS/Brannen phase route.

### 3. Signed phase

The signed phase still needs one more primitive.  Let `tau` be a transposition.
Then:

```text
tau(S_Q1) = S_Q1
tau(delta) = -delta.
```

Any equivariant readout from `S_Q1` alone to the signed `delta` line vanishes.
Thus the missing positive primitive is an odd orientation/basepoint:

```text
epsilon in {+1, -1}
tau epsilon = -epsilon
delta = epsilon * eta_APS.
```

With `epsilon = +1`, the phase would be `delta = +2/9`.  With
`epsilon = -1`, the mirror phase is selected.  The current packet does not
derive `epsilon`.

The bottom-up sign audit sharpens this further.  In the C3 group algebra:

```text
S_Q1 = 10/9 e - 2/9(g + g^2)
J    = i(g - g^2).
```

`S_Q1` generates only the even subalgebra `span{e, g+g^2}`.  The signed
selected-line phase lives on the odd line `span{J}`.  The projection of Q1
onto that line is exactly zero.

### 4. Selected-line point

Once a signed `delta` is genuinely closed, the existing selected-line cyclic
response bridge can run:

```text
delta = 2/9 -> kappa_sel,* -> first-branch m_*.
```

That still does not by itself solve generation labeling.  Existing selected-line
generation-selector no-gos require a based endpoint/source law to attach the
unbased ratio profile to a physical generation label.

## Current Orientation Candidates

The obvious candidates do not currently supply `epsilon`:

- retained parity/chiral violation acts on the `3 <-> 3bar` axis, not within
  the generation triplet;
- the conjugate-symmetric `C3` circulant family is even under conjugation and
  cannot generate the needed odd eta/Berry term;
- `C3[111]` is a sufficient proper-subgroup structure for nondegenerate
  generation masses, but the breaking/orientation itself is not derived by the
  minimal-breaking theorem.

- If strict onsite descent is the physical charged-lepton source-domain law,
  then the lepton `Q` readout is `2/3`.
- The `Q = 1` projected source shadow gives the APS/Brannen magnitude `2/9`.
