## 1. Carrier

The returned charged-lepton mass object on `T_1` is the three-slot real vector

```text
x = (u, v, w),
```

or equivalently its cyclic Fourier image

```text
H_cyc = (r0/3) B0 + (r1/6) B1 + (r2/6) B2.
```

Here the cyclic Hermitian basis is `B0 = I`, `B1 = C + C^2`,
`B2 = i(C - C^2)`.

The selector should be:

- `C_3`-covariant / invariant,
- local to the returned carrier,
- and scale-free.

---

## 2. Linear order

A real linear scalar on `x` has the form

```text
L(x) = a u + b v + c w.
```

Imposing invariance under the species 3-cycle forces

```text
a = b = c,
```

so the only invariant linear scalar is

```text
L(x) ∝ u + v + w = r0.
```

But `r0` is degree-1 and therefore not scale-free:

```text
r0(t x) = t r0(x).
```

So there is no nontrivial scale-free invariant at linear order.

---

## 3. Quadratic order

At quadratic order, the invariant scalar space is exactly two-dimensional:

```text
Q(x) = A r0^2 + C (r1^2 + r2^2).
```

Both basis elements are degree-2, so after quotienting by overall scale there
is exactly one nontrivial ratio:

```text
rho_Q = E_perp / E_+
      = (r1^2 + r2^2) / (2 r0^2).
```

The bridge to the circulant `kappa` normalization is derived in Section 4.

Equivalently,

```text
Q = (1 + rho_Q) / 3.
```

The raw Fourier-coordinate ratio

```text
rho_F = (r1^2 + r2^2) / r0^2
```

therefore satisfies `rho_F = 2 rho_Q`. This note uses `rho_Q` for the
physical block-energy ratio that appears in the Koide scalar.

Therefore the minimal nontrivial scale-free invariant selector on the returned
carrier is unique up to reparametrization.

## 4. Kappa normalization bridge (2026-06-12 repair)

The one-hop normalization authority for `kappa` is
[`KOIDE_KAPPA_BLOCK_TOTAL_FROBENIUS_ALGEBRAIC_NARROW_THEOREM_NOTE_2026-05-10.md`](KOIDE_KAPPA_BLOCK_TOTAL_FROBENIUS_ALGEBRAIC_NARROW_THEOREM_NOTE_2026-05-10.md).
It defines, on `Herm_circ(3)`,

```text
H = a I + b C + bbar C^2
  = a B0 + x B1 + y B2,    b = x + i y,
```

with block-total Frobenius normalization

```text
E_+ = 3 a^2,
E_perp = 6 |b|^2,
kappa = a^2 / |b|^2.
```

The selector coordinates in Section 1 identify

```text
a = r0/3,
x = r1/6,
y = r2/6,
|b|^2 = (r1^2 + r2^2) / 36.
```

Therefore the selector block energies match the carrier normalization:

```text
E_+    = 3 (r0/3)^2
       = r0^2 / 3,

E_perp = 6 ((r1^2 + r2^2) / 36)
       = (r1^2 + r2^2) / 6.
```

The kappa bridge is then exact:

```text
2 / kappa
  = 2 |b|^2 / a^2
  = 2 ((r1^2 + r2^2) / 36) / (r0^2 / 9)
  = (r1^2 + r2^2) / (2 r0^2)
  = E_perp / E_+
  = rho_Q.
```

This is a normalization lemma, not a physical value-law selection. If
`r = |b|^2/a^2`, then `rho_Q = 2r`; the value `r = 1/2`
(`kappa = 2`) is a stable dial setting for the Koide lane only when a
separate value-law input selects equal block energy. This selector note does
not force `r = 1/2`, and the framework locations `r = 0`, `r = 1/2`, and
`r = 1` remain distinct; quark and neutrino lanes are outside this note.
