## Statement

For the `C3`-circulant Yukawa with `r = |b|^2/a^2`, `Q = (1 + 2r)/3` exactly
(depending only on `r`, not the phase). Then:

1. (**EQUIV.**) `r = 1/2` (i.e. `Q = 2/3`) is equivalent to each of:
   - the `sqrt(m)` vector lying at exactly **45°** to the democratic
     `(1,1,1)` direction (`Q = 1/(3 cos^2 theta)`, so `Q = 2/3` iff
     `theta = 45°`);
   - **equal energy** in the `C3` singlet and doublet channels
     (`E_+ = 3 a^2 = E_perp = 6 |b|^2`);
   - equal Frobenius weight on the diagonal and off-diagonal of `H`.

2. (**NG.**) The four explicitly-checked C3/S3 unitary routes do not force
   `r = 1/2` while keeping three distinct masses. The full axis-permutation
   symmetry `S3` forces a Yukawa `H = alpha I + beta (J - I)` with eigenvalue
   multiplicities `{1, 2}` — two degenerate masses, excluded for the charged
   leptons. The only groups between `C3` and `S3` are `C3` (which leaves `r`
   free: `Q = (1 + 2r)/3` is non-constant) and `S3` (which forces degeneracy);
   there is no intermediate subgroup. And the singlet (trivial rep, dim 1) and
   doublet (standard rep, dim 2) are different-dimensional irreps, so no unitary
   singlet/doublet swap exists. Hence, for these four routes, `r = 1/2` is a
   norm-balance condition, not a fixed point of those routes. This is a bounded
   support identity over the four checked routes only: it does not claim those
   four exhaust the space of symmetry-protection mechanisms, and additional
   symmetry routes remain open rather than foreclosed.

3. (**REDIRECT.**) The remaining live route is dynamical or extra-structural:
   in the staggered-Dirac corner realization this would amount to deriving the
   ratio `|b|/a = 1/sqrt(2)` of inter-generation hopping to on-site term on the
   three `hw = 1` cube corners. This note does not derive that ratio; it only
   rules out the listed symmetry-protection routes.

## Proof

Pure finite-dimensional algebra; each step is reproduced by the runner.

- **EQUIV.** Writing `sqrt(m) = p uhat + q what` (`uhat = (1,1,1)/sqrt 3`,
  `what` a perpendicular unit vector), `Sum m = p^2 + q^2`,
  `(Sum sqrt m)^2 = 3 p^2`, so `Q = (1 + (q/p)^2)/3`; `Q = 2/3` iff `q = p`
  (45°). The circulant's diagonal contributes `3 a^2` and its off-diagonal
  `6 |b|^2` to `||H||_F^2`; these are equal iff `r = 1/2`. (Runner 1, 2.)
- **NG.** `H = alpha I + beta (J - I) = (alpha - beta) I + beta J`; `J` has
  spectrum `{3, 0, 0}`, so `H` has spectrum
  `{alpha + 2 beta, alpha - beta, alpha - beta}` — multiplicities `{1, 2}`
  (runner 3). `C3` leaves `r` free (`dQ/dr = 2/3 != 0`, runner 4). The
  irrep dimensions `1 != 2` forbid a unitary singlet/doublet swap (runner 5).
  QED for the listed C3/S3 symmetry routes.
- **REDIRECT** is a consequence: the condition is not fixed by these four
  checked routes, so any positive derivation must come from dynamical,
  variational, nonunitary, or extra-structure input — or from a symmetry route
  other than the four checked here, which this note does not foreclose.
