# Koide Signed-Eigenvalue vs Singular-Value Readout Narrow Theorem

**Date:** 2026-05-29
**Type:** positive_theorem
**Claim scope:** the standalone algebraic fact that, on the `C_3[111]`-circulant
Hermitian operator `H = aI + bC + b̄C²` (`a ∈ ℝ_{>0}`, `b ∈ ℂ`) with real
spectrum `λ_k = a + 2|b|cos(θ + 2πk/3)` (`θ = arg b`, `k = 0,1,2`), the two
"`√mass`" readout maps

```text
(S) signed readout            w_k = λ_k         (real signed eigenvalues; the
                                                 Brannen/Hermitian "det_R" reading)
(V) singular-value readout    w_k = |λ_k| ≥ 0   (the would-be Yukawa / modulus reading)
```

feed the Koide invariant `Q(w) = (Σ_k w_k²)/(Σ_k w_k)²` to *inequivalent* values
at the operator-side Koide point `r := |b|²/a² = 1/2`:

- the signed readout gives `Q(S) = 2/3` **exactly and independently of θ**;
- the singular-value readout gives a **θ-dependent** `Q(V)` that is **not** `2/3`
  (e.g. `θ = 0.4 → 0.566`, `θ = 0.9 → 0.416`), equal to `2/3` **only** on the
  sign-homogeneous sub-region where all `λ_k` share one sign.

This is purely a statement about two scalar functions of the eigenvalue triple of
an abstract circulant Hermitian operator. No observed charged-lepton mass value,
no selection principle fixing `r = 1/2` or `θ`, and no Yukawa-physics
identification enters as a proof input. The empirical charged-lepton value
`Q ≈ 2/3` appears **only** as the comparator that the signed readout matches.

## Statement

Let `C` be the standard `3×3` cyclic permutation matrix, `ω = e^{2πi/3}`, and let
`(a, b) ∈ ℝ_{>0} × ℂ`. Define the circulant Hermitian

```text
H  =  a I  +  b C  +  b̄ C²,                                                  (1)
```

with `C_3`-character spectrum (real, since `H` is Hermitian)

```text
λ_k  =  a + b ω^k + b̄ ω^{-k}  =  a + 2|b| cos(θ + 2πk/3),   θ := arg b.       (2)
```

Write `r := |b|²/a²` (scale-invariant: `Q` below is unchanged under
`(a,|b|) → (s a, s|b|)`, `s > 0`, so `a > 0` is a normalization). Define the two
readout 3-vectors `S := (λ_0, λ_1, λ_2)` and `V := (|λ_0|, |λ_1|, |λ_2|)`, and the
Koide invariant of a 3-vector `w`,

```text
Q(w)  :=  (w_0² + w_1² + w_2²) / (w_0 + w_1 + w_2)².                          (3)
```

**Lemma A (signed readout, `θ`-independent).**

```text
Q(S)  =  (a² + 2|b|²) / (3a²)  =  (1 + 2r)/3,    independent of θ;            (A)
        Q(S)|_{r = 1/2}  =  2/3.
```

**Lemma B (numerator invariance).** Because each `λ_k` is real, `|λ_k|² = λ_k²`,
so the two readouts share the Koide numerator — equivalently, the **mass
spectrum** `m_k := w_k²` is identical for `S` and `V`:

```text
Σ_k |λ_k|²  =  Σ_k λ_k²  =  3a² + 6|b|²;     m_k(S) = m_k(V) = λ_k².          (B)
```

**Theorem (signed/singular-value inequivalence).**

```text
(i)   Q(V)  =  (3a² + 6|b|²) / (Σ_k |λ_k|)².                                  (T-i)

(ii)  Q(V)  ≤  Q(S)  =  (1 + 2r)/3,     with equality  ⇔  all λ_k share
      one sign  (⇔  Σ_k |λ_k| = |Σ_k λ_k| = 3a).                             (T-ii)

(iii) At r = 1/2, Q(V) is a NON-CONSTANT function of θ.  Exactly,
        Q(V)(0)    = 2/3,
        Q(V)(π/3)  = 6/(9 + 4√2)  ≈ 0.4094,
        Q(V)(π/2)  = 6/(7 + 2√6)  ≈ 0.5042,
      and numerically  Q(V)(0.4) ≈ 0.5658,  Q(V)(0.9) ≈ 0.4160,
      while  Q(S) ≡ 2/3  at every θ.                                          (T-iii)

(iv)  Hence S and V are algebraically inequivalent readouts of the same
      operator H at r = 1/2; only the signed readout S yields the
      θ-independent value 2/3.                                               (T-iv)
```

**Corollary C1 (sign-flip boundary at `r = 1/2`).** The same-sign region (where
`Q(V) = 2/3`) is `|θ mod (2π/3)| < π/12`; at the boundary `θ = π/12` exactly one
eigenvalue vanishes (`λ_k = a(1 + √2·(−1/√2)) = 0`).

**Corollary C2 (one-negative closed form).** On the region with exactly one
negative eigenvalue `λ_min < 0`,

```text
Σ_k |λ_k|  =  Σ_k λ_k − 2λ_min  =  3a − 2λ_min,
Q(V)  =  (3a² + 6|b|²) / (3a − 2λ_min)²   <  2/3   (since 3a − 2λ_min > 3a).
```

**Corollary C3 (sign is the only difference).** By (B), `S` and `V` produce the
*identical* mass triple `m_k = λ_k²`; they differ **only** in the sign of the
`√m_k` components. `Q` is sensitive to that sign solely through the
`(Σ_k √m_k)²` denominator, which is `(3a)² = 9a²` for `S` but `(Σ_k|λ_k|)² ≥ 9a²`
for `V`.

## Proof

**Lemma A.** Summing (2) over `k` and using the standard root-of-unity sums
`Σ_k cos(θ + 2πk/3) = 0` and `Σ_k cos²(θ + 2πk/3) = 3/2` (both pure trigonometric
identities; see the cited circulant `Q = 2/3` narrow theorem),

```text
Σ_k λ_k   =  3a,
Σ_k λ_k²  =  3a² + 4a|b|·0 + 4|b|²·(3/2)  =  3a² + 6|b|².
```

Hence `Q(S) = (3a² + 6|b|²)/(3a)² = (a² + 2|b|²)/(3a²) = (1 + 2r)/3`, with all
`θ`-dependence cancelled. At `r = 1/2` this is `(1 + 1)/3 = 2/3`. ∎

**Lemma B.** Each `λ_k ∈ ℝ`, so `|λ_k|² = λ_k²` term by term; summing gives (B),
and `m_k(S) = λ_k² = |λ_k|² = m_k(V)`. ∎

**Theorem.** (T-i) The numerator of `Q(V)` is `Σ_k |λ_k|² = Σ_k λ_k² = 3a² + 6|b|²`
by (B); the denominator is `(Σ_k |λ_k|)²` by definition.

(T-ii) The triangle inequality gives `Σ_k |λ_k| ≥ |Σ_k λ_k| = |3a| = 3a` (using
`a > 0`), with equality iff all `λ_k` have a common sign. Squaring,
`(Σ_k|λ_k|)² ≥ (Σ_k λ_k)² = 9a²`, so

```text
Q(V)  =  (3a² + 6|b|²)/(Σ_k|λ_k|)²  ≤  (3a² + 6|b|²)/(9a²)  =  Q(S),
```

with equality iff sign-homogeneous.

(T-iii) Direct exact evaluation at `r = 1/2` (set `a = 1`, `|b| = 1/√2`, so
`Σ_k λ_k² = 6` and `Σ_k λ_k = 3`):

- `θ = 0`: `λ = (1+√2, 1−√2/2, 1−√2/2)`, all positive, so `Σ|λ| = 3` and
  `Q(V) = 6/9 = 2/3`.
- `θ = π/3`: `λ = (1+√2/2, 1−√2, 1+√2/2)` with `λ_1 = 1−√2 < 0`, so
  `Σ|λ| = (1+√2/2)+(√2−1)+(1+√2/2) = 1+2√2` and
  `Q(V) = 6/(1+2√2)² = 6/(9+4√2) ≈ 0.4094`.
- `θ = π/2`: `λ = (1, 1−√6/2, 1+√6/2)` with `λ_1 < 0`, so `Σ|λ| = 1+√6` and
  `Q(V) = 6/(1+√6)² = 6/(7+2√6) ≈ 0.5042`.

These three values `{2/3, 6/(9+4√2), 6/(7+2√6)}` are pairwise distinct, so `Q(V)`
is non-constant in `θ`. The float samples `Q(V)(0.4) ≈ 0.5658` and
`Q(V)(0.9) ≈ 0.4160` (each with sign pattern `(+,−,+)`) confirm the brief's
stated values and lie strictly below `2/3`, consistent with (T-ii).

(T-iv) `Q(S) ≡ 2/3` is constant (Lemma A) while `Q(V)` takes at least three
distinct values (T-iii); two functions that differ on the parameter domain are
inequivalent. ∎

**Corollaries.** C1: at `r = 1/2`, `λ_k = a(1 + √2 cos(θ + 2πk/3)) = 0 ⇔
cos(θ + 2πk/3) = −1/√2 ⇔ θ + 2πk/3 ≡ ±3π/4`; the angle set `{θ + 2πk/3}` is
invariant under `θ → θ + 2π/3`, giving the stated window. C2 is the triangle-sum
specialized to one sign flip. C3 restates (B) and the denominator computation in
the proof of (T-ii). ∎

## The new fact, and why it is a positive constraint

Both readouts assign the **same masses** `m_k = λ_k²` to `H`; they differ only in
whether `√m_k` is allowed to be negative. The Koide ratio sees that difference
**only** through the `(Σ_k √m_k)²` denominator. The retained Brannen
`Q = 2/3` closure therefore rests on a structural input that is easy to miss when
it is implicit: **`√m_k` is a signed real vector** (one or more components
negative), produced by reading the spectrum of a *Hermitian* operator. Singular
values are `≥ 0` and erase that sign structure.

The consequence is a constraint, stated positively:

> Reading the charged-lepton mass operator as the singular values of a
> (non-Hermitian) Yukawa is **not** a free reinterpretation at the `r = 1/2`
> operator. By (T-iii) it changes the value of `Q` away from `2/3` for generic
> `θ`. Among the two readouts of this circulant operator, it is specifically the
> **Hermitian / signed-eigenvalue (det_R-structured)** readout that is
> compatible with the empirical `Q ≈ 2/3`.

This is phenomenology-compatible-side information: it tells us which readout class
to keep, not that any particular operator is forced.

## What this opens

This narrow theorem isolates a previously-implicit ingredient — the **sign
structure of `√m`** — as an explicit, reviewable object, and sharpens the
charged-lepton frontier into a cleaner set of sub-questions:

- **Readout-class question.** The native framework operator class is *Hermitian*
  (real, signed spectrum) — e.g. the real anti-Hermitian native Dirac `D` with
  Hermitian lift `H = iD` of
  `cpt_exact_real_anti_hermitian_d_narrow_theorem_note_2026-05-10`. That places
  the native readout on the **signed** side of this dichotomy, i.e. the side this
  theorem shows is compatible with `Q = 2/3`. Whether the specific charged-lepton
  mass operator *is* the circulant Hermitian `H` at `r = 1/2` remains the separate
  identification carried by the cited bridge/cone notes.
- **`r = 1/2` selection** (unchanged by this note): the value `r = 1/2` enters
  here as a hypothesis. The operator-side condition `Q = 2/3 ⇔ 3a² = 6|b|² ⇔
  r = 1/2` is the algebraic equivalence of
  `koide_circulant_character_bridge_narrow_theorem_note_2026-05-09` and
  `charged_lepton_koide_cone_algebraic_equivalence_narrow_theorem_note_2026-05-10`;
  what selects `r = 1/2` physically is still open.
- **Operator chirality** (`koide_anticommuting_operator_derivation_theorem_note_2026-05-10`):
  the anti-commuting-operator route to `Q = 2/3` is itself a Hermitian-`H`
  mechanism (`{H, Γ_χ} = 0`, real eigenvectors). This note is consistent with and
  complementary to that route — both live on the signed/Hermitian side — and the
  remaining chirality-import question is untouched here.

None of these is closed by this note; the theorem narrows *what kind of readout*
the data already prefers, which is the next handle on the `√m`-sign and `r = 1/2`
questions.

## What this claims

- The signed-readout identity (A) and its `θ`-independence (Lemma A).
- The numerator/mass-spectrum invariance (B) (Lemma B).
- The inequivalence theorem (T-i)–(T-iv): the singular-value readout `Q(V)` is
  `θ`-dependent, bounded above by `Q(S)`, equal to it only when the spectrum is
  sign-homogeneous, and in particular non-constant (hence `≠ 2/3`) at `r = 1/2`.
- Corollaries C1–C3 (sign-flip boundary, one-negative closed form, "sign is the
  only difference").

## What this does NOT claim

- Does **not** derive `r = 1/2`. The Koide point enters as a hypothesis; the
  physical selector for `r = 1/2` is out of scope.
- Does **not** derive `Q = 2/3` for charged leptons, nor predict `m_e, m_μ, m_τ`.
- Does **not** identify `H = aI + bC + b̄C²` (or its eigenvalues with `√m_k`) as
  *the* charged-lepton mass operator; that identification is downstream (cited
  bridge/cone notes).
- Does **not** assert that the framework forces the Hermitian readout `S`. It
  shows the two readouts are inequivalent and that `S` is the one compatible with
  the comparator `2/3`; it does not close the readout-class selection.
