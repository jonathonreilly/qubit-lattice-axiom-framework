## Claim

The charged-lepton Koide A1-condition
`r = |b|^2 / a^2 = 1/2` on the `C_3`-equivariant Hermitian circulant
`H = aI + bC + b-bar C^2` (`hw=1`) is equivalent to the equal-block /
**complex-dimension counting** ("det_C") of the non-trivial doublet of
the generation algebra `R[Z_3] = R (+) C` — `kappa = 2`, `<=> {H,
Gamma_chi} = 0 <=>` Koide `Q = 2/3` (retained
`KOIDE_ANTICOMMUTING_OPERATOR_DERIVATION_THEOREM`,
`CHARGED_LEPTON_KOIDE_CONE_ALGEBRAIC_EQUIVALENCE`,
`KOIDE_KAPPA_BLOCK_TOTAL_FROBENIUS_MEASURE`). The complex-dimension
counting requires the continuous rotation of the doublet,
`U(1)_b : b -> e^{i theta} b`, to be a symmetry (this is the SO(2)/U(1)_b
angular quotient that Probe 13,
`KOIDE_A1_PROBE_REAL_STRUCTURE`, isolated as the precise missing
primitive and left open as its "option 2").

**Theorem.** No continuous `U(1)_b` symmetry can act on the generation
doublet, because it is incompatible with the retained order-3 relation
`C^3 = I`:

```text
(T1) A continuous rotation of the doublet plane (B1, B2) by angle alpha,
     with B1 = C + C^2 and B2 = i(C - C^2), is IDENTICALLY the rephasing
     of the order-3 shift:
         rotate (B1,B2) by alpha   <=>   C -> e^{i alpha} C.

(T2) The generation relabeling C is retained with C^3 = I. Any rephased
     shift must preserve that relation:
         (e^{i alpha} C)^3 = e^{3 i alpha} C^3 = e^{3 i alpha} I,
     which equals I only for  alpha in {0, 2pi/3, 4pi/3}.
     [Conjugation form: (g C g^dag)^3 = g C^3 g^dag = I likewise forces
      e^{3 i alpha} = 1.]

(T3) Therefore the only doublet rotations consistent with C^3 = I are the
     three discrete cube-roots — i.e. the discrete C_3 itself. The
     continuous U(1)_b does not exist on the generation factor: it is
     not merely absent from the retained inventory, it is OBSTRUCTED by
     the order-3 relation.
```

Consequently the equal-block / det_C counting — hence `Q = 2/3` — cannot
be forced by any continuous symmetry acting on the generation factor.
The two concrete families of retained continuous symmetry confirm this
with no rotation generator on the doublet:

- **Gauge circles** (`U(1)_em`, `U(1)_Y`) are generation-blind: the three
  generation patterns carry identical gauge charge, so a gauge phase is
  a scalar `e^{i chi} I_3` on the triplet and `g H g^dag = H` (`b`
  unchanged) — zero action on the doublet.
- **Lattice translations** (diagonal corner phases `diag(e^{i phi_j})`)
  either map `C` out of the `C_3`-circulant class (a generic phase
  profile; not a symmetry of the mass-operator structure) or, for a
  linear profile of slope `2 pi k / 3`, reproduce exactly the discrete
  `C_3` character — never a continuous rotation of `b`.

This **sharpens Probe 13** from a survey ("none of the *known* retained
continuous symmetries acts as `U(1)_b`") into a theorem ("*none can*,
because `C^3 = I`"), closing Probe 13's left-open option 2 negatively
with a reason.
