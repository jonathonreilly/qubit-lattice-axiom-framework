reproduces the textbook constant `K ~ 1.04 x 10^9 GeV^-1` numerically (to

## Statement

Let `T_0`, `H_100`, and `g_*S(T_0)` be abstract positive real symbols, and
let `M_Pl` be a positive real symbol identified with the Planck mass
admission carried by the Tier-A `S` entry of the admitted-input registry.
Let `pi` denote the standard transcendental period. Suppose the five
premises (P1)–(P5) hold:

```text
P1 (Friedmann)        :  H^2 = (8 pi / 3) * G_N * rho                  (F1)
                          with G_N = 1 / M_Pl^2 in natural units (hbar = c = 1).
P2 (Stefan-Boltzmann) :  rho_rad(T) = (pi^2 / 30) * g_*(T) * T^4       (SB)
P3 (Entropy density)  :  s(T)        = (2 pi^2 / 45) * g_*S(T) * T^3   (SD)
P4 (Boltzmann tail)   :  Y_infty     ~ x_F * sqrt(45 / pi) /
                                       (sqrt(g_*(T_F)) * M_Pl * <sigma_v>)
                                                                       (BT)
                          (s-wave Kolb-Turner solution, leading order).
P5 (Entropy conservation)
                      :  s * a^3 = constant ⇒ n_chi today = s_0 * Y_infty.
                                                                       (EC)
```

Define the present-epoch entropy density

```text
s_0   :=  (2 pi^2 / 45) * g_*S(T_0) * T_0^3                            (D1)
```

and the critical-density per `h^2`

```text
rho_c / h^2  :=  3 H_100^2 / (8 pi G_N)
              =  3 H_100^2 M_Pl^2 / (8 pi).                            (D2)
```

Define the Kolb-Turner prefactor

```text
K   :=   s_0  *  sqrt(45 / pi)  /  (rho_c / h^2)                       (D3)
```

so that

```text
Omega_X h^2  =  m_X * s_0 * Y_infty / (rho_c / h^2)
             =  K * x_F / ( sqrt(g_*(T_F)) * M_Pl * <sigma_v> )        (KT)
```

is the Kolb-Turner relic-abundance form.

Then identity (P*) holds:

```text
K  =  ( (2 pi^2 / 45) * g_*S(T_0) * T_0^3 ) * sqrt(45 / pi) /
       ( 3 H_100^2 M_Pl^2 / (8 pi) )                                   (P*)
   =  ( 16 pi^3 * g_*S(T_0) * T_0^3 * sqrt(45 / pi) ) /
       ( 135 * H_100^2 * M_Pl^2 ).
```

## Proof

Pure algebraic substitution.

**Step 1 (relate `Y_infty` to `Omega_X h^2`).** By (EC) and the
identification `Omega_X h^2 = m_X n_X / (rho_c / h^2)`,

```text
Omega_X h^2  =  m_X * s_0 * Y_infty / (rho_c / h^2).                   (1)
```

**Step 2 (substitute (BT)).** By (BT),

```text
Y_infty  =  x_F * sqrt(45 / pi) / ( sqrt(g_*(T_F)) * m_X * M_Pl * <sigma_v> ).
                                                                       (2)
```

The `m_X` cancels against the `m_X` in (1), giving

```text
Omega_X h^2  =  [ s_0 * sqrt(45 / pi) / (rho_c / h^2) ]
                *  x_F / ( sqrt(g_*(T_F)) * M_Pl * <sigma_v> ).        (3)
```

**Step 3 (identify `K`).** Comparing (3) to (KT),

```text
K  =  s_0 * sqrt(45 / pi) / (rho_c / h^2).                             (4)
```

This is identity (P*).

**Step 4 (substitute (D1)).** By (D1),

```text
K  =  ( (2 pi^2 / 45) * g_*S(T_0) * T_0^3 ) * sqrt(45 / pi) /
       (rho_c / h^2).                                                  (5)
```

**Step 5 (substitute (D2)).** By (D2),

```text
K  =  ( (2 pi^2 / 45) * g_*S(T_0) * T_0^3 ) * sqrt(45 / pi) /
       ( 3 H_100^2 M_Pl^2 / (8 pi) )                                   (6)
   =  ( 16 pi^3 * g_*S(T_0) * T_0^3 * sqrt(45 / pi) ) /
       ( 135 * H_100^2 * M_Pl^2 ).
```

(Simplifying constants: `(2 pi^2 / 45) * (8 pi / 3) = 16 pi^3 / 135`,
so the cleared form is `16 pi^3 g_*S(T_0) T_0^3 sqrt(45/pi)
/ (135 H_100^2 M_Pl^2)`. Equivalently `16 sqrt(5) pi^(5/2) g_*S(T_0)
T_0^3 / (45 H_100^2 M_Pl^2)` after distributing the `sqrt(45/pi) =
3 sqrt(5) / sqrt(pi)` factor.)

∎
