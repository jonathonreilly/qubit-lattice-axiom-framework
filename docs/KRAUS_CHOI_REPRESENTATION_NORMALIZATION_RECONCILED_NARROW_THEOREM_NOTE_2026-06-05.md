## Purpose

The earlier note
`KRAUS_CHOI_REPRESENTATION_ON_QUBIT_LATTICE_NARROW_THEOREM_NOTE_2026-05-20.md`
stated the Kraus operator-sum representation and the Choi–Jamiołkowski
characterization of CPTP maps on the finite-region qubit algebra, but its
Choi-matrix normalization is **internally inconsistent**: it defines the
maximally entangled vector both as `|Ω⟩ = Σ_i |i⟩|i⟩` (unnormalized) and as
`|Ω⟩ = (1/√d) Σ_i |i⟩|i⟩` (normalized), then pairs the **normalized** vector and
the **normalized**-convention Kraus prefactor `K_r = √d · vec⁻¹(v_r)` with the
**unnormalized**-convention inverse formula `Φ(X) = Tr₁[(Xᵀ ⊗ 𝟙) C_Φ]`. Those
two conventions differ by a factor `d`, so the formulas as written do not
round-trip: with the normalized Choi matrix the inverse formula is off by `1/d`,
and with the unnormalized Choi matrix the `√d` Kraus prefactor overcounts the map
by `d`.

This note states the Kraus↔Choi correspondence with **one** convention used
end-to-end and with every `d`-factor made explicit and consistent, and its
companion runner **reproves** the full correspondence from primitives on the
qubit algebra `M₂(ℂ)` and the two-qubit algebra `M₂(ℂ) ⊗ M₂(ℂ)`.

## Convention (one, used throughout)

Let `d = 2^|Λ|` be the dimension of the finite-region qubit algebra
`A_Λ = ⊗_{x∈Λ} M₂(ℂ) ≅ M_d(ℂ)`, fixed by the Quantum and Lattice axioms of
[`MINIMAL_AXIOMS_2026-06-05.md`](MINIMAL_AXIOMS_2026-06-05.md) (one qubit
`M₂(ℂ)` per site `x ∈ Z³`). Throughout this note the maximally entangled vector
is the **unnormalized** one:

```text
|Ω⟩ = Σ_{i=0}^{d-1} |i⟩|i⟩            (⟨Ω|Ω⟩ = d)                          (U)
```

With this single choice, the four objects are:

```text
Choi matrix:   C_Φ = (id ⊗ Φ)(|Ω⟩⟨Ω|) = Σ_{i,j} |i⟩⟨j| ⊗ Φ(|i⟩⟨j|)        (1)
                     (NO 1/d prefactor)

inverse map:   Φ(ρ) = Tr₁[(ρᵀ ⊗ 𝟙) C_Φ]                                    (2)
                     (NO d-factor)

Kraus ops:     C_Φ = Σ_a λ_a |v_a⟩⟨v_a|   (eigendecomposition, λ_a ≥ 0)
               K_a = √λ_a · reshape(v_a, d×d)ᵀ                              (3)
                     (eigenvalue absorbed; NO extra √d factor)

CP  ⟺  C_Φ ⪰ 0 (positive semidefinite)                                     (4)
TP  ⟺  Tr₂ C_Φ = 𝟙_d   ⟺   Σ_a K_a† K_a = 𝟙_d                              (5)
```

The transpose in (3) is forced by the convention (U): since
`(𝟙 ⊗ K)|Ω⟩ = Σ_{i,m} K_{m,i} |i⟩|m⟩`, the bipartite eigenvector component at
index `(i, m)` equals `K_{m,i}`, so `K = reshape(v, d×d)ᵀ`. The partial trace in
(5) is over the **output** (second) factor.

## Claim

> **Theorem (Kraus–Choi correspondence, single-convention form).** Let
> `Φ : M_d(ℂ) → M_d(ℂ)` be linear, with `C_Φ` defined by (1) under convention
> (U). Then:
>
> 1. **(Reconstruction)** `Φ` is recovered from `C_Φ` by (2): for every
>    `ρ ∈ M_d(ℂ)`, `Φ(ρ) = Tr₁[(ρᵀ ⊗ 𝟙) C_Φ]` exactly — **no** `d`-factor.
> 2. **(Complete positivity)** `Φ` is completely positive iff `C_Φ ⪰ 0`. When
>    `C_Φ ⪰ 0`, the operators `K_a` of (3) satisfy
>    `Φ(X) = Σ_a K_a X K_a†` for all `X` — **no** extra `√d`.
> 3. **(Trace preservation)** `Φ` is trace-preserving iff `Tr₂ C_Φ = 𝟙_d`, iff
>    `Σ_a K_a† K_a = 𝟙_d`; and `Tr₁ C_Φ = Φ(𝟙_d)`.
>
> Applied to the framework substrate `A_Λ = ⊗_x M₂(ℂ) ≅ M_d(ℂ)`, `d = 2^|Λ|`,
> all four objects (Choi matrix, inverse map, Kraus operators, CP/TP conditions)
> are mutually consistent with the `d`-factors of (1)–(5).

The earlier note's mixed convention is the special case where (1) carries a
spurious `1/d` while (2) omits the compensating `d` (then (2) returns `Φ(ρ)/d`),
or (1) is unnormalized while (3) carries a spurious `√d` (then the operator sum
returns `d·Φ(X)`). Fixing either mismatch — equivalently, choosing one
convention end-to-end — removes the inconsistency.

## Why the two conventions are both internally consistent (the fix is "pick one")

There is no uniquely "correct" convention; there are two self-consistent ones,
and the only error is mixing them:

| object | unnormalized `\|Ω⟩=Σ\|i⟩\|i⟩` (this note) | normalized `\|Ω⟩=(1/√d)Σ\|i⟩\|i⟩` |
|---|---|---|
| Choi `C_Φ` | `Σ_{ij} \|i⟩⟨j\| ⊗ Φ(\|i⟩⟨j\|)` | `(1/d) Σ_{ij} \|i⟩⟨j\| ⊗ Φ(\|i⟩⟨j\|)` |
| inverse | `Tr₁[(ρᵀ⊗𝟙) C_Φ]` | `d · Tr₁[(ρᵀ⊗𝟙) C_Φ]` |
| Kraus from `v_a` | `√λ_a · reshape(v_a)ᵀ` | `√d · √λ_a · reshape(v_a)ᵀ` |
| CP | `C_Φ ⪰ 0` | `C_Φ ⪰ 0` |
| TP | `Tr₂ C_Φ = 𝟙` | `Tr₂ C_Φ = (1/d) 𝟙` |

The runner verifies that the unnormalized column round-trips exactly, that the
matched normalized column also round-trips (`1/d` Choi with the `√d` Kraus
prefactor and the `d`-weighted inverse), and that the two **mixed** rows of the
earlier note fail by exactly the predicted `1/d` and `d` factors.

## Reproven content (companion runner)

The companion runner
[`scripts/audit_companion_kraus_choi_normalization_reconciled_2026_06_05.py`](../scripts/audit_companion_kraus_choi_normalization_reconciled_2026_06_05.py)
reproves the correspondence from primitives — `26 PASS / 0 FAIL`:

- **Part A (exact, sympy, `M₂`).** For a symbolic single-Kraus CP map
  `Φ(X) = K X K†`, the inverse formula (2) returns `Φ(ρ)` exactly with **no**
  `d`-factor (`Tr₁[(ρᵀ⊗𝟙) C_Φ] − Φ(ρ) = 0` as a symbolic matrix), and the mixed
  combination (normalized Choi + no-`d` inverse) returns exactly `Φ(ρ)/d`.
- **Part B (numeric, `M₂` and `M₂⊗M₂`).** Random CPTP maps are generated from
  primitives via Stinespring isometries (so `Σ_a K_a†K_a = 𝟙` by construction).
  For 40 random maps at each of `d = 2` and `d = 4`, all eight links hold to
  machine precision: `C_Φ ⪰ 0`; `Tr₂ C_Φ = 𝟙`; `Tr₁ C_Φ = Φ(𝟙)`; the inverse
  formula (2) round-trips; the Kraus operators (3) reproduce `Φ`; the extracted
  Kraus operators satisfy `Σ_a K_a†K_a = 𝟙`; and they rebuild the **same**
  Choi matrix (full loop).
- **Part C (named qubit channels + CP boundary).** Dephasing, depolarizing, and
  a unitary channel pass the entire reconciled chain; the transpose map (positive
  but not completely positive) has a Choi matrix with a negative eigenvalue
  (`min eig = −1`), confirming the CP ⟺ `C_Φ ⪰ 0` direction (4).
- **Part D (normalization guards — the actual repair).** The unnormalized chain
  is consistent; "normalized Choi + no-`d` inverse" is off by exactly `1/d`;
  "unnormalized Choi + spurious `√d` Kraus" overcounts by exactly `d`; and the
  matched normalized convention is internally consistent — demonstrating the fix
  is "use one convention", not "one is right".
