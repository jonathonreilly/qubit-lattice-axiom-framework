axiom (symbol `λ(k)=6−2Σ_μ cos k_μ`).

1. **Resolvent identity (framework-internal).** `G = L⁻¹`, and for `x≠0`
   `G(x) = (L⁻¹)_{0x} = ∫₀^∞ (e^{−tL})_{0x} dt` (the resolvent as the time-integral of
   the heat kernel — `e^{−tL}` is built from the Lattice graph operator `L`).

2. **Heat-kernel factorization (framework-internal).** `L = Σ_μ L_μ` with the axis
   Laplacians commuting, so `(e^{−tL})_{0x} = ∏_μ (e^{−tL_μ})_{0,x_μ}`, and the **exact**
   1D nearest-neighbor heat kernel is `(e^{−tL₁})_{0n} = e^{−2t} I_n(2t)` (`I_n` modified
   Bessel). Hence

   `G(x) = ∫₀^∞ ∏_μ e^{−2t} I_{x_μ}(2t) dt`   — exact, framework-internal.

   (Independently: `G(0) = 0.252731…`, the Watson integral — validates the representation.)

   `t`, `e^{−2t} I_n(2t) → (4πt)^{−1/2} e^{−n²/(4t)}` (the 1D continuum heat kernel), so

   `G(x) → ∫₀^∞ (4πt)^{−3/2} e^{−|x|²/(4t)} dt = 1/(4π|x|)`.
