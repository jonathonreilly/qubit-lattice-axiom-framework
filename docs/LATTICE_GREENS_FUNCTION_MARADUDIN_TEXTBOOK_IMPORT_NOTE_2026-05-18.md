## The asymptotic

Let `(-Delta_lat)` be the nearest-neighbor graph Laplacian on the
cubic lattice `Z^3` with stencil

```text
(-Delta_lat f)(x) = 6 f(x) - sum_{|y - x| = 1} f(y).
```

Its Green's function `G(r) = (-Delta_lat)^{-1}(r)` (the lattice
potential generated by a unit point source) satisfies the
**Maradudin-Montroll-Weiss asymptotic** at large lattice separation:

```text
G(r)  ->  1 / (4 pi |r|)        as |r| -> infinity.
```

The leading `1 / (4 pi |r|)` continuum-limit form is the standard
3D Newton-Poisson Green's function with the natural lattice unit
spacing. Subleading corrections decay faster than `1 / |r|` and are
not load-bearing for the asymptotic statement.

## Standard textbook references

- A. A. Maradudin, E. W. Montroll, G. H. Weiss, I. P. Ipatova,
  *Theory of Lattice Dynamics in the Harmonic Approximation*, 2nd
  ed., Academic Press / Solid State Physics Suppl. 3 (1971),
  Appendix B (lattice Green's functions).
- G. F. Lawler, *Intersections of Random Walks*, Birkhäuser (1991),
  §1.5 (cubic-lattice Green's function asymptotic via random-walk
  representation; equivalent formulation).
- F. Spitzer, *Principles of Random Walk*, 2nd ed., Springer (1976),
  §29 (Green's function on `Z^d` for transient lattices `d >= 3`).

The asymptotic `G(r) ~ 1 / (4 pi |r|)` on `Z^3` is a standard result
of lattice potential theory derivable from any of these treatments.
