## Statement

Laplacian Green function at zero separation by `(D1)`-`(D2)`. Then:

**Conclusion (T2) (monotone ordering).** The readouts satisfy

```text
G_lat(0; 8) < G_lat(0; 16) < G_lat(0; 32) < G_lat(0; 64),              (T2)
```

## Proof

`(T1)` Pure finite arithmetic. For each `L in {8, 16, 32, 64}` the sum
`(D1)` is a finite sum over `L^3 - 1` terms, each term being the
rational-trigonometric value
`1 / [ (2 sin(pi n_x / L))^2 + (2 sin(pi n_y / L))^2 + (2 sin(pi n_z / L))^2 ]`,
divided by `L^3`. The runner evaluates this sum at machine precision
using `math.sin` from the Python standard library and the rational
divisor `L^3`. The four numerical readouts `(V1)`-`(V4)` follow by
direct evaluation. The `(0, 0, 0)` index is excluded by construction in
`(D1)`; including it would give a zero denominator and is the only term
omitted from the sum.

`(T2)` By direct comparison of the four readouts: `0.224605... <
0.238630... < 0.245676... < 0.249203...`. The monotone-increasing
ordering across these
four sample sizes is a numerical fact of `(V1)`-`(V4)`. The narrow
theorem does not claim monotonicity for all `L`; only that the four
sample readouts are ordered as in `(T2)`.

`(T3)` By direct comparison: `0.249203... < 0.2527` gives `(T3a)`. The
gap is `0.2527 - 0.249203... = 0.003497... < 0.005`, giving `(T3b)`.
The literature value `0.2527` is quoted (not derived) from
`MONOPOLE_DERIVED_NOTE.md` Step 3, which itself cites the
Banks-Myerson-Kogut 1977 / Polyakov 1977 lattice-gauge-theory tradition
and the Brandt-Klauder-Madras `Z^3` random-walk constant. This narrow
theorem does **not** derive `0.2527`; it only reports the four
finite-`L` sample readouts and the numerical gap to the quoted
literature constant.

`(T4)` Under any permutation `sigma in S_3` of the three index
coordinates,

```text
sum_{n != 0} 1 / [ hat{k}(n_x)^2 + hat{k}(n_y)^2 + hat{k}(n_z)^2 ]
   =  sum_{n != 0} 1 / [ hat{k}(n_{sigma(x)})^2 + hat{k}(n_{sigma(y)})^2 + hat{k}(n_{sigma(z)})^2 ]
```

because the index set `{(n_x, n_y, n_z) : 0 <= n_x, n_y, n_z < L, (n_x,
n_y, n_z) != (0, 0, 0)}` is invariant under coordinate relabeling, the
summand depends on `(n_x, n_y, n_z)` only through the unordered triple
`(hat{k}(n_x)^2, hat{k}(n_y)^2, hat{k}(n_z)^2)`, and the addition of
floats is commutative. Therefore `G_lat(0; L)` is invariant under each
of the six finite permutations in `S_3`. The runner verifies this
explicitly at `L = 8` for the three generators
`(x <-> y), (x <-> z), (y <-> z)`.
∎
