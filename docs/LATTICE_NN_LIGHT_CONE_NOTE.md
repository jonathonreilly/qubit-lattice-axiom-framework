## Definitions

Let `V` be a finite set of vertices and let `R subset V x V` be the one-step
dependency relation. The ordered pair `(u, v) in R` means that the value at
vertex `v` after one update tick is allowed to use the value at vertex `u` from
the previous tick.

For an undirected nearest-neighbor lattice update, `R` contains the directed
versions of the nearest-neighbor edges and contains `(v, v)` only if the
recurrence carries the previous value at `v` forward. For a DAG update, the
off-diagonal part of `R` contains the directed parent-to-child dependency
edges. Carry self-edges may be added, but in that case `R` itself is no longer
literally acyclic.

For a source set `S subset V`, define the forward causal neighborhoods
recursively:

```text
C_0(S) = S
C_{t+1}(S) = C_t(S) union {v in V : there exists u in C_t(S) with (u, v) in R}.
```

For any `A subset V`, write

```text
R^+(A) = {v in V : there exists u in A with (u, v) in R}.
```

Thus `C_{t+1}(S) = C_t(S) union R^+(C_t(S))`. This is a purely
combinatorial construction: it introduces neither a spatial metric nor a
conversion from update ticks to physical time.

Define the predecessor set `P_R(v) = {u in V : (u, v) in R}`. Assign an
arbitrary state space `X_v` to every vertex. An update rule is `R`-local when,
for every `t in N_0` and `v in V`, it has a fixed map

```text
F_{v,t}: product_{u in P_R(v)} X_u -> X_v
```

and the update is

```text
x_v(t + 1) = F_{v,t}((x_u(t))_{u in P_R(v)}).
```

The indexed tuple retains predecessor labels; no arguments outside `P_R(v)` are
available to the map. The two histories compared below use the same state
spaces and map family. If an update uses external randomness, condition on the
same random choice in both histories, so that the realized map `F_{v,t}` is
shared pathwise; no stochastic independence or physical noise model is part of
the claim. The state spaces and maps may otherwise be arbitrary: linearity,
invertibility, differentiability, and a common state space are not assumed.

## Theorem

Let `V` be finite. For any relation `R`, state spaces `{X_v}_{v in V}`, fixed
`R`-local map family `{F_{v,t}}`, source set `S subset V`, and two histories
whose initial configurations differ only on `S`, the evolved configurations
can differ at any `t in N_0` only on `C_t(S)`.

Equivalently, no vertex outside the forward reachability set of `S` in the
one-step dependency graph can be influenced by the initial perturbation within
`t` update ticks.

## Proof

Let

```text
D_t = {v in V : x_v(t) differs between the two histories}.
```

The load-bearing one-step lemma is

```text
D_{t+1} subset R^+(D_t).
```

Indeed, take `v` outside `R^+(D_t)`. Every predecessor `u` with `(u, v) in R`
then lies outside `D_t`, so every argument supplied to `F_{v,t}` is identical
in the two histories. The function and, when present, the external random
choice are also shared. The outputs at `v` are therefore equal, which puts `v`
outside `D_{t+1}` and proves the lemma.

The theorem now follows by induction on `t`.

At `t = 0`, the initial-condition hypothesis gives `D_0 subset S = C_0(S)`.

If `D_t subset C_t(S)`, monotonicity of `R^+`, the one-step lemma, and the
definition of `C_{t+1}(S)` give

```text
D_{t+1} subset R^+(D_t)
        subset R^+(C_t(S))
        subset C_t(S) union R^+(C_t(S))
        = C_{t+1}(S).
```

Hence `D_t subset C_t(S)` for every finite tick. Notice that the proof gives a
containment, not a claim that every reachable vertex must change: a local
function may ignore an allowed input, or distinct effects may cancel.
