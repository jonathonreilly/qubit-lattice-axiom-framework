## Summary

The old finite-path explanation imported a scalar/ray picture to explain the
measured `kubo_true(b)` slope.  That is not the native centroid observable.
The exact first-order detector-centroid response is the adjoint edge sum

```text
alpha(b) = sum_e c_e / (sqrt((x_e - x_src)^2 + (z_e - b)^2) + eps).
```

For a finite edge list this has the expansion

```text
alpha(b) = M0/b + M1/b^2 + M2/b^3 + O(b^-4),
M0 = sum_e c_e,
M1 = sum_e c_e (z_e - eps).
```

The fixed harness certificate gives a nearly cancelled monopole and a live
signed dipole:

```text
|M0|/sum|c| = 1.293740e-04
|M1|/sum|c| = 1.243191e-01
sign split |c| positive/negative = 0.500/0.500
dipole-window slope on b=[30,45,60,80] = -2.020343
```

The decisive no-go is simple: a nonzero nonnegative scalar-potential path or
layer sum has `M0 = sum w_e > 0`, hence its leading large-`b` term is `M0/b`.
It cannot be the same detector-centroid functional unless the weights are
allowed to be signed and adjoint-dependent, which is exactly the wave/Kubo
structure rather than a textbook path-length import.

## Proof Sketch

For each edge let

```text
D_e(b) = sqrt((b - z_e)^2 + (x_e - x_src)^2) + eps.
```

For `b` larger than the finite edge support,

```text
D_e(b)^-1
  = b^-1 + (z_e - eps)b^-2
    + ((z_e - eps)^2 - (x_e - x_src)^2/2)b^-3 + O(b^-4).
```

Summing against the fixed adjoint coefficients gives the displayed multipole
series. A nonnegative scalar-potential layer model has the same expansion with
`c_e` replaced by `w_e >= 0`; if it is nonzero then `M0 = sum w_e > 0`, so the
monopole survives and the leading falloff is `b^-1`. The detector-centroid
response instead needs the signed adjoint cancellation.
