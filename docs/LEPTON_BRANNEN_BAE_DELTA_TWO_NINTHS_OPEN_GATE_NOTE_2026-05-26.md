## Claim

This note records a conditional charged-lepton mass-spectrum gate. It
does not derive the Brannen phase, the BAE coefficient, or the
dimensionful mass scale.

Given the Brannen/Koide algebraic form

```text
x_k / a = 1 + sqrt(2) cos(delta + 2 pi k / 3),  k = 0, 1, 2,
```

and the trial phase

```text
delta = 2 / 9 radians,
```

the dimensionless sorted positive ratios are

```text
electron-like:  0.040350...
muon-like:      0.580212...
tau-like:       2.379438...
```

Those ratios are close to the ratios extracted from the PDG charged
lepton masses after normalizing by
`a_PDG = (sqrt(m_e) + sqrt(m_mu) + sqrt(m_tau)) / 3`:

```text
electron:  +0.000001...
muon:      +0.000014...
tau:       -0.000015...
```

Equivalently, the PDG-extracted phase on the same Brannen-BAE chamber is

```text
delta_PDG = 0.222270... radians,
delta_PDG - 2/9 = 0.000047... radians.
```

This is useful downstream only if a future retained dynamics row derives
or admits the phase `delta = 2/9` for the charged-lepton readout. Until
then, the result is an open gate plus empirical comparator, not a
retained lepton-mass theorem.

## Boundaries

This open gate does not claim:

- a derivation of `delta = 2/9`;
- a derivation of the Brannen amplitude-equipartition coefficient
  `sqrt(2)`;
- a derivation of the overall charged-lepton scale `a`;
- absolute predictions of `m_e`, `m_mu`, or `m_tau`;
- a neutrino-sector result;
- a new axiom, new theory language, or new retained status.

The Koide ratio `Q = 2/3` is not evidence for `delta = 2/9`, because the
Brannen/Koide algebraic identity gives `Q = 2/3` for every phase once
the `sqrt(2)` coefficient is assumed. The phase-sensitive content is
only the sorted dimensionless ratios and the closeness of `delta_PDG`
to `2/9`.
