## Scope

This note preserves the durable part of the lepton mass scale proposal
as an empirical open gate. It does **not** prove a lepton mass theorem
and does **not** derive the electroweak scale.

The recorded observation is:

```text
a_lepton^2 := ((sqrt(m_e) + sqrt(m_mu) + sqrt(m_tau)) / 3)^2
m_W / 4^4 = m_W / 256
```

using PDG charged-lepton masses and PDG `m_W`, the two quantities agree
at about `0.033%`:

```text
m_W / 256       = 313.9421875 MeV
a_lepton^2      = 313.8411267 MeV
relative offset = 0.03220%
```

This is a numerical target for a future derivation of the `1/256`
factor. The note only records that the target is sharp and internally
well-defined.

## What Is Imported

- PDG `m_W = 80369.2 MeV`.
- PDG charged-lepton masses `m_e`, `m_mu`, and `m_tau`.
- The Brannen/Koide square-root mass coordinate used to define
  `a_lepton`.
- The repository baseline that the one-qubit operator algebra
  `M_2(C)` has complex dimension `4`.

Those are empirical/comparator inputs here, not derivations. Because
`m_W` and the lepton masses are observed quantities, this row cannot be
a retained structural theorem.
