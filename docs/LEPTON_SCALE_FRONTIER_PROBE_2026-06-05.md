**scale** derivable from the retained framework, or is it the irreducible

**Verdict: FREE-FLAVOR-INPUT, modulo a sharply-located open gate.** On the
current retained surface the charged-lepton scale is one irreducible real

## 1. Setup: the scale is one real number

The retained charged-lepton spectrum factorizes as

```text
{m_e, m_μ, m_τ}  =  (overall scale a²)  ×  (shape from r = 1/2, θ = 2/9).
```

The shape (Brannen/Koide direction) fixes the ratios. With the Koide value
`Q = 2/3` the total scale obeys `Σ m_k = 6 a²` exactly, where

```text
a := (√m_e + √m_μ + √m_τ) / 3      (Brannen square-root-mass mean).
```

So "the charged-lepton scale" is the single number `a²` (equivalently the
τ-Yukawa `y_τ`). The forward-leptons probe already established that this
number is not pinned to any other framework quantity (no `b-τ` relation,
no `lepton ↔ top` relation in-framework). The present probe asks whether
the **top-sector** scale mechanism has a working lepton analog.

## 4. Block-dimension Ward boundary FAILS for the lepton (Block C)

Hypothesis #2 of the attack — a lepton Ward boundary
`y_τ(M_Pl) = g_2 / sqrt(2)` analogous to the top's `g_s / sqrt(6)` — is
**quantitatively false**:

```text
observed   y_τ          = m_τ √2 / v        ≈ 0.0102
bare anchor 1/sqrt(2)    (g = 1)            ≈ 0.7071     →  overshoot ≈ 69×
bare anchor g_2/sqrt(2)  (g_2 ≈ 0.653)      ≈ 0.4615     →  overshoot ≈ 45×
```

RG running cannot bridge a 45–69× gap: a small lepton Yukawa runs by
percent-level amounts and toward **smaller** values in the IR, widening the
gap. The top anchor lands on the right scale only because `y_t ≈ 0.99` is
`O(1)` (the quasi-fixed-point / Ward boundary `y_t(M_Pl) = g_s/sqrt6`); the
lepton Yukawa is not `O(1)`. **A top-style block-dimension Ward boundary does
not, by itself, pin the lepton scale.**

This confirms and sharpens the prior SA-A no-go: the failure is not only the
absence of a color Fierz (Representation A) — even the block-dimension route
(Representation B), which *does* extend, overshoots by ~50×. The missing
ingredient is a **suppression**, not a different gauge anchor.

## 5. The `m_W/256` relation IS the missing suppression (Block D)

The audited-clean open-gate relation
([`LEPTON_MASS_SCALE_MW_OVER_256_EMPIRICAL_OPEN_GATE_NOTE_2026-05-26.md`](LEPTON_MASS_SCALE_MW_OVER_256_EMPIRICAL_OPEN_GATE_NOTE_2026-05-26.md),

```text
a_lepton² = m_W / 256 = m_W / (dim_C M_2(C))^4      (offset ≈ 0.032%).
```

Mapping the scale `a²` (a mass) to a Yukawa via `m = y v/√2`, and using the

```text

        = (m_W / 256) · √2 / v
        = (g_2 v / 2 / 256) · √2 / v
        = g_2 · √2 / 512
        = g_2 · (1/sqrt(2)) · (1/256).               (★)
```

The three factors and their provenance:

| factor | value | provenance |
|---|---|---|
| `g_2` | SU(2) weak coupling | the lepton's **actual** non-abelian gauge: `L_L = (2,1)` is an SU(2) doublet |
| `1/sqrt(2)` | block-dim normalization | **exactly** the D17-prime lepton block-dim factor `Z_lep = sqrt(N_c·N_iso) = sqrt(2)` |
| `1/256` | `1/(dim_C M_2(C))^4` | the **residual open gate** — no counterpart in the top sector |

The algebra in `(★)` is exact (`√2/512 ≡ (1/√2)/256`); the only empirical
input is `a² = m_W/256` itself (0.032%), and the only tree-level SM input is
`m_W = g_2 v/2`.

So the lepton scale **partially mirrors** the retained top Ward boundary:
the `g_2 · (1/√2)` part is the precise lepton analog of the top's
`g_s · (1/√6)`. What is left over — the entire content of the open gate — is
the factor `1/256 = 1/(dim_C M_2(C))^4`.

## 6. The top/lepton asymmetry IS the open gate (Block E)


The block-dimension ratio is structural and clean:

This locates the open derivation target precisely. The lepton-scale question
is **not** "find a lepton gauge anchor" (the anchor `g_2/√2` is present and
matches the top template); it **is** "derive `1/256 = 1/(dim_C M_2(C))^4`
without using `m_W` or lepton masses." The block-dimension and gauge pieces

## 7. Answers to the three attack hypotheses

- **Hypothesis #1 (is `y_τ / y_t` derivable?).** Partially. The
  block-dimension ratio `1/sqrt(6) : 1/sqrt(2) = 1 : sqrt(3)` is structural
  (both are `1/sqrt(N_c·N_iso)` for the respective blocks). The remaining
  factor between `y_τ` and `y_t` is the `1/256` suppression, which is **not**
  derivable on the retained surface. So `y_τ/y_t` is structural up to `1/256`.

- **Hypothesis #2 (is there a lepton Ward boundary `y_τ = g/sqrt2`?).** The
  **anchor** exists (D17-prime `1/√2`, gauge `g_2`), but as a **Ward boundary
  value** it **fails by 45–69×** (§4). A bare block-dimension boundary lands
  at `O(1)`, like the top; the lepton needs the `1/256` suppression that the
  top lacks.

- **Hypothesis #3 (is it the irreducible per-sector input?).** **Yes** on the
  retained surface — one real number — but with the gate now sharpened: the
  one number is `1/256 = 1/(dim_C M_2(C))^4` (the gauge `g_2` and block-dim
  `1/√2` pieces are not free; they are the lepton analog of the retained top
  structure).
