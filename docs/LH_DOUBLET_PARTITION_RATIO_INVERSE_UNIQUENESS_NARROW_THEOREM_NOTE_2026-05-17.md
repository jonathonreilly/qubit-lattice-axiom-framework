## Statement

Let `N >= 2` be a fixed positive integer and let `k >= 1` be a fixed
positive integer. Consider the set

```text
P(N)  :=  { (m, n) in Z_{>=1} x Z_{>=1}  :  m + n = N }
```

of ordered positive-integer partitions of `N` into two parts. For each
`(m, n) in P(N)`, the trace condition

```text
(L1)   m * alpha + n * beta  =  0
```

on a single unique traceless abelian generator with eigenvalue `alpha`
on the `m`-multiplicity block and eigenvalue `beta` on the
`n`-multiplicity block has a one-parameter family of real solutions

```text
beta  =  - (m / n) * alpha
```

i.e. the ratio is forced to `beta / alpha = -(m / n)`. Now require
additionally that this ratio equals `-k` (i.e. that `beta / alpha`
is the negative of a fixed positive integer `k`). Then:

```text
(R1)  beta / alpha  =  -k   <==>   m / n  =  k
                                      <==>   m  =  k * n.
(R2)  Under the trace-surface constraint m + n = N, substitution gives
        k * n + n  =  N,
        n  =  N / (k + 1),
        m  =  k * N / (k + 1).
(R3)  The pair (m, n) is in P(N) (i.e. m >= 1 and n >= 1) if and only if
        (k + 1) divides N    and    N >= k + 1.
(R4)  Whenever (R3) holds, the pair (m, n) determined by (R2) is the
        unique element of P(N) with beta / alpha = -k.
```

The framework instance `(N, k) = (8, 3)` gives the rational closed-form
readout

```text
(k + 1)  =  4    divides    N = 8,
n  =  8 / 4  =  2,
m  =  3 * 8 / 4  =  6,
(m, n)  =  (6, 2)
```

so the LH-doublet partition is forced uniquely. The runner additionally
verifies the inverse-uniqueness sweep across the seven ordered partitions
of `N = 8` (namely `(1, 7), (2, 6), (3, 5), (4, 4), (5, 3), (6, 2),
(7, 1)`) showing the corresponding ratios `(-1/7, -1/3, -3/5, -1, -5/3,
-3, -7)` — confirming `(6, 2)` is the only partition with ratio `-3` and
that no other partition of `8` produces any other negative integer ratio
other than the already-named `(7, 1) -> -7, (4, 4) -> -1`.

## Proof

`(R1)` Solve `(L1)` for `beta`:

```text
m * alpha + n * beta  =  0,
n * beta  =  - m * alpha,
beta  =  - (m / n) * alpha,
beta / alpha  =  - m / n.
```

Setting `beta / alpha = -k` with `k` a positive integer:

```text
- m / n  =  - k,
m / n  =  k,
m  =  k * n.
```

`(R2)` Substitute `m = k * n` into the trace-surface state-count
constraint `m + n = N`:

```text
k * n + n  =  N,
(k + 1) * n  =  N,
n  =  N / (k + 1),
m  =  k * n  =  k * N / (k + 1).
```

`(R3)` For `(m, n)` to be in `P(N)` (positive integers summing to `N`),
both `m >= 1` and `n >= 1` are required. Substituting from `(R2)`:

```text
n  =  N / (k + 1)  >= 1   <==>   N  >=  k + 1,
m  =  k * N / (k + 1)  >= 1   <==>   k * N  >=  k + 1.
```

For positive integers `k >= 1` and `N >= 2`, the second inequality is
automatic once `N >= (k + 1) / k = 1 + 1/k`; for any `N >= 2` it is
satisfied. Integrality of both `m` and `n` requires `(k + 1)` to
divide `N`.

`(R4)` Uniqueness within `P(N)`: suppose `(m', n') in P(N)` also
satisfies `m' / n' = k` (i.e. has ratio `-k`). Then `m' = k * n'` and
`m' + n' = N`, so `(k + 1) * n' = N` and `n' = N / (k + 1) = n`. Hence
`m' = m`. The pair is unique. ∎

## Framework instance and counterfactuals

Specialized to `N = 8`:

```text
P(8)  =  { (1, 7), (2, 6), (3, 5), (4, 4), (5, 3), (6, 2), (7, 1) }
```

The map `(m, n) -> -m / n` gives the seven ratios

```text
(1, 7) -> -1/7,
(2, 6) -> -1/3,
(3, 5) -> -3/5,
(4, 4) -> -1,
(5, 3) -> -5/3,

```

Out of seven partitions, only three give *integer* ratios: `(4, 4) -> -1`,
`(6, 2) -> -3`, `(7, 1) -> -7`. The framework target `k = 3` is hit by
exactly one partition `(6, 2)`. This confirms `(R4)` for the framework
instance and shows the partition is uniquely forced by the ratio.
