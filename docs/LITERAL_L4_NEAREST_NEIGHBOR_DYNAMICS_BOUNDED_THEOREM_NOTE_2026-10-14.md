## 5. Exact ordinary-NN Pauli rotations with arbitrary dirty transit

For a nonempty Pauli word P, sort its support by active factor index and choose the first factor p as pivot. At an X factor apply H; at a Y factor apply S† then H; at a Z factor do nothing. Let this tensor product basis change be B_P. Its phases obey

`B_P P B_P†=product_(q in supp P) Z_q`.

Next apply `CNOT(q→p)` for every other q in increasing index order. If C is this parity word, `C†Z_p C=product Z_q`. Apply the literal one-site rotation

then undo the CNOTs in reverse order and the basis changes in reverse order with their actual adjoints. The resulting matrix is

`B_P† C† exp(-i theta Z_p) C B_P = exp(-i theta P)`.          (15)

The pivot can be an arbitrary unknown input, entangled with every other system. No clean parity ancilla, measurement, reset or initialized transit is used. This is unitary conjugation on all vectors, not a computational-basis-only calculation.

Every CNOT is physically routed. For ordinary representative coordinates l,r use the axis-ordered Manhattan path `v_0=l,...,v_d=r` within the box, adjusting coordinate 1, then 2, then 3. `Pi† CNOT_(v_(d-1),v_d) Pi=CNOT_(l,r) tensor I_other`.      (16)
