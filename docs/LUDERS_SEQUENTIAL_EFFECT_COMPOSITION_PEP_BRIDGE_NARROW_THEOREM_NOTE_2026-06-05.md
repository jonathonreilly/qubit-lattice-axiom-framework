The primitives, all standard on `M_d(C)`:

- an **orthogonal projection** `P`: `P = P†`, `P² = P` (so `0 ≤ P ≤ I`);
- an **effect** `E`: `E = E†`, `0 ≤ E ≤ I` (a POVM element);
- a **state** `ρ`: `ρ = ρ†`, `ρ ≥ 0`, `Tr ρ = 1` (a density operator);
- the **trace/effect pairing** `(ρ, E) ↦ Tr(ρ E)` (the candidate probability
  functional);
- the **Lüders update** `ρ ↦ ρ|_P = (P ρ P)/Tr(P ρ P)` (the parent's derived
  rule, taken here as the given upstream state-update map).

## 2. Load-bearing step (B1) — `M_{P,E} = P E P` is the effective two-step operator

Compose the two physical steps. After the Lüders update with outcome `P`, the
state is `ρ|_P = (P ρ P)/Tr(P ρ P)`. The probability of then observing the
effect `E` is, by the trace/effect pairing,

```text
p(E | P) = Tr(ρ|_P · E) = Tr( (P ρ P / Tr(P ρ P)) · E )
         = Tr(P ρ P · E) / Tr(P ρ P).
```

By trace cyclicity `Tr(P ρ P · E) = Tr(ρ · P E P)` and `Tr(P ρ P) = Tr(ρ · P)`,
so

```text
p(E | P) = Tr(ρ · P E P) / Tr(ρ · P),       hence
Tr(ρ · P E P) = Tr(ρ · P) · p(E | P) = p(P) · p(E | P) = p(P then E).
```

The left-hand operator paired against `ρ` is `P E P`; reading off the effect
that produces the chained probability `p(P then E)` against the **pre-update**
state `ρ` gives the **effective two-step (sequential) effect operator**

```text
M_{P,E} = P E P.
```

This is the standard sequential-effect product. The runner reproves the chain
exactly on a rational `d = 2` instance (common value `12163/16900`, all rational)
and numerically over `d = 2, 3, 4` (residuals `~10⁻¹⁵`). Trace cyclicity itself
is reproven exactly (`Part 0`).

The boundary conditions are immediate and are reproven exactly:
`M_{P,I} = P I P = P² = P` and `M_{I,E} = I E I = E`. These are the conditions the
parent's Step 4 invokes; §6/`Part 6` records that they are **necessary but not
sufficient** to single out `P E P`.

## 3. Load-bearing step (B2) — `0 ≤ P E P ≤ P ≤ I` (valid effect)

`P E P` must itself be a legitimate effect for the two-step reading to be
consistent. Reproven from primitives:

- **Positivity.** For any vector `v`, `⟨v, P E P v⟩ = ⟨P v, E (P v)⟩ ≥ 0` since
  `E ≥ 0` (`P = P†`). So `P E P ≥ 0` (congruence by `P` preserves positivity).
- **Upper bound `P E P ≤ P`.** `I − E ≥ 0`, so `P(I−E)P ≥ 0` by the same
  congruence. Using `P² = P`, `P(I−E)P = P − P E P`, hence `P − P E P ≥ 0`, i.e.
  `P E P ≤ P`.
- **`P ≤ I`.** `I − P` is an orthogonal projection (the complementary
  projection), hence `≥ 0`.

So `0 ≤ P E P ≤ P ≤ I`: `P E P` is a valid effect, supported on `range(P)` (it
annihilates `ker P`). The runner reproves the spectra exactly on `d = 2`
(`spectrum(P E P) = [0, 12163/16900]`, `spectrum(P − P E P) = [0, 4737/16900]`,
`spectrum(I − P) = [0, 1]`) and numerically over `d = 2, 3, 4` (most-negative
eigenvalues `≥ −10⁻¹⁵`), including the exact congruence identity
`P − P E P = P(I − E)P`.

## 4. Load-bearing steps (B3), (B4) — trace pairing and associative-consistency

**(B3) Trace/effect pairing.** `ρ ↦ Tr(ρ E)` is **linear** in `ρ`
(`Tr` is linear), so on a convex mixture `Tr((a ρ₁ + (1−a) ρ₂) E) =
a Tr(ρ₁ E) + (1−a) Tr(ρ₂ E)`. On a state `ρ` and effect `E`, `Tr(ρ E)` is
**real** (both Hermitian) and lies in **`[0,1]`**: writing `ρ = Σ_k p_k |k⟩⟨k|`
with `p_k ≥ 0`, `Σ p_k = 1`, `Tr(ρ E) = Σ_k p_k ⟨k|E|k⟩` is a convex combination
of `⟨k|E|k⟩ ∈ [0,1]` (because `0 ≤ E ≤ I`), hence in `[0,1]`. The runner reproves
linearity (residuals `~10⁻¹⁶`), reality (`|Im| ≤ 10⁻¹⁶`), and the `[0,1]` bound
over `d = 2, 3, 4`. This is the standard-math probability representation the
parent imports.

**(B4) Associative-consistency.** For projections `P, Q` and effect `F`, compose
"`Q` then `F`" into `M_{Q,F} = Q F Q` (a valid effect by §3), then "`P` then
`M_{Q,F}`" into `P (Q F Q) P`. This equals the compositional form
`(QP)† F (QP) = P Q F Q P` that the parent's `(U4)` check uses for the composite
Kraus operator `QP` (the parent's Step 3 writes the two-projection update via
`P₂ P₁`). The runner reproves `P (Q F Q) P = (QP)† F (QP)` over `d = 2, 3, 4`
(residuals `~10⁻¹⁶`), confirms the outer composition stays a valid effect
(`0 ≤ · ≤ P`), and reproves the boundary collapse `P Q I Q P = P Q P` at `F = I`.
An exact `d = 3` commuting/nested case (`Part 5`) shows the product reduces to
the expected common-support effect (`diag(1/2, 0, 0)`).
