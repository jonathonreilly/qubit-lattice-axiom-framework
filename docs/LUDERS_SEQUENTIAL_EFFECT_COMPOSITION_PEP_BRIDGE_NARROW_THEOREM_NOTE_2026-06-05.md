## Claim

This row is narrowed to a finite matrix theorem. In `M_d(C)`, let `P` be an
orthogonal projection, `E` an effect (`0 <= E <= I`), and `rho` a density
operator. Define the compressed effect

```text
M_{P,E} = P E P.
```

Then:

- `P E P` is Hermitian and positive.
- `0 <= P E P <= P <= I`, so the compression is a valid effect supported on
  `range(P)`.
- Trace cyclicity gives the exact scalar identity
  `Tr(rho P E P) = Tr(P rho P E)`.
- Boundary cases close: `P I P = P` and `I E I = E`.
- Nested compression is composition-compatible:
  `P(Q F Q)P = (Q P)^* F (Q P)`.

That is the load-bearing content. The note does not claim that the framework
has derived a measurement update, a Born rule, a trace/effect probability
pairing, or a probability interpretation for the trace scalar. If a downstream
row separately supplies those measurement-side premises, this finite theorem is
available as algebraic support for the `P E P` compression.

## 2. Compression Is A Valid Effect

For any vector `v`,

```text
<v, P E P v> = <P v, E P v> >= 0,
```

so `P E P >= 0`. Since `I - E >= 0`,

```text
P - P E P = P(I - E)P >= 0,
```

and because `P` is an orthogonal projection, `P <= I`. Hence
`0 <= P E P <= P <= I`.

## 3. Trace Identity

The trace scalar associated with the compressed effect is

```text
Tr(rho P E P).
```

Finite-dimensional trace cyclicity gives

```text
Tr(rho P E P) = Tr(P rho P E).
```

This is the algebraic identity often used inside a Lüders-style downstream
calculation, but here it is only a trace-compression identity.

## 4. Nested Compression

For another projection `Q` and effect `F`,

```text
P(QFQ)P = P Q F Q P = (Q P)^* F (Q P),
```

because `P = P^*` and `Q = Q^*`. The nested compression is again a valid effect
bounded by `P`, and the `F = I` boundary gives `P Q P`.
