## 1. Setup and finite effect-pairing derivation

By the Quantum axiom
([`MINIMAL_AXIOMS_2026-06-05.md`](MINIMAL_AXIOMS_2026-06-05.md), §"Quantum"),
the per-site operator algebra is `A_x ~= M_2(C)`. Finite regions live in finite
matrix carriers. The statements here are finite linear algebra, checked on
`M_d(C)` for `d = 2, 3, 4`.

Hypotheses:

- `P` is an orthogonal projection: `P = P^*`, `P^2 = P`;
- `E,F` are effects: `0 <= E,F <= I`;
- `m` is a normalized finite effect-probability functional satisfying:
  `m(0)=0`, `m(I)=1`, and POVM additivity over finite partitions
  `{E_i}` with `sum_i E_i=I`;
- the projective record uses the canonical retained frame `K_P=P`;
- `Tr(rho P) > 0`, after `rho` is reconstructed from `m`.

The trace/effect pairing is not assumed. It follows from the finite
effect-algebra calculation below.

### 1.1 Effect additivity forces real linearity

The complement law follows from the two-outcome POVM `{E, I-E}`:

```text
m(E) + m(I-E) = 1.
```

If `E_1 + E_2 <= I`, then `{E_1, E_2, I-E_1-E_2}` is a POVM, so

```text
m(E_1 + E_2) = m(E_1) + m(E_2).
```

Iterating gives rational homogeneity on the effect cone, and boundedness
`0 <= m <= 1` upgrades the one-dimensional Cauchy relation to real
homogeneity on `[0,1]`. Any Hermitian `H` can be shifted and rescaled into the
effect interval, so `m` extends uniquely to a real-linear functional `F` on
`Herm(M_d(C))`.

### 1.2 Riesz representation gives the trace/effect pairing

The real vector space `Herm(M_d(C))` has Hilbert-Schmidt inner product
`<A,B> = Tr(AB)`. By finite-dimensional Riesz representation, there is a unique
Hermitian `rho` with

```text
F(H) = Tr(rho H)
```

for all Hermitian `H`. Normalization gives `Tr rho = F(I)=m(I)=1`. Positivity
on every rank-one projector gives `<psi|rho|psi> = m(|psi><psi|) >= 0`, so
`rho >= 0`. Therefore `rho` is a density matrix and, for every effect `E`,

```text
m(E) = Tr(rho E).
```

This is the finite-dimensional effect-pairing theorem needed here. It does not
assert that the minimal axioms themselves create a physical measurement
context; it says that once the row is in the finite effect/probability setting,
the trace pairing is no longer a separate import.

## 2. Canonical projective branch - `K_P=P` gives the Lüders update

The retained LSP-projective theorem constructs the canonical projective
measurement dilation and derives the outcome Kraus operator

```text
K_P = P.
```

The retained finite Kraus-instrument theorem gives the selective branch state
for any nonzero branch probability:

```text
rho|_P = K_P rho K_P^* / Tr(K_P rho K_P^*).
```

Substituting `K_P=P=P^*` gives

```text
rho|_P = P rho P / Tr(P rho P).
```

This is the Lüders update in the canonical projective frame. It is derived from
the retained `K_P=P` and finite Kraus selective-state algebra, not added as a
new axiom and not imported as an unexplained premise.

## 3. Sequential identity - `P E P` represents the two-step probability

Using the finite trace/effect pairing from §1 and the branch update from §2,

```text
p(E | P) = Tr(rho|_P E)
         = Tr((P rho P / Tr(P rho P)) E)
         = Tr(P rho P E) / Tr(P rho P).
```

Trace cyclicity gives `Tr(P rho P E) = Tr(rho P E P)` and
`Tr(P rho P) = Tr(rho P)`, so

```text
Tr(rho P E P) = Tr(rho P) * Tr(rho|_P E).
```

Therefore the pre-update effect paired against `rho` for the chained
probability is `M_{P,E} = P E P`.

The boundary conditions are immediate:

```text
M_{P,I} = P I P = P,
M_{I,E} = I E I = E.
```

The runner checks the identity exactly on a rational `d = 2` instance and
numerically over `d = 2, 3, 4`.

## 4. Valid-effect support - `0 <= P E P <= P <= I`

`P E P` is a legitimate effect under the stated hypotheses:

- Positivity: for any vector `v`,
  `<v, P E P v> = <P v, E P v> >= 0`.
- Upper bound by `P`: since `I - E >= 0`,
  `P(I - E)P >= 0`; using `P^2 = P`, this is `P - P E P >= 0`.
- Upper bound by `I`: since `P` is an orthogonal projection, `I - P >= 0`.

Thus `0 <= P E P <= P <= I`, with support inside `range(P)`.

## 5. Trace/effect and associativity checks

The runner checks the elementary support properties of the trace/effect pairing
generated by the finite effect-probability derivation:

```text
Tr((a rho_1 + (1-a) rho_2) E)
  = a Tr(rho_1 E) + (1-a) Tr(rho_2 E),
0 <= Tr(rho E) <= 1
```

for states `rho`, effects `E`, and `a in [0,1]`.

For projections `P,Q` and effect `F`, the canonical sequential product gives

```text
P (Q F Q) P = (Q P)^* F (Q P),
```

which is the matrix form used by the parent composition check. The runner also
checks that the outer composition is again a valid effect and that the `F = I`
boundary collapses to `P Q P`.
