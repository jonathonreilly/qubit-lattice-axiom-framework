## Proof

As a complex vector space, `M_2(C)` has basis

```text
E_11, E_12, E_21, E_22
```

so `dim_C(M_2(C)) = 4`.

For finite-dimensional complex vector spaces,

```text
dim_C(V ⊗_C W) = dim_C(V) dim_C(W).
```

By induction,

```text
dim_C(M_2(C)^⊗d) = dim_C(M_2(C))^d = 4^d.
```

At the bounded parameter value `d=4`,

```text
dim_C(M_2(C)^⊗4) = 4^4 = 256.
```

Equivalently, using the matrix-algebra identity

```text
M_n(C) ⊗_C M_m(C) ~= M_{nm}(C),
```

one obtains

```text
M_2(C)^⊗4 ~= M_16(C)
dim_C(M_16(C)) = 16^2 = 256.
```

The reciprocal bookkeeping value is therefore exactly

```text
1 / dim_C(M_2(C)^⊗4) = 1/256.
```
