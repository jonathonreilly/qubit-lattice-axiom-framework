## 4. Proof

The proof is a linear-algebra rank count on the four-component complex
polarization vector `ε^μ` at fixed null momentum `k^μ` with `k^2 = 0`.

### 4.1 Plane-wave reduction

By (AC3), the source-free wave equation `∂_ν ∂^ν A_μ = 0` is solved by
the Fourier ansatz

```text
A^μ(x)  =  ε^μ  exp(i k · x),
```

with `k^μ` real and `k^2 := k_μ k^μ = 0` (null shell). The polarization
vector `ε^μ ∈ C^4` carries one Lorentz index. At fixed null `k^μ`, the
question reduces to counting equivalence classes of `ε^μ` modulo the
gauge identification (L2) and the Lorenz-gauge condition (L3).

### 4.2 Step 1: Total Lorentz-vector dof count = 4

The polarization vector `ε^μ ∈ C^4` has `4` complex components (one per
Lorentz index, `μ = 0, 1, 2, 3`). At the level of real degrees of
freedom this is `8`, but the physical polarization count is the count
of independent complex helicity amplitudes per mode, conventionally
quoted as `4` (the four Lorentz-vector components before gauge fixing).

### 4.3 Step 2: Lorenz-gauge constraint kills 1 dof

Substituting the plane-wave ansatz into the Lorenz-gauge condition (L3)
gives

```text
∂_μ A^μ  =  i k_μ ε^μ exp(i k · x)  =  0
⟹  k_μ ε^μ  =  0.
```

This is one linear scalar constraint on the four-component complex
vector `ε^μ`. Since `k_μ ≠ 0` (the momentum is non-zero on the null
shell except at `k = 0`, which is excluded as the zero mode), the
constraint `k_μ ε^μ = 0` has rank `1` on `C^4`. The constraint reduces
the dimension by `1`:

```text
dim_C {ε^μ ∈ C^4 : k_μ ε^μ = 0}  =  4 − 1  =  3.
```

### 4.4 Step 3: Residual gauge orbit kills 1 dof

After raising the vector index, the gauge identification (L2)
`A^μ ↦ A^μ + ∂^μ Λ` on the plane-wave ansatz with
`Λ(x) = -i λ exp(i k · x)` becomes

```text
ε^μ  ↦  ε^μ  +  ∂^μ(-i λ exp(i k · x)) / exp(i k · x)
     =  ε^μ  +  k^μ λ
     ↦  ε^μ  +  c k^μ        (re-labelling c := λ).
```

Inside the Lorenz-gauge slice (after Step 2), the residual gauge
transformations preserving `k_μ ε^μ = 0` are exactly those with
`∂_ν ∂^ν Λ = 0`, i.e. `k^2 λ = 0`. Since `k^2 = 0` on the null shell,
this is satisfied automatically for every `λ`, so the residual gauge
freedom is the full one-parameter family `ε^μ ∼ ε^μ + c k^μ` for
arbitrary `c ∈ C`.

The vector `k^μ` itself lies in the Lorenz-gauge slice
(`k_μ k^μ = k^2 = 0`), so `k^μ` is in the kernel of the gauge-shift
quotient. The residual gauge orbit reduces the dimension by `1`:

```text
dim_C {ε^μ ∈ C^4 : k_μ ε^μ = 0} / {ε^μ ∼ ε^μ + c k^μ}
  =  3 − 1
  =  2.
```

### 4.5 Step 4: Net polarization count = 2

Combining Steps 1-3,

```text
#(real Lorentz-vector components)  −  #(Lorenz-gauge constraint)
   −  #(residual gauge orbit)
=  4  −  1  −  1
=  2.
```

The physical polarization equivalence-class space `C^4 / (Lorenz +
residual)` has complex dimension `2`. ∎

### 4.6 Explicit transverse basis at `k^μ = (ω, 0, 0, ω)`

To make Step 4 concrete, choose the canonical null momentum

```text
k^μ  =  (ω, 0, 0, ω),     k_μ  =  (ω, 0, 0, −ω),     k^2 = 0.
```

The Lorenz-gauge constraint `k_μ ε^μ = 0` becomes

```text
ω ε_0  −  ω ε_3  =  0  ⟹  ε_0  =  ε_3.
```

The residual gauge orbit `ε^μ ∼ ε^μ + c k^μ` shifts

```text
ε_0  →  ε_0 + c ω,
ε_3  →  ε_3 + c ω,
```

so we may choose `c` to set `ε_3 = 0`, which then forces `ε_0 = 0` (by
the Lorenz constraint). The remaining two independent complex
components are `ε_1` and `ε_2`, giving the standard transverse-spatial
polarization basis. ∎

This explicit construction realizes the abstract `4 − 1 − 1 = 2` count
on the conventional canonical null frame and exhibits the two
polarizations as the two transverse-spatial vector components.
