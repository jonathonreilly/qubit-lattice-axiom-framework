## 1. Claim Scope

Let `V = C^4`. Let `ell: V -> C` be a nonzero linear functional and let
`k in V` be a nonzero vector with `ell(k)=0`. Then

```text
dim_C ker(ell) / span_C{k} = 2.
```

Equivalently, a four-component complex vector constrained by one nonzero
linear row and quotiented by one nonzero direction lying inside that row's
kernel has quotient dimension

```text
4 - 1 - 1 = 2.
```

The canonical runner model uses the concrete pair

```text

```

so `ell(k)=0`, `rank(ell)=1`, `rank(k)=1`, and the quotient has two
independent representatives, for example `(0,1,0,0)^T` and `(0,0,1,0)^T`.

## 4. Proof

Because `ell` is a nonzero linear functional on `C^4`, rank-nullity gives

```text
dim_C ker(ell) = 4 - rank(ell) = 4 - 1 = 3.
```

Because `k` is nonzero and `ell(k)=0`, the line `span_C{k}` is a one-dimensional
subspace of `ker(ell)`. Quotienting by that line gives

```text
dim_C ker(ell) / span_C{k}
  = dim_C ker(ell) - dim_C span_C{k}
  = 3 - 1
  = 2.
```

For the canonical runner pair,

```text
ell(eps) = eps_0 - eps_3,
k = (1,0,0,1)^T.
```

The kernel condition is `eps_0 = eps_3`. Modding out by the line generated by
`k` removes the common `(eps_0, eps_3)` direction. The two surviving coordinate
representatives are the second and third basis vectors.
