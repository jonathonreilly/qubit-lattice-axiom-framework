## What this note adds: the explicit `dim^s` interpolation

Weight each isotype block by `dim^s`. The doublet/singlet relative weight is `2^s`.
Concretely the measure balances the two isotype **slots** with a doublet weight
`3·2^(1−s)`:

```
s = 0  ->  doublet weight 6  = equal PER-BLOCK power (block-count)    ->  r = 1/2  (Q = 2/3)
s = 1  ->  doublet weight 3  = equal PER-DIM   power (dimension/Born) ->  r = 1    (Q = 1)
```

Solving `3a² = (3·2^(1−s))|b|²` gives the **closed form**

```
r(s) = 2^(s−1),      Q(s) = (1 + 2·2^(s−1))/3,      dr/ds = 2^(s−1) ln 2 > 0.
```

`r(s)` is **strictly monotone increasing**: `s=0 → r=1/2`, `s=1 → r=1`. This is a
**derivation**, not a fit — the endpoints reproduce the two canonical retained
readouts, and `s` is the explicit interpolation parameter the prior notes left

> `s` = **how much the mass-record weighs WITHIN-BLOCK (quantum/dimension) structure**
> versus only the 2-sector **PARTITION** (the cut). `s=0` = record resolves only the
> partition (classical/partition-only); `s=1` = record resolves the full within-block
> dimension (Born/quantum).
