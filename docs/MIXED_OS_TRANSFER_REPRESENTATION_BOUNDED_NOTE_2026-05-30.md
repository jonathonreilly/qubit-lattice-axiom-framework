## The deliverable (lead)

This note establishes, on explicit finite carriers, the **fermion-sector
representation equality**: the reflected Berezin/Grassmann block metric of the
staggered fields equals the operator two-step transfer eigenvalue,

```text
   <Theta(chi_a) chi_b>_Berezin-block-metric   has single positive eigenvalue   c_block · e^{-2E_j}
```

per spatial mode `j` (with `E_j = asinh(sqrt(m^2 + lambda_j^2))`), on the 2-step
blocked staggered surface under the temporal-link reflection
`theta(t, x_vec) = (-1 - t, x_vec)`. The left side is computed by genuine
Grassmann/Wick contraction with the staggered propagator `M^{-1}` (real `M^{-1}`
contractions, with **no** operator-side reference); the right side `e^{-2E_j}` is
the free-fermion operator two-step transfer eigenvalue on Fock space. The two are
**independently-computed code paths** sharing only the lattice action (the
spatial-hop spectrum `{E_j}`).

This equality is verified at three levels: (i) per spatial mode; (ii) per fixed
gauge background (`U(1)` and `SU(3)`); and (iii) — the genuine many-field test — on
the **full position-basis many-field Berezin Gram** (every Grassmann
cross-contraction, no per-mode reduction), whose positive eigenvalues reproduce the
operator spectrum and thereby fix the block normalization `c_block = 2`
**a priori** (mode- and mass-independent — a principled normalization, not a fitted
constant). The single-step construction is a built-in **negative control** that
must *break* the equality (its reflected metric is indefinite), and the
`eta_1(t) = (-1)^t` reflection sign of the 2-step block is the load-bearing physics.

This is **not** the assembly inequality
`<Omega| O_hat^dag T_full O_hat |Omega> = || W O_hat Omega ||^2 >= 0`, which is
trivially true once `T_full` is posited (that is the prior assembly lemma, recorded
in `RP_MIXED_OBSERVABLE_SINGLE_TRANSFER_MATRIX_NARROW_THEOREM_NOTE_2026-05-29.md`).
The new content here is the **equality of two independently-computed fermion-sector
objects**: the Berezin block metric and the operator transfer eigenvalue live in two
separate code paths and no prior runner checks that they agree.

**Not established here (scope boundary).** This note does **not** establish the full
gauge-fermion-**entangled** representation equality — a genuine many-field Grassmann
integral of a *mixed* (gauge × fermion) observable at each `U`, compared to the
operator sandwich. That object is the assembly target of
`RP_MIXED_OBSERVABLE_SINGLE_TRANSFER_MATRIX_NARROW_THEOREM_NOTE_2026-05-29.md` and is
the harder open step; it remains open. Likewise the det(M[U]) positive weight and

## Why two steps, and why the single-step version breaks the equality

Under `theta(t, x) = (-1 - t, x)` the staggered phase flips,
`eta_1(theta t) = -eta_1(t)`. This is precisely the place the single-step
construction fails, so it is where scrutiny is hardest; the runner handles it
explicitly.

- **Single-step (negative control).** The naive single-slice reflection
  `Theta(chi_0) = + bar(chi)_{theta 0}` (the Sharatchandra map without the staggered
  phase compensator) yields a reflected positive-cone metric that is **indefinite**
  (per-mode min eig `−0.5528`; full naive Lagrangian Gram min eig `−0.8000`,
  reproducing the documented Caracciolo–Palumbo 2013 no-go). An indefinite metric
  cannot equal any positive operator sandwich, so the single-step equality is
  violated. The runner asserts this violation (so the positive result is not an
  artifact of a trivially-true construction).
- **Two-step (the fix).** The 2-step blocking is exactly the modification that
  restores `Theta`-covariance. On the block (slices `0, 1`) the Osterwalder–Seiler
  fermion reflection carries the `gamma_0`-type sign, `Theta(chi) = - bar(chi)_{theta}`;
  this is the convention determined by reflection = adjoint, not a free parameter
  (the opposite sign is the single-step naive map above). The reflected block metric
  is then positive-semidefinite, with one physical positive eigenvalue per spatial
  mode equal to `c_block · e^{-2E_j}`, `c_block = 2` (two Grassmann pairs per 2-step
  block; a mode-independent normalization, verified numerically against `e^{-2E_j}`).
  The single positive eigenvalue per mode is the reconstructed-state norm, and its
  value `e^{-2E_j}` is the operator two-step transfer eigenvalue — the equality.

The runner additionally verifies that the Berezin forward two-point function decays
as `e^{-2E(p)}` per 2-step block (the transfer eigenvalue appearing **inside** the
path integral), confirming the construction is faithful to the staggered action and
not an artifact of the reflection convention.

## The per-config equality assembled in a shared gauge/Fock wrapper (CHECK 3) — and what it does *not* establish

The runner also assembles the per-config fermion-sector equality into a shared
operator wrapper on `H_gauge (x) H_ferm` and compares an operator-side Gram
`G_operator` to a Berezin-side Gram `G_Berezin` across a basis of observables
`F = f(U) ⊗ (fermion)`. This check is **honest context, not an independent test of
gauge–fermion mixing**, for the following structural reason:

- `G_operator` uses `T_full = (Kg^{1/2} ⊗ I)(⊕_U B[U]^dag B[U])(Kg^{1/2} ⊗ I)` with
  the operator-derived fermion blocks `Top = B[U]^dag B[U]`;
- `G_Berezin` uses the **same** quadratic form with the **same** Wilson kernel `Kg`
  (one object, used identically), the **same** flat reference state `Omega`, the
  **same** observables and the **same** Fock operators — replacing only the fermion
  block by the independently-computed Grassmann per-config block metric `Tber`.

Because the gauge half, the reference state, the observables and the Fock operators
are identical on both sides, `G_Berezin − G_operator` is a **pure function of the
per-block fermion difference `Tber − Top`**. Concretely, forcing `Tber := Top`
drives `|G_Berezin − G_operator|` to exactly `0` while the operator-Schmidt rank of
`T_full` is unchanged. So the rank `> 1` ("entangled"), the basis dimension, and the
mixed-observable count are **diagnostics of the wrapper, not load-bearing evidence**
of a gauge-fermion-entangled representation equality. Moreover `Tber = ⊗_j diag(1,
cov_j)` is per-mode factorized — it is *not* a genuine many-field Grassmann integral
of a mixed observable.

The genuine content this check delivers is therefore exactly the **per-config
fermion-sector equality** `Tber = Top` (worst per-block residual `3.2e-14` for
`U(1)`, `1.5e-14` for `SU(3)`), already established per mode (CHECK 1) and per fixed
background (CHECK 2), here exhibited inside a shared operator wrapper. A shared
finite gauge sample feeds both sides, so the comparison is exact, not statistical.

**Not established by this check.** The full gauge-fermion-**entangled**
representation equality — a many-field Grassmann integral of a *mixed* observable at
each `U` compared to the operator sandwich — is **not** tested here, because the
gauge/entanglement structure is carried identically on both compared sides rather
than being computed independently from the Berezin path integral. That mixed object
(together with the det(M[U]) weight and the Haar `U`-average) is the open assembly
target of `RP_MIXED_OBSERVABLE_SINGLE_TRANSFER_MATRIX_NARROW_THEOREM_NOTE_2026-05-29.md`
and the harder open step; it remains open.
