## Statement

Fix the finite periodic tensor-product Fock space `H_Lambda` and
translations `T_a` from the cited bridge. Define

```text
    Q_total := sum_x a_x^dag a_x.
```

Then:

**(C1) Charge is translation invariant.**

```text
    T_a Q_total T_a^dag = Q_total,
    [T_a,Q_total] = 0.                                  (1)
```

**(C2) Axial finite-block spectral generators commute with charge.** For
an axial unit translation `T_{e_mu}`, choose a Hermitian finite-block
spectral generator

```text
    K_mu := sum_theta theta Pi_theta,
    T_{e_mu} = sum_theta exp(i theta) Pi_theta,          (2)
```

with `theta` in a fixed branch and `Pi_theta` the spectral projectors of
`T_{e_mu}`. Then

```text
    [K_mu,Q_total] = 0.                                  (3)
```

**(C3) Common finite-block labels.** On this finite tensor-product
surface, `Q_total` and the commuting axial `K_mu` can be simultaneously
diagonalized after resolving degeneracies inside common eigenspaces.

## Proof

### Step 1 - Translation preserves total charge

The cited bridge proves

```text
    [T_a,Q_total] = 0
```

for every finite-block translation. This is exactly (C1).

### Step 2 - Spectral-generator commutation

Let `T := T_{e_mu}`. Since `T` is unitary, it is normal and has a
finite-dimensional spectral resolution

```text
    T = sum_theta exp(i theta) Pi_theta.
```

Because `[T,Q_total]=0`, `Q_total` preserves every eigenspace of `T`.
Equivalently, `[Pi_theta,Q_total]=0` for every spectral projector
`Pi_theta`. Therefore any finite-block Hermitian branch

```text
    K_mu = sum_theta theta Pi_theta
```

also commutes with `Q_total`. This proves (C2).

### Step 3 - Common labels

The axial translations commute with each other by the retained bridge's
group law, and each commutes with `Q_total` by (C1). The finite-block
spectral generators are functions of those commuting normal unitaries, so
they commute with each other and with `Q_total`. Finite-dimensional
commuting Hermitian operators can be simultaneously diagonalized after
choosing a basis inside degenerate common eigenspaces. This proves (C3).
QED.
