# Common-metric boundary for the native large-feature branches

Status: bounded-support.

The derived charged and neutral modes have unequal squared-energy curvatures in the common weak-coupling regime. Relative to the charged column, the neutral Q4, Q8 and Q6 slopes scale as lambda², lambda4 and lambda8. Common units or source normalization cannot make these ratios one.

[Proof and scope](../.claude/science/physics-loops/neutral-composite-24h-20261018/native/COMMON_METRIC_BOUNDARY.md); [runner](../scripts/native_common_metric_boundary.py).

This blocks simultaneous identification of these branches with a common relativistic vacuum in this regime. It does not rule out nonrelativistic composites in a medium, another phase, or a different derived physical subset. The slopes are not front velocities, and no empirical exclusion is claimed. Updated PR9718 motivates the cross-lane comparison but supplies no load-bearing theorem here.
