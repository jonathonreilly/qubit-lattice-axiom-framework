```text

  = <u_i, (J-I) u_i>
    + <E_beta u_i, (d/d beta bar D_beta) E_beta u_i> / lambda_i.
```

## Exact Finite-Block Split

On a finite packet block, write

```text
T_beta = E_beta D_beta E_beta,
E_beta = exp((beta/2) J).
```

For the shifted implementation used by the runner one replaces `J` by `J-I`;
this subtracts the same scalar contribution from both log derivatives and
therefore cancels in the ratio derivative.

The product rule gives

```text
dT_beta/dbeta = (1/2)(J T_beta + T_beta J) + E_beta D_beta' E_beta
```

where the Wilson diagonal derivative is obtained from the same character
recurrence:

```text
c'_(p,q)(beta) = (1/6) sum_{nu in N(p,q)} c_nu(beta)
r'_(p,q)(beta) = c'_(p,q)(beta)/c_(0,0)(beta)
                 - c_(p,q)(beta)c'_(0,0)(beta)/c_(0,0)(beta)^2.
```

If `lambda_i` is simple and `v_i` is normalized, Hellmann-Feynman gives

```text
d/dbeta log(lambda_i) =
  <v_i, dT_beta/dbeta v_i> / lambda_i.
```

The J-part contribution to d/dbeta log(lambda_i) is <v_i, J v_i>, since

```text
<v_i, (J T_beta + T_beta J) v_i> / (2 lambda_i)
  = <v_i, J v_i>.
```

Thus the derivative inequality is exactly equivalent, on the finite block, to

```text
Delta_J + Delta_D <= 0
Delta_J = <v_1, J v_1> - <v_0, J v_0>
Delta_D = <v_1, E_beta D_beta' E_beta v_1>/lambda_1
          - <v_0, E_beta D_beta' E_beta v_0>/lambda_0.
```

## Simplicity Hypothesis

The identities above require the local eigenvalue branches to be differentiable
at the beta value under study. For the finite block this is ensured when
lambda_0 and lambda_1 must be simple and isolated from their neighboring
eigenvalues. The runner witnesses positive gaps `lambda_0-lambda_1` and
`lambda_1-lambda_2` on the integer beta grid `1..26` at shell `16`; this is a
finite-grid witness, not an interval proof.
