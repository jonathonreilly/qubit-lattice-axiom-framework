### Hilbert-Schmidt Deflation

Rung three used

```text
lambda_1(block) <= trace_upper - lambda0_lower.
```

For frontier rows this runner also computes an exact rational upper bound
`trace2_upper` for `tr((P T_beta P)^2)` on the `B_14` block. Since the block is
positive semidefinite,

```text
lambda_1(block)^2
  <= trace2_upper - lambda0_lower^2.
```

The block bound on those rows is therefore

```text
sqrt_upper(trace2_upper - lambda0_lower^2).
```

This is a certified Hilbert-Schmidt deflation of the Perron direction. It is
used on the measured frontier row because the exact dense rational
trace-square calculation is the runtime-heavy part of the runner. The
bisection and next-integer stop rows already fail with the cheaper
trace-plus-sharp-tail bound.

### Path-Count Tail

Rung three bounded an escaping half-slice entry by replacing the number of
`n`-hop paths by `6^n`, which cancels the per-hop denominator `6^n`:

```text

```

Rung four restores the exact recurrence path count in the escaping `P -> Q`
term:

```text

  = sum_(n=0..60) a_i,out(n) (beta/2)^n / (6^n n!)

```

where `a_i,out(n)` is the exact number of `n`-hop paths from the packet label
`i in B_14` to labels outside `B_14`. The runner bounds


exactly in rational arithmetic. The outside-row piece remains the rung-three
row-weighted majorant


so the full `delta^2` majorant is still an upper bound for the tail Frobenius
