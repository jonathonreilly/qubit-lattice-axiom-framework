
```text

r_(p,q)(beta) = c_(p,q)(beta) / c_(0,0)(beta).
```


ratio is bounded by the largest certified nontrivial `r_(p,q)`.

## Certificate Method

The runner uses exact rational character-recursion arithmetic through
`ORDER = 80`. For a rational beta row and each dominant weight, it computes

```text
S_lambda,80(beta)
  = sum_(n=0..80) m_lambda^(n) beta^n / (6^n n!).
```

The nonnegative tail is bounded by

```text
E_80(beta) = sum_(n>80) beta^n / n!
          <= (beta^81 / 81!) / (1 - beta/82).
```

The dimension majorant from rung one gives

```text
c_lambda(beta) in
[ S_lambda,80(beta), S_lambda,80(beta) + E_80(beta)/d_lambda ],
c_(0,0)(beta) in
[ S_(0,0),80(beta), S_(0,0),80(beta) + E_80(beta) ].
```

The certified finite block is `0 <= p,q <= 4`. For the outside-block part, the
runner evaluates every weight appearing through order 80 and also bounds the
remaining `p+q > 80` part using the minimum SU(3) dimension on that tail. The
assembled bound is conservative:

```text
lambda_1 / lambda_0 <= block_lambda1_upper + outside_tail_upper.
```

A row is marked `CERTIFIED yes` exactly when the outside-tail upper bound stays
below the finite-block gap:

```text
tail_margin
  = (1 - block_lambda1_upper) - outside_tail_upper
  > 0.
```
