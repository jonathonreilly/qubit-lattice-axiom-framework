## Method

```text

```

with nonnegative integer recurrence multiplicities `m_lambda^(n)`. The runner
evaluates exact rational partial sums through `COEFF_ORDER = 80` and attaches


For half-slice matrix elements it evaluates

```text

```

by the same recurrence through `M_ORDER = 60`, again with exact rational
exponential tails. This avoids treating finite-box Dirichlet boundary paths as
the infinite operator.

For the certified `s = 14` block, the runner computes:

### Tail-Control Lemma

Let `P` be the orthogonal projection onto `B_14`, `Q = I - P`,
`M = exp((beta/2) J)`, `D = D_beta`, and

```text
A = P M P,  R = M - P M P.
```

The embedded finite-block comparison operator is

```text
B = A D_P A,
```

where `D_P = P D P`. The following line is an identity:

```text
T_beta - B = A D R + R D A + R D R.
```

Indeed, `M = A + R` and `A D A = A D_P A`. Since `J` is symmetric and has
row and column sums bounded by `1`, the Schur bound gives `||J||_2 <= 1`,
and therefore `||M||_2 <= exp(beta/2)`. Since `R` is symmetric, the following
line is an inequality:

```text
||T_beta - B||_2
  <= 2 ||A D_P^(1/2)||_2 ||D^(1/2) R||_2
     + ||D^(1/2) R||_2^2.
```

The runner bounds `||A D_P^(1/2)||_2` by
`exp(beta/2) sqrt(r_sup)`, with `r_sup` the largest certified `r_upper` on
`B_14`.

It remains to justify the runner's `delta` term. For a label
`j = (p,q) in B_14`, set

```text
d_j = min(14 - p, 14 - q) + 1,
E_j = sum_(n>=d_j) (beta/2)^n / n!.
```

The code computes

```text
delta^2 = sum_(j in B_14) r_upper(j) E_j^2.
```

The first step is the standard inequality

```text
||D^(1/2) R||_2 <= ||D^(1/2) R||_F.
```

The next line is an identity, and the side on which `D^(1/2)` sits matters:

```text
||D^(1/2) R||_F^2
  = sum_{i,j} r_i R_ij^2
  = sum_{(i,j) not both in B_14} r_i M_ij^2.
```

Thus the row index `i`, not the column index `j`, carries the `r_i` weight.

For fixed labels `i,j`, let `a_ij(n)` be the exact number of `n`-hop
six-neighbor recurrence paths from `j` to `i`. If `h(i,j)` is their graph
distance, then the matrix element obeys the exact nonnegative expansion

```text
M_ij = sum_(n>=h(i,j)) a_ij(n) (beta/2)^n / (6^n n!).
```

The scalar tail `E_j` used in `delta` replaces `a_ij(n)` by the crude
six-neighbor path-count ceiling `6^n` and then cancels the per-hop `1/6^n`.
So the matching inequality is

```text
M_ij <= sum_(n>=h(i,j)) (beta/2)^n / n! <= E_j
```

whenever an escape from `j in B_14` to the outside requires at least `d_j`
hops. This is the deliberate slack: `exp_tail_from` drops both the per-hop
`1/6` factors and the endpoint path multiplicity.

To cover the pieces not visible in a bare P-column derivation, split the
Frobenius sum by rows:

```text
sum_{(i,j) not both in B_14} r_i M_ij^2
  = sum_{i in B_14, j outside B_14} r_i M_ij^2
    + sum_{i outside B_14, j arbitrary} r_i M_ij^2.
```

For each `i in B_14`, the runner's proof gate computes the exact integer
outside-path counts through `M_ORDER = 60`,

```text
L_i = sum_(n=0..60) a_i,out(n) (beta/2)^n / (6^n n!)
      + exp_tail_after(beta/2, 60),
```

where `a_i,out(n)` counts `n`-hop paths from `i` to labels outside `B_14`.
This gives the inequality

```text
sum_{j outside B_14} M_ij^2 <= L_i^2.
```

For the outside-row term, the coefficient recurrence gives an exact upper
bound `C_Q^upper / c_(0,0)^lower` for
`sum_{i outside B_14} r_i`. The finite part is summed exactly from the
recurrence layers. The omitted part uses the repo-internal SU(3) dimension
bookkeeping

```text
sum_lambda m_lambda^(n) dim_su3(lambda) = 6^n,
dim_su3(lambda) m_lambda^(n) <= 6^n,
```

so the remaining scalar exponential tail is a valid upper bound. Since
`||M||_2 <= exp(beta/2)`, this yields the inequality

```text
sum_{i outside B_14, j arbitrary} r_i M_ij^2
  <= exp(beta) C_Q^upper / c_(0,0)^lower.
```

The runner then checks, in exact rational arithmetic for every row in the
deliverable table, that

```text
sum_{i in B_14} r_upper(i) L_i^2
  + exp(beta) C_Q^upper / c_(0,0)^lower
  <= delta^2.
```

Combining the displayed identity and inequalities proves

```text
||D^(1/2) R||_2 <= delta,
```

including the `Q M Q` tail-tail block and the outside-row `r_i` weighting.
Substituting this into the operator-norm decomposition above is exactly the
runner's half-slice escape radius

```text
2 exp(beta/2) sqrt(r_sup) delta + delta^2.
```

Rows are marked `CERTIFIED yes` exactly when

```text

```

An overlap or negative margin is reported as `CERTIFIED no`.
