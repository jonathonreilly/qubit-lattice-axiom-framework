## Object

The operator is the native half-slice packet operator

```text
T_beta = exp((beta/2) J) D_beta exp((beta/2) J),
```

where

```text
D_beta chi_(p,q) = r_(p,q)(beta) chi_(p,q),
r_(p,q)(beta) = c_(p,q)(beta) / c_(0,0)(beta),
c_(p,q)(beta) = sum_n m^(n)_(p,q) beta^n/(6^n n!).
```

Here `m^(n)_(p,q)` is the exact multiplicity generated by the six-neighbor
dominant-weight recurrence from the character note:

```text
J chi_(p,q)
 = (1/6) [ chi_(p+1,q) + chi_(p-1,q+1) + chi_(p,q-1)
         + chi_(p,q+1) + chi_(p+1,q-1) + chi_(p-1,q) ],
```

with negative-label terms omitted.

Both `M_beta = exp((beta/2)J)` and `D_beta` grow with beta. The large-beta
analysis therefore scales out positive scalar factors that cancel in
`lambda_1/lambda_0`:

- `exp((beta/2)J) = exp(beta/2) exp((beta/2)(J-I))`;
- on the active `p,q = O(sqrt(beta))` packet scale, `D_beta` grows like
  `beta^(3/2)` times a fixed saddle profile.

## Analytic Route

Let

```text
d_(p,q) = (p+1)(q+1)(p+q+2)/2,
C2(p,q) = (p^2 + q^2 + p q + 3p + 3q)/3.
```

The exact recurrence has `d_(p,q)` as the spectral-edge harmonic function:

```text
6 d_(p,q) = sum_neighbors d_neighbor
```

with the same boundary convention as the recurrence. The Wilson coefficient
saddle gives, on the `p,q = O(sqrt(beta))` scale,

```text
r_(p,q)(beta) = d_(p,q) exp[-3 C2(p,q)/beta] * (1 + lower-order terms).
```

Equivalently, for `x = p/sqrt(beta)` and `y = q/sqrt(beta)`,

```text
beta^(-3/2) r_(p,q)(beta)
    -> H(x,y) exp[-Q(x,y)],
H(x,y) = x y (x+y) / 2,
Q(x,y) = x^2 + x y + y^2.
```

For the half-slice multiplier, the interior Taylor expansion of the
six-neighbor recurrence gives

```text
J - I -> beta^(-1) L,
L = (1/3)(partial_xx - partial_xy + partial_yy),
```

again with the A2 chamber boundary encoded by the same spectral-edge harmonic
function. Up to a positive scalar, the leading large-beta operator is therefore

```text
T_infty = S_(1/2) M_[H exp(-Q)] S_(1/2),
S_t = exp(t L),
```

on the scaled A2 dominant chamber.

## Uniform Bound Attempt

The uniform half-line bound is not proved here.

What is established in this source packet:

- shell-stable true discrete ratios on beta `{50, 60, 80, 100, 140, 200}`;
- a saddle-reduced large-beta operator with limiting ratio `0.1938058`;
- agreement between the true-route and reduced-route extrapolated limits to
  the runner tolerance;
- reduced-operator falsifiers showing that the normalization is load-bearing.

What remains open:

- an explicit operator-norm remainder estimate between the scaled true
  operator and `T_infty` on the active `sqrt(beta)` packet window;
- a tail estimate outside that active window with constants usable at a named
  beta threshold;
- a proof of eventual monotonicity for the true ratio, or a replacement
  operator-norm argument that does not need monotonicity.

The missing lemma is:

```text

  after scaling out exp(beta) beta^(3/2), the true T_beta converges to
  T_infty in the block operator norm with an explicit decreasing remainder
  epsilon(beta), and the top two eigenvalues remain isolated with explicit
  perturbation margins.
```

With that lemma and an independently supplied finite-window certificate, one
could turn the large-beta characterization into an explicit half-line bound.
This note does not claim that step.
