## 1. Geometric Saddle-Profile Piece

Write

```text
d_(p,q) = (p+1)(q+1)(p+q+2)/2,
C2(p,q) = (p^2 + q^2 + p q + 3p + 3q)/3,
x = p / sqrt(beta),
y = q / sqrt(beta),
s = x + y,
delta = beta^(-1/2).
```

The saddle heat-kernel diagonal used by this reduction is

```text
r_sad_(p,q)(beta) = d_(p,q) exp[-3 C2(p,q)/beta].
```

Then

```text
beta^(-3/2) r_sad_(p,q)(beta)
 = ((x + delta)(y + delta)(x + y + 2 delta)/2)
   exp[-Q(x,y)] exp[-3(x+y) delta],
```

where

```text
H(x,y) = x y (x+y) / 2,
Q(x,y) = x^2 + x y + y^2.
```

For `0 <= x,y <= a` and `beta >= 1`,

```text
| beta^(-3/2) r_sad_(p,q)(beta) - H(x,y) exp[-Q(x,y)] |
 <= K_geom(a) beta^(-1/2),
K_geom(a) = 6 a^4 + 3 a^2 + 3 a + 1.
```

Derivation: expand the polynomial factor as

```text
((x + delta)(y + delta)(s + 2 delta)/2)
 = H(x,y)
   + delta (x y + s^2/2)
   + delta^2 (3s/2)
   + delta^3.
```

Using `s <= 2a`, `xy <= a^2`, `delta <= 1`, and
`1 - exp[-3s delta] <= 3s delta`, the polynomial difference contributes
`(3 a^2 + 3 a + 1) beta^(-1/2)` and the exponential shift contributes
`6 a^4 beta^(-1/2)`. The A2 boundary convention is included because the
same formula applies at `p = 0` or `q = 0`; there `H = 0` and the
remaining saddle diagonal is `O(beta^(-1/2))`.

This proves the geometric part of sub-lemma 1 for `r_sad`, not for the exact
Wilson diagonal `r_(p,q)(beta)`. The missing Wilson piece is the named
estimate

```text
wilson_to_saddle_uniform(a):
| beta^(-3/2) r_(p,q)(beta)
  - beta^(-3/2) d_(p,q) exp[-3 C2(p,q)/beta] |
 <= K_W(a) beta^(-1/2)
```

for all `p,q <= a sqrt(beta)`. If that estimate is later supplied, then

```text
K_diag(a) = K_W(a) + K_geom(a).
```

No value of `K_W(a)` is fitted or inferred here.

## 2. Saddle Tail Piece

For the saddle diagonal alone, if `max(x,y) > a`, `a >= 1`, and `beta >= 1`,
then `s = x + y > a`, `Q >= 3 s^2/4`, and

```text
((x + delta)(y + delta)(s + 2 delta)/2)
 <= (s + 2)^3 / 8.
```

The function `(s + 2)^3 exp[-3 s^2/4] / 8` decreases for `s >= 1`, so

```text
sup_(max(x,y)>a) beta^(-3/2) r_sad_(p,q)(beta)
 <= K_tail_sad(a),
K_tail_sad(a) = ((a + 2)^3 / 8) exp[-3 a^2 / 4].
```

Because the scaled half-slice factors are contractions, the saddle-tail
operator-norm contribution is bounded by this multiplier-norm tail. For the
true Wilson diagonal this again depends on `wilson_to_saddle_uniform(a)` or
a separate true-tail estimate. The true-tail constant is therefore not
available in this note.

## 3. Semigroup Contraction

Let

```text
E_beta = exp((beta/2)(J - I)).
```

The character recurrence authority identifies `J` as multiplication by

```text
j(U) = (chi_(1,0)(U) + chi_(0,1)(U)) / 6
     = Re Tr(U) / 3.
```

For `U in SU(3)`, `|Re Tr(U)| <= 3`, hence `|j(U)| <= 1`. Multiplication by
`j` is therefore a self-adjoint contraction on the class-function Hilbert
surface. Thus `sigma(J) subset [-1,1]`, `sigma(J - I) subset [-2,0]`, and
for every `beta >= 0`,

```text
|| E_beta || <= 1.
```

The same estimate holds for every finite packet compression used by the
paired runners. This proves the semigroup control needed to
stop diagonal and tail estimates from being amplified by the two half-slice
factors. It does not prove the separate continuum-generator comparison
`E_beta -> S_(1/2)` with boundary terms.

## 4. Eigen-Ratio Perturbation Transfer

This algebraic transfer does not depend on a fit. If a comparison operator
`T_infty` is normalized by its top eigenvalue and has top two eigenvalues

```text
mu_0 = 1,
mu_1 = L, with 0 <= L < 1.
```

The runner uses `L_sample = 0.1938058` only as a non-authority numerical witness
for the algebraic inequality below; this note does not claim that value as a
derived limiting ratio.

If the scaled true operator satisfies

```text
|| T_beta - T_infty || <= epsilon(beta) < 1,
```

then Weyl's eigenvalue inequality gives

```text
lambda_0(beta) >= 1 - epsilon(beta),
|lambda_1(beta) - L| <= epsilon(beta).
```

Consequently

```text
|lambda_1/lambda_0(beta) - L|
 <= (1 + L) epsilon(beta) / (1 - epsilon(beta)).
```

If a later operator estimate supplies

```text

```

then the half-line numerical threshold would be determined by

```text
K / sqrt(beta) < (1 - L) / 2,
beta > (2K / (1 - L))^2.
```

This proves the perturbation-transfer algebra. It does not supply `K`; the
load-bearing missing input is still the true operator-norm remainder.
