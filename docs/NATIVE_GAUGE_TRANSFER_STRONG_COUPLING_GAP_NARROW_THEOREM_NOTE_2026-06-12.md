## Theorem

For `0 <= beta <= 1`, the nontrivial coefficient-transfer spectral ratio obeys

```text
lambda_1(beta) / lambda_0(beta) <= (2/3) beta.
```

Equivalently, the native coefficient-transfer gap satisfies

```text
1 - lambda_1(beta)/lambda_0(beta) >= 1 - (2/3) beta > 0
```

on this explicit strong-coupling interval.

At `beta = 0`, `w_0 = chi_(0,0)`, so

```text
r_(0,0)(0) = 1,        r_(p,q)(0) = 0 for (p,q) != (0,0).
```

The transfer collapses exactly to the trivial-channel projector. The spectrum
is `{1, 0, ...}` and the gap is exactly `1`.

## Exact Leading Scaling

The exact recurrence gives the coefficient of `chi_(p,q)` in `Y^n` as a
nonnegative integer `m_(p,q)^(n)`. Hence

```text
c_(p,q)(beta)
  = sum_(n>=0) m_(p,q)^(n) (beta/6)^n / n!.
```

The Pieri branch

```text
(a,b) tensor (1,0) contains (a+1,b),
(a,b) tensor (0,1) contains (a,b+1)
```

reaches `(p,q)` from `(0,0)` in `p+q` steps, and the highest-weight summand
appears once in that leading branch. Therefore

```text
c_(p,q)(beta)
  = beta^(p+q) / (p! q! 6^(p+q)) + higher powers,
```

with the trivial case `c_(0,0)(0)=1`. In particular,

```text
c_(1,0)(beta) / c_(0,0)(beta) = beta/6 + O(beta^2),
c_(0,1)(beta) / c_(0,0)(beta) = beta/6 + O(beta^2).
```

Thus the first nontrivial channel is the fundamental/antifundamental pair and
the gap bound has `p = 1`.

## Convergent Majorant

For each `n`, `Y^n` is the character of

```text
(V_(1,0) direct-sum V_(0,1))^(tensor n).
```

At the identity this representation has dimension `6^n`, while

```text
Y^n = sum_lambda m_lambda^(n) chi_lambda,
```

so

```text
sum_lambda m_lambda^(n) d_lambda = 6^n.
```

For any fixed nontrivial `lambda`,

```text
m_lambda^(n) <= 6^n / d_lambda.
```

Since every nontrivial SU(3) irrep has `d_lambda >= 3`, and since
`c_(0,0)(beta) >= 1` for `beta >= 0`,

```text
c_lambda(beta) / c_(0,0)(beta)
  <= (1/d_lambda) sum_(n>=1) beta^n/n!
  <= (1/3) * 2 beta
  = (2/3) beta
```

for `0 <= beta <= 1`. The last step uses the exact rational majorant
`1/n! <= 1/2^(n-1)` for `n >= 1`, hence

```text
sum_(n>=1) beta^n/n! <= beta sum_(n>=1) 1/2^(n-1) = 2 beta.
```

This proves the displayed bound without asymptotic truncation.
