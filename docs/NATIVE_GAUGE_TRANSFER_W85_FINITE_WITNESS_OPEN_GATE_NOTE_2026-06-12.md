## Target Quantity

With `a = max(p,q)/sqrt(beta)`,

```text
H(x,y) = x y (x+y)/2,
Q(x,y) = x^2 + x y + y^2,
rho(beta,p,q) = sqrt(beta) | beta^(-3/2) r_(p,q)(beta) - H(x,y) exp(-Q(x,y)) |.
```

W85 would require a uniform theorem of the form

```text
rho(beta,p,q) <= K_W(a)
```

together with a proved comparison such as `K_W(a) <= K_geom(a)`. This note does
not supply that theorem. It only checks that `rho <= K_geom(a)` on the sampled
cells below, using the finite-mode coefficient routine already present in the
repo.
