## Question

[`NATIVE_GAUGE_CLOSURE_NOTE.md`](NATIVE_GAUGE_CLOSURE_NOTE.md) surface

The lattice-gauge holonomy form
`U = exp(i a A^a_μ T_a)` instead requires a *gauged connection* on edges. Does
the native one-qubit operator algebra on the `Z^3` spatial substrate, together
with staggered nearest-neighbor hopping, **force** a continuous `su(3)` parallel
transport around a plaquette, or is the native flux only scalar in the taste
operator algebra — so that the continuous connection `A^a_μ` is added structure
rather than derived?

## Answer

**No** — the native structure does not force a continuous `su(3)` connection.

Under both natural identifications of the native "hop in direction μ" that the
framework actually supplies, the single-plaquette holonomy is **exactly a
scalar operator** on the taste space, with **zero traceless `su(3)` component**.
The continuous color connection `A^a_μ` is therefore not generated by the native
hops.

The remaining open object is narrower and clean:

> the gauge **group** `su(3)` and its canonical generator normalization are
> separate lanes; the gauge **field** `A^a_μ` enters by the standard
> minimal-coupling principle as added structure. The two native hop
> identifications tested here carry only scalar plaquette phases in the taste
> operator algebra.

This is a boundary, not a wall: it delimits exactly what staggered hopping
alone supplies, and leaves the complementary positive programs untouched
(see *Remaining open* below).

## Theorem (native plaquette holonomy has zero traceless `su(3)` component)

Let the native taste-space directional hops `L_μ` (μ = 1,2,3) be involutory
unitaries on `V` (`L_μ† L_μ = I`, `L_μ² = I`), and let the plaquette holonomy
in the (μ,ν) plane be the path-ordered group commutator

```text
W_{μν} = L_μ L_ν L_μ^{-1} L_ν^{-1}.
```

**(1) Clifford-folded hops.** With the staggered-phase folded hops equal to
the cubic Clifford generators `Γ_μ` of
[`NATIVE_GAUGE_CLOSURE_NOTE.md`](NATIVE_GAUGE_CLOSURE_NOTE.md)
(`{Γ_μ, Γ_ν} = 2 δ_{μν} I`), anticommutation gives, for μ ≠ ν,

```text
W_{μν} = Γ_μ Γ_ν Γ_μ Γ_ν = − Γ_μ Γ_μ Γ_ν Γ_ν = − I.
```

So every Clifford-folded plaquette holonomy is the scalar taste-space operator
`−I`.

**(2) Cube-shift hops.** With the graph-first one-step axis shifts `S_μ` from
[`GRAPH_FIRST_SU3_INTEGRATION_NOTE.md`](GRAPH_FIRST_SU3_INTEGRATION_NOTE.md)
(the shifts whose commutant yields `su(3)`), which mutually commute, for μ ≠ ν

```text
W_{μν} = S_μ S_ν S_μ^{-1} S_ν^{-1} = I.
```

So every cube-shift plaquette holonomy is the trivial scalar operator `+I`.

**(3) Operator-center membership and vanishing traceless part.** In both cases
`W_{μν} = c·I` with `c ∈ {+1, −1}`, hence the traceless component
`W_{μν} − (Tr W_{μν}/8) I = 0` exactly. The scalar operator `−I` commutes with
all native generators, but this note does not identify it with a color-group
center element. No `W_{μν}` has a nonzero projection onto the traceless `su(3)`
sector. ∎

## Compatibility note (`g_bare = 1` is not promoted here)

native hop identifications tested here. It does not set or improve the audit
status of `g_bare_rigidity_theorem_note`; any downstream reuse is owned by the
independent audit lane.
