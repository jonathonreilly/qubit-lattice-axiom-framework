## Question

The retained parity/chiral violation acts on the `3 ↔ 3̄` axis, not within the
generation triplet (`PARITY_VIOLATION_DOES_NOT_REACH_GENERATION_TRIPLET...`). So
a *new* parity violation acting **within** the triplet would be needed to lift
its `S_3` mass degeneracy. What is its precise form, and is it constrained?

## Answer

A new axis-exchange parity violation has an exact order parameter: the **phase
`delta`** of the framework's retained C_3-circulant generation mass matrix
(`koide_circulant_character_bridge`, `koide_circulant_q_two_thirds`)

```text
H(a,b) = a I + b C + conj(b) C^2 ,   C = 3-cycle,   b = |b| e^{i*delta}.
```

- `C_3` (the 3-cycle) preserves `H` for **every** `delta` — the circulant/Koide
  structure is intact.
- A transposition (axis-exchange reflection, `C → C^2`) conjugates `b`, i.e.
  sends `delta → -delta`. `H` is transposition-invariant **iff
  `sin(delta)=0`** (`delta = 0` or `pi` modulo `2pi`). So a generic
  `delta` away from the real-axis fixed loci is precisely an axis-exchange
  parity violation acting *within* the triplet.
- `sin(delta)=0` → spectrum degenerate (1 + 2, full `S_3`);
  generic `sin(delta) != 0` → three distinct masses, `C_3` only — the
  Koide-compatible regime.

So a new parity violation is a nonzero circulant phase: it acts within the
generation triplet, lands on `C_3` (not trivial, hence Koide-compatible), and
the transposition acts on it as `delta → -delta` — the same orientation/`i` flip
seen in the complex-qubit split.

## Theorem (delta is the axis-exchange parity order parameter)

For `H(a,b) = aI + bC + b̄C^2` on `C^3` with `C` the 3-cycle and
`b = |b|e^{iδ}`:

**(1)** `C H C† = H` for all `δ` (circulant ⇒ `C_3`-invariant).

**(2)** With `τ` a transposition (`C → C^2`), `τ H(δ) τ† = H(−δ)`; hence `H` is
`τ`-invariant iff `δ = -δ` modulo `2pi`, i.e. `delta = 0` or `pi` modulo
`2pi`.

**(3)** Eigenvalues `λ_k = a + 2|b|cos(δ + 2πk/3)`, `k=0,1,2` (matches the
retained circulant form). At `sin(delta)=0`, the spectrum is degenerate
(1+2). For generic `sin(delta) != 0`: three distinct values.

**(4)** `δ` and `−δ` give the same eigenvalue *set* (a mirror) but
`H(δ) ≠ H(−δ)` — the parity is *violated*, not absent. ∎

## What this claims

- `δ` is the axis-exchange parity order parameter for the generation triplet:
  `sin(delta)=0` ⇔ `S_3`-symmetric & degenerate; generic `sin(delta)!=0` ⇔
  `C_3`-only & nondegenerate.
- `C_3` is preserved for all `δ`; a transposition acts by `δ → −δ`.
- The nondegenerate regime is `C_3` (Koide-compatible), not trivial.

## What this does NOT claim

- Does **not** derive that `δ` is nonzero or fixed by the framework. Whether

  cluster).
- Does **not** derive the Koide relation or any mass value; it uses the retained
  circulant form and identifies `δ`'s role.
- Does **not** identify `δ` with a CP phase or any PDG quantity.
- Consumes no PDG value, fitted selector, comparator, scale, or mass input.
