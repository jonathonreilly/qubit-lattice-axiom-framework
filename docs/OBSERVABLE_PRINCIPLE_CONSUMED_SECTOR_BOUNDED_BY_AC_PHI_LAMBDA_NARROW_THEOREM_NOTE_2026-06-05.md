## 2. What the parent actually consumes

The parent's load-bearing in-scope claim is the four exact-algebra identities on
the exact minimal hierarchy block. Their physical content — the hierarchy

## 3. (A) The consumed amplitude is real-positive

The free staggered operator is real and antisymmetric (real `η` phases,
antisymmetric forward–backward difference), so its eigenvalues come in conjugate
pairs `± iλ`, and for real `j`

```text
det(D + jI) = ∏ (j² + λ²) ≥ 0,   > 0 when D + jI is invertible.
```

This is the determinant-positivity mechanism of
[`STAGGERED_ONLY_DET_POSITIVITY_CASE_A_NOTE_2026-05-17.md`](STAGGERED_ONLY_DET_POSITIVITY_CASE_A_NOTE_2026-05-17.md)
(`det(M_KS + mI) ≥ mⁿ > 0` config-by-config). The runner reproves the mechanism
symbolically (`n = 2, 4`: `det(A + jI) = ∏(j² + λ²)`) and numerically (300
real-antisymmetric seeds at `n = 5, 6, 8`, including odd dimension: `det` real to
`1e-7`, strictly positive for `j > 0`; spectrum purely imaginary to `1e-15`).
Hence `arg Z ≡ 0` on the consumed sector.

A generic complex anti-Hermitian operator has **unpaired** imaginary eigenvalues
and would not give a real determinant; the `± iλ` pairing requires the real
structure the staggered operator has. The runner records this so the reality claim
is not over-stated.

## 4. (B)–(C) P2 is eliminated; the generator is fixed without it

On `Z ∈ R_{>0}` the three readings of the logarithmic generator coincide,

```text
log|Z| = Re Log Z = log Z,
```

and a one-parameter phase-sensitive family `G_b(Z) = log|Z| + b·arg Z` gives the
**same** value `log Z` for every `b`, because `arg Z = 0` (runner Part 2:
`max|G_b − log Z| = 0` for `b ∈ {0, 5, −3, 100}`). So the phase-blindness premise
P2 — which is exactly the restriction "`b = 0`" — discriminates nothing on the
consumed sector. By explicit contrast, off the consumed sector (a genuinely
complex `Z = 1.4 e^{0.9 i}`) the same family differs by `4.5`: P2 is non-trivial
**only** there, which the parent does not load-bear on.

With the phase gone, the generator-selection equation is the Cauchy equation on
`R_{>0}`:

```text
W(r₁ r₂) = W(r₁) + W(r₂),   r = Z > 0,   W continuous ⟹ W(r) = c·log r.
```

The additivity is the **Record** content; continuity is the finite-block
analyticity of `j ↦ det(D + jI)` (a polynomial in `j`), not a Record claim. No
phase-blindness premise is used. The runner reproves the Cauchy solution form and
that an additive constant is forbidden (`W(1·1) = 2W(1) ⟹ W(1) = 0`). The Cauchy
classifier is the standard comparator (J. Aczél, *Lectures on Functional Equations
and Their Applications*, 1966, §2.1 Thm 1).
