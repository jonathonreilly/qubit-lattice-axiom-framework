## 1. Setup and notation

### 1.1 APBC phase set

For positive integer `L_t`, the antiperiodic-boundary-condition (APBC)
temporal phase set is

```text
Φ(L_t)  :=  { z_n := exp(i (2n+1) π / L_t)  :  n = 0, 1, …, L_t - 1 }.   (Φ)
```

This is exactly the set of `L_t`-th roots of `-1` (i.e.,
`z^{L_t} + 1 = 0`), equivalently the primitive `2 L_t`-th roots of
unity that are not `L_t`-th roots of unity. `|Φ(L_t)| = L_t`.

This is the standard temporal-Matsubara phase set used in the parent
note's `Σ_ω` sums (see e.g. parent `temporal_modes(lt)` =
`[(2n+1) π / lt for n in 0, …, lt-1]`).

### 1.2 Klein-four action

The Klein-four group on `Φ(L_t)`:

```text
K_4 := { 1, σ_-, σ_*, σ_{-*} }                                          (K4)
```

where

```text
σ_-(z)   := -z,
σ_*(z)   := z*  (complex conjugation),
σ_{-*}(z):= -z* = σ_- ∘ σ_*(z).                                          (K4-gens)
```

Multiplication: `σ_-^2 = σ_*^2 = σ_{-*}^2 = 1`, and
`σ_- σ_* = σ_{-*}`, giving `K_4 = Z_2 × Z_2`. On the unit circle
`σ_*(z) = z^{-1}`, so `K_4` factors through the dihedral order-4
subgroup of `O(2)` acting on `S^1`.

### 1.3 Klein-four action restricts to `Φ(L_t)` for even `L_t`

For `L_t` even, `K_4` preserves `Φ(L_t)`. Indeed, write `L_t = 2m`,
`m >= 1`:

- `σ_*(z_n) = z_n* = exp(-i (2n+1) π / (2m))`. Using
  `exp(-i (2n+1) π / (2m)) = exp(i (4m - 2n - 1) π / (2m))
                          = exp(i (2(2m - n - 1) + 1) π / (2m))
                          = z_{2m - n - 1}`. So
  `σ_*(z_n) = z_{2m - n - 1} ∈ Φ(2m)`.
- `σ_-(z_n) = -z_n = exp(i (2n+1) π / (2m) + i π) = exp(i (2n + 1 + 2m) π / (2m))
                  = exp(i (2(n + m) + 1) π / (2m)) = z_{n + m mod 2m}`. So
  `σ_-(z_n) = z_{n + m mod 2m} ∈ Φ(2m)`.
- `σ_{-*}(z_n) = z_{(2m - n - 1) + m mod 2m} = z_{(3m - n - 1) mod 2m} ∈ Φ(2m)`.

Hence `K_4 ⊂ Sym(Φ(2m))`. (For odd `L_t`, `σ_-` does *not* preserve
`Φ(L_t)`; the APBC framework already restricts to even `L_t` in the
parent note's hierarchy block context.)

### 1.4 Klein-four orbit invariant

**Lemma 1.4.** The function `sin²(arg z)` is constant on every
`K_4`-orbit. Equivalently `sin²` is a complete Klein-four invariant on
`S^1`.

*Proof.* Write `z = e^{i ω}`. The four generators act as
`ω → ω, π + ω, -ω, π - ω` (mod 2π) respectively. Using
`sin(ω) = sin(π - ω) = -sin(π + ω) = -sin(-ω)`, all four images have
the same `sin²(ω)`. Conversely, the equation `sin²(ω) = c` for
`c ∈ [0, 1]` has solutions `ω = arcsin(√c), π - arcsin(√c),
-arcsin(√c), π + arcsin(√c)` in `[0, 2π)`, which is exactly a
single `K_4`-orbit (with possible degenerations at `c = 0` giving the
fixed points `{0, π}` and `c = 1` giving the pair `{π/2, 3π/2} = {i, -i}`).
∎

## 2. Statement

**Theorem 2 (Klein-four APBC orbit partition, closed form).** For every
even `L_t = 2m` with `m >= 1`, the Klein-four orbit set
`Φ(L_t) / K_4` has cardinality

```text
| Φ(L_t) / K_4 |  =  ceil(m / 2)  =  ceil(L_t / 4).                     (T2)
```

Equivalently, the number of distinct values of
`sin²((2n+1) π / L_t)` for `n = 0, …, L_t - 1` is exactly `ceil(L_t/4)`.

### 2.1 Three immediate corollaries

**Corollary 2.1.1 (single-orbit characterization).** The orbit
partition is **single** (one orbit) if and only if `L_t ∈ {2, 4}`.

*Proof.* `ceil(L_t / 4) = 1 ⇔ L_t ∈ {1, 2, 3, 4}`. Restricting to
even `L_t`: `L_t ∈ {2, 4}`. ∎

**Corollary 2.1.2 (orbit-size dichotomy at `L_t ∈ {2, 4}`).** At
`L_t = 2`, the unique orbit has size 2: `Φ(2) = {+i, -i}` with
`sin²(π/2) = 1`. At `L_t = 4`, the unique orbit has size 4:
`Φ(4) = {e^{iπ/4}, e^{i3π/4}, e^{i5π/4}, e^{i7π/4}}` with
`sin²(π/4) = sin²(3π/4) = sin²(5π/4) = sin²(7π/4) = 1/2`.

*Proof.* Direct computation. At `L_t = 2`, `Φ(2) = {e^{iπ/2}, e^{i3π/2}}
                                              = {i, -i}`; `K_4` acts
transitively (orbit of `i` under `K_4` is `{i, -i, -i, i} = {i, -i}`).
At `L_t = 4`, `Φ(4) = {e^{iπ/4}, e^{i3π/4}, e^{i5π/4}, e^{i7π/4}}`;
`K_4` acts on `e^{iπ/4}` as `{e^{iπ/4}, e^{i5π/4} = -e^{iπ/4},
                              e^{-iπ/4} = e^{i7π/4} = (e^{iπ/4})*,
                              e^{i3π/4} = -e^{-iπ/4} = -((e^{iπ/4})*)}`,
covering all four phases. ∎

**Corollary 2.1.3 (unique minimal resolved orbit).** `L_t = 4` is the
unique even `L_t` for which `Φ(L_t)` is a single `K_4`-orbit of size
**greater than 2**. Equivalently, `L_t = 4` is the unique minimal
resolved orbit on the APBC temporal circle under the Klein-four
sign/conjugation action.

*Proof.* By Corollary 2.1.1, single-orbit cases are exactly
`L_t ∈ {2, 4}`. By Corollary 2.1.2, the `L_t = 2` orbit has size 2 and
the `L_t = 4` orbit has size 4. Since "resolved" means "size > 2"
(distinguishing from the unresolved sign pair `{+i, -i}` that is
already a length-2 Klein-four orbit on `S^1`), only `L_t = 4`
satisfies both "single orbit" and "resolved". For `L_t ≥ 6` (even),
`ceil(L_t/4) ≥ 2`, so the orbit partition is not single. ∎

## 3. Proof of Theorem 2

Write `L_t = 2m`, `m >= 1`. Set `θ_n := (2n+1) π / (2m)` for
`n = 0, 1, …, 2m - 1`. By Lemma 1.4 the Klein-four orbits in `Φ(2m)`
are level sets of `sin²(θ_n)`. We count distinct values of
`s_n := sin²(θ_n)` for `n = 0, …, 2m - 1`.

### 3.1 Two collapse identities

**(C1) Period-π collapse.** `sin²(θ + π) = sin²(θ)` for all `θ`.

`θ_{n+m} = (2(n+m)+1) π / (2m) = (2n+1) π / (2m) + π = θ_n + π`. So
`s_{n+m} = s_n` for `n = 0, …, m - 1`. Hence the effective parameter
space reduces from `n ∈ {0, …, 2m - 1}` to `n ∈ {0, …, m - 1}`.

**(C2) Reflection-around-`π/2` collapse.** `sin²(π - θ) = sin²(θ)`
for all `θ`.

`π - θ_n = π - (2n+1) π / (2m) = (2m - 2n - 1) π / (2m)
                              = (2 (m - 1 - n) + 1) π / (2m) = θ_{m-1-n}`.
So `s_{m-1-n} = s_n` for `n = 0, …, m - 1`. Hence the
reduced parameter space `{0, …, m - 1}` is collapsed by the
involution `ι(n) := m - 1 - n`.

### 3.2 Counting `ι`-orbits on `{0, …, m - 1}`

The involution `ι(n) = m - 1 - n` on `{0, …, m - 1}` has fixed point
`n = (m - 1) / 2` iff `m` is odd, and no fixed point if `m` is even.

- If `m` is **odd**: one fixed point (`n = (m-1)/2`) and `(m - 1) / 2`
  pairs `{n, m - 1 - n}` (`n = 0, …, (m - 3)/2`). Total orbits:
  `1 + (m - 1) / 2 = (m + 1) / 2 = ceil(m/2)`.
- If `m` is **even**: no fixed point, `m / 2` pairs
  `{n, m - 1 - n}` (`n = 0, …, m/2 - 1`). Total orbits:
  `m / 2 = ceil(m/2)`.

In both cases the orbit count is `ceil(m/2)`.

### 3.3 No further collapse

It remains to show that the only collapses among `s_n` for
`n ∈ {0, …, m - 1}` are those induced by `ι`. Equivalently, if
`sin²(θ_n) = sin²(θ_{n'})` with `n, n' ∈ {0, …, m - 1}`, then
`n = n'` or `n' = m - 1 - n`.

`sin²(α) = sin²(β)` ⇔ `cos(2α) = cos(2β)` ⇔
`2α ≡ ±2β (mod 2π)` ⇔ `α ≡ ±β (mod π)`.

With `α = θ_n = (2n+1) π / (2m)` and `β = θ_{n'} = (2n'+1) π / (2m)`:

- `α ≡ β (mod π)`: `(2n+1) / (2m) - (2n'+1) / (2m) ∈ Z`, i.e.,
  `(n - n') / m ∈ Z`. With `n, n' ∈ {0, …, m - 1}`, this forces
  `n = n'`.
- `α ≡ -β (mod π)`: `(2n+1) / (2m) + (2n'+1) / (2m) ∈ Z`, i.e.,
  `(n + n' + 1) / m ∈ Z`. With `n, n' ∈ {0, …, m - 1}`,
  `n + n' + 1 ∈ {1, …, 2m - 1}`. Multiples of `m` in this range:
  exactly `n + n' + 1 = m`, i.e., `n' = m - 1 - n`.

So the only collapses are `n' = n` (trivial) and `n' = m - 1 - n` (the
`ι` involution), giving exactly `ceil(m/2)` orbits as in §3.2.

### 3.4 Identification with `Φ(2m) / K_4`

By §3.1-§3.3, the number of distinct values of `s_n` for
`n ∈ {0, …, 2m - 1}` is exactly `ceil(m / 2)`. By Lemma 1.4 this is
the number of `K_4`-orbits on `Φ(2m)`. Thus
`|Φ(2m) / K_4| = ceil(m / 2) = ceil(L_t / 4)`. ∎
