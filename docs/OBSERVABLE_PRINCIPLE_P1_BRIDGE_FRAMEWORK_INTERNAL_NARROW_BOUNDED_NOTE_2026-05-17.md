## 1. Counterexample family `F_p[J] = r(J)^p`

### 1.1 Construction

Let `D` be an invertible real anti-Hermitian operator on a
finite-dimensional complex Hilbert space `V = C^N` (`N` even), with
the discrete-symmetry algebra of
[`CPT_EXACT_REAL_ANTI_HERMITIAN_D_NARROW_THEOREM_NOTE_2026-05-10.md`](CPT_EXACT_REAL_ANTI_HERMITIAN_D_NARROW_THEOREM_NOTE_2026-05-10.md).
For `J ∈ Sym_N(R)` in the local domain `U_0 ⊂ Sym_N(R)` on which
`det(D + J) ≠ 0`, define

```text
r(J)  :=  |det(D + J)| / |det D|  ∈  R_+,                              (r)
```

and the candidate functional family

```text
F_p[J]  :=  r(J)^p,    p ∈ R,                                          (F_p)
```

with the convention `F_0[J] = 1` (constant).

### 1.2 Properties on the real-D block

Direct algebraic check on independent direct sums `D = D_A ⊕ D_B`,
`J = J_A ⊕ J_B` with no hopping bonds across `A | B`:

```text
r(J)     =  r_A(J_A) · r_B(J_B)                                       (r-mult)
F_p[J]   =  ( r_A(J_A) · r_B(J_B) )^p
         =  r_A(J_A)^p  ·  r_B(J_B)^p
         =  F_p[A][J_A]  ·  F_p[B][J_B].                              (F-mult)
```

So `F_p` is **block-multiplicative** for every real `p`. It is
**block-additive**

```text
F_p[J_A ⊕ J_B]  =  F_p[A][J_A]  +  F_p[B][J_B]                        (F-add)
```

only when `p = 0` (trivially, both sides `2 = 2 - 1`... actually both
sides degenerate) or never except trivially. In particular, for `p ≠ 1`
the additive residual

```text
∆_add(F_p)  :=  F_p[J]  -  F_p[A][J_A]  -  F_p[B][J_B]
            =  r_A^p r_B^p  -  r_A^p  -  r_B^p                        (∆-add)
```

is generically nonzero. (Runner T1 verifies `∆_add(F_p) ≠ 0` for several
explicit `p ∈ {2, 1/2, 3, -1}` on a rational grid.)

The natural-log generator `W[J] := log r(J) = log|det(D+J)| - log|det D|`
satisfies `∆_add(W) ≡ 0` identically (because `log(r_A r_B) = log r_A +
log r_B`). This is the standard Cauchy multiplicative-to-additive
content; see the context-only failed candidate
`OBSERVABLE_PRINCIPLE_REAL_D_BLOCK_UNIQUENESS_NARROW_THEOREM_NOTE_2026-05-10.md`
§"(X3) Cauchy–Erdős functional-equation closure".

### 1.3 Properties of `F_p` outside (X2)

`F_p` satisfies (R) (continuity), depends only on `r(J)` (so it depends
only through the determinant ratio, the (C) criterion of (X2)), and
satisfies normalization `F_p[0] = 1` (which after additive constant
subtraction gives `F̃_p[J] := F_p[J] − 1` and satisfies `F̃_p[0] = 0`,
recovering (N)). It fails to satisfy (A) for `p ≠ 1`.

`F_p` is therefore outside class (X2) only because of (A); the (C) and
(R)/(N) criteria are individually compatible. The Cauchy step (X3) is
the multiplicative-to-additive closure applied to the function
`f : R_+ → R` defined by `F[J] = f(r(J))`; (X3) reduces `f` to
`c log r` only on the class of `f` that are ALREADY additive, which is
exactly (A).

So the exclusion of `F_p` for `p ≠ 1` happens at the (A) admissibility
criterion. (A) is block-additivity. (A) is P1 in the broad parent.
