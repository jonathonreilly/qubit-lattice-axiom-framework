## 0.1 Critical stress test — Jones-index admission decomposition

The mandatory critical stress test for this route is whether the
Jones-index admission is **genuinely smaller than P1** or whether it
**relabels P1** in subfactor-identification vocabulary. The honest split:

**Genuinely smaller than P1:**

- **Jones index theorem for type I subfactor inclusions** (Jones 1983):
  For type I subfactor inclusion `M_n(ℂ) ⊂ M_{nk}(ℂ)` (`n × n` matrices
  embedded as upper-left block in `nk × nk` matrices), the Jones
  index `[M_{nk}(ℂ) : M_n(ℂ)] = k²`. This is universal finite-dim
  algebra (Murray-von Neumann 1936 dimension theory of factors).
- **Multiplicativity under tensor product** (Pimsner-Popa 1986): For
  type I subfactor inclusions `M_a ⊗ N_c ⊃ M_b ⊗ N_d`,
  `[M_a ⊗ N_c : M_b ⊗ N_d] = [M_a : M_b] · [N_c : N_d]`. This is a
  structural theorem about Jones index under tensor product, with no
  independence-of-functionals input.
- **Log-of-product is sum of logs.** Universal real-analysis identity.

These three pieces combine: **`log [A_1 ⊗ A_2 : B_1 ⊗ B_2] = log [A_1 :
B_1] + log [A_2 : B_2]`**. This is structural additivity of the
Jones-index-log under tensor product. No independence input on
**functionals**; only structural input on **subfactor inclusions**.

**Logically equivalent to P1 (Pattern-L identification vocabulary):**

- **Identification `W[J] = log [A(D+J) : A(D)]` for some canonical
  inclusion.** The trivial inclusion `A_B ⊂ A_{B ∪ extra}` gives Jones
  index `2^|extra|` independent of `J`, so cannot equal `W[J]`. Any
  J-dependent inclusion requires choosing which subalgebra `A(D+J)` and
  which inclusion `A(D)` — and on finite-dim type I algebras
  `A_Λ = M_{2^|Λ|}(ℂ)`, the only natural J-dependent subalgebras are
  (a) the commutant of `D + J`, which is in general `ℂ · I` if `D + J`
  has all distinct eigenvalues, or (b) the spectral projectors of
  `D + J`, which gives a maximal abelian subalgebra. Neither makes
  `log [A(D+J) : A(D)]` equal `log |det(D + J)| - log |det D|` as an
  identity. The identification step requires **either** an admitted
  ansatz that `W` lies in the additive class of subfactor-log
  invariants, **or** the Pimsner-Popa entropy-of-inclusion formula
  applied to a state-dependent inclusion — but the latter requires
  selecting which state and which inclusion, which IS the P1 selection
  step.
- **Selection of additive over multiplicative.** Even within the
  "log [A:B]" family of subfactor-log invariants, choosing the
  **additive** target (`log` of the index) over a **multiplicative**
  target (the index itself, or a power of it) IS the Cauchy
  classifier in subfactor-log vocabulary, IS Pattern-L circularity.

The crucial question (per the prompt): **is there a canonical Jones-index
quantity that the framework's `W` naturally equals?** Honest answer:

### Exercise 2 — Elon first-principles: Why does Jones index give log structure?

From the first-principles perspective:

- **Jones index `[M : N]` is a real number** (integer-valued for type I,
  continuous-spectrum-valued for type II_1 via Jones tower). It measures
  the "size" of the bigger factor relative to the smaller. For type I
  inclusion `M_n(ℂ) ⊂ M_{nk}(ℂ)`, `[M_{nk}(ℂ) : M_n(ℂ)] = k²`
  (square of the embedding multiplicity).
- **Pimsner-Popa formula** (Pimsner-Popa 1986): For type II_1 inclusions
  with conditional expectation `E_N : M → N`, the entropy of the
  inclusion is `log [M : N]`. This is the natural "amount of information
  lost when restricting from M to N" — a real number that adds when
  inclusions compose.
- **The log appears** because Jones index is **multiplicative** under
  tensor product (Pimsner-Popa), and log turns products into sums. This
  is the same mathematical reason that `log Z` appears as the cumulant
  generating function in statistical mechanics (the cumulant route,
  PR #1641):
  multiplicativity under independence becomes additivity under log.
- **Is this structurally different from cumulant-generating-functional?**
  Structurally, **no**. Both the cumulant route and the Jones-index
  route here identify a real-valued multiplicative quantity on the
  algebraic structure, then take the log to get additivity. The
  cumulant route takes the partition function `Z[J]` itself; this route
  takes the Jones index of a J-dependent inclusion. Both routes face the same
  obstruction at the identification step: **which** multiplicative
  quantity is the "physical scalar generator"? Choosing the log over
  any positive-power is Pattern-L circularity in either vocabulary.

The first-principles conclusion: Jones-index gives log-additive
structure for the same structural reason that any multiplicative
quantity gives log-additive structure — by `log(xy) = log x + log y`.
The Jones-index admission is **not** structurally different from the
cumulant-generating-functional admission of the cumulant route; it's the same
selection step in different vocabulary.

## 3. Load-bearing step (class A) — Jones index multiplicativity → log-additivity
