### Exercise 2 — Elon Musk first-principles

Strip to first principles. What does "locality of source-derivatives"
mean operationally?

The physical content: for a scalar physical observable generator `W`
defined on local sources `J = Σ_x j_x P_x`, the derivative
`∂W/∂j_x` is a *local* quantity at site `x` — i.e., changing the
source `j_y` at a distant site `y` does not change `∂W/∂j_x`.

In QFT vocabulary, this is the cluster decomposition of the connected
one-point function `⟨O_x⟩_J = ∂W/∂j_x`: the response of a local
observable to local sources is local.

For the natural-log generator `W = log|det(D+J)|`:
`∂W/∂j_x = Tr[(D+J)^{-1} P_x] = (D+J)^{-1}_{xx}`. This depends on
`(D+J)^{-1}` at site `x`, and through the inverse Dirac kernel this
depends on `J` everywhere (the resolvent kernel decays exponentially
with separation under standard Combes-Thomas conditions, but is not
strictly compact-supported). So strict finite-range locality fails
even for `log` on a fully-connected `D`.

But on **block-diagonal `D`** (no hopping between regions `A` and `B`),
the inverse kernel `(D+J)^{-1}` is itself block-diagonal:
`(D_A + J_A)^{-1}` and `(D_B + J_B)^{-1}` separately. So
`(D+J)^{-1}_{xy} = 0` for `x ∈ A, y ∈ B`. Therefore on block-diagonal
`D`, `∂W/∂j_x = (D+J)^{-1}_{xx}` for `x ∈ A` depends only on `J_A`
(not on `J_B`). Locality is **exact** on block-diagonal `D`.

This is the route's intended distinguishing feature versus `F_p`:
- For `W = log`: on block-diagonal `D`, `∂W/∂j_x` for `x ∈ A` is
  `J_B`-independent.
- For `F_p = (det)^p`, `p ≠ 0`: on block-diagonal `D`,
  `∂F_p/∂j_x = p · F_p · ∂(log r)/∂j_x = p · det_A^p det_B^p ·
  (det_A)^{-1} · ∂det_A/∂j_x = p · det_A^{p-1} det_B^p · ∂det_A/∂j_x`,
  which depends on `J_B` via the `det_B^p` factor. So `F_p` is
  **NOT** "local in `J_B`" for `p ≠ 0`.

So locality (in the precise sense "`∂W/∂j_x` for `x ∈ A` is independent
of `J_B`") DOES distinguish `log` from `F_p`. The route appears, at
first sight, to bypass G3.

But now ask the deep structural question: **is "`∂W/∂j_x` for `x ∈ A`
is independent of `J_B`" a primitive distinct from additivity?**

By integration: if `∂W/∂j_x` for `x ∈ A` is independent of `J_B`, then

```text
W[J_A ⊕ J_B] - W[0 ⊕ J_B] = ∫_0^{J_A} (∂W/∂j_x) dJ_x'
```

depends only on `J_A` (since the integrand does). Setting `J_A = 0`
gives `W[0 ⊕ J_B] - W[0 ⊕ J_B] = 0`. Define
`f(J_A) := W[J_A ⊕ J_B] - W[0 ⊕ J_B]`; by the integration above,
`f` depends only on `J_A`. Evaluating at `J_B = 0`:
`f(J_A) = W[J_A ⊕ 0] - W[0]`. Therefore
`W[J_A ⊕ J_B] = W[J_A ⊕ 0] + W[0 ⊕ J_B] - W[0]`. With `W[0] = 0`:
`W[J_A ⊕ J_B] = W[J_A] + W[J_B]`. **That is P1.**

So the integration step IS the construction of additivity from
locality. It is not "smuggling in" additivity beyond locality; it
literally derives additivity from locality. But that is exactly the
sense in which locality and additivity are equivalent: each derives
the other on smooth `W` with `W[0] = 0` (the converse is trivial:
additive `W` has vanishing cross-derivatives, hence
`J_B`-independent `∂W/∂j_x` for `x ∈ A`).

**The deep structural reason locality and additivity are equivalent.**
Cross-block second-derivative vanishing says: at the level of
second-order variations, `W` decomposes into independent contributions
from `A` and `B`. Block-additivity says: at the level of the value of
`W`, the same decomposition holds. By the fundamental theorem of
calculus + the boundary condition `W[0] = 0`, second-order
decomposition integrates exactly to value-level decomposition. The
two conditions are the same condition expressed at different
derivative orders — and `W[0] = 0` is the boundary condition that
links them.

Is the route **circular**? Specifically: does "physical scalar
generator has local source-derivatives" presuppose "physical scalar
generator is additive on independent subsystems"?

The route claims locality is a STRICTLY STRONGER constraint than just
"continuous CPT-even scalar functional of `|Z|`" that genuinely
excludes `F_p`. The math shows locality is **EQUIVALENT** to additivity
on smooth `W` with `W[0] = 0`. The two premises are not strictly
ordered; they are logically equal.

So "physical scalar generator has local source-derivatives" is
**logically equivalent** to "physical scalar generator is additive on
independent subsystems". Imposing locality as a primitive on the
class of physical scalar generators is the same admitted classification
choice as imposing additivity. **The route is circular** in the sense
that locality and P1 are the same admission expressed in different
vocabulary.

**Honest classification of outcome:** sharpened no_go. Locality is
not strictly stronger than P1; it is equivalent on smooth `W` with
`W[0] = 0`. The route exhibits the same Pattern L circularity as the
other Pattern-L candidates in the Route D consolidated no-go.

### Exercise 4 — Math search (Tao-style)

Pose the bare math problem:

> Let `D` be a self-adjoint (or real anti-Hermitian) operator on
> `ℓ²(Z³ × {1,...,N})` with a finite-range hopping kernel and a mass
> gap. Let `J = Σ_x j_x P_x` be a local source with `j_x ∈ R` and
> `P_x` the local projector at site `x`. Define
> `W[J] = log|det(D+J)|` (or, more generally, any smooth scalar
> functional of `det(D+J)`). On a domain `U` where `det(D+J) ≠ 0`,
> is `∂W/∂j_x` necessarily a *local* function of `j_y` — specifically,
> independent of `j_y` for `|x - y|` sufficiently large?

Math answer (rigorous):

- **Strict finite-range locality fails for `W = log` on connected `D`.**
  `∂W/∂j_x = Tr[(D+J)^{-1} P_x] = (D+J)^{-1}_{xx}`. By Combes-Thomas,
  `|(D+J)^{-1}_{x,y}| ≤ C exp(-η |x-y|)`, but this is *exponential
  decay*, not strict zero outside a finite range. So
  `(D+J)^{-1}_{xx}` depends on `j_y` for all `y`, with the dependence
  decaying exponentially in `|x-y|`. **There is no finite range `R`
  such that `∂W/∂j_x` is exactly independent of `j_y` for
  `|x-y| > R`.**
- **Strict zero-derivative across the partition holds on block-diagonal
  `D`.** If `D = D_A ⊕ D_B` and `J = J_A ⊕ J_B` (no hopping or source
  coupling across the partition), then `(D + J)^{-1} = (D_A + J_A)^{-1}
  ⊕ (D_B + J_B)^{-1}`. The mixed off-block entries are exactly zero.
  So `(D+J)^{-1}_{xy} = 0` for `x ∈ A, y ∈ B`. Therefore
  `∂²W/∂j_x ∂j_y = -Tr[(D+J)^{-1} P_x (D+J)^{-1} P_y]
                  = -(D+J)^{-1}_{xy} (D+J)^{-1}_{yx} = 0` exactly
  for `x ∈ A, y ∈ B`.
- **The same vanishing fails for `F_p = (det)^p` on the same
  block-diagonal `D` for `p ≠ 0`.** `∂²F_p/∂j_x ∂j_y` for
  `x ∈ A, y ∈ B` on block-diagonal `D` equals
  `p² · det_A^p det_B^p · ∂(log det_A)/∂j_x · ∂(log det_B)/∂j_y`,
  which is nonzero (the global prefactor `F_p` couples the regions).

So the math answer is: on block-diagonal `D`, exact locality (cross-
block second-derivative vanishing) **does** distinguish `log` from
`F_p`. **But** — and this is the load-bearing finding — the math
also says that this distinguishing condition, on smooth `W` with
`W[0] = 0`, is **equivalent** to additivity. The proof (elementary
multivariable calculus):

> **Lemma (locality ≡ additivity on smooth `W` with `W[0] = 0`).**
> Let `W : R^|A| × R^|B| → R` be smooth on a convex open neighborhood
> `U ⊂ R^|A| × R^|B|` of the origin, with `W(0, 0) = 0`. Then the
> following are equivalent:
> - (A) (additivity) `W(J_A, J_B) = W(J_A, 0) + W(0, J_B)` for all
>   `(J_A, J_B) ∈ U`.
> - (B) (locality) `∂²W/∂j_a ∂j_b (J_A, J_B) = 0` for all
>   `a ∈ A, b ∈ B, (J_A, J_B) ∈ U`.

(Proof in §3.1.)

So on the class of smooth `W` with `W[0] = 0`, locality and
additivity are not separable premises; they are the same constraint
on `W`.

**Does this give a derivation of P1 from existing framework primitives?**
No. The Lemma is elementary calculus, but it shows the route's
candidate "locality" primitive is the SAME premise as P1. The route
does NOT close P1; it provides a sharpened circularity finding (D6)
in the spirit of the Route D consolidated no-go's Pattern L family.

## 3. Load-bearing step — equivalence (Class A claim)

### 3.1 Lemma (locality ≡ additivity on smooth `W` with `W[0] = 0`)

**Statement.** Let `U ⊂ R^|A| × R^|B|` be a convex open neighborhood
of the origin. Let `W : U → R` be twice continuously differentiable
with `W(0, 0) = 0`. The following are equivalent:

- **(A) Block-additivity:** `W(J_A, J_B) = W(J_A, 0) + W(0, J_B)`
  for all `(J_A, J_B) ∈ U`.
- **(B) Cross-block second-derivative vanishing:**
  `∂²W/∂j_a ∂j_b (J_A, J_B) = 0` for all `a ∈ A, b ∈ B` and all
  `(J_A, J_B) ∈ U`.

**Proof.**

**(A) ⟹ (B):** Assume (A). Differentiate both sides with respect
to `j_a` (`a ∈ A`):

```text
∂W/∂j_a (J_A, J_B) = ∂[W(J_A, 0) + W(0, J_B)]/∂j_a
                    = ∂W/∂j_a (J_A, 0)
```

(the second term has no `j_a` dependence since `a ∈ A` and the
argument is `0` in the `A`-slot). So `∂W/∂j_a (J_A, J_B)` is
independent of `J_B`. Differentiating again with respect to `j_b`
(`b ∈ B`) gives `∂²W/∂j_a ∂j_b = 0`. QED (A) ⟹ (B).

**(B) ⟹ (A):** Assume (B). Then for any `a ∈ A`, `∂W/∂j_a` is
independent of `J_B` (since its `j_b`-derivative is zero for all
`b ∈ B`, integration along any `J_B`-path from 0 gives no change).
So
`∂W/∂j_a (J_A, J_B) = ∂W/∂j_a (J_A, 0)` for all `(J_A, J_B) ∈ U`.

Define `G(J_A, J_B) := W(J_A, J_B) - W(0, J_B)`. Then
`G(0, J_B) = 0`. Compute `∂G/∂j_a = ∂W/∂j_a (J_A, J_B) - 0 =
∂W/∂j_a (J_A, 0)` (by the previous step), which is independent of
`J_B`. By the fundamental theorem of calculus along any path from
`(0, J_B)` to `(J_A, J_B)` at fixed `J_B`:

```text
G(J_A, J_B) - G(0, J_B) = ∫_0^{J_A} ∂G/∂j_a (J_A', J_B) dJ_A'
                        = ∫_0^{J_A} ∂W/∂j_a (J_A', 0) dJ_A'
```

The right-hand side is **independent of `J_B`** (the integrand has
no `J_B` dependence). Therefore `G(J_A, J_B)` depends only on
`J_A`. Setting `J_B = 0`:

```text
G(J_A, 0) = W(J_A, 0) - W(0, 0) = W(J_A, 0) - 0 = W(J_A, 0)
```

(using `W(0, 0) = 0`). So `G(J_A, J_B) = W(J_A, 0)` for all
`(J_A, J_B) ∈ U`. Substituting back:

```text
W(J_A, J_B) = G(J_A, J_B) + W(0, J_B) = W(J_A, 0) + W(0, J_B)
```

which is (A). QED (B) ⟹ (A).

Therefore (A) ⇔ (B) on smooth `W` with `W(0, 0) = 0`. ∎

### 3.2 Application to the locality route

Apply the Lemma with `j_A := J_A`-coordinates and `j_B := J_B`-
coordinates. The locality primitive (L_∂) is exactly condition (B);
the block-additivity P1 is exactly condition (A). On smooth `W` with
`W[0] = 0`, the two are equivalent.

**Therefore (L_∂) is logically equivalent to P1 on smooth `W` with
`W[0] = 0`.** The locality primitive is a relabeling of P1, not an
independent constraint.
