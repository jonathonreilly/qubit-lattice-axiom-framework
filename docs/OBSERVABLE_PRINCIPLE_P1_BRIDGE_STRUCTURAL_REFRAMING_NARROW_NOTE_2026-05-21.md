### Exercise 4 — Math search (Tao-style)

**Pose the bare math problem.** Let `Z[J]` be a smooth positive
functional of a source `J ∈ R^n` on a finite-dim space. Define the
moment generating function `M[J] := Z[J] / Z[0]` (normalized so
`M[0] = 1`), with moments `M_α := ∂^α M[J] / ∂J^α |_{J=0}` (multi-index
α). The cumulant generating function is defined by `K[J] := log M[J]
= log Z[J] - log Z[0]`, with cumulants `kappa_α := ∂^α K[J] / ∂J^α
|_{J=0}`.

**Question 1: Is `K[J] = log M[J]` the unique generating function for
which the Bell/Möbius moment-cumulant inversion holds?**

Answer: **YES**, in the formal-power-series sense. The
exponential formula `exp(K[t]) = M[t]` (`t` a multi-index of formal
variables) uniquely determines K = log M as a formal power series.
Equivalently, the moment-cumulant identity `M_α = sum_{pi in P(α)}
prod_{B in pi} kappa_B` (where `P(α)` is the set partition lattice of
α) is uniquely inverted by Möbius inversion on `P(α)` to give
`kappa_α = sum_{pi in P(α)} (-1)^{|pi|-1} (|pi|-1)! prod_{B in pi}
M_B`. The unique formal-power-series generator with these inversion
properties is `K = log M`.

**Question 2: Is the Bell/Möbius identity a derivation (theorem) or
a definition (convention)?**

Answer: **It is a theorem of combinatorics** (Rota 1964). The
lattice `P(n)` of set partitions of `{1,...,n}` has a Möbius function
`mu_{P(n)}(pi, hat_1) = (-1)^{n - |pi|} prod_{B in pi} (|B| - 1)!`,
and Möbius inversion on `P(n)` gives the moment-cumulant relation.
This is a purely combinatorial theorem with no probabilistic or
physical input.

**Question 3 (THE MAKE-OR-BREAK): does this answer hold WITHOUT
independence as input?**

Answer: **YES for the single-variable moment-cumulant identity;
NO for cumulant additivity on independent variables**.

Detailed answer:

- The single-variable Bell/Möbius identity `M_n = sum_{pi in P(n)}
  prod_{B in pi} kappa_{|B|}` and its inverse `kappa_n = sum_{pi in
  P(n)} (-1)^{|pi|-1} (|pi|-1)! prod_{B in pi} M_{|B|}` hold WITHOUT
  any independence input. They are formal-series identities that
  define cumulants from moments for ONE generating function.

- The cumulant additivity property `kappa_n(X + Y) = kappa_n(X) +
  kappa_n(Y)` for independent random variables X, Y, derived via

## 3. Load-bearing step (Class A) — derivation and equivalence proof

### 3.1 The 3-line P1 derivation under the structural admissions

Under (I) `Z[J] = det(D+J)`, (II.b) `W[J] = log|Z[J]| - log|Z[0]|`,
(III) block-diagonal determinant identity, (IV) `D = D_A ⊕ D_B`, and

```text
W[J_A (+) J_B] = log|det(D_A (+) D_B + J_A (+) J_B)| - log|det(D_A (+) D_B)|        (by II.b, IV)
              = log|det((D_A + J_A) (+) (D_B + J_B))| - log|det(D_A (+) D_B)|       (linear addition)
              = log|det(D_A + J_A) · det(D_B + J_B)| - log|det D_A · det D_B|       (by III)
              = log|det(D_A + J_A)| + log|det(D_B + J_B)|
                - log|det D_A| - log|det D_B|                                       (by VI)
              = (log|det(D_A + J_A)| - log|det D_A|)
                + (log|det(D_B + J_B)| - log|det D_B|)                              (reordering)
              = W[J_A] + W[J_B].                                                    (by II.b)
```

This is the 3-line trivial derivation that the structural reframing

Cauchy classifier is invoked**.

### 3.2 Equivalence Lemma — (II.b) is logically equivalent to P1

**Lemma (cumulant-generating-functional admission ⇔ P1).**
On the class of smooth `W : J ↦ R` with `W[0] = 0`, continuous CPT-even
(i.e., `W` depends only on `|Z|`) scalar functionals of the positive
real `r = |Z| > 0`, and on the framework's block-diagonal substrate
`D = D_A ⊕ D_B`:

- (II.b) "the framework's physical scalar bosonic observable generator
  is the canonical cumulant generating function `W = log|Z|`"

and

- P1 "scalar additivity on independent subsystems: `W[J_A ⊕ J_B] =
  W[J_A] + W[J_B]`"

are **logically equivalent**, up to the standard normalization `c = 1`
of the natural logarithm.

**Proof.**

(⇒) (II.b) ⇒ P1: this is the 3-line derivation of §3.1 above.
Elementary determinant algebra plus log algebra gives the additivity
from the log-form.

(⇐) P1 ⇒ (II.b) up to scale: assume `W` is additive on independent
subsystems, continuous, CPT-even (depends only on `|Z|`), and `W[0] =
0`. Define `f : R_+ → R` by `f(r) := W[J]` where `r = |Z[J]|` is the
modulus of the partition function. By multiplicative factorization of
`|Z|` on direct-sum substrates (`|Z[J_A ⊕ J_B]| = |Z[J_A]| · |Z[J_B]|`
from (III)) and P1 additivity of W:

```text
f(r_A · r_B) = W[J_A (+) J_B] = W[J_A] + W[J_B] = f(r_A) + f(r_B).
```

So `f : (R_+, *) → (R, +)` is a continuous group homomorphism with
`f(1) = 0` (from `W[0] = 0`). By the Cauchy classifier theorem (Cauchy
1821; Aczel 1966 §2.1 Theorem 1), the unique such homomorphism up to
scale is `f(r) = c log r` for some `c in R`. With the standard
normalization `c = 1` (parent-note P4 runner-local convention), this
is `f(r) = log r`, i.e., `W[J] = log|Z[J]| - log|Z[0]|`. This is (II.b).

The two directions establish (II.b) ⇔ P1 on the framework substrate
up to the standard normalization. QED.
