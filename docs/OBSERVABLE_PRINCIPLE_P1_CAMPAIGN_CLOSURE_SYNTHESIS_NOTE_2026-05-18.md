## 2. The universal counterexample family

Define

```text
F_p[J] := r(J)^p,   r(J) := |Z[J]| > 0,   p ∈ R \ {0}.                  (1)
```

Properties:

1. **Continuous** (composition of continuous functions): ✓
2. **CPT-even** (depends only on `|Z|`, not on the fermionic phase): ✓
3. **Positive** (`r > 0`): ✓
4. **Multiplicatively factorizing** on independent subsystems
   (`Z[J_A ⊕ J_B] = Z_A · Z_B`):

   ```text
   F_p[J_A ⊕ J_B] = (r_A · r_B)^p = r_A^p · r_B^p = F_p[J_A] · F_p[J_B].   (2)
   ```

5. **Not additive** for `p ≠ 0`:

   ```text
   (r_A · r_B)^p ≠ r_A^p + r_B^p     generically for (r_A, r_B) > 0.       (3)
   ```

6. **Operator-algebraically admissible** for every `p` (D1).
7. **Reflection-positivity-compatible** for every `p` (`F_p > 0`).
8. **Gauge-invariant** for every `p` (orthogonal to gauge structure).
9. **CL3-color-automorphism-compatible** for every `p`
   (orthogonal to rep theory).
10. **Max-entropy-class-compatible** for every `p`
    (the entropy obstruction note `bae_max_entropy_retained_bounded_obstruction_note_2026-05-10_baemaxent`
    is an explicit obstruction).

Only the `p → 0` limit (`log r`, equivalently `log|Z|`) is additive.
Selecting the `log` representative from the family
`{(·)^p : p ∈ R}` requires the **Cauchy classifier**
`f(xy) = f(x) + f(y) + continuity → c log`, which IS P1 in
different vocabulary (Pattern L circularity).

## 3. Pattern L vs Pattern D taxonomy (Route E)

Every cross-disciplinary scaffold that selects `log` falls into one
of two patterns:

### Pattern L (log-reducing, circular)

Scaffolds that invoke `log` explicitly to define the "physical
scalar observable":

- Cramer rate function `Λ(X) = log E[e^{λX}]`
- Tropical dequantization `(*, +) → (max, +)` via `log_b`

- Shannon-Khinchin-Aczel-Daroczy entropy
  `H(p) = -k Σ p_i log p_i`

In each case, the **choice of `log` over `(·)^p`** is the
classification choice. That choice IS additivity, which IS P1.

### Pattern D (functor-additivity on direct sums, inapplicable)

Scaffolds that supply "additivity-on-direct-sums" theorems on
integer-valued or vector-space-valued invariants:

- Atiyah-Singer index `ind(D_1 ⊔ D_2) = ind(D_1) + ind(D_2)`
  — additivity via `dim` functor on direct sums

  `χ(X ⊔ Y) = χ(X) + χ(Y)` — additivity via Grothendieck ring `K_0`
- Homology direct sum
  `H_*(X ⊔ Y) = H_*(X) ⊕ H_*(Y)` — additivity via direct sums
- Synthetic differential geometry tangent functor
  `T(M × N) = TM ⊕ TN` — additivity via tangent functor

These Pattern-D scaffolds have **no native applicability** to
`Z[J] = det(D+J) ∈ R`, which is a single real number with no

## 6. Steelman check (N7 in this campaign)

**Steelman:** "P1 could be derivable from a future retained
primitive that hasn't been discovered yet. For instance: define
'physical scalar observable' as a functional whose local source
derivatives depend only on local data. Then `F_p[J] = |Z[J]|^p`
has local source derivative
`∂F_p/∂j_{x ∈ A} = p · |Z_A|^{p-1} · |Z_B|^p · ∂|Z_A|/∂j_x`, which
carries a global factor `|Z_B|^p` from the OTHER subsystem `B`. So
'locality of local source response' excludes `F_p` for `p ≠ 0` and
selects `log|Z|`. This locality requirement might be derivable from
cluster decomposition + the substrate's local-action structure,
giving a Path (a) candidate."

**Counter to the steelman:** "Locality of local source response" —
the requirement that `∂F/∂j_{x ∈ A}` depends only on data in
subsystem `A` — is **logically equivalent to additivity on
independent subsystems**:

- If `F[J_A ⊕ J_B] = F[J_A] + F[J_B]` (P1 = additivity), then
  `∂F/∂j_{x ∈ A} = ∂F_A/∂j_x` depends only on `A`. ✓
- Conversely, if `∂F/∂j_{x ∈ A}` depends only on `A` for all `x ∈ A`,
  integrating from `J_A = 0`, `J_B = 0` to `J_A`, `J_B` along an
  arbitrary path gives `F[J_A ⊕ J_B] - F[0] = F_A[J_A] + F_B[J_B]`
  for some functionals `F_A`, `F_B`; choosing the path along `A`
  first then `B`, vs `B` first then `A`, gives the same `F` only if
  the cross-derivative `∂²F/∂j_x ∂j_y` vanishes for `x ∈ A, y ∈ B`,
  which is the **additive decomposition** of `F`. So locality of
  source response ⇒ additivity.

Therefore the "locality of local source response" steelman candidate
**relabels P1 in derivative-locality vocabulary**; it does not
derive P1. This is Pattern L circularity in a different form
(equivalence of additivity and derivative-locality).

The steelman therefore confirms rather than refutes Route D's
structural foreclosure.
