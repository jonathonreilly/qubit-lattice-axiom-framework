## Question

The previous record-capacity note reduced the remaining P1 supplier target to
a realization plus rate-cap package:

```text
(CAP-real)  e-fold readout increments are realized by finite record collections;
(CAP-M)     each unit record has bounded magnitude, M = 1 inside the
            conditional unit schema;
(CAP-K)     each e-fold uses at most K disjoint record sectors.
```

This note asks whether the rate cap `(CAP-K)` follows once registration is
required to be a finite-speed lattice process.

## Result

Yes, conditionally. In the declared finite-speed registration class, a record
of one e-fold must be established by a source-supported perturbation over a
supplied clock window `tau`, and a register site counts only if it is
`delta`-sensitive in operator norm to that perturbation. The linked
finite-range Lieb-Robinson surface then gives a finite sensitivity radius.

For source region side length `s_X`, source budget `J_V`, LR velocity
`v_LR`, and threshold `delta`, every sensitive register lies within

```text
D* = v_LR tau + log((e/(e-1)) J_V / (v_LR delta)).
```

Thus the e-fold's sensitive register set is contained in a box of

```text
N_reach = (s_X + 2 ceil(D*))^3
```

sites. With one qubit per site, the site-register reading gives

```text
K <= N_reach,
```

and the weakest joint-sector reading gives a larger but still finite

```text
K <= 2^N_reach.
```

The bound contains no e-fold index, so it is uniform over e-folds. Combined
with `(CAP-real)` and the unit-record `(CAP-M)` inside that conditional
schema, Lemma C from the prior note gives `(BR-int)`, and the tested exponent
family selects `p = 0`.

## Realization Class

The theorem is not unconditional. Its class has four declared clauses:

- **REG-dyn:** the e-fold records are established by lattice dynamics
  generated by `H + V_k`, where `V_k` is supported in a bounded source
  region and `H` is the linked finite-range hopping/LR surface.
- **REG-tau:** each e-fold has a supplied clock window `tau`. The window is
  not derived from record counts.
- **REG-thr:** a register site must be `delta`-sensitive in operator norm to
  the e-fold source change.
- **REG-site:** pairwise disjoint records occupy pairwise disjoint nonempty
  register-site sets. The runner also checks the weaker joint-sector reading.

`(CAP-real) remains declared`. It is the association between the T1-d scalar
readout increment and the registered collection. This note does not construct
that association and does not assert it as supplied.

## Proof Sketch

Duhamel gives, for a local register observable `B_y`,

```text
||alpha_t^{H+V}(B_y) - alpha_t^H(B_y)||
  <= int_0^t ||[V, alpha_u^H(B_y)]|| du.
```

The finite-range LR bound controls the commutator tail by a series and a
closed exponential bound. If a site is `delta`-sensitive during `t <= tau`,
then the exponential bound forces its distance from the source region to be
at most `D*`. Counting sites in the enclosing box gives `N_reach`, and hence
the finite `K` bounds above.

The runner verifies the Duhamel identity on an explicit four-site instance,
checks the LR series bound against exact chain and `Z^3` block dynamics,
derives the `D*` expression symbolically, and checks the canonical
`Z^3, m -> 0, tau = 1, J_V = 1, delta = 1/10, s_X = 1` instance:

```text
D* ~= 63.82,
N_reach = 129^3 = 2146689.
```

## Falsifiers And Scope

The prior `4^k` unit-record witness remains valid as additive bookkeeping.
This note only shows it is not realizable by a uniformly bounded-window
finite-speed registration process. In the site-register reading, the
canonical cap admits `4^10` but not `4^11`; the required windows grow without
bound. In the weakest joint-sector reading, each fixed window still fails at
finite `k`.

An unbounded-speed comparator breaks the sensitivity bound by a large factor,
and symbolically `D* -> infinity` as `v_LR -> infinity`. Finite propagation
speed is load-bearing.

The exact reconstructed log-transfer `H` is quasilocal rather than strictly
finite-range. The runner records that the cap form survives on finite
truncations using the linked quasilocality numbers, but a volume-uniform
exact-H quasilocal LR constant remains a named open refinement.

## Boundaries

- This note proves `(CAP-K)` only inside the declared finite-speed
  registration class.
- `(CAP-real) remains declared`; `(REG-dyn)`, `(REG-tau)`, `(REG-thr)`, and
  `(REG-site)` are class clauses, not axioms, primitives, or accepted
  premises.
- The load-bearing route is a supplied dynamics law, `(REG-dyn)+(REG-tau)`,
  stated uniformly over every e-fold. This is a supplied law in the
  family-lift sense. It consumes no post-record certificate, and its
  uniformity comes from the symbolic absence of the e-fold index in `D*`, not
  from finite-prefix extrapolation.
- No probability law is constructed. No branch-to-scalar map is asserted.
- Records are not forced to form, and the clock window `tau` is supplied.
- This note does NOT retire P1 and does not claim unconditional P1 closure.
