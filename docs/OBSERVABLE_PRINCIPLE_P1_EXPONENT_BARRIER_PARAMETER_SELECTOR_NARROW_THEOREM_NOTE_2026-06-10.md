## 2. The family, normalized

On the real-positive branch the amplitude is `z = det(D+J)/det(D) in R_{>0}`
with `z = 1` at zero source. The exponent family `F_p = z^p` has, for each
`p`, a unique zero-baseline normalized scalar representative (the repo's

```text
g_p(z) = (z^p - 1)/p ,   g_p(1) = 0,  g_p'(1) = 1,   lim_{p->0} g_p = log z,
```

## 3. The sharpened no-go: class extension by reduction

### 3.1 Lemma R (single-pair additive rigidity) — Class A

**Statement.** Fix any pair `(r_1, r_2)` with `r_1, r_2 > 0` and
`r_1 != 1 != r_2`. If `s · g_p` satisfies the single additive-identity
instance

```text
g_p(r_1 r_2) = g_p(r_1) + g_p(r_2)
```

then `p = 0` (or `s = 0`, the degenerate zero readout).

**Proof.** With `x = r_1^p, y = r_2^p`, the residual is
`[(xy-1) - (x-1) - (y-1)]/p = (x-1)(y-1)/p`. For `p != 0`, both factors
share the sign of `p` (exactly: `(r_1^p-1)(r_2^p-1) =
4 (r_1 r_2)^{p/2} sinh(p ln r_1 / 2) sinh(p ln r_2 / 2) > 0`), so the
residual never vanishes. Runner T2 reproves the factorization symbolically
and the sinh sign argument at the concrete nondegenerate pair `(2,3)`. ∎

**Consequence (class extension).** The proven-irreducible class of the
2026-05-31 no-go extends from full (Add)/(Loc)/(Pot) to: **any selector that
entails even one nondegenerate additive-identity instance is P1-on-a-slice
and is inside the class.** Full additivity is not needed to smuggle P1 in;
one pointwise instance suffices. This is the screening test for §3.2–§3.4
and for all future N7 proposals.

### 3.2 Scale-free response kernel: reduces (full equivalence)

The candidate "select the `W` whose response kernel `z·W'(z)` is scale-free
(constant)" is (Add) verbatim in log coordinates: `z W' = c` with `W(1)=0`
integrates uniquely to `W = c log z` (runner T3, exact ODE), and conversely
differentiating `W(λz) = W(λ) + W(z)` at `z = 1` gives `λW'(λ) = W'(1)`
constant. Scale-freeness ⟺ (Add). **Discarded as a class escape; the
reduction is the content.**

### 3.3 Mode-product linearization of L1: reduces (additive sector decomposition)

The det-positivity lemma's L1 mechanism is
`det(I+B) = prod_k (1 + lambda_k^2)` for real antisymmetric `B`. The
candidate "select the readout that linearizes the proven product-over-modes
structure" fails the hostile check: the spectral mechanism behind L1 is an
*orthogonal block-diagonalization of `B` into disjoint 2x2 rotation blocks*
— a block-diagonal direct sum. Runner T4 exhibits the exact 4x4 instance
(`lambda = (1,2)` mixed by a rational Givens rotation;
`det(I+B) = 2·5 = 10` exactly). Demanding
`W(prod_k d_k) = sum_k W(d_k)` over those blocks is additive sector
decomposition verbatim, and any instance with two nondegenerate modes is a
Lemma-R instance forcing `p = 0`. **Discarded; it is P1 on the spectral
sectors.**

### 3.4 Inversion antisymmetry: reduces (additive instance on the reciprocal slice)

The candidate `W(1/z) = -W(z)` does point-select on the family:
`g_p(1/z) + g_p(z) = (z^{p/2} - z^{-p/2})^2 / p`, zero for all `z` iff
`p = 0` (runner T5). But it is the additive identity at the pair `(z, 1/z)`
given `W(1) = 0`, with operator realization `det(M ⊕ M^{-1}) = 1`
(recomputed exactly in T5): additivity demanded on the unit-determinant
reciprocal-pair sector. Standalone it does not pin the readout at all
(witness `log z + (log z)^3` is inversion-antisymmetric and non-additive,
residual `= 6` at `(e,e)`), so **its selective power on the family is
entirely its additive-slice content**. By Lemma R it is inside the extended
class. **Discarded.**

## 5. The theorem: the barrier-parameter selector

### 5.1 Statement

**Selector (NU)** (declared premise — see license boundary §5.4): the
sign-normalized readout `W` is twice differentiable on all of `R_{>0}` with
`W''` nonvanishing of constant sign, and its barrier parameter

```text
nu[W] := sup_{z>0} W'(z)^2 / |W''(z)|
```

is finite. (Domain note: "all of `R_{>0}`" is the same full-domain
hypothesis as lemma fact L3's continuity-on-`R_{>0}` and Boundary T1-d's
Cauchy-domain clause — the selector consumes no new domain input.)

**Theorem (conditional, Class A; runner T7).** Within
`{s · g_p : s != 0, p in R}`:

```text
W'^2 / |W''|  =  |s| · z^p / |p - 1| ,
```

so `nu[s·g_p] < infinity` on `R_{>0}` **iff `p = 0`**:

- `p > 0`: ratio `-> infinity` as `z -> infinity` — rejected;
- `p < 0`: ratio `-> infinity` as `z -> 0+` — rejected;
- `p = 1`: `W'' ≡ 0` — rejected by the curvature leg (and `g_1` is
  non-additive anyway: residual `(r_1-1)(r_2-1)`);
- `p = 2` (the convex quadratic, which *passes* bare self-concordance —
  this is why (NU) and not the third-derivative SC inequality is the clean
  selector): ratio `= |s| z^2 -> infinity` — rejected;
- `p = 0`: `W'^2/W'' = -1` identically, `nu[log] = 1` — selected. The log
  is the canonical barrier of `R_{>0}` and is self-concordance-extremal:
  `|W'''| = 2|W''|^{3/2}` with exact equality.

Rescaling cannot rescue any `p != 0`: the ratio carries `|s|` linearly, and
unboundedness in `z` is `s`-invariant (runner T7).

### 5.2 Class escape (the load-bearing negative half — Class A; runner T8)

(NU) is outside the extended irreducible class of §3.1. Proof by witness
family. Let

```text
W_{eps,omega}(z) = log z + eps · cos(omega · log z)   (and the sin partner),
```

with small `eps·omega`. Then (runner T8, exact):

1. **(NU) passes:** `z^2 W'' = -1 - (sqrt(2)/10) cos(log z + pi/4)` for
   `eps = 1/10, omega = 1`, bounded away from zero of constant sign, and
   `nu[W] <= (1+eps)^2 / (1 - eps·sqrt(2)) < infinity`.
2. **Additivity fails at every nondegenerate pair:** the cos witness
   violates the additive identity at the generic pair `(e, e)` and at the
   reciprocal pair `(e, 1/e)` (residual `(1 - 2cos 1)/10 != 0` — so not
   even the inversion slice is entailed). The sin-witness family covers all
   remaining pairs: its additive residual has small-`omega` expansion
   `-eps·omega^3 · u_1 u_2 (u_1 + u_2)/2` (`u_i = log r_i`), nonzero unless
   `u_1 = 0`, `u_2 = 0`, or `u_1 + u_2 = 0`, and the cos witness covers the
   `u_1 + u_2 = 0` slice. Hence **for every nondegenerate pair there is a
   (NU)-passing readout violating the additive identity there** — (NU)
   entails no additive-identity instance at all. By Lemma R's screening
   criterion, (NU) is not P1-on-any-slice.
3. **No cross-block evaluation (structural):** (NU) consumes only the
   one-variable map `z -> W(z)`; the runner asserts the selector's
   expression closure contains no two-block source symbols (`j_a`, `j_b`),

   implicitly.
4. **Not exponent-blind:** unlike the normalized/Born gradient (which
   returns `d log Z/dj` for every `p` — recomputed in T8 for contrast),
   (NU) partitions the family into `{p = 0}` versus the rest.

So (NU) is a positivity/convexity/analyticity-type condition that selects
`log` without cross-block second-derivative vanishing and without additive
sector decomposition — the exact N7 shape.
