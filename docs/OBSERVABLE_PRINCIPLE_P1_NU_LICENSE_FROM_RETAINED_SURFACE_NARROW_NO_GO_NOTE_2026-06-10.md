## 3. The positive half: Lemma N and the (BR) selector

### 3.1 Lemma N (license-demand reduction): (NU) => (BR), with constant `nu`

**Statement.** Let `W` be C^2 on `R_{>0}` satisfying (NU-ii) + (NU-iii).
Then

```text
sup_{z>0} |z W'(z)| <= nu[W].
```

Sharp at the selected member: `nu[c log z] = |c| = sup|zW'|`.

**Proof.** Pass to `u = log z in R`, `h(u) = W(e^u)`. Exactly (runner T3):

```text
h'(u) = z W'(z),     h''(u) - h'(u) = z^2 W''(z) =: phi(u),
```

so (ii) says `phi` is nonvanishing of constant sign on all of `R`, and
(iii) says `h'^2 <= nu |phi|` everywhere. Write `g = h'` (C^1 on `R`).

*Negative-curvature branch (`phi < 0`, the log-like sign):* the constraint
reads `g' <= g - g^2/nu`. (a) If `g(u_1) = c > nu` at any point, the
backward comparison solution of `G' = G - G^2/nu`, `G(u_1) = c` — the
logistic `G(u) = nu c e^{u-u_1} / (nu + c(e^{u-u_1} - 1))`, reproven exact
in the runner — blows up at the finite backward time
`u_* = u_1 + log(1 - nu/c) < u_1`; by the comparison principle `g >= G` on
`(u_*, u_1]`, contradicting continuity of `g` on all of `R`. So `g <= nu`
everywhere. (b) If `g(u_2) = -delta < 0`, the forward comparison solution
through `-delta` reaches `-infinity` at the finite forward time
`u_{**} = u_2 + log(1 + nu/delta)`; `g <= G` forward gives the same
contradiction. So `0 <= g <= nu`.

*Positive-curvature branch (`phi > 0`):* the constraint reads
`g' >= g + g^2/nu`. If `g > 0` anywhere, the super-logistic comparison
solution blows up at finite forward time (runner T3) — contradiction; so
`g <= 0`. Then `k = -g >= 0` obeys `k' <= k - k^2/nu`, the same logistic
trap as branch (a), giving `k <= nu`. So `-nu <= g <= 0`.

In both branches `sup|zW'| = sup|g| <= nu`. The full-`R` domain (= the
T1-d clause) is load-bearing: the blow-up arguments need room on both
sides. ∎

The comparison principle itself is standard mathematics (one-sided ODE
comparison with locally Lipschitz right side); the load-bearing instances —
both comparison solutions, their initial conditions, and their exact finite
blow-up times — are reproven symbolically in the runner (T3), and the
lemma's conclusion is verified on the family and on the (NU)-passing cos
witness (`sup|zW'| = 11/10 <= nu-bound = (11/10)^2/(1 - sqrt(2)/10)`).
