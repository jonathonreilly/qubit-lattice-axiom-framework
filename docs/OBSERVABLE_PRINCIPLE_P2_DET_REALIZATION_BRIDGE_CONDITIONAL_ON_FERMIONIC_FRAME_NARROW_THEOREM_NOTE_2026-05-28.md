### 4.1 The invariance theorem (proved inline; also recorded in the sibling Result B)

> **Lemma (relabeling-invariance).** For any permutation unitary `P` relabeling
> the three `hw = 1` corner-triplet staggered modes (extended by the identity on
> the rest of the mode space) and any operator `X`,
>
> ```text
> det(P X P^†) = det(X),     spec(P X P^†) = spec(X),
> Z = Tr(e^{−βĤ}) = ∑_k e^{−βE_k}   (a symmetric function of spec(Ĥ))  is invariant.
> ```

**Proof.** A permutation unitary satisfies `P^† = P^{−1}` and `|det P| = 1`, so
`det(P X P^†) = det(P) det(X) det(P^{−1}) = det(X)`. Conjugation by an invertible
matrix is a similarity transform, so `spec(P X P^†) = spec(X)`. The trace
`Z = Tr(e^{−βĤ}) = ∑_k e^{−βE_k}` is a symmetric function of `spec(Ĥ)`, hence
invariant whenever the spectrum is. A relabeling of the `hw = 1` triplet is
exactly such a conjugation. ∎

The proof above is self-contained, and the runner's Block 3 exhibits it to
