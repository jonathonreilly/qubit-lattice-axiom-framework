## 3. Lemmas D1–D4 with inline proofs

### D1 — character-form selection

**Statement.** Let `χ: GL(n, C) → C*` be an algebraic/rational scalar
character satisfying

```text
χ(A·S)  =  χ(A) · χ(S)        for all A, S ∈ GL(n, C).                   (M)
```

Then `χ = det^k` for some integer `k`. In particular `tr`, the power
traces `tr(M^s)` (`s ≠ 1`), and the elementary symmetric polynomials
`e_1, …, e_{n-1}` are excluded by `(M)` alone.

**Inline proof.** The commutator subgroup of `GL(n, C)` is `SL(n, C)`,
because every matrix of determinant 1 is a product of elementary
transvections, and every such transvection is itself a commutator. The
abelianization is therefore

```text
GL(n, C) / [GL(n, C), GL(n, C)]  =  GL(n, C) / SL(n, C)  ≅  C*,
```

with the isomorphism given by `det`. Any homomorphism `χ` from `GL(n, C)`
to an abelian group must kill the commutator subgroup `SL(n, C)`; hence
`χ` factors as `χ = φ ∘ det` for some homomorphism `φ: C* → C*`. Inside
the algebraic/rational character class, the only such `φ` are the
integer powers `φ(z) = z^k`, so `χ = det^k`.

The exclusion of `tr` is immediate: `tr(A·S) ≠ tr(A) · tr(S)` for generic
`A, S` (a concrete numeric witness with `A = [[2,1],[1,2]]`,
`S = [[3,0],[1,4]]` gives `tr(A·S) = 15` while `tr(A)·tr(S) = 28`, and
`tr(A) + tr(S) = 11` — all three distinct). The exclusion of power
traces `tr(M^s)` for `s ≠ 1` and elementary symmetric polynomials
`e_{1..n-1}` is verified symbolically by the runner; each fails `(M)` on
generic 2x2 and 3x3 entries.

### D2 — logarithmic-form selection (Cauchy–Erdős via dense-image continuous extension)

```text

```

Then `W(r) = c log r` for some real constant `c`.

### D3 — overall-scale normalization `c = 1`

**Statement.** The framework's per-site one-qubit operator algebra
`A_x = M_2(C) ≅ Cl(3, 0)` (one-qubit-per-site baseline) admits a **unique
tracial state** `τ`, characterized by `τ(AB) = τ(BA)` for all
`A, B ∈ M_2(C)`. Its density-matrix form is `ρ = I_2 / 2`, equivalently
`τ(A) = Tr(A) / 2`. Any other normalized tracial state on `M_2(C)`
equals `τ`.

**Inline proof.** Let `τ` be any normalized tracial linear functional on
`M_2(C)` (equivalently `M_n(C)` for any `n`). On the matrix units
`E_{ij}`, traciality gives

```text
τ(E_{ij})  =  τ(E_{ii} E_{ij})  =  τ(E_{ij} E_{ii})  =  0    for i ≠ j,
```

because `E_{ij} E_{ii} = δ_{i ≠ j} · 0` when `i ≠ j` in the second
factor. Similarly,

```text
τ(E_{ii})  =  τ(E_{ij} E_{ji})  =  τ(E_{ji} E_{ij})  =  τ(E_{jj})    for all i, j,
```

so all diagonal matrix-unit values are equal; normalization `τ(I) = 1`
fixes them to `1/n`. For `n = 2`: `τ(A) = Tr(A)/2`. ∎

### D4 — phase-blindness on the staggered surface

**Statement.** On the staggered Cl(3)/Z³ canonical block with mass term
`m·I` (`m > 0`) and balanced even sublattice partition, the Berezin
determinant readout `det(M)` with `M = M_KS + m·I` satisfies

```text
det(M)  =  ∏_{i=1}^{n/2}  (m² + σ_i²)  ≥  m^n  >  0,
```

configuration-by-configuration on every SU(3) gauge background, with
`σ_i` the singular values of the off-diagonal block `K` of `M_KS` in the
ε-sorted basis. In particular `det(M)` is a strictly positive real, so
`log|det(M)| = log det(M)` there with no phase. On the source-perturbed
neighbourhood `M = M_KS + m·I + J`, continuity of the determinant
preserves the sign on an open `U_0` neighbourhood of `J = 0`, so
`|det(M)| = det(M)` continues there.

**Inline proof sketch (see retained authority for the full derivation).**
`M_KS` is anti-Hermitian and `{ε, M_KS} = 0`; in the ε-sorted basis
`M_KS = [[0, K]; [-K^†, 0]]` and `M = m·I + M_KS` has block form
`[[m·I, K]; [-K^†, m·I]]`. Then `ε M` is Hermitian, and the SVD of `K`
diagonalizes `ε M` into `n/2` decoupled 2x2 blocks of the form
`[[m, σ_i]; [σ_i, -m]]`, each with determinant `−(m² + σ_i²)`. So
`det(ε M) = (−1)^{n/2} ∏_i (m² + σ_i²)`, and since `det(ε) = (−1)^{n/2}`
on the balanced lattice, the multiplicativity `det(ε M) = det(ε)·det(M)`
gives `det(M) = ∏_i (m² + σ_i²)`. Strict positivity follows from
`m² + σ_i² ≥ m² > 0`. ∎
