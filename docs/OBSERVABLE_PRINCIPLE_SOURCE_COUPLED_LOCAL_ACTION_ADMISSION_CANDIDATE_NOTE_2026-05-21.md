### Exercise 2: Elon first-principles

Strip to first principles. What does it mean for the source-coupled
local action to be the primitive observable-side structure in a lattice
framework?

**First principle 1.** A lattice action is a sum of local terms by
construction. On the staggered Cl(3)⊗Z³ lattice, the source-deformed
Dirac operator `D + J` acts on the Grassmann field `ψ` at each site;
the bilinear `ψ̄(D + J)ψ` is by construction a sum

```text
S[J] = ψ̄(D + J)ψ = Σ_{x,y} ψ̄_x (D + J)_{x,y} ψ_y                       (1)
```

over lattice sites. For a local source `J = Σ_x j_x P_x` with local
projectors `P_x` (the parent note's local-source convention), `S`
decomposes into single-site source-dependent terms plus the
source-independent kinetic part:

```text
S[J] = ψ̄ D ψ + Σ_x j_x · (ψ̄ P_x ψ)
     = Σ_x s_x(J, ψ, ψ̄),                                                (2)
```

where `s_x(J, ψ, ψ̄)` collects the kinetic terms at site `x` plus the
single-site source term `j_x (ψ̄ P_x ψ)`. The `Σ_x s_x` decomposition
is structural; no additivity-on-independent-subsystems premise is
invoked to obtain it.

**First principle 2.** The partition function `Z[J]` is the Berezin
integral of `exp(-S[J])`:

```text
Z[J] = ∫ exp(-S[J]) Dψ̄ Dψ = det(D + J).                                (3)
```

Berezin integration on Grassmann generators is a universal
mathematical operation (Berezin 1966; DeWitt 1984; standard QFT
textbook content). The identity `∫ exp(-ψ̄ M ψ) Dψ̄ Dψ = det(M)` for
square matrix `M` is a finite-dimensional theorem of multilinear
algebra; no probability theory, no classification of physical
observables, no admitted P1 input. (3) is a derived equation, not an
admission.

**First principle 3.** For block-diagonal `D = D_A ⊕ D_B` on
direct-sum Hilbert space `H_A ⊕ H_B` with local sources
`J = J_A ⊕ J_B` supported on disjoint regions, the Grassmann variables
factorize: `Dψ̄ Dψ = (Dψ̄_A Dψ_A)(Dψ̄_B Dψ_B)`, the action factorizes
`S[J_A ⊕ J_B] = S_A[J_A] + S_B[J_B]` by the local decomposition (2),
and the exponential factorizes
`exp(-S[J_A ⊕ J_B]) = exp(-S_A) · exp(-S_B)`. Berezin integration
factorizes:

```text
Z[J_A ⊕ J_B] = ∫ exp(-S_A) · exp(-S_B) Dψ̄_A Dψ_A Dψ̄_B Dψ_B
            = (∫ exp(-S_A) Dψ̄_A Dψ_A) · (∫ exp(-S_B) Dψ̄_B Dψ_B)
            = Z_A[J_A] · Z_B[J_B].                                       (4)
```

Equation (4) is the multiplicative factorization. **It is derived
from Berezin factorization on independent Grassmann generators, not
from a multiplicative-factorization premise.**

**First principle 4.** The generating functional `W[J]` of the
framework is defined as `W[J] := log|Z[J]| - log|Z[0]|` via the
**Bell/Möbius cumulant-generating-functional convention** (S.2). The
log-multiplicativity gives, from (4):

```text
W[J_A ⊕ J_B] = log|Z[J_A ⊕ J_B]| - log|Z[0]|
            = log|Z_A[J_A] · Z_B[J_B]| - log|Z_A[0] · Z_B[0]|
            = log|Z_A[J_A]| + log|Z_B[J_B]|
              - log|Z_A[0]| - log|Z_B[0]|
            = W_A[J_A] + W_B[J_B].                                       (5)
```

**P1 (scalar additivity on independent subsystems) follows in three
lines from S.1 (Berezin) + (4) + S.2 (cumulant-generating-functional
identity) + elementary `log|ab| = log|a| + log|b|`.** No selection
step from `{F_p}` is invoked; P1 is a derived corollary, not a
foundational premise.

**First principle 5.** The source-coupling convention separates local
insertions from connected responses:

```text
O_x[J] := ∂S[J]/∂j_x = ψ̄ P_x ψ                                         (6)
```

`∂S/∂j_x` is the local operator insertion coupled to the source at
site `x`. After Berezin integration, source derivatives of
`W = log Z` generate its expectation value and connected responses:
`⟨O_x⟩[J] = ∂W/∂j_x`, with higher connected responses from higher
source derivatives of `W`. The source-derivative `∂S/∂j_x` is local by
construction because `S` is a sum of local terms. Additivity on
disjoint regions is likewise structural:
`∂S/∂j_A := Σ_{x ∈ A} ∂s_x/∂j_x = Σ_{x ∈ A} (ψ̄ P_x ψ)`.

**Comparison with standard QFT foundations.** In standard QFT
(Peskin-Schroeder, Weinberg, Zinn-Justin, Itzykson-Zuber), the
foundational object is the **action S** (the Lagrangian density
integrated over spacetime). The partition function `Z[J]` is derived
from S via path integration. The generating functional `W = log Z` is
derived from Z as the connected generating functional (Peskin-Schroeder
§9, Weinberg Vol II §16). The lattice-QFT tradition (Wilson 1974;
Susskind 1977; Kogut-Susskind 1975; Becher-Joos 1982) puts the action
S at the foundation, with Z and W as derived computational tools.

The current parent note's parent scalar-generator-selection shape — treating W as the primary
scalar observable generator with P1 as a selection premise — is
**non-standard** relative to the standard QFT foundational layer. The
source-coupled local-action candidate **aligns the framework with standard QFT
conventions**: the local action is foundational; the partition
function and generating functional are derived computational tools.
This alignment does not by itself force the audit lane to ratify the
restructuring, but it is the structural rationale for considering the
source-coupled local-action shape as the framework's foundational layer.

### Exercise 4: Math search (Tao-style)

**Bare math problem.** Let `H = H_A ⊕ H_B` be a finite-dimensional

```text
S[J](ψ, ψ̄) := ψ̄(D + J)ψ = Σ_{x,y} ψ̄_x (D + J)_{x,y} ψ_y.              (7)
```

**Question (a).** Does `S[J_A ⊕ J_B] = S_A[J_A] + S_B[J_B]` (action
additivity on direct-sum decomposition) follow without invoking an
additivity-on-independent-subsystems premise on the functional class?

**Honest answer.** Yes. Since `(D + J)` is block-diagonal,
`(D + J)_{x,y} = 0` when `x ∈ A` and `y ∈ B` (or vice versa), so

```text
S[J_A ⊕ J_B] = Σ_{x,y ∈ A} ψ̄_x (D_A + J_A)_{x,y} ψ_y
              + Σ_{x,y ∈ B} ψ̄_x (D_B + J_B)_{x,y} ψ_y
            = S_A[J_A] + S_B[J_B].                                       (8)
```

Equation (8) is **direct construction** by block-diagonal matrix
algebra. No additivity premise, no classification on `{F_p}`, no
Cauchy classifier.

**Question (b).** Does `Z[J_A ⊕ J_B] = Z_A[J_A] · Z_B[J_B]` follow from
Berezin factorization on independent Grassmann variables, without
invoking a multiplicative-factorization premise?

**Honest answer.** Yes. The Grassmann generators
`{ψ_x, ψ̄_x : x ∈ A} ∪ {ψ_x, ψ̄_x : x ∈ B}` are independent (their
anticommutators across A and B are zero by Grassmann algebra rules),
so the integration measure factorizes
`Dψ̄ Dψ = (Dψ̄_A Dψ_A)(Dψ̄_B Dψ_B)`. The Berezin integration formula
gives

```text
Z[J_A ⊕ J_B] = ∫ exp(-S[J_A ⊕ J_B]) Dψ̄ Dψ
            = ∫ ∫ exp(-S_A[J_A] - S_B[J_B]) (Dψ̄_A Dψ_A)(Dψ̄_B Dψ_B)
            = (∫ exp(-S_A) Dψ̄_A Dψ_A) · (∫ exp(-S_B) Dψ̄_B Dψ_B)
            = Z_A[J_A] · Z_B[J_B].                                       (9)
```

Equation (9) is **direct construction** by Berezin factorization. No
multiplicative-factorization premise, no Hilbert-tensor-product
factorization premise, no classification step.

**Question (c).** Does `log|Z[J_A ⊕ J_B]| = log|Z_A| + log|Z_B|` follow
from log algebra?

**Honest answer.** Yes. From (9),
`|Z[J_A ⊕ J_B]| = |Z_A| · |Z_B|`, so
`log|Z[J_A ⊕ J_B]| = log|Z_A · Z_B| = log|Z_A| + log|Z_B|` by
elementary log algebra on positive reals.

**Question (d).** Does the convention that `∂S/∂j_x` defines a local
operator insertion, with `∂W/∂j_x` generating its response, require an
additivity-on-independent-subsystems premise on the functional class of
admissible observables?

**Honest answer.** No additivity premise is required to **derive**
the locality of ∂S/∂j_x: if `S = Σ_x s_x(J)` is a local sum, then
`∂S/∂j_x = ∂s_x/∂j_x` is the single-site coefficient, automatically
local. Additivity on disjoint regions follows: for `A ⊂ Z^3`,
`∂S/∂j_A := Σ_{x ∈ A} ∂s_x/∂j_x = Σ_{x ∈ A} (ψ̄ P_x ψ)` is a local sum.

**But** the source-coupling interpretation itself is a convention
(S.3). It is the standard lattice-QFT convention; it does not arise
from the two-axiom framework alone without admitting how source couplings name physical
insertions and responses. The convention is structurally smaller than
P1 because it does not select among the `{F_p}` family, does not
require the Cauchy classifier, and does not impose additivity on
functionals of |Z|. It is still an admitted convention.

**Bottom line of Exercise 4.** Action-additivity (8), partition-
function-multiplicativity (9), and log-additivity (5) all follow by
**direct construction** from Berezin algebra plus block-diagonal
matrix algebra. The source-coupled local-action candidate's derivation of P1 from
