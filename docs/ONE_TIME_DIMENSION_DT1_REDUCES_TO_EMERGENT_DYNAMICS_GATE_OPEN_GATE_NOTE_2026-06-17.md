## Kinematic Witness

The runner constructs a finite two-site qubit sector with two commuting
Hermitian generators:

```text
G1 = sigma_z tensor I,
G2 = I tensor sigma_z.
```

It verifies:

- `G1` and `G2` commute and are linearly independent;
- `U(s,t) = exp(-i(sG1 + tG2))` is an `R^2` group homomorphism;
- `U(1,0)` is not on the one-parameter orbit generated by `G1 + G2`.

This is a kinematic witness that the Lattice/Quantum/Record baseline by itself
does not exclude an independent second commuting clock generator. Record is a
durable realized-outcome readout with finite additivity over finite
pairwise-disjoint record collections; it supplies no order, dynamics, or
generator-count rule.

## Tested Non-Closures

The runner and note check the following current candidate routes:

- **Clifford/anomaly parity:** allows `d_t = 1, 3, 5, ...`; it supplies only the
  odd lower/parity side.
- **Tegmark/ultrahyperbolic well-posedness:** requires an external predictive
  determinism desideratum not supplied by the axioms or primitives.
- **Record single-order:** is a supplied post-record layer, not a consequence of
  Record itself.
- **Stone/N5:** proves uniqueness relative to a supplied one-parameter transfer;
  using it to rule out multiple generators assumes the single-generator clause.
- **Bare kinematics:** admits the two-generator witness above, so it does not
  supply `d_t <= 1`.

This list supports the open-gate reduction. It is not an exhaustive no-go claim
that every future route to the single-generator gate is impossible.
