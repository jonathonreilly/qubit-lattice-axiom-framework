- Densities in the affine chart `ρ = (I + r · σ)/2`, with Pauli matrices
  `σ = (σ_x, σ_y, σ_z)` and `I` the `2 × 2` identity.
- The proper cubic group `G`: the `24` signed permutation matrices of
  determinant `+1`. It is generated by the right-hand `90°` rotations about the

This is the `3`-vector representation of the proper cubic group. It is not a
Born kernel and not a uniqueness argument for a universal parameter `r = 1/2`.

## Theorem 1 — generating rotations act irreducibly on `Q^3`

The `90°` rotation about `z` sends `(x, y, z) ↦ (−y, x, z)`. The `90°`
rotation about `x` sends `(x, y, z) ↦ (x, −z, y)`. Write `R_z` and `R_x` for
these linear maps. They generate a group that acts irreducibly on `Q^3`.

**Proof.** The stated formulae are the standard right-hand `90°` matrices

```text
R_z = [[ 0, -1, 0],
       [ 1,  0, 0],
       [ 0,  0, 1]],
R_x = [[ 1,  0,  0],
       [ 0,  0, -1],
       [ 0,  1,  0]].
```

Both are signed permutation matrices of determinant `+1`. Closing under
multiplication produces exactly the `24` determinant-`+1` signed permutation
matrices, which is `G`.

The standard Euclidean form on `Q^3` is `G`-invariant, and `|G| = 24` is
invertible in `Q`, so every `Q`-subrepresentation is complemented by its
orthogonal. It is therefore enough to rule out a one-dimensional invariant
subspace.

Let `0 ≠ r = (x, y, z) ∈ Q^3` and suppose `Q r` is `G`-invariant. Then every
generator multiple of `r` is a rational multiple of `r`.

- If `R_z r = λ r`, then `−y = λ x`, `x = λ y`, and `z = λ z`. The first two
  equations give `−y = λ² y`. Over `Q` one cannot have `λ² = −1`. Thus `y = 0`,
  hence `x = 0`, so `r = (0, 0, z)` with `z ≠ 0`. Then `R_z r = r`, but
  `R_x r = (0, −z, 0)` is not a rational multiple of `(0, 0, z)`.
- The same obstruction appears after rotating any other single-axis vector
  into the `z`-axis.

Thus there is no one-dimensional invariant `Q`-subspace, hence no proper
invariant subspace. The action is irreducible on `Q^3`.

A direct spanning argument, used by the runner, is equivalent. If `r ≠ 0`,
the `Q`-span of `{ g r : g ∈ G }` is all of `Q^3`:

- one nonzero coordinate: `R_z` and `R_x` permute the axes and produce a
  basis;
- exactly two nonzero coordinates, say `(x, y, 0)` with `x y ≠ 0`: the block
  `[[x, −y], [y, x]]` has determinant `x² + y² ≠ 0`, so the coordinate plane is
  filled, and `R_x r = (x, 0, y)` supplies the third axis;
- three nonzero coordinates: `R_z r − r = (−y − x, x − y, 0)` is a nonzero
  vector in a coordinate plane (`x = −y` and `y = x` would force `x = y = 0`),
  and the previous case applies.

## Theorem 2 — the only common fixed vector is `0`

If `R r = r` for every `R` in the generating set `{R_z, R_x}`, then `r = 0`.

**Witness.** `R_z r = r` means `(−y, x, z) = (x, y, z)`, so `x = −y` and
`y = x`. Substituting gives `x = −x`, hence `x = 0` and `y = 0`. Then
`R_x r = r` with `x = 0` means `(0, −z, y) = (0, y, z)`, so `y = −z` and
`z = y`. Substituting gives `y = −y`, hence `y = 0` and `z = 0`. Therefore
`r = 0`.

Because the generators already force `r = 0`, the same vanishing holds for
every element of `G`. Equivalently, the Reynolds projector
`(1/|G|) ∑_{g ∈ G} g` is the zero endomorphism of `Q^3`.

## Theorem 3 — the only cubic-invariant traceless Hermitian `2 × 2` is `0`

Identify traceless Hermitian matrices with Bloch vectors by

```text
r · σ = [[ z,      x − i y ],
         [ x + i y,   −z    ]].
```

This is a `Q(i)`-linear isomorphism from `Q^3` onto the traceless Hermitian
`2 × 2` matrices with rational (equivalently, in this chart, `Q`-coordinate)
Pauli coefficients. The proper cubic action is defined so that
`R · (r · σ) = (R r) · σ`. Therefore `H = r · σ` is cubic-invariant if and
only if `r` is cubic-invariant. Theorem 2 gives `r = 0`, hence `H = 0`.

In the affine chart `ρ = (I + r · σ)/2`, the same vanishing is `ρ = I/2`.
Thus the only cubic-invariant density in this affine chart is `I/2`.

This identification is a statement about the chart. It does not adopt `I/2`
as a vacuum, and it does not declare `I/2` to be a physical state of the
lattice.

## Theorem 4 — covariance constrains only a cubic-symmetric Bloch chart

Lattice names proper cubic rotations about each site. Admissibility names one
fixed nearest-neighbor rule, covariant under those rotations. If a site law is
represented as a Bloch density `ρ = (I + r · σ)/2`, and if the nearest-neighbor
`6`-tuple is cubic-symmetric (so the covariance action is the `3`-vector
action of `G` on that site's `r`), then covariance forces `R r = r` for every
`R ∈ G`, hence `r = 0` by Theorem 2.

A `6`-tuple that breaks cubic symmetry is not so constrained. The vector

```text
r = (3/5, 0, 0)
```

is a legal point of the chart (`r ∈ Q^3`; `|r|` is not required). It is not
cubic-invariant: `R_z` sends it to `(0, 3/5, 0)`. Both vectors are admissible
as Bloch coordinates. Neither is forbidden by Lattice or Admissibility once
the neighborhood itself fails to be a cubic singlet.

## Theorem 5 — not universal `r = 1/2`, not a Born kernel, not a vacuum

This note is not a universal `r = 1/2` claim, not a Born-kernel uniqueness
theorem, and not a vacuum axiom. It does not adopt `I/2`. It does not force `r = 1/2` through any dictionary. The symbol `r` here is a Bloch `3`-vector,
not a Born weight, not a Koide parameter, and not a unique tracial state.

In particular:

- `r = 0` in this chart is the statement that the traceless Pauli part
  vanishes. It is not the parameter value `r = 1/2`.
- Uniqueness of `I/2` is uniqueness of a `G`-fixed point in one affine chart
  under a representation hypothesis. It is not uniqueness of a Born kernel
  on menus, and it is independent of any unique-tracial-state argument.
- Displaying `I/2` as the unique invariant density in the chart is not an
  adoption of `I/2` as vacuum and is not an instruction to insert `I/2` into
  any other dictionary.
