## Minimum Future Primitive Candidates

These are not proposed as axiom edits here. They are the smallest operational
premise shapes the current evidence would need if bridge derivations fail.

### 1. Record Extension / Occurrence

```text
Given a finite record boundary and local possibility domains, a local
composable rule may extend the record set by locking available possibilities at
selected unrecorded sites. It never overwrites records and never locks
unavailable possibilities.
```

This would unlock record production, empirical histories, and frequency claims.
It must also say whether activation/selection is deterministic, weighted, or
instrument-based, and how occurrence rate is normalized.

### 2. Physical Readout Coupling

```text
In a supplied finite record context, a physical scalar readout must be
identified by a local covariant coupling from selected record invariants to
record values.
```

For the current charged-lepton lane, the concrete target is:

```text
the charged-lepton phase magnitude records the selected local C3 defect
density.
```

This would unlock the remaining `AC_phi_lambda` phase-defect atom if accepted
or derived. It should not be worded as a general "read every invariant" rule;
the coupling must name the physical context and scalar readout.

### 3. Physical Source / Observable Selector

```text
A physical source/action theorem must identify which record-facing action/RN
coordinate is the physical source, including its direction, unit, and measured
observable semantics.
```

This would unlock source/action coefficients, metric/observable rows, and
source-normalized predictions. The current RN/action algebra is already narrow:
the missing piece is physical source direction and unit, not finite probability
calculus.

### 4. Gauge-Sector Measure / Theta Selector

```text
A gauge-sector theorem must supply the emergent topological sector label, the
pointwise sector measure used by record-facing probabilities, and the joint
gauge/mass invariant `theta_bar`.
```

This is probably a bridge target before it is a primitive target. The current
theta stack does not justify putting a generic theta selector into the axioms.

## Axiom Consequence

The four ontology axioms should stay minimal unless the project intentionally
chooses an operational foundation rather than an ontology-only foundation.

The cleanest current policy is:

```text
Do not edit Lattice, Qubit, Admissibility, or Record for these gates.
Build bridge theorems first.
If a bridge route fails, register the specific operational primitive that
failed, with its boundary and non-claims.
```

This preserves the current story: reality is a physical lattice of local
possibility, constrained by nearest-neighbor admissibility, with records as
fixed readable outcomes. The missing work is how physical law produces,
couples, weights, sources, and measures those records.
