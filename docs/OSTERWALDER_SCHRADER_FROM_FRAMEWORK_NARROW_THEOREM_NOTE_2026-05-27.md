## 5. Proof

### 5.1 (OS1) Discrete spectral decomposition of T

By (C-RP) (R2), the physical Hilbert space `H_phys` reconstructed from
the staggered-only canonical action on a finite block is
finite-dimensional. By (C-RP) (R3), the transfer matrix
`T : H_phys → H_phys` is Hermitian and positive with
`0 < ‖T‖_op ≤ 1`.

On a finite-dimensional complex Hilbert space, every positive
Hermitian operator is diagonalizable with positive real eigenvalues
(finite-dim spectral theorem; Halmos §79). Hence there exists an
orthonormal basis `{|k⟩}_{k=1}^{N}` of `H_phys` (with
`N = dim H_phys < ∞`) and positive reals
`λ_1, λ_2, ..., λ_N ∈ (0, M_T]` such that

```text
    T  =  Σ_k  λ_k · |k⟩⟨k|,                                          (5.1.a)
```

with `M_T = ‖T‖_op = max_k λ_k`. By (C-SC) Step 2, the kernel of `T`
is empty on the canonical surface (else restrict to its orthogonal
complement). So all `λ_k > 0` and (5.1.a) is the (OS1) statement. ∎

### 5.2 (OS2) Discrete Euclidean semigroup

By (C-SC) (SC1), `H := -(1/a_τ) log(T / M_T)` is self-adjoint on
`H_phys`. Without loss of generality, absorb `M_T` into a constant
shift of `H` (or set `M_T = 1` by canonical normalization; the
following arithmetic is identical up to that shift, which only adds
an overall phase to `U(t)` that does NOT affect unitarity, group
property, or Wick-rotation correspondence). Under the canonical
normalization of (C-SC), `M_T = 1` and `H = -(1/a_τ) log(T)` directly.

From (OS1), apply the spectral functional calculus:

```text
    H  =  -(1/a_τ) log(T)  =  Σ_k  E_k · |k⟩⟨k|,
                              E_k := -(1/a_τ) log(λ_k) ≥ 0.            (5.2.a)
```

The exponential function applied to `-n a_τ H` yields

```text
    exp(-n a_τ H)  =  Σ_k  exp(-n a_τ E_k) · |k⟩⟨k|
                   =  Σ_k  λ_k^n · |k⟩⟨k|.                             (5.2.b)
```

By (OS1), the right-hand side of (5.2.b) is `T^n`. Hence

```text
    T^n  =  exp(-n a_τ H),    n ∈ Z_{≥0}.                              (5.2.c)
```

This is the (OS2) statement. ∎

### 5.3 (OS3) Real-time analytic continuation

On the *same* orthonormal eigenbasis `{|k⟩}` of (OS1), define

```text
    U(t)  :=  Σ_k  exp(-i t E_k) · |k⟩⟨k|,    t ∈ R.                  (5.3.a)
```

The right-hand side is a finite sum of bounded scalar functions
(each `|exp(-i t E_k)| = 1`) times fixed orthogonal projectors
`|k⟩⟨k|`. On the finite-dim `H_phys`, this defines an operator-valued
function `U : R → B(H_phys)` with `‖U(t)‖_op ≤ 1` for all `t`.

No infinite-dim functional analysis (Stone's theorem on Banach spaces,
analytic continuation of unbounded operators, etc.) is invoked: the
spectral expansion (5.3.a) is direct operator definition on
finite-dim `H_phys`. ∎

### 5.4 (OS4) Properties of U(t)

Direct computation from the spectral expansion (5.3.a):

**(OS4.a) Unitarity.** Using orthonormality `⟨k|j⟩ = δ_{kj}` and
`exp(+i θ) · exp(-i θ) = 1`:

```text
    U(t)^†  =  Σ_k  exp(+i t E_k) · |k⟩⟨k|,
    U(t)^† U(t)  =  Σ_{k,j} exp(+i t E_k) exp(-i t E_j) |k⟩⟨k|j⟩⟨j|
                  =  Σ_k  exp(+i t E_k) exp(-i t E_k) |k⟩⟨k|
                  =  Σ_k  |k⟩⟨k|  =  I_{H_phys}.                       (5.4.a)
```

**(OS4.b) Group property.** Using `exp(-i s E_k) · exp(-i t E_k) =
exp(-i (s+t) E_k)`:

```text
    U(s) U(t)  =  Σ_{k,j} exp(-i s E_k) exp(-i t E_j) |k⟩⟨k|j⟩⟨j|
                =  Σ_k  exp(-i (s + t) E_k) |k⟩⟨k|  =  U(s + t).      (5.4.b)
```

**(OS4.c) Identity at zero.** From `exp(0) = 1`:

```text
    U(0)  =  Σ_k  exp(0) |k⟩⟨k|  =  Σ_k  |k⟩⟨k|  =  I_{H_phys}.       (5.4.c)
```

**(OS4.d) Strong continuity.** Each scalar `exp(-i t E_k)` is a
continuous function of `t`. On the finite-dim `H_phys`, the sum
`Σ_k exp(-i t E_k) |k⟩⟨k|` is a finite sum, so `t → U(t)` is
operator-norm continuous (and therefore strongly continuous). ∎

**(OS4.e) Generator is H.** From (5.3.a) and (5.2.a):

```text
    U(t)  =  Σ_k  exp(-i t E_k) |k⟩⟨k|  =  exp(-it · Σ_k E_k |k⟩⟨k|)
          =  exp(-itH).                                                (5.4.e)
```

Combining (5.4.a)–(5.4.e): `U(t) = exp(-itH)` is a strongly-continuous
one-parameter unitary group on `H_phys` with self-adjoint generator
`H` from (C-SC). ∎

### 5.5 (OS5) Wick-rotation bridge T^n ↔ U(t)

From (5.2.c) and (5.4.e):

```text
    T^n  =  exp(-n a_τ H)         (Euclidean discrete semigroup),
    U(t)  =  exp(-itH)            (Lorentzian unitary group).
```

Both are obtained by applying the **same** spectral functional
calculus on the **same** self-adjoint generator `H` (5.2.a) on the
**same** finite-dim Hilbert space `H_phys`. The only difference is
the scalar prefactor in the exponent:

```text
    T^n parametrized by   x_E := n · a_τ ∈ a_τ · Z_{≥0} ⊆ R_{≥0},
    U(t) parametrized by  x_L := i · t ∈ i · R,
    with exp(-x · H) the common functional form.
```

The "Wick rotation" `x_E → x_L`, i.e., `n a_τ → i t`, is a scalar
parameter rotation inside the spectral functional calculus, not a
separate operator-level analytic continuation. The spectral expansion
of `exp(-x H)` over the orthonormal eigenbasis `{|k⟩}` is the same
finite sum

```text
    exp(-x H)  =  Σ_k  exp(-x E_k) |k⟩⟨k|
```

regardless of whether `x ∈ R_{≥0}` (Euclidean side) or
`x ∈ iR` (Lorentzian side). The framework's (P-OS) statement is
precisely this observation: on finite-dim `H_phys` with the spectral
data of (OS1), the `T^n ↔ U(t)` bridge is a parameter substitution
inside a finite spectral sum, no separate axiom.

This is exactly the inline step (C-Sc) Step 1 lines 261–266 already
records:

The present narrow records that this inline step **IS** the framework's
