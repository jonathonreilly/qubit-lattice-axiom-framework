## Statement

Let the 8 native spatial Brillouin-zone corners be `k in {0,pi}^3`. Let the
framework CPT operator be `Theta = C.P.T` with the retained_bounded instance of
[`CPT_EXACT_REAL_ANTI_HERMITIAN_D...`](CPT_EXACT_NOTE.md): `C =`
sublattice parity `(-1)^{x1+x2+x3}`, `P =` spatial inversion `x -> -x`, `T = K =`
complex conjugation; the antiunitary representative on the Hermitian lift
`H = iD` is `Theta_H = P.K`. Let the temporal-corner exchange be the Matsubara
character `S : k4 = 0 <-> k4 = pi`.

**Conclusion (A) — structural slot (count-preserving vs count-doubling).** The
K/CPT-orbit involution acts **within the 8 spatial corners**: `P` and `K` send
`k -> -k`, and `C` sends `k -> k+(pi,pi,pi)`, each of which maps `{0,pi}^3` onto
itself (since `-0 = 0`, `-pi = pi` mod `2pi`). So the K/CPT operation is a
**permutation of the 8 corners — the count stays 8**
(`staggered_dirac_substep3_bz_corner_hamming_orbit`, retained). The temporal
factor of 2 is, by contrast, a **new coordinate** `k4 in {0,pi}`: it takes the
corner set `{0,pi}^3` to `{0,pi}^3 x {0,pi}`, **doubling the count `8 -> 16`**
(`naive_lattice_fermion_two_power_d_species_count`, retained). A
count-preserving spatial `Z2` cannot be the count-doubling temporal `Z2`.

**Conclusion (B) — linearity (antiunitary vs unitary).** `Theta_H = P.K` is
**antiunitary** (`Theta_H(i v) = -i Theta_H(v)`); the temporal exchange `S` is a
**unitary** translation character (`S(i v) = i S(v)`). An antilinear involution
and a linear involution are different operators; the K/CPT `Z2` and the
temporal-corner `Z2` are not the same group acting on the same structure — they
coincide only in cardinality (both order 2).

**Conclusion (C) — finite-additivity gives multiplicity 1, not 2.** A3 states
the realized outcome **is** the orbit — a *single* realized record — and the
scalar readout `I` is "finitely additive over any finite pairwise-disjoint
collection of records." The realized orbit is a collection of size 1, so
`I(orbit) = c` (**multiplicity 1**). To obtain the factor of 2 one must
re-declare the single orbit `{s, Ks}` as **two disjoint records** and sum
`I({s}) + I({Ks}) = 2c` — which is precisely an **occupancy / weighting /
within-sector rule**, every one of which A3 disclaims **verbatim** ("A record
supplies no ... weighting, normalization, ... within-sector data, or occupancy
rule"). Additivity-as-stated delivers `x1`; the `x2` requires the disclaimed
ingredient.

**Conclusion (D) — the native-Lorentzian temporal `Z2` cancels in the
magnitude.** The only constructions that realize a genuine real-time temporal
`Z2` entering a partition function are the **Schwinger–Keldysh** closed-time-path
(forward + backward branches) and the **thermofield double** (modular
conjugation `J`, which by Bisognano–Wichmann equals `U(R(pi)).Theta` — the PCT
operator, the real correspondence that makes this a tempting trap). But on the
magnitude they **cancel**: integrating out the two contour branches gives
`det(fwd) . det(bwd) = det . det^{-1}`, the celebrated Keldysh normalization
`Z = 1`. The thermofield generator is a *difference* `H (x) I - I (x) H~`, with
the thermal vacuum in its kernel and a *single-copy* partition trace. So the
real-time temporal `Z2` is exactly the `Z2` that **vanishes** from `|det|` — the
opposite of the Euclidean Matsubara product `prod_omega [...] = u_0^{8 L_t}`
(`hierarchy_matsubara_determinant_ratio`, unaudited context) that genuinely
multiplies the magnitude and produces the `16` at `L_t = 2`.

Each of (A), (B), (C), (D) independently precludes the K/CPT-orbit route to the
temporal factor of 2.

## Proof

**(A), (B).** Direct, finite. The corner set `{0,pi}^3` is closed under `k->-k`
and `k -> k+(pi,pi,pi)` (mod `2pi`); the runner (Section S) enumerates all 8
corners and verifies `P`, `C` map the set onto itself bijectively (count 8
preserved), while the product set `{0,pi}^3 x {0,pi}` has 16 elements (count
doubled). Antilinearity of `Theta_H = P.K` and linearity of `S` are verified
explicitly (Section L): `Theta_H(i v) = -i Theta_H(v)` and `S(i v) = i S(v)`,
with `Theta_H^2 = P.conj(P.conj(.)) = P^2 = I` (P real orthogonal). An antilinear
involution is not a linear involution.

**(C).** The realized-outcome multiplicity is computed both ways (Section C): the
orbit-as-one-record gives `I = c` (`mult = 1`); the split-into-two-records gives
`I = 2c` (`mult = 2`); the two differ exactly by the factor 2, and the `x2`
requires the finer 2-record partition, i.e. the occupancy rule A3 disclaims. This
is the same count-vs-weight boundary the framework already records at
[`FLAVOR_RECORD_READOUT_FORM_NOT_WEIGHT_2026-06-02.md`](FLAVOR_RECORD_READOUT_FORM_NOT_WEIGHT_2026-06-02.md)
(open_gate): "counting distinguishable labels twice ... is a plausible
block-count principle, but it is an extra principle beyond additive scalar record
readout."

**(D).** The Keldysh cancellation is verified from first principles (Section K):
for 200 random `4x4` operators `D`, `|det(D) . det(D^{-1})| = 1` to machine
precision — robustly, independent of `D` (the physical content: the cancellation
is structural, not accidental). The thermofield generator `H (x) I - I (x) H` is
verified traceless with a zero mode (Section K). For contrast (Section E), the
Euclidean temporal product `|det|^{L_t}` is verified to scale the exponent with
`L_t` (so `L_t = 2` doubles it, generically changing the magnitude — unlike the
Keldysh `Z=1`), giving the exponent `8 x L_t = 16` at `L_t = 2`. The literature
statements (Keldysh `Z=1`: Kamenev; Bisognano–Wichmann `J = U(R(pi)).Theta`) are
**corroboration**; the load-bearing cancellation is the runner's own finite
computation. ∎
