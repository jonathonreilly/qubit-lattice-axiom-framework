## Claim

For the free staggered (Kogut-Susskind) operator `M = M_KS + m I`, `m > 0`,
with clean temporal hop (`eta_0 = 1`) on an even-`L_t` lattice, the zero-source
fermion determinant factorizes as

```text
det(M_KS + m I) = Z_vac * Tr(e^{-beta H_hat}),       beta = L_t a,
```

where `Z_vac > 0` is a real-positive normalization factor and `H_hat` is the
free two-step transfer Hamiltonian with `H_hat = H_hat^dag >= 0`. Therefore
on this finite free zero-source surface

```text
det(M_KS + m I) in R_{>0},        log|det(M_KS + m I)| = log det(M_KS + m I).
```

So the modulus is automatic **on this surface**. This is useful bounded
support for the P2 phase-positive side and for the determinant-to-trace bridge.
It does not remove the parent row's broader P2 condition by itself.

## Step 1: Free Determinant as Transfer Trace

The free theory factorizes over spatial momenta `p = 2 pi n / L_s`. For each
momentum, the temporal mode equation

```text
alpha_t psi_t + (1/2) psi_{t+1} - (1/2) psi_{t-1} = 0,
alpha_t = m + i (-1)^t sin p,
```

gives the single-step classical transfer matrix

```text
V_{t+1} = T_s(t) V_t,        T_s(t) = [[ -2 alpha_t, 1 ], [ 1, 0 ]].
```

The two-step matrix `T_odd(p) T_even(p)` has eigenvalues
`e^{+2E(p)}` and `e^{-2E(p)}`, with

```text
E(p) = arcsinh(sqrt(m^2 + sin^2 p)).
```

For antiperiodic temporal boundary conditions, the finite banded determinant
identity is

```text
det(M_p) = (1/2)^{L_t} det(I + T_full(p))
         = (1/2)^{L_t} (1 + e^{+L_t a E(p)})(1 + e^{-L_t a E(p)}).
```

The runner checks this directly against the finite matrix determinant for
`L_t in {4,6}`, `L_s in {2,3}`, and `m in {0.3, 0.5, 0.9, 1.5}`.

## Step 2: Positive Trace Factor

The reflection-positivity source row

On the free surface, the two-step transfer has

```text
T_hat^2 = exp(-2a H_hat),       H_hat = sum_p E(p) a_p^dag a_p >= 0.
```

Thus

```text
Tr(e^{-beta H_hat}) = product_p (1 + e^{-L_t a E(p)}) > 0,
Z_vac               = product_p (1/2)^{L_t}(1 + e^{+L_t a E(p)}) > 0,
det(M_KS + m I)     = Z_vac * Tr(e^{-beta H_hat}).
```

Both factors are positive real because every `E(p)` is real and
non-negative.
