## Setup

per site, on an `L_t × L_s` lattice with the canonical staggered phases
`η_0 = 1` (clean temporal hop) and `η_1(t) = (−1)^t` (staggered spatial
phase), antiperiodic temporal boundary condition (fermionic thermal BC):

```text
S = Σ_{t,x} χ̄(t,x) [ m χ(t,x)
      + (1/2)( χ(t+1,x) − χ(t−1,x) )                  (temporal hop)
      + (1/2) (−1)^t ( χ(t,x+1) − χ(t,x−1) ) ]        (spatial hop)
```

with `m > 0` real. The fermion amplitude is the finite Grassmann Gaussian

```text
Z = ∫ Dχ̄ Dχ  e^{−S}  =  det(M_KS + m I),                                (1)
```

the same `Z = det(D + J)` object the parent note uses, here with `J = 0` and
`D = M_KS + m I` the free staggered operator. `M_KS` is real anti-Hermitian
(`M_KS^† = −M_KS`); the staggered-only positivity row
[`STAGGERED_ONLY_DET_POSITIVITY_CASE_A_NOTE_2026-05-17.md`](STAGGERED_ONLY_DET_POSITIVITY_CASE_A_NOTE_2026-05-17.md)

## Step 1 — det = transfer-matrix trace (derived for the free staggered case)

The free theory factorizes across spatial momentum `p = 2π n / L_s`. Per `p`,
the temporal-mode operator `M_p` is the tri-diagonal (antiperiodic) banded
matrix

```text
(M_p)_{tt}      = m + i η_1(t) sin p = m + i (−1)^t sin p,
(M_p)_{t,t+1}   = +1/2  (× (−1) across the antiperiodic temporal seam),
(M_p)_{t,t−1}   = −1/2  (× (−1) across the seam),
```

and the full determinant is the product over `p`:

```text
det(M_KS + m I) = ∏_p det(M_p).                                          (2)
```

The banded mode equation `α_t ψ_t + (1/2) ψ_{t+1} − (1/2) ψ_{t−1} = 0`,
`α_t = m + i (−1)^t sin p`, rearranges to the **classical single-step
transfer matrix** on the amplitude 2-vector `V_t = (ψ_t, ψ_{t−1})`:

```text
V_{t+1} = T_s(t) V_t,    T_s(t) = [[ −2 α_t, 1 ], [ 1, 0 ]].             (3)
```

Because `η_1` alternates, `T_s` alternates between `T_even` (`α = m + i sin p`)
and `T_odd` (`α = m − i sin p`); these come **straight from the action**, no
convention admitted. The **2-step** classical matrix
`T2cl(p) = T_odd(p) · T_even(p)` has eigenvalues `e^{±2 a E(p)}` with the
**exact free staggered 1+1d dispersion**

```text
E(p) = arcsinh √( m² + sin² p ) ≥ 0,   sinh² E(p) = m² + sin² p.        (4)
```

The runner verifies the action-derived 2-step decaying eigenvalue equals
`e^{−2 a E(p)}` to `< 5×10⁻¹⁶` over the Brillouin zone — the **faithfulness
anchor** that the construction reproduces the known staggered dispersion, not
an artifact.

For the antiperiodic free-fermion determinant, the standard one-period
identity is `det(M_p) = (1/2)^{L_t} det( I + T_full(p) )`, where `T_full(p)`
is the `L_t`-step product of single-step transfers, with eigenvalues
`e^{±L_t a E(p)}` and `det T_full = 1`, so
`det(I + T_full) = 1 + tr(T_full) + det(T_full) = 2 + 2 cosh(L_t a E)`. Hence
**per spatial momentum**

```text
det(M_p) = (1/2)^{L_t} ( 1 + e^{+L_t a E(p)} )( 1 + e^{−L_t a E(p)} ).   (5)
```

This is the transfer-matrix ↔ determinant identity the qubit-trace note's
Step 4 left open, now written out for the free staggered case. The runner
confirms (5) and (2) to machine precision (max residual `5×10⁻¹¹` across
`L_t ∈ {4,6}`, `L_s ∈ {2,3}`, `m ∈ {0.3, 0.5, 0.9, 1.5}`).

## Step 3 — The bridge conclusion (Z real-positive ⟹ P2 theorem)

Splitting the per-mode factor (5) into the physical Fock trace and the
zero-point factor:

```text
Tr(e^{−β Ĥ}) = ∏_p ( 1 + e^{−L_t a E(p)} ) > 0,      β = L_t a,         (7)
Z_vac        = ∏_p (1/2)^{L_t} ( 1 + e^{+L_t a E(p)} ) > 0,             (8)
```

so that, combining (2), (5), (6):

```text
det(M_KS + m I) = Z_vac · Tr[ (T̂²)^{L_t/2} ]
                = Z_vac · Tr[ e^{−L_t a Ĥ} ]
                = Z_vac · Tr( e^{−β Ĥ} )  =  Z_vac · Z_qubit.           (9)
```

Both factors in (9) are **manifestly real-positive**: every `E(p)` is real
(equation (4) is `arcsinh` of a non-negative real), `e^{x} > 0`, and
`(1/2)^{L_t} > 0`. The zero-point factor `Z_vac` is the standard
"vacuum-energy subtraction" the RP note performs via `T̂²/λ_max` — here made
explicit and shown positive rather than divided out. Therefore

```text
Z = det(M_KS + m I) ∈ ℝ_{>0}.                                          (10)
```

Because `Z` is a positive real, the modulus in the parent's generator is
automatic:

```text
W = log|det(M_KS + m I)| = log( det(M_KS + m I) ) = log Z_vac + log Z_qubit. (11)
```

There is **no phase** for the generator to be sensitive to. This is exactly
the qubit-trace note's Step 2 (P2 from trace positivity, `Z = Tr(e^{−(H+J)})`
real-positive for self-adjoint `H + J`) — now realized on the **determinant
surface** because `det(M_KS + m I)` *is* `Z_vac · Tr(e^{−β Ĥ})` with
self-adjoint `Ĥ ≥ 0`. P2 phase-blindness is a **theorem** here, supplying the
"retained theorem" the audit verdict said P2 lacked.

The runner confirms `|Im Z| = 0`, `Re Z > 0` (min `0.0159`), and
`log|det| = log Z` to residual `0` across all tested lattices and masses.
