## Claim

On the formal Dirac/derivative sign surface, define parity by

```text
P_D M P_D^{-1} = gamma^0 M gamma^0
```

on the 4x4 Dirac matrix, and define the abstract derivative sign character by

```text
partial_0 -> + partial_0,
partial_i -> - partial_i    for i in {1,2,3}.
```

For each operator in the four formal dimension-5 SME-style structures

```text
gamma^mu partial_nu partial_rho,
partial_mu partial_nu with unit Clifford,
gamma_5 gamma^mu partial_nu,
sigma^{mu nu} partial_rho,
```

the net formal parity weight is

```text
(-1)^N,
```

where `N` is the total count of spatial indices:

- each spatial `gamma^i` contributes `1`;
- `gamma_5` contributes `3`;
- `sigma^{mu nu}` contributes the number of spatial indices among `mu,nu`;
- each spatial derivative `partial_i` contributes `1`;
- time indices contribute `0`.

Therefore odd-`N` formal operators are P-odd and even-`N` formal operators
are P-even. The P-symmetric projection vanishes exactly in the odd-`N`
sector, and the P-antisymmetric projection vanishes exactly in the even-`N`
sector.

That formal sign identity is the entire binding theorem.

## Exact Formal Algebra

The formal Dirac parity table is

```text
gamma^0 -> + gamma^0,
gamma^i -> - gamma^i,
gamma_5 -> - gamma_5,
sigma^{ij} -> + sigma^{ij},
sigma^{0i} -> - sigma^{0i}.
```

Combining this table with the derivative sign character gives the total
weight `(-1)^N` for every enumerated index assignment in the four named
structures.

Examples:

```text
gamma^1 partial_2 partial_2: N = 1 + 1 + 1 = 3, P-weight = -1.
gamma^0 partial_1 partial_0: N = 0 + 1 + 0 = 1, P-weight = -1.
gamma_5 gamma^0 partial_1: N = 3 + 0 + 1 = 4, P-weight = +1.
sigma^{0i} partial_j: N = 1 + 1 = 2, P-weight = +1.
sigma^{12} partial_3: N = 2 + 1 = 3, P-weight = -1.
```

The runner exhaustively enumerates index assignments rather than using
representatives.
