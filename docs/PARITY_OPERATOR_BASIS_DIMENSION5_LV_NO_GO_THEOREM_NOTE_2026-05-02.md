## Setting

The repaired setting is formal. For the gamma-structure side of the SME-style
operator basis, use the standard 4-dimensional Dirac algebra in the chiral
(Weyl) basis with `P_Dirac = gamma^0` so that
`P_Dirac M P_Dirac^{-1}` implements the standard parity action on each Dirac
structure:

```text
    gamma^0       -> + gamma^0,        gamma^i      -> - gamma^i,
    gamma_5       -> - gamma_5,        sigma^{ij}  -> + sigma^{ij},
                                       sigma^{0i}  -> - sigma^{0i}.
```

Derivative factors are formal symbols with sign character
`partial_i -> -partial_i`, `partial_0 -> partial_0`. This note does not
identify those symbols with any actual lattice derivative representatives.
Any such identification is a separate bridge theorem and no load-bearing
dependency edge is claimed here.

## Theorem (per-operator algebraic P-weight identities on the SME-style basis, odd-spatial-parity sector)

**Theorem.** Let

```text
    O^{(5)}  :=  bar(psi)(x) Gamma psi(x)
```

be any local fermion-bilinear LV operator of mass dimension 5 built
as a formal single-flavor Dirac-algebra symbol with a constant SME-style
coefficient, where `Gamma` lies in the canonical SME-style dim-5 basis

```text
    Gamma  in  {  gamma^mu partial_nu partial_rho,
                  partial_mu partial_nu (with unit Clifford),
                  gamma_5 gamma^mu partial_nu,
                  sigma^{mu nu} partial_rho  },
```

with at least one unpaired spatial index in the dispersion-modifying
piece **and with odd total spatial-index parity** (counting spatial
gamma indices, gamma_5 as 3, sigma spatial indices, and spatial
derivative indices). Then:

(a) Every such `O^{(5)}` carries odd parity weight under
    the formal parity action, i.e.
    `P_form O^{(5)} P_form^{-1} = - O^{(5)}` on the formal symbol.

(b) Hence the parity-symmetric projection
    `(O^{(5)} + P O^{(5)} P^{-1}) / 2` vanishes for each candidate.

Operators in the same basis with *even* total spatial-index parity
(e.g. `gamma_5 gamma^0 partial_i`, `sigma^{0i} partial_j`) are P-even
under the formal parity action; the theorem does not assert P-odd weight
for them and the runner verifies the P-even outcome on those
exhaustively as a consistency cross-check, not as part of the claim.

This theorem is not a lattice-action coefficient no-go. It does not prove that
every physical dimension-5 LV deformation is absent from a lattice action; it
only proves the stated formal sign identity.

## Proof

**Step 1: formal parity action on derivatives and gamma structures.**

By formal convention, `partial_i -> -partial_i` and `partial_0` remains
unchanged. This is abstract sign bookkeeping only; the repaired row does not
construct or certify lattice derivative representatives.

On Dirac structures the parity action `P_Dirac = gamma^0` gives
the standard table

```text
    gamma^0  -> + gamma^0,       gamma^i  -> - gamma^i,
    gamma_5  -> - gamma_5,       sigma^{ij} -> + sigma^{ij},
                                 sigma^{0i} -> - sigma^{0i},
    gamma_5 gamma^0 -> - gamma_5 gamma^0,
    gamma_5 gamma^i -> + gamma_5 gamma^i.
```

**Step 2: counting parity weight of each candidate (odd-spatial-parity sector).**

Treat each candidate as a product of a Dirac-structure parity weight
and a derivative-side parity weight. The Dirac-structure weight is
`+1` if `P_Dirac M P_Dirac^{-1} = M` and `-1` if it returns `-M`.
The derivative-side weight is `(-1)^k` where `k` is the number of
unpaired spatial-index derivatives.

A direct factorization gives net P-weight `(-1)^N` with `N` the
**total spatial-index count** of the operator:

  N = (# spatial gamma^i factors)
    + (# gamma_5 factors) * 3
    + (# spatial indices in each sigma^{mu nu} factor)
    + (# spatial-index derivatives partial_i).

Equivalently, the net P-weight is the *parity* of `N`. The theorem
covers the odd-`N` sector only.

- (a) `gamma^mu partial_nu partial_rho`. Representative odd-`N`
  case: `gamma^1 partial_2 partial_2` has `N = 1 + 2 = 3`
  (odd), so net **P-weight = -1**. The variant
  `gamma^0 partial_i partial_0` has `N = 0 + 1 + 0 = 1` (odd),
  net **P-weight = -1**. The fully time-time piece
  `gamma^0 partial_0 partial_0` has `N = 0` (excluded by the
  dispersion-modifying premise).

- (b) `partial_mu partial_nu` with the unit Clifford structure.
  Representative odd-`N` case: `partial_1 partial_0` has
  `N = 1 + 0 = 1` (odd). Net **P-weight = -1**.

- (c) `gamma_5 gamma^mu partial_nu`. Representative odd-`N` case:
  `gamma_5 gamma^1 partial_2` has `N = 3 + 1 + 1 = 5` (odd),
  net **P-weight = -1**. Counter-example outside this theorem's
  sector: `gamma_5 gamma^0 partial_i` has
  `N = 3 + 0 + 1 = 4` (even), so net **P-weight = +1**; this
  even-`N` case is explicitly outside the narrowed claim and is
  verified P-even by the runner as a consistency cross-check.

- (d) `sigma^{mu nu} partial_rho`. Representative odd-`N` case:
  `sigma^{12} partial_3` has `N = 2 + 1 = 3` (odd), net
  **P-weight = -1**. Counter-example outside this theorem's sector:
  `sigma^{0i} partial_j` has `N = 1 + 1 = 2` (even), so net
  **P-weight = +1**; this even-`N` case is explicitly outside the
  narrowed claim.

In every odd-`N` case in the four covered structures the
dispersion-modifying LV piece is P-odd; the even-`N` operators are
P-even and outside the theorem's scope.

**Step 3: parity-symmetric projection.**

Define `Sym_P[O] := (O + P O P^{-1}) / 2` and
`Asym_P[O] := (O - P O P^{-1}) / 2`. By Step 2, for odd total
spatial-index parity `P O^{(5)} P^{-1} = - O^{(5)}` on the
dispersion-modifying piece, so `Sym_P[O^{(5)}] = 0` and
`Asym_P[O^{(5)}] = O^{(5)}`. For even total spatial-index parity
(outside the theorem's sector) the reverse holds:
`Asym_P[O^{(5)}] = 0` and `Sym_P[O^{(5)}] = O^{(5)}`. The runner
checks both identities directly on each Dirac-structure candidate
via exhaustive enumeration over allowed index assignments, applying
the full parity action `P_Dirac M P_Dirac^{-1}` combined with the
derivative-side sign character to each operator (no representative
shortcut, no hardcoded `P O = -O`).

## Scope (what this note proves and what it does NOT)

**Proves:**

- The per-operator algebraic P-weight identity in the **odd total
  spatial-index parity sector**: each allowed index assignment for
  the four named 4×4 Dirac-structure candidates in the canonical
  SME-style dim-5 basis (with at least one unpaired spatial index
  and odd total spatial-index parity) carries net formal P-weight `-1`
  under the formal parity action, so the parity-symmetric
  projection of the operator vanishes.
- A consistency cross-check on the *excluded* even-spatial-parity
  sector: those operators carry net P-weight `+1`, so the
  parity-antisymmetric projection vanishes. This is reported as a
  cross-check, not as part of the bounded theorem's claim.

**Does NOT prove:**

- A construction or certification of actual lattice derivative
  representatives for the four SME-style bilinears.
- A physical no-go theorem for action coefficients claiming that no
  dim-5 LV operator in this basis can be added to a lattice action. The
  per-operator P-weight identity above does not extend to such a physical
  coefficient statement within the scope of this note.
- A P-odd identity for even-spatial-parity operators
  (e.g. `gamma_5 gamma^0 partial_i`, `sigma^{0i} partial_j`). These
  operators are explicitly outside this theorem's odd-spatial-parity
  sector.
- Higher-dimension or multi-fermion LV operators are not addressed.
- Parity-violating extensions of the framework (e.g., a chiral
  electroweak embedding with explicit `P`-violating gauge couplings)
  are outside scope.
