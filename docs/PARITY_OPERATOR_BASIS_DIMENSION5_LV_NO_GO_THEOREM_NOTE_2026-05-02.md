## Setting

Throughout, the framework is the staggered `Cl(3)/Z^3` lattice of
[CPT_EXACT_NOTE](CPT_EXACT_NOTE.md): a finite even periodic torus
`Z^3 / L Z^3` with `L` even, single-component staggered fermions, and
the standard staggered phases

```text
    eta_1(x) = 1,                   eta_2(x) = (-1)^{x_1},
    eta_3(x) = (-1)^{x_1 + x_2}.
```

The cited discrete symmetries are:

- **Sublattice parity** `epsilon(x) = (-1)^{x_1 + x_2 + x_3}`, acting
  on single-component staggered fermions as a diagonal `+/- 1`
  involution. The free staggered hopping Hamiltonian satisfies the
  exact identity `epsilon H_0 epsilon = -H_0`.
- **Spatial inversion** `P_inv: x -> (-x) mod L` (well defined on the
  even periodic torus). This note does not use a lattice derivative
  representative for `P_inv partial_i P_inv^{-1}`.

For the formal SME-style templates below, derivative labels are
bookkeeping symbols with parity-sign convention
`chi(partial_0)=+1`, `chi(partial_i)=-1` for `i in {1,2,3}`. This
formal convention is not promoted here to an actual staggered-lattice
operator dictionary.

For the gamma-structure side of the SME-style template basis, we use
the standard 4-dimensional Dirac algebra in the chiral (Weyl) basis
with `P_Dirac = gamma^0` so that `P_Dirac M P_Dirac^{-1}` implements
the standard parity action on each Dirac structure:

```text
    gamma^0       -> + gamma^0,        gamma^i      -> - gamma^i,
    gamma_5       -> - gamma_5,        sigma^{ij}  -> + sigma^{ij},
                                       sigma^{0i}  -> - sigma^{0i}.
```

## Theorem (formal per-template P-sign identities, odd-spatial-parity sector)

**Theorem.** Let `T` be one of the formal templates

```text
    gamma^mu partial_nu partial_rho,
    partial_mu partial_nu (with unit Clifford),
    gamma_5 gamma^mu partial_nu,
    sigma^{mu nu} partial_rho,
```

with at least one spatial index and with odd total spatial-index
parity, counted by assigning `gamma^i` one spatial index, `gamma_5`
three, `sigma^{mu nu}` the number of spatial labels among `mu,nu`,
and each formal `partial_i` one. Under the 4x4 Dirac parity action
`P_Dirac = gamma^0` and the formal derivative-sign convention
`chi(partial_0)=+1`, `chi(partial_i)=-1`, the formal P-sign of `T`
is `-1`.

Equivalently, the formal P-symmetric projection of each odd-parity
template vanishes.

Templates in the same basis with *even* total spatial-index parity
(e.g. `gamma_5 gamma^0 partial_i`, `sigma^{0i} partial_j`) are formal
P-even; the theorem does not assert P-odd weight for them and the
runner verifies the P-even outcome on those exhaustively as a
consistency cross-check, not as part of the claim.

The free staggered hopping Hamiltonian `H_0` on the periodic
lattice `Z^3 / L Z^3` with `L` even satisfies the lattice identity
`epsilon H_0 epsilon = -H_0`. This is a separate lattice identity, not
a derivation of an SME derivative-operator dictionary.

## Proof

**Step 1: formal derivative signs and gamma structures.**

The derivative labels are formal signs, not lattice operators:
`chi(partial_0)=+1` and `chi(partial_i)=-1` for spatial labels. No
claim in this note depends on constructing an actual staggered
finite-difference representative for these symbols.

On Dirac structures the parity action `P_Dirac = gamma^0` gives
the standard table

```text
    gamma^0  -> + gamma^0,       gamma^i  -> - gamma^i,
    gamma_5  -> - gamma_5,       sigma^{ij} -> + sigma^{ij},
                                 sigma^{0i} -> - sigma^{0i},
    gamma_5 gamma^0 -> - gamma_5 gamma^0,
    gamma_5 gamma^i -> + gamma_5 gamma^i.
```

**Step 2: counting parity sign of each template (odd-spatial-parity sector).**

Treat each template as a product of a Dirac-structure parity weight
and a formal derivative-label sign. The Dirac-structure weight is
`+1` if `P_Dirac M P_Dirac^{-1} = M` and `-1` if it returns `-M`.
The formal derivative-sign factor is `(-1)^k` where `k` is the number
of spatial derivative labels.

A direct factorization gives net P-sign `(-1)^N` with `N` the
**total spatial-index count** of the template:

  N = (# spatial gamma^i factors)
    + (# gamma_5 factors) * 3
    + (# spatial indices in each sigma^{mu nu} factor)
    + (# spatial-index derivatives partial_i).

Equivalently, the net P-sign is the *parity* of `N`. The theorem
covers the odd-`N` sector only.

- (a) `gamma^mu partial_nu partial_rho`. Representative odd-`N`
  case: `gamma^1 partial_2 partial_2` has `N = 1 + 2 = 3`
  (odd), so net **P-sign = -1**. The variant
  `gamma^0 partial_i partial_0` has `N = 0 + 1 + 0 = 1` (odd),
  net **P-sign = -1**. The fully time-time piece
  `gamma^0 partial_0 partial_0` has `N = 0` (excluded by the
  dispersion-modifying premise).

- (b) `partial_mu partial_nu` with the unit Clifford structure.
  Representative odd-`N` case: `partial_1 partial_0` has
  `N = 1 + 0 = 1` (odd). Net **P-sign = -1**.

- (c) `gamma_5 gamma^mu partial_nu`. Representative odd-`N` case:
  `gamma_5 gamma^1 partial_2` has `N = 3 + 1 + 1 = 5` (odd),
  net **P-sign = -1**. Counter-example outside this theorem's
  sector: `gamma_5 gamma^0 partial_i` has
  `N = 3 + 0 + 1 = 4` (even), so net **P-sign = +1**; this
  even-`N` case is explicitly outside the narrowed claim and is
  verified P-even by the runner as a consistency cross-check.

- (d) `sigma^{mu nu} partial_rho`. Representative odd-`N` case:
  `sigma^{12} partial_3` has `N = 2 + 1 = 3` (odd), net
  **P-sign = -1**. Counter-example outside this theorem's sector:
  `sigma^{0i} partial_j` has `N = 1 + 1 = 2` (even), so net
  **P-sign = +1**; this even-`N` case is explicitly outside the
  narrowed claim.

In every odd-`N` case in the four covered formal structures the
template is P-odd; the even-`N` templates are P-even and outside the
theorem's scope.

**Step 3: parity-symmetric projection.**

Define `Sym_P[T] := (T + P_formal(T)) / 2` and
`Asym_P[T] := (T - P_formal(T)) / 2`, where `P_formal` applies
`P_Dirac M P_Dirac^{-1}` to the 4x4 matrix factor and the formal
`chi(partial_mu)` sign to derivative labels. By Step 2, for odd total
spatial-index parity `P_formal(T) = -T`, so `Sym_P[T] = 0` and
`Asym_P[T] = T`. For even total spatial-index parity (outside the
theorem's sector) the reverse holds: `Asym_P[T] = 0` and
`Sym_P[T] = T`. The runner checks both identities by exhaustive
enumeration over allowed index assignments, applying the formal parity
action rather than a representative shortcut or a hardcoded
`P_formal(T) = -T`.

## Scope (what this note proves and what it does NOT)

**Proves:**

- The lattice identity `epsilon H_0 epsilon = -H_0` on the free
  staggered hopping Hamiltonian on the periodic even-`L` torus.
- The formal per-template algebraic P-sign identity in the **odd total
  spatial-index parity sector**: each allowed index assignment for the
  four named 4x4 Dirac-structure templates, combined with the formal
  derivative-label sign convention, has net P-sign `-1`, so the formal
  parity-symmetric projection vanishes.
- A consistency cross-check on the *excluded* even-spatial-parity
  sector: those templates carry net P-sign `+1`, so the
  parity-antisymmetric projection vanishes. This is reported as a
  cross-check, not as part of the bounded theorem's claim.

**Does NOT prove:**

- A lattice-action coefficient no-go corollary stating that no
  dim-5 LV template in this basis can be added to the staggered
  lattice action. The formal per-template P-sign identity above does not
  extend to such a lattice-action coefficient statement within the
  scope of this note.
- A retained bridge from the formal `partial_mu` labels to actual
  staggered-lattice derivative representatives, or a proof that the
  four templates are a complete lattice operator basis.
- A P-odd identity for even-spatial-parity templates
  (e.g. `gamma_5 gamma^0 partial_i`, `sigma^{0i} partial_j`). These
  templates are explicitly outside this theorem's odd-spatial-parity
  sector.
- Higher-dimension or multi-fermion LV templates are not addressed.
- Parity-violating extensions of the framework (e.g., a chiral
  electroweak embedding with explicit `P`-violating gauge couplings)
  are outside scope.
