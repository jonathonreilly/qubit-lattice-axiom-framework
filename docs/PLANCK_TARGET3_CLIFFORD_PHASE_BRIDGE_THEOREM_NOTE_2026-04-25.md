also supplies a linear coframe-response map

```text

```

```text

```


complex CAR modes.

## Exact Conditional Algebra

Choose an orthonormal coframe basis and write the four supplied response
operators as

```text
Gamma_t, Gamma_n, Gamma_1, Gamma_2.
```

The coframe premise says

```text
Gamma_a^2 = I,
Gamma_a Gamma_b + Gamma_b Gamma_a = 0    for a != b.
```

Equivalently,

```text
{Gamma_a, Gamma_b} = 2 delta_ab I.
```

The `16` Clifford words

```text
1, Gamma_a, Gamma_a Gamma_b, Gamma_a Gamma_b Gamma_c,
Gamma_t Gamma_n Gamma_1 Gamma_2
```

span `M_4(C)`, and the commutant is only the scalar algebra. Thus the
rank-four active block is the irreducible complex `Cl_4(C)` module.

Now pair the axes by an oriented face choice:

```text
c_N = (Gamma_t + i Gamma_n) / 2,
c_T = (Gamma_1 + i Gamma_2) / 2.
```

The Clifford relations imply

```text
{c_i, c_j} = 0,
{c_i, c_j^dagger} = delta_ij I.
```

So the same four-dimensional active block is the Fock space of two
complex CAR modes.

The bivector `Gamma_t Gamma_n` squares to `-I`. Therefore its spin lift
has the usual central phase behavior: a `2 pi` vector turn acts as `-I`
on the spinor module, and a `4 pi` turn returns to `I`. This is a finite
Clifford phase fact, not a laboratory-unit derivation.
