# Plaquette beta=6 Perturbative-Derivation Bounded Obstruction

**Date:** 2026-05-27
**Claim type:** no_go
**Claim scope:** the standalone numerical statement that on the
`Cl(3) / Z^3 graph-first SU(3)` Wilson gauge surface at `g_bare = 1,
beta = 6`, the average plaquette `<P>(beta=6)` is not reached inside
the bounded perturbative envelope tested here: the listed 16-term
Parma-NSPT-lineage coefficient packet for
`<P>(beta) = 1 - sum_{n>=1} w_n / beta^n`, finite truncations
`N <= 16`, Lepage-Mackenzie tadpole-improved fixed points
`N <= 8`, Pade `[m/n]` resummations with `m+n <= 12`, and

canonical MC value `<P>_MC = 0.5934`. This is a no-go for that finite
weak-coupling/tadpole/Pade route only; it does not rule out
strong-coupling, transfer-matrix, exact Wigner-Racah, Monte Carlo, or
other non-perturbative analytic routes.

## Statement (bounded obstruction)

Let `BETA = 6`, `N_c = 3`, `g_bare^2 = 2 N_c / BETA = 1`,
`alpha_bare = g_bare^2 / (4 pi) = 1/(4 pi)`. Let `<P>_MC = 0.5934` be
the canonical Monte Carlo Wilson-plaquette value at this point (used
**only** as a comparator, never as a derivation input). Let
`{w_n}_{n=1..16}` be the Parma-NSPT-lineage coefficient packet of
the Wilson-plaquette perturbative expansion
```text
<P>(beta) = 1 - sum_{n>=1} w_n / beta^n .                              (1)
```
For SU(3) pure gauge theory the leading coefficient is the textbook
1-loop result `w_1 = (N^2 - 1) / (2 N^2) = 4/9`; subsequent values are
those reported in the Parma NSPT lineage and reproduced by independent
groups (see "Coefficient references" below). These coefficients are
load-bearing for the bounded numerical no-go, but they are not framework
primitives, new axioms, retained-grade authorities, or empirical
selectors.

**Conclusion (T1; truncated series saturation).** The truncated series
in (1) at `beta = 6`, evaluated at every finite truncation order
`N in {1, 2, ..., 16}` using the literature coefficients listed in the
runner, saturates at
```text
<P>_PT(N=16; beta=6)  =  0.919331 ,                                    (2)
```
with the differences `|<P>_PT(N) - <P>_PT(N=16)|` already below `1e-4`
for `N >= 6`. The truncated PT series is numerically Cauchy-convergent
to the value `~0.9193` at `beta = 6` over the truncation range in which
the published coefficients exist; this saturation value is **distinct**
from the MC comparator by
```text
<P>_PT(N=16) - <P>_MC  =  0.919331 - 0.5934  =  +0.32593                (3)
```
i.e. a 54.9% relative residual.

**Conclusion (T2; tadpole-improvement saturation).** Adopting
Lepage-Mackenzie tadpole improvement, i.e. iterating the
self-consistent fixed point
```text
<P>_(k+1)  =  1 - sum_{n=1..N} w_n / (beta * <P>_k)^n                   (4)
```
to numerical convergence, every truncation `N in {1,...,8}` saturates at
```text
<P>_TI(N=8; beta=6)  =  0.910550 ,                                     (5)
```
with residual
```text
<P>_TI(N=8) - <P>_MC  =  0.910550 - 0.5934  =  +0.31715                 (6)
```
i.e. a 53.4% relative residual. Tadpole improvement reduces the
1-loop value by `< 1%` at `beta = 6` and does not change the
saturation regime.

**Conclusion (T3; Pade resummation saturation).** Pade `[m/n]`
approximants of the truncated series (1) at every `(m, n)` with
`m + n in {2, ..., 12}` evaluate at `beta = 6` to
```text
<P>_Pade[m/n](beta=6)  ~=  0.919331 ,                                  (7)
```
to better than `1e-5` for all `m + n >= 6` in the accepted runner
filter. Pade resummation does not extend the truncated-series
saturation regime inside this finite coefficient packet.

**Conclusion (T4; tadpole-improved Pade saturation).**
Self-consistent iteration of (4) using Pade `[m/n]` approximants in
place of the truncated polynomial in (4) reaches `<P>_TI-Pade = 0.910550`
to better than `1e-5` for all `(m, n)` tested with `m + n in
{3, ..., 8}`. No combination of finite-order PT truncation, tadpole
improvement, and Pade resummation tested in the runner brings
`<P>_analytic` within `5%` of the MC value.

**Conclusion (T5; finite-route residual and renormalon diagnostic).** The
pure-gauge one-loop beta-function coefficient is
`b_0 = 11 N_c / 3 = 11`. The IR renormalon associated with the
dimension-4 gluon-condensate operator is the standard lattice-PT
diagnostic for eventual factorial growth of `w_n` at large `n`, with an
expected optimal truncation scale
```text
n*  =  1 / (alpha_lat * b_0 / 4)  ~=  4.57                              (8)
```
at `alpha_lat = 1/(4 pi) ~ 0.0796`. Within the listed 16-term
coefficient packet, the numerical minimum of `|w_n / beta^n|` is much
smaller than the residual `(3)`. The runner therefore records a large
finite-route residual and a standard renormalon-scale diagnostic; it
does not prove that the residual is uniquely equal to a gluon-condensate
matrix element. The residual dwarfs the F2 2-loop scale (`0.0833%` from
PR #2030) by roughly three orders of magnitude.

**Final analytic estimate.** The best analytic estimate produced by
any of the combinations tested is
```text
<P>_analytic  =  0.910550        (tadpole-improved [3/2]-Pade, N=5)    (9)
```
with residual `+0.31715` (53.45%) versus MC.

**Honest verdict.** Inside the tested finite coefficient packet and
method grid, the Wilson plaquette `<P>` at `beta = 6` is not reached by
finite-order lattice perturbation theory, tadpole improvement, or Pade
resummation. The framework's existing classification of `<P>(beta=6)` as a
**computed input** (canonical lattice Monte Carlo evaluation; see
`PLAQUETTE_SELF_CONSISTENCY_NOTE.md` and `COMPLETE_PREDICTION_CHAIN_2026_04_15.md`
section 11.4) is not changed by this note. This obstruction note narrows
one weak-coupling analytic route; it does not close the full
non-perturbative derivation problem.
