The orbit quotient is laptop-sized as a diagnostic graph, and at `NMAX = 4`

runner does not find a graph-width reduction of the independent internal
link-label contraction from this class-sector diagonalization alone.

## Bounded Verdict

The honest cost finding is negative for the direct original-graph contraction
methods tested here:

- raw dense original-graph contraction is not laptop-feasible at
  `NMAX in {2,3,4}`;
- support-only sparse estimates are still far above the budget;
- the symmetry orbit quotient is small, but is not an exact contraction of the
  original independent-link environment;
- class-sector diagonalization reduces boundary readout bookkeeping, not the
  internal graph width by itself.

This is a costed bounded statement, not a global no-go. The named open targets
are:

- certified lower/upper width tightening beyond the MMW bracket;
- a rank-aware contractor using actual intertwiner gauges and recoupling
  structure rather than support-density estimates;
- an exact stabilizer-block construction on the original independent-link
  state space;
- a subsequent runner that computes `rho_(p,q)^{L_s=3,NMAX}` only after one of
  those exact original-graph routes has a feasible cost certificate.
