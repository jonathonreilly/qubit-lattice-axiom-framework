## Definitions

Fix finite `L >= 2` on the symmetric torus `Lambda_L = (Z/L)^4`, with derived-time axis `0` and spatial axes `1,2,3`. A plaquette is `p = (x, mu, nu)` with `mu < nu`. Define

```text
X_p(U) = (1/N_c) Re Tr U_p,       N_c = 3.
```

The spatial-spatial class is

```text
P_s = { (x, mu, nu) : mu,nu in {1,2,3}, mu < nu },
```

with `N_s = 3L^4`. The spatial-temporal class is

```text
P_t = { (x, 0, i) : i in {1,2,3} },
```

with `N_t = 3L^4`. The all-plaquette observable is

```text
P_all(U) = (1/(6L^4)) sum_p X_p(U).
```

The source-sector mark is one selected spatial plaquette `p0 in P_s` in one time slice. The source-sector note supplies the marked operator grammar; this note supplies the translation/class-average bridge from that mark to `P_all`.

## Theorem A: Within-Class Bridge

**Statement.** For every finite symmetric periodic accepted Wilson surface,

```text
E_beta[X_p0] = (1/N_s) sum_(p in P_s) E_beta[X_p].
```

Equivalently, the single marked spatial plaquette equals the spatial-class average in expectation.

**Proof.** The finite Wilson measure is

```text
dmu_beta(U) = Z_L(beta)^(-1)
              exp[-(beta/N_c) sum_p (N_c - Re Tr U_p)]
              prod_links dU_link.
```

Translations in all four periodic directions and spatial cubic permutations of axes `1,2,3` act as bijections of the link variables. Haar product measure is invariant under relabeling links and under orientation reversal `U -> U^dag`; the Wilson action is invariant because the plaquette sum is relabeled and `Re Tr U_p = Re Tr U_p^dag`.

For any two spatial plaquettes `p,q in P_s`, a periodic translation sends the base site of `p` to the base site of `q`, and a spatial-axis permutation sends the unordered spatial orientation of `p` to that of `q`. Therefore there is a measure-preserving Wilson-action automorphism `g` with `X_p(U) = X_q(gU)`. Change variables in the compact integral:

```text
E_beta[X_p] = int X_p(U) dmu_beta(U)
            = int X_q(U) dmu_beta(U)
            = E_beta[X_q].
```

Thus every spatial plaquette has one common expectation, call it `P_s(beta,L)`. Averaging over all `N_s` spatial plaquettes gives the same number, so a single marked spatial plaquette in one slice equals the spatial-class average. This is finite-`L`; no thermodynamic limit is used.

## Theorem B: Across-Class Bridge On The Accepted Surface

**Statement.** On the accepted symmetric periodic `L^4` Wilson surface with one common coefficient on all six plaquette orientations,

```text
P_s(beta,L) = P_t(beta,L),
```

so the spatial-class and temporal-class expectations are equal. Hence

```text
E_beta[X_p0] = E_beta[P_all].
```

**Proof.** The subtlety is that `3 spatial + 1 derived time` does not by itself grant full continuum `SO(4)` or even a time-space exchange symmetry for every framework object. The proof here uses only the accepted pure Wilson measure surface quoted above:

1. the finite lattice is symmetric `L^4` and periodic in all four directions;
2. the Wilson action has one common `beta/N_c` coefficient on every plaquette orientation;
3. the Haar product is the same compact Haar measure on every oriented link.

Under those three accepted-surface facts, a coordinate-axis permutation that swaps derived time `0` with a spatial axis is a bijection of the link-variable product space. It maps spatial plaquettes to temporal plaquettes and temporal plaquettes to spatial plaquettes, preserves the Haar product, and preserves the Wilson action because the action is one common sum over all plaquettes. Therefore the same change-of-variables argument gives equal expectations for a spatial and a temporal plaquette.

With `N_s = N_t = 3L^4`,

```text
E_beta[P_all]
  = (N_s P_s(beta,L) + N_t P_t(beta,L)) / (N_s + N_t)
  = P_s(beta,L)
  = E_beta[X_p0].
```

This is not a claim that every derived-time construction in the repo has full 4D hypercubic symmetry. It is the narrower statement that the accepted pure Wilson plaquette measure used for `<P>_L(beta)` is invariant under the finite axis permutation because the accepted surface has equal extents, periodic boundary conditions, equal link Haar factors, and one common Wilson coefficient.

Taking the thermodynamic limit preserves the identification at every differentiability point covered by the plaquette-value program note:

```text
lim_L E_beta[X_p0] = lim_L E_beta[P_all] = 1 + f'(beta).
```

At `beta = 6`, this is the bridge to `<P>* := 1 + f'(6)` when the derivative exists. If the derivative is not supplied, the same bridge targets the one-sided bracket `[1 + f'(6-), 1 + f'(6+)]`.

## Counterfactual Split If The Accepted-Surface Premise Is Dropped

If a future note works on an anisotropic surface, a non-symmetric `L_s^3 x L_t` finite volume, or a surface that marks a temporal class with a different coefficient, the across-class proof above does not apply. The honest replacement is the split

```text
<P>_all = (N_s <P_s> + N_t <P_t>) / (N_s + N_t).
```

On the symmetric count surface this is

```text
<P>_all = (1/2)(<P_s> + <P_t>).
```

The named object for that non-accepted-surface situation is

```text

```

It could be measured in-repo by adding a temporal-marked source-sector construction parallel to the existing spatial marked-plaquette source-sector construction, then comparing its finite-`L` source readout against the spatial-marked readout. On the accepted common-coefficient symmetric Wilson surface of this note, `Delta_ST(beta,L) = 0` follows by the axis-permutation symmetry above.
