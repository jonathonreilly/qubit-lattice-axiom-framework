## Statement

Let `J(beta)` be the V=1 SU(3) Wilson-character integral as above, and
let `a_n` denote its exact rational Taylor coefficients computed
through the Bars 1980 Bessel-determinant identity `(Bars)`. Fix the
ansatz orders `r = 2`, `d = 12` and define the matching matrix

```text
M_{N, (k,m)}  =  [beta^N] of  beta^m * J^{(k)}(beta)
              =  prod_{ell=0}^{k-1} (N - m + k - ell) * a_{N - m + k}     (Mat)
```

for index pairs `(k, m) in {0, ..., r} x {0, ..., d}` (columns,
`num_unknowns = (r + 1) * (d + 1) = 39`) and row index
`N in {0, 1, ..., num_eqs - 1}`, with `a_n = 0` for `n < 0`.

**(T1) Full column rank at (r=2, d=12) at ORDER=48.** With
`a_0, ..., a_48` the exact rational Taylor coefficients of `J(beta)`
computed via `(Bars)` to truncation order 48, and with the equation
cap `num_eqs = 44` (= `min(num_unknowns + 8, ORDER - r - 2)` at
`ORDER = 48`), the matching matrix `M` of size `44 x 39` has exact
rank

```text
rank(M)  =  39  =  num_unknowns.                                      (T1)
```

Equivalently, `ker(M) = {0}`: the only polynomial-coefficient
differential operator

```text
L_2  =  sum_{k=0}^{2} sum_{m=0}^{12} p_{k,m} * beta^m * d^k / d beta^k
```

with `p_{k,m} in Q` that annihilates the truncated Taylor series of
`J(beta)` to degree 48 is the trivial operator
`L_2 = 0` (i.e. `p_{k,m} = 0` for all `(k, m)`).

**(T2) Stability under depth.** Repeating the same construction at
`ORDER = 52` (cap `num_eqs = min(47, 48) = 47 > 39`), with the
re-computed Taylor coefficients `a_0, ..., a_52`, the matching matrix
of size `47 x 39` again has

```text
rank(M_{52})  =  39  =  num_unknowns,                                  (T2)
```

so the conclusion is invariant under further increase of the
truncation depth in the narrow window inspected by this theorem.

**(T3) Companion cells (r=2, d=10) and (r=2, d=11) re-confirmed.**
At `ORDER = 48`, the rank checks at the two neighbouring cells

```text
(r, d) = (2, 10):   num_unknowns = 33,   num_eqs = 41,   rank = 33,    (T3a)
(r, d) = (2, 11):   num_unknowns = 36,   num_eqs = 44,   rank = 36,    (T3b)
```

both return `rank = num_unknowns`, so the (r=2, d=10) and
(r=2, d=11) cells (which the parent runner DID evaluate at `ORDER = 40`
with no slack, exactly `36 = 36` equations vs `36` unknowns at
`d = 11`) carry through with positive slack `>= 5` at the bumped depth.

## Proof

Items `(T1)`, `(T2)`, `(T3)` are direct exact-rational computations.
The Bessel-determinant series in `(Bars)` is a polynomial in nine
holonomic modified-Bessel functions and converges absolutely on every
fixed `|beta| < infinity`. At any given Taylor truncation order `N`,
the coefficients `a_0, ..., a_N` are computable as a finite sum over
`k` of `3 x 3` determinants of modified-Bessel Taylor coefficients,
each itself a finite rational sum (the `I_n(beta / 3)` series has
strictly positive-power-of-beta entries decreasing as
`6^{-(n + 2m)} / (m! (n + m)!)`, with only finitely many entries below
the truncation degree).

The runner builds `a_0, ..., a_48` exactly as rationals via the
explicit pure-Python `Fraction`-polynomial implementation in the
parent companion runner (`I_series_dict`, `poly_add`, `poly_mul`,
`det3x3_dict`, `build_J_series`), reproduced verbatim in the audit
companion runner attached to this note. The matching matrix entries
`(Mat)` are then exact rationals, and Gaussian elimination over
`Fraction` returns the exact rank. By the runner certificate
`[R12]`, the rank equals `num_unknowns = 39`. This proves `(T1)`.

`(T2)` is the same construction at `ORDER = 52`. `(T3)` is the same
construction at `(r=2, d=10)` and `(r=2, d=11)`. All four checks pass
in the audit companion runner with exit code 0 and `PASS = 15,
FAIL = 0`.
