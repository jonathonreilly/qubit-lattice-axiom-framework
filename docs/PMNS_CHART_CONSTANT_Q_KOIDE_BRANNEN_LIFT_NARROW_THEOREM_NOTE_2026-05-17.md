## Statement

parameters), and define
```text
x_k  :=  v_0 (1 + sqrt(2) cos(delta + 2 pi k / 3)),   k = 0, 1, 2.        (1)
```
Define the Brannen `Q` ratio
```text
Q  :=  (Σ_k x_k^2) / (Σ_k x_k)^2.                                         (2)
```

Let the PMNS affine Hermitian chart constants be
```text
Q_Koide  :=  2/3,                                                          (3)
SELECTOR :=  sqrt(6) / 3,                                                  (4)
E2       :=  sqrt(8) / 3.                                                  (5)
```
These are the chart constants entering the parent
`pmns_selector_three_identity_support_note_2026-04-21`.

**Conclusion (T1) (Brannen-lift of `Q_Koide`).** By the retained narrow
theorem

`Q = 2/3` symbolically in `(v_0, delta)`. Therefore the PMNS chart
constant numeric `Q_Koide = 2/3` equals the Brannen `Q` value:
```text
Q_Koide  =  Q  =  2/3.                                                     (6)
```

**Conclusion (T2) (chart-side scalar identity).** The PMNS chart-side
scalar identity `SELECTOR^2 = Q_Koide` is exact under (3) and (4):
```text
SELECTOR^2  =  (sqrt(6) / 3)^2  =  6 / 9  =  2/3  =  Q_Koide.              (7)
```

**Conclusion (T3) (chart-side dimensional identity).** The PMNS
chart-side identity `2 SELECTOR / sqrt(3) = E2` is exact under (4) and
(5):
```text
2 SELECTOR / sqrt(3)  =  2 (sqrt(6) / 3) / sqrt(3)
                      =  2 sqrt(6) / (3 sqrt(3))
                      =  2 sqrt(2) / 3
                      =  sqrt(8) / 3

```

**Conclusion (T4) (composed lift identity).** Composing (6) with (7):
```text
SELECTOR^2  =  Q  =  (Σ_k x_k^2) / (Σ_k x_k)^2  =  2/3.                    (9)
```
The PMNS chart-side scalar identity `SELECTOR^2 = Q_Koide` is now
algebraically traceable to the retained Brannen narrow theorem rather
than to an imported numeric constant.

## Proof

`(T1)`. By the retained narrow theorem (see
[`KOIDE_CIRCULANT_Q_TWO_THIRDS_ALGEBRAIC_NARROW_THEOREM_NOTE_2026-05-10.md`](./KOIDE_CIRCULANT_Q_TWO_THIRDS_ALGEBRAIC_NARROW_THEOREM_NOTE_2026-05-10.md)

```text
Σ_k x_k     =  3 v_0,                                                     (10)
Σ_k x_k^2   =  6 v_0^2,                                                   (11)
```
so `Q = 6 v_0^2 / (3 v_0)^2 = 6 / 9 = 2/3` symbolically in `(v_0,
delta)`. Substituting numerically, `Q = 2/3 = Q_Koide`.

`(T2)`. Direct computation: `(sqrt(6) / 3)^2 = 6 / 9 = 2/3`.

`(T3)`. Direct computation:
```text
2 (sqrt(6) / 3) / sqrt(3)  =  (2 sqrt(6)) / (3 sqrt(3))
                           =  2 sqrt(6 / 3) / 3
                           =  2 sqrt(2) / 3
                           =  sqrt(4 · 2) / 3
                           =  sqrt(8) / 3
                           =  E2.
```

`(T4)`. Combining `(T1)` and `(T2)`:
```text
SELECTOR^2  =  2/3  =  Q  =  (Σ_k x_k^2) / (Σ_k x_k)^2.
```
The chain `SELECTOR^2 = Q_Koide = Q` is closed by substitution. ∎
