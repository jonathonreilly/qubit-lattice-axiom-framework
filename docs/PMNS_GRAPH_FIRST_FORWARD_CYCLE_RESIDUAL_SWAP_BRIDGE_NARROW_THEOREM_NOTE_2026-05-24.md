## 4. Proof

### 4.1 (B1) Forward-cycle operator from `S_3` restriction

By the retained axis-to-active-lane bridge authority, for every
`sigma in S_3` the tensor-factor permutation unitary
`T_sigma : C^8 -> C^8` restricts to `V_1` as the standard 3x3
permutation matrix `P_sigma` in the ordered basis `(X_1, X_2, X_3)`,
where `P_sigma e_j = e_{sigma(j)}`.

Take `sigma = (1 3 2)` (the 3-cycle `1 -> 3 -> 2 -> 1`). Then
`P_{(1 3 2)} e_1 = e_3`, `P_{(1 3 2)} e_2 = e_1`,
`P_{(1 3 2)} e_3 = e_2`, so

```text
P_{(1 3 2)}  =  [P_{(1 3 2)} e_1 | P_{(1 3 2)} e_2 | P_{(1 3 2)} e_3]
             =  [e_3 | e_1 | e_2]
             =  [[0, 1, 0], [0, 0, 1], [1, 0, 0]]
             =:  CYCLE.
```

This is `T_{(1 3 2)}|_{V_1}` by the bridge authority. The 3-cycle
algebra `CYCLE^3 = I`, `CYCLE^{-1} = CYCLE^2 = CYCLE^T` follows from
`(1 3 2)^3 = id` and `(1 3 2)^{-1} = (1 2 3)`, combined with the
permutation-rep homomorphism. (Direct matrix verification confirmed by
the companion runner.) ∎

### 4.2 (B2) Cycle-channel basis from diagonal-projector forward transport

**Lemma (matrix-unit / permutation product).** For any permutation
`sigma in S_3` with permutation matrix `P_sigma` and any `i in {1,2,3}`,

```text
E_{ii} . P_sigma  =  E_{i, sigma^{-1}(i)}.
```

**Proof of lemma.** Compute entrywise: `(E_{ii} P_sigma)_{p,q}
= sum_r (E_{ii})_{p,r} (P_sigma)_{r,q} = delta_{p,i} (P_sigma)_{i,q}
= delta_{p,i} delta_{i, sigma(q)} = delta_{p,i} delta_{q, sigma^{-1}(i)}
= (E_{i, sigma^{-1}(i)})_{p,q}`. ∎

Specialize to `sigma = (1 3 2)`, `sigma^{-1} = (1 2 3)`:
`sigma^{-1}(1) = 2, sigma^{-1}(2) = 3, sigma^{-1}(3) = 1`, giving the
forward-orientation cycle:

```text
E_11 . CYCLE  =  E_{1, 2}  =  E_12,
E_22 . CYCLE  =  E_{2, 3}  =  E_23,
E_33 . CYCLE  =  E_{3, 1}  =  E_31.
```

This is precisely the primary-runner identity
`E_ii . CYCLE = E_{i, sigma^{-1}(i)}`, now derived from the lemma and
the choice of forward 3-cycle in (B1). ∎

### 4.3 (B3) Cycle exchange under residual swap

The conjugacy class of 3-cycles in `S_3` consists of exactly the two
mutually inverse elements `(1 2 3), (1 3 2)`, and any transposition
`tau` conjugates them: `tau . (1 2 3) . tau = (1 3 2)`. In particular
for `tau = (2 3)`,

```text
(2 3) . (1 3 2) . (2 3)  =  (1 2 3)  =  (1 3 2)^{-1}.
```

Applying the permutation-rep homomorphism:

```text
P_23 . CYCLE . P_23  =  P_{(2 3)(1 3 2)(2 3)}  =  P_{(1 2 3)}  =  CYCLE^{-1}  =  CYCLE^T.
```

(Direct matrix verification confirmed by the companion runner.) ∎

### 4.4 (B4) Residual swap action on `M_3(C)` — unitary presentation

**Lemma (matrix-unit / permutation conjugation).** For any
`sigma in S_3` and any `i, j in {1,2,3}`,

```text
P_sigma . E_{ij} . P_sigma^{-1}  =  E_{sigma(i), sigma(j)}.
```

**Proof of lemma.** Compute entrywise:
`(P_sigma E_{ij} P_sigma^{-1})_{p,q}
 = sum_{r,s} (P_sigma)_{p,r} (E_{ij})_{r,s} (P_sigma^{-1})_{s,q}
 = (P_sigma)_{p,i} (P_sigma^{-1})_{j,q}
 = delta_{p, sigma(i)} delta_{q, sigma(j)}
 = (E_{sigma(i), sigma(j)})_{p,q}`. ∎

For `sigma = (2 3)` we have `P_sigma^{-1} = P_sigma = P_23`, so

```text
P_23 . E_{ij} . P_23  =  E_{(2 3)(i), (2 3)(j)}.
```

Specialized to the forward-cycle basis:

```text
P_23 . E_12 . P_23   =  E_{1, 3}  =  E_13,
P_23 . E_23 . P_23   =  E_{3, 2}  =  E_32,
P_23 . E_31 . P_23   =  E_{2, 1}  =  E_21.
```

These are the reverse-cycle basis elements, NOT the forward-cycle
basis: the unitary residual swap exchanges the forward and reverse
cycle channels pointwise. ∎

### 4.5 (B5) Residual swap action on the forward-cycle channel — antiunitary

Define the conjugate-linear involution
`R[A] := P_23 . A^dagger . P_23` on `M_3(C)`. Using
`E_{ij}^dagger = E_{ji}` and (B4):

```text
R[E_12]  =  P_23 . E_21 . P_23  =  E_{(2 3)(2), (2 3)(1)}  =  E_31,
R[E_23]  =  P_23 . E_32 . P_23  =  E_{(2 3)(3), (2 3)(2)}  =  E_23,
R[E_31]  =  P_23 . E_13 . P_23  =  E_{(2 3)(1), (2 3)(3)}  =  E_12.
```

So `R` carries `(E_12, E_23, E_31) -> (E_31, E_23, E_12)`. On
`A_fwd = c_1 E_12 + c_2 E_23 + c_3 E_31`, conjugate-linearity of `R`
in the coefficients (since `R[c E] = conj(c) R[E]`) gives

```text
R[A_fwd]  =  conj(c_1) E_31 + conj(c_2) E_23 + conj(c_3) E_12
          =  conj(c_3) E_12 + conj(c_2) E_23 + conj(c_1) E_31.
```

So `R` is the explicit coefficient involution
`(c_1, c_2, c_3) -> (conj(c_3), conj(c_2), conj(c_1))` on the
forward-cycle channel. ∎

### 4.6 (B6) Channel-preservation closure

By (B5), `R[A_fwd]` is a linear combination of exactly
`E_12, E_23, E_31` with the explicit coefficients above. There is no
component along any other matrix unit. So
`R : forward-cycle channel -> forward-cycle channel` is well-defined
and surjective (and bijective, by (B7) below). ∎

### 4.7 (B7) Involution and `S_3` generation

`R o R = id`: applying the coefficient map twice yields
`(c_1, c_2, c_3) -> (conj(c_3), conj(c_2), conj(c_1))
-> (conj(conj(c_1)), conj(conj(c_2)), conj(conj(c_3)))
= (c_1, c_2, c_3)`.

`<CYCLE, P_23> = S_3` in the standard permutation rep: the dihedral
relation (B3) gives `P_23 CYCLE P_23 = CYCLE^{-1}`, and
`(CYCLE, P_23)` are an order-3 and an order-2 element with the
dihedral relation, so they generate a copy of `D_3 = S_3`. Enumerating
the 6 elements:

```text
{I, CYCLE, CYCLE^2, P_23, CYCLE . P_23, CYCLE^2 . P_23}
=  {P_id, P_{(1 3 2)}, P_{(1 2 3)}, P_{(2 3)}, P_{(1 2)}, P_{(1 3)}}.
```

These exhaust `S_3` in its standard 3x3 permutation rep. ∎

### 4.8 (B8) Generic non-fixedness

The fixed-point equation `R[A_fwd] = A_fwd` reads
`(conj(c_3), conj(c_2), conj(c_1)) = (c_1, c_2, c_3)`, i.e.
`c_1 = conj(c_3)` (which is equivalent to `c_3 = conj(c_1)`) and
`c_2 = conj(c_2)` (i.e. `c_2` real). This is a 3-real-parameter family
in `C^3 ~= R^6`, of Lebesgue measure zero. Hence a generic
`(c_1, c_2, c_3) in C^3` is not fixed by R-anti. ∎
