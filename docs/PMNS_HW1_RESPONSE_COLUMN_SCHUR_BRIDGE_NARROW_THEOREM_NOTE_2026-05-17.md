# PMNS HW=1 Response-Column / Schur-Complement Bridge Narrow Theorem

**Date:** 2026-05-17
**Type:** positive_theorem
**Claim scope:** the standalone linear-algebra equivalence that, given a
supplied sector-operator fixture `M` carrying a retained 3 x 3 active or
passive block and given the supplied hw=1 source-response columns
constructed from that block at probe weight `lam`, two structurally
disjoint reconstruction lanes recover the same effective block:

- **Lane A (response-column inversion).** Form the response-column
  matrix `K := [c_1 | c_2 | c_3]` and recover the block via
  `delta_A := (I - K^{-1}) / lam` (passive convention) or
  `delta_A := I + (I - K^{-1}) / lam` (active convention,
  `subtract_identity=True`).
- **Lane B (direct Schur complement).** Partition the sector operator
  `M = [[A, B], [C, F]]` on the retained 3 x 3 support and form
  `delta_B := A - B F^{-1} C`.

**Claim.** `delta_A = delta_B` exactly as identities in the rational
function field over the matrix entries of `M`, in both the passive and
the active convention.

This is purely a statement about elementary matrix algebra given the
supplied source/transfer pack. The narrow theorem isolates the

## 0. Honest scoping

This note packages a single algebraic statement: the column-inversion
construction and the Schur-complement construction, when applied to
**the same sector-operator fixture** with **the same probe weight**,
produce the same effective 3 x 3 block. The two helper paths are the
code primitives actually invoked by the parent runner's Part 4 cross-check:

- column-inversion helper: `derive_active_block_from_response_columns`,

  (same file).

The narrow theorem is `positive_theorem`, not `bounded_theorem`,

## 1. Theorem (column-inversion / Schur-complement equivalence)

**Setup.** Let `d, s` be positive integers (in the parent's application
`d = 3` is the retained support dimension and `s` is the spectator
dimension; the equivalence below holds for any `d, s`). Let
`M ∈ Mat_{d+s}(F)` (over a field `F` of characteristic zero, e.g. `R`
or `C`) be a sector-operator block-partitioned as

```text
       [ A   B ]
M  =   [       ]                                                       (M)
       [ C   F ]
```

with `A ∈ Mat_{d}(F)`, `B ∈ Mat_{d,s}(F)`, `C ∈ Mat_{s,d}(F)`,
`F ∈ Mat_{s}(F)`. Assume `F` is invertible. Let `lam ∈ F` be a probe
weight (positive real in the parent's runner). Define the Schur
complement

```text
delta_S  :=  A - B F^{-1} C                                            (S)
```

so `delta_S ∈ Mat_d(F)` is the effective block of `M` on the retained
support. The Schur-complement primitive `effective_block_from_sector_operator`
returns exactly `delta_S` (and returns `M` itself if `s = 0`).

**Passive convention (no identity shift).** Assume `(I_d - lam · delta_S)`
is invertible (this is a generic non-degeneracy condition; on the parent's
fixtures it holds because `lam = 0.27` is small and `delta_S` is the
finite passive block). Build response columns

```text
K_pass  :=  (I_d - lam · delta_S)^{-1}                                 (K-pass)
c_i^pass  :=  K_pass · e_i,    i = 1, ..., d                           (col-pass)
```

where `e_i` is the i-th standard basis vector of `F^d`. The column-inversion
recovery formula is

```text
delta_A^pass  :=  (I_d - K_pass^{-1}) / lam.                           (R-pass)
```

**Active convention (with identity shift).** Define `delta := delta_S - I_d`
and assume `(I_d - lam · delta)` is invertible. Build response columns

```text
K_act  :=  (I_d - lam · delta)^{-1}  =  (I_d - lam · (delta_S - I_d))^{-1}
                                     =  ((1 + lam) I_d - lam · delta_S)^{-1}
                                                                       (K-act)
c_i^act  :=  K_act · e_i.                                              (col-act)
```

The column-inversion recovery formula (active) is

```text
delta_A^act  :=  I_d + (I_d - K_act^{-1}) / lam.                       (R-act)
```

**Claim (PASSIVE).** `delta_A^pass = delta_S` exactly as an identity in
the rational function field `F(M_{ij}, lam)`.

**Claim (ACTIVE).** `delta_A^act = delta_S` exactly as an identity in
the rational function field `F(M_{ij}, lam)`.

## 2. Proof

The two conventions reduce to the same one-line algebraic identity
applied to two different "block" arguments. We prove the passive case
first and then the active case as a substitution.

### 2.1 Passive case

Set `delta := delta_S` for the passive case. By construction (K-pass),

```text
K_pass = (I_d - lam · delta)^{-1}.                                     (i)
```

Take the matrix inverse of both sides (well-defined under the genericity
hypothesis):

```text
K_pass^{-1} = I_d - lam · delta.                                       (ii)
```

Subtract from `I_d` and divide by `lam` (nonzero):

```text
(I_d - K_pass^{-1}) / lam  =  (I_d - (I_d - lam · delta)) / lam
                           =  (lam · delta) / lam
                           =  delta
                           =  delta_S.                                 (iii)
```

So `delta_A^pass = delta_S`. ∎

### 2.2 Active case

Set `delta := delta_S - I_d` for the active case. By construction (K-act),

```text
K_act = (I_d - lam · delta)^{-1}.                                      (iv)
```

The same one-line identity (i)-(iii) applied with the active `delta`
gives

```text
(I_d - K_act^{-1}) / lam  =  delta  =  delta_S - I_d.                  (v)
```

Add `I_d` to both sides:

```text
I_d + (I_d - K_act^{-1}) / lam  =  delta_S.                            (vi)
```

So `delta_A^act = delta_S`. ∎

### 2.3 Why this is a "bridge"

In the parent's Part 4 cross-check, Lane A composes two operations:

- `effective_block_from_sector_operator(M) -> delta_S` followed by
  `response_columns_from_block(delta_S, lam, ...) -> K`,
- then `derive_*_block_from_response_columns(columns, lam) -> delta'`.

Lane B applies `effective_block_from_sector_operator(M) -> delta_S`
directly without the column-build / column-invert detour.

Theorem 1 says: the column-build step `delta -> K` is invertible by
the column-invert step `K -> delta`, so Lane A's two-step round-trip
collapses to the identity on the `delta_S` produced by the shared
first step. Therefore Lane A and Lane B end with the same block. The
Schur-complement primitive is shared between the two lanes by
construction (both lanes use `effective_block_from_sector_operator` to
reduce `M` to its 3 x 3 effective block on the retained support — the
distinction is only in whether Lane A then takes a column-build /
column-invert detour or not). The bridge identity says that detour is
literally the algebraic identity `(I - lam · delta) -> (I - lam · delta)`,
not a new derivation.

This is a pure linear-algebra equivalence; nothing about Cl(3), Z^3,
the source/transfer-pack derivation, the tau classifier, the q
classifier, the Hermitian eigen-closure, branch/sheet labels, or the
PMNS magnitudes enters.

## 3. Derivable corollaries

The passive identity (R-pass) and the active identity (R-act) imply
the following immediate consequences (all in the same rational function
field, all proven by substitution):

- **Round-trip identity (passive).**
  `derive_passive_block_from_response_columns(response_columns_from_block(delta, lam, subtract_identity=False), lam) = (K_pass, delta)` for any `delta`
  with `(I_d - lam · delta)` invertible.
- **Round-trip identity (active).**
  `derive_active_block_from_response_columns(response_columns_from_block(delta_S - I_d, lam, subtract_identity=True), lam) = (K_act, delta_S)` for any
  `delta_S` with `(I_d - lam · (delta_S - I_d))` invertible.
- **Schur primitive's identity on `s = 0`.** When the spectator block
  is empty (`s = 0`), `effective_block_from_sector_operator(M) = M`
  trivially, and the same equivalence holds with `delta_S = M`.
- **Invariance under spectator extension.** For any spectator block
  `(B, C, F)` with `F` invertible, the round-trip
  `M -> delta_S -> K -> delta_A` produces the same `delta_S` independent
  of `(B, C, F)`, so two sector-operator fixtures sharing the same
  Schur complement on the retained support produce the same response
  columns and the same column-inverted block.

## 9. Validation

Audit-companion runner:
[`scripts/audit_companion_pmns_hw1_response_column_schur_bridge_exact_2026_05_17.py`](./../scripts/audit_companion_pmns_hw1_response_column_schur_bridge_exact_2026_05_17.py)
verifies symbolically (sympy exact algebra) that for the small-`d`
test cases:

1. **Passive `d = 2`.** `(I - K_pass^{-1}) / lam` simplifies to the
   symbolic `delta` entry-by-entry.
2. **Active `d = 2`.** `I + (I - K_act^{-1}) / lam` simplifies to the
   symbolic `delta + I = delta_S` entry-by-entry.
3. **Passive `d = 3`.** Same check on a fully symbolic 3 x 3 `delta`.
4. **Active `d = 3`.** Same check on a fully symbolic 3 x 3 `delta_S`.
5. **Schur identity, `d = 2, s = 1`.** For a fully symbolic 3 x 3
   sector operator `M = [[A, B], [C, F]]` (smallest non-trivial
   dimensions tractable at exact-sympy precision; the d = 3, s = 2
   case is covered numerically in checks 9 and 10),
   `effective_block_from_sector_operator(M) = A - B F^{-1} C` and the
   full round-trip `M -> delta_S -> K_pass -> delta_A^pass = A - B F^{-1} C`
   reduces to zero symbolically.
6. **Active round-trip on a Schur-derived block.** For the same
   symbolic `M` at `d = 2, s = 1`, the active-convention round-trip
   `M -> delta_S -> K_act -> delta_A^act` reduces to `delta_S = A - B F^{-1} C`
   symbolically.
7. **Round-trip identity (passive), `d = 3`.**
   `response_columns_from_block(delta, lam, subtract_identity=False)`
   composed with
   `derive_passive_block_from_response_columns(..., lam)` returns
   `delta` symbolically.
8. **Round-trip identity (active), `d = 3`.**
   `response_columns_from_block(delta - I, lam, subtract_identity=True)`
   composed with
   `derive_active_block_from_response_columns(..., lam)` returns
   `delta` symbolically.
9. **Independent FP cross-check (passive).** At one independent random
   numerical sample of `(M, lam)` with `d = 3, s = 2`, Lane A and Lane B
   produce the same `delta_S` to machine precision.
10. **Independent FP cross-check (active).** Same FP cross-check on
    the active-convention round-trip.
11. **Counterfactual probe.** Replacing Lane A's column-invert step
    with the wrong inverse `(K - I) / lam` (sign flip on the identity
    subtraction) fails to recover `delta` on a generic block,
    confirming the sign of the algebraic identity is load-bearing.
12. **Spectator-extension invariance.** Two sector operators sharing
    the same Schur complement on the retained 3 x 3 support produce
    the same `delta_A^pass` after the column round-trip, independent
    of the spectator block `(B, C, F)`.
