## Question

The positivity/orientation program asks whether a positivity-type constraint
can break the (physically unbroken) `S_3` axis-symmetry on the hw=1 generation
triplet down to `C_3`. The natural candidate is the retained staggered
determinant positivity `staggered_only_det_positivity_case_a_note`
(`det(M_KS + mI) > 0`). Does that positivity actually do the breaking?

## Answer

**No — the determinant-magnitude positivity route does not close.** The
staggered determinant is `S_3`-invariant (reflection-even), so it is a
trivial-representation constraint and breaks nothing. Breaking `S_3 → C_3 = A_3`
through a one-dimensional sign/magnitude constraint requires coupling to the
**sign (orientation) representation** of `S_3`. An orientation-sign /
handedness positivity — the sign of the volume form / `Cl(3)` pseudoscalar —
is the representation-theoretic route that has `C_3` as its positive level set.
This note does not derive that physical positivity bridge.

## Theorem (one-dimensional character obstruction + selection)

`S_3` has exactly two one-dimensional representations: the trivial rep and the
sign rep `sgn`. Therefore a one-dimensional representation-valued
sign/magnitude constraint has only two possible representation characters:
trivial, whose positive level set is all of `S_3`, or `sgn`, whose positive
level set is `A_3=C_3`. This is not a statement about arbitrary binary class
functions on `S_3`: for example, the identity-conjugacy-class selector is a
binary class function but is not a one-dimensional character and is outside
this note's sign/magnitude route.

**(A) Determinant-magnitude positivity is the trivial rep.** The massless
staggered Dirac operator `D` is anti-Hermitian, so `det(D + mI) = ∏_i(m² + σ_i²)
> 0` for every configuration. Axis permutations act by gauge-equivalent
relabelings (see `STAGGERED_AXIS_SYMMETRY_IS_S3_NARROW_THEOREM_NOTE_2026-05-23.md`),
so `det(D + mI)` is identical under the identity, a transposition, and a 3-cycle
(verified: `Δlog det = 0` exactly, sign `+1` throughout). Hence
`det`-positivity is constant on `S_3` (trivial rep) and **selects all of `S_3`**
— it cannot break `S_3 → C_3`.

**(B) Orientation sign is the sign rep, and has `C_3` as its positive level
set.**
`sgn(σ) = det(ρ_perm(σ))` equals `+1` on the identity and the two 3-cycles and
`−1` on the three transpositions. The subset `{σ : sgn(σ) = +1}` is exactly
`A_3 = C_3`. Hence, if an independently derived constraint requires the
orientation sign to be positive, that handedness selection breaks
`S_3 → C_3`; among one-dimensional sign/magnitude constraints, this is the
nontrivial route with `C_3` as the positive level set.

**Conclusion.** Determinant-magnitude positivity (trivial rep) cannot supply the
`S_3 → C_3` breaker. A one-dimensional positivity route to `C_3` must instead
use the orientation (sign) representation, but the framework-level derivation
of such a handedness constraint remains a separate open bridge. ∎

## What this claims

- `det(D + mI)` is positive and `S_3`-invariant (reflection-even), verified
  under identity, transposition, and 3-cycle orderings.
- Therefore determinant-magnitude positivity cannot break `S_3 → C_3`.
- The orientation sign is the sign rep, whose positive level set is exactly
  `C_3`; any one-dimensional positivity route to `C_3` must be an
  orientation-sign (handedness) route.

The negative boundary is narrow: only the determinant-magnitude positivity route
is closed. The gate does not claim that no `S_3 -> C_3` route exists.

- **N1 alternative routes.** Direct determinant magnitude fails because it is
  constant on `S_3`; determinant sign/phase fails for this retained positive
  `det(D + mI)` surface; axis-order relabeling fails because the tested
  orderings give identical log-determinants; per-site chirality is blocked by
  `NO_PER_SITE_CHIRALITY_THEOREM_NOTE_2026-05-02.md`; global orientation-sign
  selection remains open and is explicitly not ruled out.
- **N2 wall independence.** There is one closed wall: determinant-magnitude

  asserted.
- **N3 hidden-wall scan.** The only hidden assumptions are the finite `S_3`
  sign/trivial representation split and the staggered determinant surface; both
  are named above, and the global orientation bridge is left open.
- **N4 residual matching.** The residual closed here is exactly the
  determinant-magnitude route, not the separate orientation-sign bridge.
- **N5 rhetoric audit.** The claim is stated at the one-dimensional
  sign/magnitude constraint resolution only; it does not rule out
  higher-structure selectors or a future global handedness derivation.
- **N6 partial-closure path scan.** The partial closure path is the
  orientation-sign reframe recorded here; it changes the next target rather than

- **N7 steelman.** A future derivation might attach a global orientation

  determinant-magnitude no-go.
- **N8 cross-cycle echo.** The existing no-per-site-chirality and orientation
  selection notes show why per-site handedness is unavailable while global

## Consequence for the program (corrected next target)

This **closes the determinant-positivity route** and corrects the target within
the one-dimensional sign/magnitude analysis. A possible `S_3 → C_3` positivity
breaker must be an **orientation-sign / handedness** constraint — the sign of
the `Cl(3)` pseudoscalar / volume form, which is the `C_3`-even,
transposition-odd object studied in
`POSITIVITY_ORIENTATION_SELECTS_C3_NARROW_THEOREM_NOTE_2026-05-23.md`. Two
honest constraints on where it can live:

- it must couple to the orientation/handedness, not to a magnitude/determinant;
- the framework's retained `no_per_site_chirality_theorem` forbids a per-site
  `γ_5`, so any handedness object must be a lattice-level / global orientation,
  not a per-site one.

So the precise open question is now: does the framework *force* a global
handedness (orientation-sign) selection? That is the corrected bridge target;
the det-magnitude route is ruled out.
