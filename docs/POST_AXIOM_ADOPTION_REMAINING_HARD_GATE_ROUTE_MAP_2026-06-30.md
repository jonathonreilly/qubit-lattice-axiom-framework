## Claim

If the 2026-06-29 axiom reset and the strict nearest-neighbor/Dirac bridge are
retained, the repo is in a better state but not finished.

The improvement is that "missing dynamics" is no longer one broad blocker. It
has split into named bridge targets:

```text
new axioms
  -> local possibility, admissible availability, fixed records
strict nearest-neighbor composition
  -> flux(-1) / first-order Dirac kinetic branch
durable two-outcome record idempotence
  -> conditional charged-lepton r = 1/2
```

What remains is the bridge work that makes those structures physical:

1. select the charged-lepton/generation record context;
2. close the physical species/locus bridge;
3. close `A_R-eta`;
4. close theta's gauge/mass bridge;
5. supply record occurrence/production;
6. derive probability/Born weights and measurement semantics;
7. close source/action coefficients;
8. close scale/metric/observable identification beyond the approved units
   primitive.

These are not equal in priority. The highest-leverage next target is the
charged-lepton/generation context selector, because it touches both the
remaining `AC_phi_lambda` atoms and the conditional `r = 1/2` theorem.

or else an honest narrowing that the remaining missing atom is exactly the
orientation/context selector.

### 6. Probability, Born Weights, And Measurement Semantics

**Current standing:** record counts are available; Born/frequency law is not
derived.

**Existing path evidence:**

  derive Born frequencies.
- The observable-principle and P-cal notes provide a possible log/free-energy

**Next bridge target:** derive a probability rule from selective instruments,

If this route fails, the exact missing atom is not Record; it is the instrument
plus effect-measure semantics.

### 8. Scale / Metric / Observable Bridge

**Current standing:** one scale reference is approved; metric and observable
bridges remain.

The scale-reference primitive supplies one dimensionful units conversion:

```text

```

It supplies no dimensionless physics and does not prove the framework's natural
unit equals the Planck length by self-consistency.

The kinetic-isotropy primitive supplies only OS0 form isotropy:

```text
c_t = c_s.
```

It does not supply dynamics or a Lorentz-closure theorem.

**Next bridge target:** separate two questions:

1. metric emergence: which record/source structure defines the operational
   metric;
2. observable identification: which scalar readouts correspond to measured
   physical observables.

The scale primitive should not be treated as an observable bridge.
