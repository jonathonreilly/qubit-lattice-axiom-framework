## Result

This block turns the post-record dynamics stack into a conditional audit
evidence ladder.

The lowercase source-anchor name is: conditional audit evidence ladder.

The ladder is not an audit verdict system. It is a finite classifier for what a
bounded or conditional row is allowed to claim from the evidence it supplies:

| Row needs | Sufficient evidence | Allowed branch-local reading |
|---|---|---|
| append/count semantics | finite alphabet + post-record append/count theorem | exact support candidate |
| p-value / calibrated flag | finite law + exact enumeration, or law-scoped concentration certificate | conditional audit ready |
| p-value from expectation only | expected counts or one-time marginals | blocked: expectation-only evidence cannot certify p-values |
| p-value from simulation only | Monte Carlo or numerical sample without finite certificate | support-only, not calibrated |
| stable dial setting | supplied score/rule plus map/flow stability certificate | stable setting under that supplied dynamics |
| selected dial value | selector/invariance/target rule, not stability alone | blocked until selector supplied |
| production dynamics | supplied formation/kernel/time bridge | bounded support with open imports |
| audit status change | independent audit result | independent audit owns verdicts |

This is the direct campaign answer to the bounded/conditional audit-lane
problem: after Record types post-record words/counts correctly, each row must
say which rung it is on. Rows cannot jump from count support to p-values, from
simulation to calibration, from stable settings to selected dials, or from a
branch-local note to an audit verdict.

## Key firewalls

- expectation-only evidence cannot certify p-values;
- simulation evidence is support-only unless paired with a finite certificate;
- stable settings are not selected dials;
- finite law and concentration certificates are law-scoped;
- independent audit owns verdicts.
