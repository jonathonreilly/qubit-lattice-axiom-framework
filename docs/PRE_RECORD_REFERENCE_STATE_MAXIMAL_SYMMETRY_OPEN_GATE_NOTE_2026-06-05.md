## 3. The classification gap — `{Quantum, Lattice, Record}` do NOT entail `X`

The decisive point is that **record-absence is strictly weaker than `X`**.

**Lemma (record-free ≠ maximally symmetric).** A *pure* state `|psi><psi|` has
registered **no outcome**, hence is a fully admissible "no record yet"
reference under the Record axiom (a record is the registration of a *realized*
outcome; none has been realized). Yet `|psi><psi|`:

- is **not** unitarily invariant (runner `B1a`: `max ||U|psi><psi|U^dag −
  |psi><psi||| = 1.40 > 0`);
- is **not** tracial (runner `B1b`: `|omega([X,Z])| = 0.73 != 0`);
- is **not** max-entropy (runner `B1c`: `S = 0 < log 2`).

Therefore "no record yet" does **not** imply `X`. □

**Sharpeners.**

- **B2 (measure-zero selection).** The set of admissible no-record-yet
  references is the **entire Bloch ball** (every density matrix is a valid
  state with no outcome registered); `X` selects the single **centre** point
  `I/2`. `X` is a strict, measure-zero extra constraint on a 3-ball, not a
  consequence of record-absence (which constrains the state's geometry not at
  all). Runner: all 5000 sampled Bloch states valid; centre is one point.
- **B3 (axiom-text).** The Record axiom supplies no weighting / normalization /
  probability / symmetry of any reference; Quantum supplies only `M_2(C)`;
  Lattice only `Z^3`. Neither the Jaynes max-entropy *principle* (candidate 2)
  nor a no-preferred-basis *symmetry* (candidates 1, 3) is inside the axioms.
  The logical content of this string-level fact is **witnessed exactly** by
  B1–B2.
- **B4 (relabeling).** A basis-relabeling unitary `U` carries one record-free
  pure reference to a **distinct** record-free pure reference (runner: differ
