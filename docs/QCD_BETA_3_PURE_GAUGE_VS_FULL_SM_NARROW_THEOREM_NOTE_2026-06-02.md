
## Proof

Pure substitution.

**Step 1 (gauge boson + ghost).** Apply `(X3)` with `C_2(adj SU(3)) =
N_color`: contribution `+(11/3) * N_color`.

**Step 2 (quark matter).** Apply `(X3)` with `T(F^Weyl) = 1/2`:
contribution `-(4/3) * (1/2) * N_quark = -(2/3) * N_quark`.

(No scalar contribution: the SM Higgs is `(1, 2)_{+1/2}` — an
SU(3)-singlet — so contributes 0 to `b_3` at 1-loop.)

**Step 3 (sum).** Add and combine over a common denominator:

```text
b_3  =  (11/3) * N_color  -  (2/3) * N_quark  =  (11 N_color  -  2 N_quark) / 3.   (P1)
```

**Step 4 (pure-gauge instance).** Apply `(X1a)`: `N_quark = 0`, and
`(X0)`: `N_color = 3`. Substitute into `(P1)`:

```text
b_3(N_quark = 0)  =  (11 * 3 - 2 * 0) / 3  =  33 / 3  =  11.            (P2a)
```

**Step 5 (full-SM instance).** Apply `(X1b)`: `N_quark = 6` (from
`N_gen × N_pair = 3 × 2 = 6`, where `N_gen = 3` comes from `(X2)` and
`N_pair = 2` from the SU(2) admission inside `(X3)`), and `(X0)`:
`N_color = 3`. Substitute into `(P1)`:

```text
b_3(N_quark = 6)  =  (11 * 3 - 2 * 6) / 3  =  21 / 3  =  7.            (P2b)
```

**Step 6 (difference).** Subtract `(P2b)` from `(P2a)`:

```text
Δb_3  =  11  -  7  =  4.                                                  (P2)
```

Equivalently, `Δb_3 = (2/3) · N_quark = (2/3)(6) = 4`, the algebraic
form of the sea-quark correction at framework counts. The per-sector
decomposition `(P3)` follows by reading the two additive contributions
individually with their framework values. ∎

## Derivable corollaries

```text
(C1) Per-sector decomposition at full SM: 11 + (-4) = 7, exact Rational.
(C2) Pure-gauge-to-full-SM ratio: b_3(0) : b_3(6) = 11 : 7. The
     1-loop asymptotic-freedom strengthening factor from full SM to
     pure gauge.
(C3) The sea-quark correction is linear in N_quark with slope -(2/3),
     parametric in N_color (slope independent of N_color):
        b_3(N_quark) - b_3(0)  =  -(2/3) * N_quark.
     Evaluates to -4 at N_quark = 6, matching (P2) by sign.
(C4) Asymptotic-freedom threshold: b_3 > 0 requires
        N_quark  <  (11/2) * N_color  =  16.5 at N_color = 3.
     Hence the textbook bound N_quark <= 16 is reproduced parametric
     in N_color; framework N_quark = 6 sits well below threshold.
(C5) Counterfactual N_pair = 4 → N_quark = N_gen × N_pair = 12 →
     b_3 = (33 - 24)/3 = 3, confirming (P1) is genuinely parametric.
```

All five corollaries follow algebraically from `(P1)` plus the framework
inputs.
