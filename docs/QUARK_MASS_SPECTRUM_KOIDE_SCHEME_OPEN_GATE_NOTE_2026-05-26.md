## Claim

This note opens the quark-mass-spectrum lane with a boundary condition,
not a quark-mass theorem.

For any three real generation coordinates `x_k`, including formal
sqrt-mass coordinates, the `C_3` circulant/Brannen parametrization

```text
x_k = a + 2 |b| cos(delta + 2 pi k / 3)
```

is an algebraic coordinate system. Existing Koide algebra then gives

```text
Q = (sum x_k^2) / (sum x_k)^2
|b|^2 / a^2 = (3Q - 1) / 2.
```

Using the packet-local central-value comparator convention below, the
apparent Koide/Brannen amplitude ratios for the up- and down-type quark
sectors are not the charged-lepton BAE value `|b|^2/a^2 = 1/2`:

```text
sector       Q comparator       apparent |b|^2/a^2
charged l    0.666660...        0.499991...
up quarks    0.849094...        0.773642...
down quarks  0.731428...        0.597141...
```

This is useful as a lane-opening warning: the charged-lepton BAE
coefficient must not be copied into the quark mass lane without a
separate derivation, and any quark-mass claim must state its
renormalization scheme and scale. The note does not derive quark masses,
quark Brannen phases, quark amplitude ratios, or quark mass scales.

## Boundaries

This open gate does not claim:

- a framework derivation of any quark mass;
- a framework derivation of quark-sector `|b|/a` or `delta`;
- a transfer of charged-lepton BAE to quarks;
- a CKM-to-mass theorem;
- a new axiom, new theory language, or new retained status.

The durable result is the review boundary: quark-sector mass work must
not assume the lepton BAE coefficient, and any numerical comparison must
make the quark mass scheme explicit.
