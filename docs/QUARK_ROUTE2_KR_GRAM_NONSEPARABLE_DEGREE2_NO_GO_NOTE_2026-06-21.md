## Gram Collapse

For any symmetric source metric

```text
M = [[m00, m01],
     [m01, m11]],
```

the current carrier gives

```text
K_R^T M K_R = A_M(delta_A1) [[u_E^2, u_E u_T],
                             [u_E u_T, u_T^2]]
```

where

```text
A_M(delta_A1) = m00 + 2 m01 delta_A1 + m11 delta_A1^2.
```

At the unit `E` probe `(u_E,u_T)=(1,0)` and the unit `T1` probe
`(u_E,u_T)=(0,1)`, both diagonal readouts are exactly `A_M(delta_A1)`.
Thus every such source-side Gram has

```text
response_E / response_T = 1.
```

The same collapse persists through finite tensor powers of this grammar:
source contractions only build powers or products of source-side scalars
`A_M(delta_A1)`, while channel-blind bright contractions see the two unit
bright probes symmetrically.
