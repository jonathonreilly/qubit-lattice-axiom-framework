## Statement

Let `Λ` be a finite set of `N` framework lattice sites. For each
`x ∈ Λ`, A1 supplies the local qubit algebra `A_x ≅ M_2(C)`. Choose one
rank-one projection `n_x ∈ A_x`, interpreted only as a qubit occupation
readout at that site. Let `n_x` also denote its tensor embedding into
`A_Λ := ⊗_{x∈Λ} A_x`, and define

```text
    Q_total := Σ_{x∈Λ} n_x.                                                 (1)
```

Then:

**(I1) Per-site spectrum.** Each `n_x` has spectrum `{0, 1}`.

**(I2) Multi-site commutativity.** `[n_x, n_y] = 0` for all `x, y ∈ Λ`.

**(I3) Integer total spectrum.** `Spec(Q_total) = {0, 1, ..., N}`.

**(I4) Binomial multiplicity.** The eigenspace at eigenvalue `k` has
dimension `C(N, k)`.

**(I5) Pauli-coordinate formula.** In any basis where the chosen readout
projection is `n = (I - σ_3)/2`, one has
`Q_total = (N/2) I - (1/2) Σ_x σ_{3,x}`.

## Proof

### Step 1 - A1 Supplies Qubit Algebras

By [`MINIMAL_AXIOMS_2026-05-20.md`](MINIMAL_AXIOMS_2026-05-20.md), A1
says that reality is a qubit at every lattice site. The same axiom note
states the equivalent local-algebra form: for each site `x`, the primitive
local operator algebra is `A_x ≅ M_2(C) = End(C^2)`.

### Step 2 - Per-Site Projection Spectrum (I1)

A rank-one projection `n_x ∈ M_2(C)` satisfies `n_x^2 = n_x = n_x†` and
has trace one. Therefore its eigenvalues are exactly `0` and `1`. In a
chosen readout basis,

```text
    n = [[0, 0], [0, 1]] = (I - σ_3)/2.                                      (2)
```

This basis choice is not an added axiom: all rank-one qubit projections
are unitarily equivalent, and the spectrum statement is invariant.

### Step 3 - Tensor Embedding and Commutativity (I2)

On the finite tensor product `A_Λ = ⊗_{x∈Λ} A_x`, the embedded operator
`n_x` acts as `n` on factor `x` and identity on every other factor. If
`x ≠ y`, the operators act on disjoint tensor factors, hence commute.
If `x = y`, the commutator is zero trivially.

### Step 4 - Integer Total Spectrum (I3)

Since the `n_x` are commuting Hermitian projections, they have a joint
eigenbasis labelled by binary strings `ν ∈ {0, 1}^N`. For a joint basis
vector `|ν⟩`,

```text
    n_x |ν⟩ = ν_x |ν⟩,
    Q_total |ν⟩ = (Σ_x ν_x) |ν⟩.                                             (3)
```

As `ν` ranges over `{0, 1}^N`, the Hamming weight `Σ_x ν_x` takes every
integer value from `0` through `N`. Hence
`Spec(Q_total) = {0, 1, ..., N}`.

### Step 5 - Multiplicity (I4)

The eigenspace with eigenvalue `k` is spanned by the binary strings with
exactly `k` ones. There are `C(N, k)` such strings, so
`dim Ker(Q_total - k I) = C(N, k)`.

### Step 6 - Pauli-Coordinate Formula (I5)

In a basis where `n = (I - σ_3)/2`, tensor embedding gives

```text
    Q_total = Σ_x (I - σ_{3,x})/2
            = (N/2) I_tot - (1/2) Σ_x σ_{3,x}.                               (4)
```

This coordinate formula is a representation of the invariant projection
counting theorem, not an independent physical charge postulate. ∎

## Corollaries

C1. **Integer qubit occupation sectors.** A finite `N`-site A1 qubit block
splits into occupation-count sectors

```text
    (C^2)^{⊗N} = ⊕_{k=0}^{N} H_k,    dim H_k = C(N, k).
```

C2. **Parity grading.** The operator `(-1)^{Q_total}` gives the even/odd
qubit-occupation parity split. For `N ≥ 1`, the even and odd parity
subspaces each have dimension `2^{N-1}`.

C3. **Half-filling sector.** When `N` is even, the largest occupation
sector is `k = N/2`, with dimension `C(N, N/2)`.
