## Claim

The finite color matrix space has one scalar channel and eight traceless
channels:

```
dim(M_3(C)) = 9,
dim(C I_3) = 1,
dim(traceless M_3(C)) = 8.
```

Therefore the adjoint/traceless channel-count fraction is exactly

```
F_adj = 8 / 9.
```

If one additionally supplies the connected-trace selector premise

```
(M0) the physical connected readout keeps the traceless/adjoint channel
     and discards the scalar/singlet channel,
```

then the connected-channel readout is

```

```

This is a conditional consequence of `(M0)`. The finite algebra alone
does not derive `(M0)`.

## Exact Finite Algebra

Let `V = M_3(C)` be the `9`-dimensional complex vector space of `3 x 3`
color matrices. It splits as

```
V = C I_3  direct_sum  sl_3(C),
```

where `C I_3` is the scalar/singlet line and `sl_3(C)` is the traceless
subspace.

The dimensions are

```
dim(C I_3) = 1,
dim(sl_3(C)) = 3^2 - 1 = 8,
dim(V) = 3^2 = 9.
```

Hence the traceless-channel fraction is

```
F_adj = dim(sl_3(C)) / dim(M_3(C))
      = (3^2 - 1) / 3^2
      = 8 / 9.
```

This dimension calculation is the complete unconditional content of the
row.

## Selector Parameter

To make the missing readout choice explicit, write the normalized channel
weights as

```
C = 8/9,     S = 1/9,     C + S = 1,
```

where `C` denotes the traceless/adjoint channel fraction and `S` denotes
the scalar/singlet channel fraction.

A one-parameter readout family is

```
P(kappa_EW) = C + kappa_EW S = 8/9 + kappa_EW / 9.
```

Two admissible algebraic choices are immediate:

```
kappa_EW = 0  =>  P(kappa_EW) = 8/9,
kappa_EW = 1  =>  P(kappa_EW) = 1.
```

The finite channel algebra therefore does not select `kappa_EW = 0`.
The special `R_conn = 8/9` readout requires the explicit selector premise
`(M0)`.

Equivalently, the inverse package factor associated with this
parameterized readout would be

```
K_EW(kappa_EW) = 1 / P(kappa_EW) = 9 / (8 + kappa_EW),
```

so `K_EW(0) = 9/8` and `K_EW(1) = 1`. The algebra records the family; it
does not choose a member.
