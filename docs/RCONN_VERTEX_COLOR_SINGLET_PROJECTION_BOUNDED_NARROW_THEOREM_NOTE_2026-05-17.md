## Statement

Let `V_color = C^{N_c}` with `N_c >= 2`, and let
`End(V_color)` carry the Hilbert-Schmidt inner product

```text
<A, B>_HS = Tr_color(A^\dagger B).
```

Let `M_color` be a nonzero Hermitian `N_c x N_c` color insertion. Decompose
the Hermitian matrix algebra into the orthogonal direct sum

```text
Herm(N_c) = C I_color  \oplus  su(N_c)_Herm,traceless.
```

Then the singlet projection is

```text
Proj_{C I}(M_color) = (Tr_color M_color / N_c) I_color,
```

and its normalized Hilbert-Schmidt weight is

```text
rho_singlet(M_color)
  = (|Tr_color M_color|^2 / N_c) / Tr_color[M_color^2].          (P1)
```

The adjoint/traceless weight is

```text
rho_adjoint(M_color) = 1 - rho_singlet(M_color).                 (P2)
```

Consequently:

```text
rho_singlet(I_color) = 1,        rho_adjoint(I_color) = 0,        (P3)
rho_singlet(sqrt(2) t^A) = 0,    rho_adjoint(sqrt(2) t^A) = 1,    (P4)
```

where `t^A` is any SU(`N_c`) generator normalized by
`Tr_color(t^A t^B) = (1/2) delta^{AB}`.

For every nonzero Hermitian `M_color`, `rho_singlet(M_color) = 0` if and
only if `Tr_color M_color = 0`.

## Proof

The projection formula is ordinary finite-dimensional linear algebra.
For any Hermitian `M_color`, the coefficient of its projection onto
`I_color` is fixed by orthogonality:

```text
alpha = <I_color, M_color>_HS / <I_color, I_color>_HS
      = Tr_color M_color / N_c.
```

Thus

```text
Proj_{C I}(M_color) = alpha I_color.
```

The Hilbert-Schmidt norm of this projection is

```text
||alpha I_color||_HS^2
  = Tr_color((alpha I_color)^\dagger (alpha I_color))
  = |alpha|^2 N_c
  = |Tr_color M_color|^2 / N_c.
```

Because `M_color` is Hermitian,

```text
||M_color||_HS^2 = Tr_color(M_color^\dagger M_color)
                 = Tr_color[M_color^2].
```

Dividing the projected norm by the total norm gives (P1). The traceless
subspace is orthogonal to `I_color`, so (P2) follows by Pythagoras.

For `M_color = I_color`, `Tr_color I_color = N_c` and
`Tr_color(I_color^2) = N_c`, hence `rho_singlet = 1`. For
`M_color = sqrt(2) t^A`, tracelessness gives `Tr_color M_color = 0`, while
normalization gives `Tr_color(M_color^2) = 1`, hence `rho_singlet = 0`.

Finally, the denominator in (P1) is positive for nonzero Hermitian
`M_color`, so `rho_singlet = 0` exactly when `Tr_color M_color = 0`.
