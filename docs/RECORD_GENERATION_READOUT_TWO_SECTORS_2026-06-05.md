## Proof

Write `C3 = {e, g, g^2}` and let `omega = e^{2 pi i / 3}`.

### 1. The carrier and its complex characters

On the supplied hw=1 carrier `{e1, e2, e3}`, the generator `g` acts by the cyclic
permutation `e1 -> e2 -> e3 -> e1`, i.e. by the permutation matrix

```text
P = [[0,0,1],[1,0,0],[0,1,0]],   P^3 = I,   P != I,   P^2 != I,
```

the (left) regular representation of `C3` — faithful, three-dimensional. Over `C`
the regular representation of the abelian group `C3` is multiplicity-free and
decomposes into its three one-dimensional irreducible characters
`chi_a(g^k) = omega^{a k}`:

```text
chi_0 = (1, 1,        1       )    (trivial)
chi_1 = (1, omega,    omega^2 )    (faithful)
chi_2 = (1, omega^2,  omega   )    (faithful, = chi_1-bar)
```

Schur orthogonality `(1/3) sum_k chi_a(g^k) conj(chi_b(g^k)) = delta_{ab}` holds
(verified: Gram `= I_3`), and the regular character `(3,0,0)` contains each `chi_a`
exactly once (multiplicities `(1,1,1)`). So the three central sectors of the
*complexified* carrier are exactly `chi_0, chi_1, chi_2`.

### 2. The `K`/CPT (complex conjugation) action and its orbits

The context's fixed `K`/CPT conjugation acts on a character pointwise by complex
conjugation: `(K . chi_a)(g^k) = conj(omega^{a k}) = omega^{-a k}`, i.e.
`K . chi_a = chi_{-a mod 3}`. Concretely:

```text
K . chi_0 = chi_0           (chi_0 is real -> fixed)
K . chi_1 = chi_2           (the two faithful characters are
K . chi_2 = chi_1            complex-conjugate -> swapped)
```

`K` is an involution (`K^2 = id`), acting on the sector index set `{0,1,2}` as the
permutation `(0)(1 2)`. Its orbits are therefore

```text
{chi_0}        -- SINGLET, dimension 1
{chi_1, chi_2} -- DOUBLET, dimension 2
```

Two orbits, of dimensions `1` and `2`, with `1 + 2 = 3 = |C3|`. This is the
claimed result.

### 3. Frobenius-Schur indicators confirm the reality types

The Frobenius-Schur indicator `nu(chi) = (1/|G|) sum_{g} chi(g^2)` evaluates to

```text
nu(chi_0) = +1   (REAL type)
nu(chi_1) =  0   (COMPLEX type)
nu(chi_2) =  0   (COMPLEX type)
```

The pattern `(+1, 0, 0)` says exactly: `chi_0` is realizable over `R` as a
one-dimensional real block, while `chi_1, chi_2` form one complex-conjugate pair
that fuses under conjugation into a single two-dimensional real-irreducible block.
Counting real-irreducible blocks: `n_real (=1) + n_complex_pairs (=1) = 2`, which
equals the `K`/CPT-orbit count.

### 4. Contrast: `K`/CPT is what makes it two, not three

Diagonalizing the regular representation `P` over `C` (by the `3x3` DFT) gives the
distinct eigenvalue multiset `{1, omega, omega^2}` — i.e.
`C[Z3] = C ⊕ C ⊕ C`, **three** central sectors. Without the `K`/CPT
identification the generation readout would resolve three sectors.

Over `R`, the same regular representation is real-equivalent to
`(1) ⊕ rotation(2 pi/3)`:

```text
T^T P T = [[1, 0,           0          ],
           [0, cos(2pi/3), -sin(2pi/3) ],
           [0, sin(2pi/3),  cos(2pi/3) ]]
        = (1) ⊕ R(2pi/3),
```

so `R[Z3] = R ⊕ C` — the trivial one-dimensional real block plus a single
two-dimensional real-irreducible rotation block. That rotation block has no real
eigenvalue (irreducible over `R`) and splits over `C` precisely into
`{omega, omega^2}`: it *is* the fused `{chi_1, chi_2}` pair. The fixed `K`/CPT
conjugation in the readout context is exactly this real-structure fusion
`C[Z3]=C^3 -> R[Z3]=R⊕C`, and the `K`/CPT-orbit count (`2`) equals the real
Wedderburn block count (`2`). ∎
