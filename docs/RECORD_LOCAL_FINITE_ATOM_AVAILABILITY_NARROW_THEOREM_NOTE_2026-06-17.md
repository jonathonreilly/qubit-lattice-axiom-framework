## Result

For every finite `n`, the Lattice and Quantum axioms admit a concrete finite
local readout context with `n` pairwise support-disjoint nonzero
record-eligible readout atoms.

Choose the lattice sites

```text
x_k = (k,0,0),    k = 0, ..., n-1.
```

At each site, Quantum supplies a one-site copy of `M_2(C)`. In a declared local
diagonal readout context choose

```text
P_0 = [[1,0],[0,0]],     P_1 = [[0,0],[0,1]],
```

with the fixed conjugation `K` given by entrywise complex conjugation in this
declared basis. The commutative algebra generated by `{P_0,P_1}` has a finite
two-sector decomposition, both sectors are nonzero, and both are fixed by `K`.

Therefore the framework has, for arbitrary finite `n`, a supplied finite
readout context containing `n` nonzero possible realized-outcome labels with
pairwise disjoint lattice supports. If a later production layer realizes the
chosen atom at each support, Record's finite additivity reads the resulting
finite collection as an ordinary finite sum. With the declared unit-count
readout functional on the finite Boolean context, that sum is exactly `n`.

## What This Repairs

This note removes a hidden source-side import in the unbounded finite-record

## Proof

Fix finite `n`. The sites `x_k = (k,0,0)` are distinct because equality in
`Z^3` is coordinatewise. Thus their one-site algebras have disjoint lattice
supports.

At each site, `P_0` and `P_1` obey

```text
P_i^2 = P_i,        P_0 P_1 = 0,        P_0 + P_1 = I_2,
```

and each has trace one, hence is nonzero. In the commutative readout algebra
`span{P_0,P_1}`, these are the central atoms. Entrywise complex conjugation
leaves both matrices fixed, so the `K`-orbits are singleton atoms.

Tag the readout atom `P_1` at site `x_k` as `r_k`. The tags have pairwise
disjoint lattice support. Since `n` was arbitrary and finite, the construction
gives a finite collection `{r_0, ..., r_{n-1}}` for every finite `n`.

The declared unit-count functional on the finite Boolean context sends each
single-site atom to `1` and the empty collection to `0`. Finite additivity then
gives

```text
I({r_0, ..., r_{n-1}}) = 1 + ... + 1 = n.
```

This is an exact finite algebra statement. It is not a completed infinite
history and not a production theorem.
