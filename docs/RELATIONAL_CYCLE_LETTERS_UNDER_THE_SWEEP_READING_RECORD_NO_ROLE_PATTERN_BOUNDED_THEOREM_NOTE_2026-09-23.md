# Sweep records can fail the canonical phase and parity readouts

**Date:** 2026-09-23
**Type:** bounded_theorem

## Result and scope

A deterministic bounded search finds forty distinct sweep records on a side-three core, none among the 768 normalized cycle spirals. The first is completed on its low faces and satisfies the sweep rule at all 27 core sites. Every one of the forty fails the static cycle rule at (2,2,2), whose six neighbours are inside the core, so changing faces cannot repair that failure.

For the completed first witness, back-step phase minus position has 3,3,4 distinct residues on the three axes. These sets also have both parities, so no global offset makes that canonical phase/parity readout equal to position. The control spiral does have the canonical readout. The forty witnesses are a bounded prefix, not an exhaustive enumeration.

## Boundaries and non-claims

This disproves a guaranteed canonical phase/parity readout for all sweep records. It does not exclude every possible local role decoder or say no sweep record carries roles. The fixed axis convention and supplied planar decoder are part of the test. No universal failure of formation or physics conclusion follows.
