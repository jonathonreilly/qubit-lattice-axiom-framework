## Theorem

**I1 - Registrable channel.** The elementary symmetric invariants of the
eigenvalues are exactly

```text
e1 = 3a
e2 = 3a^2 - 3B^2
e3 = a^3 - 3 a B^2 + 2 B^3 cos(3 delta)
```

Hence `delta` enters the registrable K/CPT-orbit-symmetric data solely through
`cos(3 delta)`. Check tags: I1a, I1b.

**I2 - Free coordinate.** The coordinate

```text
x = cos(3 delta) = (e3 - a^3 + 3 a B^2) / (2 B^3)
```

is a free affine coordinate whenever `B != 0`: given `a` and `B`, the map
`e3 <-> x` is an affine bijection and `x` ranges over `[-1,1]`. The symmetric
mass-side surface fixes `a` and `B^2` through `e1` and `e2`, but it leaves the
third invariant, equivalently `x`, free. The mass-phase datum is unpinned by
the registrable surface. Check tag: I2.

**I3 - Geometric constant is operator-free.** The fixed-locus density is

```text
L_3(1,2) = (1/3) sum_{j=1,2}
  1 / ((omega^j - 1)(omega^(2j) - 1)) = 2/9
```

exactly, with `omega = exp(2 pi i / 3)`. The comparison values are
`L_3(1,1) = L_3(2,2) = 1/9`, and the core identity is
`(omega - 1)(omega^2 - 1) = 3`. This computation uses only the `C_3` character
phases `{2 pi k / 3}`. It contains no `a`, no `B`, no `delta`, and no `H`; it
is a geometric rotation/Lefschetz number, not an operator datum. Check tags:
I3a, I3b.

**I4 - Three pinning constraints all fail.** No retained structure tested here
forces `x = 2/9` read as radians.

- **I4a:** `C_3` covariance `[H, C] = 0` holds for every `delta`, so covariance
  cannot pin a value. Check tag: I4a.
- **I4b:** on the Hermitian-positive mass surface `a > 2B > 0`, every eigenvalue
  is positive, so `det H` is real positive and `arg det H = 0`. There is no
  holonomy or determinant phase on this surface that can source `2/9`. Check

- **I4c:** the retained nondegenerate conjugation-even spectral-scalar branch

  form `n pi / 3` for any integer `n`, so this spectral-action stationary route
  cannot land `2/9`. Check tag: I4c.
