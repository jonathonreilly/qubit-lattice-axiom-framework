## Setup (Lattice+Quantum baseline, no new imports)

Each site is one qubit `C²` (Quantum). Sites sit on a periodic ring `x = 0..L-1`,
the closed-loop slice of the `Z`/`Z³` lattice (Lattice). On each site the **creation**
operator is `a† = σ_-` (vacuum `e₁ ↦` occupied `e₂`), `a = σ_+`, `n = a†a = diag(0,1)`.
The carrier bit is **purely** the cross-site sign:

```
HCB:  b_x = bare on-site ladder,                    [b_x, b_y] = 0   (commute cross-site)
CAR:  c_x = (∏_{y<x} σ₃^(y)) · ladder_x,            {c_x, c_y} = 0   (anticommute)
```

On any single site `b_x = c_x` as a `2×2` matrix; `b_x² = c_x² = 0`. The two differ
only in the cross-site exchange (matches `statistics_agnostic` /
`CAR_FROM_POSITIVITY` exactly). The Z₂ grading
`F = (-1)^Q = ∏_x σ₃^(x)` is **literally the same operator** in both frames (it is built
from the **shared** number operators `n_x`), per
`fermion_parity_z2_grading_theorem`.

The **ring** Hamiltonian is the nearest-neighbour hopping including the wrap bond:
`H = -t ∑_{x=0}^{L-1} (a†_x a_{x+1} + h.c.)` with `x+1` taken mod `L`. In the HCB frame
the wrap bond is the naive `a†_{L-1} a_0`; in the CAR frame it carries the
Jordan–Wigner string on the interior sites — **this is the only place the statistics
sign enters**, and it is precisely the closed-Wilson-line / loop datum.
