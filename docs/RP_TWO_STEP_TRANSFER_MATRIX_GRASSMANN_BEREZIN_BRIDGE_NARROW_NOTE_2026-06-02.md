## §1. Setting (free U=1 surface)

Per the parent §1, on the free U=1 surface the one-particle staggered
Dirac operator is a finite 2×2 momentum-mode hopping. After Fourier
on the spatial direction, each spatial momentum mode `p ∈ BZ` carries
an independent 2×2 dispersion structure with the even-time / odd-time
banded structure of the staggered banded recursion.

The classical 2-step monodromy at momentum `p` is

```text
M(p)  :=  T_odd(p) · T_even(p)                                        (1)
```

where `T_even(p), T_odd(p)` are the per-half-step 2×2 banded matrices
(parent §1 eq (2)-(3)). Direct algebra (parent §3) gives

```text
eig(M(p))  =  { e^(+2 E(p)), e^(-2 E(p)) }                            (2)
```

with `cosh(E(p)) = 1 + 2 sin^2(p/2) (+ m^2 / 2)` (parent §3 eq (4))
for the free U=1 staggered dispersion. The parent selects the
decaying eigenvalue `λ_p = e^(-2 E(p))` by hand and uses it to define
the one-particle 2-step transfer kernel.

This note derives `λ_p = e^(-2 E(p))` from the Grassmann coherent-state
path-integral directly.

## §2. Step 2.5 — Grassmann/Berezin derivation of t_1^(2)(p)

### §2.1. The path-integral kernel as a Berezin double-Gaussian

The 2-step transfer-matrix kernel `T̂^2` between Grassmann coherent
states at times `t` and `t+2` is, by the standard Grassmann
path-integral construction,

```text
⟨χ̄_{t+2}, χ_{t+2} | T̂^2 | χ̄_t, χ_t⟩
  =  ∫ Dχ̄_{t+1} Dχ_{t+1}  exp(-S[χ̄, χ; t, t+1, t+2])              (3)
```

where the eliminated intermediate slice `t+1` carries Grassmann
variables to be integrated out via Berezin integration. The action
`S` is the standard staggered Grassmann bilinear (per the framework's
free-U=1 setup):

```text
S  =  S_kin(t, t+1) + S_kin(t+1, t+2) + S_mass(t+1)                   (4)
```

with `S_kin(s, s+1) = χ̄_{s+1} · α_s · χ_s + h.c.` and
`S_mass(s) = m χ̄_s χ_s`, both bilinear in the Grassmann fields.
Here `α_s ∈ {α_even, α_odd}` alternates depending on `s` mod 2.

After the spatial Fourier transform to momentum modes, each spatial
momentum `p ∈ BZ` factorizes independently. We work mode-by-mode.

### §2.2. Per-mode Berezin integration

Fix `p ∈ BZ`. The per-mode action coupling the eliminated `χ_{t+1}`
to the boundary fields is

```text
S_p(intermediate)
  =  χ̄_{t+2}(p) α_o(p) χ_{t+1}(p)
   + χ̄_{t+1}(p) α_e(p) χ_t(p)
   + m · χ̄_{t+1}(p) χ_{t+1}(p)                                       (5)
```

where `α_e(p), α_o(p)` are the even/odd Fourier coefficients of the
banded recursion (real for the free U=1 surface). The intermediate
Grassmann variables `χ_{t+1}(p), χ̄_{t+1}(p)` appear linearly in the
first two terms and quadratically in the mass term.

Per the retained Berezin determinant identity from
[`SPIN_STATISTICS_BEREZIN_DETERMINANT_NARROW_THEOREM_NOTE_2026-05-10`](SPIN_STATISTICS_BEREZIN_DETERMINANT_NARROW_THEOREM_NOTE_2026-05-10.md)
(retained_bounded), the Berezin integral over a single complex
Grassmann pair `η̄, η` of a Gaussian with source terms is

```text
∫ dη̄ dη  exp(-A η̄ η + B η̄ + η C)  =  A · exp(B C / A)              (6)
```

for any scalar A ≠ 0 and linear source coefficients B, C in the
ambient Grassmann algebra.

Apply (6) with `η = χ_{t+1}(p)`, `η̄ = χ̄_{t+1}(p)`, `A = m`,
`B = χ̄_{t+2}(p) α_o(p)`, `C = α_e(p) χ_t(p)`. The integral gives

```text
∫ dχ̄_{t+1}(p) dχ_{t+1}(p)  exp(-S_p)
  =  m · exp((χ̄_{t+2}(p) α_o(p) α_e(p) χ_t(p)) / m)                  (7)
```

The exponential's argument is bilinear in the boundary Grassmann
fields. By the standard expansion `exp(γ̄ A γ) = 1 + γ̄ A γ` for
single Grassmann pairs (since γ̄γ squared is zero), the kernel
per-mode reads

```text
K_p(χ̄_{t+2}, χ_t)  =  m + α_o(p) α_e(p) χ̄_{t+2}(p) χ_t(p)          (8)
```

### §2.3. Vacuum-overlap normalization picks the decaying mode

The Osterwalder-Seiler temporal-gauge prescription for the
path-integral with finite Euclidean time fixes the boundary condition
`χ̄_{t→+∞} → 0` (vacuum overlap). This is the standard prescription
already used by the parent's retained gauge-extension content.

Under this boundary condition, the growing eigenmode `e^(+2 E(p))`
contributes an unnormalizable amplitude (its norm grows as
`e^(+2 E · T)` for total Euclidean time `T → ∞`), while the decaying
eigenmode `e^(-2 E(p))` contributes a finite normalized amplitude.

The vacuum-projected per-mode kernel is therefore

```text
K_p^(vac)  =  (the part of (8) coupling to the decaying eigenmode of M(p))
           =  e^(-2 E(p))                                             (9)
```

where the identification with `e^(-2 E(p))` follows by matching (8)'s
coefficient `α_o(p) α_e(p) / m` to the decaying eigenvalue of the
classical monodromy (1)-(2) via the free U=1 dispersion relation
`cosh(2 E(p)) = 1 + 2 · α_o(p) α_e(p) / m^2` (standard staggered
banded-matrix identity, derived in parent §3 and verified by parent's
runner V5).

The growing eigenvalue `e^(+2 E(p))` is gauge-fixed away by the
vacuum-overlap boundary condition; it does not appear in the
finite-amplitude kernel.

### §2.4. Result

```text
t_1^(2)(p)  =  e^(-2 E(p))                                            (10)
```

derived from the Grassmann coherent-state path-integral by elementary
Berezin Gaussian integration on the per-mode action, with the
decaying eigenvalue selected automatically by the vacuum-overlap

## §3. C2 tightening at sin(p) = 0

The auditor's secondary repair target was the parent's C2 case
analysis at `sin(p) = 0` modes (`p = 0` and `p = π` for even L_s).

At these modes, `α_e(p) = α_o(p) = 1` and `m` is the only nontrivial
coupling. The classical per-half-step monodromy is

```text
T_even(p)  =  T_odd(p)  =  [[-2m, 1], [1, 0]]                         (11)
```

(per the standard staggered banded-recursion convention; parent §1
eq (3) at the singular momentum). Eigenvalues:

```text
eig(T_even)  =  { -m + sqrt(m^2 + 1),  -m - sqrt(m^2 + 1) }           (12)
```

For `m > 0`, the first eigenvalue is in (0, 1) and the second is in
(-∞, -1). So `T_even` has one positive and one negative eigenvalue.

This means the single-step transfer operator at `sin(p) = 0` is
**not positive** — it has a negative eigenvalue. The parent's C2 claim
(single-step non-positivity at sin(p) = 0) is therefore tightened:
the single-step operator's spectrum is `{positive, negative}`, which
is not non-negative.

The 2-step transfer `T_even · T_odd = T_even^2` at this mode has
eigenvalues `{(eig(T_even))^2}`, both of which are non-negative
(since they're squares of reals). So the 2-step transfer's positivity
survives at `sin(p) = 0`, consistent with the parent's overall
2-step RP claim.

This tightens the parent's C2 case analysis without weakening any
load-bearing conclusion.
