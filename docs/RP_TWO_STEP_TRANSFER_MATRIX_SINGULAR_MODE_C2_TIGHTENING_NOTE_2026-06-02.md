## 1. Claim

At the singular momentum modes (`sin(p)=0`) of the parent's free `U=1`
surface, the half-step matrix is

```text
T_even(m) = [[-2m, 1],
             [  1, 0]]
```

for `m > 0`. Its eigenvalues are

```text
lambda_+(m) = -m + sqrt(m^2 + 1)
lambda_-(m) = -m - sqrt(m^2 + 1).
```

Therefore `lambda_+(m) in (0, 1)` and `lambda_-(m) < -1` for every
`m > 0`. The one-step matrix is not positive semidefinite. The two-step
matrix `T_even(m)^2` has eigenvalues `lambda_+(m)^2` and `lambda_-(m)^2`,
so its spectrum is non-negative.

This is a C2 tightening only: it supports the parent's two-step rather than
one-step RP boundary at the singular modes, but it does not prove the full
parent row or any Grassmann/Berezin bridge.

## 2. Proof

The characteristic polynomial of `T_even(m)` is

```text
det(T_even - lambda I)
  = det([[-2m - lambda, 1],
         [1, -lambda]])
  = lambda^2 + 2m lambda - 1.
```

The roots are

```text
lambda = -m +/- sqrt(m^2 + 1).
```

For `m > 0`, `sqrt(m^2 + 1) > m`, so `lambda_+ > 0`. Also
`sqrt(m^2 + 1) < m + 1` for `m > 0`, so `lambda_+ < 1`. The lower root
`lambda_- = -m - sqrt(m^2 + 1)` is strictly less than `-1` because
`m + sqrt(m^2 + 1) > 1`.

Since `T_even(m)` is real symmetric, it is diagonalizable with those real
eigenvalues. Its square has eigenvalues `lambda_+^2` and `lambda_-^2`,
both non-negative.
