## Setup and definitions

All objects reuse the single-source-of-truth primitives in
[`scripts/frontier_s3_boundary_link_theorem.py`](./../scripts/frontier_s3_boundary_link_theorem.py)
(`cubical_ball`, `classify_vertices`, `analyze_2complex`).

**Cubical ball.** `B_R` is the union of all unit cubes whose 8 corners lie
within Euclidean distance `R` of the origin (`cubical_ball(R)`). A unit cube
has min-corner `c = (c1, c2, c3)` in `Z^3`. Its farthest-corner squared
distance from the origin separates over axes,

```text
Phi(c) = g(c1) + g(c2) + g(c3),     g(t) = max(t^2, (t+1)^2),       (MEM)
```

and the cube lies in `B_R` iff `Phi(c) <= R^2`. This is the sole membership
fact used; it is exact, integer, separable, and `R` enters only as the
constant `R^2` on the right.

**Kuhn / Freudenthal triangulation.** Each unit cube of `B_R` is split into 6
simplices, one per axis-permutation `pi`: the monotone lattice path
`c -> c + e_{pi(0)} -> c + e_{pi(0)} + e_{pi(1)} -> c + (1,1,1)`. This
subdivision is **globally coherent**: on any shared square face it places the
same min-to-max diagonal (fixed by the global lattice order, identical from
either incident cube). So adjacent cubes triangulate face-coherently with no
diagonal-convention choice, and the **same** simplicial `boundary(B_R)` is the
object that is coned and glued. Call the triangulated ball `K(B_R)`.

**Cone-cap (simplicial join).** `boundary(B_R)` is the set of triangles in
exactly one tetrahedron of `K(B_R)`. With a single new apex vertex `a`, the cap
is the simplicial join `a * boundary(B_R)`: its tetrahedra are
`{a} u t` for every boundary triangle `t`.

**Glued complex.** `M_R = K(B_R) u (a * boundary(B_R))`, the union of the two
along their common `boundary(B_R)`.

**Recognizers.** `analyze_2complex` is the canonical combinatorial recognizer
(verdict `S^2`: closed, connected, `chi = 2`, orientable, every vertex link a
cycle; verdict `disk`: connected, `chi = 1`, one boundary circle, integer
`H_1 = 0` via Smith Normal Form, every vertex link a 1-sphere or 1-arc). For
the large whole-surface `S^2` checks the runner uses a fast closed-surface
`S^2` recognizer that tests the **same** `S^2` conditions
(closed + connected + `chi = 2` + orientable + every vertex link a cycle)
without computing the integer-`H_1` Smith Normal Form that the `S^2` verdict
never reads; it is cross-checked equal to `analyze_2complex`'s `S^2` verdict on
`boundary(B_R)` for `R = 2, 3, 4`. The per-vertex **disk** verdicts keep the
full `analyze_2complex` recognizer.

## The all-`R` closure (three `R`-independent lemmas)

Throughout, `R` enters **only** as the inert threshold `R^2` in `(MEM)`; every
lemma's proof works verbatim for every `R`, and the finite runner is a
cross-check, never the basis of the all-`R` step.

### Lemma L1: `B_R` is a PL 3-ball, for all `R`

**Statement (`R`-free).** For every `R >= 2`, `K(B_R)` is a PL 3-ball.

`L1` factors into two `R`-free sub-statements.

**L1(a) -- star-shaped toward-origin cubical downset (`R`-free).** The
present-cube set `C(R) = { c : Phi(c) <= R^2 }` is a **downset** under the
per-axis "one step toward the origin" order (`c_i -> c_i - sign(c_i)`, no move
when `c_i = 0`). Because `Phi` is a sum of independent per-axis terms, a
toward-origin step on axis `i` changes membership only through the single term
`g(c_i)`, so it suffices to prove the `R`-free scalar monotonicity

```text
g(t - sign(t)) <= g(t)     for every integer t != 0.                  (MONO)
```

*Proof of (MONO).* `g(t) = max(t^2, (t+1)^2)` is a discrete "V" with continuous
minimum at `t = -1/2`; on integers `g(0) = g(-1) = 1`. For `t >= 1`,
`g(t) = (t+1)^2` and `g(t-1) = t^2 < (t+1)^2`. For `t <= -2`, `g(t) = t^2` and
`g(t+1) = (t+1)^2 < t^2`. For `t = -1`, the step to `0` gives `g(0) = 1 = g(-1)`
(the single flat step). So `(MONO)` holds for all integers `t != 0`. ∎

Hence if `c in C(R)` and `c_i != 0`, the stepped cube `c'` satisfies
`Phi(c') = Phi(c) - g(c_i) + g(c_i - sign(c_i)) <= Phi(c) <= R^2`, so
`c' in C(R)`. The argument never mentions `R` except as the inert bound `R^2`
preserved by a decrease of `Phi`; the geometric content is entirely in `(MONO)`.
The downset's per-axis minima sit at coordinate values `{0, -1}`, whose shared
corner is the lattice origin: "toward the smaller penalty" is "toward the
origin."

**L1(b) -- the Kuhn triangulation of any toward-origin cubical downset
collapses (`R`-free).** This is the load-bearing all-`R` step, and it is proven
**without** the open "star-shaped => collapsible" direction (Goodrick's
conjecture, open; Bing--Goodrick built non-collapsible balls; and `B_R` is
non-convex for `R >= 3`, so convex-ball collapse results do not apply).
Collapsibility comes from the **explicit discrete Morse matching** below with a
single critical cell and a strictly-monotone global key, **not** from "it is a
ball": star-shaped / contractible does **not** imply collapsible in general
(the Bing house), so the matching must genuinely have one critical cell for
every downset, which is what is established here.

*A-priori closure -- the to-origin discrete Morse matching (uniform in `D`).*
Fix **one** rule, defined identically for every finite star-shaped toward-origin
cubical downset `D` (no per-`D` enumeration, no freeze). Let
`kappa(c) = (sum_i near(c_i), #{i : c_i = -1}, c)` with
`near(t) = max(0, t, -(t+1))` be the strict radial **cube** key (`near(0) =
near(-1) = 0`); `kappa` is a strict total order on cubes whose **unique** minimum
on any downset is the central cube `c0 = (0,0,0)`. For a simplex `sigma` of
`K(D)`, let `intro(sigma)` be the `kappa`-minimum present cube whose closed cube
contains `sigma` (the first cube to carry `sigma` as cubes are added in
increasing `kappa`); the fibers `F_c = intro^{-1}(c)` **partition** the cells.
On the fiber of each cube `c` the matching `mu` is the elementary-collapse
matching of the **relative collapse** `Kuhn(c) ↘ A_c`, where
`A_c = Kuhn(c) ∩ K(D_{<c})` is the **attachment** (the cells of `c` already
introduced by an earlier cube). The global matching is
`mu(D) = ∪_c mu_c`. Three properties hold, each **uniform in `D`**:

- **(Valid).** `mu` is a valid partial matching (an involution `cell <->
  matched partner`; dimensions differ by exactly one). Immediate from the
  per-fiber relative collapses, which pair disjoint free faces with their unique
  cofaces.
- **(Single-critical = origin).** The fiber decomposition gives
  `critical(mu) = ∪_c critical(mu_c)`. For `c != c0`, `A_c` is a **nonempty**
  subcomplex that **contains `c`'s toward-origin corner** and onto which
  `Kuhn(c)` **relatively collapses**, consuming **all** of `F_c` -- **zero**
  critical cells in that fiber. (`A_c` is the union of the closed Kuhn faces of
  `c` shared with smaller-`kappa` present neighbours, all meeting the
  toward-corner -- a cone toward that corner; it need not be a union of *full
  square* facets, but it is always nonempty and `Kuhn(c)` collapses onto it,
  which is the load-bearing fact, verified below over the closed single-cube
  family.) The **unique** attachment-free cube is `c0 = (0,0,0)` (the only cube
  whose `kappa` is minimal and which has no forced toward-origin facet, and it
  lies in every nonempty downset); `mu_{c0}` collapses `Kuhn(c0)` onto its
  toward-origin corner, the lattice **origin** `(0,0,0)`, leaving exactly that
  one critical 0-cell. Total critical count `= 1` (`c0`) `+ 0` (every later
  cube) `= 1`, the origin.
- **(Acyclic, by a strictly-monotone global key -- one line, no enumeration).**
  The global key is `f(sigma) = kappa(intro(sigma))`. Along any gradient
  (`V`-path) step: **(H1)** matched pairs share `intro` (the relative collapse
  pairs only cells of one fiber), so `f` is **constant** on matched up-steps;
  **(M)** a regular (unmatched) down-step `sigma > tau` (`tau` a facet of
  `sigma`) never **raises** `f`, because the set of present cubes whose closed
  cube contains `tau` is a **superset** of those containing `sigma` (every cube
  containing `sigma` contains its face `tau`), so its `kappa`-minimum is no
  larger: `kappa(intro(tau)) <= kappa(intro(sigma))`. Hence along any `V`-path
  `f` never increases **and** matched steps never leave a fiber; a **closed**
  `V`-path can neither raise `f` nor cross fibers, so it lives inside a single
  fiber `F_c` -- but `mu_c` is an honest elementary-collapse sequence, which is
  acyclic. A closed `V`-path would force the strictly-decreasing key to return
  to its start: impossible. This is exactly the requested one-line
  strictly-monotone-global-function argument (cited comparators: the Cluster /
  Patchwork Lemma, Jonsson 2008 Lemma 4.2, cf. Hersh; the linear-extension
  matching, Chari 2000), holding on the explicit complex for **every** `D`.

**Single-criticality is a-priori, not a freeze.** The only step that looks
local-finite -- "`A_c` is a nonempty cone toward `c`'s toward-origin corner that
`Kuhn(c)` collapses onto" -- reduces to a **closed single-cube fact** about ONE
unit cube's 26-neighbour
shell, generated by **abstract** local downset rules (one family per cube
sign-class, **translation-invariant** in the actual coordinate), **not** by
enumerating realized attachments at growing radius. The companion runner
enumerates that finite abstract family exhaustively and verifies that on every
member `Kuhn(c)` relatively collapses onto `A_c` with zero extra critical cells
(and the attachment-free member collapses to the toward-corner); it then
verifies **reverse inclusion** -- every attachment realized by an actual downset
lies in the abstract family -- so the family **covers reality without sampling
it**. There is no "the type set stabilizes at `R_0`" step: the universe is the
unit cube's finite face lattice, an `R`-free constant. By Forman's theorem, an
acyclic matching with a **single** critical cell collapses the complex to a
point, so `K(D)` is **collapsible** for every toward-origin cubical downset `D`,
in particular `K(B_R)` at every `R`.

*Two prior `R`-free certificates (now cited comparators whose completeness
follows).* The earlier radial **shelling** (build-up collapse: order cubes by
`kappa`, each new cube `Kuhn(c)` collapses onto its smaller-key attachment
removing only interior cells, so `K(D' u {c}) ↘ K(D')`; the `2 x 2 x 2` central
block Kuhn-collapses to a point) and the earlier **min-vertex discrete Morse
field** (radial vertex order `vkey(v) = (|v|^2, v)`; the apex `v` absorbs its
descending link `dlk(v)`) both reach the same conclusion. Each was originally
completed by a **type-set freeze** (attachment-types freeze; descending-link
types freeze at `R_0 = 9`). Those certificates remain valid and are retained as
**cited comparators** in the cross-check runner, but their completeness now
**follows** from the a-priori closure above and no longer carries the all-`R`
force: the single-cube universe + reverse inclusion discharge "every cube's
attachment collapses" structurally, and the explicit greedy free-face collapse
the explicit-complex runner exhibits at small `R` is a **cross-check** of the
general matching, not its basis.

**Assembling L1.** `K(B_R)` is a finite PL 3-manifold-with-boundary (existing
exact certificate: no triangle in more than two tetrahedra; interior-vertex
links are combinatorial `S^2`; boundary-vertex links are 2-disks -- the latter
all-`R` via the companion boundary-link disk theorem, whose effective status
(`s3_boundary_link_theorem_note`) is owned by the audit lane). A collapsible
compact PL 3-manifold-with-boundary that is **full-dimensional** is a PL 3-ball
(cited comparator: J.H.C. Whitehead; cf. Rourke and Sanderson, *Introduction to
Piecewise-Linear Topology* -- the conclusion is supplied here by the explicit
a-priori collapse, not by invoking the theorem). Every `B_R` is
full-dimensional, so the gate is met; the L1(b) collapse itself holds for any
toward-origin downset (a thin / degenerate downset would still collapse to
`{origin}` but to a lower-dimensional ball -- correctly, since it is not a
3-manifold). The argument is **forward**: it collapses `B_R` from its
interior downset structure and **never references `boundary(B_R)`'s
sphericity**, so it does **not consume the hard PL Schoenflies** direction
(which is what "`boundary(B_R)` is a PL 2-sphere => `B_R` is a PL 3-ball" would
require, and which the all-R note flagged as unavailable for non-convex `B_R`,
`R >= 3`). None of L1(a), L1(b), or the manifold-with-boundary certificate
depends on `R`: each is a local combinatorial property whose verification rule
is identical for every radius, with `R` entering only as the membership cutoff
that selects which cubes exist. ∎ (L1)

### Lemma L2: `cone(boundary B_R)` is a PL 3-ball, for all `R`

**Statement (`R`-free).** Let `S` be **any** combinatorial PL 2-sphere and `a`
a fresh apex vertex. The simplicial cone (join) `C = a * S` is a PL 3-ball with
`boundary(C) = S`. Applied to Part A, `boundary(B_R)` is a PL 2-sphere for every
`R`, so `cone(boundary B_R)` is a PL 3-ball for every `R`.

*Proof (`R`-free; `R` appears nowhere -- the only input is the abstract "`S` is
a PL `S^2`" hypothesis, which Part A discharges uniformly in `R`).* The join
`C = a * S` is purely combinatorial. Four primitive facts the recognizer reads:

- **Apex link.** `lk(a, a * S) = S` (join link law). The apex link is the PL
  2-sphere `S`.
- **Base-vertex links.** `lk(v, a * S) = a * lk_S(v)` (join link law). Because
  `S` is a closed combinatorial 2-manifold, every `lk_S(v)` is a single
  1-cycle `C_n`; the cone over a cycle is the wheel `W_n` with `V = n+1`,
  `E = 2n`, `F = n`, hence `chi = 1`, a single rim boundary, integer
  `H_1 = 0` -- a 2-disk, for **every** `n`. So every interior vertex link of
  `C` is a 2-disk and the apex link is the 2-sphere `S`: `C` is a compact PL
  3-manifold-with-boundary (each base edge lies in exactly two base triangles,
  hence in exactly two cone tetrahedra).
- **Collapsibility to the apex.** The canonical join matching pairs each base
  simplex `s in S` with `s u {a}` and removes pairs in decreasing dimension of
  `s`; each `s` is free at its step (its only remaining coface is `s u {a}`).
  This is a valid sequence of elementary collapses landing on the apex `{a}`,
  for **any** base complex.
- **Boundary.** `boundary(C) = S`: the base triangles have degree 1 in `C`, the
  "wall" triangles `{a} u e` have degree 2; so the gluing 2-sphere is produced
  **by construction** as `boundary(C) = S`.

A collapsible compact PL 3-manifold-with-boundary is a PL 3-ball (cited
comparator: Whitehead; Rourke--Sanderson cone lemma). Equivalently and more
directly, the join of a PL 2-sphere with a point is a PL 3-ball
(Newman's / Alexander's cone theorem, cited as comparator), which the join
construction instantiates by construction. The cap is a ball **by
construction** (it is literally a cone), so the hard "an arbitrary embedded
2-sphere bounds a ball" direction is **not** used. **Base-agnosticity** is the
`R`-independence witness: the entire argument runs identically and passes on the
octahedron, icosahedron, and boundary-of-tetrahedron, proving it depends only on
the abstract `S^2` hypothesis, not on any metric / lattice property of `B_R`.
∎ (L2)

### Lemma L3: two PL 3-balls glued = PL `S^3`, for all `R`

**Statement (`R`-free).** Let `K1`, `K2` be combinatorial 3-balls with
`K1 ∩ K2 = boundary(K1) = boundary(K2) = S`, a combinatorial 2-sphere. Then
`M = K1 u_S K2` is a combinatorial 3-sphere. Applied with `K1 = K(B_R)` (a PL
3-ball by L1), `K2 = a * boundary(B_R)` (a PL 3-ball by L2), and
`S = boundary(B_R)` (a PL 2-sphere by Part A), `M_R` is a PL `S^3` for **every**
`R`.

*Proof (`R`-free; via the easy direction of Newman doubling).* The two-ball
decomposition is an **`R`-free set identity** forced by the join definition of
the cone-cap, with no cell counting:

```text
st(a, M)        = {tetrahedra of M containing a} = K2  (the cone-cap),
lk(a, M)        = {opposite faces}               = S   (the cone base),
M - int st(a)   = {tetrahedra not containing a}  = K1  (= K(B_R)),
K1 ∩ K2         = S   (the common boundary 2-sphere).
```

Each is an identity of sets that holds verbatim for every `R`. The three
inputs are `R`-free theorems: `S` is a PL `S^2` (Part A, all `R`), `K1` is a PL
3-ball (L1, all `R`), `K2 = a * S` is a PL 3-ball (L2, all `R`).

The conclusion now follows from the **easy direction of Newman doubling** --
**the union of two combinatorial 3-balls along their common combinatorial
2-sphere is a combinatorial 3-sphere** -- which reads no `R`, counts no cells,
and enumerates no vertex links. This is the cited comparator (Newman 1926); it
is reproven in the sense that the two balls and the gluing sphere are produced
constructively (the join + the L1 collapse data), so the doubling is applied to
explicit balls rather than asserted abstractly. The **hard** recognition
direction -- PL Schoenflies (an arbitrary embedded 2-sphere bounds a ball) and
PL Poincare (an arbitrary simply-connected closed 3-manifold is `S^3`) -- is
**not** used: both balls and the gluing sphere are produced by explicit join
and collapse data, and the sphere is read off the two-ball / cone **form**, not
from a "closed 3-manifold => `S^3`" inference.

The combinatorial-3-sphere criterion below is verified on the explicit glued
complex as a **structural cross-check** (each clause is a consequence of the
two-ball / cone form, not a per-`R` enumeration that grounds the all-`R`
claim):

- **(C-pm) Pseudomanifold.** Every 2-face of `M_R` is in exactly two
  tetrahedra. The interface is where the two balls' boundaries cancel: each
  boundary triangle has degree 1 in `K(B_R)` and degree 1 in the cone, summing
  to 2 -- a structural consequence of the two-ball form.
- **(C-link) Every vertex link is a combinatorial 2-sphere**, by vertex class:
  apex link `= boundary(B_R) = S^2`; interior `B_R` vertices `-> octahedral
  S^2`; boundary `B_R` vertices `-> ` their 2-disk link glued to the cone disk
  over the same boundary circle `= S^2` (the general `disk u_{circle} cone =
  S^2` identity, needing only that the `B_R` link is **some** 2-disk with that
  boundary circle).
- **(C-sc) Strong connectivity.** The dual graph on tetrahedra is connected
  (through the shared boundary `S`).
- **(C-euler) `chi(M_R) = 0`.** The Euler characteristic of `S^3`. This is a
  **cross-check only**, not sufficient alone: a 3-torus also has `chi = 0`, so
  the manifold content is carried by (C-pm), (C-link), (C-sc) -- and the
  `S^3`-vs-other-3-manifold content is carried by the two-ball / cone form via
  Newman doubling. ∎ (L3)

### The all-`R` conclusion

Part A (`boundary(B_R)` is a PL 2-sphere for all `R`) `+` L1 `+` L2 `+` L3, each
`R`-independent, give: **`M_R = B_R u cone(boundary B_R)` is a PL `S^3` for all
`R >= 2`.** No step of the chain leans on the finite runner for its all-`R`
force; the only `R`-dependence anywhere is the inert threshold `R^2` in `(MEM)`.
