## 3. Total Shell Space And Covariant Orbit Patch

Let `C` be the space of all complete six-neighbour conditions. Each slot is
either blank or contains one element of `M_2(C)`. Absence is an occupancy
case, not a readable matrix value.

Let `eta_*` be the exact Block-4 front shell. Its remote contexts `A` and `B`
give the same `eta_*`. Let `O_*` be the 24-element proper-cubic orbit of this
shell. For shells with the same occupancy pattern, use the squared
Hilbert--Schmidt distance to the closest orbit member,

\[
 D(\eta,O_*)=\min_{o\in O_*}\sum_{a:\,o_a\ne\bot}
              \|\eta_a-o_a\|_{HS}^2.                \tag{4}
\]

For a different occupancy pattern set the patch weight to zero. Otherwise

\[
 w(\eta)=\max\{0,1-D(\eta,O_*)/(1/64)\}.             \tag{5}

The finite minimum makes `w` Borel and invariant under the Block-4 proper-
cubic spatial slot action. It equals one on the exact orbit and is nonzero on
a genuine content neighbourhood; this is stronger than a singleton equality
trigger. Translation never enters because the rule reads relative neighbour
slots only. This block tests the spatial slot action; it does not claim or
execute an additional Pauli/unitary co-action on the `M_2(C)` contents.

Define the Hermitian condition-dependent center

\[
 H_\eta={1\over7}\left(k(\eta)I_2+
   \sum_{a:\eta_a\ne\bot}{\eta_a+\eta_a^\dagger\over2}\right), \tag{6}
\]

where `k(eta)` is the number of occupied neighbours. The normalized density

\[
 d\gamma_\eta(R)=\pi^{-4}
   e^{-\|R-H_\eta\|_{HS}^2}\,d^8R                  \tag{7}
\]

has full support on `M_2(C)`. Equation (7) is the product of eight normalized
one-dimensional Gaussians in Hilbert--Schmidt coordinates. Its center changes
with neighbour occupancy and content, so the rule genuinely varies with the
nearest-neighbour condition.

Every preloaded apparatus Record in the supplied initial state has a current
