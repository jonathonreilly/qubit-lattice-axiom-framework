## Claim

Let `Omega` be a finite sharp-record sample space with strictly positive
reference probability `P_0`. For a smooth probability path `P_h` with
`P_h << P_0`, define

```text
R_h := dP_h / dP_0,
s := d log R_h / dh |_{h=0}.
```

Then:

1. `E_0[s] = 0`.
2. The canonical quadratic form on the tangent space is

   ```text
   <s,t>_F := E_0[s t].
   ```

3. In probability-coordinate form, if `dp = dP_h/dh|_0`, then

   ```text
   s_i = dp_i / p_i,
   ||s||_F^2 = sum_i dp_i^2 / p_i.
   ```

4. Every zero-mean score `O` has the normalized positive exponential chart

   ```text
   R_h = exp(h O - W(h)),
   W(h) = log E_0 exp(h O),
   ```

   and its origin score is `O`.
5. For the two-outcome sharp signed record with uniform reference and
   `epsilon = (+1,-1)`, one has

   ```text
   E_0[epsilon] = 0,
   E_0[epsilon^2] = 1.
   ```

   Thus the primitive signed record is a Fisher-unit tangent, and
   `lambda epsilon` has norm `lambda^2`.

## Proof

Normalization gives `E_0[R_h]=1`, so differentiating at `h=0` gives
`E_0[s]=0`. If `dp_i = dP_h(i)/dh|_0`, then `R'_0(i)=dp_i/p_i`, hence
`s_i=dp_i/p_i`. The Fisher form is the second-order local quadratic form of the
RN chart:

```text
E_0[s^2] = sum_i p_i (dp_i/p_i)^2 = sum_i dp_i^2/p_i.
```

For the exponential chart, `W(h)` is exactly the scalar that enforces
normalization. Differentiating `log R_h = hO-W(h)` at the origin gives
`O - W'(0)`, and `W'(0)=E_0[O]=0` for zero-mean `O`.

The two-outcome signed-record calculation is immediate from the uniform
reference.
