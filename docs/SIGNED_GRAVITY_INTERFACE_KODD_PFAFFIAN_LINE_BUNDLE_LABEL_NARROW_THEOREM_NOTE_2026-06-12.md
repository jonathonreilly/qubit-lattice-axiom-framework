## Construction

The runner builds the native staggered cylinder exactly as specified:

```text
eta_x = 1, eta_y = (-1)^x
H = -i D
K = 2 asinh(sqrt(m^2 + H^2))
K_odd = (K - R Kbar R)/2
```

The step wall uses row centers `y + 1/2`, so
`phi(y) = +/- theta/Lx` is exactly odd under `y -> Ly - 1 - y`. The smooth
control uses the row-centered lattice version
`phi(y) = (theta/Lx) tanh(((y + 1/2) - Ly/2)/2)`, again exactly odd under the
same reflection.

The O-real basis is built from `eigh(R)`, multiplying the `R = -1` eigenvector
columns by `i`. In that basis `K_odd = i B`, and the runner tests that `B` is
real antisymmetric before any Pfaffian measurement is read.

The transported support policy is relative, not absolute:

```text
rank(theta) = #{ singular values s_j(B(theta)) with s_j / s_0 > 0.05 }.
```

The runner prints the measured gap bracketing this relative tolerance. This is
load-bearing: a fixed absolute cutoff near `1e-10` reproduces the known rank
jumps and remains a trap control.

At each theta, the raw SVD frame is treated as an unoriented subspace frame.
Before the polar Procrustes step, the runner flips one raw column if needed to
put the raw frame in the continuity orientation class of the previous
transported frame. These raw flips are reported separately as SVD gauge flips.
The actual transport event count is the determinant of the polar alignment
after this continuity choice.

Pfaffian signs are computed on the transported restricted real antisymmetric
matrix by real Schur blocks with the `det(Q)` correction:

```text
Pf(A) sign = sign(det Q * product_j T[2j, 2j+1]).
```
