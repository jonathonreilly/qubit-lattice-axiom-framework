# Parity-Grading Escape Dichotomy: Where a Signed Source Can Come From Without a New Pin

**Type:** bounded_theorem
**Claim type:** bounded_theorem
**Claim scope:** Three finite-dimensional results that, together,

signed (orientation-odd, nonzero-`eta`) source — and locate a
candidate escape **inside registered transfer-log-generator
structure**, so that no new admitted term ("pin") is required to keep
the lane open.

**(P1) General parity obstruction (closes two of the three named
routes at pure-staggered level).** Let `H` be any single-particle
Hermitian operator on a parity-graded site set (`p(x) =
(-1)^{sum x_mu}`) whose nonzero matrix elements connect **only
opposite-parity** pairs — nearest-neighbor hops on any subgraph of
`Z^d`: closed torus, open box, defect geometries, with arbitrary
complex couplings / U(1) backgrounds. Then `Gamma_5 H Gamma_5 = -H`
exactly, the spectrum is mirror-symmetric, and `eta_delta(H) = 0`
identically — no branch label is ever defined. In particular the
**manifold-with-boundary route is closed for parity-flipping-only
matter**, alongside the gauge-background route: of the retained
bulk-vanishing row's three named openings, only the
symmetry-breaking-mass route survives at this level.

**(P2) On-site mass is insufficient (orientation-even).** Adding any
uniform on-site term `m I` to a (P1)-class `H` produces nonzero
`eta_delta` (the spectrum shifts), but the asymmetry is
**orientation-even**: every lattice reflection that preserves the hop
class leaves `eta_delta` invariant, so the on-site mass cannot source
the orientation-odd `[+1, -1]` label pair. The escape therefore
requires **same-parity couplings** (support distance >= 2) with
momentum-dependent mass structure — the Wilson-type second difference
being the minimal sufficient realization (sister realization note,
plain-text pointer below).

**(P3) A no-pin escape candidate already exists.** The
registered transfer-log-generator structure is **not** in the (P1) class: the
logarithmic generator of a strictly-local positive transfer
(`H = -log T` for `T = e^{-A/2} e^{-B} e^{-A/2}` with `A, B` local)
generically contains **same-parity (distance-2) couplings** — its
Baker-Campbell-Hausdorff tails are exactly the terms (P1) forbids the
bare hop operator from having. The candidate source of the
symmetry-breaking structure is therefore a **registered transfer
log-generator structure**, not a new admitted term.
**Named open target (bounded here, to be derived later):** whether
the derived same-parity content realizes a gapped window with
orientation-odd coupling (the sister realization note's sufficiency
conditions). NOT claimed: that it does; the source action `S_int`;
any change to the proposal row.

The sister notes (plain-text pointers below) derive
the signed-source label mechanism from the retained `Cl(3,1)` grading
and realize the twist datum in the named Wilson-mass route — but the
Wilson-mass **term** is not part of the admitted matter carrier (pure

be admitted to keep a lane alive. This note does the no-pin work:

- it proves the obstruction is exactly a **parity-grading** fact, so
  the search space for escapes is sharply bounded (P1);
- it eliminates the cheapest would-be escape (on-site mass) on

## Statements and proofs

**(P1).** If every nonzero element of `H` connects opposite-parity
sites then, in the parity grading, `H` is block-off-diagonal, i.e.
`Gamma_5 H Gamma_5 = -H` exactly — regardless of the coupling values,
the background phases, the boundary conditions, or defects (the
property is per-element). If `H psi = lambda psi` then
`H (Gamma_5 psi) = -lambda (Gamma_5 psi)`: nonzero spectrum pairs,
`eta_delta = 0`, and the branch label (which requires
`eta_delta != 0`) is never defined. Geometry enters nowhere, so
closed tori, open boundaries, and defect graphs are all covered. ∎

*Scope remark.* This extends the pure-staggered (W0) statement of the
sister realization note from tori to arbitrary geometries: the
"manifold-with-boundary" opening named by the retained bulk-vanishing
row is **not** available to parity-flipping-only matter; it requires
the same symmetry-breaking content as everything else.

**(P2).** `m I` commutes with everything, so
`spec(H + m I) = m + spec(H)` with `spec(H)` mirror-symmetric;
`eta_delta(H + m I)` can be nonzero (it counts the levels crossed by
the shift). But let `R` be any lattice reflection mapping the site
set to itself and preserving the coupling class (the runner uses
`x -> L_x - 1 - x` on the defect-symmetric box, composed with complex
conjugation as the orientation-reversal implementation). Then
`R (H + m I) R^{-1}` (with the conjugation) has the same spectrum, so
`eta_delta` is **invariant** under orientation reversal: the
asymmetry is orientation-even. The signed source needs the
orientation-**odd** pair `chi(reversed) = -chi`; on-site mass cannot
produce it. Escapes must therefore add same-parity **couplings**
(distance >= 2), and to open a gapped labeled window they must be
momentum-dependent (the constant shift only translates the mirror
spectrum) — the Wilson-type second difference is the minimal
sufficient form, realized in the sister note. ∎

**(P3).** The derived generator `H_log = -log T` of the strictly
local transfer has the norm-convergent BCH structure whose
third-order terms are nested commutators of `A` and `B`; for the
witness family the Pauli expansion of `H_log` contains strings with
support on **both** ends of the chain (distance 2 — same parity),
with coefficient `~ 4.8e-2` at the witness couplings (runner,
recomputed exactly). A single-factor control (`T = e^{-A}`) gives
`H_log = A` exactly — **no** same-parity content — so the same-parity
couplings are generated precisely by the non-commuting composition,
i.e. by the same BCH tails the single-clock narrowing identified.
Hence this transfer-log-generator structure contains the coupling
class that (P1) requires and the bare hop operator lacks. ∎

*What (P3) does and does not buy.* It buys: the no-pin candidate —
any lane needing same-parity structure may target the registered
transfer log-generator rather than admitting a Wilson-mass term. It does NOT
buy: a gapped topological window, an orientation-odd coupling, or a
boundary tower; those are the named open derivation targets
(sufficiency conditions in the sister realization note).
