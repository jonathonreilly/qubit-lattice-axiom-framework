## Statements

**(T1) The retained sector swap carries orientation reversal.** In the
real `Cl(3,1)` algebra:

```text
    e_4 eps e_4^{-1} = -eps,
    e_4 (e_1 e_2 e_3) e_4^{-1} = -(e_1 e_2 e_3).
```

The first says the odd retained generator `e_4` exchanges the two
`eps`-sectors; the second says the same conjugation reverses the
boundary volume element. Hence **sector exchange = boundary
orientation reversal**: whatever boundary spectral data one sector
carries, the other carries its orientation image. (Pure Clifford
algebra: moving `e_4` through three anticommuting generators gives
`(-1)^3`.)

**(T2) Sector selection derives the opposite label pair.** The
boundary block `I (x) A(a) (x) eps` commutes with `Gamma_prod`, and on
the `eps = s` eigenspace (`s = +/-1`, sector dimension 2) it acts as
`s * A(a) (x) I_2`. Therefore

```text
    eta_delta^{(s)} = s * 2 * eta_delta(A(a)),
    chi_s := sign(eta_delta^{(s)}) = s * sign(eta_delta(A(a))),
```

i.e. the two sectors carry **opposite** labels, `(chi_+, chi_-) =
(+1, -1)` (for `a in (0, 1/2)`), from ONE twist datum. Consistently
with (T1), `-A(a)` is exactly the orientation image of `A(a)`
(`eta` of any `-U B U^dag` is `-eta(B)`, exact for the counting
regulator). The factor 2 is the sector dimension and drops out of the
sign.

**(T3) Quantized labels and branch conditions.** On the
spectrally-truncated twisted tower with the exact half-integer cutoff
family `Lambda in Z_{\ge 0} + 1/2`:

```text
    a in (0, 1/2)   : h_delta = 0, eta_delta = +1  -> chi = +1
    a in (-1/2, 0)  : h_delta = 0, eta_delta = -1  -> chi = -1
    a = 0           : h_delta = 1                  -> label undefined (gap fails)
    a = +/- 1/2     : eta_delta = 0                -> label undefined
```

The undefined cases are exactly the proposal's branch conditions
(`h_delta = 0` and `eta_delta != 0`), and the `a = 0` case is the
consistency leg with the retained bulk-vanishing row: the untwisted
(flat/mean-field) surface carries **no** label, matching
`eta_APS = 0` identically on the closed staggered torus.

For a general cutoff `Lambda = m + r`, `m in Z_{\ge 0}`, `0 <= r < 1`,
and `0 < a < 1/2`,

```text
    eta_delta(A(a)) = floor(Lambda - a) + 1 - floor(Lambda + a).
```

Equivalently, `eta_delta(A(a)) = 1_{r >= a} - 1_{r >= 1-a}`. Thus the
positive interval has the uniform label `+1` exactly when `r = 1/2`;
for a single fixed `a` the positive-label condition is `a <= r < 1 - a`.
The negative interval follows by reflection. This note claims the uniform
theorem only for `Lambda in Z_{\ge 0}+1/2`. Non-half-integer cutoffs are
excluded from the theorem surface rather than silently admitted.

**(T4) Coexistence with the Koide-side anticommutation (escape hatch

```text
    {D_gen (x) I (x) N,  Gamma_prod} = 0      (since {D_gen, G} = 0, [N, eps] = 0),
    [I (x) A(a) (x) eps, Gamma_prod] = 0      (sector selection),
    [D_gen, C_3] = 0                           (C_3-equivariance kept).
```

So one total Dirac simultaneously (i) anticommutes with the product

## Proof

**(T1).** `e_4 e_i = -e_i e_4` for `i = 1, 2, 3`. Moving `e_4`
through `e_1 e_2 e_3` gives `(-1)^3 = -1`, so
`e_4 (e_1 e_2 e_3) = -(e_1 e_2 e_3) e_4`, and conjugation flips the
sign. For `gamma_5 = (e_1 e_2 e_3) e_4`:
`e_4 gamma_5 e_4^{-1} = -(e_1 e_2 e_3) e_4 e_4 e_4^{-1} = -gamma_5`,
and `eps = i gamma_5` inherits the sign. `eps^2 = (i)^2 gamma_5^2 =
(-1)(-I) = +I`; `gamma_5` is real orthogonal with square `-I`, hence
skew (`gamma_5^T = gamma_5^{-1} = -gamma_5`), so `eps^dag = -i
gamma_5^T = i gamma_5 = eps`. ∎

**(T2).** `[A (x) eps, I (x) eps] = 0`, and on the `eps = s`
eigenspace `E_s` (dimension 2: `tr(eps) = 0`), `(A (x) eps)|_{E_s} =
s A (x) I_2`. The spectrum of `s A (x) I_2` is the tower `s(n + a)`
with multiplicity 2, so `eta_delta^{(s)} = 2 s eta_delta(A)` and the
sign follows. For the orientation image: if `B' = -U B U^dag` then
`spec(B') = -spec(B)` and the counting `eta` flips exactly. ∎

**(T3).** Spectral truncation keeps `lambda = n + a` with `|n + a| <=
Lambda`. For `a in (0, 1/2)`, positives are `n >= 0` with
`n <= Lambda - a` (`floor(Lambda - a) + 1` values), while negatives
are `n <= -1` with `n >= -Lambda - a` (`floor(Lambda + a)` values).
Hence `eta_delta(A(a)) = floor(Lambda - a) + 1 - floor(Lambda + a)`.
Writing `Lambda = m + r`, `0 <= r < 1`, this is equivalently
`eta_delta = 1_{r >= a} - 1_{r >= 1-a}`. It equals `+1` throughout
`a in (0, 1/2)` exactly for the canonical half-integer cutoff family
`Lambda in Z_{\ge0}+1/2`; for a single fixed positive twist, the exact
condition is `a <= r < 1-a`. The map `a -> -a` flips the spectrum,
giving the negative interval. At `a = 0` the `n = 0` eigenvalue sits
in the `delta`-window (`h_delta = 1`). At `a = 1/2` and half-integer
`Lambda`, the spectrum is reflection-symmetric, so `eta_delta = 0`.
The runner checks the floor formula, the half-integer family, and
explicit excluded non-half-integer counterexample cutoffs, plus the
index-truncation falsifier. ∎

**(T4).** Factor-wise: `(D_gen (x) N)(G (x) eps) + (G (x) eps)(D_gen
(x) N) = (D_gen G) (x) (N eps) + (G D_gen) (x) (eps N) = (D_gen G +
G D_gen) (x) (N eps) = 0` using `[N, eps] = 0` then `{D_gen, G} = 0`.
The boundary block commutes with `Gamma_prod` since each tensor slot
commutes. Hermiticity: `D_gen (x) N` is (antisym)x(antisym) =
symmetric real; `A (x) eps` is Hermitian; the two parts commute via
`[N, eps] = 0`. ∎
