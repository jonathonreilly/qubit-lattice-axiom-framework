## Target

The signed-gravity source-action row is blocked at the origin of

```text

```

The product-grading eta-sector bridge already supplies an important half of
the story: an odd sector involution `Gamma_prod` and the opposite label pair

> Once the product grading exists, is the scalar source action forced to use

The answer is no in a narrow, checkable sense. The product grading gives the
label carrier; the active source action still needs a source-line / section
activation rule.

## Statement

Work in the finite two-sector scalar-source class generated by the identity
and the product grading:

```text
C = a I + b Gamma,          Gamma = diag(+1,-1).
```

For a positive normalized density `rho`, positive mass `M`, and scalar field
`Phi`, consider linear weak-field source terms

```text
S_C = - M <rho, Phi> C.
```

Variation gives the sector source vector

```text
J_C = M (a+b, a-b).
```

Then:

1. **Even scalar source class.** The orientation-exchange operator `R` with
   `R Gamma R^-1 = -Gamma` fixes only the identity direction. If the scalar
   source coefficient is orientation-even (`R C R^-1 = C`), then `b=0` and
   `J_C` is proportional to `[+1,+1]` or `[0,0]`.
2. **Odd source-line class.** The desired source vector `[+1,-1]` is the
   unique odd direction: it requires `a=0`, `b=1`, i.e. the coefficient
   `Gamma`.
3. **Locking.** Source-only or response-only use of `Gamma` fails the mixed
   pair action-reaction table. The locked table appears only when the same
   odd coefficient is used on both source and response.

So the product grading does not need a new sign axiom to provide the label
pair, but it also does not by itself derive the scalar interaction. The
remaining missing premise is precisely the activation of the odd orientation
line as an active source/response coefficient.

## Proof

In the basis where `Gamma = diag(+1,-1)`, every coefficient in the stated
class is `aI + bGamma`. Conjugation by the sector-exchange matrix

```text
R = [[0,1],[1,0]]
```

sends `Gamma` to `-Gamma` and leaves `I` fixed. Hence the invariant subspace is
`span{I}` and the odd subspace is `span{Gamma}`.

The finite-difference variation of `S_C` gives the diagonal sector entries of
`C` multiplied by `M rho`, hence integrated active source
`M(a+b, a-b)`. Solving `M(a+b, a-b) = M(1,-1)` gives `a=0`, `b=1`.
Solving the same target over the even/spectator basis has nonzero residual.

The runner verifies these equations directly, then replays the four-pair
table:

| source coefficient | response coefficient | table |
|---|---|---|
| `I` | `I` | fail: all pairs attract |
| `Gamma` | `I` | fail: mixed pairs unbalanced |
| `I` | `Gamma` | fail: mixed pairs unbalanced |
| `Gamma` | `Gamma` | pass: same-sector attract, opposite-sector repel |
