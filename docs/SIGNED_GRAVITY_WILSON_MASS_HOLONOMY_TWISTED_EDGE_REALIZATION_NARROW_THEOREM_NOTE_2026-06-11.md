## Statements

**(W0) Pure staggered: no twist datum on any closed background.** For
every U(1) background and every even `L`:

```text
    { Gamma_5, H_stag } = 0      exactly,
```

since every term of `H_stag` hops one site (parity flip) and the link
phase multiplies both the hop and its conjugate symmetrically. Hence
`spec(H_stag)` is mirror-symmetric (`lambda <-> -lambda` via
`Gamma_5`), `eta_delta(H_stag) = 0` identically, and the branch label
is never defined. The retained mean-field vanishing row is the
free-background special case; the containment scan's negative finding
is structural. (This is the sister bridge note's mirror-spectrum
falsifier (F1) operating natively: the staggered parity grading IS a
full anticommuting grading for every background.)

**(W1) Wilson-mass route: the twist datum exists, with the holonomy as
the twist.** On the Wilson-mass cylinder in the gapped window, the
in-gap edge sector of each boundary is sharply localized (runner:

```text
    theta = 0      : h_delta = 1 on each edge     -> label undefined (gap fails)
    theta in (0,pi): chi_bottom = +1, h_delta = 0 -> defined, quantized
    theta in (-pi,0): chi_bottom = -1             -> defined, quantized
    theta = pi     : eta_delta = 0 on each edge   -> label undefined
```

The label is stable under lattice growth (`L_x = 20 -> 40`: the edge

**(W2) Orientation pairing.** At every `theta`, the two boundary

```text

```

the geometric realization of the sector/orientation pair (the two

**(W3) Load-bearing controls.** In the trivial window (`m = +1`) the

## Proof

`t_b c^dag_{x'} c_x + conj(t_b) c^dag_x c_{x'}` with `x, x'` nearest
neighbors. In the single-particle matrix, every nonzero entry connects
sites of opposite `(-1)^{x_1+x_2}` parity, for any values of the
`t_b`. Therefore the matrix is block-off-diagonal in the
`Gamma_5`-grading, i.e. `Gamma_5 H Gamma_5 = -H` exactly. If
`H psi = lambda psi` then `H (Gamma_5 psi) = -lambda (Gamma_5 psi)`,
so nonzero eigenvalues pair and `eta_delta = 0`. ∎

**(W1)/(W2)/(W3).** Finite-dimensional spectral computation on the
