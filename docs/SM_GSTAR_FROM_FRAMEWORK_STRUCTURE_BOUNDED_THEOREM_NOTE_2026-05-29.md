3 * [ 24 + 4 + 2 ] = 3 * 30 = 90`. The runner repeats both factorisations with

## 5. Counterfactual pass (run before authoring)

Per `feedback_run_counterfactual_before_compute`, the implicit choices were
exercised before authoring. Each is marked CLOSED (settled by a retained
framework result or by an explicit regime declaration) or OPEN (residual).

1. **Thermal regime (high-T unbroken vs post-EWSB massive).** If the broken
   phase were counted, massive `W^+, W^-, Z` use `4 - 1 = 3` polarizations and
   the Higgs eaten-Goldstone bookkeeping moves 3 scalar dof into the
   longitudinal vectors; the bosonic total stays `28` but the sourcing changes.
   The cascade consumer fixes `T > 250 GeV`, so we count massless gauge-group
   dof (`2` pol) and `4` Higgs scalar dof. **CLOSED by explicit regime
   declaration (I11);** the regime is an honest import, not framework-derived.

2. **Massless-vector polarization count (`2` vs other).** A count `!= 2` breaks
   the `28` bosonic total (`24 -> 36` at `3` pol). The `2` rests on the rank
   arithmetic `4 - 1 - 1 = 2` of the massless-vector narrow theorem, which
   **admits the Lorentzian R^{3,1} signature** as standard relativistic-QFT
   context. The framework's emergent-Lorentz derivation is **currently under
   repair**. **OPEN (R-POL):** bounded narrow identity over admitted signature,
   not a fully framework-derived count, until emergent-Lorentz lands.

3. **Neutrino sector (LH-only Weyl / Dirac / Majorana / RH-present).** The most
   load-bearing fermionic choice. LH-only active neutrino (chosen): `2` dof per
   generation -> per-gen `30` -> fermionic `90`. Dirac with thermalized `nu_R`:
   `4` dof per generation -> per-gen `32` -> fermionic `96` -> `g_* = 28 +
   (7/8) * 96 = 112`. The framework anomaly content **includes** `nu_R: (1,1)_0`
   as a gauge singlet, but `nu_R` carries no SU(3) / SU(2) / U(1)_Y charge, so at
   the leptogenesis temperature it need not be in thermal equilibrium. The
   chosen inventory counts only the LH active neutrino. **OPEN (R-MATTER /
   I12):** the `nu_R` thermal exclusion is a sector premise; the neutral-singlet
   branch convention `Y(nu_R) = 0` is itself a convention in the matter-closure
   note. This is the single most important honest caveat — if `nu_R` were
   thermalized Dirac, `g_* = 112` not `106.75`.

4. **One Higgs doublet vs more.** A second complex doublet adds `4` scalar dof
   (`28 -> 32 -> g_* = 110.75`). The gauge-selection and EW-mass notes work
   *given* one doublet but do not derive single-doublet minimality; the repo's
   two-Higgs no-gos foreclose specific DM-sector slot constructions, not a
   general minimality theorem. **OPEN (R-HIGGS):** single complex doublet is a
   named residual.

5. **Color count `N_c = 3` + `dim adj 8`.** `N_c != 3` rescales the quark dof
   (`24 = 2 N_c * 4`) and gluon dof (`2(N_c^2 - 1)`). **CLOSED by retained
   framework result** (`CL3_COLOR_AUTOMORPHISM_THEOREM`).

6. **Generation count `n_gen = 3`.** `n_gen != 3` rescales the fermionic total
   linearly. **CLOSED by retained framework result** (three-generation
   observable + M_3(C) Burnside).

7. **Fermion thermal weight `7/8`.** A different statistical weight changes the
   combination. The *ratio* `7/8 = eta(4)/zeta(4)` is **CLOSED (retained);** the
   full substrate fermionic-SB derivation is **OPEN (R-FSB).**

**Counterfactual conclusion.** Color count, generation count, the `7/8` ratio,
and the SU(3)/SU(2) sectors are CLOSED by retained framework results. The
thermal regime is CLOSED by an explicit (honest) regime declaration. The OPEN
