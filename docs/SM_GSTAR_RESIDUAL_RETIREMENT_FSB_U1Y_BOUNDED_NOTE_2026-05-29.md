## 1. R-FSB — fermion thermal weight `7/8`

### 1.1 What `g_*` consumes

The census arithmetic uses the fermion/boson Stefan-Boltzmann **ratio**

```text
w_F  =  7/8
```

as a pure rational multiplier on the fermionic dof count
(`g_* = N_bosons + w_F * N_fermions`). It does **not** use the full substrate
fermionic Stefan-Boltzmann energy-density law `u_F = (7/8) u_B` per mode, nor
its derivation, nor any absolute energy density. Only the dimensionless rational
`7/8` enters the dof count.

### 1.2 Retained source of the `7/8` ratio

The ratio `7/8` is the content of the **retained** positive theorem
[`HIERARCHY_SEVEN_EIGHTHS_RIEMANN_DIRICHLET_DIMENSIONAL_ANCHOR_NARROW_THEOREM_NOTE_2026-05-10.md`](HIERARCHY_SEVEN_EIGHTHS_RIEMANN_DIRICHLET_DIMENSIONAL_ANCHOR_NARROW_THEOREM_NOTE_2026-05-10.md)
(ledger `effective_status: retained`, `claim_type: positive_theorem`, verified
against `docs/audit/data/audit_ledger.json` on 2026-05-29). That theorem proves
two independent identities that each land on `7/8` at `d = 4`:

**(i) Per-mode lattice ratio.** With `c = d − 1`,

```text
R_lat(c)  =  (c + 1/2) / (c + 1)  =  1 − 1/(2(c + 1)),
```

so at `c = 3` (`d = 4`), `R_lat(3) = (3 + 1/2)/(3 + 1) = (7/2)/4 = 7/8`.

**(ii) Riemann-Dirichlet quotient.** For real `s > 1`,

```text
η(s) / ζ(s)  =  1 − 2^(1 − s),
```

so at `s = 4`, `η(4)/ζ(4) = 1 − 2^(−3) = 1 − 1/8 = 7/8`.

The retained theorem further proves these two values coincide on `7/8` at no
integer `d ≥ 2` other than `d = 4` (the integer alignment equation
`2^(d − 2) = d` has its unique solution at `d = 4`). The fermion thermal weight
the `g_*` census consumes is exactly this retained rational.

### 1.3 What stays separately blocked (not needed by `g_*`)

The full substrate fermionic Stefan-Boltzmann law lives in
`AXIOM_FIRST_FERMIONIC_STEFAN_BOLTZMANN_NARROW_THEOREM_NOTE_2026-05-26.md`
(ledger `effective_status: unaudited`). That note is a **stronger** statement —
it asserts the full per-mode fermionic energy-density law, and is blocked on the
unaudited Wightman-reconstruction chain (KMS condition, spectrum condition,
spin-statistics, anomaly-forces-time, Lorentz kernel — all currently
unaudited). It is **not** tractable in isolation. But the `g_*` dof-count never
consumes the energy-density law; it consumes only the dimensionless `7/8`
ratio, which is the retained anchor's content. R-FSB is therefore retired **for
the `g_*` dof-count purpose** to a retained source; the full fermionic-SB law
remains a separate, stronger, separately-blocked target that `g_*` does not
require.

## 2. R-U1Y — U(1) gauge degree-of-freedom count

### 2.1 What `g_*` consumes

The census arithmetic uses, for the abelian gauge sector, two facts and nothing
more:

1. **exactly one** abelian (rank-1) gauge factor exists in the unbroken-phase
   gauge group, contributing `1` gauge generator (one massless vector); and
2. that one massless vector carries `2` transverse polarizations,

giving `1 * 2 = 2` abelian gauge degrees of freedom in `N_bosons`. The
`g_*` dof-count does **not** consume the hypercharge **values** (the `+1/3`,
`−1`, ... eigenvalue assignment), nor the anomaly-complete `U(1)_Y`
identification, nor electric charge. The dof count needs only the **rank** —
the number of abelian gauge factors, which is one.

### 2.2 Retained source of "exactly one abelian factor"

The existence of **exactly one** abelian gauge factor is the content of the
retained gauge-closure structure. The note
[`NATIVE_GAUGE_CLOSURE_NOTE.md`](NATIVE_GAUGE_CLOSURE_NOTE.md) (ledger
`effective_status: retained`, `claim_type: positive_theorem`) carries, via its
retained graph-first `SU(3)` dependency
[`GRAPH_FIRST_SU3_INTEGRATION_NOTE.md`](GRAPH_FIRST_SU3_INTEGRATION_NOTE.md)
(ledger `effective_status: retained`, `claim_type: positive_theorem`), the
joint-commutant decomposition

```text
Comm( su(2)_weak , residual swap )  ≅  gl(3) ⊕ gl(1),
```

with compact semisimple part `su(3)`. The `gl(3)` semisimple part is the color
sector; the single `gl(1)` summand is **exactly one** abelian (rank-1) factor.
The commutant of a single abelian factor has rank `1`, so the abelian gauge
content is one generator → one massless vector. This rank-1 abelian-factor
count is retained structural content (it is what the retained runner
[`scripts/frontier_graph_first_su3_integration.py`](../scripts/frontier_graph_first_su3_integration.py)
verifies via the `3 ⊕ 1` block split: a 9-dimensional symmetric/semisimple

Combining the `2`-transverse-polarization count for a massless vector (R-POL,
