## Theorem (conditional triangulation convergence)

Let the one-generation anomaly-allowed family be (doubled-`Y` convention,
`Q = T_3 + Y/2`), as a function of color rank `N_c`:

```text
Y(Q_L) = 1/N_c,   Y(L_L) = -1,
Y(u_R^c) = -(1 + 1/N_c),   Y(d_R^c) = (1 - 1/N_c),
Y(e_R^c) = 2,   Y(nu_R^c) = 0.
```

**(1) Looseness of the anomaly-family row.** The four perturbative trace combinations
(`grav-U(1)`, `U(1)^3`, `SU(2)^2 U(1)`, `SU(N_c)^2 U(1)`) vanish for this family
at `N_c = 3, 5, 7` (and all odd `N_c >= 3` under Witten parity). Hence anomaly
cancellation alone does not select `N_c`.

**(2) Independent collapse.** The graph-first `su(3)` integration row fixes
`N_c = 3` by graph topology; the Burnside three-generation row fixes
`n_gen = 3` by finite matrix algebra. Both have `deps = []`, sharing no
lineage with the anomaly-family row.

**(3) Convergence.** Substituting `N_c = 3` into the family yields the
right-handed singlet particle hypercharges `(u_R, d_R, e_R, nu_R) =
(+4/3, -2/3, -2, 0)`, identical to the unique tuple of
hypercharge-uniqueness enumeration row, with `Y(Q_L) = +1/3` and
`Y(L_L) = -1`. The left-Weyl carrier electric-charge spectrum is
`{0, ±1/3, ±2/3, ±1}`.

**(4) Residual freedom.** Multiplying every hypercharge by a nonzero rational
`λ` preserves all four anomaly traces (verified at `λ = 7/5`), so the absolute
normalization residual is genuinely free; the template residual is an explicit
hypothesis of the hypercharge-enumeration row. ∎
