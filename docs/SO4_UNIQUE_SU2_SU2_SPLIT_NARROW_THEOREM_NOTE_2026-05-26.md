matrices with Lie bracket the matrix commutator, for any integer


## 5. Proof

The argument is direct Lie-algebra classification.

### 5.1 (S1) Dimension formula

The real vector space of `d × d` skew-symmetric matrices is the kernel
of the symmetrization operator on `M_{d×d}(R)`, dimension
`d² - d(d+1)/2 = d(d-1)/2`. This is the standard linear-algebra
dimension formula for skew-symmetric matrices.

### 5.2 (S2) Small-`d` degeneracies

For `d ∈ {0, 1}`: `so(d) = 0` since `d(d-1)/2 = 0`.

For `d = 2`: `so(2) = span(J)` where `J = ((0, -1), (1, 0))` is the
canonical generator of plane rotations. Since `dim so(2) = 1`, the
Lie bracket on `so(2)` is identically zero (any 1-dim Lie algebra is
abelian). Hence `so(2) ≅ R ≅ u(1)`, abelian.

### 5.3 (S3) Simplicity of `so(d)` for `d ≥ 3`, `d ≠ 4`

By the Cartan classification of compact simple real Lie algebras
(Helgason, Ch. X; Knapp, Ch. VI; Fulton-Harris, Ch. 17), the compact
real Lie algebras `so(d)` for `d ≥ 3`, `d ≠ 4` are simple. Concretely:

- `so(3)` is simple, `≅ su(2)`, with Cartan label `B_1 = A_1`.
- `so(5)` is simple, `≅ usp(4)`, with Cartan label `B_2 = C_2`.
- `so(6)` is simple, `≅ su(4)`, with Cartan label `D_3 = A_3`.
- `so(7)` is simple, with Cartan label `B_3`.
- `so(d)` for `d ≥ 7` odd is simple of type `B_{(d-1)/2}`.
- `so(d)` for `d ≥ 8` even is simple of type `D_{d/2}` (with the
  caveat that `D_2 = A_1 + A_1` is reducible — see Step 5.4).

The simplicity of each of these is a standard theorem in compact
Lie-algebra classification. No internal framework derivation is
required; we cite the classification as admitted-context mathematical
infrastructure.

### 5.4 (S4) `so(4) ≅ su(2)_L ⊕ su(2)_R`

The Lie algebra `so(4)` has dimension 6. There are several equivalent
constructions of the `su(2) ⊕ su(2)` split; we use the Plücker / Hodge
self-dual decomposition of 2-forms on `R^4`.

Let `(e_1, e_2, e_3, e_4)` be the standard orthonormal basis of `R^4`.
Identify `so(4) ≅ Λ^2(R^4)` (antisymmetric `4 × 4` real matrices
`A_{μν} = -A_{νμ}` correspond to 2-forms via `A ↦ ∑_{μ < ν} A_{μν}
e^μ ∧ e^ν`). The 6-dimensional space `Λ^2(R^4)` carries the Hodge star
operator `* : Λ^2(R^4) → Λ^2(R^4)` defined by

```text
(*omega)_{μν}  :=  (1/2) ε_{μνρσ} omega^{ρσ},
```

with `ε_{μνρσ}` the totally-antisymmetric symbol normalized so
`ε_{1234} = +1`. On `Λ^2(R^4)` with Euclidean signature,
`*² = +I` (the operator squared is the identity), so `*` has
eigenvalues `±1`. The eigenspaces

```text
Λ^+(R^4)  :=  { omega ∈ Λ^2(R^4) :  *omega = +omega }    (self-dual)
Λ^-(R^4)  :=  { omega ∈ Λ^2(R^4) :  *omega = -omega }   (anti-self-dual)
```

each have real dimension 3, and `Λ^2(R^4) = Λ^+(R^4) ⊕ Λ^-(R^4)` is
an orthogonal direct-sum decomposition. Explicit bases:

```text
Λ^+ basis:  η^+_1 := e^1 ∧ e^2 + e^3 ∧ e^4,
            η^+_2 := e^1 ∧ e^3 - e^2 ∧ e^4,
            η^+_3 := e^1 ∧ e^4 + e^2 ∧ e^3;

Λ^- basis:  η^-_1 := e^1 ∧ e^2 - e^3 ∧ e^4,
            η^-_2 := e^1 ∧ e^3 + e^2 ∧ e^4,
            η^-_3 := e^1 ∧ e^4 - e^2 ∧ e^3.
```

The Lie bracket on `so(4) ≅ Λ^2(R^4)` is computed via the matrix
commutator after re-expressing 2-forms as skew matrices `A_{μν}`. By
direct sympy computation (companion runner), one verifies:

- Each `η^±_i` is a skew matrix on `R^4` after re-identification.
- `[η^+_i, η^+_j] = c_+ · ε_{ijk} η^+_k` with `c_+ = -2` (overall
  scalar from the unit-coefficient sum normalization of each `η^+`;
  the sign reflects a Plücker-basis orientation convention). The
  bracket closes within `span{η^+_0, η^+_1, η^+_2}` and the structure
  constants are antisymmetric in `(i, j)` and proportional to
  `ε_{ijk}`, hence isomorphic to the `su(2)` bracket up to overall
  scalar rescaling (so isomorphic as Lie algebras).
- `[η^-_i, η^-_j] = c_- · ε_{ijk} η^-_k` with `c_- = -2`, an
  independent `su(2)` copy with the same convention sign.
- `[η^+_i, η^-_j] = 0` for all `i, j` (mutual commutativity).

These three properties together establish that
`{η^+_1, η^+_2, η^+_3}` spans a 3-dim Lie subalgebra isomorphic to
`su(2)`, that `{η^-_1, η^-_2, η^-_3}` spans an independent 3-dim Lie
subalgebra isomorphic to `su(2)`, and that the two subalgebras
mutually commute. Since the union of their bases spans the full
`6`-dim space `Λ^2(R^4) ≅ so(4)`, we have the direct-sum decomposition
(★):

```text
so(4)  =  Λ^+(R^4) ⊕ Λ^-(R^4)  ≅  su(2) ⊕ su(2).
```

This decomposition is the Lie-algebra-level statement of the
classical accidental isomorphism `Spin(4) ≅ SU(2) × SU(2)`.

### 5.5 (S5) Uniqueness

Combining (S1)-(S4):

- For `d ∈ {0, 1}`: `so(d) = 0`, no simple ideals.
- For `d = 2`: `so(d)` abelian, no simple non-abelian ideals.
- For `d = 3` and `d ∈ {5, 6, 7, ...}`: `so(d)` is simple, so any
  ideal is either `0` or all of `so(d)`. Hence `so(d)` cannot be a
  direct sum of two nonzero simple non-abelian ideals (this would
  contradict simplicity).
- For `d = 4`: by (S4), `so(4) ≅ su(2) ⊕ su(2)` is a direct sum of
  two nonzero simple non-abelian ideals.

Hence among all `d ∈ {2, 3, 4, 5, ...}`, exactly `d = 4` realizes the
decomposition property. QED.
