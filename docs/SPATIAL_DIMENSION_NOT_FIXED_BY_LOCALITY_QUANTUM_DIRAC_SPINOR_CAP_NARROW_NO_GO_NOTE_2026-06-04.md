## Statement

Let each site carry the qubit `M_2(C)` (Quantum) on a discrete
near-neighbour lattice (Locality). Then:

1. (**NG — the no-go.**) `{Locality, Quantum}` do **not** fix `d_s`. For
   every integer `d` there is a local qubit model on `Z^d`: the Ising model
   `H = sum_<x,y> sigma_3^x sigma_3^y` couples nearest neighbours in all `d`
   directions using the **same** on-site bond operator `sigma_3`. The
   directions are distinguished by the **graph** (which neighbour), not by
   the on-site algebra, and the bonds commute (`[sigma_3, sigma_3] = 0`), so
   there is **no algebraic cap** on `d`. The qubit's three observables do
   not constrain the lattice dimension.

2. (**CAP — the conditional cap.**) Suppose instead the dynamics demands an
   **anticommuting spatial frame**: each direction `mu` carries a distinct
   Hermitian generator `gamma_mu` with `{gamma_mu, gamma_nu} = 2 delta_{mu
   nu}` (a Dirac / relativistic kinetic term). On a 2-component spinor (the
   qubit) the maximal such frame has exactly **3** elements — only `M = 0`
   anticommutes with all of `sigma_1, sigma_2, sigma_3` (no fourth axis).
   Hence

   ```text
   d_s <= 3   (for a 2-component Dirac/Weyl spinor).                (CAP)
   ```

3. (**WEYL — the maximal realization.**) The maximal case is the
   2-component **Weyl** spinor of 3+1 dimensions: the massless equation
   `i sigma^mu d_mu psi = 0` with `sigma^mu = (I, sigma_1, sigma_2,
   sigma_3)`, whose three **spatial** gammas are exactly the Paulis. Then
   `d_s = 3`.

4. (**SIZE — the cap is set by the spinor size.**) A 4-component spinor
   admits a 4-element anticommuting Hermitian frame
   (`alpha_i = sigma_1 (x) sigma_i`, `beta = sigma_3 (x) I`), impossible at
   `n = 2`. So `d_s <= 3` is **specific to choosing the 2-component (qubit)
   spinor** — i.e. specific to the matter dynamics, not to `{Locality,
   Quantum}`.

5. (**CONS — the consequence.**) `d_s = 3` follows from `{qubit}` **plus**
   the relativistic-matter structure that realizes the qubit as a 2-spinor
   Dirac/Weyl field (clauses CAP, WEYL). That structure is an admitted gate
   (the staggered-Dirac realization). Therefore `d_s = 3` is **downstream of
   the matter-dynamics admission**, not a theorem of `{Locality, Quantum,
   Record}`.

## Proof

Pure finite-dimensional algebra on the Pauli generators; reproduced at exact
precision by the runner.

### NG. `{Locality, Quantum}` do not fix `d_s`.

The `d`-dimensional Ising model `H = sum_<x,y> sigma_3^x sigma_3^y` on `Z^d`
is, for every `d`, a translation-invariant near-neighbour Hamiltonian of
qubits — it satisfies Locality and Quantum verbatim. The bond operator is
`sigma_3` in every direction; on a single site these reuse one operator, and
`[sigma_3, sigma_3] = 0`, so no anticommutation/independence constraint
limits how many directions exist. The lattice dimension is a property of the
graph, on which the qubit imposes nothing. (Runner A, A2.)

### CAP. An anticommuting frame on a 2-spinor caps at 3.

If each direction carries a distinct Hermitian `gamma_mu` with
`{gamma_mu, gamma_nu} = 2 delta_{mu nu}`, the `gamma_mu` are mutually
anticommuting traceless Hermitian elements of `M_2(C)`. The only matrix
anticommuting with all of `sigma_1, sigma_2, sigma_3` is `0` (the linear map
`M -> ({M, sigma_i})_i` has trivial kernel, rank 4), so the maximal frame
has exactly 3 elements. (Runner B.)

### WEYL / SIZE.

`sigma^mu = (I, sigma_1, sigma_2, sigma_3)` gives the 3+1D Weyl operator;
the spatial part satisfies the Euclidean Clifford relations (runner C). A
4-component spinor admits a 4-element anticommuting Hermitian frame (runner
D), so the cap is set by the spinor size — the qubit being a 2-spinor is the
dynamical choice, not an axiom. QED.
