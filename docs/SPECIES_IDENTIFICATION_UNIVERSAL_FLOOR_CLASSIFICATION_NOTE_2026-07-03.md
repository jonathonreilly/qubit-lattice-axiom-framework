## Purpose

This note prepares the governance question left open by the species-bridge
parent: whether AC_phi_lambda(iii), the abstract-sector to physical-species
identification, belongs with universal-floor inputs beside the past hypothesis
rather than inside the framework-specific admitted derivation-target bucket.

The classification claim prepared for the owner is narrow: at the C3-structural
grade, the species identification has the same universal abstract-to-physical
shape as ordinary gauge-theory species naming and carries no tested C3-grade
number, selector, ordering, or weight. If the owner accepts the past-hypothesis
precedent as the universal-floor standard, this identification is a candidate
for the same bucket. The note itself does not make that ruling.

## Leg 1 — The Universal-Floor Test

The arrow note states the test in the past-hypothesis case:

> "This open input is **universal-floor**: every theory with time-symmetric microdynamics (CM, QM, QFT, GR) needs the same boundary input for a thermodynamic arrow. It is **not** a framework-specific gap."

The same arrow note names the registry placement it is using:

> "`ADMITTED_INPUT_REGISTRY_TIER_A_NOTE_2026-05-23.md` — the central admitted- input registry; the past hypothesis sits with the universal-floor admissions (scale reference / strong-CP-style shared problems), not the framework-specific Tier A-1 derivation targets (AC_phi_lambda, theta)."

The registry surface distinguishes that framework-specific derivation-target
bucket from universal-floor material:

> "Tier A-1 — Admitted derivation-targets (irreducible; have no-go portfolios)"

and later summarizes the counted dimensionless items as:

> "two dimensionless Tier-A admissions — AC_φλ (framework-specific physics) and θ (an SM-shared problem)."

So the standard is not "important open input." The standard is: every relevant
physical theory needs the same kind of supplied bridge or boundary, and the
input is not a special gap created by this framework's derivation program.

## Leg 2 — Universality Of The Species Identification

The parent species note already supplies the universality premise. It says the
minimum form of AC_phi_lambda(iii) is:

> "a single interpretive identification of an already-derived irreducible C₃-structure with the physical fermion generations, carrying no tested C₃-grade number, selector, ordering, or weight."

It then places that identification in the same class as a standard gauge-theory
bridge:

> "What remains is a pure abstract→physical identification of the **same class — at the C₃-structural grade — as** abstract su(3) → physical color"

and makes the governance gap explicit:

> "It is the same identification every gauge theory makes between its abstract representation-theoretic content and the named physical species at the C₃-structural grade; if that universal identification is not counted as a framework-specific admission elsewhere, AC_φλ(iii) need not be either — but this note does not make that governance call; it only fixes the tested C₃-grade content to zero."

This note assembles that call for the owner. It does not make it either.

## Leg 3 — The Carries-No-Number Discriminator

The past hypothesis carries no dimensionless number to derive. It supplies a
low-record, low-entropy boundary condition. The arrow note calls it:

> "the **past hypothesis** = a **universal-floor** open input"

The species identification passes the same no-number discriminator at the tested
C3 grade, because the parent says it carries:

> "no tested C₃-grade number, selector, ordering, or weight."

Strong CP fails this discriminator. The registry's theta entry names a
dimensionless theta problem directly:

> "`θ̄ = θ_gauge + arg det(M_q)`"

and then names numerical alternatives:

> "`θ_gauge = 0`"

and:

> "`arg det M ∈ {0, π} → 0`"

So theta remains outside this no-number universal-floor bucket and remains on
the admitted derivation-target surface, while the registry can still call it
SM-shared.

CKM/PMNS also fails this discriminator. The parent expressly excludes it:

> "**Not** a claim about across-fermion-type alignment (the CKM/PMNS mixing structure) — a separate residual, not addressed here."

That residual carries measured mixing data. This classification must not touch
it. It survives as a separate genuinely open residual.

## Honest Counterargument

"Every theory needs it" does not by itself make an input free. A universal input
can still be an input, and moving it out of the framework-specific bucket risks
making the registry look cleaner without solving the physical bridge.

The defense is narrow. The past-hypothesis precedent already accepts a
universal-floor bucket for an input every time-symmetric microdynamics needs,
and the carries-no-number discriminator keeps that bucket small. Theta fails
because it carries theta. CKM/PMNS fails because it carries measured mixing
structure. The species identification passes only at the C3-structural grade
and only because the parent reduced it to an abstract-to-physical
identification carrying no tested C3-grade number, selector, ordering, or
weight.
