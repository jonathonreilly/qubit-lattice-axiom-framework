  the SU(2)_L electroweak sphaleron reaction is in chemical equilibrium,

  ```text
    sum_i ( 3 mu_qL,i + mu_lL,i )  =  0,
  ```
  where the sum runs over the `N_F` lepton/quark families and
  `mu_qL,i, mu_lL,i` are the chemical potentials of the left-handed

- **E2 B - L conservation.** The sphaleron reaction conserves `B - L`.
  Beyond this admission no further dynamical input on the early-universe

- **E3 Plasma hypercharge neutrality.** The thermalised plasma is weak
  hypercharge neutral,
  ```text
    Q_Y  :=  sum_a g_a Y_a mu_a  =  0,
  ```
  where the sum runs over all SU(2)_L-component plasma species (quarks,
  leptons, Higgs doublet), `g_a` is the species multiplicity (color

  retained one-generation spectrum from authority (2) above.

- **E4 Yukawa-mediated chemical equilibria.** Inside the EWPT window
  the Standard-Model Yukawa reactions are in chemical equilibrium with
  the Higgs doublet `phi`, so that for each family `i`
  ```text
    mu_uR,i   =  mu_qL,i + mu_phi,
    mu_dR,i   =  mu_qL,i - mu_phi,
    mu_eR,i   =  mu_lL,i - mu_phi,
  ```

  `q̄_L phĩ u_R + q̄_L phi d_R + l̄_L phi e_R + h.c.`

## Exact arithmetic check

Working in the flavor-symmetric branch and using the retained
hypercharge multiplicities `(Y_qL, Y_uR, Y_dR, Y_lL, Y_eR) = (+1/3,
+4/3, -2/3, -1, -2)` with color multiplicity `N_c = 3` for quarks and
SU(2) doublet multiplicity `2` for left-handed doublets and the Higgs:

```text
Plasma hypercharge neutrality (E3):

  Q_Y / (T^2/6)  =  N_F [ N_c · 2 · (+1/3) · mu_qL
                          + N_c · 1 · (+4/3) · mu_uR
                          + N_c · 1 · (-2/3) · mu_dR
                          + 1   · 2 · (-1)  · mu_lL
                          + 1   · 1 · (-2)  · mu_eR ]
                    + N_H · 2 · 2 · (+1) · mu_phi
                =  N_F [ 2 mu_qL + 4 mu_uR - 2 mu_dR - 2 mu_lL - 2 mu_eR ]
                    + 4 N_H mu_phi.

(The bosonic factor 2 comes from E5; the Higgs doublet has 2 SU(2)
states.)

Substituting Yukawa (E4):

  N_F [ 2 mu_qL + 4 (mu_qL + mu_phi) - 2 (mu_qL - mu_phi)
        - 2 mu_lL - 2 (mu_lL - mu_phi) ]  + 4 N_H mu_phi
  =  N_F [ 4 mu_qL - 4 mu_lL + 8 mu_phi ] + 4 N_H mu_phi
  =  4 N_F mu_qL - 4 N_F mu_lL + (8 N_F + 4 N_H) mu_phi
  =  0.                                                              (B4)

Substituting sphaleron equilibrium (B3) `mu_lL = -3 mu_qL`:

  4 N_F mu_qL - 4 N_F (-3 mu_qL) + (8 N_F + 4 N_H) mu_phi  =  0
  16 N_F mu_qL + (8 N_F + 4 N_H) mu_phi                    =  0
  mu_qL = -(8 N_F + 4 N_H) / (16 N_F) · mu_phi
        = -(2 N_F + N_H) / (4 N_F)   · mu_phi.                      (B5)

Baryon-number density (no color in the SU(2) doublet bookkeeping
because color was already collected as the factor `N_c = 3` × the
1-particle factor 1/3 of baryon number):

  n_B / (T^2/6)   =  N_F · (1/3) · [ N_c · 2 · mu_qL
                                    + N_c · 1 · mu_uR
                                    + N_c · 1 · mu_dR ]
                  =  N_F · (1/3) · 3 · [ 2 mu_qL + mu_uR + mu_dR ]
                  =  N_F [ 2 mu_qL + (mu_qL + mu_phi) + (mu_qL - mu_phi) ]
                  =  4 N_F mu_qL.                                    (B6a)

Substituting (B5):

  n_B / (T^2/6)  =  4 N_F · ( -(2 N_F + N_H) / (4 N_F) ) mu_phi
                 =  -(2 N_F + N_H) mu_phi.                          (B6b)

Lepton-number density:

  n_L / (T^2/6)   =  N_F · [ 1 · 2 · mu_lL + 1 · 1 · mu_eR ]
                  =  N_F · [ 2 mu_lL + (mu_lL - mu_phi) ]
                  =  N_F · [ 3 mu_lL - mu_phi ]
                  =  N_F · [ -9 mu_qL - mu_phi ].                   (B7a)

Substituting (B5):

  n_L / (T^2/6)  =  N_F · [ -9 · ( -(2 N_F + N_H) / (4 N_F) ) mu_phi
                            - mu_phi ]
                 =  N_F · [ (9 (2 N_F + N_H)) / (4 N_F) - 1 ] mu_phi
                 =  N_F · [ (9 (2 N_F + N_H) - 4 N_F) / (4 N_F) ] mu_phi
                 =  ((14 N_F + 9 N_H) / 4) mu_phi.                  (B7b)

(B - L) density:

  (n_B - n_L) / (T^2/6)
                  =  -(2 N_F + N_H) mu_phi  -  ((14 N_F + 9 N_H)/4) mu_phi
                  =  ( -(8 N_F + 4 N_H) - (14 N_F + 9 N_H) ) / 4 · mu_phi
                  =  -(22 N_F + 13 N_H) / 4 · mu_phi.               (B7c)

Ratio:

  C_sph  =  n_B / (n_B - n_L)
         =  -(2 N_F + N_H) mu_phi / ( -(22 N_F + 13 N_H)/4 · mu_phi )
         =  4 (2 N_F + N_H) / (22 N_F + 13 N_H)
         =  (8 N_F + 4 N_H) / (22 N_F + 13 N_H).                    (★)

At (N_F, N_H) = (3, 1):

  C_sph  =  (24 + 4) / (66 + 13)
         =  28 / 79
         =  0.354430379746...                                      (★★)
```

The factor `(T^2 / 6)` cancels exactly between numerator and
denominator, so the ratio is independent of the small-`mu/T` thermal
prefactor in E5.
