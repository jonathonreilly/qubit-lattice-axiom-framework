## Question

chirality-5mode-cones (PR #10023, A2-A3) showed that with five modes per site every single-particle operator is a
Spin(10) tensor, so free cones carry the vector 10. The 16 is only the site's Fock content. Following the owner's
composite-before-atomic principle and symmetric mass generation (SMG), this note asks whether the 16 can appear
instead as a COMPOSITE fermionic quasiparticle. The idea: a strong Spin(10)-symmetric on-site interaction gaps the
elementary 10s, a site's lowest parity-odd excitation is the 16bar (5 + 10bar + 1), and weak hopping moves that
excitation coherently.

## Setting (supplied)

- Sites with five complex modes c_{s,a}, Majoranas g_{2a} = c + c^dag and g_{2a+1} = i(c^dag - c), with
  Jordan-Wigner order.
- Spin(10) generators M_ab = (i/2) sum_s g_a^s g_b^s, with Cartans sum_s (n_{s,a} - 1/2).
- The unique invariant hop, by Schur: K_st = i sum_a g_a^s g_a^t = 2i sum_a (c_s^dag c_t - h.c.).
- Model: H = U sum_s P_odd(s) + (t/2) sum_<st> K_st.
- Clusters: n = 2 (dimer), n = 3 (open chain), and n = 4 (ring, with flux 0, the uniform K_{s,s+1}, and flux pi).
- Exact sector method: H conserves every flavour number N_a. Every root-class irrep has a state at weight 0 and
  every vector-class irrep has one at weight e_1, so two sectors (7776 and 5184 states for n = 4) contain every
  multiplet.
- Exact Casimir identity, proved and checked (B2): C = 45n/4 + sum_{s<t} (10 - K_st^2)/4.

## A. One site (exact)

- A1. The Casimir is 45/4 on all 32 states.
- A2. The commutant of Spin(10) on the Fock space has dimension 2: span{1, (-1)^F}.
- A3. Hence an invariant on-site interaction is a + b(-1)^F. The even level (the vacuum plus Lambda^2 and Lambda^4,
  1 + 10 + 5) is one degenerate 16. The odd level (5 + 10 + 1) is the 16bar.
- So the task's premise of "a site ground state that is a singlet" cannot hold for one five-mode site under full
  Spin(10). The vacuum is a Spin(10) singlet only under U(5). With a U(5)-only interaction the lowest odd excitation
  is n = 1, the elementary 5, which is not composite. The 16bar is a level above a degenerate 16 "moment", not an
  excitation above a singlet.

## B. The centre theorem (exact, on the Fock space of a fixed finite site set)

- B3/A4/F1/B3b. exp(2 pi i M_01) = prod_s exp(2 pi i (n_{s,0} - 1/2)) = (-1)^n_sites, a c-number (checked for
  n = 1, 2, 3, 4). The centre generator is z = exp(i pi sum Cartans) = (-1)^F (-i)^n_sites (checked for n = 1 to 4).
- Consequences. Conjugation by -1 in Spin(10) is the identity on the whole operator algebra, but (-1)^F negates
  every odd operator. Therefore:
  - every operator on the Fock space of the fixed site set, and every state of that space relative to any vacuum
    of the same space, transforms as a true SO(10) representation;
  - a fermion-parity-odd state has relative centre charge -1, which is the vector class (10, 120, 126, 320, ...);
  - a spinor (relative centre charge +-i) does not occur in that space.
- This is a statement about the operator algebra and needs no Hamiltonian; in particular it holds for every
  Spin(10)-invariant Hamiltonian of any coupling strength, range or order on that space. It extends #10023 A2 from
  single-particle operators to all states of the fixed finite site set.
- Boundary. It is not a statement about superselection sectors of an infinite-volume limit. A deconfined spinon is not
  a state of the finite space reached from the vacuum, so fractionalised sectors are outside the theorem. The two
  controls show where the hypothesis matters: relative to a 2-site vacuum every 1-site state has z-ratio +-i (B3c, a
  changed site count), and for a Spin(10) acting on a supplied 16-component field the element -1 acts as (-1)^F (B3d).
- Physical reading (conditional): the GUT structure Spin x_Z2 Spin(10) identifies the internal -1 with (-1)^F. On the
  states of a fixed finite site set whose Spin(10) is generated by site bilinears, -1 acts as the scalar (-1)^n, so it
  is never (-1)^F relative to the vacuum.
- B4/B5 (exact two-site algebra):
  - The defect hop on 16 x 16bar has |K| = 10, 6, 2 on 1, 45, 210. The amplitude depends on the pair's total
    representation.
  - The exchange on 16 x 16 is K^2 = 64, 16, 0 on 10, 120, 126, so the second-order energy is -K^2 t^2/(8U) and it
    favours the 10.

## C-E. Finite clusters (finite diagnostics)

- C1. n = 2: the lowest even state is the 10, with E = -0.0770 (about -8t^2/U).
- C2. n = 2: the lowest odd state is the singlet of 16 x 16bar, with E = U - 5t. The relative representation is
  10 x 1 = 10.
- D1/D2. n = 3: the even and odd ground multiplets both have Casimir 45/4 (a 16-type), with residual 2e-13.
  - An odd cluster is a spinor. This is the composite-before-atomic form of the 16: three five-mode sites carry a
    16 ground multiplet.
  - But because z = (-1)^F (-i)^n, a 16 moving relative to an even-site vacuum would have to change the site count
    by an odd number.
- E0/E1. 4-ring: H commutes with the fermionic translation. The vacuum is a Spin(10) singlet (C = 7e-17), and the gap
  to the next state is 0.043 at t = 0.1. The Mott vacuum is selected by exchange.
- E2. Odd band, t = 0.1, flux 0. E(k) - U at k = 0, pi/2, pi, 3pi/2:
  - -0.611 [120], -0.683 [120], -0.611 [120], -0.696 [10].
  - Every state is vector class, and none has Casimir 45/4.
- E3. The defect moves at FIRST order. The exact projected one-defect hop has lowest coefficient -6.000, and the
  fitted slope is -6.107. So k = 1, not t^k/U^(k-1). In the Spin(10) Mott regime the elementary-parity defect is
  never gapped away from first-order motion: it is the hop itself.
- E4. Selection rule: c^dag on the singlet vacuum reaches only 10 states. Z = 0 exactly on 120 and 126.
- E5. Flux 0: the lowest fermion is a 10 with ZERO elementary residue (Z = 5e-27), a genuine three-mode composite.
- E6. Flux pi: the lowest fermion is the elementary-reached 10 (Z = 0.48, doubly degenerate).
- Answers to the task's questions (finite clusters n <= 4):
  - Composite fermions do form and propagate coherently at O(t).
  - Their Spin(10) representations are 10, 120 and 126, never the 16.
  - They are fermions (odd parity, so yes).
  - Cones in a 3D band: not computed. The content question is already decided by B, so a cone would carry a tensor.
    The 10 and 120 are real, so an invariant Majorana mass is allowed for them. Whether 126 alone is protected is
    not checked.

## Conclusion

**NO, within the stated boundary.** On the Fock space of a fixed finite set of five-mode sites with
on-site-generated Spin(10), no state is a spinor relative to a vacuum of that space, composite or elementary, for
any Hamiltonian. The obstruction is exact and kinematic (B3, B3b), not dynamical. The SMG/Mott regime does produce
composite fermions in the finite clusters, but they are vector-class tensors. The chirality-wall item (i) of #10023
("an emergent fermionic 16 is not shown") is sharpened only to this: no state of a finite fixed-site, site-bilinear
Spin(10) system carries spinor class relative to its vacuum. Fractionalised sectors in infinite volume, a changing
site count and a Spin(10) not generated by site bilinears are not excluded.

## Where the wall can move (routes, not results)

1. Site count is not fixed. An excitation that adds or removes one five-mode site carries centre (-i)^{+-1}, which
   is spinor class. Section D shows the odd-cluster ground state is a 16. A "moving site/vacancy" 16 needs the
   Z^3 / permanent-site axiom to bend (records creating or removing sites; compare the scale-ladder "removed sites"
   lane). UNTESTED.
2. Fractionalisation. A deconfined spinon (a domain wall between Mott patterns) can carry z = +-i individually.
   Local operators still create such spinons only in pairs, so a single deconfined one needs an emergent Z4 (or
   Z2) gauge field, i.e. topological order. Not computed. This is a route that keeps the axioms (corrected
   2026-11-14; the held text said "the only route"). The centre theorem does not exclude it, and this list of routes
   is not exhaustive.
3. Spin(10) not generated by site bilinears. If -1 in Spin(10) is to act as (-1)^F, the internal symmetry must be
   tied to the spacetime spin structure (as in Spin x_Z2 Spin(10)): for example, the cone's two-component slot
   carries the (-1)^F that the internal centre lacks. That needs the 16 to sit in a supplied spinor-index field,
   which is #10023's part B and fails the gate there.
