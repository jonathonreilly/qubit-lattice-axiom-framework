## Derivation

### Step 1: BZ-corner enumeration

By Block 03, the Kawamoto-Smit kinetic operator on Z³ APBC is
diagonalized in momentum space at the **BZ corners** k_μ ∈ {0, π}.
Each corner is labeled by a binary vector `n = (n_1, n_2, n_3) ∈ {0,1}³`
with `k_μ = n_μ · π`. There are 2³ = 8 corners total.

The runner enumerates this finite corner carrier directly. Standard
staggered-fermion BZ-corner language is cited only as parallel context, not
as a hidden derivation input. The 8 corners constitute the "taste-cube"
`V = {0,1}³`.

### Step 2: Hamming-weight grading

Each BZ corner has a Hamming weight `hw(n) = n_1 + n_2 + n_3 ∈ {0,1,2,3}`.

The 8 corners distribute as:
- hw = 0: (0,0,0) — **1 corner**
- hw = 1: (1,0,0), (0,1,0), (0,0,1) — **3 corners**
- hw = 2: (1,1,0), (1,0,1), (0,1,1) — **3 corners**
- hw = 3: (1,1,1) — **1 corner**

This is a structural counting fact on `{0,1}³`. The total
`1+3+3+1 = 8` matches the spectral structure FP retained.

This note does **not** identify BZ-corner Hamming parity with the K-S
position-space sublattice/chirality grading; any such
parity-to-chirality identification is a separate bridge. The runner checks
the correct boundary:
multiplication by the position-space staggered field
`epsilon(x)=(-1)^(x_1+x_2+x_3)` shifts momentum by `pi(1,1,1)`, so on
binary BZ-corner labels it complements every bit:

```text
n -> n xor (1,1,1).
```

In dimension three this maps `hw=0 <-> hw=3` and `hw=1 <-> hw=2`.
Thus `epsilon` is an off-diagonal corner-pairing operation on this finite
corner basis, not a diagonal chirality label for `hw` parity.

### Step 3: M_3(C) algebra on hw=1 (native finite proof)

The three lattice translations `T_x, T_y, T_z` act on the hw=1 triplet
as:

```
T_x: diag(−1, +1, +1)
T_y: diag(+1, −1, +1)
T_z: diag(+1, +1, −1)
```

(distinct joint characters separating the three corners). Combined
with the `C_3[111]` cyclic generator that maps `(1,0,0) → (0,1,0) →
(0,0,1) → (1,0,0)`, these operators generate the full M_3(C) algebra
on `H_hw=1`.

The runner proves this directly on the finite carrier: it constructs the
three translation-character projectors, verifies they are rank-one
orthogonal idempotents resolving `I_3`, and verifies that the products
`P_i C_3^k P_j` recover all nine matrix units `E_ij`. Therefore the
generated algebra has dimension 9 and is exactly `M_3(C)`.

The historical M3 note remains a parallel citation; it is not used here as a
hidden imported proof step.

### Step 4: No proper quotient/subspace (native finite proof)

If a quotient claims to preserve any exact retained operator, the
observable-descent lemma forces its kernel to be invariant under that
operator. In the present finite carrier, preserving the translation
projectors forces any invariant subspace to be a coordinate subspace
`span{X_i : i in S}`. Preserving the `C_3[111]` cycle forces `S` to be
closed under the three-cycle. The only such subsets are the empty set and
the full set `{1,2,3}`.

Therefore **no proper nonzero subspace** and hence no proper exact quotient
preserves both the translation-character separation and the `C_3[111]`
cycle on hw=1.

### Step 5: hw=1 algebraic triplet boundary

The combination of Steps 1-4 yields:

**The hw=1 BZ-corner triplet on the staggered-Dirac Z³ APBC carries
an exact irreducible M_3(C) algebra, with no proper quotient. This
is the algebraic triplet boundary. The physical-species / SM-generation
reading remains outside this note's load-bearing claim.**

The hw=1 triplet is the standard representation of S_3 on the three
