## 4. Theorem (bounded, three parts)

**(T1) Two-candidate collapse on the physical per-site space
(unconditional within the two-candidate surface).** The canonical CCR
`[a_x, a_y^†] = δ_{xy}` has no finite-dimensional realization: in any
finite dimension `tr([a, a^†]) = 0` while the CCR demands
`tr(I) = dim > 0`, and no finite truncation repairs it (defect norm `= K`
at every cutoff `K`). The physical per-site space has `dim_C H_x = 2`
(retained U4 row; recomputed). Hence the free-boson candidate is
excluded, and the single-pair Grassmann candidate (`χ̄_x² = 0`, per-site
Fock module `{|0⟩, χ̄_x|0⟩}`, `dim = 2 = 2^1`, matching `k = 1`) is the
unique survivor of the two-candidate surface `{free boson, single-pair
Grassmann}`, carrying the Berezin finite-determinant partition readout.
This reproduces, at block altitude, (D5) of the 05-16 bridge note at its
current U4-discharged strength.

**(T2) Conditional forcing given `GL(F)`.** Let `F = ⊗_x σ₃^(x)` be the
retained fermion-parity grading and `GL(F)` the predicate
`{ψ_x, ψ_y} = {ψ_x, ψ_y^†} = 0` for all `x ≠ y` (cross-site graded
locality of the `F`-odd matter fields). Then within the explicit
three-candidate list `{free boson, hard-core boson, Grassmann/CAR}`,
exactly one candidate passes `{dim_C H_x = 2} ∧ GL(F)`: the
Grassmann/CAR class (the Jordan-Wigner realization passes `GL(F)`
exactly; the hard-core realization fails it; the free boson already fails
the dimensional readout). **Given `GL(F)`, the matter measure's
statistics class is forced to be Grassmann/CAR.** This is the
discriminator note's (T2), re-verified by this note's runner.

**(T3) Boundary — no unconditional forcing.** Without `GL(F)`, every
tested predicate (per-site dimension, generated ungraded operator
algebra, `F`-oddness) is constant across the hard-core and Grassmann/CAR
frames: the tie of the retained 2026-05-25 no-go returns. The
2026-05-07 unconditional claim ("uniquely Grassmann") is therefore
withdrawn; `GL(F)` is strictly additional input (the same ungraded
algebra `M_{2^{|Λ|}}(ℂ)` contains both a `GL(F)`-passing and a
`GL(F)`-failing generating family, so no functional of the ungraded
algebra decides it).

### Proof

**(T1).** Trace obstruction: linearity and cyclicity give
`tr(a a^† − a^† a) = 0 ≠ d = tr(I_d)` for any finite-dimensional
candidate realization, so the CCR branch requires an infinite-dimensional
per-site space (this is the (S2′) content of the re-scoped 04-29
authority, consumed at its declared grade and recomputed by runner [B]).
The retained per-site readout gives `dim_C H_x = 2`, chirality-independent
(runner [A] recomputes the Clifford relations, faithfulness
`dim_R = 8 = dim_R M_2(ℂ)`, irreducibility via scalar commutant, and the
carrier dimension for both `ρ_± = ±σ_i`). The single-pair Grassmann Fock
module has dimension exactly `2` by nilpotency, and `p ≥ 2` pairs give
`2^p ≠ 2`, so the `k = 1` single-pair form is selected. Falsification
leg: on the `k = 2` module `ρ_+ ⊕ ρ_+` (`ℂ⁴`, faithful, Clifford
relations hold) the single-pair match fails (`2 ≠ 4`) — the retained
dim-2/`k = 1` input is load-bearing. ∎

**(T2).** Exact finite computation at `|Λ| = 3` (runner [C]): the JW
fields `c_x = (∏_{y<x} σ₃^{(y)}) σ₊^{(x)}` satisfy cross-site CAR
(`GL(F)` passes, on-site CAR exact); the hard-core fields `σ₊^{(x)}`
commute cross-site with `{σ₊^{(x)}, σ₊^{(y)}} ≠ 0` (`GL(F)` fails); the
free boson fails the dimensional readout by (T1). Selection certificate:
exactly one survivor of `{dim = 2} ∧ GL(F)`. ∎

**(T3).** Runner [C] falsification leg: with `GL(F)` deleted, the
predicate vector (per-site dim `2 = 2`; generated ungraded algebra
`64 = 64 = dim M_8(ℂ)` at `|Λ| = 3`; `F`-oddness of both families) is
constant across the two tied frames. Runner [D] then evaluates the claim
tuple: unconditional forcing FALSE, conditional forcing TRUE, `GL(F)`
strictly additional. ∎

**Load-bearing step.** The decisive step is the **conditional selection
certificate**: *exactly one of the explicit three candidates passes
`{dim_C H_x = 2} ∧ GL(F)` — the Grassmann/CAR class — while without
`GL(F)` every tested predicate is constant across the tied frames.* It is
a first-principles finite linear-algebra computation from the baseline
objects plus the explicitly declared `GL(F)` hypothesis (rubric class
(C) for the conditional statement; the falsification legs show the
conclusion fails when either the dim-2 input or the `GL(F)` hypothesis is
dropped, so neither is decorative).
