



## Proof

For one site, set

```text
a = [[0,1],[0,0]],        a^dag = [[0,0],[1,0]],
n = a^dag a = [[0,0],[0,1]].
```

Direct multiplication gives `a^2 = 0`, `{a,a^dag}=I`, `n^dag=n`, `n^2=n`, and
the spectrum `{0,1}`. The commutators are

```text
[n,a] = -a,       [n,a^dag] = a^dag.
```

If an arbitrary one-site matrix `R` has the same commutators and is normalized
by `R|0>=0`, then solving the four linear equations gives
`R = diag(0,1) = n`. This proves uniqueness of the normalized onsite U(1)
generator.

For a finite site set, use the standard Jordan-Wigner tensor realization of the
finite CAR algebra. The local projections `n_x = a_x^dag a_x` commute, their sum
`Q` has the required commutators with every `a_x` and `a_x^dag`, and the bilinear
commutator follows by exact matrix multiplication:

```text
[a_x^dag a_y, a_p^dag a_p]
  = delta_yp a_x^dag a_p - delta_px a_p^dag a_y.
```

This is precisely the `rho_p = E_pp` surface used by the abstract bilinear
continuity theorem.
