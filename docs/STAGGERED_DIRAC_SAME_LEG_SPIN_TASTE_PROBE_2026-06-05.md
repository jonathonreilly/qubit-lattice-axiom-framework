## 1. The hatch this probe attacks

`r = 1/2` (the charged-lepton Koide value `Q = 2/3` via the circulant
`H = a I + b C + conj(b) C^2`, `r := |b|^2/a^2`) requires a Hermitian
off-block `C_3`-orbit-splitting grading `Gamma_chi` on the generation
factor `R^3` that **anticommutes** with `H`. Two established walls block
the obvious routes:

- **WALL A — distinct-tensor-factor route.** In the standard Connes-Lott
  structure `H_st = R^3 ⊗ (H_L ⊕ H_R)`, the chirality grading is
  `gamma_CL = I_3 ⊗ sigma_3`, living on a factor **separate** from the
  generation `R^3`. Its restriction to a fixed-chirality generation copy
  is the scalar `±I_3`, so it commutes with every generation operator and
  cannot grade the generation orbit. (Recorded in
  `KOIDE_Z3_EQUIVARIANT_ANTICOMMUTING_NO_GO_NOTE_2026-05-16`: the
  literal single-factor identification `gamma = Gamma_chi` plus
  `C_3`-equivariance forces the Dirac to zero; the multi-factor structure
  is explicitly left open as the hatch.)

- **WALL B — `d = 3+1` native `S_3` invariance.** The native
  staggered/KS chirality on the spatial cube is the staggered phase
  `eps(x) = (-1)^{hw(x)}` (Hamming weight = form degree). On the `hw = 1`
  generation orbit `{e1, e2, e3}` this is the constant `(-1)^1 = -1`,
  `S_3`-invariant, hence a scalar — it cannot anticommute-grade the
  generation index.

The distinct-factor probe (WALL A) explicitly **relocated** the open
question to a multi-factor / non-separate construction. This note tests
the most physical such construction available in the framework: the
KS/staggered taste cube, where chirality and the generation index share
the **same** `C^8` leg.

## 2. The same-leg structure (it is real)

On the retained taste-cube surface (`s3_taste_cube_decomposition` =
**retained**; substep-2 Kähler-Dirac equivalence and substep-3 BZ-corner
Hamming orbit = retained):

- Taste cube `V = (C^2)^{⊗3} = C^8`, basis `|b1 b2 b3>`, `b ∈ {0,1}^3`,
  graded by Hamming weight `hw = b1 + b2 + b3` (form degree).
- `S_3` permutes the three tensor positions (cubic axis permutations);
  `C^8 = 4 A_1 + 0 A_2 + 2 E`; the `hw = 1` sector
  `{e1 = |100>, e2 = |010>, e3 = |001>}` is the 3-point permutation rep
  `A_1 + E`, with the `Z_3` 3-cycle `e1 → e2 → e3 → e1` (the generation
  orbit).
- The same-leg chirality is `Gamma_KS = (-1)^{hw}`. The runner verifies
  (Part 2) that the **spin-taste `gamma5 ⊗ xi5`** analog — the product
  `sigma_3 ⊗ sigma_3 ⊗ sigma_3` of `sigma_3` over the three qubit factors
  — **equals** `(-1)^{hw}` exactly on `C^8`. So the famous spin-taste
  `gamma5` *is* the staggered phase here; chirality and the generation
  index live on the same 8-dim leg, **not** a product `C^3 ⊗ C^2` of a
  generation factor with a separate chirality factor (`8` is not `3·2`;
  the generation triple sits *inside* `C^8`). `Gamma_KS` is a legitimate
  Hermitian involution (`Gamma_KS^2 = I`) that genuinely grades the cube
  into 4 even-`hw` and 4 odd-`hw` corners.

This is the genuine entanglement the hatch promised: it is **not** the
`I_3 ⊗ sigma_3` product.

## 3. What the probe finds

**(A) `hw = 1` projection → `S_3`-uniform scalar `-I_3` (Parts 3-4).**
The entire `hw = 1` generation orbit lies in **one** chirality sector
(odd `hw`). Hence `Gamma_KS` restricted to the generation orbit is exactly
the scalar `-I_3`. As a scalar it commutes with **every** Hermitian
generation operator (verified on 200 random Hermitian `3×3` operators), so
`{Gamma_KS|_{hw=1}, H} = -2H`, which is nonzero for nonzero `H`: it
delivers **no** anticommuting grading. The `d = 4` spin-taste `gamma5 ⊗ xi5`
analog gives the identical `-I_3` restriction.

**(B) The crux — no off-block generation grading is induced (Part 5).**
In the `Z_3` Fourier basis `H = diag(L_0, L_1, L_2)` with
`L_k = a + b ω^k + conj(b) ω^{2k}`, the entrywise anticommutation rule is
`{Gamma, H}_{jk} = (L_j + L_k) Gamma_{jk}` (verified symbolically for all
9 entries). An off-block (singlet↔doublet) grading **requires**
`Gamma_{jk} ≠ 0` for some `j ≠ k`. The same-leg chirality supplies only
the diagonal scalar `-I_3` — **zero** off-block entries — so it cannot
produce the singlet↔doublet mixing `r = 1/2` needs.

**(C) Same wall as the distinct-factor route (Part 6).** The
`I_3 ⊗ sigma_3` comparator is reproduced: within a fixed-chirality
generation copy it is `+I_3` (scalar), commuting with all `A ⊗ I_2`
generation operators. **Both** the same-leg cube chirality and the
distinct-factor chirality reduce to a scalar on the generation orbit —
the same `S_3`-uniform wall reached by two different doors.

**(D) What a genuine off-block grade would cost (Part 7).** A genuine
off-block Hermitian **grading** (involution `Gamma^2 = I`) mixing the
`Z_3` singlet (mode 0) with a doublet component (mode 1) must, by the
entrywise rule, satisfy **both** `L_0 + L_1 = 0` (the off-block pair) and
`L_2 = 0` (mode 2 must carry a `±1` chirality sign, since the involution
acts on all of `C^3`). Together these force `a = 0`. (Honest scoping: the
*weaker* `L_0 + L_1 = 0` **alone** — a rank-2 *non-involution* partial
grade — does **not** force `a = 0`; it gives `a = sqrt(3) b_i/2 - b_r/2`.
The full `Z_2` chirality grading is what forces `a = 0`.) On the `a = 0`
surface the spectrum is origin-symmetric `{+λ, -λ, 0}`, so `mean = a = 0`,
`Σ L = 0`, and the eigenvalue/affine Koide readout `Q = (Σ L^2)/(Σ L)^2`
**diverges** (not `2/3`). `a = 0` is the chiral limit where `r = |b|^2/a^2`
itself diverges: the off-block grade exists **only** where its own Koide
ratio is undefined, and never reaches the finite `r = 1/2` point. Cross-
check: at the genuine `r = 1/2` Koide point (`a = 1`, `b = 1/sqrt(2)`),
`Q = 2/3` exactly but `a = 1 ≠ 0`, so no off-block grade exists there.
This is the **same** origin-reflection (`mean = a = 0`) spectral
obstruction surfaced by
`CHIRALITY_AFFINE_CHIRAL_LIMIT_PROBE_2026-06-05`.

**(E) Splitting requires breaking the cubic `S_3` symmetry (Part 8).** On
the `hw = 1` orbit, `S_3` acts as `A_1 + E`. By Schur, any
`S_3`-equivariant Hermitian grading is `c_1 P_{A_1} + c_E P_E` — diagonal
in the `A_1/E` split, with **zero** singlet(`A_1`)↔doublet(`E`) off-block.
The orbit-splitting the grade needs is exactly an `A_1 ↔ E` mixing, which
no `S_3`-invariant operator supplies. A preferred-axis grade
`diag(1, -1, -1)` (referenced to one site) *does* split, but is **not**
`S_3`-invariant: orbit-splitting ⇒ breaking the cubic symmetry (a preferred
axis/site), which is not native to the cube.

**(F) Adversarial steelman — full hw-mixing Kähler-Dirac (Part 9).** The
strongest escape: the generation orbit is **not** an invariant subspace of
the actual staggered Dirac. The runner builds the genuine Kähler-Dirac
operator `D_KD = d - δ` on the cube; it anticommutes with `gamma5`
globally (`{gamma5, D_KD} = 0`, form-parity reversal), `i D_KD` is
Hermitian, and `D_KD` has **zero** `hw1 → hw1` block (generations couple
only to `hw = 0, 2` — they are *not* mass eigenstates). Even so, `gamma5`
is **constant** `-1` across the entire generation orbit. hw-mixing dynamics
change *which* states are mass eigenstates, never the chirality *value* on
the generation orbit, which is pinned at `-1` by `hw = 1`. The escape does
**not** open.

## 4. Verdict and the wall

**VERDICT: COLLAPSES-TO-S3-UNIFORM.**

The same-leg spin-taste chirality `Gamma_KS = (-1)^{hw} = gamma5 ⊗ xi5`,
restricted to the `hw = 1` generation orbit, is the `S_3`-invariant scalar
`-I_3` (the whole orbit sits in one chirality sector). It induces **no**
off-block singlet↔doublet generation grading and does **not** reach
`r = 1/2`. The same-leg and distinct-factor routes hit the **same**
`S_3`-uniform wall by different doors. A genuine off-block anticommuting
grade forces `a = 0` (chiral limit, `r → ∞`, **not** `r = 1/2`), with
origin-symmetric spectrum `{+λ, -λ, 0}`; splitting the `C_3` orbit requires
**breaking** the cubic `S_3` symmetry (a preferred axis/site), which is not
native to the cube.

So the same-leg structure — the relocated hatch — **reduces** to the `S_3`
wall; it does not evade it. The honest middle outcome the `d = 3+1` wall
predicts is confirmed, and adversarially re-verified against the full
hw-mixing Kähler-Dirac dynamics. The next path this opens is the explicit
cubic-`S_3`-breaking selector (the preferred axis/site that would split the
`A_1` singlet from the `E` doublet) — a `C_3`-orbit-breaking import, the
same single named import the generation-chirality gate and the Koide
`Q = 2/3` gate already share.

  `{Gamma, H} = 0`, `Gamma^2 = I`, off-block (singlet↔doublet),
  **derived from the same-leg cube chirality `(-1)^{hw}` without an

  reduction and be the sought same-leg native grading. The runner shows the
  `hw = 1` restriction of `(-1)^{hw}` is the scalar `-I_3` (Parts 3-4) and
  that any off-block involution forces `a = 0` (Part 7), so no such point

  cube (refuted by `sigma_3^{⊗3} = (-1)^{hw}` in Part 2).

  the generation orbit (refuted by Part 9: `gamma5 = -I_3` on `hw = 1`
  regardless of `D_KD`'s hw-mixing).
