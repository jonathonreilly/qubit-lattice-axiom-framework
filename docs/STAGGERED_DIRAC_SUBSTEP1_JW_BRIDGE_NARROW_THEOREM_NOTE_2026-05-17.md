## 1. Claim scope

Let `V` be a finite-dimensional complex vector space carrying a faithful
irreducible representation of the real Clifford algebra `Cl(3,0)`, so
that (by the cited upstream narrow theorem) `dim_C V = 2`, realized by
Pauli generators `γ_i ↦ σ_i`. Let `Λ` be a finite set of `N := |Λ|`
sites with a fixed total ordering `π : Λ → {1, ..., N}` (the cubic
lattice block `Λ ⊂ Z^3` admits the canonical lexicographic ordering on
coordinates `(z, y, x)`, so a total ordering exists by the abstract
finite-set structure of `Λ`). Define the tensor-product Fock space

```text
H_Λ  :=  V^{⊗N}  =  ⊗_{x ∈ Λ} V_x   with   dim_C H_Λ = 2^N           (T)
```

and the per-site Pauli ladder operators

```text
σ_+^(x)  :=  (σ_1 + i σ_2) / 2  at site x,                            (L+)
σ_-^(x)  :=  (σ_1 - i σ_2) / 2  at site x,                            (L-)
σ_3^(x)  :=  σ_3              at site x,                              (L3)
```

each extended to `H_Λ` by tensor identity on the other factors.

Define the **Jordan-Wigner cross-site operators**

```text
c_x   :=  ( ∏_{y ∈ Λ : π(y) < π(x)} σ_3^(y) ) · σ_+^(x)               (JW+)
c_x^†:=  ( ∏_{y ∈ Λ : π(y) < π(x)} σ_3^(y) ) · σ_-^(x)                (JW-)
```

where the product runs over sites strictly preceding `x` in the total
ordering `π`, in increasing order of `π`, and the empty product (for
the `π`-minimum site) is the identity on `H_Λ`.

Then the following algebraic facts hold:

- **(J1) Cross-site anticommutation.** For all `x, y ∈ Λ`:

  ```text
  {c_x, c_y}      :=  c_x c_y + c_y c_x      =  0,                    (J1a)
  {c_x^†, c_y^†}  :=  c_x^† c_y^† + c_y^† c_x^†  =  0,                (J1b)
  {c_x, c_y^†}    :=  c_x c_y^† + c_y^† c_x    =  δ_{xy} · I_{H_Λ}.   (J1c)
  ```

  In particular for `x ≠ y` the off-diagonal anticommutator
  `{c_x, c_y^†} = 0`, and (J1a)-(J1b) hold for all pairs including
  `x = y`.

- **(J2) On-site nilpotency.** For each `x ∈ Λ`:

  ```text
  c_x²  =  0 ,    (c_x^†)²  =  0  .                                   (J2)
  ```

  These follow from `(σ_±^(x))² = 0` and the fact that the JW-string
  operator
  `S_x := ∏_{y : π(y) < π(x)} σ_3^(y)`
  satisfies `S_x² = I_{H_Λ}` and `{S_x, σ_±^(x)} ≠ 0` is not required

- **(J3) Generated CAR algebra.** The complex *-algebra generated by
  `{c_x, c_x^† : x ∈ Λ}` is isomorphic to the abstract canonical
  anticommutation algebra `CAR(2N)` on `2N` generators with the defining

- **(J4) Per-site Fock projection.** On `H_Λ`, the per-site number

  string by string-cancellation `S_x^2 = I`), with `Spec(n̂_x) = {0, 1}`,

## 5. Proof

### 5.1 Setup — site-extended Pauli operators

By the cited upstream narrow theorem, the Cl(3) faithful complex
irrep on `V ≅ ℂ²` is realized by Pauli matrices `γ_i ↦ σ_i`. The
per-site Pauli ladders `σ_±^(x) := (σ_1 ± i σ_2)/2` at site `x` are
extended to `H_Λ = V^{⊗N}` by tensor identity on the other factors,
i.e.

```text
σ_a^(x)  :=  I_2^{⊗ (π(x)-1)}  ⊗  σ_a  ⊗  I_2^{⊗ (N - π(x))}        (5.1)
```

for `a ∈ {1, 2, 3, +, -}`. The per-site relations follow:

```text
(σ_+^(x))² = 0,    (σ_-^(x))² = 0,    {σ_+^(x), σ_-^(x)} = I_{H_Λ},  (5.2)
[σ_a^(x), σ_b^(y)] = 0   for x ≠ y, all a, b ∈ {1,2,3,+,-},          (5.3)
σ_3^(x)² = I_{H_Λ},                                                   (5.4)
{σ_3^(x), σ_±^(x)} = 0,  [σ_3^(x), σ_3^(y)] = 0 for x ≠ y.           (5.5)
```

Equations (5.2)-(5.5) follow from standard Pauli-matrix algebra
(2-by-2 matrix arithmetic on the per-site factor) and the
disjoint-tensor-factor commutativity (5.3).

### 5.2 JW-string operator and its `Z_2`-grading action

For each site `x`, define the **Jordan-Wigner string operator**

```text
S_x  :=  ∏_{y ∈ Λ : π(y) < π(x)} σ_3^(y) ,                            (5.6)
```

with `S_x := I_{H_Λ}` for the `π`-minimum site `x`. Standard
properties:

- `S_x² = I_{H_Λ}` (each `σ_3^(y)²  = I_{H_Λ}` and the per-site
  σ_3's commute with each other, so the product squares to identity);
- For `x ≠ y`, the strings `S_x` and `S_y` commute (each is a product
  of per-site `σ_3`'s which all mutually commute by (5.5)).

The crucial **Z_2-grading action** of `σ_3` on the Pauli ladders is:

```text
σ_3^(y) · σ_±^(y)  =  -σ_±^(y) · σ_3^(y),                             (5.7)
```

i.e. per-site anticommutation `{σ_3^(y), σ_±^(y)} = 0`, while at
distinct sites `[σ_3^(y), σ_±^(x)] = 0` for `y ≠ x` by (5.3).

### 5.3 (J2) On-site nilpotency

By (5.1) and the per-site nilpotency `(σ_±)² = 0`, extending by
tensor identity preserves nilpotency: `(σ_±^(x))² = 0` on `H_Λ`.

For the JW operators (JW+)-(JW-), apply on-site:

```text
c_x²  =  (S_x σ_+^(x)) (S_x σ_+^(x))
      =  S_x (σ_+^(x) S_x) σ_+^(x)                                     (5.8)
```

Now `σ_+^(x)` and `S_x` act on disjoint tensor factors (since `S_x`
is supported on sites `y` with `π(y) < π(x)`, which are all distinct
from `x`), so `σ_+^(x) S_x = S_x σ_+^(x)` by (5.3). Hence

```text
c_x²  =  S_x · S_x · σ_+^(x) σ_+^(x)  =  I_{H_Λ} · 0  =  0 .          (5.9)
```

Identical for `(c_x^†)² = 0`. ∎

### 5.4 (J1) Cross-site anticommutation

**Sub-case 1: same site `x = y`.** The on-site CAR
`{c_x, c_x^†} = I_{H_Λ}` follows from the JW-string identity
`S_x^2 = I` and the per-site Pauli anticommutator
`{σ_+^(x), σ_-^(x)} = I`. Concretely:

```text
c_x c_x^†  =  S_x σ_+^(x) · S_x σ_-^(x)
          =  S_x · S_x · σ_+^(x) σ_-^(x)   [string commutes with σ_±^(x)]
          =  σ_+^(x) σ_-^(x) .                                         (5.10)
```

Similarly `c_x^† c_x = σ_-^(x) σ_+^(x)`. So

```text
{c_x, c_x^†}  =  σ_+^(x) σ_-^(x) + σ_-^(x) σ_+^(x)  =  I_{H_Λ}        (5.11)
```

by (5.2).

For `{c_x, c_x}`, by (5.9) `c_x^2 = 0`; expanding
`{c_x, c_x} = 2 c_x^2 = 0`. Similarly `{c_x^†, c_x^†} = 0`. ∎

**Sub-case 2: distinct sites `x ≠ y`.** Without loss of generality
assume `π(x) < π(y)`. Then by definition of the JW strings,

```text
S_x  =  ∏_{z : π(z) < π(x)} σ_3^(z) ,                                 (5.12a)
S_y  =  ∏_{z : π(z) < π(y)} σ_3^(z)
     =  S_x · σ_3^(x) · (∏_{z : π(x) < π(z) < π(y)} σ_3^(z)) .         (5.12b)
```

Denote the middle factor `T_{xy} := ∏_{π(x) < π(z) < π(y)} σ_3^(z)`,
so `S_y = S_x · σ_3^(x) · T_{xy}`.

Now compute `c_x c_y`:

```text
c_x c_y  =  S_x σ_+^(x) · S_y σ_+^(y)
        =  S_x σ_+^(x) · S_x · σ_3^(x) · T_{xy} · σ_+^(y)
        =  S_x · S_x · σ_+^(x) σ_3^(x) · T_{xy} · σ_+^(y)              (5.13)
              [σ_+^(x) commutes with S_x by disjoint support;
               T_{xy} and σ_+^(y) commute with σ_+^(x) by disjoint
               support (y > x, all z in T_{xy} have π(x) < π(z) < π(y))]
        =  I_{H_Λ} · σ_+^(x) σ_3^(x) · T_{xy} · σ_+^(y)
        =  -σ_3^(x) σ_+^(x) · T_{xy} · σ_+^(y)
              [by (5.7): σ_+^(x) σ_3^(x) = -σ_3^(x) σ_+^(x)]
        =  -σ_3^(x) · σ_+^(x) · T_{xy} · σ_+^(y) .
```

Symmetrically:

```text
c_y c_x  =  S_y σ_+^(y) · S_x σ_+^(x)
        =  S_x · σ_3^(x) · T_{xy} · σ_+^(y) · S_x · σ_+^(x)
        =  S_x · σ_3^(x) · T_{xy} · S_x · σ_+^(y) σ_+^(x)              (5.14)
              [σ_+^(y) commutes with S_x by disjoint support]
        =  S_x · S_x · σ_3^(x) · T_{xy} · σ_+^(y) σ_+^(x)
              [σ_3^(x) commutes with S_x by disjoint support;
               T_{xy} commutes with S_x by disjoint support]
        =  σ_3^(x) · T_{xy} · σ_+^(y) σ_+^(x)
        =  σ_3^(x) · σ_+^(x) · T_{xy} · σ_+^(y) ,
              [σ_+^(x) commutes with T_{xy} and σ_+^(y) by disjoint
               support; the final reordering moves σ_+^(x) to its
               position next to σ_3^(x) without sign change]
```

where in the last step we used the disjoint-support commutations
(`σ_+^(x)` lives on factor `x`; `T_{xy}` lives on factors strictly
between `x` and `y`; `σ_+^(y)` lives on factor `y` — all mutually
disjoint).

Comparing (5.13) and (5.14):

```text
c_x c_y  =  -σ_3^(x) · σ_+^(x) · T_{xy} · σ_+^(y)
c_y c_x  =  +σ_3^(x) · σ_+^(x) · T_{xy} · σ_+^(y)
```

Hence

```text
{c_x, c_y}  =  c_x c_y + c_y c_x  =  0 .                              (5.15)
```

Identical computation with `σ_-^(y)` in place of `σ_+^(y)` gives
`{c_x, c_y^†} = 0` for `x ≠ y`, since the only sign-bearing step is
the on-site `σ_+^(x) σ_3^(x) = -σ_3^(x) σ_+^(x)`; the per-site
identity of `σ_+^(y)` vs. `σ_-^(y)` does not affect the cross-site
sign-flip.

The case `π(x) > π(y)` is symmetric (swap roles of `x` and `y` in
(5.12)-(5.15)).

Identical computation with `(c_x^†, c_y^†)` gives `{c_x^†, c_y^†} = 0`
for `x ≠ y`. ∎

**Sub-case 3: cross-site `{c_x, c_y^†}` for `x ≠ y`.** Run the
computation of sub-case 2 with `σ_-^(y)` in place of `σ_+^(y)`. The
on-site `σ_+^(x) σ_3^(x) = -σ_3^(x) σ_+^(x)` produces the same sign
flip, and the cross-site terms remain disjoint-factor commuting. The
expansion gives

```text
c_x c_y^†  =  -σ_3^(x) · σ_+^(x) · T_{xy} · σ_-^(y),                  (5.16)
c_y^† c_x  =  +σ_3^(x) · σ_+^(x) · T_{xy} · σ_-^(y),
{c_x, c_y^†}  =  0    for x ≠ y .                                     (5.17)
```

Combined with the on-site `{c_x, c_x^†} = I_{H_Λ}` from sub-case 1,

```text
{c_x, c_y^†}  =  δ_{xy} · I_{H_Λ}     for all x, y ∈ Λ . ∎          (J1c)
```

### 5.5 (J3) Generated CAR algebra

By (J1)-(J2), the complex *-algebra `A := ⟨{c_x, c_x^† : x ∈ Λ}⟩_C`
satisfies the abstract CAR relations on `2N` generators. The standard
abstract CAR algebra `CAR(2N)` has complex dimension `2^{2N} = 4^N`
as a vector space, spanned by monomials of the form
`(c_{x_1}^†)^{n_1} ... (c_{x_N}^†)^{n_N} (c_{x_N})^{m_N} ...
(c_{x_1})^{m_1}` with `n_x, m_x ∈ {0, 1}` (each generator appears at
most once due to nilpotency (J2)).

The image algebra `A ⊂ End(H_Λ)` is generated by `2N` operators in a
`(2^N)^2 = 4^N`-dim endomorphism algebra. The map from the abstract
`CAR(2N)` to `A` is surjective by construction; injectivity follows
from the irreducibility of the standard Fock representation of
`CAR(2N)` on `H = ⊗ ℂ²` (the JW construction is the canonical
realization of this Fock representation). Hence `A ≅ CAR(2N)` and
`dim_C A = 4^N`, matching `dim_C End(H_Λ)`. The CAR representation
is faithful and irreducible on `H_Λ`.

This irreducibility-on-the-tensor-product fact is the abstract
algebraic content of the **fermion-Fock representation theorem** for
finite-mode CAR — well-established standard finite-dim representation
theory; cited as admitted-context, not re-derived here. ∎

### 5.6 (J4) Per-site Fock projection

Compute `c_x^† c_x`:

```text
c_x^† c_x  =  S_x σ_-^(x) · S_x σ_+^(x)
          =  S_x · S_x · σ_-^(x) σ_+^(x)                              (5.18)
              [string commutes with same-site σ_±]
          =  I_{H_Λ} · σ_-^(x) σ_+^(x)
          =  σ_-^(x) σ_+^(x) .
```

By Pauli algebra `σ_- σ_+ = (I_2 - σ_3)/2` (standard identity from
`σ_± = (σ_1 ± i σ_2)/2`), and lifted to `H_Λ` by tensor identity:

```text
n̂_x  :=  c_x^† c_x  =  (I_x - σ_3^(x))/2 .                            (5.19)
```

Hence `Spec(n̂_x) = {0, 1}`: the eigenvalue `0` on the `+1`-eigenspace
of `σ_3^(x)`, and `1` on the `-1`-eigenspace. The number operators
at distinct sites commute: `[n̂_x, n̂_y] = 0` for all `x, y` (each is a
function of `σ_3^(x)`, and σ_3's at distinct sites commute by (5.5)),
so they are simultaneously diagonalizable on the occupation-number
basis

```text
|ν⟩  :=  |ν_1, ν_2, ..., ν_N⟩  ,    ν_x ∈ {0, 1}.                    (5.20)
```

The vacuum `|0⟩` is the all-zero state. By construction `S_x` acts
on the vacuum as `(+1)^{|{y : π(y) < π(x)}|} = +1` (each `σ_3^(y)`
acts as `+1` on the per-site `+1`-eigenstate, which is the
`ν_y = 0` state of the vacuum). Hence `c_x |0⟩ = S_x σ_+^(x) |0⟩ =
σ_+^(x) |0⟩ = 0` (since `σ_+` annihilates the spin-up `|0⟩` state),
and `c_x^† |0⟩ = σ_-^(x) |0⟩ = |1⟩_x ⊗ vac_{rest}` is the
single-particle state at site `x`. ∎
