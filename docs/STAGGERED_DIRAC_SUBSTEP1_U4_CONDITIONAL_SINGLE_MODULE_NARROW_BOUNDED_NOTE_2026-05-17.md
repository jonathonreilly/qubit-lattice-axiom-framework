## 1. Claim scope

Let `Cl(3,0)` be the real Clifford algebra on three generators
`γ_1, γ_2, γ_3` satisfying `{γ_i, γ_j} = 2 δ_{ij} · 1`. Let `Λ` be a
finite block of `Z^3` lattice sites. For each site `x ∈ Λ`, let
`H_x` be a finite-dim complex vector space carrying a representation
`ρ_x : Cl(3,0) → End(H_x)` of the physical Cl(3) local algebra.

There are two distinct surfaces:

- **Abstract representation surface.** Start only with a faithful
  finite-dimensional complex Cl(3) representation. This surface admits
  all multiplicities `k >= 1`; it does not force `k = 1`.
- **Current minimal-Quantum framework surface.** Start with the current
  Quantum axiom's primitive one-site carrier: one qubit,
  equivalently `A_x ~= M_2(C) ~= Cl(3,0)`. This surface is not an
  arbitrary faithful representation surface. It fixes the physical
  one-site carrier to the single two-dimensional Pauli module.

**Multiplicity classification (M1).** By the cited retained narrow
theorem on the Cl(3) faithful complex-irrep dim-two readout, every
finite-dim complex representation of `Cl(3,0)` decomposes as

```text
H_x  ≅  ρ_+^{n_+(x)}  ⊕  ρ_-^{n_-(x)}                                  (M1)
```

with `dim_C H_x = 2 (n_+(x) + n_-(x))`. The total multiplicity
`k(x) := n_+(x) + n_-(x) ∈ Z_{≥0}` is the *multiplicity index* of the
per-site Cl(3) module.

**Faithfulness classification (M2).** `ρ_x` is faithful if and only if
`k(x) ≥ 1` (otherwise the trivial Cl(3) action `γ_i ↦ 0` fails the
Clifford relation `γ_i² = 1 ≠ 0`, so `k(x) = 0` is the unfaithful
"zero-rep" class). Specifically:

- `k(x) = 1`: minimal faithful, `dim_C H_x = 2`; this is the canonical
  Pauli realization (positive- or negative-chirality summand alone).
- `k(x) ≥ 2`: faithful with multiplicity, `dim_C H_x = 2 k(x) ≥ 4`. The
  Cl(3) action is still faithful (each summand carries a faithful
  irrep), but contains a non-trivial isotypic component (multiple
  copies of the same irrep).

**Conditional sub-claim (C1).** *If* the per-site Hilbert space `H_x`
carries a single faithful Cl(3) module — i.e., `(n_+(x), n_-(x))` is
either `(1, 0)` or `(0, 1)`, equivalently `k(x) = 1` — *then*
`dim_C H_x = 2` exactly.

**Current-framework sub-claim (Q1).** On the current minimal-Quantum
framework surface, the primitive physical one-site carrier is one
qubit. The retained Cl(3) split identifies that carrier with one
faithful two-dimensional Pauli module. Thus the physical carrier has
`k(x) = 1` and `dim_C H_x = 2`. Multi-copy faithful modules `k >= 2`
remain valid abstract Cl(3) representations, but they are spectator
surfaces relative to the one-qubit primitive, not alternate physical
one-site carriers supplied by the current axiom.

**Conditional sub-claim (C2).** *If* additionally the canonical
positive-chirality convention is adopted (the framework-baseline
chirality choice recorded in `AXIOM_FIRST_CL3_PER_SITE_UNIQUENESS_THEOREM_NOTE_2026-04-29.md`
as the package convention), *then* the unique chirality summand is `ρ_+`
and `ρ_x(γ_i) = σ_i` on `H_x ≅ ℂ²` up to unitary conjugation.

**Honest scope.** This row closes only the single-module/dimension
piece on the current minimal-Quantum framework surface. It does not
derive staggered-Dirac dynamics, Grassmann statistics, cross-site
anticommutation, Kawamoto-Smit phases, chirality-as-physical-selection,
or the full realization gate. If the Quantum axiom's one-qubit carrier
is replaced by the abstract representation surface, the older
counterexamples `k >= 2` reappear and the theorem demotes back to the
conditional C1 statement.

## 5. Proof

### 5.0 Current minimal-Quantum surface (Q1)

By `MINIMAL_AXIOMS_2026-06-05.md`, the primitive physical local degree
of freedom at each site is one qubit; equivalently the primitive
one-site operator algebra is `A_x ~= M_2(C)`, equivalently `Cl(3,0)` in
the real-algebra reading. A one-qubit carrier is the standard
two-dimensional complex Pauli carrier. The retained Cl(3)
complexification split identifies the two chirality choices as the two
two-dimensional faithful complex module classes. Therefore the current
physical one-site carrier has total multiplicity `k = 1` and
`dim_C H_x = 2`.

This is not an algebra-only exclusion of multi-copy faithful
representations. It is the content of the current framework's primitive
one-qubit local carrier. If that axiom is dropped and one works on the
abstract representation surface only, sections 5.1-5.5 show that
`k >= 2` reappears as an admissible faithful Cl(3) module family. ∎

### 5.1 Multiplicity classification (M1)

By the cited retained narrow theorem
[`CL3_COMPLEXIFICATION_SPLIT_NARROW_THEOREM_NOTE_2026-05-10.md`](CL3_COMPLEXIFICATION_SPLIT_NARROW_THEOREM_NOTE_2026-05-10.md)
§(K4), the complexification `Cl(3,0) ⊗_R C ≅ M_2(C) ⊕ M_2(C)` is
semisimple with two two-dimensional irreducible module classes, and
standard finite-dimensional representation theory then gives that
every finite-dim complex representation decomposes as
`ρ_+^{n_+} ⊕ ρ_-^{n_-}` with `dim_C = 2(n_+ + n_-)`. The total
multiplicity index `k = n_+ + n_- ∈ Z_{≥0}` is well-defined. ∎

### 5.2 Faithfulness classification (M2)

If `k = 0`, the representation is the trivial zero-rep `ρ_x ≡ 0`, which
maps `γ_i ↦ 0`. But the Clifford relation `γ_i² = 1` requires
`ρ_x(γ_i)² = 1 ≠ 0`, contradiction. Hence the zero-rep is unfaithful
(in fact non-Clifford). Conversely, if `k ≥ 1`, at least one of `n_+`
or `n_-` is ≥ 1, so the representation contains a copy of `ρ_+` or
`ρ_-` (each faithful by (M1)). Since `ρ_+` and `ρ_-` are both faithful
2-dim irreps, their direct sums (of any multiplicity) are faithful
representations of `Cl(3,0)`. Hence `ρ_x` is faithful iff `k ≥ 1`. ∎

### 5.3 Conditional sub-claim (C1)

Assume `k(x) = 1`, i.e., `(n_+(x), n_-(x)) ∈ {(1, 0), (0, 1)}`. Then
`H_x = ρ_+` or `H_x = ρ_-`, in either case `dim_C H_x = 2`. ∎

### 5.4 Conditional sub-claim (C2)

Assume additionally the canonical positive-chirality convention. Then
the chirality choice is `(n_+, n_-) = (1, 0)`, so `H_x = ρ_+` and
`ρ_x(γ_i) = σ_i` on `H_x ≅ ℂ²` up to unitary conjugation. The
intertwiner uniqueness up to nonzero scalar within a chirality summand
follows from Schur's lemma applied to the simple module `ρ_+`. ∎

### 5.5 Counter-example surface: `k ≥ 2`

For each `k ≥ 2`, the representation `ρ_x = ρ_+^k` (`k` copies of the
positive-chirality irrep) gives a faithful Cl(3) representation on
`H_x ≅ ℂ^{2k}` of complex dimension `2k`. Similarly `ρ_-^k`,
`ρ_+^{k-1} ⊕ ρ_-`, etc., give other faithful representations of
dimension `2k`. These are not unitarily equivalent to the minimal
`k = 1` case (different complex dimensions, different isotypic
multiplicities), and none of them violate the abstract algebraic
surface (M1)-(M2). Hence `k = 1` is **not** forced by Cl(3)
representation theory alone.

These witnesses are not physical one-site carriers on the current
minimal-Quantum surface, because that surface starts with one primitive
qubit per site. They are spectator/multi-copy surfaces relative to the
current axiom, and they remain useful only as falsifiers for any
claim that the Cl(3) algebraic split by itself selects `k = 1`.

The older staggered-Dirac/Grassmann one-particle-per-site realization
also lands on `k = 1`, but it is no longer needed for this
single-module/dimension step on the current minimal-Quantum surface.
Specifically, the Grassmann per-site Fock construction
`H_x^G = span(|0⟩_x, |1⟩_x)` from a single
`(χ_x, χ̄_x)` Grassmann pair gives `dim_C H_x^G = 2`, matching `k = 1`.
Selecting more than one Grassmann pair per site would give
`dim_C H_x^G = 2^p` for `p` pairs, hence `k = 2^{p-1}` — a different
multiplicity-index selection. Those Grassmann variants are separate
realization-gate questions, not inputs to Q1.
