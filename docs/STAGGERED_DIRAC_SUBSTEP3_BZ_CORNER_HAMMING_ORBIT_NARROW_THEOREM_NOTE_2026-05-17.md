## 1. Claim scope

Let `(Z_2)^3 := {(b_1, b_2, b_3) : b_i ∈ {0, 1}}` be the 8-element
hypercube vertex set. Define the Hamming weight
`hw : (Z_2)^3 → {0, 1, 2, 3}` by `hw(b) := b_1 + b_2 + b_3`, the
symmetric group `S_3` action on `(Z_2)^3` by coordinate permutation
`(σ · b)_i := b_{σ^{-1}(i)}`, and the charge-conjugation involution
`c : (Z_2)^3 → (Z_2)^3` by `c(b) := (1, 1, 1) - b = (1 - b_1, 1 - b_2,
1 - b_3)`. The following abstract finite-set / finite-group facts hold.

- **(H1) Hypercube cardinality.** `|(Z_2)^3| = 2^3 = 8`. By exhaustive
  enumeration of `{0, 1}^3`.

- **(H2) Hamming-weight grading.** The map `hw` partitions `(Z_2)^3`
  into 4 disjoint level sets indexed by `k ∈ {0, 1, 2, 3}`:

  ```text
  L_k := {b ∈ (Z_2)^3 : hw(b) = k}.
  ```

  Their cardinalities satisfy `|L_k| = binomial(3, k)`, giving
  `(|L_0|, |L_1|, |L_2|, |L_3|) = (1, 3, 3, 1)`.

- **(H3) Binomial sum identity.** `∑_{k=0}^{3} binomial(3, k) =
  (1 + 1)^3 = 8 = |(Z_2)^3|`. The partition sum check
  `1 + 3 + 3 + 1 = 8` holds by direct arithmetic.

- **(H4) S_3 preserves Hamming weight.** For every `σ ∈ S_3` and every
  `b ∈ (Z_2)^3`, `hw(σ · b) = hw(b)`, since coordinate permutation
  reorders the sum `∑_i b_i` without changing its value.

- **(H5) S_3 acts transitively on each Hamming-weight level.** For
  every `k ∈ {0, 1, 2, 3}` and every pair `b, b' ∈ L_k`, there exists
  `σ ∈ S_3` with `σ · b = b'`. Specifically, choose `σ` to be any
  permutation of the index set `{1, 2, 3}` that sends
  `{i : b_i = 1}` to `{i : b'_i = 1}`; such `σ` exists because both
  index subsets have the same cardinality `k`. At `k = 0` and `k = 3`
  the level is a singleton, so transitivity is trivial; at `k = 1`
  and `k = 2` the level has 3 elements and `S_3` permutes them by the
  standard 3-point permutation action.

- **(H6) S_3-orbit decomposition equals Hamming-weight grading.** By
  (H4) every `S_3` orbit is contained in a single `L_k`; by (H5)
  every `L_k` is a single `S_3` orbit. Hence the 4 `S_3` orbits on
  `(Z_2)^3` are exactly the 4 Hamming-weight level sets:

  ```text
  (Z_2)^3 / S_3  =  {L_0, L_1, L_2, L_3}    (4 orbits, sizes (1, 3, 3, 1)).
  ```

  This is the unique `S_3`-orbit partition of `(Z_2)^3`.

- **(H7) Charge-conjugation involution pairs opposite-weight levels.**
  For every `b ∈ L_k`, `hw(c(b)) = 3 - hw(b)`, so `c(L_k) = L_{3-k}`.
  Hence `c` exchanges `L_0 ↔ L_3` and `L_1 ↔ L_2`. `c` commutes with
  every `σ ∈ S_3`: `c(σ · b) = (1,1,1) - σ · b = σ · ((1,1,1) - b) =
  σ · c(b)`, since `S_3` permutes the all-ones vector to itself. Hence
  `c` generates a `Z_2` subgroup of `Aut((Z_2)^3)` commuting with `S_3`,
  and the combined `S_3 × Z_2 = S_3 × ⟨c⟩` action has 2 orbits on
  `(Z_2)^3`:

  ```text
  O_paired   :=  L_0 ∪ L_3  (size 1 + 1 = 2),
  O_balanced :=  L_1 ∪ L_2  (size 3 + 3 = 6).
  ```

Facts (H1)-(H7) are abstract finite-set / finite-group statements on
the 8-element vertex set `(Z_2)^3` and the two finite groups `S_3`
(permutation) and `⟨c⟩ ≅ Z_2` (complementation). They make **no**
physics claim, consume no PDG value, and do not depend on any
framework axiom or any lattice-substrate carrier.

## 5. Proof

### 5.1 (H1) Hypercube cardinality

By definition, `(Z_2)^3 = {0, 1} × {0, 1} × {0, 1}`. By the standard
cardinality-of-Cartesian-product formula,
`|(Z_2)^3| = 2 · 2 · 2 = 8`. ∎

### 5.2 (H2) Hamming-weight grading

The map `hw : (Z_2)^3 → {0, 1, 2, 3}` is well-defined: for each
`b ∈ (Z_2)^3`, the sum `b_1 + b_2 + b_3` lies in `{0, 1, 2, 3}`
(each `b_i ∈ {0, 1}`). The fibers `L_k := hw^{-1}(k)` partition
`(Z_2)^3` into 4 disjoint level sets.

For each `k`, `|L_k| = card({b ∈ {0, 1}^3 : ∑_i b_i = k})`. A vector
`b ∈ {0, 1}^3` with weight `k` is uniquely specified by choosing
which `k` of the 3 coordinates are `1`; the number of such choices is
`binomial(3, k)`. Hence

```text
|L_0| = binomial(3, 0) = 1,
|L_1| = binomial(3, 1) = 3,
|L_2| = binomial(3, 2) = 3,
|L_3| = binomial(3, 3) = 1.
```

Explicit level sets:

```text
L_0 = {(0, 0, 0)},
L_1 = {(1, 0, 0), (0, 1, 0), (0, 0, 1)},
L_2 = {(1, 1, 0), (1, 0, 1), (0, 1, 1)},
L_3 = {(1, 1, 1)}.  ∎
```

### 5.3 (H3) Binomial sum identity

By the standard binomial identity

```text
∑_{k=0}^{n} binomial(n, k)  =  (1 + 1)^n  =  2^n
```

at `n = 3`, `∑_{k=0}^3 binomial(3, k) = 2^3 = 8`. Direct partition
sum check: `1 + 3 + 3 + 1 = 8 = |(Z_2)^3|` by (H1). ∎

### 5.4 (H4) S_3 preserves Hamming weight

The `S_3` action on `(Z_2)^3` is `(σ · b)_i := b_{σ^{-1}(i)}`. Then

```text
hw(σ · b)  =  ∑_{i=1}^{3} (σ · b)_i
            =  ∑_{i=1}^{3} b_{σ^{-1}(i)}
            =  ∑_{j=1}^{3} b_j        (relabel j := σ^{-1}(i))
            =  hw(b).
```

The relabeling step uses that `σ^{-1}` is a bijection of
`{1, 2, 3}`. Hence `hw` is `S_3`-invariant. ∎

### 5.5 (H5) S_3 transitivity on each level

For `k = 0`: `L_0 = {(0, 0, 0)}` is a singleton, trivially a single
`S_3` orbit. For `k = 3`: `L_3 = {(1, 1, 1)}` is a singleton, trivially
a single `S_3` orbit.

For `k = 1`: `L_1 = {e_1, e_2, e_3}` where `e_i` denotes the standard
basis vector. The action `σ · e_i = e_{σ(i)}` (by the definition
above), so `S_3` permutes `(e_1, e_2, e_3)` by the standard 3-point
permutation action and acts transitively (any `e_i → e_j` realized by
the transposition `(i j)` or any 3-cycle moving `i` to `j`).

For `k = 2`: `L_2 = {e_2 + e_3, e_1 + e_3, e_1 + e_2}` (writing
`(1, 1, 0) = e_1 + e_2`, etc.). Equivalently, write each weight-2
vector as `(1, 1, 1) - e_i = c(e_i)` for some `i ∈ {1, 2, 3}`. The
action of `σ` on `c(e_i)` is `σ · c(e_i) = σ · ((1,1,1) - e_i) =
(1,1,1) - σ · e_i = c(σ · e_i) = c(e_{σ(i)})`, so `S_3` permutes
`(c(e_1), c(e_2), c(e_3))` by the same 3-point action and acts
transitively.

Hence `S_3` acts transitively on each `L_k`. ∎

### 5.6 (H6) S_3-orbit decomposition equals Hamming-weight grading

By (H4), every `S_3` orbit `O ⊂ (Z_2)^3` is contained in a single
level set `L_{hw(b)}` (for any `b ∈ O`). By (H5), every level set
`L_k` is itself a single `S_3` orbit. Hence the 4 level sets `(L_0,
L_1, L_2, L_3)` are exactly the 4 `S_3` orbits of `(Z_2)^3`. The
orbit-cardinality vector is

```text
(|L_0|, |L_1|, |L_2|, |L_3|)  =  (1, 3, 3, 1),
```

summing to `2^3 = 8`. ∎

### 5.7 (H7) Charge-conjugation involution

The involution `c(b) := (1,1,1) - b` is well-defined on `(Z_2)^3`:
for `b ∈ {0, 1}^3`, `(1 - b_i) ∈ {0, 1}^3`. It satisfies
`c(c(b)) = (1,1,1) - ((1,1,1) - b) = b`, so `c` is an order-2
involution.

Weight effect: `hw(c(b)) = ∑_i (1 - b_i) = 3 - ∑_i b_i = 3 - hw(b)`.
Hence `c(L_k) = L_{3-k}`: `c` exchanges `L_0 ↔ L_3` and
`L_1 ↔ L_2`.

Commuting with `S_3`:

```text
c(σ · b)  =  (1,1,1) - σ · b
           =  σ · ((1,1,1) - b)        (since σ permutes the all-ones vector to itself)
           =  σ · c(b).
```

The step `(1,1,1) = σ · (1,1,1)` holds because every `σ ∈ S_3`
permutes the standard basis vectors and fixes their sum.

Hence `c` generates a `Z_2 = ⟨c⟩` subgroup of `Aut((Z_2)^3)`
commuting with the `S_3` action. The combined `S_3 × Z_2` action
has 2 orbits:

```text
O_paired    :=  L_0 ∪ c(L_0)  =  L_0 ∪ L_3  =  {(0,0,0), (1,1,1)},
O_balanced  :=  L_1 ∪ c(L_1)  =  L_1 ∪ L_2  =  L_1 ∪ L_2,
```

of sizes `|O_paired| = 1 + 1 = 2` and `|O_balanced| = 3 + 3 = 6`.
The combined orbit-cardinality vector is `(2, 6)`, summing to `8`. ∎
