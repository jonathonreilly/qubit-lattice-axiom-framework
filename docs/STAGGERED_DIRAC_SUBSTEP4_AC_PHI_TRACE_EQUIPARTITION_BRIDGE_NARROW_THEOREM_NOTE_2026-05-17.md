## 1. Claim scope

Let `V_3` be a 3-dimensional complex vector space with a fixed ordered
basis `(e_1, e_2, e_3)`. Let `C : V_3 → V_3` be the standard cyclic
permutation matrix in this basis,

```text
C  =  [[0, 1, 0],
       [0, 0, 1],
       [1, 0, 0]],                                                  (1)
```

so that `C^3 = I` and `C` generates the regular representation of `Z/3Z`
on `V_3`. Let `H : V_3 → V_3` be a Hermitian operator that **commutes
with `C`**, i.e., `[H, C] = 0`.

The following identities hold:

- **(P1) Circulant form.** Any such `H` has the unique decomposition

  ```text
  H  =  a I + b C + b̄ C^2,             a ∈ R, b ∈ C,                (2)
  ```

  imported as an algebraic identity from the cited retained Koide
  circulant character bridge narrow theorem.

- **(P2) Diagonal-entry equality (trace equipartition).** In the fixed
  basis `(e_1, e_2, e_3)`, every diagonal entry `⟨e_α | H | e_α⟩` equals
  the same scalar:

  ```text
  ⟨e_α | H | e_α⟩  =  a  =  Tr(H) / 3,    α = 1, 2, 3.              (3)
  ```

- **(P3) Trace identity for `H`.**

  ```text
  Tr(H)  =  3 a.                                                    (4)
  ```

  Hence the common diagonal value `a` is the trace-equipartition value
  `Tr(H) / 3`.

- **(P4) Spectrum vs diagonal separation.** The eigenvalue triple of
  `H` is `λ_k = a + b ω^k + b̄ ω^{-k}` for `k = 0, 1, 2` with
  `ω = e^{2π i / 3}`, by equation (3) of the cited retained Koide
  circulant character bridge narrow theorem. Equivalently
  `λ_k = a + 2|b| cos(arg(b) + 2π k / 3)`. For `b ≠ 0` outside the
  finite coincidence set, the three eigenvalues are pairwise distinct,
  while the diagonal entries are all equal to `a`. Hence **diagonal
  entries do not in general equal eigenvalues** for `Z/3Z`-equivariant
  Hermitian operators on `V_3`.

Facts (P1)-(P4) are exact algebraic identities on the abstract 3-dim
complex carrier with regular `Z/3Z` action, conditional on the cited
retained upstream narrow theorems. They make **no** claim that the
framework's hw=1 carrier on the physical lattice substrate IS this
3-dim `Z/3Z`-equivariant carrier; that bridge is carried by the open
staggered-Dirac realization gate and remains out of scope here.

## 5. Proof

### 5.1 (P1) Circulant form for `[H, C] = 0`

Import directly from the cited
`KOIDE_CIRCULANT_CHARACTER_BRIDGE_NARROW_THEOREM_NOTE_2026-05-09.md`:
a Hermitian `H : V_3 → V_3` commuting with the cyclic permutation `C`
has the form `H = a I + b C + b̄ C^2` with `a ∈ R` and `b ∈ C`. The
identity is recorded in equation (2) of that retained narrow theorem
and is conditional only on standard finite-dim commutant theory plus
Hermiticity (real diagonal coefficient + complex-conjugate pairing of
`C` and `C^2` coefficients). ∎

### 5.2 (P2) Diagonal-entry equality

Compute the diagonal entries `⟨e_α | H | e_α⟩` in the fixed basis
`(e_1, e_2, e_3)`. Using `H = a I + b C + b̄ C^2`,

```text
⟨e_α | H | e_α⟩  =  a ⟨e_α | e_α⟩ + b ⟨e_α | C e_α⟩ + b̄ ⟨e_α | C^2 e_α⟩.
```

The first term is `a`. The cyclic permutation `C` acts on the basis by

```text
C e_1 = e_3,   C e_2 = e_1,   C e_3 = e_2,                          (5)
```

so `⟨e_α | C e_α⟩ = 0` for all `α = 1, 2, 3` (the `C` matrix has zero
diagonal). Similarly,

```text
C^2 e_1 = e_2,   C^2 e_2 = e_3,   C^2 e_3 = e_1,                    (6)
```

so `⟨e_α | C^2 e_α⟩ = 0` for all `α = 1, 2, 3` (the `C^2` matrix also
has zero diagonal). Hence

```text
⟨e_α | H | e_α⟩  =  a    for α = 1, 2, 3.                          (7)
```

The common diagonal value is therefore independent of the basis index
`α`. ∎

### 5.3 (P3) Trace identity

By (P2), the three diagonal entries of `H` in the basis `(e_1, e_2, e_3)`
are all equal to `a`. By the standard linear-algebra formula
`Tr(H) = ∑_α ⟨e_α | H | e_α⟩`,

```text
Tr(H)  =  ⟨e_1|H|e_1⟩ + ⟨e_2|H|e_2⟩ + ⟨e_3|H|e_3⟩  =  3a.            (8)
```

Hence `a = Tr(H) / 3`, i.e., the common diagonal value of any
`C`-equivariant Hermitian `H` is the trace-equipartition value
`Tr(H) / 3`. ∎

### 5.4 (P4) Spectrum vs diagonal separation

By equation (3) of the cited
`KOIDE_CIRCULANT_CHARACTER_BRIDGE_NARROW_THEOREM_NOTE_2026-05-09.md`,
the eigenvalues of `H = a I + b C + b̄ C^2` are

```text
λ_k  =  a + b ω^k + b̄ ω^{-k}  =  a + 2|b| cos(arg(b) + 2π k / 3),   (9)
```

for `k = 0, 1, 2` and `ω = e^{2π i / 3}`. For `b ≠ 0` outside the
finite coincidence set, the three eigenvalues are pairwise distinct.

By (P2), the three diagonal entries are all equal to `a`. Compare:

```text
diagonal entries:    a, a, a                  (all equal)
eigenvalues:         a + 2|b| cos(θ + 2πk/3)  (generically 3 distinct values)
```

So for generic `b ≠ 0`, the three diagonal entries are **all equal**
while the three eigenvalues are **pairwise distinct**. The set of
diagonal entries is `{a}`; the set of eigenvalues is the spectrum.
Hence diagonal entries do NOT in general equal the eigenvalues on the
`Z/3Z`-equivariant carrier.

This separation is the structural content of the AC_φ atom on the
substep-4 abstract carrier: corner-basis expectation values are
identical (equipartitioned), while the operator spectrum carries the
distinct-eigenvalue triple. ∎

## 9. Validation

Primary runner:
[`scripts/audit_companion_staggered_dirac_substep4_ac_phi_trace_equipartition_bridge_2026_05_17.py`](../scripts/audit_companion_staggered_dirac_substep4_ac_phi_trace_equipartition_bridge_2026_05_17.py)
verifies via sympy exact symbolic arithmetic:

1. **(P1) Circulant form for `[H, C] = 0`.** Construct the cyclic
   matrix `C` and a generic Hermitian `H = a I + b C + b̄ C^2` with
   symbolic `a ∈ R, b ∈ C`. Verify `H · C = C · H` by direct symbolic
   matrix multiplication, confirming the circulant ansatz commutes with
   `C` for all `(a, b)`.
2. **(P1) Hermiticity check.** Verify `H = H^†` symbolically, i.e.,
   that the conjugate-transpose of `a I + b C + b̄ C^2` is itself.
3. **(P1) Reverse direction.** Pick a generic non-circulant Hermitian
   `H_bad` and verify symbolically that `[H_bad, C] ≠ 0`, confirming
   that the commutant of `C` is exactly the circulant algebra (a
   counter-example check that the ansatz is the *only* commuting form
   among Hermitians on `V_3`).
4. **(P2) Diagonal-entry equality.** Compute the three diagonal entries
   `⟨e_α | H | e_α⟩` for `α = 1, 2, 3` symbolically. Verify each equals
   `a` exactly.
5. **(P2) Pairwise difference.** Verify `⟨e_α|H|e_α⟩ − ⟨e_β|H|e_β⟩ = 0`
   symbolically for all pairs `(α, β) ∈ {1, 2, 3}^2`, confirming the
   identity is exact (not approximate).
6. **(P3) Trace identity.** Compute `Tr(H)` symbolically and verify
   it equals `3 a`.
7. **(P3) Equipartition.** Verify each diagonal entry equals `Tr(H)/3`
   symbolically.
8. **(P4) Eigenvalue formula.** Compute the three eigenvalues of `H`
   symbolically via the characteristic polynomial. Verify they match
   `λ_k = a + b ω^k + b̄ ω^{-k}` for `k = 0, 1, 2`.
9. **(P4) Distinctness for generic `b`.** Substitute a generic
   numerical value (e.g., `b = 1 + i/2`) and verify the three
   eigenvalues are pairwise distinct exactly.
10. **(P4) Diagonal-vs-eigenvalue separation.** Verify that the three
    diagonal entries `{a, a, a}` and the three eigenvalues are not
    equal as multisets for generic `b ≠ 0`.
11. **Counterexample: non-Hermitian commuter.** Verify that the matrix
    `b C + b̄' C^2` with `b̄' ≠ b̄` (i.e., violating the Hermitian
    coefficient pairing) still commutes with `C` but is *not* Hermitian,
    confirming that Hermiticity is load-bearing for the real-`a`,
    conjugate-`b̄`-pairing form in (P1).
12. **Coincidence-set boundary at `b = 0`.** Verify symbolically that
    when `b = 0`, all three eigenvalues equal `a` (the maximally
    degenerate case), matching the diagonal entries. The separation
    in (P4) appears strictly for `b ≠ 0`.
