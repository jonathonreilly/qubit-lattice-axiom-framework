narrower than full species-label closure and narrower than physical Standard

## Exact Algebra

Let `T_a = lambda_a / 2` be the Gell-Mann basis on `V_3 = C^3`. Then:

```text
Tr_{V_3}(T_a T_b) = (1/2) delta_ab.
```

Let `P` be any permutation matrix on the three `hw=1` corner labels. The
permuted basis has generators:

```text
T'_a = P T_a P^{-1}.
```

Trace cyclicity gives:

```text
Tr(T'_a T'_b) = Tr(P T_a P^{-1} P T_b P^{-1})
              = Tr(P T_a T_b P^{-1})
              = Tr(T_a T_b).
```

Therefore the species-label bijection is invisible to `N_F`. It can affect
which label is called `e`, `mu`, `tau`, etc.; it cannot change the trace
normalization.

The trace-surface choice itself is load-bearing. If the same generators are
traced on `V_full = V_3 x C^2`, the trace doubles:

```text
Tr_{V_full}(T_a x I_2)(T_b x I_2) = delta_ab.
```

So the `g_bare` route still needs the Wilson/Ward trace to be the structural
gauge trace on `V_3`, not the full matter tensor trace `V_3 x C^2`, unless a
separate theorem supplies an equivalent normalization quotient. This is why a
generic "staggered realization" closure is too coarse for the `g_bare` lane:
the trace target is the gauge carrier, while the full matter carrier carries
an extra weak-doublet multiplicity.
