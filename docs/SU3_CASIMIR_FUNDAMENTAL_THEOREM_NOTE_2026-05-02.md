## Proof

### Step 1 — SU(3)_c on V_3 (cited)

By cl3_color_automorphism_theorem, SU(3)_c acts on V_3 as
the fundamental "3" representation, with Gell-Mann generators T^a = λ^a / 2
in the standard basis (1).

### Step 2 — Direct finite-matrix identity (K1/K3)

The proof does not need Schur's lemma or the general SU(N) formula. It uses
the eight concrete matrices supplied by the cited framework source. Write
`T^a = lambda^a/2`. Squaring the Gell-Mann matrices gives diagonal matrices:

```text
lambda_1^2 = diag(1,1,0)    lambda_2^2 = diag(1,1,0)
lambda_3^2 = diag(1,1,0)    lambda_4^2 = diag(1,0,1)
lambda_5^2 = diag(1,0,1)    lambda_6^2 = diag(0,1,1)
lambda_7^2 = diag(0,1,1)    lambda_8^2 = (1/3) diag(1,1,4).
```

Therefore

```text
    Σ_a lambda_a^2
      = diag(16/3, 16/3, 16/3),

    Σ_a T^a T^a
      = (1/4) Σ_a lambda_a^2
      = diag(4/3, 4/3, 4/3)
      = (4/3) I_3.                                                       (4)
```

This establishes both the scalar identity and the exact value `4/3` on the
cited `V_3` carrier.

### Step 3 — Centrality (K2)

Since `C_2 = (4/3) I_3`, it commutes with every `3 x 3` matrix, hence in
particular with each generator `T^b`:

```text
    [C_2, T^b] = [(4/3) I_3, T^b] = 0.                                  (5)
```

This establishes centrality inside the framework-supplied `V_3` matrix
surface without a Schur reduction.

### Step 4 — Parallel textbook consistency check

The general fundamental SU(N) formula gives
`C_2(N) = (N^2 - 1)/(2N)`, hence `C_2(3) = 4/3`. This agrees with the
direct matrix proof above, but it is cited only as a parallel check.

### Conclusion of source proof (K1–K3)

Steps 1–3 establish (K1) the direct matrix identity
`C_2 = (4/3) I_3`, (K2) centrality, and (K3) the exact scalar value `4/3`.
No external representation-theory theorem is load-bearing in K1-K3. ∎
