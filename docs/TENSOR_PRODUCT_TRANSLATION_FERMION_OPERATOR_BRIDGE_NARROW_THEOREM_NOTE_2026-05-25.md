## Claim scope

Fix a finite block `Λ ⊂ Z^3` of `|Λ| = N` sites with periodic
identification (a finite-volume torus). On the framework's tensor-
product Fock space

```text
    H_Λ  :=  ⊗_{x ∈ Λ}  C²_x
```

— where each factor `C²_x` is the dim-two complex space supplied by the
one-qubit operator algebra on site `x` — let
`σ_+ := ( 0 0 ; 1 0 )`, `σ_- := ( 0 1 ; 0 0 )` be the standard ladder
matrices in the ordered basis `(|0>, |1>)`, and define the
**single-mode fermion
operators**

```text
    a_x   :=  ( I_{Λ \ {x}} )  ⊗  σ_-^{(x)},
    a_x^† :=  ( I_{Λ \ {x}} )  ⊗  σ_+^{(x)},                            (1)
```

acting as the indicated ladder matrix on the factor `C²_x` and as the
identity on every other factor.

For each lattice vector `a ∈ Z^3`, define the **tensor-permutation
cyclic-shift unitary** `T_a` on `H_Λ` by linear extension of its action
on tensor-product basis states:

```text
    T_a · ( ⊗_{x ∈ Λ}  |b_x⟩_x )  :=  ⊗_{x ∈ Λ}  |b_{x - a}⟩_x.        (2)
```

Equivalently, `T_a` permutes tensor factors so that the content at site
`x - a` moves into the slot indexed by `x` (active translation by `a`).

Define the **total fermion-number operator**

```text
    Q_total  :=  ∑_{x ∈ Λ}  a_x^† a_x                                   (3)
```

acting on `H_Λ`.

Then:

**(T1) Unitarity.** `T_a T_a^† = T_a^† T_a = I_{H_Λ}` for every `a ∈ Z^3`.

**(T2) Group law.** `T_a T_b = T_{a + b}` for every `a, b ∈ Z^3`; in
particular `T_0 = I` and `T_a^{-1} = T_{-a} = T_a^†`.

**(T3) Fermion-operator covariance.**
```text
    T_a · a_x · T_a^†   =   a_{x + a},
    T_a · a_x^† · T_a^† =   a_{x + a}^†.                                (4)
```
(Periodic identification on `Λ` for the right-hand-side site label.)

**(T4) Charge conservation.** `[T_a, Q_total] = 0` for every `a ∈ Z^3`,
equivalently `T_a Q_total T_a^† = Q_total`.

(T1)-(T4) are baseline-direct: the one-qubit operator algebra supplies
the per-site dim-two complex factor on which the ladder matrices are
defined, and the `Z^3` spatial substrate supplies the standard translation
structure on `Λ`.

## Proof

Let `|b⟩ := ⊗_{x ∈ Λ} |b_x⟩_x` denote a generic tensor-product basis
state of `H_Λ`, where each `|b_x⟩_x ∈ {|0⟩_x, |1⟩_x}` is a standard
basis vector of `C²_x`. Such states form an orthonormal basis of
`H_Λ`, and `T_a` is defined on basis states by (2) and extended by
linearity.

### (T1) Unitarity

Equation (2) is a permutation of the orthonormal basis `{|b⟩}` of
`H_Λ`. A linear map that permutes an orthonormal basis is unitary
(`T_a^†` then permutes the same basis by the inverse permutation
`x ↦ x + a` on labels, which corresponds to `b_x ↦ b_{x + a}` in the
ket content). Explicitly,

```text
    ⟨b | T_a^† T_a | b'⟩
      = ⟨T_a b | T_a b'⟩
      = ⟨ ⊗_x |b_{x - a}⟩  |  ⊗_x |b'_{x - a}⟩ ⟩
      = ∏_x δ_{b_{x - a}, b'_{x - a}}
      = ∏_y δ_{b_y, b'_y}            (relabel y := x - a, bijection on Λ)
      = ⟨b | b'⟩.
```

So `T_a^† T_a = I` on the orthonormal basis, hence on all of `H_Λ`;
similarly `T_a T_a^† = I`. ∎

### (T2) Group law

On any basis state,

```text
    (T_a T_b)(⊗_x |b_x⟩_x)
      = T_a ( ⊗_x |b_{x - b}⟩_x )
      = ⊗_x |b_{(x - a) - b}⟩_x
      = ⊗_x |b_{x - (a + b)}⟩_x
      = T_{a + b} (⊗_x |b_x⟩_x).
```

By linearity this holds on all of `H_Λ`. Taking `b = -a` gives
`T_a T_{-a} = T_0 = I`, and the inverse-equals-adjoint identity
follows from (T1). ∎

### (T3) Fermion-operator covariance

We prove `T_a a_x T_a^† = a_{x + a}`; the conjugate identity follows by
taking adjoints. Both sides are linear, so it suffices to check the
action on a basis state `|b⟩`.

Apply the right-hand side first. By construction (1), `a_{x + a}` acts
as `σ_-` on factor `x + a` and as the identity on every other factor:

```text
    a_{x + a} |b⟩
      =  ⊗_{y ≠ x + a} |b_y⟩_y   ⊗   σ_- |b_{x + a}⟩_{x + a}
      =  δ_{b_{x + a}, 1}  ·  ( ⊗_{y ≠ x + a} |b_y⟩_y  ⊗  |0⟩_{x + a} )
                                                                       (5)
```

(`σ_-|1⟩ = |0⟩`, `σ_- |0⟩ = 0`, so the action selects the configurations
with `b_{x + a} = 1`.)

Now apply the left-hand side. First,

```text
    T_a^† |b⟩
      =  T_{-a} |b⟩
      =  ⊗_y |b_{y + a}⟩_y                                              (6)
```

— i.e. the ket at factor `y` carries the content originally at site
`y + a`. Next, `a_x` acts as `σ_-` on factor `x`:

```text
    a_x T_a^† |b⟩
      =  ( ⊗_{y ≠ x} |b_{y + a}⟩_y )  ⊗  σ_- |b_{x + a}⟩_x
      =  δ_{b_{x + a}, 1}  ·  ( ⊗_{y ≠ x} |b_{y + a}⟩_y  ⊗  |0⟩_x ).    (7)
```

Finally, apply `T_a`. Using definition (2), `T_a` sends factor-content
`|c_y⟩_y` (at factor `y`) to `|c_{y - a}⟩_y` (at factor `y`), so the
ket sitting at factor `y` after `T_a` carries content originally
indexed at factor `y - a`. Writing the right-hand side of (7) as
`⊗_y |c_y⟩_y` with `c_y = b_{y + a}` for `y ≠ x` and `c_x = 0`, then

```text
    T_a · ( ⊗_y |c_y⟩_y )  =  ⊗_y |c_{y - a}⟩_y.
```

For the new factor at `y`, the content is `c_{y - a}`:
- if `y - a ≠ x`, then `c_{y - a} = b_{(y - a) + a} = b_y`;
- if `y - a = x`, i.e. `y = x + a`, then `c_{y - a} = c_x = 0`.

So the result equals

```text
    δ_{b_{x + a}, 1}  ·  ( ⊗_{y ≠ x + a} |b_y⟩_y  ⊗  |0⟩_{x + a} ).
```

This matches the right-hand-side (5). Hence

```text
    T_a a_x T_a^† |b⟩  =  a_{x + a} |b⟩
```

on every basis state, and by linearity on all of `H_Λ`. So
`T_a a_x T_a^† = a_{x + a}`. Taking adjoints (using `T_a` unitary)
gives `T_a a_x^† T_a^† = a_{x + a}^†`. ∎

### (T4) Charge conservation

By (T3),

```text
    T_a Q_total T_a^†
      =  T_a ( ∑_x a_x^† a_x ) T_a^†
      =  ∑_x ( T_a a_x^† T_a^† )( T_a a_x T_a^† )
      =  ∑_x a_{x + a}^† a_{x + a}                                      (8)
      =  ∑_{y ∈ Λ} a_y^† a_y                                            (relabel)
      =  Q_total.
```

(The relabel `y := x + a` is a bijection on `Λ` under the periodic
identification.) Hence `[T_a, Q_total] = 0`. ∎
