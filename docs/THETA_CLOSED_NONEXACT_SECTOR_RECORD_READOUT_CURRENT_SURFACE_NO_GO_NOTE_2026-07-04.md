## Route Fan-Out

### Frame 1: the closed non-exact carrier exists as a witness

The finite `T^4` cochain algebra is real progress. The runner rechecks that
the six unit-flux representatives are closed but not exact, and that a
complementary pair has

```text
Q_raw = 2,    Q = 1.
```

So the target object is not empty. The missing question is not whether
closed non-exact classes exist. The missing question is why the physical
theta gauge surface carries those classes as records/readout content.

### Frame 2: Record does not create the sector context

Record now includes occurrence: records form. But the axiom only says that,
when present, a record locks one admissible local possibility and that scalar
readout is determined by record content. It does not identify the gauge
sector, choose a branch section, impose `dn=0`, select a cohomology quotient,
construct an `SU(3)` torus-dual carrier, or declare the flux pairing to be a
physical observable.

Thus the Record axiom can read an already-licensed sector record. It does not
license which theta sector record exists.

### Frame 3: Admissibility does not select closed non-exactness

Admissibility determines local availability from nearest-neighbor
conditions. It is not a dynamics axiom and supplies no Hamiltonian, transfer
operator, action, measure, probability, suppression rule, or sector-weighting
law. It therefore cannot by itself prefer closed non-exact branch classes over
open-defect classes or globally exact classes.

### Frame 4: reconstruction support is not physical registration

The July theta support stack has the right shape:

- 2D spectral-flow supplier;
- 4D closed-branch cohomology carrier;
- torus-dual and Cartan-valued reconstruction surfaces;
- link-star/frame-correlation gluing support.

Those notes repeatedly state their boundary: no physical record/readout
registration, no 4D physical `SU(3)` sector, no continuum identification, no
record occurrence claim for the sector labels, and no theta retirement. That
is not a weakness of those notes. It is exactly the missing G2 bridge.

### Frame 5: exactness remains the wrong closure mechanism

Global exactness `n=dA` supplies `dn=0` but kills the quotient
`ker d2 / im d1` and forces `Q=0`. Therefore the sector-record route cannot
be repaired by replacing physical closed non-exact records with exact branch
records.


registration. The theta gauge-side winding account therefore remains live.
