## Claim

In a supplied per-plaquette action class

`A = sum_{plaquettes P} f(U_P)`,

each local summand depends on one plaquette plane. The continuum coefficient
of a local cross-plane monomial such as `F_01 F_23`, `F_02 F_13`, or
`F_03 F_12` is therefore a mixed derivative of a sum of single-plane
functions. Those mixed derivatives vanish identically for arbitrary `f`.

Equivalently, the local `F tilde F` density is a four-direction cross-plane
object, while a single plaquette supplies only two directions. Within the
supplied per-plaquette class, there is no local cross-plane `F tilde F` slot.

This is a theorem about the supplied action class, not a derivation of that
class.
