## Question

The parent 4D carrier note proves that the theta-sector carrier exists only
on the closed-branch subsurface. Its defect boundary says:

> "no class function exists and no sector decomposition survives on the unrestricted branch sum"

The parent note then leaves the forward question open:

> "whether the framework's Admissibility rule bears on it is an open forward question, not asserted here"

The minimal axiom sentence tested here is:

> "For each site, the available possibilities are determined by, and vary with, the nearest-neighbor conditions."

This note runs that test on the parent finite complex. The result is negative:
under the explicit encoding below, nearest-neighbor single-valued availability
does not force branch closure.

## Tested Encoding

The parent runner's branch grading is used without changing it:

- complex: the cubical cochain complex of `T^4_2`;
- branch datum: integer 2-cochain `n` on plaquettes `(x; mu, nu)`;
- defect datum: integer 3-cochain `dn` on cubes;
- closure target: `dn = 0` on every cube.

Encoding E1 is the supplied Admissibility reading tested here:

- each plaquette branch value is treated as a singleton local possibility;
- nearest-neighbor supplied-cell conditions are binary conditions `c(x)` on
  incident anchor vertices of the parent cubical cells;
- the fixed single-valued local rule is

```text
n(x; mu, nu) = c(x).
```

This is a modeling premise. The parent note grounds the branch cochain and the
defect cochain, but it does not ground the identification of branch data with
Admissibility-governed possibility structure. Its N6 sentence quoted above is
the guard against treating that identification as already supplied.

The runner exhausts all `2^16 = 65536` binary condition fields on the vertices
of `T^4_2`, hence all branch assignments generated by E1. It does not exhaust
the unbounded integer 2-cochain space, and no statement here extends beyond
this tested finite encoding.

## Result

Forcing fails.

The exhaustive E1 count is:

```text
closed=2 open=65534 total=65536
```

An explicit counterexample is the condition field

```text
c(0,0,0,0) = 1,
c(x) = 0 for every other vertex.
```

The fixed local rule then gives `n = 1` on the six plaquettes anchored at
`(0,0,0,0)` and `n = 0` elsewhere. This branch assignment is single-valued and
neighbor-determined under E1, but its cube coboundary is nonzero. The runner
prints, among other nonzero entries:

```text
dn((0,0,0,0); 0,1,2) = -1
dn((0,0,1,0); 0,1,2) = 1
dn((0,1,0,0); 0,1,2) = -1
dn((1,0,0,0); 0,1,2) = 1
```

So the sentence "branch assignment is a single-valued function of neighboring
conditions" is weaker than the cocycle equation `dn = 0`. It supplies locality
of availability, not the oriented face-cancellation condition around each cube.

## Sharpened Wall

Under E1, Admissibility does not close sub-wall `(i-a)`. The sharpened wall is:

```text
defect closure still requires an additional cube-compatibility condition:
either an explicit cocycle/Bianchi rule dn = 0, a branch-from-potential
construction whose coboundary squares to zero together with closed flux
representatives, or a separate dynamical suppression of dn != 0 branches.
Nearest-neighbor determination alone does not supply that structure.
```

The negative control matches the parent boundary: if the neighbor-determination
requirement is dropped entirely, a single plaquette branch assignment already
has `dn != 0`.
