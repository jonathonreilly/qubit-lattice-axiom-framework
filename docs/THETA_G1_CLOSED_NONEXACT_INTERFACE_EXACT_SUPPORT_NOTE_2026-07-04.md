## Supplied Closed-Nonexact Interface

This note studies the following supplied interface. It is not asserted to be
present in the current axioms.

```text
I1. The physical branch variable n is an integer 2-cochain on the 4D
    multi-plaquette carrier and satisfies d n = 0.
I2. Local branch changes act by exact 2-cochains, n -> n + d a.
I3. Non-exact H^2 classes are allowed; the interface does not impose n = d a.
I4. Branches with d n != 0 are outside the sector, or are dynamically
    suppressed by a separate theorem.
```

This is a G1 interface only. It does not supply G2 physical sector/readout
registration, G3 phase coefficient/action entry, G4 theta-bar assembly, or the
mass-side determinant bridge.

## Exact Support Theorem

On the finite `T^4_2` cubical cochain surface used by the theta carrier:

1. `rank d1 = 45`, `rank d2 = 45`, and

   ```text
   dim H^2(T^4_2, Z) = dim ker d2 - rank d1 = 51 - 45 = 6.
   ```

   Closed non-exact sectors exist.
2. The six unit plane-flux representatives are closed and non-exact.
3. The complementary closed non-exact branch

   ```text
   n = e01 + e23
   ```

   has `Q_raw = sum n cup n = 2`, i.e. integer theta charge `Q = 1` under the
   carrier normalization.
4. Exact local branch changes preserve both closedness and `Q_raw` inside this
   closed-nonexact sector.
5. Exact branches alone have `Q_raw = 0`, so exactness is too strong.
6. A single defect plaquette has `dn != 0`; exact branch moves preserve the
   defect current but change `Q_raw` through `{-2, -1, 0, 1, 2}`. Thus the
   unrestricted defectful branch family has no class-stable theta charge.

Therefore the supplied interface `I1-I4` is a precise positive G1 shape that
survives the no-go stack: it closes defects without requiring global exactness
and without deleting the nontrivial theta carrier.
