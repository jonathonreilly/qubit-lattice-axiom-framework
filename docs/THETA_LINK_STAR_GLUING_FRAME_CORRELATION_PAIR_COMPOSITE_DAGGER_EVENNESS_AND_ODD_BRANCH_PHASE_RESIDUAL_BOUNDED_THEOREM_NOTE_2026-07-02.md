## Answer

Four exact results (SU(2) quadrature-verified against closed forms derived
before implementation; one pre-computation expectation REFUTED by the
numbers and replaced by the stronger theorem it revealed):

1. **Pairs: the relative frame rides the composite holonomy.** For two
   plaquettes sharing a link, integrating the shared variable gives exactly

   ```text
   Int dV w_1(V S_1) w_2(V S_2)      = sum_R (c1_R c2_R / d_R) chi_R(S_2^dag S_1),
   Int dV w_1(V S_1) w_2(V^dag S_2)  = sum_R (c1_R c2_R / d_R) chi_R(S_2 S_1),
   ```

   — a class function of ONE composite (relative) holonomy. The relative
   Cartan/Weyl frame between the two plaquettes is carried by physical field
   content, never chosen. This holds for any plane pair sharing a link —
   including cross-plane adjacent pairs, the elementary steps toward the
   complementary-plane pairs the theta pairing consumes. (Runner A1-A4:
   closed forms match quadrature to <= 2.3e-4 at tolerance 3e-3; common
   left-multiplication invariance confirms composite dependence; the
   one-staple-rotation gate discriminates with differences 0.21-0.28.)

2. **Stars are exactly diagonal-conjugation objects.** For any link star
   `G(S_1..S_k) = Int dV prod_p w_p(V^{eps_p} S_p)`, the substitution
   `V -> g V g^dag` proves invariance under the simultaneous conjugation
   `S_p -> g S_p g^dag` of all staples — while independent conjugation of a
   single staple changes the value (witness difference 0.36) with the
   separate classes exactly unchanged (trace drift 2e-16). Gluing therefore
   outputs precisely joint-orbit functions: the group-level source of block
   5's "diagonal Weyl orbit suffices, per-plane orbits underdetermine."
   (Runner B1-B3.)

3. **Refuted expectation, stronger theorem: real-weight gluing is
   orientation-reversal-even.** The design expectation was that the k = 3
   star depends on the antisymmetric triple invariant (the
   `tr(ABC) - tr(ACB)` branch), witnessed by the dagger triple — which
   preserves all separate and pairwise composite traces (runner C1, exact)
   while flipping the triple branch (C2, difference 0.179). The computation
   refuted the expectation: the star value at the dagger triple is
   **identical** (C3, difference exactly 0 on the reversal-symmetric grid).
   The reason is an exact identity: substituting `V -> V^dag` and using
   `w(X^dag) = w(X)` for real class weights (with cyclicity),

   ```text
   G(S_1^dag, ..., S_k^dag) = G(S_1, ..., S_k)
   ```

   for ANY compact group, any star size, any real class weights. Combined
   with the SU(2) symmetric trace identity (runner C4, exact:
   `tr(ABC) + tr(ACB)` is generated by separate and pairwise traces), this
   gives: **the SU(2) link star is a function of separate + pairwise
   composite classes alone.** Two consequences cut in opposite directions:

   - *Positive:* for SU(2), pair composites supply ALL the joint data stars
     carry — the frame correlation (i-b'') asks for is pairwise-reducible
     there; Theorem 1 already derives the pairwise data.
   - *Negative (scoped):* real-weight gluing CANNOT register the
     orientation-odd branch. The odd triple invariant is exactly the
     parity-odd datum class a theta insertion lives in — so the theta
     structure must enter through an odd-branch-sensitive (phase/complex)
     weighting, not through real gluing weights. This is the third
     independent arrow at the same target: block 3 derived the pairing
     reduction of the `F u F` slot, block 4 obstructed the per-plaquette
     shift slot, and this block shows real gluing weights are blind to the
     odd branch — all pointing at residual (ii'), the phase-type
     multi-plaquette insertion.

4. **Chains and loops: frame transport is configurational.** The transport
   identity `Int dV chi_j(A V) chi_j(V^dag B) = chi_j(A B)/d_j` (runner D1)
   composes: a two-step chain equals one-step transport through the
