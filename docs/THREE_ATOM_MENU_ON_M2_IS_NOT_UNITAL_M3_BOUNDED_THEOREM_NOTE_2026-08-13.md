```text
P0 = |0><0| = [[1, 0], [0, 0]]
```

with exact `Fraction` entries. These are pairwise distinct. Each is a

The unital `C*`-algebra generated by `{P0, P1, P+}` is all of `M_2(C)`:
already `P0 + P1 = I_2`, and `P+` supplies the off-diagonal matrix units.
The complex dimension is `4`, not `9`. The generated algebra is therefore
**not** `M_3(C)`.

There is still no unital `*`-homomorphism `M_3(C) → M_2(C)`, because a
unital `C`-linear `*`-hom `M_k(C) → M_m(C)` exists if and only if `k | m`,
and `3 ∤ 2`. A 3-atom menu is not a unital `M_3` factor.

This leftover does not install `SU(3)`, name QCD, select color, or rewrite
Qubit. It only separates “three lockable possibilities” from a
unital `M_3` host algebra. No central decomposition is invented to fit `SU(3)`.
No `r = 1/2` axiom is adopted.

## Theorem 1 — A 3-atom menu is a type of support

`{P0, P1, P+}` is a 3-element subset of the one-site possibility domain.
Each element is a rank-1 projection, hence a possible lock content.

Admissibility states that the probability distribution over the
possibilities is determined by nearest-neighbour conditions, and that
“available” / “admissible” denotes its support. A law-level distribution
`μ` with these three rays as support is therefore allowed *as a type*.

The equal-weight triple `μ = (1/3, 1/3, 1/3)` is displayed as a test
object only. This note does not adopt those weights. It does not claim
nearest-neighbour covariance of this particular menu.

## Theorem 3 — The generated algebra is `M_2(C)`, not `M_3(C)`

The unital `*`-algebra generated by `{P0, P1, P+}` is all of `M_2(C)`.

**Proof.** `P0 + P1 = I_2`, so the unit is in the algebra. The products

```text
P0 P+ = ((1/2, 1/2), (0, 0))
P+ P0 = ((1/2, 0), (1/2, 0))
```

are in the algebra. Then

```text
E_{01} = 2 P0 P+ − P0 = ((0, 1), (0, 0))
E_{10} = 2 P+ P0 − P0 = ((0, 0), (1, 0))
```

together with `P0 = E_{00}` and `P1 = E_{11}` are the four matrix units.
The `Q`-span (hence the `C`-span) is four-dimensional. Therefore

```text
dim_C C*(P0, P1, P+) = 4 = dim_C M_2(C),
```

and the generated algebra is all of `M_2(C)`. It is **not** `M_3(C)`,
because `dim_C M_3(C) = 9` and `4 ≠ 9`.

The same comparison is the first required mutation predicate: the
statement `dim generated algebra == 9` is false.

## Theorem 4 — Still no unital `M_3 → M_2`

There is still no unital `*`-homomorphism `M_3(C) → M_2(C)`.

**Proof.** A unital `C`-linear `*`-hom `M_k(C) → M_m(C)` exists if and
only if `k | m`. Here `k = 3` and `m = 2`. The integer remainder
`2 mod 3` equals `2`, so `3 ∤ 2`. Hence no such unital homomorphism
exists.

A 3-atom menu is therefore not a unital `M_3` factor. Three lockable
rays inside `M_2(C)` do not install a copy of `M_3(C)` as a unital
`*`-subalgebra or as a unital image.

The second required mutation predicate — “a unital `M_3 → M_2`
exists” — fails.

This is a type obstruction. It does not invent a central decomposition
of `M_2(C)` to fit `SU(3)`. The centre of `M_2(C)` is scalars; it has
no three-way central splitting.
