## Statement

Fix a finite periodic block
`Lambda = Z/L_x Z x Z/L_y Z x Z/L_z Z` and the tensor-product Fock space
`H_Lambda` from the cited bridge. For each translation vector `a`, let
`T_a` be the tensor-permutation unitary defined there.

Then:

**(G1) Identity.** `T_0 = I`.

**(G2) Closure and composition.**

```text
    T_a T_b = T_{a+b}.                                  (1)
```

**(G3) Abelian commutativity.**

```text
    [T_a,T_b] = 0.                                      (2)
```

**(G4) Unitary inverse.**

```text
    T_a^dag = T_a^{-1} = T_{-a}.                        (3)
```

**(G5) Finite quotient faithfulness.** If `a` is not zero in the finite
periodic quotient, then `T_a != I`. Equivalently, as a representation of
the quotient translation group, the kernel is trivial.

## Proof

### Step 1 - Identity, closure, and inverse

The cited bridge proves unitarity and group law directly from the
tensor-permutation definition:

```text
    T_a T_b = T_{a+b},     T_0 = I,     T_a^{-1} = T_{-a} = T_a^dag.
```

This proves (G1), (G2), and (G4).

### Step 2 - Commutativity

Periodic lattice-vector addition is abelian:

```text
    a + b = b + a.
```

Therefore, using the group law,

```text
    T_a T_b = T_{a+b} = T_{b+a} = T_b T_a,
```

so `[T_a,T_b]=0`, proving (G3).

### Step 3 - Faithfulness on the finite quotient

Let `a` be nonzero in the finite periodic quotient. Then there exists at
least one site `x` with `x+a != x`. Consider the occupation-basis vector
with `b_x = 1` and `b_y = 0` for every `y != x`. The tensor-permutation
definition sends this one-occupied-site basis vector to the basis vector
with the occupied site at `x+a`, which is a distinct orthonormal basis
vector. Hence `T_a` does not act as the identity. The only quotient
element in the kernel is therefore the zero element. This proves (G5).
QED.
