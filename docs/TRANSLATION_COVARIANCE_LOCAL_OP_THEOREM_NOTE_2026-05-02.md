## Statement

Fix a finite periodic block `Lambda` and tensor-product Fock space
`H_Lambda` as in the cited bridge. For a local `2 x 2` matrix `M`, write
`M_x` for the operator acting by `M` on the factor `C^2_x` and by the
identity on all other factors.

Then:

**(C1) Single-site covariance.** For every translation `T_a`,

```text
    T_a M_x T_a^dag = M_{x+a}.                         (1)
```

**(C2) Finite support covariance.** If
`O_S = product_{x in S} M_x^{(x)}` is a finite product of single-site
operators on support set `S`, then

```text
    T_a O_S T_a^dag = O_{S+a}.                         (2)
```

where each support label is shifted by `a` modulo the finite block.

**(C3) Translation-invariant sums.** If a finite operator family satisfies
`O_{x+a} = T_a O_x T_a^dag` and the summation set is invariant under
periodic translation, then

```text
    T_a (sum_x O_x) T_a^dag = sum_x O_x,
```

equivalently `[T_a, sum_x O_x] = 0`.

**(C4) Density and hopping examples.** The number density
`n_x := a_x^dag a_x` and hopping monomial `a_x^dag a_y` obey

```text
    T_a n_x T_a^dag = n_{x+a},
    T_a (a_x^dag a_y) T_a^dag = a_{x+a}^dag a_{y+a}.    (3)
```

## Proof

### Step 1 - Local matrix basis

On each local `C^2_x` factor, the four matrices

```text
    I, a, a^dag, n := a^dag a
```

span `M_2(C)`. Therefore any local matrix `M_x` has a decomposition

```text
    M_x = c_0 I + c_- a_x + c_+ a_x^dag + c_n n_x.      (4)
```

### Step 2 - Covariance of the basis

The cited bridge gives

```text
    T_a a_x T_a^dag = a_{x+a},
    T_a a_x^dag T_a^dag = a_{x+a}^dag.
```

It also gives unitarity, hence `T_a I T_a^dag = I`. Multiplying the two
ladder identities gives

```text
    T_a n_x T_a^dag
      = (T_a a_x^dag T_a^dag)(T_a a_x T_a^dag)
      = a_{x+a}^dag a_{x+a}
      = n_{x+a}.                                      (5)
```

By linearity in (4), `T_a M_x T_a^dag = M_{x+a}` for every single-site
matrix `M`. This proves (C1).

### Step 3 - Finite support products

For a finite product `O_S = product_{x in S} M_x^{(x)}`, conjugation by
the unitary `T_a` distributes over products:

```text
    T_a O_S T_a^dag
      = product_{x in S} (T_a M_x^{(x)} T_a^dag)
      = product_{x in S} M_{x+a}^{(x)}
      = O_{S+a}.                                      (6)
```

This proves (C2). Equation (3) is the two-site case with
`M_x = a_x^dag` and `M_y = a_y`, while the density case is (5), proving
(C4).

### Step 4 - Translation-invariant sums

For a translation-invariant finite family,

```text
    T_a (sum_x O_x) T_a^dag
      = sum_x T_a O_x T_a^dag
      = sum_x O_{x+a}
      = sum_y O_y,
```

where the final equality is the periodic relabeling `y = x+a`. Thus the
sum commutes with `T_a`, proving (C3). QED.
