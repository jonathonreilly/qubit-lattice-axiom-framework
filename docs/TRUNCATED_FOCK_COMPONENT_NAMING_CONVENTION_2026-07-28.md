# Truncated-Fock two-component naming convention

Date: 2026-07-28

Authority: none

Audit: unset

Status: meta convention

Claim type: meta

## Convention

When a directional q state is supplied with two equal bookkeeping components,
the component labels may be written `(F_d,A_d)`.

This is a naming convention only. It does not derive the equal split, assert
that the labels are independent state-space factors, construct either
carrier, or supply a physical source, response, calibration, or gravity law.
Algebraic statements should use the explicit component weights and remain
valid independently of these names.
