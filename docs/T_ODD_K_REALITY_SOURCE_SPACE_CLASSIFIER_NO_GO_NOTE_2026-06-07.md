## Theorem

Let `V = C^3` be the supplied generation carrier with cyclic shift `C`, fixed
`K` as entrywise conjugation, and `S = C + C^2`. Let
`P0 = (1/3)11^T` be the singlet projector and `P1 = I-P0` the doublet
projector, so `S = 3P0 - I`.

The K-odd Hermitian generation-factor operators split orthogonally as

```text
{T = T^*, K(T)=-T}
  = span_R{ A = i(C-C^2) }  direct-sum  B_bridge.
```

The two summands have different physical meaning:

1. `span_R{A}` is the known K-odd `C3` current. It commutes with `C`, commutes
   with `S`, and is partition-blind. It cannot source the K-reality predicate,
   matching the 2026-06-06 G2 current no-go.

2. `B_bridge` is exactly the real two-dimensional space of singlet-doublet
   bridges:

   ```text
   B_bridge = { T : P0 T P0 = 0, P1 T P1 = 0, T = T^*, K(T)=-T }.
   ```

   A bridge `T` is nonzero iff `[T,S] != 0`. Equivalently, a noncommuting
   T-odd candidate is the same datum as a nonzero vector in the doublet plane:

   ```text
   q(T) = P1 T u,       u = (1,1,1)/sqrt(3).
   ```

3. Conjugation by `C` fixes `A` and rotates `B_bridge` as the faithful
   two-dimensional `C3` irrep. Therefore

   ```text
   (T + CTC^-1 + C^2 T C^-2)/3
      = projection of T onto span_R{A},
   ```

   and the noncommuting bridge component is killed by `C3` averaging. There is
   no nonzero `C3`-fixed vector in `B_bridge`.

4. On unit bridge candidates, scalar signatures such as spectrum and
   commutator norm are angle-blind:

   ```text
   eig(T) = {-1,0,+1},        ||[T,S]||_F = 3 sqrt(2).
   ```

   The commutant rotation generated by `A` moves bridge orientations
   continuously while preserving `C`, `S`, and those scalar invariants.

Hence a T-odd noncommuting K-reality source is not supplied by the finite
generation algebra as a scalar invariant or as a `C3`-equivariant object. It is
equivalent to supplying a physical `C3`-breaking doublet vector/section. This is
the exact object a future frontier route must derive.
