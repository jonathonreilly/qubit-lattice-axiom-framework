## Theorem

Let `n >= 1`, let `V = C^n` with standard orthonormal basis
`e_1, ..., e_n`, and let `E_jk in End(V)` denote the matrix unit satisfying
`E_jk e_l = delta_kl e_j`. Suppose `H in End(V)` satisfies:

1. `H >= 0` (positive semidefinite, hence Hermitian);
2. `[H, E_jk] = 0` for every `1 <= j,k <= n`; and
3. `Tr(H^dagger H) = 1`.

Then

```text
H = I_n / sqrt(n).                                                   (T1)
```

In particular, for every normalized standard basis vector `e_j`,

```text
<e_j, H e_j> = 1 / sqrt(n).                                         (T2)
```

The second hypothesis says that `H` lies in the center of `End(V)`. It is
equivalent to commuting with every endomorphism because the matrix units
span `End(V)`. The proof below derives the scalar form entry by entry; it
does not use the name of a representation-theoretic lemma as a substitute
for that derivation.

## Proof

Write `H = (h_lm)` in the standard basis.

### 1. Commutation with diagonal matrix units kills off-diagonal entries

For fixed `j`, the `(l,m)` entry of `[H,E_jj] = H E_jj - E_jj H` is

```text
h_lj delta_jm - delta_lj h_jm.
```

Set `m = j` and take `l != j`. The commutator equation gives
`h_lj = 0`. Set `l = j` and take `m != j`; it gives `h_jm = 0`.
As `j` ranges over all indices, every off-diagonal entry of `H` vanishes.
Thus

```text
H = diag(d_1, ..., d_n).
```

For `n = 1` there are no off-diagonal entries, so this step is vacuous and
the same diagonal form already holds.

### 2. Commutation with off-diagonal matrix units equates the diagonal

For a diagonal `H` and any `j,k`, direct multiplication gives

```text
H E_jk = d_j E_jk,
E_jk H = d_k E_jk.
```

Hence `[H,E_jk] = 0` implies `d_j = d_k`. When `n >= 2`, this holds for
every pair and all diagonal entries equal one scalar `c`. When `n = 1`, set
`c = d_1`; there is only one diagonal entry. Uniformly for all `n >= 1`,

```text
H = c I_n.                                                          (P1)
```

### 3. Positivity fixes the branch and Hilbert--Schmidt normalization fixes
the magnitude

Because `H >= 0`, the scalar in `(P1)` is real and `c >= 0`. The unit
Hilbert--Schmidt condition is

```text
1 = Tr(H^dagger H)
  = Tr(|c|^2 I_n)
  = n |c|^2
  = n c^2,
```

Therefore `c = 1 / sqrt(n)`, proving `(T1)`. Since `e_j` is normalized,

```text
<e_j, H e_j>
  = <e_j, (I_n / sqrt(n)) e_j>
  = <e_j,e_j> / sqrt(n)
  = 1 / sqrt(n),
```

which proves `(T2)`. The same calculation in fact holds for every unit
vector in `V`, although only the standard-basis diagonal expectations are
claimed here. QED.

## Edge cases and necessity of the hypotheses

- **`n = 1`.** Centrality is automatic, positivity gives `H = [c]` with
  `c >= 0`, and `Tr(H^dagger H) = c^2 = 1` gives `c = 1`. Thus `(T1)` and
  `(T2)` remain valid without a separate convention.
- **If positivity is omitted but Hermiticity is retained**, centrality and
  unit Hilbert--Schmidt norm give both
  `H = +I_n/sqrt(n)` and `H = -I_n/sqrt(n)`. Positivity is exactly what
  removes this sign ambiguity. If Hermiticity is also omitted, the ambiguity
  is the full phase `H = exp(i theta) I_n/sqrt(n)`.
- **If centrality is omitted**, positivity and unit Hilbert--Schmidt norm do
  not select a scalar matrix when `n >= 2`. Every rank-one orthogonal
  projector `P_u = |u><u|` is positive semidefinite and satisfies
  `Tr(P_u^dagger P_u) = Tr(P_u) = 1`; varying the unit vector `u` gives
  infinitely many such matrices. Most do not commute with all matrix units.
- **If the trace (Schatten-1) norm is substituted for the
  Hilbert--Schmidt norm**, the central positive solution is `I_n/n`, whose
  Hilbert--Schmidt square is `1/n`, not `1`. The square-root dimension factor
  therefore comes specifically from `Tr(H^dagger H) = 1`.

## Arithmetic example

For the abstract dimension `n = 6`, the theorem gives

```text
H = I_6 / sqrt(6),
<e_j, H e_j> = 1 / sqrt(6)  for j = 1,...,6.
```

This is only a six-dimensional matrix example. No physical meaning is
assigned to `6` or to a factorization `n = N_iso N_c`.

## Bookkeeping factorization

One may write the integer dimension as `n = N_iso N_c` for any positive
integer factorization. Then `(T1)` reads

```text
H = I_n / sqrt(N_iso N_c).
```

This rewriting adds no tensor-product structure, carrier interpretation, or
physical assignment. In particular, the theorem does not select meanings
for `N_iso` or `N_c` and does not show that any physical operator satisfies
the three hypotheses.

## Framework and physical boundary

finite-dimensional theorem. They are not new framework axioms, admissions,
premise-registry entries, physical inputs, or dependency authorities.

To use this theorem for a physical operator, a separate bridge must prove,
on the relevant physical state space and normalization convention, that the
operator's finite matrix representative:

2. commutes with every endomorphism (not merely with a selected physical
   symmetry subalgebra); and
3. has Hilbert--Schmidt square norm exactly one.

This note supplies none of that bridge. It does not identify its abstract

does not infer gauge-parameter independence: such an inference would first
