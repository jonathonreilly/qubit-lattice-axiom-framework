## Setting

- **Carrier.** A finite block `Lambda` of `N` sites of a
  `d`-dimensional sublattice of the `Z^3` substrate (`d in {1, 2, 3}`,
  periodic wraps), one qubit per site (Quantum axiom). Spin operators
  `S^a_x = sigma^a_x / 2`.
- **Class (stated, not claimed universal).** U(1)-symmetric two-site
  finite-range qubit Hamiltonians with transverse breaking field:

```text
    H(h) = -J sum_{<xy>} ( S^x_x S^x_y + S^y_x S^y_y )  -  h sum_x S^x_x,
```

  nearest-neighbor bonds on the sublattice, `J > 0`, `h >= 0`. The
  U(1) symmetry is generated by `Q = sum_x S^z_x`
  (`[Q, H(0)] = 0`); `h` breaks it explicitly.
- **State.** The Gibbs state `rho = e^{-beta H(h)} / Z` at finite
  `beta` on the finite block.
- **Order parameter.** `m(h) := (1/N) <sum_x S^x_x>`.
- **Fourier modes.** `Q_k = sum_x e^{i k . x} S^z_x`,
  `A_k = sum_x e^{i k . x} S^y_x`, with `k` in the discrete Brillouin
  zone of `Lambda`.

## Statements

**(B1) Bogoliubov inequality (finite-dimensional).** For any
finite-dimensional Hermitian `H`, Gibbs state at inverse temperature
`beta`, and any operators `A`, `C`:

```text
    |<[C, A]>|^2  <=  (beta/2) <{A, A^dag}> <[[C, H], C^dag]>,
```

and `<[[C, H], C^dag]> >= 0`. (Proof below via the Duhamel/Bogoliubov
scalar product; the runner verifies the inequality, the positivity,
and the two lemma steps on random instances at machine precision.)

**(B2) Ward commutator identity.** With `C = Q_k`, `A = A_{-k}`:

```text
    <[Q_k, A_{-k}]>  =  -i N m(h)        for every k,
```

an exact identity from the on-site su(2) relation
`[S^z_x, S^y_x] = -i S^x_x` (cross-site terms vanish; the Fourier
phases cancel pointwise).

**(B3) Double-commutator locality bound with the retained kernel.**
For every `k`,

```text
    0  <=  <[[Q_k, H], Q_{-k}]>  <=  N ( J E(k) + h |m(h)| ),
    E(k) = 2 sum_mu (1 - cos k_mu),
```

i.e. the momentum kernel of the double commutator is exactly the
retained Coleman-Mermin-Wagner threshold kernel. (Each bond
contributes `|e^{i k . delta} - 1|^2`-weighted terms whose
state-independent norm bound gives `J E(k)`; the field part
contributes `h <sum S^x> / N`-type terms bounded by `h |m|`. The
runner checks the inequality at every `k` on `d = 1` and `d = 2`
blocks, multiple `h`.)

**(B4) Sum rule.** `sum_k <{A_k, A_k^dag}> = N^2 / 2` exactly (each
qubit has `(S^y)^2 = 1/4`).

**(B5) Assembled bound and the low-`d` conclusion.** Combining
(B1)-(B4) per mode and summing over the Brillouin zone:

```text
    m(h)^2 * (1/N) sum_k 1/( J E(k) + h |m(h)| )  <=  beta / 4,
```

i.e. `m(h)^2 <= (beta/4) / S_Lambda(h |m(h)|)`. The retained IR
threshold row supplies: `(1/N) sum_k 1/E(k)` **diverges** as
`N -> infinity` for `d <= 2` and converges for `d >= 3`. Hence for
`d <= 2`, `S_Lambda(eps) -> infinity` as `eps -> 0` after
`N -> infinity`, so `m(h) -> 0` as `h -> 0`: **no continuous-U(1)
symmetry breaking at finite temperature on the stated class for
`d <= 2`.** For `d >= 3` the bound stays finite and asserts nothing
(no ordering claim is made).

## Proof

**(B1).** Work in the eigenbasis `H|n> = E_n|n>`, `p_n = e^{-beta
E_n}/Z`. Define the Duhamel/Bogoliubov scalar product

```text
    (X, Y) := (1/Z) sum_{m,n} conj(X_{nm}) Y_{nm} w_{mn},
    w_{mn} := (e^{-beta E_m} - e^{-beta E_n}) / (beta (E_n - E_m)),
```

with the coincidence value `w_{mm} = e^{-beta E_m}`. It is a positive
sesquilinear form, so Cauchy-Schwarz holds. Two lemmas:

- **(L1)** `(X, X) <= (1/2) <{X, X^dag}>`: entrywise,
  `w_{mn} <= (e^{-beta E_m} + e^{-beta E_n})/2` — the logarithmic mean
  of two positives never exceeds their arithmetic mean (for
  `u = beta E_m`, `v = beta E_n`:
  `(e^{-u} - e^{-v})/(v - u) <= (e^{-u} + e^{-v})/2`).
- **(L2)** `beta ([H, C^dag], X) = <[C, X]>` for all `X`: entrywise,
  `[H, C^dag]_{nm} = (E_n - E_m) C^dag_{nm}`, and
  `beta (E_n - E_m) w_{mn} = e^{-beta E_m} - e^{-beta E_n}`, which
  resums to the thermal trace of the commutator.

Take `X = A` in (L2) and apply Cauchy-Schwarz:

```text
    |<[C, A]>|^2 = beta^2 |([H, C^dag], A)|^2
                <= beta^2 ([H, C^dag], [H, C^dag]) (A, A).
```

By (L2) again, `beta ([H, C^dag], [H, C^dag]) = <[C, [H, C^dag]]> =
<[[C, H], C^dag]>` (and this is `>= 0` since it equals
`beta (X, X) >= 0` for `X = [H, C^dag]`). With (L1) on `(A, A)`:

```text
    |<[C, A]>|^2 <= (beta/2) <{A, A^dag}> <[[C, H], C^dag]>.  ∎
```

**(B2).** `[Q_k, A_{-k}] = sum_{x,y} e^{ik.x} e^{-ik.y}
[S^z_x, S^y_y] = sum_x [S^z_x, S^y_x] = -i sum_x S^x_x` (cross terms
vanish because spin operators on distinct sites commute; the phases
cancel at `x = y`). Take expectations. ∎

**(B3).** Write `H = H_J + H_h`. For the bond part, with
`b_delta(k) := |e^{i k . delta} - 1|^2 = 2(1 - cos k . delta)`:
`[[Q_k, H_J], Q_{-k}]` expands over bonds; each bond `<x, x+delta>`
contributes operators with prefactor `J b_delta(k)` and thermal
expectation bounded by the operator norm of the bond spin bilinears
(`||S^a S^b|| = 1/4`, four bilinears per bond), giving
`<[[Q_k, H_J], Q_{-k}])> <= J N sum_mu b_{e_mu}(k) = J N E(k)` on the
nearest-neighbor sublattice. For the field part,
`[[Q_k, H_h], Q_{-k}] = h sum_x S^x_x` exactly (two su(2) rotations
return `S^x`), so its expectation is `h N m(h) <= h N |m(h)|`.
Positivity of the total is part of (B1). The runner checks the
inequality at every discrete `k` rather than relying on this display.
∎

**(B4).** `sum_k <{A_k, A_k^dag}> = N sum_x <{S^y_x, S^y_x}> = N * N *
2 * (1/4) = N^2/2`, using the discrete Fourier completeness
`sum_k e^{i k (x - y)} = N delta_{xy}` and `(S^y_x)^2 = I/4` on the
qubit carrier. ∎

**(B5).** For each `k`, (B1) with (B2) gives
`N^2 m^2 <= (beta/2) <{A_{-k}, A_{-k}^dag}> <[[Q_k, H], Q_{-k}]>`.
Divide by the (B3) bound, sum over `k`, and apply (B4):

```text
    N^2 m^2 sum_k 1/( N (J E(k) + h|m|) )
        <= (beta/2) sum_k <{A_k, A_k^dag}> = (beta/2)(N^2/2),
```

which is the displayed bound after dividing by `N^2`. The `k = 0`
mode has `E(0) = 0` but the `h|m|` regulator keeps the summand finite
for `h > 0`; for `h = 0` and `m = 0` the bound is vacuous, which is
consistent. The low-`d` conclusion composes the bound with the
retained IR threshold row exactly as stated in (B5). ∎
