Q_W(r, u_0)

## 1. The Algebraic Core

Start from the all-orders Wilson-shifted total curvature expression at
the extremum `m* = -4r`, with Hamming-weight multiplicities
`C(4,k) = (1,4,6,4,1)`. Taking the sign-flipped curvature magnitude
termwise and dividing by the declared diagnostic all-corners count
`16` yields the normalized diagnostic core `Q_W` above. The factor
`1/64` is `(1/4) * (1/16)`: the upstream curvature's prefactor times
the diagnostic count division.

This split keeps `r` and `u_0` symbolic for the theorem. For the
numerical sanity check only, the runner uses the current B1 plaquette
surface

```text
<P> = 0.5934,     u_0 = <P>^(1/4) = 0.877681381...
```

rather than the older rounded `u_0 = 0.8776` comparator used by the
May 2026 matching notes.

## 2. Exact Reductions

At `r = 0`, every summand becomes `1/u_0^2`, so

```text
Q_W(0, u_0)
  = (1/64) * sum_k C(4,k) * 1/u_0^2
  = (1/64) * 16/u_0^2
  = 1/(4 u_0^2).
```

Expanding in `r` gives

```text
Q_W(r, u_0)
  = 1/(4 u_0^2)
    - 3 r^2/(4 u_0^4)
    + 25 r^4/(8 u_0^6)
    + O(r^6).
```

The coefficients use only the centered binomial moments

```text
sum_k C(4,k) (k - 2)^2 = 16,
sum_k C(4,k) (k - 2)^4 = 40.
```

These are exact finite sums. The runner checks them with rational test
values and with the B1 numerical `u_0` surface.
