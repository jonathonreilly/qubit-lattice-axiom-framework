## 1. Object and claim

### 1.1 The Wilson one-link weight and transfer kernel

For a single temporal link in temporal gauge (`U_0 = 1`), the standard Wilson
gauge transfer kernel between two adjacent time slices, in the convention
instantiated by the repo's reflection-positivity notes, is

```text
    K(U, U') = exp( -beta ( 1 - Re Tr(U' U^dag) / N_c ) ),      U, U' in SU(3).   (1)
```

Factor out the constant `exp(-beta)`:

```text
    K(U, U') = exp(-beta) * w( U' U^dag ),                                          (2)
    w(V)     = exp( (beta / N_c) Re Tr V ).                                         (3)
```

The prefactor `exp(-beta) > 0` is an overall positive scalar and is irrelevant
to positivity; the entire content is the **one-link Wilson weight** `w`, a real
class function on SU(3). Because `Tr V = chi_box(V)` (fundamental character) and
`conj(Tr V) = Tr V^dag = chi_boxbar(V)` (antifundamental character) on SU(3),

```text
    Re Tr V = (1/2)( chi_box(V) + chi_boxbar(V) ),                                  (4)
```

so

```text
    w(V) = exp( (beta / (2 N_c)) ( chi_box(V) + chi_boxbar(V) ) ).                  (5)
```

By Peter-Weyl, `w` has a convergent character (Fourier) expansion over the
SU(3) irreps `lambda` (labelled by highest weights `(p, q)`, dimension
`d_lambda = (p+1)(q+1)(p+q+2)/2`):

```text
    w(V) = sum_lambda c_lambda(beta) chi_lambda(V),                                 (6)
    c_lambda(beta) = integral_{SU(3)} w(V) conj(chi_lambda(V)) dV,                  (7)
```

`dV` the normalized Haar measure.

### 1.2 Claim (H1)

> **Theorem (H1).** For every SU(3) irrep `lambda` and every `beta >= 0`,
> `c_lambda(beta) >= 0`. Equivalently, the one-link Wilson weight `w` is a
> **positive-definite class function** on SU(3); equivalently, the Wilson
> gauge transfer kernel `K(U, U')` of `(1)` is a **positive semidefinite**
> kernel on SU(3) (the gauge half of single-link reflection positivity).

The three formulations are equivalent (§4). The proof of `c_lambda(beta) >= 0`
is the load-bearing, genuinely non-circular step (§3), and rests on the
non-negativity of SU(3) tensor-product multiplicities (§2).

## 2. The load-bearing fact: SU(3) tensor-product multiplicities are
## non-negative integers

The characters of SU(3) form a commutative ring (the representation ring): for
any two irreps `lambda, mu`,

```text
    chi_lambda * chi_mu = sum_nu N^nu_{lambda mu} chi_nu,                           (8)
```

where the structure constants `N^nu_{lambda mu}` are the **Clebsch-Gordan /
tensor-product multiplicities**, equal to the multiplicity of the irrep `nu` in
the tensor product representation `lambda (x) mu`. These are **non-negative
integers**:

```text
    N^nu_{lambda mu}  in  Z_{>=0}.                                                  (9)
```

This is a standard, classical fact of the representation theory of compact Lie
groups: `N^nu_{lambda mu} = dim Hom_{SU(3)}( V_nu , V_lambda (x) V_mu )` is the
dimension of a space of intertwiners, hence a non-negative integer. For
`SU(N)` it is given concretely by the **Littlewood-Richardson rule** (a count of
LR skew tableaux, manifestly a non-negative integer). See Fulton–Harris,
*Representation Theory* (GTM 129), §15 and §A; or Bump, *Lie Groups* (GTM 225),
for the compact-group intertwiner statement. No framework input is involved;
this is textbook rep theory.

Two immediate consequences used below:

- **(P1)** `chi_box + chi_boxbar` is a real class function whose own character
  coefficients are non-negative (they are `1` on `box` and `boxbar`, `0`
  elsewhere). It is therefore a **positive-definite class function** (a
  non-negative-integer combination of irreducible characters).
- **(P2)** For every integer `n >= 0`,
  ```text
      ( chi_box + chi_boxbar )^n = sum_nu m_nu^{(n)} chi_nu,    m_nu^{(n)} in Z_{>=0},   (10)
  ```
  because the product of characters re-expands through `(8)` with non-negative
  integer coefficients, and sums/powers of such expansions stay non-negative by
  `(9)`. (Equivalently, `( chi_box + chi_boxbar )^n` is the character of the
  `n`-fold tensor power of `box (+) boxbar`, whose irrep multiplicities are
  non-negative integers.)

## 3. Proof of (H1): `c_lambda(beta) >= 0`

Fix `beta >= 0`. Expand the exponential `(5)` in its (everywhere-convergent,
since the exponent is a bounded continuous function on the compact group SU(3))
power series:

```text
    w(V) = sum_{n>=0} (1/n!) ( beta / (2 N_c) )^n ( chi_box(V) + chi_boxbar(V) )^n.   (11)
```

Insert the non-negative-integer expansion `(10)` of each power:

```text
    w(V) = sum_{n>=0} (1/n!) ( beta / (2 N_c) )^n sum_nu m_nu^{(n)} chi_nu(V).        (12)
```

The series converges uniformly (it is the uniformly convergent exponential
series of a bounded class function, and on a compact group uniform convergence
permits term-by-term integration against the bounded characters `chi_nu`).
Collecting the coefficient of a fixed `chi_lambda` and using Schur
orthonormality `integral chi_nu conj(chi_lambda) dV = delta_{nu, lambda}`,

```text
    c_lambda(beta) = sum_{n>=0} (1/n!) ( beta / (2 N_c) )^n m_lambda^{(n)}.           (13)
```

Every factor on the right is **non-negative** for `beta >= 0`:
`1/n! > 0`, `(beta/(2 N_c))^n >= 0`, and `m_lambda^{(n)} in Z_{>=0}` by `(10)`.
A convergent sum of non-negative terms is non-negative, hence

```text
    c_lambda(beta) >= 0    for every irrep lambda and every beta >= 0.   ∎          (14)
```

Two structural restatements (each a corollary of the same fact):

- **Closure under product/exponential.** `chi_box + chi_boxbar` is
  positive-definite (P1); products of positive-definite class functions are
  positive-definite because their character coefficients convolve through the
  non-negative structure constants `(9)`; hence each power is positive-definite,
  and the `beta >= 0` exponential series `(11)` is a non-negative combination of
  positive-definite functions, therefore positive-definite. This is the abstract
  "exp of a positive-definite class function (with `beta >= 0`) is
  positive-definite" statement, made concrete by the SU(3) CG ring.
- **Boundary check.** At `beta = 0`, `w = 1 = chi_0`, so
  `c_lambda(0) = delta_{lambda, 0} >= 0`; only the trivial irrep survives, as it
  must.

## 4. Equivalence: non-negative character coefficients ⟺ PSD transfer kernel
## ⟺ gauge-link reflection positivity (gauge half)

Let `f, g` be square-integrable functions on SU(3). The Wilson kernel acts by
**convolution** by the class function `w`:

```text
    (K f)(U') = integral_{SU(3)} K(U, U') f(U) dU
              = exp(-beta) integral_{SU(3)} w(U' U^dag) f(U) dU.                     (15)
```

Decompose `f` in the Peter-Weyl basis. By Schur orthogonality, convolution by a
class function `w = sum_lambda c_lambda chi_lambda` acts on the
matrix-coefficient block of each irrep `lambda` as the scalar
`c_lambda / d_lambda` (this is exactly the per-link convolution
diagonalization recorded, for a general compact group and any class-function
one-link weight, in the retained mixed-kernel factorization theorem cited
below). Therefore the eigenvalues of the Hermitian convolution operator `K` are

```text
    exp(-beta) * c_lambda(beta) / d_lambda,    each with multiplicity d_lambda^2.    (16)
```

Hence the following are **equivalent**:

```text
    (A)  c_lambda(beta) >= 0 for all lambda;
    (B)  all eigenvalues (16) are >= 0, i.e. K is a positive semidefinite operator;
    (C)  for every finite set of configurations {U_i} the Gram matrix
         G_{ij} = K(U_i, U_j) = exp(-beta) w(U_j U_i^dag) is positive semidefinite.
```

`(A) ⟺ (B)` is `(16)`. `(B) ⟺ (C)` is the standard equivalence between
positivity of a (Hermitian, convolution) integral operator and positive
semidefiniteness of all its finite Gram matrices (Bochner / Schur–Godement for
class functions on a compact group); the kernel is Hermitian because
`Tr(U_i U_j^dag) = conj(Tr(U_j U_i^dag))` and `w` depends only on the real part,
so `K(U_i, U_j) = conj(K(U_j, U_i))`. Statement `(C)` is precisely the
**gauge-link reflection-positivity** condition (the gauge half): the reflected
inner product built from the single-link kernel is a sum of manifestly
non-negative Gram quadratic forms.

Combining §3 and §4: `(A)` holds (Theorem H1), so `(B)` and `(C)` hold — the
Wilson SU(3) gauge transfer kernel is positive semidefinite for all `beta >= 0`.
