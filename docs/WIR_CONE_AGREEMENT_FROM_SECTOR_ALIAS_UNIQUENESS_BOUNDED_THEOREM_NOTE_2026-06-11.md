## The theorem (finite-dimensional, exact)

**Alias structure.** On integer tick data,
`cos((2 pi - w) n) = cos(w n)` exactly: quasi-energies `w` and `2 pi - w`
are layer-by-layer indistinguishable. The alias group is generated by
`w -> w + 2 pi` and `w -> -w`, and the spectrum-condition sector `[0, pi]`
is **exactly a fundamental domain**: every alias orbit meets it once, and
two in-sector frequencies with identical integer data coincide (runner
alias-sector checks). The sector is not a convenience — it is the unique
window in which the registered layer data determines the band.

**Real-even data form.** With the landed spectrum-reflection pairing (the
tick spectrum is `w <-> -w` paired — the corollary of
[`TICK_UNITARITY_FROM_SPECTRUM_REFLECTION_CONJUGACY_BOUNDED_THEOREM_NOTE_2026-06-10.md`](TICK_UNITARITY_FROM_SPECTRUM_REFLECTION_CONJUGACY_BOUNDED_THEOREM_NOTE_2026-06-10.md)),
the tick-generated layer correlation takes the real, even, RP-shaped form
`C(n) = sum_j c_j cos(w_j n)`, `c_j > 0`. Dropping the pairing breaks
real-evenness (runner data-form and hostile-witness checks).

**Prony recovery.** For bands with distinct `w_j` in the sector, the pairs
`{(c_j, w_j)}` are uniquely recoverable from finitely many `C(n)` values
(exact Prony recovery on 25 random bands).

**Euclidean companion.** Among candidate Euclidean rate sets
`E_j = w_j + 2 pi m_j` whose Wick continuation matches the same integer
data, **exactly one lies in the sector: `E_j = w_j`** (every nontrivial lift
exits `[0, pi]`). The in-sector companion `g(n) = sum_j c_j e^{-E_j n}` is
reflection-positive (the Hankel `[g(m+n)]` is PSD; runner companion checks).

**Cone-agreement corollary.** Per fiber, the reconstructed dispersion equals
the quasi-energy band on the sector — at **all** sampled momenta. In
particular cone-point slopes agree, so the Wick-IR cone-agreement premise is
discharged in this bounded setting. Fed the dichotomy's saturating band
(`|v| = 1`), the landed inverse map returns
`xi = c_t/c_s = 1` exactly; fed a contrast band (`v = 0.6`), the mismatch
diagnostic `xi = 1/v^2` is preserved (runner cone-agreement checks).
