## 5. Proof

The argument is direct engineering-dimension bookkeeping on the
bare Yang-Mills action (★).

### 5.1 (Y1)-(Y3) Setup

- Action is dimensionless: `[ S ] = 0` (path-integral
  exponential `exp(iS)`).
- Coordinates: `[ x^μ ] = -1`, hence `[ d^d x ] = - d`.
- Partial derivatives: `[ ∂_μ ] = + 1`.

### 5.2 (Y4) Gauge-field dimension from kinetic term

The Lagrangian density `L = - ( 1 / 4 ) tr( F_{μν} F^{μν} )` must
satisfy `[ L ] = d` (so that `∫ d^d x · L` is dimensionless). The
kinetic content of `F_{μν}` is
`∂_μ A_ν`, so

```text
[ F_{μν} F^{μν} ]  ⊃  [ ∂_μ A_ν · ∂^μ A^ν ]  =  2 · [ ∂ ] + 2 · [ A ]
                    =  2 + 2 · [ A ].
```

Requiring `[ L ] = d` gives `2 + 2 · [ A ] = d`, i.e.,
`[ A_μ ] = ( d - 2 ) / 2`. ∎

### 5.3 (Y5) Field-strength dimension

With `[ A_μ ] = ( d - 2 ) / 2`:

```text
[ F_{μν} ]  =  [ ∂_μ A_ν ]  =  [ ∂ ] + [ A ]  =  1 + ( d - 2 ) / 2  =  d / 2.
```

For dimensional consistency, the non-abelian term `i g_YM [A_μ, A_ν]`
in `F_{μν}` must also carry `d / 2`:

```text
[ g_YM ] + 2 · [ A_μ ]  =  d / 2,
[ g_YM ] + ( d - 2 )  =  d / 2,
[ g_YM ]  =  d / 2 - ( d - 2 )  =  2 - d / 2  =  ( 4 - d ) / 2.
```

This is **identity (D)**. ∎

### 5.4 (Y6)-(Y7) Cross-verification via cubic self-interaction

The cubic gauge self-interaction term inside the canonical action (★)
is, expanding
`F^2 = (∂A - ∂A)^2 + 2 i g_YM (∂A - ∂A)[A, A] +
(i g_YM)^2 [A, A]^2`, the middle term:

```text
S_YM ⊃ ∫ d^d x · ( - i g_YM / 2 ) ·
        tr( ( ∂_μ A_ν - ∂_ν A_μ ) [ A^μ , A^ν ] ).
```

This term must be dimensionless. The engineering-dimension content:

```text
[ d^d x ]  +  [ g_YM ]  +  [ ∂A · A · A ]
  =  - d   +  [ g_YM ]  +  ( 1 + 3 [ A ] )
  =  - d   +  [ g_YM ]  +  1 + 3 ( d - 2 ) / 2
  =  - d   +  [ g_YM ]  +  ( 3 d - 4 ) / 2
  =  [ g_YM ] + ( d - 4 ) / 2.
```

Setting this `= 0`:

```text
[ g_YM ] + ( d - 4 ) / 2  =  0,
[ g_YM ]  =  ( 4 - d ) / 2.
```

This agrees with identity (D) from the non-abelian term in
`F_{μν}`. ∎

### 5.5 (Y8) Uniqueness over `d ∈ {2, 3, ..., 12}`
