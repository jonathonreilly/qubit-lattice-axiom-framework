## Theorem Statement

On a finite qubit-record block with baseline law `P_0` and normalized local
observable `O`, the unique least-informative intervention that changes only
the expectation of `O` is the exponential Radon-Nikodym source family

```text
dP_h / dP_0 = exp(h O - psi(h)).
```

Equivalently, the same family is generated by the source-coupled local action

```text
S_h = S_0 - h O + psi(h).
```

At the origin, if `O` is Fisher-normalized, the source coordinate has unit
Fisher metric:

```text
I(0) = Var_0(O) = 1.
```

Therefore the source/action bridge is not an arbitrary notation once the
physical intervention is specified as the minimum-information bias of the
normalized signed record.  This strengthens the current Y_T source/action
stack by replacing a raw convention with a finite-record variational theorem.

## Proof

Let `Omega` be the finite set of qubit-record states and let `p_0(i) > 0`.
Among all probability laws `q` with

```text
sum_i q_i = 1,
sum_i q_i O_i = m,
```

minimize

```text
D(q || p_0) = sum_i q_i log(q_i / p_0(i)).
```

The Lagrangian is

```text
L(q, alpha, beta)
  = D(q || p_0)
    + alpha (sum_i q_i - 1)
    + beta (sum_i q_i O_i - m).
```

Stationarity gives

```text
log(q_i / p_0(i)) + 1 + alpha + beta O_i = 0,
```

so

```text
q_i = p_0(i) exp(h O_i - psi(h)),
```

after writing `h = -beta` and choosing `psi(h)` to normalize.  Strict convexity
of KL divergence on the probability simplex gives uniqueness.

If `p_0(i) = exp(-S_0(i)) / Z_0`, then

```text
q_i ∝ exp(-S_0(i) + h O_i),
```

which is exactly the action deformation

```text
S_h(i) = S_0(i) - h O_i + psi(h).
```

The score at the origin is

```text
d log(dP_h/dP_0) / dh |_{h=0} = O - E_0[O],
```

and the Fisher information is

```text
I(0) = E_0[(O - E_0[O])^2] = Var_0(O).
```

For the normalized top source tangent used in the Y_T stack, `E_0[O_top]=0`
and `Var_0(O_top)=1`, so the minimum-information source coordinate is the
same unit source coordinate used by the Fisher-arclength theorem.
