## Theorem

Let the local qubit algebra at site `x` be generated by the Pauli operator
`sigma_z`. Define the sharp spectral projections

```text
P_+(x) = (I + sigma_z(x)) / 2,
P_-(x) = (I - sigma_z(x)) / 2.
```

The LSP projective theorem supplies the ideal measurement instruments

```text
K_+ = P_+,
K_- = P_-.
```

The signed readout observable of this binary sharp measurement is

```text
E_x = (+1) P_+(x) + (-1) P_-(x) = sigma_z(x).
```

Thus the possible ideal readout outcomes are exactly

```text
epsilon_x in {-1,+1}.
```

For a finite block of sites, the PR230 source packet uses the product RN family

```text
R_h(epsilon) = exp(sum_x h_x epsilon_x) / Z(h).
```

At `h = 0`, its score is

```text
d log R_h / d h_x |_{h=0} = epsilon_x.
```

Under the qubit/LSP readout above, this is precisely the signed spectral
readout of the local projective measurement of `sigma_z(x)`. Therefore the
measurement/readout carrier of the PR230 source packet is native to the
current qubit-on-`Z^3` substrate:

```text
PR230 primitive signed source record epsilon_x
  = LSP sharp-projective signed Pauli readout at site x.
```

## Source-Family Uniqueness Corollary

The exponential RN form is also forced by the source semantics used in the
PR230 packet. Let `R_h(epsilon)` be a positive smooth normalized source family
on a finite signed-record block satisfying:

1. `R_0` is the uniform pre-source reference density;
2. source profiles compose by normalized multiplication,
   `normalize(R_h R_k) = R_{h+k}`;
3. the origin score is the signed record,
   `d log R_h / d h_x |_{h=0} = epsilon_x`.

Fix a reference record `epsilon^0`. Define the log-odds

```text
L_epsilon(h) = log(R_h(epsilon) / R_h(epsilon^0)).
```

The normalized-composition law removes the normalization constants and gives

```text
L_epsilon(h + k) = L_epsilon(h) + L_epsilon(k).
```

Smoothness makes `L_epsilon` linear in `h`. The origin-score condition fixes
its coefficient:

```text
d L_epsilon / d h_x |_{h=0} = epsilon_x - epsilon^0_x.
```

Therefore

```text
L_epsilon(h) = sum_x h_x (epsilon_x - epsilon^0_x).
```

After restoring normalization, the unique family is exactly

```text
R_h(epsilon) = exp(sum_x h_x epsilon_x) / Z(h).
```

So the PR230 source packet's product RN family is not an extra fitted choice
once the signed-record readout, smoothness, and source-composition semantics
are adopted.
