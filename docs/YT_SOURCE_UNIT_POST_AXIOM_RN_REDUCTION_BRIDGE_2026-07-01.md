surface to fix the source scale:

```text

  -> primitive normalized RN/Fisher source coordinate
```

That is no longer the right registry boundary. The current Tier-A registry has
only two genuine admitted derivation targets: `AC_phi_lambda` and `theta`.

```text

  -> finite sharp-record probability law
  -> RN/log-normalizer source calculus
  -> action-exponent deformation = RN/Fisher source coordinate.
```

Therefore the source-unit blocker for `Y_T` is not generic P-cal/RN algebra.
It is the narrower physical selector:

```text

  identify the physical top Yukawa deformation with the primitive operational
  RN/Fisher source coordinate for normalized O_top, or supply strict
  same-source top/W pole-response evidence that fixes the same coefficient.
```

calculation goes through without an extra Tier-A P-cal admission:

```text

  + physical RN/Fisher source coordinate
  -> lambda = 1
```

## Finite Source-Unit Calculation

Let the six-component top source direction be

```text
u = (1, 1, 1, 1, 1, 1) / sqrt(6).
```

Then

```text
||u||^2 = 1,
u_i = 1/sqrt(6).
```

For a supplied record-facing RN source coordinate

```text
R_h = exp(h O_top) / E_0 exp(h O_top),
```

with `O_top` normalized by `u`, the unit source has coefficient
`1/sqrt(6)` in each of the six equal components. A rescaled coordinate

```text
R_h^(lambda) = exp(h lambda O_top) / E_0 exp(h lambda O_top)
```

has Fisher norm `lambda^2` and coefficient `lambda/sqrt(6)`. Thus the
finite algebra does not force `lambda = 1`; the physical source coordinate
does. Once that coordinate is supplied, the source-unit result is exact.
