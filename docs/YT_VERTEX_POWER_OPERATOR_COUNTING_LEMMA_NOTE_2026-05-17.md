# `y_t` Vertex-Power Operator-Counting Lemma

**Date:** 2026-05-17
**Claim type:** bounded_theorem
**Claim scope:** Conditional on the staggered-Dirac realization open gate
and the conventional `U_mu(x) = exp(i a g A_mu)` link-exponential map,
the vacuum-polarization channel `Pi = -Tr[D^{-1} D' D^{-1} D']` of the
staggered Dirac operator `D` carries exactly two insertions of the
single-link vertex `D' = dD/dA`. Equivalently, the operator-counting
exponent for the LM dressing in the bare-coupling-map identity
`alpha_eff = alpha_bare / u_0^{n_link}` is `n_link = 2` for the gauge
vacuum polarization on the same lattice operator surface that hosts the
hierarchy theorem's `n_link = 1` hopping term. This is an operator-level
structural lemma: it does not claim a numerical value for `alpha_s(M_Z)`,
a closure of the renormalized `y_t` lane, or a derivation of the
staggered-Dirac realization itself.

## Admissions (names, not closures)

This lemma is conditional on three named items:

1. **Staggered-Dirac realization gate** —
   the staggered Dirac operator `D` with single-link nearest-neighbour
   hopping
   `D_{x,y}[U] = sum_mu (1/2) eta_mu(x) [U_mu(x) delta_{y, x+mu} -
   U_mu(y)^dagger delta_{y, x-mu}] + m epsilon(x) delta_{x,y}`
   is the realization on the substrate. See `MINIMAL_AXIOMS_2026-05-03.md`
   §"Staggered-Dirac realization derivation target".
2. **Link-exponential convention** —
   the gauge link is `U_mu(x) = exp(i A_mu(x))` (lattice spacing absorbed
   into `A`), so that `dU/dA = i U` and `d^2 U / dA^2 = -U`. This is the
   standard lattice gauge convention used throughout the `_yt` cluster.
3. **Bare-coupling-map identity** —
   the `alpha_eff = alpha_bare / u_0^{n_link}` LM coupling-map identity
   on the current operator surface, parameterized by the integer `n_link`
   of single-link gauge insertions per insertion-counted observable.
   See `YT_VERTEX_POWER_DERIVATION.md`.

The lemma derives `n_link = 2` for the gauge vacuum polarization
*relative to* `n_link = 1` for the hopping bilinear, given the above.

## Statement (S1 — single-link vertex insertion)

Let `D[U]` be the staggered Dirac operator above and let
`A_mu(x) = epsilon * a_mu(x)` be a c-number background gauge field
expansion parameter (with `a_mu(x)` a fixed test profile). Define

```text
D'  :=  d D[U(epsilon)] / d epsilon  |_{epsilon = 0}.
```

Then `D'` is supported on nearest-neighbour bonds and each non-zero
matrix element of `D'` is linear in the link variable
`dU_mu(x)/d epsilon|_{epsilon=0} = i a_mu(x) U_mu(x)|_{epsilon=0}`, i.e.,
**`D'` carries exactly one power of the gauge link `U`** per non-zero
entry.

**Proof (S1).** Differentiate `D` term-by-term in `epsilon`:

```text
D_{x,y}'  =  sum_mu (1/2) eta_mu(x) [(dU_mu(x)/d epsilon) delta_{y, x+mu}
                                     - (dU_mu(y)^dagger / d epsilon) delta_{y, x-mu}].
```

Since `dU/d epsilon |_{epsilon=0} = i a U|_{epsilon=0}`, each surviving
term in `D'` contains exactly the factor `U_mu(x)|_{epsilon=0}` (one
gauge link) and the mass term `m epsilon(x) delta_{x,y}` is independent
of `U` so drops out. **Hence `D'` is single-link.** ∎

## Statement (S2 — vacuum-polarization vertex count)

The Euclidean one-loop fermion-induced gauge effective action is
`Gamma_F[A] = -Tr ln D[U(A)]`. Expanding to second order in `A`,

```text
Gamma_F[A]  =  Gamma_F[0]  -  (1/2) Tr[D[0]^{-1} D'']  -  (1/2) Tr[D[0]^{-1} D' D[0]^{-1} D']
              +  O(A^3),
```

where `D' = dD/dA |_{A=0}` is the single-link vertex of S1 and
`D'' = d^2 D / dA^2 |_{A=0}` is the (mass-independent) tadpole insertion.

The non-trivial vacuum-polarization piece is

```text
Pi  :=  -(1/2) Tr[D[0]^{-1} D' D[0]^{-1} D'].
```

`Pi` contains **two insertions of `D'`**. By S1, each carries one power
of the gauge link `U`. **Hence the gauge-link-counting exponent for the
vacuum polarization is `n_link = 2`.** ∎

## Statement (S3 — relative count vs hopping)

The hierarchy theorem's hopping bilinear (one hopping term in `D`)
carries one power of `U` per non-zero matrix element by direct reading
of the staggered hopping form, so `n_link = 1` for the hopping bilinear.
The vacuum polarization (two `D'` insertions) carries two powers, so

```text
n_link(vacuum polarization)  =  2  =  2 * n_link(hopping).
```

This relative count is the structural input that the bare-coupling-map
identity converts into the abstract algebraic identity
`alpha_s(v) = alpha_bare / u_0^2`. ∎

## Numerical Verification

The paired runner `scripts/frontier_yt_vertex_power_operator_counting_lemma.py`
performs the structural checks at small `L` and machine precision:

1. **Single-link verification:** for each non-zero matrix element of `D'`
   on a small lattice, confirm it factors as `(constant) * U_mu(x)`,
   i.e., is degree-1 in `U`.
2. **Bubble two-insertion count:** confirm that
   `Tr[D[0]^{-1} D' D[0]^{-1} D']` is invariant under
   `D' -> lambda D'` only as `lambda^2`, not `lambda^1` or `lambda^4`.
3. **Tadpole one-insertion count (companion):** confirm that
   `Tr[D[0]^{-1} D'']` is invariant under `D'' -> mu D''` only as `mu^1`.
4. **u_0 scaling of bubble:** for a uniform link rescaling
   `U_mu(x) -> u_0 U_mu(x)`, confirm the bubble scales as `u_0^2` when
   D' is held fixed (since `D[u_0 U]^{-1}` produces a `u_0^{-1}` factor
   per inverse and the two D' insertions are u_0-independent in the
   structure-only counting). Equivalently, confirm that the log-det
   bubble Z_F is u_0^0 once the same `u_0` factors are pulled out of
   `D[U]` and `D'[U]` consistently (the cancellation pattern that the
   parent note `YT_VERTEX_POWER_DERIVATION.md` and its runner already
   document at 13/0 PASS).
5. **Relative-count check vs hopping:** confirm that the hopping bilinear
   `Tr[D[0]] = 0` (staggered) but that `d Tr[D] / d epsilon` has the
   single-link structure required by S1, while `Pi` has two such
   insertions and therefore `n_link = 2` strictly exceeds the hopping's
   `n_link = 1`.

## What this lemma DOES claim

- **S1**: the vertex insertion `D' = dD/dA` is degree-1 in `U` per
  non-zero matrix element, given the staggered Dirac form and the
  link-exponential convention.
- **S2**: the one-loop vacuum-polarization piece `-(1/2) Tr[D^{-1} D' D^{-1} D']`
  carries exactly two such insertions.
- **S3**: the relative gauge-link count is `n_link = 2` for the vacuum
  polarization vs `n_link = 1` for the hopping bilinear.

The structural count `n_link = 2` is the operator-level input that
unlocks the abstract algebraic identity already retained as
`alpha_s_tadpole_improvement_vertex_power_narrow_theorem_note_2026-05-10`.

  is a named gauge convention.
- Does **not** assign a numerical value to `u_0`, `alpha_bare`,
  `alpha_s(v)`, or `alpha_s(M_Z)`. No external numerical target enters.
- Does **not** close the renormalized `y_t` lane, the `v`-endpoint

- Does **not** introduce any new framework axiom. The lemma is over
