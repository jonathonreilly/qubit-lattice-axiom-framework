## Statement

Let `g_bare, y_t_bare, u_0` be abstract positive real symbols. Suppose
the equal-dressing premise holds for the two single-vertex readouts, so
the same canonical tadpole factor multiplies both couplings:

```text
ED          :  n_link(y_t) = n_link(g_s) and both readouts use the
               same coupling-level dressing factor 1/sqrt(u_0).        (I1)
```

The 2026-06-06 companion packet reproves the background algebra that
motivates this input: link-monomial homogeneity under `U = u_0 V`, the
coupling square-root readout `g -> g/u_0^{n/2}`, and the gauge-side
single-link count `n_link(g_s)=1`. It does not discharge the Yukawa-side
structural equality, because that routing passes through the framework's
same-1PI / `H_unit` open gate. Under the equal single-vertex dressing
premise, the two readouts used here are

```text
g_s(M_Pl)  :=  g_bare   / sqrt(u_0),                                   (D1)
y_t(M_Pl)  :=  y_t_bare / sqrt(u_0).                                   (D2)
```

Then the algebraic identity

```text
y_t(M_Pl) / g_s(M_Pl)  =  y_t_bare / g_bare                            (P1)
```

holds exactly as an identity in the polynomial ring in
`(g_bare, y_t_bare, u_0, 1/u_0, 1/sqrt(u_0))`. In particular, `(P1)` is
identically independent of `u_0` (the common `1/sqrt(u_0)` tadpole factor
cancels in the ratio).

## Proof

Pure algebraic substitution.

`(P1)`. From `(D1)` and `(D2)`:

```text
y_t(M_Pl) / g_s(M_Pl)  =  (y_t_bare / sqrt(u_0)) / (g_bare / sqrt(u_0))
                       =  (y_t_bare / sqrt(u_0)) * (sqrt(u_0) / g_bare)
                       =  y_t_bare * sqrt(u_0) / (sqrt(u_0) * g_bare)
                       =  y_t_bare / g_bare.
```

The common `1/sqrt(u_0)` factor in numerator and denominator cancels
exactly. The RHS is independent of `u_0`. ∎

## Derivable corollaries

```text
y_t(M_Pl) * g_bare        =  y_t_bare * g_s(M_Pl)
                                       (cross-multiplication of (P1))
y_t(M_Pl)^2 / g_s(M_Pl)^2  =  y_t_bare^2 / g_bare^2

                                       ((D2) restated as bare readout)
g_s(M_Pl) * sqrt(u_0)     =  g_bare
                                       ((D1) restated as bare readout)
```

All follow algebraically from `(D1)` and `(D2)`.
