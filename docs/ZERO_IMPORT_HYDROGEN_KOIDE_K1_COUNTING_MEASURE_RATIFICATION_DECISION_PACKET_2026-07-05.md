## Purpose

The K1 counting-measure target discriminator names the hydrogen-facing handoff:

```text
K1_COUNTING_MEASURE_RETAINED.
```

The current support reduces the Koide count to one binary: block/orbit/
holomorphic count gives `r = 1/2` and `Q = 2/3`, while dimension/Born/trace
count gives `r = 1` and `Q = 1`. The current-surface no-go records that the
retained, primitive, merged-PR, and open-PR surfaces still do not supply the
selector theorem, the dimension/Born default exclusion, owner ratification, or
audit acceptance. This packet packages the K1 object as a reviewable owner/audit
decision contract without spending it as retained.

The selector theorem and default-exclusion inputs are now named as the narrower
subtarget
`ZERO_IMPORT_HYDROGEN_KOIDE_K1_SELECTOR_DEFAULT_EXCLUSION_TARGET_DISCRIMINATOR_2026-07-05.md`.
That packet can feed `ORBIT_OR_HOLOMORPHIC_COUNT_SELECTOR_RETAINED` and
`DIMENSION_BORN_DEFAULT_EXCLUSION` if later accepted, but it does not by itself
ratify `K1_COUNTING_MEASURE_RETAINED`.

the Koide K1 block/orbit/holomorphic counting-measure handoff.

| K1.6 | leakage and comparator boundary: K1 consumes no K2/K3/K4/native/branch/mass inputs and no observed lepton, alpha, Rydberg, or hydrogen data as proof input |
| K1.7 | governance boundary: no new axiom, approved primitive, or new Tier-A numerical admission is added; owner and audit acceptance are required |
