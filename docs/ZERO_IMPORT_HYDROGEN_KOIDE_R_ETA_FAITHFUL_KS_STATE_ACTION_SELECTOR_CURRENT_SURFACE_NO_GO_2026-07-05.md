### N7 - Steelman

The strongest objection is that the KS route already determines the selector:
the Kawamoto-Smit map reconstructs the spinor kinetic frame, the Grassmann
surface supplies the fermionic matter mode, and staggered chirality excludes
the wrong scalar reading. A reviewer could say the faithful spin-lift selector
is therefore only a repackaging. This note treats that as the next positive
target, not as an impossibility: the repo still needs an explicit retained
theorem selecting that physical action law.

### N8 - Cross-Cycle Echo

Earlier matter-attachment, carrier-attachment, and boost-action faith notes
carry the same wall shape: operator-frame or bounded route support is not
automatically a physical state-action theorem. Prior retirements of similar
walls required explicit bridge theorems, accepted conventions, or approved
primitive registration. None is present for this selector handle now.

impossibility is not shipped.
