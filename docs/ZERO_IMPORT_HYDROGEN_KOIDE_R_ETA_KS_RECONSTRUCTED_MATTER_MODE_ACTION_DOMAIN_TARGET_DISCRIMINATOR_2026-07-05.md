## Target

The target handoff is:

```text
KS_RECONSTRUCTED_MATTER_MODE_ACTION_DOMAIN_RETAINED
```

Meaning: the Kawamoto-Smit / Grassmann reconstructed matter mode is established
as a physical matter-state object in the domain of a spatial-rotation action.
The target is only the domain theorem. It does not decide whether the action on
that domain is the faithful fundamental `SU(2)` spin lift, the trivial scalar
lift, or an adjoint/operator-frame reading.

This is a child input of
`FAITHFUL_KS_STATE_ACTION_SELECTOR_RETAINED`. It is not the physical rotation
action-selector theorem, the selector theorem, the KS spin-lift action-law
theorem, the scalar-lift exclusion theorem, the KS child theorem, or the parent
physical matter-state bridge.
