## Scope

The h-class fixed-locus packet names a missing input:

```text
SINGLE_FIXED_POINT_READOUT_THEOREM_RETAINED.
```

This discriminator packages that input as its own target. The target is not
physical carrier-context realization, not h-unit identity-radian selection, not
full R-eta retirement, not K1/K3/K4, not a branch mass map, and not hydrogen.

The target sentence is:

```text
the charged-lepton registered datum reads one intensive C3 fixed-point local
Lefschetz density L3(1,2)=2/9, rather than the vanishing global eta/equivariant
readout, the extensive sum over fixed sites, or another K-even functional.
```

This is a readout-functional selection handoff only. It uses the physical
carrier-context lane as a boundary condition but does not prove
`PHYSICAL_CARRIER_CONTEXT_RETAINED`.
