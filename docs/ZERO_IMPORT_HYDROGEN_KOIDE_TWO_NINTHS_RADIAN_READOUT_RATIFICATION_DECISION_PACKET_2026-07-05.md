## Ratification Decision Contract

This packet is decision-ready only if all nine contract inputs are visible:

```text
TWO_NINTHS_READOUT_TEXT_LOCK

DISTINGUISHED_TWO_NINTHS_THEOREM_RETAINED

FOLD_AND_BRANCH_DOMAIN_LOCK
NO_COMPARATOR_PROOF_INPUT
NO_NEW_PRIMITIVE_OR_AXIOM
OWNER_RATIFICATION
AUDIT_ACCEPTANCE
```

The contract means:

1. **TWO_NINTHS_READOUT_TEXT_LOCK:** TNR.1-TNR.6 above is the complete object
   being decided.
2. **FINITE_TWO_NINTHS_DENSITY_CONTEXT_ACCEPTED:** the forced finite `2/9`
   density context is accepted as support, not as radian readout.
3. **DISTINGUISHED_TWO_NINTHS_THEOREM_RETAINED:** a retained theorem identifies
   the distinguished Koide value as exact pure `2/9` without observed lepton
   data or fitted phase data.
4. **RADIAN_READOUT_LICENSE_RETAINED:** the pure number is licensed as the
   charged-lepton `delta` phase.
5. **FOLD_AND_BRANCH_DOMAIN_LOCK:** the `Phi = (1/3) arccos(cos 3delta)`
   fold, branch, sign/chamber, and nondegenerate-domain conventions are fixed
   without empirical selection.
6. **NO_COMPARATOR_PROOF_INPUT:** observed or fitted lepton/hydrogen data is
   excluded as proof input.
7. **NO_NEW_PRIMITIVE_OR_AXIOM:** the decision retires an import; it does not
   add an axiom, approved primitive, or new Tier-A numerical admission.
8. **OWNER_RATIFICATION:** the owner accepts this exact two-ninths/radian
   readout object.
9. **AUDIT_ACCEPTANCE:** the normal independent review/audit path accepts the
   decision and dependency consequences.

No proper subset of those nine contract inputs is a retained two-ninths/radian
readout handoff.
