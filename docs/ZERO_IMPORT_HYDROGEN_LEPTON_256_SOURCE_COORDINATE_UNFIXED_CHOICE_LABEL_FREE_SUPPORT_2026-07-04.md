## Scope

The current compressed C1 target is the normalized label-free charged-lepton
full-cell source-probe interface. Its label-free clause says:

```text
the source controls carry no physical coordinate tag beyond
J(j) = sum_c j_c O_c.
```

The review surface included `#4952`, an owner-special-review Qualification
clarification proposal. The latest refresh found it closed without merge, so
this note treats it only as a conditional route or as shorthand for an
equivalent retained rule. Its proposed clause was:

```text
In particular, a law may not depend on a choice not fixed by the supplied
structure, unless that choice is admitted.
```

This note checks the hydrogen-facing consequence of that proposed clause. If
`#4952` or an equivalent law-level unfixed-choice restriction is accepted, then
a law-level charged-lepton source-strength rule cannot depend on a source
coordinate tag not fixed by the supplied source structure. Therefore the
coordinate-tagged nonuniform rays that defeated label-free naturality become
admission/state-data routes, not zero-import law-level derivations.

This supports the label-free clause of C1 only. It does not supply the
charged-lepton source/action interface, projective source strength, `S_l`
source-readout identity, A3 precision, electron readout, `alpha(0)`, or
hydrogen.

## Finite Source-Coordinate Test

Let

```text
C = {0,1,2,3}^4,
|C| = 256,
J(j) = sum_{c in C} j_c O_c.
```

Let `G_tf` be generated by independent local coordinate relabelings and slot
permutations. This group acts transitively on `C`.

If the supplied structure is only the source family `J(j)` plus the tensor-frame
relabeling action, then every law-level scalar weight assignment that depends
only on supplied-structure invariants is constant on `G_tf`-orbits. Since
there is one orbit,

```text
w_c = w_d  for all c,d in C.
```

After the projective L1 section is supplied, this gives

```text
sigma([j])_c = 1/256.
```

By contrast, a nonuniform law such as

```text
w_c = 4  if the first source coordinate has value 0,
w_c = 1  otherwise
```

depends on the predicate "first source coordinate has value 0." That predicate
is not fixed by the supplied tensor-frame source structure: a source-coordinate
relabeling moves it. Under `#4952`'s proposed rule, using that predicate in a
law is an unfixed-choice dependence unless the coordinate tag is admitted.
