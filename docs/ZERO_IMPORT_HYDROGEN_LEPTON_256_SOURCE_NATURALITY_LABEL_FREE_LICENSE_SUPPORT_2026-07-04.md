## Conditional License Theorem

Let

```text
C = {0,1,2,3}^4,
|C| = 256,
J(j) = sum_{c in C} j_c O_c.
```

Let `G_tf` be the finite tensor-frame source relabeling group generated by
independent local coordinate relabelings and slot permutations. It acts
transitively on `C`.

Assume the charged-lepton source interface is label-free:

1. the physical source family is exactly the slot-resolved family
   `J(j) = sum_c j_c O_c`;
2. tensor-frame relabelings that preserve this source family are gauge/source
   coordinate isomorphisms, not different physical source systems;
3. the projective source-strength assignment is a function of the physical
   source-interface isomorphism class, not of coordinate names.

Then for every `g in G_tf`,

```text
[j] = [rho_g j].
```

This is exactly W5b. Because every generator has finite order, any positive
projective character is trivial on the generator:

```text
[rho_g j] = [lambda_g j],  g^n = e,  lambda_g > 0
  -> lambda_g^n = 1
  -> lambda_g = 1.
```

Thus the ray is ordinarily invariant under the transitive tensor-frame action.
Transitivity then forces all singleton source strengths to agree, and the L1
section gives

```text
sigma([j])_c = 1/256.
```

## Counterexample Boundary

A nonuniform ray is possible only if there is extra source-coordinate content.
For example,

```text
j_c = 4  if the first source coordinate has value 0,
j_c = 1  otherwise
```

normalizes to a valid positive source ray, but it is not invariant under
source-coordinate relabeling. Its distinguished first-coordinate predicate is
a physical tag. If such a tag is supplied by a charged-lepton theorem, W5b
does not hold. If no such tag is supplied, the tag is not an allowed
zero-import source selector.
