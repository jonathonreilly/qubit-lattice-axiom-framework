## Review rule

- Only `retained`, `retained_bounded`, and `retained_no_go` are retained-grade.
- `retained_pending_chain`, `audited_*`, `audit_in_progress`, `open_gate`,
  `meta`, and `unaudited` are not publication authority.
- A section heading or author-side table label is never a verdict; the badge on
  each generated row governs.
- Historical sole-/three-axiom statements must not be read as conclusions on
  the current Lattice/Qubit/Admissibility/Record surface.
- Negative claims require a current authenticated N1-N8 packet.

The current package is therefore a review and re-audit surface, not a claim of
Nature readiness or a broad retained theorem core.
