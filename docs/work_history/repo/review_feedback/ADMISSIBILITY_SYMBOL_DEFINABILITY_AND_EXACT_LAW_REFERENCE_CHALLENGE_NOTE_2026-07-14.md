## Question

The live Admissibility axiom already says:

> There is one fixed nearest-neighbor admissibility rule, covariant under
> lattice translations and proper cubic rotations.

Does that singular existential already identify the law as model data, making
an additional exact-law reference redundant? Or does the theory still fail to
choose between predictively distinct rules?

The answer depends on which job the document is meant to do: define a
framework schema, state a theory of our universe, or describe one instantiated
model.

## Result Up Front

The challenge changes the constitutional conclusion, but it does not erase the
predictive gap.

1. **No second existence statement is needed.** The current sentence already
   gives the language one rule slot and commits each intended model to one
   fixed interpretation. Adding a fifth axiom merely saying that a law exists
   would duplicate that content.
2. **A named function symbol is not an extensional specification.** In standard
   model semantics, each model gives the symbol one interpretation. Different
   models of the same theory may give it different interpretations. The word
   “one” prevents a model from switching rules mid-history; it does not by
   itself make all models use the same table.
3. **The current structural clauses do not implicitly define even the
   availability map.** Two expansions of the same rule-free foundation reduct
   satisfy fixedness, nearest-neighbor dependence, proper-cubic covariance,
   variation, and possibility-label neutrality, yet give opposite singleton
   menus on one four-to-two neighbor profile. A common write bridge then
   produces opposite next records.
4. **Even an exact availability table is not the complete physical law.** The
   live memo expressly says Admissibility is not dynamics. Two complete record
   laws can share the same extensional availability map while assigning
   different record weights, rates, instruments, collision behavior, or
   response. The exact-law lower bound therefore concerns the complete
   predictive object L*, not the bare symbol A.
5. **A stable external exact artifact can be a definition or cross-reference
   rather than another prose axiom.** But its semantic status depends on use.
   If it merely exposes a rule already uniquely derivable, it is definitional.
   If it chooses one of several models still admitted by the current theory,
   it is model-selection and therefore adds physical content even when written
   as a definition. If it is supplied only in an instantiated model, that
   model predicts while the framework remains a family.

So **the lower bound narrows**:

> The framework does not need another axiom saying “there is a law.” A TOE
> theory needs either a theorem that uniquely determines the complete
> predictive law up to exact physical equivalence, or one stable exact
> specification that selects it. That specification may be housed as a
> definition/cross-reference in the type-correct place rather than as a new
> independent axiom sentence.

No axiom edit is recommended at this stage. There is still no exact complete
referent ready to cite, and an availability-only identifier would not close the
physics lanes.

## 1. What The Live Sentence Supplies

Let L0 be the foundation language with lattice, one-site possibility algebra,
record predicates, and readout, but with the admissibility symbol removed. Let
L be L0 plus a symbol A of schematic type

    A : nearest-neighbor condition -> nonempty menu of possibilities.

There are two natural formal readings of the English sentence.

### Named-symbol reading

A is a nonlogical function or relation symbol in the signature. Every L-model
automatically gives A exactly one interpretation A^M. “Fixed” says that this
interpretation does not change from state to state or event to event inside M.

This is the most natural reading of the live memo and registry. On this
reading, “one” is not a theorem that the structural conditions have a unique
solution. It is the declaration that the model contains one designated rule.

### Quantified-rule reading

The sentence can instead be formalized in a stronger higher-order metalanguage:

    there exists A such that LocalCovariantVarying(A).

That asserts existence but still not unique existence. Replacing it by

    there exists exactly one A such that LocalCovariantVarying(A)

would assert a uniqueness theorem about candidate rules on a supplied
background. The current two-model construction shows that the displayed
structural property does not have that uniqueness on the tested reduct.

On either reading, a singular grammatical subject is not an extensional table.
The distinction is the same as the distinction between naming one mass
parameter m and supplying its value.

## 2. Theory, Model, And Extensional Specification

A **theory** T is a set of sentences. It defines a class Mod(T) of structures
that satisfy those sentences.

A **model** M is one such structure. It includes:

- the site set and lattice relations;
- the one-site algebra;
- the record and readout interpretations; and
- one extensional interpretation A^M of the admissibility symbol.

An **extensional specification** of A gives its value on every input in its
declared domain, or gives a finite rule from which every value follows.

Therefore these are all compatible:

    every model has one A;
    A is perfectly fixed within every model;
    every A gives one menu at every condition;
    different models interpret A differently.

The first three are intra-model functionality. The fourth is inter-model
underdetermination.

This is not a complaint about model theory. A framework is often intentionally
a schema whose models differ. The distinction matters only when the framework
is asked to be the complete theory of one universe and to make unconditional
record predictions.

## 3. Paired Expansions Of One Foundation Reduct

The exact finite runner checks a binary orthogonal-projector sector of the live
M2(C) possibility domain. The analytic lift is coordinate-free.

At one site, suppose the six nearest-neighbor record contents lie in an
orthogonal pair of rank-one projectors {P, 1-P}. Define two rules:

### Majority availability

- if one projector appears more often, only that projector is available;
- on a three-to-three tie, both are available.

### Minority availability

- if one projector appears less often, only that projector is available;
- on a three-to-three tie, both are available.

For nonbinary or noncommuting neighbor profiles, give both rules the same full
menu. This common extension is enough to make them total.

Both rules are:

- fixed;
- functions only of the six nearest neighbors;
- invariant under translations and proper cubic rotations;
- equivariant under simultaneous unitary conjugation of the projector data,
  so no projector label is privileged; and
- genuinely varying with neighbor conditions.

Hold fixed the complete L0 reduct: the same Z3 lattice, the same M2(C)
possibility fibers, the same current record configuration, and the same
readout. Evaluate both expansions on the same externally supplied local test
condition at an arbitrarily chosen site. Put the already existing record in a
three-to-three context, where both rules allow it. The two L-expansions differ
only in A.

At an open test site with four P neighbors and two 1-P neighbors:

    majority menu = {P}
    minority menu = {1-P}.

Apply the same covariant conditional write bridge to both expansions: at every
ready site whose menu is a singleton, the new record locks its sole member.
The bridge privileges no site or state; readiness is its supplied domain. The
next readable record is P in one completion and 1-P in the other.

Both models can be completed with the same append-only Record semantics. An
anchor record forms in the shared tie context, remains present with unchanged
content, and has content-only additive scalar readout. The target append adds
one record without altering the anchor. Thus record formation, one-record-per-
site uniqueness, permanence, readability, and finite additivity can all be
satisfied in both completions; only the admissible target content differs.

The runner exhausts all 64 binary six-neighbor profiles and all 24 proper cubic
rotations. It also checks global label exchange, nonempty menus, variation, a

This is a same-reduct paired-expansion witness. It directly refutes implicit
definability for this faithful formalization of the displayed clauses. It is

## 4. Named Function Symbol Versus Unique Existence

Four notions must not be collapsed.

| notion | what it says | what it does not say |
|---|---|---|
| named symbol A | every model interprets A once | all models give A the same extension |
| functionality | one supplied A gives one menu for each input | which function A is |
| unique existence relative to a reduct | one A satisfies a defining condition on that fixed reduct | that every allowed reduct carries the same empirical parameters |
| explicit identity | a formula, table, or exact referent fixes A | that A is the complete dynamics |

The runner also checks a useful parameter trap. Let a binary parameter epsilon
select majority at epsilon=0 and minority at epsilon=1. For each fixed epsilon
there exists exactly one selected rule. But if the theory does not fix epsilon,
its models still make opposite record predictions.

Unique existence can therefore relocate rather than eliminate freedom. To
close the theory, every selector appearing in the purported definition must
itself be fixed by the supplied structure, derived, or declared empirical
model data.

There is one important positive route. If the current foundation proves that
every L0 reduct has one and only one admissibility expansion and proves that
all complete record predictions follow from it, no exact-law adoption is
needed. That is the zero-edit uniqueness route.

## 5. Implicit Definability, Explicit Definability, And Beth

For a classical first-order theory T in L=L0 union {A}:

**Implicit definability** means that whenever two models of T have the same L0
reduct, their interpretations of A agree.

**Explicit definability** means that there is an L0 formula delta such that T
proves, for every input and output,

    A(input, output) iff delta(input, output).

Every explicit definition is automatically implicit: two structures agreeing
on all L0 facts must agree on delta and therefore on A.

Beth's definability theorem supplies the nontrivial converse for classical
first-order theories: if A is implicitly definable, then an explicit
definition exists. The original source is E. W. Beth, “On Padoa's Method in
the Theory of Definition,” Indagationes Mathematicae 15 (1953), 330-339,
[doi:10.1016/S1385-7258(53)50042-3](https://doi.org/10.1016/S1385-7258(53)50042-3).

The logical consequence here is deliberately modest:

- the paired same-reduct expansions already refute implicit definability;
- explicit definability would imply implicit definability, so they also refute
  an L0 explicit definition for this formalized theory;
- Beth is not needed for that negative direction;
- Beth says that a future genuine implicit-uniqueness theorem would, under a
  classical first-order formalization, support a zero-edit explicit definition.

The scope guard matters. The public axioms are English statements about
algebra-valued possibilities, and a final law may use second-order,
infinitary, categorical, or finite-only semantics. Beth's classical theorem
cannot be imported unchanged into every such logic. In particular, a
finite-only Beth property is not automatic. The paired expansions remain a
direct semantic witness; the theorem's converse must be rechecked for the
chosen final formal language.

## 6. Three Different Jobs For The Framework

| role | is the singular symbol enough? | honest status |
|---|---|---|
| **framework schema** | yes | A is a model parameter ranging over fixed covariant local constraints; downstream results are uniform in A or conditional on A |
| **theory of our universe** | no, unless predictions are invariant across every admitted A or A/L* is uniquely derived | the theory still admits worlds with different readable records |
| **instantiated model** | yes, if A^M and every other law field are supplied extensionally | the model predicts, but any empirically inserted table or coefficient is model data rather than a derivation from the framework |

This table resolves the strongest objection to the earlier exact-reference
language. “There is one actual rule” can be ontologically true and sufficient
to describe a model even when the public theory cannot calculate which rule it
is. Requiring an internal derivation in every working model would confuse a
theory with its instances.

But a true TOE target is stronger than a family plus an unspecified member. If
two admitted members predict opposite records for the same supplied
preparation, the theory of our universe has not yet selected a prediction.

## 7. Can A Stable External Exact Artifact Be A Definition?

Yes, but there are three semantically different cases.

### Conservative definitional extension

Suppose the reduced theory T0 already gives an L0 formula delta that uniquely
determines A. Introducing the new symbol A together with

    A iff delta

is a conservative definitional extension: it abbreviates old-language
content and adds no new old-language physical consequences. A stable external
artifact may document or mechanically implement delta. This is definition,
not a new physics axiom.

### Model-selection inside the current language

Suppose the current theory already contains A but admits the majority and
minority expansions. Adding

    A = A_artifact

removes one of those old L-models. That is not conservative relative to the
existing language. It is model-selection and adds predictive physical content,
even if the sentence is filed under “Definitions” or implemented as a registry
cross-reference.

Syntax does not decide premise weight. Excluding a record-distinguishable model
is substantive.

### Instantiation outside the framework theory

A model file may set

    A_model := A_artifact

without changing the framework schema. This creates a fully specified model
of that aspect. Its predictions are conditional on the supplied artifact.
That is often the right research architecture, but it is not a derivation of
the artifact from the framework.

### What “stable exact” requires

A stable external exact artifact must supply:

- an immutable content identifier, preferably content-addressed;
- a versioned input/output schema and total declared domain;
- exact equations, tables, code plus semantics, or a proof-equivalent finite
  definition;
- all physical parameters rather than a family with free coefficients;
- the projection relating the complete law to Admissibility and Record; and
- an exact physical-equivalence criterion if the artifact denotes a class.

A mutable path, nickname, architecture label, or human convention is not an
exact referent. The runner hashes the full 64-row menu tables. Selecting one
hash reduces the two A-expansions to one; merely naming “a covariant rule” does
not.

## 9. Clause And Placement Consequences

The model-theory challenge removes one bad option and sharpens the remaining
ones.

### Route 0 — framework schema

If the intended endpoint is a framework parameterized by A, make no edit.
State explicitly in downstream work that results are uniform in A or
conditional on an instantiated A.

### Route 1 — unique derivation or implicit-definition theorem

If the four axioms plus approved primitives uniquely determine one complete
physical-equivalence class L*, make no axiom edit. Publish the theorem and its
exact artifact as the canonical derived specification. Under suitable
classical first-order formalization, Beth turns genuine implicit definability
into an explicit definition.

### Route 2 — adopt an exact availability map only

If the scientific decision is only to select A, the minimum syntactic surface
is a definitional cross-reference adjacent to Admissibility:

    The admissibility rule is the rule specified by <immutable identifier>.

This does not need a fifth axiom name. However, because it excludes current
models, it is foundation-strengthening unless the rule was already derivable.
It also leaves every non-availability lane open.

### Route 3 — complete local law

If the exact referent is a local continuation/instrument/QCA law L* and A is
its menu projection, retype Admissibility as the local physical-law slot:

    The physical law is the law specified by <immutable identifier>; its
    nearest-neighbor availability projection is the admissibility rule.

That preserves one constitutional identity but requires retiring the memo's
sentence that Admissibility is not dynamics. The referenced artifact, not the
short sentence, must pass the complete-law contract.

### Route 4 — complete global-history law

If L* is a global action, history constraint, or history measure not
type-identical to a nearest-neighbor menu map, keep Admissibility unchanged and
use a separate Law slot. A fifth name is then type honesty, not a second
independent physics atom.

### Route 5 — empirical instantiated model

Keep the model's exact artifact in a model/parameter specification rather than
the axioms. The framework remains general; claims depending on the artifact
remain conditional or fitted. This is scientifically legitimate but is not
the final parameter-free TOE claim.

No Record sentence follows from this analysis. A reader, clock, second witness,
storage pressure, or formation trigger should be derived from the exact law or
tested as a separate import, not used to hide the missing extensional law.

### N7 — Strongest Hostile Steelman

A hostile reviewer should say: the phrase “there is one fixed rule” is a
definite description of the actual world's rule, so the model already contains
exactly the object needed. Physics theories routinely contain constants or
functions whose values are learned empirically; demanding that the short axiom
print the full table confuses a theory with a model and confuses semantic
reference with human calculability. Moreover, all observable consequences
might turn out invariant over the admissible rule family, or a future
reconstruction theorem might prove the relevant rules operationally
equivalent. In any of those cases an added exact-law axiom is redundant.

This steelman is convincing for a framework schema and for a fully
instantiated empirical model. It also defeats the broad claim that “the symbol
does not identify anything.” The conclusion is therefore narrowed exactly as
the steelman requires. It does not defeat the theory-of-our-universe residual:
the displayed pair produces different readable records, and exact A still
does not carry the dynamics the memo expressly withholds.
