They are generated by a small signed symplectic-tableau algebra:

- five bits represent a signed two-qubit Pauli row;
- two commuting independent rows represent a stabilizer state;
- one symplectic parity test determines commutation;
- three parameterized bit updates implement `H`, `S`, and `CNOT`;
- commuting-row multiplication and one pivot rule implement conditional Pauli
  measurement.

The reconstruction exactly matches the independent Cycle-48 matrix results.

## Clifford reconstruction

```text
H(q):     phase correction, swap x[q] and z[q]
S(q):     phase correction, z[q] ^= x[q]
CNOT(c,t): phase correction, x[t] ^= x[c], z[c] ^= z[t].
```

Applied to both state generators and canonicalized by the stabilizer-group
key, they reconstruct:


On all 32 signed rows:

```text

```

Thus the declared reverse CNOT and SWAP maps are consequences of the smaller
generator set.

## Conditional measurement reconstruction

For a signed measured Pauli `P`:

1. If `P` commutes with both state generators, it or `-P` is already in the
   maximal stabilizer group. The matching outcome is certain and leaves the
   state unchanged; the opposite transcript is rejected.
2. If `P` anticommutes with a generator, the branch is classified as half
   weight. One anticommuting generator is replaced by signed `P`; any other
   anticommuting generator is first multiplied by the pivot. The new group key
   is the exact Lüders target.

The result is:

```text
state/measurement/outcome branches                1,800
wrong probability classes or targets                  0
all generator-basis presentations                10,800
basis disagreements                                    0
```

The six-basis invariance matters. It proves the algorithm acts on the physical
stabilizer group, not on the arbitrary pair of labels Cycle 48 happened to
store.
