seven-vertex BKSF graph.  It supplies a target-independent open-boundary state
encoder in two cleanly separated pieces:

1. start every BKSF graph-edge qubit in `|0>`, measure the local loop checks, and apply

## Target-independent preparation protocol

The vacuum protocol is fixed before any target matter state is supplied:

1. **Cell triangles.** Measure the 12 triangle rows per cell and use the same
   fixed 12-column intra-cell Z decoder everywhere.  Its rank is 12, it closes
   every unit syndrome, has 30 active table entries, and maximum correction
   weight seven.
2. **Coarse plaquettes.** Measure the coarse plaquette rows and use an
   open-boundary Z-chain decoder on matter-stream edges.
3. **Bond rectangles.** Measure each bond rectangle and correct it on its
   unique reference-bond Z edge.

Later stages do not reopen earlier syndromes.  Every correction is Z type, so
all `B_v` and hence every `D_x` stay positive.  Matrix identities test every
lawful syndrome, rather than sampled measurement outcomes.  Removing any
active coefficient from the canonical cube decoders is detected; all unit
syndromes remain closed before deletion.

Checks have bounded weights: at most 10 for cell triangles, 16 for bond
rectangles on the tested cubes, and 36 for coarse plaquettes.  Greedy disjoint

corresponding conservative sequential-ancilla two-qubit-layer upper bound is
672 at L5.  This is a bounded check-measurement schedule; it is not the depth
of the classical correction network.

No stage or schedule counter is physical time.

## Explicit local logical tableau and coherent load circuit

For mode `a=0,...,5` in cell `x`, with reference vertex `r_x`, define

```text
Z_(x,a) = B_(x,a),
X_(x,a) = -i [product_(b=a)^5 B_(x,b)] A_((x,a),r_x).
```

The suffix and its phase are load bearing.  In the `D_x=+1` code sector the
reference occupation is the parity of the six matter occupations.  An
independent seven-mode Jordan--Wigner decoder exhausts all 64 matter states for
each of the six modes.  All 384 suffix actions flip the requested matter bit,
flip the reference-parity bit, and have amplitude `+1`, with zero orientation
failure.  A second explicit test loads every one of the 64 six-mode basis
states from vacuum: the suffix loader has zero state or amplitude failures.

This amplitude test resolves an ambiguity invisible to canonical
commutators.  The local prefix representative

```text
A_((x,a),r_x) product_(b<a) B_(x,b)
```

has the same canonical Pauli algebra but decodes as
`-i X_(x,a) product_(b=0)^5 Z_(x,b)`.  It mismatches plain `+1` X on all 384
mode/state columns.  The runner verifies both the decoded phase formula with
zero failures and the exact physical-Pauli relation

```text
prefix = -i suffix-X cell-Z
```

with operator order as written.  A scalar phase cannot remove the
occupation-dependent cell-parity factor, so the prefix is not used by the
loader.  When applied successively from vacuum it has a non-`+1` amplitude on
32 of the 64 full-cell columns.  It could define a bounded parity-twisted local
chart, but it is not the plain computational-basis isometry claimed here.

The remaining order is a six-mode intra-cell Fock chart; it is not a global
Jordan--Wigner order or parity service.  Exact tests on the L shape, planar
square, and cubes L2--L5 give:

- zero canonical-pair failures;
- zero commutators with every loop and `D` stabilizer;
- zero Hermitian-involution failures;
- logical symplectic rank exactly `12N`;
- maximum X weight 19 and maximum Z weight 6;
- at most 12 controlled-X support colors and six parity-CNOT support colors.

Given a prepared vacuum and one input qubit per logical mode, apply controlled
`X_(x,a)` from the input to the edge code, then apply CNOTs from the physical
edges in the Z support back to that input.  The second layer is the coherent
logical-Z parity CNOT.  Per mode it implements

```text
|q>|0_L> -> |q>|q_L> -> |0>|q_L>,    q in {0,1},
```

and therefore extends linearly to every superposition and entangled `6N`-qubit
input.  Controlled Pauli factors and parity CNOTs use only the bounded supports
above.  The circuit, its support coloring, and all phases are independent of
the target amplitudes.

This closes the previous distinction between an algebra-only BKSF map and an
open-boundary common state encoder.  The encoder still depends on preparing
the vacuum, whose exact measurement/feedforward implementation has the range
boundary below.
