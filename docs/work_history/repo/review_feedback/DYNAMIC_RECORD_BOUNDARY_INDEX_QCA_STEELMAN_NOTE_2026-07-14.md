## 1. Primitive Displacement Obstruction

Start with the smallest deterministic primitive-qubit permutation update,

```text
q_x at one update <- q_(x-v),
```

for a fixed nearest-neighbor displacement `v`. Translation covariance is
automatic. Proper-cubic covariance requires

```text
R v = v
```

for all 24 proper cubic rotations. Exhausting `v` in `{-1,0,1}^3` leaves only

```text
v=(0,0,0).
```

This primitive displacement obstruction is exact for the one-component
permutation class. It is not a theorem about interacting Clifford QCAs,
multi-component walks, or exotic three-dimensional indices.

The carrier count explains the next move. One `M_2(C)` factor cannot be both
an independent permanent record bit and an independent outgoing qubit factor:

```text
2 < 2 x 2.
```

A direct record plus six independent face rails has dimension

```text
2 x 2^6 = 2^7,
```

so it uses seven primitive qubits. The center and its six nearest neighbors
form exactly such a proper-cubic orbit. A more economical single-particle
direction label has dimension six; together with a record it has dimension
`12` and first fits in four qubits, but it does not provide six independent
qubit channels and leaves four binary-encoding states unused.

These are direct-encoding counts, not global lower bounds over every quantum
code.

## 2. A Record-Generated Boundary

For a binary record indicator `r(x)`, define the local record gradient at an
empty face site `x` by

```text
g_i(x) = r(x-e_i) - r(x+e_i),    i=x,y,z.
```

If the only record is at `c`, then for all six unit directions `d`,

```text
g(c+d)=d.
```

If the occurrence field is absent on that fixture, `g=0`. The runner verifies

```text
g_R(Rx)=R g(x)
```

for all 24 proper cubic rotations and verifies the translated formula around
an arbitrary center. The boundary normal is therefore relational record
content, not a preferred direction in the law.

This is a kinematic closure only. It does not say which record occurs, prepare
an isolated record, resolve overlapping boundaries, or prove that a record
cluster carries a topological bulk phase. The realized-state primitive permits
pointwise evaluation at such a history but does not select it.

It is also post-record geometry. If no record exists, `g=0`; the boundary rule
cannot nucleate the first record from an empty record configuration. The first
record may be realized boundary data or may require a different branch of the
exact formation law. The index does not decide that question.

## 4. Interacting Six-Ray QCA

Take six independent bilateral one-qubit rails related by the proper cubic
group. Each rail has coordinate `n in Z`; its record boundary is at `n=0`, its
interior/reservoir is `n<0`, and its low-record exterior is `n>=0`. Along each
rail apply the same translation-invariant controlled phase

```text
D_phi = diag(1,1,1,exp(i phi))
```

on neighboring rail qubits, then shift every qubit one position outward. The
controlled-phase layer is finite depth (the gates commute), local, and
interacting for nonzero `phi`. The shift supplies the long-range algebra flow.

For this partitioned wire model define

```text
nu = number of outward qubit factors crossing a cut
   - number of inward qubit factors crossing it,
index = 2^nu.
```

One outward ray has `nu=1`, index `2`. The six-ray shell has `nu=6`, index
`64`; the law with all six shifts reversed has index `1/64`. Proper-cubic
covariance requires the six `phi` values to agree but places no equation on
their common value.

Two exact laws are

```text
U_(pi/2) = shift after D_(pi/2),
U_pi     = shift after D_pi.
```

They are distinct, unitary, translation-covariant along each ray,
proper-cubic across the star, and share the same index. Their local entangling
strengths differ. Thus deterministic uniqueness is not obtained from the
index.

This is the smallest explicit positive object in the cycle, but its scope is
important:

- it is a six-ray boundary QCA around an isolated relational center;
- the bilateral interior factors and exterior factors are explicit generated
  carrier structure;
- it is not a homogeneous construction covering arbitrary overlapping record
  domains on all of `Z^3`;
- its index is the displayed partitioned wire-flow index, not a computed
  invariant of a full three-dimensional anomalous bulk;
- its boundary rails and initially usable exterior are explicit carrier/state
  data; and

The construction therefore proves that interaction and nonzero flow are

## 7. Stable Record Instrument


```text

```

This is an exact unitary two-copy premeasurement. The reduced record/witness

```text
(|00><00|+|11><11|)/2.
```

Now compare two channels:

1. retain the pure coherent GHZ state;
2. apply the basis-record instrument with conditional members `|000>` and

The two channels have the same local two-record density matrix and can be
adjoined to the same outward indexed QCA. Their global density matrices are

Thus a stable record instrument is not derived from the displayed index. This
is a category boundary as well as a parameter boundary: the wire-flow index is
defined for automorphisms, while an outcome-producing instrument carries
