# Exact-Law Constitutional Placement Schema Probe

**Date:** 2026-07-14

**Type:** meta

**Authority:** none. This is a local language-placement and type-safety probe.
It is not an axiom proposal, axiom amendment, primitive, canonical-law choice,
premise registration, audit verdict, or owner approval. It changes no live
foundation, registry, policy, queue, or audit surface.

## Question

If the remaining irreducible content is one exact predictive-law identity,
where can that identity eventually be stated without pretending that the
current Admissibility axiom already supplies dynamics, or that Record alone
supplies the rest of physics?

This question is prior to prose polish. A short sentence in the wrong type can
be less honest than a longer sentence in the right place.

## Result Up Front

The scientific atom is still one exact referent, not a list of formation
slogans. Its honest constitutional location depends on the type of the object
that survives the law search:

1. If the selected object is a local continuation law whose availability
   projection is exactly the current nearest-neighbor menu rule, the smallest
   coherent cut is to **retype Admissibility as the complete local law** and
   identify the exact object there. That keeps four named axioms but requires
   retiring the memo's explicit sentence that Admissibility is not dynamics.
2. If the selected object is instead a global-history action, constraint, or
   equivalence class not naturally identical to a per-site nearest-neighbor
   continuation map, the clean placement is a separate **Law** axiom while
   retaining Admissibility as its local availability interface. That makes
   five named axioms but adds no more scientific content than route 1.
3. Putting a trigger in Record closes only the record event. It cannot by
   itself identify coherent evolution, contexts, weights or deterministic
   continuation, concurrency, actuality, renewal, matter, or gravity.
4. Putting “the law is ...” only in Qualification can carry the reference in
   prose, but conflicts with the memo's rule that the axioms state only their
   named primitive content. It is not the clean endpoint.

No route is ready to land because no exact referent has passed the ten-field
contract. The result is a placement gate, not a wording recommendation.

## 1. The Type Mismatch In The Live Text

The live Admissibility axiom supplies a function of the schematic type

```text
A : nearest-neighbor condition -> nonempty set of available possibilities.
```

The memo then states verbatim that Admissibility is not a dynamics axiom and
does not choose a Hamiltonian or transfer operator, weights, a record-
production process, or persistence dynamics.

A complete predictive law has a larger type. Depending on whether it is
deterministic, sampled, or a global constraint, it must determine or encode the
ten-field contract:

```text
DOMAIN, STATE, CONTEXT, ATOMIC_LAW, CONTINUATION,
AVAILABILITY, CONCURRENCY, RECORD, ACTUALITY, STATISTICS.
```

It may also expose contingent boundary/history slots without selecting their
values. Its availability projection can equal `A` while its continuation or
statistics differ.

The companion gives an exact finite witness. Two laws have the same complete
availability support `{0,1}` for every neighborhood but assign probabilities
`(1/2,1/2)` and `(2/3,1/3)` to the same next record. Naming their common
availability rule does not identify which law makes the prediction.

Therefore the sentence

```text
The fixed admissibility rule is [EXACT COMPLETE LAW].
```

is type-safe only if the bracketed source defines a named availability
projection and the sentence identifies merely that projection. In that
reading it does not adopt the rest of the law. If it is intended to adopt the
whole object, the axiom must first be retyped from menu constraint to physical
law.

## 2. Placement Alternatives

### Route A — derive the exact law; make no edit

This remains the best outcome. A theorem from the present four axioms could
identify one complete law or one exact transcript-equivalence class. The
canonical specification would then be a theorem target, not a new premise.

No present theorem meets that gate.

### Route B — retype Admissibility as the complete local law

This route preserves four named axioms and places one new scientific atom in
the paragraph already owning the fixed nearest-neighbor rule. Its eventual
shape, before language polishing, is:

```text
### [Admissibility/Local Law — final name unresolved]

[One fixed covariant local physical-law sentence.]

[The existing nearest-neighbor availability sentence, now explicitly the
availability projection of that law.]

[One stable exact-law identification.]
```

This is honest only if the referent really is local in the declared sense and
fills continuation, event, actuality, and statistics rather than merely
pointing to an architecture. Required synchronized consequences include:

- the title, Purpose list, and every “four axiom names” surface;
- the relation-to-dynamics section, which must no longer say the axiom is not
  dynamics;
- the open-gate list, which must remove only fields actually filled by the
  referent;
- the registry quotation and no-laundering boundary;
- the minimality policy approval record and fixed-foundation description;
- the primary runner's source needles and boundary text; and
- controlled-vocabulary and cross-reference surfaces identified by the impact
  map.

The scientific content count is one. The editorial blast radius is large
because the current memo deliberately firewalls Admissibility from dynamics.

### Route C — add a separate Law axiom

This route retains the exact current meaning of Admissibility and gives the
larger object its own type:

```text
### Law / Physical Continuation

[One stable exact-law identification, with its relation to Admissibility and
Record defined by the referent.]
```

It is semantically clean for a global-history action or constraint and avoids
rewriting “availability” to mean “all physics.” It increases the named axiom
count from four to five, so the title, Purpose, registry, policy, runner, and
every exact-four guard must change. That is an editorial and constitutional
cost, not an extra independent physics atom.

A fifth name is preferable to a four-name fiction if the final law is not a
nearest-neighbor continuation object. Conversely, a fifth name is unnecessary
if the complete law naturally subsumes the current Admissibility map.

### Route D — add formation content to Record

Record already supplies occurrence, one locked admissible possibility per
site, permanence, readability, and scalar additivity. A formation trigger can
say when one record appears or which possibility it locks. Even an exact
trigger does not identify the rest of the predictive law.

The runner's field matrix grants a generous Record trigger the `RECORD` field
and, if explicitly bundled, one part of `AVAILABILITY` or `ACTUALITY`. It still
leaves the coherent/deterministic continuation, contexts, overlapping-event
composition, weights, renewal, and downstream matter/gravity interfaces
unidentified. This route is therefore an optional theorem or clarification
after a law is known, not a substitute for law identity.

### Route E — put the identity in Qualification only

Qualification already contains general law discipline. A reference placed
there could technically be premise text because the whole memo is registered.
But the memo says, “These axioms state only their named primitive content.” A
load-bearing exact law in an unnamed paragraph would violate that organization
and make dependency descriptions misleading. It should not be the final form.

## 3. What The Exact Referent Must Be

The reference cannot be a family name such as `QCA`, `multiway`,
`causal-front`, `least action`, `maximum entropy`, `Wolfram model`, or
`disagreement law`. Those are languages or mechanisms with inequivalent
members.

A stable referent must identify either:

1. one complete exact mathematical object, including every physical parameter
   and the boundary/history interface; or
2. one exactly defined equivalence class plus a proof that every
   representative gives identical probabilities for every finite readable
   record protocol in scope.

The source must be stable under file renaming and editorial refactoring. The
repo can implement that with a canonical claim identifier and source path in
the premise registry, but the identity cannot be only a mutable prose label.
The referent must pass the canonical-law completeness runner independently of
the axiom sentence.

## 4. Does Record Need To Change?

Not on present evidence.

Once an exact law is supplied, the following are theorem targets:

```text
formation event -> one appended record;
old record identity and content are preserved;
later compatible reads reveal rather than create the record;
record append order defines a causal clock order;
formation statistics follow from the exact event law or deterministic corpus.
```

The live Record axiom already insists that records form and are permanent. A
candidate law that cannot satisfy those statements is not a completion of this
framework; it is a different framework. Adding two witnesses, a reader, a
clock, a counting rule, or storage pressure to Record would not repair an
incomplete law.

One Record clarification becomes necessary only if the selected law exposes a
real ambiguity in the intended invariant—for example, whether permanence is
site-tethered, content-tethered under motion, or only sector-relative. That
question cannot be polished before the law decides which notion is physically
realized.

## 5. Decision Gate Before Language Iteration

Do not choose Route B or C by counting sentences. Choose it by the final
object's mathematical type:

```text
local continuation/instrument/QCA with an availability projection
    -> retyped Admissibility is the smallest coherent placement;

global history action/constraint not identical to the local menu map
    -> separate Law is the smallest type-safe placement;

uniqueness theorem from the current four axioms
    -> no constitutional edit;

formation trigger without a complete exact law
    -> not ready for any constitutional cut.
```

Only after this gate closes should exact prose be iterated. The eventual
language can then be short because the stable referent, not adjectives in the
axiom sentence, carries the equation.

## 6. No-Go Discipline Gate

boundary, identifying the existing availability map alone cannot identify a
complete predictive law.** No universal claim is made that a four-axiom
formulation, a fifth Law axiom, or a derivation is impossible.
