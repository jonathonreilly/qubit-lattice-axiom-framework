## Result

`FINITE_CYCLE48_LOCAL_DECODER` is constructive at finite scope.

Cycle 48's abstract preparation decoder uses six permanent bits. Codes `0`
through `59` name the complete sixty-state pure two-qubit stabilizer class;
codes `60` through `63` are rejected. This cycle realizes that finite map as
strict nearest-neighbour record formation. The only variable input is six
literal permanent H0/H1 records. There is no host-time lookup during a run,
supplied state selector, coordinate parity, overwrite, reader, or hidden
carrier.

A serial chain writes one record per observed prefix. The role of the first
record distinguishes `0` from `1`; the role of the second distinguishes all
four two-bit prefixes; and so on. There are exactly

```text
2 + 4 + 8 + 16 + 32 + 64 = 126
```

nonempty prefixes, so the existing 153-role campaign alphabet can name every
one while reserving 27 interface roles. The sixth record is already the
physical state ID. Sixty final roles decode to the Cycle-48 state IDs and four
different final roles are explicit rejects.

The decoder is compiled into the same raw rule table as the Cycle-144
physical-byte/recurrent-root bind. The two raw domains are disjoint, their
union is single-valued, and every word in every proper-cubic orientation stays
quiet against the completed bound corpus.

The six input bits are not generated from the recurrent archive. They remain
preparation records. This result also does not compile
Cycle 48's Clifford gates, Pauli instruments, teleportation corrections, or
event transcript into this local device. Born–Lüders weights remain
conditional on the Cycle-48 operational import. No axiom addition follows.

## What bridge this closes

Cycle 48 had already established, inside its declared finite stabilizer
fragment, that complete preparation and event records determine the coherent
carrier state and all later declared statistics. Its six-bit preparation code
was nevertheless a Python-level decoder. Cycle 145 removes that particular
host lookup: a fixed local covariant rule now turns the six literal records
into one physical state-ID record.

This is a real but narrow bridge:

```text
six permanent preparation records
    -> local prefix history
    -> one of 60 physical stabilizer IDs / four rejects.
```

It does not yet provide:

- generation or copying of the six inputs from the recurrent archive;
- a local physical implementation of the 420 Clifford transitions;
- a local implementation of the 1,800 binary Pauli outcome branches;
- an occurrence law or derivation of their `0`, `1/2`, and `1` weights;
- arbitrary non-stabilizer state reconstruction;
- compact-law selection or uniqueness.

The next constructive interface is therefore not “invent a decoder.” It is
to bind literal preparation/event records to this input/output port, then ask
whether the transition table can be compressed into a smaller recurrent
grammar without importing a selector.
