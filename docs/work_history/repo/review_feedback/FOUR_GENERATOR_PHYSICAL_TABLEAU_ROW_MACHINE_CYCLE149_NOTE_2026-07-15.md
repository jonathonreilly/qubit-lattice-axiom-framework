## Result

Cycle 149 constructs a **four-generator physical tableau-row machine**. It
replaces the state-level Clifford ROM with a recurrent processor for one
five-bit signed Pauli row. Two copies of that processor update the two
generators of a stabilizer state, independently of which of the six generator
bases represents the state.

The local primitive alphabet is:

```text
H on qubit 0
H on qubit 1
S on qubit 0
CNOT 0 -> 1.
```

`S` on qubit 1 is generated by an explicit eleven-event word. Reverse CNOT
and SWAP are generated by the shorter Cycle-148 identities. All seven declared
Cycle-48 gates are thereby implemented on every signed row.

The deletion/minimality result is bounded to subsets of the five declared
primitives `H0,H1,S0,S1,CX01`. It is not a universal generator minimum over
all possible gates, encodings, or group presentations. Within that exact
tournament no three-element subset generates the full 11,520-element action,
and precisely three four-element subsets do.

The measurement pivot compiler remains open. The current 1,800 conditional
measurement rows have a compact mathematical reconstruction but are not yet
replaced by a physical commutation/multiply/pivot tape. No axiom addition
follows.

## Bounded generator tournament

Each of the 31 nonempty subsets of

```text
H0,H1,S0,S1,CX01
```

is closed exactly as a permutation group on the sixty stabilizer states. The
full group has 11,520 elements. The largest three-generator subgroup has
1,152 elements. The inclusion-minimal full-group subsets are exactly:

```text
H0,H1,S0,CX01
H0,H1,S1,CX01
H0,S0,S1,CX01.
```

This establishes four as the minimum cardinality inside the named tournament.
It does not show that every possible physical generator presentation needs
four atoms. A different primitive could package a longer word into one event;
whether that is more fundamental is a law-selection question, not settled by
group cardinality.

## Compression accounting

The relevant progression is:

```text
expanded state-level Clifford rows                 480
five-primitive row-level rows                       160
four-generator row-level rows                       128.
```

This row count is not a universal description-length metric. The compact
machine carries two generator rows per state and expands derived gates into
longer event histories. It trades space in the law for time/records in the
history. That trade is precisely visible rather than hidden:

- state-level ROM: one state record per gate, more law rows;
- tableau machine: two row records per primitive step, fewer law rows and
  basis-independent algebra.

The latter is scientifically preferable as a compression candidate because
the same four update atoms explain every state and every generator basis, but
selection remains open.
