apparatus uses symbolic one-site role labels. What is the honest size and type

physical-equivalence class, is nature's law.

## What honest binary encoding means

An open neighbour slot plus 153 possible symbolic roles gives 154 local input
symbols. Seven bits provide only 128 words, so every neighbour port needs
eight literal `H0/H1` records. One exact radius-one signature is therefore a
48-bit word:

```text
six ordered neighbour ports * eight bits = 48 bits.
```

The output role needs another eight bits. The full extensional law is a
deterministic

```text
48-bit exact signature -> 8-bit output word
```

classifier on 101,996 accepted keys.

This is a macrocode statement. It does not mean one microscopic lattice site
holds 48 input bits. A literal implementation needs spatial words, a physical
frame ordering the six directions, exact equality and open-slot checks, a
selector/program bank, output-word construction, completion records, fresh
support, and recursive handoff to the next macrocell.

Cycles 58, 75, 81, 87, and the later compiler chain construct bounded pieces
of exactly that architecture. They do not yet replace the complete symbolic
law by one autonomous all-row spatial binary implementation.

## Why prefix compression is not a shortcut

The 101,996 exact keys share many binary prefixes. A full prefix trie has
1,240,739 nodes rather than the 4,895,809 nodes obtained by storing every
48-bit path separately. Unary-path compression gives the abstract Patricia
shape with 101,995 branch nodes and 203,991 total branch-plus-leaf nodes.

The shortest prefix unique among the listed keys ranges from 11 to 48 bits,
with mean 40.261 bits. That does **not** license early physical firing. The
law matches exact neighbour signatures. An unexamined later port could contain
an extra record, turning the local signature into a different key or no key.
Unless a completion/cage record physically certifies every remaining slot, an
exact implementation must still verify all six ports.

The trie census therefore prices a possible selector. It does not change the
law's exact-match semantics.

## Representation compression is not a complexity theorem

With one arbitrary sorted 8-bit codebook, the raw fixed-width table occupies
713,972 bytes and zlib compresses to 301,507 bytes. Quotienting spatial
rotations first gives 30,898 fixed-width bytes and 12,940 zlib bytes.

These numbers show real regularity. They are not:

- Kolmogorov-complexity bounds;
- a proof of a minimum law description;
- evidence that the Python module graph is optimal;
- a naturalness metric; or
- an empirical selection theorem.

A short generative program may reproduce all 4,414 cases. Conversely, a
12.9-kilobyte compressed lookup table is still an unexplained law value if its
contents are hand-designed to implement our apparatus.
