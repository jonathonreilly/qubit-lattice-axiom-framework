## What “First” Can Mean on Infinite `Z3`

Three meanings are often collapsed:

1. **one unique spatial seed on a boundary slice**;
2. **a locally first event in a finite causal patch**; and
3. **a globally earliest event in an infinite spacetime history**.

The first has the invariant-probability obstruction proved below. The second
is compatible with positive-density event fields. The third need not exist.
For countably many independent exponential clocks of rate `lambda`,

```text
P(all clocks exceed epsilon) = lim_N exp(-lambda epsilon N) = 0,
```

so their infimum is zero. Each individual clock equals zero with probability
zero, so no site attains that infimum. An infinite homogeneous process can be
well defined locally without possessing a single global first event.

This matters for axiom language. “Records form” need not mean that the whole
infinite lattice waits and then chooses one coordinate. It can mean that one
law assigns locally finite record events to finite causal regions. That law
still has to specify its occurrence semantics.

## Exact Infinite-Volume Statement

### Theorem 1: no invariant finite nonempty seed set

There is no countably additive translation-invariant probability measure on
subsets of `Z3` that is concentrated on finite nonempty subsets.

**Proof.** Let `S` be the random seed set and let

```text
p = P(x belongs to S),
```

which is independent of `x` by translation invariance. For cubic boxes `B_n`,

```text
p = E[ |S intersect B_n| / |B_n| ].
```

Because `S` is finite almost surely, the ratio tends pointwise to zero. It is
bounded by one, so bounded convergence gives `p=0`. Countable additivity then
gives

```text
P(S is nonempty)
  = P(union_x {x belongs to S})
 <= sum_x P(x belongs to S)
  = 0,
```

contradicting concentration on nonempty sets. QED.

For exactly one seed, an even shorter proof is available. An `N`-site box has
expected seed count `Np <= 1`, so `p <= 1/N` for every `N`, hence `p=0`; the
same countable-union contradiction follows.

This theorem does not prohibit a contingent actual configuration with one
seed. It prohibits a normalized translation-invariant probability measure
that selects such a configuration. The covariance of the *set* of all
single-seed histories is not a probability law on that set.

### Quantum one-particle analogue

The one-particle Hilbert space is `ell2(Z3)`. A vector fixed by every
translation has constant amplitude. A nonzero constant amplitude is not
square summable, so the only invariant vector is zero. Likewise, a
translation-invariant trace-class density operator would have constant
diagonal `p`; its trace is either zero or divergent, never one.

This is only the exactly-one sector. Translation-invariant positive-density
algebraic quantum states exist. The theorem is not a quantum-cosmology no-go.

continuous IID priorities, the central candidate is the minimum with
probability `1/(k+1)`. Therefore

```text
rho(q)
 = q sum_{k=0}^{M-1} C(M-1,k) q^k (1-q)^(M-1-k)/(k+1)
```

```text

```

It does not cover deterministic relations with multiple histories, nonuniform

supplied site, spatial frame, or boundary record. It does supply a probability

physical formation process it still needs temporal/update semantics.

### Quantum route

A finite-torus uniform one-particle state is normalized and invariant. Its
fixed-window mass vanishes in the infinite limit, and no nonzero invariant
one-particle vector or density operator is normalizable on infinite `Z3`.
Positive-density invariant quantum states remain live, with their density,
amplitudes, phases, record instrument, and actuality rule still to be fixed.

### QCA route

A translation-covariant QCA maps invariant states to invariant states and can
create coherent correlations. It may encode a positive-density superposition
of hard-core seed histories. Unitary covariance alone does not select one
permanent classical record history or assign its Born/readout bridge. Iterating
a QCA also supplies a step structure; deriving the physical tick from later
records does not explain why the first QCA step is actual. The QCA route is
live, not closed by the classical obstruction.

### Global-history route

The periodic orbit measure is an explicit global-history success. More general
nonlocal consistency conditions could select an orbit of allowed histories.
A **covariant solution set is not a normalized selector**: without a measure
or unique-history theorem it supplies possibilities, not unconditional
weights. A timeless history law can avoid an external clock while still
carrying substantive occurrence and actuality content.

### Contingent-boundary route

Cycle 17 law directly. This is a valid contingent-boundary route for a lab or
one cosmological history. It leaves the all-open autonomous-nucleation target
by supplying state/history content. That content is not thereby an axiom.
