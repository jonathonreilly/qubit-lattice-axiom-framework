## Result up front

The tournament produces two bounded physical constructions and one useful
host-steered scaffold. It does not yet produce a physical clock.

1. **Autonomous local lineage/residue sidecar.** One fixed `step(state)`
   circuit grows a rooted occupied predecessor chain and rotates a six-rail
   residue tag. Each macrocell contains 192 physical M2 sites: 30 for the
   inherited Cycle-342 Record word and 162 constant-overhead lineage/router
   sites. Every primitive gate has support at most three on a connected
   nearest-neighbour subgraph. The same 16,111 circuit layers are used for
   N=6, 12, and held N=18. The physical update does not perform a global
   scratch scan or choose a gate from state. The decisive limitation is also
   executable: every future 30-M2 Record word and local formation input is
   preloaded before the frontier arrives. The route generates only the
   lineage/occupancy/residue sidecar; it does not generate Record content,
   occurrence, typing, or permanence.
2. **Autonomous local same-track rendezvous.** A fixed nine-layer rule uses
   48 M2 per longitudinal cell to propagate two fronts and latch their local
   collision. It is a genuine connected-NN, state-only update. Six adversarial
   fixtures put distinct lawful endpoint-0 and endpoint-1 Records on the same
   supplied phase/sheet track; all six latch. Therefore the construction is a
   same-track rendezvous, not an endpoint matcher and not an event-identity
   compiler. The missing endpoint field is a route-specific omission.
3. **Host-steered local-link counter scaffold.** The selected unary increment
   and transport templates use explicit connected-NN gates of support at most
   three, count N=6/12/18 exactly, and survive link, deletion, alias and frame
   controls. But Python scans for the active head, reads the encoded links,
   chooses the next block, and then selects that move's gate template. A fixed
   global layer list applied everywhere has not been constructed. This route
   is a host-steered partial, not an autonomous physical compiler.

The strongest constructive compiler result is Route 1:

> On the declared code space, a bounded proper-cubic physical M2 patch can
> autonomously propagate local predecessor, occupancy and period-six residue
> structure with no Record ID, arithmetic position, membership mask, copied
