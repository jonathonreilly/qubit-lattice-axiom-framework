## Result

Cycle 436 constructs two bounded, reversible physical formation laws on the
same physical pointer input:

1. **A: coarse effect-functional candidate.** Fine pointer labels 0 and 1 from
   the declared proportional ray refinement both write the same complete
   79-M2 protected candidate packet. The source pointer remains physically
   present, so reversibility does not require erasing refinement information.
2. **B: fine presentation-faithful candidate.** The same pointer labels write
   two distinct complete 79-M2 protected candidate packets. The distinction is
   verified on the actual fixed-width packet words, not by comparing unequal
   bank widths or container hashes.

Each packet is a Cycle-370-compatible protected candidate packet compiled by
the Cycle-433 field-by-field writer. Both laws have exact E/G intertwining and
an exact inverse on their declared code spaces. Both survive train L=3, held
L=6, all 24 proper-cubic frames, leakage, deletion, and lawful-domain controls.

This is a positive physical availability result on one bounded proportional
ray-refinement class. It is not a derivation of general effect functionality,
eligibility, grading, normalization, actualization, statistics, or a Born
rule. No candidate is selected. A candidate packet is not an actual Record,
and there is no occurrence, sampler, frequency, or probability-law selection.

## Exact compiler identity and inverse

## Deletion, leakage, and lawful-domain controls

The runner checks all of the following:

- deleting the refinement bit leaves A invariant and remains visible in B;
- deleting a load gate in the label-1 matcher blocks that write;
- deleting one nonzero Cycle-433 payload-field write corrupts or invalidates
  the decoded candidate packet;
- deleting each of readiness, fresh capacity, payload presence, lawful-payload
  certificate, faithful close, and provenance leaves the target blank;
- a dirty protected target is refused without changing it;
- deleting a physical refined branch produces a visible completeness defect;
- malformed routing laws, labels, split values, bank widths, and payloads are
  rejected;
- each single protected occupancy-bit fault is rejected;
- nominal matcher and packet workspace leakage is zero.

These are mechanism controls. They do not select either formation law.
