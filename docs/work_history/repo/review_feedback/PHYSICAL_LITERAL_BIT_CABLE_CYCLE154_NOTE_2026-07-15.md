## Result

Cycle 154 builds a physical literal-bit cable with straight and covariant turn
cells. An `H0` or `H1` record is copied through fresh nearest-neighbor sites;
one pre-existing guide role and three quiet frame records type each cable cell.
The rule has only four canonical rows:

```text
H0 straight    H1 straight    H0 turn    H1 turn.
```

A finite path compiler chooses a compatible guide orientation at each straight
cell. That choice is between proper-cubic images of the same row; it adds no
new transition content. One fixed guide choice failed beside a corner because
it occupied a later cell's frame site. Compatibility search repaired the
layout without adding a special corner rule.

This is transport infrastructure. It can carry a producer's bit only when that
producer leaves an adjacent open port. Cycle 153's five-bit verification
fixture is terminal and therefore does not attach directly; a port-bearing row
fanout is a separate composition requirement. The cable does not choose a
fundamental law and does not derive occurrence or equal weights. No axiom
addition follows.

## Minimal law and merge

Each row has five direct parents: the previous bit, one guide, and three frame
records. The sixth neighbor is the open continuation port. Straight and turn
rows are distinct by an invariant relation: the port is opposite the bit in a
straight cell and perpendicular to it in a turn cell.

```text
canonical rows                                           4
proper-cubic raw rows                                   96
Cycle-153 union                                      83,276
combined law                                         83,372
raw conflicts                                             0
```

The guide uses an existing role. No new alphabet item or substrate object is
introduced. Deleting any direct parent from the four rows gives twenty
controls; no intended copy survives.

## Path controls

The probe contains four path topologies:

```text
straight
one ninety-degree turn
two turns
three-axis route.
```

Both bit values are checked under all 24 proper-cubic rotations, for 192 exact
histories. Each path has one enabled front at a time, every write preserves the
bit, every intermediate record is permanent, the final continuation port
remains open, and the completed cable enables nothing else.

The compiler does not add answer-specific roles. At a straight segment it may
choose any perpendicular placement of the same guide role. It accepts the
first placement compatible with already fixed guards. A turn's guide is fixed
relationally by the cross product of incoming and outgoing directions, which
is preserved by every proper-cubic rotation.

Every cell sees one guide parent, but that does not require one unique guide
site per cell. In the one-turn and two-turn fixtures, a compatible permanent
guide record neighbors two cells and serves both local signatures. The four
tested paths therefore use 4, 3, 3, and 4 distinct guide records respectively.
This is shared local support, not an omitted parent.

Deleting any of the 28 distinct path-guide records across both bit values
causes a strict preterminal stall. Adding the
cable rows preserves all 768 Cycle-153 fanout graphs, all 54,000 Cycle-152
router graphs, all 86,640 earlier mixed histories, and the Cycle-144 bound
terminal.
