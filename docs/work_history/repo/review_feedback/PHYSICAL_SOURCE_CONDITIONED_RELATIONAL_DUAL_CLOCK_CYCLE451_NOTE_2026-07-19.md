## Deletion semantics

not returned as zero duration.  Source deletion removes the receiver-one
branch.  Response-control deletion keeps the source branch but returns the
exposed clock to 4.  Deleting either clock pairing changes only that clock's
complete word.  Detector deletion prevents the common return event; reflection
certificate deletion prevents the conditional endpoint edge.  These controls
keep source production, clock response, event matching, and interpretation as
separate load-bearing interfaces.
