## Exact Question

Suppose the strongest missing compiler exists: a genuinely primitive,
one-`M_2(C)`-per-site, unit-translation and proper-cubic, locality-preserving
three-dimensional QCA `alpha` in a nontrivial anomalous bulk class.

Does its class plus the Record axiom:

1. select one finite-depth representative;
2. select one record decoder/instrument;
3. make all same-class phase decorations record-invisible; or
4. support a full operational equivalence only when the preparation,

The probe takes route 4 seriously. It first holds the record protocol fixed,

## Result In Plain Language

The survivor splits cleanly.

First, a same-class primitive difference can be readable. On the one-qubit
cubic lattice, apply the same controlled phase to every nearest-neighbor edge.
The law is unit-translation invariant, invariant under all 24 proper cubic
rotations, range one, finite depth, and uses no blocks. Choose two
non-Clifford angles. Prepare one Bell pair on any neighboring sites with every
other site in `0`. A fixed phase-sensitive decoder followed by two ordinary
basis records writes different record contents for the two laws. One angle
writes `00`; an angle shifted by `pi` writes `10`, deterministically. This is a
record transcript difference, not merely a difference in inaccessible wave
function phase.

Second, an immediate phase-blind record sees no difference. Recording the two
sites directly in the computational basis gives `00` or `11` with equal
weights for every phase. Permanence also does not select a phase because the
phase circuit commutes with every computational record projector.

Third, a label change is not enough in general. A third non-Clifford phase
gives a `50/50` transcript under the same decoder where the reference law is
deterministic. No permutation of record labels turns a deterministic
distribution into a mixed one.

Fourth, complete protocol transport restores equivalence exactly. If

```text
U_2 = F U_1
```

and a record instrument has branches `K_t`, replace them for `U_1` by

```text
K'_t = K_t F.
```

Then for every prepared state,

```text
K'_t U_1 = K_t U_2
```

branch by branch. Probabilities, unnormalized post-record states, record
labels, and every content-only readout of those records agree. Completeness is
preserved because `F` is unitary. In the phase fixture this is the simple
statement that only the relative phase between update and decoder is visible:

```text
p(00) = cos((phi-chi)/2)^2,
p(10) = sin((phi-chi)/2)^2.
```

Shifting law phase `phi` and decoder phase `chi` by the same amount changes
nothing.

This does not make the bare bulk class a complete physical law. It gives a
precise fork:

- **Fixed-protocol reading:** finite-depth representatives are physically
  distinct when an allowed common record protocol distinguishes them.
- **Fully transported reading:** the representative is gauge only as part of
  an equivalence class of the complete operational package—update,
  preparation, interventions, decoder, instrument, transcript labels,
  readout, and claimed clock/resource statistics.

The present axioms state neither equivalence relation. “Only records are
readable” does not imply phase blindness, because a local decoder can turn a
phase into different record content. Nor does it choose the decoder.

The most useful bare-metal lesson is therefore:

> The physically meaningful object cannot be the update class alone. It is
> either one selected update-plus-commit protocol, or an exactly defined
> equivalence class of complete update-plus-commit protocols.

That conclusion is compatible with the user's read/lock intuition: reading
can be the interface that makes otherwise representational phase physically
relative. It does not yet explain why a read occurs or which outcome is
actual.

## 2. Primitive Unit-Translation And Proper-Cubic Phase Law

At each primitive site `x`, let

```text
n_x=(1-Z_x)/2.
```

For every undirected nearest-neighbor edge `<x,y>`, set

```text
C_phi(x,y)=exp(i phi n_x n_y),
C_phi=product_<x,y> C_phi(x,y).
```

All edge gates commute. The full product has these exact properties:

- one `M_2(C)` carrier per site;
- range-one gates only;
- invariance under every unit translation;
- invariance under all 24 proper cubic rotations;
- no absolute macrocell or preferred edge direction;
- a six-layer finite circuit realization if a schedule is desired; and
- identical action independent of the parity coloring used to evaluate the
  commuting product.

The six-layer implementation is a compiler convenience, not law structure.
The complete commuting product has unit-translation symmetry even though an
individual evaluation layer does not.

Use three angles:

```text
phi_0   = pi/4,
phi_perp=5pi/4,
phi_mix =3pi/4.
```

Every corresponding two-site controlled phase is non-Clifford. All three
global circuits have the same carrier, range, depth bound, translations,
proper-cubic covariance, and trivial finite-depth bulk class.

This already defeats representative selection by range, circuit depth,
carrier count, spatial symmetry, or Clifford-versus-non-Clifford status.

## 3. Exact Record-Visible Fixture

Choose any nearest-neighbor edge and prepare

```text
|B>=(|00>+|11>)/sqrt(2)
```

on its two sites, with every other primitive site in `|0>`. This is an
experimental state, not a macrocell. In the `|11>` branch exactly one
nearest-neighbor edge has both ends occupied. Hence the full-lattice circuit
acts on the fixture as

```text
C_phi |B>
  =(|00>+exp(i phi)|11>)/sqrt(2).
```

Translate or properly rotate the preparation and the same equation holds.
The law does not privilege the chosen edge.

### Phase-blind immediate record

Record both sites immediately in the computational basis. For all `phi`,

```text
p(00)=1/2,
p(11)=1/2,
p(01)=p(10)=0.
```

Thus some legal protocols are phase-blind. This is not a theorem that all
record protocols are phase-blind.

### Phase-sensitive record decoder

For decoder reference phase `chi`, apply

```text
D_chi
  =(H tensor I) CNOT (diag(1,exp(-i chi)) tensor I),
```

then lock each site in the computational basis. Exact amplitudes give

```text
D_chi C_phi |B>
  =[(1+exp(i(phi-chi)))/2]|00>
   +[(1-exp(i(phi-chi)))/2]|10>.
```

At `chi=phi_0`:

```text
phi=phi_0:     transcript 00 with certainty,
phi=phi_perp:  transcript 10 with certainty,
phi=phi_mix:   transcripts 00 and 10 with weights 1/2,1/2.
```

The first two are orthogonal basis outputs. Their content difference does not
depend on estimating a small probability or on choosing a scalar summary.
The third proves that merely permuting transcript labels cannot identify the
two complete distributions.

The decoder is finite and local to the prepared edge. Moving it with the
preparation preserves covariance. It is supplied protocol content, not a new
site factor and not a law-level preferred direction.

## 4. Conditional Lift To Any Primitive Anomalous QCA

This cycle does not construct the missing primitive anomalous `alpha`. It
proves a conditional lift that applies if one is found.

Define

```text
U_phi=alpha o C_phi.
```

If `alpha` is one-qubit-per-site, unit-translation/proper-cubic covariant, and
locality preserving, then every `U_phi` has those same properties. Since
`C_phi` is finite depth,

```text
[U_phi]=[alpha]
```

in any bulk equivalence that quotients those circuits. If `alpha` is Clifford,
the three displayed `U_phi` are non-Clifford: otherwise multiplying by
`alpha^-1` would make the non-Clifford `C_phi` Clifford.

The record test also lifts without preparing `alpha^-1|B>`. Let `P_t` be the
two-site record projectors after `D_chi`. The QCA image

```text
Q_t=alpha(D_chi^dagger P_t D_chi)
```

is supported in a finite neighborhood because `alpha` is locality preserving.
For output state `U_phi|B>`, measuring the common local projector family
`{Q_t}` gives exactly the transcript formulas above. In Schrödinger language,
the protocol decodes the common `alpha` layer before writing the two basis
records; in Heisenberg language it directly measures the finite-support
projectors `Q_t`.

This is a conditional distinguishability theorem, not a completed instrument
compiler. Implementing the `Q_t` record event from the admissibility rule is
still open.

## 5. Why Record Permanence Does Not Select The Phase

Every `C_phi` is diagonal in the computational record projectors:

```text
[C_phi,Z_x]=0
```

for every site. Therefore an already locked computational record keeps its
content under every displayed phase law. The three laws are equally compatible
with that scoped permanence contract.

For the phase-sensitive protocol, the decoder acts before the records lock.
After the projective branch writes `00` or `10`, an immediate repeated
computational read returns the same content exactly. The same rank-one Lüders
instrument shape works for every `phi` and every `chi`.

Thus neither of these generic record requirements selects one member:

- preserve an existing locked basis value; or
- write a complete, rank-one, exactly repeatable pair of records.

The relative update/decoder phase remains.

## 6. Exact Full-Transport Identity

Let two same-class updates obey

```text
U_2=F U_1,
```

where `F` is the finite-depth relative circuit. Let a supplied record
instrument have branch Kraus maps `{K_t}` with

```text
sum_t K_t^dagger K_t=I.
```

Define the transported protocol

```text
K'_t=K_t F.
```

Then

```text
sum_t K'_t^dagger K'_t=I
```

and, for every input density matrix `rho`,

```text
K'_t U_1 rho U_1^dagger K'_t^dagger
 =K_t U_2 rho U_2^dagger K_t^dagger.
```

The equality is branchwise, so it preserves more than terminal support:

- each transcript probability;
- each unnormalized post-record state;
- each normalized branch state when nonzero;
- the same outcome label `t`; and
- every subsequent content-only readout applied to that branch.

For `U_phi=alpha C_phi`, the relative map is

```text
F=alpha C_(phi_2-phi_1) alpha^-1.
```

Conjugating a bounded-depth circuit by a QCA expands each gate by a bounded
radius. The bounded-overlap gates can be recolored into finitely many layers,
so `F` remains finite depth. This is why finite-depth circuits form the kernel
of the QCA quotient.

The runner verifies the branch equality for several exact inputs and verifies
the simpler simultaneous phase shift

```text
(phi,chi)->(phi+delta,chi+delta).
```
