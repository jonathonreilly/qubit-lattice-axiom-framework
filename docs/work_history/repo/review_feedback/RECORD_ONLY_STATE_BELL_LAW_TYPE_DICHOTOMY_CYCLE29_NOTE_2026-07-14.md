## 2. Bell-local factorization on record states

Let a preparation record and its complete common-past record configuration be
summarized by `lambda`. Let distant setting records be `a,b in {0,1}` and
outcome records be `x,y in {-1,+1}`. Bell-local factorization is

```text
p(x,y|a,b,lambda)=p_A(x|a,lambda) p_B(y|b,lambda),
p(lambda|a,b)=p(lambda).
```

Every stochastic response is a convex mixture of deterministic response
maps. There are four maps per wing and sixteen pairs. For every pair,

```text
S=A0 B0 + A0 B1 + A1 B0 - A1 B1
```

has `|S|=2`; convexity gives `CHSH <= 2` for every such record-only local
response law. The runner enumerates all sixteen vertices exactly.

This is not a claim that records cause classicality. It is the consequence of
the displayed factorization and setting independence. A record-history theory
can reject that factorization while remaining operationally no-signalling.

## 4. Why current records may still be insufficient predictors

A state definition and a Markov-sufficiency theorem are different claims.
Two histories may currently expose the same coarse parity record while one
retains coherent phase relations and the other has been dephased. A later
phase-sensitive test can return probabilities `1` and `1/2`.

Therefore the sentence “state is a configuration of records” is predictively
complete only if the exact law proves **record-fibre strong lumpability**:
every two law histories with the same complete record configuration give the
same future transcript law under every legal protocol.

There are three nonconstitutional ways to close that test:

- retain a **persistent preparation record** whose content distinguishes the
  relevant process class;
- let the global law condition on the complete record history rather than only
  a coarse present decoder; or
- prove the apparently different hidden descriptions are physically
  equivalent under every legal future record protocol.

If none works and future probabilities require an unrecorded carrier value,
then the present state definition is false for that law and Qualification
would need revision. Adding formation prose to Record would not fix it.

Delayed common-future locking can create one later joint parity record, but it
does not retroactively turn earlier distant local outcome records into a
