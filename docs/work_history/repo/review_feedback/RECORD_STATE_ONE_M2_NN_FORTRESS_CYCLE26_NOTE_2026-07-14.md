## 1. The Exact State Test

Let `Omega` be any proposed microscopic state space, let `C` be the set of
record configurations, and let

```text
pi : Omega -> C
```

forget every unrecorded variable. The current Qualification says that the
physical state is `c in C`. Therefore a proposed microscopic law is compatible
with that state definition only if equal fibres have equal future record
answers.

For a discrete Markov kernel `K` and every record output fibre `c'`, the test is

```text
sum_[pi(eta)=c'] K(omega,eta)
  = sum_[pi(eta)=c'] K(omega',eta)

whenever pi(omega)=pi(omega').
```

For adaptive quantum instruments, replace the one-step sum by the conditional
law of every finite future record transcript under every law-permitted future
protocol. This is **strong lumpability** of every record fibre. It has three
outcomes:

1. **Derived:** if the putative working state is `D(c)` for one fixed decoder
   `D`, it adds no physical state; equal records decode identically.
2. **Gauge:** if different fibre points give exactly the same future record
   laws, their difference is operationally invisible relative to that law.
3. **Hidden physical refinement:** if one future record protocol distinguishes
   two fibre points, `c` was not a complete physical state for that
   architecture.

The runner uses the smallest quantum separator. `|+>` and `|->` can sit above
the same empty record configuration. A later `X` record distinguishes them
with certainty, so that fibre is not lumpable. If the only permitted future

restricted law. The restriction has to be a theorem or explicit law domain;

This is not a claim that wavefunctions cannot exist. It is a typing result:
future-sensitive coherent state is additional physical state relative to the

## 7. The Direct Quantum-Control Capacity Bound

The fortress's extensional record law can assign one rank-one `M_2`
possibility to every finite token. That does not increase the algebra. But a
CP/unitary implementation on the same carrier has a sharper constraint.

Suppose a permanent predecessor record can be in pure states `|psi_i>`, the
open target and environment start in fixed states, and the dynamics leaves the
predecessor record unchanged while writing successor/environment states:

```text
|psi_i>|0>|e0> -> |psi_i>|phi_i>|e_i>.
```

Inner-product preservation gives

```text
<psi_i|psi_j>
 = <psi_i|psi_j><phi_i|phi_j><e_i|e_j>.
```

If the predecessor states are nonorthogonal, the last two factors must both
have magnitude one. The successor and environment therefore cannot carry a
distinct perfectly readable control result. This is the nondisturbing
information bound behind the familiar perfect-discrimination ceiling.

Consequences:

- at one site, at most two mutually orthogonal pure record controls can drive
  distinct deterministic readable branches on a literal qubit carrier;
- thousands of nonorthogonal rank-one labels are valid modal possibilities
  but are not automatically thousands of nondestructively readable classical
  controller states; and
- a rule that directly inspects their exact labels is an extensional
  record-law semantics unless a quantum implementation bridge is supplied.

This does not close spatial coding. Three qubits have `2^3=8` orthogonal basis
states, enough for the six NN directions plus source and stop. A distributed
binary tile can place those bits in permanent neighboring records, and a
record-grown frame can set its orientation and block phase. Building a full
unit-translation/proper-cubic, collision-safe, binary macrotile version of the
fortress remains an exact constructive target.
