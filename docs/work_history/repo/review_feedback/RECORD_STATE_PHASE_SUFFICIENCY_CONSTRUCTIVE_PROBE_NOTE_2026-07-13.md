## Exact Semantic Theorem

If the physical law is Markov on record configurations, then two procedures
ending in the same complete record configuration have the same lawful future
support and, if a statistics law exists, the same future statistics.

Therefore:

> Operationally distinguishable preparations must end in distinguishable
> complete record configurations, or the state type must be widened.

This is substitution, not a quantum no-go. It says exactly what a record-only
state must accomplish.

## What A Full Rule Must Prove

The Qualification sentence can remain unchanged only if the canonical law
proves all four conditions:

1. **preparation separation:** every pair of operationally distinct
   preparations leaves distinct persistent global record configurations;
2. **record Markov sufficiency:** future support/statistics depend on no
   unrecorded history variable after the complete record configuration is
   specified;
3. **local phase transport:** the nearest-neighbor rule carries relational
   phase/reference information to every later interference context at finite
   speed; and
4. **quantum completeness:** the resulting contextual tables cover the full
   physical preparation/effect repertoire, including entangled phases, not
   only the two finite controls.

If any future-distinguishable preparation pair violates condition 1 or 2, the
current state definition is false for that law and must be widened. If all four
are theorems, no Qualification edit is needed and operational states remain
representations of record-conditioned futures rather than extra ontology.
