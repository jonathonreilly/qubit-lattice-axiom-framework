## Result Up Front

**Corrected result after the Cycle-42 primitive-scope audit:** actual-state
reference is closed; complete-history status is conditional. No universal
standalone actuality or sampler axiom is forced.

The earlier draft of this note conflated one law-admissible realized state with
one complete physical history. The live Record axiom supplies actual record
facts. The approved realized-state primitive licenses pointwise evaluation at
one law-admissible state supplied by physical history. It supplies neither the
state value nor a complete history `h_*`.

For a law on complete record histories, the actual history must instead be:

1. uniquely derived from the law and boundary;
2. realized under law-owned one-outcome dynamics, with realized outcomes still
   contingent world data;
3. reconstructed from records by a proved state-to-history theorem; or
4. supplied explicitly as contingent world-history data.

A normalized measure on complete histories supplies probabilities and support,
but it selects no member. The identity random-history construction represents
the measure only after an actual member is independently supplied by one of
the four routes. No canonical map `S:mu_L -> h_*` exists for the displayed
symmetric pair.

A normalized measure does not canonically select its member. The exact paired
control keeps the same fair measure on two complete record histories and adds
no actuality annotation, actual history `h_0`, or actual history `h_1`.
Every event probability is identical. In the symmetric fair law there is not
even a label-equivariant deterministic selector: the law is fixed by the
outcome swap while neither history is.

This mathematical independence does **not** prove a universal new framework
premise. Deterministic, law-owned, reconstruction, and contingent-data
architectures close the seam differently. It does prove that a branching law
must declare its chosen history route inside `L*` or an explicit data
interface; history-domain typing alone is insufficient.

The remaining distinctions are:

| question | exact object | present disposition |
|---|---|---|
| actual-state reference | one law-admissible state `s_*` | Record plus the realized-state primitive license pointwise evaluation; no value is supplied |
| complete-history membership | `h_* in Omega_L` | uniquely derived, law-realized, record-reconstructed, or explicit contingent data |
| stochastic predictions | normalized `mu_L` on record-history events | exact-law content |
| actual record value | coordinate evaluation at `h_*` | contingent realized-state data |
| probability-one claim | `mu_L(A)=1` | measure theorem; not pointwise truth at `h_*` |

| collapse/posterior state | outcome-indexed instrument map conditioned on a recorded outcome | law content that consumes, rather than selects, the outcome |

The smallest branching-law requirement is therefore a domain/statistics
declaration **plus an explicit history route**:

> `Omega_L` is the set of complete law-admissible record histories; the law is
> a normalized measure on its cylinder events; and actual `h_*` is derived,
> law-realized, record-reconstructed, or supplied through the declared

That belongs in the exact `L*` contract. It is not yet a fifth axiom sentence,

If the program intentionally demands a physical hidden seed or objective

## 1. Exact Reading of the Current Foundation

### Record

The live Record axiom supplies three facts relevant here:

```text
Records form.
When present, a record locks exactly one admissible local possibility.
A state is a configuration of records.
```

The first supplies occurrence at the ontology level. The second excludes a
single site record that simultaneously carries two alternative values. The
third identifies the instantaneous physical state type.

Record does not supply which value forms, a probability measure, a history
measure, a rate, or a state-selection algorithm. The axiom memo explicitly
keeps those outside its content.

### Realized-state primitive

The registered source is stronger on exactly the existential point and weaker
on exactly the selector point:

```text
laws do not pick the state; the world does;
one law-admissible realized-state reference is supplied by the physical history;
derivations may evaluate there pointwise;
no state-selection rule, measure, typicality, boundary, or value is supplied.
```

This is not an accidental implication. The minimality policy records the
primitive as the laws-versus-initial-conditions floor: state is an additional
datum that state-blind law structure cannot supply.

Therefore an “actuality axiom” saying only that one state is actual would
duplicate approved content. A complete-history statement would not: it would
add a stronger global datum. Whether that datum belongs in the law, follows by
theorem, or remains contingent is architecture-dependent and cannot be hidden
inside the primitive.

### From one state reference to a complete history

The primitive permits pointwise state evaluation. Physical history supplies
that state, but the primitive does not license inference from the state to the
entire physical history. The exact law or an explicit data interface must
construct or supply a path if it makes stochastic history claims.

For a complete record history

```text
h=(R_0,R_1,...),
```

define the state at cut `n` to be the record configuration `R_n`, or in an
append representation the finite restriction `h|n`. Record permanence makes
restrictions of a separately supplied `h_*` compatible. Declaring `Omega_L`
to contain complete law-admissible physical record histories does not select
`h_*` or derive it from one cut state.

If a proposed law supplies only one-step kernels or finite instruments, it
must still prove projective consistency/existence of a complete history
measure. That is law completeness, not another actualization premise.

## 2. Mathematical Separation: Measure Versus Distinguished Member

Use the two complete histories

```text
h_0=(0,0,0,0),       h_1=(1,1,1,1)
```

and the fair measure

```text
mu({h_0})=mu({h_1})=1/2.
```

Compare three structures:

```text
M_none = (Omega,F,mu)
M_0    = (Omega,F,mu; h_*=h_0)
M_1    = (Omega,F,mu; h_*=h_1).
```

For every event `A subset Omega`, all three assign the same `mu(A)`. The
annotation is not recoverable from event probabilities. Conversely, the same
actual `h_0` is compatible with the fair law and a biased full-support law.
The member does not recover the law either.

This proves two narrow facts:

```text
measure != distinguished member;
distinguished member != measure.
```

It does not prove that physical stochastic theories are incomplete. `M_none`
is the mathematical law object. `M_0` and `M_1` are two possible physical
applications of that same law. The current framework already contains the
world-side slot that distinguishes them.

### No canonical law-only selector in the symmetric pair

Let `g` exchange `h_0` and `h_1`. The fair `mu` is invariant:

```text
g_* mu = mu.
```

An equivariant deterministic selector would require

```text
S(g_*mu)=g S(mu).
```

Because `g_*mu=mu`, this becomes `S(mu)=g S(mu)`. Neither `h_0` nor `h_1` is
fixed by `g`, so no such selector exists. Picking either member adds a symmetry-
breaking label, seed, boundary, or contingent fact.

This is not a no-go against all deeper deterministic models. It is a proof
that normalization and outcome symmetry alone cannot be rephrased as a
canonical deterministic sample choice.

## 3. Sampling Algorithms Are Nonunique Representations

Take four equiprobable seeds and two samplers:

```text
X_A(0)=X_A(1)=h_0,      X_A(2)=X_A(3)=h_1;
X_B(0)=X_B(1)=h_1,      X_B(2)=X_B(3)=h_0.
```

Both push forward the uniform seed law to the same `mu`, yet they return
opposite histories at every common seed. Thus `mu` does not determine a
pathwise randomizer.

Adding a randomizer also does not answer “which seed is actual.” The identity
representation uses `Omega` itself as the seed space and `X(h)=h`; selecting
the input seed is exactly selecting the history. A sampling algorithm can move
the actuality label but cannot derive it from a distribution.

A sampler becomes physical content only if at least one of these is true:

1. its seed is a record or affects later records beyond the declared history;
2. different implementations produce different joint record-history laws;
3. the microscopic trajectory is independently observable; or
4. the law claims an objective collapse/event mechanism rather than only a
   stochastic history distribution.

Absent those conditions, samplers with the same pushforward law are a
representation quotient. A sampling algorithm is optional representation
unless record-visible.

This avoids a common category error: a Monte Carlo procedure used to simulate
the law is not automatically the mechanism by which nature produces facts.

## 4. Quantum Instruments and Collapse

For the qubit state `rho=|+><+|`, take the sharp `Z` instrument

```text
I_0(rho)=P_0 rho P_0,       I_1(rho)=P_1 rho P_1.
```

The branch traces are both `1/2`, the normalized posterior states are `P_0`
and `P_1`, and the nonselective channel is

```text
I_0(rho)+I_1(rho)=diag(1/2,1/2).
```

The instrument supplies outcome probabilities and the state change
conditional on each outcome. The summed channel forgets the outcome label.
Neither mathematical object contains a distinguished outcome value; the same
instrument can be annotated by outcome `0`, outcome `1`, or no application
record.

This is the primary-source meaning relevant here. Davies and Lewis introduced
the instrument to combine outcome statistics with operations in repeated
measurement. Ozawa proved the correspondence between completely positive
instruments and measuring-process state changes, and his operational reduction
work states the update conditional on the measurement outcome. Collapse is
conditional on an outcome; a posterior map consumes the record value when it
computes the new conditional state.

That does not leave the present framework outcome-free. Record says a formed
record locks one admissible possibility, and the realized-state primitive
supplies the actual evaluation point. What the exact law must provide is the
instrument/history measure linking prepared contexts to those record values.

There is one important type gate:

```text
nonselective channel or global density operator
    != normalized classical measure on mutually exclusive complete records.
```

An Everett-style unitary branch state, a decoherence functional, or a summed
channel cannot be silently called the `mu_L` assumed in this cycle. If the
candidate exact law is one of those objects, it still needs a theorem or
interpretive law connecting it to the framework's single realized record
history. The present result applies once the law really is a normalized
measure on complete record histories.

## 5. Probability One Is Not Pointwise Truth

The realized-state primitive deliberately supplies no typicality. That
guardrail remains necessary even after the ontology seam is closed.

Under the fair Bernoulli measure on infinite binary histories, the all-zero
history is a legitimate sample point. Its length-`N` zero cylinder has weight
`2^(-N)`, so the singleton history has measure zero by continuity. Therefore
its complement has measure one while excluding that point.

So

```text
mu(A)=1
```

does not logically imply

```text
h_* in A.
```

Probability one is not pointwise truth at the realized member. Ordinary
statistical physics may make almost-sure predictions, and experiments can test
them. But a theorem must not be reported as holding for every possible actual
history unless a pointwise theorem, deterministic uniqueness, or an explicit
genericity condition supplies that stronger statement.

This is independent of bare actuality. Knowing that one history is actual does
not make it typical, and adding a deterministic selection mechanism does not
guarantee that it avoids every null set.

## 6. Boundary Conditioning, Determinism, and Global Histories

### Boundary conditioning

From the same fair prior on `{h_0,h_1}`:

```text
mu(. | {h_0})=delta_(h_0),
mu(. | {h_1})=delta_(h_1).
```

The conditional laws are unique and different. The prior does not say which
boundary event is supplied. Boundary conditioning changes the law but does not
choose the boundary.

Conditioning on an already recorded boundary is ordinary inference or a
restricted law domain. Postulating a cosmological two-boundary condition is
contingent physical input. Neither should be renamed “collapse” merely because
the conditional measure is narrower.

### Deterministic local rule

The deterministic rule “copy the initial bit forever” admits `h_0` and `h_1`
until the initial datum is fixed. Determinism of the transition does not imply
uniqueness of the physical history. With initial bit `0` or `1`, the solution
is unique.

Thus deterministic uniqueness can identify the history, but determinism alone
does not. The initial/boundary datum is precisely the state-content slot the
realized-state primitive keeps contingent.

### Global-history law

A global constraint that all four record values agree likewise has two
solutions. A supplied final boundary makes one solution unique. A singleton
global solution can be represented by a delta measure, and no random sampler
is required.

More importantly, a genuinely stochastic law can be global from the start: it
may assign `mu_L` directly to complete histories. It does not have to sample
one local event at a time. It becomes one-world semantics only after `h_*` is
law-realized, uniquely derived, record-reconstructed, or supplied as
contingent data. A local sequential sampler with the same pushforward can be
representational, but the measure alone still selects no member.
