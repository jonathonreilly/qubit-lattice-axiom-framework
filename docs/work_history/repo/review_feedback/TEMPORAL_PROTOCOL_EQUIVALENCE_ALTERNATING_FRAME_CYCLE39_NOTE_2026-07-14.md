### 2.1 Fixed-time component


A single static common onsite `Z_all` commutes with both diagonal candidate


This is a morphism between time-indexed law presentations, not one static
automorphism of the fixed law. The foundation-static group and the temporal

## 3. Minimum Exact Record Witnesses

The one-qubit calculation isolates the uniform onsite residue. It is not a

Prepare `rho_+=|+><+|`. After the two residue updates,

```text
I rho_+ I = rho_+,
```

Therefore a fixed `X` record at the next slice gives

| candidate | `p(X+)` | `p(X-)` | scalar sign |

### 3.2 `Z`-only control

5. Write a final `X` outcome `b in {+,-}`.

## 5. The Cross-Time Idle Is The Decisive Temporal Object

There are two uses of the word “identity.” They must not be merged.

### 5.1 Same-slice categorical identity

At a fixed time,

```text
F_t I F_t^dagger = I.
```

The frame functor therefore preserves categorical identities and composition,
as Cycle 20 proved.

### 5.2 Named cross-time idle

A physical law may also name an edge `J_t` meaning that the same calibrated
apparatus is left idle from slice `t` to slice `t+1`. If its matrix is fixed as
`I` in a common temporal trivialization, then

```text
F_(t+1) J_t F_t^dagger = Z_all.
```

After two edges the connection factors cancel:

```text
Z_all Z_all=I.
```

That explains both the odd-time separator and the even-time control. The
alternating frame is a legitimate gauge only if the law's temporal
trivialization is allowed to transform with it. If `J_t=I` is a fixed named
calibration, `F_t` is not an automorphism of that law object.

The phrase “co-transport everything” is therefore too loose. The exact list
must include any cross-time idle or clock calibration that the law treats as
physical.

## 6. Permanence, Record Content, And Decoder Transport

For an abstract record label `r`, define a time-indexed concrete encoding

```text
E_t(r)=F_t E_0(r) F_t^dagger.
```

For an `X+` record, the matrices alternate:

```text
E_0(+)=P_X+,
E_1(+)=P_X-,
E_2(+)=P_X+.
```

There are two physically different readings.

1. **Transported representation.** The abstract content label `+` remains the
   same, and the decoder is transported so that

   ```text
   I_t(E_t(+))=+1
   ```

   at every time. No record is rewritten; only its concrete representation
   changes. This can preserve Record exactly.
2. **Fixed concrete dictionary.** `P_X+` and `P_X-` are physically distinct
   contents with fixed scalar signs. Alternating them changes the locked
   content or its readout. That is forbidden for an already formed permanent
   record, so the frame is not a record-faithful equivalence.

The current Qubit axiom does not privilege an `X` basis, but Record does make
whatever content actually locked permanent and readable. Whether concrete
projectors or transported abstract labels are the physical content objects is
a law/representation question. It cannot be settled by the slogan “no
possibility is privileged.”

An active implementation is also different from a passive representation
change. If the substrate must write a parity/frame certificate so that a
decoder knows which matrix represents `+`, that certificate is an extra
permanent readable record with additive cost. The Cycle-20 equivalence theorem
does not erase that added event.

transported objects. A fixed legal odd-time `X` record fails test 4/5; a fixed
`J_t=I` fails test 7. This is why the answer is law-relative rather than an
unqualified yes or no.
