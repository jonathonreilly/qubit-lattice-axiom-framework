A1 and since |S_x| - n is already second order, only the first derivative of log Z contributes:
A1   sum_x log Z(S_x) = const + beta A(n beta) sum_x (|S_x| - n) + O(theta^4).
A1 In Fourier (phi(k) = (1/n) sum_{offsets} e^{i k.delta}, real for a symmetric set) the bracket is
A1   (1/n)|n phi|^2 - n = -n (1 - phi^2), so  -log pi = (1/2N) sum_k lambda(k) |theta(k)|^2 with
A1   lambda(k) = beta A(n beta) n (1 - phi(k)^2)    -> the coefficient is beta' = beta A(n beta), not A(n beta)
A1 The claimed formation kernel is sigma^2/(1 - phi^2) with sigma^2 = A(n beta)/(n beta), i.e. an inverse
A1 stiffness n beta (1 - phi^2)/A(n beta). Their ratio is
A1   [1/lambda] / [sigma^2/(1-phi^2)] = 1/A(n beta)^2, the same in every mode,
A1 and 1/A(x)^2 = 1 + 2/x + O(1/x^2), so the two agree to leading order in 1/(n beta) and differ at the
A1 relative order 2/(n beta) - the same order as the quartic terms dropped from the expansion.
A1 exactly A(x) = 1 - 1/x + 2/(e^{2x} - 1): True
