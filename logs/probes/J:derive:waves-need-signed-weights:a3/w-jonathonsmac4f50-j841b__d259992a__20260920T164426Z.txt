W3  the equality case
     ASSUMED (Wielandt's lemma, stated at the scope used): if B is complex, C is
     nonnegative and irreducible, and |B| <= C entrywise, then rho(B) <= rho(C), with
     rho(B) = rho(C) only if B = e^{i phi} D C D^{-1} for some unimodular diagonal D.
     Applied to B = C(k), C = C(0): a branch has |lambda(k)| = 1 only if
       (i)  |W_j(k)_{mn}| = (A_j)_{mn} for every entry, which for NONNEGATIVE weights
            forces each entry's support to be a SINGLE displacement y_{j,mn}; and
       (ii) the resulting phases are a diagonal conjugation times a global phase.
     (i) alone confines k to the set where all differences of displacements within an
     entry are in the dual lattice - a proper closed subgroup, hence with empty
     interior - unless every entry is already single-site.  So |lambda| = 1 on an OPEN
     set forces single-site entries: the rule moves each component rigidly, with no
     spreading.  That is rigid transport, and it is the exception, in any dimension
     and at any number of levels.
