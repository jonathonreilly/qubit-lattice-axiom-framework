## 6. Corollary: arbitrary joint states and the correct reduced statement

\[
 U\rho U^\dagger-V_*\rho V_*^\dagger
 =(U-V_*)\rho U^\dagger+V_*\rho(U^\dagger-V_*^\dagger)
\]
and the trace ideal inequality yield
\[
 \|U\rho U^\dagger-V_*\rho V_*^\dagger\|_1\le2d(t),
 \tag{R12}
\]
with the universal state bound 2 also available. The same inequality holds on arbitrary ancillary extensions; equivalently the unhalved diamond distance between the two joint OE unitary channels is at most \(2d(t)\). One can apply the same two-term expansion to an arbitrary trace-class input operator to obtain the complete induced norm bound directly.

Let \(U_O(t)=e^{-itK}W\) and \(U_E(t)=e^{-itH_E}\). The comparator for a correlated initial state is the actual local-unitary image
\[
 (U_O\otimes U_E\otimes I_F)\rho_{OEF}
 (U_O^\dagger\otimes U_E^\dagger\otimes I_F),
 \tag{R13}
\]
with the phase in (R7) retained for the vector/operator comparison. It generally retains old–environment and passive-reference correlations.

Partial trace is invariant under \(U_E\) acting only on E, even when E is initially entangled with OF. Contractivity of trace norm thus gives
\[
 \left\|\operatorname{Tr}_E[U\rho U^\dagger]
  -(U_O\otimes I_F)\rho_{OF}(U_O^\dagger\otimes I_F)\right\|_1
 \le2d(t),\qquad \rho_{OF}=\operatorname{Tr}_E\rho.
 \tag{R14}
\]
This uses the actual initial marginal, not an assumed preparation map. All extensions sharing that marginal satisfy the same pointwise bound, although their actual reduced and joint outputs need not be identical. For arbitrary correlated input assignments it is not automatically meaningful to declare a single exact reduced CPTP map on O alone. The joint channel comparison and the uniform statement (R14) avoid that ambiguity.

If one instead fixes any density operator \(\sigma_E\) independent of the old/passive input and starts from \(\rho_{OF}\otimes\sigma_E\), the comparator factors as
\[

\]
Here \(\sigma_E\) can be mixed and internally entangled; it need not be a pure, computational-basis or sixfold product state. If \(\sigma_E\) is unknown, the bound is still uniform over it, but its actual evolved state remains in the complete comparator. There is no single fixed numerical environment output shared by all possible supplied \(\sigma_E\).
