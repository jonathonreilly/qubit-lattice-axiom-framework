# Constructed neutral observables with common diagonal blocks

Status: exact-support conditional on the supplied finite native Hamiltonian. This is an observable construction, not a new physical coupling or interaction.

Let H have spectral projectors P_E, and let A be any Hermitian plane-neutral observable. Define B=[H,[H,A]]. Then P_E B P_F=(E-F)^2 P_E A P_F, including P_E B P_E=0 on entire degenerate blocks. Thus O_alpha=H+alpha B has exactly the same diagonal blocks as H for every alpha. In a differentiation experiment H(lambda)=H-lambda O_alpha, every first-order gap slope is -Delta, even at degeneracy. Nevertheless its off-diagonal amplitudes are alpha(E-F)^2 A_EF: inelastic autocorrelation weights vary quadratically with alpha (cross response with a fixed other observable is generally linear) and is zero for alpha=0. This package promotes the explicit observable family and its calculated matrix blocks; the source-nonidentifiability theorem is deferred.

This construction stays in the algebra generated by existing native bonds. For local A and finite-range H, only overlapping bond commutators survive twice, so support grows by at most two interaction steps. Summing translated local A gives an extensive source with the same statement. If H and A are time-reversal even, the double commutator is also even; this symmetry is therefore preserved in the displayed observable family. No term O_alpha is added to the actual Hamiltonian here. Doing so would be a new interaction premise. Alpha is an arbitrary observable-construction coefficient, not inferred physics. If A is dimensionless, alpha has inverse-energy units; numerical controls use J=1.

More generally, for a finite spectrum the full set of operators with P_E O P_E=(a E+b)P_E is O=aH+bI+B, with arbitrary Hermitian off-diagonal blocks B_EF. Such B can be written [H,[H,A]] by A_EF=B_EF/(E-F)^2 away from equal energies. That algebraic inverse need not be local or remain well behaved as gaps close; no local completeness theorem follows. Requiring a local A supplies the explicit local family used in the control.

The root control uses the unchanged open 3x2x1 native model, A=sum_x C_partial,x=2 sum_x e_x^2-N_bonds I at J=1, and alpha=0,.25,1. It checks entire degenerate blocks and the spectral double-commutator identity, then compares full thermal structure-factor inelastic weights at beta=.7 (not just positive-frequency retarded weights). These are exposed synthetic model-development choices; no experimental data, scalar action, gravitational source, or fitted cosmological scale enters.

The constructive next question must fix a source operationally through the native preparation/feature dynamics, not choose its diagonal matrix elements to match universal mass rescaling. A measured response, derived interaction vertex and bulk scaling would constrain different information. The operational vertex-selection question remains open.
