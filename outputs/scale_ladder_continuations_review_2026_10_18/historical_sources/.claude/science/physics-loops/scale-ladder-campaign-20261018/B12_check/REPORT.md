# B12 independent check: all main claims confirmed, no numerical corrections

Provenance: a fresh-context agent of the same model family; not an independent-model review. Its scripts, `b12_check_tadpole_hk.py` and `b12_check_2d_weyl.py`, all pass. Saved by the supervisor from the hand-back.

## Verdicts

1. **Tadpole w = (2/d)g² confirmed** by a gauge-invariant plaquette projector on L^d tori. It reproduces the textbook ⟨1−P⟩ = (N²−1)g²/(8N) in 4D.
2. **Heat-kernel expansion confirmed.**
   - The trX² coefficient is 1/(2τ) − N/24, to 1e−5.
   - The (trX²)² coefficient is O(1), so there is no O(1/g²) quartic term.
   - τ = 3/β for SU(3).
3. **c(d) and the Λ ratios confirmed.** Using an independent contraction, c(d) = (dN² − 8N² + 12)/(24Nd), and c(4) = (3−N²)/(24N).
   - Λ_HK/Λ_W = 1.8188 (SU(3)), 1.2515 (SU(2)), 2.0730 (SU(4)).
   - Λ_MS/Λ_HK = 38.853·e^{−π²/11} = 15.840 for every N. The 38.853 is recalled from memory.
4. **2D 7/4 confirmed exactly**, by direct Weyl integration. k = 0.5, 1.75 and 3.5 for N = 2, 3, 4. W2 is reproduced, and the residues extrapolate to 11.25, 15, 63 and 120. The probe's values (11.5, …) are β = 400 values with O(1/β) corrections.

## Limits

- The 4D one-loop result uses the same structural method as B12; no independent background-field calculation was done.
- The Hamiltonian variant was not checked.
- Literature confirmation (Menotti–Onofri, NPB 190 (1981) 288; Lang–Rebbi–Salomonson–Skagerstam, PLB 101B (1981) 173) could not be retrieved through the proxy.
