The three independent scripts write result files beside themselves and refuse to overwrite existing results. To reproduce, copy quantum_core_check.py, singlet_local_check.py and extra_pair_controls.py to a fresh empty directory, then run each with Python 3 in that order. Only extra_pair_controls imports quantum_core_check; no author module is imported. NumPy and SymPy are required. All stdout, stderr and command/source receipts from the original executions are preserved here. The first local-spin execution stopped without an assertion failure; its source and partial logs remain in failed_attempts/generic_rank_stopped. The replacement uses exact rational-domain rank/nullspace operations, retaining all matrices and claimed quantities. Finite numerical eigenvalue estimates are explicitly labeled; all reported ranks, overlaps, leakage norms and moment/filter identities are exact.
