## What the map excludes, and one narrowing

A structure that writes a new record at the same `Z^3` site on a later tick contradicts AX L79–80 and L166–167. The 3+1 event lattice, a level-ordered past stacked in an extra tick, and the symmetric light-cone past of block 90 are excluded as written, because each needs a record per site per tick. KI does not supply those levels: its extra axis is a loop regulator.

The attempt's phrase "time-levels that are at most two-dimensional" describes the plane-sweep example, where time is taken from one axis of `Z^3`. It is not a bound on every one-record order. A simultaneous forming set may be any subset of `Z^3`, including a three-dimensional chunk. That chunk is still one formation. It does not write the same site again.

"Six neighbours" is the coordination number of the cubic lattice named at AX L37, not a separate axiom sentence. KI L40–41 says records' causal order is not used to derive `c_t = c_s`. It does not say that no other note names a causal order. Whether an unrecorded neighbour enters the "conditions" is open: unreadability (AX L82–83) is not absence from the conditions. Which admissible order is realized is open (RS L21–22). The per-tick amendment in the attempt's S6 is the owner's decision. This confirmation does not adopt it.
