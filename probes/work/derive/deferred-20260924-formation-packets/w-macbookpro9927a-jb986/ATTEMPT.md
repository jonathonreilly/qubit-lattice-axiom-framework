## 1. What is attempted

**One scoped claim, with explicit premises.**
- **Premises.** Let `C` be finite. Let each `p` give a matching `M_p` of oriented pairs, with `L_p = Σ_{(a,b)∈M_p}|+_{ab}⟩⟨−_{ab}|` and `u` the uniform vector. Assume:
  - (i) the graph of all pairs is connected;
  - (ii) `u` is a **cyclic vector** of the unital algebra generated by the `L_pᵀ`.
- **The claim.** For **every** rate vector `γ_p > 0` and **every** Hermitian `H` with `Hu = 0`, the Lindbladian `G = −i[H,·] + Σγ_p D[L_p]` has kernel exactly `span{|u⟩⟨u|}`. So the RK state is the unique stationary state.

**Certificate.**
- (i) and (ii) hold exactly on every flip component with `d ≥ 2`: 82,872 components of nine boxes (open `2×2, 3×2, 2×2×2, 3×3, 4×2, 4×3`; periodic `2×2, 3×2, 3×3`), with `d` up to 30.
- So on these boxes the RK state is the unique stationary state for all parameters. The frozen control covered one parameter point on three boxes.

3. **PROVED; CHECKED F1 (a separating function on every component).** Let `F₂(c) = Σ_j 3^j s_j`, with `s_j = 2c_j − 1 = ±1`.
   - **Injective.** For `s ≠ s′`, take the largest index `j` where they differ. Then `|Σ_{i<j}3^i(s_i − s′_i)| ≤ 3^j − 1 < 2·3^j = |3^j(s_j − s′_j)|`.
   - **Constant displacement.** Raising plaquette `p` changes `F₂` by `δ_p = 2(Σ_{raised}3^e − Σ_{lowered}3^e)`, the same for all its pairs. By the same argument `δ_p ≠ 0`, since its four links are distinct.
   - Checked on all 82,872 components.

4. **PROVED (the criterion).** Every `L_p` is real, so `L_p† = L_pᵀ`.
   - **(a) The target is stationary.** `L_p u = 0` (`⟨−_{ab}|u⟩ = 0`) and `Hu = 0`, so `G(|u⟩⟨u|) = 0`.
   - **(b) A stationary state is orthogonal to every `L_pᵀu`.** For a stationary density `ρ`:

     `d⟨u|ρ|u⟩/dt = ⟨u|G(ρ)|u⟩ = Σ_pγ_p⟨L_pᵀu|ρ|L_pᵀu⟩`.

     The `H` term vanishes because `Hu = 0`, and the anticommutator terms vanish because `L_pᵀL_pu = 0`. At stationarity this forces `ρL_pᵀu = 0`, so `S := supp ρ ⊥ L_pᵀu` for every `p`.
   - **(c) `S` is invariant under every `L_q`.** Let `Q` project onto `S^⊥`. Then

     `0 = QG(ρ)Q = Σ_qγ_q(QL_q√ρ)(QL_q√ρ)†`,

     since `Qρ = ρQ = 0` removes every other term. So `QL_q√ρ = 0`, and `L_qS ⊆ S`.
   - **(d) `S′ := S ∩ u^⊥` is invariant under every `L_q`.** For `x ∈ S′`, `L_qx ∈ S` and `⟨u, L_qx⟩ = ⟨L_qᵀu, x⟩ = 0` by (b).
   - **(e) By (ii), `S′ = 0`.** `S′^⊥` contains `u` and is invariant under every `L_qᵀ`. So it contains the cyclic span of `u`, which is the whole space.
   - **(f) So `ρ = |u⟩⟨u|`.**
     - From (e), `S ∩ u^⊥ = 0`, so `dim S ≤ 1`. Write `S = span{x}`.
     - `L_qx ∈ S` gives `L_qx = λ_qx`, and `L_q² = 0` gives `λ_q = 0`.
     - So `x ∈ ∩_q ker L_q = span{u}` by (i), and `ρ = |u⟩⟨u|`.
   - **(g) The whole kernel.**
     - `e^{tG}` is contractive, so the zero eigenvalue is semisimple.
     - The ergodic projection onto `ker G` is a limit of CPTP maps, hence positive and trace-preserving.
     - So `ker G` is spanned by stationary density matrices, and by (f) it is `span{|u⟩⟨u|}`.
   - **Remark.** (ii) already implies (i). Nonempty words in the `L_qᵀ` send every vector to one with zero sum on each flip component. So with two components the cyclic span of `u` cannot reach every component-sum profile.

## 3. Where the route stops

**The first failing step.** "Separating `F` ⟹ `u` is cyclic" is not proved in general.
- Step 3 gives a separating function on every component of every box. Step 4 shows cyclicity suffices for all parameters. So this one implication would give uniqueness on every geometry.
- The frozen docstring attributes a general "separating-F" argument to a companion note that is not in the frozen tree or on main.
- **A partial handle.**
  - For exponential vectors `v^{(s)}_c = e^{sF(c)}`, `m_qᵀv^{(s)} = 2κ_q(s)P_q^−v^{(s)}`, with `κ_q = (1 + t_q)/(1 − t_q)` and `t_q = e^{sδ_q}`.
  - `P_q^−v^{(s)}` weights `q`'s pairs by `e^{sF(a)}`, and these are distinct across the pairs.
  - So a Vandermonde argument would isolate each pair's difference vector, if the `v^{(s)}` were already in the cyclic span. That premise is circular.

**Not claimed.** Any gap bound, any volume scaling, any physical phase or record compiler, the frozen historical transients, and the converse of step 4.
