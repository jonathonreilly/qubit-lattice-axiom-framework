## Plain-language summary

The source note adds one particle to a sea and asks which occupied site "carries" it. One rule is "weights from the Laplace expansion of the determinant along the added particle's column". The source showed one example where adding ten times a sea orbital to that column (same many-body state, same amplitudes) changed the answer. This attempt shows the example is the tip of the iceberg. Over all equivalent ways of writing the added orbital, the Laplace rule can produce every possible carrier distribution on the occupied sites, including "site j carries it with certainty" for any j. So the Laplace rule adds no information beyond the state until a representative is chosen, and the "canonical" choice (orthogonal to the sea) depends on an inner product that nothing in the axioms or primitives supplies. This is elementary linear algebra, exact in rational arithmetic; it is not a statement about which identity rule nature uses.

## Setting and premises

- ASSUMED (lane-supplied, not axiom content): a free-fermion sea of `N0` single-particle orbitals (columns `S`, an `n x N0` array over sites), one added orbital `a`, state `Psi = c^dag_a |sea>`; configurations are sets of `N = N0+1` occupied sites. `A` is the `N x N` matrix of orbital values (rows occupied sites, column 0 = `a`, columns `1..N0` = sea), amplitude `det A`.
- ASSUMED: the Bell jump process depends on `Psi` only (as in the source), so two representatives of the same state give the same unlabelled occupation trajectories; "carrier" is an extra rule on top (source's own statement).
- Definition: `t_i = A[i,0] (A^{-1})[0,i]`, the i-th Laplace term of `det A` along column 0 divided by `det A`; carrier weights `p_i = |t_i|^2 / sum_j |t_j|^2` (the source's rule).
- Only generic nondegeneracy used: `A` invertible. `Z = {i : b_i = 0}`, `b = row 0 of A^{-1}`.

## Steps

1. PROVED. `sum_i t_i = 1` (Laplace expansion; equivalently `(A^{-1}A)_{00} = 1`). Also `t_i = (-1)^i A[i,0] minor(i,0)/det A`. CHECKED exactly (C1a, C1b: 40 random rational 5x5, cofactor route and inverse route agree).
2. PROVED. `t` is not a probability vector: entries can be negative or complex, and `sum |t_i|^2` is not 1, so `p_i` is an extra normalisation. CHECKED (C1e: 38/40 rational matrices have a negative entry; C3 complex Gaussian-rational via sympy).
3. PROVED. Intrinsic form: with `u` = coefficient vector of the added orbital and `beta` = covector with `beta(u)=1` and kernel the sea, `t_i = (A u)_i (beta A^{-1})_i`, invariant under `A -> A G` for any `G in GL(N)`. Invariance group of `t` for fixed state, fixed sea hyperplane: column-0 scaling and `GL(N0)` mixing of sea columns (Levi part): proof `A' = A diag(lambda, G)` gives `A'_{i0} = lambda A_{i0}`, row 0 of `A'^{-1}` scaled by `1/lambda`. CHECKED exactly (C1d).
4. PROVED. Not invariant under the unipotent part, column 0 -> column 0 + sum_k y_k (sea column k). Then `det A' = det A` and row 0 of `A'^{-1}` is unchanged (`E^{-1} = I - sum y_k e_k e_0^T` alters rows `k>=1` only), so `t'_i = (A_{i0} + (S y)_i) b_i`. The many-body state is unchanged because `c^dag_s |sea> = 0` for `s` in the sea span (Pauli). CHECKED exactly (C1c, C2b).
5. PROVED (realizability theorem). Fix state, sea and `a`. A vector `tau` is the Laplace vector `t(a')` of some `a' = a + S y` if and only if `sum tau_i = 1` and `tau_i = 0` for `i in Z`. Proof: `S` has rank `N0` and `b^T S = 0`, `b.a = 1`, so the left null space of `S` is span(b), and `v` lies in the column space of `S` iff `b.v = 0`. Put `a'_i = tau_i / b_i` off `Z` (and `a'_i = a_i` on `Z`, where `t_i = 0` regardless); then `b.(a'-a) = sum tau - 1 = 0`, so `a' - a = S y` for a unique `y`. Necessity: step 1 and `t_i = a'_i b_i`. Corollary: every carrier distribution `p` supported on `Z^c` occurs (take `tau = sqrt(p)/sum sqrt(p)`), including the deterministic "site j carries it" for any `j` not in `Z`. CHECKED exactly (C2a-C2d: 200 constructions with fresh cofactor determinants; the image dimension is `N0 = N-1` (C2c); forced zeros on `Z` (C2d)).
6. PROVED. Born-ensemble identity: `|Psi|^2 |t_i|^2 = |A_{i0}|^2 |M_{i0}|^2` with `M_{i0}` the sea amplitude on the configuration with site `i` removed. Summing over configurations, `sum_conf |Psi|^2 sum_i |t_i|^2 [x_i=x] = |a(x)|^2 sum_{c' not containing x} |Psi_sea(c')|^2`; for an orthonormal sea this is `|a(x)|^2 (1 - n_sea(x))`. The right side depends on the representative `a` through `|a(x)|^2`, so even the unnormalised ensemble carrier density is representative-dependent while all amplitudes and the true density are not. CHECKED exactly (C4a-C4b, L=6, N0=2, two representatives) and numerically on the physical ring (C7d, 1e-16).
7. PROVED. The "canonical" representative (the unique element of the coset orthogonal to the sea) is defined only relative to an inner product, and also relative to the choice of sea hyperplane: two diagonal-weight inner products give identical amplitudes and different Laplace weights; swapping which orbital is "added" changes `t`. CHECKED exactly (C5, C6). READING: with the standard `l^2` product, orthogonality to the sea is preserved by the unitary one-body evolution, so the canonical choice is time-consistent. That is a reason to prefer it, not a derivation of it; the axioms and primitives supply no inner product.
8. CHECKED (numerical, exact enumeration over all 792 configurations, no Monte Carlo, no time step): antiperiodic ring `L=12`, closed shell `N0=6`, `t=3`. Born weight `1 - N0/L = 0.5` (C7a); all representatives give identical amplitudes (max deviation 1.1e-16, C7b). Born-averaged carrier `<d^2>` (minimal-image distance from the origin): canonical 12.85, plain `e_0` 14.80, five fixed-coefficient shifts by sea orbitals 12.33-12.99, excess-density `<d^2>` 12.88; per-configuration extreme assignments give 0.51 and 30.41 (C7c). Reading: on this small ring and time, fixed-coefficient representatives move the carrier spread by up to 15%; the dramatic freedom of step 5 appears only for per-configuration choices (which step 5 allows, since the source's Laplace identity is a per-time assignment). The source's 12x12 two-dimensional ten-times example (1.27 to 0.63) is not reproduced here. mpmath 50-digit spot check of invariances on one physical configuration (C7e).
9. UNRESOLVED (first unresolved step). No process (nearest-neighbour or otherwise) is built whose marginals at each time realise any given carrier assignment, so "carrier displacement as a trajectory" is not defined by any rule here; only per-time marginals are. Nothing here shows which assignment, if any, nature or the framework would use.
