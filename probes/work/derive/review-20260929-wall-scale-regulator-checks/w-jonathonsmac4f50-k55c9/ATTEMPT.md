## Plain-language summary
The weak-scale formula uses a plaquette from a pure-gauge simulation but a determinant that has matter in it. Putting one unrooted staggered field (4 tastes) in the plaquette measure raises the plaquette by about 0.022. That moves the formula from 246.28 GeV to about 213 GeV, more than 500 times the quoted 0.0255 percent match. I reproduced this with my own HMC, using the same code and boundary conditions with and without matter, on two volumes (4^4 and 6^4). The shift did not shrink between them. This reproduces a defect main already corrected. It does not settle rooting, the light-mass limit, infinite volume, or the rule that picks the vertex power.
