## Verdict in plain words
Neither half is derived; both are priced. The plaquette is not an input but a computable output of the Wilson action (T28), and the licensed value 0.5934 is wrong. The repo's own never-run certification protocol, run here, gives 0.59372(4) at large volume; its April ensembles already say 0.59369(2). Both are 3e-4 high, which the protocol pre-registered as "license broken" (Band D). The weak scale moves from 246.28 to 245.74 GeV and its 0.026% match goes. The vertex power is fixed by no lattice observable: its couplings for n = 1, 2, 4 lie below the smallest coupling the lattice measures, so choosing n means choosing a length scale, which is T30's premise.
