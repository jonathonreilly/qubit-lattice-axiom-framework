## Plain-language summary

The draft asks whether uniform ice's two transverse "polarizations" fluctuate equally at small wavevectors. For the multiset {0,1,1} that is one number: the variance of the free polarization (E_x at k = (0,a,a)) against the variance of the transverse pair. The four original seeds say "equal", a second seed group says "not quite" (2.65 sigma). I re-estimated that one number with a different, much cheaper sampler in which every chain is its own seed, so the error bar comes from seeds and not from batches. At L = 4, 6, 8 the difference is within about 0.2 to 0.3 percent of zero and not resolved from zero. The measured autocorrelation time is only about 1.5 loops, so the draft's batch errors are not understated by autocorrelation. The precision needed to settle the 0.05 percent question at L = 16 is far beyond this check. Exactly at L = 2 the difference is 26 percent, so equality is not forced by symmetry; the landed polarization note already says so.

## Steps

**1. READING of the question.** The draft's null is D = 0 below, where D is the "assignment difference" of the multiset {0,1,1} (draft table row 1: P_zz 1.000 vs 0.500; difference = ratio(small P) - ratio(large P), runner `src/runner.py` lines `ratio`, `PAIRS`).

**2. PROVED (reduction).** Let k = (2pi/L)(0,a,+-a) with a = 1, so s_y^2 = s_z^2 = s^2, s_x = 0. (i) The divergence identity sum_i (1 - e^{-ik_i}) F_i = 0 holds configuration by configuration (landed static-photon note line 20, proved there; checked in step 7 on sampled configurations). With k_x = 0 it reads (1 - e^{-ik_y})F_y + (1 - e^{-ik_z})F_z = 0 and |1 - e^{-ik_y}| = |1 - e^{-ik_z}| != 0, hence |F_y| = |F_z| and S_yy = S_zz. (ii) P_zz = 1 - s^2/(2 s^2) = 1/2 for every L and for either lattice or continuum k_i^2; P_xx = 1 for the same k. (iii) Swapping axes x <-> z is a symmetry of the measure (signed permutations map ice to ice), so S_zz(a,a,0) = S_xx(0,a,a). Therefore the draft's difference is
  D = K_cont [ S_zz(0,a,a)/(1/2) - S_zz(a,a,0)/1 ] = K_cont ( 2 S_zz - S_xx ) at k = (0,a,a),
i.e. the difference between the variance of the transverse pair (S_yy + S_zz = 2 S_zz) and of the free polarization S_xx. A Gaussian field with one stiffness has D = 0. Plain language: D asks whether the two photon polarizations at this wavevector have equal strength. (Landed prior art: the same transverse-eigenvalue comparison is in the static-photon note, which does it by sorted eigenvalues and class averages at L = 8.)

**3. PROVED, CHECKED by B1 (symmetry does not force D = 0).** The stabilizer of k = (0,1,1) in the 48 signed permutations has order 4 (x -> -x, y <-> z, and their product). On the polarization plane {E_y + E_z = 0} it acts on e_x = (1,0,0) and e_t = (0,1,-1) by two different characters: (x -> -x) gives (-1,+1), (y <-> z) gives (+1,-1). Different one-dimensional representations: Schur gives S_xt = 0 and no relation between S_xx and S_tt. So D = 0 is a dynamical statement (equal stiffness), not a consequence of cubic symmetry or of divergence-freeness. check.py B1 verifies the stabilizer and characters by enumeration. This agrees with the landed static-photon note (line 22), which says symmetry enforces degeneracy only on axial and body-diagonal representations.

**4. CHECKED (exact tiny control, disjoint machinery).** On L = 2 I enumerated ice by backtracking over the 24 links with site-by-site pruning (A1): 9600 configurations, 880 at zero winding, 125 winding sectors, <W^2> = 76/25 exactly. This is disjoint from the draft's 2^24 bit-pattern scan (I did not reuse its code); I did not inspect the landed note's own enumeration code, so I claim no independence from it. Exact covariance at the three face-diagonal wavevectors (A2): S_xx = 38/25 for the free component, S_yy = S_zz = 43/75, cross term zero, divergence constraint satisfied on all 9600 configurations. Hence S_tt = 2 S_zz = 86/75, S_xx = 114/75 and, with K_cont = 17/24, **D_2 = -119/450 = -0.2644** (A3). Prior art: the landed static-photon note (`...2026-09-23.md:24`) already reports the eigenvalues 86/75 and 114/75 at (pi,pi,0). So the L = 2 value is a restatement of a landed number, not new.

**6. CHECKED (FFT / projector normalisation, consistent).** The incremental Fourier amplitudes F_i(k_j) are kept as sums with kernel e^{-ik.r}; on closed configurations they equal numpy FFT values to 1e-13 (C1, C4.*a), Parseval sum_k S_ii = N holds exactly, and the transversality identity holds with (1 - e^{-ik}) to 1e-14 but fails with the opposite sign (residual 43 to 172), so the Fourier sign convention and the projector are consistent (the sign test is vacuous at L = 2 because e^{i pi} = e^{-i pi}; it is done at L >= 4).
