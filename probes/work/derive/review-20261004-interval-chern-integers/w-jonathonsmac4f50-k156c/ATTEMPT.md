## Plain-language summary

The two source notes say: the middle gap never closes on certain surfaces, and a floating-point sum of plaquette phases came out as an integer such as +1. They say, correctly, that this is not a proof of the integer, because the phases were computed in ordinary floating point (a 30-digit repeat on one surface is also not a bound).

This attempt closes that specific hole on three torus slices of the Brillouin zone at the coupling "B". It builds, with outward-rounded interval arithmetic, a guaranteed enclosure of every vertex frame, every overlap matrix, every link determinant, every plaquette phase and their sum. The sum of the true plaquette phases is a whole multiple of 2 pi (a fact proved below), so an enclosure of width well below 2 pi pins the integer. Result: +1, 0 and +2 on the three slices, as the notes reported, now with interval windows of width 1e-5 to 1e-7 around the integers. What is still not proved here: the passage from this lattice integer to the continuum Chern number rests on items (iii) and (iv) of the stated admissibility lemma, which I checked only on samples, and I did not redo the cube-surface integers of the first note.

## Steps

1. **PROVED (integrality).** On a closed periodic mesh with frames `U_v` (orthonormal, rank 2) suppose every plaquette product `z_p` is nonzero. Then every link is nonzero (each link sits in a plaquette). Each link `l_vw` occurs in exactly two plaquettes, once as `l_vw` and once as `l_wv = conj(l_vw)` (opposite orientations), so `prod_p z_p = prod_e |l_e|^2 > 0`. Hence `sum_p Arg z_p` is a multiple of `2 pi`. Each `z_p` is invariant under `U_v -> U_v g_v` (`g_v` unitary 2x2), because `det(g_v)^* det(g_v) = 1` at each vertex. CHECKED exactly (sympy, Gaussian rationals, 3x3 torus of random 4x2 frames): the identity `prod_p z_p = prod_e l_e conj(l_e)` holds with difference 0.
2. **PROVED (frame enclosure, Sylvester integral).** Let `H` be Hermitian 4x4, `x` real with exactly two eigenvalues below `x` (so `H` restricted to the upper spectral subspace, `H_Q`, is `> x`), `X` any 4x2 matrix, `M = diag(e1, e2)` real with `e2 < x`, `R = HX - XM`. Then `Y = QX` solves `H_Q Y - Y M = QR`. With `c = (x+e2)/2`, `A = H_Q - c >= (x-e2)/2` and `B = M - c <= -(x-e2)/2`; `Y = int_0^inf e^{-tA} (QR) e^{tB} dt`, so `||QX||_F <= ||R||_F / (x - e2)`. The certified inputs are: interval inertia of `H(v) - x` (exactly two certified negative pivots; Sylvester's law of inertia), and the interval residual `R`.
3. **PROVED (frame error).** Let `G = X^dag X`, `gamma = ||G - I||_F < 1`, `Xo = X G^{-1/2}` (orthonormal). Then `s = ||Q Xo|| <= ||QX||_F / sqrt(1 - gamma)`. The polar factor `U` of `P Xo` is an orthonormal frame of the TRUE occupied space and `||U - Xo|| <= s + s^2` (singular values of `P Xo` lie in `[sqrt(1-s^2), 1]` and `1 - sqrt(1-s^2) <= s^2`). Call this `eps_v`.
4. **PROVED (link and plaquette error).** `U_v^dag U_w - Xo_v^dag Xo_w` has norm `<= eta = eps_v + eps_w`. For 2x2 contractions `A = B + E`: `|det A - det B| <= 2 eta + eta^2` (expand `det(B+E) = det B + tr(adj(B) E) + det E` with `||adj B||_F = ||B||_F <= sqrt 2`, `||E||_F <= sqrt 2 eta`, `|det E| <= eta^2`). All links have modulus `<= 1`, so the four-link products differ by at most the sum `D_p` of the four edge errors. If `D_p < |z~_p|` the principal arguments differ by at most `asin(D_p/|z~_p|) <= x/(1-x)` with `x = D_p / Re z~_p`. The normalised float-frame link is `det(X_v^dag X_w)/sqrt(det G_v det G_w)` (positive real scaling, so same phase).
5. **PROVED (branch-consistent phase enclosure).** If the rectangle `z` has `Re z > 0` and `|Im z / Re z| <= 1`, then `Arg z` lies in `t +- |t|^3/3` with `t = Im z / Re z` (interval quotient), by the alternating series for `atan`. The check certifies `Re z > 0` on every plaquette, so no branch ambiguity exists.
6. **PROVED (window).** By steps 1-5 `2 pi C_lat = sum_p Arg z_p^true` lies in `[S_lo - E, S_hi + E]` (exact Fraction sums of the plaquette enclosures and error terms). Dividing by `2 pi` with outward `pi` bounds gives a window; the integer inside it is unique when the window contains exactly one integer. The check asserts this for every mesh run. No mesh-agreement, 30-digit or positive-gap argument is used for the integer.
7. **PROVED (bridge item i).** `Y_j = Q d_jP P` solves `H_Q Y - Y H_P = -(d_jH)_{QP}`, so `||Y_j||_F <= ||d_jH||_F / g` by the same integral as step 2 (spectra separated by at least `g`).
8. **PROVED (bridge item ii).** `P d_aP d_bP P = Y_a^dag Y_b`, so `tr(P[d_aP, d_bP]) = tr(Y_a^dag Y_b) - tr(Y_b^dag Y_a) = 2i Im tr(Y_a^dag Y_b)` and a plaquette of side `h` carries flux `<= 2h^2 Fro_a Fro_b / g^2`. (Same formula as the source; I derived it independently.)
9. **ASSUMED (A2).** Bridge items (iii) (overlap `I - G`, `||G||_F <= alpha^2 h^2 / 2`, phase mismatch `<= alpha b2 h^3/6 + x^2/(1-x)`, antisymmetric under edge reversal) and (iv) (principal plaquette phase `= Phi_p + sum delta_e` when `|Phi_p| + sum |delta_e| < pi`). I followed the leading-order argument (first correction to `U_v^dag u(h)` is `-(h^2/2) U_v^dag Y^dag Y U_v`, Hermitian, so the phase starts at order `h^3`) and found no error, but I did not write out a full proof.
