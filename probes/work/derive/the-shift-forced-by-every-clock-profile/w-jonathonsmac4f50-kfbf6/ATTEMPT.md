# J:derive:the-shift-forced-by-every-clock-profile:a1 -- attempt (Claude Sonnet 5.5, same family as the supervisor, unrefereed)

Plain language first. The landed note already says: if every clock profile may drive the evolution, then the clock rules force the whole momentum constraint, and with a uniform clock only its lattice divergence. This attempt checks that, and then asks the three questions the task adds. Answers: (1) the same algebra can be read the other way, as a restriction on the clocks at a state whose momentum constraint is not zero; the allowed clocks are the kernel of an antisymmetric matrix, and that kernel is small or empty, not a rich family. (2) The transverse part is forced by a clock with a gradient: a uniform clock plus linear clocks in two independent directions already force it (for fields that fall to zero), without needing every profile. This is first order in the lapse gradient and first order in the fields. (3) Block 112's relabelling extends exactly to a finite lapse that depends on time only, and leaves a remainder when the lapse varies in space.

## 3. Steps

1. [CHECKED, retrieval] The landed bracket is recomputed independently from the stencil (`dC[N]/dh_jj = K(Delta_j N - sum_i Delta_i N)`, `dC[N]/dh_ij = 2K dN`, kinetic derivatives as in block 112) on 3^3 and 4^3 tori with random integer lapses and rational `alpha = 1/3`, `K = 2/5`: `{C[N],C[M]} = G[xi(N,M)]` exactly at `c = 1/2`, and not at `c = 1/3` (check.py A1, A2). Not new.
2. [CHECKED, retrieval] Over all lapses the `xi(N,M)` span every bond field (rank 81 on 3^3, 192 on 4^3); with `N = 1` they span only gradients (rank 26, 63 = sites - 1) (B1, B2). Landed T1(a),(b); not new.
3. [PROVED] The preservation condition is an antisymmetric operator. Let the total Hamiltonian be `H_T = sum_x lam_x C_x` with `lam` any lapse, possibly depending on the state. Then `d/dt C[M] = {C[M], H_T} = sum_x lam_x {C[M], C_x} + sum_x {C[M], lam_x} C_x`, and the second sum is weakly zero because `C_x = 0` on the constraint surface. So state dependence of the clocks adds nothing. By step 1, `{C[M], C[lam]} = -G[xi(lam, M)]`, and for a state with momentum-constraint density `G_j(x)` (the bond field with `G[xi] = sum xi_j(x) G_j(x)`, i.e. `G = D^T P`), `G[xi(lam,M)] = (K/4a) M^T A_G lam`, with `A_G[x, x+e_j] = G_j(x)`, `A_G[x+e_j, x] = -G_j(x)`, all other entries 0 (checked exactly, C1, C2). Consistency for every `M` is `A_G lam = 0`. So the consistent clocks at that state are exactly `ker A_G`.
4. [PROVED, with CHECKED samples] Properties of `A_G`: (a) antisymmetric; (b) `(A_G 1)_y = sum_j (G_j(y) - G_j(y-e_j))`, so the uniform clock is consistent iff `div G = 0` (D2); (c) for side at least 3 a single nonzero bond value gives exactly one nonzero pair of entries, so `A_G = 0` iff `G = 0` (D5), hence all lapses are consistent iff `G = 0`; (d) an antisymmetric matrix of odd size has determinant 0, so on a torus with an odd number of sites (3^3: 27) every state has a nonzero consistent lapse (D4, `det = 0` exactly); (e) `det A_G = Pf(A_G)^2` is a polynomial in the state, and on 4^3 (64 sites) rank 64 is found at random integer states (D1), so off a proper algebraic subset of states the consistent lapse on a 4^3 torus is only `lam = 0`: no clock at all. On 3^3 the rank is 26 and the kernel is 1-dimensional at random states (D1). [Genericity on 4^3 rests on one exact rank witness per sample; the polynomial argument is the proof.]
5. [CHECKED, data] On 3^3 the 1-dimensional consistent lapse of 12 random states has entries of both signs in all 12 (H1). So a positive clock is not automatic in the restriction branch. This is data, not a theorem.
6. [PROVED, using checked identities] Lattice drifting relabellings satisfy `div G = 0` exactly. For a pure-gradient relabelling `xi_j = M_{x+e_j} - M_x`, the DeWitt momentum of `D xi` at `c = 1/2` is `Lambda D grad M = (4a/K) dC[M]/dh` (E0b, exact on 3^3 and 4^3). The linear curvature term is relabelling-invariant, `<dC[N]/dh, D xi> = 0` for all `N, xi` (E0, exact). `Lambda` is symmetric. For any bond field `xi`, with `P = Lambda D xi`, `div G` paired with `M` is `<Lambda D xi, D grad M> = <D xi, Lambda D grad M> = (4a/K) <D xi, dC[M]/dh> = 0`. So the drifting relabellings (block 144's twists, lattice form) have `G != 0` for transverse `xi` (E2) and `div G = 0` exactly (E1): a uniform clock keeps them consistent, as the landed T1(c) second bullet says; this adds the exact lattice proof of the divergence-freeness.
7. [PROVED on Z^3 for finitely supported or decaying `G`; CHECKED on a padded box] Minimal lapse families. For `lam = 1`: `div G = 0`. For `lam = x_a` (the coordinate), `(A_G x_a)(y) = y_a (div G)(y) + G_a(y) + G_a(y - e_a)` (F2 exact at every box site). With `div G = 0` this is `G_a(y) = -G_a(y - e_a)`: the modulus of `G_a` is constant along axis `a`, so finite support (or decay) gives `G_a = 0`. Take `{1, x_1, x_2}`: `G_1 = G_2 = 0` and `div G = 0` leaves `G_3(y) = G_3(y - e_3)`, hence `G_3 = 0`. So a uniform clock plus linear clocks in two independent directions force the whole `G = 0`, for finitely supported or decaying `G`. Exact padded-box ranks (6^3 box, `G` supported on the interior, 192 unknowns): family `{1}` leaves a 81-dimensional solution space, `{1, x_1}` leaves 36 and has `G_1 = 0` throughout (F3), `{1, x_1, x_2}` leaves 0 (F1). So the transverse (divergence-free) part needs a clock with a gradient; the order is first in the lapse gradient and first in the fields. It does not need every profile. [Without the uniform lapse, `{x_1, x_2, x_3}` also leaves 0 in the box, F1 data.]
8. [CHECKED, data, not a theorem] On periodic tori the same families do not give the same clean picture, because a linear clock does not wrap. With sawtooth lapses `f(x_a) = x_a` added to `{1}`, the span has rank 26, 51, 72, 81 on 3^3 (full 81), 63, 109, 151, 181 on 4^3 (full 192, deficit 11), and 124, 245, 350, 375 on 5^3 (full 375). The even torus keeps a staggered deficit. This is data for the statement that the finite-torus version of step 7 depends on the parity of the side.
9. [CHECKED] A plane-wave drifting twist on 4^3, `xi = e_2 cos(pi x_1/2)`, has `G` along `e_2` only and `div G = 0` (G1). Its consistent clocks are the lapses `N(x_1, x_3)` not varying along the twist direction; a lapse localized on one site or with a sawtooth in `x_2` is not consistent (G2, G3, G4); the kernel dimension is 48, which equals the count of lapses that are 2-site periodic along `x_2` where the twist is present and free elsewhere (G5). So the restriction branch for a twist is "no clock gradient along the twist direction".
10. [CHECKED, symbolic, continuum comparator form] Finite lapse for block 112's T2, in the sector kinetic `(alpha/N)(hdot_ij hdot_ij - (tr hdot)^2)` (`beta = -alpha`) plus `K N R1(h)`, with the landed sign `R1 = -(d_i d_j h_ij - lap tr h)`.
