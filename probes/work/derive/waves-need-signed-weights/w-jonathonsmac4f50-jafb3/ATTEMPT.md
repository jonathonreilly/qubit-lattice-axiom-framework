## 1. Statements attempted

**The model** (block 13's linear formation law in level time, PR #8147, with several earlier levels). Level planes `Zᵈ`, levels
`t ∈ Z`:

`θ_{t+1}(x) = Σ_{j=0}^{J−1} Σ_y w_j(y) θ_{t−j}(x − y) + ξ_{t+1}(x)`,

with finitely supported weights. Noise does not enter the dispersion relation. A mode `θ_t(x) = λ^t e^{ik·x}` requires

`P_k(λ) = λ^J − Σ_j W_j(k) λ^{J−1−j} = 0`, where `W_j(k) = Σ_y w_j(y) e^{−ik·y}`.

The *branches* are the `J` roots. In section (a) the weights are nonnegative with gain `Σ_{j,y} w_j(y) = 1`. The *space-time step*
`(Y, T)` has law `P(Y = y, T = j+1) = w_j(y)`, with support `S ⊂ Zᵈ × {1, …, J}`. `Λ ⊂ Z^{d+1}` is the subgroup generated by `S`.

**(a) Multi-level theorem.** For nonnegative weights with gain one:

- (A1) Every branch has `|λ(k)| ≤ 1`. With gain `< 1`, every branch has `|λ| < 1`.
- (A2) A unimodular `λ` is a root at `k` iff `e^{−ik·y} = λ^t` for every `(y, t) ∈ S`.
- (A3) The set `U*` of `k` at which some branch is unimodular is the projection of the closed subgroup
  `Λ^⊥ = {(k, ω) : k·y − ωt ∈ 2πZ for all (y,t) ∈ Λ}` (with `λ = e^{−iω}`). `U*` has nonempty interior iff `rank Λ = 1`.
  Rank 1 holds iff every space-time step lies on one ray `y = t v`, `v ∈ Qᵈ` (*rigid transport*: every record copies one predecessor
  at one fixed space-time velocity). Otherwise `U*` is a closed subgroup of the `k`-torus of dimension `≤ d − 1`: nowhere dense and
  null.
- (A4) In the rigid case, `P_k(λ) = e^{−ikJ·v} Q(λ e^{ik·v})` with `Q(μ) = μ^J − Σ_j W_j(0) μ^{J−1−j}`.
  - The unimodular branches are exactly `ζ e^{−ik·v}`, `ζ^g = 1`, where `g = gcd{t : (y,t) ∈ S}`.
  - The others are `μ e^{−ik·v}` with fixed `|μ| < 1`.
  - All branches share one velocity `v`: no dispersion, and no two unimodular branches move differently.
- (A5) The root through `λ = 1` at `k = 0` is simple, and near `0` it equals
  `λ₀(k) = exp(−i v̄·k − ½ kᵀDk + O(|k|³))`, with `v̄ = E[Y]/E[T]` and `D = E[(Y − v̄T)(Y − v̄T)ᵀ]/E[T]`. For `J = 1` this is the
  GIVEN.

So "no branch has `|λ| = 1` on an open set" holds for every nonnegative multi-level rule except the rigid transports. Those are the
exception, and they carry one velocity, not a wave.

**(b) Minimal signed rules.** Real two-level rules `θ_{t+1} = w₀ * θ_t + w₁ * θ_{t−1}` (signs allowed, finite support).

- (B1) Both branches are unimodular on an open set of `k` iff:
  - `w₁ = c δ_{y₁}` with `c = ±1`; and
  - `w₀` is symmetric about `y₁/2` (`c = −1`) or antisymmetric about `y₁/2` (`c = +1`); and
  - `|A(k)| ≤ 2` somewhere, where `A(k) = W₀(k) e^{ik·y₁/2}`, which is real resp. imaginary.

  The branches are then unimodular exactly where `|A| ≤ 2`.
- (B2) Minimal negativity. At least one negative weight is needed; with none, only the positive copy `θ_{t+1} = θ_{t−1}(· − y₁)`
  qualifies, which is (A4). The rules with exactly one negative weight are two families:
  - the **a-family** `θ_{t+1} = 2a P θ_t − θ_{t−1}(· − y₁)`, with `P` a probability kernel symmetric about `y₁/2` and `0 < a ≤ 1`;
  - the **leapfrog family** `θ_{t+1} = s(θ_t(· − u) − θ_t(· − y₁ + u)) + θ_{t−1}(· − y₁)`, `0 < |s| ≤ 1`.
- (B3) Dispersion, stability region and speed of the a-family (with `y₁ = 0`):
  - `cos ω(k) = a P̂(k)`.
  - The gain is `2a − 1`.
  - Bounded iff `|a| < 1`; marginal at `a = 1` (a double root at `k = 0`, `θ_t = A + Bt`); unstable for `a > 1`.
  - At `a = 1`: `ω = √(kᵀCk) + O(|k|³)`, `C = Σ_y P(y) y yᵀ`, so the cone speed along `n̂` is `√(n̂ᵀCn̂)`. The 1D nearest-neighbour
    average gives `ω = |k|` exactly. The 3D nearest-neighbour average gives speed `1/√3` with a direction-dependent `k³` term.
  - For `a < 1`: a gap `ω(0) = arccos a`; in 1D the maximal group velocity is `a`.

**(c) Amplitudes.** The two-component nearest-neighbour unitary rule on the 1+1 event lattice:
`ψ_{t+1}(x) = Π_R C ψ_t(x − 1) + Π_L C ψ_t(x + 1)`, `C ∈ U(2)`.

- (C1) Each amplitude component obeys `ψ_{t+1} = tr U(k) ψ_t − det C ψ_{t−1}` (Cayley–Hamilton).
  - After the gauge `ψ → e^{−iαt} e^{−iφx} ψ`, this is the a-family with `a = cos θ`, `P` the nearest-neighbour average, where
    `C = e^{iα}[[a, b], [−b̄, ā]]`, `|a| = cos θ`, `φ = arg a`.
  - A real orthogonal coin needs no gauge and keeps the amplitudes real.
  - The gain-one member `a = 1` occurs only at `θ = 0`, where `C` is diagonal: two decoupled chiral copy rules, which are positive.
- (C2) Record statistics at a single readout level: `Σ_x p_t(x) = 1`, support `|x| ≤ t`, and `E[X_t²]/t² → 1 − sin θ` for every
  initial spinor at the origin. Spreading is ballistic.
- (C3) If every event's record is read when it forms, the same rule is the positive persistent walk:
  - `E[X_t²] = t(1+ρ)/(1−ρ) − 2ρ(1 − ρ^t)/(1−ρ)²`, with `ρ = cos²θ − sin²θ`;
  - it is diffusive, `D = cot²θ`.
- (C4) What is kept and what is lost:
  - kept: order-independence and invertibility (unitarity);
  - lost: the massless static kernel (the static resolvent is massive, `G(x) = (5/8) 3^{−|x|}` at `cos θ = 3/5`) except at `θ = 0`;
  - lost: the Markov property of the record statistics in level time;
  - lost: reading at every level.

## 2. Steps

### (a)

**A1 (PROVED).** Let `W_j = W_j(0) ≥ 0`, `Σ W_j = 1`. If `|λ| > 1`, then
`|λ|^J = |Σ_j W_j(k) λ^{J−1−j}| ≤ Σ_j W_j |λ|^{J−1−j} ≤ |λ|^{J−1} Σ W_j < |λ|^J`, a contradiction. With `Σ W_j < 1` the same
chain excludes `|λ| ≥ 1`.

**A2 (PROVED).** Let `|λ| = 1` be a root. Then `1 = |Σ_j W_j(k) λ^{J−1−j}| ≤ Σ_j |W_j(k)| ≤ Σ_j W_j = 1`, so both inequalities are
equalities:

- `|W_j(k)| = W_j`, so `e^{−ik·y}` is constant on `supp w_j`;
- the nonzero terms `W_j(k) λ^{J−1−j}` share one argument, and their sum is `λ^J`, so each term equals `W_j λ^J`.

Hence `W_j(k) = W_j λ^{j+1}`, i.e. `e^{−ik·y} = λ^{j+1}` on `supp w_j`. Conversely, under that condition
`Σ_j W_j(k) λ^{J−1−j} = λ^J Σ W_j = λ^J`.

**A3 (PROVED).** By A2, `k ∈ U*` iff some `ω` has `k·y − ωt ∈ 2πZ` on `S`, hence on `Λ`. So `U* = π(Λ^⊥)`, where `π` forgets `ω`.

- `Λ^⊥` is a closed subgroup of `T^{d+1}` of dimension `d + 1 − rank Λ`, and its image `π(Λ^⊥)` is a closed subgroup of `Tᵈ`.
- If `rank Λ ≥ 2`, the image has dimension `≤ d − 1`: a finite union of translates of a lower-dimensional subtorus, hence nowhere
  dense and null.
- If `rank Λ = 1`, then `Λ = Z(u, m)` with `m ≥ 1` (all `t > 0`). Every `(y, t) ∈ S` is `n(u, m)` with `n = t/m`, so `y = t v`,
  `v = u/m`. For every `k`, `ω = k·u/m` works, so `U* = Tᵈ`.
- Conversely, if `y = t v` on `S`, the rank is 1.

*CHECKED (A3):* the ranks of the four rigid examples (1) and of three generic ones (2, 3, 2), exactly. *Numerical (A-num):* 300
random nonnegative gain-one rules (`d = 1..3`, up to 4 levels, 40 random `k` each) have `max |λ| = 1.000000000000`. A unimodular root
occurred at random `k` for none of the rank-`≥ 2` rules and for every rank-1 rule.

**A4 (PROVED).** Substitute `λ = μ e^{−ik·v}` into `P_k`, using `W_j(k) = W_j e^{−ik·(j+1)v}`. This gives
`P_k = e^{−ikJ·v} Q(μ)`. By A2, the unimodular roots are the `μ` with `μ^{j+1} = 1` for every active lag, i.e. `μ^g = 1`. All
branches are `μ e^{−ik·v}` with `k`-independent `μ`, so each moves at velocity `v` with fixed `|μ|`.

*CHECKED (A4):* the identity symbolically for four rigid rules (1D and 2D, `g = 1, 2`). In each, `Q = (μ^g − 1) R` with

**A5 (PROVED).** Let `F(k, s) = Σ_{(y,t)} P(y,t) e^{−ik·y − st} − 1`. Then `P_k(e^s) = −e^{sJ} F(k, s)`.

- `F(0,0) = 0` and `∂_s F(0,0) = −E[T] ≠ 0`, so the analytic implicit function theorem gives a unique analytic `s(k)` with `s(0) = 0`.
  The root is simple because `P_0'(1) = 1 + Σ_j j W_j = E[T] > 0`.

  `−ik·E[Y] − sE[T] + ½E[(ik·Y + sT)²] + O(3) = 0`,
  so `s = −i v̄·k − ½ E[(k·(Y − v̄T))²]/E[T] + O(|k|³)`.

### (b)

**B1 (PROVED).** The product of the branches is `−W₁(k)`. If both are unimodular on an open set, then `|W₁|² = 1` there. So the
trigonometric polynomial `|W₁|² − 1` vanishes identically, and `W₁ W₁* = 1` in the Laurent ring. The units of a Laurent polynomial
ring over a field are monomials: in `fg = 1`, the product of the extreme monomials of `f` and `g` in a monomial order must be the
only term. So `W₁ = c e^{−ik·y₁}`, `c` real, `c² = 1`.

Put `λ = e^{−ik·y₁/2} ν`. Then `ν² − A ν − c = 0`, with `A = W₀ e^{ik·y₁/2}`.

- `c = −1`: `ν` and `1/ν` are the roots, and both are unimodular iff `A = ν + ν̄ ∈ [−2, 2]`.
- `c = +1`: with `ν = iη`, `η² − (A/i) η + 1 = 0`, so both are unimodular iff `A ∈ i[−2, 2]`.

Real-valued (or imaginary-valued) on an open set means everywhere, which means `w₀` is symmetric (antisymmetric) about `y₁/2`.
*CHECKED (B1, B4):* Vieta and the discriminants symbolically.

**B2 (PROVED).** With all weights `≥ 0`, `c = +1` forces `w₀` antisymmetric and nonnegative, i.e. `w₀ = 0`: the positive copy of

**C1 (PROVED; CHECKED).** `U(k) = diag(e^{−ik}, e^{ik}) C`. Cayley–Hamilton for 2×2 matrices gives
`U² − (tr U) U + (det U) I = 0`, so every component obeys `ψ̂_{t+1} = tr U ψ̂_t − det U ψ̂_{t−1}`.

For `C = e^{iα}[[a, b], [−b̄, ā]]`: `tr U = 2e^{iα}|a| cos(k − arg a)` and `det U = e^{2iα}`. The gauge `χ_t(x) = e^{−iαt} e^{−iφx} ψ_t(x)`

*CHECKED (C1):* symbolically for the orthogonal and the symmetric coin, and the general identity; `U` unitary.

*CHECKED (C2):* an exact rational walk with the Pythagorean coin `cos = 3/5`, `sin = 4/5` (real orthogonal, `ψ₀ = δ₀(1, 0)`),

**C2 (PROVED; CHECKED).** Write the position operator in Fourier as `X = i∂_k`. With `A(k) = U(k)^{−1} i ∂_k U(k)` (Hermitian because
`U` is unitary):

- `X_t := U^{−t} X U^t = X + Σ_{s<t} U^{−s} A U^s`.
- For `ψ₀` at the origin, `Xψ₀ = 0`, so `E[X_t²] = ‖X_tψ₀‖²`.

*CHECKED (C4):* the closed form exactly for every `t ≤ 120` at `ρ = −7/25` (`D = 9/16 = cot²θ`). `E[X_{120}²] = 67.84`, against the

**C4 (PROVED; CHECKED).**

- *Order-independence.* Each event's amplitude is a fixed linear function of its predecessors' amplitudes, so every linear extension
  of the causal order computes the same values. *CHECKED (C6):* level by level against a light-cone sweep for `t ≤ 16`.
- *Invertibility.* `U^{−1} = U^†`, and the scalar recursion is symmetric under `t → −t`. *CHECKED (C6):* running backward from levels

  - A nonnegative rule is not invertible in this sense: its multipliers have `|λ| < 1` off a null set (A1–A3), except the rigid
    transports.
- *The static kernel.* The static resolvent of the amplitude recursion solves `(2 − 2aP)G = δ`.
  - At `a = cos θ = 3/5`, `G(x) = (5/8)·3^{−|x|}` (CHECKED, `|x| ≤ 59`): massive, with `cosh μ = 1/a`.
  - At `a = 1` (`θ = 0`), `G(x) = −|x|/2`, the massless 1D Green function (CHECKED).
  - The gain-one nonnegative law's time-summed response `Σ_t P̂^t = 1/(1 − P̂)` is massless. So the unitary rule keeps the massless
    static kernel only in its decoupled limit.
- *Lost.*
  - The weights are no longer probabilities: the amplitude recursion has the weight `−1`, and general amplitudes are complex or signed.
  - The record statistics are not Markov in level time.
  - Reading every record at formation restores a positive law and diffusion (C3). The propagation lives only in unread amplitudes

## 3. Findings beyond the task's framing (for the referee)

- **The (a) exception.** "No branch unimodular on an open set" holds exactly for the non-rigid rules. Rigid transport (deterministic
  copying at one velocity) is unimodular everywhere, but it is advection with one velocity, not a wave (A4).
- **Waves in 1+1 without signed weights.** The massless 1+1 wave recursion `θ_{t+1} = θ_t(x−1) + θ_t(x+1) − θ_{t−1}` is solved by
  `θ = ψ_R + ψ_L` with `ψ_R(t+1, x) = ψ_R(t, x−1)` and `ψ_L(t+1, x) = ψ_L(t, x+1)`: two positive chiral copy rules. That is (C1) at
  `θ = 0`. So in 1+1, two record components already carry the massless wave with nonnegative weights.
  - What signed or unitary amplitudes add is mixing between the components without damping: the massive a-family, `a = cos θ < 1`.
  - Positive mixing (the persistent walk, a stochastic `|C_ij|²`) gives the damped, telegraph-type law and diffusion.
  - In `d ≥ 2`, finitely many chiral copy components give finitely many velocities, not an isotropic cone.

## 4. What remains open

- **The vector version of (a).** For nonnegative matrix weights (several record components, stochastic mixing), are the rules with a
  unimodular branch on an open set exactly the componentwise copies (permutation-type weights)? Not proved here. The chiral pair and
  the persistent walk are the two sides of it.
- **(b) beyond two levels.** The minimal signed rules with `J ≥ 3` levels are not classified. The two-level classification (B1–B2)
  is complete.
- **(c) in higher dimensions.** Which multi-component unitary nearest-neighbour rules on `Z³` give an isotropic cone? The eta-twisted
  eight-component family of the UT placement note is one candidate, with cone speed `1/√3` per tick. The 3+1 event-lattice version is
  not treated here.
